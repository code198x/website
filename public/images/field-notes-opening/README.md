# Field Notes opening artwork

Original imagined editorial workbench illustration, generated using the built-in image_gen tool. Abstract paper traces, electronics and the loose thread suggest investigation; none is historical or technical evidence. No third-party images, logos, named people or software captures were supplied.

The approved landscape concept is delivered at 1280 and 2172 pixels wide. A separate portrait composition, derived from that concept, is delivered at 600 and 1122 pixels wide. The heading is live text, outside the raster. The page visibly identifies the art as AI-generated illustration.

`provenance.json` records exact prompts, source identities/hashes, processing and delivery dimensions/hashes/byte sizes. Each WebP embeds its exact generation prompt in XMP and has a prompt sidecar. Sources were proportionally resized and WebP-encoded at quality 84; metadata insertion was verified not to change decoded pixels. Master originals are retained with the design evidence, not exposed as production downloads.
