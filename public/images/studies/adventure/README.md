# Adventure study imagery

The header is original editorial artwork generated with the built-in image tool. It imagines a cave; it is neither a historical screenshot nor a reconstruction of a surveyed location. `header-prompt.txt` and `provenance.json` record the prompt and conversion.

The six SVGs are three original explanatory diagrams in wide and phone compositions, copied byte for byte from the committed documentation study. The study source record stores their hashes and canonical revision.
