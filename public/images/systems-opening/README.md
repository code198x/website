# Systems opening photographs

These are separate photographic works arranged in CSS around live text. Their
individual source and licence records are in `provenance.json`, with visible
credits under **Photographs and credits** on `/systems/`.

- Atari 400: Evan-Amos, **CC BY-SA 3.0**. Both resized WebP delivery copies retain
  that licence: https://creativecommons.org/licenses/by-sa/3.0/ . The file record
  is https://commons.wikimedia.org/wiki/File:Atari-400-Comp.png .
- Acorn Electron: Bilby, **CC BY 3.0**:
  https://creativecommons.org/licenses/by/3.0/ . Source:
  https://commons.wikimedia.org/wiki/File:Acorn_Electron_4x3.jpg .
- Sony HB-10P: Doppelgangland / Ubcule, public-domain author dedication; the
  supplied transparent derivative already includes Ubcule's retouching.
- C64 and NES: Evan-Amos, public domain. Amiga 500 Plus: Sernot / Ubcule,
  public domain, including existing retouching. Exact file pages are in the record.
- ZX Spectrum: the project's existing supplied photograph.

Delivery changes: proportional resize and WebP encoding. The complete input
frames remain in the delivery files. CSS positions, rotates, blends white
backgrounds into paper and clips some edges at the artwork boundary. No AI
retouching, generated hardware details or altered marks are used.

For existing photos, input hashes identify the metadata-bearing website copies.
Original-source hashes are also recorded; decoded RGB pixels were verified equal
to the held originals. New source SHA-1 values were matched against Commons'
individual imageinfo records. A collection name or site's footer licence was not
used as evidence of permission.
