## Download Instructions

1. Visit the Wikimedia Commons links above
2. Click on an image to view it
3. Look for "Download" or resolution options
4. Choose the highest quality available
5. Save with descriptive names like "commodore-vic-20.jpg"
6. Copy to: public/images/systems/

## Naming Convention

Use lowercase with hyphens, matching the .md filename:

- commodore-vic-20.jpg
- texas-instruments-ti-994a.jpg
- coleco-colecovision.jpg
- etc.

## Quick Terminal Commands

After downloading to Downloads folder:

```bash
# Example for moving images (adjust filenames as needed)
cp ~/Downloads/vic20.jpg public/images/systems/commodore-vic-20.jpg
cp ~/Downloads/ti994a.jpg public/images/systems/texas-instruments-ti-994a.jpg
# etc.
```
