# Code Like It's 198x: System Expansion Plan

## CORE STRUCTURE: Powers of 2 Consistency

### **Complete Course Architecture**
- **Phases 0-8**: 9 total phases (Phase 0 optional per system)
- **16 Tiers** per phase (2⁴)
- **32 Lessons** per tier (2⁵)
- **4 Tiers per Game** (2²)
- **8 Games per Phase** (2³) - excluding Phase 0
- **64 Complete Games per System** across Phases 1-8

### **Phase Zero: High-Level Programming Foundation**
**For Systems with Built-in Programming Languages**
- **16 Tiers** of BASIC/FORTH/native language programming
- **32 Lessons per Tier**

- **Educational Bridge**: Prepares students for assembly programming
- **Historical Authenticity**: How people actually learned these systems

## SYSTEM EXPANSION PRIORITIES

### **Tier 1 Priority Systems** (Immediate Educational Value)

#### **Dragon 32/64 (1982-1984) - TOP PRIORITY**
- **CPU**: Motorola 6809 (unique 8-bit architecture)
- **Phase Zero**: Microsoft Extended Color BASIC
- **Assembly Uniqueness**: 
  - Advanced 8-bit architecture (neither 6502 nor Z80)
  - 16-bit arithmetic operations
  - Advanced addressing modes
  - Clean, orthogonal instruction set
- **Game Concept**: "Dragon's Lair Explorer" - adventure showcasing 6809's advanced features
- **Educational Value**: Third major 8-bit architecture approach
- **Historical Significance**: Popular in UK/Europe, influenced later processors
- **Why Priority**: Fills major gap in 8-bit CPU education

#### **Apple II (1977)**
- **CPU**: 6502 (different approach from C64/NES)
- **Phase Zero**: Applesoft BASIC
- **Assembly Uniqueness**: Creative graphics programming, disk system control
- **Game Concept**: "Pixel Painter Pro" - graphics game leveraging Apple II's unique color system
- **Educational Value**: Alternative 6502 programming style, business computing heritage
- **Historical Significance**: Launched personal computer revolution
- **Why Important**: Shows 6502 in business/education context vs. gaming focus

#### **BBC Micro (1981)**
- **CPU**: 6502 (educational focus)
- **Phase Zero**: BBC BASIC (extremely powerful)
- **Assembly Uniqueness**: Professional development environment, educational design
- **Game Concept**: "Logic Academy" - educational programming puzzles
- **Educational Value**: Best-documented vintage system, designed for learning
- **Historical Significance**: Shaped UK computing education
- **Why Important**: Ultimate educational computer, professional assembly development

#### **MSX (1983)**
- **CPU**: Z80 (standardized approach)
- **Phase Zero**: MSX-BASIC (Microsoft standard)
- **Assembly Uniqueness**: Standardized hardware, international platform
- **Game Concept**: "MSX Commander" - strategy game showcasing TMS9918 graphics
- **Educational Value**: Z80 in standardized, sprite-oriented environment
- **Historical Significance**: Massive in Japan, Brazil, parts of Europe
- **Why Important**: International Z80 standard, sprite-based graphics

### **Tier 2 Priority Systems** (Specialized Educational Niches)

#### **Jupiter Ace (1982)**
- **CPU**: Z80
- **Phase Zero**: FORTH (unique language!)
- **Assembly Uniqueness**: Z80 in FORTH environment
- **Game Concept**: "FORTH Quest" - programming puzzles using FORTH concepts
- **Educational Value**: Only home computer with FORTH built-in
- **Historical Significance**: Unique approach to home computing
- **Why Interesting**: Teaches FORTH programming + Z80 assembly

#### **Amstrad CPC (1984)**
- **CPU**: Z80
- **Phase Zero**: Locomotive BASIC
- **Assembly Uniqueness**: Integrated computer/monitor, Mode 0 graphics
- **Game Concept**: "Color Command Center" - strategy using CPC's colorful graphics
- **Educational Value**: Z80 with unique graphics modes
- **Historical Significance**: Popular in Europe, affordable computing
- **Why Useful**: Alternative Z80 approach with distinctive graphics

#### **Oric-1/Atmos (1983)**
- **CPU**: 6502
- **Phase Zero**: Microsoft BASIC
- **Assembly Uniqueness**: High-resolution graphics, French design
- **Game Concept**: "Oric Orchestra" - music/graphics showcasing capabilities
- **Educational Value**: 6502 with unique European perspective
- **Historical Significance**: French computing independence
- **Why Notable**: European 6502 alternative to Apple II

### **Tier 3 Priority Systems** (Assembly Only - No Phase Zero)

#### **Atari 2600 (1977)**
- **CPU**: 6507 (simplified 6502)
- **Phase Zero**: N/A (cartridge-based console)
- **Assembly Uniqueness**: Extreme constraints, cycle-perfect timing
- **Game Concept**: "Scanline Racer" - racing game teaching raster programming
- **Educational Value**: Ultimate constraint programming challenge
- **Historical Significance**: Launched video game industry
- **Why Essential**: Master class in optimization and timing

#### **Game Boy (1989)**
- **CPU**: Sharp LR35902 (Z80-like)
- **Phase Zero**: N/A (game console)
- **Assembly Uniqueness**: Portable constraints, battery efficiency
- **Game Concept**: "Pocket Platformer" - showcasing portable game design
- **Educational Value**: Mobile programming constraints
- **Historical Significance**: Portable gaming revolution
- **Why Important**: Battery-conscious programming, portable design

#### **Atari ST (1985)**
- **CPU**: 68000 (alternative to Amiga)
- **Phase Zero**: N/A (GEM desktop environment)
- **Assembly Uniqueness**: Clean 68000 implementation, MIDI focus
- **Game Concept**: "Digital Symphony" - music creation with visuals
- **Educational Value**: Alternative 68000 approach, MIDI programming
- **Historical Significance**: Music production powerhouse
- **Why Valuable**: Different 68000 perspective from Amiga

## PHASE ZERO CURRICULUM DESIGN

### **Learning Progression Strategy**
- **Phase Zero**: High-level programming in system's native language
- **Bridge Lessons**: Final Phase Zero tiers introduce assembly concepts
- **Phase 1**: Assembly fundamentals through game creation
- **Phases 2-8**: Advanced assembly techniques and complex games

### **Phase Zero Benefits**
1. **Gentler Introduction**: Complete beginners start with familiar concepts
2. **System Familiarity**: Students learn hardware before assembly
3. **Historical Authenticity**: How people actually learned these systems
4. **Motivation Building**: Success with BASIC/FORTH builds confidence
5. **Concept Foundation**: Variables, loops, conditionals before assembly
6. **Unique Language Exposure**: FORTH on Jupiter Ace, advanced BBC BASIC

### **BASIC Programming Progression** (16 Tiers)
- **Tiers 1-4**: "Text Adventure Creator" - Learn variables, input/output, conditionals
- **Tiers 5-8**: "Arcade Action Simulator" - Learn loops, arrays, simple graphics
- **Tiers 9-12**: "Strategy Game Engine" - Learn subroutines, complex logic, data structures
- **Tiers 13-16**: "System Integrator" - Learn PEEK/POKE, hardware control, assembly bridge

### **FORTH Programming Progression** (Jupiter Ace)
- **Tiers 1-4**: "Stack Explorer" - Learn stack operations, basic FORTH concepts
- **Tiers 5-8**: "Word Builder" - Learn FORTH definitions, vocabulary creation
- **Tiers 9-12**: "Logic Engine" - Learn control structures, complex stack manipulation
- **Tiers 13-16**: "Hardware Interface" - Learn memory access, assembly integration
