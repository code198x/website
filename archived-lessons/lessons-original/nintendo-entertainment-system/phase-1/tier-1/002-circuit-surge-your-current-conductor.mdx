## Your Current Conductor Appears

Let's start with the magic - adding your controllable electrical current to the circuit world:

```nasm
; Circuit Surge - Current Conductor Creation
.segment "HEADER"
.byte "NES", $1A
.byte $02, $01
.byte $00, $00

.segment "CODE"
RESET:
    ; Initialize NES for precise current control
    SEI
    CLD
    LDX #$FF
    TXS
    
    ; Set up digital circuit world from Lesson 1
    LDA #$3F            ; Point to palette
    STA $2006
    LDA #$00
    STA $2006
    
    ; Circuit colors
    LDA #$0F            ; Black background
    STA $2007
    LDA #$30            ; White conductors
    STA $2007
    LDA #$16            ; Red active current
    STA $2007
    LDA #$27            ; Yellow power source
    STA $2007
    
    ; Draw circuit layout
    LDA #$20            ; Point to name table
    STA $2006
    LDA #$00
    STA $2006
    
    LDA #$01            ; Circuit line tile
    STA $2007           ; Horizontal conductor
    STA $2007           ; Continue line
    STA $2007           ; Extend circuit
    
    LDA #$02            ; Junction tile
    STA $2007           ; Junction point
    
    ; Create current conductor entity
    LDA #$05            ; Starting X position (column 5)
    STA $80             ; Store X in zero page (fast access)
    LDA #$03            ; Starting Y position (row 3)  
    STA $81             ; Store Y in zero page (fast access)
    LDA #$01            ; Moving right initially
    STA $82             ; Current direction in zero page
    
    ; Place current conductor on screen
    JSR PlaceCurrentConductor
    
    ; Main electrical flow loop
MainLoop:
    JSR UpdateCurrentFlow
    JSR PlaceCurrentConductor
    JMP MainLoop

; Place current conductor at precise position
PlaceCurrentConductor:
    ; Calculate screen address from conductor position
    LDA $81             ; Load Y position
    CMP #$00            ; Check if at row 0
    BEQ CalculateX      ; Skip Y calculation if zero
    
    ; Multiply Y by 32 (NES screen width)
    TAX                 ; Transfer Y to X register
    LDA #$00            ; Initialize result
    CLC                 ; Clear carry
MultiplyY:
    ADC #$20            ; Add 32 for each row
    DEX                 ; Decrement row counter
    BNE MultiplyY       ; Continue until Y rows processed
    
CalculateX:
    CLC                 ; Clear carry for X addition
    ADC $80             ; Add X position
    TAY                 ; Use Y as offset
    
    ; Point to screen memory plus calculated position
    LDA #$20            ; Screen base high byte
    STA $2006
    STY $2006           ; Screen base + position
    
    ; Place current conductor character
    LDA #$04            ; Current conductor tile (flowing electricity)
    STA $2007           ; Write to screen
    
    RTS

; Update current conductor movement
UpdateCurrentFlow:
    ; Load current position and direction
    LDA $80             ; Load X position
    LDX $81             ; Load Y position  
    LDY $82             ; Load direction
    
    ; Move conductor based on direction
    CPY #$01            ; Check if moving right
    BEQ MoveRight
    CPY #$02            ; Check if moving down
    BEQ MoveDown
    CPY #$03            ; Check if moving left
    BEQ MoveLeft
    JMP MoveUp          ; Must be moving up

MoveRight:
    CLC                 ; Clear carry
    ADC #$01            ; Increment X position
    CMP #$1F            ; Check right boundary (31)
    BNE StoreNewX       ; Continue if within bounds
    LDA #$02            ; Hit boundary, change to down
    STA $82             ; Store new direction
    LDA #$1E            ; Clamp X position
    JMP StoreNewX

MoveDown:
    TXA                 ; Transfer Y to accumulator
    CLC                 ; Clear carry
    ADC #$01            ; Increment Y position
    CMP #$1D            ; Check bottom boundary (29)
    BNE StoreNewY       ; Continue if within bounds
    LDA #$03            ; Hit boundary, change to left
    STA $82             ; Store new direction
    LDA #$1C            ; Clamp Y position
    JMP StoreNewY

MoveLeft:
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Decrement X position
    CMP #$FF            ; Check if went negative
    BNE StoreNewX       ; Continue if positive
    LDA #$04            ; Hit boundary, change to up
    STA $82             ; Store new direction
    LDA #$01            ; Clamp X position
    JMP StoreNewX

MoveUp:
    TXA                 ; Transfer Y to accumulator
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Decrement Y position
    CMP #$FF            ; Check if went negative
    BNE StoreNewY       ; Continue if positive
    LDA #$01            ; Hit boundary, change to right
    STA $82             ; Store new direction
    LDA #$01            ; Clamp Y position
    JMP StoreNewY

StoreNewX:
    STA $80             ; Store updated X position
    RTS
    
StoreNewY:
    STA $81             ; Store updated Y position (A contains new Y)
    RTS

NMI:
IRQ:
    RTI

.segment "VECTORS"
.word NMI, RESET, IRQ

.segment "CHR"
; Current conductor graphics data
.byte $00,$00,$00,$00,$00,$00,$00,$00  ; Empty
.byte $00,$00,$FF,$FF,$FF,$FF,$00,$00  ; Horizontal conductor
.byte $18,$18,$18,$18,$18,$18,$18,$18  ; Vertical conductor
.byte $18,$18,$FF,$FF,$FF,$FF,$18,$18  ; Junction
.byte $3C,$7E,$FF,$FF,$FF,$FF,$7E,$3C  ; Current conductor (flowing)
```

## What Just Happened? The Magic Behind Your Current Conductor

Now that you've seen your electrical current flowing, let's understand how the **6502 processor** orchestrated this precise current management.

### A, X, and Y Registers: Your Electrical Control System

The most important thing to understand: **the 6502's three registers work together like an electrical control panel**. In your current conductor code:

```nasm
LDA #$05            ; Load X position into A register (primary control)
STA $80             ; Store X in zero page memory (fast access)
LDX $81             ; Load Y position into X register (coordinate tracking)
LDY $82             ; Load direction into Y register (flow direction)
```

**A Register**: Your primary electrical conductor
- Handles all calculations and data processing
- Controls current positioning and boundary checking
- Manages electrical flow direction changes

**X Register**: Your coordinate tracker
- Stores Y coordinates for precise positioning
- Used for counting and boundary calculations
- Tracks vertical electrical flow

**Y Register**: Your flow direction controller
- Manages current direction (1=right, 2=down, 3=left, 4=up)
- Controls electrical flow patterns
- Handles direction state management

### Zero Page Memory: Your Circuit's Fast Storage

**Zero Page memory** ($00-$FF) provides lightning-fast access for real-time current management:
- **$80**: Current X position (horizontal electrical flow)
- **$81**: Current Y position (vertical electrical flow)
- **$82**: Flow direction (electrical pathway routing)

This is your circuit's "electrical control panel" - instant access to critical flow data.

### Load and Store Instructions: Your Current Flow Tools

The 6502's load and store instructions enable precise electrical control:

```nasm
LDA $80             ; Load current X position (fast zero page)
STA $2007           ; Store current to screen (direct hardware)
LDX $81             ; Load Y coordinate into X register
STX $2006           ; Store to PPU address register
```

**Why this matters for electrical games**: Every electrical calculation happens at precisely 1.79 MHz with perfect timing for smooth current flow.

## NES Memory-Mapped Hardware Control

**The NES Advantage**: Direct hardware control through memory-mapped I/O creates instant electrical responses:

**Memory Map - Your Electrical Control Panel:**
- **$0000-$07FF**: Circuit RAM - Your current state and flow data
- **$2006-$2007**: PPU Registers - Direct visual current control
- **$4000-$4017**: APU & I/O - Electrical sound effects (sparks, hums)
- **$8000-$FFFF**: Your electrical engineering program

When you write `STA $2007`, you're directly controlling the electrical visualization hardware!

## Practice: Create Complex Current Patterns

Let's enhance your electrical system with multiple current types:

```nasm
    ; Create alternating current (AC) conductor
    LDA #$0A            ; AC starting X position
    STA $83             ; Store AC X position
    LDA #$05            ; AC starting Y position
    STA $84             ; Store AC Y position
    LDA #$FF            ; AC alternating flag
    STA $85             ; Store AC state
    
    ; Create power surge conductor
    LDA #$15            ; Surge starting X position
    STA $86             ; Store surge X position
    LDA #$08            ; Surge starting Y position
    STA $87             ; Store surge Y position
    LDA #$03            ; Surge intensity
    STA $88             ; Store surge power
    
UpdateACCurrent:
    ; Alternating current moves back and forth
    LDA $85             ; Load AC state
    CMP #$FF            ; Check direction
    BEQ ACMoveRight     ; Move right if $FF
    
    ; Move left
    LDA $83             ; Load AC X position
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Move left
    STA $83             ; Store new position
    CMP #$02            ; Check left boundary
    BNE ACDone          ; Continue if not at boundary
    LDA #$FF            ; Change direction to right
    STA $85             ; Store new direction
    JMP ACDone
    
ACMoveRight:
    LDA $83             ; Load AC X position
    CLC                 ; Clear carry for addition
    ADC #$01            ; Move right
    STA $83             ; Store new position
    CMP #$18            ; Check right boundary
    BNE ACDone          ; Continue if not at boundary
    LDA #$00            ; Change direction to left
    STA $85             ; Store new direction
    
ACDone:
    RTS
```

### Quick Reference: Today's Electrical Control Instructions

- **LDA source**: Load electrical data into primary control register
- **LDX source**: Load coordinate data into X tracking register
- **LDY source**: Load flow direction into Y control register
- **STA destination**: Store electrical state to memory or hardware
- **STX/STY destination**: Store tracking data to zero page memory

Save this reference - you'll use these instructions to control all your electrical systems!
