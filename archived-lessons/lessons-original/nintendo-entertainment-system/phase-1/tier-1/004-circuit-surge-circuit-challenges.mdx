# Lesson 4: Circuit Surge - Circuit Challenges

**Your digital circuits need challenging obstacles!** In the last lesson, you added electronic sparks and audio feedback to your electrical world. Today, you'll create circuit challenges - electrical obstacles, routing puzzles, and interactive switches that require precise electrical thinking to navigate and solve!

## Your Circuit Challenges Energize

Let's start with the magic - adding electrical puzzle elements to your digital circuit world:

```nasm
; Circuit Surge - Circuit Challenges Creation
.segment "HEADER"
.byte "NES", $1A
.byte $02, $01
.byte $00, $00

.segment "CODE"
RESET:
    ; Initialize NES for precise circuit control
    SEI
    CLD
    LDX #$FF
    TXS
    
    ; Set up enhanced digital circuit world from Lessons 1-3
    LDA #$3F            ; Point to palette
    STA $2006           ; PPU address high
    LDA #$00            ; Point to palette start
    STA $2006           ; PPU address low
    
    ; Enhanced circuit colors with challenge elements
    LDA #$0F            ; Black background
    STA $2007           ; Write palette
    LDA #$30            ; White conductors
    STA $2007           ; Write palette
    LDA #$16            ; Red current flow
    STA $2007           ; Write palette
    LDA #$27            ; Yellow sparks and switches
    STA $2007           ; Write palette
    
    ; Initialize circuit challenge system
    JSR InitChallengeSystem
    
    ; Set up current conductor from previous lessons
    LDA #$05            ; Starting X position
    STA $80             ; Store in zero page
    LDA #$03            ; Starting Y position
    STA $81             ; Store in zero page
    
    ; Initialize electronic sparks from Lesson 3
    JSR InitAPUSystem
    
    ; Create electrical obstacles and puzzles
    JSR CreateCircuitObstacles
    
    ; Set up circuit switches and routing
    JSR CreateCircuitSwitches
    
    ; Main electrical challenge loop
MainLoop:
    JSR UpdateCurrentFlow       ; From previous lessons
    JSR CheckCircuitCollisions  ; New obstacle detection
    JSR UpdateCircuitSwitches   ; Interactive switch system
    JSR CheckCircuitCompletion  ; Puzzle completion checking
    JSR UpdateSparkEffects      ; From Lesson 3
    JMP MainLoop

; Initialize circuit challenge system
InitChallengeSystem:
    ; Set up challenge state variables in zero page
    LDA #$00            ; No challenges completed initially
    STA $88             ; Challenges completed counter
    STA $89             ; Current challenge ID
    
    ; Initialize obstacle states
    LDA #$01            ; Obstacle 1 active
    STA $8A             ; Barrier state
    LDA #$01            ; Obstacle 2 active
    STA $8B             ; Gate state
    LDA #$01            ; Obstacle 3 active
    STA $8C             ; Lock state
    
    ; Set circuit switch states
    LDA #$00            ; Switch 1 off
    STA $8D             ; Switch 1 state
    LDA #$00            ; Switch 2 off
    STA $8E             ; Switch 2 state
    LDA #$00            ; Switch 3 off
    STA $8F             ; Switch 3 state
    
    ; Initialize puzzle timer for dynamic challenges
    LDA #$FF            ; Maximum timer value
    STA $90             ; Circuit timer
    
    RTS

; Create electrical obstacles and circuit barriers
CreateCircuitObstacles:
    ; Create Electrical Barrier (requires switch activation)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$88            ; Barrier position (row 4, col 8)
    STA $2006           ; PPU address low
    
    LDA #$08            ; Electrical barrier tile
    STA $2007           ; Place barrier
    STA $2007           ; Continue barrier
    STA $2007           ; Make barrier wider
    
    ; Create Circuit Gate (requires current routing)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$CC            ; Gate position (row 6, col 12)
    STA $2006           ; PPU address low
    
    LDA #$09            ; Circuit gate tile
    STA $2007           ; Place gate
    
    ; Create Power Lock (requires multiple switches)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$F0            ; Lock position (row 7, col 16)
    STA $2006           ; PPU address low
    
    LDA #$0A            ; Power lock tile
    STA $2007           ; Place lock
    
    ; Create Electrical Conduits (routing paths)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$A5            ; Conduit position (row 5, col 5)
    STA $2006           ; PPU address low
    
    LDA #$02            ; Conduit tile (from Lesson 1)
    STA $2007           ; Place conduit junction
    
    RTS

; Create interactive circuit switches
CreateCircuitSwitches:
    ; Create Switch 1 (controls barrier)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$4A            ; Switch 1 position (row 2, col 10)
    STA $2006           ; PPU address low
    
    LDA #$0B            ; Switch tile (off state)
    STA $2007           ; Place switch 1
    
    ; Create Switch 2 (controls gate)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$B8            ; Switch 2 position (row 5, col 24)
    STA $2006           ; PPU address low
    
    LDA #$0B            ; Switch tile (off state)
    STA $2007           ; Place switch 2
    
    ; Create Switch 3 (part of lock combination)
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$D5            ; Switch 3 position (row 6, col 21)
    STA $2006           ; PPU address low
    
    LDA #$0B            ; Switch tile (off state)
    STA $2007           ; Place switch 3
    
    ; Create Circuit Goal
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$1E8           ; Goal position (row 15, col 8)
    STA $2006           ; PPU address low
    
    LDA #$0F            ; Goal tile (bright target)
    STA $2007           ; Place goal
    
    RTS

; Check collisions with circuit obstacles
CheckCircuitCollisions:
    ; Calculate current conductor screen position for collision checking
    LDA $81             ; Load conductor Y position
    CMP #$00            ; Compare with row 0 (sets flags)
    BEQ CalculateCollisionX ; Skip Y calculation if zero
    
    ; Multiply Y by 32 (NES screen width)
    TAX                 ; Transfer Y to X register
    LDA #$00            ; Initialize result
    CLC                 ; Clear carry
MultiplyCollisionY:
    ADC #$20            ; Add 32 for each row
    DEX                 ; Decrement row counter
    BNE MultiplyCollisionY ; Continue until Y rows processed
    
CalculateCollisionX:
    CLC                 ; Clear carry for X addition
    ADC $80             ; Add conductor X position
    TAY                 ; Use Y as screen offset
    
    ; Point to screen memory plus calculated position
    LDA #$20            ; Screen base high byte
    STA $2006           ; PPU address high
    STY $2006           ; Screen base + position
    
    ; Read what tile conductor is on
    LDA $2007           ; Read tile (first read is buffered)
    LDA $2007           ; Read actual tile
    
    ; Check for electrical barrier collision
    CMP #$08            ; Compare with barrier tile (sets flags)
    BEQ HandleBarrierCollision ; Branch if Equal (hit barrier)
    
    ; Check for circuit gate collision
    CMP #$09            ; Compare with gate tile (sets flags)
    BEQ HandleGateCollision ; Branch if Equal (hit gate)
    
    ; Check for power lock collision
    CMP #$0A            ; Compare with lock tile (sets flags)
    BEQ HandleLockCollision ; Branch if Equal (hit lock)
    
    ; Check for switch collision
    CMP #$0B            ; Compare with switch tile (sets flags)
    BEQ HandleSwitchCollision ; Branch if Equal (hit switch)
    CMP #$0C            ; Compare with activated switch tile (sets flags)
    BEQ HandleSwitchCollision ; Branch if Equal (hit active switch)
    
    ; Check for goal collision
    CMP #$0F            ; Compare with goal tile (sets flags)
    BEQ HandleGoalCollision ; Branch if Equal (reached goal)
    
    ; No special collision
    RTS

; Handle electrical barrier collision
HandleBarrierCollision:
    ; Check if barrier is disabled by switch
    LDA $8D             ; Load switch 1 state
    CMP #$01            ; Compare with activated state (sets flags)
    BEQ BarrierOpen     ; Branch if Equal (switch activated, barrier open)
    
    ; Barrier is active - block movement
    JSR FlashBarrierBlocked
    
    ; Move conductor back one position
    LDA $80             ; Load current X
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Move back
    BCS StoreBlockedX   ; Branch if Carry Set (result positive)
    LDA #$00            ; Clamp to screen edge
    
StoreBlockedX:
    STA $80             ; Store corrected position
    RTS
    
BarrierOpen:
    ; Barrier is open - conductor passes through
    JSR FlashBarrierOpen
    RTS

; Handle circuit gate collision
HandleGateCollision:
    ; Check if gate is powered by correct routing
    JSR CheckCircuitRouting
    CMP #$01            ; Compare result with success (sets flags)
    BEQ GateOpen        ; Branch if Equal (correct routing)
    
    ; Gate is closed - block movement
    JSR FlashGateBlocked
    
    ; Move conductor back
    LDA $80             ; Load current X
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Move back
    BCS StoreGateBlockedX ; Branch if Carry Set (positive result)
    LDA #$00            ; Clamp to edge
    
StoreGateBlockedX:
    STA $80             ; Store corrected position
    RTS
    
GateOpen:
    ; Gate is open - conductor passes
    JSR FlashGateOpen
    
    ; Mark gate as completed
    LDA #$00            ; Mark gate as disabled
    STA $8B             ; Update gate state
    RTS

; Handle power lock collision
HandleLockCollision:
    ; Check if all required switches are activated
    LDA $8D             ; Load switch 1 state
    CMP #$01            ; Compare with activated (sets flags)
    BNE LockBlocked     ; Branch if Not Equal (switch 1 off)
    
    LDA $8E             ; Load switch 2 state
    CMP #$01            ; Compare with activated (sets flags)
    BNE LockBlocked     ; Branch if Not Equal (switch 2 off)
    
    LDA $8F             ; Load switch 3 state
    CMP #$01            ; Compare with activated (sets flags)
    BNE LockBlocked     ; Branch if Not Equal (switch 3 off)
    
    ; All switches activated - unlock
    JSR FlashLockOpen
    
    ; Mark lock as disabled
    LDA #$00            ; Mark lock as disabled
    STA $8C             ; Update lock state
    
    ; Remove lock from screen
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$F0            ; Lock position
    STA $2006           ; PPU address low
    LDA #$00            ; Empty tile
    STA $2007           ; Remove lock
    
    RTS
    
LockBlocked:
    ; Lock is still active - block movement
    JSR FlashLockBlocked
    
    ; Move conductor back
    LDA $80             ; Load current X
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Move back
    BCS StoreLockBlockedX ; Branch if Carry Set (positive)
    LDA #$00            ; Clamp to edge
    
StoreLockBlockedX:
    STA $80             ; Store corrected position
    RTS

; Handle switch activation collision
HandleSwitchCollision:
    ; Determine which switch was activated by position
    LDA $81             ; Load conductor Y position
    CMP #$02            ; Compare with switch 1 row (sets flags)
    BEQ ActivateSwitch1 ; Branch if Equal (at switch 1)
    CMP #$05            ; Compare with switch 2 row (sets flags)
    BEQ ActivateSwitch2 ; Branch if Equal (at switch 2)
    CMP #$06            ; Compare with switch 3 row (sets flags)
    BEQ ActivateSwitch3 ; Branch if Equal (at switch 3)
    
    RTS                 ; Unknown switch position
    
ActivateSwitch1:
    ; Toggle switch 1 state
    LDA $8D             ; Load current switch 1 state
    EOR #$01            ; Toggle between 0 and 1 (sets flags)
    STA $8D             ; Store new state
    
    JSR UpdateSwitch1Visual
    JSR PlaySwitchSound
    RTS
    
ActivateSwitch2:
    ; Toggle switch 2 state
    LDA $8E             ; Load current switch 2 state
    EOR #$01            ; Toggle between 0 and 1 (sets flags)
    STA $8E             ; Store new state
    
    JSR UpdateSwitch2Visual
    JSR PlaySwitchSound
    RTS
    
ActivateSwitch3:
    ; Toggle switch 3 state
    LDA $8F             ; Load current switch 3 state
    EOR #$01            ; Toggle between 0 and 1 (sets flags)
    STA $8F             ; Store new state
    
    JSR UpdateSwitch3Visual
    JSR PlaySwitchSound
    RTS

; Handle goal collision
HandleGoalCollision:
    ; Check if all obstacles are cleared
    LDA $8A             ; Load barrier state
    CMP #$00            ; Compare with disabled (sets flags)
    BNE GoalBlocked     ; Branch if Not Equal (barrier still active)
    
    LDA $8B             ; Load gate state
    CMP #$00            ; Compare with disabled (sets flags)
    BNE GoalBlocked     ; Branch if Not Equal (gate still active)
    
    LDA $8C             ; Load lock state
    CMP #$00            ; Compare with disabled (sets flags)
    BNE GoalBlocked     ; Branch if Not Equal (lock still active)
    
    ; All obstacles cleared - goal reached!
    JSR HandleCircuitCompletion
    RTS
    
GoalBlocked:
    ; Not all obstacles cleared
    JSR FlashGoalBlocked
    RTS

; Check circuit routing for gate activation
CheckCircuitRouting:
    ; Simple routing check - verify switch 2 is activated
    LDA $8E             ; Load switch 2 state
    CMP #$01            ; Compare with activated (sets flags)
    BEQ RoutingCorrect  ; Branch if Equal (correct routing)
    
    ; Incorrect routing
    LDA #$00            ; Return failure
    RTS
    
RoutingCorrect:
    LDA #$01            ; Return success
    RTS

; Update circuit switches based on state
UpdateCircuitSwitches:
    ; Update switch visuals based on states
    LDA $90             ; Load circuit timer
    SEC                 ; Set carry for subtraction
    SBC #$01            ; Decrement timer
    STA $90             ; Store updated timer
    CMP #$00            ; Compare with zero (sets flags)
    BNE TimerContinue   ; Branch if Not Equal (timer active)
    
    ; Reset timer
    LDA #$FF            ; Reset to maximum
    STA $90             ; Store reset value
    
    ; Create pulsing effect on inactive switches
    JSR PulseInactiveSwitches
    
TimerContinue:
    RTS

; Create pulsing visual effects on inactive switches
PulseInactiveSwitches:
    ; Pulse switch 1 if inactive
    LDA $8D             ; Load switch 1 state
    CMP #$00            ; Compare with inactive (sets flags)
    BNE PulseSwitch2    ; Branch if Not Equal (switch active)
    
    ; Pulse switch 1
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$4A            ; Switch 1 position
    STA $2006           ; PPU address low
    
    LDA $90             ; Load timer for pulsing
    AND #$10            ; Mask for pulse timing (sets flags)
    BEQ Switch1Dim      ; Branch if Equal (dim phase)
    LDA #$0C            ; Bright switch tile
    JMP Switch1Update
Switch1Dim:
    LDA #$0B            ; Normal switch tile
Switch1Update:
    STA $2007           ; Update switch 1 visual
    
PulseSwitch2:
    ; Pulse switch 2 if inactive
    LDA $8E             ; Load switch 2 state
    CMP #$00            ; Compare with inactive (sets flags)
    BNE PulseSwitch3    ; Branch if Not Equal (switch active)
    
    ; Similar pulsing for switch 2
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$B8            ; Switch 2 position
    STA $2006           ; PPU address low
    
    LDA $90             ; Load timer
    AND #$10            ; Mask for pulse (sets flags)
    BEQ Switch2Dim      ; Branch if Equal (dim phase)
    LDA #$0C            ; Bright switch tile
    JMP Switch2Update
Switch2Dim:
    LDA #$0B            ; Normal switch tile
Switch2Update:
    STA $2007           ; Update switch 2 visual
    
PulseSwitch3:
    ; Pulse switch 3 if inactive
    LDA $8F             ; Load switch 3 state
    CMP #$00            ; Compare with inactive (sets flags)
    BNE PulseDone       ; Branch if Not Equal (switch active)
    
    ; Similar pulsing for switch 3
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$D5            ; Switch 3 position
    STA $2006           ; PPU address low
    
    LDA $90             ; Load timer
    AND #$10            ; Mask for pulse (sets flags)
    BEQ Switch3Dim      ; Branch if Equal (dim phase)
    LDA #$0C            ; Bright switch tile
    JMP Switch3Update
Switch3Dim:
    LDA #$0B            ; Normal switch tile
Switch3Update:
    STA $2007           ; Update switch 3 visual
    
PulseDone:
    RTS

; Update switch 1 visual state
UpdateSwitch1Visual:
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$4A            ; Switch 1 position
    STA $2006           ; PPU address low
    
    LDA $8D             ; Load switch 1 state
    CMP #$01            ; Compare with activated (sets flags)
    BEQ Switch1Active   ; Branch if Equal (switch on)
    
    LDA #$0B            ; Off switch tile
    JMP Switch1Store
Switch1Active:
    LDA #$0C            ; On switch tile
Switch1Store:
    STA $2007           ; Update switch visual
    RTS

; Update switch 2 visual state
UpdateSwitch2Visual:
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$B8            ; Switch 2 position
    STA $2006           ; PPU address low
    
    LDA $8E             ; Load switch 2 state
    CMP #$01            ; Compare with activated (sets flags)
    BEQ Switch2Active   ; Branch if Equal (switch on)
    
    LDA #$0B            ; Off switch tile
    JMP Switch2Store
Switch2Active:
    LDA #$0C            ; On switch tile
Switch2Store:
    STA $2007           ; Update switch visual
    RTS

; Update switch 3 visual state
UpdateSwitch3Visual:
    LDA #$20            ; Point to name table
    STA $2006           ; PPU address high
    LDA #$D5            ; Switch 3 position
    STA $2006           ; PPU address low
    
    LDA $8F             ; Load switch 3 state

    LDA #$0B            ; Off switch tile

Switch3Active:
    LDA #$0C            ; On switch tile
Switch3Store:
    STA $2007           ; Update switch visual
    RTS

; Check circuit completion status
CheckCircuitCompletion:
    ; Check if all challenges solved
    LDA $88             ; Load challenges completed
    CMP #$03            ; Compare with total challenges (sets flags)
    BEQ CircuitComplete ; Branch if Equal (all complete)
    
    RTS                 ; Not complete yet
    
CircuitComplete:
    ; All circuits solved - maintain completion state
    RTS

; Handle complete circuit solution
HandleCircuitCompletion:
    ; Flash victory sequence
    LDX #$05            ; Flash 5 times
VictoryFlash:
    ; Use pulse channel for victory sound
    LDA #$8F            ; Strong attack, full volume
    STA $4000           ; Pulse 1 control
    
    LDA #$80            ; Victory frequency low
    STA $4002           ; Pulse 1 frequency low
    LDA #$02            ; Victory frequency high
    STA $4003           ; Pulse 1 frequency high
    
    ; Brief delay for flash effect
    LDY #$FF            ; Delay counter
VictoryDelay1:
    DEY                 ; Decrement counter
    BNE VictoryDelay1   ; Continue until zero
    
    ; Stop sound
    LDA #$30            ; Zero volume
    STA $4000           ; Stop pulse 1
    
    ; Another delay
    LDY #$FF            ; Delay counter
VictoryDelay2:
    DEY                 ; Decrement counter
    BNE VictoryDelay2   ; Continue until zero
    
    DEX                 ; Decrement flash counter
    BNE VictoryFlash    ; Continue flashing
    
    ; Mark circuit as completed
    LDA #$03            ; All challenges completed
    STA $88             ; Store completion status
    
    RTS

; Play switch activation sound
PlaySwitchSound:
    ; Use noise channel for switch click
    LDA #$30            ; Constant volume, medium level
    STA $400C           ; Noise control
    
    LDA #$08            ; Click frequency
    STA $400E           ; Noise period
    
    LDA #$08            ; Short duration
    STA $400F           ; Noise length
    
    RTS

; Flash feedback functions
FlashBarrierBlocked:
    ; Flash red for blocked barrier
    JSR FlashRed
    RTS

FlashBarrierOpen:
    ; Flash green for open barrier
    JSR FlashGreen
    RTS

FlashGateBlocked:
    ; Flash red for blocked gate
    JSR FlashRed
    RTS

FlashGateOpen:
    ; Flash green for open gate
    JSR FlashGreen
    RTS

FlashLockBlocked:
    ; Flash red for blocked lock
    JSR FlashRed
    RTS

FlashLockOpen:
    ; Flash cyan for open lock
    JSR FlashCyan
    RTS

FlashGoalBlocked:
    ; Flash magenta for blocked goal
    JSR FlashMagenta
    RTS

; Flash color functions
FlashRed:
    ; Flash red background briefly
    LDA #$3F            ; Point to palette
    STA $2006           ; PPU address high
    LDA #$00            ; Background color
    STA $2006           ; PPU address low
    LDA #$16            ; Red color
    STA $2007           ; Set red background
    
    ; Brief delay
    LDY #$80            ; Delay counter
RedDelay:

    BNE RedDelay        ; Continue until zero
    
    ; Restore normal background
    LDA #$3F            ; Point to palette
    STA $2006           ; PPU address high

    STA $2006           ; PPU address low
    LDA #$0F            ; Black background
    STA $2007           ; Restore background
    
    RTS

FlashGreen:
    ; Flash green background briefly
    LDA #$3F            ; Point to palette

    LDA #$00            ; Background color
    STA $2006           ; PPU address low
    LDA #$1A            ; Green color
    STA $2007           ; Set green background
    
    ; Brief delay
    LDY #$80            ; Delay counter
GreenDelay:

    LDA #$00            ; Background color

    LDA #$1C            ; Cyan color
    STA $2007           ; Set cyan background
    
    ; Brief delay

CyanDelay:

    ; Restore normal background

FlashMagenta:

    LDA #$00            ; Background color
    STA $2006           ; PPU address low
    LDA #$14            ; Magenta color
    STA $2007           ; Set magenta background
    
    ; Brief delay
    LDY #$80            ; Delay counter
MagentaDelay:

    BNE MagentaDelay    ; Continue until zero

; Enhanced current flow update (from previous lessons)
UpdateCurrentFlow:
    ; Update current conductor movement
    LDA $80             ; Load X position
    CLC                 ; Clear carry
    ADC #$01            ; Move right
    CMP #$20            ; Compare with screen edge (sets flags)
    BCC StoreCurrentX   ; Branch if Carry Clear (within bounds)
    LDA #$00            ; Wrap to left edge
    
StoreCurrentX:
    STA $80             ; Store new X position
    
    JSR PlaceCurrentConductor ; Place conductor on screen
    RTS

; Enhanced conductor placement (from previous lessons)
PlaceCurrentConductor:
    ; Calculate screen address from conductor position
    LDA $81             ; Load Y position
    CMP #$00            ; Compare with row 0 (sets flags)
    BEQ CalculateCurrentX ; Branch if Equal (skip Y calculation)
    
    ; Multiply Y by 32 (NES screen width)
    TAX                 ; Transfer Y to X register
    LDA #$00            ; Initialize result
    CLC                 ; Clear carry
MultiplyCurrentY:
    ADC #$20            ; Add 32 for each row
    DEX                 ; Decrement row counter
    BNE MultiplyCurrentY ; Continue until Y rows processed
    
CalculateCurrentX:
    CLC                 ; Clear carry for X addition
    ADC $80             ; Add X position
    TAY                 ; Use Y as offset
    
    ; Point to screen memory plus calculated position
    LDA #$20            ; Screen base high byte
    STA $2006           ; PPU address high
    STY $2006           ; Screen base + position
    
    ; Place current conductor character
    LDA #$04            ; Current conductor tile
    STA $2007           ; Write to screen
    
    RTS

; Enhanced APU initialization (from Lesson 3)
InitAPUSystem:
    ; Clear all APU registers for clean sound
    LDX #$00            ; Start at register 0
ClearAPU:
    LDA #$00            ; Clear value
    STA $4000,X         ; Clear APU register
    INX                 ; Next register
    CPX #$20            ; Check all APU registers (sets flags)
    BNE ClearAPU        ; Branch if Not Equal (continue clearing)
    
    ; Enable APU channels
    LDA #$0F            ; Enable pulse, triangle, noise
```

### 6502 Status Flags: Your Circuit Logic Controller

The most important thing to understand: **status flags automatically provide information for circuit decisions**. In your circuit challenge code:

**Zero Flag (Z)**: Testing circuit states and switch positions
```nasm
CMP #$01            ; Compare switch state with activated
BEQ BarrierOpen     ; Branch if Equal (Zero flag set)
CMP #$00            ; Compare with disabled state
BNE GoalBlocked     ; Branch if Not Equal (Zero flag clear)
```

**Carry Flag (C)**: Position calculations and boundary checking
```nasm
ADC #$20            ; Add 32 for each row (sets Carry on overflow)
BCC StoreCurrentX   ; Branch if Carry Clear (within bounds)
SBC #$01            ; Move back (uses Carry for borrow)
BCS StoreBlockedX   ; Branch if Carry Set (positive result)
```

**Status Flag Examples in Circuit Challenge Logic:**

| Flag | Example | Use Case |
|------|---------|----------|
| **Zero Flag** | `CMP #$01 / BEQ activated` | Test switch states and circuit completion |
| **Carry Flag** | `SBC #$01 / BCS positive` | Handle movement bounds and collision response |
| **Combined Flags** | `EOR #$01 / STA state` | Toggle switch states and update logic |
