## Your First Digital Circuit

Let's start with the magic. Here's the code that creates your flowing electrical circuit world:

```nasm
; Circuit Surge - Digital World Creation
.segment "HEADER"
.byte "NES", $1A    ; NES ROM signature
.byte $02, $01      ; 32K PRG, 8K CHR
.byte $00, $00      ; Mapper 0

.segment "CODE"
RESET:
    ; Initialize NES for circuit graphics
    SEI                 ; Disable interrupts during setup
    CLD                 ; Clear decimal mode
    LDX #$FF
    TXS                 ; Set up stack

    ; Create electrical flow visualization
    LDA #$3F            ; Point to palette memory
    STA $2006           ; PPU address high
    LDA #$00
    STA $2006           ; PPU address low

    ; Set circuit colors
    LDA #$0F            ; Background: Black
    STA $2007
    LDA #$30            ; Conductor: White
    STA $2007
    LDA #$16            ; Active current: Bright red
    STA $2007
    LDA #$27            ; Power source: Bright yellow
    STA $2007

    ; Draw initial circuit layout
    LDA #$20            ; Point to name table
    STA $2006
    LDA #$00
    STA $2006

    ; Create horizontal circuit line
    LDA #$01            ; Circuit line tile
    STA $2007           ; Draw first segment
    STA $2007           ; Extend line
    STA $2007           ; Continue circuit

    ; Create vertical junction
    LDA #$02            ; Junction tile
    STA $2007           ; Place junction point

    ; Infinite loop to see your circuit
loop:
    JMP loop

NMI:
IRQ:
    RTI

.segment "VECTORS"
.word NMI, RESET, IRQ

.segment "CHR"
; Circuit graphics data (simplified)
.byte $00,$00,$00,$00,$00,$00,$00,$00  ; Empty
.byte $00,$00,$FF,$FF,$FF,$FF,$00,$00  ; Horizontal line
.byte $18,$18,$18,$18,$18,$18,$18,$18  ; Vertical line
.byte $18,$18,$FF,$FF,$FF,$FF,$18,$18  ; Junction
```

## What Just Happened? The Magic Behind Your Game

Now that you've seen something electrifying happen, let's understand the magic. This is how the **6502 processor** - the precise brain of your NES - orchestrated your digital circuit world.

### Memory-Mapped I/O: Direct Hardware Control

The most important thing to understand: **the NES uses memory-mapped I/O** - you control graphics and sound by writing to specific memory addresses, just like electrical switches!

```nasm
LDA #$3F            ; Point to palette memory
STA $2006           ; PPU address register
LDA #$0F            ; Black background color
STA $2007           ; Write directly to graphics hardware!
```

This simple sequence:

1. Loads the palette address ($3F00) into the **A register**
2. Writes it to the **PPU address register** ($2006)
3. Writes color data directly to **graphics memory** ($2007)

### The 6502: Your Electrical Conductor

The **6502 processor** in the NES is like an electrical conductor, directing current (data) through circuits (memory) to create your game:

**A Register**: Your primary electrical conductor

- Carries current (data) from one circuit to another
- Used for all major electrical operations (game calculations)
- Controls the flow of information through your digital world

**X and Y Registers**: Your positioning controllers

- **X**: Horizontal positioning and counting (like circuit grid X-coordinates)
- **Y**: Vertical positioning and indexing (like circuit grid Y-coordinates)
- Track electrical current position and flow direction

### Console Game Programming Power

**Why Assembly for NES Games?**

You might wonder: "Why not use a high-level language?" Here's why assembly gives you precise control:

**High-Level Version** (slow, imprecise):

```c
for(int i = 0; i < 60; i++) {
    drawPixel(i, color);
}
```

**6502 Assembly Version** (precise, real-time):

```nasm
LDX #60             ; 60 pixels to draw
LDA #$16            ; Bright red current color
loop:
    STA $2007       ; Write directly to PPU
    DEX             ; Count down
    BNE loop        ; Continue until done
```

The assembly version runs at exactly **1.79 million instructions per second** with **perfect timing** for 60 FPS gameplay.

### Understanding NES Hardware Architecture

In **Circuit Surge**, you'll use the NES's memory-mapped system to create flowing electrical effects:

**Memory Map - Your Electrical Control Panel:**

- **$0000-$07FF**: RAM (2KB) - Your program variables and current state
- **$2000-$2007**: PPU Registers - Graphics hardware (visual circuits)
- **$4000-$4017**: APU & I/O - Sound hardware (electrical hums and sparks)
- **$8000-$FFFF**: Your game code (the electrical engineering program)

This gives you **direct hardware control** impossible on other systems!

### Quick Reference: Today's Assembly Instructions

- **LDA #value**: Load an immediate value into the A register
- **STA address**: Store A register contents to memory address
- **LDX #value**: Load an immediate value into the X register
- **LDY #value**: Load an immediate value into the Y register
- **JMP label**: Jump to a program location (infinite loop)

Save this reference - you'll use these instructions to create precise console games!
