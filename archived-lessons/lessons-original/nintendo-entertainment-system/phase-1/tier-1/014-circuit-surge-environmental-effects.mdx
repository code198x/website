# Lesson 14: Circuit Surge - Environmental Effects

**Your electrical world needs atmospheric effects!** In your advanced entity behaviors from Lesson 13, you created intelligent electrical conductor AI. Today, you'll add dynamic environmental effects with particle systems, electrical hazards, and immersive visual effects that transform your static circuit board into a living, breathing electrical world. You'll master advanced graphics programming through authentic NES techniques that create engaging electrical environmental storytelling!

## Your Environmental Effects Energize

Let's create dynamic environmental effects using particle systems and NES PPU optimization:

```nasm
; Circuit Surge - Environmental Effects System
.segment "HEADER"
.byte "NES", $1A
.byte $02, $01
.byte $00, $00

.segment "CODE"
RESET:
    ; Initialize complete NES environment
    SEI
    CLD
    LDX #$FF
    TXS

    ; Set up enhanced electrical world for environmental effects
    JSR InitCompleteElectricalState
    JSR InitElectricalNetworkSystem
    JSR InitElectricalEfficiencySystem
    JSR InitSmoothMotionSystem
    JSR InitPrecisionControlSystem
    JSR InitAdvancedBehaviorSystem

    ; Initialize new environmental effects systems
    JSR InitEnvironmentalEffectsSystem
    JSR InitParticleSystem
    JSR InitAtmosphericEffects
    JSR InitElectricalHazards

    ; Set up effects-ready electrical world
    JSR CreateEnvironmentalEffectsWorld

    ; Environmental Effects main loop
EnvironmentalEffectsLoop:
    ; Start frame timing for environmental processing
    JSR StartEnvironmentalFrameTiming

    ; Wait for VBlank for stable PPU access
    JSR WaitForVBlank

    ; Process precision electrical control
    JSR ReadPrecisionControllerInput
    JSR ProcessInputPollingOptimization
    JSR ExecutePrecisionCommands

    ; Update conductor with precision control
    JSR UpdatePrecisionConductorMovement
    JSR UpdatePrecisionNetworkFlows

    ; Process advanced electrical entity behaviors
    JSR UpdateElectricalEntityStateMachines
    JSR ProcessElectricalDecisionTrees
    JSR ExecuteAdaptiveElectricalBehaviors
    JSR UpdateElectricalBehavioralInteractions

    ; Process environmental effects systems
    JSR UpdateParticleSystems
    JSR UpdateAtmosphericEffects
    JSR UpdateElectricalHazards
    JSR ProcessEnvironmentalInteractions

    ; Process efficiency systems with environmental context
    JSR ProcessEfficiencyEventsEnvironmental
    JSR UpdateEfficiencyCalculationsEnvironmental

    ; Process advanced collision systems
    JSR ProcessEnvironmentalElectricalCollisions
    JSR UpdateElectricalEfficiencyTrackingEnvironmental

    ; Update visual systems with environmental effects
    JSR UpdateEnvironmentalVisualEffects
    JSR RenderParticleSystems
    JSR UpdateAtmosphericDisplay
    JSR UpdateEnvironmentalEfficiencyDisplay

    ; Update audio systems with environmental feedback
    JSR UpdateEnvironmentalAudioSystems

    ; Check for environmental victory conditions
    JSR CheckEnvironmentalVictoryConditions

    ; Complete environmental frame timing
    JSR CompleteEnvironmentalFrameTiming

    JMP EnvironmentalEffectsLoop

; Initialize environmental effects system using PPU optimization
InitEnvironmentalEffectsSystem:
    ; Set up environmental effects framework for NES constraints
    JSR InitEnvironmentalFramework
    JSR InitPPUEffectsOptimization
    JSR InitEnvironmentalMemoryManagement
    JSR InitEffectsTimingSystem

    ; Initialize environmental control variables
    LDA #$00
    STA GlobalEnvironmentalState
    STA EnvironmentalUpdateCounter
    STA AtmosphericIntensityLevel
    STA HazardActivityLevel

    ; Initialize environmental timing variables
    STA EnvironmentalTimingCounter
    STA LastEnvironmentalUpdate
    STA EffectsResponseTime

    ; Set environmental parameters for NES optimization
    LDA #$04            ; Environmental update frequency (every 4 frames for 60fps/15fps updates)
    STA EnvironmentalUpdateFrequency
    LDA #$02            ; Base atmospheric intensity
    STA BaseAtmosphericIntensity
    LDA #$08            ; Maximum atmospheric intensity (limited for PPU)
    STA MaxAtmosphericIntensity

    RTS

; Initialize particle system for dynamic effects
InitParticleSystem:
    ; Set up particle system framework optimized for NES sprites
    JSR InitParticleFramework
    JSR InitParticleMemoryPools
    JSR InitParticleRenderingSystem
    JSR InitParticlePhysicsSystem

    ; Initialize particle pools (limited by sprite constraints)
    LDX #$1F            ; Initialize 32 particle slots (use sprite limit efficiently)

InitParticleSlotsLoop:
    LDA #$00            ; Inactive particle
    STA ParticleActiveArray,X
    STA ParticleTypeArray,X
    STA ParticleXPositionArray,X
    STA ParticleYPositionArray,X
    STA ParticleXVelocityArray,X
    STA ParticleYVelocityArray,X
    STA ParticleLifeTimerArray,X
    STA ParticleSpriteArray,X

    DEX
    BPL InitParticleSlotsLoop

    ; Set particle system parameters
    LDA #$20            ; Maximum active particles (32, managed for sprite limit)
    STA MaxActiveParticles
    LDA #$00            ; Current particle count
    STA CurrentParticleCount
    LDA #$02            ; Particle spawn rate (limited for performance)
    STA ParticleSpawnRate

    RTS

; Initialize atmospheric effects for immersive environment
InitAtmosphericEffects:
    ; Set up atmospheric effects framework
    JSR InitAtmosphericFramework
    JSR InitAmbientParticleSystem
    JSR InitAtmosphericColorCycling
    JSR InitEnvironmentalMoodSystem

    ; Initialize atmospheric effects variables
    LDA #$00
    STA AtmosphericParticleCount
    STA ColorCycleCounter
    STA MoodTransitionState
    STA AtmosphericDensity

    ; Initialize atmospheric color cycling for NES palette
    LDA #$16            ; Starting color index (blue)
    STA CurrentAtmosphericColor
    LDA #$10            ; Color cycle speed (moderate for visibility)
    STA ColorCycleSpeed

    ; Set atmospheric parameters for NES constraints
    LDA #$08            ; Atmospheric particle density (reduced for sprite limits)
    STA AtmosphericParticleDensity
    LDA #$01            ; Atmospheric drift speed
    STA AtmosphericDriftSpeed

    RTS

; Initialize electrical hazards for gameplay challenge
InitElectricalHazards:
    ; Set up electrical hazards framework
    JSR InitHazardFramework
    JSR InitHazardSpawnSystem
    JSR InitHazardInteractionSystem
    JSR InitHazardVisualEffects

    ; Initialize hazard system variables
    LDA #$00
    STA ActiveHazardCount
    STA HazardSpawnTimer
    STA HazardIntensityLevel
    STA ElectricalDangerLevel

    ; Initialize hazard arrays (limited for NES)
    LDX #$07            ; Initialize 8 hazard slots

InitHazardSlotsLoop:
    LDA #$00            ; Inactive hazard
    STA HazardActiveArray,X
    STA HazardTypeArray,X
    STA HazardXPositionArray,X
    STA HazardYPositionArray,X
    STA HazardSizeArray,X
    STA HazardIntensityArray,X
    STA HazardTimerArray,X
    STA HazardSpriteArray,X

    DEX
    BPL InitHazardSlotsLoop

    ; Set hazard parameters
    LDA #$08            ; Maximum hazards
    STA MaxElectricalHazards
    LDA #$B4            ; Hazard spawn interval (180 frames = 3 seconds)
    STA HazardSpawnInterval

    RTS

; Create environmental effects world with electrical enhancement
CreateEnvironmentalEffectsWorld:
    ; Draw enhanced world with environmental zones
    JSR DrawEnvironmentalWorldBoundaries

    ; Create atmospheric effect zones
    JSR CreateAtmosphericEffectZones

    ; Set up electrical hazard areas
    JSR SetupElectricalHazardAreas

    ; Initialize environmental visual systems
    JSR InitEnvironmentalVisualSystems

    RTS

; Draw environmental world boundaries with electrical zones
DrawEnvironmentalWorldBoundaries:
    ; Load environmental circuit board pattern
    LDA #$20            ; Name table 0
    STA PPU_ADDR
    LDA #$00
    STA PPU_ADDR

    ; Draw environmental circuit board with atmospheric zones
    LDY #$00            ; Row counter

DrawEnvironmentalRowsLoop:
    LDX #$00            ; Column counter

DrawEnvironmentalColumnsLoop:
    ; Calculate environmental zone type
    TYA                 ; Y position
    CLC
    ADC DrawColumnXOffset,X
    AND #$07            ; Mask to 8 zone types

    ; Special electrical zones for effects
    CMP #$02            ; Atmospheric zone 1 (rows 2-3)
    BEQ DrawAtmosphericZone1
    CMP #$05            ; Hazard zone (rows 5-6)
    BEQ DrawHazardZone

    ; Normal circuit pattern
    LDA CircuitPatternTable,X
    JMP StoreEnvironmentalTile

DrawAtmosphericZone1:
    ; Atmospheric particle area
    LDA #$2A            ; Special atmospheric tile
    JMP StoreEnvironmentalTile

DrawHazardZone:
    ; Electrical hazard zone
    LDA #$2B            ; Special hazard tile

StoreEnvironmentalTile:
    STA PPU_DATA        ; Write tile to name table

    INX
    CPX #$20            ; 32 columns
    BNE DrawEnvironmentalColumnsLoop

    INY
    CPY #$1E            ; 30 rows
    BNE DrawEnvironmentalRowsLoop

    ; Set up environmental attribute table
    JSR SetupEnvironmentalAttributes

    RTS

; Setup environmental attributes for atmospheric effects
SetupEnvironmentalAttributes:
    ; Load attribute table
    LDA #$23            ; Attribute table 0
    STA PPU_ADDR
    LDA #$C0
    STA PPU_ADDR

    LDY #$00            ; Attribute counter

SetupAttributesLoop:
    ; Calculate environmental attribute
    TYA
    AND #$03            ; 4 different environmental palettes
    TAX
    LDA EnvironmentalPaletteTable,X
    STA PPU_DATA

    INY
    CPY #$40            ; 64 attribute bytes
    BNE SetupAttributesLoop

    RTS

; Update particle systems for dynamic environmental effects
UpdateParticleSystems:
    ; Check if it's time to update particles
    INC EnvironmentalUpdateCounter
    LDA EnvironmentalUpdateCounter
    CMP EnvironmentalUpdateFrequency
    BCC SkipParticleUpdate

    ; Reset counter and update particles
    LDA #$00
    STA EnvironmentalUpdateCounter

    ; Spawn new particles
    JSR SpawnElectricalParticles

    ; Update existing particles
    JSR UpdateExistingParticles

    ; Remove expired particles
    JSR RemoveExpiredParticles

SkipParticleUpdate:
    RTS

; Spawn electrical particles based on game state
SpawnElectricalParticles:
    ; Check if we can spawn more particles
    LDA CurrentParticleCount
    CMP MaxActiveParticles
    BCS NoParticleSpawn

    ; Determine particle type based on electrical state
    JSR DetermineElectricalParticleSpawnType

    ; Spawn atmospheric particles
    JSR SpawnAtmosphericParticles

    ; Spawn effect particles from game events
    JSR SpawnElectricalEffectParticles

    ; Spawn hazard particles
    JSR SpawnHazardParticles

NoParticleSpawn:
    RTS

; Spawn atmospheric particles for ambient environment
SpawnAtmosphericParticles:
    ; Check atmospheric particle spawn rate
    INC AtmosphericParticleSpawnCounter
    LDA AtmosphericParticleSpawnCounter
    AND #$0F            ; Spawn every 16 frames (4 times per second)
    BNE AtmosphericSpawnComplete

    ; Find available particle slot
    JSR FindAvailableParticleSlot
    CPX #$FF            ; Check if slot found
    BEQ AtmosphericSpawnComplete

    ; Create atmospheric particle
    LDA #$01            ; Particle active
    STA ParticleActiveArray,X
    LDA #$01            ; Atmospheric particle type
    STA ParticleTypeArray,X

    ; Random spawn position across screen width
    JSR GenerateRandomNumber
    AND #$EF            ; Limit to screen width (240 pixels)
    CLC
    ADC #$08            ; Offset from edge
    STA ParticleXPositionArray,X
    LDA #$10            ; Top of playfield
    STA ParticleYPositionArray,X

    ; Set atmospheric particle velocity
    LDA #$00            ; No horizontal movement
    STA ParticleXVelocityArray,X
    LDA #$01            ; Slow downward drift
    STA ParticleYVelocityArray,X

    ; Set particle properties
    LDA #$FF            ; Long life (255 frames)
    STA ParticleLifeTimerArray,X

    ; Assign sprite for particle
    LDA CurrentParticleCount
    STA ParticleSpriteArray,X

    ; Increment particle count
    INC CurrentParticleCount

AtmosphericSpawnComplete:
    RTS

; Spawn electrical effect particles from game events
SpawnElectricalEffectParticles:
    ; Check for conductor interaction events
    JSR CheckConductorInteractionEvents

    ; Check for network flow events
    JSR CheckNetworkFlowEvents

    ; Check for efficiency achievement events
    JSR CheckEfficiencyAchievementEvents

    RTS

; Check for conductor interaction events and spawn particles
CheckConductorInteractionEvents:
    ; Check conductor interaction flags
    LDX #$07            ; Check all 8 conductors

CheckInteractionLoop:
    LDA ConductorInteractionFlags,X
    BEQ NextInteractionCheck

    ; Conductor interaction occurred - create effect particles
    LDA #$00            ; Clear interaction flag
    STA ConductorInteractionFlags,X

    ; Spawn interaction particle burst
    LDY #$03            ; Spawn 4 interaction particles

SpawnInteractionParticlesLoop:
    TYA                 ; Save Y counter
    PHA
    TXA                 ; Save X counter
    PHA

    JSR FindAvailableParticleSlot
    CPX #$FF            ; Check if slot found
    BEQ InteractionParticleComplete

    ; Create interaction particle
    LDA #$01            ; Particle active
    STA ParticleActiveArray,X
    LDA #$02            ; Interaction particle type
    STA ParticleTypeArray,X

    ; Set interaction position from conductor
    LDA ConductorInteractionX
    STA ParticleXPositionArray,X
    LDA ConductorInteractionY
    STA ParticleYPositionArray,X

    ; Random interaction velocity
    JSR GenerateRandomNumber
    AND #$0F            ; Limit velocity range
    SEC
    SBC #$08            ; Center around 0 (-8 to +7)
    STA ParticleXVelocityArray,X

    JSR GenerateRandomNumber
    AND #$0F            ; Limit velocity range
    SEC
    SBC #$08            ; Center around 0 (-8 to +7)
    STA ParticleYVelocityArray,X

    ; Set interaction particle properties
    LDA #$1E            ; Short life (30 frames)
    STA ParticleLifeTimerArray,X

    ; Assign sprite for particle
    LDA CurrentParticleCount
    STA ParticleSpriteArray,X

    ; Increment particle count
    INC CurrentParticleCount

InteractionParticleComplete:
    PLA                 ; Restore X counter
    TAX
    PLA                 ; Restore Y counter
    TAY
    DEY
    BNE SpawnInteractionParticlesLoop

NextInteractionCheck:
    DEX
    BPL CheckInteractionLoop

    RTS

; Update existing particles with physics simulation
UpdateExistingParticles:
    ; Process all active particles
    LDX #$00            ; Start with particle 0

UpdateParticlesLoop:
    ; Check if particle is active
    LDA ParticleActiveArray,X
    BEQ NextParticleUpdate

    ; Update particle physics
    JSR UpdateParticlePhysics

    ; Update particle life
    JSR UpdateParticleLife

    ; Update particle sprite properties
    JSR UpdateParticleSpriteProperties

NextParticleUpdate:
    INX
    CPX #$20            ; Check all 32 particles
    BNE UpdateParticlesLoop

    RTS

; Update particle physics for realistic movement
UpdateParticlePhysics:
    ; X contains particle index
    ; Update X position
    LDA ParticleXPositionArray,X
    CLC
    ADC ParticleXVelocityArray,X
    STA ParticleXPositionArray,X

    ; Check X boundaries
    CMP #$F0            ; Right boundary
    BCC CheckParticleYPhysics

    ; Outside boundaries - mark for removal
    LDA #$01            ; 1 frame life (will expire next update)
    STA ParticleLifeTimerArray,X

CheckParticleYPhysics:
    ; Update Y position
    LDA ParticleYPositionArray,X
    CLC
    ADC ParticleYVelocityArray,X
    STA ParticleYPositionArray,X

    ; Check Y boundaries
    CMP #$E0            ; Bottom boundary
    BCC ParticlePhysicsComplete

    ; Below screen - mark for removal
    LDA #$01            ; 1 frame life (will expire next update)
    STA ParticleLifeTimerArray,X

ParticlePhysicsComplete:
    ; Apply environmental forces based on particle type
    LDA ParticleTypeArray,X
    CMP #$01            ; Atmospheric particle
    BEQ ApplyAtmosphericForces
    CMP #$02            ; Interaction particle
    BEQ ApplyInteractionForces

    RTS

ApplyAtmosphericForces:
    ; Apply atmospheric drift and gravity
    LDA ParticleYVelocityArray,X
    CMP #$02            ; Maximum fall speed
    BCS AtmosphericForcesComplete
    INC ParticleYVelocityArray,X ; Slight gravity

AtmosphericForcesComplete:
    RTS

ApplyInteractionForces:
    ; Apply interaction particle deceleration
    LDA ParticleXVelocityArray,X
    BEQ CheckInteractionYDecel
    BMI InteractionXNegative

    ; Positive X velocity - decelerate
    DEC ParticleXVelocityArray,X
    JMP CheckInteractionYDecel

InteractionXNegative:
    ; Negative X velocity - decelerate
    INC ParticleXVelocityArray,X

CheckInteractionYDecel:
    LDA ParticleYVelocityArray,X
    BEQ InteractionForcesComplete
    BMI InteractionYNegative

    ; Positive Y velocity - decelerate
    DEC ParticleYVelocityArray,X
    JMP InteractionForcesComplete

InteractionYNegative:
    ; Negative Y velocity - decelerate (add gravity)
    INC ParticleYVelocityArray,X

InteractionForcesComplete:
    RTS

; Update atmospheric effects for environmental immersion
UpdateAtmosphericEffects:
    ; Update atmospheric color cycling
    JSR UpdateAtmosphericColorCycling

    ; Update atmospheric density
    JSR UpdateAtmosphericDensity

    ; Update environmental mood
    JSR UpdateEnvironmentalMood

    RTS

; Update atmospheric color cycling for dynamic environment
UpdateAtmosphericColorCycling:
    ; Increment color cycle counter
    INC ColorCycleCounter
    LDA ColorCycleCounter
    CMP ColorCycleSpeed
    BCC ColorCyclingComplete

    ; Reset counter and cycle color
    LDA #$00
    STA ColorCycleCounter

    ; Cycle through atmospheric colors
    INC CurrentAtmosphericColor
    LDA CurrentAtmosphericColor
    CMP #$30            ; Wrap at palette boundary
    BCC StoreAtmosphericColor
    LDA #$16            ; Reset to start color

StoreAtmosphericColor:
    STA CurrentAtmosphericColor

    ; Update background palette for atmospheric effect
    JSR UpdateAtmosphericPalette

ColorCyclingComplete:
    RTS

; Update atmospheric palette during VBlank
UpdateAtmosphericPalette:
    ; Wait for VBlank
    JSR WaitForVBlank

    ; Update palette
    LDA #$3F            ; Palette RAM
    STA PPU_ADDR
    LDA #$01            ; Background color 1
    STA PPU_ADDR
    LDA CurrentAtmosphericColor
    STA PPU_DATA

    RTS

; Update electrical hazards for dynamic challenges
UpdateElectricalHazards:
    ; Update hazard spawn timing
    JSR UpdateHazardSpawnTiming

    ; Update existing hazards
    JSR UpdateExistingHazards

    ; Check hazard interactions
    JSR CheckHazardInteractions

    RTS

; Update hazard spawn timing for dynamic challenge
UpdateHazardSpawnTiming:
    ; Decrement spawn timer
    DEC HazardSpawnTimer
    BNE HazardSpawnTimingComplete

    ; Reset timer and spawn hazard
    LDA HazardSpawnInterval
    STA HazardSpawnTimer

    ; Check if we can spawn more hazards
    LDA ActiveHazardCount
    CMP MaxElectricalHazards
    BCS HazardSpawnTimingComplete

    ; Spawn new electrical hazard
    JSR SpawnElectricalHazard

HazardSpawnTimingComplete:
    RTS

; Spawn electrical hazard for gameplay challenge
SpawnElectricalHazard:
    ; Find available hazard slot
    JSR FindAvailableHazardSlot
    CPX #$FF            ; Check if slot found
    BEQ HazardSpawnComplete

    ; Create electrical hazard
    LDA #$01            ; Hazard active
    STA HazardActiveArray,X

    ; Determine hazard type based on current electrical state
    LDA GlobalEnvironmentalState
    AND #$03            ; 4 hazard types
    STA HazardTypeArray,X

    ; Set hazard position
    JSR GenerateRandomNumber
    AND #$DF            ; Limit to screen area
    CLC
    ADC #$10            ; Offset from edges
    STA HazardXPositionArray,X

    JSR GenerateRandomNumber
    AND #$7F            ; Limit Y range
    CLC
    ADC #$20            ; Offset from top
    STA HazardYPositionArray,X

    ; Set hazard properties based on type
    LDY HazardTypeArray,X
    LDA HazardSizeTable,Y
    STA HazardSizeArray,X
    LDA HazardIntensityTable,Y
    STA HazardIntensityArray,X
    LDA HazardDurationTable,Y
    STA HazardTimerArray,X

    ; Assign sprite for hazard
    LDA ActiveHazardCount
    STA HazardSpriteArray,X

    ; Increment active hazard count
    INC ActiveHazardCount

HazardSpawnComplete:
    RTS

; Render particle systems using sprite management
RenderParticleSystems:
    ; Clear sprite buffer
    JSR ClearSpriteBuffer

    ; Render all active particles
    LDX #$00            ; Start with particle 0
    LDY #$00            ; Sprite index

RenderParticlesLoop:
    ; Check if particle is active
    LDA ParticleActiveArray,X
    BEQ NextParticleRender

    ; Check sprite limit
    CPY #$40            ; 64 sprites maximum
    BCS ParticleRenderingComplete

    ; Render individual particle
    JSR RenderIndividualParticle

    ; Advance sprite index by 4 (one sprite)
    INY
    INY
    INY
    INY

NextParticleRender:
    INX
    CPX #$20            ; Check all 32 particles
    BNE RenderParticlesLoop

ParticleRenderingComplete:
    ; Upload sprite data during VBlank
    JSR UploadSpriteData

    RTS

; Render individual particle using sprites
RenderIndividualParticle:
    ; X contains particle index, Y contains sprite buffer offset
    ; Set sprite Y position
    LDA ParticleYPositionArray,X
    SEC
    SBC #$01            ; Adjust for PPU sprite offset
    STA SpriteBuffer,Y

    ; Set sprite tile based on particle type
    LDA ParticleTypeArray,X
    TAZ                 ; Use Z as temporary
    LDA ParticleTileTable,Z
    INY
    STA SpriteBuffer,Y

    ; Set sprite attributes (palette and priority)
    INY
    LDA ParticleTypeArray,X
    AND #$03            ; 4 different particle palettes
    STA SpriteBuffer,Y

    ; Set sprite X position
    INY
    LDA ParticleXPositionArray,X
    STA SpriteBuffer,Y

    ; Move back to start of next sprite
    DEY
    DEY
    DEY

    RTS

; Environmental effects data tables and variables
.segment "BSS"

GlobalEnvironmentalState:           .res 1  ; Global environmental state
EnvironmentalUpdateCounter:         .res 1  ; Environmental update counter
AtmosphericIntensityLevel:          .res 1  ; Atmospheric intensity level
HazardActivityLevel:                .res 1  ; Hazard activity level
EnvironmentalTimingCounter:         .res 1  ; Environmental timing counter

; Particle system variables

ParticleYPositionArray:             .res 32 ; Particle Y positions

; Particle system control variables

AtmosphericParticleSpawnCounter:    .res 1  ; Atmospheric spawn counter

; Atmospheric effects variables
ColorCycleCounter:                  .res 1  ; Color cycle counter
MoodTransitionState:                .res 1  ; Mood transition state
AtmosphericDensity:                 .res 1  ; Atmospheric density
CurrentAtmosphericColor:            .res 1  ; Current atmospheric color
ColorCycleSpeed:                    .res 1  ; Color cycle speed
AtmosphericParticleDensity:         .res 1  ; Atmospheric particle density
AtmosphericDriftSpeed:              .res 1  ; Atmospheric drift speed

; Electrical hazards variables
HazardActiveArray:                  .res 8  ; Hazard active flags
HazardTypeArray:                    .res 8  ; Hazard type IDs
HazardXPositionArray:               .res 8  ; Hazard X positions
HazardYPositionArray:               .res 8  ; Hazard Y positions
HazardSizeArray:                    .res 8  ; Hazard sizes
HazardIntensityArray:               .res 8  ; Hazard intensities
HazardTimerArray:                   .res 8  ; Hazard timers
HazardSpriteArray:                  .res 8  ; Hazard sprite assignments

; Hazard system control variables
ActiveHazardCount:                  .res 1  ; Active hazard count
HazardSpawnTimer:                   .res 1  ; Hazard spawn timer
HazardIntensityLevel:               .res 1  ; Hazard intensity level
ElectricalDangerLevel:              .res 1  ; Electrical danger level

; Conductor interaction tracking
ConductorInteractionFlags:          .res 8  ; Conductor interaction flags
ConductorInteractionX:              .res 1  ; Interaction X position
ConductorInteractionY:              .res 1  ; Interaction Y position

; Sprite management
SpriteBuffer:                       .res 256 ; Sprite buffer (64 sprites × 4 bytes)

.segment "RODATA"

; Data tables
ParticleTileTable:                  .byte $10, $11, $12, $13, $14, $15, $16, $17
HazardSizeTable:                    .byte $08, $10, $18, $20
HazardIntensityTable:               .byte $02, $04, $06, $08

; Environmental palette table
EnvironmentalPaletteTable:          .byte $00, $01, $02, $03

; Circuit pattern table

                                    .byte $28, $29, $2A, $2B, $2C, $2D, $2E, $2F
                                    .byte $30, $31, $32, $33, $34, $35, $36, $37
                                    .byte $38, $39, $3A, $3B, $3C, $3D, $3E, $3F

; Column offset table for pattern variation
DrawColumnXOffset:                  .byte $00, $01, $02, $03, $04, $05, $06, $07
                                    .byte $08, $09, $0A, $0B, $0C, $0D, $0E, $0F
                                    .byte $10, $11, $12, $13, $14, $15, $16, $17
                                    .byte $18, $19, $1A, $1B, $1C, $1D, $1E, $1F
```
