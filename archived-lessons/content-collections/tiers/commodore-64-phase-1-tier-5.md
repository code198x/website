# Tier 5: Subroutines and Code Organization

Learn the power of modular programming in 6502 assembly! This tier teaches you subroutines and code organisation while beginning your journey toward creating **Color Cascade**, a pattern-matching assembly game.

## What You'll Start Building

Begin **Color Cascade** development:

- Modular subroutines for display and colour control
- Organized assembly code structure
- Reusable graphics routines
- Foundation for complex visual effects

## Tier Overview

**Lessons 1-8: Subroutine Fundamentals**

- JSR (Jump to Subroutine) instruction
- RTS (Return from Subroutine) instruction
- Understanding the call/return mechanism
- Creating your first assembly subroutines

**Lessons 9-16: Stack Operations**

- How the 6502 stack works
- Stack pointer management
- Preserving registers in subroutines
- Parameter passing techniques

**Lessons 17-24: Code Organization**

- Structuring assembly programs with subroutines
- Creating reusable code modules
- Label organisation and naming conventions
- Building function libraries

**Lessons 25-32: Color Cascade Architecture**

- Designing the game's subroutine structure
- Creating display and colour control routines
- Building input handling subroutines
- Implementing modular game architecture

## Key Assembly Concepts

Expand your skills into modular programming:

- **Subroutines** - Creating reusable blocks of assembly code
- **Stack Management** - Understanding how function calls work
- **Code Organization** - Structuring complex assembly programs
- **Modularity** - Building programs from interchangeable parts
- **Professional Practices** - Writing maintainable assembly code

## Assembly Programming Benefits

Discover the power of structured assembly:

- **Reusable code** - Write once, use many times
- **Organized structure** - Easy to understand and maintain
- **Efficient execution** - Optimized subroutine calls
- **Professional development** - Industry-standard practices
- **Scalable architecture** - Build complex programs systematically

## Modular Programming Mindset

Learn to think in modules:

- **Divide and conquer** - Break complex problems into smaller parts
- **Single responsibility** - Each subroutine has one clear purpose
- **Reusability** - Design code that can be used in multiple contexts
- **Testing** - Easier to test and debug individual components
- **Collaboration** - Multiple programmers can work on different subroutines

## Real-World Applications

Modular programming skills transfer directly to:

- **Embedded systems** with subroutine-based firmware
- **Game engines** built from modular components
- **Operating systems** organised around system calls
- **Device drivers** using standardized function interfaces
- **Modern programming** where functions are fundamental

The modular programming techniques you learn here form the foundation for all software engineering!
