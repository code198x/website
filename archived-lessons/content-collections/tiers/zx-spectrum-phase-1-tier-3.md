# Tier 3: Decisions and Choices

Teach your assembly programs to think! Learn conditional assembly programming to create software that makes intelligent decisions and responds appropriately to different situations using direct hardware control.

## What You'll Learn

Create assembly programs that can choose their own path:

- Z80 jump and branch instructions for decision making
- Comparing values and making choices using assembly flags
- Creating assembly programs that respond intelligently
- Building complex decision logic with assembly code

## Tier Overview

**Lessons 1-8: Basic Assembly Conditionals**

- Z80 jump and branch instruction structure
- Simple true/false decisions using assembly flags
- Comparing numbers and data using assembly operations
- Creating your first decision-making assembly program

**Lessons 9-16: Assembly Comparison Operations**

- Equal to and not equal to comparisons using Z80 flags
- Greater than and less than relationships in assembly
- Complex comparisons using multiple assembly operations
- Combining assembly comparisons for complex decisions

**Lessons 17-24: Complex Assembly Decision Logic**

- Nested assembly jumps for multi-level decisions
- Multiple condition checking using assembly flags
- Creating decision trees and flowcharts for assembly code
- Building a simple assembly quiz program

**Lessons 25-32: Advanced Assembly Conditional Programming**

- Optimizing assembly decision logic for efficiency
- Common assembly conditional programming patterns
- Debugging assembly conditional logic errors
- Preparing for Pixel Painter assembly game project

Assembly conditional programming transforms your code from simple calculators into intelligent, responsive software that can adapt and respond to any situation using direct hardware control!
