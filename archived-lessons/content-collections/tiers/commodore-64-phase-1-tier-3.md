# Tier 3: Branching and Program Flow

Learn how the 6502 processor makes decisions at the hardware level. This tier teaches you conditional branching and program flow control - the foundation of intelligent assembly language programs.

## What You'll Build

Enhance **Number Quest** with intelligent assembly features:

- Conditional logic for hint generation
- Branch-based difficulty adjustment
- Multiple game modes using efficient flow control
- Assembly-based decision trees

## Tier Overview

**Lessons 1-8: Status Flags and Comparisons**

- Understanding 6502 processor status flags
- Compare operations (CMP, CPX, CPY)
- How flags are set and tested
- Basic branching with flag conditions

**Lessons 9-16: Branch Instructions**

- Branch on Equal/Not Equal (BEQ, BNE)
- Branch on Carry/No Carry (BCC, BCS)
- Branch on Negative/Positive (BMI, BPL)
- Branch on Overflow (BVS, BVC)

**Lessons 17-24: Complex Decision Logic**

- Building decision trees with multiple branches
- Efficient branching patterns and optimisation
- Creating state machines in assembly
- Managing program flow with jumps and branches

**Lessons 25-32: Number Quest Intelligence**

- Implementing assembly-based game logic
- Building conditional hint systems
- Creating adaptive difficulty through branching
- Optimizing decision-making code

## Key Assembly Concepts

This tier covers essential 6502 decision-making:

- **Status Flags** - How the processor tracks computation results
- **Conditional Branching** - Making decisions based on flag states
- **Program Flow Control** - Directing execution at the hardware level
- **Efficient Branching** - Writing optimal decision-making code
- **State Management** - Tracking program state through memory

## Hardware-Level Decision Making

Learn how computers really make decisions:

- **Flag-based logic** - How processors implement boolean operations
- **Branch prediction** - Understanding processor efficiency
- **Conditional execution** - Hardware-level program flow
- **Memory-based state** - Storing decision information
- **Optimization patterns** - Writing efficient decision code

## Real-World Applications

These assembly concepts apply to:

- **Embedded systems** that make real-time decisions
- **Game engines** requiring high-performance logic
- **Operating systems** managing system resources
- **Compilers** that translate high-level logic to machine code
- **Device drivers** handling hardware conditions

Understanding decision-making at the assembly level gives you insight into how all programming languages implement logic and control flow!
