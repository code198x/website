# Tile Craft

**Tile Craft** explores the sophisticated world of NES background graphics and level design, teaching advanced PPU programming through the creation of a complete tile-based world editor.

## The Game Concept

Build a professional-quality level design system:

- **Tile Editor**: Create and modify NES tile graphics and patterns
- **Level Designer**: Build complex, scrolling game worlds
- **World Editor**: Connect multiple levels into complete game experiences
- **Testing Environment**: Play and refine created levels
- **Export System**: Generate data for use in other NES games

## Why This Game for Tiers 9-12?

**Tile Craft** introduces sophisticated NES programming concepts:

- **Advanced Graphics**: Learn the NES background and tile systems
- **Memory Management**: Handle complex data structures efficiently
- **System Architecture**: Build large, interconnected software systems
- **Data Compression**: Store maximum content in minimal space
- **Performance Optimization**: Maintain smooth scrolling and responsiveness

## NES Graphics System Mastery

Leverages the complete NES PPU background capabilities:

- **Pattern Tables**: Design and manipulate tile graphics data
- **Name Tables**: Control tile placement and screen layout
- **Attribute Tables**: Manage colour palettes and visual effects
- **Scrolling Registers**: Create smooth camera movement
- **Advanced Techniques**: Split-screen effects and dynamic graphics

## Progressive Development
