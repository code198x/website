# Power-ups and Collectibles: The Art of Reward
**From simple scoring to strategic gameplay transformation**

In 1987, "R-Type" changed everything. A single power-up capsule could transform your weak fighter into a screen-filling force of destruction. "Gradius" let players choose their upgrades, creating strategic decisions. "Bubble Bobble" filled screens with fruits, diamonds, and mysterious items that could change the entire game's dynamic. These weren't just scoring bonuses - they were gameplay transformers.

The C64's best games understood that collectibles weren't decorations; they were motivation. Every coin in "Super Mario Bros" pulled players forward. Every diamond in "Boulder Dash" created risk/reward calculations. Every power-up in "Arkanoid" offered a glimpse of greater power. Great item systems don't just reward players - they teach them, guide them, and transform their experience.

This lesson reveals the architecture behind compelling collectible systems. You'll learn how to create items that feel meaningful, implement power-ups that change gameplay without breaking balance, and design visual feedback that makes every collection feel satisfying.

## The Psychology of Collectibles

Before examining code, consider what made C64 collectibles compelling:

- **"Pac-Man"** - Dots created path-finding puzzles; power pellets offered temporary revenge
- **"Defender"** - Humanoids weren't just scores; saving them was the game's emotional core  
- **"Impossible Mission"** - Furniture pieces were puzzle elements, not just collectibles
- **"The Last Ninja"** - Items were tools that unlocked new areas and abilities
- **"Turrican"** - Power-ups felt essential; losing them was genuinely painful

The best collectibles served multiple purposes: scoring, progression, strategy, and emotional engagement.

```asm
; Professional item management system
; Used by games like "Metroid" and "Zelda"

; Item structure - 16 bytes per item for maximum flexibility
ITEM_TYPE        = 0    ; Object type ID
ITEM_SUBTYPE     = 1    ; Variant or level
ITEM_X_LO        = 2    ; X position low byte
```

## Advanced Item Spawning

Professional item placement creates meaningful choices:

```asm
; Intelligent item spawning system
; Balances randomness with player need and game flow

spawn_item_advanced:
    ; Input: A = item type, X = x position, Y = y position
    sta temp_item_type
    stx temp_x_pos
    sty temp_y_pos
    
    ; Find available item slot
    jsr find_free_item_slot
    bcc .spawn_failed       ; Carry clear = no slots
    
    ; X now contains the item index (0-31)
    stx temp_item_index
    
    ; Calculate item table offset (index * 16)
    txa
    asl                     ; * 2
    asl                     ; * 4
    asl                     ; * 8
    asl                     ; * 16
    tay
    
    ; Initialize core properties
    lda temp_item_type
    sta item_table+ITEM_TYPE,y
    lda #0
    sta item_table+ITEM_SUBTYPE,y
    
    ; Position
    lda temp_x_pos
    sta item_table+ITEM_X_LO,y
    lda #0
    sta item_table+ITEM_X_HI,y
    lda temp_y_pos
    sta item_table+ITEM_Y,y
    
    ; Initialize from type tables
    ldx temp_item_type
    lda item_base_values,x
    sta item_table+ITEM_VALUE,y
    lda item_sprites,x
    sta item_table+ITEM_SPRITE,y
    lda item_characters,x
    sta item_table+ITEM_CHARACTER,y
    lda item_colors,x
    sta item_table+ITEM_COLOR,y
    lda item_behaviors,x
    sta item_table+ITEM_BEHAVIOR,y
    
    ; Initialize animation and physics
    lda #0
    sta item_table+ITEM_VX,y
    sta item_table+ITEM_VY,y
    sta item_table+ITEM_ANIM_FRAME,y
    sta item_table+ITEM_ANIM_TIMER,y
    sta item_table+ITEM_STATE,y
    sta item_table+ITEM_SPECIAL,y
    
    ; Apply special initialization based on type
    lda temp_item_type
    cmp #TYPE_COIN
    bcc .init_scoring
    cmp #TYPE_LIFE_UP
    bcc .init_scoring
    cmp #TYPE_SHIELD
    bcc .init_health
    cmp #TYPE_KEY_RED
    bcc .init_powerup
    cmp #TYPE_ARTIFACT
    bcc .init_key
    jmp .init_special
    
.init_scoring:
    ; Scoring items get sparkle effect
    lda item_table+ITEM_BEHAVIOR,y
    ora #BEHAV_SPARKLE
    sta item_table+ITEM_BEHAVIOR,y
    jmp .spawn_complete
    
.init_health:
    ; Health items pulse gently
    lda item_table+ITEM_BEHAVIOR,y
    ora #BEHAV_PULSE
    sta item_table+ITEM_BEHAVIOR,y
    jmp .spawn_complete
    
.init_powerup:
    ; Power-ups are magnetic and float
    lda item_table+ITEM_BEHAVIOR,y
    ora #BEHAV_MAGNETIC|BEHAV_FLOAT
    sta item_table+ITEM_BEHAVIOR,y
    
    ; Set power-up duration
    lda #180                ; 3 seconds default
    sta item_table+ITEM_SPECIAL,y
    jmp .spawn_complete
    
.init_key:
    ; Keys are static but important
    lda #1                  ; One-time use
    sta item_table+ITEM_SPECIAL,y
    jmp .spawn_complete
    
.init_special:
    ; Special items get unique behaviors
    jmp .spawn_complete
    
.spawn_complete:
    sec                     ; Success
    rts
    
.spawn_failed:
    clc                     ; Failed
    rts

find_free_item_slot:
    ; Returns: Carry set if slot found, X = slot index
    ldx #0
.search_loop:
    txa
    asl
    asl
    asl
    asl
    tay
    
    lda item_table+ITEM_TYPE,y
    cmp #TYPE_EMPTY
    beq .found_slot
    
    inx
    cpx #MAX_ITEMS
    bne .search_loop
    
    clc                     ; No slots found
    rts
    
.found_slot:
    sec                     ; Slot found
    rts

; Variables for item spawning
temp_item_type:  .byte 0
temp_x_pos:      .byte 0
temp_y_pos:      .byte 0
temp_item_index: .byte 0
```

This spawning system automatically configures items based on type, making it easy to create diverse collectibles with consistent behavior.

## Sophisticated Collection Detection

Handle complex collision scenarios with precision:

```asm
; Advanced collision detection with item magnetism and zones
check_item_collection:
    ; Get player position and collision box
    lda player_x_lo
    sta player_center_x
    lda player_y
    clc
    adc #4                  ; Center of 8-pixel sprite
    sta player_center_y
    
    ldx #0
.collection_loop:
    txa
    asl
    asl
    asl
    asl
    tay
    
    ; Check if item exists
    lda item_table+ITEM_TYPE,y
    cmp #TYPE_EMPTY
    beq .next_item
    
    ; Calculate distance to player
    lda item_table+ITEM_X_LO,y
    clc
    adc #4                  ; Item center
    sec
    sbc player_center_x
    bpl .positive_dx
    eor #$ff                ; Make positive
    clc
    adc #1
.positive_dx:
    sta distance_x
    
    lda item_table+ITEM_Y,y
    clc
    adc #4
    sec
    sbc player_center_y
    bpl .positive_dy
    eor #$ff
    clc
    adc #1
.positive_dy:
    sta distance_y
    
    ; Check for magnetic attraction
    lda item_table+ITEM_BEHAVIOR,y
    and #BEHAV_MAGNETIC
    beq .check_collection
    
    ; Apply magnetic force if within range
    lda distance_x
    clc
    adc distance_y
    cmp #32                 ; Magnetic range
    bcs .check_collection
    
    jsr apply_magnetic_force
    
.check_collection:
    ; Check for actual collection (close contact)
    lda distance_x
    cmp #6                  ; Collection tolerance
    bcs .next_item
    lda distance_y
    cmp #6
    bcs .next_item
    
    ; Item collected!
    jsr process_item_collection
    
    ; Remove item from world
    lda #TYPE_EMPTY
    sta item_table+ITEM_TYPE,y
    
    ; Visual/audio feedback
    jsr collection_feedback
    
.next_item:
    inx
    cpx #MAX_ITEMS
    bne .collection_loop
    rts

apply_magnetic_force:
    ; Y = item offset, distance_x/y set
    ; Move item toward player
    
    ; X-axis attraction
    lda item_table+ITEM_X_LO,y
    cmp player_center_x
    beq .check_y_magnetic
    bcs .pull_left
    
    ; Pull right
    inc item_table+ITEM_X_LO,y
    jmp .check_y_magnetic
.pull_left:
    dec item_table+ITEM_X_LO,y
    
.check_y_magnetic:
    ; Y-axis attraction
    lda item_table+ITEM_Y,y
    cmp player_center_y
    beq .magnetic_done
    bcs .pull_up
    
    ; Pull down
    inc item_table+ITEM_Y,y
    jmp .magnetic_done
.pull_up:
    dec item_table+ITEM_Y,y
    
.magnetic_done:
    rts

process_item_collection:
    ; Y = item table offset
    ; Handle different item types appropriately
    
    lda item_table+ITEM_TYPE,y
    
    ; Scoring items
    cmp #TYPE_COIN
    beq .collect_coin
    cmp #TYPE_GEM
    beq .collect_gem
    cmp #TYPE_DIAMOND
    beq .collect_diamond
    
    ; Health/life items
    cmp #TYPE_LIFE_UP
    beq .collect_life
    cmp #TYPE_HEALTH
    beq .collect_health
    
    ; Power-ups
    cmp #TYPE_SHIELD
    beq .collect_shield
    cmp #TYPE_SPEED
    beq .collect_speed
    cmp #TYPE_WEAPON
    beq .collect_weapon
    cmp #TYPE_FREEZE
    beq .collect_freeze
    
    ; Keys and tools
    cmp #TYPE_KEY_RED
    bcc .collect_key
    cmp #TYPE_ARTIFACT
    bcc .collect_key
    cmp #TYPE_TOOL
    beq .collect_tool
    
    rts
    
.collect_coin:
    lda item_table+ITEM_VALUE,y
    jsr add_to_score
    jsr register_combo_action
    rts
    
.collect_gem:
    lda item_table+ITEM_VALUE,y
    asl                     ; 2x multiplier
    jsr add_to_score
    jsr register_combo_action
    rts
    
.collect_diamond:
    lda item_table+ITEM_VALUE,y
    asl
    asl                     ; 4x multiplier
    jsr add_to_score
    jsr register_combo_action
    jsr trigger_diamond_sparkles
    rts
    
.collect_life:
    jsr add_player_life
    rts
    
.collect_health:
    lda item_table+ITEM_VALUE,y
    jsr restore_player_health
    rts
    
.collect_shield:
    lda item_table+ITEM_SPECIAL,y  ; Duration
    jsr activate_shield_powerup
    rts
    
.collect_speed:
    lda item_table+ITEM_SPECIAL,y
    jsr activate_speed_powerup
    rts
    
.collect_weapon:
    jsr upgrade_weapon_level
    rts
    
.collect_freeze:
    lda item_table+ITEM_SPECIAL,y
    jsr activate_freeze_powerup
    rts
    
.collect_key:
    lda item_table+ITEM_TYPE,y
    jsr add_to_inventory
    rts
    
.collect_tool:
    lda item_table+ITEM_TYPE,y
    jsr add_to_inventory
    rts

; Collection detection variables
player_center_x: .byte 0
player_center_y: .byte 0
distance_x:      .byte 0
distance_y:      .byte 0
```

This system handles everything from simple collection to magnetic attraction, making items feel responsive and alive.

## Power-up Effect Management

Create temporary abilities that transform gameplay:

```asm
; Professional power-up system with stacking and interactions
; Used by games like "Gradius" and "R-Type"

; Power-up state tracking
active_powerups:     .byte 0    ; Bit flags for active powers
shield_timer:        .byte 0    ; Remaining shield time  
speed_timer:         .byte 0    ; Remaining speed boost time
weapon_level:        .byte 0    ; Current weapon power (0-7)
freeze_timer:        .byte 0    ; Enemy freeze remaining
invulnerable_timer:  .byte 0    ; Temporary invulnerability

; Power-up bit flags
POWER_SHIELD    = $01
POWER_SPEED     = $02
POWER_WEAPON    = $04
POWER_FREEZE    = $08
POWER_INVULN    = $10
POWER_DOUBLE    = $20   ; Double-shot
POWER_RAPID     = $40   ; Rapid fire
POWER_SPECIAL   = $80   ; Special weapon

activate_shield_powerup:
    ; Input: A = duration in seconds
    asl
    asl
    asl                     ; Convert to frames (*8 ≈ *60/8)
    asl
    asl
    asl
    sta shield_timer
    
    ; Set power-up flag
    lda active_powerups
    ora #POWER_SHIELD
    sta active_powerups
    
    ; Visual feedback - change player color
    lda #SHIELD_COLOR
    sta player_color_override
    
    ; Sound effect
    jsr play_powerup_sound
    
    ; Display message
    lda #<msg_shield_active
    ldy #>msg_shield_active
    ldx #SHIELD_COLOR
    jsr queue_message
    
    rts

activate_speed_powerup:
    ; Input: A = duration
    asl
    asl
    asl
    asl
    asl
    asl
    sta speed_timer
    
    lda active_powerups
    ora #POWER_SPEED
    sta active_powerups
    
    ; Increase player movement speed
    lda #2
    sta player_speed_bonus
    
    lda #SPEED_COLOR
    sta player_color_override
    
    jsr play_speed_sound
    
    lda #<msg_speed_active
    ldy #>msg_speed_active
    ldx #SPEED_COLOR
    jsr queue_message
    
    rts

upgrade_weapon_level:
    ; Increment weapon power
    inc weapon_level
    lda weapon_level
    cmp #8
    bcc .weapon_ok
    lda #7                  ; Maximum level
    sta weapon_level
    
    ; Award points for max weapon bonus
    lda #100
    jsr add_to_score
    
.weapon_ok:
    lda active_powerups
    ora #POWER_WEAPON
    sta active_powerups
    
    ; Check for special weapon unlocks
    lda weapon_level
    cmp #4
    bcc .no_double_shot
    
    lda active_powerups
    ora #POWER_DOUBLE
    sta active_powerups
    
.no_double_shot:
    cmp #6
    bcc .no_rapid_fire
    
    lda active_powerups
    ora #POWER_RAPID
    sta active_powerups
    
.no_rapid_fire:
    ; Visual feedback
    jsr update_weapon_display
    jsr play_weapon_sound
    
    rts

activate_freeze_powerup:
    ; Input: A = duration
    asl
    asl
    asl
    asl
    asl
    asl
    sta freeze_timer
    
    lda active_powerups
    ora #POWER_FREEZE
    sta active_powerups
    
    ; Apply freeze to all enemies
    jsr freeze_all_enemies
    
    ; Visual effect - flash screen
    jsr flash_screen_effect
    
    lda #<msg_freeze_active
    ldy #>msg_freeze_active
    ldx #FREEZE_COLOR
    jsr queue_message
    
    rts

update_powerups:
    ; Update all active power-up timers
    
    ; Shield power-up
    lda shield_timer
    beq .no_shield_update
    
    dec shield_timer
    bne .shield_still_active
    
    ; Shield expired
    lda active_powerups
    and #($FF ^ POWER_SHIELD)  ; Clear shield bit
    sta active_powerups
    
    lda #NORMAL_PLAYER_COLOR
    sta player_color_override
    
    lda #<msg_shield_expired
    ldy #>msg_shield_expired
    ldx #$02                ; Red warning
    jsr queue_message
    
.shield_still_active:
    ; Flash warning when shield is about to expire
    lda shield_timer
    cmp #60                 ; Last second
    bcs .no_shield_update
    
    and #$04                ; Flash every 4 frames
    beq .no_shield_update
    lda #WARNING_COLOR
    sta player_color_override
    
.no_shield_update:
    
    ; Speed power-up
    lda speed_timer
    beq .no_speed_update
    
    dec speed_timer
    bne .no_speed_update
    
    ; Speed expired
    lda active_powerups
    and #($FF ^ POWER_SPEED)
    sta active_powerups
    
    lda #0
    sta player_speed_bonus
    
    lda #NORMAL_PLAYER_COLOR
    sta player_color_override
    
.no_speed_update:
    
    ; Freeze power-up
    lda freeze_timer
    beq .no_freeze_update
    
    dec freeze_timer
    bne .no_freeze_update
    
    ; Freeze expired
    lda active_powerups
    and #($FF ^ POWER_FREEZE)
    sta active_powerups
    
    jsr unfreeze_all_enemies
    
.no_freeze_update:
    
    ; Invulnerability (from taking damage)
    lda invulnerable_timer
    beq .no_invuln_update
    
    dec invulnerable_timer
    bne .invuln_still_active
    
    lda active_powerups
    and #($FF ^ POWER_INVULN)
    sta active_powerups
    
    lda #NORMAL_PLAYER_COLOR
    sta player_color_override
    jmp .no_invuln_update
    
.invuln_still_active:
    ; Flash player during invulnerability
    lda invulnerable_timer
    and #$02
    beq .flash_normal
    lda #INVULN_FLASH_COLOR
    jmp .set_invuln_color
.flash_normal:
    lda #NORMAL_PLAYER_COLOR
.set_invuln_color:
    sta player_color_override
    
.no_invuln_update:
    rts

; Power-up constants
SHIELD_COLOR         = $0D  ; Light green
SPEED_COLOR          = $07  ; Yellow
FREEZE_COLOR         = $0E  ; Light blue
WARNING_COLOR        = $02  ; Red
NORMAL_PLAYER_COLOR  = $01  ; White
INVULN_FLASH_COLOR   = $0F  ; Light gray

; Power-up messages
msg_shield_active:
    .text "SHIELD ACTIVE!"
    .byte 0
msg_shield_expired:
    .text "SHIELD DOWN"
    .byte 0
msg_speed_active:
    .text "SPEED BOOST!"
    .byte 0
msg_freeze_active:
    .text "TIME FREEZE!"
    .byte 0

; Power-up state variables
player_color_override: .byte NORMAL_PLAYER_COLOR
player_speed_bonus:    .byte 0
```

This system creates layered power-up effects that stack and interact naturally, providing rich gameplay possibilities.

## Advanced Item Animation

Create visually compelling collectibles that attract attention:

```asm
; Professional item animation system
; Creates the visual appeal that made C64 collectibles memorable

animation_master_timer: .byte 0
float_sine_index:      .byte 0
sparkle_phase:         .byte 0
rotation_angle:        .byte 0

animate_all_items:
    ; Master animation timing
    inc animation_master_timer
    
    ; Update animation indices every few frames
    lda animation_master_timer
    and #$03                ; Every 4 frames
    bne .skip_index_update
    
    inc float_sine_index
    lda float_sine_index
    and #$1F                ; 32-frame cycle
    sta float_sine_index
    
    inc sparkle_phase
    lda sparkle_phase
    and #$07                ; 8-frame sparkle cycle
    sta sparkle_phase
    
    inc rotation_angle
    lda rotation_angle
    and #$0F                ; 16-frame rotation
    sta rotation_angle
    
.skip_index_update:
    
    ; Animate each active item
    ldx #0
.item_animation_loop:
    txa
    asl
    asl
    asl
    asl
    tay
    
    lda item_table+ITEM_TYPE,y
    cmp #TYPE_EMPTY
    beq .next_animation
    
    ; Update item's animation timer
    inc item_table+ITEM_ANIM_TIMER,y
    
    ; Apply behavior-based animations
    lda item_table+ITEM_BEHAVIOR,y
    
    and #BEHAV_FLOAT
    beq .check_rotate
    jsr animate_floating
    
.check_rotate:
    lda item_table+ITEM_BEHAVIOR,y
    and #BEHAV_ROTATE
    beq .check_sparkle
    jsr animate_rotation
    
.check_sparkle:
    lda item_table+ITEM_BEHAVIOR,y
    and #BEHAV_SPARKLE
    beq .check_pulse
    jsr animate_sparkle
    
.check_pulse:
    lda item_table+ITEM_BEHAVIOR,y
    and #BEHAV_PULSE
    beq .check_bounce
    jsr animate_pulse
    
.check_bounce:
    lda item_table+ITEM_BEHAVIOR,y
    and #BEHAV_BOUNCE
    beq .next_animation
    jsr animate_bounce
    
.next_animation:
    inx
    cpx #MAX_ITEMS
    bne .item_animation_loop
    
    rts

animate_floating:
    ; Y = item table offset
    ; Create gentle vertical floating motion
    
    lda float_sine_index
    tax
    lda floating_sine_table,x
    
    ; Add to base Y position (stored in ITEM_STATE)
    clc
    adc item_table+ITEM_STATE,y
    sta item_table+ITEM_Y,y
    
    rts

animate_rotation:
    ; Y = item table offset
    ; Rotate through different character representations
    
    lda item_table+ITEM_TYPE,y
    cmp #TYPE_DIAMOND
    bne .not_diamond
    
    ; Diamond rotation uses different characters
    lda rotation_angle
    lsr
    lsr                     ; /4 for slower rotation
    and #$03                ; 4 frames
    tax
    lda diamond_rotation_chars,x
    sta item_table+ITEM_CHARACTER,y
    
.not_diamond:
    rts

animate_sparkle:
    ; Y = item table offset
    ; Cycle through sparkle colors
    
    lda sparkle_phase
    tax
    lda sparkle_color_table,x
    sta item_table+ITEM_COLOR,y
    
    rts

animate_pulse:
    ; Y = item table offset
    ; Pulse between two sizes/colors
    
    lda item_table+ITEM_ANIM_TIMER,y
    and #$08                ; 8-frame half-cycle
    beq .pulse_small
    
    ; Pulse large/bright
    lda item_table+ITEM_TYPE,y
    tax
    lda item_colors,x
    ora #$08                ; Make brighter if possible
    sta item_table+ITEM_COLOR,y
    jmp .pulse_done
    
.pulse_small:
    ; Pulse small/dim
    lda item_table+ITEM_TYPE,y
    tax
    lda item_colors,x
    sta item_table+ITEM_COLOR,y
    
.pulse_done:
    rts

animate_bounce:
    ; Y = item table offset
    ; Simple bouncing physics
    
    ; Apply gravity
    lda item_table+ITEM_VY,y
    clc
    adc #1                  ; Gravity constant
    sta item_table+ITEM_VY,y
    
    ; Apply velocity to position
    lda item_table+ITEM_Y,y
    clc
    adc item_table+ITEM_VY,y
    sta item_table+ITEM_Y,y
    
    ; Check for ground collision (simplified)
    cmp #180                ; Ground level
    bcc .bounce_done
    
    ; Bounce!
    lda #180
    sta item_table+ITEM_Y,y
    
    lda item_table+ITEM_VY,y
    eor #$FF                ; Negate velocity
    clc
    adc #1
    lsr                     ; Lose energy on bounce
    sta item_table+ITEM_VY,y
    
.bounce_done:
    rts

; Animation data tables
floating_sine_table:
    .byte 0,0,1,1,2,2,3,3,3,3,3,2,2,1,1,0
    .byte 0,0,-1,-1,-2,-2,-3,-3,-3,-3,-3,-2,-2,-1,-1,0

diamond_rotation_chars:
    .byte $4F,$7E,$4F,$7C   ; Different diamond views

sparkle_color_table:
    .byte $01,$07,$0F,$03,$0E,$06,$0A,$02

; Store base positions for floating items
init_floating_item:
    ; Y = item table offset
    ; Store original Y position in STATE field
    lda item_table+ITEM_Y,y
    sta item_table+ITEM_STATE,y
    rts
```

## Strategic Item Spawning

Control the flow of rewards to maintain engagement:

```asm
; Intelligent spawning system that responds to player state
; Balances challenge, reward, and pacing

spawn_manager:
    ; Check global spawn cooldown
    lda global_spawn_timer
    beq .check_spawn_conditions
    dec global_spawn_timer
    rts
    
.check_spawn_conditions:
    ; Analyze game state to determine what to spawn
    jsr analyze_game_state
    
    ; Check if we should spawn something
    lda $d41b               ; Hardware random
    and spawn_probability   ; Variable probability
    bne .no_spawn_this_frame
    
    ; Determine spawn type based on analysis
    jsr choose_spawn_type
    
    ; Find safe spawn location
    jsr find_spawn_location
    bcc .no_spawn_this_frame  ; Carry clear = no safe location
    
    ; Spawn the item
    jsr spawn_item_advanced
    
    ; Set cooldown based on what was spawned
    lda last_spawned_type
    jsr set_spawn_cooldown
    
.no_spawn_this_frame:
    rts

analyze_game_state:
    ; Examine player state and adjust spawn priorities
    lda #0
    sta spawn_priority_health
    sta spawn_priority_power
    sta spawn_priority_score
    sta spawn_priority_special
    
    ; Check player health
    lda player_health
    cmp #3                  ; Low health threshold
    bcs .health_ok
    lda #80                 ; High priority for health items
    sta spawn_priority_health
    
.health_ok:
    ; Check power-up status
    lda active_powerups
    bne .has_powerups
    lda #60                 ; Medium priority for power-ups
    sta spawn_priority_power
    
.has_powerups:
    ; Check score progress (encourage scoring)
    lda frame_count
    and #$3F                ; Every 64 frames
    bne .score_check_done
    inc spawn_priority_score ; Gradually increase score priority
    
.score_check_done:
    ; Special items based on level progress
    lda current_level
    and #$03
    beq .no_special_bonus
    lda #40
    sta spawn_priority_special
    
.no_special_bonus:
    rts

choose_spawn_type:
    ; Weighted random selection based on priorities
    lda $d41b
    sta random_value
    
    ; Check health priority first
    lda spawn_priority_health
    beq .check_power_priority
    cmp random_value
    bcc .check_power_priority
    
    lda #TYPE_HEALTH
    sta chosen_spawn_type
    rts
    
.check_power_priority:
    lda spawn_priority_power
    beq .check_score_priority
    clc
    adc spawn_priority_health
    cmp random_value
    bcc .check_score_priority
    
    jsr choose_powerup_type
    rts
    
.check_score_priority:
    lda spawn_priority_score
    beq .check_special_priority
    clc
    adc spawn_priority_power
    adc spawn_priority_health
    cmp random_value
    bcc .check_special_priority
    
    jsr choose_scoring_type
    rts
    
.check_special_priority:
    lda spawn_priority_special
    beq .default_spawn
    
    jsr choose_special_type
    rts
    
.default_spawn:
    lda #TYPE_COIN
    sta chosen_spawn_type
    rts

choose_powerup_type:
    ; Select appropriate power-up based on player state
    lda active_powerups
    and #POWER_SHIELD
    bne .no_shield_spawn
    
    lda $d41b
    and #$03
    bne .try_speed
    lda #TYPE_SHIELD
    sta chosen_spawn_type
    rts
    
.try_speed:
.no_shield_spawn:
    lda active_powerups
    and #POWER_SPEED
    bne .try_weapon
    
    lda $d41b
    and #$01
    beq .try_weapon
    lda #TYPE_SPEED
    sta chosen_spawn_type
    rts
    
.try_weapon:
    lda weapon_level
    cmp #7                  ; Max weapon?
    bcs .try_freeze
    
    lda #TYPE_WEAPON
    sta chosen_spawn_type
    rts
    
.try_freeze:
    lda #TYPE_FREEZE
    sta chosen_spawn_type
    rts

choose_scoring_type:
    ; Higher value items as game progresses
    lda current_level
    clc
    adc $d41b
    and #$0F
    
    cmp #12
    bcs .spawn_diamond
    cmp #8
    bcs .spawn_gem
    
    lda #TYPE_COIN
    sta chosen_spawn_type
    rts
    
.spawn_gem:
    lda #TYPE_GEM
    sta chosen_spawn_type
    rts
    
.spawn_diamond:
    lda #TYPE_DIAMOND
    sta chosen_spawn_type
    rts

choose_special_type:
    ; Keys, artifacts, special tools
    lda keys_needed
    beq .try_artifact
    
    lda #TYPE_KEY_RED       ; Simplification
    sta chosen_spawn_type
    rts
    
.try_artifact:
    lda #TYPE_ARTIFACT
    sta chosen_spawn_type
    rts

find_spawn_location:
    ; Find safe location not too close to player
    lda #10                 ; Maximum attempts
    sta spawn_attempts
    
.location_search:
    ; Generate random position
    lda $d41b
    and #$F0                ; Align to 16-pixel grid
    clc
    adc #32                 ; Border margin
    cmp #255-32
    bcc .x_ok
    lda #255-32
.x_ok:
    sta temp_spawn_x
    
    lda $d41b
    and #$78                ; Y position range
    clc
    adc #50
    sta temp_spawn_y
    
    ; Check distance from player
    lda temp_spawn_x
    sec
    sbc player_x_lo
    bpl .dx_positive
    eor #$FF
    clc
    adc #1
.dx_positive:
    cmp #32                 ; Minimum distance
    bcc .try_again
    
    lda temp_spawn_y
    sec
    sbc player_y
    bpl .dy_positive
    eor #$FF
    clc
    adc #1
.dy_positive:
    cmp #32
    bcc .try_again
    
    ; Location is good
    ldx temp_spawn_x
    ldy temp_spawn_y
    sec                     ; Success
    rts
    
.try_again:
    dec spawn_attempts
    bne .location_search
    
    clc                     ; Failed
    rts

set_spawn_cooldown:
    ; A = item type that was spawned
    cmp #TYPE_DIAMOND
    beq .rare_cooldown
    cmp #TYPE_LIFE_UP
    beq .rare_cooldown
    cmp #TYPE_ARTIFACT
    beq .rare_cooldown
    
    ; Common items
    lda #30                 ; 0.5 seconds
    sta global_spawn_timer
    rts
    
.rare_cooldown:
    lda #180                ; 3 seconds for rare items
    sta global_spawn_timer
    rts

    ; Input: A = item type

    rts

    rts

    ; Find item in inventory
    ; Input: A = item type to find
    ; Output: Carry set if found, Y = index
    
    ldy #0

    cpy inventory_count
    bcs .not_found
    
    cmp inventory_items,y
    beq .found_item
    
    iny
    jmp .search_loop

    rts

    rts

    lda inventory_count
    beq .no_items
    
    lda selected_item
    cmp inventory_count
    bcs .invalid_selection
    
    tay
    lda inventory_items,y
    
    ; Handle different item types
    cmp #TYPE_KEY_RED
    beq .use_red_key
    cmp #TYPE_KEY_BLUE
    beq .use_blue_key
    cmp #TYPE_KEY_GOLD
    beq .use_gold_key
```

```asm
    asl
    asl
```

## Historical Masters

The games that perfected C64 collectible systems:

- **"Boulder Dash"** (1984) - First Software created the template for strategic collection with diamonds that required puzzle-solving to reach
- **"R-Type"** (1988) - Irem's power-up system was so compelling that losing upgrades felt genuinely painful
- **"Bubble Bobble"** (1987) - Taito filled screens with diverse collectibles, each with unique behaviors and values
- **"Arkanoid"** (1987) - Imagine's falling power-ups transformed simple ball-and-paddle into strategic gameplay
- **"The Last Ninja"** (1987) - System 3 proved that adventure game inventories could work beautifully on the C64
- **"Gradius"** (1988) - Konami's upgrade selection system gave players meaningful choices about their power progression

Each game understood that collectibles weren't just rewards - they were gameplay motivators that guided player behavior and created memorable moments.

## Quick Reference

### Item System Architecture
```asm
; 16-byte item structure
ITEM_TYPE = 0        ; What kind of item
ITEM_X_LO/HI = 2,3   ; Position
ITEM_VALUE = 7       ; Points/power/duration
ITEM_BEHAVIOR = 13   ; Animation/physics flags
```

### Behavior Flags
- `BEHAV_STATIC` - Stationary
- `BEHAV_FLOAT` - Bobs up/down
- `BEHAV_ROTATE` - Spins/changes appearance  
- `BEHAV_MAGNETIC` - Attracted to player
- `BEHAV_SPARKLE` - Color animation
- `BEHAV_PULSE` - Size/brightness changes

### Power-up Management
- Use timers for temporary effects
- Stack compatible power-ups
- Provide visual feedback (color changes, flashing)
- Handle interactions between different power types
- Include expiration warnings

### Animation Principles
- Use sine tables for smooth floating
- Rotate through character variations for spinning
- Cycle colors for sparkle effects
- Apply simple physics for bouncing
- Synchronize timing for visual coherence

Master collectible systems, and your games will keep players engaged for hours!
