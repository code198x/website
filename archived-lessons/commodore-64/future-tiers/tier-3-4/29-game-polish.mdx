# Game Polish and Feel

The difference between a good game and a great game isn't features - it's feel. Polish is what made "Bubble Bobble" magical, what made every hit in "International Karate" feel powerful, what made "Turrican" explosions satisfying. Today you'll learn these techniques.

## What You'll Build

This lesson teaches you to add:
1. **Screen shake** that makes explosions feel powerful
2. **Particle systems** for dynamic visual effects
3. **Smooth transitions** between game states
4. **Responsive feedback** for every player action

These details transform functional code into memorable experiences.

## The Psychology of Polish

Players don't consciously notice good polish - they feel it. When Mario jumps, there's a subtle squash before he leaves the ground. When Mega Man fires, the screen freezes for two frames. These microsecond details create the sensation we call "game feel."

Steve Bjork understood this when creating "Bubble Bobble" - every bubble had personality, every enemy had character, every action had feedback.

## Screen Shake: Making the World React

Screen shake communicates power. Use it for explosions, heavy landings, and powerful attacks:

```asm
; Advanced screen shake system
; Supports intensity, duration, and decay

    * = $0801
    ; BASIC stub
    !byte $0b,$08,$0a,$00,$9e
    !text "2061"
    !byte $00,$00,$00

    * = $080d

; Shake parameters
shake_intensity:  .byte 0    ; Current shake strength
shake_duration:   .byte 0    ; Frames remaining
shake_decay:      .byte 0    ; Decay rate
shake_x:          .byte 0    ; Current X offset
shake_y:          .byte 0    ; Current Y offset

; Original scroll values
base_scroll_x:    .byte $C8
base_scroll_y:    .byte $1B

main:
    jsr init_display
    
game_loop:
    ; Update shake
    jsr update_shake
    jsr apply_shake
    
    ; Check for shake triggers
    jsr $FFE4          ; GETIN
    cmp #' '           ; Spacebar
    bne check_other
    
    ; Big explosion shake
    lda #8             ; Intensity
    ldx #30            ; Duration
    ldy #1             ; Fast decay
    jsr trigger_shake
    
check_other:
    cmp #'1'
    bne continue_game
    
    ; Small shake
    lda #3
    ldx #10
    ldy #2
    jsr trigger_shake
    
continue_game:
    ; Wait for frame
    jsr wait_frame
    jmp game_loop

; Trigger screen shake
; A = intensity, X = duration, Y = decay rate
trigger_shake:
    sta shake_intensity
    stx shake_duration
    sty shake_decay
    rts

; Update shake system
update_shake:
    lda shake_duration
    beq shake_done
    
    ; Decrease duration
    dec shake_duration
    
    ; Apply decay to intensity
    lda shake_intensity
    sec
    sbc shake_decay
    bcs store_intensity
    lda #0
    
store_intensity:
    sta shake_intensity
    
    ; Calculate random offset based on intensity
    lda shake_intensity
    beq shake_done
    
    ; X offset
    lda $D41B          ; Random
    and #$0F
    sec
    sbc #8             ; -8 to +7
    
    ; Scale by intensity
    ldx shake_intensity
scale_x:
    asl                ; Multiply
    dex
    bne scale_x
    
    ; Limit range
    cmp #$F8           ; -8
    bcs x_ok
    cmp #$08           ; +8
    bcc x_ok
    lda #0
x_ok:
    sta shake_x
    
    ; Y offset (similar)
    lda $D41B
    and #$0F
    sec
    sbc #8
    
    ldx shake_intensity
scale_y:
    asl
    dex
    bne scale_y
    
    cmp #$F8
    bcs y_ok
    cmp #$08
    bcc y_ok
    lda #0
y_ok:
    sta shake_y
    rts

shake_done:
    lda #0
    sta shake_x
    sta shake_y
    rts

; Apply shake to display
apply_shake:
    ; Horizontal scroll
    lda base_scroll_x
    clc
    adc shake_x
    and #$CF           ; Keep in valid range
    sta $D016
    
    ; Vertical scroll
    lda base_scroll_y
    clc
    adc shake_y
    and #$1F           ; Keep in valid range
    ora #$10           ; Keep screen on
    sta $D011
    rts

init_display:
    lda #0
    sta $D020
    sta $D021
    rts

wait_frame:
    lda $D012
wait:
    cmp $D012
    beq wait
    rts
```

## Particle Systems

Particles add life and energy to your game:

```asm
; Complete particle system
; Supports different particle types and behaviors

MAX_PARTICLES = 32
GRAVITY = 1

; Particle data arrays
particle_active: .res MAX_PARTICLES
particle_x_lo:   .res MAX_PARTICLES
particle_x_hi:   .res MAX_PARTICLES
particle_y:      .res MAX_PARTICLES
particle_vx:     .res MAX_PARTICLES
particle_vy:     .res MAX_PARTICLES
particle_life:   .res MAX_PARTICLES
particle_type:   .res MAX_PARTICLES
particle_color:  .res MAX_PARTICLES

; Particle types
PARTICLE_SPARK = 0
PARTICLE_SMOKE = 1
PARTICLE_STAR = 2
PARTICLE_DEBRIS = 3

; Initialize particle system
init_particles:
    ldx #MAX_PARTICLES-1
    lda #0
clear_particles:
    sta particle_active,x
    dex
    bpl clear_particles
    rts

; Spawn explosion at X,Y
; A = particle count
spawn_explosion:
    sta temp_count
    stx spawn_x
    sty spawn_y
    
    ldx #0
find_slot:
    lda particle_active,x
    beq found_slot
    inx
    cpx #MAX_PARTICLES
    bne find_slot
    rts                ; No free slots

found_slot:
    ; Activate particle
    lda #1
    sta particle_active,x
    
    ; Set position
    lda spawn_x
    sta particle_x_lo,x
    lda #0
    sta particle_x_hi,x
    lda spawn_y
    sta particle_y,x
    
    ; Random velocity (explosion pattern)
    jsr get_random
    and #$0F
    sec
    sbc #8             ; -8 to +7
    sta particle_vx,x
    
    jsr get_random
    and #$0F
    sec
    sbc #12            ; Bias upward
    sta particle_vy,x
    
    ; Set properties
    lda #30            ; Lifetime
    sta particle_life,x
    
    lda #PARTICLE_SPARK
    sta particle_type,x
    
    ; Random color (hot colors)
    jsr get_random
    and #$03
    tay
    lda explosion_colors,y
    sta particle_color,x
    
    ; Next particle
    dec temp_count
    beq done_spawning
    inx
    cpx #MAX_PARTICLES
    bne find_slot

done_spawning:
    rts

explosion_colors:
    .byte 1,7,10,2    ; White, yellow, light red, red

spawn_x:     .byte 0
spawn_y:     .byte 0
temp_count:  .byte 0

; Update all particles
update_particles:
    ldx #0
update_particle_loop:
    lda particle_active,x
    beq next_particle
    
    ; Update lifetime
    dec particle_life,x
    bne particle_alive
    
    ; Particle died
    lda #0
    sta particle_active,x
    jmp next_particle

particle_alive:
    ; Update position based on velocity
    lda particle_x_lo,x
    clc
    adc particle_vx,x
    sta particle_x_lo,x
    
    ; Handle carry for 16-bit X
    lda particle_x_hi,x
    adc #0
    sta particle_x_hi,x
    
    ; Update Y position
    lda particle_y,x
    clc
    adc particle_vy,x
    sta particle_y,x
    
    ; Apply physics based on type
    lda particle_type,x
    cmp #PARTICLE_SPARK
    beq apply_spark_physics
    cmp #PARTICLE_SMOKE
    beq apply_smoke_physics
    cmp #PARTICLE_DEBRIS
    beq apply_debris_physics
    jmp next_particle

apply_spark_physics:
    ; Sparks fall with gravity
    lda particle_vy,x
    clc
    adc #GRAVITY
    sta particle_vy,x
    
    ; Fade color over time
    lda particle_life,x
    cmp #10
    bcs no_fade
    lda #2             ; Fade to red
    sta particle_color,x
no_fade:
    jmp next_particle

apply_smoke_physics:
    ; Smoke rises and spreads
    dec particle_vy,x
    
    ; Random drift
    jsr get_random
    and #$01
    beq no_drift
    inc particle_vx,x
no_drift:
    jmp next_particle

apply_debris_physics:
    ; Heavy pieces fall fast
    lda particle_vy,x
    clc
    adc #GRAVITY*2
    sta particle_vy,x
    
    ; Bounce on ground
    lda particle_y,x
    cmp #200
    bcc next_particle
    
    ; Reverse and dampen
    lda particle_vy,x
    eor #$FF
    lsr                ; Dampen
    sta particle_vy,x
    
next_particle:
    inx
    cpx #MAX_PARTICLES
    beq done_updating
    jmp update_particle_loop
done_updating:
    rts

; Draw all particles
draw_particles:
    ldx #0
draw_particle_loop:
    lda particle_active,x
    beq skip_draw
    
    ; Convert to screen coordinates
    lda particle_x_hi,x
    bne skip_draw      ; Off screen
    
    lda particle_x_lo,x
    lsr
    lsr
    lsr                ; Divide by 8 for char position
    sta temp_x
    
    lda particle_y,x
    lsr
    lsr
    lsr
    sta temp_y
    
    ; Calculate screen address
    lda temp_y
    asl
    asl
    asl                ; *8
    sta screen_ptr
    lda #0
    sta screen_ptr+1
    
    asl screen_ptr
    rol screen_ptr+1
    asl screen_ptr
    rol screen_ptr+1
    asl screen_ptr
    rol screen_ptr+1    ; *64 total
    
    lda temp_x
    clc
    adc screen_ptr
    sta screen_ptr
    lda #$04           ; Screen at $0400
    adc screen_ptr+1
    sta screen_ptr+1
    
    ; Draw particle character based on type
    ldy #0
    lda particle_type,x
    asl
    tay
    lda particle_chars,y
    sta (screen_ptr),y
    
    ; Set color
    lda screen_ptr+1
    clc
    adc #$D4           ; Color RAM offset
    sta screen_ptr+1
    
    lda particle_color,x
    sta (screen_ptr),y
    
skip_draw:
    inx
    cpx #MAX_PARTICLES
    bne draw_particle_loop
    rts

particle_chars:
    .byte $2E          ; Spark = period
    .byte $2A          ; Smoke = asterisk
    .byte $51          ; Star = ball
    .byte $A6          ; Debris = block

temp_x:      .byte 0
temp_y:      .byte 0
screen_ptr:  .word 0

; Get random number
get_random:
    lda $D41B
    rts
```

## Movement Polish

Make movement feel responsive and natural:

```asm
; Smooth acceleration and deceleration
; Creates natural-feeling movement

; Player physics
player_x:        .word 128*256  ; 16-bit fixed point
player_y:        .word 100*256
player_vx:       .word 0
player_vy:       .word 0

; Movement constants
ACCELERATION = 32      ; Acceleration rate
MAX_SPEED = 512       ; Maximum velocity
FRICTION = 16         ; Deceleration rate
JUMP_POWER = -768     ; Jump velocity
GRAVITY_ACCEL = 24    ; Gravity strength

; Update player movement
update_player:
    ; Read joystick
    lda $DC00
    and #$1F
    sta joy_state
    
    ; Horizontal movement with acceleration
    lda joy_state
    and #$04           ; Left?
    bne check_right
    
    ; Accelerate left
    lda player_vx
    sec
    sbc #ACCELERATION
    sta player_vx
    lda player_vx+1
    sbc #0
    sta player_vx+1
    
    ; Limit speed
    lda player_vx+1
    cmp #$FE           ; -512
    bcs apply_friction
    lda #$FE
    sta player_vx+1
    lda #$00
    sta player_vx
    jmp apply_friction

check_right:
    lda joy_state
    and #$08           ; Right?
    bne apply_friction
    
    ; Accelerate right
    lda player_vx
    clc
    adc #ACCELERATION
    sta player_vx
    lda player_vx+1
    adc #0
    sta player_vx+1
    
    ; Limit speed
    lda player_vx+1
    cmp #$02           ; 512
    bcc apply_friction
    lda #$02
    sta player_vx+1
    lda #$00
    sta player_vx

apply_friction:
    ; Apply friction when not moving
    lda joy_state
    and #$0C           ; Any horizontal input?
    bne update_position
    
    ; Friction reduces velocity
    lda player_vx+1
    bmi negative_velocity
    
    ; Positive velocity - subtract friction
    lda player_vx
    sec
    sbc #FRICTION
    sta player_vx
    lda player_vx+1
    sbc #0
    sta player_vx+1
    bpl update_position
    
    ; Stopped
    lda #0
    sta player_vx
    sta player_vx+1
    jmp update_position

negative_velocity:
    ; Negative velocity - add friction
    lda player_vx
    clc
    adc #FRICTION
    sta player_vx
    lda player_vx+1
    adc #0
    sta player_vx+1
    bmi update_position
    
    ; Stopped
    lda #0
    sta player_vx
    sta player_vx+1

update_position:
    ; Apply velocity to position
    lda player_x
    clc
    adc player_vx
    sta player_x
    lda player_x+1
    adc player_vx+1
    sta player_x+1
    
    ; Vertical physics
    lda player_vy
    clc
    adc #GRAVITY_ACCEL
    sta player_vy
    lda player_vy+1
    adc #0
    sta player_vy+1
    
    ; Apply vertical velocity
    lda player_y
    clc
    adc player_vy
    sta player_y
    lda player_y+1
    adc player_vy+1
    sta player_y+1
    
    ; Ground collision
    lda player_y+1
    cmp #150           ; Ground level
    bcc not_grounded
    
    ; Hit ground
    lda #150
    sta player_y+1
    lda #0
    sta player_y
    sta player_vy
    sta player_vy+1
    
    ; Check for jump
    lda joy_state
    and #$01           ; Up/Jump?
    bne not_grounded
    
    ; Jump!
    lda #<JUMP_POWER
    sta player_vy
    lda #>JUMP_POWER
    sta player_vy+1
    
    ; Jump squash animation
    jsr squash_sprite

not_grounded:
    rts

joy_state: .byte 0

; Squash and stretch animation
squash_sprite:
    ; Temporarily deform sprite
    lda #$FF
    sta $07F8          ; Wide sprite
    
    ; Wait a few frames
    ldx #3
squash_wait:
    jsr wait_frame
    dex
    bne squash_wait
    
    ; Restore
    lda #$00
    sta $07F8
    rts
```

## Hit Stop and Impact

Make hits feel powerful:

```asm
; Hit stop - freeze frame on impact
; Makes combat feel visceral

hit_stop_timer: .byte 0

; Trigger hit stop
; A = frames to freeze
trigger_hit_stop:
    sta hit_stop_timer
    
    ; Flash effect during stop
    inc $D020
    
    ; Sound effect
    lda #$81
    sta $D404          ; Gate on
    lda #$F0
    sta $D401          ; High frequency
    rts

; Update with hit stop
game_update:
    ; Check hit stop
    lda hit_stop_timer
    beq normal_update
    
    ; Frozen - just decrement
    dec hit_stop_timer
    bne still_frozen
    
    ; End of hit stop
    dec $D020          ; Restore border
    lda #$80
    sta $D404          ; Gate off

still_frozen:
    rts                ; Skip normal update

normal_update:
    ; Regular game logic
    jsr update_player
    jsr update_enemies
    jsr check_collisions
    rts

; Enhanced collision with juice
check_player_enemy_collision:
    ; ... collision detection code ...
    bcc no_collision
    
    ; Collision detected!
    
    ; Hit stop
    lda #4
    jsr trigger_hit_stop
    
    ; Screen shake
    lda #5
    ldx #15
    ldy #2
    jsr trigger_shake
    
    ; Spawn particles
    lda player_x+1
    tax
    lda player_y+1
    tay
    lda #8
    jsr spawn_explosion
    
    ; Knockback
    jsr apply_knockback
    
no_collision:
    rts

; Knockback effect
apply_knockback:
    ; Push player away from enemy
    lda player_x+1
    cmp enemy_x
    bcs push_right
    
    ; Push left
    lda #$FC
    sta player_vx+1
    jmp knockback_done
    
push_right:
    lda #$04
    sta player_vx+1
    
knockback_done:
    lda #$FE          ; Upward
    sta player_vy+1
    rts
```

## Smooth Transitions

Polish screen transitions:

```asm
; Multiple transition effects

; Fade to black
fade_out:
    ldx #15
fade_loop:
    stx $D021
    
    ; Multiple frames per step
    ldy #4
fade_wait:
    jsr wait_frame
    dey
    bne fade_wait
    
    dex
    bpl fade_loop
    rts

; Iris wipe effect
iris_wipe:
    ; Start from center
    lda #20
    sta wipe_x
    lda #12
    sta wipe_y
    lda #0
    sta wipe_radius
    
wipe_loop:
    ; Clear circle area
    jsr clear_circle
    
    ; Increase radius
    inc wipe_radius
    lda wipe_radius
    cmp #25
    bcc wipe_loop
    rts

wipe_x:      .byte 0
wipe_y:      .byte 0
wipe_radius: .byte 0

; Slide transition
slide_transition:
    ; Slide old screen left
    ldx #0
slide_left:
    stx $D016          ; Fine scroll
    
    ldy #2
    jsr wait_frames
    
    inx
    cpx #8
    bne slide_left
    
    ; Swap screens
    jsr swap_screen_buffers
    
    ; Slide new screen in
    ldx #8
slide_in:
    stx $D016
    
    ldy #2
    jsr wait_frames
    
    dex
    bpl slide_in
    
    rts

; Dissolve effect
dissolve_transition:
    ; Random pixel replacement
    ldx #0
dissolve_loop:
    ; Random position
    jsr get_random
    and #$03
    sta temp_page
    
    jsr get_random
    sta temp_offset
    
    ; Copy from new screen to current
    lda temp_page
    clc
    adc #$04
    sta copy_source+2
    adc #$10           ; New screen offset
    sta copy_dest+2
    
    ldy temp_offset
copy_source:
    lda $0400,y
copy_dest:
    sta $1400,y
    
    inx
    cpx #100           ; Pixels per frame
    bne dissolve_loop
    
    ; Continue for multiple frames
    jsr wait_frame
    
    lda dissolve_counter
    clc
    adc #100
    sta dissolve_counter
    bcc dissolve_loop
    
    rts

dissolve_counter: .byte 0
temp_page:        .byte 0
temp_offset:      .byte 0
```

## UI Polish

```asm
; Animated menu cursor
cursor_x:        .byte 5

cursor_target_y: .byte 10
cursor_frame:    .byte 0

; Update animated cursor
update_cursor:

    inc cursor_frame

    tax

    sta screen_ptr
    lda screen_lines+1,x
    sta screen_ptr+1

    sta (screen_ptr),y

    lda cursor_frame
    lsr
    and #$07
    tax
    lda pulse_colors,x
    sta (color_ptr),y

check_button_hover:

    cmp button_x
    bcc no_hover
    cmp button_x_end
    bcs no_hover
    
    lda cursor_y
    cmp button_y
    bne no_hover

    lda button_hover_frame
    and #$08

    sta button_color
    jmp draw_button

    lda #15
    sta button_color
    jmp draw_button

    sta button_color

    ; Draw button with current color
    rts

button_x_end:       .byte 20
button_y:           .byte 15
button_color:       .byte 12
button_hover_frame: .byte 0
```

## Audio Polish

```asm
; Layered sound effects
; Play multiple sounds simultaneously

; Sound channels allocation
CHANNEL_MUSIC = 0      ; Voice 1
CHANNEL_SFX = 1        ; Voice 2
CHANNEL_UI = 2         ; Voice 3

; Play UI feedback sound
play_ui_beep:
    ; Quick beep on voice 3
    lda #$09           ; Fast attack
    sta $D413
    lda #$00           ; No sustain
    sta $D414
    
    lda #$30           ; Mid frequency
    sta $D40E
    lda #$10
    sta $D40F
    
    lda #$11           ; Triangle wave
    sta $D412
    
    ; Auto-off timer
    lda #5
    sta ui_sound_timer
    rts

ui_sound_timer: .byte 0

; Update sound timers
update_sounds:
    ; UI sound auto-off
    lda ui_sound_timer
    beq check_sfx
    dec ui_sound_timer
    bne check_sfx
    
    ; Turn off UI sound
    lda #$10
    sta $D412

    ; Update other sound channels
    rts

; Footstep sounds
play_footstep:
    ; Alternate between two pitches
    lda footstep_alt
    eor #$01
    sta footstep_alt
    beq footstep_low
    
    lda #$08
    jmp play_footstep_pitch
    
footstep_low:
    lda #$06

    sta $D408
    
    ; Very short envelope
    lda #$00
    sta $D40C
    lda #$08
    sta $D40D
    
    ; Noise burst
    lda #$81
    sta $D40B
    
    lda #3
    sta footstep_timer
    rts

footstep_alt:   .byte 0
footstep_timer: .byte 0
```

## Complete Polish Example

Put it all together in a polished game segment:

```asm
; Polished player death sequence
player_death:
    ; Freeze frame
    lda #8
    jsr trigger_hit_stop
    
    ; Big shake
    lda #10
    ldx #40
    ldy #1
    jsr trigger_shake
    
    ; Explosion particles
    lda player_x+1
    tax
    lda player_y+1
    tay
    lda #16
    jsr spawn_explosion
    
    ; Sound effect
    jsr play_explosion_sound
    
    ; Wait for hit stop
death_wait:
    jsr wait_frame
    lda hit_stop_timer
    bne death_wait
    
    ; Fade out
    jsr fade_out
    
    ; Show game over with style
    jsr game_over_sequence
    rts

; Polished collectible pickup
collect_item:
    ; Particle burst
    lda item_x
    tax
    lda item_y
    tay
    lda #4
    jsr spawn_star_particles
    
    ; Score popup
    jsr spawn_score_popup
    
    ; Sound effect
    jsr play_pickup_sound
    
    ; Screen flash
    inc $D020
    lda #2
    sta flash_timer
    
    ; Animate score increase
    jsr animate_score
    
    rts

flash_timer: .byte 0

; Update flash
update_flash:
    lda flash_timer
    beq no_flash
    dec flash_timer
    bne no_flash
    
    ; Restore border
    lda #0
    sta $D020
    
no_flash:
    rts
```

## Historical Context

**"Bubble Bobble" (1987)** - Every bubble had physics, every enemy had personality, every bonus had fanfare. The attention to detail made it timeless.

**"Turrican" (1990)** - Manfred Trenz understood that explosions needed particles, weapons needed feedback, and movement needed weight.

**"International Karate +" (1987)** - Archer Maclean made every hit feel impactful through animation, sound, and perfect timing.

**"Shadow of the Beast" (1989)** - Though on Amiga, its influence reached C64 developers who learned that atmosphere comes from polish.

Before calling your game complete:
- [ ] Does every action have visual feedback?
- [ ] Does every action have audio feedback?
- [ ] Do collisions feel impactful?
- [ ] Are transitions smooth?
- [ ] Does movement feel natural?
- [ ] Do menus feel responsive?
- [ ] Are there particle effects?
- [ ] Is there screen shake for big events?
- [ ] Do controls feel tight?
- [ ] Are there no dead moments?
