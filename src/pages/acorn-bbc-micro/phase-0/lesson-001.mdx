# Your First BBC Micro Program

Welcome! You're about to write your first program for the BBC Micro.

## What You'll Build

A simple program that fills the screen with text. When you run it, you'll see "HELLO BBC!" scrolling endlessly down the screen.

## The Code

Type this exactly as shown:

```basic
10 PRINT "HELLO BBC!"
20 GOTO 10
```

That's it! Just two lines.

## How to Run It

1. Start your BBC Micro emulator (BeebEm recommended)
2. You'll see the BBC Micro welcome screen with `>` prompt
3. Type the program exactly as shown above
4. Press `RETURN` after each line
5. When you're done typing, type `RUN` and press `RETURN`

## Stopping the Program

Press `ESCAPE` key.

## What Just Happened?

- **Line 10:** Prints "HELLO BBC!" to the screen
- **Line 20:** Goes back to line 10 (creates a loop)
- **Result:** Infinite loop that keeps printing

## BBC BASIC Note

The BBC Micro runs BBC BASIC, which is more sophisticated than many other 8-bit BASICs. It has proper procedures, better error handling, and an assembler built-in (which we'll use in Phase 1!).

## You Did It!

You just wrote and ran your first BBC Micro program. The BBC Micro is responding to your commands!
