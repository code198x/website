# Your First BBC Micro Assembly Program

Welcome to BBC Micro assembly! You're about to write your first 6502 assembly program using BBC BASIC's built-in assembler.

## What You'll Build

A program that changes the screen border colour (if available) or flashes the screen. BBC BASIC makes this particularly easy with its integrated assembler!

## The Code

Type this in BBC BASIC:

```basic
10 REM BBC Micro Assembly - Border Flash
20 DIM code% 100
30 FOR pass% = 0 TO 3 STEP 3
40 P% = code%
50 [OPT pass%
60 .loop
70 LDA #19
80 JSR &FFEE
90 LDA #1
100 JSR &FFEE
110 LDA #0
120 JSR &FFEE
130 LDX #255
140 .delay
150 DEX
160 BNE delay
170 JMP loop
180 ]
190 NEXT
200 CALL code%
```

## How to Run It

1. Start your BBC Micro emulator (BeebEm recommended)
2. You'll see the BBC Micro `>` prompt
3. Type the program exactly as shown
4. Press `RETURN` after each line
5. When done, type `RUN` and press `RETURN`

## What Just Happened?

- **`DIM code% 100`:** Reserves 100 bytes of memory for machine code
- **`FOR pass% = 0 TO 3 STEP 3`:** Two-pass assembly (pass 0 and pass 3)
- **`[OPT pass%`:** Starts assembler block
- **`LDA #19`:** Load accumulator with 19 (VDU define colour command)
- **`JSR &FFEE`:** Call OSWRCH (OS write character routine)
- **`LDA #1` / `JSR &FFEE`:** Send logical colour 1
- **`LDA #0` / `JSR &FFEE`:** Send physical colour 0
- **Delay loop:** Slows down the colour changes
- **`]`:** Ends assembler block
- **`CALL code%`:** Executes the assembled machine code

## BBC BASIC's Integrated Assembler

The BBC Micro is unique - it has a full 6502 assembler built into BASIC! This makes it perfect for learning assembly - you can mix BASIC and assembly in the same program.

## Two-Pass Assembly

The assembler runs twice:
- **Pass 0:** Figures out label addresses
- **Pass 3:** Generates the final machine code

This is why we use `FOR pass% = 0 TO 3 STEP 3`.

## OS Routines

The BBC Micro has a sophisticated operating system with useful routines:
- **OSWRCH (&FFEE):** Write character/command to VDU
- **OSRDCH (&FFE0):** Read character from keyboard
- **OSBYTE (&FFF4):** Various OS functions

You just wrote and ran your first BBC Micro assembly program using the integrated assembler. This is one of the best ways to learn assembly!
