## The NES Controller

The NES controller is a **shift register** with 8 buttons: **A, B, Select, Start, Up, Down, Left, Right**.

Unlike the C64's joystick ports where you read all directions at once, the NES controller gives you one button at a time. You have to "ask" for each button in sequence.

The controller connects to register **$4016**. Reading this register requires two steps:

### Step 1: Strobe

### Step 2: Read

Now read $4016 eight times. Each read returns the next button's state in bit 0:

| Read | Button |
|------|--------|
| 1 | A |
| 2 | B |
| 3 | Select |
| 4 | Start |
| 5 | Up |
| 6 | Down |
| 7 | Left |
| 8 | Right |

## Building the Button Byte

We want all 8 buttons packed into a single byte for easy testing. The clever trick: use `lsr` and `rol` to shift each button into position.

<CodeFromFile src="nintendo-entertainment-system/game-01-neon-nexus/unit-03/snippets/02-building-the-button-byte.asm" lang="asm" />

**New instructions:**

**`lsr a`** — "Logical Shift Right." Shifts all bits in A right by one. Bit 0 falls into the **carry flag**. A zero enters bit 7. (We've used `lsr` before on memory, but `lsr a` operates on the accumulator.)

**`rol buttons`** — "Rotate Left." Shifts all bits in `buttons` left by one. The **carry flag** enters bit 0. Bit 7 exits into carry. Combined with `lsr`, this builds up our button byte bit by bit.

After 8 iterations, `buttons` contains:

```
Bit 7  6  5  4  3  2  1  0
    R  L  D  U  St Se B  A
```

Right in bit 7, A in bit 0. This order comes from reading buttons last-to-first with the rotate pattern.

## Boundary Checking

Right now, the ship can fly off any edge of the screen. That's bad — sprites wrap around, and the player gets lost.

Let's add boundary checking:

<CodeFromFile src="nintendo-entertainment-system/game-01-neon-nexus/unit-03/snippets/07-boundary-checking.asm" lang="asm" />

**`cmp`** — "Compare." Subtracts the operand from A without storing the result. Sets flags based on the comparison: carry is set if A >= operand, zero is set if A == operand.

**`bcc`** — "Branch if Carry Clear." Branches if A < operand in the comparison.

**`bcs`** — "Branch if Carry Set." Branches if A >= operand in the comparison.

## The Main Loop

In Unit 2, our main loop was just `jmp forever`. Now it needs to do work:

1. Wait for vblank (so we run at 60fps, not thousands of fps)
2. Read the controller
3. Update the player
4. Repeat

We'll use `frame_counter` as a synchronisation flag. The NMI increments it every vblank. The main loop waits for it to change, then processes one frame of game logic.

- Build + run: `ca65 nexus.asm -o nexus.o && ld65 -C nes.cfg nexus.o -o nexus.nes && fceux nexus.nes`
- Press Up/Down/Left/Right — the ship should move
