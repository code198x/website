## What You're Building

Right now enemies move at a constant speed. The game starts easy and stays easy—not very compelling. Classic arcade games ramp up difficulty as the player progresses, creating tension and challenge.

This unit adds:
- A difficulty level that increases with score
- Enemies that move faster at higher difficulty
- A frame skip system to control speed without floating-point maths

## The Plan

1. Add a `difficulty` variable that tracks current level
2. Increase difficulty every 50 points
3. Modify enemy movement to move faster at higher difficulty
4. Cap difficulty at a maximum level

## The Challenge of Variable Speed

The 6502 doesn't have floating-point numbers or easy multiplication. We can't simply multiply speed by 1.5. Instead, we use a frame-skip approach: at low difficulty, enemies move every frame. At high difficulty, enemies move twice per frame (or skip frames less often).

Another approach: instead of moving 1 pixel per frame, we can move 2 pixels per frame at higher difficulty. This is simpler and works well for our game.

## Build It. Run It.

Assemble and run:

```bash

ld65 -C nes.cfg nexus.o -o nexus.nes
```

Test the difficulty:
1. Start a new game—enemies move slowly
2. Collect items to reach 50 points—enemies should speed up
3. Continue to 100, 150 points—enemies get progressively faster
4. The game should feel more challenging as you play longer

## What You've Built
