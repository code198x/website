## What You're Building

Sound. The game comes alive.

![Sound Effects](/images/nintendo-entertainment-system/game-01-neon-nexus/unit-13/screenshot.png)

Collect an item: ascending beep. Hit an enemy: descending warble.

## The APU

The NES Audio Processing Unit has 5 channels:
- 2 pulse waves (square waves)
- 1 triangle wave
- 1 noise channel
- 1 DMC (sample playback)

We use pulse channel 1 for simple sound effects.

## APU Registers

```asm
APUSTATUS = $4015         ; Enable channels
APU_PULSE1_CTRL = $4000   ; Volume, duty cycle
APU_PULSE1_SWEEP = $4001  ; Frequency sweep
APU_PULSE1_LO = $4002     ; Period low byte
APU_PULSE1_HI = $4003     ; Period high, length
```

## Collection Sound

A short, high-pitched beep:

```asm
play_collect_sound:
    lda #%10011111      ; 50% duty, constant vol, vol 15
    sta APU_PULSE1_CTRL
    lda #0
    sta APU_PULSE1_SWEEP
    lda #$C4            ; Period low (high pitch)
    sta APU_PULSE1_LO
    lda #%00001000      ; Period high, trigger
    sta APU_PULSE1_HI
    rts
```

## Death Sound

A descending tone using the sweep unit:

```asm
play_death_sound:
    lda #%10011111      ; 50% duty, vol 15
    sta APU_PULSE1_CTRL
    lda #%10001111      ; Sweep down, fast
    sta APU_PULSE1_SWEEP
    lda #$00            ; Start low pitch
    sta APU_PULSE1_LO
    lda #%00001011      ; Trigger
    sta APU_PULSE1_HI
    rts
```

The sweep unit automatically decreases the frequency, creating a falling sound.
