## What You're Building

A score. Collect items, earn points.

![Scoring](/images/nintendo-entertainment-system/game-01-neon-nexus/unit-12/screenshot.png)

## Score Variables

A 16-bit score allows values up to 65,535:

```asm
score_lo:  .res 1     ; Low byte
score_hi:  .res 1     ; High byte
```

## Adding Points

When an item is collected, add 100 points:

```asm
; Add 100 to score
lda score_lo
clc
adc #100
sta score_lo
lda score_hi
adc #0           ; Add carry to high byte
sta score_hi
```

The `adc #0` adds the carry flag from the low byte addition. If score_lo overflowed (went past 255), the carry is set and score_hi increments.

## 16-Bit Arithmetic

The 6502 is an 8-bit processor. For numbers larger than 255:
1. Add low bytes, storing the result
2. Add high bytes **with carry** (`adc #0` uses the carry from step 1)

This extends to any number of bytes.
