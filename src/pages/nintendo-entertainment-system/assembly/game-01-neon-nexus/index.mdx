## What You're Building

Navigate the neon grid. Avoid enemies. Collect items. Survive.

Neon Nexus is a fixed-screen action game where you move around a single screen, dodging enemies and grabbing pickups. Simple, but it teaches everything you need to know about NES graphics.

## Why This Game?

The PPU is the heart of NES development. This single-screen game touches all the fundamentals:

- **Pattern tables** for tile graphics
- **Nametables** for the background
- **Sprites** for the player and enemies
- **Palettes** for colour
- **Controller input** for movement

No scrolling complexity. Just pure PPU fundamentals.

## What You'll Learn

By the end of this game, you'll understand:

- **PPU setup** — Configuring the NES graphics chip
- **Pattern tables** — Storing tile graphics in CHR-ROM
- **Nametables** — Building backgrounds from tiles
- **OAM and sprites** — Drawing and animating hardware sprites
- **Palettes** — Managing the NES's limited colour palette
- **Controller input** — Reading button presses
- **APU basics** — Playing sound effects and music

## Prerequisites

This is Game 1. No prerequisites — just enthusiasm and a willingness to learn 6502 assembly.

You'll need an emulator (FCEUX) and the cc65 toolchain (ca65 assembler, ld65 linker). If you haven't set these up yet, see [Getting Started](/nintendo-entertainment-system/getting-started).

## Time Investment

Each unit takes 60-90 minutes. The full game is 16 units, so roughly 16-24 hours total.

Every unit produces something that works. By the end of Unit 1, you'll have a NES ROM showing the game's neon grid on screen.
