## What You're Building

Collecting items is fun, but without danger, it's just a chore. Let's make the enemies deadly.

By the end of this unit, you'll have:

- Collision detection against all 4 enemies
- A game state machine (playing vs game over)
- Press Start to restart after dying
- A proper game loop with state-dependent behaviour

## The Plan

Here's what we need to add:

1. **Game state variable** — Track whether we're playing or dead
2. **Enemy collision loop** — Check player against all enemies
3. **State-dependent logic** — Only update gameplay when playing
4. **Game reset** — Restart everything when player presses Start
5. **Game over handling** — Stop the action when caught

## What You've Built

Look at what you made:

- **State machine** controlling game flow
- **Enemy collision** checking all 4 enemies in a loop
- **Game over state** that freezes gameplay
- **Restart functionality** with Start button
- **Clean reset** restoring initial conditions

The game has stakes now. Getting caught means starting over.

## What You've Learnt

- **State machines** manage game flow (playing, paused, game over)
- **Looping collision** scales to any number of enemies
- **Early exit** (`rts` on hit) avoids unnecessary checks
- **Game reset** restores initial state without rebooting
- **Conditional main loop** runs different code based on state
