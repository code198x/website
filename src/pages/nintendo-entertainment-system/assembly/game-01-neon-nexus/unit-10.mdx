## What You're Building

Games without sound feel lifeless. A simple "bleep" when collecting an item or a harsh buzz on death transforms the experience. The NES has a dedicated Audio Processing Unit (APU) with five sound channels—more than enough for retro sound effects.

This unit adds:

- A sound effect trigger system
- Collect sound (rising tone)

- Sound effect timers that update each frame

## The NES APU

The APU has five channels:

| Channel | Registers | Sound Type |
|---------|-----------|------------|
| Pulse 1 | $4000-$4003 | Square wave with duty cycle |
| Pulse 2 | $4004-$4007 | Square wave with duty cycle |
| Triangle | $4008-$400B | Triangle wave (bass/melody) |
| Noise | $400C-$400F | Noise (percussion/effects) |
| DMC | $4010-$4013 | Sample playback |

For sound effects, we'll use Pulse 1. Each pulse channel has four registers:

- **$4000 (Pulse 1 Control)**: Duty cycle, volume, envelope
- **$4001 (Pulse 1 Sweep)**: Frequency sweep (pitch bend)
- **$4002 (Pulse 1 Timer Low)**: Lower 8 bits of frequency
- **$4003 (Pulse 1 Timer High + Length)**: Upper 3 bits of frequency + length counter

The APU also has a status register at **$4015** that enables/disables channels.

## Understanding Pulse Control

The control register ($4000/$4004) packs several settings into one byte:

```
Bit 7-6: Duty cycle (wave shape)
         00 = 12.5% (thin, sharp)
         01 = 25%   (classic square)
         10 = 50%   (hollow)
         11 = 75%   (like 25%, inverted)

Bit 5:   Length counter halt (1 = ignore length counter)
Bit 4:   Constant volume (1 = use volume bits directly)
Bit 3-0: Volume or envelope period (0-15)
```

For simple sound effects, we use `%10111111` which means:
- 50% duty cycle
- Length counter halted
- Constant volume
- Volume = 15 (maximum)

## Frequency and Pitch

The timer value determines pitch. Lower timer = higher pitch. The formula is:

```
Frequency = CPU_clock / (16 × (timer + 1))
```

For NTSC NES (1.789773 MHz CPU), some useful timer values:
- Timer = 253: ~440 Hz (A4)
- Timer = 190: ~587 Hz (D5)
- Timer = 126: ~880 Hz (A5)
