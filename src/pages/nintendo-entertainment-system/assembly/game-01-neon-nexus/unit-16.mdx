## Technical Skills Acquired

**PPU (Picture Processing Unit):**
- Pattern tables for tile graphics
- Nametables for background layout
- Attribute tables for colour regions
- OAM for sprite management
- VBlank timing for safe updates

**CPU (6502):**
- Memory-mapped I/O
- Zero page for fast access
- Indexed addressing modes
- Branching and comparisons
- Subroutine structure

**APU (Audio Processing Unit):**
- Pulse channel basics
- Frequency control
- Sweep unit for effects

**Game Logic:**
- State machine architecture
- Collision detection
- Input handling with edge detection
- Score and lives tracking
