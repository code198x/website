## What You're Building

Our game over transition is abrupt—the screen instantly changes and the player can immediately restart. Classic arcade games used subtle effects to make these transitions feel more impactful: a brief screen flash, a pause before accepting input, and sometimes a fade effect.

This unit adds:
- Screen flash effect on death (using PPU emphasis bits)
- A delay timer before the game over screen accepts input
- Cleaner state transition handling
- Visual polish that makes game over feel significant

## The Plan

2. Implement screen flash using PPU emphasis bits

## PPU Emphasis Bits

The NES PPU has three emphasis bits in PPUMASK ($2001) that tint the screen:

```
PPUMASK ($2001):
Bit 7: Emphasize blue
Bit 6: Emphasize green
Bit 5: Emphasize red
```

## Why Use Emphasis Bits?

The emphasis bits are a simple but effective tool:
- No palette changes required
- Works instantly (takes effect next frame)
- Affects the entire screen uniformly
- Can create flash, fade, or tint effects

The flash gives players visual feedback that something significant happened—their game just ended.

## Input Delay Benefits

The input delay serves multiple purposes:
1. **Prevents accidental restart**: Players might be mashing buttons when they die
2. **Lets the moment sink in**: The player sees their score and high score
3. **Feels more polished**: Instant restart feels cheap; a pause feels deliberate

One second (60 frames at NTSC) is a good balance—long enough to notice, short enough not to frustrate.

## Death Freeze Frame

For extra polish, we can freeze the sprites in place during the flash. The sprites are already updated in the OAM buffer, so they'll stay visible during the flash frames before we hide them for the game over screen.

This creates a "freeze frame" moment—the player sees exactly where they died before the screen transitions.

## State Flow Summary

The refined game over flow:
1. Player loses last life
2. Death sound plays
3. Screen flashes white (8 frames)
4. Flash clears, game over text draws
5. Input ignored for 60 frames
6. Player can now press START to restart
