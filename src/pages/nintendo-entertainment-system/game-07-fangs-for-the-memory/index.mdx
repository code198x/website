## What You'll Build

Snake game with a pun. Eat food, grow longer, don't hit yourself.

Guide your snake. Eat the food. Grow longer. Don't collide with your own tail. Simple to explain, but the implementation teaches efficient data structures — particularly ring buffers for managing a growing, moving entity.

## Skills You'll Master

- **Grid-based movement** — discrete positions
- **Ring buffer management** — efficient snake storage
- **Self-collision detection** — body checking
- **Food spawning** — random placement
- **Length difficulty** — harder as you grow
- **Tight game loop** — performance focus
- **Multiple game modes** — variety

## Prerequisites

Complete **Game 6: Crypt Crawler** first.
