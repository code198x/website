## What You're Building

Every proper game starts with a title screen. It's the first thing players see—a moment to present your game before the action begins. We already have `STATE_PLAYING` and `STATE_GAMEOVER`. Now we add `STATE_TITLE` to create a complete three-state game flow.

This unit adds:
- A title screen showing the game name
- "PRESS START" prompt
- A game over message when lives run out
- Clean transitions between all three states

## The Plan

1. Add `STATE_TITLE` constant and start there on boot
2. Add letter tiles to CHR-ROM for text display
3. Create routines to draw title screen and game over text
4. Restructure the main loop to dispatch based on state
5. Handle button presses to transition between states

## The Three-State Machine

Our game now has three distinct states:

```
        [TITLE]
           |
       Press Start
           ↓
        [PLAYING] ←──────┐
           |              |
       Lose all lives     |
           ↓              |
       [GAMEOVER]         |
           |              |
       Press Start ───────┘
```

Update the constants to include the new state:

```asm
; Game state constants
STATE_TITLE    = 0
STATE_PLAYING  = 1
STATE_GAMEOVER = 2
```

On reset, we now start at `STATE_TITLE` instead of jumping straight into gameplay.

## Letter Tiles for Text

To display "NEON NEXUS", "PRESS START", and "GAME OVER", we need letter tiles in CHR-ROM. Each letter is an 8x8 pixel tile, just like digits.

We'll add tiles 14-39 for letters A-Z. The tile index for any letter is: `letter_ascii - 'A' + 14`. For our specific text, we only need: A, E, G, M, N, O, P, R, S, T, U, V, X.

Since we're writing directly to the nametable, we need to calculate PPU addresses. The NES nametable starts at $2000, with 32 tiles per row. To write text at row R, column C:

```
PPU address = $2000 + (R × 32) + C
```

For row 10, column 11 (roughly centred):
- $2000 + (10 × 32) + 11 = $2000 + 320 + 11 = $214B

## Drawing the Title Screen

The title screen draws text to the nametable during vblank. We only need to draw it once when entering the title state, not every frame.

```asm
draw_title_screen:
    ; Clear sprites (hide player, enemies, item)
    ldx #0
    lda #$FF
@clear_sprites:
    sta oam, x
    inx
    bne @clear_sprites

    ; Set PPU address for "NEON NEXUS" (row 10, column 11)
    lda PPUSTATUS           ; reset latch
    lda #$21
    sta PPUADDR
    lda #$4B                ; $214B
    sta PPUADDR

    ; Write "NEON NEXUS" - tile indices
    ldx #0
@title_loop:
    lda title_text, x
    beq @press_start        ; null terminator
    sta PPUDATA
    inx
    bne @title_loop

@press_start:
    ; Set PPU address for "PRESS START" (row 14, column 10)
    lda #$21
    sta PPUADDR
    lda #$CA                ; $21CA
    sta PPUADDR

    ldx #0
@press_loop:
    lda press_text, x
    beq @done
    sta PPUDATA
    inx
    bne @press_loop

@done:
    ; Reset scroll
    lda #0
    sta PPUSCROLL
    sta PPUSCROLL

    rts

; Text data (tile indices, null-terminated)
title_text:
    .byte 27, 18, 28, 27    ; NEON
    .byte 0                 ; space
    .byte 27, 18, 33, 32, 30; NEXUS
    .byte 0                 ; terminator

press_text:
    .byte 29, 31, 18, 30, 30; PRESS
    .byte 0                 ; space
    .byte 30, 31, 14, 31, 31; START (note: reuses letters)
    .byte 0                 ; terminator
```

Wait—that's getting complicated with manual tile indices. Let's simplify by defining our letter tiles starting at index 14 and using a helper table:

```asm
; Tile indices for letters we use:
; 14=A, 15=E, 16=G, 17=M, 18=N, 19=O, 20=P, 21=R, 22=S, 23=T, 24=U, 25=V, 26=X
```

Actually, for clarity in the code listing, we'll use direct byte values that match our CHR-ROM tile layout.

## Drawing Game Over Text

Similar to the title screen, game over draws text to the nametable:

```asm
draw_game_over:
    ; Set PPU address for "GAME OVER" (row 12, column 11)
    lda PPUSTATUS
    lda #$21
    sta PPUADDR
    lda #$8B                ; $218B
    sta PPUADDR

    ldx #0
@loop:
    lda gameover_text, x
    beq @done
    sta PPUDATA
    inx
    bne @loop

@done:
    lda #0
    sta PPUSCROLL
    sta PPUSCROLL
    rts

gameover_text:
    .byte 16, 14, 17, 15    ; GAME
    .byte 0                 ; space
    .byte 19, 25, 15, 21    ; OVER
    .byte 0                 ; terminator
```

## Clearing the Screen

When transitioning between states, we need to clear text from the previous state. A simple approach: clear a portion of the nametable when entering a new state.

```asm
clear_playfield:
    ; Clear rows 8-16 of nametable (where text appears)
    lda PPUSTATUS
    lda #$21
    sta PPUADDR
    lda #$00                ; start of row 8
    sta PPUADDR

    lda #0                  ; blank tile
    ldx #0
@loop:
    sta PPUDATA
    sta PPUDATA
    sta PPUDATA
    sta PPUDATA             ; 4 at a time for speed
    inx
    cpx #64                 ; 256 tiles = 8 rows
    bne @loop

    lda #0
    sta PPUSCROLL
    sta PPUSCROLL

    rts
```

## Restructured Main Loop

The main loop now dispatches based on `game_state`:

```asm
game_loop:
    ; Wait for vblank
    lda nmi_ready
    beq game_loop
    lda #0
    sta nmi_ready

    ; Dispatch based on state
    lda game_state

    cmp #STATE_TITLE
    beq @title_state

    cmp #STATE_PLAYING
    beq @playing_state

    ; Must be STATE_GAMEOVER
    jmp @gameover_state

@title_state:
    jsr read_controller
    lda buttons
    and #BTN_START
    beq game_loop           ; wait for Start

    ; Start pressed - begin game
    jsr clear_playfield
    jsr reset_game
    lda #STATE_PLAYING
    sta game_state
    jmp game_loop

@playing_state:
    ; ... existing game logic ...
    jsr read_controller
    jsr update_player
    ; etc.
    jmp game_loop

@gameover_state:
    jsr read_controller
    lda buttons
    and #BTN_START
    beq game_loop           ; wait for Start

    ; Restart game
    jsr clear_playfield
    jsr reset_game
    lda #STATE_PLAYING
    sta game_state
    jmp game_loop
```

## Tracking Screen State

One issue: we only want to draw the title or game over text once, not every frame. We can use a flag to track whether we've drawn the current state's screen:

```asm
.segment "ZEROPAGE"
screen_drawn:   .res 1      ; has current state's screen been drawn?
```

When changing states, set `screen_drawn = 0`. In each state handler, check this flag:

```asm
@title_state:
    ; Draw title screen if not already drawn
    lda screen_drawn
    bne @title_input
    jsr draw_title_screen
    lda #1
    sta screen_drawn

@title_input:
    jsr read_controller
    ; ... rest of title handling
```

## Initialisation Changes

On reset, we now start at the title screen:

```asm
reset:
    ; ... existing setup ...

    ; Start at title screen
    lda #STATE_TITLE
    sta game_state
    lda #0
    sta screen_drawn

    ; Draw title immediately
    jsr draw_title_screen
    lda #1
    sta screen_drawn
```

## Transitioning to Game Over

When `lose_life` detects zero lives remaining, it sets the game over state and clears the screen_drawn flag:

```asm
@game_over:
    lda #STATE_GAMEOVER
    sta game_state
    lda #0
    sta screen_drawn        ; trigger game over screen draw
    rts
```

## The Complete Code

Here's the complete `nexus.asm` with title screen and game state machine:

```asm
;
; Neon Nexus - Unit 9: Title Screen
; Complete game with title, gameplay, and game over states
;

; ============================================================================
; iNES Header
; ============================================================================

.segment "HEADER"
    .byte "NES", $1A    ; iNES identifier
    .byte 2             ; 2x 16KB PRG-ROM
    .byte 1             ; 1x 8KB CHR-ROM
    .byte $01           ; Mapper 0, vertical mirroring
    .byte $00           ; Mapper 0

; ============================================================================
; Hardware Constants
; ============================================================================

PPUCTRL   = $2000
PPUMASK   = $2001
PPUSTATUS = $2002
PPUADDR   = $2006
PPUDATA   = $2007
PPUSCROLL = $2005
OAMDMA    = $4014
JOYPAD1   = $4016

; Controller button masks
BTN_RIGHT  = %00000001
BTN_LEFT   = %00000010
BTN_DOWN   = %00000100
BTN_UP     = %00001000
BTN_START  = %00010000
BTN_SELECT = %00100000
BTN_B      = %01000000
BTN_A      = %10000000

; Game constants
PLAYER_SPEED  = 2
ENEMY_SPEED   = 1
NUM_ENEMIES   = 4
SPAWN_X       = 120
SPAWN_Y       = 120
INVULN_TIME   = 60

; Collision box sizes
HITBOX_SIZE = 6

; Game state constants
STATE_TITLE    = 0
STATE_PLAYING  = 1
STATE_GAMEOVER = 2

; Tile indices for letters (matching CHR-ROM layout)
TILE_A = 14
TILE_E = 15
TILE_G = 16
TILE_M = 17
TILE_N = 18
TILE_O = 19
TILE_P = 20
TILE_R = 21
TILE_S = 22
TILE_T = 23
TILE_U = 24
TILE_V = 25
TILE_X = 26

; ============================================================================
; Zero Page Variables
; ============================================================================

.segment "ZEROPAGE"
nmi_ready:      .res 1      ; flag set by NMI
buttons:        .res 1      ; controller state
player_x:       .res 1      ; player X position
player_y:       .res 1      ; player Y position
enemy_x:        .res 4      ; enemy X positions
enemy_y:        .res 4      ; enemy Y positions
item_x:         .res 1      ; item X position
item_y:         .res 1      ; item Y position
score:          .res 2      ; 16-bit score (low, high)
game_state:     .res 1      ; current game state
lives:          .res 1      ; remaining lives
invuln_timer:   .res 1      ; invulnerability countdown
screen_drawn:   .res 1      ; has current screen been drawn?
temp:           .res 1      ; temporary for division

; ============================================================================
; OAM Buffer
; ============================================================================

.segment "OAM"
oam: .res 256               ; shadow OAM at $0200

; ============================================================================
; Main Code
; ============================================================================

.segment "CODE"

; ----------------------------------------------------------------------------
; reset - Entry point, called on power-on and reset
; ----------------------------------------------------------------------------
reset:
    sei                     ; disable interrupts
    cld                     ; clear decimal mode

    ldx #$40
    stx $4017               ; disable APU frame IRQ
    ldx #$FF
    txs                     ; setup stack
    inx                     ; X = 0
    stx PPUCTRL             ; disable NMI
    stx PPUMASK             ; disable rendering
    stx $4010               ; disable DMC IRQs

    ; Wait for PPU to stabilise (first vblank)
@vblank1:
    bit PPUSTATUS
    bpl @vblank1

    ; Clear RAM
    lda #0
@clear_ram:
    sta $0000, x
    sta $0100, x
    sta $0200, x
    sta $0300, x
    sta $0400, x
    sta $0500, x
    sta $0600, x
    sta $0700, x
    inx
    bne @clear_ram

    ; Wait for PPU (second vblank)
@vblank2:
    bit PPUSTATUS
    bpl @vblank2

    ; Hide all sprites initially
    ldx #0
    lda #$FF
@hide_sprites:
    sta oam, x
    inx
    bne @hide_sprites

    ; Load palette
    jsr load_palette

    ; Start at title screen
    lda #STATE_TITLE
    sta game_state
    lda #0
    sta screen_drawn

    ; Enable rendering
    lda #%10010000          ; enable NMI, sprites from table 0
    sta PPUCTRL
    lda #%00011110          ; enable sprites and background
    sta PPUMASK

    ; Fall through to game loop

; ----------------------------------------------------------------------------
; game_loop - Main loop, dispatches based on game state
; ----------------------------------------------------------------------------
game_loop:
    lda nmi_ready
    beq game_loop           ; wait for vblank
    lda #0
    sta nmi_ready

    ; Dispatch based on state
    lda game_state

    cmp #STATE_TITLE
    beq title_state

    cmp #STATE_PLAYING
    beq playing_state

    jmp gameover_state

; --- Title State ---
title_state:
    ; Draw title screen if not already drawn
    lda screen_drawn
    bne @check_input
    jsr draw_title_screen
    lda #1
    sta screen_drawn

@check_input:
    jsr read_controller
    lda buttons
    and #BTN_START
    beq game_loop           ; wait for Start

    ; Start pressed - begin game
    jsr clear_playfield
    jsr init_game
    lda #STATE_PLAYING
    sta game_state
    lda #0
    sta screen_drawn
    jmp game_loop

; --- Playing State ---
playing_state:
    ; Decrement invulnerability timer
    lda invuln_timer
    beq @no_invuln
    dec invuln_timer
@no_invuln:

    jsr read_controller
    jsr update_player
    jsr move_enemies
    jsr check_item_collision
    jsr check_enemy_collision
    jsr update_player_sprite
    jsr update_enemy_sprites
    jsr update_item_sprite

    jmp game_loop

; --- Game Over State ---
gameover_state:
    ; Draw game over screen if not already drawn
    lda screen_drawn
    bne @check_restart
    jsr draw_game_over
    lda #1
    sta screen_drawn

@check_restart:
    jsr read_controller
    lda buttons
    and #BTN_START
    beq game_loop           ; wait for Start

    ; Restart game
    jsr clear_playfield
    jsr init_game
    lda #STATE_PLAYING
    sta game_state
    lda #0
    sta screen_drawn
    jmp game_loop

; ----------------------------------------------------------------------------
; nmi - Called every vblank (60 times per second)
; ----------------------------------------------------------------------------
nmi:
    pha
    txa
    pha
    tya
    pha

    ; DMA copy shadow OAM to PPU
    lda #$00
    sta $2003               ; OAM address = 0
    lda #$02                ; page $0200
    sta OAMDMA              ; start DMA

    ; Only draw HUD during gameplay
    lda game_state
    cmp #STATE_PLAYING
    bne @skip_hud
    jsr draw_hud
@skip_hud:

    lda #1
    sta nmi_ready

    pla
    tay
    pla
    tax
    pla
    rti

; ----------------------------------------------------------------------------
; irq - Not used
; ----------------------------------------------------------------------------
irq:
    rti

; ----------------------------------------------------------------------------
; init_game - Initialise all game variables for new game
; ----------------------------------------------------------------------------
init_game:
    lda #SPAWN_X
    sta player_x
    lda #SPAWN_Y
    sta player_y

    lda #3
    sta lives

    lda #0
    sta score
    sta score+1
    sta invuln_timer

    jsr init_enemies
    jsr respawn_item

    rts

; ----------------------------------------------------------------------------
; init_enemies - Set initial enemy positions
; ----------------------------------------------------------------------------
init_enemies:
    lda #30
    sta enemy_x
    lda #50
    sta enemy_y

    lda #200
    sta enemy_x+1
    lda #50
    sta enemy_y+1

    lda #30
    sta enemy_x+2
    lda #180
    sta enemy_y+2

    lda #200
    sta enemy_x+3
    lda #180
    sta enemy_y+3

    rts

; ----------------------------------------------------------------------------
; respawn_item - Place item at new position
; ----------------------------------------------------------------------------
respawn_item:
    lda item_x
    clc
    adc #67
    and #%01111111
    clc
    adc #60
    sta item_x

    lda item_y
    clc
    adc #53
    and #%01111111
    clc
    adc #40
    sta item_y

    rts

; ----------------------------------------------------------------------------
; draw_title_screen - Draw "NEON NEXUS" and "PRESS START"
; ----------------------------------------------------------------------------
draw_title_screen:
    ; Hide all sprites on title
    ldx #0
    lda #$FF
@hide:
    sta oam, x
    inx
    bne @hide

    ; "NEON NEXUS" at row 10, column 11 = $2000 + 320 + 11 = $214B
    lda PPUSTATUS
    lda #$21
    sta PPUADDR
    lda #$4B
    sta PPUADDR

    ldx #0
@title_loop:
    lda title_text, x
    beq @draw_press
    sta PPUDATA
    inx
    bne @title_loop

@draw_press:
    ; "PRESS START" at row 14, column 10 = $2000 + 448 + 10 = $21CA
    lda #$21
    sta PPUADDR
    lda #$CA
    sta PPUADDR

    ldx #0
@press_loop:
    lda press_text, x
    beq @done
    sta PPUDATA
    inx
    bne @press_loop

@done:
    lda #0
    sta PPUSCROLL
    sta PPUSCROLL
    rts

; Title text: "NEON NEXUS" (with space)
title_text:
    .byte TILE_N, TILE_E, TILE_O, TILE_N  ; NEON
    .byte 0                                ; space
    .byte TILE_N, TILE_E, TILE_X, TILE_U, TILE_S  ; NEXUS
    .byte 0                                ; terminator

; Press text: "PRESS START"
press_text:
    .byte TILE_P, TILE_R, TILE_E, TILE_S, TILE_S  ; PRESS
    .byte 0                                        ; space
    .byte TILE_S, TILE_T, TILE_A, TILE_R, TILE_T  ; START
    .byte 0                                        ; terminator

; ----------------------------------------------------------------------------
; draw_game_over - Draw "GAME OVER" message
; ----------------------------------------------------------------------------
draw_game_over:
    ; Hide sprites
    ldx #0
    lda #$FF
@hide:
    sta oam, x
    inx
    bne @hide

    ; "GAME OVER" at row 12, column 11 = $2000 + 384 + 11 = $218B
    lda PPUSTATUS
    lda #$21
    sta PPUADDR
    lda #$8B
    sta PPUADDR

    ldx #0
@loop:
    lda gameover_text, x
    beq @done
    sta PPUDATA
    inx
    bne @loop

@done:
    lda #0
    sta PPUSCROLL
    sta PPUSCROLL
    rts

; Game over text: "GAME OVER"
gameover_text:
    .byte TILE_G, TILE_A, TILE_M, TILE_E  ; GAME
    .byte 0                                ; space
    .byte TILE_O, TILE_V, TILE_E, TILE_R  ; OVER
    .byte 0                                ; terminator

; ----------------------------------------------------------------------------
; clear_playfield - Clear text area of nametable
; ----------------------------------------------------------------------------
clear_playfield:
    lda PPUSTATUS

    ; Clear rows 8-16 ($2100-$2200)
    lda #$21
    sta PPUADDR
    lda #$00
    sta PPUADDR

    lda #0                  ; blank tile
    ldx #0
@loop:
    sta PPUDATA
    sta PPUDATA
    sta PPUDATA
    sta PPUDATA
    inx
    cpx #64                 ; 256 tiles
    bne @loop

    lda #0
    sta PPUSCROLL
    sta PPUSCROLL
    rts

; ----------------------------------------------------------------------------
; read_controller - Read joypad state into buttons variable
; ----------------------------------------------------------------------------
read_controller:
    lda #1
    sta JOYPAD1
    lda #0
    sta JOYPAD1

    ldx #8
@loop:
    lda JOYPAD1
    lsr a
    rol buttons
    dex
    bne @loop

    rts

; ----------------------------------------------------------------------------
; update_player - Move player based on controller input
; ----------------------------------------------------------------------------
update_player:
    lda buttons
    and #BTN_RIGHT
    beq @check_left
    lda player_x
    clc
    adc #PLAYER_SPEED
    cmp #248
    bcs @check_left
    sta player_x

@check_left:
    lda buttons
    and #BTN_LEFT
    beq @check_down
    lda player_x
    sec
    sbc #PLAYER_SPEED
    bcc @check_down
    sta player_x

@check_down:
    lda buttons
    and #BTN_DOWN
    beq @check_up
    lda player_y
    clc
    adc #PLAYER_SPEED
    cmp #224
    bcs @check_up
    sta player_y

@check_up:
    lda buttons
    and #BTN_UP
    beq @done
    lda player_y
    sec
    sbc #PLAYER_SPEED
    cmp #16
    bcc @done
    sta player_y

@done:
    rts

; ----------------------------------------------------------------------------
; move_enemies - Update enemy positions
; ----------------------------------------------------------------------------
move_enemies:
    ldx #0

@loop:
    lda enemy_x, x
    sec
    sbc #ENEMY_SPEED
    sta enemy_x, x

    cmp #250
    bcc @next

    lda #248
    sta enemy_x, x

@next:
    inx
    cpx #NUM_ENEMIES
    bne @loop

    rts

; ----------------------------------------------------------------------------
; check_item_collision - Test player/item overlap
; ----------------------------------------------------------------------------
check_item_collision:
    lda player_x
    sec
    sbc item_x
    bcs @check_x_pos
    eor #$FF
    clc
    adc #1
@check_x_pos:
    cmp #HITBOX_SIZE
    bcs @no_collision

    lda player_y
    sec
    sbc item_y
    bcs @check_y_pos
    eor #$FF
    clc
    adc #1
@check_y_pos:
    cmp #HITBOX_SIZE
    bcs @no_collision

    jsr collect_item

@no_collision:
    rts

; ----------------------------------------------------------------------------
; collect_item - Handle item pickup
; ----------------------------------------------------------------------------
collect_item:
    lda score
    clc
    adc #10
    sta score
    lda score+1
    adc #0
    sta score+1

    jsr respawn_item
    rts

; ----------------------------------------------------------------------------
; check_enemy_collision - Test player/enemy overlap
; ----------------------------------------------------------------------------
check_enemy_collision:
    lda invuln_timer
    bne @done

    ldx #0

@loop:
    lda player_x
    sec
    sbc enemy_x, x
    bcs @check_x
    eor #$FF
    clc
    adc #1
@check_x:
    cmp #HITBOX_SIZE
    bcs @next

    lda player_y
    sec
    sbc enemy_y, x
    bcs @check_y
    eor #$FF
    clc
    adc #1
@check_y:
    cmp #HITBOX_SIZE
    bcs @next

    jsr lose_life
    rts

@next:
    inx
    cpx #NUM_ENEMIES
    bne @loop

@done:
    rts

; ----------------------------------------------------------------------------
; lose_life - Handle player death
; ----------------------------------------------------------------------------
lose_life:
    dec lives

    lda lives
    beq @game_over

    jsr respawn_player
    rts

@game_over:
    lda #STATE_GAMEOVER
    sta game_state
    lda #0
    sta screen_drawn
    rts

; ----------------------------------------------------------------------------
; respawn_player - Reset player position with invulnerability
; ----------------------------------------------------------------------------
respawn_player:
    lda #SPAWN_X
    sta player_x
    lda #SPAWN_Y
    sta player_y

    lda #INVULN_TIME
    sta invuln_timer
    rts

; ----------------------------------------------------------------------------
; update_player_sprite - Write player to shadow OAM with flicker
; ----------------------------------------------------------------------------
update_player_sprite:
    lda invuln_timer
    beq @visible

    and #%00000100
    beq @hidden

@visible:
    lda player_y
    sta oam
    lda #1
    sta oam+1
    lda #0
    sta oam+2

    adc #4
    sta PPUDATA

    lda #0
    sta PPUSCROLL
    sta PPUSCROLL

; ----------------------------------------------------------------------------

    ldx #0
@loop:
    cmp #10
    bcc @done
    sec
    sbc #10
    inx
    bne @loop
@done:
    sta temp
    txa
    rts
```
