## What You're Building

Every arcade game has a high score—a target to beat, a reason to play "just one more game". Without a high score, there's no persistence between sessions, no goal beyond mere survival.

This unit adds:
- A high score variable that persists between games
- Comparison logic to check if current score beats the record
- High score display on the game over screen
- "NEW HIGH" notification when the record is broken

## The Plan

1. Add a `high_score` variable (16-bit like `score`)
2. Compare score to high score at game over
3. Update high score if beaten
4. Display high score on game over screen
5. Add "NEW HIGH" text when record is broken

## High Score Storage

Add the high score variable to zero page:

```asm
.segment "ZEROPAGE"
high_score:     .res 2      ; best score (low, high bytes)
new_high:       .res 1      ; flag: did we beat the record?
```

Note: This high score only persists while the console is powered on. True persistence would require battery-backed RAM (SRAM), which is beyond this unit's scope.

## Initialising High Score

On first boot, set high score to 0:

```asm
reset:
    ; ... existing setup ...

    lda #0
    sta high_score
    sta high_score+1
```

Important: We do NOT reset high score in `init_game`. The high score persists across game sessions—only a power cycle resets it.

## Comparing Scores

At game over, we compare the current score to the high score. Since scores are 16-bit, we compare high bytes first, then low bytes if tied:

```asm
check_high_score:
    ; Clear the new high flag
    lda #0
    sta new_high

    ; Compare high bytes first
    lda score+1
    cmp high_score+1
    bcc @not_new            ; score < high_score
    bne @new_record         ; score > high_score

    ; High bytes equal - compare low bytes
    lda score
    cmp high_score
    bcc @not_new            ; score < high_score
    beq @not_new            ; score == high_score (not new)

@new_record:
    ; New high score!
    lda score
    sta high_score
    lda score+1
    sta high_score+1

    lda #1
    sta new_high            ; set flag for display

@not_new:
    rts
```

The comparison logic:
1. If `score+1 > high_score+1`: new record
2. If `score+1 < high_score+1`: not new
3. If equal: compare low bytes
4. If `score > high_score`: new record

## Calling the Check

Call `check_high_score` when entering game over state:

```asm
@game_over:
    jsr check_high_score    ; compare before changing state

    lda #STATE_GAMEOVER
    sta game_state
    lda #0
    sta screen_drawn
    rts
```

## Displaying High Score

Modify `draw_game_over` to show the high score:

```asm
draw_game_over:
    ; Hide sprites
    ldx #0
    lda #$FF
@hide:
    sta oam, x
    inx
    bne @hide

    ; "GAME OVER" at row 10
    lda PPUSTATUS
    lda #$21
    sta PPUADDR
    lda #$4B                ; row 10, col 11
    sta PPUADDR

    ldx #0
@go_loop:
    lda gameover_text, x
    beq @draw_hi
    sta PPUDATA
    inx
    bne @go_loop

@draw_hi:
    ; "HI" at row 13, col 11
    lda #$21
    sta PPUADDR
    lda #$AB                ; row 13, col 11
    sta PPUADDR

    lda #TILE_H
    sta PPUDATA
    lda #TILE_I
    sta PPUDATA
    lda #0                  ; space
    sta PPUDATA

    ; High score digits
    lda high_score+1
    jsr div10
    clc
    adc #4
    sta PPUDATA

    lda temp
    jsr div10
    clc
    adc #4
    sta PPUDATA

    lda temp
    clc
    adc #4
    sta PPUDATA

    ; Check if new high score
    lda new_high
    beq @done

    ; "NEW" at row 15
    lda #$21
    sta PPUADDR
    lda #$EB                ; row 15, col 11
    sta PPUADDR

    lda #TILE_N
    sta PPUDATA
    lda #TILE_E
    sta PPUDATA
    lda #TILE_W
    sta PPUDATA

@done:
    lda #0
    sta PPUSCROLL
    sta PPUSCROLL
    rts
```

## Build It. Run It.

Assemble and run:

```bash
ca65 nexus.asm -o nexus.o
ld65 -C nes.cfg nexus.o -o nexus.nes
```

Test the high score:
1. Play a game and get some points
2. Game over—you should see "HI" followed by your score
3. If this is your first game, you should also see "NEW"
4. Play again and score lower—high score remains, no "NEW"
5. Score higher—high score updates, "NEW" appears

    sta $0600, x

@no_invuln:

    lda #STATE_PLAYING

    txa
    pha
    tya
    pha

    tay
    pla
    tax
    pla

    sta APU_STATUS

    lda #%00110000
    sta APU_PULSE1_CTRL
    lda #0
    sta APU_PULSE1_SWEEP

    lda #0
    sta sfx_timer
    sta sfx_type
    sta sfx_pitch

    rts

; Sound routines

play_collect_sound:
    lda #SFX_COLLECT
    sta sfx_type
    lda #15
    sta sfx_timer
    lda #0
    sta sfx_pitch

    lda #%10111111
    sta APU_PULSE1_CTRL
    lda #0
    sta APU_PULSE1_SWEEP

    lda collect_pitches
    sta APU_PULSE1_TIMER_LO
    lda #%00001000
    sta APU_PULSE1_TIMER_HI

    rts

play_death_sound:
    lda #SFX_DEATH
    sta sfx_type
    lda #20
    sta sfx_timer
    lda #0
    sta sfx_pitch

    lda #%11111111
    sta APU_PULSE1_CTRL
    lda #0
    sta APU_PULSE1_SWEEP

    lda death_pitches
    sta APU_PULSE1_TIMER_LO
    lda #%00001000
    sta APU_PULSE1_TIMER_HI

    rts

update_sound:
    lda sfx_timer
    beq @done

    dec sfx_timer
    beq @end_sound

    lda sfx_type
    cmp #SFX_COLLECT
    beq @update_collect
    cmp #SFX_DEATH
    beq @update_death
    rts

@update_collect:
    lda sfx_timer
    and #%00000011
    bne @done

    ldx sfx_pitch
    cpx #5
    bcs @done

@update_death:
    lda sfx_timer
    and #%00000011
    bne @done

    cpx #5
    bcs @done

    sta APU_PULSE1_CTRL
    lda #SFX_NONE
    sta sfx_type
@done:

death_pitches:

    lda #0

    lda enemy_speeds, x

    sbc item_y
    bcs @check_y_pos

    clc
    adc #1

    bcs @no_collision

@no_collision:
    rts

    adc #10
    sta score
    lda score+1
    adc #0
    sta score+1

    jsr update_difficulty
    jsr play_collect_sound
    jsr respawn_item
    rts

; check_enemy_collision
; ----------------------------------------------------------------------------

    bne @done

    ldx #0

@loop:
    lda player_x
    sec
    sbc enemy_x, x
    bcs @check_x
    eor #$FF
