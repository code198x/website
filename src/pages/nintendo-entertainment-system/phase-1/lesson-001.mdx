# Your First NES Assembly Program

Welcome to NES assembly! You're about to write your first 6502 assembly program for the Nintendo Entertainment System.

## What You'll Build

A program that changes the background colour. When you run it, you'll see a solid colour filling the screen.

## The Code

Save this as `hello.asm`:

```nasm
; Your first NES assembly program
; Changes the background colour

        .inesprg 1   ; 1 PRG ROM bank (16KB)
        .ineschr 0   ; 0 CHR ROM banks (we don't need graphics yet)
        .inesmap 0   ; Mapper 0 (NROM, simplest)
        .inesmir 1   ; Vertical mirroring

        .bank 0
        .org $C000   ; PRG ROM starts at $C000

RESET:
        sei          ; Disable interrupts
        cld          ; Clear decimal mode (NES doesn't use it)

        ; Wait for PPU to be ready
        ldx #$FF
        txs          ; Set up stack pointer

        ; Turn off rendering
        lda #$00
        sta $2000    ; PPUCTRL
        sta $2001    ; PPUMASK

        ; Change background colour
        lda #$1F     ; Colour $1F (light blue)
        sta $2001    ; PPUMASK - enables rendering with colour

loop:   jmp loop     ; Loop forever

        ; Interrupt vectors at end of ROM
        .bank 1
        .org $FFFA
        .dw 0        ; NMI vector (not used yet)
        .dw RESET    ; RESET vector (entry point)
        .dw 0        ; IRQ vector (not used yet)
```

## How to Assemble and Run It

### Using NESASM3:
```bash
nesasm3 hello.asm
```

This creates `hello.nes`.

### Run in Mesen or FCEUX emulator:
```bash
mesen hello.nes
```

Or in emulator: File → Open → hello.nes

## What Just Happened?

- **iNES header:** Required metadata for NES ROM files
- **`RESET:`:** Entry point when NES powers on
- **`sei`/`cld`:** Disable interrupts and decimal mode (NES 6502 variant doesn't have decimal mode)
- **`ldx #$FF` / `txs`:** Sets up the stack pointer at $01FF
- **`sta $2000`:** Writes to PPUCTRL (PPU control register)
- **`sta $2001`:** Writes to PPUMASK (PPU mask register, controls rendering)
- **`lda #$1F` / `sta $2001`:** Sets background colour to light blue and enables rendering
- **Interrupt vectors:** NES requires these at $FFFA-$FFFF

## The 6502 on NES

The NES uses a modified 6502 CPU (no decimal mode, different addressing). It's the same instruction set you'd use on a C64, but the hardware around it is completely different!
