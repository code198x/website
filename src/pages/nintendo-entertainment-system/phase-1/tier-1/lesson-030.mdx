Pong is silent. This lesson adds sound effects using APU pulse channels: high-pitch beep for paddle hits, mid-pitch tone for wall bounces, descending chirp for scoring. Sound brings game to life with audio feedback.

Simple but effective audio.

## The One-Minute Tour

- **APU pulse channels**—$4000-$4007 (two square wave generators)
- **Frequency control**—Pitch via timer registers
- **Envelope**—Volume decay over time
- **Three sounds**—Paddle hit, wall bounce, score
- **Sound triggers**—Play on game events

## Your Sound Effects

```nasm
.segment "CODE"
; Play paddle hit sound (high blip)
PlayPaddleHitSound:
    ; Pulse 1: High pitch
    LDA #%00111111      ; Duty 00, envelope on, volume 15
    STA $4000
    LDA #$C9            ; Low frequency byte
    STA $4002
    LDA #$00            ; High frequency byte
    STA $4003
    RTS

; Play wall bounce sound (mid pitch)
PlayWallBounceSound:
    LDA #%00111010      ; Volume 10
    STA $4000
    LDA #$54            ; Mid frequency
    STA $4002
    LDA #$00
    STA $4003
    RTS

; Play score sound (descending chirp)
PlayScoreSound:
    ; Use pulse 2 for variety
    LDA #%00111111
    STA $4004
    LDA #$20            ; Low pitch
    STA $4006
    LDA #$01
    STA $4007
    RTS

; Integrate into game
HandlePaddle1Complete:
    ; ... collision logic ...
    JSR PlayPaddleHitSound
    RTS

BounceTop:
    ; ... bounce logic ...
    JSR PlayWallBounceSound
    RTS

ScorePlayer1:
    INC score_p1
    JSR PlayScoreSound
    ; ...
    RTS
```

**Run this**—game has audio feedback!

## Quick Reference

### APU Pulse Registers
```
$4000: Duty/Volume
$4002: Frequency low
$4003: Frequency high/Length
```
