Scores convert to tiles—but don't appear on screen. This lesson writes score tiles to nametable during VBlank, calculates nametable addresses ($2000 + row×32 + col), updates only changed tiles (not full screen), and creates a status bar layout. Players can now *see* the score.

This completes the scoring arc—scores are tracked and displayed!

## The One-Minute Tour

- **VBlank updates**—Write to PPU only during VBlank window
- **Nametable addresses**—$2000 + (row × 32) + column
- **Status bar**—Top 2 rows reserved for scores
- **Selective updates**—Change only score tiles, not entire screen
- **PPU address sequence**—Write high byte, then low byte to $2006
- **Update flag**—nametable_update signals NMI to update

## Your Score Display

```nasm
.segment "ZEROPAGE"
nametable_update: .res 1  ; Flag: update needed

.segment "CODE"
; NMI handler
NMI:
    ; ... save registers ...

    ; OAM DMA (always first)
    LDA #$00
    STA $2003
    LDA #>oam_buffer
    STA $4014

    ; Update nametable if flagged
    LDA nametable_update
    BEQ @no_update
    JSR UpdateScoreDisplay
    LDA #$00
    STA nametable_update

@no_update:
    ; ... restore registers, RTI ...

; Update score display in nametable
UpdateScoreDisplay:
    ; Player 1 score at (4, 1)
    LDA score_p1
    JSR ScoreToDigits

    ; Write P1 tens digit
    LDA #$20
    STA $2006           ; High byte
    LDA #(1*32 + 4)     ; Row 1, Col 4
    STA $2006           ; Low byte

    LDA digit_tens
    JSR DigitToTile
    STA $2007           ; Write tile

    ; Write P1 ones digit
    LDA #$20
    STA $2006
    LDA #(1*32 + 5)
    STA $2006

    LDA digit_ones
    JSR DigitToTile
    STA $2007

    ; Player 2 score at (26, 1)
    LDA score_p2
    JSR ScoreToDigits

    ; Write P2 tens
    LDA #$20
    STA $2006
    LDA #(1*32 + 26)
    STA $2006

    LDA digit_tens
    JSR DigitToTile
    STA $2007

    ; Write P2 ones
    LDA #$20
    STA $2006
    LDA #(1*32 + 27)
    STA $2006

    LDA digit_ones
    JSR DigitToTile
    STA $2007

    RTS

; After scoring, flag update
ScorePlayer1:
    INC score_p1
    LDA #$01
    STA nametable_update    ; Request update
    ; ... rest of scoring ...
    RTS
```

**Run this**—scores appear in status bar, update when points scored!

## How This Works

### Nametable Address Calculation

Address = $2000 + (row × 32) + column:

```
Example: Row 1, Column 4
Address = $2000 + (1 × 32) + 4
        = $2000 + 32 + 4
        = $2024
```

**Why ×32?** Nametable is 32 tiles wide. Each row = 32 tiles.

### PPU Address Writing

Set PPU address via $2006 (two writes):

```nasm
LDA #$20        ; High byte
STA $2006
LDA #$24        ; Low byte
STA $2006
; PPU address now = $2024
```

**Then write data:**
```nasm
LDA tile_index
STA $2007       ; Write to address, auto-increment
```

### VBlank-Only Updates

Never write to PPU while rendering:

```nasm
; In NMI (during VBlank):
JSR UpdateScoreDisplay

; NOT in main loop (during rendering)!
```

**Why?** Writing during rendering causes visual glitches.

### Status Bar Layout

```
Row 0: Game title / decoration
Row 1: P1 score (cols 4-5)    P2 score (cols 26-27)
Row 2: Separator line
Rows 3-29: Play area
```

## Building Your Game

Add to NMI handler:

```nasm
NMI:
    ; OAM DMA first
    ; ... OAM code ...

    ; Then nametable updates
    LDA nametable_update
    BEQ skip
    JSR UpdateScoreDisplay
    LDA #$00
    STA nametable_update
skip:
    ; ... restore, RTI ...
```

Flag updates after scoring:

```nasm
ScorePlayer1:
    INC score_p1
    LDA #$01
    STA nametable_update
    ; ...
```

## Quick Reference

### Nametable Address
```
Address = $2000 + (row × 32) + col
Example: (1, 4) = $2000 + 32 + 4 = $2024
```

### PPU Write Sequence
```nasm
LDA #HIGH_BYTE
STA $2006
LDA #LOW_BYTE
STA $2006
LDA tile_data
STA $2007
```
