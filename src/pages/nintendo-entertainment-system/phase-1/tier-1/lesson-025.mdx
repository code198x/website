Pong has physics—but no scorekeeping. This lesson creates score variables in RAM (score_p1, score_p2), implements scoring logic when ball exits screen edges, detects win conditions (first to 11 points), and launches ball toward the player who was scored on. This adds game structure: play isn't endless, there's a winner.

Scores exist but aren't displayed yet (that's L26-27).

## The One-Minute Tour

- **Score variables**—score_p1, score_p2 in zero page (0-99 range)
- **Award logic**—Increment score when ball exits left/right edge
- **Win detection**—Check if score >= win_score (typically 11)
- **Game state**—STATE_PLAYING vs STATE_GAMEOVER
- **Launch fairness**—Ball goes toward player who was scored on
- **Cap enforcement**—Don't score beyond win condition

## Your Scoring System

```nasm
.segment "ZEROPAGE"
score_p1: .res 1        ; Player 1 score (0-99)
score_p2: .res 1        ; Player 2 score (0-99)
win_score: .res 1       ; Score needed to win (11 typical)

; Game state
game_state: .res 1
STATE_TITLE = 0
STATE_PLAYING = 1
STATE_GAMEOVER = 2

.segment "CODE"
; Initialize scores
InitScores:
    LDA #$00
    STA score_p1
    STA score_p2
    LDA #11             ; Play to 11 points (classic Pong)
    STA win_score
    RTS

; Award point to player 1
ScorePlayer1:
    LDA score_p1
    CMP win_score       ; Already at win score?
    BCS :+              ; Skip if >= win_score

    INC score_p1        ; Increment score

    ; Check for win
    LDA score_p1
    CMP win_score
    BCC :+              ; Branch if < win_score

    ; Player 1 wins!
    LDA #STATE_GAMEOVER
    STA game_state

:   RTS

; Award point to player 2
ScorePlayer2:
    LDA score_p2
    CMP win_score
    BCS :+

    INC score_p2

    ; Check for win
    LDA score_p2
    CMP win_score
    BCC :+

    ; Player 2 wins!
    LDA #STATE_GAMEOVER
    STA game_state

:   RTS

; Check ball boundaries with scoring
CheckBallBoundaries:
    ; Top/bottom (from L19)
    ; ... bounce logic ...

    ; Left boundary (P2 scores)
    LDA ball_x
    BNE :+

    JSR ScorePlayer2
    LDA #1              ; Launch right (toward P2)
    JSR ResetBallToward
    RTS

    ; Right boundary (P1 scores)
:   LDA ball_x
    CMP #255
    BNE :+

    JSR ScorePlayer1
    LDA #0              ; Launch left (toward P1)
    JSR ResetBallToward

:   RTS
```

**Run this**—scores track, game ends at 11 points!

## How This Works

### Score Award Logic

When ball exits, award point to opponent:

```nasm
; Ball exits left edge = P1 missed, P2 scores
LDA ball_x
BNE not_left
JSR ScorePlayer2

; Ball exits right edge = P2 missed, P1 scores
LDA ball_x
CMP #255
BNE not_right
JSR ScorePlayer1
```

**Why opponent scores?** Player who failed to return ball loses the point.

### Win Condition

Check after each score:

```nasm
INC score_p1
LDA score_p1
CMP win_score
BCC still_playing

; Score >= win_score, player wins
LDA #STATE_GAMEOVER
STA game_state
```

**Effect:** Game loop can check game_state and transition to game over screen.

### Launch Fairness

Ball launches toward player who was scored on:

```nasm
; P2 scored, launch toward P2
LDA #1              ; Direction = right
JSR ResetBallToward
```

**Implementation (from L20):**
```nasm
ResetBallToward:
    ; A = 0 (left) or 1 (right)
    ; Center position
    LDA #128
    STA ball_x
    LDA #120
    STA ball_y

    ; Set velocity based on direction
    ; ... velocity setup ...
```

## Building Your Game

Integrate scoring into ball boundaries:

```nasm
MainLoop:
    ; ... game logic ...
    JSR UpdateBallPhysics
    JSR CheckBallBoundaries  ; Now includes scoring
    ; ...
```
