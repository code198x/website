Paddle 2 exists—but controlled by same input as paddle 1. This lesson reads controller 2 from $4017, assigns paddle 2 to player 2's controller, enables simultaneous independent input. Now two players can compete!

True 2-player Pong.

## The One-Minute Tour

- **Controller 2**—$4017 register, same protocol as $4016
- **Dual strobe**—Single strobe latches both controllers
- **Independent buttons**—buttons1, buttons2 variables
- **Simultaneous input**—Both players act same frame
- **Same paddle logic**—UpdatePaddle1/2 use different button vars

## Your 2-Player Input

```nasm
.segment "ZEROPAGE"
buttons1: .res 1        ; Controller 1
buttons2: .res 1        ; Controller 2

.segment "CODE"
; Read both controllers
ReadControllers:
    ; Strobe both controllers
    LDA #$01
    STA $4016
    LDA #$00
    STA $4016

    ; Read controller 1
    LDX #$08
:   LDA $4016
    LSR
    ROL buttons1
    DEX
    BNE :-

    ; Read controller 2
    LDX #$08
:   LDA $4017
    LSR
    ROL buttons2
    DEX
    BNE :-

    RTS

; Update paddle 1 (uses buttons1)
UpdatePaddle1:
    LDA buttons1
    AND #BUTTON_UP
    BEQ :+
    ; Move up
:   LDA buttons1
    AND #BUTTON_DOWN
    BEQ :+
    ; Move down
:   RTS

; Update paddle 2 (uses buttons2)
UpdatePaddle2:
    LDA buttons2
    AND #BUTTON_UP
    BEQ :+
    ; Move up
:   LDA buttons2
    AND #BUTTON_DOWN
    BEQ :+
    ; Move down
:   RTS
```

**Run this**—both players control their paddles independently!

## How This Works

Controller 2 uses $4017, same protocol as $4016:

```nasm
; Strobe (latches both):
LDA #$01
STA $4016
LDA #$00
STA $4016

; Read P1 from $4016
; Read P2 from $4017
```

## Quick Reference

### Dual Controller Read
```nasm
; Strobe both
LDA #$01
STA $4016
LDA #$00
STA $4016

; Read controller 1
LDX #8
loop1:
    LDA $4016
    LSR
    ROL buttons1
    DEX
    BNE loop1

; Read controller 2
LDX #8
loop2:
    LDA $4017
    LSR
    ROL buttons2
    DEX
    BNE loop2
```
