Game works—but looks basic. This lesson adds visual polish: center court line (dashed vertical line), sprite flash effects on collision (temporarily change palette), and clean presentation. Small touches that make game feel complete.

Professional presentation matters.

## The One-Minute Tour

- **Center line**—Vertical dashed line at X=128 (court middle)
- **Flash effect**—Briefly change sprite palette on hit
- **Flash timer**—Countdown for effect duration
- **Visual feedback**—Player sees/feels every action
- **Court aesthetics**—Classic Pong look

## Your Visual Polish

```asm
.segment "ZEROPAGE"
flash_timer: .res 1     ; Countdown for flash

.segment "CODE"
; Draw center line in nametable
DrawCenterLine:
    ; Column 16 (middle of 32-tile width)
    LDX #$00            ; Start at row 3
:   LDA #$20
    STA $2006
    TXA
    ASL
    ASL
    ASL
    ASL
    ASL                 ; X * 32
    CLC
    ADC #16             ; + 16 (column)
    STA $2006

    ; Dashed effect (every other row)
    TXA
    AND #$01
    BEQ @dash
    LDA #$00            ; Blank
    JMP @write
@dash:
    LDA #$03            ; Line tile
@write:
    STA $2007

    INX
    CPX #19             ; Rows 3-21
    BNE :-
    RTS

; Flash paddle on hit
FlashPaddleOnHit:
    LDA #10             ; Flash for 10 frames
    STA flash_timer
    RTS

; Update flash effect each frame
UpdateFlashEffect:
    LDA flash_timer
    BEQ :+
    DEC flash_timer
    ; Modify paddle sprite attributes during flash
:   RTS
```

**Run this**—game looks polished!
