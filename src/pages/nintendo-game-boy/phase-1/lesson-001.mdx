# Your First Game Boy Assembly Program

Welcome to Game Boy assembly! You're about to write your first Sharp SM83 (Z80-like) assembly program for Nintendo's handheld.

## What You'll Build

A program that changes the background colour. When you run it, you'll see the screen fade between the Game Boy's 4 shades.

## The Code

Save this as `hello.asm`:

```nasm
; Your first Game Boy assembly program
; Changes background colour palette

SECTION "Header", ROM0[$0100]
        nop
        jp Start

        ; Minimal GB ROM header
SECTION "Header Data", ROM0[$0104]
        ; Nintendo logo goes here (emulators often add this automatically)
        ds $30

SECTION "Main", ROM0[$0150]
Start:
        ; Turn off LCD during setup
        ld a, 0
        ld [$FF40], a   ; LCDC register

        ; Set up background palette
        ld a, %11100100  ; Palette: 3,2,1,0 (darkest to lightest)
        ld [$FF47], a    ; BGP register

        ; Turn LCD back on
        ld a, %10000001  ; LCD on, BG on
        ld [$FF40], a

loop:   ; Cycle through palette values
        ld a, [$FF47]    ; Load current palette
        rlca             ; Rotate left
        ld [$FF47], a    ; Store new palette

        ; Small delay
        ld b, 2
delay:  dec b
        jr nz, delay

        jr loop          ; Loop forever
```

## How to Assemble and Run It

### Using RGBDS (RGBASM + RGBLINK + RGBFIX):
```bash
rgbasm -o hello.o hello.asm
rgblink -o hello.gb hello.o
rgbfix -v -p 0 hello.gb
```

This creates `hello.gb`.

### Run in SameBoy or BGB emulator:
```bash
sameboy hello.gb
```

Or in emulator: File → Open ROM → hello.gb

## What Just Happened?

- **ROM sections:** Game Boy ROMs have specific required sections (header at $0100, code at $0150+)
- **`ld [$FF40], a`:** Writes to LCDC (LCD Control register)
- **`ld [$FF47], a`:** Writes to BGP (Background Palette register)
- **`rlca`:** Rotates accumulator left, cycling through palette values
- **Delay loop:** Slows down the palette changes so you can see them

## Sharp SM83 CPU

The Game Boy uses the Sharp SM83, a hybrid between Z80 and 8080. It's similar to Z80 but with some differences (no IX/IY registers, no shadow registers, different timing).

## Game Boy Memory-Mapped I/O

Unlike computers, the Game Boy uses memory-mapped hardware registers (all in $FF00-$FF7F range, called "High RAM" region).
