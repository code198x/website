## What You'll Build

Classic snake game using character graphics. Eat food, grow longer, don't hit yourself.

Guide a growing serpent. Each morsel extends your body. The challenge: avoid your own ever-lengthening tail. This game introduces arrays for tracking the snake body and the TI variable for consistent timing.

## Skills You'll Master

- **Array usage** — snake body storage
- **Timed movement** — TI variable
- **Self-collision detection** — body checks
- **Food spawning** — random placement
- **Growth mechanics** — extending the snake
- **Screen wrapping** — edge behaviour
- **Speed progression** — increasing difficulty
- **Game over conditions** — failure states

## Prerequisites

Complete **Game 4: Maze Escape** first.

## Time Investment

64 units at 60-90 minutes each. Roughly 64-96 hours total.
