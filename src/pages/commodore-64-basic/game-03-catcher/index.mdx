## What You'll Build

Catch falling objects with a paddle. Keyboard-controlled action game with real-time input.

Objects fall from above. You move left and right to catch them. Miss too many and it's game over. This introduces real-time keyboard input — the GET statement that makes action games possible in BASIC.

## Skills You'll Master

- **Keyboard input** — GET statement
- **Real-time game loop** — continuous play
- **Player movement** — responsive controls
- **Falling object mechanics** — gravity simulation
- **Collision detection** — screen PEEK
- **Score display** — on-screen numbers
- **Lives system** — failure conditions
- **Increasing difficulty** — ramping challenge

## Prerequisites

Complete **Game 2: Cosmic Drift** first.
