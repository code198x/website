## What You'll Build

Space game with scrolling asteroids. Your ship dodges falling obstacles. First encounter with attribute clash.

Asteroids descend from above. Your UDG ship weaves between them. As more objects fill the screen, you'll notice colour bleeding between cells — attribute clash. This is intentional: understanding this limitation prepares you for Z80 assembly.

## Skills You'll Master

- **Multiple moving objects** — parallel animation
- **Simulated scrolling** — character movement
- **UDG sprites** — ship and asteroid graphics
- **DRAW for effects** — visual feedback
- **Difficulty ramping** — increasing challenge
- **High score system** — persistent best
- **Attribute clash awareness** — colour cell limits
- **Performance observation** — speed constraints
