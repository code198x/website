## What You'll Build

Flip-screen top-down exploration. Navigate dungeon rooms, collect items, avoid enemies. The ancestor to Zelda-style adventures.

Explore a dungeon one room at a time. Each screen transition reveals new challenges. Keys unlock doors. Items grant abilities. Enemies chase with simple but effective AI. This game teaches room-based data structures and state persistence across screens.

## Skills You'll Master

- **Room data structures** — tile-based dungeon design
- **Screen transitions** — Copper-enhanced room changes
- **Persistent state** — items and progress tracked
- **Key/door mechanics** — unlocking progression
- **Chase AI** — enemies that pursue
- **Blitter tile rendering** — efficient room drawing
- **Inventory system** — item management
