## What You'll Build

Side-scrolling runner. The world rushes past. Obstacles appear. The Amiga's custom chipset does the heavy lifting.

Guide your character through an ever-accelerating world. The Copper paints the sky. Hardware sprites draw the player. The Blitter renders obstacles. Paula plays the sounds. This is your introduction to the custom chipset symphony.

## Why This Game?

Exodus is your first Amiga game — and it introduces every custom chip. The Amiga wasn't about one killer feature. It was about Agnus, Denise, and Paula working in harmony. Exodus naturally exercises them all:

- Set up **Copper lists** for display configuration
- Use **hardware sprites** for the player
- Draw obstacles with the **Blitter**
- Play sound effects with **Paula**
- Read **joystick input** for controls
- Implement **scrolling** with the Blitter

By the end, you'll understand how the custom chipset renders every frame.

## Skills You'll Master

- **Copper lists** — programming the display
- **Hardware sprites** — drawing the player
- **Blitter basics** — drawing obstacles
- **Paula audio** — sound effects
- **Joystick input** — controls
- **Scrolling** — Blitter-based world movement

## Prerequisites

This is Game 1. No prerequisites — just enthusiasm and a willingness to learn 68000 assembly.

You'll need an emulator (FS-UAE), an assembler (vasm), and disk tools (amitools).
