## What You'll Build

Flip-screen exploration. Navigate dungeon rooms, collect keys, find the exit.

A dungeon of interconnected rooms awaits. Each transition reveals new challenges. Keys unlock doors. Items persist across rooms. Enemies chase with simple AI. A map system helps you navigate. Save your progress to return later.

## Skills You'll Master

- **Room data structures** — level design
- **Screen transitions** — room changes
- **Persistent state** — items collected
- **Key/door mechanics** — unlocking progress
- **Enemy chase behaviour** — simple AI
- **Inventory display** — item management
- **Map system** — dungeon overview
- **Save/load game state** — progress persistence
