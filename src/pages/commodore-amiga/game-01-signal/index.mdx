## What You're Building

Cross the road. Ride the logs. Reach home. Don't die.

Signal is a Frogger-style game where you guide a frog across busy roads and treacherous rivers to reach safety. Simple concept, but it touches every part of the Amiga's custom chipset:

- **Copper** paints the coloured zones
- **Sprites** draw the frog
- **Blitter** draws cars and logs
- **Paula** plays the sounds

## Why This Game?

The Amiga wasn't about one killer feature — it was about the custom chips working in harmony. Signal naturally exercises them all without going deep on any single one. You'll see the chipset symphony from day one.

## What You'll Learn

By the end of this game, you'll understand:

- **Copper lists** — Programming the display with the Copper
- **Hardware sprites** — Using the Amiga's 8 hardware sprites
- **Blitter objects** — Drawing and animating with the Blitter
- **Paula audio** — Playing sound effects through Paula
- **Joystick input** — Reading the joystick ports
- **Collision detection** — Knowing when the frog hits something

## Prerequisites

This is Game 1. No prerequisites — just enthusiasm and a willingness to learn 68000 assembly.

You'll need an emulator (FS-UAE), an assembler (vasm), and disk tools (amitools). If you haven't set these up yet, see [Getting Started](/commodore-amiga/getting-started).

## Time Investment

Each unit takes 60-90 minutes. The full game is 16 units, so roughly 16-24 hours total.

Every unit produces something that works. By the end of Unit 1, you'll have a display showing the game's coloured zones, controlled entirely by the Copper.
