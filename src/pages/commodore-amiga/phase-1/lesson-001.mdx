# Your First Amiga Assembly Program

Welcome to Amiga assembly! You're about to write your first Motorola 68000 assembly program for Commodore's legendary 16-bit computer.

## What You'll Build

A program that changes the screen background colour. When you run it, you'll see the entire screen flash different colours.

## The Code

Save this as `hello.asm`:

```nasm
; Your first Amiga assembly program
; Changes background colour using Copper

        section code,code

Start:
        ; Take over the machine (disable multitasking)
        move.l  4.w,a6          ; Get ExecBase
        jsr     -132(a6)        ; Forbid()

        ; Save old copper list
        lea     $dff000,a5      ; Custom chip base
        move.l  $84(a5),old_cop ; Save COP1LC

        ; Install our copper list
        lea     copper(pc),a0
        move.l  a0,$80(a5)      ; COP1LC (copper list pointer)
        move.w  #0,$88(a5)      ; COPJMP1 (start copper)

loop:
        ; Wait for mouse button
        btst    #6,$bfe001      ; Left mouse button
        bne.s   loop

        ; Restore and exit
        move.l  old_cop(pc),$80(a5)  ; Restore old copper
        move.l  4.w,a6
        jsr     -138(a6)        ; Permit()
        rts

old_cop:
        dc.l    0

; Copper list - changes background colour
copper:
        dc.w    $0180,$0F00     ; COLOR00 = red
        dc.w    $FFDF,$FFFE     ; Wait

        dc.w    $0180,$00F0     ; COLOR00 = green
        dc.w    $FFDF,$FFFE     ; Wait

        dc.w    $0180,$000F     ; COLOR00 = blue
        dc.w    $FFDF,$FFFE     ; Wait

        dc.w    $FFFF,$FFFE     ; End of copper list
```

## How to Assemble and Run It

### Using VASM (68k assembler):
```bash
vasmm68k_mot -kick1hunks -Fhunkexe -o hello -nosym hello.asm
```

This creates `hello` (Amiga executable).

### Run in WinUAE or FS-UAE emulator:
1. Boot Workbench
2. Copy `hello` to Workbench disk
3. Double-click to run (or run from CLI)

## What Just Happened?

- **`move.l 4.w,a6`:** Gets ExecBase (Amiga OS executive library base)
- **`jsr -132(a6)`:** Calls Forbid() to disable multitasking
- **`lea $dff000,a5`:** Loads address of custom chip registers
- **`move.l a0,$80(a5)`:** Installs our copper list at COP1LC register
- **Copper list:** A display list that runs in sync with the video beam, changing colours at specific screen positions
- **`btst #6,$bfe001`:** Tests left mouse button state
- **`jsr -138(a6)`:** Calls Permit() to restore multitasking

## The Copper

The Copper is a coprocessor unique to the Amiga. It can autonomously write to chip registers in sync with the video beam, perfect for effects like colour bars, parallax scrolling, and more!

## Motorola 68000 on Amiga

The Amiga uses the same 68000 CPU as the Genesis, but in a completely different environment - it has an operating system (AmigaOS), multitasking, and custom chips (Agnus, Denise, Paula).
