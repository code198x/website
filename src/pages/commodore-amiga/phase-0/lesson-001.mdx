# Your First Amiga Program

Welcome! You're about to write your first program for the Amiga using AMOS BASIC.

## What You'll Build

A simple program that fills the screen with text. When you run it, you'll see "HELLO AMIGA!" scrolling endlessly down the screen.

## The Code

Type this in AMOS:

```amos
Print "HELLO AMIGA!"
Goto 1
```

That's it! Just two lines.

## How to Run It

1. Start your Amiga emulator (WinUAE or FS-UAE recommended)
2. Boot AMOS BASIC from disk image
3. You'll see the AMOS editor screen
4. Type the program exactly as shown above
5. Press `F1` to run the program

## Stopping the Program

Press `ESC` (or `Ctrl-C` in some configurations).

## What Just Happened?

- **Line 1:** Prints "HELLO AMIGA!" to the screen
- **Line 2:** Goes back to line 1 (creates a loop)
- **Result:** Infinite loop that keeps printing

## About AMOS

AMOS (AMOS BASIC) was specifically designed for game creation on the Amiga. Unlike typical BASIC interpreters, AMOS is optimized for graphics, sound, and sprite handling - perfect for making games!

## You Did It!

You just wrote and ran your first Amiga program. The Amiga is responding to your commands!
