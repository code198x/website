# Lesson 002: Interactive Oracle

Interactive program with user input and conditional responses - your first conversation with the Amiga.

## The One-Minute Tour

- **Input$** gets text input from user (returns string)
- **Input** gets numeric input (returns number)
- **If...Then...End If** structured conditionals (no line numbers needed)
- **Else** provides alternative execution path
- **String comparison** works with `=` operator
- **String concatenation** uses `+` to combine text
- **Ink** changes text colour (0-15 in default palette)

## Example Programme

Type this programme to create an interactive oracle:

```amos
' Lesson 002: Interactive Oracle
' User input and conditional branching

Cls 0

' Get user's name
Locate 5,5
Print "What is your name?"
Locate 7,5
Input name$

' Respond based on name
If name$="Alice" Then
  Locate 10,5
  Print "Hello Alice, welcome back!"
Else
  Locate 10,5
  Print "Nice to meet you, "+name$
End If

' Number guessing
Locate 13,5
Print "Pick a number 1-10:"
Locate 15,5
Input guess

If guess=7 Then
  Locate 18,5
  Ink 2
  Print "Lucky number! You win!"
Else
  Locate 18,5
  Ink 3
  Print "Try again! The answer was 7."
End If

Locate 22,5
Print "Press any key to exit"
Wait Key
```

**Run it:**
1. Load AMOS Professional
2. Load `interactive-oracle.amos`
3. Press F1 to run
4. Type your name when prompted
5. Enter a number 1-10
6. Press any key to exit

**What happens:**
- Programme asks for your name
- If you type "Alice", you get a special greeting
- Otherwise, it greets you by name
- You guess a number
- Programme tells you if you won (guessed 7)
- Text appears in different colours based on success

## Understanding Input

### Input$ for Text

`Input$` pauses the programme and waits for the user to type text:

```amos
Input name$
```

**How it works:**
1. Displays a flashing cursor
2. User types text
3. User presses Return/Enter
4. Text is stored in the variable
5. Programme continues

**Common uses:**
- Get player name
- Read menu choice ("A", "B", "C")
- Collect any text input
- Password entry (though visible!)

### Input for Numbers

`Input` (without $) reads numeric input:

```amos
Input age
Input score
Input choice
```

**AMOS is smart:** If user types "abc" when you ask for a number, AMOS will ask again with "?Redo From Start". It validates the input automatically.

### Prompts

You can include a prompt string:

```amos
Input "Enter your age: ";age
Input "Choose 1-3: ";choice
```

The semicolon `;` keeps the cursor on the same line after the prompt.

## Understanding Conditionals

### If...Then...End If Structure

AMOS uses **structured conditionals** (no line numbers needed):

```amos
If condition Then
  ' Code when condition is true
End If
```

**This is MODERN:** Unlike C64 BASIC where you need:
```basic
10 IF X=5 THEN GOTO 100
```

AMOS lets you write clear, readable code without GOTO spaghetti.

### If...Then...Else...End If

Add an `Else` clause for alternative behaviour:

```amos
If score>100 Then
  Print "You win!"
Else
  Print "Try again!"
End If
```

**Execution flow:**
1. Check condition (`score>100`)
2. If TRUE → run the `Then` block, skip `Else`
3. If FALSE → skip `Then` block, run `Else`
4. Continue after `End If`

### Multiple Conditions

Check several things:

```amos
If name$="Alice" Then
  Print "Hello Alice!"
End If

If name$="Bob" Then
  Print "Hello Bob!"
End If

If name$="Carol" Then
  Print "Hello Carol!"
End If

' Alternative: nested If
If name$="Alice" Then
  Print "Hello Alice!"
Else
  If name$="Bob" Then
    Print "Hello Bob!"
  Else
    Print "Hello stranger!"
  End If
End If
```

**AMOS also has:** `Else If` for cleaner multiple conditions (covered in later lessons).

## String Operations

### String Comparison

Compare strings with `=`:

```amos
If name$="Alice" Then
  Print "Exact match!"
End If
```

**Case sensitive:** "Alice" ≠ "alice" ≠ "ALICE"

**To ignore case:** Convert to uppercase with `Upper$`:

```amos
If Upper$(name$)="ALICE" Then
  Print "Matches regardless of case"
End If
```

### String Concatenation

Combine strings with `+`:

```amos
greeting$="Hello, "+name$
Print greeting$

' Or inline:
Print "Welcome, "+name$+"!"
```

**Examples:**
```amos
first$="Game"
last$="Over"
full$=first$+" "+last$    ' "Game Over"

score$="Score: "+Str$(points)  ' Convert number to string
```

## Experiments

### Experiment 1: Multiple Questions

Ask several questions in sequence:

```amos
Cls 0
Locate 5,5
Print "What is your favourite colour?"
Input colour$

Locate 8,5
Print "How old are you?"
Input age

Locate 11,5
If age<18 Then
  Print "You're young!"
Else
  Print "You're an adult!"
End If

Locate 14,5
Print "You like "+colour$
Wait Key
```

### Experiment 2: Score Tracking

Build a simple quiz:

```amos
score=0

' Question 1
Print "What is 5+3?"
Input answer
If answer=8 Then
  score=score+1
  Ink 2
  Print "Correct!"
Else
  Ink 3
  Print "Wrong! The answer was 8."
End If

' Question 2
Ink 1
Print ""
Print "What is 10-4?"
Input answer
If answer=6 Then
  score=score+1
  Ink 2
  Print "Correct!"
Else
  Ink 3
  Print "Wrong! The answer was 6."
End If

' Show total
Ink 1
Print ""
Print "You scored "+Str$(score)+"/2"
Wait Key
```

### Experiment 3: Random Answer

Use `Rnd()` for random numbers:

```amos
secret=Rnd(10)+1    ' Random number 1-10

Print "I'm thinking of a number 1-10"
Input guess

If guess=secret Then
  Print "You guessed it!"
Else
  Print "Nope! It was "+Str$(secret)
End If
```

## Quick Reference

### Input Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `Input$` | Get string from user | `Input name$` |
| `Input` | Get number from user | `Input age` |
| `Input "prompt";var` | Get input with prompt | `Input "Age: ";age` |

### Conditional Structures

```amos
' Simple condition
If condition Then
  ' code
End If

' With alternative
If condition Then
  ' code when true
Else
  ' code when false
End If

' Nested conditions
If condition1 Then
  ' code
Else
  If condition2 Then
    ' code
  Else
    ' code
  End If
End If
```

### Comparison Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| `=` | Equal to | `If x=5` |
| `<>` | Not equal to | `If name$<>"Bob"` |
| `>` | Greater than | `If score>100` |
| `<` | Less than | `If age<18` |
| `>=` | Greater or equal | `If points>=50` |
| `<=` | Less or equal | `If lives<=0` |

### String Functions

| Function | Purpose | Example |
|----------|---------|---------|
| `Upper$(s$)` | Convert to uppercase | `Upper$("hello")` → "HELLO" |
| `Lower$(s$)` | Convert to lowercase | `Lower$("HELLO")` → "hello" |
| `Str$(n)` | Number to string | `Str$(42)` → "42" |
| `Val(s$)` | String to number | `Val("42")` → 42 |
| `Len(s$)` | String length | `Len("Hello")` → 5 |
