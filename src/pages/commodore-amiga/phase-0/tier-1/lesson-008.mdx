# Lesson 008: Screen Artist

Master the Amiga's hardware-accelerated drawing commands and create your own custom colour palettes. Every drawing operation uses the blitter - no CPU overhead!

## The One-Minute Tour

- **Plot** - Draw single pixels
- **Draw** - Lines from last position
- **Circle** - Rings and filled circles
- **Bar** - Filled rectangles
- **Box** - Rectangle outlines
- **Colour command** - Programme custom RGB palettes
- **Ink/Paper** - Set foreground/background colours
- **All hardware-accelerated** - Blitter does the work

## Example Programme

Here's a drawing showcase with custom colours:

```amos
' Screen Artist Demo
Screen Open 0,320,256,32,Lowres
Curs Off: Flash Off: Cls 0

' Custom palette
Colour 1,$F00    ' Red
Colour 2,$0F0    ' Green
Colour 3,$00F    ' Blue

' Draw shapes
Ink 1: Bar 50,50 To 100,100       ' Red square
Ink 2: Circle 150,75,30            ' Green circle
Ink 3: Box 200,50 To 250,100      ' Blue outline

' Lines
Plot 10,150
For x=10 To 300 Step 10
  Draw x,150+Rnd(40)
Next x

Wait Key
```

**Run it:**
1. Load AMOS Professional
2. Load `screen-artist.amos`
3. Press F1 to run
4. Watch progressive drawing demonstration
5. Press SPACE to see BOB capture

## Understanding Drawing Commands

### Plot - Single Pixels

```amos
Plot x,y
```

Draws one pixel at coordinates (x,y) in current Ink colour.

**Examples:**
```amos
Ink 2
Plot 160,128    ' Center pixel

' Draw horizontal line manually
For x=100 To 200
  Plot x,100
Next x

' Random starfield
For i=1 To 100
  Ink Rnd(15)+1
  Plot Rnd(320),Rnd(256)
Next i
```

**Use Plot for:**
- Pixel-level control
- Starfields
- Particle effects
- Custom patterns

### Draw - Connected Lines

```amos
Plot x1,y1      ' Set starting point
Draw x2,y2      ' Draw line to new point
Draw x3,y3      ' Continue from x2,y2
```

**Important:** `Draw` continues from the last graphics position (set by `Plot` or previous `Draw`).

**Examples:**
```amos
' Simple line
Plot 50,50
Draw 250,200

' Connected line segments
Plot 50,50
Draw 100,100
Draw 150,50
Draw 200,100    ' Creates zigzag

' Triangle
Plot 160,50
Draw 200,150
Draw 120,150
Draw 160,50     ' Close the shape
```

**Use Draw for:**
- Wireframe graphics
- Line graphs
- Polygons
- Geometric patterns

### Circle - Rings and Filled

```amos
Circle x,y,radius
```

Draws circle centered at (x,y) with specified radius. Outline in current Ink colour.

**Examples:**
```amos
' Single circle
Ink 2
Circle 160,128,50

' Concentric circles (target)
For r=10 To 100 Step 10
  Ink Rnd(15)+1
  Circle 160,128,r
Next r

' Bubble pattern
For i=1 To 20
  x=Rnd(320)
  y=Rnd(256)
  r=Rnd(30)+5
  Ink Rnd(15)+1
  Circle x,y,r
Next i
```

**Note:** For filled circles, use `CircleFill x,y,radius` (covered in later lessons).

**Use Circle for:**
- Character designs (heads, eyes)
- Explosions
- Bubbles and particles
- Radar displays

### Bar - Filled Rectangles

```amos
Bar x1,y1 To x2,y2
```

Draws filled rectangle from (x1,y1) to (x2,y2) in current Ink colour.

**Examples:**
```amos
' Single rectangle
Ink 3
Bar 50,50 To 150,100

' Colour bars
For i=0 To 31
  Ink i
  Bar i*10,50 To (i+1)*10,150
Next i

' Building blocks
Ink 8: Bar 100,150 To 150,200    ' Base
Ink 9: Bar 110,120 To 140,150    ' Middle
Ink 1: Bar 120,100 To 130,120    ' Top
```

**Use Bar for:**
- Solid shapes
- UI elements
- Building sprites
- Fill operations

### Box - Rectangle Outlines

```amos
Box x1,y1 To x2,y2
```

Draws rectangle outline in current Ink colour. No fill.

**Examples:**
```amos
' Single outline
Ink 2
Box 50,50 To 150,100

' Nested boxes
For i=0 To 5
  Ink i+1
  Box 100-i*10,80-i*10 To 220+i*10,160+i*10
Next i

' Window frames
Ink 7
Box 50,50 To 270,200      ' Outer
Box 52,52 To 268,198      ' Inner (double border)
```

**Use Box for:**
- Frames and borders
- UI outlines
- Wireframe graphics
- Highlighting areas

## Understanding Colours

### The Ink and Paper System

```amos
Ink colour      ' Set foreground (drawing) colour
Paper colour    ' Set background (fill) colour
```

**Range:** 0-31 in 32-colour mode (0-15 in 16-colour mode)

**Examples:**
```amos
Ink 1           ' Red text/graphics
Print "Hello"
Bar 10,10 To 50,50

Ink 2           ' Switch to green
Circle 100,100,30

Paper 4         ' Yellow background
Cls Paper       ' Clear to Paper colour
```

**Default colours:**
- Colour 0: Black (background)
- Colour 1: White (foreground)
- Colours 2-31: Various (set with `Colour` command)

### Programming the Palette

```amos
Colour index,$RGB
```

**Format:** $RGB where R, G, B are hexadecimal digits (0-F)
- Each channel: 0 (off) to F (maximum brightness, value 15)
- 4 bits per channel = 4096 possible colours total
- 32 simultaneously displayable in low-res

**Examples:**
```amos
' Primary colours
Colour 1,$F00      ' Red (R=15, G=0, B=0)
Colour 2,$0F0      ' Green (R=0, G=15, B=0)
Colour 3,$00F      ' Blue (R=0, G=0, B=15)

' Secondary colours
Colour 4,$FF0      ' Yellow (R=15, G=15, B=0)
Colour 5,$F0F      ' Magenta (R=15, G=0, B=15)
Colour 6,$0FF      ' Cyan (R=0, G=15, B=15)

' Grayscale
Colour 7,$000      ' Black
Colour 8,$888      ' Dark gray
Colour 9,$CCC      ' Light gray
Colour 10,$FFF     ' White

' Custom shades
Colour 11,$800     ' Dark red
Colour 12,$C00     ' Medium red
Colour 13,$F00     ' Bright red
```

### RGB Colour Mixing

| Colour | R | G | B | Hex |
|--------|---|---|---|-----|
| Black | 0 | 0 | 0 | $000 |
| Red | 15 | 0 | 0 | $F00 |
| Green | 0 | 15 | 0 | $0F0 |
| Blue | 0 | 0 | 15 | $00F |

| Magenta | 15 | 0 | 15 | $F0F |
| Cyan | 0 | 15 | 15 | $0FF |
| White | 15 | 15 | 15 | $FFF |
| Orange | 15 | 8 | 0 | $F80 |

**Creating shades:**
```amos
' Blue gradient
Colour 1,$00F      ' Bright blue
Colour 2,$00C      ' Medium-bright
Colour 3,$009      ' Medium
Colour 4,$006      ' Medium-dark
Colour 5,$003      ' Dark blue
```

## Understanding Hardware Acceleration

### What the Blitter Does

Every drawing command uses the Amiga's blitter:

```
Plot   → Blitter sets pixel
Draw   → Blitter draws line
Circle → Blitter draws arc segments
Bar    → Blitter fills rectangle
Box    → Blitter draws four lines
```

**CPU is free:** While blitter draws, CPU continues programme execution. True parallel processing!

### Blitter Line Algorithm

```amos
' This line:
Plot 10,10
Draw 200,150

' Triggers hardware Bresenham line algorithm
' Blitter calculates and draws all pixels
' CPU continues immediately
```

**Compare to C64:**
- C64: CPU draws each pixel manually (slow)
- Amiga: Blitter draws entire line (instant, CPU free)

### Performance Advantage

```amos
' Draw 1000 lines
For i=1 To 1000
  Plot Rnd(320),Rnd(256)
  Draw Rnd(320),Rnd(256)
Next i
```

**Amiga:** ~1 second (blitter-accelerated)
**C64:** ~30 seconds (CPU-drawn)

This is why Amiga games look so much smoother!

## Programme Structure

### Drawing and Capturing Workflow

```amos
' 1. INITIALIZE
Screen Open 0,320,256,32,Lowres
Curs Off: Flash Off: Cls 0

' 2. SET UP PALETTE
Colour 1,$F00
Colour 2,$0F0
Colour 3,$00F

' 3. DRAW GRAPHICS
Ink 1: Bar 0,0 To 31,31
Ink 2: Circle 16,16,12
Ink 3: Box 8,8 To 24,24

' 4. CAPTURE AS BOB
Get Bob 1,0,0 To 32,32

' 5. USE BOB
Cls 0
For x=0 To 288 Step 32
  Paste Bob x,100,1
Next x
```

This pattern creates reusable sprites with custom colours.

## Experiments

### Experiment 1: Colour Gradients

Create smooth colour transitions:

```amos
' Red to yellow gradient
For i=0 To 15
  Colour i+1,$F00+i*$010    ' Increase green
  Ink i+1
  Bar i*20,50 To (i+1)*20,150
Next i
```

### Experiment 2: Pattern Generator

Use nested loops for complex patterns:

```amos
' Geometric pattern
For x=0 To 300 Step 20
  For y=0 To 236 Step 20
    Ink (x+y)/10
    Box x,y To x+15,y+15
  Next y
Next x
```

### Experiment 3: Sprite Editor

Simple pixel editor:

```amos
' 16x16 sprite grid
For x=0 To 15
  For y=0 To 15
    Box x*16,y*16 To (x+1)*16,(y+1)*16
  Next y
Next x

' Click to draw pixels
Do
  If Mouse Click Then
    mx=X Mouse/16
    my=Y Mouse/16
    Ink 2
    Bar mx*16+1,my*16+1 To (mx+1)*16-1,(my+1)*16-1
  End If
Loop Until Inkey$<>""

' Capture result
Get Bob 1,0,0 To 256,256
```

**Technical Specifications:**

**Blitter Capabilities:**
- Three channels: A (source), B (source), C (destination)
- 16 logic operations (AND, OR, XOR, etc.)
- Line drawing with Bresenham algorithm
- Area fill with carry propagation
- 7.16 MHz operation (PAL)

**Colour System:**
- 4096 colours possible (12-bit RGB)
- 32 simultaneous in low-res (5 bitplanes)
- 16 simultaneous in high-res (4 bitplanes)
- Copper can change palette mid-screen (advanced)

**Historical Context:**

In 1985, the Amiga's colour capabilities were revolutionary:
- **PC (CGA):** 4 colours, 320×200
- **C64:** 16 colours (fixed palette)
- **Atari ST:** 512 colours, 16 simultaneous
- **Amiga:** 4096 colours, 32 simultaneous, programmable

The Amiga dominated graphics until VGA arrived in 1987.
