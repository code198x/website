# Lesson 011: Music Player

Build a complete music player using AMOS's Music Bank system. While Sam Play handles sound effects, Music plays full multi-channel compositions using all 4 Paula channels simultaneously.

## The One-Minute Tour

- **Music Bank** - Multi-track music file container
- **Music command** - Play/stop music tracks
- **Music variables** - Check playback status
- **Tempo control** - Adjust playback speed
- **Pattern-based** - Music stored as note patterns (not samples)
- **4-channel compositions** - Full soundtrack capability

## Example Programme

Here's an interactive music player:

```amos
' Music Player
Screen Open 0,320,256,16,Lowres
Curs Off: Flash Off: Cls 0

' Note: Would load music bank in real usage
' Music Bank Load "music.abk"

Locate 8,8: Print "MUSIC PLAYER"
Locate 10,6: Print "1-5: Play Track"
Locate 11,6: Print "S: Stop"
Locate 12,6: Print "Q: Quit"

track=0

Do
  k$=Upper$(Inkey$)

  If k$>="1" and k$<="5" Then
    track=Val(k$)
    Music track
  End If

  If k$="S" Then Music Stop
  If k$="Q" Then Exit

  ' Visual feedback
  If Music(1) Then
    Ink 2: Locate 14,10
    Print "Playing Track ";track
  Else
    Ink 1: Locate 14,10
    Print "Stopped       "
  End If

  Wait Vbl
Loop

Music Stop
Wait Key
```

**Run it:**
1. Load AMOS Professional
2. Load `music-player.amos`
3. Press F1 to run
4. Press 1-5 to select tracks
5. Press S to stop
6. Press Q to quit
7. Watch playback status

## Understanding Music Bank

### What is Music Bank?

**Music Bank vs Sam Play:**

| Feature | Sam Play | Music Bank |
|---------|----------|------------|
| Purpose | Sound effects | Music compositions |
| Channels | 1 at a time | All 4 simultaneously |
| Format | 8-bit PCM samples | Note patterns + instruments |
| Size | ~28KB per second | ~10KB per minute |
| Use case | Explosions, jumps | Background music, themes |

**Music Bank files (`.abk`):**
- Contain multiple music tracks
- Store note patterns (not audio samples)
- Include instrument definitions
- Tempo and timing information
- Loop points for continuous play

### How Music Works

**Pattern-based music:**
```
Track 1:
  Channel 0: C-4, D-4, E-4, F-4 (melody)
  Channel 1: C-3, C-3, C-3, C-3 (bass)
  Channel 2: --- (drums on channel 2)
  Channel 3: --- (drums on channel 3)

Paula plays all 4 channels in sync
```

Compare to:
- **MOD files** (Amiga tracker format)
- **MIDI** (but MIDI is notes only, MOD includes samples)
- **SID music** (C64 synthesizer programming)

**Advantage:** Music data is tiny. 3-minute song ≈ 30KB data + 200KB samples.

## Understanding Music Commands

### Music Bank Load

```amos
Music Bank Load "filename.abk"
```

**Loads music bank into memory:**
- Multiple tracks (1-N)
- Instrument samples
- Pattern data
- Tempo settings

**Example:**
```amos
Music Bank Load "game-music.abk"
' Now ready to play tracks 1-5
```

**File locations:**
- Same directory as AMOS program
- Specify full path if needed
- `.abk` extension required

### Music Command

```amos
Music track_number
```

**Plays music track:**
- `track_number`: Which track to play (1-N)
- Uses all 4 Paula channels
- Loops automatically (unless track says otherwise)
- Previous track stops automatically

**Examples:**
```amos
Music 1     ' Play track 1 (title screen)
Music 2     ' Play track 2 (level 1)
Music 3     ' Play track 3 (boss battle)
```

### Music Stop

```amos
Music Stop
```

**Stops current music:**
- Silences all 4 channels
- Playback position resets
- No fade out (instant stop)

**Common pattern:**
```amos
Music Stop
Wait 10
Music 2     ' Switch to next track
```

### Music Off

```amos
Music Off
```

**Disables music system:**
- Stops playback
- Frees music channels
- Use if you need channels for Sam Play

**Re-enable:**
```amos
Music On
```

## Understanding Music Variables

### Music(0) - Playback Position

```amos
position = Music(0)
```

**Returns:**
- Current pattern position
- Value: 0 to pattern length
- Updates continuously while playing

**Use for:**
```amos
' Wait for music to reach position 16
While Music(0)&lt;16
  Wait Vbl
Wend
```

### Music(1) - Playing Status

```amos
is_playing = Music(1)
```

**Returns:**
- `1` if music is playing
- `0` if stopped

**Use for:**
```amos
' Only update display if music playing
If Music(1) Then
  Print "Track: ";current_track
End If
```

### Example - Wait for Track End

```amos
Music 1
While Music(1)
  Wait Vbl
Wend
Print "Track finished"
```

## Understanding Tempo Control

### Tempo Command

```amos
Tempo speed
```

**Sets music playback speed:**
- `speed`: 1-255 (default is track's original tempo)
- Higher = faster playback
- Lower = slower playback
- 50 = 1 beat per second (typically)

**Examples:**
```amos
Tempo 50    ' Normal speed
Music 1

Tempo 100   ' Double speed (fast-forward)
Music 1

Tempo 25    ' Half speed (slow motion)
Music 1
```

### Tempo Use Cases

**Game speed adjustment:**
```amos
If difficulty=1 Then Tempo 40    ' Easy: slower music
If difficulty=2 Then Tempo 50    ' Normal
If difficulty=3 Then Tempo 60    ' Hard: faster music
```

**Dynamic music:**
```amos
' Speed up as timer runs out
Tempo 50-timer_remaining
```

## Understanding Audio Visualization

### Combining Sound and Graphics

```amos
Do
  ' Update visuals based on music
  If Music(1) Then
    ' Music playing: animated display
    Ink 2+Rnd(6)
    Circle 160,128,Rnd(50)+10
  Else
    ' Music stopped: static display
    Ink 1
    Locate 10,10: Print "Stopped"
  End If

  Wait Vbl
Loop
```

### Beat Detection

```amos
last_pos=0

Do
  current_pos=Music(0)

  ' Detect beat (position change)
  If current_pos<>last_pos Then
    ' Flash on beat
    Ink Rnd(15)+1
    Circle 160,128,30
  End If

  last_pos=current_pos
  Wait Vbl
Loop
```

### Spectrum Display

```amos
' Visualize 4 channels as bars
Do
  For c=0 To 3
    ' Sample channel activity (simplified)
    height=Rnd(100)+20

    Ink c+2
    Bar c*80,200 To (c+1)*80-10,200-height
  Next c

  Wait Vbl
Loop Until Music(1)=0
```

## Programme Structure

### Complete Music Player

```amos
' 1. INITIALIZE
Screen Open 0,320,256,16,Lowres
Curs Off: Flash Off: Cls 0
Setup_Palette
Music Bank Load "music.abk"

' 2. DISPLAY UI
Draw_Player_Interface

' 3. SETUP VARIABLES
track=1
playing=False

' 4. MAIN LOOP
Do
  ' Get input
  k$=Upper$(Inkey$)

  ' Process commands
  If k$>="1" and k$<="5" Then
    track=Val(k$)
    Music track
    playing=True
  End If

  If k$="S" Then
    Music Stop
    playing=False
  End If

  ' Update display
  Update_Status_Display[track,playing]

  ' Visual feedback
  If Music(1) Then
    Animate_Playing_Indicator
  End If

  ' Synchronize
  Wait Vbl
Loop Until k$="Q"

' 5. CLEANUP
Music Stop
```

## Experiments

### Experiment 1: Playlist

Create auto-advancing playlist:

```amos
Dim playlist(4)
playlist(0)=1: playlist(1)=2: playlist(2)=3: playlist(3)=1

index=0
Music playlist(index)

Do
  ' Check if track finished
  If Music(1)=0 Then
    Add index,1
    If index>3 Then index=0

    Music playlist(index)
    Print "Now playing: ";playlist(index)
  End If

  Wait Vbl
Loop Until Inkey$<>""
```

### Experiment 2: Volume Fade

Cross-fade between tracks:

```amos
' Fade out current track
For v=64 To 0 Step -4
  Vol 0,v: Vol 1,v: Vol 2,v: Vol 3,v
  Wait 5
Next v

Music Stop

' Switch track
Music 2

' Fade in new track
For v=0 To 64 Step 4
  Vol 0,v: Vol 1,v: Vol 2,v: Vol 3,v
  Wait 5
Next v
```

### Experiment 3: Music Synchronization

Sync game events to music beats:

```amos
Music 1
last_beat=0

Do
  beat=Music(0)/4  ' Beat every 4 positions

  If beat<>last_beat Then
    ' Spawn enemy on beat
    Create_Enemy
    Flash_Screen
  End If

  last_beat=beat
  Wait Vbl
Loop
```

**Technical Specifications:**

**Music Bank Format:**
- **Pattern data**: Note sequences for 4 channels
- **Instrument samples**: 8-bit PCM (reused across tracks)
- **Effect commands**: Volume, pitch bend, portamento
- **Loop points**: Seamless repeating sections
- **Tempo metadata**: Original playback speed

**Memory Usage:**
- Music data: ~10KB per minute
- Instrument samples: ~100-300KB (shared)
- Total: ~500KB for 5-track music bank

**Tracker Format Compatibility:**

AMOS music banks use a format similar to:
- **ProTracker** (`.mod` files)
- **NoiseTracker**
- **SoundTracker**

Can be created with:
- AMOS Music Bank editor
- ProTracker (with conversion)
- OctaMED (with export)

**Historical Context:**

**Amiga music revolution (1987-1992):**

Before Amiga:
- **C64 SID music**: Synthesized (legendary but synthetic)
- **PC speaker**: Beeps only
- **Apple II**: No music hardware

After Amiga:
- Sampled instruments (real piano, real drums)
- 4 simultaneous channels
- Tracker scene (thousands of musicians)
- "Demoscene" music competitions

**Famous Amiga musicians:**
- Chris Hülsbeck (Turrican, Apidya)
- David Whittaker (Shadow of the Beast)
- Jeroen Tel (Robocop 3)
- Tim Wright (Lemmings)

**Legacy:**
- Tracker format inspired FastTracker (PC), Renoise (modern)
- Demoscene music became underground electronic scene
- Sample-based music became standard (all modern games)
