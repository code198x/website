Welcome to Amiga programming! Unlike BASIC on other machines, the Amiga's power comes from AMOS Professional—a structured BASIC designed specifically for games. You'll work with screens, copper lists, blitter operations, and the legendary Paula sound chip. But first: open a screen and write some text.

Every AMOS program starts by opening a screen. The Amiga can have multiple screens layered on top of each other, each with different resolutions and colour depths. Let's create one screen and put text on it.

## The One-Minute Tour

- **AMOS Professional** is a game-focused BASIC with built-in sprite/music editors
- **Screen Open** creates a new display with specified width, height, colours, and resolution
- **Lowres** mode is 320×256 pixels (PAL) with up to 32 colours
- **Curs Off** hides the text cursor
- **Cls** clears the screen to a specified colour (0-31)
- **Ink** sets the text colour
- **Centre** displays centered text
- **Wait Key** pauses until a key is pressed

## Your First Amiga Program

Type this into AMOS Professional:

```amos
Rem ** Hello, Amiga World **
Rem ** Display text with colors **

' Set screen mode and colors
Screen Open 0,320,256,16,Lowres
Curs Off
Cls 0

' Set ink color and display text
Ink 14
Locate 10,12
Centre "HELLO, AMIGA!"

' Wait for mouse click
Wait Key
```

**Run this** by pressing F1 (or selecting Run from the menu).

The screen clears to black, then "HELLO, AMIGA!" appears in yellow, centered horizontally at row 12. The Amiga's clean, sharp display makes text look professional—even in BASIC.

## How This Works

### Opening a Screen

```amos
Screen Open 0,320,256,16,Lowres
```

This creates screen 0 with dimensions 320×256 pixels, 16 colours, in Lowres mode. The Amiga has several screen modes:

- **Lowres** = 320×256 (320×200 NTSC), up to 32 colours
- **Hires** = 640×256 (640×200 NTSC), up to 16 colours
- **HAM** = Hold-And-Modify, 4096 colours (special mode)

Screen 0 is the first screen. You can have multiple screens (0-7) stacked like layers. The number 16 means this screen uses 16 out of 32 possible colours (4 bitplanes).

**Why 16 colours?** Each bitplane doubles the colours: 1 plane = 2 colours, 2 planes = 4, 3 planes = 8, 4 planes = 16, 5 planes = 32. More bitplanes = more memory, slower blitter operations.

### Hiding the Cursor

```amos
Curs Off
```

The text cursor (that flashing block) disappears. You'll rarely want it visible in games. `Curs On` brings it back. Simple.

### Clearing the Screen

```amos
Cls 0
```

Cls fills the entire screen with colour 0 (usually black). The Amiga has 32 colours per screen (0-31), defined in a palette. AMOS sets up a default palette when you open a screen. We'll customize palettes in later lessons.

### Setting Text Colour

```amos
Ink 14
```

Ink sets the drawing colour for text. Colour 14 in the default AMOS palette is yellow. After setting Ink, all text operations (Print, Centre, Text) use that colour until you change it.

### Positioning and Centering Text

```amos
Locate 10,12
Centre "HELLO, AMIGA!"
```

Locate moves the text cursor to column 10, row 12 (each character cell is 8×8 pixels in lowres). Centre displays text centered on the current line. The Amiga has a proportional font, so Centre calculates the exact middle based on actual character widths—not fixed character counts like the C64 or Spectrum.

**Amiga quirk:** Text coordinates are in character cells, but graphics coordinates are in pixels. A 320-pixel-wide screen is 40 characters wide (320÷8=40).

### Waiting for Input

```amos
Wait Key
```

Wait Key stops the program until any key is pressed. Without this, the program would finish and return to the AMOS editor immediately—you'd barely see your text. AMOS also has `Wait Vbl` (wait for vertical blank) and `Wait n` (wait n 50ths of a second).

## Experiment: Different Colours

Change the Ink colour:

```amos
Ink 1   ; Try 0-15 (default palette)
```

**Default AMOS palette colours:**
- 0 = Black
- 1 = White
- 2 = Red
- 3 = Green
- 4 = Blue
- 5 = Yellow
- 6 = Magenta
- 7 = Cyan
- 8-15 = Variations/greys

Try different combinations:
```amos
Cls 2    ' Red background
Ink 1    ' White text
```

## Experiment: Multiple Lines

```amos
Locate 5,10
Centre "WELCOME TO"
Locate 5,12
Centre "THE AMIGA!"
Locate 5,14
Centre "THE FUTURE IS HERE"
```

Text appears on different rows. The Amiga screen has 32 rows (256÷8=32) and 40 columns (320÷8=40) in lowres mode.

## Experiment: Different Screen Sizes

```amos
Screen Open 0,640,256,4,Hires  ' High resolution
```

Hires mode gives you sharper text but fewer colours (4 vs 16). Try it—the text will look crisper but you lose colour depth.

## Quick Reference: AMOS Screen Modes

| Mode | Resolution | Max Colours | Notes |
|------|------------|-------------|-------|
| Lowres | 320×256 | 32 | Standard mode, 40 chars wide |
| Hires | 640×256 | 16 | Sharp text, 80 chars wide |
| HAM | 320×256 | 4096 | Special mode, slow |
| EHB | 320×256 | 64 | Extra Half-Brite mode |

## Quick Reference: AMOS Text Commands

| Command | Purpose | Parameters |
|---------|---------|------------|
| Screen Open | Create screen | screen,width,height,colours,mode |
| Curs Off/On | Hide/show cursor | - |
| Cls n | Clear to colour | 0-31 |
| Ink n | Set text colour | 0-31 |
| Locate x,y | Position cursor | column, row |
| Centre s$ | Centered text | string |
| Print s$ | Left-aligned text | string |
| Wait Key | Wait for keypress | - |

## Quick Reference: Screen Calculations

```
Lowres (320×256):
- Character width: 8 pixels
- Character height: 8 pixels
- Columns: 320 ÷ 8 = 40
- Rows: 256 ÷ 8 = 32

Hires (640×256):
- Character width: 8 pixels
- Character height: 8 pixels
- Columns: 640 ÷ 8 = 80
- Rows: 256 ÷ 8 = 32
```
