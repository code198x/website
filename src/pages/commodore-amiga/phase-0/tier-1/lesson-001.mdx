# Lesson 001: Hello, Amiga

Your first AMOS Professional program - an infinite counter demonstrating modern structured programming.

## The One-Minute Tour

- **AMOS Professional is NOT traditional BASIC** - no line numbers, compiled for speed
- **Structured syntax** with modern control flow (Repeat/Until, Procedures)
- **Comments use single quote** `'` not REM
- **Locate positions text** at row, column coordinates (0-based)
- **Fast execution** - internally compiled, not interpreted
- **Amiga-specific** - designed for OCS/ECS chipset features

## Example Programme

Here's your first AMOS Professional program:

```amos
' Lesson 001: Hello, Amiga
' Infinite counter demonstrating structured AMOS programming

' Initialize counter variable
count=0

' Infinite loop - runs until Ctrl+C pressed
Repeat
  count=count+1
  Locate 10,15
  Print count
Until False
```

**What it does:**
1. Creates a variable `count` and sets it to 0
2. Enters an infinite loop (Repeat...Until False)
3. Increments the counter each iteration
4. Positions cursor at row 10, column 15
5. Prints the current count
6. Repeats forever (until you press Ctrl+C)

**Run it:**
1. Load AMOS Professional on your Amiga
2. Type or load `hello-amiga.amos`
3. Press **F1** to run
4. Watch the numbers count up rapidly
5. Press **Ctrl+C** to stop

## Experiment: Variations

Try modifying the programme to explore AMOS features:

**Count by tens:**
```amos
count=count+10
```

**Count backwards:**
```amos
count=100
Repeat
  count=count-1
  Locate 10,15
  Print count
Until False
```

**Slower counting:**
```amos
Repeat
  count=count+1
  Locate 10,15
  Print count
  Wait Vbl    ' Wait for vertical blank (1/50 second on PAL)
Until False
```

**Colourful counter:**
```amos
Cls 0           ' Clear screen to colour 0 (black)
Repeat
  count=count+1
  Locate 10,15
  Ink 2         ' Set text colour to 2 (white)
  Print count
Until False
```

## Understanding AMOS Professional

### What Makes AMOS Different

Traditional BASIC (Commodore 64, BBC Micro):
```basic
10 REM COUNTER PROGRAM
20 LET COUNT = 0
30 PRINT COUNT
40 LET COUNT = COUNT + 1
50 GOTO 30
```

AMOS Professional (Amiga):
```amos
' Counter program
count=0
Repeat
  Print count
  count=count+1
Until False
```

**Key differences:**
- **No line numbers** - code flows naturally like modern languages
- **Structured loops** - Repeat/Until, Do/Loop, For/Next
- **Comments with '** instead of REM
- **Optional LET keyword** - just write `count=0`
- **Fast compiled execution** - AMOS compiles as you type
- **Modern syntax** - feels more like Pascal or C than 1980s BASIC

### The Locate Command

`Locate row,column` positions the text cursor on screen:

```amos
Locate 0,0      ' Top-left corner
Locate 10,15    ' Row 10, column 15
Locate 25,39    ' Bottom-right (in 40-column mode)
```

**Coordinates:**
- **Row:** 0-25 (26 rows in default text mode)
- **Column:** 0-39 (40 columns) or 0-79 (80 columns)
- **Origin:** Top-left is (0,0)

**Why use Locate?**
- Update numbers without screen flicker
- Create fixed UI elements (score, status)
- Draw ASCII art at precise positions
- Build text-based games and menus

### Repeat...Until Loops

The Repeat...Until structure tests condition AFTER each iteration:

```amos
Repeat
  ' This code ALWAYS runs at least once
Until condition
```

**Common patterns:**

**Infinite loop:**
```amos
Repeat
  ' Game main loop
Until False    ' Never true, runs forever
```

**Count to target:**
```amos
Repeat
  count=count+1
  Print count
Until count=100    ' Stops when count reaches 100
```

**Wait for input:**
```amos
Repeat
  key$=Inkey$
Until key$<>""    ' Repeat until a key is pressed
```

### Variables

AMOS Professional variables don't need declaration:

```amos
score=0          ' Integer variable
name$="Player"   ' String variable ($ suffix)
pi#=3.14159      ' Floating-point variable (# suffix)
```

**Variable types:**
- **Integer** (no suffix) - whole numbers, -32768 to 32767
- **String** ($ suffix) - text, up to 255 characters
- **Floating-point** (# suffix) - decimal numbers

**Why AMOS Was Revolutionary:**

In 1990, AMOS Professional brought modern structured programming to the Amiga:
- **No line numbers** like GW-BASIC required
- **Compiled speed** approaching hand-coded assembly
- **Built-in sprite/BOB editors** for graphics
- **Music and sound** commands for Paula audio chip
- **Procedure libraries** for code reuse

Games like *Striker Manager*, *Wings of Death*, and *Die Aliens Die* were written entirely in AMOS Professional.

### Essential Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `Cls 0` | Clear screen to colour | `Cls 0` (black) |

### Loop Structures

| Structure | When to Use |
|-----------|-------------|
| `Repeat...Until` | Test condition after loop body |
| `Do...Loop` | Infinite loop with manual exit |
| `While...Wend` | Test condition before loop body |
| `For...Next` | Count with known iterations |
