# Lesson 006: Data Bank

Store entire question banks in arrays for random access, search functionality, and flexible quiz systems.

## The One-Minute Tour

- **Dim statement** - Declare arrays for structured data
- **Zero-based indexing** - Arrays start at 0 (question$(0) is first)
- **Parallel arrays** - Two arrays with related data (question$(i) and answer$(i))
- **Loading arrays** - Read Data into memory for random access
- **Count tracking** - Variable tracks how many items actually loaded
- **Instr function** - Find substring within string for search
- **Sentinel values** - "END" marker stops array loading

## Example Programme

Here's a simplified 5-question data bank with search:

```amos
' Simple Data Bank
Dim question$(10)
Dim answer$(10)
count=0

' Load questions
For i=0 To 9
  Read q$,a$
  If q$="END" Then Exit
  question$(i)=q$
  answer$(i)=a$
  Add count,1
Next i

' Menu
Do
  Cls 0
  Print "DATA BANK - ";count;" questions loaded"
  Print "1. Take Quiz"
  Print "2. Search"
  Print "3. Quit"
  Input choice

  If choice=1 Then TakeQuiz
  If choice=2 Then DoSearch
  If choice=3 Then Exit
Loop

End

Procedure TakeQuiz
  score=0
  For i=0 To count-1
    Print question$(i)
    Input response$
    If response$=answer$(i) Then Add score,1
  Next i
  Print "Score: ";score;"/";count
  Wait Key
End Proc

Procedure DoSearch
  Input "Search for: ";search$
  found=0

  For i=0 To count-1
    If Instr(question$(i),search$)>0 Then
      Print question$(i)
      Add found,1
    End If
  Next i

  Print "Found ";found;" questions"
  Wait Key
End Proc

' Question data
Data "Capital of France?","Paris"
Data "Planets?","8"
Data "Boiling point (°C)?","100"
Data "Continents?","7"
Data "Moon landing year?","1969"
Data "END","END"
```

**Run it:**
1. Load AMOS Professional
2. Load `data-bank.amos`
3. Press F1 to run
4. Watch questions load into arrays
5. Choose option:
   - Take full quiz (all 15 questions)
   - Search for questions
   - Browse all questions

## Understanding Arrays

### What Are Arrays?

Arrays are collections of variables accessed by index number:

```amos
' Without arrays (tedious):
question1$="Capital of France?"
question2$="Planets?"
question3$="Boiling point?"

' With arrays (scalable):
Dim question$(3)
question$(0)="Capital of France?"
question$(1)="Planets?"
question$(2)="Boiling point?"
```

**Key advantage:** Use loops to process hundreds of items with simple code.

### Declaring Arrays

```amos
Dim arrayName(size)      ' Number array
Dim arrayName$(size)     ' String array
```

**Important:**
- `Dim question$(20)` creates 21 elements: question$(0) through question$(20)
- AMOS arrays are zero-based by default (unlike C64 BASIC which starts at 1)

### Accessing Array Elements

```amos
Dim scores(5)

scores(0)=100        ' First element
scores(1)=85         ' Second element
scores(5)=70         ' Last element (sixth element)

' Use variable as index
For i=0 To 5
  Print scores(i)    ' Access each element
Next i
```

### Zero-Based vs One-Based

**C64 BASIC (one-based):**
```basic
10 DIM Q$(5)         ' Creates Q$(1) to Q$(5)
20 FOR I=1 TO 5      ' Start at 1
30 PRINT Q$(I)
40 NEXT I
```

**AMOS (zero-based):**
```amos
Dim Q$(5)            ' Creates Q$(0) to Q$(5)
For I=0 To 5         ' Start at 0
  Print Q$(I)
Next I
```

**Why zero-based?** Matches most modern languages (C, JavaScript, Python). Makes array math simpler (`count-1` is last index).

## Understanding Parallel Arrays

### What Are Parallel Arrays?

Two arrays where elements at same index are related:

```amos
Dim country$(3)
Dim capital$(3)

country$(0)="France"    : capital$(0)="Paris"
country$(1)="UK"        : capital$(1)="London"
country$(2)="Spain"     : capital$(2)="Madrid"
```

**Relationship:** `country$(i)` and `capital$(i)` belong together.

### Why Parallel Arrays?

**Without (mixed data, confusing):**
```amos
Data "France","Paris","UK","London","Spain","Madrid"
Read c1$,cap1$,c2$,cap2$,c3$,cap3$    ' Messy!
```

**With parallel arrays (organized):**
```amos
Data "France","Paris"
Data "UK","London"
Data "Spain","Madrid"

For i=0 To 2
  Read country$(i),capital$(i)    ' Clean loading
Next i

' Easy access
For i=0 To 2
  Print country$(i);" -> ";capital$(i)
Next i
```

### Parallel Array Pattern

```amos
Dim question$(20)      ' Array 1
Dim answer$(20)        ' Array 2 (parallel)
count=0                ' Tracks how many pairs

For i=0 To 19
  Read q$,a$
  If q$="END" Then Exit
  question$(i)=q$      ' Store in same index
  answer$(i)=a$        ' Parallel relationship
  Add count,1
Next i

' Use together
For i=0 To count-1
  Print question$(i)
  Input response$
  If response$=answer$(i) Then Print "Correct!"
Next i
```

## Understanding Array Loading

### The Loading Pattern

```amos
Dim array$(20)         ' 1. Declare array (max size)
count=0                ' 2. Initialize counter

For i=0 To 19          ' 3. Loop through possible indices
  Read value$          ' 4. Read next value
  If value$="END" Then Exit    ' 5. Stop at sentinel
  array$(i)=value$     ' 6. Store in array
  Add count,1          ' 7. Track actual count
Next i

' Now use array with count
For i=0 To count-1     ' 8. Only loop through loaded items
  Print array$(i)
Next i
```

**Why sentinel value?** Array has 20 spaces, but you might only load 15 items. "END" marker tells programme when to stop reading.

### Count Variable

```amos
Dim question$(20)      ' Max 20 questions
count=0                ' Actual number loaded

' Load until "END"
For i=0 To 19
  Read q$,a$
  If q$="END" Then Exit
  question$(i)=q$
  answer$(i)=a$
  Add count,1          ' count now = actual items
Next i

' Use count as limit
For i=0 To count-1     ' Only iterate loaded items
  Print question$(i)
Next i

Print "Total questions: ";count
```

**Why?** Separates array capacity (20) from actual usage (maybe 15). Makes code flexible.

## Understanding Search with Instr

### The Instr Function

Finds substring within string:

```amos
position=Instr(text$,search$)

' Returns:
'   0 = not found
'   1+ = position where found (1-based!)
```

**Examples:**
```amos
text$="The quick brown fox"

position=Instr(text$,"quick")   ' Returns 5 (starts at position 5)
position=Instr(text$,"slow")    ' Returns 0 (not found)
position=Instr(text$,"fox")     ' Returns 17
```

### Search Pattern

```amos
For i=0 To count-1
  If Instr(question$(i),search$)>0 Then
    ' Found match - search$ appears in question$(i)
    Print question$(i)
  End If
Next i
```

**How it works:**
1. Loop through all questions
2. Check if search term appears in each question
3. If `Instr` returns >0, there's a match
4. Display matching questions

### Case Sensitivity

```amos
search$="france"
question$="Capital of France?"

If Instr(question$,search$)>0 Then
  Print "Found!"         ' Won't match - "france" ≠ "France"
End If

' Case-insensitive search (convert both to uppercase):
search$=Upper$("france")           ' "FRANCE"
question$=Upper$("Capital of France?")   ' "CAPITAL OF FRANCE?"

If Instr(question$,search$)>0 Then
  Print "Found!"         ' Now matches!
End If
```

## Programme Structure

### Data Bank Architecture

```amos
' 1. DECLARATIONS
Dim question$(20)
Dim answer$(20)
count=0

' 2. INITIALIZATION (load data)
For i=0 To 19
  Read q$,a$
  If q$="END" Then Exit
  question$(i)=q$
  answer$(i)=a$
  Add count,1
Next i

' 3. MAIN MENU LOOP
Do
  ' Display options
  ' Get choice
  ' Call procedures
Loop

' 4. PROCEDURES
Procedure FullQuiz
  ' Iterate all questions
End Proc

Procedure SearchQuestions
  ' Search array with Instr
End Proc

Procedure BrowseAll
  ' Display all with pagination
End Proc

' 5. DATA
Data "question","answer"
Data "END","END"
```

### Why This Order?

1. **Declarations first** - Arrays must exist before use
2. **Load immediately** - Get data into arrays before menu
3. **Menu uses arrays** - All procedures access loaded data
4. **Procedures are stateless** - Don't reload data each time
5. **Data at end** - Traditional BASIC convention

## Experiments

### Experiment 1: Random Question Order

Shuffle array indices for random quiz:

```amos
Procedure RandomQuiz
  ' Create array of indices
  Dim indices(count-1)
  For i=0 To count-1
    indices(i)=i
  Next i

  ' Shuffle indices
  For i=count-1 To 1 Step -1
    j=Rnd(i+1)
    temp=indices(i)
    indices(i)=indices(j)
    indices(j)=temp
  Next i

  ' Ask questions in random order
  For i=0 To count-1
    idx=indices(i)
    Print question$(idx)
    Input response$
    If response$=answer$(idx) Then Add score,1
  Next i
End Proc
```

### Experiment 2: Category System

Add third array for categories:

```amos
Dim question$(20)
Dim answer$(20)
Dim category$(20)    ' New array
count=0

' Load with categories
For i=0 To 19
  Read q$,a$,cat$
  If q$="END" Then Exit
  question$(i)=q$
  answer$(i)=a$
  category$(i)=cat$
  Add count,1
Next i

' Search by category
Procedure SearchByCategory[wanted$]
  For i=0 To count-1
    If category$(i)=wanted$ Then
      Print question$(i)
    End If
  Next i
End Proc

' Data with categories
Data "Capital of France?","Paris","Geography"
Data "Planets?","8","Science"
Data "2+2?","4","Maths"
```

### Experiment 3: Edit Questions

Allow adding/modifying questions at runtime:

```amos
Procedure AddQuestion
  If count>=20 Then
    Print "Array full!"
    Wait Key
    Exit
  End If

  Input "New question: ";question$(count)
  Input "Answer: ";answer$(count)
  Add count,1
  Print "Added! Total: ";count
  Wait Key
End Proc

Procedure EditQuestion[index]
  Print "Current: ";question$(index)
  Input "New question: ";question$(index)
  Input "New answer: ";answer$(index)
  Print "Updated!"
  Wait Key
End Proc
```

**Why Zero-Based Arrays?**

In 1990, AMOS chose zero-based indexing to align with:
- **Amiga memory addressing** - Memory addresses start at 0
- **C language convention** - Amiga system programming uses C
- **Efficient array math** - `array$(count-1)` is last element

**C64 BASIC vs AMOS Arrays:**

| Feature | C64 BASIC | AMOS |
|---------|-----------|------|
| Index start | 1 | 0 |
| Declaration | `DIM A(10)` | `Dim A(10)` |
| Size | 10 elements (1-10) | 11 elements (0-10) |
| Loop | `FOR I=1 TO 10` | `For I=0 To 10` |

Modern equivalent: Most languages (Python, JavaScript, Java, C++) use zero-based arrays. AMOS was ahead of its time.

## Quick Reference

### Array Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `Dim array(size)` | Declare number array | `Dim scores(10)` |
| `Dim array$(size)` | Declare string array | `Dim names$(20)` |
| `array(index)` | Access element | `score=scores(5)` |
| `array(index)=value` | Assign element | `scores(5)=100` |

### Array Patterns

**Loading from Data:**
```amos
For i=0 To size-1
  Read array$(i)
  Add count,1
Next i
```

**Iterating all elements:**
```amos
For i=0 To count-1
  Print array$(i)
Next i
```

**Searching:**
```amos
For i=0 To count-1
  If array$(i)=target$ Then
    ' Found at index i
  End If
Next i
```

### String Functions

| Function | Purpose | Example |
|----------|---------|---------|
| `Instr(text$,search$)` | Find substring position | `pos=Instr(q$,"year")` |
| `Upper$(text$)` | Convert to uppercase | `s$=Upper$("hello")` |
| `Lower$(text$)` | Convert to lowercase | `s$=Lower$("HELLO")` |
| `Len(text$)` | String length | `size=Len(question$)` |

### Array Indexing

```amos
Dim array$(10)           ' Creates 11 elements
' Valid indices: 0 to 10
array$(0)                ' First element
array$(10)               ' Last element
array$(count-1)          ' Last loaded element
```
