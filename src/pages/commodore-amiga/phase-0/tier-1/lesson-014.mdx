# Lesson 014: Collect & Score

**Build a complete game.** Combine movement, collision, and timer mechanics to create a full gameplay loop with win/lose conditions, score tracking, and restart capability using procedures.

## The One-Minute Tour

- **Timer counts down automatically** - `Timer=30*50` sets 30 seconds (1500 ticks)
- **50 ticks = 1 second** - PAL frame rate (50Hz)
- **Win condition** - Check if score reaches target
- **Lose condition** - Check if timer reaches zero
- **Exit breaks loop** - Immediate game over when condition met
- **Procedure structure** - Enables restart without reloading
- **Game state** - Use Exit + checks to determine outcome
- **Complete loop** - Input → movement → collision → win/lose → display

## Example: Time Trial Collection

```amos
Screen Open 0,320,256,32,Lowres
Curs Off: Flash Off

Procedure PlayGame
  Cls 0

  ' Create player sprite (blue square)
  Ink 2
  Bar 0,0 To 15,15
  Get Bob 1,0,0 To 16,16
  Cls 0

  ' Create collectible sprite (yellow circle)
  Ink 3
  Circle 8,8,7
  Get Bob 2,0,0 To 16,16
  Cls 0

  ' Player starting position
  px=150: py=120
  Bob 1,px,py,1

  ' Create 10 collectibles
  For i=2 To 11
    Bob i,Rnd(280)+20,Rnd(220)+20,2
  Next i

  ' Game variables
  score=0
  target=100  ' Need 100 points to win
  Timer=30*50 ' 30 seconds

  ' === MAIN GAME LOOP ===
  Do
    ' INPUT
    If Jleft(1) Then Dec px,2
    If Jright(1) Then Add px,2
    If Jup(1) Then Dec py,2
    If Jdown(1) Then Add py,2

    ' Boundary checking
    If px&lt;0 Then px=0
    If px>304 Then px=304
    If py&lt;0 Then py=0
    If py>240 Then py=240

    ' MOVEMENT
    Bob 1,px,py,1

    ' COLLISION
    hit=Col(1)
    If hit>1 Then
      Bob Off hit
      Add score,10
      Sam Play 0,1  ' Collection sound
    End If

    ' DISPLAY
    Locate 0,0
    Print "Score: ";score;" / ";target;" "
    Locate 0,1
    Print "Time: ";Timer/50;" sec "

    ' WIN CONDITION
    If score>=target Then Exit

    ' LOSE CONDITION
    If Timer&lt;=0 Then Exit

    ' SYNCHRONIZE
    Wait Vbl
    Bob Update
  Loop

  ' === GAME OVER ===
  ' Hide all BOBs
  For i=1 To 11
    Bob Off i
  Next i

  Cls 0
  Locate 10,12

  ' Determine outcome
  If score>=target Then
    Ink 2  ' Green
    Print "YOU WIN!"
  Else
    Ink 1  ' Red
    Print "TIME'S UP!"
  End If

  Locate 9,14
  Ink 4  ' Yellow
  Print "Final Score: ";score

  Locate 8,16
  Ink 1
  Print "Press any key..."

  Wait Key
End Proc

' Start game
PlayGame
```

**What's happening:**
1. **Procedure PlayGame** - Encapsulates entire game (enables restart)
2. **Timer=30*50** - 30 second countdown (1500 ticks @ 50Hz)
3. **target=100** - Win by collecting 10 items (10 points each)
4. **Exit breaks loop** - Immediately when win/lose condition met
5. **After loop** - Check which condition caused exit, show result

**Try it:** Collect all items before time runs out. Notice countdown creates urgency.

## Timer Deep Dive

**Timer mechanics:**
```amos
Timer = 1500     ' Set to 1500 ticks
' Timer automatically decrements:
' Frame 1: Timer=1499
' Frame 2: Timer=1498
' ...
' Frame 1500: Timer=0
```

**Converting ticks to seconds:**
```amos
' PAL Amiga = 50 frames/second
seconds = 30
Timer = seconds * 50  ' = 1500 ticks

' Display seconds remaining:
Print Timer/50         ' Shows: 30, 29, 28...
```

**Fractional seconds:**
```amos
' Show tenths of seconds
Print Timer/5          ' Shows: 300, 299, 298...
' Or:
Print (Timer/50);".";(Timer Mod 50)/5
' Shows: 30.0, 29.9, 29.8...
```

**Multiple timers:**
```amos
' AMOS only has ONE Timer variable
' For multiple timers, use your own:
gameTimer = Timer      ' Copy current Timer
powerupTimer = 50*5    ' 5 second countdown

Do
  Dec powerupTimer,1   ' Manual countdown
  If powerupTimer&lt;=0 Then
    ' Power-up expired
    powerupTimer = 50*5  ' Reset
  End If
Loop
```

## Win/Lose Condition Architecture

**Standard pattern:**
```amos
Do
  ' ... gameplay ...

  ' Check ALL win conditions
  If score>=target Then Exit
  If enemiesDefeated>=10 Then Exit

  ' Check ALL lose conditions
  If lives&lt;=0 Then Exit
  If Timer&lt;=0 Then Exit
Loop

' After loop, determine which condition:
If score>=target or enemiesDefeated>=10 Then
  Print "VICTORY!"
Else
  Print "DEFEAT!"
End If
```

**Why Exit instead of variable?**
```amos
' WRONG: Variable approach (less efficient)
gameOver=0
Do
  If score>=target Then gameOver=1
  If Timer&lt;=0 Then gameOver=2
Loop Until gameOver>0

' RIGHT: Exit approach (cleaner)
Do
  If score>=target Then Exit
  If Timer&lt;=0 Then Exit
Loop
```

Exit is faster and clearer - loop terminates immediately.

## Procedure Benefits for Game Structure

**Without procedure:**
```amos
' Main program
score=0
Timer=30*50
Do
  ' gameplay
Loop

' Game over
Print "GAME OVER"
' CAN'T RESTART - would need to reload entire program
End
```

**With procedure:**
```amos
Procedure PlayGame
  score=0
  Timer=30*50
  Do
    ' gameplay
  Loop
  Print "GAME OVER"
  Wait Key
End Proc

' Menu system
Do
  Cls 0
  Print "1. Play"
  Print "2. Quit"
  k$=Inkey$
  If k$="1" Then PlayGame  ' Can call again and again
  If k$="2" Then End
Loop
```

**Advantages:**
- Variables auto-reset each call
- Easy to add menu system
- Practice mode (restart quickly)
- Can pass parameters (difficulty)

## Game State Management

**State variable approach:**
```amos
' States: 0=menu, 1=playing, 2=game over, 3=victory
gameState = 0

Do
  If gameState=0 Then
    ' Menu display
    If k$="1" Then gameState=1
  End If

  If gameState=1 Then
    ' Gameplay
    If score>=target Then gameState=3
    If Timer&lt;=0 Then gameState=2
  End If

  If gameState=2 Then
    ' Game over screen
    If k$<>"" Then gameState=0
  End If

  If gameState=3 Then
    ' Victory screen
    If k$<>"" Then gameState=0
  End If
Loop
```

**Why state machines?** Complex games need multiple modes (pause, shop, inventory). State variable controls which code runs.

## In Game Use: Arcade Score Attack

**Complete arcade structure:**
```amos
Procedure ArcadeGame
  lives=3
  score=0
  level=1

  Do While lives>0
    ' Play one level
    result = PlayLevel(level)

    If result=1 Then
      ' Level complete
      Add score,1000*level  ' Bonus
      Add level,1
    Else
      ' Level failed
      Dec lives,1
    End If
  Loop

  ' Final score display
  Print "GAME OVER"
  Print "Final Score: ";score
  Print "Levels Cleared: ";level-1
End Proc
```

## From the Vault

**Timer accuracy:**
- PAL Amiga = 50.0Hz (exact)
- NTSC Amiga = 59.94Hz (NTSC video standard)
- Timer tracks VBL interrupts (frame-perfect)
- No drift over time (hardware clock)

**Arcade conventions:**
- **Time trial** = beat clock (1970s-80s standard)
- **Score attack** = maximize points (1980s competitive)
- **Survival** = last as long as possible (modern endless)

## Quick Reference

### Timer Commands
| Command | Purpose | Example |
|---------|---------|---------|
| `Timer=value` | Set timer | `Timer=30*50` |
| `Timer` | Read timer | `If Timer&lt;=0` |
| `50 ticks` | 1 second | `Timer/50` shows seconds |

### Game Flow Control
| Command | Purpose | Use Case |
|---------|---------|----------|
| `Exit` | Break from Do loop | Win/lose conditions |
| `Wait Key` | Pause for input | Game over screen |
| `Procedure` | Encapsulate game | Enable restart |

### Condition Patterns
| Pattern | Code | Purpose |
|---------|------|---------|
| Win check | `If score>=target Then Exit` | Victory |
| Lose check | `If Timer&lt;=0 Then Exit` | Defeat |
| Post-loop | `If score>=target Then...` | Determine outcome |

### Display Formatting
| Technique | Code | Result |
|-----------|------|--------|
| Right-align | `Locate 12,0: Print score` | Clean HUD |
| Color code | `Ink 2/Ink 1` based on value | Visual urgency |
| Progress bar | For loop with characters | Visual feedback |
