# Lesson 010: Paula Sound

Meet Paula - the Amiga's revolutionary 4-channel audio chip. While other computers beep and squawk, Paula delivers CD-quality stereo sound with zero CPU overhead.

## The One-Minute Tour

- **Paula chip** - 4 independent 8-bit PCM audio channels
- **Sam Play** - Play sound samples on any channel
- **Built-in samples** - 40 pre-loaded sounds (drums, bass, effects)
- **Stereo output** - Channels 0,2 left / 1,3 right
- **DMA audio** - Hardware playback, CPU free
- **8-bit PCM** - Pulse Code Modulation samples

## Example Programme

Here's a simple 4-channel sound demo:

```amos
' Paula Sound Demo
Screen Open 0,320,256,2,Lowres
Curs Off: Flash Off: Cls 0

Locate 5,10: Print "PAULA SOUND DEMO"
Locate 7,8: Print "Press keys 1-4"

Do
  k$=Inkey$

  ' Channel 0 (left)
  If k$="1" Then Sam Play 0,1

  ' Channel 1 (right)
  If k$="2" Then Sam Play 1,5

  ' Channel 2 (left)
  If k$="3" Then Sam Play 2,10

  ' Channel 3 (right)
  If k$="4" Then Sam Play 3,15

  If k$=" " Then Exit
Loop

Wait Key
```

**Run it:**
1. Load AMOS Professional
2. Load `paula-sound.amos`
3. Press F1 to run
4. Press keys 1-4 to hear different channels
5. Press SPACE to quit
6. Notice stereo separation!

## Understanding Paula

### The Paula Audio Chip

**Paula (Portia/Agnus/Denise's sister chip):**
- 4 independent audio channels
- 8-bit signed PCM samples
- 28.37 kHz sample rate (PAL)
- DMA-driven (no CPU overhead)
- Hardware mixing
- Stereo routing

**Channel routing:**
```
Channel 0 → Left speaker
Channel 1 → Right speaker
Channel 2 → Left speaker
Channel 3 → Right speaker
```

### What's PCM?

**PCM (Pulse Code Modulation):**
```
Digital audio representation:
- Sample: Single amplitude measurement
- 8-bit: 256 possible values (-128 to +127)
- 28.37 kHz: 28,370 samples per second

Result: Near-CD quality audio (CD is 16-bit, 44.1kHz)
```

**Compare to other computers (1985):**
- **C64**: 3-channel synthesizer (SID chip, generated tones)
- **ZX Spectrum**: 1-channel beeper (toggled speaker)
- **Atari ST**: 3-channel synthesizer (Yamaha PSG)
- **Amiga**: 4-channel sampled audio (Paula)

Paula plays recorded sounds. The others generate tones.

### How DMA Audio Works

**Traditional (C64, Spectrum):**
```
CPU: Load byte → Write to sound register → Repeat 28,370 times/second
Result: 100% CPU usage for audio
```

**Paula (Amiga):**
```
CPU: "Paula, play this sample on channel 0"
Paula: "On it!" (plays via DMA, CPU continues working)
Result: 0% CPU usage for audio
```

**DMA (Direct Memory Access):** Hardware reads memory and outputs audio independently. True parallel processing!

## Understanding Sam Play

### Basic Syntax

```amos
Sam Play channel,sample
```

**Parameters:**
- `channel`: Which audio channel (0-3)
- `sample`: Sample number to play (1-40 built-in)

**Examples:**
```amos
Sam Play 0,1     ' Play sample 1 on channel 0 (left)
Sam Play 1,5     ' Play sample 5 on channel 1 (right)
Sam Play 2,10    ' Play sample 10 on channel 2 (left)
Sam Play 3,15    ' Play sample 15 on channel 3 (right)
```

### Built-in Samples

AMOS Professional includes 40 pre-loaded samples:

| Range | Content | Examples |
|-------|---------|----------|
| 1-10 | Drums & Percussion | Kick, snare, hi-hat, cymbal |
| 11-20 | Bass sounds | Bass drum, tom, low thump |
| 21-30 | Melodic | Synth, chords, effects |
| 31-40 | Sound effects | Explosions, zaps, bleeps |

**Experiment:** Try different sample numbers to hear the variety!

### Simultaneous Playback

```amos
' Play all 4 channels at once
Sam Play 0,1     ' Left: kick drum
Sam Play 1,5     ' Right: snare
Sam Play 2,10    ' Left: bass
Sam Play 3,15    ' Right: cymbal

' All play simultaneously!
```

This is Paula's magic. Four independent sounds at once.

## Understanding Volume Control

### Vol Command

```amos
Vol channel,volume
```

**Parameters:**
- `channel`: Audio channel (0-3)
- `volume`: Loudness (0-64, where 64 is maximum)

**Examples:**
```amos
Vol 0,64    ' Channel 0: Maximum volume
Vol 1,32    ' Channel 1: Half volume
Vol 2,16    ' Channel 2: Quarter volume
Vol 3,0     ' Channel 3: Muted

Sam Play 0,1    ' Plays at set volume
```

**Default volume:** 64 (maximum)

### Volume Patterns

```amos
' Fade in
For v=0 To 64 Step 4
  Vol 0,v
  Sam Play 0,1
  Wait 5
Next v

' Fade out
For v=64 To 0 Step -4
  Vol 0,v
  Sam Play 0,1
  Wait 5
Next v
```

## Understanding Sample Banks

### Loading External Samples

```amos
Sam Bank Load "sounds.abk"
```

**Sample banks (`.abk` files):**
- Created with AMOS Sample Bank editor
- Can contain hundreds of samples
- Stored in chip RAM
- Loaded before use

**After loading:**
```amos
Sam Bank Load "explosions.abk"
Sam Play 0,1    ' Play first sample from bank
Sam Play 1,2    ' Play second sample from bank
```

### Creating Your Own Samples

**Sample sources:**
- Record from microphone
- Digitize vinyl/tape
- Use tracker software (ProTracker, OctaMED)
- Sample other Amiga games (legally!)
- Use sample CDs

**Sample requirements:**
- Format: 8-bit signed PCM
- Rate: Any (Paula resamples)
- Length: Limited by chip RAM (512KB standard)

## Understanding Sam Stop

### Stopping Playback

```amos
Sam Stop channel
```

**Examples:**
```amos
Sam Stop 0      ' Stop channel 0
Sam Stop 1      ' Stop channel 1

' Stop all channels
For c=0 To 3
  Sam Stop c
Next c
```

**Use case:** Stop looping samples or long sounds

## Programme Structure

### Interactive Sound Demo

```amos
' 1. INITIALIZE
Screen Open 0,320,256,2,Lowres
Curs Off: Flash Off: Cls 0

' 2. DISPLAY UI
Print "Sound Demo"
Print "1-4: Play channels"
Print "Q: Quit"

' 3. MAIN LOOP
Do
  k$=Inkey$

  ' Map keys to channels
  If k$="1" Then Sam Play 0,1
  If k$="2" Then Sam Play 1,5
  If k$="3" Then Sam Play 2,10
  If k$="4" Then Sam Play 3,15

  ' Quit condition
  If k$="q" or k$="Q" Then Exit
Loop

' 4. CLEANUP (optional)
For c=0 To 3
  Sam Stop c
Next c
```

This pattern works for any interactive audio application.

## Experiments

### Experiment 1: Drum Machine

Create a simple rhythm pattern:

```amos
' Basic drum loop
Do
  Sam Play 0,1    ' Kick
  Wait 25
  Sam Play 1,5    ' Snare
  Wait 25
  Sam Play 0,1    ' Kick
  Wait 25
  Sam Play 3,10   ' Hi-hat
  Wait 25
Loop Until Inkey$<>""
```

**Wait timing:** 50 units = 1 second (PAL), so 25 = 0.5 seconds

### Experiment 2: Stereo Panning

Move sound between left and right:

```amos
' Play on left
Sam Play 0,1
Wait 50

' Play on right
Sam Play 1,1
Wait 50

' Play on both
Sam Play 0,1
Sam Play 1,1
Wait 50
```

### Experiment 3: Volume Envelope

Create attack-decay-sustain-release:

```amos
' Attack (0 → 64)
For v=0 To 64 Step 8
  Vol 0,v
  Wait 2
Next v

Sam Play 0,1

' Decay (64 → 32)
For v=64 To 32 Step -4
  Vol 0,v
  Wait 3
Next v

' Sustain (hold at 32)
Wait 50

' Release (32 → 0)
For v=32 To 0 Step -4
  Vol 0,v
  Wait 5
Next v
```

**Technical Specifications:**

**Paula Audio Chip:**
- Part number: 8364 (Agnus/Paula combo in A500)
- 4 independent DMA channels
- 8-bit signed samples
- Sample rates: 3.5 kHz to 28.37 kHz (PAL) / 28.8 kHz (NTSC)
- 6-bit volume control per channel (0-63, AMOS extends to 0-64)
- Hardware low-pass filter (optional, controlled by CIA)

**Memory Usage:**
- Samples stored in chip RAM (512KB standard Amiga)
- 1 second of audio ≈ 28KB
- Built-in 40 samples ≈ 150KB
- External banks load on demand

**Historical Context:**

In 1985, Paula's capabilities were revolutionary:

**Other computers:**
- **C64 (1982)**: SID chip, 3 synthesized channels, needs CPU programming
- **Apple II (1977)**: 1-bit speaker toggle, CPU-driven
- **ZX Spectrum (1982)**: 1-bit beeper, CPU-driven
- **Atari ST (1985)**: Yamaha PSG, 3 synthesized channels

**Amiga (1985):**
- 4 channels of sampled audio
- DMA (zero CPU overhead)
- 8-bit quality (arcade-level)
- Stereo output

**Result:** Amiga game soundtracks sounded like arcade games or Commodore 64 SID music, while being easier to create (just record and play).

**Famous Amiga audio:**
- "Turrican" series (Chris Hülsbeck)
- "Shadow of the Beast" (David Whittaker)
- "Xenon 2" (Bomb the Bass)

These were sampled music and sound effects, not synthesized.
