# Lesson 004: Quiz Master

Simple quiz programme using Data statements - your first data-driven application.

## The One-Minute Tour

- **Data statements** store question/answer pairs
- **Read command** retrieves data sequentially
- **Sequential access** - data items read in order, one at a time
- **Mixed data types** - strings and numbers in same Data line
- **Else If** - multiple conditional branches
- **Score tracking** - accumulate correct answers across questions

## Example Programme

Here's a complete five-question quiz:

```amos
' Lesson 004: Quiz Master
' Simple quiz using Data statements

' Initialize score
score=0
total=5

Cls 0
Locate 3,10
Print "=== QUIZ MASTER ==="
Locate 5,5
Print "Answer 5 questions"
Locate 6,5
Print "Press any key to start"
Wait Key

' Question 1
Cls 0
Locate 5,5
Read question$
Read answer
Print question$
Locate 7,5
Input guess
If guess=answer Then
  Locate 10,5
  Ink 2
  Print "Correct!"
  Add score,1
Else
  Locate 10,5
  Ink 3
  Print "Wrong! Answer was: ";answer
End If
Wait 150

' ... questions 2-5 follow same pattern ...

' Show final score
Cls 0
Locate 10,10
Ink 1
Print "Your score: ";score;"/";total
Locate 12,10
If score=total Then
  Ink 2
  Print "Perfect score!"
Else If score>=3 Then
  Ink 2
  Print "Well done!"
Else
  Ink 3
  Print "Keep practising!"
End If

Wait Key

' Question data
Data "What is 5 + 3?",8
Data "What is 10 - 4?",6
Data "What is 7 * 2?",14
Data "What is 15 / 3?",5
Data "What is 12 + 8?",20
```

**Run it:**
1. Load AMOS Professional
2. Load `quiz-master.amos`
3. Press F1 to run
4. Answer five maths questions
5. View your final score

## Understanding Data Statements

### What Are Data Statements?

Data statements store values that your programme can read later:

```amos
Data "Hello",42,"World",3.14
```

**Key features:**
- Can appear anywhere in programme (usually at end)
- Mix strings and numbers freely
- No line numbers needed (unlike C64 BASIC)
- Values separated by commas
- Read in order from first to last

### The Read Command

`Read` retrieves the next value from Data:

```amos
Read name$        ' Read string
Read age          ' Read number
Read city$        ' Read another string
```

**Important:** Read moves through Data sequentially. Once you've read a value, the next Read gets the next value. You can't go backwards without Restore (lesson 006).

### Data for Question/Answer Pairs

Perfect for quiz programmes:

```amos
' Two values per question: question text, correct answer
Data "Capital of France?","Paris"
Data "2 + 2 = ?",4
Data "Amiga CPU?","68000"

' Read question and answer together
Read question$
Read answer$      ' String answer
' or
Read question$
Read answer       ' Numeric answer
```

## Understanding Else If

### Multiple Conditions

Check several conditions in sequence:

```amos
If score=5 Then
  Print "Perfect!"
Else If score>=3 Then
  Print "Good!"
Else
  Print "Keep trying!"
End If
```

**How it works:**
1. Check first condition (`score=5`)
2. If TRUE → execute that block, skip rest
3. If FALSE → check next condition (`score>=3`)
4. If TRUE → execute that block, skip rest
5. If all FALSE → execute Else block (if present)

**Without Else If** (nested):
```amos
If score=5 Then
  Print "Perfect!"
Else
  If score>=3 Then
    Print "Good!"
  Else
    Print "Keep trying!"
  End If
End If
```

Else If is cleaner and avoids deep nesting.

## Programme Structure

### Pattern for Each Question

```amos
' 1. Clear screen
Cls 0

' 2. Read question data
Locate 5,5
Read question$
Read answer

' 3. Display question
Print question$

' 4. Get user answer
Locate 7,5
Input guess

' 5. Check answer and update score
If guess=answer Then
  Locate 10,5
  Ink 2
  Print "Correct!"
  Add score,1
Else
  Locate 10,5
  Ink 3
  Print "Wrong! Answer was: ";answer
End If

' 6. Pause before next question
Wait 150
```

This pattern repeats for each question. In lesson 005, we'll learn loops to avoid repetition!

**Why Data Statements?**

In 1990, data-driven programmes were revolutionary:
- **Before:** Hard-code every value in programme logic
- **With Data:** Separate content from code
- **Benefit:** Easy to modify questions without changing programme structure

Modern equivalent: JSON files, databases. Same concept: data separate from code.

## Quick Reference

### Data Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `Data value,value,...` | Store data | `Data "Question",42` |
| `Read variable` | Get next data value | `Read answer` |
| `Restore` | Reset to first data | `Restore` (L006) |

### Data Rules

- Define Data anywhere (usually at end of programme)
- Values separated by commas
- Mix strings and numbers
- Strings need quotes if they contain spaces or commas
- Read in order from first Data to last

### Common Patterns

```amos
' Question/answer pair
Data "Question text",answer_value
Read question$
Read answer

' Multiple values per record
Data "Name",age,city$
Read name$
Read age
Read city$

' All strings
Data "Red","Green","Blue"
Read colour1$
Read colour2$
Read colour3$
```
