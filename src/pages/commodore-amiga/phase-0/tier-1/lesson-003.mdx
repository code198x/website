# Lesson 003: Dungeon Quest

Complete text adventure game with procedures and state management - your first real game!

## The One-Minute Tour

- **Procedures** are named code blocks (`Proc...End Proc`)
- **State variables** track room, inventory, score
- **Game loop** uses `Do...Loop Until` with exit condition
- **Procedure calls** execute by name (no GOSUB, no brackets)
- **Multiple conditionals** check state and respond appropriately
- **Add command** increments variables (`Add score,10`)

## Example Programme

Here's a complete three-room text adventure:

```amos
' Lesson 003: Dungeon Quest
' Complete text adventure with procedures and state management

' Game state variables
room=1
has_key=0
score=0
playing=True

' Main game loop
Do
  Cls 0

  ' Display current room
  If room=1 Then Room1
  If room=2 Then Room2
  If room=3 Then Room3

  ' Display status
  Locate 20,2
  Print "Score: ";score
  Locate 21,2
  If has_key=1 Then Print "You have the golden key"

  ' Get command
  Locate 23,2
  Input "Command (N/S/T/Q): ";cmd$

  ' Process command
  If cmd$="N" or cmd$="n" Then Add room,1
  If cmd$="S" or cmd$="s" Then Add room,-1
  If cmd$="T" or cmd$="t" Then TakeTreasure
  If cmd$="Q" or cmd$="q" Then playing=False

  ' Keep room in valid range
  If room>3 Then room=3
  If room<1 Then room=1

Loop Until playing=False

' Game over
Cls 0
Locate 10,10
Print "Thanks for playing! Final score: ";score
Wait Key

' Room procedures
Procedure Room1
  Locate 5,5
  Print "=== Dark Cave Entrance ==="
  Locate 7,5
  Print "You stand at the entrance to a"
  Locate 8,5
  Print "mysterious dungeon. Cold air"
  Locate 9,5
  Print "flows from the depths."
  Locate 11,5
  Print "Exits: North"
End Proc

Procedure Room2
  Locate 5,5
  Print "=== Treasure Chamber ==="
  Locate 7,5
  Print "A vast chamber filled with"
  Locate 8,5
  Print "glittering treasures!"
  Locate 10,5
  If has_key=0 Then
    Print "You see a golden key on a pedestal."
  Else
    Print "The pedestal is empty."
  End If
  Locate 12,5
  Print "Exits: North, South"
End Proc

Procedure Room3
  Locate 5,5
  Print "=== Dragon's Lair ==="
  Locate 7,5
  If has_key=1 Then
    Print "The golden key unlocks the"
    Print "treasure chest! You win!"
    Add score,100
  Else
    Print "A massive treasure chest sits here,"
    Locate 9,5
    Print "but it's locked tight."
  End If
  Locate 12,5
  Print "Exits: South"
End Proc

Procedure TakeTreasure
  If room=2 and has_key=0 Then
    has_key=1
    Add score,10
    Locate 18,5
    Ink 2
    Print "You take the golden key!"
  Else
    Locate 18,5
    Ink 3
    Print "Nothing to take here."
  End If
  Wait 100
End Proc
```

**Run it:**
1. Load AMOS Professional
2. Load `dungeon-quest.amos`
3. Press F1 to run
4. Use commands to explore:
   - **N** - Move north
   - **S** - Move south
   - **T** - Take item
   - **Q** - Quit game

**The Goal:** Collect the key from Room 2, then unlock the treasure in Room 3!

## Understanding Procedures

### Defining Procedures

Procedures organize code into reusable blocks:

```amos
Procedure Name
  ' Code goes here
End Proc
```

**Rules:**
- Define procedures AFTER your main programme code
- Name can be any valid AMOS identifier
- No parameters in basic AMOS (use global variables)
- All variables are global (procedures can access any variable)

**Example:**
```amos
' Main programme
score=0
AddPoints
Print "Score: ";score
Wait Key

' Procedure definition
Procedure AddPoints
  score=score+10
End Proc
```

### Calling Procedures

Execute a procedure by writing its name:

```amos
Room1           ' Call Room1 procedure
TakeTreasure    ' Call TakeTreasure procedure
DrawScreen      ' Call DrawScreen procedure
```

**NOT like traditional BASIC:**
- No GOSUB command
- No RETURN command
- No line numbers
- No brackets after name

**This is modern:** More like Pascal or C than 1980s BASIC.

### Why Use Procedures?

**Organization:** Keep related code together:
```amos
Procedure DrawMenu
  Cls 0
  Locate 5,10
  Print "1. New Game"
  Locate 7,10
  Print "2. Load Game"
  Locate 9,10
  Print "3. Quit"
End Proc
```

**Reuse:** Call the same code multiple times:
```amos
DrawMenu      ' Show menu
Input choice
If choice=1 Then NewGame
DrawMenu      ' Show menu again
```

**Clarity:** Makes main loop readable:
```amos
Do
  DrawRoom
  DrawStatus
  GetCommand
  ProcessCommand
Loop
```

## Understanding Game State

### State Variables

Track what's happening in your game:

```amos
room=1          ' Current room number
has_key=0       ' Boolean: 0=no, 1=yes
score=0         ' Current score
playing=True    ' Game is running
```

**Boolean values:**
- Use `0` for False
- Use `1` for True
- Or use `True` and `False` keywords

### Checking State

Use state variables in conditionals:

```amos
If has_key=1 Then
  Print "You have the key!"
End If

If room=3 and has_key=1 Then
  Print "You win!"
  Add score,100
End If
```

**AND operator:** Both conditions must be true
**OR operator:** Either condition can be true

### Updating State

Change variables as things happen:

```amos
' Player moves north
Add room,1

' Player picks up key
has_key=1
Add score,10

' Player uses item
items=items-1
```

## Understanding the Game Loop

### Do...Loop Until Structure

The main game loop runs until exit condition:

```amos
playing=True

Do
  ' Display current state
  ' Get player input
  ' Update game state
Loop Until playing=False
```

**How it works:**
1. Set `playing=True` to start
2. Run loop body (display, input, update)
3. Check condition after each iteration
4. When user quits, set `playing=False`
5. Loop exits, programme continues

### Alternative: Infinite Loop with Exit

```amos
Do
  ' Game code
  If cmd$="Q" Then Exit
Loop
```

`Exit` immediately leaves the loop.

## The Add Command

AMOS has a shortcut for incrementing:

```amos
' Traditional way:
score=score+10

' AMOS shortcut:
Add score,10
```

**Works with any value:**
```amos
Add lives,1        ' Increment by 1
Add score,50       ' Add 50 points
Add room,-1        ' Move backwards (south)
```

**Why use Add?**
- Shorter syntax
- Slightly faster execution
- More readable intent ("add to score" vs "score equals score plus")

```amos
  Locate 5,5
  Print "=== Wizard's Tower ==="
  Locate 7,5

  Locate 11,5

End Proc

' Update room display

  Cls 0
  If room=1 Then Room1
  If room=2 Then Room2
  If room=3 Then Room3
  If room=4 Then Room4
  If room=5 Then Room5
  ' ... rest of game loop

  ' Update boundaries

Loop Until playing=False
```

### Experiment 2: Multiple Items

Track several inventory items:

```amos
has_key=0
has_sword=0
has_torch=0

' In room procedures:
If has_torch=0 Then
  Print "It's too dark to see!"
End If

If has_sword=1 Then
  Print "Your sword gleams in the light."
End If
```

### Experiment 3: Combat System

Add health and combat:

```amos
health=100
monster_health=50

Procedure Fight
  Locate 15,5
  Print "A monster attacks!"
  Locate 17,5
  Input "Attack (Y/N)? ";action$

  If action$="Y" or action$="y" Then
    If has_sword=1 Then
      Add monster_health,-20
      Print "You strike with your sword!"
    Else
      Add monster_health,-10
      Print "You punch the monster!"
    End If

    If monster_health<=0 Then
      Print "Monster defeated!"
      Add score,50
    Else
      ' Monster strikes back
      Add health,-15
      Print "The monster hits you!"
    End If
  End If
  Wait 200
End Proc
```

## Quick Reference

### Procedure Syntax

```amos
' Define procedure
Procedure Name
  ' Code here
End Proc

' Call procedure
Name
```

### Game Loop Patterns

```amos
' Do...Loop Until (test at end)
Do
  ' Code
Loop Until condition

' Do...Loop with Exit (infinite)
Do
  ' Code
  If condition Then Exit
Loop

' While...Wend (test at start)
While condition
  ' Code
Wend
```

### State Management

| Task | Code |
|------|------|
| Boolean variable | `has_key=0` or `has_key=1` |
| Check state | `If has_key=1 Then` |
| Multiple checks | `If room=2 and has_key=0 Then` |
| Increment | `Add score,10` |
| Decrement | `Add health,-5` |

### Common Commands

| Command | Purpose | Example |
|---------|---------|---------|
| `Do...Loop` | Main game loop | See above |
| `Procedure` | Define code block | `Procedure Name` |
| `End Proc` | End procedure | `End Proc` |
| `Add var,n` | Increment variable | `Add score,10` |
| `Exit` | Leave current loop | `If done Then Exit` |
