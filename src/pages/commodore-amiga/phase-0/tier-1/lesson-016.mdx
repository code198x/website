# Lesson 016: Amiga Arcade

**The complete game.** Every concept from lessons 1-15 combined into one playable arcade experience: procedures, arrays, BOBs, collision, input, sound, timers, AI, difficulty progression - professional game architecture.

## The One-Minute Tour

- **Menu system** - Clean navigation, procedure-based
- **Complete game loop** - Input → movement → AI → collision → display → sync
- **Player sprite** - Joystick control, boundary checking
- **Enemy AI** - Multiple enemies with chase behaviour

- **Timer countdown** - 60 seconds to collect all items

## The Complete Game

```amos
' Amiga Arcade
' Complete game combining all Phase 0 Tier 1 concepts

Screen Open 0,320,256,32,Lowres
Curs Off: Flash Off

' === MENU PROCEDURE ===
Procedure Menu
  Cls 0

  ' Set up palette
  Colour 1,$FFF    ' White
  Colour 2,$0F0    ' Green
  Colour 3,$F00    ' Red
  Colour 4,$FF0    ' Yellow

  ' Display title
  Ink 4
  Locate 9,8: Print "=== AMIGA ARCADE ==="

  Ink 1
  Locate 11,10: Print "Avoid red enemies!"
  Locate 12,10: Print "Collect yellow items!"

  Locate 14,12: Print "1. Start Game"
  Locate 15,12: Print "2. Quit"

  ' Menu loop
  Do
    k$=Inkey$
    If k$="1" Then PlayGame
    If k$="2" Then End
  Loop
End Proc

' === GAME PROCEDURE ===
Procedure PlayGame
  Cls 0

  ' Create player sprite (blue square)
  Ink 2
  Bar 0,0 To 15,15
  Ink 14
  Circle 8,8,5
  Get Bob 1,0,0 To 16,16
  Cls 0

  ' Create enemy sprite (red square)
  Ink 1
  Box 0,0 To 15,15
  Bar 2,2 To 13,13
  Get Bob 2,0,0 To 16,16
  Cls 0

  ' Create collectible sprite (yellow circle)
  Ink 3
  Circle 8,8,7
  Ink 6
  Circle 8,8,3
  Get Bob 3,0,0 To 16,16
  Cls 0

  ' Initialize entity arrays
  Dim ex(8),ey(8),ea(8)      ' Enemies (up to 8)
  Dim cx(10),cy(10),ca(10)   ' Collectibles (up to 10)

  ' Player starting position
  px=150
  py=120
  Bob 1,px,py,1

  ' Create enemies (start with 5)
  enemyCount=5
  enemySpeed=1
  For i=1 To enemyCount
    ex(i)=Rnd(280)+20
    ey(i)=Rnd(220)+20
    ea(i)=1
    Bob i+10,ex(i),ey(i),2    ' BOBs 11-18
  Next i

  ' Create collectibles (10 items)
  For i=1 To 10
    cx(i)=Rnd(280)+20
    cy(i)=Rnd(220)+20
    ca(i)=1
    Bob i+20,cx(i),cy(i),3    ' BOBs 21-30
  Next i

  ' Game variables
  score=0
  lives=3
  Timer=60*50    ' 60 seconds

  ' === MAIN GAME LOOP ===
  Do
    ' PLAYER MOVEMENT
    If Jleft(1) Then Dec px,3
    If Jright(1) Then Add px,3
    If Jup(1) Then Dec py,3
    If Jdown(1) Then Add py,3

    ' Boundary checking
    If px&lt;0 Then px=0
    If px>304 Then px=304
    If py&lt;0 Then py=0
    If py>240 Then py=240

    Bob 1,px,py,1

    ' ENEMY AI (chase player)
    For i=1 To enemyCount
      If ea(i)=1 Then
        If ex(i)<px Then Add ex(i),enemySpeed
        If ex(i)>px Then Dec ex(i),enemySpeed
        If ey(i)<py Then Add ey(i),enemySpeed
        If ey(i)>py Then Dec ey(i),enemySpeed
        Bob i+10,ex(i),ey(i),2
      End If
    Next i

    ' COLLISION DETECTION
    hit=Col(1)

    ' Collect items
    If hit>=21 and hit&lt;=30 Then
      itemNum=hit-20
      If ca(itemNum)=1 Then
        ca(itemNum)=0
        Bob Off hit
        Add score,10
        Sam Play 0,1    ' Collect sound
      End If
    End If

    ' Hit enemy (lose life)
    If hit>=11 and hit&lt;=10+enemyCount Then
      enemyNum=hit-10
      If ea(enemyNum)=1 Then
        ea(enemyNum)=0
        Bob Off hit
        Dec lives,1
        Sam Play 1,5    ' Hit sound

        ' Game over if no lives left
        If lives&lt;=0 Then Exit
      End If
    End If

    ' DIFFICULTY PROGRESSION
    ' Increase enemy speed at 50 points
    If score>=50 and enemySpeed=1 Then
      enemySpeed=2
      Locate 10,10
      Print "ENEMIES FASTER!"
      Wait 100
    End If

    ' DISPLAY HUD
    Locate 0,0
    Print "Score: ";score;" "
    Locate 0,1
    Print "Lives: ";lives;" "
    Locate 0,2
    Print "Time: ";Timer/50;" "

    ' TIME UP (lose condition)
    If Timer&lt;=0 Then Exit

    ' SYNCHRONIZE
    Wait Vbl
    Bob Update
  Loop

  ' === GAME OVER ===
  ' Hide all BOBs
  For i=1 To 30
    Bob Off i
  Next i

  Cls 0

  ' Display result
  Locate 10,10
  If lives>0 Then
    Ink 2
    Print "TIME'S UP!"
  Else
    Ink 1
    Print "GAME OVER!"
  End If

  Locate 9,12
  Ink 4
  Print "Final Score: ";score

  Locate 8,14
  Ink 1
  Print "Press any key..."

  Wait Key

  ' Return to menu
  Menu
End Proc

' === START GAME ===
Menu
```

**What's happening:**

**Menu System:**
1. Colour palette setup for visual polish
2. Title and instructions
3. Key-based navigation
4. Calls PlayGame or End

**Game Setup:**
5. Three sprite types: player, enemy, collectible
6. Parallel arrays: ex/ey/ea (enemies), cx/cy/ca (collectibles)
7. BOB numbering: 1=player, 11-18=enemies, 21-30=collectibles

**Game Loop:**
8. Player input with boundary checking
9. Enemy AI: chase player if active (ea(i)=1)
10. Collision: distinguish items (21-30) from enemies (11-18)
11. Score for collection, lives for hits
12. Difficulty: enemySpeed increases at 50 points
13. HUD: score, lives, timer
14. Win/lose: Exit on lives&lt;=0 or Timer&lt;=0

**Game Over:**
15. Hide all BOBs
16. Display outcome and final score
17. Return to Menu (procedure recursion)

**Try it:** Collect 10 items before timer runs out, avoid 5 enemies, watch difficulty increase.

## Game Architecture Breakdown

**Procedure structure:**
```
┌─────────────────┐
│      Menu       │ ← Entry point
│  (Procedure)    │
└────────┬────────┘
         │
         ↓
┌─────────────────┐
│   PlayGame      │ ← Main game
│  (Procedure)    │
│                 │
│ 1. Setup        │
│ 2. Game Loop    │
│ 3. Game Over    │
└────────┬────────┘
         │
         ↓ (restart)
┌─────────────────┐
│  Back to Menu   │ ← Recursive call
└─────────────────┘
```

**Why procedures?**
- **Encapsulation** - Each function self-contained
- **Restart capability** - Call PlayGame again
- **Variable scope** - score/lives reset each call
- **Professional structure** - Matches commercial games

## Entity Management System

**BOB allocation strategy:**
```
BOB 1       → Player (always active)
BOBs 11-18  → Enemies (8 slots, ea(i) tracks state)
BOBs 21-30  → Collectibles (10 slots, ca(i) tracks state)
```

**Why separated ranges?**
```amos
hit = Col(1)

' Easy range checking:
If hit>=21 and hit&lt;=30 Then
  ' Definitely a collectible
End If

If hit>=11 and hit&lt;=18 Then
  ' Definitely an enemy
End If
```

**Array-to-BOB mapping:**
```amos
' Enemies:
Array index i → BOB number i+10
  ea(1) → BOB 11
  ea(2) → BOB 12
  ...

' Collectibles:
Array index i → BOB number i+20
  ca(1) → BOB 21
  ca(2) → BOB 22
  ...
```

**Collision resolution:**
```amos
' Enemy collision:
hit=Col(1)              ' Returns BOB 11-18
enemyNum = hit-10       ' Convert to array index 1-8
ea(enemyNum) = 0        ' Mark inactive

' Item collision:
hit=Col(1)              ' Returns BOB 21-30
itemNum = hit-20        ' Convert to array index 1-10
ca(itemNum) = 0         ' Mark collected
```

## Game Loop Pattern (Universal)

**The standard structure:**
```amos
Do
  ' 1. INPUT
  Read joystick/keyboard
  Apply to movement variables

  ' 2. PLAYER UPDATE
  Move player
  Boundary checking
  Update BOB position

  ' 3. ENEMY UPDATE
  For each active enemy
    AI logic (chase/patrol/flee)
    Update position
    Update BOB
  Next

  ' 4. COLLISION
  hit = Col(player)
  Check hit range
  Apply effects (score/damage)

  ' 5. GAME LOGIC
  Update score/lives/timer
  Check win/lose conditions
  Apply difficulty changes

  ' 6. DISPLAY
  Update HUD
  Show status messages

  ' 7. SYNCHRONIZE
  Wait Vbl
  Bob Update
Loop Until game_over
```

**This pattern scales:**
- Add more enemy types → expand step 3
- Add power-ups → expand step 4
- Add boss → special case in step 3
- Add multiplayer → duplicate step 1-2

**Professional games use this exact structure.**

## Difficulty Progression Mechanics

**Enemy speed increase:**
```amos
enemySpeed = 1         ' Start value

' At milestone:
If score>=50 and enemySpeed=1 Then
  enemySpeed = 2       ' Increase
  Print "ENEMIES FASTER!"
  Wait 100             ' Brief pause
End If

' In AI loop:
If ex(i)<px Then Add ex(i),enemySpeed
```

**Why check enemySpeed=1?**
- Prevents multiple triggers
- Only increases once at 50 points
- Additional milestones need separate checks

**Alternative progression ideas:**
```amos
' Add more enemies
If score>=100 and enemyCount=5 Then
  enemyCount=8
  For i=6 To 8
    ea(i)=1
    ex(i)=Rnd(280)+20
    ey(i)=Rnd(220)+20
    Bob On i+10
    Bob i+10,ex(i),ey(i),2
  Next i
End If

' Reduce player speed
If score>=75 and playerSpeed=3 Then
  playerSpeed=2
End If

' Decrease timer rate (harder to survive)
If score>=50 Then
  Dec Timer,2    ' Counts down 2× as fast
Else
  Dec Timer,1    ' Normal countdown
End If
```

## Lives System Implementation

**Tracking lives:**
```amos
lives = 3              ' Starting lives

' On enemy hit:
If hit>=11 and hit&lt;=18 Then
  Dec lives,1
  Sam Play 1,5         ' Hit sound

  ' Immediate game over check
  If lives&lt;=0 Then Exit
End If
```

**Why immediate Exit?**
- Prevents player from continuing with 0 lives
- Clean game over (no extra frames)
- Player sees final collision before exit

**Visual feedback options:**
```amos
' Invincibility frames after hit:
If invincible>0 Then
  Dec invincible,1
  ' Flash player (Bob Off/On alternating)
  If invincible Mod 10 &lt;5 Then
    Bob Off 1
  Else
    Bob On 1
  End If
End If

' Only check collision when vulnerable:
If invincible&lt;=0 Then
  hit=Col(1)
  If hit>=11 and hit&lt;=18 Then
    Dec lives,1
    invincible=50*2    ' 2 seconds
  End If
End If
```

## HUD Display Architecture

**Information hierarchy:**
```amos
Locate 0,0: Print "Score: ";score;" "
Locate 0,1: Print "Lives: ";lives;" "
Locate 0,2: Print "Time: ";Timer/50;" "
```

**Why spaces after?**
- Clears previous digits
- Prevents "Score: 1100" becoming "Score: 1009" visually
- Clean erase-and-redraw

**Color-coded urgency:**
```amos
' Score (always yellow)
Ink 4
Locate 0,0
Print "Score: ";score;" "

' Lives (red when low)
If lives&lt;=1 Then
  Ink 1    ' Red warning
Else
  Ink 2    ' Green safe
End If
Locate 0,1
Print "Lives: ";lives;" "

' Timer (red when urgent)
If Timer/50&lt;=10 Then
  Ink 1    ' Red: hurry!
Else
  Ink 4    ' Yellow: normal
End If
Locate 0,2
Print "Time: ";Timer/50;" "
```

## Audio Feedback System

**Event-driven sound:**
```amos
' Collection:
If hit>=21 and hit&lt;=30 Then
  Bob Off hit
  Add score,10
  Sam Play 0,1    ' Channel 0, Sample 1 (pickup)
End If

' Damage:
If hit>=11 and hit&lt;=18 Then
  Bob Off hit
  Dec lives,1
  Sam Play 1,5    ' Channel 1, Sample 5 (explosion)
End If
```

**Why different channels?**
- Prevents sound cutting off
- Allows simultaneous effects
- Channel 0=left, Channel 1=right (stereo)

**Professional enhancement:**
```amos
' Background music during gameplay:
Music 1              ' Start background track

' Stop music on game over:
Music Stop

' Menu music:
Music 2
```

## Game Over and Results

**Outcome determination:**
```amos
' After Exit from loop:
Cls 0
Locate 10,10

' Check WHY loop exited:
If lives>0 Then
  ' Timer ran out (lives still remain)
  Ink 2
  Print "TIME'S UP!"
Else
  ' Lives depleted
  Ink 1
  Print "GAME OVER!"
End If

' Always show final score:
Locate 9,12
Ink 4
Print "Final Score: ";score
```

**Both conditions matter:**
- `lives&lt;=0` → killed by enemies
- `Timer&lt;=0` → time expired
- One causes Exit, other checked after
