## What You Need

To develop for the Amiga, you need:

1. **An assembler** - converts 68000 assembly to machine code
2. **Disk tools** - creates ADF disk images
3. **An emulator** - runs your programs

## Installing the Assembler

We use **vasm** with Motorola syntax for 68000 assembly.

### macOS (Homebrew)

```bash
brew install vasm
```

### Linux

```bash
# Build from source
wget http://www.compilers.de/vasm.tar.gz
tar xzf vasm.tar.gz
cd vasm
make CPU=m68k SYNTAX=mot
sudo cp vasmm68k_mot /usr/local/bin/
```

### Windows

Download from [compilers.de/vasm](http://www.compilers.de/vasm.html).

### Verify Installation

```bash
vasmm68k_mot
```

You should see usage information.

## Installing Disk Tools

We use **amitools** for creating ADF disk images.

```bash
pip3 install amitools
```

Verify:

```bash
xdftool
```

## Installing the Emulator

We recommend **FS-UAE**.

### macOS

```bash
brew install --cask fs-uae
```

### Linux

```bash
# Ubuntu/Debian
sudo add-apt-repository ppa:fengestad/stable
sudo apt update
sudo apt install fs-uae
```

### Windows

Download from [fs-uae.net](https://fs-uae.net/).

### Kickstart ROM

FS-UAE requires Kickstart ROM files. You can:
- Dump from a real Amiga
- Purchase from [Amiga Forever](https://www.amigaforever.com/)
- Use AROS replacements (limited compatibility)

Place ROM files in `~/Documents/FS-UAE/Kickstarts/`.

## Your First Program

Create a file called `hello.asm`:

```asm
CUSTOM          equ $dff000
ExecBase        equ 4
OldOpenLibrary  equ -408
CloseLibrary    equ -414
LoadView        equ -222
WaitTOF         equ -270

            section code,code

start:
            move.l  ExecBase,a6
            lea     gfxname(pc),a1
            jsr     OldOpenLibrary(a6)
            tst.l   d0
            beq     .exit
            move.l  d0,a6

            ; Clear display
            sub.l   a1,a1
            jsr     LoadView(a6)
            jsr     WaitTOF(a6)

            ; Set background to blue
            move.w  #$00f,$180+CUSTOM

            ; Wait for mouse
.wait:
            btst    #6,$bfe001
            bne     .wait

            ; Exit
            move.l  a6,a1
            move.l  ExecBase,a6
            jsr     CloseLibrary(a6)
.exit:
            moveq   #0,d0
            rts

gfxname:    dc.b    "graphics.library",0
```

## Building

```bash
vasmm68k_mot -Fhunkexe -kick1hunks -o hello -nosym hello.asm
```

## Creating a Bootable Disk

```bash
# Create disk, format, add boot block, add program
xdftool hello.adf create + format "Hello" ofs + boot install boot1x + write hello

# Create startup-sequence
mkdir -p s
echo "hello" > s/startup-sequence
xdftool hello.adf + makedir s + write s/startup-sequence s/startup-sequence

# Set executable permission
xdftool hello.adf + protect hello +e
```

## Running

```bash
fs-uae --floppy_drive_0=hello.adf
```

You should see a blue screen. Click the left mouse button to exit.

## Key Addresses

| Address | Purpose |
|---------|---------|
| $DFF000 | Custom chip base |
| $BFE001 | CIA-A (mouse buttons, etc.) |
| $DFF180 | COLOR00 (background) |
| $DFF080 | COP1LC (copper list address) |
