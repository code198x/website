# Your First Genesis Assembly Program

Welcome to Genesis assembly! You're about to write your first Motorola 68000 assembly program for Sega's 16-bit console.

## What You'll Build

A program that changes the background colour. When you run it, you'll see a solid colour filling the screen.

## The Code

Save this as `hello.asm`:

```nasm
; Your first Genesis assembly program
; Changes background colour

        org     $000000

; Genesis ROM header
        dc.l    $00FFFE00       ; Initial stack pointer
        dc.l    Start           ; Entry point

        ; Fill rest of header (simplified)
        org     $000100
        dc.b    "SEGA GENESIS    " ; Console name
        dc.b    "(C)SEGA 2024.JAN" ; Copyright
        dc.b    "HELLO GENESIS                           " ; Domestic name
        dc.b    "HELLO GENESIS                           " ; International name
        dc.b    "GM 00000000-00"  ; Serial number
        dc.w    $0000             ; Checksum
        dc.b    "J               " ; I/O support
        dc.l    $000000,$0FFFFF   ; ROM start/end
        dc.l    $FF0000,$FFFFFF   ; RAM start/end
        dc.b    "            "     ; Extra memory
        dc.b    "            "     ; Modem
        dc.b    "                                        " ; Notes
        dc.b    "JUE             " ; Region

        org     $000200

Start:
        ; Disable interrupts
        move.w  #$2700,sr

        ; Write to VDP (Video Display Processor)
        ; Set background colour to blue

        ; VDP control port
        lea     $C00004,a0
        ; VDP data port
        lea     $C00000,a1

        ; Set up CRAM (colour RAM) write
        move.w  #$C000,d0        ; CRAM write command
        move.w  d0,(a0)          ; Send to VDP control

        ; Write colour (Genesis uses RGB, 3 bits each)
        move.w  #$0F00,d0        ; Blue colour (0RGB)
        move.w  d0,(a1)          ; Write to VDP data

loop:   bra     loop             ; Loop forever
```

## How to Assemble and Run It

### Using VASM (68k assembler):
```bash
vasmm68k_mot -Fbin -o hello.bin hello.asm
```

This creates `hello.bin`.

### Run in Gens or BlastEm emulator:
```bash
blastem hello.bin
```

Or in emulator: File → Load ROM → hello.bin

## What Just Happened?

- **ROM header:** Genesis requires extensive header data for console to boot
- **`move.w #$2700,sr`:** Sets status register to disable interrupts (supervisor mode)
- **`lea $C00004,a0`:** Loads VDP control port address into address register A0
- **`move.w #$C000,d0`:** Prepares CRAM write command
- **`move.w d0,(a0)`:** Sends command to VDP
- **`move.w #$0F00,d0`:** Blue colour value (Genesis uses $0RGB format, 3 bits per channel)
- **`move.w d0,(a1)`:** Writes colour to VDP data port

## Motorola 68000

The Genesis uses the powerful 68000 CPU - a 32-bit processor (internally) with 16-bit external bus. It has:
- 8 data registers (D0-D7)
- 8 address registers (A0-A7)
- Much more powerful than 6502 or Z80!
