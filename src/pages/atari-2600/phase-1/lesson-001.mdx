# Your First Atari 2600 Assembly Program

Welcome to Atari 2600 assembly! You're about to write your first 6507 (6502 variant) assembly program for Atari's legendary console.

## What You'll Build

A program that changes the background colour. This is deceptively simple on the 2600 - you have to race the electron beam!

## The Code

Save this as `hello.asm`:

```nasm
; Your first Atari 2600 assembly program
; Changes background colour

        processor 6502
        include "vcs.h"
        include "macro.h"

        org $F000       ; Start of 4K ROM

Start:
        ; Clear RAM and registers
        sei             ; Disable interrupts
        cld             ; Clear decimal mode
        ldx #$FF
        txs             ; Set up stack

        ; Clear zero page
        ldx #0
        lda #0
ClearLoop:
        sta 0,X
        inx
        bne ClearLoop

MainLoop:
        ; VSYNC - start of frame
        lda #2
        sta VSYNC       ; Turn on VSYNC
        sta WSYNC       ; Wait for scanline
        sta WSYNC
        sta WSYNC       ; 3 scanlines of VSYNC
        lda #0
        sta VSYNC       ; Turn off VSYNC

        ; VBLANK - 37 scanlines
        lda #2
        sta VBLANK      ; Turn on VBLANK
        ldx #37
VBlankLoop:
        sta WSYNC       ; Wait for scanline
        dex
        bne VBlankLoop
        lda #0
        sta VBLANK      ; Turn off VBLANK

        ; Visible screen - 192 scanlines
        ; Change colour on each scanline
        ldx #192
ScanLoop:
        inx             ; Increment colour
        stx COLUBK      ; Set background colour
        sta WSYNC       ; Wait for next scanline
        dex
        dex
        dex
        bne ScanLoop

        ; Overscan - 30 scanlines
        ldx #30
OverscanLoop:
        sta WSYNC
        dex
        bne OverscanLoop

        jmp MainLoop    ; Next frame

        ; Interrupt vectors
        org $FFFC
        .word Start     ; RESET vector
        .word Start     ; IRQ vector
```

## How to Assemble and Run It

### Using DASM assembler:
```bash
dasm hello.asm -f3 -ohello.bin
```

This creates `hello.bin`.

### Run in Stella emulator:
```bash
stella hello.bin
```

Or in Stella: File → Open ROM → hello.bin

## What Just Happened?

- **Racing the beam:** The 2600 has NO framebuffer! You must write to registers in sync with the electron beam
- **VSYNC:** 3 scanlines to signal start of frame
- **VBLANK:** 37 scanlines of vertical blank (beam returning to top)
- **Visible:** 192 scanlines where you draw (race the beam!)
- **WSYNC:** Write to this register to wait for the next scanline
- **COLUBK:** Background colour register - changes take effect immediately
- **Overscan:** 30 scanlines at bottom of frame

## "Racing the Beam"

The 2600's 128 bytes of RAM can't hold a frame buffer. Instead, you write to hardware registers (TIA chip) in perfect sync with the TV's electron beam. This is called "kernel programming" - you're writing code that executes per-scanline!

## 6507 CPU

The 2600 uses the 6507, a cost-reduced 6502 with only 13 address lines (8KB address space). Same instruction set as 6502, but extremely constrained!

## You Did It!

You just wrote and ran your first Atari 2600 program. You're racing the beam - one of the most challenging programming techniques in retro gaming!
