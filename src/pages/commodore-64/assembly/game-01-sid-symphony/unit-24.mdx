## What Is Syncopation?

In music, syncopation means emphasising weak beats or off-beats:

| Beat Position | Type | Feel |
|---------------|------|------|
| 0, 4, 8, 12... | Strong beat | Expected, stable |
| 2, 6, 10, 14... | Weak beat | Slightly off |
| 1, 3, 5, 7... | Off-beat | Surprising, pushed |

Our first three songs placed notes primarily on strong beats. Song 4 inverts this—notes land on off-beats, creating a "pushed" feeling.

## Syncopated Patterns

Compare a normal pattern to a syncopated one:

```
Normal:   [0]--[4]--[8]--[12]--[16]  (on the beat)
Synco:    -[1]--[5]--[9]--[13]--[17] (off the beat)
```

The syncopated version feels like it's rushing ahead. Players must resist the urge to hit early.

## Song 4 Data Structure

Like our other songs, Song 4 has three difficulty variants:

```asm
; --- EASY: Sparse syncopated notes (10 notes) ---
song4_easy:
            !byte 1, 1, $47          ; Off-beat accent
            !byte 9, 2, $3B          ; Pushed note
            !byte 17, 3, $27         ; Syncopated hit
            ; ... 10 notes on prominent off-beats

; --- NORMAL: Syncopated with anchors (32 notes) ---
song4_normal:
            !byte 0, 1, $47          ; Anchor
            !byte 1, 2, $3B          ; Off-beat
            !byte 3, 3, $27          ; Syncopated
            !byte 4, 1, $47          ; Anchor
            ; ... mix of anchors and off-beats

; --- HARD: Dense syncopated chaos (56 notes) ---
song4_hard:
            !byte 0, 1, $47          ; Anchor
            !byte 1, 2, $3B          ; Off-beat
            !byte 1, 3, $27          ; Chord
            !byte 3, 1, $47          ; Syncopated
            ; ... nearly every off-beat filled
```

## The Anchor Concept

Pure syncopation is disorienting. Normal and Hard modes include "anchors"—notes on strong beats that help players stay oriented:

```asm
            !byte 0, 1, $47          ; Anchor - strong beat
            !byte 1, 2, $3B          ; Off-beat - syncopated
            !byte 3, 3, $27          ; Syncopated
            !byte 4, 1, $47          ; Anchor - strong beat
```

Anchors on beats 0, 4, 8, etc. provide reference points. The off-beat notes between them create the syncopated feel without losing the listener entirely.

## Tempo Choice: 125 BPM

We chose 125 BPM deliberately:

| Song | BPM | Character |
|------|-----|-----------|
| First Steps | 120 | Relaxed |
| Upbeat Groove | 130 | Energetic |
| Speed Rush | 150 | Frantic |
| Off-Beat | 125 | Groovy |

125 BPM sits between our relaxed and energetic songs. Fast enough to feel lively, slow enough that players can process the unexpected note positions.

## Frames Per Beat

At 125 BPM:

```
frames_per_beat = 3000 / 125 = 24 frames
```

This gives players 480ms per beat (24 frames ÷ 50 fps)—enough time to adjust when notes don't land where expected.

## Song Selection Logic

The transition routine handles all four songs:

```asm
transition_to_game:
            lda selected_song
            beq setup_song1
            cmp #1
            beq setup_song2
            cmp #2
            beq setup_song3
            jmp setup_song4

setup_song4:
            lda #TEMPO_SONG4
            sta frames_per_beat
            lda #LENGTH_SONG4
            sta song_length

            ; Select difficulty variant
            lda difficulty
            cmp #DIFF_EASY
            beq load_s4_easy
            cmp #DIFF_NORMAL
            beq load_s4_normal
            jmp load_s4_hard
```

## Why Syncopation Challenges Players

Most rhythm games train players to expect notes on the beat. Syncopation breaks this expectation:

1. **Visual prediction fails** - Eyes see note approaching, brain predicts strong beat
2. **Motor preparation misfires** - Finger starts moving for expected timing
3. **Correction required** - Must hold slightly, hit on off-beat

This creates a distinctive "groove" feeling when mastered—the push-pull between expectation and reality.

## Difficulty Progression with Syncopation

| Difficulty | Notes | Strategy |
|------------|-------|----------|
| Easy | 10 | Learn where off-beats feel |
| Normal | 32 | Mix of anchors and off-beats |
| Hard | 56 | Dense syncopation with chords |

Easy mode strips to the most prominent syncopated accents. Normal adds anchors for orientation. Hard fills nearly every off-beat, requiring players to fully internalise the pushed feel.
