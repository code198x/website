## Custom Character Logo Design

The C64's character set is at $3000 in our game. We've been using custom characters for notes, tracks, and UI elements. Now we add logo characters.

### Logo Character Set

We define ten new characters (133-142) for building the logo:

```asm
; Logo characters (for title screen design)
CHAR_LOGO_TL = 133              ; Top-left corner
CHAR_LOGO_TR = 134              ; Top-right corner
CHAR_LOGO_BL = 135              ; Bottom-left corner
CHAR_LOGO_BR = 136              ; Bottom-right corner
CHAR_LOGO_H  = 137              ; Horizontal bar
CHAR_LOGO_V  = 138              ; Vertical bar
CHAR_LOGO_FULL = 139            ; Full block
CHAR_LOGO_HALF_T = 140          ; Half block top
CHAR_LOGO_HALF_B = 141          ; Half block bottom
CHAR_LOGO_DOT = 142             ; Centre dot (decorative)
```

Each character is 8x8 pixels. Combining them creates larger designs.

### Character Definitions

Corner characters use partial fills:

```asm
; Character 133 - Top-left corner
lda #%11111111
sta CHARSET + (133 * 8) + 0
sta CHARSET + (133 * 8) + 1
lda #%11000000
sta CHARSET + (133 * 8) + 2
sta CHARSET + (133 * 8) + 3
sta CHARSET + (133 * 8) + 4
sta CHARSET + (133 * 8) + 5
sta CHARSET + (133 * 8) + 6
sta CHARSET + (133 * 8) + 7
```

The top two rows are solid (`%11111111`), remaining rows have only left pixels set (`%11000000`). This creates a corner that connects to horizontal and vertical bars.

### Building the Logo

The logo uses data tables for screen layout:

```asm
logo_row1:
    ; S       I       D
    !byte CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_SPACE
    !byte CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_SPACE
    !byte CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_LOGO_FULL, CHAR_SPACE
    !byte CHAR_SPACE, CHAR_SPACE, CHAR_SPACE, CHAR_SPACE
    !byte 0
```

Each letter is three characters wide. Spacing between letters creates readability. The null terminator (0) marks the end.

## Visual Hierarchy

Good title screens guide the eye:

1. **Logo** (rows 4-6) - Largest, brightest element
2. **Title text** (row 8) - "SYMPHONY" in spaced capitals
3. **Separator** (row 10) - Visual break using decorative characters
4. **Subtitle** (row 12) - "A RHYTHM GAME" in subdued colour
5. **Instructions** (rows 15, 17) - Controls and guidance
6. **Call to action** (row 21) - "PRESS FIRE TO START" in yellow
7. **Version** (row 24) - Small, dim, out of the way

### Colour Choices

```asm
lda #14             ; Light blue for logo
lda #1              ; White for "SYMPHONY"
lda #SUBTITLE_COL   ; Grey (11) for subtitle
lda #7              ; Yellow for call to action
lda #11             ; Dark grey for version
```

Bright colours draw attention. Dim colours recede. The yellow "PRESS FIRE" stands out because it's the action the player should take.

## Decorative Elements

### Top Border

A framed top border uses corner and horizontal bar characters:

```asm
logo_top_border:
    !byte CHAR_LOGO_TL, CHAR_LOGO_H, CHAR_LOGO_H, ...
    !byte CHAR_LOGO_H, CHAR_LOGO_H, CHAR_LOGO_TR
    !byte 0
```

The `CHAR_LOGO_TL` corner connects smoothly to `CHAR_LOGO_H` bars, ending with `CHAR_LOGO_TR`.

### Separator Line

The separator uses dots and bars:

```asm
separator_text:
    !byte CHAR_LOGO_DOT, CHAR_SPACE, CHAR_LOGO_H, ...
    !byte CHAR_LOGO_H, CHAR_SPACE, CHAR_LOGO_DOT
    !byte 0
```

Dots at each end add visual interest. The line separates the logo from the content below.

## Typography Trick: Spaced Letters

"SYMPHONY" uses spaces between letters for an elegant look:

```asm
symphony_text:
    !scr "s y m p h o n y"
    !byte 0
```

The `!scr` directive converts to screen codes. Spaces between letters create a refined, professional appearance often seen in title screens of the era.

## Drawing Efficiency

Each element uses a similar pattern:

```asm
ldx #0
draw_logo_row1:
    lda logo_row1,x
    beq draw_logo1_done
    sta SCREEN + (4 * 40) + 12,x
    lda #14             ; Light blue
    sta COLRAM + (4 * 40) + 12,x
    inx
    jmp draw_logo_row1
draw_logo1_done:
```

- Load byte from data table
- Check for zero terminator
- Write to screen memory
- Write colour to colour RAM
- Increment and loop

This pattern repeats for each line. The position formula `(row * 40) + column` places content precisely.

## Try This

1. **Different logo style** - Create characters for outlined letters instead of filled blocks
2. **Colour gradient** - Use different colours for each logo row (top lighter than bottom)
3. **Border variations** - Add bottom border to frame the entire title area
4. **Title centering** - Calculate positions to perfectly centre text

## Memory Cost

The logo characters add:
- 10 new characters × 8 bytes = 80 bytes in charset
- Logo data tables ≈ 120 bytes
- Total: ~200 bytes

On a 64KB machine with ~40KB available, this is negligible for the visual improvement gained.
