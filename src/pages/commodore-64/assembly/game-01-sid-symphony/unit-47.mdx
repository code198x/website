Every polished game needs a pause function. Life interrupts—phones ring, doorbells sound, drinks need fetching. This unit adds a proper pause system with menu options and a countdown before resuming, ensuring players never lose progress to the unexpected.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

![Unit 47 Screenshot](/images/commodore-64/game-01-sid-symphony/unit-47/screenshot.png)

During gameplay, press P to pause. Navigate the menu with the joystick: up/down selects options, fire confirms. Choose Resume for a 3-2-1 countdown before play continues, Restart to begin the song again, or Quit to return to the song selection menu.

## Pause State Variables

```asm
game_paused      = $4B          ; 1 = game is paused
pause_cursor     = $4C          ; Pause menu cursor (0=Resume, 1=Restart, 2=Quit)
countdown_value  = $4D          ; Resume countdown (3, 2, 1, 0)
countdown_timer  = $4E          ; Frames remaining for current number
```

The `game_paused` flag controls whether the main game loop updates gameplay or the pause menu.

## Detecting the Pause Key

During gameplay, we check for the P key using the C64 keyboard matrix:

```asm
update_playing:
            ; Check if game is paused
            lda game_paused
            beq up_not_paused
            jmp update_paused

up_not_paused:
            ; Check for P key (row 1, column 5)
            lda #$FD                ; Row 1
            sta CIA1_PRA
            lda CIA1_PRB
            and #$20                ; Column 5 = P
            bne up_no_pause_key
            ; P pressed - pause the game
            jsr pause_game
```

The C64 keyboard matrix requires setting a row in CIA1_PRA and reading the column from CIA1_PRB. Row 1 ($FD) with column 5 ($20) gives us the P key.

## Pausing the Game

```asm
pause_game:
            lda #1
            sta game_paused
            lda #0
            sta pause_cursor

            ; Silence SID
            lda #0
            sta SID_VOLUME

            ; Draw pause overlay
            jsr draw_pause_overlay
            jsr play_menu_select
            rts
```

Silencing the SID immediately signals the pause—the sudden quiet is unmistakable.

## Drawing the Pause Overlay

The overlay draws directly over the gameplay screen:

```asm
draw_pause_overlay:
            ; Draw "PAUSED" at row 8
            ldx #0
dpo_title:
            lda pause_title_text,x
            beq dpo_items
            sta SCREEN + (8 * 40) + 17,x
            lda #1                  ; White
            sta COLRAM + (8 * 40) + 17,x
            inx
            bne dpo_title

dpo_items:
            ; Draw menu items at rows 12, 14, 16
            ; ...
```

Menu items appear in yellow with a cursor indicator. The overlay is positioned centrally to stand out against the note tracks.

## Pause Menu Navigation

```asm
update_paused:
            ; Handle countdown if active
            lda countdown_value
            beq up_pause_menu
            jmp update_countdown

up_pause_menu:
            ; Check joystick up
            lda CIA1_PRA
            and #$01
            beq up_pause_up

            ; Check joystick down
            lda CIA1_PRA
            and #$02
            beq up_pause_down

            ; Check fire
            lda CIA1_PRA
            and #$10
            beq up_pause_fire
```

Standard menu navigation—up and down move the cursor, fire selects.

## Menu Options

| Selection | Action |
|-----------|--------|
| Resume | Start 3-2-1 countdown, then continue |
| Restart | Reinitialise game, play song from beginning |
| Quit | Return to song selection menu |

```asm
up_pause_fire:
            jsr play_menu_select
            lda pause_cursor
            cmp #0
            beq up_do_resume
            cmp #1
            beq up_do_restart
            jmp up_do_quit
```

## The Resume Countdown

Resuming immediately would be unfair—players need a moment to ready themselves:

```asm
up_do_resume:
            ; Start countdown
            lda #3
            sta countdown_value
            lda #50                 ; ~1 second per number
            sta countdown_timer
            jsr draw_countdown
            rts
```

The countdown displays 3, 2, 1 with a sound on each number change:

```asm
update_countdown:
            dec countdown_timer
            bne uc_not_done

            ; Timer reached zero - decrement countdown value
            dec countdown_value
            lda countdown_value
            beq uc_resume           ; Countdown complete

            ; Draw new number
            lda #50
            sta countdown_timer
            jsr draw_countdown
            jsr play_menu_move
            rts

uc_resume:
            ; Countdown complete - resume gameplay
            lda #0
            sta game_paused
            ; Restore volume
            lda #$0F
            sta SID_VOLUME
            ; Clear overlay
            jsr clear_pause_overlay
            rts
```

## Countdown Display

Large, central numbers make the countdown unmissable:

```asm
draw_countdown:
            ; Clear pause menu area
            ldx #10
            lda #' '
dcn_clear:
            sta SCREEN + (12 * 40) + 13,x
            sta SCREEN + (14 * 40) + 13,x
            sta SCREEN + (16 * 40) + 13,x
            dex
            bpl dcn_clear

            ; Draw countdown number (centered)
            lda countdown_value
            clc
            adc #'0'                ; Convert to screen code
            sta SCREEN + (14 * 40) + 19
            lda #1                  ; White
            sta COLRAM + (14 * 40) + 19
            rts
```

## Restart Handling

Restarting requires reinitialising all game state:

```asm
up_do_restart:
            lda #0
            sta game_paused
            ; Restore volume
            lda #$0F
            sta SID_VOLUME
            ; Re-init gameplay
            jsr init_game
            rts
```

The `init_game` routine handles clearing notes, resetting score/health/combo, and repositioning the song to its start.

## Quit to Menu

```asm
up_do_quit:
            lda #0
            sta game_paused
            ; Restore volume
            lda #$0F
            sta SID_VOLUME
            ; Silence all voices
            jsr init_sid
            ; Go to menu
            jsr show_menu
            lda #STATE_MENU
            sta game_state
            rts
```

## Why the Countdown?

Rhythm games require synchronisation between player and music. Without a countdown:

| Scenario | Problem |
|----------|---------|
| Immediate resume | Notes hit while player is unprepared |
| Music starts mid-phrase | Hard to find the beat |
| No warning | Unfair to the player |

The 3-2-1 countdown solves all three: it gives preparation time, the music starts fresh, and the visual warning is unmistakable.
