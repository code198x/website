When players nail perfect timing, they deserve celebration. This unit adds a "PERFECT!" text popup that appears briefly on the track where the hit occurred, cycling through colours as it fades. Combined with the existing border and background flash, perfect hits now feel genuinely rewarding.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

![Unit 37 Screenshot](/images/commodore-64/game-01-sid-symphony/unit-37/screenshot.png)

Play a song and hit notes with perfect timing. "PERFECT!" appears on the track, cycling from white through yellow and green before fading. The layered effects—border flash, background flash, and text popup—create a satisfying cascade of feedback.

## Effect Variables

We add two new variables to track the effect state:

```asm
perfect_effect   = $29          ; Perfect hit effect countdown
perfect_track    = $2A          ; Which track showed last perfect (1-3)
```

When `perfect_effect` is non-zero, we draw the text. `perfect_track` tells us which track row to draw on.

## Triggering the Effect

In the `award_perfect` routine, we trigger the effect after all the existing feedback:

```asm
            ; Trigger "PERFECT!" text effect (Unit 37)
            lda #12                 ; Effect duration (frames)
            sta perfect_effect
            lda key_pressed         ; Which track was hit
            sta perfect_track
```

We use `key_pressed` which already contains 1, 2, or 3 indicating which track the player hit. The effect lasts 12 frames—just under a quarter second at 50Hz.

## Drawing the Text

The effect routine handles both drawing and clearing:

```asm
update_perfect_effect:
            lda perfect_effect
            beq clear_perfect_text      ; Effect ended, clear text

            dec perfect_effect

            ; Show "PERFECT!" text near the hit track
            lda perfect_track
            cmp #1
            beq perfect_track1
            cmp #2
            beq perfect_track2
            jmp perfect_track3
```

We branch to track-specific drawing code because each track has a different screen row.

## Track-Specific Drawing

Each track draws the text at its row position:

```asm
perfect_track1:
            ldx #0
perfect_draw_t1:
            lda perfect_text,x
            beq perfect_draw_done
            sta SCREEN + (TRACK1_ROW * 40) + 8,x
            lda perfect_effect
            lsr
            and #$03
            tay
            lda perfect_colours,y
            sta COLRAM + (TRACK1_ROW * 40) + 8,x
            inx
            jmp perfect_draw_t1
```

Key details:
- Position +8 places the text just past the hit zone
- Colour is calculated from `perfect_effect` countdown, creating a fade
- The same pattern repeats for tracks 2 and 3

## Colour Cycling

The colour sequence creates a fade effect:

```asm
perfect_colours:
            !byte 1                 ; White
            !byte 7                 ; Yellow
            !byte 13                ; Light green
            !byte 5                 ; Green
```

| perfect_effect | After LSR+AND | Colour |
|----------------|---------------|--------|
| 12-9 | 0-1 | White/Yellow |
| 8-5 | 2-3 | Light green/Green |
| 4-1 | 0-1 | White/Yellow |
| 0 | (cleared) | — |

This creates a pulsing fade rather than a linear one.

## Clearing the Text

When the effect ends, we clear all three tracks:

```asm
clear_perfect_text:
            ldx #7
clear_perfect_loop:
            lda #CHAR_SPACE
            sta SCREEN + (TRACK1_ROW * 40) + 8,x
            sta SCREEN + (TRACK2_ROW * 40) + 8,x
            sta SCREEN + (TRACK3_ROW * 40) + 8,x
            dex
            bpl clear_perfect_loop
            rts
```

We clear all tracks because the player might have switched tracks mid-effect. The loop runs 8 times (index 7 to 0), matching the 8 characters of "PERFECT!".

## Integration Point

The effect updates alongside other visual effects:

```asm
            ; Update beat pulse marker
            jsr update_beat_marker

            ; Update perfect hit text effect (Unit 37)
            jsr update_perfect_effect
```

This keeps all visual updates grouped together in the game loop.

## The Effect Stack

Perfect hits now trigger multiple layered effects:

| Layer | Effect | Duration |
|-------|--------|----------|
| 1 | Border flash (white) | 6 frames |
| 2 | Background flash (black) | 3 frames |
| 3 | "PERFECT!" text | 12 frames |
| 4 | Sound effect | ~0.2 seconds |

These overlapping durations create a cascade that starts dramatic and settles smoothly.
