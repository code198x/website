A complete game needs a complete audio palette. This unit adds the finishing touches: a triumphant victory jingle when you complete a song, a somber stinger when you fail, and organised sound effect routines. The game now has a distinct audio identity.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

## Jingle System

Unlike single sound effects, jingles play sequences of notes over time:

```asm
jingle_playing   = $37          ; Currently playing jingle (0=none, 1=victory)
jingle_pos       = $38          ; Position in jingle data
jingle_timer     = $39          ; Frames until next note
```

The system is data-driven, making it easy to add more jingles later.

## Victory Jingle Data

The victory melody is defined as parallel note and duration arrays:

```asm
; Victory jingle note data (freq high bytes, ascending)
victory_notes:
            !byte $10               ; C
            !byte $14               ; E
            !byte $18               ; G
            !byte $20               ; C (octave up)
            !byte $28               ; E (held)
            !byte 0                 ; End marker

; Victory jingle durations (frames per note)
victory_durations:
            !byte 6                 ; Quick
            !byte 6
            !byte 6
            !byte 8                 ; Slightly longer
            !byte 12                ; Hold final note
```

The ascending C major arpeggio with a held final note creates a classic "success" feeling.

## Starting a Jingle

When a song ends successfully:

```asm
play_victory_jingle:
            ; Stop any current note sounds
            lda #$00
            sta SID_V3_CTRL

            ; Start victory sequence
            lda #1                  ; Jingle type 1 = victory
            sta jingle_playing
            lda #0
            sta jingle_pos
            lda #1                  ; Start immediately
            sta jingle_timer
            rts
```

Setting `jingle_timer` to 1 means the first note plays on the next frame.

## Jingle Playback

Each frame, we check if a jingle is playing:

```asm
update_jingle:
            lda jingle_playing
            beq jingle_done

            ; Decrement timer
            dec jingle_timer
            bne jingle_done

            ; Time for next note...
```

When the timer reaches zero, we play the next note and reset the timer.

## Playing Each Note

```asm
update_victory_jingle:
            ; Get note from victory sequence
            ldx jingle_pos
            lda victory_notes,x
            beq victory_end         ; 0 = end of sequence

            ; Play this note
            sta SID_V3_FREQ_HI
            ; ... configure voice 3 ...
            lda #$41                ; Pulse, gate on
            sta SID_V3_CTRL

            ; Set duration for this note
            lda victory_durations,x
            sta jingle_timer

            ; Advance position
            inc jingle_pos
```

The indexed read from `victory_notes` and `victory_durations` makes adding new jingles straightforward.

## Game Over Stinger

Failure gets a single somber note:

```asm
play_gameover_stinger:
            ; Configure voice 3 for somber tone
            lda #GAMEOVER_FREQ
            sta SID_V3_FREQ_LO
            lda #$03                ; Low frequency
            sta SID_V3_FREQ_HI
            ; ... slow attack, long release ...
            lda #GAMEOVER_WAVE
            ora #$01                ; Gate on
            sta SID_V3_CTRL
            rts
```

The slow attack and long release create a mournful quality—appropriate for failure.

## Sound Effect Constants

New sound settings for game over and menu back:

```asm
; Menu back sound
MENU_BACK_FREQ    = $08         ; Lower pitch for back
MENU_BACK_WAVE    = $11         ; Triangle (soft)
MENU_BACK_AD      = $00         ; Instant
MENU_BACK_SR      = $40         ; Very short

; Game over stinger
GAMEOVER_FREQ     = $06         ; Low, somber
GAMEOVER_WAVE     = $11         ; Triangle
GAMEOVER_AD       = $09         ; Slow attack
GAMEOVER_SR       = $A0         ; Long release
```

Note the contrast: menu back is quick and soft; game over is slow and heavy.
