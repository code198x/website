A game can be functionally complete yet feel lifeless. Visual polish transforms correct mechanics into satisfying experiences. The same hit that merely updates a score should also flash, pulse, and celebrate.

This unit adds three visual enhancements: screen flash on perfect hits, a pulsing beat marker, and improved feedback timing.

## Beat Marker

The beat marker pulses on every downbeat, helping players feel the rhythm:

```asm
update_beat_marker:
            lda beat_pulse
            beq beat_marker_dim

            ; Pulse is active - show bright marker
            dec beat_pulse
            lda beat_pulse
            lsr                     ; Divide by 2 for colour selection
            and #$03                ; Keep in range 0-3
            tax
            lda beat_colours,x
            sta COLRAM + (HIT_ROW * 40) + 19
            lda #$51                ; Filled circle character
            sta SCREEN + (HIT_ROW * 40) + 19
            rts

beat_marker_dim:
            ; Show dim marker when not pulsing
            lda #11                 ; Dark grey
            sta COLRAM + (HIT_ROW * 40) + 19
            lda #$57                ; Empty circle character
            sta SCREEN + (HIT_ROW * 40) + 19
            rts
```

The marker cycles through colours (white → yellow → green → grey) as it fades, creating a smooth pulse effect.

## Colour Fade Table

Instead of complex colour calculations, we use a lookup table:

```asm
beat_colours:
            !byte 1                 ; White (brightest)
            !byte 7                 ; Yellow
            !byte 5                 ; Green
            !byte 11                ; Dark grey (dimmest)
```

The pulse counter divides by 2 and masks to select colours, creating a 4-step fade that feels natural.

## Triggering the Pulse

Every beat triggers a new pulse:

```asm
update_playing:
            inc frame_count
            lda frame_count
            cmp frames_per_beat
            bcc no_new_beat

            lda #0
            sta frame_count
            jsr advance_song
            jsr check_spawn_note

            ; Trigger beat pulse on every new beat
            lda #8                  ; Pulse duration (frames)
            sta beat_pulse
```

Setting `beat_pulse` to 8 means the marker stays bright for 8 frames then fades over 4 colour steps.

## Screen Flash on Perfect

Perfect hits deserve more celebration than a border flash. We briefly flash the entire background:

```asm
            ; Screen flash effect for perfect hits
            lda #0                  ; Black background flash
            sta BGCOL
            lda #3                  ; Flash duration
            sta bg_flash
```

The background colour register ($D021) controls the entire screen background. Flashing it black for 3 frames creates a dramatic "impact" feel.

## Background Flash Handler

The flash handler restores the normal background:

```asm
            ; Update background flash (perfect hit effect)
            lda bg_flash
            beq bg_flash_done
            dec bg_flash
            bne bg_flash_done
            ; Reset background to default
            lda #6                  ; Blue background
            sta BGCOL
bg_flash_done:
```

The countdown pattern is familiar from border flash—decrement until zero, then restore.

## Variable Initialization

New effect variables need initialization:

```asm
init_game:
            jsr init_screen
            jsr init_notes
            jsr init_score
            jsr init_health
            jsr init_combo
            jsr init_song

            ; Initialize visual effect variables
            lda #0
            sta bg_flash
            sta beat_pulse

            rts
```

Starting at zero ensures no spurious flashes at game start.

## Why Polish Matters

Consider the psychology of feedback:

| Without Polish | With Polish |
|----------------|-------------|
| Number changes | Number changes + flash |
| Silent hit | Sound + border + screen flash |
| No rhythm help | Pulsing beat marker |

The functional result is identical—score increases, health updates. But the polished version *feels* more responsive, more alive.

## Performance Considerations

Our effects are cheap:
- **Beat marker**: One character + colour write per frame
- **Background flash**: One register write every few frames
- **Border flash**: Already existed

On a machine where every cycle counts, simple countdown timers and lookup tables provide rich effects without expensive calculations.

## The Flash Hierarchy

We now have layered visual feedback:

| Event | Border | Background | Marker |
|-------|--------|------------|--------|
| Beat | - | - | Pulse |
| Perfect | White | Black flash | - |
| Good | Yellow | - | - |
| Miss | Red | - | - |
| Combo tier | Tier colour | - | - |

Each feedback type uses appropriate channels without conflicts.
