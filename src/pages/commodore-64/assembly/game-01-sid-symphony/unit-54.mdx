Ring modulation is one of the SID's most distinctive features. By multiplying two waveforms together, it creates complex harmonic content impossible with simple oscillators—the metallic clangs, eerie bells, and sci-fi effects that define the C64 sound.

## What is Ring Modulation?

Ring modulation multiplies two signals together. Mathematically:

```
Output = Signal_A × Signal_B
```

When both signals are sine waves, you get sum and difference frequencies:

```
Input A: 440 Hz (A4)
Input B: 550 Hz (C#5)
Output:  990 Hz (sum) + 110 Hz (difference)
```

The original frequencies disappear, replaced by new harmonics. This creates the characteristic "metallic" or "bell-like" quality.

## SID Ring Modulation

The SID implements ring modulation between adjacent voices:

| Voice | Ring-Mods With |
|-------|----------------|
| Voice 1 | Voice 3's frequency |
| Voice 2 | Voice 1's frequency |
| Voice 3 | Voice 2's frequency |

It's a circular chain: 1←3, 2←1, 3←2.

## Enabling Ring Modulation

Set bit 2 of the control register:

```asm
; Voice 1 control register: $D404
; Bit 0: Gate (start/stop)
; Bit 1: Sync
; Bit 2: Ring modulation    ← This one
; Bit 3: Test
; Bits 4-7: Waveform

            ; Enable ring mod on Voice 1 (with triangle wave)
            lda #$14            ; %00010100 = Triangle + Ring
            sta $D404

            ; Voice 3 provides the modulating frequency
            ; Set Voice 3 to a different pitch
            lda #$20
            sta $D40E           ; Voice 3 freq low
            lda #$10
            sta $D40F           ; Voice 3 freq high
```

## Creating Bell Sounds

Bells have inharmonic overtones—frequencies that aren't simple multiples of the fundamental. Ring modulation excels at this:

```asm
; Bell-like sound using ring modulation
bell_sound:
            ; Voice 1: Carrier (main pitch)
            lda #$00
            sta $D400           ; Freq low
            lda #$1C            ; ~440 Hz
            sta $D401           ; Freq high
            lda #$09            ; Fast attack, medium decay
            sta $D405
            lda #$00            ; No sustain, no release
            sta $D406

            ; Voice 3: Modulator (creates harmonics)
            lda #$00
            sta $D40E
            lda #$23            ; Slightly different frequency
            sta $D40F           ; Creates inharmonic beating
            lda #$11            ; Triangle wave (no gate needed)
            sta $D412

            ; Trigger Voice 1 with ring mod
            lda #$15            ; Triangle + Ring + Gate
            sta $D404
            rts
```

The slight frequency difference between voices creates the characteristic bell shimmer.

## Metallic Effects

For harsh, metallic sounds, use higher modulator frequencies:

```asm
; Metallic clang
metallic_sound:
            ; Carrier: Low frequency
            lda #$00
            sta $D400
            lda #$08            ; Low pitch
            sta $D401

            ; Modulator: Much higher frequency
            lda #$00
            sta $D40E
            lda #$40            ; High pitch
            sta $D40F
            lda #$11            ; Triangle
            sta $D412

            ; Ring mod with sawtooth for harsh harmonics
            lda #$25            ; Sawtooth + Ring + Gate
            sta $D404
            rts
```

## Frequency Relationships

Different frequency ratios create different characters:

| Ratio | Sound Character |
|-------|-----------------|
| 1:1 | Hollow, filtered |
| 2:1 | Octave-ish |
| 3:2 | Bell-like |
| Irrational | Metallic, complex |

Experiment by slowly sweeping one frequency while holding the other constant.

## Combining with Filters

Ring modulation pairs beautifully with the SID filter:

```asm
            ; Set up resonant low-pass filter
            lda #$40            ; Cutoff frequency
            sta $D415
            lda #$D1            ; High resonance + filter Voice 1
            sta $D417
            lda #$10            ; Low-pass mode
            sta $D418
```

Sweeping the filter cutoff over a ring-modulated sound creates evolving, alive textures.

## Sync vs Ring Mod

The SID also offers hard sync (bit 1). The difference:

| Feature | Sync | Ring Mod |
|---------|------|----------|
| Effect | Resets oscillator phase | Multiplies waveforms |
| Sound | Aggressive, cutting | Metallic, bell-like |
| Control | One oscillator dominates | Both contribute equally |

You can even combine both for extreme timbres:

```asm
            lda #$17            ; Triangle + Ring + Sync + Gate
            sta $D404
```
