## Finding Playtesters

Good playtesters include:

| Type | Value |
|------|-------|
| Non-gamers | Find confusing interfaces |
| Genre fans | Compare to other rhythm games |
| Kids | Test accessibility |
| Experienced devs | Spot technical issues |

Diverse perspectives reveal diverse problems.

## Running a Playtest Session

1. **Set up** - Prepare build, have notepad ready
2. **Brief** - Minimal instruction, let them discover
3. **Observe** - Watch silently, note frustrations
4. **Listen** - Record verbal reactions
5. **Debrief** - Ask open questions after

**Don't:** Explain, justify, or defend. Just observe.

## What to Watch For

| Signal | Meaning |
|--------|---------|
| Pausing | Confusion or processing |
| Sighing | Frustration |
| Leaning forward | Engagement |
| Button mashing | Lost or bored |
| "What?" | Unclear feedback |
| "Yes!" | Satisfaction |

## Feedback Triage

Not all feedback is equal:

```
MUST FIX:
- Crashes
- Softlocks
- Broken core mechanics

SHOULD FIX:
- Confusing UI
- Unfair difficulty spikes
- Missing feedback

COULD FIX:
- Polish requests
- Feature suggestions

WON'T FIX:
- Personal preferences
- Scope creep
```

## When to Stop Polishing

Ship when:
- Critical bugs fixed
- Core experience works
- Testers can complete the game
- Diminishing returns on changes

**Perfect is the enemy of done.**

## Common Playtest Findings

### "I didn't know I could do that"
- Add tutorial hints
- Improve visual affordances

### "The timing feels off"
- Adjust input windows
- Add visual/audio feedback

### "It's too hard/easy"
- Add difficulty options
- Rebalance note patterns

### "I don't understand what happened"
- Add clearer feedback
- Improve result screens

## Document Everything

Keep a playtest log:

```
Date: 2026-01-15
Tester: Bob (casual gamer)
Build: v0.15

Observations:
- Struggled to understand hit timing (2:15)
- Missed pause instructions (3:40)
- Completed first song with C grade

Feedback:
- "When do I press the button?"
- "Can I restart without going back to menu?"

Action items:
- [ ] Add timing indicator
- [ ] Add restart from pause menu
```
