## Common C64 Game Bugs

### Score Overflow
```asm
; Bug: Score wraps at 65535
add_score:
            clc
            lda score_lo
            adc points
            sta score_lo
            bcc .done
            inc score_hi       ; What if score_hi is already $FF?
.done:
            rts

; Fix: Cap at maximum or use 24-bit score
add_score_safe:
            clc
            lda score_lo
            adc points
            sta score_lo
            bcc .done
            lda score_hi
            cmp #$FF
            beq .done          ; Already maxed
            inc score_hi
.done:
            rts
```

### Off-by-One Errors
```asm
; Bug: Loop processes one too many/few
.loop:
            ldx #MAX_NOTES
            ; Should be ldx #MAX_NOTES-1 or
            ; should compare with MAX_NOTES+1
```

### Memory Corruption
```asm
; Bug: Writing past array bounds
            ldx note_index
            cpx #MAX_NOTES      ; Must check BEFORE writing
            bcs .skip
            sta note_track,x
.skip:
```

## Edge Case Checklist

| Category | Test |
|----------|------|
| **Values** | 0, 1, max-1, max, max+1 |
| **Timing** | Start, middle, end of frame |
| **Input** | No input, rapid input, held input |
| **State** | Every transition |

## Defensive Programming

Guard against impossible states:

```asm
update_state:
            lda game_state
            cmp #STATE_TITLE
            beq .title
            cmp #STATE_MENU
            beq .menu
            cmp #STATE_PLAYING
            beq .playing
            ; Unknown state - recover gracefully
            lda #STATE_TITLE
            sta game_state
            rts
.title:
            ; ...
```

## Testing Methodology

1. **Smoke test** - Does it start?
2. **Happy path** - Normal gameplay
3. **Boundary tests** - Edge values
4. **Stress test** - Rapid inputs, long sessions
5. **Recovery test** - Resume from pause, game over restart

## Common Bug Categories

### Timing Bugs
- Frame-rate dependent behaviour
- Race conditions with interrupts
- Missing wait states

### State Bugs
- Unreachable states
- Invalid transitions
- Missing initialisation

### Resource Bugs
- Memory leaks (rare in assembly)
- Running out of sprite slots
- Stack overflow

## Debugging Tools

On emulators:
- **Memory watch** - Monitor variable values
- **Breakpoints** - Stop at specific addresses
- **Trace log** - Record execution

On real hardware:
- **Border colours** - Visual indicators
- **SID noise** - Audio debugging
