From Unit 1's first key press triggering sound, to this: a playable game with title screen, three-track gameplay, hit detection with timing windows, combo multipliers, health system, results screen, and game over handling. Hand it to a friend and watch them play SID Symphony.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

## What You Built

The complete Phase 1 game includes:

**Visuals:**
- Custom character set (notes, tracks, hit zone, bars)
- Three colour-coded tracks
- Score, miss count, combo, health, and progress displays
- Title screen with instructions
- Results screen with statistics
- Game over screen for failure

**Audio:**
- Three SID voices for note playback
- Distinct sounds for perfect and good hits
- Harsh noise for misses
- Menu click sounds

**Gameplay:**
- Hit detection with timing windows (perfect/good)
- Score multipliers based on combo (1x/2x/3x/4x)
- Health that rises on hits and falls on misses
- One complete song with 30+ notes
- Win condition (complete song)
- Lose condition (health depletes)

**Flow:**
- Title → Playing → Results/Game Over → Title
- Complete state machine with clean transitions

## Balance Decisions

The game is tuned for fair difficulty:

```asm
; Timing windows - forgiving enough to learn
HIT_ZONE_MIN = 2           ; Early hit possible
HIT_ZONE_MAX = 5           ; Late hit possible
HIT_ZONE_CENTRE = 3        ; Perfect timing

; Health - misses hurt but not too much
HEALTH_MISS   = 8          ; Lose 8 per miss
HEALTH_START  = 32         ; Start half full
HEALTH_MAX    = 64         ; Can recover fully
```

A new player can make several mistakes and still complete the song. An expert chases the perfect run.
