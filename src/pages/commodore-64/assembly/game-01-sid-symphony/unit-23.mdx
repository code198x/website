Rhythm games can frustrate newcomers. Miss a few notes and health drains. Game over before you've learnt the pattern. Frustration. Quit.

This unit adds Practice Mode—a no-fail option where health never depletes. Combined with adjustable speed, learners can work through difficult sections at their own pace.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

![Unit 23 Screenshot](/images/commodore-64/game-01-sid-symphony/unit-23/screenshot.png)

Press P to toggle practice mode. Use + and - to adjust speed between 0.5x, 0.75x, and 1.0x. When practice mode is on, you can miss every note and keep playing.

## The Learning Problem

Normal gameplay creates a conflict:

1. **Miss notes** → Health drains → Game over
2. **To learn** → Must play the section → But keep dying
3. **Result:** Can't practice what you need to learn

Practice mode breaks this cycle. No health loss means unlimited attempts at difficult passages.

## Practice Mode Flag

A single flag controls practice mode:

```asm
practice_mode = $19             ; 0=Normal play, 1=Practice mode
```

When set to 1, the miss handler skips health reduction:

```asm
handle_miss:
            jsr play_miss_sound
            jsr break_combo

            ; In practice mode, don't decrease health
            lda practice_mode
            bne skip_health_loss

            ; Decrease health (using difficulty-adjusted amount)
            lda health_miss_amt
            jsr decrease_health

skip_health_loss:
            ; Flash border red (still provides feedback)
            lda #MISS_COL
            sta BORDER
            ; ...
```

The visual feedback (red flash, break sound) remains. Players still know they missed—they just don't die.

## Speed Settings

Three speed options slow the scroll:

```asm
; Speed multipliers (stored as frame adjustment)
SPEED_HALF    = 2               ; 0.5x speed (double frames)
SPEED_3QRTR   = 1               ; 0.75x speed
SPEED_NORMAL  = 0               ; 1.0x speed (no adjustment)

speed_setting = $1A             ; 0=0.5x, 1=0.75x, 2=1.0x
```

When starting a song, we apply the speed modifier:

```asm
apply_speed_modifier:
            lda speed_setting
            beq speed_half_tempo    ; 0 = 0.5x
            cmp #1
            beq speed_3qrtr_tempo   ; 1 = 0.75x
            rts                     ; 2 = 1.0x, no change

speed_half_tempo:
            ; 0.5x speed = double frames_per_beat
            asl frames_per_beat
            rts

speed_3qrtr_tempo:
            ; 0.75x speed = multiply by ~1.33
            lda frames_per_beat
            lsr                     ; Divide by 2
            clc
            adc frames_per_beat     ; Add to original
            sta frames_per_beat
            rts
```

At 0.5x speed, notes scroll at half pace—more time to read patterns and react.

## Menu Controls

Two new keyboard inputs:

```asm
menu_check_keys:
            ; Check P key for practice toggle
            lda #$FD                ; Keyboard row 1
            sta CIA1_PRA
            lda CIA1_PRB
            and #$20                ; Column 5 = P
            beq menu_p_pressed

            ; Check + key
            lda #$FE                ; Keyboard row 0
            sta CIA1_PRA
            lda CIA1_PRB
            and #$01                ; Column 0 = +
            beq menu_plus_pressed

            ; Check - key
            lda #$DF                ; Keyboard row 5
            sta CIA1_PRA
            lda CIA1_PRB
            and #$08                ; Column 3 = -
            beq menu_minus_pressed
```

The P key toggles practice mode on/off. Plus and minus cycle through speed settings.

## Menu Display

Practice mode shows its state:

```asm
draw_practice_state:
            lda practice_mode
            beq draw_prac_off
            ; Draw "ON" in cyan
            lda #'o'
            sta SCREEN + (17 * 40) + 22
            lda #'n'
            sta SCREEN + (17 * 40) + 23
            lda #PRACTICE_COL
            sta COLRAM + (17 * 40) + 22
            sta COLRAM + (17 * 40) + 23
            rts

draw_prac_off:
            ; Draw "OFF" in grey
            ; ...
```

Cyan text for "ON" provides visual confirmation that practice mode is active.

## Speed Display

Speed shows with colour coding:

| Speed | Colour | Meaning |
|-------|--------|---------|
| 0.5x | Green | Slow, safe |
| 0.75x | Yellow | Medium |
| 1.0x | White | Full speed |

This mirrors our difficulty colour scheme—players understand the progression intuitively.

## Design Philosophy

Practice modes should:

1. **Remove barriers** - No death means no progress blockers
2. **Preserve feedback** - Miss sounds/visuals still fire
3. **Allow speed control** - Different learners need different paces
4. **Be optional** - Experts shouldn't be forced through practice

We meet all four criteria. Practice mode is entirely optional, clearly visible in the menu, and doesn't affect scoring (practice scores don't save).

## When to Use Practice Mode

Recommended for:
- **First playthrough** - Learn the pattern before attempting Normal
- **Difficult sections** - Master tricky passages at slow speed
- **New songs** - Understand the structure before high-speed attempts

Once comfortable, switch to Normal mode for the real challenge.
