Loading screens transformed the tedious wait for tape and disk loading into part of the experience. This unit explores how professional games displayed graphics and music while loading.

## The Loading Problem

Standard C64 tape loading is slow:

| Media | Speed | 64KB Load Time |
|-------|-------|----------------|
| Datasette (stock) | 50 bytes/sec | ~21 minutes |
| Datasette (turbo) | 300 bytes/sec | ~3.5 minutes |
| 1541 disk (stock) | 400 bytes/sec | ~2.7 minutes |
| 1541 disk (fast) | 4000 bytes/sec | ~16 seconds |

Games often required 5-10 minutes to load. Players stared at a blank screen—unacceptable.

## How Loading Screens Work

The loader is a small program that runs first:

```
Memory Layout:
┌──────────────────────┐ $FFFF
│  Kernal ROM          │
├──────────────────────┤ $E000
│  (I/O area)          │
├──────────────────────┤ $D000
│  Main Game Code      │  ← Loads second
│  (being loaded)      │
├──────────────────────┤ $2000
│  Loading Screen      │  ← Already in memory
│  + Music Player      │
├──────────────────────┤ $0800
│  Loader Code         │  ← Loads first, runs while loading
└──────────────────────┘ $0000
```

The loader displays graphics and plays music while streaming data from tape.

## IRQ-Driven Loading

The key is using interrupts to multitask:

```asm
; Simplified loading screen concept
loading_irq:
            ; Update music every frame
            jsr music_play

            ; Animate loading bar
            jsr update_progress

            ; Check if more data to load
            lda loading_complete
            beq .continue

            ; Jump to main game
            jmp game_start

.continue:
            ; Acknowledge interrupt
            lda #$01
            sta $D019
            rti
```

The IRQ fires every frame, updating music and graphics while the main loop handles data streaming.

## Turbo Loaders

Standard Commodore loading uses the serial bus slowly. Turbo loaders bypass this:

```asm
; Turbo tape loader concept (simplified)
read_byte:
            ldx #8              ; 8 bits per byte
.bit_loop:
            ; Wait for pulse edge
            lda $DD0D           ; CIA timer
            and #$10
            beq .bit_loop

            ; Measure pulse width
            lda $DD04           ; Timer low byte

            ; Decode bit from pulse length
            cmp #THRESHOLD
            rol result          ; Rotate into result

            dex
            bne .bit_loop
            rts
```

Famous loaders:
- **Novaload** - Rainbow stripes during load
- **Firebird** - Distinctive pulse patterns
- **Ocean** - Iconic loading screens with music

## Loading Screen Graphics

Two main approaches:

### Multicolour Bitmap (160×200)
```asm
; Set up multicolour mode
            lda #$3B            ; Bitmap mode
            sta $D011
            lda #$18            ; Multicolour
            sta $D016

; Point to bitmap and screen RAM
            lda #$18            ; Bitmap at $2000, screen at $0400
            sta $D018
```

### Character-Based Art
```asm
; Custom character set for logo
            lda #$1C            ; Chars at $3000
            sta $D018

; Copy pre-designed screen
            ldx #0
.copy:
            lda loading_screen,x
            sta $0400,x
            lda loading_colours,x
            sta $D800,x
            ; ... continue for full screen
```

## Music During Loading

The SID can play while loading if carefully timed:

```asm
; Music must be interrupt-driven
; and not conflict with loader timing

music_init:
            ; Set up SID
            ; ...
            rts

music_play:
            ; Called from IRQ
            ; Must be cycle-counted
            ; ...
            rts
```

Limitations:
- Can't use noise waveform (interferes with tape signals)
- Must be very cycle-stable
- Simple melodies work best

## Why We Don't Need One

Our game loads instantly:

| Method | Result |
|--------|--------|
| VICE emulator | Instant load |
| SD2IEC | Near-instant |
| Ultimate 64 | Instant |
| Real 1541 + JiffyDOS | ~5 seconds |

Loading screens matter for tape distribution, which is rare today.

## If We Added One

For authentic .d64 disk distribution:

1. **Create loader** - Small program at $0801
2. **Design screen** - Multicolour bitmap or character art
3. **Add music** - Simple SID tune (no noise)
4. **Progress bar** - Show loading percentage
5. **Seamless transition** - Jump to game when done

The loader would be maybe 2-3KB, leaving plenty of room for impressive graphics.
