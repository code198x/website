## What Are Polyrhythms?

Polyrhythm means "many rhythms"—multiple rhythmic patterns occurring simultaneously. In our context, this manifests as multiple notes on the same beat:

```
Beat:     0   1   2   3   4
Track 1:  [X]     [X]     [X]
Track 2:  [X]         [X] [X]
Track 3:  [X]     [X] [X]
```

Beat 0 has notes on all three tracks simultaneously—a three-note chord. Beat 3 has a two-note chord. Beat 4 has another two-note chord.

## Chord Data Structure

Our note format already supports chords naturally. Each note entry specifies beat, track, and frequency:

```asm
song5_normal:
            !byte 0, 1, $47          ; Beat 0, Track 1
            !byte 0, 2, $3B          ; Beat 0, Track 2 (chord!)
            !byte 0, 3, $27          ; Beat 0, Track 3 (3-note chord!)
            !byte 4, 1, $47          ; Beat 4, single note
            ; ...
```

When multiple notes share the same beat number, they appear simultaneously on screen—and must be hit together.

## Difficulty Progression

Our three difficulty variants handle chords differently:

| Difficulty | Notes | Chords | Strategy |
|------------|-------|--------|----------|
| Easy | 12 | 6 two-note | Learn chord coordination |
| Normal | 28 | Mix of 2/3-note | Build muscle memory |
| Hard | 70 | Frequent 3-note | Maximum coordination |

Easy mode uses only two-note chords, giving players time to learn the finger coordination. Hard mode throws three-note chords every few beats.

## Easy Pattern: Learning Chords

```asm
song5_easy:
            !byte 0, 1, $47          ; Track 1
            !byte 0, 2, $3B          ; Track 2 (2-note chord)
            !byte 8, 2, $3B          ; Single note
            !byte 16, 1, $47         ; Track 1
            !byte 16, 3, $27         ; Track 3 (2-note chord)
            ; ...
```

Chords appear on strong beats (0, 16, 32, 48), with single notes between them. This teaches the hand shape without overwhelming.

## Hard Pattern: Chord Storm

```asm
song5_hard:
            !byte 0, 1, $47          ; 3-note chord
            !byte 0, 2, $3B
            !byte 0, 3, $27
            !byte 2, 1, $47          ; 2-note chord
            !byte 2, 2, $3B
            !byte 4, 2, $3B          ; 3-note chord
            !byte 4, 1, $47
            !byte 4, 3, $27
            ; ...
```

Nearly every beat has multiple notes. The pattern alternates between two-note and three-note chords with minimal rest.

## Tempo Choice: 136 BPM

We chose a medium tempo for Chordstorm:

| Song | BPM | Focus |
|------|-----|-------|
| First Steps | 120 | Learning basics |
| Upbeat Groove | 130 | Building speed |
| Speed Rush | 150 | Reaction time |
| Off-Beat | 125 | Syncopation feel |
| Chordstorm | 136 | Chord coordination |

136 BPM is fast enough to be challenging but not so fast that chord coordination becomes impossible. At this tempo:

```
frames_per_beat = 3000 / 136 ≈ 22 frames
22 frames ÷ 50 fps = 440ms per beat
```

440ms gives players time to see and prepare for multi-note hits.

## Player Skills

Chordstorm tests different skills than single-note songs:

1. **Hand positioning** - Fingers must hover over multiple keys
2. **Simultaneous timing** - All notes must hit within the window
3. **Quick transitions** - Moving between chord shapes rapidly
4. **Visual scanning** - Reading multiple tracks at once

Players who excel at Speed Rush (fast single notes) may struggle with Chordstorm until they develop chord reflexes.

## Branch Distance Solutions

With more code, branch instructions reach their limits:

```asm
transition_to_game:
            lda selected_song
            beq setup_song1
            cmp #1
            beq setup_song2
            cmp #2
            bne +
            jmp setup_song3
+           cmp #3
            bne ++
            jmp setup_song4
++          jmp setup_song5
```

The trampoline pattern (`bne` over `jmp`) handles far targets while keeping the logic readable.
