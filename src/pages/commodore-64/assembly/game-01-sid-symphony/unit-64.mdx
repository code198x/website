## Distribution Formats

### PRG File
The simplest format—what we've been making:
```bash
acme -f cbm -o symphony.prg symphony.asm
```
Works with emulators and SD card solutions like SD2IEC.

### D64 Disk Image
Standard 1541 disk format:
```bash
c1541 -format "sidsym,ss" d64 sidsymphony.d64
c1541 sidsymphony.d64 -write symphony.prg symphony
```
Required for accurate 1541 emulation.

## Creating a Release Package

A professional release includes:

```
sidsymphony-v1.0/
├── symphony.prg           # Game file
├── sidsymphony.d64       # Disk image
├── README.txt            # Instructions
├── CREDITS.txt           # Acknowledgements
├── screenshot.png        # For listing pages
└── source/               # Optional: source code
    └── symphony.asm
```

## Where to Release

### CSDb (csdb.dk)
The primary database for C64 releases:
- Create releaser account
- Upload with proper credits
- Tag correctly (Game, Music, etc.)

### itch.io
Modern game marketplace:
- Set up C64 page
- Include emulator instructions
- Can charge or offer free

### Lemon64
Active C64 community:
- Post in forum
- Get feedback
- Build reputation

### GitHub
For open source releases:
- Include source code
- Document build process
- Accept contributions
