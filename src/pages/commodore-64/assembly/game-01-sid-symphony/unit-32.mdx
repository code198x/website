Phase 2 is complete. What began as a simple single-song rhythm game in Phase 1 has grown into a feature-complete experience with six songs, multiple game modes, and rich scoring mechanics.

This unit consolidates all Phase 2 features and prepares for Phase 3's visual and audio polish.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

## Phase 2 Feature Summary

Over 16 units, we built substantial content and systems:

### Content (Units 17-21, 24, 26, 29)

| Song | BPM | Focus |
|------|-----|-------|
| First Steps | 120 | Basic timing |
| Upbeat Groove | 130 | Track variety |
| Speed Rush | 150 | Fast reactions |
| Off-Beat | 125 | Syncopation |
| Chordstorm | 136 | Polyrhythms |
| Fusion | 130 | All combined |

Six songs × three difficulties = 18 distinct challenges.

### Game Modes (Units 23, 27-28)

| Mode | Purpose |
|------|---------|
| Normal | Complete songs for high scores |
| Practice | No health loss, adjustable speed |
| Endless | Songs loop until health depletes |

Players can learn without penalty, then challenge themselves for records.

### Scoring Systems (Units 25, 30-31)

| Feature | Description |
|---------|-------------|
| High scores | Per song/difficulty, persists in session |
| Combo multiplier | 1x-4x based on consecutive hits |
| Perfect streaks | Bonus every 5 consecutive perfects |
| Section bonuses | Rewards at 25%, 50%, 75% completion |
| Full combo bonus | 200 points for zero misses |
| Performance grades | S/A/B/C/D based on accuracy |

Multiple overlapping systems reward different aspects of skill.

## Integration Verification

Phase completion means verifying everything works together:

### Mode Combinations

| Practice | Endless | Result |
|----------|---------|--------|
| OFF | OFF | Standard play |
| ON | OFF | Learn without penalty |
| OFF | ON | Survival challenge |
| ON | ON | Infinite practice loop |

All four combinations function correctly.

### State Transitions

```
TITLE → MENU → PLAYING → RESULTS → MENU
                      ↓
                 GAME OVER → MENU
```

Every transition works. No stuck states. No crashes.

### Score Flow

1. Hit note → base points
2. Apply combo multiplier
3. Check streak bonus
4. Check section milestone
5. Update display

All scoring layers compose without conflict.
