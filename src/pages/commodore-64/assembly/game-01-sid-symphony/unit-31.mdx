Numbers tell part of the story. A score of 4,350 means nothing without context—was that good? Great? Mediocre? Performance grades give players instant understanding of how well they played.

This unit adds letter grades (S/A/B/C/D), accuracy percentage calculation, and best streak tracking to the results screen.

## Grade Thresholds

Letter grades based on perfect hit percentage:

```asm
; Performance grade thresholds (based on accuracy percentage)
GRADE_S_THRESHOLD = 95          ; 95%+ perfect rate = S rank
GRADE_A_THRESHOLD = 85          ; 85%+ = A rank
GRADE_B_THRESHOLD = 70          ; 70%+ = B rank
GRADE_C_THRESHOLD = 50          ; 50%+ = C rank
                                ; Below 50% = D rank
```

S rank requires near-perfection—95% of all hits must be perfect timing. This creates aspirational goals for dedicated players.

## Grade Variables

Two variables store the calculated grade:

```asm
current_grade = $23             ; Current performance grade letter (screen code)
current_grade_col = $24         ; Colour for current grade
```

Screen codes and colours are calculated together so display is immediate.

## Percentage Calculation

Calculating (perfect_count × 100) / notes_hit requires multiplication and division in 8-bit assembly:

```asm
calculate_grade:
            ; If no notes hit, give D grade
            lda notes_hit
            bne calc_grade_continue
            lda #'d'
            sta current_grade
            lda #2                  ; Red
            sta current_grade_col
            rts

calc_grade_continue:
            ; Multiply perfect_count by 100
            ; Using shifts: 100 = 64 + 32 + 4
            lda perfect_count
            sta work_lo
            lda #0
            sta work_hi
```

We check for zero notes first to avoid division by zero.

## Multiplication by Shifting

Multiplying by 100 uses binary decomposition:

```asm
            ; Multiply by 100 (64 + 32 + 4 = 100)
            ; work = perfect * 64
            asl work_lo
            rol work_hi             ; *2
            asl work_lo
            rol work_hi             ; *4
            ...
            asl work_lo
            rol work_hi             ; *64
```

Six shifts create ×64, then we add ×32 and ×4 to get ×100. This avoids slow multiplication loops.

## Division by Subtraction

For small dividends, repeated subtraction is simplest:

```asm
grade_div_loop:
            ; Check if work >= notes_hit
            lda work_hi
            bne grade_can_sub       ; High byte nonzero, can subtract
            lda work_lo
            cmp notes_hit
            bcc grade_div_done      ; work < notes_hit, done
grade_can_sub:
            ; Subtract notes_hit from work
            lda work_lo
            sec
            sbc notes_hit
            sta work_lo
            lda work_hi
            sbc #0
            sta work_hi
            inc ZP_TEMP             ; Increment percentage
            lda ZP_TEMP
            cmp #101                ; Cap at 100%
            bcc grade_div_loop
```

Each subtraction increments the quotient. We cap at 100% to prevent overflow from rounding.

## Grade Determination

Cascading comparisons find the correct grade:

```asm
            lda ZP_TEMP
            cmp #GRADE_S_THRESHOLD
            bcs grade_is_s
            cmp #GRADE_A_THRESHOLD
            bcs grade_is_a
            cmp #GRADE_B_THRESHOLD
            bcs grade_is_b
            cmp #GRADE_C_THRESHOLD
            bcs grade_is_c
            ; Below C threshold = D
```

Branch-if-carry-set (BCS) checks "greater than or equal" after a compare.

## Grade Colours

Each grade has a distinct colour for instant recognition:

```asm
grade_is_s:
            lda #'s'
            sta current_grade
            lda #7                  ; Yellow
            sta current_grade_col
            rts

grade_is_a:
            lda #'a'
            sta current_grade
            lda #5                  ; Green
            sta current_grade_col
            rts
```

| Grade | Colour | Meaning |
|-------|--------|---------|
| S | Yellow | Superb—near perfect |
| A | Green | Excellent |
| B | Cyan | Good |
| C | Light grey | Average |
| D | Red | Needs practice |

## Grade Display

The grade appears prominently on the results screen:

```asm
draw_grade:
            ; Calculate and display performance grade
            jsr calculate_grade
            ; Display grade label
            ldx #0
draw_grade_label:
            lda grade_label,x
            beq draw_grade_letter
            sta SCREEN + (7 * 40) + 14,x
            lda #7
            sta COLRAM + (7 * 40) + 14,x
            inx
            jmp draw_grade_label

draw_grade_letter:
            lda current_grade
            sta SCREEN + (7 * 40) + 22
            ldx current_grade_col
            stx COLRAM + (7 * 40) + 22
```

The grade letter stands alone, coloured for impact.

## Best Streak Display

We also show the best perfect streak achieved:

```asm
            ; Draw best streak on row 19
            ldx #0
draw_streak_label:
            lda streak_label,x
            beq draw_streak_value
            sta SCREEN + (19 * 40) + 12,x
            lda #3                  ; Cyan
            sta COLRAM + (19 * 40) + 12,x
            inx
            jmp draw_streak_label
```

Players see their longest run of consecutive perfect hits—a secondary goal beyond the overall grade.
