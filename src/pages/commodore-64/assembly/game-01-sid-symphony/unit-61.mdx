## Scrolling Implementation

Credits typically scroll vertically:

```asm
credits_scroll:
            ; Decrement scroll position
            dec credits_y
            lda credits_y
            cmp #$FF            ; Wrapped below 0?
            bne .no_wrap
            lda #7              ; Reset to 7
            sta credits_y
            jsr scroll_screen_up
.no_wrap:

            ; Set soft scroll register
            lda credits_y
            ora #$10            ; Bit 4 = screen on
            sta $D011
            rts

scroll_screen_up:
            ; Move screen memory up one row
            ldx #0
.loop:
            lda SCREEN+40,x
            sta SCREEN,x
            lda COLRAM+40,x
            sta COLRAM,x
            inx
            cpx #(24*40)
            bne .loop

            ; Clear bottom row
            ; Load next credits line
            rts
```

## Timing and Pacing

Credits should be readable:

| Element | Duration |
|---------|----------|
| Name | 2-3 seconds |
| Section gap | 1 second |
| Total | 30-60 seconds |

Too fast = unreadable. Too slow = boring.

## Music Selection

Credits music should:

- **Feel conclusive** - Resolution, not tension
- **Match game tone** - Upbeat for fun games
- **Loop gracefully** - If credits are longer than music

## Easter Eggs

Hidden content rewards dedicated players:

```asm
; Check for secret input during credits
check_easter_egg:
            lda key_sequence
            cmp #KONAMI_CODE     ; Up, up, down, down...
            bne .no_egg

            ; Secret unlocked!
            jsr show_bonus_content
.no_egg:
            rts
```

Common easter eggs:
- Developer photos
- Outtakes/bloopers
- Hidden mini-games
- Special messages

## Credits Data Format

Efficient storage:

```asm
credits_data:
            !byte CREDIT_TITLE
            !scr "sid symphony"
            !byte 0

            !byte CREDIT_SECTION
            !scr "code"
            !byte 0

            !byte CREDIT_NAME
            !scr "your name"
            !byte 0

            !byte CREDIT_END
```

The byte prefix indicates formatting.
