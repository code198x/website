The final song is the boss fight of rhythm games. It tests everything players have learnt while providing a satisfying capstone to their journey.

## Finale Design Philosophy

A great finale song balances challenge with reward:

| Element | Purpose |
|---------|---------|
| Callbacks | Reference earlier songs' patterns |
| Escalation | Build intensity throughout |
| Spectacle | Impressive audio and visuals |
| Mastery test | Require all learnt skills |

## Building to the Climax

Structure the song with clear phases:

```
Intro (Easy):      Establish theme
Build (Medium):    Add complexity
Challenge (Hard):  Full intensity
Cooldown:          Brief respite
Finale (Extreme):  Ultimate test
Resolution:        Satisfying ending
```

## Pattern Callbacks

Reference earlier songs:

```asm
; Opening recalls Song 1's simple pattern
song7_pattern1:
            !byte 1, 0, 0, 0        ; Like "First Steps"

; Bridge uses Song 3's speed
song7_pattern2:
            !byte 1, 2, 1, 3        ; Fast like "Speed Rush"

; Pre-finale echoes Song 5's polyrhythms
song7_pattern3:
            !byte 1, 1, 2, 2, 3, 3  ; Complex like "Chordstorm"
```

Players recognise familiar elements—it feels like a celebration of their journey.

## Difficulty Curve

Avoid frustration through careful tuning:

```
✗ Constant maximum difficulty = Exhaustion
✗ Random spikes = Unfair
✓ Gradual escalation with breathers = Engaging
```

Give players moments to recover and appreciate their progress.

## Audio Spectacle

The finale should sound special:

- **Full SID utilisation** - All three voices active
- **Filter sweeps** - Dynamic audio
- **Tempo changes** - Dramatic pacing
- **Chord progression** - Musical resolution

## Victory Reward

Players who complete the finale deserve celebration:

```asm
finale_complete:
            ; Special victory screen
            jsr draw_finale_victory

            ; Play special jingle
            jsr play_finale_fanfare

            ; Show completion stats
            jsr display_game_stats

            ; Unlock credits
            lda #1
            sta credits_unlocked
```
