## Musical Design Philosophy

The two songs should feel different while remaining similarly challenging:

| Aspect | First Steps | Upbeat Groove |
|--------|-------------|---------------|
| Tempo | 120 BPM | 130 BPM |
| Key | Minor | Major |
| Feel | Steady, deliberate | Bouncy, energetic |
| Notes | ~27 | ~52 |
| Character | Introductory | Challenging |

Both songs have similar difficulty, but the faster tempo of Song 2 demands quicker reactions.

## Per-Song Tempo

Each song needs its own tempo. We store frames-per-beat as a variable:

```asm
; Per-song tempo (frames per beat)
TEMPO_SONG1   = 25              ; 120 BPM (50fps / 25 = 2 beats/sec)
TEMPO_SONG2   = 23              ; 130 BPM (50fps / 23 = ~2.17 beats/sec)

; Zero page variable
frames_per_beat = $13           ; Current song's tempo
```

The main loop now uses this variable instead of a constant:

```asm
update_playing:
            inc frame_count
            lda frame_count
            cmp frames_per_beat     ; Use per-song tempo!
            bcc no_new_beat
```

## Song Selection Logic

When transitioning to gameplay, we load the appropriate song data:

```asm
transition_to_game:
            lda selected_song
            beq load_song1
            jmp load_song2

load_song1:
            lda #TEMPO_SONG1
            sta frames_per_beat
            lda #<song1_data
            sta song_data_ptr
            lda #>song1_data
            sta song_data_ptr+1
            jmp start_game

load_song2:
            lda #TEMPO_SONG2
            sta frames_per_beat
            lda #<song2_data
            sta song_data_ptr
            lda #>song2_data
            sta song_data_ptr+1
```

The song data pointer is a 16-bit address stored in two bytes. When initialising the song, we copy this to `song_pos`:

```asm
init_song:
            ; Point to selected song data
            lda song_data_ptr
            sta song_pos
            lda song_data_ptr+1
            sta song_pos_hi
```

## Composing Song 2

"Upbeat Groove" uses a major key (C major) for brightness:

```asm
song2_data:
            ; Opening - bouncy start
            !byte 0, 1, $47          ; C5 - bright start
            !byte 1, 2, $35          ; G4 - quick response
            !byte 3, 3, $16          ; E3 - bass hit

            ; Bouncy phrase 1
            !byte 4, 1, $4F          ; D5
            !byte 5, 2, $2C          ; E4
            !byte 7, 1, $47          ; C5
            !byte 8, 3, $11          ; C3 bass
```

Notice the syncopation—notes fall on odd beats (1, 3, 5, 7) more often than Song 1's steady on-beat patterns. This creates the "bouncy" feel.

## SID Frequencies and Musical Notes

The high byte of the SID frequency roughly maps to musical notes:

| Note | Freq Hi | Character |
|------|---------|-----------|
| C3 | $11 | Deep bass |
| E3 | $16 | Bass |
| G3 | $1A | Bass |
| E4 | $2C | Low mid |
| G4 | $35 | Mid |
| C5 | $47 | High |
| D5 | $4F | High |
| E5 | $58 | Bright |
| G5 | $6A | Very high |

Song 2 uses more high notes ($47-$6A range) than Song 1, contributing to its brighter sound.

## Menu Updates

The menu now shows both songs with tempo information:

```asm
draw_song_list:
            ; Song 1: "First Steps" (120 BPM)
            ldx #0
draw_song1:
            lda song1_name,x
            ; ...

            ; Song 1 tempo info
            ldx #0
draw_tempo1:
            lda song1_tempo_text,x
            ; ...

            ; Song 2: "Upbeat Groove" (130 BPM)
            ldx #0
draw_song2:
            lda song2_name,x
            ; ...
```

Players can see what they're choosing before they commit.

## Note Density Comparison

Song 2 has nearly twice as many notes as Song 1:

**Song 1 structure:**
- Gentle intro (3 notes)
- Build (3 notes)
- Complexity (4 notes)
- Theme (3 notes)
- Variation (3 notes)
- Intensity (4 notes)
- Climax (5 notes)
- Resolution (4 notes)
- **Total: ~27 notes**

**Song 2 structure:**
- Bouncy intro (3 notes)
- Phrase 1 (4 notes)
- Syncopated section (5 notes)
- Energy build (5 notes)
- High energy (6 notes)
- Interlude (6 notes)
- Peak section (8 notes)
- Continued intensity (6 notes)
- Wind down (4 notes)
- Final phrase (5 notes)
- **Total: ~52 notes**

More notes at faster tempo—Song 2 is noticeably harder, preparing players for difficulty levels in the next unit.
