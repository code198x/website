Learning individual skills is one thing. Applying them together is another. Our sixth song, "Fusion," combines basic rhythm, syncopation, and polyrhythms into a comprehensive test of everything players have learnt.

This unit adds a song that synthesises all previous techniques while reorganising the menu to accommodate six songs.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

![Unit 29 Screenshot](/images/commodore-64/game-01-sid-symphony/unit-29/screenshot.png)

The menu now shows six songs with "Fusion" at 130 BPM. This song doesn't introduce new mechanics—it combines existing ones in challenging ways.

## What Makes Fusion Different

Each previous song focused on one technique:

| Song | BPM | Focus |
|------|-----|-------|
| First Steps | 120 | Basic timing |
| Upbeat Groove | 130 | Track variety |
| Speed Rush | 150 | Fast reactions |
| Off-Beat | 125 | Syncopation |
| Chordstorm | 136 | Polyrhythms |
| Fusion | 130 | All combined |

Fusion doesn't add new skills—it demands players use all skills simultaneously.

## Pattern Design Philosophy

Easy mode introduces combinations gently:

```asm
song6_easy:
            !byte 0, 1, $47          ; Strong beat
            !byte 4, 2, $3B          ; Basic rhythm
            !byte 8, 1, $47
            !byte 8, 2, $3B          ; Simple 2-note chord
            !byte 14, 3, $27         ; Off-beat (syncopation)
```

Players encounter each element—basic beats, simple chords, off-beats—with breathing room between challenges.

## Normal Mode: Building Complexity

Normal mode layers techniques within sections:

```asm
song6_normal:
            ; Section 1: Basic + syncopation
            !byte 0, 1, $47          ; Strong downbeat
            !byte 2, 2, $3B          ; Quick follow
            !byte 6, 3, $27          ; Off-beat
            ; Section 2: Add chords
            !byte 16, 1, $47         ; 2-note chord
            !byte 16, 2, $3B
            ; Section 3: Full mix
            !byte 32, 1, $47         ; 3-note chord
            !byte 32, 2, $3B
            !byte 32, 3, $27
```

Each section adds complexity, building to full integration in section 3.

## Hard Mode: Maximum Challenge

Hard mode throws everything at once:

```asm
song6_hard:
            ; Section 1: Fast basic + syncopation
            !byte 0, 1, $47
            !byte 1, 2, $3B
            !byte 2, 3, $27
            !byte 3, 1, $58          ; Off-beat
            !byte 8, 1, $47          ; 2-note chord
            !byte 8, 2, $3B
```

Notes arrive every beat, chords appear frequently, and off-beats disrupt expected patterns. Players need automatic responses to each technique.

## Song Setup Pattern

Song 6 follows the established pattern:

```asm
setup_song6:
            lda #TEMPO_SONG6
            sta frames_per_beat
            lda #LENGTH_SONG6
            sta song_length

            ; Select difficulty variant
            lda difficulty
            cmp #DIFF_EASY
            beq load_s6_easy
            cmp #DIFF_NORMAL
            beq load_s6_normal
            jmp load_s6_hard
```

The structure is identical to other songs—only the data pointers differ.

## High Score Table Growth

With six songs and three difficulties, we need 18 high score entries:

```asm
; High Score Table (6 songs x 3 difficulties = 18 entries)
high_scores:
            ; Songs 1-5...
            ; Song 6 (Fusion)
            !word 0               ; Easy
            !word 0               ; Normal
            !word 0               ; Hard
```

The index formula `(song × 3) + difficulty` handles all 18 entries automatically.

## Skill Synthesis Value

Why create a "fusion" song rather than just more technique-specific songs?

1. **Transfer testing** - Can players apply skills in new contexts?
2. **Adaptive switching** - Must quickly shift between technique mindsets
3. **Pattern recognition** - Identifying which technique a pattern requires
4. **Confidence building** - Success proves comprehensive mastery
