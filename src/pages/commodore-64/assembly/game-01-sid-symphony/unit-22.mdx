A combo counter that just shows numbers isn't enough. Players need to *feel* when they're on fire.

This unit adds escalating visual feedback. As your combo builds, the border colour shifts through stages—dark grey, green, yellow, red. Breaking a big combo resets everything to black, making the loss tangible.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

Play any song and watch the border. As you build a combo, the colour intensifies. Miss a note at a 50+ combo and watch everything go dark.

## The Feedback Problem

Our combo system works mechanically—multipliers increase, scores scale. But the visual feedback is subtle. A number changing from "49" to "50" doesn't convey the significance of hitting Tier 4.

Players need:
1. **Peripheral awareness** - See combo status without looking at the number
2. **Emotional escalation** - Feel the building intensity
3. **Visceral loss** - Breaking a streak should hurt

The border is perfect for this. It surrounds the entire screen, visible in peripheral vision, and changes are immediately noticeable.

## Combo Border Colours

We define colours for each tier:

```asm
; Combo border colours (escalating intensity)
COMBO_BORDER_0 = 0              ; Black - no combo
COMBO_BORDER_1 = 11             ; Dark grey - building
COMBO_BORDER_2 = 5              ; Green - 2x (tier 2)
COMBO_BORDER_3 = 7              ; Yellow - 3x (tier 3)
COMBO_BORDER_4 = 2              ; Red - 4x (tier 4 / fire!)
```

The progression is deliberate:
- **Black** (0): No combo—neutral state
- **Dark grey** (11): Building towards Tier 2—something's happening
- **Green** (5): 2x multiplier—positive reinforcement
- **Yellow** (7): 3x multiplier—caution, getting serious
- **Red** (2): 4x multiplier—you're on fire!

## Updating the Border

When displaying the combo, we now also set the border:

```asm
combo_col_1x:
            lda #11             ; Grey text
            ldx #COMBO_BORDER_1 ; Dark grey border
            jmp set_combo_col

combo_col_2x:
            lda #7              ; Yellow text
            ldx #COMBO_BORDER_2 ; Green border
            jmp set_combo_col

combo_col_3x:
            lda #5              ; Green text
            ldx #COMBO_BORDER_3 ; Yellow border
            jmp set_combo_col

combo_col_4x:
            lda #1              ; White text
            ldx #COMBO_BORDER_4 ; Red border (fire!)

set_combo_col:
            sta COLRAM + (COMBO_ROW * 40) + 34
            sta COLRAM + (COMBO_ROW * 40) + 35
            sta COLRAM + (COMBO_ROW * 40) + 36

            ; Update border colour for visual feedback
            lda combo
            beq reset_border    ; No combo = black border
            stx BORDER          ; Set border to tier colour
            rts

reset_border:
            lda #COMBO_BORDER_0
            sta BORDER
            rts
```

The X register carries the border colour through the branching logic. When we set the combo text colour (in A), we simultaneously set the border (in X).

## The Emotional Arc

Consider a player's experience during a good run:

| Combo | Border | Player Feels |
|-------|--------|--------------|
| 0 | Black | Neutral, starting fresh |
| 1-9 | Dark grey | Something's building... |
| 10-24 | Green | I'm doing well! |
| 25-49 | Yellow | Getting intense... |
| 50+ | Red | ON FIRE! Don't mess up! |

The colour escalation creates tension. At red border, every note matters. The player's palms sweat. Their focus sharpens.

Then they miss.

| Combo | Border | Player Feels |
|-------|--------|--------------|
| 0 | Black | Devastating. All that progress, gone. |

The instant shift from red to black is punishing—and motivating. They want to get back there.

## Why the Border?

We could use other visual feedback:
- **Background colour** - Too distracting, affects note visibility
- **Text colour only** - Requires looking at the number
- **Sprite effects** - Possible, but complex

The border provides:
1. **Peripheral visibility** - Always visible without focus shift
2. **Non-intrusive** - Doesn't affect gameplay area
3. **Instant updates** - Single register write
4. **Universal meaning** - Coloured borders are standard "heat" indicators

## Colour Psychology

The colour choices aren't arbitrary:

- **Green** - Safety, success, "go" signal
- **Yellow** - Caution, attention, transitional
- **Red** - Danger, intensity, "hot"

This traffic-light progression is culturally universal. Players instinctively understand that green is good, red is extreme.

## Technical Note: Border Register

The C64 border colour is set via a single register:

```asm
BORDER = $D020
```

Writing a value (0-15) changes the entire border instantly. No need to wait for vertical blank—the change is immediate and safe.
