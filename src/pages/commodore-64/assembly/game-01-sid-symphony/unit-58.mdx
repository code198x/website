Two-player mode transforms SID Symphony from solo practice into social competition. Two players share the keyboard, each with their own controls, competing on the same song.

## Run It

Assemble and run:

```bash
acme -f cbm -o symphony.prg symphony.asm
```

![Unit 58 Screenshot](/images/commodore-64/game-01-sid-symphony/unit-58/screenshot.png)

Press "2" from the menu to toggle two-player mode. Version shows "PHASE 4 V0.10".

## The Design Challenge

Adding a second player requires:

1. **Separate state** - Independent scores, combos, health
2. **Different controls** - Non-conflicting keyboard areas
3. **Shared resources** - Same notes, same song
4. **Fair competition** - Equal opportunity for both

## Keyboard Layout

The C64 keyboard splits naturally:

```
┌─────────────────────────────────────────────┐
│ ← 1 2 3 4 5 6 7 8 9 0 + - £ HOME DEL      │
│  CTRL Q W E R T Y U I O P @ * ↑ RESTORE   │
│ R/S SL A S D F G H J K L : ; = RETURN     │
│  C= SHIFT Z X C B N M , . / SHIFT ↓ →     │
│         SPACE                              │
└─────────────────────────────────────────────┘

Player 1: Z, X, C (left side, bottom row)
Player 2: 1, 2, 3 (top row, left side)
```

Players sit side by side, each with their own area of the keyboard.

## Player 2 State Variables

We duplicate the essential game state:

```asm
; Zero page variables (Unit 58)
two_player_mode  = $4F          ; 0 = single, 1 = two player
p2_hit_quality   = $55          ; Player 2 hit quality
p2_combo         = $56          ; Player 2 current combo
p2_perfect_streak = $57         ; Player 2 consecutive perfects
p2_miss_track    = $58          ; Player 2 miss effect track

; Data section variables
p2_score_lo:  !byte 0
p2_score_hi:  !byte 0
p2_miss_count: !byte 0
p2_perfect_count: !byte 0
p2_good_count: !byte 0
p2_health:    !byte 0
p2_max_combo: !byte 0
p2_notes_hit: !byte 0
```

Each player tracks their own performance independently.

## Keyboard Scanning for Player 2

The C64 keyboard matrix requires different row/column combinations:

```asm
check_p2_keys:
            ; Check key 1 (row 0, bit 0) for track 1
            lda #$FE
            sta CIA1_PRA
            lda CIA1_PRB
            and #$01
            bne .check_p2_key2

            lda #1
            jsr check_p2_hit
            bcc .check_p2_key2
            jsr play_voice1_note

.check_p2_key2:
            ; Check key 2 (row 3, bit 0) for track 2
            lda #$F7
            sta CIA1_PRA
            lda CIA1_PRB
            and #$01
            bne .check_p2_key3

            lda #2
            jsr check_p2_hit
            ; ...
```

Each key requires its specific row and column mask in the keyboard matrix.

## Shared Notes, Separate Hits

Both players see the same notes, but each can hit independently:

```asm
; In check_p2_hit:
.p2_hit_success:
            ; Clear the note - BOTH players benefit
            lda #0
            sta note_track,x
            inc p2_notes_hit
            sec
            rts
```

When either player hits a note, it disappears. This creates interesting dynamics - players race for notes!

## Menu Toggle

Pressing "2" toggles two-player mode:

```asm
menu_2_pressed:
            ; Toggle two player mode
            lda two_player_mode
            eor #1
            sta two_player_mode
            jsr play_menu_move
            jsr draw_2p_state
            lda #KEY_DELAY
            sta key_delay_count
            jmp menu_check_fire
```

The display shows "2P: ON" or "2P: OFF" on the menu.

## Initialisation

When starting a game, both players get fresh state:

```asm
init_p2:
            lda #0
            sta p2_score_lo
            sta p2_score_hi
            sta p2_miss_count
            sta p2_perfect_count
            sta p2_good_count
            sta p2_combo
            sta p2_max_combo
            sta p2_notes_hit
            sta p2_hit_quality
            sta p2_perfect_streak
            sta p2_miss_track
            lda #100                ; Full health
            sta p2_health
            rts
```

Both players start with full health and zero score.

## Competition Modes

Two-player rhythm games often use different modes:

| Mode | Description |
|------|-------------|
| Race | First to reach score wins |
| Survival | Last player standing wins |
| Accuracy | Highest percentage wins |
| Co-op | Combined score vs threshold |

Our current implementation is basic race mode - highest score at song end wins.
