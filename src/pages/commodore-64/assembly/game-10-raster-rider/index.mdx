## What You'll Build

Racing game with pseudo-3D road using raster effects.

The road stretches into the distance. Other cars weave ahead. This is Out Run on the C64 — and it's all done with raster tricks. Colour cycling creates the illusion of speed. Perspective is simulated line by line.

## Skills You'll Master

- **Advanced raster splits** — per-scanline changes
- **Colour cycling** — speed illusion
- **Road perspective** — pseudo-3D rendering
- **Opponent cars** — traffic AI
- **Timer-based gameplay** — checkpoint racing
- **Track variety** — different courses
- **Position scoring** — race results

## Prerequisites

Complete **Game 9: Sprite Storm** first.
