## What You'll Build

Number guessing game with scoring. Simple text-based game introducing BASIC fundamentals.

The computer thinks of a number. You guess. Higher? Lower? Each guess narrows down the possibilities. Score based on attempts. This deceptively simple game teaches the foundations of programming — variables, conditionals, loops, and the game loop itself.

## Skills You'll Master

- **BASIC environment** — direct mode and program mode
- **Variables and data types** — storing information
- **INPUT and PRINT** — interaction with the player
- **IF/THEN logic** — making decisions
- **FOR/NEXT loops** — repetition
- **Random numbers** — RND function
- **Simple game loop** — the heartbeat of every game
- **Screen clearing** — PRINT CHR$(147)

## Prerequisites

None — this is your first game!

## Time Investment

64 units at 60-90 minutes each. Roughly 64-96 hours total.
