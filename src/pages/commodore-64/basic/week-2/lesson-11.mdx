## Why String Manipulation Matters

Text adventures, command parsers, password checkers - they all need to slice and analyse strings. Instead of checking entire phrases, you can extract words, compare parts, and respond intelligently.

## Getting String Length

```basic
NEW
10 INPUT "ENTER YOUR NAME";NM$
20 L=LEN(NM$)
30 PRINT "YOUR NAME HAS";L;"LETTERS"
```

**Run it!** Type a name and see how many characters it contains.

**Key point:** `LEN(string$)` returns the number of characters, including spaces.

## LEFT$ - Get Characters from the Left

```basic
NEW
10 TX$="COMMODORE 64"
20 PRINT LEFT$(TX$,9)
```

Output: `COMMODORE`

`LEFT$(string$, n)` returns the first `n` characters.

## RIGHT$ - Get Characters from the Right

```basic
NEW
10 TX$="COMMODORE 64"
20 PRINT RIGHT$(TX$,2)
```

Output: `64`

`RIGHT$(string$, n)` returns the last `n` characters.

## MID$ - Get Characters from the Middle

```basic
NEW
10 TX$="COMMODORE 64"
20 PRINT MID$(TX$,11,2)
```

Output: `64`

`MID$(string$, start, length)` returns `length` characters starting at position `start` (positions start at 1, not 0!).

## Combining String Functions

Extract the first word from a sentence:

```basic
NEW
10 INPUT "ENTER COMMAND";CM$
20 SP=1
30 FOR I=1 TO LEN(CM$)
40 IF MID$(CM$,I,1)=" " THEN SP=I:I=LEN(CM$)
50 NEXT I
60 WD$=LEFT$(CM$,SP-1)
70 PRINT "FIRST WORD: ";WD$
```

![First word extraction](./lesson11-firstword.png)

Type "GET SWORD" and it extracts "GET". This is how adventure games parse commands!

## How It Works

**Line 20**: Assume space at position 1 (handles single-word input)
**Lines 30-50**: Loop through each character looking for a space
**Line 40**: When space found, remember position and exit loop early
**Line 60**: Extract everything before the space

## WOW Moment: Text Adventure Parser

A simple but impressive command parser:

```basic
NEW
10 PRINT CHR$(147)
20 PRINT "YOU ARE IN A DARK ROOM."
30 PRINT "EXITS: NORTH, EAST"
40 PRINT "ITEMS: SWORD, LAMP"
50 PRINT
60 INPUT "WHAT DO YOU DO";CM$
70 GOSUB 1000
80 GOSUB 2000
90 GOTO 50
1000 REM *** PARSE COMMAND ***
1010 SP=0
1020 FOR I=1 TO LEN(CM$)
1030 IF MID$(CM$,I,1)=" " THEN SP=I:I=LEN(CM$)
1040 NEXT I
1050 IF SP=0 THEN VB$=CM$:OB$="":RETURN
1060 VB$=LEFT$(CM$,SP-1)
1070 OB$=MID$(CM$,SP+1,LEN(CM$)-SP)
1080 RETURN
2000 REM *** EXECUTE COMMAND ***
2010 IF VB$="GO" OR VB$="WALK" THEN GOSUB 3000:RETURN
2020 IF VB$="GET" OR VB$="TAKE" THEN GOSUB 4000:RETURN
2030 IF VB$="LOOK" OR VB$="EXAMINE" THEN GOSUB 5000:RETURN
2040 PRINT "I DON'T UNDERSTAND '";VB$;"'"
2050 RETURN
3000 REM *** GO COMMAND ***
3010 IF OB$="NORTH" OR OB$="N" THEN PRINT "YOU GO NORTH...":RETURN
3020 IF OB$="EAST" OR OB$="E" THEN PRINT "YOU GO EAST...":RETURN
3030 PRINT "YOU CAN'T GO THAT WAY"
3040 RETURN
4000 REM *** GET COMMAND ***
4010 IF OB$="SWORD" THEN PRINT "YOU TAKE THE SWORD":RETURN
4020 IF OB$="LAMP" THEN PRINT "YOU TAKE THE LAMP":RETURN
4030 PRINT "THERE'S NO ";OB$;" HERE"
4040 RETURN
5000 REM *** LOOK COMMAND ***
5010 PRINT "IT'S TOO DARK TO SEE MUCH"
5020 RETURN
```

![Text adventure parser](./lesson11-adventure.png)

Try these commands:
- `GET SWORD`
- `GO NORTH`
- `LOOK`
- `TAKE LAMP`
- `WALK EAST`

The parser splits your input into a verb (GET, GO, LOOK) and an object (SWORD, NORTH, LAMP), then executes the appropriate action!

## How the Parser Works

**Subroutine 1000 (Parse)**:
- Finds the space between words
- Extracts verb (VB$) before space
- Extracts object (OB$) after space
- Handles single-word commands (no space)

**Subroutine 2000 (Execute)**:
- Checks which verb was entered
- Calls the appropriate handler subroutine
- Shows error for unknown verbs

**Subroutines 3000-5000 (Handlers)**:
- Each verb has its own subroutine
- Checks the object and responds appropriately

## String Comparison Tips

BASIC V2 string comparison is case-sensitive:
- `"NORTH"="NORTH"` → TRUE
- `"north"="NORTH"` → FALSE

For real games, you'd convert input to uppercase first (we'll cover that in a later lesson).

## Quick Reference

```basic
LEN(A$)              REM Number of characters
LEFT$(A$,3)          REM First 3 characters
RIGHT$(A$,2)         REM Last 2 characters
MID$(A$,5,3)         REM 3 characters starting at position 5

REM String positions start at 1, not 0!
```

## What You've Learnt

- `LEN` tells you how long a string is
- `LEFT$` grabs characters from the start
- `RIGHT$` grabs characters from the end
- `MID$` grabs characters from any position
- String positions start at 1 (not 0 like arrays!)
- You can build command parsers by splitting input
- Subroutines organise complex logic
