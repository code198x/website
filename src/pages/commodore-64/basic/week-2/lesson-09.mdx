## Why Arrays Matter

You've learnt to store one value in a variable: `SC=100`. But what if you need to store 5 high scores? Or 10 enemy positions? Arrays let you store multiple related values under one name.

## Declaring an Array

Use `DIM` to create an array:

```basic
NEW
10 DIM SC(4)
20 SC(0) = 500
30 SC(1) = 450
40 SC(2) = 400
50 SC(3) = 350
60 SC(4) = 300
70 PRINT "HIGH SCORES:"
80 FOR I=0 TO 4
90 PRINT SC(I)
100 NEXT I
```

**Run it!** You'll see 5 high scores printed.

**Key points:**
- `DIM SC(4)` creates an array with 5 slots (0-4)
- Arrays in BASIC V2 always start at index 0
- Access each slot with `SC(0)`, `SC(1)`, etc.

## Building a High Score Table

Let's make it interactive:

```basic
NEW
10 PRINT CHR$(147)
20 DIM SC(4)
30 SC(0)=500:SC(1)=450:SC(2)=400
40 SC(3)=350:SC(4)=300
50 INPUT "YOUR SCORE";NS
60 GOSUB 1000
70 PRINT:PRINT "HIGH SCORES:"
80 FOR I=0 TO 4
90 PRINT I+1;") ";SC(I)
100 NEXT I
110 END
1000 REM *** INSERT SCORE ***
1010 IF NS<=SC(4) THEN RETURN
1020 FOR I=3 TO 0 STEP -1
1030 SC(I+1)=SC(I)
1040 NEXT I
1050 SC(0)=NS
1060 RETURN
```

![High score table](./lesson09-highscore.png)

Type in a score higher than 300 and watch it slot into the correct position!

## How It Works

**Lines 20-40**: Set up initial high scores
**Line 50**: Get player's score
**Line 60**: Call subroutine to insert score
**Lines 80-100**: Display the table

**The insertion subroutine (1000-1060)**:
- Line 1010: Only insert if score beats the lowest
- Lines 1020-1040: Shift all scores down one slot
- Line 1050: Put new score at the top

This is how every C64 game stores high scores!

## Storing Enemy Positions

Arrays are perfect for game objects:

```basic
NEW
10 PRINT CHR$(147)
20 DIM EX(7),EY(7)
30 FOR I=0 TO 7
40 EX(I)=INT(RND(1)*40)
50 EY(I)=INT(RND(1)*25)
60 NEXT I
70 REM *** DRAW ENEMIES ***
80 FOR I=0 TO 7
90 POKE 1024+EY(I)*40+EX(I),81
100 NEXT I
110 PRINT "8 ENEMIES PLACED!"
```

8 enemies (`Q` characters) appear at random positions. We're using two arrays: `EX()` for X coordinates, `EY()` for Y coordinates.

## String Arrays

You can store text too:

```basic
NEW
10 DIM NM$(4)
20 NM$(0)="ALICE"
21 NM$(1)="BOB"
22 NM$(2)="CAROL"
23 NM$(3)="DAVE"
24 NM$(4)="EVE"
30 FOR I=0 TO 4
40 PRINT NM$(I)
50 NEXT I
```

Notice the `$` - that's how you declare a string array!

## Common Pattern: Parallel Arrays

Store related data in matching arrays:

```basic
NEW
10 DIM NM$(2),SC(2)
20 NM$(0)="ALICE":SC(0)=500
21 NM$(1)="BOB":SC(1)=450
22 NM$(2)="CAROL":SC(2)=400
30 FOR I=0 TO 2
40 PRINT NM$(I);" - ";SC(I)
50 NEXT I
```

Each player has a name (in `NM$()`) and score (in `SC()`) at the same index.

## WOW Moment: Random Starfield

Let's use arrays to animate 20 stars:

```basic
NEW
10 PRINT CHR$(147)
20 DIM SX(19),SY(19)
30 FOR I=0 TO 19
40 SX(I)=INT(RND(1)*40)
50 SY(I)=INT(RND(1)*25)
60 NEXT I
70 REM *** ANIMATION LOOP ***
80 FOR I=0 TO 19
90 POKE 1024+SY(I)*40+SX(I),32
100 SX(I)=SX(I)-1
110 IF SX(I)<0 THEN SX(I)=39
120 POKE 1024+SY(I)*40+SX(I),46
130 NEXT I
140 FOR J=1 TO 10:NEXT J
150 GOTO 80
```

![Scrolling starfield](./lesson09-starfield.png)

Watch the stars scroll from right to left! This uses everything you've learnt:
- Arrays to store 20 star positions
- Loops to update all stars
- POKEs for fast screen drawing
- Wrapping when stars go off-screen

**This is the foundation of every space shooter's background!**

## Quick Reference

```basic
DIM AR(9)         REM Create array with 10 slots (0-9)
DIM NM$(4)        REM String array with 5 slots
AR(3) = 100       REM Store value
X = AR(3)         REM Retrieve value
```

## What You've Learnt

- Arrays store multiple values under one name
- Use `DIM` to declare array size
- Access elements with index: `AR(0)`, `AR(1)`...
- String arrays need `$`: `NM$()`
- Parallel arrays link related data
- Arrays + loops = powerful patterns
