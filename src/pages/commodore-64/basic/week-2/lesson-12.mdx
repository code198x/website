## Why DATA Matters

Typing the same numbers into arrays gets tedious fast. Mazes, levels, music notes, character sets - they all need lots of data. DATA statements let you store that information right in your program, then READ it when needed.

## Basic DATA and READ

```basic
NEW
10 DATA 100,200,300,400,500
20 FOR I=1 TO 5
30 READ SC
40 PRINT SC
50 NEXT I
```

Output:
```
100
200
300
400
500
```

**Key points:**
- DATA holds the values (can be anywhere in the program)
- READ fetches the next value each time it's called
- The DATA pointer automatically moves forward

## Multiple DATA Lines

You can split data across many lines:

```basic
NEW
10 DATA 1,2,3
20 DATA 4,5,6
30 DATA 7,8,9
40 FOR I=1 TO 9
50 READ N
60 PRINT N;
70 NEXT I
```

Output: `1 2 3 4 5 6 7 8 9`

BASIC reads through all DATA statements in order, from lowest to highest line number.

## String DATA

DATA can hold text too:

```basic
NEW
10 DATA ALICE,BOB,CAROL,DAVE,EVE
20 FOR I=1 TO 5
30 READ NM$
40 PRINT NM$
50 NEXT I
```

**Remember:** No quotes needed for simple strings in DATA (unless they contain commas or special characters).

## RESTORE - Reset the DATA Pointer

```basic
NEW
10 DATA 10,20,30
20 READ A:READ B:READ C
30 PRINT A;B;C
40 RESTORE
50 READ A:READ B:READ C
60 PRINT A;B;C
```

Output:
```
102030
102030
```

`RESTORE` moves the DATA pointer back to the first value, letting you READ the same data again.

## WOW Moment: Draw a Maze

Let's use DATA to store a 10×10 maze and draw it:

```basic
NEW
10 PRINT CHR$(147)
20 FOR Y=0 TO 9
30 FOR X=0 TO 10
40 READ C
50 POKE 1024+Y*40+X+5,C
60 IF C=32 THEN POKE 55296+Y*40+X+5,1
70 IF C=160 THEN POKE 55296+Y*40+X+5,0
80 NEXT X
90 NEXT Y
100 END
1000 DATA 160,160,160,160,160,160,160,160,160,160
1010 DATA 160,32,32,32,160,32,32,32,32,160
1020 DATA 160,32,160,32,160,32,160,160,32,160
1030 DATA 160,32,160,32,32,32,32,32,32,160
1040 DATA 160,32,160,160,160,160,160,160,32,160
1050 DATA 160,32,32,32,32,32,32,32,32,160
1060 DATA 160,32,160,160,32,160,160,160,32,160
1070 DATA 160,32,32,160,32,32,32,160,32,160
1080 DATA 160,160,32,160,160,160,32,160,32,160
1090 DATA 160,160,160,160,160,160,160,160,160,160
```

![Maze drawn from DATA](/images/lessons/commodore-64/basic/week-2/lesson-12/lesson12-maze.png)

A complete maze drawn from data! Character 160 (solid block) for walls in black, character 32 (space) for paths in white.

## How the Maze Works

**Lines 20-30**: Nested loops for rows (Y) and columns (X)

**Line 40**: READ the next character code

**Line 50**: POKE it to screen memory (offset by 5 to centre it)

**Lines 60-70**: Set colour - white (1) for paths, black (0) for walls

**Lines 1000-1090**: The maze data (10 rows × 10 columns = 100 values)

Want to change the maze? Just edit the DATA lines!

## Common Pattern: Level Data

This is exactly how classic C64 games stored levels:

```basic
NEW
10 PRINT CHR$(147)
20 REM *** READ LEVEL 1 ***
30 FOR I=1 TO 5
40 READ EX,EY
50 POKE 1024+EY*40+EX,81
60 NEXT I
70 END
1000 REM *** LEVEL 1: ENEMY POSITIONS ***
1010 DATA 10,5,20,8,15,12,25,15,30,10
```

Each pair of values is an X,Y position. Easy to add more levels by adding more DATA blocks!

## Reading Mixed Data

You can mix numbers and strings:

```basic
NEW
10 FOR I=1 TO 3
20 READ NM$,SC
30 PRINT NM$;":";SC
40 NEXT I
50 DATA ALICE,500
60 DATA BOB,450
70 DATA CAROL,400
```

Output:
```
ALICE:500
BOB:450
CAROL:400
```

Just make sure to READ in the same order as your DATA!

## Quick Reference

```basic
DATA 1,2,3,4,5        REM Store values
READ A                REM Read next value into A
RESTORE               REM Reset to first DATA value

REM DATA can contain:
DATA 100,200,300      REM Numbers
DATA HELLO,WORLD      REM Strings
DATA 10,ALICE,20      REM Mixed
```

## What You've Learnt

- DATA stores lists of values in your program
- READ fetches values one at a time
- RESTORE resets back to the first DATA value
- DATA can hold numbers, strings, or both
- Perfect for level data, mazes, music, character sets
- Professional games used DATA for all their levels
- Change the data without changing the code!
