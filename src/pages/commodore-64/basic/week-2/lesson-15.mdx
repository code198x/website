## Why Functions Matter

You've used subroutines for reusable code. But what about reusable **calculations**? Square roots, conversions, score multipliers - write them once as functions, use them everywhere.

## Defining a Simple Function

```basic
NEW
10 DEF FN SQ(X)=X*X
20 PRINT FN SQ(5)
30 PRINT FN SQ(12)
```

Output:
```
25
144
```

**Line 10**: `DEF FN SQ(X)` defines a function called SQ that squares X

**Lines 20-30**: Call the function with different values

## Using Functions in Formulas

```basic
NEW
10 DEF FN DB(X)=X*2
20 SC=100
30 PRINT "SCORE:";SC
40 PRINT "DOUBLE:";FN DB(SC)
```

Output:
```
SCORE: 100
DOUBLE: 200
```

Functions work anywhere you'd use a variable or number.

## Temperature Conversion

```basic
NEW
10 DEF FN CF(C)=C*9/5+32
20 INPUT "CELSIUS";C
30 F=FN CF(C)
40 PRINT C;"C = ";F;"F"
```

Perfect for converting game stats or measurements!

## WOW Moment: Projectile Arc Calculator

Calculate bullet trajectories:

```basic
NEW
10 PRINT CHR$(147)
20 DEF FN AR(T)=VY*T-4.9*T*T/(VX*VX)
30 INPUT "ANGLE (45=BEST)";AN
40 INPUT "SPEED (1-20)";SP
50 A=AN*0.01745
60 VX=SP*COS(A)
70 VY=SP*SIN(A)
80 PRINT:PRINT "TRAJECTORY:"
90 FOR T=0 TO 20 STEP 0.5
100 X=VX*T
110 Y=FN AR(T)
120 IF Y<0 THEN 150
130 SX=INT(X):SY=20-INT(Y)
140 IF SX<40 AND SY<25 THEN POKE 1024+SY*40+SX,42
150 NEXT T
160 PRINT:PRINT "HIT GROUND AT X=";INT(X)
```

![Projectile arc](/images/lessons/commodore-64/basic/week-2/lesson-15/lesson15-projectile.png)

Watch the bullet arc across the screen! The function calculates realistic gravity.

## How the Projectile Works

**Line 20**: `FN AR(T)` calculates Y position using physics formula
- Uses global variables VX and VY (set in lines 60-70)
- Only takes one parameter (T for time) as required by C64 BASIC

**Lines 30-70**: Get angle and speed, convert to velocity components

**Lines 90-150**: Loop through time, calculate and draw each position

**Line 110**: Function call returns Y position at time T

This is how every shooting game calculates bullet paths!

## The One-Parameter Limit

**IMPORTANT**: C64 BASIC V2 functions can only have ONE parameter:

✓ **Valid:**
```basic
DEF FN SQ(X)=X*X              REM One parameter
DEF FN DB(N)=N*2              REM One parameter
```

✗ **Invalid:**
```basic
DEF FN AV(A,B)=(A+B)/2        REM Multiple parameters - WON'T WORK!
```

## Working with Multiple Values

When you need multiple values, use global variables:

```basic
NEW
10 REM DISTANCE CALCULATOR
20 DEF FN DI(X)=SQR((X2-X1)*(X2-X1)+(Y2-Y1)*(Y2-Y1))
30 X1=5:Y1=5
40 X2=10:Y2=10
50 D=FN DI(0)
60 PRINT "DISTANCE:";INT(D)
```

The function uses X1, Y1, X2, Y2 as global variables, and takes a dummy parameter (0).

## Score Multiplier Example

```basic
NEW
10 DEF FN BO(SC)=SC*(1+LV*0.5)
20 SC=100:LV=3
30 PRINT "BASE SCORE:";SC
40 PRINT "WITH LEVEL";LV;"BONUS:";FN BO(SC)
```

Output:
```
BASE SCORE: 100
WITH LEVEL 3 BONUS: 250
```

LV is a global variable - the function uses it even though it's not a parameter.

## Function Limitations

C64 BASIC functions:
- Can only have **ONE parameter**
- Can only return **one value**
- Can't modify variables (pure calculation)
- Limited to **one line**
- Parameters must be numbers (no strings)
- Can use global variables for additional values

For complex logic, use subroutines instead.

## Common Game Functions

```basic
DEF FN SQ(X)=X*X                              REM Square
DEF FN RN(M)=INT(RND(1)*M)+1                  REM Random 1 to M
DEF FN CF(C)=C*9/5+32                         REM Celsius to Fahrenheit
DEF FN PC(V)=INT(V/MX*100)                    REM Percentage (uses global MX)
```

## Quick Reference

```basic
DEF FN NAME(PARAM)=FORMULA    REM Define function
RESULT=FN NAME(VALUE)         REM Call function

REM Examples:
DEF FN SQ(X)=X*X              REM Square
DEF FN DB(N)=N*2              REM Double
DEF FN HL(N)=N/2              REM Half
```

## What You've Learnt

- DEF FN defines reusable calculations
- Functions take ONE parameter and return one value
- Perfect for physics, scoring, conversions
- One line only (but can be complex)
- Numbers only, no strings
- Use global variables when you need multiple values
- Every calculation in games uses functions
- Makes code cleaner and more maintainable
