## Why Functions Matter

You've used subroutines for reusable code. But what about reusable **calculations**? Distance formulas, score multipliers, trajectory calculations - write them once as functions, use them everywhere.

## Defining a Simple Function

```basic
NEW
10 DEF FN SQ(X)=X*X
20 PRINT FN SQ(5)
30 PRINT FN SQ(12)
```

Output:
```
25
144
```

**Line 10**: `DEF FN SQ(X)` defines a function called SQ that squares X
**Lines 20-30**: Call the function with different values

## Multiple Parameters

```basic
NEW
10 DEF FN AV(A,B)=(A+B)/2
20 PRINT FN AV(10,20)
30 PRINT FN AV(5,15)
```

Output:
```
15
10
```

Functions can take multiple parameters - just separate them with commas.

## Using Functions in Formulas

```basic
NEW
10 DEF FN DI(X1,Y1,X2,Y2)=SQR((X2-X1)*(X2-X1)+(Y2-Y1)*(Y2-Y1))
20 X1=5:Y1=5:X2=10:Y2=10
30 D=FN DI(X1,Y1,X2,Y2)
40 PRINT "DISTANCE:";INT(D)
```

This calculates the distance between two points - essential for collision detection!

## WOW Moment: Projectile Arc Calculator

Calculate bullet trajectories:

```basic
NEW
10 PRINT CHR$(147)
20 DEF FN AR(X,S,A)=S*X-4.9*X*X/(A*A)
30 INPUT "ANGLE (45=BEST)";AN
40 INPUT "SPEED (1-20)";SP
50 A=AN*0.01745
60 VX=SP*COS(A)
70 VY=SP*SIN(A)
80 PRINT:PRINT "TRAJECTORY:"
90 FOR T=0 TO 20 STEP 0.5
100 X=VX*T
110 Y=FN AR(T,VY,VX)
120 IF Y<0 THEN 150
130 SX=INT(X):SY=20-INT(Y)
140 IF SX<40 AND SY<25 THEN POKE 1024+SY*40+SX,42
150 NEXT T
160 PRINT:PRINT "HIT GROUND AT X=";INT(X)
```

![Projectile arc](./lesson15-projectile.png)

Watch the bullet arc across the screen! The function calculates realistic gravity.

## How the Projectile Works

**Line 20**: `FN AR` calculates Y position using physics formula
**Lines 30-70**: Get angle and speed, convert to velocity components
**Lines 90-150**: Loop through time, calculate and draw each position
**Line 110**: Function call returns Y position at time T

This is how every shooting game calculates bullet paths!

## Function Limitations

C64 BASIC functions:
- Can only return **one value**
- Can't modify variables (pure calculation)
- Limited to **one line**
- Parameters must be numbers (no strings)

For complex logic, use subroutines instead.

## Score Multiplier Example

```basic
NEW
10 DEF FN BO(SC,LV)=SC*(1+LV*0.5)
20 SC=100:LV=3
30 PRINT "BASE SCORE:";SC
40 PRINT "WITH LEVEL";LV;"BONUS:";FN BO(SC,LV)
```

Output:
```
BASE SCORE: 100
WITH LEVEL 3 BONUS: 250
```

## Common Game Functions

```basic
DEF FN DI(X1,Y1,X2,Y2)=SQR((X2-X1)^2+(Y2-Y1)^2)  REM Distance
DEF FN SC(B,M)=INT(B*M)                           REM Score with multiplier
DEF FN RN(MN,MX)=INT(RND(1)*(MX-MN+1))+MN         REM Random in range
```

## Quick Reference

```basic
DEF FN NAME(PARAM)=FORMULA    REM Define function
RESULT=FN NAME(VALUE)         REM Call function

REM Examples:
DEF FN SQ(X)=X*X              REM Square
DEF FN AV(A,B)=(A+B)/2        REM Average
DEF FN MAX(A,B)=(A>B)*A+(A<=B)*B  REM Maximum
```

## What You've Learnt

- DEF FN defines reusable calculations
- Functions take parameters and return one value
- Perfect for physics, scoring, distance
- One line only (but can be complex)
- Numbers only, no strings
- Every calculation in games uses functions
- Makes code cleaner and more maintainable
