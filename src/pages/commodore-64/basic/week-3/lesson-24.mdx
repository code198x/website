## Collision Detection: Automatic Hit Testing!

Moving sprites is great, but games need to know when sprites **touch**. The C64 does this automatically! The VIC-II chip watches all sprites and sets bits in a register when they collide.

No calculations needed—the hardware does it for you!

## The Collision Register

**Register 53279** = Sprite-to-Sprite Collision

- Bit 0 = sprite 0 collided
- Bit 1 = sprite 1 collided
- Reading the register **clears** it!

## Basic Example

Detect if sprite 0 and sprite 1 touch:

```basic
10 REM *** COLLISION TEST ***
20 PRINT CHR$(147);"COLLISION DEMO"
30 REM SETUP TWO SPRITES
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,255:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53287,2:POKE 53288,7
80 POKE 53269,3:REM ENABLE BOTH
90 REM POSITION FAR APART
100 POKE 53248,50:POKE 53249,120
110 POKE 53250,250:POKE 53251,120
120 PRINT "SPRITES APART - NO HIT"
130 FOR I=1 TO 2000:NEXT I
140 REM MOVE TOGETHER
150 POKE 53248,100:POKE 53249,120
160 POKE 53250,110:POKE 53251,120
170 FOR I=1 TO 200:NEXT I:REM WAIT
180 C=PEEK(53279)
190 IF C>0 THEN PRINT "NOW TOUCHING - HIT!"
```

Sprites start apart (no collision), then move together (collision detected)!

## Practical Example

Move one sprite into another:

```basic
10 REM *** MOVING COLLISION ***
20 FOR I=832 TO 894:POKE I,255:NEXT I
30 FOR I=896 TO 958:POKE I,255:NEXT I
40 POKE 2040,13:POKE 2041,14
50 POKE 53287,2:POKE 53288,7
60 POKE 53269,3
68 POKE 53250,200:POKE 53251,120:REM SPRITE 1 FIXED
70 X=50
80 C=PEEK(53279):REM CLEAR PREVIOUS COLLISION
85 POKE 53248,X:POKE 53249,120:REM SPRITE 0 MOVES
90 FOR I=1 TO 50:NEXT I:REM DELAY FOR VISIBILITY
95 X=X+2
100 C=PEEK(53279):REM CHECK NEW COLLISION
110 IF C>0 THEN GOTO 130
120 GOTO 80
130 PRINT "COLLISION!"
```

Red sprite moves until it hits yellow!

## WOW Moment: Color Change on Collision

```basic
NEW
10 REM *** COLLISION COLOR ***
20 PRINT CHR$(147)
30 REM SETUP SPRITES
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,255:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53287,2:POKE 53288,7
80 POKE 53269,3
85 C=PEEK(53279):REM CLEAR REGISTER
90 X=50
100 REM MOVE AND CHECK
110 POKE 53248,X:POKE 53249,120
120 POKE 53250,200:POKE 53251,120
130 X=X+1:IF X>250 THEN X=50
140 C=PEEK(53279)
150 IF C>0 THEN POKE 53280,10:GOTO 170
160 POKE 53280,6
170 GOTO 110
```

## Quick Reference

```basic
REM COLLISION REGISTERS
53279  Sprite-to-Sprite
53278  Sprite-to-Background

REM READING COLLISION
C = PEEK(53279)
IF C>0 THEN collision happened
Reading CLEARS the register!

REM IMPORTANT: CLEAR AT START
C=PEEK(53279) before checking
Clears old collision data

REM BIT TESTING
IF C AND 1  Sprite 0 involved
IF C AND 2  Sprite 1 involved
IF C AND 4  Sprite 2 involved
(etc.)
```
