## Lesson 21 – Smarter Decisions II

Week 2 gave you global collision logic; now we tailor it per room. You’ll assign behaviours through tables, letting one loop adapt to different hazards, exits, and enemy speeds.

> [📷 suggested: screenshot showing two rooms with different hazard behaviours]

---

### The One-Minute Tour

- Store room rules (hazard damage, exit scores, enemy speed) in arrays.  
- On entry, copy those values into globals the loop consumes.  
- Use `ON...GOSUB` to branch to hazard/exit handlers depending on tile type.  
- Difficulty scaling becomes data, not code edits.

---

### Extending the Loader

Add rule tables alongside room DATA:

```basic
30 DIM MAP(9,17),EX(3),EY(3)
31 DIM RULEDMG(2),RULEBONUS(2),RULESPEED(2)
```

Populate them when loading a room:

```basic
5130 IF ROOM=1 THEN RESTORE 9000
5140 IF ROOM=2 THEN RESTORE 9100
5150 FOR R=0 TO 9
5160 FOR C=0 TO 17:READ MAP(R,C):NEXT C
5170 NEXT R
5180 FOR I=0 TO 3:READ EX(I),EY(I):NEXT I
5190 READ TITLE$,RULEDMG(ROOM),RULEBONUS(ROOM),RULESPEED(ROOM)
```

`RULEDMG` = lives lost on hazard; `RULEBONUS` = score from exit; `RULESPEED` controls enemy pace.

---

### Applying Rules in the Loop

```basic
5400 REM --- PLAYER MOVE ---
5410 GET K$:IF K$="" THEN RETURN
5420 NX=PX:NY=PY
5430 IF K$="W" OR K$=CHR$(145) THEN NY=PY-1
5440 IF K$="S" OR K$=CHR$(17) THEN NY=PY+1
5450 IF K$="A" OR K$=CHR$(157) THEN NX=PX-1
5460 IF K$="D" OR K$=CHR$(29) THEN NX=PX+1
5470 MX=NX-11:MY=NY-5
5480 IF MX<0 OR MX>17 OR MY<0 OR MY>9 THEN RETURN
5490 TILE=MAP(MY,MX)
5500 IF TILE=1 THEN RETURN
5510 POKE SCREEN+PY*40+PX,32
5520 PX=NX:PY=NY
5530 POKE SCREEN+PY*40+PX,64
5540 IF TILE>1 THEN ON TILE-1 GOSUB 6000,6100
5550 RETURN
```

`ON TILE-1` routes to hazard or exit handlers depending on the tile value:

- `TILE=2` → exits.  
- `TILE=3` → hazards.

### Hazard / Exit Logic

```basic
6000 REM --- EXIT ---
6010 SCORE=SCORE+RULEBONUS(ROOM)
6020 PRINT CHR$(19)
6030 PRINT "SCORE:";SCORE;" LIVES:";LIVES;"     ";
6040 STATE=2:RETURN

6100 REM --- HAZARD ---
6110 LIVES=LIVES-RULEDMG(ROOM)
6120 IF LIVES<0 THEN LIVES=0
6130 PRINT CHR$(19)
6140 PRINT "SCORE:";SCORE;" LIVES:";LIVES;"     ";
6150 IF LIVES=0 THEN STATE=3
6160 RETURN
```

No branching inside the handlers themselves—just simple arithmetic guided by the rule tables.

### Enemy Speed Adjustment

```basic
5530 ENEMYDELAY=RULESPEED(ROOM)
6500 REM --- ENEMY LOOP ---
6510 FOR I=0 TO 2
6520 POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),32
6530 IF STEP MOD ENEMYDELAY<>0 THEN GOTO 6580
6540 DX=0:DY=0
6550 IF EX(I)<PX-11 THEN DX=1
6560 IF EX(I)>PX-11 THEN DX=-1
6570 IF EY(I)<PY-5 THEN DY=1
6575 IF EY(I)>PY-5 THEN DY=-1
6580 NX=EX(I)+DX:NY=EY(I)+DY
6590 IF MAP(NY,NX)=1 THEN DX=0:DY=0
6600 EX(I)=EX(I)+DX:EY(I)=EY(I)+DY
6610 POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),81
6620 IF EX(I)+11=PX AND EY(I)+5=PY THEN GOSUB 6100
6630 NEXT I
```

Let `STEP` (a frame counter) gate enemy movement. Different rooms, different speeds—no duplicate code.

### Example Rule DATA

```basic
9000 REM ROOM 1 DATA + RULES
9010 DATA ... map rows ...
9020 DATA ... enemies ...
9030 DATA "DUSTY HALL",1,100,1

9100 REM ROOM 2 DATA + RULES
9110 DATA ... map rows ...
9120 DATA ... enemies ...
9130 DATA "TOXIC CHAMBER",2,150,2
```

Room 1 hazards subtract 1 life and exits award 100 points; enemies move every frame (`RULESPEED=1`). Room 2 hazards hit twice as hard, grant bigger bonuses, and enemies move every other frame.

### Experiment Section

- Add rule columns for music cues, HUD colour changes, or time limits.  
- Make certain rooms safe: set `RULEDMG(ROOM)=0` to create rest areas.  
- Difficulty mode: use `LEVEL` to offset into alternative rule arrays.  
- Tie the parser in—rooms can unlock commands when specific flags are set.  
- Save rule values into a buffer before writing so you can undo changes (for temporary power-ups).

---

### Concept Expansion

Room-specific logic is the prelude to full state machines: separate data, shared engine. Changing behaviour becomes a DATA change, not a code rewrite.

---

### Game Integration

- Boss fights: treat a room’s rule set as the behaviour script for special encounters.  
- Puzzles: mark tiles that require a key; rules decide whether to block or allow passage.  
- Campaign difficulty: adjust `RULESPEED` and `RULEDMG` via a global difficulty setting at load time.  
- Analytics: log which room killed the player to tweak balancing.

### Quick Reference

```basic

DMG=RULEDMG(ROOM)             : REM current room's damage
BONUS=RULEBONUS(ROOM)         : REM exit reward
SPEED=RULESPEED(ROOM)         : REM enemy step delay
RESTORE 9000                  : REM load room-specific DATA
```
