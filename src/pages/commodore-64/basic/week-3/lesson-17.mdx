## You've Been Using This Already!

Remember when you did `POKE 1024,X` in earlier lessons? You were writing directly to **screen memory**—the 1000 bytes that control every character on the display. You've been doing it; now let's understand HOW it works.

The C64's screen is 40×25 characters. Each position is one byte of memory starting at **address 1024**. When you POKE values there, characters appear instantly—no PRINT needed!

## The Formula Revealed

```basic
ADDRESS = 1024 + (ROW * 40) + COLUMN
```

- **ROW**: 0-24 (top to bottom)
- **COLUMN**: 0-39 (left to right)
- **1024**: Start of screen memory

Why multiply by 40? Each row is 40 characters wide. Row 5 starts at position 200 (5×40).

## Basic Example

Place an asterisk (*) at row 5, column 10:

```basic
10 REM *** PLACE ONE CHARACTER ***
20 P=1024+(5*40)+10
30 POKE P,42
```

Character code 42 is `*`. It appears exactly where the maths says!

## Practical Example

Place three letters spelling "WOW":

```basic
10 REM *** SPELL WOW ***
20 REM W AT ROW 10, COL 15
30 P=1024+(10*40)+15
40 POKE P,87
50 REM O AT ROW 10, COL 16
60 P=1024+(10*40)+16
70 POKE P,79
80 REM W AT ROW 10, COL 17
90 P=1024+(10*40)+17
100 POKE P,87
```

The word appears horizontally in the middle of the screen!

## WOW Moment: Place Your Initial Anywhere

```basic
NEW
10 REM *** MY INITIAL ***
20 PRINT CHR$(147):REM CLEAR SCREEN
30 INPUT "ROW (0-24)";R
40 INPUT "COLUMN (0-39)";C
50 INPUT "LETTER (A-Z)";L$
60 REM CALCULATE POSITION
70 P=1024+(R*40)+C
80 REM CONVERT PETSCII TO SCREEN CODE
90 CO=ASC(L$)-64
100 REM PLACE IT
110 POKE P,CO
```

Type any row, any column, any letter—it appears exactly there. You now understand the mechanism you've been using!

## Quick Reference

```basic
REM SCREEN MEMORY BASICS
1024       Start of screen memory
1024+999   End (40×25=1000 characters)

REM POSITION FORMULA
P = 1024 + (ROW * 40) + COLUMN

REM CHARACTER CODES
REM SCREEN CODES (for direct POKE):
1-26    A-Z (uppercase)
48-57   0-9
42      * (asterisk)

REM PETSCII CODES (from ASC):
65-90   A-Z (but shows as graphics in screen memory!)

REM CONVERT PETSCII TO SCREEN CODE:
SCREEN CODE = ASC(L$) - 64
```

## What You've Learnt

- Screen memory starts at address 1024
- Formula: 1024 + (row × 40) + column explains POKE positions
- You've been using this—now you know why it works
- ASC() converts letters to character codes
- Direct screen control = instant graphics
