## Lesson 23 – Memory Games III

Your rooms have maps, enemies, and rules; now add narrative and sound. We’ll extend the loader to read dialogue strings and music cues per room so each space tells its own story.

> [📷 suggested: screenshot showing room title, description, and play button for music]

---

### The One-Minute Tour

- Store dialogue lines and music identifiers alongside map data.  
- After loading, fill `LOG$( )` and a `MUSIC$` array to guide the UI and SID routines.  
- Trigger cues by room without new `IF` chains—data drives everything.

---

### Extending the DATA Blocks

Add dialogue lines and a music id at the end of each room definition:

```basic
9130 DATA "DUSTY HALL",1,100,1
9135 DATA "You wipe cobwebs from your face.","The floor hums with latent power.","Your steps echo down the hall.","" ,"" ,"TITLE1"
```

Five dialogue slots (empty strings allowed) and a music id (`TITLE1`) follow the rules.

---

### Loader Updates

Declare extra arrays:

```basic
32 DIM DIALOG$(4),MUSIC$(2)
```

Modify the loader:

```basic
5180 FOR I=0 TO 3:READ EX(I),EY(I):NEXT I
5190 READ TITLE$,RULEDMG(ROOM),RULEBONUS(ROOM),RULESPEED(ROOM)
5200 FOR I=0 TO 4:READ DIALOG$(I):NEXT I
5210 READ MUSIC$(ROOM)
5220 RETURN
```

Now every room automatically populates its text and audio cues.

---

### Displaying Dialogue

Reuse the log routine from Lesson 22:

```basic
5400 REM --- DRAW DIALOGUE BOX ---
5410 PRINT CHR$(147)
5420 PRINT TITLE$
5430 PRINT "--------"
5440 FOR I=0 TO 4
5450 LINE$=LEFT$(DIALOG$(I),36)
5460 PRINT "  ";LINE$
5470 NEXT I
```

You can call this when entering the room, after hazards, or during cut-scenes.

---

### Music Cue Stub

```basic
5500 REM --- PLAY ROOM MUSIC ---
5510 RESTORE 9500
5520 TARGET$=MUSIC$(ROOM)
5530 GOSUB 6000   : REM look up frequency table for TARGET$
5540 RETURN
```

`MUSIC$(ROOM)` might be `TITLE1`, `CHILL`, etc. Store the frequency sequences in a separate DATA block and use a lookup routine (`6000`) to play them. (Implementing the SID playback is Lesson 24’s domain; here we just provide the hook.)

---

### Experiment Section

- Branch dialogue depending on `RULEDMG`: if hazards are lethal, print “The air is toxic!”  
- Add `ITEM$` arrays to list power-ups found in each room.  
- Store `MUSIC$(ROOM)` as an index instead of string for compactness.  
- Combine parser commands so `LOOK` prints the dialogue box, `LISTEN` plays the cue.  
- Save the last music id to avoid restarting the track if the room reloads quickly.

---

### Concept Expansion

Streaming per-room metadata is the stepping stone to script engines. Later, you’ll load full conversation trees or soundtrack playlists from disk, but the pattern—DATA + loader—remains.

---

### Game Integration

- Title cards: room titles feed the HUD or cut-scene transitions.  
- Dynamic music: `MUSIC$(ROOM)` drives SID sequences for ambient vs. combat.  
- Quest text: populate the dialogue buffer with hints or story beats.  
- Random chatter: rotate a selection of dialogue lines in each room for variety.
