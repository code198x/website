## You've Been Colouring Text Too!

Remember `POKE 646,X` to change text color? That sets the color for PRINT. But there's another system: **color memory**—1000 bytes starting at **55296** that control the color of each screen position independently.

Screen memory (1024+) controls WHAT character appears. Color memory (55296+) controls WHAT COLOR it is. Two parallel systems!

## The Color Memory Formula

```basic
COLOR ADDRESS = 55296 + (ROW * 40) + COLUMN
```

Same calculation as screen memory, different starting point!

## The 16 Colors

```
0=Black    1=White     2=Red       3=Cyan
4=Purple   5=Green     6=Blue      7=Yellow
8=Orange   9=Brown    10=Lt Red   11=Dk Grey
12=Med Grey 13=Lt Green 14=Lt Blue 15=Lt Grey
```

## Basic Example

Place a red asterisk at row 10, column 20:

```basic
10 REM *** RED ASTERISK ***
20 P=1024+(10*40)+20
30 POKE P,42:REM ASTERISK CHARACTER
40 C=55296+(10*40)+20
50 POKE C,2:REM RED COLOR
```

Same position calculation, different addresses!

## Practical Example

Write "HELLO" with each letter a different color:

```basic
10 REM *** RAINBOW HELLO ***
20 P=1024+(12*40)+15:REM POSITION
30 C=55296+(12*40)+15:REM COLOR
40 FOR I=0 TO 4
50 READ L,CO
60 POKE P+I,L:REM CHARACTER
70 POKE C+I,CO:REM COLOR
80 NEXT I
90 DATA 8,2,5,5,12,7,12,13,15,3
```

Each letter gets its own color value!

## WOW Moment: Rainbow Text

```basic
NEW
10 REM *** RAINBOW TEXT ***
20 PRINT CHR$(147)
30 INPUT "MESSAGE";M$
40 R=12:C=5:REM START POSITION
50 FOR I=1 TO LEN(M$)
60 P=1024+(R*40)+C+I
70 CO=55296+(R*40)+C+I
80 L$=MID$(M$,I,1):CH=ASC(L$)
85 IF CH>=65 AND CH<=90 THEN CH=CH-64:REM A-Z
90 POKE P,CH
100 POKE CO,I AND 15:REM CYCLE COLORS
110 NEXT I
```

![Rainbow colored text](/images/lessons/commodore-64/basic/week-3/lesson-18/rainbow.png)

Every letter gets a different color! The `AND 15` keeps colors in range 0-15.

## Quick Reference

```basic
REM COLOR MEMORY
55296      Start of color memory
55296+999  End (matches screen memory)

REM POSITION (SAME AS SCREEN)
C = 55296 + (ROW * 40) + COLUMN

REM COLOR CODES
0-15   16 different colors
646    PRINT color (different system)

REM PATTERN
POKE screen, character
POKE color, color_value
```

## What You've Learnt

- Color memory starts at 55296
- Same position formula as screen memory
- 16 colors (0-15) available
- Each screen position has independent color
- Screen + color memory work together

Now you control both WHAT appears and WHAT COLOR it is!
