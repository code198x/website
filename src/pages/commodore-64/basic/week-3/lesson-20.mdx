## Hardware Sprites: The C64's Secret Weapon

Characters are great, but they're locked to a grid. **Hardware sprites** move smoothly anywhere on screen—the C64's graphics chip draws them automatically!

8 sprites available (numbered 0-7). Each is 24×21 pixels. They move independently and can overlap anything on screen.

## How Sprites Work

Three steps:
1. **Define the shape** - 63 bytes of sprite data
2. **Point to it** - Tell the C64 where the data is
3. **Enable it** - Turn the sprite on

## Basic Example

Create a simple block sprite:

```basic
10 REM *** SIMPLE SPRITE ***
20 REM STEP 1: CLEAR SPRITE DATA
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 REM STEP 2: SET SPRITE POINTER
50 POKE 2040,13
60 REM STEP 3: ENABLE SPRITE 0
70 POKE 53269,1
80 REM SET POSITION
90 POKE 53248,160:REM X
100 POKE 53249,120:REM Y
```

A white block appears! The sprite is drawn by hardware.

## Understanding the Registers

```basic
2040+N   Sprite N pointer (which block of 64 bytes)
53248+N*2 Sprite N X position
53249+N*2 Sprite N Y position
53269    Enable register (bit 0=sprite 0)
53287+N  Sprite N color
```

## Practical Example

Create a colored sprite:

```basic
10 REM *** COLORED SPRITE ***
20 REM CLEAR SPRITE MEMORY
30 FOR I=832 TO 894:POKE I,0:NEXT I
40 REM DRAW CROSS PATTERN
50 FOR I=0 TO 20:POKE 832+I*3+1,255:NEXT
60 POKE 832+30+0,255:POKE 832+30+2,255
70 REM SET POINTER
80 POKE 2040,13
90 REM SET COLOR
100 POKE 53287,2:REM RED
110 REM POSITION
120 POKE 53248,180:POKE 53249,140
130 REM ENABLE
140 POKE 53269,1
```

A red cross sprite!

## WOW Moment: Your First Sprite

```basic
NEW
10 REM *** MY FIRST SPRITE ***
20 PRINT CHR$(147)
30 REM STEP 1: DEFINE SPRITE (SMILEY)
40 FOR I=832 TO 894:POKE I,0:NEXT I
50 DATA 0,60,0,0,102,0,1,219,128
60 DATA 1,219,128,1,128,128,1,128,128
70 FOR I=0 TO 17:READ V:POKE 832+I/3*3+I MOD 3,V:NEXT I
80 REM STEP 2: POINT TO IT
90 POKE 2040,13
100 REM STEP 3: COLOR IT
110 POKE 53287,7:REM YELLOW
120 REM STEP 4: POSITION IT
130 POKE 53248,160:POKE 53249,120
140 REM STEP 5: ENABLE IT
150 POKE 53269,1
```

## Quick Reference

```basic
REM SPRITE SETUP
832-894   Sprite 0 data (block 13)
2040      Sprite 0 pointer
53269     Enable register
53248,53249 Sprite 0 X,Y
53287     Sprite 0 color

REM SPRITE MATH
Sprite data = 64 bytes (63 used)
Block number = address / 64
Block 13 = 832 / 64
```
