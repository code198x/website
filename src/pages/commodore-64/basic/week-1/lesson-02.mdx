## The Screen is Getting Messy

After Lesson 1, your screen probably looks cluttered with all your PRINT experiments. Wouldn't it be nice to start fresh?

Let's learn how to control the screen itself.

## Clearing the Screen

Type this command:

```basic
PRINT CHR$(147)
```

![Screen Before Clear](/images/lessons/commodore-64/basic/week-1/lesson-02/screen-clear-before.png)

After running `PRINT CHR$(147)`:

![Screen After Clear](/images/lessons/commodore-64/basic/week-1/lesson-02/screen-clear-after.png)

**Boom!** The screen is now completely clear, and the cursor is back at the top-left corner.

## What Just Happened?

**CHR$(147)** - This tells BASIC to print character number 147. But 147 isn't a visible character—it's a **control code** that tells the screen to clear itself.

Let's break it down:

- **CHR$()** - "Character function" - converts a number into its corresponding character
- **147** - The specific code number for "clear screen" on the C64

Think of it like this: normal characters (A, B, C, 1, 2, 3) have codes too, but some special codes perform actions instead of displaying visible characters.

## Common Control Codes

Here are the most useful control codes you'll use:

| Code | What It Does |
|------|-------------|
| `CHR$(147)` | Clear screen and home cursor |
| `CHR$(19)` | HOME - Move cursor to top-left without clearing |
| `CHR$(13)` | RETURN - Move to start of next line |
| `CHR$(17)` | Cursor DOWN |
| `CHR$(145)` | Cursor UP |

## The HOME Command

Try this:

```basic
PRINT "HELLO"
PRINT CHR$(19)
PRINT "WORLD"
```

![HOME Command Demo](/images/lessons/commodore-64/basic/week-1/lesson-02/home-command-demo.png)

**Result:**
```
WORLD
```

Where did "HELLO" go? The `CHR$(19)` moved the cursor back to the home position (top-left), and then "WORLD" was printed over it.

The old text is still there—you just wrote over the top of it!

## Clearing Before You Start

From now on, you'll often want to clear the screen before running your programs. Here's the pattern:

```basic
PRINT CHR$(147)
PRINT "YOUR PROGRAM STARTS HERE"
```

This makes everything look clean and professional.

## Multiple Control Codes

You can combine control codes with text:

```basic
PRINT CHR$(147); "CLEAN START"
```

**Result:** Screen clears, then displays "CLEAN START" at the top.

Notice the semicolon joins them together, so both actions happen in one PRINT command.

## Lowercase Mode

The C64 actually has two character sets. By default, you see UPPERCASE and graphics characters. Try this:

```basic
PRINT CHR$(14)
PRINT "now i can type lowercase!"
```

![Lowercase Mode](/images/lessons/commodore-64/basic/week-1/lesson-02/lowercase-mode.png)

**To switch back:**

```basic
PRINT CHR$(142)
PRINT "BACK TO UPPERCASE"
```

![Uppercase Mode](/images/lessons/commodore-64/basic/week-1/lesson-02/uppercase-mode.png)

<div class="note">
<div class="note-title">💡 Character Set Note</div>

`CHR$(14)` switches to lowercase/uppercase mode (yes, you can now have true lowercase)

`CHR$(142)` switches back to uppercase/graphics mode (the default with PETSCII graphics)

Most C64 games and programs use the uppercase/graphics mode because it includes special drawing characters.
</div>

## Line Breaks

You can add line breaks without multiple PRINT commands:

```basic
PRINT CHR$(147); "LINE 1"; CHR$(13); "LINE 2"; CHR$(13); "LINE 3"
```

![Multiple Line Breaks](/images/lessons/commodore-64/basic/week-1/lesson-02/multiple-line-breaks.png)

This prints:
```
LINE 1
LINE 2
LINE 3
```

All from one PRINT command! `CHR$(13)` is the code for RETURN (line break).

## Why CHR$() Exists

You might wonder: "Why not just clear the screen with a special command like CLEAR or CLS?"

The C64's designers made everything go through the same screen output system. Whether you're printing text, numbers, or control codes, it all uses PRINT. This consistency makes the system simpler.

Other computers have dedicated commands like `CLS` (Clear Screen) or `HOME`. The C64 achieves the same results with `CHR$()` codes.

## Common Mistakes

**Forgetting the dollar sign:**
```basic
PRINT CHR(147)    ❌ WRONG - Missing $
PRINT CHR$(147)   ✅ CORRECT
```

**Using quotes:**
```basic
PRINT "CHR$(147)"    ❌ WRONG - Prints the text literally
PRINT CHR$(147)      ✅ CORRECT - Executes the control code
```
