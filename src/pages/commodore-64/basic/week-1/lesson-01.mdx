## Welcome to the Commodore 64!

You've just turned on your Commodore 64, and you're greeted with a blue screen that says:

```
    **** COMMODORE 64 BASIC V2 ****

 64K RAM SYSTEM  38911 BASIC BYTES FREE

READY.
```

![C64 Ready Screen](/images/lessons/commodore-64/basic/week-1/lesson-01/c64-ready-screen.png)

That blinking cursor is waiting for you. The C64 is **ready** to be programmed. No installation, no setup, no downloads—just you and the computer.

Let's make it do something!

## Your First Command

Type this exactly as shown (BASIC isn't case-sensitive, so you can use lowercase if you prefer):

```basic
PRINT "HELLO COMMODORE 64"
```

Now press **RETURN** (the Enter key).

### What You'll See

![First PRINT Command](/images/lessons/commodore-64/basic/week-1/lesson-01/first-print-command.png)

```
HELLO COMMODORE 64
READY.
```

**Congratulations!** You just told the computer to display text, and it did exactly what you asked.

## How It Works

Let's break down what happened:

**`PRINT`** - This is a BASIC command that displays information on the screen. Think of it as asking the computer to show you something.

**`"HELLO COMMODORE 64"`** - This is a **string**—programmer speak for "a piece of text." The quotation marks tell BASIC: "treat everything between these marks as text to display, not as commands."

**Why the quotes?** Without them, BASIC would try to interpret each word as a command or variable name. The quotes say "no, this is just text."

## Try Different Messages

Type each of these commands and press RETURN after each one:

```basic
PRINT "MY NAME IS STEVE"
PRINT "I AM LEARNING TO CODE"
PRINT "THIS IS BRILLIANT"
```

![Multiple PRINT Commands](/images/lessons/commodore-64/basic/week-1/lesson-01/multiple-print-commands.png)

Each time, the C64 displays exactly what you told it to.

## Multiple Things on One Line

You can print several things at once by separating them with semicolons:

```basic
PRINT "HELLO"; " "; "WORLD"
```

**Result:**
```
HELLO WORLD
```

The semicolon joins the pieces together. Notice we added `" "` (a space) between the words—otherwise they'd run together as `HELLOWORLD`.

## Printing Numbers

You don't need quotes for numbers:

```basic
PRINT 42
```

![Printing Numbers](/images/lessons/commodore-64/basic/week-1/lesson-01/printing-numbers.png)

**Result:**
```
 42
```

Notice the space before the number? That's the C64 leaving room for a minus sign in case the number is negative. This is normal behaviour.

You can do maths directly in PRINT:

```basic
PRINT 10 + 5
```

**Result:**
```
 15
```

```basic
PRINT 100 - 25
```

**Result:**
```
 75
```

The C64 calculates the answer and displays it.

## Mixing Text and Numbers

Combine both with a semicolon:

```basic
PRINT "THE ANSWER IS"; 42
```

**Result:**
```
THE ANSWER IS 42
```

## Empty Lines

Want a blank line? Just use PRINT by itself:

```basic
PRINT
```

**Result:**
```
[blank line]
READY.
```

It just moves the cursor down one line. Right now, creating nicely formatted output with blank lines between text is a bit awkward because each command shows `READY.` after it. But don't worry - in Lesson 3, we'll learn how to write programs with multiple PRINT commands that run together without the READY prompts appearing between them!

## What Happens with Mistakes?

Try this intentionally wrong command (we've misspelled PRINT):

```basic
PRNT "HELLO"
```

![Syntax Error](/images/lessons/commodore-64/basic/week-1/lesson-01/syntax-error.png)

**Result:**
```
?SYNTAX  ERROR
READY.
```

The C64 is telling you: "I don't understand that." The question mark means it's an error, and `SYNTAX ERROR` means you wrote something it couldn't interpret as valid BASIC.

**Don't panic!** Errors are normal. Just type the command again, correctly this time.

## The Cursor

That blinking square cursor shows where your next character will appear. You can use these keys to control it:

<div class="note">
<div class="note-title">⌨️ Cursor Control Keys</div>

**Arrow Keys** (↑ ↓ ← →) - Move the cursor around the screen

**INST/DEL** - Delete the character to the left of the cursor

**CLR/HOME** - Move cursor to top-left (hold SHIFT to clear the entire screen)

These keys are in the top-right area of the C64 keyboard, near the RESTORE key.

</div>

## Why This Matters

You've just learned the most fundamental concept in programming: **output**. Every program, no matter how complex, needs to communicate results to humans. PRINT is how C64 programs talk to you.

In the next lesson, we'll learn how to control what the screen looks like—colours, positioning, and clearing the display.

<div class="note">
<div class="note-title">💡 Historical Note</div>

The PRINT command comes from early computer history, when computers were connected to teletype printers. "Printing" meant sending text to the printer. Even though we're displaying on a screen now, the command name stuck.

</div>
