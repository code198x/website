## Why We Need Variables

So far, everything you've printed has been fixed. If you want to print the number 42, you type `PRINT 42`. But what if you want to:
- Count how many times something happens?
- Remember a score?
- Do calculations with changing numbers?

That's where **variables** come in.

## Your First Variable

Type this:

```basic
A=10
```

Press RETURN. Nothing seems to happen! But the C64 has stored the number 10 in a variable called `A`.

Now type:

```basic
PRINT A
```

![first-variable.png](/images/lessons/commodore-64/basic/week-1/lesson-05/first-variable.png)
*Capture: Screen showing A=10 followed by PRINT A displaying 10*

**Result:**
```
 10
```

The C64 remembered! The variable `A` is holding the value 10, and PRINT displays it.

## What Are Variables?

Think of variables as **named storage boxes** in the computer's memory. Each box:
- Has a name (like A, X, or SC)
- Holds one number
- Can be changed at any time

```basic
SC=0
LIVES=3
SPEED=5
```

Each variable now holds a different number.

## Variable Names

You can name variables almost anything:

**Valid names:**
- Single letters: `A`, `B`, `X`, `Y`
- Words: `SC`, `LIVES`, `SPEED`
- With numbers: `X1`, `PLAYER2`, `LEVEL3`

**Rules:**
- Must start with a letter
- Can contain letters and numbers
- No spaces allowed
- Maximum of 2 characters actually matter (C64 limitation!)

<div class="note">
<div class="note-title">⚠️ Important C64 Quirk</div>

The C64 only looks at the first **two characters** of variable names! So:

```basic
SCREEN=10
SC=10
```

These are **the same variable** to the C64! Both are just "SC" internally.

For clarity in your programs, use short, distinct names:
- `SC` for score
- `LV` for lives (not LIVES)
- `SP` for speed (not SPEED)

</div>

## Doing Maths with Variables

Variables become powerful when you do calculations:

```basic
A=10
B=5
C=A+B
PRINT C
```

![variable-math.png](/images/lessons/commodore-64/basic/week-1/lesson-05/variable-math.png)
*Capture: Screen showing the four commands above with result 15*

**Result:**
```
 15
```

The C64 added A (10) and B (5), then stored the result (15) in C.

## Maths Operators

You can use these operators with variables:

| Operator | What It Does | Example |
|----------|--------------|---------|
| `+` | Addition | `A+B` |
| `-` | Subtraction | `A-B` |
| `*` | Multiplication | `A*B` |
| `/` | Division | `A/B` |
| `^` | Power | `A^2` (A squared) |

Try this:

```basic
X=20
Y=X*2
PRINT Y
```

**Result:** `40` (because 20 × 2 = 40)

## Changing Variables

Variables can change value:

```basic
SC=0
PRINT SC
```

Shows: `0`

```basic
SC=10
PRINT SC
```

Shows: `10`

## Incrementing: Adding to Itself

Here's a crucial programming concept:

```basic
SC=0
SC=SC+1
PRINT SC
```

![incrementing.png](/images/lessons/commodore-64/basic/week-1/lesson-05/incrementing.png)
*Capture: Screen showing the three commands with result 1*

**Result:**
```
 1
```

**What happened?**
1. SC starts at 0
2. `SC=SC+1` means "take the current SC (0), add 1, store result back in SC"
3. SC is now 1

This is how you **count** in programming!

## Building a Counter

Let's make a program that counts:

```basic
NEW
10 SC=0
20 PRINT CHR$(147)
30 PRINT "SC: "; SC
40 SC=SC+1
50 FOR I=1 TO 100: NEXT I
60 GOTO 30
```

![counter-program.png](/images/lessons/commodore-64/basic/week-1/lesson-05/counter-program.png)
*Capture: Screen showing "SC: [a number]" updating*

RUN this program. Watch the score increase! Press RUN/STOP to halt it.

**How it works:**
- Line 10: Start SC at 0
- Line 20: Clear screen
- Line 30: Display the current score
- Line 40: Add 1 to score
- Line 50: Small delay so you can see it
- Line 60: Loop back to line 30

## Variables in Loops

Combining variables with loops creates powerful effects:

```basic
NEW
10 X=1
20 PRINT X
30 X=X+1
40 IF X<=10 THEN GOTO 20
```

This counts from 1 to 10, then stops.

(Don't worry about `IF...THEN` yet—we'll learn that in Lesson 7!)

## String Variables

So far we've used numeric variables. You can also store **text** in variables by adding `$`:

```basic
N$="STEVE"
PRINT "HELLO "; N$
```

![string-variables.png](/images/lessons/commodore-64/basic/week-1/lesson-05/string-variables.png)
*Capture: Screen showing the two commands with output "HELLO STEVE"*

**Result:**
```
HELLO STEVE
```

The `$` means "this variable holds text, not numbers."

**Rules for string variables:**
- Add `$` to the name: `NAME$`, `A$`, `WORD$`
- Put text in quotes: `NAME$="FRED"`
- Can't do maths with them (no `NAME$+5`)

## Combining Everything

Let's make something more interesting:

```basic
NEW
10 SC=0
20 PRINT CHR$(147)
30 NAME$="PLAYER"
40 LIVES=3
50 PRINT "NAME: "; NAME$
60 PRINT "SC: "; SC
70 PRINT "LIVES: "; LIVES
80 PRINT
90 PRINT "PRESS ANY KEY"
100 GET K$: IF K$="" THEN 100
110 SC=SC+100
120 GOTO 20
```

![game-stats-program.png](/images/lessons/commodore-64/basic/week-1/lesson-05/game-stats-program.png)
*Capture: Screen showing the player stats display with NAME, SC, and LIVES*

This creates a simple display that shows player stats. Press any key and the score increases by 100!

(Don't worry about `GET K$` on line 100—we'll learn keyboard input properly in Lesson 6!)

## Common Mistakes

**Forgetting the $ for text:**
```basic
NAME="FRED"     ❌ WRONG - BASIC thinks NAME is a number
NAME$="FRED"    ✅ CORRECT
```

**Using = instead of ==:**
In BASIC, `=` does two things:
- **Assigns** values: `A=10` (stores 10 in A)
- **Compares** values: `IF A=10` (checks if A equals 10)

This is different from some modern languages, but it works!

**Variable names too similar:**
Remember, only first 2 characters matter:
```basic
SC=10
SCRAP=20
PRINT SC    Shows 20! (because SC... = SC...)
```

Keep names distinct in their first two letters!

## Why Variables Matter

Variables are essential for:
- **Remembering things** between commands
- **Counting** events (score, lives, attempts)
- **Calculations** that change
- **Making programs interactive**

Without variables, you can only print fixed information. With variables, your programs can **remember, calculate, and respond**.
