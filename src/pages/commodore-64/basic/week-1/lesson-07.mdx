## Programs That Make Decisions

So far, your programs run line by line, always doing the same thing. **IF/THEN** changes that—it lets programs **choose** what to do based on **conditions**.

This is where programming becomes truly powerful.

## Your First IF/THEN

Type this program:

```basic
NEW
10 A=10
20 IF A=10 THEN PRINT "A IS TEN!"
30 PRINT "DONE"
```

![first-if-then.png](/images/lessons/commodore-64/basic/week-1/lesson-07/first-if-then.png)
*Capture: Screen showing the program output "A IS TEN!" followed by "DONE"*

RUN it.

**Result:**
```
A IS TEN!
DONE
```

Now change line 10:

```basic
10 A=5
```

RUN again.

![if-then-false.png](/images/lessons/commodore-64/basic/week-1/lesson-07/if-then-false.png)
*Capture: Screen showing only "DONE" (the IF condition was false)*

**Result:**
```
DONE
```

The `PRINT "A IS TEN!"` was **skipped** because `A=5` (not 10).

## How IF/THEN Works

```basic
IF condition THEN action
```

- **IF** checks if something is true
- **THEN** says what to do if it's true
- If false, **skip** the action and continue

**Line 20 explained:**
```basic
20 IF A=10 THEN PRINT "A IS TEN!"
```

1. Check: Is A equal to 10?
2. Yes → Execute `PRINT "A IS TEN!"`
3. No → Skip to line 30

## Comparison Operators

You can compare values in different ways:

| Operator | Meaning | Example |
|----------|---------|---------|
| `=` | Equal to | `IF A=10` |
| `<>` | Not equal to | `IF A<>10` |
| `<` | Less than | `IF A<10` |
| `>` | Greater than | `IF A>10` |
| `<=` | Less than or equal | `IF A<=10` |
| `>=` | Greater than or equal | `IF A>=10` |

Try these:

```basic
NEW
10 A=15
20 IF A>10 THEN PRINT "A IS BIGGER THAN 10"
30 IF A<20 THEN PRINT "A IS SMALLER THAN 20"
40 IF A<>10 THEN PRINT "A IS NOT 10"
```

![comparison-operators.png](/images/lessons/commodore-64/basic/week-1/lesson-07/comparison-operators.png)
*Capture: Screen showing all three messages printed*

**Result:**
```
A IS BIGGER THAN 10
A IS SMALLER THAN 20
A IS NOT 10
```

All three conditions are true (15 > 10, 15 < 20, 15 ≠ 10), so all three print.

## IF/THEN with GOTO

The real power comes from jumping to different line numbers:

```basic
NEW
10 PRINT CHR$(147)
20 PRINT "GUESS THE NUMBER (1-10)"
30 INPUT N
40 IF N=7 THEN GOTO 100
50 PRINT "WRONG! TRY AGAIN"
60 GOTO 20
100 PRINT "CORRECT! YOU WIN!"
```

![guess-number.png](/images/lessons/commodore-64/basic/week-1/lesson-07/guess-number.png)
*Capture: Screen showing "GUESS THE NUMBER", user entering 5, "WRONG! TRY AGAIN", then entering 7, "CORRECT! YOU WIN!"*

This program:
- Asks for a number
- If you guess 7 → jump to line 100 (success)
- If wrong → print "WRONG!" and loop back

This is how you create branching paths in programs!

## Comparing Strings

IF/THEN works with text too:

```basic
NEW
10 PRINT CHR$(147)
20 PRINT "ENTER PASSWORD:"
30 INPUT P$
40 IF P$="SECRET" THEN GOTO 100
50 PRINT "ACCESS DENIED"
60 GOTO 20
100 PRINT "ACCESS GRANTED!"
```

![password-check.png](/images/lessons/commodore-64/basic/week-1/lesson-07/password-check.png)
*Capture: Screen showing password prompt, "WRONG" typed, "ACCESS DENIED", then "SECRET" typed, "ACCESS GRANTED!"*

You must type exactly `SECRET` (all capitals). Anything else is denied.

**Important:** String comparisons are **case-sensitive**:
- `"HELLO"` ≠ `"hello"` ≠ `"Hello"`

## Multiple Actions After THEN

You can do **multiple things** on one line using `:` (colon):

```basic
NEW
10 SC=0
20 PRINT CHR$(147)
30 PRINT "SC: "; SC
40 PRINT
50 PRINT "PRESS SPACE"
60 GET K$: IF K$="" THEN 60
70 IF K$=" " THEN SC=SC+1: GOTO 20
80 IF K$="Q" THEN PRINT "QUIT": END
90 GOTO 60
```

![multiple-actions.png](/images/lessons/commodore-64/basic/week-1/lesson-07/multiple-actions.png)
*Capture: Screen showing score incrementing from 0 to 3 as SPACE is pressed*

Line 70 does **two things** if SPACE is pressed:
1. Increase score (`SC=SC+1`)
2. Jump to line 20 (`GOTO 20`)

The `:` separates commands on the same line.

## IF Without THEN GOTO

Often, you want to **skip** ahead if something is true. You can write:

```basic
IF condition THEN line_number
```

This is shorthand for `IF condition THEN GOTO line_number`.

Example:

```basic
NEW
10 PRINT "ENTER A NUMBER (1-100)"
20 INPUT N
30 IF N<1 THEN 10
40 IF N>100 THEN 10
50 PRINT "VALID NUMBER: "; N
```

![validation.png](/images/lessons/commodore-64/basic/week-1/lesson-07/validation.png)
*Capture: Screen showing entering -5, looping back, entering 150, looping back, entering 50, "VALID NUMBER: 50"*

Lines 30-40 reject invalid numbers and loop back to line 10.

## Opposite Conditions

Sometimes it's easier to check the **opposite**:

```basic
10 GET K$: IF K$="" THEN 10
```

This means: "If **no** key pressed, keep checking."

It's the same as:
```basic
10 GET K$
20 IF K$<>"" THEN 30
25 GOTO 10
30 PRINT K$
```

But line 10 is much shorter!

## Building a Simple Game Logic

Let's use IF/THEN to create game-like behaviour:

```basic
NEW
10 LIVES=3
20 SC=0
30 PRINT CHR$(147)
40 PRINT "LIVES: "; LIVES
50 PRINT "SC: "; SC
60 PRINT
70 PRINT "H = HIT (+10 POINTS)"
80 PRINT "M = MISS (-1 LIFE)"
90 PRINT "Q = QUIT"
100 PRINT
110 GET K$: IF K$="" THEN 110
120 IF K$="H" THEN SC=SC+10: GOTO 30
130 IF K$="M" THEN LIVES=LIVES-1
140 IF K$="Q" THEN PRINT "GAME OVER": END
150 IF LIVES<1 THEN PRINT "NO LIVES LEFT!": END
160 GOTO 30
```

![game-logic.png](/images/lessons/commodore-64/basic/week-1/lesson-07/game-logic.png)
*Capture: Screen showing LIVES: 2, SC: 30 after hitting H three times and M once*

This demonstrates:
- Tracking multiple variables (LIVES, SC)
- Different outcomes for different keys
- Game over condition (line 150)

## Checking Multiple Conditions

What if you need **two things** to be true?

You can use nested IFs:

```basic
NEW
10 INPUT "ENTER NUMBER 1-10: "; N
20 IF N>=1 THEN IF N<=10 THEN GOTO 100
30 PRINT "OUT OF RANGE"
40 GOTO 10
100 PRINT "VALID!"
```

![nested-if.png](/images/lessons/commodore-64/basic/week-1/lesson-07/nested-if.png)
*Capture: Screen showing entering 15, "OUT OF RANGE", entering 7, "VALID!"*

Line 20 checks **both** conditions:
1. Is N &gt;= 1?
2. If yes, then is N &lt;= 10?
3. If both true, jump to line 100

This nested approach is clear and works reliably. (C64 BASIC does have AND and OR operators, but we'll cover those in a later lesson.)

## Alternative: Separate Checks

You can also check conditions separately:

```basic
NEW
10 INPUT "ENTER NUMBER 1-10: "; N
20 IF N<1 THEN PRINT "TOO LOW!": GOTO 10
30 IF N>10 THEN PRINT "TOO HIGH!": GOTO 10
40 PRINT "VALID!"
```

![separate-checks.png](/images/lessons/commodore-64/basic/week-1/lesson-07/separate-checks.png)
*Capture: Screen showing entering -5, "TOO LOW!", entering 50, "TOO HIGH!", entering 7, "VALID!"*

This gives **different messages** for different problems—more user-friendly!

## Boolean Expressions

Sometimes you want to store the **result** of a comparison:

```basic
NEW
10 A=10
20 B=5
30 R = (A>B)
40 PRINT "A > B: "; R
```

![boolean-result.png](/images/lessons/commodore-64/basic/week-1/lesson-07/boolean-result.png)
*Capture: Screen showing "A > B: -1"*

**Result:**
```
A > B: -1
```

In C64 BASIC:
- **True** = -1
- **False** = 0

So `R` holds -1 because A (10) is indeed greater than B (5).

You can use this result in IF statements:

```basic
NEW
10 A=100
20 B=50
30 R=(A>B)
40 IF R THEN PRINT "A IS BIGGER"
50 IF R=0 THEN PRINT "A IS NOT BIGGER"
```

![boolean-math.png](/images/lessons/commodore-64/basic/week-1/lesson-07/boolean-math.png)
*Capture: Screen showing "A IS BIGGER"*

This can be useful when you need to check the same condition multiple times—calculate it once, then reuse the result.

## Common Patterns

**Wait for specific key:**
```basic
100 GET K$: IF K$<>"Y" THEN 100
```

**Validation loop:**
```basic
100 INPUT "ENTER 1-10: "; N
110 IF N<1 THEN 100
120 IF N>10 THEN 100
```

**Exit condition:**
```basic
100 IF LIVES<1 THEN PRINT "GAME OVER": END
```

## Common Mistakes

**Using = for "not equal":**
```basic
IF A = 10 THEN ...     ✅ Check if equal
IF A <> 10 THEN ...    ✅ Check if NOT equal
IF A != 10 THEN ...    ❌ Wrong syntax (not C64 BASIC)
```

**Forgetting THEN:**
```basic
IF A=10 PRINT "YES"    ❌ Syntax error
IF A=10 THEN PRINT "YES"    ✅ Correct
```

**Wrong comparison operator:**
```basic
IF A => 10 THEN ...    ❌ Wrong order
IF A >= 10 THEN ...    ✅ Correct
```

**String comparison without quotes:**
```basic
IF K$=A THEN ...       ❌ Compares K$ to variable A
IF K$="A" THEN ...     ✅ Compares K$ to letter A
```

## Why IF/THEN Matters

IF/THEN is fundamental for:
- **Game logic** (collision detection, win/lose conditions)
- **Input validation** (checking if numbers are in range)
- **Menus** (responding to different choices)
- **Branching stories** (choose-your-own-adventure)
- **AI behavior** (enemies reacting to player position)

Without IF/THEN, programs can only do one thing. With IF/THEN, programs can **adapt** and **respond**.
