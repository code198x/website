## Lesson 51 – Menus & Options

With a title screen in place, players need somewhere to choose modes, difficulty, or toggles. We’ll build a responsive menu that highlights choices, accepts keyboard and joystick input, and calls the correct library routine.

> [📷 suggested: menu screenshot with the current item highlighted]

---

### The One-Minute Tour

- Keep menu items in arrays (`ITEM$()`, `ACTION()`) so you can print and dispatch them dynamically.
- Highlight the active item by printing it with reverse video (`CHR$(18)` toggles reverse on/off).
- Poll input every frame so the menu stays responsive and you can animate backgrounds in the future.

---

### Example Program

```basic
NEW
10 REM *** MENU DEMO ***
20 GOSUB 9000
30 PRINT CHR$(147)
40 PRINT "COSMIC CAFE OPTIONS"
50 PRINT
60 GOSUB 1000
70 GET K$:IF K$="" THEN GOTO 70
80 IF K$="W" OR K$=CHR$(145) THEN GOSUB 1100
90 IF K$="S" OR K$=CHR$(17) THEN GOSUB 1200
100 IF K$=CHR$(13) OR K$=" " THEN GOSUB 1300
110 IF K$="J" THEN GOSUB 1400
120 GOTO 60

9000 REM *** MENU DATA ***
9010 DIM ITEM$(3),ACTION(3)
9020 DATA "START GAME",1000,"OPTIONS",2000,"HIGH SCORES",3000
9030 FOR I=1 TO 3
9040 READ ITEM$(I):READ ACTION(I)
9050 NEXT I
9060 SEL=1
9070 RETURN

1000 REM *** DRAW MENU ***
1010 FOR I=1 TO 3
1020 PRINT TAB(6);
1030 IF I=SEL THEN PRINT CHR$(18);"> ";ITEM$(I);CHR$(146) ELSE PRINT "  ";ITEM$(I)
1040 NEXT I
1050 PRINT TAB(4);"W/S = MOVE  RETURN = SELECT  J = JOYSTICK"
1060 RETURN

1100 REM *** MOVE UP ***
1110 SEL=SEL-1:IF SEL<1 THEN SEL=3
1120 PRINT CHR$(147):PRINT "COSMIC CAFE OPTIONS":PRINT
1130 GOSUB 1000
1140 RETURN

1200 REM *** MOVE DOWN ***
1210 SEL=SEL+1:IF SEL>3 THEN SEL=1
1220 PRINT CHR$(147):PRINT "COSMIC CAFE OPTIONS":PRINT
1230 GOSUB 1000
1240 RETURN

1300 REM *** EXECUTE OPTION ***
1310 PRINT CHR$(147):PRINT "RUNNING " ;ITEM$(SEL)
1320 GOSUB ACTION(SEL)
1330 PRINT :PRINT "PRESS ANY KEY TO RETURN"
1340 GET K$:IF K$="" THEN 1340
1350 PRINT CHR$(147):PRINT "COSMIC CAFE OPTIONS":PRINT
1360 GOSUB 1000
1370 RETURN

1400 REM *** JOYSTICK SUPPORT ***
1410 V=PEEK(56320)
1420 IF V AND 1=0 THEN GOSUB 1100
1430 IF V AND 2=0 THEN GOSUB 1200
1440 IF V AND 16=0 THEN GOSUB 1300
1450 RETURN

1500 REM *** START GAME PLACEHOLDER ***
1510 PRINT "(Game would launch)"
1520 RETURN

2000 REM *** OPTIONS PLACEHOLDER ***
2010 PRINT "Difficulty: NORMAL"
2020 PRINT "Sound: ON"
2030 RETURN

3000 REM *** HIGH SCORE PLACEHOLDER ***
3010 PRINT "ACE  600"
3020 PRINT "JAX  480"
3030 PRINT "MIN  360"
3040 RETURN
```

Sample interaction:

```
COSMIC CAFE OPTIONS
> START GAME
  OPTIONS
  HIGH SCORES
W/S = MOVE  RETURN = SELECT  J = JOYSTICK
```

Selecting an item changes `SEL` and redraws the menu. Reverse video (`CHR$(18)` / `CHR$(146)`) highlights the active choice. `ACTION()` stores the line numbers of the routines to run; pressing `RETURN` calls the correct one. The joystick reader checks port two (`PEEK(56320)`) so players can navigate with a stick as well.

> **Tip:** Always redraw the heading and menu after executing an option so the screen resets before the next input.

### Concept Expansion

Menus are just arrays plus input. Once you have this loop running you can plug it into title screens, pause overlays, even debugging consoles. Add state transitions so each option jumps to its own substate and back.

---

### Game Integration

Reuse the dispatcher pattern:

```basic
SELECT = WRAP(SELECT + DELTA)
GOSUB 5000
IF FIRE THEN GOSUB ACTION(SELECT)
```

Wrap logic ensures the cursor loops top-to-bottom without extra conditionals.

### Quick Reference

```basic
REM Reverse video highlight
PRINT CHR$(18);"> ";ITEM$(SEL);CHR$(146)

REM Joystick port 2 bits
UP = 1
DOWN = 2
FIRE = 16

REM Dispatch stored line numbers
GOSUB ACTION(SEL)
```

### What You’ve Learnt

- Menus live comfortably inside arrays—names, actions, help text—all indexed by the current selection.
- Reverse video and redraw-on-change keep navigation readable.
- Supporting both keyboard and joystick makes your menu arcade-ready.
