## Let the Game Play Itself!

Attract modes drew attention in shops—**Defender**'s endless demo, **Uridium**'s autopilot, **Impossible Mission**'s showcase. Self-playing demos showed off gameplay before the player pressed start!

You'll create an attract mode with scripted AI playing the game automatically. This is the marketing tool that sold C64 games from shop shelves!

## Basic Example

Simple scripted movement:

```basic
10 REM *** BASIC DEMO ***
20 PRINT CHR$(147)
30 X=5
40 PRINT CHR$(19)
50 PRINT "*** AUTO-DEMO ***"
60 PRINT
70 FOR I=0 TO 20
80 IF I=X THEN PRINT "P";
90 IF I<>X THEN PRINT ".";
100 NEXT I
110 X=X+1
120 IF X>20 THEN X=5
130 FOR I=1 TO 100:NEXT I
140 GOTO 40
```

The player moves automatically! No input needed—X increases until it loops back. This shows movement but doesn't demonstrate actual gameplay!

## Practical Example

Scripted sequence:

```basic
10 REM *** SCRIPTED DEMO ***
20 PRINT CHR$(147)
30 DIM MV$(10)
40 MV$(1)="RRRR":MV$(2)="UUU"
50 MV$(3)="LLLL":MV$(4)="DDD"
60 MV$(5)="RRRR"
70 X=5:Y=5:M=1:P=1
80 PRINT CHR$(19)
90 PRINT "AUTO-DEMO (PRESS KEY TO PLAY)"
100 FOR I=1 TO 5:PRINT:NEXT I
110 FOR I=0 TO 10
120 IF I=X THEN PRINT "@";
130 IF I<>X THEN PRINT ".";
140 NEXT I
150 REM *** EXECUTE SCRIPT ***
160 IF P>LEN(MV$(M)) THEN M=M+1:P=1
170 IF M>5 THEN M=1
180 C$=MID$(MV$(M),P,1)
190 IF C$="R" THEN X=X+1
200 IF C$="L" THEN X=X-1
210 P=P+1
220 FOR I=1 TO 200:NEXT I
230 GET K$:IF K$<>"" THEN PRINT "STARTING GAME...":END
240 GOTO 80
```

Now it follows a script! MV$ array holds movement sequences (RRRR = move right 4 times). The demo executes each command in sequence, looping back to the start. Press any key to interrupt and start playing!

## WOW Moment: AI Auto-Play Demo

```basic
NEW
10 REM *** ATTRACT MODE ***
20 PRINT CHR$(147)
30 POKE 53280,0:POKE 53281,11
40 REM *** INIT ***
50 PX=5:EX=20:SC=0:T=0
60 REM *** MAIN DEMO LOOP ***
70 PRINT CHR$(19)
80 T=T+1
90 PRINT "*** AUTO-DEMO ***"
100 PRINT
110 PRINT "SCORE:";SC;" TIME:";T
120 PRINT
130 PRINT "(PRESS FIRE TO PLAY)"
140 PRINT
150 REM *** DRAW GAME ***
160 FOR I=0 TO 30
170 IF I=PX THEN PRINT CHR$(18);"P";CHR$(146);
180 IF I=EX THEN PRINT "E";
190 IF I<>PX AND I<>EX THEN PRINT ".";
200 NEXT I
210 PRINT
220 PRINT
230 PRINT "AI DECISION: ";
240 REM *** SIMPLE AI ***
250 IF EX>PX+3 THEN PRINT "MOVE RIGHT":PX=PX+1
260 IF EX<PX-3 THEN PRINT "MOVE LEFT":PX=PX-1
270 IF ABS(EX-PX)<4 THEN PRINT "ATTACK!":SC=SC+10:EX=5+INT(RND(1)*20)
280 REM *** ENEMY MOVES ***
290 IF RND(1)<0.3 THEN EX=EX+INT(RND(1)*3)-1
300 IF EX<5 THEN EX=5
310 IF EX>28 THEN EX=28
320 REM *** TIMEOUT CHECK ***
330 IF T>100 THEN PRINT CHR$(147):PRINT "DEMO FINISHED":FOR I=1 TO 1500:NEXT I:GOTO 20
340 REM *** EXIT TO GAME ***
350 GET K$:IF K$<>"" THEN GOSUB 500
360 FOR I=1 TO 150:NEXT I
370 GOTO 70
380 REM
500 REM *** START ACTUAL GAME ***
510 PRINT CHR$(147)
520 POKE 53280,6:POKE 53281,14
530 PRINT
540 PRINT "  *** STARTING GAME ***"
550 PRINT
560 PRINT "  (AI DEMO HAS ENDED)"
570 PRINT
580 PRINT "  YOUR TURN TO PLAY!"
590 PRINT
600 FOR I=1 TO 2000:NEXT I
610 PRINT CHR$(147)
620 PRINT "GAME WOULD START HERE..."
630 PRINT
640 PRINT "PRESS FIRE TO RETURN"
650 GET K$:IF K$="" THEN GOTO 650
660 GOTO 20
```

![AI-controlled attract mode demonstration](/images/lessons/commodore-64/basic/week-7/lesson-55/attract.gif)

A complete attract mode with AI player! The computer controls the player (P) automatically using simple decision logic:

- **If enemy far right**: Move right toward target
- **If enemy far left**: Move left toward target
- **If enemy close**: Attack! Score 10 points, spawn new enemy

The AI makes visible decisions—you can see it thinking! "MOVE RIGHT", "MOVE LEFT", "ATTACK!" appear each frame. The enemy (E) wanders randomly, the AI pursues and attacks!

After 100 frames, the demo resets and loops. Press any key to interrupt and transition to the actual game. This is exactly how **Uridium**, **Wizball**, and **Impossible Mission** showcased gameplay!

The attract mode colour scheme (cyan background) differs from game colours (blue background), showing players it's a demo!

Try creating more complex AI (dodge enemies, collect power-ups), multiple demo scenarios, or high-score replays!

## Quick Reference

```basic
REM ATTRACT MODE STRUCTURE
T=0                         Demo timer
IF T>100 THEN reset         Loop demo

REM SIMPLE AI
IF target>player THEN move right
IF target<player THEN move left
IF near target THEN action

REM SCRIPTED DEMO
DIM MV$(10)                 Movement commands
MV$(1)="RRRUUULLL"         Sequence
Execute one command per frame

REM VISUAL FEEDBACK
PRINT "AI DECISION: ";     Show thinking
Different colours vs gameplay
"AUTO-DEMO" title

REM EXIT TO GAME
GET K$:IF K$<>"" THEN      Interrupt
Transition to actual gameplay
Reset game state

REM AI PATTERNS
- Chase target (move toward)
- Flee danger (move away)
- Collect items (path to nearest)
- Follow script (predefined)
- Perfect play (show ideal strategy)
- Random valid (just don't die)

REM ATTRACT BEST PRACTICES
- Loop indefinitely until keypress
- Show score/gameplay elements
- Make AI visible/understandable
- Different colours = demo mode
- Timeout and restart (variety)
```
