## Navigate Your Options!

After the title screen comes the menu—**Paradroid**'s difficulty selection, **Wizball**'s control options, **Impossible Mission**'s level choice. Menus let players customise their experience before playing!

You'll create a menu system with cursor navigation, option highlighting, and selection confirmation. This is the interface that gave players control over their C64 gaming experience!

## Basic Example

Simple number menu:

```basic
10 REM *** NUMBER MENU ***
20 PRINT CHR$(147)
30 PRINT "MAIN MENU"
40 PRINT
50 PRINT "1. START GAME"
60 PRINT "2. INSTRUCTIONS"
70 PRINT "3. HIGH SCORES"
80 PRINT
90 PRINT "SELECT:"
100 GET K$:IF K$="" THEN GOTO 100
110 IF K$="1" THEN PRINT "STARTING GAME..."
120 IF K$="2" THEN PRINT "SHOWING INSTRUCTIONS..."
130 IF K$="3" THEN PRINT "HIGH SCORES..."
```

Basic menu with number keys! Press 1, 2, or 3 to select. This works but lacks visual feedback—players can't see which option they're selecting before confirming!

## Practical Example

Menu with cursor indicator:

```basic
10 REM *** CURSOR MENU ***
20 PRINT CHR$(147)
30 S=1
40 PRINT CHR$(19)
50 PRINT "MAIN MENU"
60 PRINT
70 IF S=1 THEN PRINT "> START GAME"
80 IF S<>1 THEN PRINT "  START GAME"
90 IF S=2 THEN PRINT "> INSTRUCTIONS"
100 IF S<>2 THEN PRINT "  INSTRUCTIONS"
110 IF S=3 THEN PRINT "> HIGH SCORES"
120 IF S<>3 THEN PRINT "  HIGH SCORES"
130 PRINT
140 PRINT "USE W/S, PRESS SPACE"
150 GET K$:IF K$="" THEN GOTO 150
160 IF K$="W" AND S>1 THEN S=S-1
170 IF K$="S" AND S<3 THEN S=S+1
180 IF K$=" " THEN GOSUB 300
190 GOTO 40
200 REM
300 REM *** SELECTION ***
310 PRINT CHR$(147)
320 IF S=1 THEN PRINT "STARTING GAME..."
330 IF S=2 THEN PRINT "SHOWING INSTRUCTIONS..."
340 IF S=3 THEN PRINT "HIGH SCORES..."
350 RETURN
```

Now there's visual feedback! The ">" cursor shows which option is selected. W/S moves up/down, space selects. CHR$(19) cursor home redraws the menu each frame!

## WOW Moment: Animated Menu System

```basic
NEW
10 REM *** ANIMATED MENU ***
20 PRINT CHR$(147)
30 POKE 53280,6:POKE 53281,14
40 S=1:C=0
50 REM *** DRAW MENU ***
60 PRINT CHR$(19)
70 PRINT
80 PRINT "      *** MAIN MENU ***"
90 PRINT
100 PRINT
110 REM *** OPTIONS ***
120 C=C+1:IF C>60 THEN C=0
130 IF S=1 THEN PRINT CHR$(18);"     > START GAME     ";CHR$(146)
140 IF S<>1 THEN PRINT "       START GAME       "
150 PRINT
160 IF S=2 THEN PRINT CHR$(18);"     > DIFFICULTY     ";CHR$(146)
170 IF S<>2 THEN PRINT "       DIFFICULTY       "
180 PRINT
190 IF S=3 THEN PRINT CHR$(18);"     > INSTRUCTIONS   ";CHR$(146)
200 IF S<>3 THEN PRINT "       INSTRUCTIONS     "
210 PRINT
220 IF S=4 THEN PRINT CHR$(18);"     > HIGH SCORES    ";CHR$(146)
230 IF S<>4 THEN PRINT "       HIGH SCORES      "
240 PRINT
250 PRINT
260 IF C<30 THEN PRINT "    PRESS W/S TO MOVE"
270 IF C>=30 THEN PRINT "    SPACE TO SELECT  "
280 REM *** INPUT ***
290 GET K$:IF K$="" THEN GOTO 50
300 IF K$="W" AND S>1 THEN S=S-1:GOTO 50
310 IF K$="S" AND S<4 THEN S=S+1:GOTO 50
320 IF K$=" " THEN GOSUB 400
330 GOTO 50
340 REM
400 REM *** SELECTION HANDLER ***
410 PRINT CHR$(147)
420 POKE 53280,0:POKE 53281,0
430 PRINT
440 IF S=1 THEN PRINT "   STARTING GAME...":FOR I=1 TO 1000:NEXT I
450 IF S=2 THEN PRINT "   CHOOSE DIFFICULTY...":FOR I=1 TO 1000:NEXT I
460 IF S=3 THEN PRINT "   LOADING INSTRUCTIONS...":FOR I=1 TO 1000:NEXT I
470 IF S=4 THEN PRINT "   HIGH SCORES...":FOR I=1 TO 1000:NEXT I
480 RETURN
```

![Animated menu with cursor navigation](/images/lessons/commodore-64/basic/week-7/lesson-50/menu.gif)

A complete animated menu system! The selected option appears in reverse video (CHR$(18) = reverse on, CHR$(146) = reverse off), creating a highlighted bar like **Paradroid** and **Uridium**!

The flashing instruction text alternates between "press W/S" and "space to select" using counter C. Players can navigate up/down through 4 options, seeing exactly what they're selecting!

Try adding more options, changing colours, or using sprites as cursor indicators!

## Quick Reference

```basic
REM MENU STRUCTURE
S=1                         Selection (1-4)
PRINT CHR$(19)              Cursor home (redraw)

REM CURSOR NAVIGATION
IF K$="W" AND S>1 THEN S=S-1    Move up
IF K$="S" AND S<MAX THEN S=S+1  Move down
IF K$=" " THEN GOSUB 400        Select

REM VISUAL FEEDBACK
CHR$(18)                    Reverse video on
CHR$(146)                   Reverse video off
IF S=1 THEN PRINT ">..."    Cursor indicator
IF S=1 THEN PRINT CHR$(18)  Highlight

REM FLASHING HINTS
C=C+1:IF C>60 THEN C=0      Counter
IF C<30 THEN PRINT "TIP 1"  First message
IF C>=30 THEN PRINT "TIP 2" Second message

REM MENU BEST PRACTICES
- Use reverse video for selected option
- Flash instruction text for clarity
- Limit movement to valid range (S>1, S<MAX)
- Clear visual difference between states
- Sound effects on navigation (advanced)
```

## What You've Learnt

- Menus provide player choice before gameplay
- Cursor navigation with boundary checking
- Reverse video highlights selected options
- Flashing text guides player interaction
- Visual feedback confirms menu state
- Commercial games always included option menus

Every professional C64 game used menu systems—now you can build them!
