## Lesson 50 – Title Screens

Your game deserves ceremony. A good title screen cycles colours, bounces logos, and politely waits for the player. In this lesson we wrap your state machine around an attract mode that feels alive even before gameplay begins.

> [📷 suggested: animated title screen showing colour cycling banner]

---

### The One-Minute Tour

- Keep the title in its own state so the main loop still runs even when nothing is happening.
- Use the jiffy clock (`TI`) to animate text and cycle colours without blocking input.
- Trigger the transition to gameplay with a single key or joystick press while the animation continues.

---

### Example Program

```basic
NEW
10 REM *** TITLE SCREEN ***
20 GOSUB 9000 : REM initialise colours & strings
30 STATE=0:LAST=-1:KEY$="":ANGLE=0
40 TI$="000000":NEXTT=0
50 GET K$:IF K$<>"" THEN KEY$=K$
60 IF STATE<>LAST THEN GOSUB 500
70 ON STATE+1 GOSUB 600,700
80 LAST=STATE:GOTO 50

500 REM *** DRAW STATE ***
510 IF STATE=0 THEN GOSUB 1000
520 IF STATE=1 THEN GOSUB 1100
530 RETURN

600 REM *** TITLE LOOP ***
610 IF TI<NEXTT THEN 640
620 ANGLE=ANGLE+.25:IF ANGLE>6.283 THEN ANGLE=ANGLE-6.283
630 GOSUB 1200:NEXTT=TI+1
640 IF KEY$<>"" THEN STATE=1:KEY$=""
650 RETURN

700 REM *** PLACEHOLDER GAME ***
710 PRINT CHR$(147);"GAME WOULD START HERE";:PRINT
720 PRINT "PRESS Q TO GO BACK"
730 IF KEY$="Q" THEN STATE=0:KEY$="":RETURN
740 RETURN

9000 REM *** INIT ***
9010 PRINT CHR$(147)
9020 PRINT "PREPARING TITLE..."
9030 BANNER$="COSMIC CAFE"
9040 HINT$="PRESS SPACE TO START"
9050 COLORS(0)=1:COLORS(1)=7:COLORS(2)=15:COLORS(3)=9
9060 RETURN

1000 REM *** DRAW STATIC TITLE BACKDROP ***
1010 PRINT CHR$(147)
1020 PRINT "=============================="
1030 PRINT "         COSMIC CAFE         "
1040 PRINT "=============================="
1050 PRINT
1060 PRINT "PREPARE FOR A GALACTIC SHIFT"
1070 PRINT
1080 RETURN

1100 REM *** REFRESH GAME SCREEN (placeholder) ***
1110 RETURN

1200 REM *** ANIMATE BOUNCE & COLOR CYCLE ***
1210 ROW=10+INT(SIN(ANGLE)*2)
1220 COLIDX=(INT(ANGLE*4) AND 3)
1230 POKE 646,COLORS(COLIDX)
1240 PRINT CHR$(19);TAB(10);BANNER$
1250 PRINT TAB(8);"* GALACTIC DRIP! *"
1260 FOR L=0 TO 3
1270 PRINT TAB(ROW);HINT$
1280 NEXT L
1290 RETURN
```

Sample output (while waiting):

```
==============================
         COSMIC CAFE
==============================

PREPARE FOR A GALACTIC SHIFT

PRESS SPACE TO START   (bouncing and colour-cycling)
```

The title screen is state `0`. The loop always runs, even when you are waiting for a key. `ANGLE` feeds `SIN` to bounce the prompt and cycles the border colour by poking `646` with values from the palette array. Pressing `SPACE` flips `STATE` to `1`, which would normally start the real game—here it simply prints a placeholder message until you press `Q` to return.

> **Tip:** Keep title visuals quick to draw. We print strings and reuse animation variables; no slow `FOR` loop clears or redraws the entire screen each frame.

### Experiment Section

- Swap the banner for PETSCII art from your library—draw it once in `DRAW STATIC TITLE`, then animate only the prompt.
- Add an attract-mode demo: after 10 seconds without input, set `STATE=2` and start a scripted gameplay loop.
- Play a SID arpeggio every few seconds by calling your library sound routine inside `ANIMATE` when `ANGLE` wraps.
- Replace the key with joystick fire by checking bit 4 of `PEEK(56320)`.

### Concept Expansion

Title screens are just another state. By isolating them you can swap backgrounds, run demo logic, or show high scores without touching gameplay code. Later lessons will feed cutscenes and menus through the same machinery.

---

### Game Integration

Keep one initialisation block per screen:

```basic
IF STATE_CHANGED THEN GOSUB 2000
GOSUB 2100
```

Keep the draw routine at line `2000` and the animation tick at line `2100` (give them clear `REM` banners). That pattern ensures the title is redrawn when you arrive, but animation continues smoothly every frame.

### What You’ve Learnt

- Title screens run best as a dedicated state that keeps the main loop alive.
- Timers let you animate text and colours without blocking input.
- Press-to-start prompts should respond instantly while the attract mode keeps moving.
