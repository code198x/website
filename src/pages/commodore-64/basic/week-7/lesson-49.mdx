## Your Game's First Impression!

Every classic C64 game started with a title screen—**Impossible Mission**'s bouncing logo, **Uridium**'s scrolling text, **Paradroid**'s animated graphics. The title screen sets the tone before gameplay begins!

You'll create an animated title screen with a bouncing logo and "press fire to start" message. This is the professional presentation that made C64 games memorable!

## Basic Example

Simple title display:

```basic
10 REM *** SIMPLE TITLE ***
20 PRINT CHR$(147)
30 PRINT
40 PRINT "  *** SPACE RAIDERS ***"
50 PRINT
60 PRINT "    PRESS FIRE TO START"
70 PRINT
80 GET K$:IF K$="" THEN GOTO 80
90 PRINT "GAME STARTS HERE..."
```

Basic title and wait for keypress! Line 80 loops until a key is pressed (GET returns "" when no key). This works, but it's static—no animation or visual interest!

## Practical Example

Flashing "press fire" text:

```basic
10 REM *** FLASHING TITLE ***
20 PRINT CHR$(147)
30 PRINT
40 PRINT "  *** SPACE RAIDERS ***"
50 PRINT
60 C=0
70 C=C+1
80 IF C>30 THEN C=0
90 IF C<15 THEN PRINT CHR$(19);"    PRESS FIRE TO START"
100 IF C>=15 THEN PRINT CHR$(19);"                          "
110 GET K$:IF K$="" THEN GOTO 70
120 PRINT CHR$(147)
130 PRINT "GAME STARTS HERE..."
```

Now the "press fire" message flashes on and off! CHR$(19) is cursor home—it moves the cursor to the start of the current line so we can overwrite text. The counter C creates the flash timing!

## WOW Moment: Bouncing Logo Title

```basic
NEW
10 REM *** BOUNCING TITLE ***
20 PRINT CHR$(147)
30 POKE 53280,0:POKE 53281,0
40 REM *** SPRITE LOGO ***
50 FOR I=832 TO 895
60 READ D:POKE I,D
70 NEXT I
80 POKE 2040,13:POKE 53269,1
90 POKE 53287,1
100 X=160:Y=100:DY=2
110 REM *** TITLE TEXT ***
120 PRINT CHR$(147)
130 FOR I=1 TO 5:PRINT:NEXT I
140 PRINT "       SPACE RAIDERS"
150 PRINT
160 PRINT "     BY YOUR NAME 2025"
170 PRINT
180 C=0
190 REM *** ANIMATION LOOP ***
200 Y=Y+DY
210 IF Y>200 THEN Y=200:DY=-2
220 IF Y<50 THEN Y=50:DY=2
230 POKE 53249,Y
240 POKE 53248,X
250 C=C+1
260 IF C>40 THEN C=0
270 IF C<20 THEN PRINT CHR$(19):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT "    PRESS FIRE TO START"
280 IF C>=20 THEN PRINT CHR$(19):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT CHR$(17):PRINT "                          "
290 GET K$:IF K$="" THEN GOTO 200
300 PRINT CHR$(147)
310 PRINT "GAME LOADING..."
320 REM *** SPRITE DATA ***
330 DATA 0,126,0,1,255,128,3,255,192
340 DATA 7,255,224,15,255,240,15,255,240
350 DATA 31,255,248,31,255,248,63,255,252
360 DATA 63,255,252,127,255,254,127,255,254
370 DATA 127,255,254,63,255,252,63,255,252
380 DATA 31,255,248,15,255,240,7,255,224
390 DATA 3,255,192,1,255,128,0,126,0
```

![Bouncing logo title screen](/images/lessons/commodore-64/basic/week-7/lesson-49/title.png)

A complete animated title screen! The sprite logo bounces up and down whilst the "press fire" message flashes. This is exactly how **Boulder Dash**, **Paradroid**, and other classics introduced their games!

The logo bounces between Y=50 and Y=200, reversing direction when it hits the limits (DY changes from +2 to -2). The flashing message uses multiple CHR$(17) (cursor down) to position text at the correct line!

Try changing the sprite data to create your own logo, adjust bounce speed with DY, or add colour cycling!

## Quick Reference

```basic
REM TITLE SCREEN ELEMENTS
PRINT CHR$(147)             Clear screen
PRINT CHR$(19)              Cursor home
PRINT CHR$(17)              Cursor down

REM BOUNCING SPRITE
Y=Y+DY                      Move sprite
IF Y>MAX THEN Y=MAX:DY=-DY  Reverse at bottom
IF Y<MIN THEN Y=MIN:DY=-DY  Reverse at top

REM FLASHING TEXT
C=C+1:IF C>30 THEN C=0      Counter
IF C<15 THEN PRINT "TEXT"   Show text
IF C>=15 THEN PRINT "    "  Hide text

REM WAIT FOR INPUT
GET K$:IF K$="" THEN GOTO   Loop until keypress

REM TITLE BEST PRACTICES
- Use sprite for logo (scalable, animatable)
- Flash "press fire" so players know to start
- Show game name, author, year
- Animate something (bounce, scroll, colour)
- Black background (0) shows colours best
```

## What You've Learnt

- Title screens set professional presentation standards
- Bouncing sprites create dynamic visual interest
- Flashing text draws attention to "press fire"
- Cursor control positions text precisely
- Animation loops run whilst waiting for input
- Commercial games always had animated titles

Every C64 game you loved started with an animated title screen—now you know how to build them!
