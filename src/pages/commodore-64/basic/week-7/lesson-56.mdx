## Teach Players How to Play!

Instructions made games accessible—**Elite**'s comprehensive manual screens, **Paradroid**'s control guide, **Impossible Mission**'s objective explanation. Clear instructions helped players understand complex games!

You'll create a multi-page instructions screen with controls, rules, and examples. This is the tutorial system that made C64 games learnable without reading printed manuals!

## Basic Example

Simple instructions:

```basic
10 REM *** BASIC INSTRUCTIONS ***
20 PRINT CHR$(147)
30 PRINT "*** HOW TO PLAY ***"
40 PRINT
50 PRINT "W/A/S/D = MOVE"
60 PRINT "SPACE = SHOOT"
70 PRINT "Q = QUIT"
80 PRINT
90 PRINT "AVOID ENEMIES!"
100 PRINT "COLLECT STARS!"
110 PRINT
120 PRINT "PRESS FIRE TO START"
130 GET K$:IF K$="" THEN GOTO 130
140 PRINT "STARTING GAME..."
```

Basic controls and goals! But it's all on one screen. Complex games needed multiple pages with examples and strategies!

## Practical Example

Multi-page instructions:

```basic
10 REM *** PAGED INSTRUCTIONS ***
20 PRINT CHR$(147)
30 P=1
40 PRINT CHR$(19)
50 PRINT "*** INSTRUCTIONS ***"
60 PRINT
70 IF P=1 THEN PRINT "CONTROLS:":PRINT:PRINT "W = UP":PRINT "S = DOWN":PRINT "A = LEFT":PRINT "D = RIGHT":PRINT "SPACE = FIRE"
80 IF P=2 THEN PRINT "RULES:":PRINT:PRINT "AVOID RED ENEMIES":PRINT "COLLECT GREEN ITEMS":PRINT "REACH EXIT TO WIN"
90 IF P=3 THEN PRINT "SCORING:":PRINT:PRINT "ENEMY: 10 POINTS":PRINT "ITEM: 50 POINTS":PRINT "WIN: 500 BONUS"
100 PRINT
110 PRINT "PAGE";P;"/3"
120 PRINT
130 PRINT "N=NEXT P=PREV SPACE=START"
140 GET K$
150 IF K$="N" AND P<3 THEN P=P+1:GOTO 40
160 IF K$="P" AND P>1 THEN P=P-1:GOTO 40
170 IF K$=" " THEN PRINT CHR$(147):PRINT "STARTING...":END
180 GOTO 40
```

Now there are 3 pages! N/P navigate between pages, space starts the game. Each page focuses on one topic: controls, rules, scoring. Page counter shows progress!

![Visual instructions with animated examples](/images/lessons/commodore-64/basic/week-7/lesson-56/instructions.gif)

Complete visual instructions with FOUR pages:

- **PAGE 1**: Controls listing with flashing prompt
- **PAGE 2**: Objectives with reverse video highlights
- **PAGE 3**: Animated visual example showing player (P), enemy (E), and moving star (*)
- **PAGE 4**: Pro tips for advanced play

Page 3 demonstrates actual gameplay—the star moves across the screen showing what to collect! This is exactly how **Paradroid**, **Impossible Mission**, and **Elite** taught complex mechanics!

Each page uses reverse video (CHR$(18)/CHR$(146)) to highlight important elements. Navigation shows available options (N=Next only appears on pages 1-3, P=Prev only on pages 2-4)!

Try adding more pages (power-ups, enemies, scoring details), screenshots from actual gameplay, or interactive tutorial levels!

## Quick Reference

```basic
REM MULTI-PAGE STRUCTURE
P=1                         Current page
ON P GOTO 100,200,300      Page dispatcher

REM PAGE CONTENT
100 REM *** PAGE 1 ***
110 PRINT "CONTROLS..."
120 GOTO navigation

REM VISUAL EXAMPLES
A=A+1:IF A>20 THEN A=0     Animation counter
FOR I=0 TO 20               Draw example
IF I=A THEN PRINT "*"      Animated element

REM NAVIGATION
IF P<MAX THEN PRINT "N=NEXT"   Conditional hints
IF P>1 THEN PRINT "P=PREV"
IF K$="N" AND P<MAX THEN P=P+1

REM HIGHLIGHT IMPORTANT TEXT
CHR$(18);"KEY INFO";CHR$(146)  Reverse video
Numbers, controls, warnings

REM INSTRUCTION TOPICS
1. Controls (how to play)
2. Objectives (what to do)
3. Examples (visual demo)
4. Scoring (points system)
5. Enemies (threats explained)
6. Power-ups (collectibles)
7. Tips (strategy guide)

REM BEST PRACTICES
- One topic per page (not overwhelming)
- Visual examples (show don't tell)
- Reverse video for emphasis
- Clear navigation hints
- Animated demonstrations
- Space bar always starts game
```

## What You've Learnt

- Instructions make complex games accessible
- Multi-page organisation prevents information overload
- Visual examples demonstrate gameplay concepts
- Reverse video highlights important information
- Animated demos show mechanics in action
- Professional games always included clear instructions

Every well-designed C64 game taught players how to play—now you can too!
