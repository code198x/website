## Choose Your Challenge!

The best games let players choose difficulty—**Elite**'s combat rating, **Paradroid**'s robot difficulty, **Boulder Dash**'s cave selection. Difficulty settings make games accessible to beginners whilst challenging experts!

You'll create a difficulty system with EASY/NORMAL/HARD modes affecting speed, enemy count, and scoring. This is the accessibility feature that made C64 games playable for everyone!

## Basic Example

Simple speed multiplier:

```basic
10 REM *** BASIC DIFFICULTY ***
20 PRINT CHR$(147)
30 PRINT "SELECT DIFFICULTY:"
40 PRINT "1=EASY 2=NORMAL 3=HARD"
50 GET K$:IF K$="" THEN GOTO 50
60 D=VAL(K$)
70 IF D<1 OR D>3 THEN GOTO 50
80 SP=D*2
90 PRINT CHR$(147)
100 PRINT "SPEED:";SP
110 FOR I=1 TO 100
120 PRINT ".";
130 FOR J=1 TO SP*50:NEXT J
140 NEXT I
```

The difficulty D multiplies the delay—harder = faster animation! Easy (D=1) has SP=2, Normal (D=2) has SP=4, Hard (D=3) has SP=6. Simple but effective!

## Practical Example

Difficulty affects multiple variables:

```basic
10 REM *** MULTI-VARIABLE DIFFICULTY ***
20 PRINT CHR$(147)
30 PRINT "SELECT DIFFICULTY:"
40 PRINT
50 PRINT "1. EASY   (SLOW, FEW ENEMIES)"
60 PRINT "2. NORMAL (MEDIUM, NORMAL)"
70 PRINT "3. HARD   (FAST, MANY ENEMIES)"
80 PRINT
90 GET K$:IF K$="" THEN GOTO 90
100 D=VAL(K$)
110 IF D<1 OR D>3 THEN GOTO 90
120 REM *** SET DIFFICULTY VARS ***
130 SP=D+1
140 EN=D*3
150 PT=10/D
160 PRINT CHR$(147)
170 PRINT "DIFFICULTY:";D
180 PRINT "SPEED:";SP
190 PRINT "ENEMIES:";EN
200 PRINT "POINTS PER HIT:";PT
```

Now difficulty affects speed (SP), enemy count (EN), and points (PT)! Easy gives more points per hit (10÷1=10), Hard gives fewer (10÷3=3). This balances the challenge—harder modes give less reward!

## WOW Moment: Complete Difficulty System

```basic
NEW
10 REM *** DIFFICULTY SELECTOR ***
20 PRINT CHR$(147)
30 POKE 53280,6:POKE 53281,14
40 PRINT
50 PRINT "   *** SPACE RAIDERS ***"
60 PRINT
70 PRINT "   SELECT DIFFICULTY:"
80 PRINT
90 PRINT "   1. EASY"
100 PRINT "      SLOW ENEMIES"
110 PRINT "      3 ENEMIES"
120 PRINT "      20 POINTS PER HIT"
130 PRINT
140 PRINT "   2. NORMAL"
150 PRINT "      NORMAL ENEMIES"
160 PRINT "      5 ENEMIES"
170 PRINT "      10 POINTS PER HIT"
180 PRINT
190 PRINT "   3. HARD"
200 PRINT "      FAST ENEMIES"
210 PRINT "      8 ENEMIES"
220 PRINT "      5 POINTS PER HIT"
230 PRINT
240 GET K$:IF K$="" THEN GOTO 240
250 D=VAL(K$)
260 IF D<1 OR D>3 THEN GOTO 240
270 REM *** APPLY DIFFICULTY ***
280 IF D=1 THEN SP=1:EN=3:PT=20:DI$="EASY"
290 IF D=2 THEN SP=2:EN=5:PT=10:DI$="NORMAL"
300 IF D=3 THEN SP=3:EN=8:PT=5:DI$="HARD"
310 REM *** GAME SIMULATION ***
320 PRINT CHR$(147)
330 POKE 53280,0:POKE 53281,0
340 PRINT "DIFFICULTY:";DI$
350 PRINT "ENEMIES:";EN;" SPEED:";SP
360 PRINT
370 SC=0
380 FOR I=1 TO EN
390 PRINT "ENEMY";I;"APPROACHING..."
400 FOR J=1 TO 2000/(SP*SP):NEXT J
410 PRINT "HIT! +";PT
420 SC=SC+PT
430 FOR J=1 TO 500:NEXT J
440 NEXT I
450 PRINT
460 PRINT "WAVE COMPLETE!"
470 PRINT "SCORE:";SC
480 PRINT
490 PRINT "PRESS FIRE"
500 GET K$:IF K$="" THEN GOTO 500
510 GOTO 20
```

![Difficulty selection affecting gameplay](/images/lessons/commodore-64/basic/week-7/lesson-52/difficulty.png)

A complete difficulty system with gameplay demonstration! Players see exactly what each difficulty means before selecting:

- **EASY**: 3 enemies, slow (SP=1), 20 points each = 60 points total
- **NORMAL**: 5 enemies, medium (SP=2), 10 points each = 50 points total
- **HARD**: 8 enemies, fast (SP=3), 5 points each = 40 points total

The delay `2000/(SP*SP)` makes harder difficulties feel much faster—HARD is 9× faster than EASY! Notice how harder modes give fewer total points, balancing risk with reward like **Defender** and **Uridium**!

After completing the wave, press fire to return to difficulty selection and try another mode!

Try adding more difficulty variables (lives, power-up frequency, boss health), or create custom difficulty with individual sliders!

## Quick Reference

```basic
REM DIFFICULTY VARIABLES
D=1/2/3                     Difficulty level
SP=D+1                      Speed multiplier
EN=D*3                      Enemy count
PT=10/D                     Points per hit

REM DIFFICULTY MENU
PRINT "1=EASY 2=NORMAL 3=HARD"
GET K$:D=VAL(K$)
IF D<1 OR D>3 THEN...       Validate

REM APPLY TO GAMEPLAY
FOR J=1 TO 1000/SP          Faster delays
IF RND(1)<D*0.1 THEN...     More events
SC=SC+(10/D)                Fewer points

REM DIFFICULTY FACTORS
- Enemy speed (movement delay)
- Enemy count (wave size)
- Enemy health (hits to kill)
- Player lives (starting count)
- Points value (score per action)
- Power-up frequency (spawn rate)
- Boss difficulty (health, patterns)

REM BALANCE PRINCIPLES
- Easy: Learn mechanics safely
- Normal: Standard challenge
- Hard: Expert execution required
- Harder = less score OR more reward
```
