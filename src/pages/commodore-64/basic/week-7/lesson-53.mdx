## Collect Power, Change Everything!

Power-ups made games exciting—**Paradroid**'s energy boosts, **Wizball**'s colour collection, **Impossible Mission**'s puzzle pieces. Temporary abilities and collectibles added strategy and reward!

You'll create a power-up system with invincibility, speed boost, and point multipliers. This is the gameplay mechanic that made collecting items so satisfying!

## Basic Example

Simple pickup:

```basic
10 REM *** BASIC PICKUP ***
20 PRINT CHR$(147)
30 X=10:PX=20
40 PRINT CHR$(19)
50 PRINT "YOU:";X;" ITEM:";PX
60 GET K$
70 IF K$="D" THEN X=X+1
80 IF K$="A" THEN X=X-1
90 IF X=PX THEN PRINT "COLLECTED!":END
100 GOTO 40
```

When player position (X) equals power-up position (PX), you collect it! Simple collision detection. But there's no visual item, no effect, no timer!

## Practical Example

Power-up with timer:

```basic
10 REM *** TIMED POWER-UP ***
20 PRINT CHR$(147)
30 X=10:PX=20:PW=0:TM=0
40 PRINT CHR$(19)
50 IF PW=1 THEN PRINT "*** INVINCIBLE ***";
60 PRINT "TIME LEFT:";TM
70 PRINT
80 PRINT "YOU:";X;" POWER-UP:";PX
90 GET K$
100 IF K$="D" AND X<30 THEN X=X+1
110 IF K$="A" AND X>0 THEN X=X-1
120 IF X=PX AND PW=0 THEN PW=1:TM=50:PX=-1
130 IF PW=1 THEN TM=TM-1
140 IF TM=0 THEN PW=0
150 GOTO 40
```

Now the power-up activates for 50 frames! PW=1 means powered up, TM counts down. When TM reaches 0, power-up ends (PW=0). PX=-1 hides the collected item!

## WOW Moment: Multiple Power-Up System

```basic
NEW
10 REM *** POWER-UP SYSTEM ***
20 PRINT CHR$(147)
30 POKE 53280,0:POKE 53281,0
40 REM *** INIT ***
50 X=5:SC=0:SP=1
60 DIM PT(3):DIM PX(3):DIM TM(3)
70 FOR I=1 TO 3
80 PT(I)=0:PX(I)=5+I*7:TM(I)=0
90 NEXT I
100 REM *** MAIN LOOP ***
110 PRINT CHR$(19)
120 PRINT "SCORE:";SC;" SPEED:";SP
130 PRINT
140 REM *** SHOW POWER-UPS ***
150 FOR I=1 TO 3
160 IF PT(I)=1 THEN PRINT CHR$(18);"[";CHR$(146);
170 IF I=1 THEN PRINT "INVINCIBLE";
180 IF I=2 THEN PRINT "SPEED x2";
190 IF I=3 THEN PRINT "POINTS x5";
200 IF PT(I)=1 THEN PRINT " ";TM(I);CHR$(18);"]";CHR$(146)
210 PRINT
220 NEXT I
230 PRINT
240 REM *** DRAW ITEMS ***
250 FOR I=0 TO 30
260 IF I=X THEN PRINT "@";
270 IF I=PX(1) AND PT(1)=0 THEN PRINT "I";
280 IF I=PX(2) AND PT(2)=0 THEN PRINT "S";
290 IF I=PX(3) AND PT(3)=0 THEN PRINT "P";
300 IF I<>X AND I<>PX(1) AND I<>PX(2) AND I<>PX(3) THEN PRINT ".";
310 NEXT I
320 PRINT
330 PRINT
340 PRINT "A/D TO MOVE"
350 REM *** INPUT ***
360 GET K$
370 IF K$="D" AND X<30 THEN X=X+SP
380 IF K$="A" AND X>0 THEN X=X-SP
390 REM *** COLLECT ***
400 IF X=PX(1) AND PT(1)=0 THEN PT(1)=1:TM(1)=100:POKE 53280,7
410 IF X=PX(2) AND PT(2)=0 THEN PT(2)=1:TM(2)=50:SP=2
420 IF X=PX(3) AND PT(3)=0 THEN PT(3)=1:TM(3)=80
430 REM *** TIMERS ***
440 FOR I=1 TO 3
450 IF PT(I)=1 THEN TM(I)=TM(I)-1
460 IF TM(I)=0 THEN PT(I)=0
470 NEXT I
480 IF PT(1)=0 THEN POKE 53280,0
490 IF PT(2)=0 THEN SP=1
500 REM *** SCORING ***
510 MU=1
520 IF PT(3)=1 THEN MU=5
530 SC=SC+1*MU
540 GOTO 110
```

![Multiple power-ups with timers](/images/lessons/commodore-64/basic/week-7/lesson-53/powerups.png)

A complete power-up system with THREE collectibles:

- **I (Invincible)**: Border turns yellow for 100 frames
- **S (Speed)**: Move 2 spaces instead of 1 for 50 frames
- **P (Points)**: Score multiplied by 5 for 80 frames

Each power-up has its own type (PT array), position (PX array), and timer (TM array). When you collect an item, it activates (PT=1), sets the timer, and triggers the effect!

Active power-ups show in reverse video with countdown. When timers hit 0, effects end. The score increases every frame—watch it climb 5× faster with the P power-up!

Try adding more power-up types (shield, weapon upgrade, extra life), visual effects (flashing sprites), or stacking rules (can you have multiple active?)!

## Quick Reference

```basic
REM POWER-UP STRUCTURE
DIM PT(3)                   Power-up type active
DIM PX(3)                   Power-up X position
DIM TM(3)                   Power-up timer

REM COLLECTION
IF X=PX(1) AND PT(1)=0 THEN Collect
PT(1)=1                     Activate
TM(1)=100                   Set duration
PX(1)=-1                    Hide (or leave visible)

REM TIMER COUNTDOWN
IF PT(1)=1 THEN TM(1)=TM(1)-1
IF TM(1)=0 THEN PT(1)=0     Deactivate

REM EFFECTS
IF PT(1)=1 THEN...          Invincibility logic
IF PT(2)=1 THEN SP=2        Speed boost
IF PT(3)=1 THEN MU=5        Point multiplier

REM VISUAL FEEDBACK
POKE 53280,C                Border colour
CHR$(18)...CHR$(146)        Reverse video
Sprite colour change
Sound effect on collect

REM POWER-UP TYPES
- Invincibility (ignore collisions)
- Speed boost (faster movement)
- Point multiplier (score bonus)
- Weapon upgrade (more damage)
- Shield (extra hit point)
- Magnet (auto-collect items)
```

## What You've Learnt

- Power-ups add strategic gameplay depth
- Timers create temporary effect windows
- Arrays manage multiple simultaneous power-ups
- Visual feedback shows active status
- Effects modify core game variables
- Collection detection uses position matching

Every classic C64 game used power-ups—now you know the systems!
