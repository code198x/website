## What You'll Build

Navigate through a maze to reach the exit. Introduces DATA statements for level design.

Walls surround you. A path exists somewhere. Find the exit before time runs out. This game teaches level data storage with DATA/READ statements — the foundation of content-rich games.

## Skills You'll Master

- **DATA and READ statements** — embedded data
- **Level data storage** — maze definition
- **Maze rendering** — character graphics
- **Four-directional movement** — up/down/left/right
- **Wall collision** — movement constraints
- **Multiple levels** — progression
- **Timer/scoring** — time pressure
- **Level completion** — victory conditions

## Prerequisites

Complete **Game 3: Catcher** first.
