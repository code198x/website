## Save Your Progress!

Every adventure game and RPG saves your progress—**The Bard's Tale**, **Ultima**, **Elite**. Without persistence, you'd lose everything when you turn off the computer!

The C64 disk drive (1541) works like a file. You OPEN a file, PRINT# data to it, CLOSE it, then later OPEN and INPUT# to read it back. You'll save high scores, player stats, and game state so progress persists across sessions!

## Basic Example

Save one variable to disk:

```basic
10 REM *** SAVE SCORE ***
20 SCORE=1500
30 OPEN 1,8,2,"SCORE,S,W"
40 PRINT#1,SCORE
50 CLOSE 1
60 PRINT "SCORE SAVED!"
70 END
```

Your score is saved to disk! OPEN 1,8,2 opens file number 1 on device 8 (disk drive), secondary address 2 (write mode). PRINT#1 writes the variable. The file "SCORE" now contains 1500!

## Practical Example

Save and load back:

```basic
10 REM *** SAVE/LOAD DEMO ***
20 PRINT CHR$(147)
30 PRINT "1 = SAVE SCORE"
40 PRINT "2 = LOAD SCORE"
50 GET K$:IF K$="" THEN GOTO 50
60 IF K$="1" THEN GOSUB 200
70 IF K$="2" THEN GOSUB 300
80 GOTO 20
90 REM
200 REM *** SAVE ***
210 INPUT "ENTER SCORE";SC
220 OPEN 1,8,2,"SCORE,S,W"
230 PRINT#1,SC
240 CLOSE 1
250 PRINT "SAVED!"
260 FOR D=1 TO 1000:NEXT D
270 RETURN
300 REM *** LOAD ***
310 OPEN 1,8,2,"SCORE,S,R"
320 INPUT#1,SC
330 CLOSE 1
340 PRINT "LOADED SCORE:";SC
350 FOR D=1 TO 1000:NEXT D
360 RETURN
```

Save a score, then load it back! The ",S,W" means sequential write, ",S,R" means sequential read. The disk drive acts like permanent memory—turn off the C64, turn it back on, and your data is still there!

400 PRINT#1,GP
410 PRINT#1,HP
420 CLOSE 1

440 FOR D=1 TO 1000:NEXT D
450 RETURN
460 REM
470 REM *** LOAD GAME ***
480 PRINT CHR$(147)
490 PRINT "LOADING GAME..."

550 CLOSE 1

A complete save game system! Create a new game with your name, level, gold, and HP. Press 3 to save all four variables to disk. Turn off the C64, turn it back on, press 2 to load—your exact progress is restored!

This is how **Ultima** and **The Bard's Tale** saved your adventure progress. The disk drive stores everything permanently!

Try creating a character, saving, running NEW (which erases all variables), then loading—your character comes back!

## Quick Reference

```basic
REM OPEN FILE
OPEN filenum,device,secondary,"filename,type,mode"
filenum: 1-255 (your choice)
device: 8 = disk drive
secondary: 2 = data file
type: S = sequential
mode: W = write, R = read

REM SAVE DATA
OPEN 1,8,2,"DATA,S,W"
PRINT#1,variable         Save one variable
PRINT#1,var1;var2;var3   Save multiple (same line)
CLOSE 1                  Always close!

REM LOAD DATA
OPEN 1,8,2,"DATA,S,R"
INPUT#1,variable         Load one variable
INPUT#1,var1,var2,var3   Load multiple
CLOSE 1                  Always close!

REM ERROR CHECKING
DS=PEEK(186)             Device status
IF DS<>0 THEN PRINT "ERROR"

REM FILE OPERATIONS
OPEN 15,8,15,"S0:FILE"   Delete file
OPEN 15,8,15,"R0:NEW=OLD" Rename file
```

## What You've Learnt

- OPEN creates file connection to disk drive
- PRINT# writes variables to disk file
- INPUT# reads variables from disk file
- CLOSE must be called after operations
- Sequential files (,S,W or ,S,R) for simple data
- Multiple variables can be saved/loaded
- Data persists even when C64 is turned off

This is the foundation of save game systems in every C64 adventure and RPG!
