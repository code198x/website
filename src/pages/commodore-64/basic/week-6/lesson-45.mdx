## Cinematic Scene Changes!

Every professional game transitions between screens with **fades** and **wipes**—not instant cuts! Think of **Elite's** hyperspace tunnel or **The Last Ninja's** level changes.

You'll manipulate colour memory to fade screens to black, then fade in the new scene. You'll also create wipe effects that reveal screens line-by-line. These are the polishing touches that make games feel complete!

## Basic Example

Fade screen to black:

```basic
10 REM *** FADE TO BLACK ***
20 PRINT CHR$(147)
30 FOR I=1 TO 5:PRINT "*** HELLO C64 ***":NEXT I
40 FOR C=1 TO 0 STEP -1
50 FOR I=55296 TO 56295
60 POKE I,C
70 NEXT I
80 FOR D=1 TO 200:NEXT D
90 NEXT C
100 PRINT CHR$(147)
```

The screen fades to black! Colour memory (55296-56295) controls text colour for every character. By changing all colours from 1 (white) to 0 (black), the screen gradually disappears.

## Practical Example

Fade out and fade in:

```basic
10 REM *** FADE TRANSITION ***
20 PRINT CHR$(147)
30 POKE 53280,6:POKE 53281,14
40 PRINT "*** LEVEL 1 COMPLETE ***"
50 FOR I=1 TO 3:PRINT:NEXT I
60 PRINT "PRESS SPACE FOR NEXT LEVEL"
70 GET K$:IF K$<>" " THEN GOTO 70
80 REM FADE OUT
90 FOR C=1 TO 0 STEP -1
100 FOR I=55296 TO 56295
110 POKE I,C
120 NEXT I
130 FOR D=1 TO 100:NEXT D
140 NEXT C
150 REM CHANGE SCENE
160 PRINT CHR$(147)
170 POKE 53280,0:POKE 53281,0
180 PRINT "*** LEVEL 2 ***"
190 PRINT:PRINT "NEW CHALLENGES AWAIT!"
200 REM FADE IN
210 FOR C=0 TO 5
220 FOR I=55296 TO 56295
230 POKE I,C
240 NEXT I
250 FOR D=1 TO 100:NEXT D
260 NEXT C
270 END
```

Fade out, change screen content, fade in! The old scene darkens to black, the new scene is drawn while invisible, then brightens to reveal the new level. Professional transition!

## WOW Moment: Multi-Effect Scene Changes

```basic
NEW
10 REM *** SCREEN TRANSITIONS ***
20 PRINT CHR$(147)
30 PRINT "*** TRANSITION DEMO ***"
40 PRINT
50 PRINT "1 = FADE OUT/IN"
60 PRINT "2 = WIPE DOWN"
70 PRINT "3 = WIPE ACROSS"
80 PRINT "4 = FLASH"
90 PRINT
100 PRINT "SELECT TRANSITION:"
110 GET K$:IF K$="" THEN GOTO 110
120 IF K$="1" THEN GOSUB 200
130 IF K$="2" THEN GOSUB 300
140 IF K$="3" THEN GOSUB 400
150 IF K$="4" THEN GOSUB 500
160 GOTO 20
170 REM
200 REM *** FADE TRANSITION ***
210 REM FADE OUT
220 FOR C=1 TO 0 STEP -1
230 FOR I=55296 TO 56295
240 POKE I,C
250 NEXT I
260 FOR D=1 TO 80:NEXT D
270 NEXT C
280 REM NEW SCENE
290 PRINT CHR$(147)
300 POKE 53280,RND(1)*15:POKE 53281,RND(1)*15
310 PRINT "*** NEW SCENE ***"
320 FOR I=1 TO 10:PRINT "CONTENT LINE";I:NEXT I
330 REM FADE IN
340 FOR C=0 TO 7
350 FOR I=55296 TO 56295
360 POKE I,C
370 NEXT I
380 FOR D=1 TO 80:NEXT D
390 NEXT C
400 RETURN
410 REM
420 REM *** WIPE DOWN ***
430 PRINT CHR$(147)
440 FOR R=0 TO 24
450 FOR C=0 TO 39
460 POKE 1024+R*40+C,160
470 POKE 55296+R*40+C,0
480 NEXT C
490 FOR D=1 TO 20:NEXT D
500 NEXT R
510 PRINT CHR$(147)
520 POKE 53280,RND(1)*15
530 PRINT "*** WIPED ***"
540 RETURN
550 REM
560 REM *** WIPE ACROSS ***
570 PRINT CHR$(147)
580 FOR C=0 TO 39
590 FOR R=0 TO 24
600 POKE 1024+R*40+C,160
610 POKE 55296+R*40+C,0
620 NEXT R
630 FOR D=1 TO 15:NEXT D
640 NEXT C
650 PRINT CHR$(147)
660 POKE 53280,RND(1)*15
670 PRINT "*** WIPED ACROSS ***"
680 RETURN
690 REM
700 REM *** FLASH ***
710 FOR F=1 TO 5
720 POKE 53280,1
730 FOR D=1 TO 50:NEXT D
740 POKE 53280,0
750 FOR D=1 TO 50:NEXT D
760 NEXT F
770 PRINT CHR$(147)
780 POKE 53280,RND(1)*15
790 PRINT "*** FLASH COMPLETE ***"
800 RETURN
```

Four professional transitions! Option 1 fades out and in, 2 wipes down row-by-row, 3 wipes across column-by-column, 4 flashes the border. Each creates a different mood—fade for calm, wipe for dramatic, flash for teleport!

Try adding these transitions to your games between levels or scenes!

## Quick Reference

```basic
REM COLOUR MEMORY
55296-56295              1000 bytes (40×25 screen)
POKE 55296+pos,colour    Change character colour

REM FADE OUT
FOR C=colour TO 0 STEP -1  Darken
FOR I=55296 TO 56295       All chars
POKE I,C                   Set colour
FOR D=1 TO 100:NEXT        Delay for effect

REM FADE IN
FOR C=0 TO colour          Brighten
Same as fade out           But count up

REM WIPE DOWN
FOR R=0 TO 24              Each row
FOR C=0 TO 39              Each column
POKE 1024+R*40+C,char      Clear char
POKE 55296+R*40+C,0        Black colour

REM WIPE ACROSS
FOR C=0 TO 39              Each column
FOR R=0 TO 24              Each row
Reverse of wipe down       Column first

REM FLASH
POKE 53280,1               White border
FOR D=1 TO 50:NEXT         Delay
POKE 53280,0               Black border
Repeat several times       Creates flash effect
```

## What You've Learnt

- Colour memory can be faded to create transitions
- Fade out (bright to black) then fade in (black to bright)
- Wipe effects reveal screen row-by-row or column-by-column
- Delay loops control transition speed
- Border flashing creates teleport effects
- Transitions polish scene changes between levels

Professional games use these exact techniques to create cinematic scene changes!
