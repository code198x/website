## Design Your Own Graphics!

The C64 screen shows characters—letters, numbers, symbols. But what if you could **redefine** those characters to be game graphics instead?

Every character is made from an 8×8 grid of pixels. By changing the pattern, you can turn the letter 'A' into a spaceship, 'B' into a brick wall, 'C' into a coin! This is how games like **Boulderdash** and **Pacman** created detailed graphics using only text mode.

You'll design 4 custom characters and use them to build a mini-game!

## Basic Example

Redefine one character (uppercase A):

```basic
10 REM *** CUSTOM CHARACTER ***
20 POKE 56334,PEEK(56334)AND254
30 POKE 1,PEEK(1)AND251
40 FOR I=0 TO 7
50 READ D:POKE 4096+I,D
60 NEXT I
70 POKE 1,PEEK(1)OR4
80 POKE 56334,PEEK(56334)OR1
90 POKE 53272,(PEEK(53272)AND240)OR12
100 PRINT CHR$(147)
110 PRINT "AAAAA"
120 DATA 0,24,60,126,255,126,60,24
```

The letter 'A' now looks like a diamond! Lines 20-30 unlock the ROM, lines 40-60 write the new pattern (8 bytes, one per row), lines 70-80 lock it again, and line 90 switches to your custom character set at 4096 ($1000).

## Practical Example

Create 4 game characters:

```basic
10 REM *** GAME GRAPHICS ***
20 POKE 56334,PEEK(56334)AND254
30 POKE 1,PEEK(1)AND251
40 REM CHAR A: PLAYER
50 FOR I=0 TO 7:READ D:POKE 4096+I,D:NEXT I
60 DATA 24,60,126,219,255,126,60,36
70 REM CHAR B: WALL
80 FOR I=0 TO 7:READ D:POKE 4096+8+I,D:NEXT I
90 DATA 255,219,255,219,255,219,255,219
100 REM CHAR C: COIN
110 FOR I=0 TO 7:READ D:POKE 4096+16+I,D:NEXT I
120 DATA 60,66,133,141,177,161,66,60
130 REM CHAR D: EXIT
140 FOR I=0 TO 7:READ D:POKE 4096+24+I,D:NEXT I
150 DATA 24,36,66,153,153,66,36,24
160 POKE 1,PEEK(1)OR4
170 POKE 56334,PEEK(56334)OR1
180 POKE 53272,(PEEK(53272)AND240)OR12
190 PRINT CHR$(147)
200 PRINT "A = PLAYER"
210 PRINT "B = WALL"
220 PRINT "C = COIN"
230 PRINT "D = EXIT"
```

Four custom characters! A is the player, B is a wall, C is a coin, D is the exit. Each character is 8 bytes—one byte per row, where each bit represents a pixel (1=on, 0=off).

## Quick Reference

```basic
REM UNLOCK CHARACTER ROM
POKE 56334,PEEK(56334)AND254  Disable interrupts
POKE 1,PEEK(1)AND251          Switch to RAM

REM DEFINE CHARACTER
4096+CHAR*8                   Start address
CHAR: A=0, B=8, C=16, etc     8 bytes per char
DATA 255,129,189,189,189,189,129,255  8 rows

REM LOCK AND SWITCH
POKE 1,PEEK(1)OR4             Back to ROM
POKE 56334,PEEK(56334)OR1     Enable interrupts
POKE 53272,(PEEK(53272)AND240)OR12  Use charset at 4096

REM DESIGN PATTERNS
Binary to decimal:
11111111 = 255 (all pixels)
10000001 = 129 (border)
01111110 = 126 (filled middle)
00011000 = 24  (small dot)

REM CHECK SCREEN CHARACTER
PEEK(1024+Y*40+X)             Character code at X,Y
65=A, 66=B, 67=C, etc         ASCII values
```

## What You've Learnt

- Characters are 8×8 pixel patterns stored in ROM
- You can redefine characters in RAM at 4096
- Each character is 8 bytes (one per row)
- Binary patterns become decimal DATA values
- Custom characters create game graphics in text mode
- PEEK screen memory to detect character collisions

This is the secret behind every text-mode C64 game—custom character sets turn letters into game graphics!
