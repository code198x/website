## Make BASIC Faster!

BASIC is slow compared to machine code, but smart programming can make it **twice as fast**! Every commercial game used these tricks to squeeze more performance from BASIC loops.

You'll compare slow and fast versions of the same code, learning why some patterns are faster. These are the secrets used in **Wizard of Wor**, **Jumpman**, and other BASIC-accelerated games!

## Basic Example

Slow vs fast loops:

```basic
10 REM *** SLOW VERSION ***
20 FOR I=1 TO 1000
30 POKE 53280,PEEK(53280)+1
40 IF PEEK(53280)>15 THEN POKE 53280,0
50 NEXT I
60 REM *** FAST VERSION ***
70 C=0
80 FOR I=1 TO 1000
90 POKE 53280,C
100 C=C+1
110 IF C>15 THEN C=0
120 NEXT I
```

The fast version is twice as fast! Why? PEEK is slow—reading from memory takes time. Storing the value in variable C and using arithmetic is much faster. Avoid PEEK in loops when possible!

## Practical Example

Fast sprite movement:

```basic
10 REM *** SLOW SPRITE ***
20 FOR I=832 TO 895:POKE I,255:NEXT I
30 POKE 2040,13:POKE 53269,1
40 FOR I=1 TO 200
50 POKE 53248,PEEK(53248)+2
60 NEXT I
70 REM *** FAST SPRITE ***
80 X=24
90 FOR I=1 TO 200
100 X=X+2
110 POKE 53248,X
120 NEXT I
```

Same movement, half the time! The slow version reads the position with PEEK, adds 2, writes it back. The fast version tracks position in variable X—no PEEK needed. Variables are always faster than memory reads!

## Quick Reference

```basic
REM OPTIMIZATION RULES
1. Avoid PEEK in loops       Use variables instead
2. Reuse calculations        Store in vars, don't repeat
3. Use integers              Faster than floats
4. Short variable names      A is faster than SCORE
5. Move code out of loops    Calculate once, not 1000 times

REM TIMING
TI$="000000"                 Reset timer to 0
TI                           Read timer (60ths/sec)
T/60                         Convert to seconds

REM VARIABLE REUSE
X=X+2                        Faster than PEEK+POKE
C=C+1:IF C>15 THEN C=0      Faster than modulo

REM CALCULATED GOTO
ON X GOTO 100,200,300        Jump by variable
Faster than: IF X=1 THEN 100:IF X=2 THEN 200...

REM COMMON MISTAKES
FOR I=1 TO LEN(A$)          Slow! Calculates LEN each loop
L=LEN(A$):FOR I=1 TO L      Fast! Calculate once

POKE P,PEEK(P)+1            Slow! Read then write
V=V+1:POKE P,V              Fast! Variable arithmetic
```

## What You've Learnt

- PEEK is slow—use variables to track values
- Calculate once outside loops, not every iteration
- Variables are faster than memory reads
- System timer (TI) measures code performance
- Reusing variables can double execution speed
- Simple optimisations have dramatic effects in BASIC

These are the exact techniques used in commercial C64 games to make BASIC fast enough for real-time gameplay!
