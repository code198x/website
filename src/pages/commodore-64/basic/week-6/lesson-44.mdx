## Lesson 44 – Hit Detection

Bullets are useless unless the world notices. The VIC-II tracks sprite overlaps for you—read the collision register once per frame, react, and you instantly have explosions, score bumps, and enemy respawns.

> [📷 suggested: enemy sprite flashing when the projectile connects]

---

### The One-Minute Tour

- `PEEK(53279)` returns a bitmask of the sprites that collided this frame.
- React first, then clear the hit by reading the register only once.
- Flash colours and award points immediately so the player *feels* the impact.

---

### Example Program

```basic
NEW
10 REM *** HIT DETECTION DEMO ***
20 PRINT CHR$(147);"SPACE FIRE  Q QUIT"
30 FOR I=832 TO 957:POKE I,0:NEXT I
40 POKE 2040,13:POKE 2041,14:POKE 2042,15
50 POKE 53269,7:POKE 53287,12:POKE 53288,1:POKE 53289,2
60 PX=160:PY=210:BX=0:BY=0:SHOT=0:COOL=0
70 ENX=80:ENY=90:DIR=2:ALIVE=1:RESPAWN=0:SCORE=0
80 R=RND(-TI)
90 GET K$:IF K$="Q" THEN END
100 IF K$="A" THEN PX=PX-4
110 IF K$="D" THEN PX=PX+4
120 IF K$="W" THEN PY=PY-3
130 IF K$="S" THEN PY=PY+3
140 IF PX<24 THEN PX=24
150 IF PX>320 THEN PX=320
160 IF PY<80 THEN PY=80
170 IF PY>233 THEN PY=233
180 POKE 53248,PX:POKE 53249,PY
190 IF K$=" " AND SHOT=0 AND COOL=0 THEN GOSUB 400
200 IF SHOT=1 THEN GOSUB 420
210 IF COOL>0 THEN COOL=COOL-1
220 IF ALIVE THEN GOSUB 480 ELSE GOSUB 500
230 COL=PEEK(53279)
240 IF (COL AND 2) AND (COL AND 4) THEN GOSUB 520
250 PRINT CHR$(19);"SCORE:";SCORE;TAB(18);"SHOT:";:IF SHOT THEN PRINT "FLYING"; ELSE PRINT "READY ";
260 IF ALIVE=0 THEN PRINT TAB(30);"TARGET RESET" ELSE PRINT TAB(30);"TARGET ACTIVE";
270 FOR D=1 TO 3:NEXT D
280 GOTO 90
400 REM *** LAUNCH ***
410 SHOT=1:BX=PX:BY=PY-16:COOL=20:POKE 53250,BX:POKE 53251,BY:POKE 53288,1
415 RETURN
420 REM *** BULLET UPDATE ***
430 BY=BY-6
440 IF BY<48 THEN SHOT=0:POKE 53251,0:RETURN
450 POKE 53250,BX:POKE 53251,BY
460 RETURN
480 REM *** ENEMY MOVE ***
490 ENX=ENX+DIR
500 IF ENX<40 OR ENX>290 THEN DIR=-DIR:ENX=ENX+DIR
510 POKE 53252,ENX:POKE 53253,ENY
520 RETURN
530 REM *** RESPAWN TIMER ***
540 RESPAWN=RESPAWN-1
550 IF RESPAWN<=0 THEN GOSUB 640
560 RETURN
580 REM *** HANDLE HIT ***
590 SHOT=0:POKE 53251,0:COOL=10
600 ALIVE=0:SCORE=SCORE+100:RESPAWN=30
610 POKE 53289,10:FOR F=1 TO 50:NEXT F:POKE 53289,2
620 POKE 53253,0
630 RETURN
640 REM *** READY NEW TARGET ***
650 ENX=40+INT(RND(1)*240)
660 ENY=70+INT(RND(1)*60)
670 IF RND(1)<.5 THEN DIR=2 ELSE DIR=-2
680 ALIVE=1:RESPAWN=0
690 POKE 53252,ENX:POKE 53253,ENY
700 RETURN
```

Sample output (after a hit):

```
SCORE:100       SHOT:READY            TARGET RESET
```

Lines 230–240 grab the collision register once per frame. Bit 2 corresponds to sprite #1 (the bullet), and bit 4 to sprite #2 (the enemy). When both bits are set, we know those two sprites overlapped. The hit routine (580–700) cancels the projectile, flashes the enemy colour, bumps the score, and respawns the target elsewhere for the next volley after a short cooldown.

> **Tip:** Read `53279` into a variable and act on that copy. Every read clears the register, so calling `PEEK` twice would miss the hit entirely.

### Experiment Section

- Spawn debris when the collision happens by briefly turning on extra sprites with random offsets.
- Require two hits: add a `shield` counter that must reach zero before the enemy disappears.
- Introduce friendly fire: if the enemy collides with the player, deduct a life using the same bitmask trick.
- Use `COL AND 1` to watch for collisions between the player and enemy when you expand the loop.

### Concept Expansion

Once you’re comfortable reacting to collisions, you can stack behaviours: play SID noises, spawn particles, advance difficulty tables, or trigger state shifts for enemies. The mechanic works for bullets, power-ups, even moving obstacles.

---

### Game Integration

Store the collision mask after the main update step:

```basic
COL=PEEK(53279)
IF COL AND ENEMY_MASK THEN GOSUB 5200
```

Park the hit-response routine at line `5200` (add a `REM ENEMY HIT HANDLER`). Processing collisions at the end of the frame keeps input and movement logic clean.

### Quick Reference

```basic
REM Read once per frame
COL=PEEK(53279)

REM Test bullet (sprite 1) vs enemy (sprite 2)
IF (COL AND 2) AND (COL AND 4) THEN GOSUB 5200

REM Reset projectile
SHOT=0:POKE 53251,0:COOL=10
```

### What You’ve Learnt

- Sprite collisions are a single `PEEK` away—just remember to react immediately.
- Hits should cancel or recycle the actors involved so the next frame is ready.
- Flashing colours and updating the score right away sells the impact.
