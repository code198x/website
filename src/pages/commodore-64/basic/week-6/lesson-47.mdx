## Lesson 47 – Saving Scores

Arcades lived on high-score tables. In BASIC we can keep them in memory and persist them to disk for the next play session. This lesson builds a five-entry table, inserts a new result, and writes it out so your triumph survives the power switch.

### The One-Minute Tour

- Use parallel arrays (`NAME$()`, `SCORE()`) to keep names and values aligned.
- Find the insert position, shift lower entries down, and drop the new champion in place.
- `OPEN`/`PRINT#` writes data to disk—perfect for keeping a small text leaderboard.

---

### Example Program

```basic
NEW
10 REM *** HIGH SCORE TABLE ***
20 DIM NAME$(5),SC(5)
30 FOR I=1 TO 5:READ NAME$(I):READ SC(I):NEXT I
40 GOSUB 150
50 INPUT "YOUR SCORE";NS
60 INPUT "INITIALS (3 CHARS)";N$
70 N$=LEFT$(N$,3)
80 GOSUB 200
90 GOSUB 150
100 INPUT "SAVE TO DISK (Y/N)";A$
110 IF A$="Y" THEN GOSUB 300
120 DATA "ACE",500,"JAX",420,"MIN",360,"SID",220,"DOC",150
130 END
150 PRINT CHR$(147);"TOP PILOTS"
160 FOR I=1 TO 5
170 PRINT I;".";TAB(6);NAME$(I);TAB(12);SC(I)
180 NEXT I
190 RETURN
200 FOR I=1 TO 5
210 IF NS>SC(I) THEN POS=I:GOTO 230
220 NEXT I:RETURN
230 FOR J=5 TO POS+1 STEP -1
240 SC(J)=SC(J-1):NAME$(J)=NAME$(J-1)
250 NEXT J
260 SC(POS)=NS:NAME$(POS)=N$
270 RETURN
300 PRINT "SAVING..."
310 OPEN 1,8,2,"HISCORE,S,W"
320 FOR I=1 TO 5
330 PRINT#1,NAME$(I);",";SC(I)
340 NEXT I
350 CLOSE 1
360 PRINT "DONE. LOAD WITH OPEN 1,8,2:""HISCORE,S,R"""
370 RETURN
```

Sample output:

```
TOP PILOTS
1. ACE    500
2. JAX    420
3. MIN    360
4. YOU    275
5. SID    220
```

Lines 20–40 seed the table from `DATA`. When a new score arrives, the insert routine (200–270) scans for the first score lower than the newcomer, slides the trailing entries down, and drops the new initials into the gap. If the player doesn’t beat the table, nothing changes. The save routine (300–370) writes comma-separated lines to a disk file named `HISCORE`, which you can reload later with `INPUT#` or `GET#`.

> **Tip:** When running inside an emulator, device 8 points to the mounted disk image. Replace it with `1` (tape) or `0` (keyboard) if you’re experimenting elsewhere.

### Concept Expansion

Saving data is just formatted text. Once you understand how to write and read arrays, you can persist settings, level progress, even map edits. The same insertion logic works for combo multipliers or lap times.

---

### Game Integration

Load on start-up, save on demand:

```basic
GOSUB 9000
IF SCORE>SC(5) THEN GOSUB 9200: GOSUB 9400
```

Use the 9000s block for score-table utilities (e.g., `9000 REM LOAD TABLE`, `9200 REM INSERT NEW SCORE`, `9400 REM SAVE TABLE`). This keeps your leaderboard up to date without rebuilding it from scratch.

### Quick Reference

```basic
REM Insert score
FOR I=1 TO 5
  IF NS>SC(I) THEN POS=I:GOTO 230
NEXT I
RETURN

230 FOR J=5 TO POS+1 STEP -1
  SC(J)=SC(J-1)
NEXT J
SC(POS)=NS
NAME$(POS)=N$

REM Disk save
OPEN 1,8,2,"HISCORE,S,W"
FOR I=1 TO 5:PRINT#1,NAME$(I);",";SC(I):NEXT I:CLOSE 1
```

### What You’ve Learnt

- Parallel arrays make high-score tables easy to sort and print.
- Insertion-by-shift keeps the list in descending order at all times.
- Simple file commands let you persist data for your next power-on.
