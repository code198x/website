## What You'll Build

Card matching puzzle game with custom characters. Find pairs, clear the board, compete with a friend.

Cards face down on a grid. Turn over two — do they match? Memory and strategy combine. Custom character graphics make each card distinctive. Two-player mode adds competition.

## Skills You'll Master

- **Custom character definition** — graphical characters
- **Two-dimensional arrays** — grid storage
- **Game state management** — tracking revealed cards
- **Turn-based mechanics** — alternating play
- **Match detection** — pair finding
- **Score and move tracking** — statistics
- **Two-player mode** — multiplayer BASIC
- **Polish and presentation** — game feel
