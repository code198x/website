## The Ultimate Arcade Experience!

Every classic arcade cabinet has one thing: a **high score table**! Three-letter names like "ACE", "JAX", "ZED"—just like Pac-Man, Defender, and Donkey Kong!

You'll store names in a string array and scores in a numeric array, then sort them to keep the best players on top. This is the capstone of Week 5—combining arrays, loops, and input handling into one classic feature!

## Basic Example

Store one score with a name:

```basic
10 REM *** STORE ONE SCORE ***
20 DIM N$(5),S(5)
30 N$(1)="ACE"
40 S(1)=1500
50 PRINT CHR$(147)
60 PRINT "HIGH SCORES"
70 PRINT "-----------"
80 PRINT "1. ";N$(1);SPC(10);S(1)
90 END
```

Arrays for names and scores! N$(1) holds the name, S(1) holds the score. This is the basic storage pattern.

## Practical Example

Add a new score and sort:

```basic
10 REM *** ADD AND SORT ***
20 DIM N$(5),S(5)
30 N$(1)="ACE":S(1)=1500
40 N$(2)="MAX":S(2)=1200
50 N$(3)="ZED":S(3)=900
60 REM NEW SCORE
70 INPUT "NAME (3 LETTERS)";NA$
80 INPUT "SCORE";NS
90 REM FIND POSITION
100 P=4
110 FOR I=1 TO 3
120 IF NS>S(I) THEN P=I:GOTO 150
130 NEXT I
140 REM INSERT SCORE
150 FOR I=3 TO P STEP -1
160 N$(I+1)=N$(I)
170 S(I+1)=S(I)
180 NEXT I
190 N$(P)=NA$:S(P)=NS
200 REM DISPLAY
210 PRINT CHR$(147)
220 FOR I=1 TO 4
230 PRINT I;". ";N$(I);SPC(8);S(I)
240 NEXT I
250 END
```

Enter a name and score—it finds the right position, shifts lower scores down, and inserts the new entry! Just like arcade machines do it.

## Quick Reference

```basic
REM ARRAY SETUP
DIM N$(5),S(5)    Name and score arrays

REM NAME INPUT
INPUT "NAME";NA$
IF LEN(NA$)<>3    Enforce 3 characters
NA$=LEFT$(NA$,3)  Truncate to 3 letters

REM FIND POSITION
FOR I=1 TO 5
IF NS>S(I) THEN P=I  Position for insert

REM SHIFT DOWN
FOR I=4 TO P STEP -1  Work backwards
N$(I+1)=N$(I)         Move name down
S(I+1)=S(I)           Move score down

REM INSERT
N$(P)=NA$         Insert name
S(P)=NS           Insert score

REM FORMATTING
SPC(12-LEN(STR$(S(I))))  Right-align scores
```
