## Lesson 36 – Verticality

Side-scrollers get all the love, but a C64 world is two-dimensional. Once the camera glides, the player must glide with it—up, down, left, right. Verticality is about managing motion on both axes, balancing thrust and gravity, and keeping sprites inside the scene without jerky stops.

### The One-Minute Tour

- Store horizontal and vertical velocity separately so controls feel responsive.
- Clamp positions to safe bounds and zero the velocity when you collide with the edge.
- Apply “friction” each frame so the sprite settles naturally instead of drifting forever.

---

### Example Program

```basic
NEW
10 REM *** TWO-AXIS THRUST ***
20 PRINT CHR$(147);"ARROW KEYS: WASD  SPACE: STOP"
30 POKE 2040,13:POKE 53287,6:POKE 53269,1
40 X=160:Y=120:VX=0:VY=0
50 GET K$
60 IF K$="A" AND VX>-4 THEN VX=VX-1
70 IF K$="D" AND VX<4 THEN VX=VX+1
80 IF K$="W" AND VY>-4 THEN VY=VY-1
90 IF K$="S" AND VY<4 THEN VY=VY+1
100 IF K$=" " THEN VX=0:VY=0
110 X=X+VX:Y=Y+VY
120 IF X<24 THEN X=24:VX=0
130 IF X>320 THEN X=320:VX=0
140 IF Y<50 THEN Y=50:VY=0
150 IF Y>233 THEN Y=233:VY=0
160 POKE 53248,X:POKE 53249,Y
170 IF VX>0 THEN VX=VX-1
180 IF VX<0 THEN VX=VX+1
190 IF VY>0 THEN VY=VY-1
200 IF VY<0 THEN VY=VY+1
210 FOR D=1 TO 4:NEXT D
220 GOTO 50
```

This loop keeps a sprite floating in space. Lines 60–90 nudge horizontal (`VX`) and vertical (`VY`) velocity in response to WASD input. Lines 120–150 clamp the position to the safe play area and reset velocity if you hit a boundary. Lines 170–200 apply friction, slowly reducing velocity so the sprite drifts to a stop—like a hovercraft.

> **Tip:** Keep velocities small (±4 pixels/frame). Bigger steps can skip past collision checks or make the motion feel sloppy.

---

### Experiment Section

- Replace the friction block with `VY=VY+GRAV` to add gravity while leaving horizontal thrusters.
- Draw a status panel at the top: `PRINT "VX:";VX;" VY:";VY` to teach players how thrust affects movement.
- Swap keyboard input for joystick reads from `PEEK(56320)` and map each bit to a direction.
- Limit vertical thrust so the player must ride air currents or platforms to climb.

### Concept Expansion

Two-axis control is the backbone of scrolling shooters, jetpack adventures, and platformers with climbing. By separating velocity from position you also make room for acceleration, gravity, knockback, or AI-driven movement. The next lesson gives that same freedom to your enemies so the world feels alive.

### Game Integration

Collision with your `DATA` map is one array lookup away:

```basic
CELLX=INT((X-24)/8)
CELLY=INT((Y-50)/8)
IF MAP(CELLY,CELLX)=1 THEN Y=Y-8:VY=0
```

Snapping the sprite back by eight pixels keeps it aligned to the grid, and zeroing `VY` stops further drift into the wall. Mix this with smooth scrolling and the player will ride the level effortlessly.

### Quick Reference

```basic
REM Velocity handling
VX=VX+DX
VY=VY+DY
X=X+VX
Y=Y+VY

REM Bounds check (screen safe zone)
IF X<24 THEN X=24:VX=0
IF Y>233 THEN Y=233:VY=0

REM Friction
IF VX>0 THEN VX=VX-1
```
