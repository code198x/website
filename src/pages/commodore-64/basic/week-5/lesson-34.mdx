## Navigate the Labyrinth!

You've moved sprites freely—but what if **walls block your path**? Maze navigation checks each move before allowing it, creating the tight corridors of Pac-Man, Boulder Dash, and every dungeon crawler!

Every maze game uses the same principle: check what's ahead, move only if it's clear.

## Basic Example

Single wall check:

```basic
10 REM *** WALL CHECK ***
20 PRINT CHR$(147)
30 REM DRAW WALL
40 FOR I=10 TO 20
50 POKE 1024+5*40+I,160
60 POKE 55296+5*40+I,0
70 NEXT I
80 FOR I=832 TO 894:POKE I,255:NEXT I
90 POKE 2040,13:POKE 53269,1:POKE 53287,7
100 X=100:Y=80
110 GET K$
120 IF K$="D" THEN NX=X+3:NY=Y
130 P=1024+INT(NY/8)*40+INT(NX/8)
140 IF PEEK(P)<>160 THEN X=NX:Y=NY
150 POKE 53248,X:POKE 53249,Y
160 GOTO 110
```

Try moving right into the wall—it blocks you! Character 160 (solid block) stops movement.

Four-direction wall checking:

```basic

200 NX=X:NY=Y
210 IF K$="W" THEN NY=Y-3

280 GOTO 190
```

Navigate inside the box! Walls block all four directions.

## How Collision Detection Works

**Lines 180-220**: Store next position in NX/NY before moving

**Line 240**: Convert sprite X/Y to screen position

**Line 250**: Check if that position contains a wall (160)

**Line 260**: Only update X/Y if path is clear

**Line 280**: Check if player reached goal (81)

**Lines 1010-1130**: 13×21 maze stored in DATA (273 values)

## Quick Reference

```basic
REM COLLISION PATTERN
NX=X:NY=Y                    Start with current position
IF K$="W" THEN NY=Y-3        Calculate next position
P=1024+INT(NY/8)*40+INT(NX/8) Convert to screen memory
IF PEEK(P)=160 THEN 270      If wall, skip movement
X=NX:Y=NY                    Otherwise, update position

REM MAZE CHARACTERS
160   Solid block (wall)
32    Space (path)
81    Q (goal)

REM SPRITE TO SCREEN
Position = 1024 + INT(Y/8)*40 + INT(X/8)
   └─ Screen memory  └─ Row    └─ Column

REM DATA MAZE
1010 DATA 160,160,160...
   └─ One DATA line per maze row
```

## What You've Learnt

- Check next position before moving

- Convert sprite X/Y to screen position
- Block movement if wall detected
- DATA statements create maze layouts
- Grid-based movement for precision
