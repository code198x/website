## Catch Them Before They Fall!

What goes up must come down—and **falling object games** turn gravity into gameplay! Move your basket to catch items as they drop, score points, and experience the arcade classic that defined reaction-based gaming.

From Kaboom! to Ice Cold Beer, catch games test reflexes with simple physics and addictive scoring.

## Basic Example

Single falling object:

```basic
10 REM *** FALLING OBJECT ***
20 PRINT CHR$(147)
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 POKE 2040,13:POKE 53269,1
50 POKE 53287,7
60 X=160:Y=50
70 Y=Y+2
80 POKE 53248,X:POKE 53249,Y
90 IF Y>229 THEN Y=50
100 FOR D=1 TO 5:NEXT D
110 GOTO 70
```

Watch it drop! When it reaches bottom, it respawns at top. This is the foundation of all falling object games.

## Practical Example

Add basket to catch it:

```basic
10 REM *** BASKET CATCH ***
20 PRINT CHR$(147)
30 PRINT "SCORE:0"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,170:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53269,3:POKE 53287,2:POKE 53288,7
80 OX=160:OY=50:BX=160:BY=200:SC=0
90 GET K$
100 IF K$="A" THEN BX=BX-4
110 IF K$="D" THEN BX=BX+4
120 IF BX<24 THEN BX=24
130 IF BX>320 THEN BX=320
140 OY=OY+2
150 POKE 53248,OX:POKE 53249,OY
160 POKE 53250,BX:POKE 53251,BY
170 REM CHECK CATCH
180 C=PEEK(53279)
190 IF C>0 AND OY>180 THEN SC=SC+1:OY=50:OX=INT(RND(1)*200)+60
200 IF OY>229 THEN PRINT CHR$(19);"MISSED!":END
210 POKE 1046,SC+48
220 FOR D=1 TO 3:NEXT D
230 GOTO 90
```

Catch it in the basket or game over! Score increases with each catch.

## WOW Moment: Complete Catch Game

```basic
NEW
10 REM *** CATCH GAME ***
20 PRINT CHR$(147)
30 PRINT "SCORE:0  LIVES:3"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,170:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53269,3:POKE 53287,2:POKE 53288,7
80 OX=160:OY=50:BX=160:BY=200:SC=0:LV=3:SP=2
90 GET K$
100 IF K$="A" THEN BX=BX-5
110 IF K$="D" THEN BX=BX+5
120 IF BX<24 THEN BX=24
130 IF BX>320 THEN BX=320
140 REM FALLING OBJECT
150 OY=OY+SP
160 POKE 53248,OX:POKE 53249,OY
170 POKE 53250,BX:POKE 53251,BY
180 REM CHECK CATCH
190 C=PEEK(53279)
200 IF C>0 AND OY>180 THEN GOSUB 400
210 REM CHECK MISS
220 IF OY>229 THEN GOSUB 500
230 REM UPDATE HUD
240 POKE 1046,(SC/10)+48
250 POKE 1047,SC AND 15+48
260 POKE 1056,LV+48
270 FOR D=1 TO 3:NEXT D
280 GOTO 90
390 REM *** CATCH ROUTINE ***
400 SC=SC+1
410 POKE 53287,14:FOR F=1 TO 20:NEXT F:POKE 53287,2
420 OY=50:OX=INT(RND(1)*200)+60
430 IF SC>0 AND SC/5=INT(SC/5) THEN SP=SP+1
440 RETURN
490 REM *** MISS ROUTINE ***
500 LV=LV-1
510 POKE 53287,10:FOR F=1 TO 30:NEXT F:POKE 53287,2
520 IF LV=0 THEN PRINT CHR$(19);"GAME OVER! SCORE:";SC:END
530 OY=50:OX=INT(RND(1)*200)+60
540 RETURN
```

![Catch game with scoring](/images/lessons/commodore-64/basic/week-5/lesson-33/catch.gif)

Catch falling objects before they hit the ground! Score increases with each catch, speed increases every 5 catches, miss and lose a life! The basket sprite (170 pattern) creates the perfect catching platform, whilst colour flashes give feedback for catches (yellow) and misses (red).

## Quick Reference

```basic
REM GRAVITY PATTERN
OY=OY+SP         Add speed to Y position
SP=2             Starting fall speed
SP=SP+1          Increase difficulty

REM CATCH DETECTION
C=PEEK(53279)             Check collision
IF C>0 AND OY>180 THEN... Only catch near bottom

REM RESPAWN PATTERN
OY=50                      Reset to top
OX=INT(RND(1)*200)+60     Random X position

REM DIFFICULTY SCALING
IF SC/5=INT(SC/5) THEN SP=SP+1
   └─ Every 5 points    └─ Speed increase

REM FEEDBACK
POKE 53287,14  Yellow flash for catch
POKE 53287,10  Red flash for miss
```

## What You've Learnt

- Gravity = add to Y position each frame
- Catch detection needs position check
- Random respawn keeps game unpredictable
- Speed scaling creates difficulty curve
- Colour feedback communicates game state

You've mastered vertical scrolling gameplay!
