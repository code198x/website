## Remember This!

Can you repeat what the computer shows you? Simon Says is the classic **memory pattern game**—watch the sequence of colours and sounds, then repeat it exactly!

Every memory game from Simon to Brain Training uses this exact pattern: show sequence, player repeats, add one more step.

## Basic Example

Show 3-number sequence, player repeats:

```basic
10 REM *** PATTERN REPEAT ***
20 PRINT CHR$(147)
30 DIM P(3)
40 P(1)=7:P(2)=4:P(3)=2
50 PRINT "WATCH THE PATTERN:"
60 FOR I=1 TO 3
70 POKE 53281,P(I)
80 FOR J=1 TO 30:NEXT J
90 POKE 53281,0
100 FOR J=1 TO 20:NEXT J
110 NEXT I
120 PRINT "ENTER 3 COLOURS (1-7):"
130 FOR I=1 TO 3
140 INPUT "COLOUR";C
150 IF C<>P(I) THEN PRINT "WRONG!":END
160 NEXT I
170 PRINT "CORRECT!"
```

Three colours flash on the border—can you remember them? Pattern stored in array P().

## Practical Example

Growing sequence—adds 1 each round:

```basic
10 REM *** GROWING PATTERN ***
20 PRINT CHR$(147)
30 DIM P(10)
40 LEN=1
50 FOR R=1 TO 5
60 P(LEN)=INT(RND(1)*4)+2
70 PRINT CHR$(147)
80 PRINT "ROUND";R;" - WATCH:"
90 FOR I=1 TO LEN
100 POKE 53281,P(I)
110 FOR J=1 TO 40:NEXT J
120 POKE 53281,0
130 FOR J=1 TO 20:NEXT J
140 NEXT I
150 PRINT "REPEAT (2-5):"
160 FOR I=1 TO LEN
170 INPUT C
180 IF C<>P(I) THEN PRINT "WRONG!":END
190 NEXT I
200 PRINT "CORRECT!":PRINT
210 FOR J=1 TO 60:NEXT J
220 LEN=LEN+1
230 NEXT R
240 PRINT "YOU WON!"
```

Five rounds, pattern grows by 1 each round! LEN tracks how long the sequence is.

## WOW Moment: Simon Says with Sound

```basic
60 GET K$:IF K$="" THEN GOTO 60
70 DIM P(20):DIM C(4):DIM N(4)
80 C(1)=7:C(2)=10:C(3)=2:C(4)=5
90 N(1)=220:N(2)=262:N(3)=330:N(4)=392
100 LEN=3

130 PRINT CHR$(147)
140 PRINT "ROUND";R;" - LENGTH";LEN
150 PRINT:PRINT "WATCH THE PATTERN:"
160 FOR I=1 TO LEN
170 COL=P(I)
180 POKE 53281,C(COL)
190 POKE 54296,15
200 POKE 54273,N(COL)/256
210 POKE 54272,N(COL) AND 255
220 POKE 54276,33
230 FOR J=1 TO 25:NEXT J
240 POKE 54276,32
250 POKE 53281,0
260 FOR J=1 TO 15:NEXT J
270 NEXT I

290 FOR I=1 TO LEN
300 GET K$:IF K$="" THEN GOTO 300
310 IF K$<"1" OR K$>"4" THEN GOTO 300
320 NUM=VAL(K$)

410 IF NUM<>P(I) THEN GOTO 470

510 END
```

## Quick Reference

```basic
REM PATTERN ARRAYS
DIM P(20)            Pattern sequence
P(1)=7               Store colour/number
LEN=3                Current length

REM COLOUR ARRAYS
DIM C(4)             Colour table
C(1)=7:C(2)=10       Yellow, light cyan
C(3)=2:C(4)=5        Red, green

REM SOUND ARRAYS
DIM N(4)             Note frequencies
N(1)=220:N(2)=262    A3, C4
N(3)=330:N(4)=392    E4, G4

REM DISPLAY PATTERN
FOR I=1 TO LEN       Loop through pattern
POKE 53281,C(P(I))   Show colour
Wait delay
POKE 53281,0         Clear

REM INPUT CHECK
IF NUM<>P(I)         Compare to pattern
THEN GOTO gameover   Wrong = end
```

## What You've Learnt

- Arrays store sequences of patterns
- Colour/sound arrays for feedback
- Loop through pattern to display
- Compare input to stored sequence
- Length variable = progressive difficulty

Pattern memory transforms simple colours into brain-training challenges!
