## Dodge to Survive!

How far can you run? Endless runner games like **Canabalt** and **Temple Run** use one simple pattern: obstacles scroll toward you, and you dodge!

Every runner game uses this exact mechanic: scrolling hazards, player movement, distance tracking.

## Basic Example

Single scrolling obstacle:

```basic
10 REM *** SCROLLING OBSTACLE ***
20 PRINT CHR$(147)
30 OX=320:OY=120
40 PY=120
50 PRINT CHR$(19);"*"
60 OX=OX-2
70 IF OX<24 THEN OX=320:OY=120
80 POKE 53248,OX:POKE 53249,OY
90 GOTO 60
```

An obstacle scrolls from right to left! When it goes off screen, it reappears on the right.

## Practical Example

Dodge obstacle with up/down:

```basic
10 REM *** DODGE OBSTACLE ***
20 PRINT CHR$(147)
30 PRINT "W/S TO DODGE - HIT Q TO QUIT"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53287,14:POKE 53269,1
60 PY=120:OX=320:OY=120
70 GET K$
80 IF K$="W" THEN PY=PY-3
90 IF K$="S" THEN PY=PY+3
100 IF K$="Q" THEN END
110 IF PY<50 THEN PY=50
120 IF PY>229 THEN PY=229
130 OX=OX-3
140 IF OX<24 THEN OX=320:OY=INT(RND(1)*150)+70
150 POKE 53248,120:POKE 53249,PY
160 POKE 53250,OX:POKE 53251,OY
170 IF PEEK(53279) THEN PRINT CHR$(147);"HIT!":END
180 GOTO 70
```

Dodge the scrolling obstacle with W/S keys! Collision detection stops the game. The obstacle reappears at a random height each time.

## WOW Moment: Obstacle Course Race

```basic
NEW
10 REM *** OBSTACLE COURSE ***
20 PRINT CHR$(147)
30 PRINT "DODGE OBSTACLES - REACH 100M TO WIN!"
40 PRINT:PRINT "W/S TO MOVE - PRESS ANY KEY"
50 GET K$:IF K$="" THEN GOTO 50
60 FOR I=832 TO 894:POKE I,255:NEXT I
70 POKE 2040,13:POKE 53287,3
80 POKE 53269,7
90 PY=120:DIST=0
100 O1X=320:O1Y=80
110 O2X=420:O2Y=160
120 O3X=520:O3Y=100
130 POKE 53241,2:POKE 53242,2:POKE 53243,2
140 GET K$
150 IF K$="W" THEN PY=PY-3
160 IF K$="S" THEN PY=PY+3
170 IF K$="Q" THEN END
180 IF PY<50 THEN PY=50
190 IF PY>229 THEN PY=229
200 O1X=O1X-2:O2X=O2X-2:O3X=O3X-2
210 IF O1X<24 THEN O1X=340:O1Y=INT(RND(1)*150)+70
220 IF O2X<24 THEN O2X=340:O2Y=INT(RND(1)*150)+70
230 IF O3X<24 THEN O3X=340:O3Y=INT(RND(1)*150)+70
240 DIST=DIST+1
250 POKE 53248,120:POKE 53249,PY
260 POKE 53250,O1X:POKE 53251,O1Y
270 POKE 53252,O2X:POKE 53253,O2Y
280 POKE 53254,O3X:POKE 53255,O3Y
290 PRINT CHR$(19);"DISTANCE:";INT(DIST/10);"M    "
300 IF PEEK(53279) THEN GOTO 350
310 IF DIST>=1000 THEN GOTO 370
320 GOTO 140
350 PRINT CHR$(147)
360 PRINT "CRASHED AT";INT(DIST/10);"M!":END
370 PRINT CHR$(147)
380 PRINT "YOU WIN! 100M COMPLETE!"
390 END
```

![Obstacle course with distance tracking](/images/lessons/commodore-64/basic/week-5/lesson-39/race.png)

Three scrolling obstacles at random heights! Dodge them with W/S keys and reach 100 metres to win. Each obstacle respawns at a new position when it scrolls off-screen—the course never ends until you crash or reach the finish!

## Quick Reference

```basic
REM SCROLLING OBSTACLES
OX=OX-2              Move left
IF OX<24 THEN OX=320 Wrap to right edge

REM RANDOM HEIGHTS
OY=RND(1)*150+70     Random Y between 70-220

REM DISTANCE TRACKING
DIST=DIST+1          Increment each frame
INT(DIST/10)         Convert to metres

REM MULTIPLE SPRITES
POKE 53269,7         Enable sprites 0,1,2
O1X, O2X, O3X        Track separately
POKE 53250-255       Position obstacles

REM COLLISION DETECTION
PEEK(53279)          Sprite-sprite collision
Bit set = collision detected
```

## What You've Learnt

- Scrolling obstacles create runner gameplay
- Multiple obstacles increase difficulty
- Distance tracking measures progress
- Random respawning keeps gameplay fresh
- Collision ends the game or triggers loss

Scrolling hazards turn simple dodging into addictive "one more try" gameplay!
