### Your Skill Timeline

- **Week 1–2:** Core language—loops, conditions, arrays, data-driven maps.
- **Week 3–4:** Sprites, HUDs, random events, AI, the `Circuit Run` mini-game.
- **Week 5–6:** Scrolling worlds, power-ups, states, collisions, `Scroll Runner` and `Galactic Miner`.
- **Week 7:** Libraries, menus, cutscenes, debugging, optimisation, assembly helpers.
- **Week 8:** Tuning feel, squeezing speed, analysing limits, preparing for machine code.

You’ve written playable games, modular libraries, and even poked a machine-code routine into RAM. That’s a full retro toolkit.

---

### Reflection Checklist

Run through this list when you ship a project:

- [ ] Controls feel tight (`Lesson 57`): fixed-step loops, easing, instrumented tuning.
- [ ] Performance budget met (`Lesson 58`): hotspot profiling, table-based updates.
- [ ] Fallbacks in place (`Lesson 59`): friendly errors, optional features toggled.
- [ ] Memory map understood (`Lesson 60`): pointers verified, screen RAM tidy.
- [ ] Hybrid helpers installed (`Lesson 61`): assembly routines at the ready.
- [ ] BASIC-to-assembly plan drafted (`Lesson 62`): identify routines to port.
- [ ] Threshold report logged (`Lesson 63`): know what breaks first.

Keep this list near your keyboard. The next time you build a lesson project—or help someone else—check the boxes.
