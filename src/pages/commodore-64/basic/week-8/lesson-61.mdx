## Test Your Knowledge!

Quiz games made learning fun—**Trivial Pursuit**, **Brain Quiz**, **Mastermind**. Test knowledge under time pressure, compete for high scores, learn whilst playing!

You'll create a complete quiz game with 10 questions, multiple choice, timer, and scoring. This is the genre that made trivia competitive!

## Basic Example

Basic question and answer:

```basic
10 REM *** BASIC QUIZ ***
20 PRINT CHR$(147)
30 PRINT "WHAT IS 2+2?"
40 PRINT
50 PRINT "A) 3"
60 PRINT "B) 4"
70 PRINT "C) 5"
80 PRINT
90 INPUT "ANSWER";A$
100 IF A$="B" THEN PRINT "CORRECT!":END
110 PRINT "WRONG! ANSWER WAS B"
120 END
```

Basic question with multiple choice! But there's only one question, no timer, no score tracking!

## Practical Example

Multiple questions with scoring:

```basic
10 REM *** MULTI-QUESTION QUIZ ***
20 PRINT CHR$(147)
30 SC=0:Q=1
40 PRINT CHR$(19)
50 PRINT "SCORE:";SC
60 PRINT
70 ON Q GOTO 100,200,300
80 PRINT "QUIZ COMPLETE! SCORE:";SC:END
90 REM
100 PRINT "WHAT IS 2+2?"
110 PRINT "A)3 B)4 C)5"
120 INPUT A$
130 IF A$="B" THEN SC=SC+10:PRINT "CORRECT!"
140 IF A$<>"B" THEN PRINT "WRONG! (B)"
150 Q=2:FOR I=1 TO 1000:NEXT I:GOTO 40
160 REM
200 PRINT "CAPITAL OF FRANCE?"
210 PRINT "A)LONDON B)PARIS C)ROME"
220 INPUT A$
230 IF A$="B" THEN SC=SC+10:PRINT "CORRECT!"
240 IF A$<>"B" THEN PRINT "WRONG! (B)"
250 Q=3:FOR I=1 TO 1000:NEXT I:GOTO 40
260 REM
300 PRINT "FIRST C64 YEAR?"
310 PRINT "A)1980 B)1982 C)1984"
320 INPUT A$
330 IF A$="B" THEN SC=SC+10:PRINT "CORRECT!"
340 IF A$<>"B" THEN PRINT "WRONG! (B)"
350 Q=4:FOR I=1 TO 1000:NEXT I:GOTO 40
```

Now there are multiple questions with score tracking! But we need a timer and more questions!

## WOW Moment: Complete Quiz Game with Timer

```basic
NEW
10 REM *** TRIVIA CHALLENGE ***
20 PRINT CHR$(147)
30 POKE 53280,6:POKE 53281,14
40 PRINT
50 PRINT "  *** TRIVIA CHALLENGE ***"
60 PRINT
70 PRINT "  10 QUESTIONS"
80 PRINT "  10 SECONDS EACH"
90 PRINT "  10 POINTS PER CORRECT"
100 PRINT
110 PRINT "  PRESS FIRE TO START"
120 GET K$:IF K$="" THEN GOTO 120
130 REM *** INIT ***
140 SC=0:Q=1
150 DIM QS$(10):DIM A$(10):DIM B$(10):DIM C$(10):DIM AN$(10)
160 REM *** LOAD QUESTIONS ***
170 QS$(1)="WHAT IS 2+2?":A$(1)="3":B$(1)="4":C$(1)="5":AN$(1)="B"
180 QS$(2)="CAPITAL OF FRANCE?":A$(2)="LONDON":B$(2)="PARIS":C$(2)="ROME":AN$(2)="B"
190 QS$(3)="C64 RELEASE YEAR?":A$(3)="1980":B$(3)="1982":C$(3)="1984":AN$(3)="B"
200 QS$(4)="PLANETS IN SYSTEM?":A$(4)="7":B$(4)="8":C$(4)="9":AN$(4)="B"
210 QS$(5)="SPEED OF LIGHT?":A$(5)="100000":B$(5)="200000":C$(5)="300000":AN$(5)="C"
220 QS$(6)="H2O IS?":A$(6)="OXYGEN":B$(6)="WATER":C$(6)="HYDROGEN":AN$(6)="B"
230 QS$(7)="BINARY FOR 8?":A$(7)="1000":B$(7)="1001":C$(7)="1010":AN$(7)="A"
240 QS$(8)="BIGGEST OCEAN?":A$(8)="ATLANTIC":B$(8)="PACIFIC":C$(8)="INDIAN":AN$(8)="B"
250 QS$(9)="DAYS IN YEAR?":A$(9)="364":B$(9)="365":C$(9)="366":AN$(9)="B"
260 QS$(10)="BITS IN BYTE?":A$(10)="4":B$(10)="8":C$(10)="16":AN$(10)="B"
270 REM *** QUESTION LOOP ***
280 PRINT CHR$(147)
290 POKE 53280,0:POKE 53281,11
300 PRINT "QUESTION";Q;"/10  SCORE:";SC
310 PRINT
320 PRINT QS$(Q)
330 PRINT
340 PRINT "A) ";A$(Q)
350 PRINT "B) ";B$(Q)
360 PRINT "C) ";C$(Q)
370 PRINT
380 PRINT "TIME: ";
390 REM *** TIMER ***
400 TI$="000000"
410 AN$=""
420 FOR T=10 TO 0 STEP -1
430 PRINT CHR$(19);CHR$(17);CHR$(17);CHR$(17);CHR$(17);CHR$(17);CHR$(17);CHR$(17);CHR$(17);"TIME: ";T;" "
440 FOR I=1 TO 100
450 GET K$
460 IF K$="A" OR K$="B" OR K$="C" THEN AN$=K$:T=0:I=100
470 NEXT I
480 NEXT T
490 REM *** CHECK ANSWER ***
500 PRINT CHR$(147)
510 PRINT "QUESTION";Q;": ";QS$(Q)
520 PRINT
530 IF AN$="" THEN PRINT "TIME'S UP!":PRINT "ANSWER WAS: ";AN$(Q):GOTO 600
540 PRINT "YOU ANSWERED: ";AN$
550 PRINT "CORRECT ANSWER: ";AN$(Q)
560 PRINT
570 IF AN$=AN$(Q) THEN PRINT CHR$(18);"CORRECT! +10";CHR$(146):SC=SC+10:POKE 53280,5
580 IF AN$<>AN$(Q) THEN PRINT "WRONG!":POKE 53280,2
590 REM
600 FOR I=1 TO 1500:NEXT I
610 Q=Q+1
620 IF Q>10 THEN GOSUB 1000
630 GOTO 280
640 REM
1000 REM *** FINAL SCORE ***
1010 PRINT CHR$(147)
1020 POKE 53280,6:POKE 53281,14
1030 PRINT
1040 PRINT "  *** QUIZ COMPLETE ***"
1050 PRINT
1060 PRINT "  FINAL SCORE: ";SC;"/100"
1070 PRINT
1080 IF SC=100 THEN PRINT "  PERFECT! GENIUS!"
1090 IF SC>=70 AND SC<100 THEN PRINT "  EXCELLENT!"
1100 IF SC>=40 AND SC<70 THEN PRINT "  GOOD EFFORT!"
1110 IF SC<40 THEN PRINT "  KEEP PRACTISING!"
1120 PRINT
1130 PRINT "  PRESS FIRE TO RETRY"
1140 GET K$:IF K$="" THEN GOTO 1140
1150 GOTO 130
```

![Complete quiz game with timer](/images/lessons/commodore-64/basic/week-8/lesson-61/quiz.png)

A complete quiz game with **10 questions** covering maths, science, geography, and C64 trivia! Each question has:

- **3 multiple choice options** (A, B, C)
- **10 second timer** counting down
- **10 points** for correct answers
- **Instant feedback** (correct/wrong)

The timer uses a FOR loop counting down from 10 to 0. Inside the loop, GET K$ checks for A/B/C input. If answered, the timer exits early. If time runs out (T=0), answer is marked as timeout!

Colour feedback: green border for correct, red for wrong. Final score categories:
- **100**: Perfect genius!
- **70-99**: Excellent!
- **40-69**: Good effort!
- **0-39**: Keep practising!

Questions stored in arrays (QS$, A$, B$, C$, AN$) make it easy to add more. Try creating themed quizzes (history, sports, movies) or difficulty levels!

## Quick Reference

```basic
REM QUIZ STRUCTURE
DIM QS$(10)                 Questions
DIM A$(10):DIM B$(10):DIM C$(10)  Choices
DIM AN$(10)                 Correct answers

REM QUESTION DISPLAY
PRINT QS$(Q)
PRINT "A) ";A$(Q)
PRINT "B) ";B$(Q)
PRINT "C) ";C$(Q)

REM TIMER
TI$="000000"                Reset timer
FOR T=10 TO 0 STEP -1       Countdown
PRINT T                     Display time
GET K$                      Check input
IF answered THEN exit       Early exit
NEXT T

REM ANSWER CHECK
IF AN$=AN$(Q) THEN correct
IF AN$<>AN$(Q) THEN wrong
IF AN$="" THEN timeout

REM SCORING
SC=SC+10                    Points per correct
Final score / total * 100   Percentage
```
