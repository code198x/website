## Sprites Come Alive!

A moving sprite is good—but an **animated** sprite feels alive! By flipping the sprite pointer between two different frames, you create the illusion of movement.

Every C64 game from Impossible Mission to Creatures uses this exact technique: alternate sprite data on every few frames.

## Basic Example

Flip between two frames:

```basic
10 REM *** FRAME FLIP ***
20 REM FRAME 1
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 REM FRAME 2
50 FOR I=896 TO 958:POKE I,0:NEXT I
60 POKE 53269,1:POKE 53287,7
70 F=13
80 POKE 2040,F
90 FOR D=1 TO 200:NEXT D
100 F=F+1:IF F>14 THEN F=13
110 GOTO 80
```

Sprite flips between solid and empty! Frames 13 and 14 alternate.

## Practical Example

Animate while moving:

```basic
10 REM *** MOVE + ANIMATE ***
20 FOR I=832 TO 894:POKE I,255:NEXT I
30 FOR I=896 TO 958:POKE I,170:NEXT I
40 POKE 2040,13:POKE 53269,1
50 POKE 53287,3
60 X=50:F=13:C=0
70 X=X+2:C=C+1
80 IF C>5 THEN F=F+1:C=0
90 IF F>14 THEN F=13
100 IF X>300 THEN X=50
110 POKE 53248,X:POKE 53249,120
120 POKE 2040,F
130 GOTO 70
```

Sprite moves AND animates! Frame changes every 5 pixels.

## WOW Moment: Walking Character

```basic
NEW
10 REM *** WALKING SPRITE ***
20 PRINT CHR$(147)
30 PRINT "USE A/D TO WALK"
40 REM FRAME 1 - LEFT FOOT
50 FOR I=832 TO 894:POKE I,255:NEXT I
60 REM FRAME 2 - RIGHT FOOT
70 FOR I=896 TO 958:POKE I,170:NEXT I
80 POKE 53269,1:POKE 53287,14
90 X=160:Y=120:F=13:C=0
100 GET K$
110 IF K$="A" THEN X=X-2:C=C+1
120 IF K$="D" THEN X=X+2:C=C+1
130 REM ANIMATE WHEN MOVING
140 IF C>3 THEN F=F+1:C=0
150 IF F>14 THEN F=13
160 REM BOUNDARIES
170 IF X<24 THEN X=24
180 IF X>320 THEN X=320
190 POKE 53248,X:POKE 53249,Y
200 POKE 2040,F
210 GOTO 100
```

![Walking animated sprite](/images/lessons/commodore-64/basic/week-4/lesson-26/walking.png)

Watch the legs move! The sprite only animates when you press A or D. Release the key and it stops—just like professional games!

`★ Insight ─────────────────────────────────────`
The counter (C) controls animation speed independently of movement speed. This separation is crucial: fast movement with slow animation looks like sliding on ice, while slow movement with fast animation looks jittery. The ratio C>3 (flip every 4 pixels) creates natural-looking walking.
`─────────────────────────────────────────────────`

## Quick Reference

```basic
REM ANIMATION BASICS
2040       Sprite 0 pointer
Frame 13   First sprite (memory 832)
Frame 14   Second sprite (memory 896)
Frame 15   Third sprite (memory 960)

REM ANIMATION PATTERN
C=C+1                Count frames
IF C>N THEN...       Flip after N frames
F=F+1                Next frame
IF F>14 THEN F=13    Loop back to first

REM TIMING
C>1   Fast animation
C>3   Medium animation
C>10  Slow animation
```

## What You've Learnt

- POKE 2040 switches sprite frames
- Counter controls animation speed
- Separate counters for move/animate
- Only animate when moving
- Two frames create convincing motion

Movement + animation = living character!
