## Three Chances to Survive!

Single-hit deaths are harsh—but **lives systems** give players multiple chances! Track how many attempts remain, respawn after failure, and create the classic "one more try" arcade experience.

From Space Invaders to Pac-Man, the 3-life system became the universal standard for arcade fairness.

## Basic Example

Simple life counter:

```basic
10 REM *** BASIC LIVES ***
20 PRINT CHR$(147)
30 PRINT "LIVES:3"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53269,1:POKE 53287,7
60 X=160:Y=120:L=3
70 GET K$
80 IF K$="W" THEN Y=Y-3
90 IF K$="S" THEN Y=Y+3
100 IF K$="A" THEN X=X-3
110 IF K$="D" THEN X=X+3
120 POKE 53248,X:POKE 53249,Y
130 REM LOSE LIFE AT BOTTOM
140 IF Y>229 THEN L=L-1:Y=120
150 POKE 1030,L+48
160 IF L=0 THEN PRINT CHR$(19);"GAME OVER":END
170 GOTO 70
```

Fall off bottom, lose a life! Three chances to survive.

## Practical Example

Lives with enemy collision:

```basic
10 REM *** COLLISION LIVES ***
20 PRINT CHR$(147)
30 PRINT "LIVES:3"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,170:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53269,3:POKE 53287,7:POKE 53288,2
80 PX=100:PY=120:EX=250:EY=120:L=3
90 GET K$
100 IF K$="W" THEN PY=PY-3
110 IF K$="S" THEN PY=PY+3
120 IF K$="A" THEN PX=PX-3
130 IF K$="D" THEN PX=PX+3
140 IF EX<PX THEN EX=EX+2
150 IF EX>PX THEN EX=EX-2
160 IF EY<PY THEN EY=EY+2
170 IF EY>PY THEN EY=EY-2
180 POKE 53248,PX:POKE 53249,PY
190 POKE 53250,EX:POKE 53251,EY
200 C=PEEK(53279)
210 IF C>0 THEN L=L-1:PX=100:EX=250:FOR D=1 TO 30:NEXT D
220 POKE 1030,L+48
230 IF L=0 THEN PRINT CHR$(19);"GAME OVER":END
240 GOTO 90
```

Touch enemy, respawn with one less life!

## WOW Moment: Complete Arcade Game

```basic
NEW
10 REM *** ARCADE SURVIVOR ***
20 PRINT CHR$(147)
30 PRINT "LIVES:3  SCORE:000"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,170:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53269,3:POKE 53287,7:POKE 53288,2
80 PX=100:PY=120:EX=250:EY=120:L=3:SC=0
90 REM PLACE 10 DOTS
100 FOR I=0 TO 9
110 DX=INT(RND(1)*35)+3
120 DY=INT(RND(1)*20)+4
130 POKE 1024+DY*40+DX,81
140 POKE 55296+DY*40+DX,7
150 NEXT I
160 GET K$
170 IF K$="W" THEN PY=PY-3
180 IF K$="S" THEN PY=PY+3
190 IF K$="A" THEN PX=PX-3
200 IF K$="D" THEN PX=PX+3
210 REM ENEMY AI
220 IF EX<PX THEN EX=EX+2
230 IF EX>PX THEN EX=EX-2
240 IF EY<PY THEN EY=EY+2
250 IF EY>PY THEN EY=EY-2
260 POKE 53248,PX:POKE 53249,PY
270 POKE 53250,EX:POKE 53251,EY
280 REM COLLECT DOTS
290 P=1024+INT(PY/8)*40+INT(PX/8)
300 IF PEEK(P)=81 THEN POKE P,32:SC=SC+10
310 REM COLLISION
320 C=PEEK(53279)
330 IF C>0 THEN L=L-1:PX=100:EX=250:FOR D=1 TO 30:NEXT D
340 REM UPDATE HUD
350 POKE 1030,L+48
360 POKE 1042,(SC/100)+48
370 POKE 1043,(SC/10) AND 15+48
380 POKE 1044,SC AND 15+48
390 REM CHECK STATES
400 IF L=0 THEN PRINT CHR$(19);"GAME OVER! SCORE:";SC:END
410 IF SC=100 THEN PRINT CHR$(19);"YOU WIN! LIVES:";L:END
420 GOTO 160
```

Collect 10 dots whilst avoiding the chaser! Lose lives on collision, respawn and try again! This is a complete arcade game—score to win, lives to lose, HUD to track it all!

## Quick Reference

```basic
REM LIVES SYSTEM
L=3              Start with 3 lives
L=L-1            Lose a life
IF L=0 THEN END  Game over when zero

REM RESPAWN PATTERN
IF C>0 THEN L=L-1:PX=100:EX=250:FOR D=1 TO 30:NEXT D
   └─ Collision  └─ Life  └─ Reset positions └─ Invincibility delay

REM LIVES DISPLAY
POKE 1030,L+48   Display lives in HUD

REM WIN CONDITION
IF SC=100 THEN PRINT "YOU WIN!":END

REM GAME OVER
IF L=0 THEN PRINT "GAME OVER!":END
```

## What You've Learnt

- Lives create multiple chances
- Respawn repositions player and enemies
- Short delay prevents instant re-collision
- Game over when lives reach zero
- Win condition completes the game loop

You've built a complete arcade game with all the classic elements!
