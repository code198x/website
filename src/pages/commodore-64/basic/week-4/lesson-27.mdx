## Keep Score!

Moving, animating sprites are exciting—but games need **scoring** to track progress! Print the score at the top of the screen and update it when the player collects things.

Every arcade game from Pac-Man to Defender uses this pattern: fixed score position, updated after each collect.

## Basic Example

Display a score:

```basic
10 REM *** SCORE DISPLAY ***
20 PRINT CHR$(147)
30 SC=0
40 PRINT "SCORE:";SC
50 FOR I=1 TO 500:NEXT I
60 SC=SC+10
70 PRINT CHR$(19);"SCORE:";SC
80 GOTO 50
```

Score increases every half second! CHR$(19) is HOME, moving cursor to top-left.

## Practical Example

Fixed score position:

```basic
10 REM *** FIXED SCORE ***
20 PRINT CHR$(147)
30 SC=0
40 PRINT "SCORE:";SC
50 GET K$
60 IF K$=" " THEN SC=SC+5
70 POKE 1024,83:REM 'S'
80 POKE 1025,67:REM 'C'
90 POKE 1030,SC/100+48
100 POKE 1031,(SC/10) AND 15+48
110 POKE 1032,SC AND 15+48
120 GOTO 50
```

Press SPACE to score! POKEs to screen memory avoid flicker.

## WOW Moment: Collect the Dots

```basic
NEW
10 REM *** SCORE GAME ***
20 PRINT CHR$(147)
30 PRINT "SCORE:000"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53269,1
60 POKE 53287,14
70 X=160:Y=120:SC=0
80 REM PLACE 5 DOTS
90 FOR I=0 TO 4
100 POKE 1200+I*40,81
110 POKE 55296+I*40,7
120 NEXT I
130 GET K$
140 IF K$="W" THEN Y=Y-3
150 IF K$="S" THEN Y=Y+3
160 IF K$="A" THEN X=X-3
170 IF K$="D" THEN X=X+3
180 POKE 53248,X:POKE 53249,Y
190 REM CHECK FOR DOT
200 P=1024+INT(Y/8)*40+INT(X/8)
210 IF PEEK(P)=81 THEN POKE P,32:SC=SC+10
220 REM UPDATE SCORE
230 POKE 1030,SC/100+48
240 POKE 1031,(SC/10) AND 15+48
250 POKE 1032,SC AND 15+48
260 GOTO 130
```

![Collecting dots with score](/images/lessons/commodore-64/basic/week-4/lesson-27/score.gif)

Collect all 5 dots to reach 50 points! The sprite's position is converted to screen memory, checks for a dot (character 81), removes it, and adds 10 to the score. Pure game mechanics!

## Quick Reference

```basic
REM SCORE DISPLAY
PRINT "SCORE:";SC        Simple display
CHR$(19)                HOME key (move to top-left)

REM DIRECT SCREEN UPDATE
POKE 1030,digit+48      Write digit to screen
+48 converts 0-9 to ASCII codes

REM POSITION TO SCREEN MEMORY
1024 + Y*40 + X         Character position
Y/8 converts pixel to character row
X/8 converts pixel to character column

REM COLLECT DETECTION
P = position calculation
IF PEEK(P)=item THEN... Check for item
POKE P,32               Remove (space character)
```

## What You've Learnt

- Print score at fixed position
- Update score without flicker
- Convert pixel position to screen
- Detect sprite touching item
- Remove collected items

Scores transform movement into goals!
