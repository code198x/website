## You're in Control Now!

You've moved sprites with loops and formulas—but what about **player control**? GET K$ reads the keyboard, letting you move sprites wherever you want!

Every C64 game from Pac-Man to Impossible Mission uses this exact pattern: read key, update position, repeat.

## Basic Example

Move right with cursor key:

```basic
10 REM *** KEY MOVE RIGHT ***
20 FOR I=832 TO 894:POKE I,255:NEXT I
30 POKE 2040,13:POKE 53269,1
40 POKE 53287,7
50 X=100:Y=120
60 GET K$
70 IF K$=CHR$(29) THEN X=X+2
80 POKE 53248,X:POKE 53249,Y
90 GOTO 60
```

Press cursor right and the sprite moves! CHR$(29) is the cursor right key.

## Practical Example

Move left and right:

```basic
10 REM *** LEFT/RIGHT ***
20 FOR I=832 TO 894:POKE I,255:NEXT I
30 POKE 2040,13:POKE 53269,1
40 POKE 53287,14
50 X=160:Y=120
60 GET K$
70 IF K$=CHR$(29) THEN X=X+3
80 IF K$=CHR$(157) THEN X=X-3
90 IF X<24 THEN X=24
100 IF X>320 THEN X=320
110 POKE 53248,X:POKE 53249,Y
120 GOTO 60
```

Cursor left/right control, with boundaries! CHR$(157) is cursor left.

## WOW Moment: WASD Controls

```basic
NEW
10 REM *** WASD CONTROLS ***
20 PRINT CHR$(147)
30 PRINT "USE W/A/S/D TO MOVE"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53287,3
60 POKE 53269,1
70 X=160:Y=120
80 GET K$
90 IF K$="W" THEN Y=Y-3
100 IF K$="S" THEN Y=Y+3
110 IF K$="A" THEN X=X-3
120 IF K$="D" THEN X=X+3
130 REM KEEP ON SCREEN
140 IF X<24 THEN X=24
150 IF X>320 THEN X=320
160 IF Y<50 THEN Y=50
170 IF Y>229 THEN Y=229
180 POKE 53248,X
190 POKE 53249,Y
200 GOTO 80
```

![WASD controlled sprite](/images/lessons/commodore-64/basic/week-4/lesson-25/wasd.png)

Smooth 4-direction control! This is the foundation of every action game. Try moving diagonally by holding W+D or S+A!

## Quick Reference

```basic
REM KEYBOARD INPUT
GET K$               Read key (instant, non-blocking)
IF K$="W" THEN...    Check specific key
K$=""                No key pressed

REM CURSOR KEYS
CHR$(17)   Cursor down
CHR$(145)  Cursor up
CHR$(29)   Cursor right
CHR$(157)  Cursor left

REM WASD PATTERN
W = up, S = down
A = left, D = right

REM BOUNDARIES
IF X<24 THEN X=24       Left edge
IF X>320 THEN X=320     Right edge
IF Y<50 THEN Y=50       Top edge
IF Y<229 THEN Y=229     Bottom edge
```

## What You've Learnt

- GET K$ reads keyboard instantly
- Compare K$ to move sprite
- WASD gives 4-direction control
- Boundary checks keep sprite on screen
- Input loop = responsive gameplay

Player control transforms sprites into games!
