## Race Against Time!

Scores are great—but adding a **timer** creates urgency! The C64's TI variable counts 60ths of a second automatically, perfect for countdown timers.

Every arcade game with time limits—from Missile Command to Pac-Man—uses hardware timers to create pressure.

## Basic Example

Simple countdown:

```basic
10 REM *** COUNTDOWN ***
20 PRINT CHR$(147)
30 TI$="000000"
40 T=600
50 PRINT CHR$(19)
60 PRINT "TIME:";INT((T-TI)/60)
70 IF TI<T THEN GOTO 50
80 PRINT "TIME UP!"
90 END
```

10-second countdown! TI counts in 60ths of a second (jiffies), so divide by 60 for seconds.

## Practical Example

Timer with gameplay:

```basic
10 REM *** TIMED GAME ***
20 PRINT CHR$(147)
30 TI$="000000":T=600
40 SC=0
50 PRINT CHR$(19)
60 PRINT "TIME:";INT((T-TI)/60);" SCORE:";SC
70 GET K$
80 IF K$=" " THEN SC=SC+1
90 IF TI<T THEN GOTO 50
100 PRINT "FINAL SCORE:";SC
110 END
```

Press SPACE to score before time runs out!

## WOW Moment: Beat the Clock

```basic
NEW
10 REM *** BEAT THE CLOCK ***
20 PRINT CHR$(147)
30 PRINT "COLLECT 10 DOTS IN 15 SECONDS!"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53269,1:POKE 53287,7
60 X=160:Y=120:SC=0
70 TI$="000000":T=900
80 REM PLACE 10 DOTS
90 FOR I=0 TO 9
100 POKE 1200+I*40+I*3,81
110 POKE 55296+I*40+I*3,7
120 NEXT I
130 GET K$
140 IF K$="W" THEN Y=Y-3
150 IF K$="S" THEN Y=Y+3
160 IF K$="A" THEN X=X-3
170 IF K$="D" THEN X=X+3
180 POKE 53248,X:POKE 53249,Y
190 REM CHECK DOTS
200 P=1024+INT(Y/8)*40+INT(X/8)
210 IF PEEK(P)=81 THEN POKE P,32:SC=SC+1
220 REM DISPLAY
230 PRINT CHR$(19)
240 PRINT "TIME:";INT((T-TI)/60);" DOTS:";SC
250 IF SC=10 THEN PRINT "YOU WIN!":END
260 IF TI<T THEN GOTO 130
270 PRINT "TIME UP! YOU LOSE!"
280 END
```

## Quick Reference

```basic
REM TIMER BASICS
TI                System timer (jiffies)
TI$="000000"      Reset timer to zero
60 jiffies = 1 second

REM COUNTDOWN PATTERN
T=600             10 seconds (600/60)
IF TI<T THEN...   While time remains
INT((T-TI)/60)    Seconds remaining

REM COMMON TIMES
300 = 5 seconds
600 = 10 seconds
900 = 15 seconds
1800 = 30 seconds
3600 = 1 minute
```

## What You've Learnt

- TI counts automatically in jiffies
- TI$="000000" resets the timer
- Divide by 60 to convert to seconds
- Countdown creates game pressure
- Check time with IF TI<T

Time limits transform simple games into challenges!
