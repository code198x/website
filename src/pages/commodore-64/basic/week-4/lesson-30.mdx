## Lesson 30 – Random Events

Arcade games thrive on unpredictability. This lesson shows how to use `RND` to scatter pickups, spawn hazards, and keep rooms fresh each run.

> [📷 suggested: screenshot with randomly placed collectibles and hazards]

---

### The One-Minute Tour

- `RND(1)` returns a decimal between 0 and &lt;1.  
- Multiply, `INT`, and offset to fit screen coordinates.  
- Keep a safe margin so items don’t spawn inside walls.  
- Use random colours or point values for variety.

---

### Random Pickups

```basic
NEW
10 PRINT CHR$(147)
20 FOR I=0 TO 9
30 X=INT(RND(1)*30)+5
40 Y=INT(RND(1)*18)+4
50 LOC=1024+Y*40+X
60 POKE LOC,81
70 POKE 55296+Y*40+X,INT(RND(1)*16)
80 NEXT I
```

Spawns ten dots in a safe window away from the edges.

---

### Random Hazard or Reward

```basic
90 FOR TURN=1 TO 5
100 X=INT(RND(1)*30)+5
110 Y=INT(RND(1)*18)+4
120 LOC=1024+Y*40+X
130 IF RND(1)<0.7 THEN POKE LOC,120 ELSE POKE LOC,42
140 NEXT TURN
```

70% chance of a hazard (`120`), 30% chance of a bonus (`42`). Adjust the probability as needed.

---

### Experiment Section

- Give each pickup a random score value (`SCORE=SCORE+INT(RND(1)*15)+5`).  
- Randomise enemy starting positions using the same pattern (with arrays).  
- Combine with the HUD: show remaining random pickups by scanning the map for character `81`.  
- Seed the timer bonus: add `RULEBONUS(ROOM)=RULEBONUS(ROOM)+(INT(RND(1)*40))` for extra variety.

---

### Concept Expansion

Randomness fuels replayability. Applied carefully, it keeps rooms lively without breaking the layout. Later, you’ll use the same techniques for procedural map generation.

---

### Game Integration

- Scatter power-ups and traps each time a room loads.  
- Randomise patrol routes by picking direction deltas at spawn.  
- Adjust difficulty on the fly: fewer safe zones as the score climbs.  
- Log random seeds (store the result of `RND(-TI)`) to reproduce interesting runs during testing.

---

### Quick Reference

```basic
INT(RND(1)*W)       : REM 0..W-1
INT(RND(1)*W)+O     : REM O..O+W-1
IF RND(1)<P THEN    : REM probability test
```
