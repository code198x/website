## The Chase is On!

Random enemies are unpredictable—but **chasing enemies** create tension! By comparing enemy position to player position, enemies can follow and hunt the player.

From Pac-Man ghosts to Space Invaders aliens, enemy AI that reacts to the player transforms games into thrilling challenges.

## Basic Example

Simple chase:

```basic
10 REM *** BASIC CHASE ***
20 PRINT CHR$(147)
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 FOR I=896 TO 958:POKE I,170:NEXT I
50 POKE 2040,13:POKE 2041,14
60 POKE 53269,3:POKE 53287,7:POKE 53288,2
70 PX=50:PY=120:EX=250:EY=120
80 IF EX<PX THEN EX=EX+1
90 IF EX>PX THEN EX=EX-1
100 POKE 53248,PX:POKE 53249,PY
110 POKE 53250,EX:POKE 53251,EY
120 FOR D=1 TO 20:NEXT D
130 GOTO 80
```

Enemy moves toward player! Simple but effective AI.

## Practical Example

Chase in both directions:

```basic
10 REM *** 2D CHASE ***
20 PRINT CHR$(147)
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 FOR I=896 TO 958:POKE I,170:NEXT I
50 POKE 2040,13:POKE 2041,14
60 POKE 53269,3:POKE 53287,14:POKE 53288,2
70 PX=100:PY=100:EX=200:EY=150
80 GET K$
90 IF K$="W" THEN PY=PY-2
100 IF K$="S" THEN PY=PY+2
110 IF K$="A" THEN PX=PX-2
120 IF K$="D" THEN PX=PX+2
130 IF EX<PX THEN EX=EX+1
140 IF EX>PX THEN EX=EX-1
150 IF EY<PY THEN EY=EY+1
160 IF EY>PY THEN EY=EY-1
170 POKE 53248,PX:POKE 53249,PY
180 POKE 53250,EX:POKE 53251,EY
190 GOTO 80
```

Run away or face the chaser!

## WOW Moment: Escape the Enemy

```basic
NEW
10 REM *** ESCAPE GAME ***
20 PRINT CHR$(147)
30 PRINT "SURVIVE 20 SECONDS!"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 FOR I=896 TO 958:POKE I,170:NEXT I
60 POKE 2040,13:POKE 2041,14
70 POKE 53269,3:POKE 53287,7:POKE 53288,2
80 PX=100:PY=120:EX=250:EY=120
90 TI$="000000":T=1200
100 GET K$
110 IF K$="W" THEN PY=PY-3
120 IF K$="S" THEN PY=PY+3
130 IF K$="A" THEN PX=PX-3
140 IF K$="D" THEN PX=PX+3
150 REM ENEMY AI
160 IF EX<PX THEN EX=EX+2
170 IF EX>PX THEN EX=EX-2
180 IF EY<PY THEN EY=EY+2
190 IF EY>PY THEN EY=EY-2
200 REM UPDATE
210 POKE 53248,PX:POKE 53249,PY
220 POKE 53250,EX:POKE 53251,EY
230 REM CHECK COLLISION
240 C=PEEK(53279)
250 IF C>0 THEN PRINT CHR$(19);"CAUGHT!":END
260 REM CHECK TIME
270 PRINT CHR$(19);"TIME:";INT((T-TI)/60)
280 IF TI>T THEN PRINT "YOU WIN!":END
290 GOTO 100
```

Survive 20 seconds without getting caught! The enemy relentlessly follows you—nowhere to hide! This is the foundation of every chase game ever made.

## Quick Reference

```basic
REM CHASE AI PATTERN
IF EX<PX THEN EX=EX+speed   Move right
IF EX>PX THEN EX=EX-speed   Move left
IF EY<PY THEN EY=EY+speed   Move down
IF EY>PY THEN EY=EY-speed   Move up

REM SPEED CONTROL
+1  Slow enemy (escapable)
+2  Medium enemy (challenging)
+3  Fast enemy (very hard)

REM COLLISION CHECK
PEEK(53279)  Sprite-sprite collision
>0 means sprites touching
```

## What You've Learnt

- Compare positions to create AI
- Chase in X and Y independently
- Speed controls difficulty
- Sprite collision for catching
- Timer adds win condition

Simple AI transforms static sprites into living opponents!
