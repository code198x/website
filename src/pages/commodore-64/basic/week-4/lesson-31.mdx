## Wrap Around the World!

Hard boundaries stop sprites—but **wrapping** creates infinite playfields! When a sprite exits one edge, it reappears on the opposite side.

Pac-Man, Asteroids, and countless arcade classics use screen wrapping to create seamless, continuous game worlds.

## Basic Example

Horizontal wrap:

```basic
10 REM *** HORIZONTAL WRAP ***
20 PRINT CHR$(147)
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 POKE 2040,13:POKE 53269,1:POKE 53287,7
50 X=24:Y=120
60 X=X+2
70 IF X>344 THEN X=24
80 POKE 53248,X:POKE 53249,Y
90 FOR D=1 TO 10:NEXT D
100 GOTO 60
```

Sprite wraps from right to left! Continuous motion.

## Practical Example

Four-way wrap:

```basic
10 REM *** 4-WAY WRAP ***
20 PRINT CHR$(147)
30 FOR I=832 TO 894:POKE I,255:NEXT I
40 POKE 2040,13:POKE 53269,1:POKE 53287,14
50 X=160:Y=120
60 GET K$
70 IF K$="W" THEN Y=Y-3
80 IF K$="S" THEN Y=Y+3
90 IF K$="A" THEN X=X-3
100 IF K$="D" THEN X=X+3
110 REM WRAP ALL EDGES
120 IF X<24 THEN X=344
130 IF X>344 THEN X=24
140 IF Y<50 THEN Y=250
150 IF Y>250 THEN Y=50
160 POKE 53248,X:POKE 53249,Y
170 GOTO 60
```

Exit any edge, appear on opposite side!

## WOW Moment: Pac-Man Wrap

```basic
NEW
10 REM *** PAC-MAN WRAP ***
20 PRINT CHR$(147)
30 PRINT "COLLECT ALL 20 DOTS!"
40 FOR I=832 TO 894:POKE I,255:NEXT I
50 POKE 2040,13:POKE 53269,1:POKE 53287,7
60 X=160:Y=120:SC=0
70 REM PLACE 20 DOTS
80 FOR I=0 TO 19
90 DX=INT(RND(1)*35)+3
100 DY=INT(RND(1)*20)+4
110 POKE 1024+DY*40+DX,81
120 POKE 55296+DY*40+DX,7
130 NEXT I
140 GET K$
150 IF K$="W" THEN Y=Y-3
160 IF K$="S" THEN Y=Y+3
170 IF K$="A" THEN X=X-3
180 IF K$="D" THEN X=X+3
190 REM WRAP EDGES
200 IF X<24 THEN X=344
210 IF X>344 THEN X=24
220 IF Y<50 THEN Y=250
230 IF Y>250 THEN Y=50
240 POKE 53248,X:POKE 53249,Y
250 REM COLLECT DOTS
260 P=1024+INT(Y/8)*40+INT(X/8)
270 IF PEEK(P)=81 THEN POKE P,32:SC=SC+1
280 REM UPDATE SCORE
290 POKE 1030,SC/10+48
300 POKE 1031,SC AND 15+48
310 IF SC=20 THEN PRINT CHR$(19);"YOU WIN!":END
320 GOTO 140
```

![Pac-Man style wrapping](/images/lessons/commodore-64/basic/week-4/lesson-31/wrap.png)

Exit left, appear right! Exit top, appear bottom! The playfield wraps seamlessly—just like the arcade! This creates the illusion of an infinite world from a small screen.

## Quick Reference

```basic
REM HORIZONTAL WRAP
IF X<24 THEN X=344     Left edge to right
IF X>344 THEN X=24     Right edge to left

REM VERTICAL WRAP
IF Y<50 THEN Y=250     Top edge to bottom
IF Y>250 THEN Y=50     Bottom edge to top

REM EDGE VALUES
24   Left sprite edge
344  Right sprite edge
50   Top sprite edge
250  Bottom sprite edge

REM WHY THESE VALUES?
Sprite width = 24 pixels
Screen coordinates adjusted for sprite size
```

## What You've Learnt

- Wrap creates continuous playfields
- Check all four edges
- Wrap values depend on sprite size
- Seamless transitions feel natural
- Classic arcade technique

Wrapping transforms limited screens into infinite worlds!
