## What You'll Build

Horizontal scrolling introduction. Runner dodges obstacles in an endless scroll.

The world moves. You survive. This is where scrolling begins — the technique that transformed games from single screens to expansive worlds. The VIC-II has hardware scrolling built in, and you'll learn to use it.

## Skills You'll Master

- **Hardware horizontal scrolling** — VIC-II $D016
- **Colour RAM scrolling** — keeping colours in sync
- **Screen buffer management** — double buffering
- **Colour splits** — basic raster techniques
- **Procedural spawning** — obstacle generation
- **Basic parallax** — background depth

## Prerequisites

Complete **Game 6: Invader Wave** first.
