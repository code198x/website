## Shaping Sound Through Time

Last lesson you played notes. Now you'll craft sonic textures. The difference between a piano and a flute playing middle C isn't pitch—it's the envelope, the shape of sound from attack through release. The SID chip's ADSR (Attack, Decay, Sustain, Release) registers transform simple waveforms into explosions, laser beams, and coin collection jingles.

---

### The One-Minute Tour

- ADSR controls the volume envelope: how sound starts, holds, and fades
- Attack (0-15): How quickly sound reaches full volume
- Decay (0-15): How quickly it drops to sustain level
- Sustain (0-15): Held volume level while gate is on
- Release (0-15): How quickly sound fades after gate off
- Noise waveform (128+1=129) creates explosion/wind/percussion sounds
- Fast attack + long release = pickup/beep sounds
- Zero attack + fast decay = explosion/impact sounds

---

### Example Programme

```basic
10 REM SIMPLE EXPLOSION SOUND
20 POKE 54277,0:POKE 54278,240
30 POKE 54296,15
40 POKE 54273,200:POKE 54272,0
50 POKE 54276,129
60 FOR I=1 TO 200:POKE 54273,200-I:NEXT I
70 POKE 54276,128
```

Sample output:

```
[Burst of white noise resembling explosion]

READY.
```

**Line 20** sets envelope: Attack=0 (instant), Decay=15 (long fade), Sustain=0, Release=0 (240 = 15×16 + 0). **Line 30** maximum volume. **Line 40** sets high starting frequency (200). **Line 50** noise waveform + gate on (129 = 128 + 1). **Line 60** pitch sweep downward from 200 to 0 over 200 iterations creates falling explosion rumble. **Line 70** gate off.

> **Tip:** The ADSR registers use 4 bits each, packed two per byte. Register 54277 contains Attack (high nibble) and Decay (low nibble). Register 54278 contains Sustain (high nibble) and Release (low nibble).

### Concept Expansion

**ADSR in analogue synthesis.** ADSR isn't a C64 invention—it's fundamental to analogue synthesisers. When you press a key on a Minimoog or ARP Odyssey, the envelope generator shapes the volume (and often the filter cutoff) through four phases: Attack (how quickly the sound reaches peak), Decay (how quickly it drops to the sustained level), Sustain (the held level while the key is down), and Release (the fadeout after releasing the key). The SID chip implements this professional synthesiser feature with 4-bit resolution per parameter.

**Nibble packing.** Each ADSR value needs 4 bits (0-15 range), so two values pack into one byte. The high nibble (bits 4-7) holds the first value, the low nibble (bits 0-3) holds the second. To manually pack Attack=9, Decay=2: `(9 × 16) + 2 = 146`. To pack Sustain=12, Release=5: `(12 × 16) + 5 = 197`. Or just use decimal: Attack 9 in bits 4-7, Decay 2 in bits 0-3 gives binary 10010010, which is 146.

**Time values.** The ADSR values aren't measured in milliseconds—they're exponential time constants that change how the SID chip's internal envelope generator ramps voltages. Attack 0 is approximately 2ms, Attack 15 is about 8 seconds. Decay/Release times range from 6ms to 24 seconds. The exponential scaling matches how human hearing perceives time, making it musically useful without complicated calculations.

**Game sound design.** Games rarely use sustain—most effects want sounds that start and stop quickly. Explosions: fast attack, medium decay, zero sustain, zero release. Coin pickup: medium attack, short decay, zero sustain, medium release for a "ding" that fades. Laser: instant attack, zero decay/sustain, long release for a zap-fade. Menu beep: medium attack, zero everything else for a clean blip.

### Game Integration

- **Explosion/impact**: Noise waveform, attack=0, decay=12-15, sustain=0, release=0
- **Coin/pickup**: Triangle wave, attack=5-9, decay=0, sustain=0, release=8-12
- **Menu beep**: Pulse wave, attack=5, decay=0, sustain=0, release=0, short duration
- **Laser/shoot**: Sawtooth, attack=0, decay=0, sustain=0, release=10-15, high pitch
- **Power-up**: Triangle, attack=2, decay=5, sustain=8, release=12, rising pitch
- **Alarm/siren**: Pulse wave, attack=0, decay=0, sustain=15, release=0, alternating frequencies

### Quick Reference

**ADSR Registers (Voice 1):**
```
54277 = Attack/Decay     (high nibble = attack, low nibble = decay)
54278 = Sustain/Release  (high nibble = sustain, low nibble = release)
```

**ADSR Value Ranges:**
```
Each parameter: 0-15 (4 bits)

Attack  0 = ~2ms       Attack  15 = ~8 seconds
Decay   0 = ~6ms       Decay   15 = ~24 seconds
Sustain 0 = silent     Sustain 15 = full volume
Release 0 = ~6ms       Release 15 = ~24 seconds
```

**Common ADSR Patterns:**
```
Explosion:    A=0  D=15 S=0  R=0   (POKE 54277,15:POKE 54278,0)
Pickup/Coin:  A=9  D=0  S=0  R=12  (POKE 54277,144:POKE 54278,12)
Laser:        A=0  D=0  S=0  R=15  (POKE 54277,0:POKE 54278,15)
Menu Beep:    A=5  D=0  S=0  R=0   (POKE 54277,80:POKE 54278,0)
Musical Note: A=9  D=9  S=12 R=5   (POKE 54277,153:POKE 54278,197)
```

**Waveform Values (with gate on):**
```
Triangle + gate = 17   (16 + 1)
Sawtooth + gate = 33   (32 + 1)
Pulse + gate    = 65   (64 + 1)
Noise + gate    = 129  (128 + 1)
```

**Packing ADSR Values Manually:**
```
High nibble value: multiply by 16
Low nibble value: add directly

Example: Attack=9, Decay=2
  (9 × 16) + 2 = 146
  POKE 54277,146
```

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `poke` instead of `POKE`) for technical compatibility with the petcat converter tool.

### What You've Learnt

- Attack/Decay pack into register 54277, Sustain/Release into 54278
- Each parameter is 0-15, packed two per byte (high/low nibbles)
- Noise waveform (128) creates explosion and percussion effects
- Different waveforms with same envelope produce different timbres
- Game sounds typically use zero sustain for quick effects
- Fast attack + long release = pickup sounds
- Zero attack + fast decay = explosion sounds
- ADSR comes from analogue synthesiser design, not unique to C64
