In Lesson 10, you played musical notes. But games don't need melodies when enemies explode or coins get collected—they need *sound effects*. Quick, punchy audio feedback that makes actions feel satisfying.

The SID chip's four waveforms aren't just for music. Each one creates a different texture: **sawtooth** for bright zaps, **noise** for explosions, **pulse** for hollow beeps, **triangle** for soft jumps. Combine them with frequency sweeps and you've got a complete game sound library.

## The One-Minute Tour

- Different **waveforms** suit different effect types (laser vs explosion vs coin)
- **Frequency sweeps** create rising/falling pitch effects (jump up, laser down)
- **GOSUB/RETURN** organizes effects into reusable subroutines
- Each effect needs **volume, ADSR, frequency, and waveform** configured
- **Noise waveform** requires frequency registers set (even though pitch is random)
- **Pulse waveform** requires pulse width registers set (54274/54275)

## First Example: Interactive Sound FX Tester

Let's build a sound effects playground where you can trigger different game sounds:

```basic
10 REM SOUND FX DEMO
20 PRINT CHR$(147)
30 PRINT "SOUND FX TESTER"
40 PRINT
50 PRINT "1=LASER 2=EXPLOSION"
60 PRINT "3=JUMP  4=COIN"
70 PRINT
80 GET K$:IF K$="" THEN 80
90 IF K$="1" THEN GOSUB 1000
100 IF K$="2" THEN GOSUB 2000
110 IF K$="3" THEN GOSUB 3000
120 IF K$="4" THEN GOSUB 4000
130 GOTO 80
1000 REM LASER
1010 POKE 54296,15
1015 POKE 54277,0:POKE 54278,240
1020 FOR F=255 TO 50 STEP -5
1030 POKE 54272,F:POKE 54273,20
1040 POKE 54276,33
1050 FOR D=1 TO 10:NEXT D
1060 NEXT F
1070 POKE 54276,32:RETURN
2000 REM EXPLOSION
2010 POKE 54296,15
2015 POKE 54277,0:POKE 54278,240
2017 POKE 54272,255:POKE 54273,255
2020 POKE 54276,129
2025 FOR D=1 TO 200:NEXT D
2030 POKE 54276,128:RETURN
3000 REM JUMP
3010 POKE 54296,15
3015 POKE 54277,0:POKE 54278,240
3020 FOR F=100 TO 200 STEP 5
3030 POKE 54272,F:POKE 54273,10
3040 POKE 54276,17
3050 FOR D=1 TO 5:NEXT D:NEXT F
3060 POKE 54276,16:RETURN
4000 REM COIN
4010 POKE 54296,15
4015 POKE 54277,0:POKE 54278,240
4016 POKE 54274,0:POKE 54275,8
4020 POKE 54272,100:POKE 54273,30
4030 POKE 54276,65
4040 FOR D=1 TO 100:NEXT D
4050 POKE 54276,64:RETURN
```

**Run this** and press keys 1-4 to hear different sound effects. Each GOSUB calls a subroutine that configures the SID chip for a specific effect type.

## Second Example: Laser Sound in a Game Context

Here's how you'd use the laser effect in an actual game loop:

```basic
10 REM LASER SWEEP
20 PRINT CHR$(147)
30 PRINT "LASER SOUND EFFECT"
40 PRINT
50 PRINT "FREQUENCY SWEEP DEMO"
60 PRINT
70 PRINT "PRESS ANY KEY"
80 GET K$:IF K$="" THEN 80
90 GOSUB 1000
100 GOTO 70
1000 REM LASER
1010 POKE 54296,15
1015 POKE 54277,0:POKE 54278,240
1020 FOR F=255 TO 50 STEP -5
1030 POKE 54272,F:POKE 54273,20
1040 POKE 54276,33
1050 FOR D=1 TO 10:NEXT D
1060 NEXT F
1070 POKE 54276,32
1080 RETURN
```

The laser subroutine is identical—it's just called from a simpler game loop. This demonstrates the power of GOSUB/RETURN: write the effect once, use it anywhere.

## How Sound Effect Design Works

### Laser Effect (Lines 1000-1070)

**Line 1015: ADSR Envelope Setup**

`POKE 54277,0:POKE 54278,240` sets Attack=0 (instant), Decay=0, Sustain=15 (full volume), Release=0. This is **critical**—without ADSR configuration, the SID chip won't produce any sound, even with correct frequency and waveform settings.

**Line 1020: Frequency Sweep**

`FOR F=255 TO 50 STEP -5` creates a descending pitch. Each loop iteration changes the frequency slightly lower, creating the classic laser "pew" sound. The `-5` step controls how fast the pitch falls.

**Line 1030: Write Frequency**

`POKE 54272,F:POKE 54273,20` writes the low and high bytes of the frequency. Register 54272 gets the changing value, 54273 stays at 20 to keep the pitch in the right range.

**Line 1040: Sawtooth Waveform**

`POKE 54276,33` enables the sawtooth waveform (32) with gate on (+1 = 33). Sawtooth creates bright, harsh tones perfect for laser sounds.

**Line 1050: Timing Delay**

`FOR D=1 TO 10:NEXT D` creates a small delay so you can hear each frequency step. Without this, the sweep happens so fast it sounds like a click instead of a sweep.

**Line 1070: Gate Off**

`POKE 54276,32` turns the gate bit off (waveform value minus 1). This stops the sound. Forgetting this leaves the SID droning at the last frequency.

### Explosion Effect (Lines 2000-2030)

**Line 2017: Noise Frequency Setup**

`POKE 54272,255:POKE 54273,255` sets the frequency registers to maximum. The noise waveform (129) generates **random frequencies**, but the oscillator still needs frequency registers set to run. Without this line, noise is silent.

**Line 2020: Noise Waveform**

`POKE 54276,129` enables noise (128) with gate on (+1 = 129). Noise produces white noise—perfect for explosions, crashes, and chaotic effects.

**Line 2025: Hold Duration**

`FOR D=1 TO 200:NEXT D` keeps the explosion sound playing for a moment. Longer delay = longer explosion.

### Jump Effect (Lines 3000-3060)

**Line 3020: Rising Sweep**

`FOR F=100 TO 200 STEP 5` creates an *ascending* pitch. Rising pitch = positive feeling (jump up, collect, power-up). Falling pitch = negative feeling (fall, death, damage).

**Line 3040: Triangle Waveform**

`POKE 54276,17` enables triangle (16) with gate on (+1 = 17). Triangle waveform produces soft, mellow tones—less harsh than sawtooth, smoother than pulse.

### Coin Effect (Lines 4000-4050)

**Line 4016: Pulse Width Required**

`POKE 54274,0:POKE 54275,8` sets the pulse width. The pulse waveform needs **three** things to work: ADSR envelope, frequency, AND pulse width. Without pulse width, you get silence even if everything else is correct.

**Line 4020: Fixed Frequency**

`POKE 54272,100:POKE 54273,30` sets a single high note. No sweep—just a clean beep. Simple effects are sometimes the most effective.

**Line 4030: Pulse Waveform**

`POKE 54276,65` enables pulse (64) with gate on (+1 = 65). Pulse creates hollow, metallic tones perfect for UI sounds and coin collect effects.

## Why Sound Effects Matter in Games

Every action in a game should have audio feedback. When you shoot, jump, collect, or take damage, a sound effect makes that action feel *real*. The C64's SID chip lets you create distinctive sounds with just a few POKEs.

**Design Principles:**
- **Rising pitch** = positive actions (jump, collect, level up)
- **Falling pitch** = negative actions (fall, lose, damage)
- **Fast sweep** = quick action (laser, hit, bounce)
- **Slow sweep** = prolonged action (warp, transform, charge)
- **Noise** = chaos (explosion, crash, static)
- **Pure tone** = clean feedback (beep, select, confirm)

Later lessons will integrate these effects into complete games (Lesson 14: Star Catcher), layer multiple voices for richer sounds, and even play effects *while* music is running.

## Experiments to Try

**1. Adjust Laser Speed**

Change line 1050 to `FOR D=1 TO 5:NEXT D` for faster sweep, or `FOR D=1 TO 20:NEXT D` for slower. How does timing affect the feel?

**2. Reverse the Jump**

Try `FOR F=200 TO 100 STEP -5` in line 3020. Now it's a falling sound—perfect for a character landing or dropping.

**3. Shorter Explosion**

Change line 2025 to `FOR D=1 TO 50:NEXT D`. How does duration affect impact?

**4. Different Waveforms**

Try using triangle (17) for the laser instead of sawtooth (33). How does the texture change?

**5. Add Pitch Variation**

In the coin effect, try: `POKE 54272,100+RND(1)*20:POKE 54273,30` for slightly randomized pitch each time.

## Quick Reference

### SID Voice 1 Registers

| Address | Register | Purpose |
|---------|----------|---------|
| 54272 ($D400) | FRELO1 | Frequency low byte |
| 54273 ($D401) | FREHI1 | Frequency high byte |
| 54274 ($D402) | PWLO1 | Pulse width low byte |
| 54275 ($D403) | PWHI1 | Pulse width high byte |
| 54276 ($D404) | VCREG1 | Waveform control |
| 54277 ($D405) | ATDCY1 | Attack/Decay |
| 54278 ($D406) | SUREL1 | Sustain/Release |
| 54296 ($D418) | SIGVOL | Volume (0-15) |

### Waveform Values

| Waveform | Gate Off | Gate On | Use Case |
|----------|----------|---------|----------|
| Sawtooth | 32 | 33 | Lasers, zaps, bright sounds |
| Noise | 128 | 129 | Explosions, crashes, static |
| Pulse | 64 | 65 | Beeps, coins, hollow tones |
| Triangle | 16 | 17 | Jumps, soft pickups, mellow |

## What You've Learnt

- Different **waveforms create different textures** (sawtooth vs noise vs pulse vs triangle)
- **Frequency sweeps** make effects dynamic (rising = positive, falling = negative)
- **GOSUB/RETURN organizes effects** into reusable subroutines
- **Noise and pulse waveforms** have special register requirements
- **ADSR envelope is mandatory**—without it, SID produces no sound
- Sound effects make games feel responsive and satisfying
