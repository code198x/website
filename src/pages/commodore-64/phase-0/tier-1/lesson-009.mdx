## Your Graphics Toolkit

You've been POKEing character codes to screen memory—now you discover the C64's built-in graphics library. Beyond letters and numbers, the character set includes solid blocks, half-blocks, box-drawing characters, and card suits. These aren't decorations; they're the building blocks used by professional games to create borders, status panels, and visual effects before sprites appear.

---

### The One-Minute Tour

- The C64 character set has 256 codes (0-255) in screen code format
- Screen codes differ from PETSCII codes used with PRINT/CHR$()
- Box-drawing characters: corners (85,73,74,75), lines (67,93)
- Block characters: solid (160), halves (161,162,163,164)
- Special symbols: filled circle (81), hearts (83), spades, clubs, diamonds
- Use CHR$() with PRINT for PETSCII codes
- Use direct screen codes with POKE to screen memory

---

### Example Program

```basic
10 PRINT CHR$(147)
20 PRINT CHR$(213);
30 FOR I=1 TO 38
40 PRINT CHR$(195);
50 NEXT I
60 PRINT CHR$(201)
70 END
```

Sample output:

```
╭──────────────────────────────────────╮

READY.
```

![Top border drawn with box-drawing characters](/images/commodore-64/phase-0/tier-1/lesson-009/example-1.png)

**Line 10** clears screen. **Line 20** prints top-left corner. **Lines 30-50** print horizontal line 38 times. **Line 60** prints top-right corner. The semicolons prevent line breaks, keeping everything on one line.

> **Tip:** CHR$(213) converts PETSCII code 213 to a character. The C64's box-drawing characters connect seamlessly when placed side-by-side.

### Experiment Section

Try these variations:

- **Complete box**: Add vertical sides with CHR$(221) and bottom border with CHR$(202), CHR$(195), CHR$(203)
- **Filled blocks**: Use CHR$(160) for solid blocks—great for health bars
- **Half-blocks**: CHR$(161) left half, CHR$(162) right half, CHR$(163) lower half, CHR$(164) upper half
- **Card suits**: CHR$(83) heart, CHR$(88) club—perfect for card games
- **Mix PRINT and POKE**: Use PRINT for layout, POKE for specific positions

Build a complete bordered box:

```basic
10 PRINT CHR$(147)
20 PRINT CHR$(213);
30 FOR I=1 TO 38:PRINT CHR$(195);:NEXT I
40 PRINT CHR$(201);
50 FOR R=1 TO 19
60 PRINT CHR$(221);
70 FOR C=1 TO 38:PRINT " ";:NEXT C
80 PRINT CHR$(221);
90 NEXT R
100 PRINT CHR$(202);
110 FOR I=1 TO 38:PRINT CHR$(195);:NEXT I
120 PRINT CHR$(203);
130 END
```

![Complete box border around screen edges](/images/commodore-64/phase-0/tier-1/lesson-009/example-2.png)

The program draws a complete box using four corner characters and two line characters, filling the entire screen border.

### Concept Expansion

**Character graphics vs sprites.** Every character is an 8×8 pixel pattern stored in ROM. When you print CHR$(213), the VIC-II chip fetches that pattern from the character generator ROM and displays it. Sprites (coming in later lessons) are larger movable hardware objects that can overlay the screen. Character graphics are fixed to the text grid but instantly available.

**PETSCII vs screen codes.** PETSCII code 65 is "A" when you PRINT it. But screen code 1 is "A" when you POKE it to 1024. They're different encoding systems. CHR$() converts PETSCII to the character you see. When POKEing screen memory, you use screen codes directly. See the PETSCII reference for conversion tables.

**Historical use.** Before developers mastered sprites, character graphics powered entire games. *Boulder Dash* used character graphics for the scrolling playfield. *Paradroid* drew its deck layouts with box characters. Even after sprites became standard, character graphics remained essential for borders, HUD panels, and status displays.

### Game Integration

- **Menu borders**: Draw boxes around option lists and score panels
- **Status displays**: Use solid blocks for health bars, experience bars
- **Maze graphics**: Build walls with solid blocks, corridors with spaces
- **Card games**: Use suit symbols (hearts, diamonds, clubs, spades)
- **Title screens**: Combine borders, blocks, and text for impactful titles
- **HUD elements**: Separate play area from score/lives with permanent borders

### Quick Reference

**Box-Drawing Characters (CHR$() codes):**
```
CHR$(213) = ╭  top-left       CHR$(201) = ╮  top-right
CHR$(202) = ╰  bottom-left    CHR$(203) = ╯  bottom-right
CHR$(195) = ─  horizontal     CHR$(221) = │  vertical
```

**Block Characters (CHR$() codes):**
```
CHR$(160) = █  solid block   CHR$(164) = ▀  upper half
CHR$(161) = ▌  left half     CHR$(163) = ▄  lower half
CHR$(162) = ▐  right half    CHR$(102) = ░  checkerboard
```

**Special Symbols (CHR$() codes):**
```
CHR$(81) = ●  filled circle  CHR$(83) = ♥  heart
CHR$(87) = ○  open circle    CHR$(88) = ♣  club
```

**Screen Codes vs PETSCII:**
- PRINT CHR$(65) displays "A" (PETSCII 65)
- POKE 1024,1 displays "A" (screen code 1)
- Different encoding—use correct system for each method
