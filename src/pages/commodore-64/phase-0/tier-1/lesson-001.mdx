# Lesson 1: Hello, Computer

## The One-Minute Tour

- You're about to make the computer obey your commands
- `PRINT` is how you tell the C64 to display text or numbers
- `FOR` loops repeat commands a specific number of times
- `GOTO` sends the programme back to an earlier line
- Together, these create a counter that never stops
- You can stop it anytime with RUN/STOP key

## Your First Programme

Type this in exactly as shown (don't worry about understanding it yet):

```basic
10 REM INFINITE COUNTER
20 FOR I=1 TO 999999
30 PRINT I
40 NEXT I
50 GOTO 20
```

Now type `RUN` and press RETURN.

Numbers should be flooding your screen. That's it. You've done it. You've commanded a computer to count, and it's obeying. Want it to stop? Hold down the RUN/STOP key.

**What's happening here?** Line 20 creates a loop - the C64 will count from 1 to 999,999. Line 30 tells it to display each number. Line 40 says "next number please" and line 50 sends everything back to line 20 to start counting from 1 again. Forever.

## Let's Make It More Interesting

Now try this variation - it counts by tens and gives you a title:

```basic
10 REM COUNTING BY TENS
20 PRINT CHR$(147);"COUNTING BY TENS"
30 PRINT
40 FOR I=10 TO 999999 STEP 10
50 PRINT I
60 NEXT I
70 PRINT "FINISHED!"
80 GOTO 20
```

Type `RUN` and watch.

**What's different?** Line 20 uses `CHR$(147)` - that's the code for "clear the screen" - followed by a title. Line 30 adds a blank line for spacing. Line 40 counts by tens (`STEP 10` instead of the default step of 1). Line 70 prints a message when the loop finishes, though you'll barely see it before line 80 loops everything back.

![Counting by tens with title](/images/commodore-64/phase-0/tier-1/lesson-001/example-2.png)

## Why This Matters

Games need to count things constantly. Enemy positions. Score. Lives remaining. Time left. Ammunition. The techniques you've just learnt - loops, printing values, repeating code - are the foundation of every game you'll build.

**The `FOR` loop** is your workhorse. It's how games update 50 sprites, check 20 collision zones, or process 100 game logic steps per frame.

**The `GOTO`** is your game loop. Every game is fundamentally an infinite loop: check input, update game state, draw screen, repeat forever.

You've just written your first game loop. It doesn't *do* much yet, but structurally, it's the same pattern that powers Pac-Man, Space Invaders, and every other game you've ever played.

## What You Can Change

**Experiment time.** Try modifying the second programme:

1. Change `STEP 10` to `STEP 100` - what happens?
2. Change the title to something else
3. Change `FOR I=10 TO 999999` to `FOR I=10 TO 100` - now what?
4. Remove line 80 entirely - how does this change the programme?

Don't worry about breaking anything. The worst that happens is you type `RUN` and it doesn't work. Just retype the line and try again.

## How Games Use This

**Jet Set Willy** uses `FOR` loops to update all 256 rooms in the mansion, checking which objects are in which locations.

**Boulder Dash** uses loops to check every tile of the cave - is it dirt? A boulder? Empty space? A diamond?

**Impossible Mission** loops through every platform, every robot, every puzzle piece, checking if the player's touched them.

Your counter programme is doing the same thing, just counting instead of checking game objects. The structure is identical.

## From the Vault

The C64's screen can display 25 rows of 40 characters each - that's 1,000 characters total. When you `PRINT` beyond the bottom of the screen, everything scrolls up one line. This is why your counter eventually pushes older numbers off the top.

The `CHR$()` function lets you print special characters by their code number. `CHR$(147)` clears the screen, `CHR$(13)` is RETURN, `CHR$(20)` deletes a character. There are 256 of these codes in total.

## Quick Reference

### Commands You've Learnt

| Command | What It Does | Example |
|---------|--------------|---------|
| `PRINT` | Display text or numbers | `PRINT "HELLO"` |
| `FOR...TO` | Loop from start to end | `FOR I=1 TO 10` |
| `FOR...TO...STEP` | Loop with custom increment | `FOR I=0 TO 100 STEP 5` |
| `NEXT` | End of loop, go to next value | `NEXT I` |
| `GOTO` | Jump to a line number | `GOTO 20` |
| `REM` | Comment (ignored by computer) | `REM THIS IS A NOTE` |
| `CHR$()` | Character by code number | `CHR$(147)` |

### Useful Codes

| Code | Effect |
|------|--------|
| `CHR$(147)` | Clear screen |
| `CHR$(19)` | Home cursor (top-left) |
| `CHR$(13)` | Return / New line |

### Stopping Programmes

| Key | What It Does |
|-----|--------------|
| RUN/STOP | Stop running programme |
| RUN/STOP + RESTORE | Emergency stop (if RUN/STOP doesn't work) |

## What You've Learnt

- How to make the computer execute your commands
- `PRINT` displays text and numbers on screen
- `FOR` loops repeat code a set number of times
- `STEP` controls how much the loop counter increases
- `GOTO` creates infinite loops (your game loop!)
- `CHR$()` lets you control the screen
- How to stop runaway programmes
