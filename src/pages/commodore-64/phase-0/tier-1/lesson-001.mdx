## Hello, Computer

When a Commodore 64 wakes up, it does not hide behind icons. It stares right at you with a blinking cursor and wordless expectation. This first lesson is about answering that stare, hearing the machine talk back, and realising that a few keystrokes already feel like magic.

![Commodore 64 boot screen showing READY prompt](/images/commodore-64/phase-0/tier-1/lesson-001/boot-screen.png)

---

### The One-Minute Tour

- `READY.` means BASIC is waiting for your command.
- `PRINT` tells the computer to show text or numbers on the screen.
- `RUN` starts the program you've typed.
- **RUN/STOP** halts a running program (on real C64 hardware; **Esc** key in VICE emulator).

---

### Example Program

```basic
10 PRINT "HELLO, 198X"
20 END
```

Sample output:

```
HELLO, 198X
READY.
```

![Example output showing HELLO, 198X displayed on the C64 screen](/images/commodore-64/phase-0/tier-1/lesson-001/example-1.png)

**Line 10** asks BASIC to display the words between the quotation marks. The quotes keep the message together, exactly as you wrote it.
**Line 20** uses `END` to stop politely. On a tiny machine, being tidy is a kindness.

> **Tip:** When typing on the C64, you can use upper or lowercase - BASIC converts everything to uppercase automatically. The lessons show uppercase to match what you'll see on screen.

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `print` instead of `PRINT`) for technical compatibility with the petcat converter tool. This is purely a file format requirement - when typing directly on the C64 or in VICE, case doesn't matter.

Try running the program: type the lines exactly, press **RETURN** at the end of each, then type `RUN` and tap **RETURN** again. BASIC will echo the phrase, print `READY.`, and wait patiently for your next idea.

---

### Experiment Section

Play with the conversation:

- Change the message in quotes. The computer will repeat whatever you shout at it.
- Add a second line: `20 PRINT "WELCOME ABOARD"`. BASIC prints in order from the lowest line number upward.
- Remove `END` and see that BASIC still stops—`RUN` ends by itself unless you give it more to do.
- Create a looping chant:

```basic
10 PRINT "SPACE TIME!"
20 GOTO 10
```

Run it, let the screen fill, then press **RUN/STOP** (or **Esc** in VICE) to escape. You just built a loop: the heart of every future game.

> **Note:** On real C64 hardware, RUN/STOP is a dedicated key at the top-left. In VICE and most emulators, use the **Esc** key instead.

### Concept Expansion

That blinking cursor is the C64's way of handing you the controls. Learning `PRINT`, `RUN`, and `RUN/STOP` gives you the first tools to communicate. In the next lessons we'll store values in variables, repeat actions with loops, and make decisions with `IF/THEN`. Each concept stacks onto this moment of simply speaking to the machine.

---

### Game Integration

Every scoreboard, splash screen, dialogue bubble, and victory message begins with `PRINT`. Even when you switch to sprites and sound, you’ll still use `PRINT` to show instructions, track score, or taunt the player. Mastering this simple command keeps your future games readable and welcoming.

### Quick Reference

| Command | Purpose | Notes |
|---------|---------|-------|
| `PRINT "TEXT"` | Display text or numbers | Quotes required for text |
| `RUN` | Execute the program in memory | Press RETURN after typing |
| `LIST` | Show the program you typed | Displays line numbers |
| `RUN/STOP` | Halt running program | Real C64 hardware only |
| `ESC` | Halt running program | VICE emulator |

### What You’ve Learnt

- The READY prompt is an open invitation to type commands.
- `PRINT` lets you converse with the computer instantly.
- `RUN`, `LIST`, and **RUN/STOP** form your basic control panel.
- Loops like `GOTO 10` can fill the screen—and you now know how to stop them.
