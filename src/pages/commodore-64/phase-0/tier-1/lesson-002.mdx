## Counting

Last lesson you spoke to the machine. Now you'll teach it to remember numbers and perform calculations. Variables store values so you can manipulate them, track scores, count lives, or build a calculator that fits in 40 lines.

---

### The One-Minute Tour

- Variables hold numbers or text
- Use `=` to store a value: `A=5`
- Arithmetic operators: `+`, `-`, `*` (multiply), `/` (divide)
- `PRINT` shows the variable's current value

---

### Example Program

```basic
10 A=5
20 B=10
30 C=A+B
40 PRINT "THE ANSWER IS";C
50 END
```

Sample output:

```
THE ANSWER IS 15
READY.
```

![Simple arithmetic showing THE ANSWER IS 15](/images/commodore-64/phase-0/tier-1/lesson-002/example-1.png)

**Line 10** stores 5 in variable A.
**Line 20** stores 10 in variable B.
**Line 30** adds them together and stores the result in C.
**Line 40** displays the answer. The semicolon keeps the number on the same line as the text.

> **Tip:** Variable names can be single letters (`A`, `X`) or longer (`SCORE`, `HP`). The C64 only reads the first two characters, so `SCORE` and `SCRAP` look identical to BASIC!

---

### Experiment Section

Play with arithmetic:

- Try subtraction: `C=B-A` (result: 5)
- Try multiplication: `C=A*B` (result: 50)
- Try division: `C=B/A` (result: 2)
- Chain operations: `D=A+B*2` (multiplication happens first, result: 25)
- Use parentheses to control order: `D=(A+B)*2` (result: 30)

Build a simple calculator:

```basic
10 PRINT "ENTER FIRST NUMBER"
20 INPUT A
30 PRINT "ENTER SECOND NUMBER"
40 INPUT B
50 PRINT "SUM=";A+B
60 PRINT "DIFFERENCE=";A-B
70 PRINT "PRODUCT=";A*B
80 PRINT "QUOTIENT=";B/A
90 END
```

Type different numbers and watch the C64 compute instantly. You just made a pocket calculator in BASIC.

![Calculator program showing all four operations with inputs 5 and 10](/images/commodore-64/phase-0/tier-1/lesson-002/example-2.png)

### Concept Expansion

Variables are the foundation of game state. Health points, score, ammo count, enemy position—all stored in variables. Next lesson we'll repeat actions with `FOR...NEXT` loops, and then we'll combine variables with `IF...THEN` to make decisions based on their values.

---

### Game Integration

- Health tracking: `HP=3`, then `HP=HP-1` when hit
- Score counters: `SC=SC+10` for each collected item
- Position tracking: `X=20` for horizontal position, `Y=10` for vertical
- Ammo management: `AM=AM-1` when firing

### Quick Reference

| Operation | Syntax | Example | Result |
|-----------|--------|---------|--------|
| Assignment | `VAR=value` | `A=5` | Stores 5 in A |
| Addition | `+` | `C=A+B` | Sum |
| Subtraction | `-` | `C=A-B` | Difference |
| Multiplication | `*` | `C=A*B` | Product |
| Division | `/` | `C=A/B` | Quotient |
| Input | `INPUT VAR` | `INPUT A` | Asks user for value |

**Order of operations:** Multiplication and division before addition and subtraction. Use parentheses `()` to override.
