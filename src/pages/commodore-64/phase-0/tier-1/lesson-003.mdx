## Repeating Yourself

You've used GOTO to create infinite loops. Now you'll learn FOR...NEXT loops that repeat a specific number of times, keeping perfect count. This is how games draw multiple sprites, animate sequences, and generate patterns without typing hundreds of lines.

---

### The One-Minute Tour

- `FOR` starts a loop with a counter variable
- `TO` sets the ending value
- `NEXT` returns to the FOR line and increments the counter
- The loop automatically stops when the counter exceeds the TO value

---

### Example Program

```basic
10 FOR I=1 TO 10
20 PRINT "LINE ";I
30 NEXT I
40 END
```

Sample output:

```
LINE 1
LINE 2
LINE 3
LINE 4
LINE 5
LINE 6
LINE 7
LINE 8
LINE 9
LINE 10
READY.
```

![FOR loop counting from 1 to 10](/images/commodore-64/phase-0/tier-1/lesson-003/example-1.png)

**Line 10** starts the loop. I starts at 1 and will count up to 10.
**Line 20** prints the current value of I on each pass through the loop.
**Line 30** increments I and jumps back to line 10. When I reaches 11, the loop stops.

> **Tip:** The loop counter (I in this example) can be any variable name. I, J, and K are traditional choices for loop counters.

### Experiment Section

Try these variations:

- Count down: Use `STEP -1` to decrease the counter
  ```basic
  10 FOR I=10 TO 1 STEP -1
  20 PRINT I
  30 NEXT I
  ```
- Count by twos: `FOR I=0 TO 20 STEP 2`
- Nested loops: Put one loop inside another to create grids
- Use the counter in calculations: `PRINT I*I` (prints squares)

Build a number pyramid:

```basic
10 FOR I=1 TO 10
20 FOR J=1 TO I
30 PRINT "*";
40 NEXT J
50 PRINT
60 NEXT I
70 END
```

Each row prints as many stars as the row number. The inner loop (J) repeats I times, and the outer loop (I) counts rows.

![Nested loops creating a star pyramid](/images/commodore-64/phase-0/tier-1/lesson-003/example-2.png)

### Concept Expansion

FOR...NEXT loops are the engine behind animation and generation. When you need to draw multiple enemies, play a sequence of notes, or fill the screen with colour, loops let you write the pattern once and execute it hundreds of times. Later lessons will combine loops with arrays to manage collections of game objects.

---

### Game Integration

- Drawing sprites: `FOR I=1 TO 5: POKE 2040+I,SPRITE: NEXT I`
- Sound sequences: `FOR F=100 TO 1000 STEP 100: POKE 54296,F: NEXT F`
- Screen fills: `FOR A=1024 TO 2023: POKE A,160: NEXT A` (fills screen with spaces)
- Difficulty ramps: `FOR WAVE=1 TO 10: ENEMIES=WAVE*2: NEXT WAVE`

### Quick Reference

| Command | Syntax | Example | Result |
|---------|--------|---------|--------|
| Start loop | `FOR VAR=start TO end` | `FOR I=1 TO 10` | Loop 10 times |
| Step value | `STEP increment` | `FOR I=10 TO 1 STEP -1` | Count backwards |
| End loop | `NEXT VAR` | `NEXT I` | Increment and repeat |
| Nested loops | Multiple FOR/NEXT pairs | `FOR I=1 TO 5: FOR J=1 TO 3` | Grid patterns |

**Order matters:** Each NEXT must match its FOR in reverse order (last FOR gets first NEXT).

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `for` instead of `FOR`) for technical compatibility with the petcat converter tool.
