## Working with Time

Games need timing—spawning enemies at intervals, countdown timers, animation frame rates. The C64 provides a simple but powerful tool: the TI (time interval) variable, which counts in "jiffies" (1/60th of a second).

## The One-Minute Tour

- **TI** counts jiffies since power-on or reset (60 jiffies = 1 second)
- **TI$** sets the clock with string assignment `TI$="000000"`
- **Spawn timers** use TI comparison to trigger events at intervals
- **Countdown mechanics** subtract TI from a limit to create time pressure
- **Division converts jiffies** to seconds (`TI/60`) or minutes (`TI/3600`)

## Reading the Clock

The TI variable increments 60 times per second, providing a consistent timebase for game logic.

```basic
10 REM reading the jiffy clock
20 PRINT CHR$(147)
30 PRINT "TI CLOCK IN JIFFIES:"
40 PRINT
50 PRINT "TI = ";TI
60 PRINT
70 PRINT "SECONDS = ";INT(TI/60)
80 PRINT "MINUTES = ";INT(TI/3600)
90 PRINT
100 PRINT "PRESS SPACE TO READ AGAIN"
110 GET A$:IF A$<>" " THEN 110
120 GOTO 20
```

![TI clock display showing jiffies, seconds, and minutes](/images/commodore-64/phase-0/tier-1/lesson-015/example-1.png)

**Line 50** reads TI directly—the number of jiffies since clock reset
**Line 70** converts to seconds by dividing by 60
**Line 80** converts to minutes by dividing by 3600 (60 seconds × 60 jiffies)

The INT function truncates to whole numbers. So `INT(419/60)` gives 6 seconds, not 6.983333.

**Resetting the clock:** TI is read-only, but you can reset it via `TI$="000000"`. The string format is HHMMSS (hours, minutes, seconds), so `TI$="000000"` sets it to midnight. Once set, TI resumes counting from that value.

## Spawn Timer

Games spawn objects at intervals—asteroids appearing every 2 seconds, enemies emerging every 5 seconds. This requires comparing the current time against the last spawn time.

```basic
10 REM spawn timer with delay
20 PRINT CHR$(147):POKE 53280,0:POKE 53281,0
30 TI$="000000"
40 LA=0
50 X=INT(RND(1)*40):Y=INT(RND(1)*25)
60 POKE 1024+Y*40+X,42:POKE 55296+Y*40+X,7
70 IF TI-LA<60 THEN 70
80 LA=TI
90 GOTO 50
```

![Random stars spawning at regular intervals on black screen](/images/commodore-64/phase-0/tier-1/lesson-015/example-2.png)

**Line 30** resets clock to zero with `TI$="000000"`
**Line 40** initialises last spawn time (LA=0)
**Line 70** checks if 60 jiffies (1 second) have passed: `IF TI-LA<60 THEN 70`
**Line 80** updates last spawn time to current time

This creates a **busy-wait loop**—the program sits at line 70 until enough time passes. The comparison `TI-LA<60` checks if fewer than 60 jiffies have elapsed. When 60 or more jiffies pass, the condition fails, execution continues to line 80, and a new star spawns.

**Why reset TI?** Without resetting, TI continues from power-on, potentially starting at thousands of jiffies. Resetting to zero makes the timing predictable and prevents immediate overflow issues.

## Countdown Timer Game

Combining TI with collision detection and scoring creates time-limited gameplay—collect as many stars as possible before time runs out.

```basic
10 REM countdown timer game
20 PRINT CHR$(147):POKE 53280,0:POKE 53281,0
30 SC=0:TI$="000000":LI=600
40 PRINT "COLLECT STARS! 10 SECONDS!"
50 PX=20:PY=12:OX=INT(RND(1)*40):OY=INT(RND(1)*25)
60 POKE 1024+PY*40+PX,81:POKE 55296+PY*40+PX,1
70 POKE 1024+OY*40+OX,42:POKE 55296+OY*40+OX,7
80 GET A$
90 IF A$="W" AND PY>0 THEN POKE 1024+PY*40+PX,32:PY=PY-1
100 IF A$="S" AND PY<24 THEN POKE 1024+PY*40+PX,32:PY=PY+1
110 IF A$="A" AND PX>0 THEN POKE 1024+PY*40+PX,32:PX=PX-1
120 IF A$="D" AND PX<39 THEN POKE 1024+PY*40+PX,32:PX=PX+1
130 POKE 1024+PY*40+PX,81:POKE 55296+PY*40+PX,1
140 IF PX=OX AND PY=OY THEN SC=SC+1:OX=INT(RND(1)*40):OY=INT(RND(1)*25)
150 POKE 1024+OY*40+OX,42:POKE 55296+OY*40+OX,7
160 RE=LI-TI
170 POKE 1024,INT(RE/60)+48:POKE 1024+1,SC+48
180 IF RE<=0 THEN PRINT CHR$(147):PRINT "TIME UP! SCORE:";SC:END
190 GOTO 80
```

![Game over screen showing TIME UP! SCORE: 0](/images/commodore-64/phase-0/tier-1/lesson-015/example-3.png)

**Line 30** sets score to zero, resets clock, and sets limit (LI=600 = 10 seconds)
**Line 160** calculates remaining time: `RE=LI-TI`
**Line 170** displays time remaining (seconds) and score as single digits
**Line 180** checks for time expiry: `IF RE<=0`

The display logic converts countdown to screen codes: `INT(RE/60)+48` turns jiffies into seconds, then adds 48 to get the digit character. So 7 seconds remaining becomes `INT(420/60)+48 = 7+48 = 55`, which is screen code for "7".

**Multiple conditions on line 180:** The THEN clause can execute multiple statements separated by colons. `THEN PRINT CHR$(147):PRINT "time up! score:";SC:END` clears screen, prints message, and ends the program—all in one line.

**Game balance:** 600 jiffies = 10 seconds. Adjusting LI changes difficulty—300 jiffies (5 seconds) creates frantic gameplay, 1200 jiffies (20 seconds) allows casual play.

## How Games Use This

**Paradroid** used timers for the circuit-board takeover minigame. You had a limited time to connect nodes—TI tracked the countdown, displaying remaining seconds.

**Boulder Dash** spawned butterflies and fireflies at timed intervals. Each cave had spawn rates defined in data tables, checked against TI-based timers.

**Impossible Mission** featured a 6-hour time limit (real-time, not game-time). TI tracked elapsed jiffies, converting to minutes and hours for the display.

**Uridium** spawned enemy ships in waves. Spawn timers ensured predictable patterns—1 second between ships in a wave, 5 seconds between waves.

## Quick Reference

**TI Clock Operations:**
```
TI              : Read jiffies (1/60 second increments)
TI$="000000"    : Reset clock to zero (HHMMSS format)
INT(TI/60)      : Convert jiffies to seconds
INT(TI/3600)    : Convert jiffies to minutes
```

**Spawn Timer Pattern:**
```
TI$="000000"         : Reset clock
LA=0                 : Last spawn time
[main loop]
IF TI-LA<60 THEN 70  : Wait 60 jiffies (1 second)
LA=TI                : Update last spawn time
[spawn object]
```

**Countdown Timer Pattern:**
```
LI=600               : Limit (10 seconds)
TI$="000000"         : Reset clock
RE=LI-TI             : Calculate remaining time
IF RE<=0 THEN [end]  : Check for time expiry
```

**Jiffy Conversion Table:**
| Jiffies | Time |
|---------|------|
| 1 | 1/60 second (16.67ms) |
| 60 | 1 second |
| 3600 | 1 minute |
| 216000 | 1 hour |
