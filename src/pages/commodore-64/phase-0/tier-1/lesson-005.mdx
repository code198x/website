## Lists of Things

You've stored single values in variables—now it's time to store entire collections. Arrays let you manage lists of related data: high scores, inventory items, enemy positions, or quiz answers. Instead of creating `SC1`, `SC2`, `SC3`, you'll use `SC(1)`, `SC(2)`, `SC(3)`—one variable name, many values.

---

### The One-Minute Tour

- `DIM` declares an array and reserves memory for it
- Arrays hold multiple values under a single variable name
- Access elements with an index number in parentheses
- Arrays are zero-indexed (start at 0, not 1)
- Perfect for tables, lists, and collections of similar data

---

### Example Program

```basic
10 DIM SC(5)
20 SC(0)=1000
30 SC(1)=850
40 SC(2)=600
50 FOR I=0 TO 2
60 PRINT "PLAYER ";I+1;": ";SC(I)
70 NEXT I
80 END
```

Sample output:

```
PLAYER 1: 1000
PLAYER 2: 850
PLAYER 3: 600
READY.
```

![Array demonstration showing three player scores](/images/commodore-64/phase-0/tier-1/lesson-005/example-1.png)

**Line 10** creates an array with 6 slots (0 through 5). **Lines 20-40** store scores. **Lines 50-70** loop through the array and display each entry. The index `I` accesses different array positions automatically.

> **Tip:** `DIM SC(5)` creates slots 0, 1, 2, 3, 4, and 5—that's 6 total positions. C64 BASIC arrays are zero-indexed.

### Experiment Section

Try these variations:

- **Expand the array**: `DIM SC(9)` for 10 players
- **Use a loop to fill**: Replace lines 20-40 with `FOR I=0 TO 2: SC(I)=1000-I*200: NEXT I`
- **Find the highest score**: Add code to check `IF SC(I)>HI THEN HI=SC(I)`
- **String arrays**: `DIM NM$(2)` for player names
- **Two-dimensional data**: While C64 BASIC supports `DIM B(3,3)` for grids, we'll explore that in later lessons

Build a simple inventory system:

```basic
10 DIM IT$(4)
20 IT$(0)="SWORD"
30 IT$(1)="SHIELD"
40 IT$(2)="POTION"
50 IT$(3)="KEY"
60 PRINT "YOUR INVENTORY:"
70 FOR I=0 TO 3
80 PRINT I+1;". ";IT$(I)
90 NEXT I
100 END
```

The program displays a numbered list of items from the array.

### Concept Expansion

Arrays are fundamental to game programming. Use them for enemy coordinates, level data, dialogue lines, sound frequencies, colour palettes, or animation frames. Later lessons will combine arrays with screen memory manipulation for tile-based graphics and sprite systems.

---

### Game Integration

- **High score tables**: Store top 10 scores with `DIM SC(9)` and `DIM NM$(9)`
- **Level layouts**: `DIM LV(99)` for a 10×10 tile map
- **Enemy data**: `DIM EX(4)`, `DIM EY(4)` for five enemy positions
- **Dialogue trees**: `DIM DL$(19)` for 20 lines of conversation
- **Animation frames**: `DIM FR(7)` for character codes forming a sequence

### Quick Reference

| Command | Purpose | Example |
|---------|---------|---------|
| `DIM A(N)` | Create array with N+1 elements (0 to N) | `DIM SC(9)` |
| `A(I)` | Access element at index I | `SC(0)=1000` |
| `DIM A$(N)` | String array | `DIM NM$(5)` |
| `FOR I=0 TO N` | Loop through array | `FOR I=0 TO 9` |

**Arrays are zero-indexed**: `DIM A(5)` creates slots 0, 1, 2, 3, 4, 5 (6 total).

**C64 BASIC V2 reserves 11 elements by default** for undimensioned arrays (0-10), but always use `DIM` for clarity and to create larger arrays.

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `dim` instead of `DIM`) for technical compatibility with the petcat converter tool.
