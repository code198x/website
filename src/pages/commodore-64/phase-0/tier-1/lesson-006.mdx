## Data and Code, Together

You've learnt to store values in variables and arrays—but what if you need dozens of quiz questions, enemy names, or dialogue lines? Typing them into variables is tedious and clutters your code. DATA statements let you embed information right in your program, keeping logic and content separate. READ fetches each value in sequence, and RESTORE lets you start over.

---

### The One-Minute Tour

- `DATA` stores values as comma-separated lists
- `READ` retrieves the next value from DATA statements
- `RESTORE` resets the read pointer to the first DATA line
- DATA can appear anywhere in your program
- Perfect for questions, messages, level layouts, or lookup tables

---

### Example Program

```basic
10 READ A$
20 READ B
30 PRINT A$;" COSTS ";B;" GOLD"
40 DATA SWORD,50
50 DATA POTION,10
60 END
```

Sample output:

```
SWORD COSTS 50 GOLD
READY.
```

![DATA statement reading item and price](/images/commodore-64/phase-0/tier-1/lesson-006/example-1.png)

**Line 10** reads the first string (`"SWORD"`) from the DATA. **Line 20** reads the first number (`50`). **Lines 40-50** contain the DATA values. BASIC reads them sequentially regardless of where they appear in your program.

> **Tip:** DATA values are read in order across all DATA statements. Once READ, a value is consumed—use RESTORE to start over from the beginning.

### Experiment Section

Try these variations:

- **Multiple items**: Add `DATA SHIELD,75` on line 50 and loop through all items
- **Strings with spaces**: Use `DATA "MAGIC SWORD",100` for multi-word strings
- **Reset the pointer**: Add `RESTORE` before line 10 to re-read from the start
- **Mix types**: `DATA PLAYER,100,5,3` (name, HP, attack, defense)
- **Check for end**: Use `ON ERROR GOTO` to detect when DATA runs out (advanced)

Build a simple quiz program:

```basic
10 SC=0
20 FOR Q=1 TO 3
30 READ QU$,AN$
40 PRINT QU$
50 INPUT US$
60 IF US$=AN$ THEN PRINT "CORRECT!": SC=SC+1
70 IF US$<>AN$ THEN PRINT "WRONG. IT'S ";AN$
80 PRINT
90 NEXT Q
100 PRINT "SCORE: ";SC;"/3"
110 DATA "WHAT IS 2+2?","4"
120 DATA "CAPITAL OF FRANCE?","PARIS"
130 DATA "BITS IN A BYTE?","8"
140 END
```

The program reads question-answer pairs from DATA and checks your responses.

### Concept Expansion

DATA statements revolutionise how you structure programs. Store level maps as numbers (`DATA 1,0,0,1` for walls and spaces), dialogue trees as strings, or sprite coordinates as pairs. Combined with arrays and loops, DATA turns static lists into dynamic game content. Later lessons will use DATA for tile maps, colour sequences, and sound frequencies.

---

### Game Integration

- **Dialogue systems**: `DATA "HELLO, TRAVELER","NEED A SWORD?","COME BACK SOON"`
- **Level data**: `DATA 1,1,1,1,0,0,0,1` (walls and floors for a maze)
- **Enemy stats**: `DATA GOBLIN,20,5,ORC,50,12` (name, HP, damage per enemy)
- **Music notes**: `DATA 262,294,330,349` (frequencies for C, D, E, F)
- **Colour palettes**: `DATA 0,1,2,3,4,5,6,7` (VIC-II colour codes)

### Quick Reference

| Statement | Purpose | Example |
|-----------|---------|---------|
| `DATA val1,val2,...` | Store values | `DATA 10,20,30` |
| `READ var` | Get next value | `READ A` |
| `READ var1,var2,...` | Get multiple values | `READ A,B$,C` |
| `RESTORE` | Reset to first DATA | `RESTORE` |
| `RESTORE line` | Reset to specific line | `RESTORE 100` |

**DATA values are read sequentially** across all DATA lines in program order (by line number).

**String DATA with spaces**: Enclose in quotes: `DATA "MAGIC SWORD"`

**Mixed types**: `READ` expects the correct type—string variable for strings, numeric for numbers.

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `data` instead of `DATA`) for technical compatibility with the petcat converter tool.
