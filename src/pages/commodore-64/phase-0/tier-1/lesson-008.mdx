## Beyond PRINT

You've changed border and background colours—now you're going to paint the screen directly. The C64's text display isn't just for typing; it's a grid of 1000 character positions (40 columns × 25 rows) stored in memory. By POKEing character codes to specific addresses, you can draw anywhere on screen instantly, creating patterns, borders, and graphics that PRINT could never achieve.

---

### The One-Minute Tour

- Screen memory starts at address 1024 (top-left corner)
- Each screen position has an address: 1024 to 2023 (1000 positions total)
- POKE a character code (0-255) to display that character
- Colour memory starts at 55296 (same grid layout)
- POKE a colour value (0-15) to change character colour
- Calculate position: `1024 + (row * 40) + column`

---

### Example Program

```basic
10 PRINT CHR$(147)
20 POKE 1024,42
30 POKE 1024+40,42
40 POKE 1024+80,42
50 POKE 1024+120,42
60 POKE 1024+160,42
70 END
```

Sample output:

```
*
*
READY.
*
*

```

![Vertical line of asterisks drawn with POKE](/images/commodore-64/phase-0/tier-1/lesson-008/example-1.png)

**Line 10** clears screen. **Lines 20-60** POKE character 42 (asterisk) to five vertical positions. Each position is 40 bytes apart (one row down). The asterisks appear instantly in a vertical line.

> **Tip:** Character code 42 is an asterisk (*) in C64 screen codes. Screen codes differ from PETSCII/ASCII—use a character chart to find the right codes for different symbols.

### Experiment Section

Try these variations:

- **Horizontal line**: Change line spacing to +1 instead of +40
- **Diagonal line**: Add both row and column: `1024+(I*41)` in a loop
- **Fill screen**: Use a FOR loop from 1024 to 2023
- **Different characters**: Try code 160 (solid block) or 102 (checkerboard)
- **Coloured characters**: `POKE 55296,5` makes top-left green

Build a simple pattern drawer:

```basic
10 PRINT CHR$(147)
20 FOR R=0 TO 24
30 FOR C=0 TO 39
40 SC=1024+(R*40)+C
50 POKE SC,160
60 POKE 55296+(R*40)+C,1+(R AND 7)
70 NEXT C
80 NEXT R
90 END
```

The programme fills the screen with solid blocks, each row in a different colour (cycling through colours 1-8).

### Concept Expansion

**Screen memory is a character grid.** Unlike modern graphics where you draw pixels, the C64 text mode displays 8×8 character blocks. Memory location 1024 is the top-left corner, 1063 is top-right (1024+39), 1064 is second row start, and 2023 is bottom-right. It's a linear array representing a 40×25 grid.

**Colour memory works identically** but starts at 55296. Each position corresponds to the same screen position. POKE 1024,81 displays an asterisk; POKE 55296,2 makes it red. They're separate memory areas but mirror the same layout.

**Why 1024?** The C64's default screen memory starts at $0400 in hexadecimal (1024 decimal). You can actually move screen memory to different addresses (like $C000 for double-buffering), but that's for later lessons. Colour memory is always at 55296 ($D800).

### Game Integration

- **Draw borders**: Create boxes around play areas with character graphics
- **Status displays**: Draw health bars using repeated block characters
- **Tile maps**: Place maze walls, floors, treasure icons by POKEing codes
- **Sprite-free graphics**: Simple games can use character graphics before sprites
- **Instant updates**: No waiting for PRINT—POKE is immediate

### Quick Reference

| Memory Area | Address Range | Purpose |
|-------------|---------------|---------|
| Screen RAM | 1024-2023 | Character codes (what to display) |
| Colour RAM | 55296-56295 | Colour values (what colour) |

**Position Calculation:**
```
Screen address = 1024 + (row * 40) + column
Colour address = 55296 + (row * 40) + column
```

**Common Character Codes (Screen Codes, Uppercase Mode):**
```
32 = Space       42 = *          160 = Solid block
65 = A           81 = ●          102 = Checkerboard
```

**Screen Dimensions:** 40 columns × 25 rows = 1000 positions

> **Note for .bas files:** The downloadable code samples use lowercase keywords (e.g., `poke` instead of `POKE`) for technical compatibility with the petcat converter tool.
