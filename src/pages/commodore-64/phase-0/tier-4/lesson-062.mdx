In Lesson 50, you built a racing game and discovered BASIC's character-based limitation: the road could only move in 8-pixel jumps, creating a jerky freeze-jump pattern. You tried optimization after optimization, but nothing fixed the fundamental problem: **BASIC can only move whole characters, not individual pixels**.

In Lesson 57, you attempted smooth pixel scrolling and discovered why it's impossible: it requires VIC-II register manipulation ($D011 and $D016) with frame-perfect timing that BASIC simply cannot achieve.

This lesson solves that problem. You're going to call a pre-written assembly routine that manipulates the VIC-II hardware directly. With one `SYS` command to activate it, your scrolling will transform from choppy 8-pixel jumps to buttery smooth 1-pixel motion at 60 fps.

**This is what commercial C64 games feel like.** This is what assembly unlocks.

## The One-Minute Tour

**What Smooth Scrolling Requires:**
- **VIC-II register $D016** - horizontal fine scroll (bits 0-2, values 0-7)
- **VIC-II register $D011** - vertical fine scroll (bits 0-2, values 0-7)
- **Raster interrupt timing** - update registers at exact scanlines
- **Character shifting** - move screen memory when fine scroll wraps

**What the Assembly Routine Does:**
- **Runs every frame** - via raster interrupt (60 times per second)
- **Decrements fine scroll** - smooth pixel-by-pixel motion
- **Signals BASIC** - sets flag when character shift needed
- **Zero CPU overhead** - BASIC game logic unaffected

**The Experience:**
- Replace BASIC's 8-pixel jumps with assembly's 1-pixel smoothness
- Keep all BASIC game logic (movement, collision, scoring)
- Watch your racing game transform into a commercial-quality scroller

## Example: Smooth Horizontal Scroller

Here's a complete demonstration showing the difference between BASIC's character-based scrolling and assembly's smooth hardware scrolling:

```basic
100 REM SMOOTH SCROLLER WITH ASSEMBLY
110 REM SOLVES L57 TEARING/JITTER PROBLEM
120 GOSUB 9000:REM LOAD ML SCROLLER
130 GOSUB 9600:REM ACTIVATE SCROLLER
140 REM GAME STATE
150 DIM SC$(1):SC$(0)="SMOOTH AS SILK! NO TEARING OR JITTER! ASSEMBLY TIMING IS PRECISE!     "
160 SO=0:REM SCREEN OFFSET (WHICH COLUMN)
170 POKE 49200,7:REM INIT FINE SCROLL TO 7
180 POKE 49201,1:REM SCROLL DIRECTION (1=LEFT, 0=STOP)
190 REM DRAW INITIAL TEXT
200 FOR I=0 TO 39
210 CH=ASC(MID$(SC$(0),SO+I+1,1))
220 POKE 1024+12*40+I,CH
230 NEXT I
240 REM MAIN LOOP
250 GET K$
260 IF K$="S" THEN POKE 49201,0:REM STOP SCROLL
270 IF K$="G" THEN POKE 49201,1:REM GO SCROLL
280 REM CHECK IF CHARACTER SHIFT NEEDED
290 FS=PEEK(49200):REM READ CURRENT FINE SCROLL
300 IF FS=0 AND PEEK(49202)=1 THEN GOSUB 1000:REM SHIFT HAPPENED
310 FOR I=1 TO 20:NEXT I:REM SLOW DOWN MAIN LOOP
320 GOTO 250
1000 REM SHIFT SCREEN CONTENT
1010 REM CALLED WHEN FINE SCROLL WRAPPED 7->0
1020 POKE 49202,0:REM CLEAR SHIFT FLAG
1030 SO=SO+1:REM ADVANCE OFFSET
1040 IF SO>=LEN(SC$(0))-40 THEN SO=0:REM WRAP CONTENT
1050 REM REDRAW LINE
1060 FOR I=0 TO 39
1070 CH=ASC(MID$(SC$(0),SO+I+1,1))
1080 POKE 1024+12*40+I,CH
1090 NEXT I
1100 RETURN
9000 REM LOAD ML SCROLLER ROUTINE
9010 REM TARGET: $C000 (49152)
9020 REM MEMORY LOCATIONS:
9030 REM $C030 (49200): FINE SCROLL VALUE (0-7)
9040 REM $C031 (49201): SCROLL ACTIVE (1=ON, 0=OFF)
9050 REM $C032 (49202): SHIFT FLAG (1=NEED SHIFT)
9060 AD=49152
9070 FOR I=1 TO 77:REM 77 BYTES
9080 READ BY
9090 POKE AD,BY
9100 AD=AD+1
9110 NEXT I
9120 RETURN
9130 REM === ML SCROLLER ROUTINE ===
9140 REM SETUP: CONFIGURE RASTER INTERRUPT
9150 DATA 120:REM SEI (DISABLE INTERRUPTS)
9160 DATA 169,28:REM LDA #<IRQ_HANDLER ($C01C = 49180)
9170 DATA 141,20,3:REM STA $0314 (IRQ VECTOR LOW)
9180 DATA 169,192:REM LDA #>IRQ_HANDLER
9190 DATA 141,21,3:REM STA $0315 (IRQ VECTOR HIGH)
9200 DATA 169,250:REM LDA #250 (RASTER LINE)
9210 DATA 141,18,208:REM STA $D012 (RASTER TARGET)
9220 DATA 169,27:REM LDA #27
9230 DATA 141,17,208:REM STA $D011 (RASTER BIT 8 CLEAR)
9240 DATA 169,1:REM LDA #1
9250 DATA 141,26,208:REM STA $D01A (ENABLE RASTER IRQ)
9260 DATA 88:REM CLI (ENABLE INTERRUPTS)
9270 DATA 96:REM RTS (RETURN TO BASIC)
9280 REM === IRQ HANDLER (CALLED EVERY FRAME) ===
9290 DATA 173,49,192:REM LDA $C031 (CHECK SCROLL ACTIVE)
9300 DATA 240,45:REM BEQ +45 (SKIP IF 0)
9310 REM DECREMENT FINE SCROLL
9320 DATA 173,48,192:REM LDA $C030 (LOAD FINE SCROLL)
9330 DATA 56:REM SEC (SET CARRY)
9340 DATA 233,1:REM SBC #1 (SUBTRACT 1)
9350 DATA 16,13:REM BPL +13 (BRANCH IF >=0)
9360 REM WRAPPED: 0->7, SET SHIFT FLAG
9370 DATA 169,7:REM LDA #7 (RESET TO 7)
9380 DATA 141,48,192:REM STA $C030 (STORE FINE SCROLL)
9390 DATA 169,1:REM LDA #1
9400 DATA 141,50,192:REM STA $C032 (SET SHIFT FLAG)
9410 DATA 76,68,192:REM JMP $C044 (EXIT)
9420 REM STORE NEW FINE SCROLL
9430 DATA 141,48,192:REM STA $C030 (STORE FINE SCROLL)
9440 REM UPDATE VIC-II $D016
9450 DATA 173,22,208:REM LDA $D016 (LOAD CURRENT)
9460 DATA 41,248:REM AND #248 (CLEAR BITS 0-2)
9470 DATA 13,48,192:REM ORA $C030 (ADD FINE SCROLL)
9480 DATA 141,22,208:REM STA $D016 (UPDATE REGISTER)
9490 REM EXIT IRQ
9500 DATA 173,25,208:REM LDA $D019 (ACK IRQ)
9510 DATA 141,25,208:REM STA $D019
9520 DATA 76,49,234:REM JMP $EA31 (KERNAL IRQ EXIT)
9600 REM ACTIVATE ML SCROLLER
9610 PRINT "ACTIVATING SMOOTH SCROLLER..."
9620 SYS 49152:REM SETUP RASTER INTERRUPT
9630 PRINT "SCROLLER ACTIVE!"
9640 FOR I=1 TO 100:NEXT I
9650 RETURN
```

## Understanding Raster Interrupts

**What's a raster interrupt?**
- The electron beam draws the screen line by line (top to bottom)
- Each horizontal line is called a **raster line** (0-312 on PAL C64)
- A **raster interrupt** triggers code at a specific line number
- **Frame-perfect timing** - happens at exact same point every frame

**Why BASIC can't use them:**
```basic
REM BASIC ATTEMPTS SMOOTH SCROLL
100 POKE 53270,7:REM SET FINE SCROLL TO 7
110 FOR I=1 TO 100:NEXT I:REM DELAY
120 POKE 53270,6:REM DECREMENT TO 6
```
**Problem:**
- Line 100 executes "sometime" during the frame
- Maybe raster line 50, maybe line 200, never consistent
- VIC-II needs update at **exact same raster line** every frame
- Result: Tearing, jitter, inconsistent motion

**How assembly solves this:**
```assembly
; PSEUDOCODE - ACTUAL ASSEMBLY TECHNIQUE
SETUP:
  Set interrupt vector to $C01C (our handler)
  Set raster trigger to line 250
  Enable raster interrupts

IRQ_HANDLER: (runs automatically at raster line 250)
  Decrement fine scroll value
  Update $D016 register
  Return
```

**Result:**
- Code runs at **exactly** raster line 250 every frame
- VIC-II receives consistent timing
- Smooth, tear-free scrolling

## Memory Communication Between BASIC and Assembly

**The hybrid technique uses shared memory:**

**Memory Location $C030 (49200): Fine scroll value (0-7)**
```basic
BASIC READS:  FS=PEEK(49200):REM CHECK CURRENT POSITION
ASSEMBLY WRITES: STA $C030 :REM UPDATE SCROLL VALUE
```

**Memory Location $C031 (49201): Scroll active flag**
```basic
BASIC WRITES: POKE 49201,1:REM START SCROLLING
ASSEMBLY READS: LDA $C031 :REM CHECK IF ENABLED
```

**Memory Location $C032 (49202): Shift needed flag**
```basic
ASSEMBLY WRITES: STA $C032 :REM SIGNAL CHARACTER SHIFT
BASIC READS: IF PEEK(49202)=1 THEN GOSUB 1000
```

**The cooperation:**
1. BASIC starts scroller (POKE 49201,1)
2. Assembly decrements fine scroll every frame
3. When fine scroll wraps 7→0, assembly sets flag (POKE 49202,1)
4. BASIC sees flag, shifts screen content
5. BASIC clears flag (POKE 49202,0)
6. Process repeats

## From the Vault

**VIC-II Register $D016 (53270):**
- **Bits 0-2:** Horizontal fine scroll (0-7 pixels)
- **Bit 3:** 38/40 column select
- **Bit 4:** Multicolour mode
- **Bits 5-7:** Unused

**Horizontal Scrolling Technique:**
```
Initial: $D016 = %00001111 (binary) = 15 (fine scroll = 7)
Frame 1: $D016 = %00001110 (binary) = 14 (fine scroll = 6)
Frame 2: $D016 = %00001101 (binary) = 13 (fine scroll = 5)
...
Frame 7: $D016 = %00001000 (binary) = 8  (fine scroll = 0)
Frame 8: Shift screen memory left, reset to %00001111
```

**Raster Interrupt Setup:**
- **$D012 (53266):** Raster line trigger (0-255, bit 8 in $D011)
- **$D01A (53274):** Interrupt enable register (bit 0 = raster)
- **$D019 (53273):** Interrupt status register (read to acknowledge)
