You've mastered harmony, sequences, background music, and effects. Now synthesize everything into a complete music composition tool—a 3-voice studio that creates professional game soundtracks and exports them as reusable DATA statements.

**This is tool building, not just game building.** Create a utility that generates music for every project you'll ever make. The Music Studio demonstrates how programmers build tools to amplify their capabilities.

## The One-Minute Tour

- **Three simultaneous voices** create melody, harmony, and bass playing together in perfect synchronisation
- **Interactive composition workflow** lets you enter notes, hear playback, and refine until satisfied
- **Data export system** generates BASIC DATA statements you can copy into any game
- **State-based playback** manages three independent timers so all voices advance correctly
- **Reusable component design** means every song becomes a portable music asset
- **Complete music structure** teaches you melody (main tune), harmony (chords), and bass (foundation)

![3-voice music demo playing melody, harmony, and bass](/images/commodore-64/phase-0/tier-2/lesson-027/screenshot-1.png)

The melody plays on voice 1 (sawtooth waveform), harmony on voice 2 (triangle), and bass on voice 3 (triangle at half frequency). Each voice has independent timing tracked by separate position counters (`P1`, `P2`, `P3`) and timers (`T1`, `T2`, `T3`).

### How It Works

**Music data structure:**

- **Lines 50-70:** Three pairs of arrays store notes and durations for each voice
- **Lines 120-170:** Melody array contains a simple scale pattern (12 notes)
- **Lines 190-220:** Harmony array has longer chords that change less frequently (8 notes)
- **Lines 240-260:** Bass array plays whole notes providing foundation (6 notes)

**Playback engine:**

- **Lines 300-310:** Initialise position counters and start timers for all three voices
- **Lines 320-360:** Main loop calls each voice update subroutine every frame
- **Lines 1000-3080:** Each voice checks its timer, plays next note when duration expires

**Voice 3 bass trick:**

Line 3050 divides frequency by 2, making voice 3 play one octave lower than written. This saves you entering lower note values—just use the same note numbers as melody.

### Menu System

**Lines 200-380:** Main menu displays current song status (how many notes in each voice) and offers 8 options:

1. **Edit melody** (lines 1000-1160): Enter notes for voice 1, the main tune
2. **Edit harmony** (lines 1500-1660): Add chord notes for voice 2
3. **Edit bass** (lines 2000-2170): Create foundation notes for voice 3
4. **Play song** (lines 3000-3140): Hear all voices together
5. **Export data** (lines 4000-4290): Generate DATA statements
6. **Load demo** (lines 5000-5160): Pre-fill with example music
7. **Clear all** (lines 6000-6050): Start fresh
8. **Quit** (lines 7000-7030): Exit cleanly

### Composition Workflow

**Step 1: Edit melody**

Press `1` to enter melody notes. The program prompts for note number (0-24 for C4 through C6, or 99 for rest) and duration in jiffies. Enter `-1` to finish. Each note is stored in arrays `M1()` and `D1()`.

**Step 2: Add harmony**

Press `2` to add harmony notes. These typically last longer than melody notes and form chords (thirds or fifths above melody). Sparse harmony (not every melody note needs accompaniment) often sounds better.

**Step 3: Create bass**

Press `3` to add bass notes. Remember these play one octave lower automatically, so use the same note numbers as melody. Whole notes (120 jiffies) on root notes work well for bass.

**Step 4: Preview**

Press `4` to hear everything together. The playback engine (lines 3060-3100) calls all three voice update subroutines every frame, each managing its own position and timer.

**Step 5: Export**

Press `5` to generate DATA statements. The export routine (lines 4000-4290) prints properly formatted DATA lines you can copy directly into game code:

```basic
REM VOICE 1 (MELODY)
1000 DATA 0,30,2,30,4,30,5,60,4,30,2,30,0,60,99,30
1010 DATA -1
```

The `-1` terminator lets your game loader know when to stop reading notes.

## Music Theory Basics

**Melody, harmony, and bass work together:**

**Melody** is the tune you hum—the main musical line that carries the composition. Use shorter notes (15-30 jiffies) with varied pitch to create movement and interest.

**Harmony** adds chords that support the melody. Typically uses notes that are a third (2 semitones) or fifth (5 semitones) above melody notes. Longer durations (60-120 jiffies) let harmony form a bed underneath melody.

**Bass** provides low-frequency foundation. Root notes of chords (often matching melody's starting note) with very long durations (120-240 jiffies) anchor the entire composition.

**Example harmony relationships:**

- Melody plays C (note 0) → Harmony plays E (note 4) or G (note 7)
- Melody plays G (note 7) → Harmony plays B (note 11) or D (note 14)
- Bass typically plays C (note 0) whilst melody and harmony move above

## Using Exported Music in Games

Once you've exported music, integrate it into any game:

```basic
9000 REM MUSIC DATA LOADER
9010 RESTORE 9100:REM MELODY DATA
9020 L1=0
9030 READ NO,DU
9040 IF NO=-1 THEN 9070
9050 L1=L1+1:M1(L1)=NO:D1(L1)=DU
9060 GOTO 9030
9070 REM LOAD HARMONY AND BASS SIMILARLY
9080 RETURN
9100 REM VOICE 1 (MELODY)
9110 DATA 0,30,2,30,4,30,5,60
9120 DATA 4,30,2,30,0,60,99,30
9130 DATA -1
```

Add this loader to Space Defender, Asteroid Field, or any Tier 1 game. The music plays in the background using the playback engine from Lesson 25, whilst gameplay runs normally.

## Quick Reference

**Note Numbers to Pitch:**
```
0=C4   1=C#4  2=D4   3=D#4  4=E4   5=F4
6=F#4  7=G4   8=G#4  9=A4   10=A#4 11=B4
12=C5  13=C#5 14=D5  15=D#5 16=E5  17=F5
18=F#5 19=G5  20=G#5 21=A5  22=A#5 23=B5
24=C6
99=REST (silence)
```

**Duration Guide (120 BPM):**
```
Whole note:    120 jiffies
Half note:     60 jiffies
Quarter note:  30 jiffies
Eighth note:   15 jiffies
```

**Common Chord Intervals:**
```
Major third:   +4 semitones (e.g., C→E)
Perfect fifth: +7 semitones (e.g., C→G)
Octave:        +12 semitones (e.g., C4→C5)
```

**SID Voice Registers:**
```
Voice 1: 54272-54278 ($D400-$D406)
Voice 2: 54279-54285 ($D407-$D40D)
Voice 3: 54286-54292 ($D40E-$D414)

Frequency: +0 (low), +1 (high)
Control:   +4 (waveform + gate)
ADSR:      +5 (attack/decay), +6 (sustain/release)
```

**Waveform Control Values:**
```
17  = Triangle (smooth, pure)
33  = Sawtooth (bright, rich)
65  = Pulse (hollow, variable)
129 = Noise (percussion, effects)
```
