## Shaping Sound Over Time

In Lesson 023, we discovered ADSR registers must be initialized for audible sound. But those registers control far more than on/off—they shape how sound emerges, sustains, and fades. This lesson explores envelope shaping: the technique that transforms simple waveforms into organs, pianos, violins, and bells.

---

### The One-Minute Tour

- ADSR = Attack, Decay, Sustain, Release (four envelope stages)
- Attack/Decay register (54277/54284/54291): 4 bits each
- Sustain/Release register (54278/54285/54292): 4 bits each
- Attack: 2ms-8s (how quickly sound reaches full volume)
- Decay: 6ms-24s (how quickly it drops to sustain level)
- Sustain: 0-15 (volume level held during gate-on)
- Release: 6ms-24s (how quickly it fades after gate-off)
- Different ADSR values = different instrument characteristics
- Each voice has independent ADSR control

### Example Program

```basic
10 REM ADSR INSTRUMENT COMPARISON
20 REM SETUP VOLUME
30 POKE 54296,15
40 REM ORGAN SOUND - INSTANT ATTACK, SUSTAIN
50 POKE 54277,0:POKE 54278,240
60 POKE 54272,57:POKE 54273,17
70 POKE 54276,17
80 FOR T=1 TO 60:NEXT
90 POKE 54276,16
100 FOR T=1 TO 30:NEXT
110 REM PIANO - FAST ATTACK, QUICK DECAY
120 POKE 54277,9:POKE 54278,0
130 POKE 54272,57:POKE 54273,17
140 POKE 54276,17
150 FOR T=1 TO 60:NEXT
160 POKE 54276,16
170 FOR T=1 TO 30:NEXT
180 REM VIOLIN - SLOW ATTACK, LONG RELEASE
190 POKE 54277,35:POKE 54278,244
200 POKE 54272,57:POKE 54273,17
210 POKE 54276,17
220 FOR T=1 TO 60:NEXT
230 POKE 54276,16
240 FOR T=1 TO 60:NEXT
```

**Lines 50-90** demonstrate organ sound with instant attack (value 0) and full sustain (240 = sustain 15, release 0)—sound appears immediately and holds steady. **Lines 120-160** create piano sound with fast attack (9) and zero sustain—sound hits quickly then decays completely. **Lines 190-240** produce violin sound with slower attack (35) and long release (244)—sound swells gradually and fades smoothly.

### Concept Expansion

**ADSR Envelope Stages**

The Sound Interface Device generates volume envelopes in four stages:

```
Volume
  15 |        ___________
     |       /|          \
     |      / |           \
     |     /  |            \______
     |    /   |                   \
   0 |___/    |                    \___
     |    |   |   |                |
     Attack Decay Sustain         Release
         Gate ON -->      <-- Gate OFF
```

**Stage 1: Attack** — Volume rises from 0 to maximum
- Rate: 0-15 (0=2ms, 15=8s)
- Started by: Setting gate bit (control register bit 0 = 1)
- Effect: Fast attack = percussive, slow attack = swell

**Stage 2: Decay** — Volume falls from maximum to sustain level
- Rate: 0-15 (0=6ms, 15=24s)
- Started by: Attack reaching maximum
- Effect: Fast decay = plucked, slow decay = held

**Stage 3: Sustain** — Volume holds at specified level
- Level: 0-15 (0=silent, 15=maximum)
- Duration: Until gate cleared
- Effect: High sustain = organ-like, zero sustain = percussion

**Stage 4: Release** — Volume falls from sustain to zero
- Rate: 0-15 (0=6ms, 15=24s)
- Started by: Clearing gate bit (control register bit 0 = 0)
- Effect: Fast release = abrupt, slow release = fade

**Register Format**

Attack/Decay register (54277, 54284, 54291):
```
Bits 4-7: Attack rate (0-15)
Bits 0-3: Decay rate (0-15)

Value = (Attack × 16) + Decay

Example: Attack=2, Decay=9
POKE 54277, (2*16)+9 = 41
```

Sustain/Release register (54278, 54285, 54292):
```
Bits 4-7: Sustain level (0-15)
Bits 0-3: Release rate (0-15)

Value = (Sustain × 16) + Release

Example: Sustain=12, Release=8
POKE 54278, (12*16)+8 = 200
```

**Voice-Specific ADSR**

Each voice has independent envelope control:

```basic
REM Voice 1: Piano sound
POKE 54277, 9:POKE 54278, 0    REM Attack=0, Decay=9, Sustain=0, Release=0

REM Voice 2: Organ sound
POKE 54284, 0:POKE 54285, 240  REM Attack=0, Decay=0, Sustain=15, Release=0

REM Voice 3: Strings sound
POKE 54291, 53:POKE 54292, 196 REM Attack=3, Decay=5, Sustain=12, Release=4
```

This enables polyphonic music with different instruments playing simultaneously—melody with piano, bass with organ, harmony with strings.

**Practical Applications**

**Music:** Use sustain values to control note length without timing loops. High sustain (12-15) for held notes, low sustain (0-4) for staccato.

**Sound effects:** Zero sustain creates percussion and impacts. Fast attack + fast decay = laser/explosion. Slow attack + slow release = wind/ambiance.

**Memory efficiency:** Changing ADSR values creates instrument variation without storing multiple waveforms or frequency tables.

### How Games Use This

**The Last Ninja** (1987, System 3): Used distinct ADSR envelopes for each instrument in the soundtrack—percussion with zero sustain, melody with medium sustain, bass with high sustain, creating rich polyphonic music from three voices.

**Commando** (1985, Elite): Gunfire sounds used fast attack + zero sustain for immediate impact. Background music used slow attack + high sustain for atmospheric pad sounds. Enemy death sounds used fast attack + slow release for fade-out effect.

**International Karate** (1985, System 3): Impact sounds (punch/kick) used instant attack + fast decay + zero sustain. Title screen music used slow attack + high sustain for dramatic orchestral effect.

**Wizball** (1987, Ocean): Martin Galway's soundtrack used complex ADSR combinations—fast attack for lead sounds, slow attack for background pads, varied sustain levels for rhythmic effects, creating one of the most musically sophisticated C64 soundtracks.

### Quick Reference

**Register Addresses:**
```
Voice 1: 54277 (Attack/Decay), 54278 (Sustain/Release)
Voice 2: 54284 (Attack/Decay), 54285 (Sustain/Release)
Voice 3: 54291 (Attack/Decay), 54292 (Sustain/Release)
```

**Value Calculation:**
```basic
REM Attack/Decay register
AD = (ATTACK * 16) + DECAY
POKE 54277, AD

REM Sustain/Release register
SR = (SUSTAIN * 16) + RELEASE
POKE 54278, SR
```

**Common Presets:**
```basic
REM Organ (instant, sustained)
POKE 54277,0:POKE 54278,240

REM Piano (fast, percussive)
POKE 54277,9:POKE 54278,0

REM Strings (gradual, smooth)
POKE 54277,53:POKE 54278,196

REM Percussion (immediate, short)
POKE 54277,15:POKE 54278,0

REM Pad (slow swell, long fade)
POKE 54277,51:POKE 54278,249
```

### What You've Learnt

- ADSR controls sound evolution: Attack, Decay, Sustain, Release
- Attack/Decay register combines two 4-bit values (formula: A×16 + D)
- Sustain/Release register combines two 4-bit values (formula: S×16 + R)
- Attack determines how quickly sound reaches full volume (2ms-8s)
- Decay determines how quickly it drops to sustain level (6ms-24s)
- Sustain sets held volume level (0-15) during gate-on
- Release determines fade time after gate-off (6ms-24s)
- Each voice has independent ADSR control for varied instruments
- Envelope shaping creates instrument character more than waveform choice
- Same frequency + waveform + different ADSR = different instruments
