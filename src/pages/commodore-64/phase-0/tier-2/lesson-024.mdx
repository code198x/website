## Lesson 24 – Mini-Game: Terminal Tangle

Week 3’s capstone: a multi-room maze where you dodge patrollers, read logs, and choose actions via the menu engine. Terminal Tangle pulls movement, logic, data loading, dialogue, and UI into one cohesive game.

> [🎥 suggested: clip showing the player moving through rooms, reading terminals, and choosing menu options]

---

### The One-Minute Tour

- Title screen menu built with Lesson 22’s reverse-video highlight.  
- Loader from Lessons 20–23 populates maps, rules, dialogue, and music id per room.  
- Gameplay loop merges Lesson 18 movement, Lesson 21 rule-based hazards, and Lesson 22/23 text UI.  
- Game over triggers the dialogue log and returns to the title.

---

### The Game Listing

```basic
NEW
5 REM === TERMINAL TANGLE ===
10 PRINT CHR$(147)
20 SCREEN=1024:COLOR=55296
30 DIM MAP(9,17),EX(3),EY(3),EDX(3)
40 DIM RULEDMG(3),RULEBONUS(3),RULESPEED(3)
50 DIM DIALOG$(4),MUSIC$(3)
60 DIM OPT$(3)
70 DATA "START", "LOAD", "CREDITS", "QUIT"
80 FOR I=0 TO 3:READ OPT$(I):NEXT
90 STATE=1:ROOM=1:LEVEL=1:SCORE=0:LIVES=3
100 ON STATE GOTO 1000,2000,3000
```

#### Title Menu (State 1)

```basic
1000 REM --- TITLE ---
1010 SEL=0
1020 GOSUB 2200
1030 GET K$:IF K$="" THEN 1030
1040 IF K$="S" OR K$=CHR$(17) THEN SEL=SEL+1
1050 IF K$="W" OR K$=CHR$(145) THEN SEL=SEL-1
1060 IF SEL>3 THEN SEL=0
1070 IF SEL<0 THEN SEL=3
1080 IF K$=CHR$(13) THEN ON SEL+1 GOTO 1100,1200,1300,1400
1090 GOTO 1020
1100 SCORE=0:LIVES=3:ROOM=1:STATE=2:GOTO 100

1300 GOSUB 3100:STATE=1:GOTO 100
1400 PRINT CHR$(147);"THANKS FOR PLAYING!":END
```

#### Gameplay (State 2)

```basic
2000 REM --- GAMEPLAY STATE ---
2010 GOSUB 4000            : REM load room data
2020 GOSUB 4100            : REM draw map + HUD
2030 GOSUB 4200            : REM play room music (stub)
2040 STEP=0
2050 GOSUB 4300            : REM main loop
2060 IF LIVES<=0 THEN STATE=3 ELSE STATE=2
2070 ROOM=ROOM+1:IF ROOM>3 THEN ROOM=1
2080 GOTO 100
```

Main loop merges mechanics:

```basic
4300 REM --- GAME LOOP ---
4310 POKE SCREEN+PY*40+PX,64
4320 FOR I=0 TO 3:IF EX(I)+EY(I)=0 THEN NEXT I ELSE POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),81
4330 PRINT CHR$(19)
4340 PRINT "SCORE:";RIGHT$("00000"+STR$(SCORE),5);" LIVES:";LIVES;" ROOM:";ROOM;"     ";
4350 STEP=STEP+1
4360 GOSUB 4400            : REM handle player input
4370 GOSUB 4500            : REM move enemies based on rules
4380 IF LIVES<=0 THEN RETURN
4390 TILE=MAP(PY-5,PX-11)
4400 IF TILE>1 THEN ON TILE-1 GOSUB 4600,4700
4410 GOTO 4310
```

Player movement blends previous lessons:

```basic
4400 REM --- PLAYER INPUT ---
4410 GET K$:IF K$="" THEN RETURN
4420 NX=PX:NY=PY
4430 IF K$="W" OR K$=CHR$(145) THEN NY=PY-1
4440 IF K$="S" OR K$=CHR$(17) THEN NY=PY+1
4450 IF K$="A" OR K$=CHR$(157) THEN NX=PX-1
4460 IF K$="D" OR K$=CHR$(29) THEN NX=PX+1
4470 MX=NX-11:MY=NY-5
4480 IF MX<0 OR MX>17 OR MY<0 OR MY>9 THEN RETURN
4490 IF MAP(MY,MX)=1 THEN RETURN
4500 POKE SCREEN+PY*40+PX,32
4510 PX=NX:PY=NY
4520 POKE SCREEN+PY*40+PX,64
4530 RETURN
```

Enemy logic respects per-room rule speed:

```basic
4500 REM --- ENEMY MOVE ---
4510 FOR I=0 TO 3
4520 IF EX(I)+EY(I)=0 THEN NEXT I
4530 IF STEP MOD RULESPEED(ROOM)<>0 THEN POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),81:GOTO 4590
4540 POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),32
4550 DX=0:DY=0
4560 IF EX(I)<PX-11 THEN DX=1
4570 IF EX(I)>PX-11 THEN DX=-1
4580 IF EY(I)<PY-5 THEN DY=1
4585 IF EY(I)>PY-5 THEN DY=-1
4590 NX=EX(I)+DX:NY=EY(I)+DY
4600 IF MAP(NY,NX)=1 THEN DX=0:DY=0
4610 EX(I)=EX(I)+DX:EY(I)=EY(I)+DY
4620 POKE SCREEN+(EY(I)+5)*40+(EX(I)+11),81
4630 IF EX(I)+11=PX AND EY(I)+5=PY THEN GOSUB 4700
4640 NEXT I
4650 RETURN
```

Hazard/exit handling via rule tables:

```basic
4600 REM --- EXIT TILE ---
4610 SCORE=SCORE+RULEBONUS(ROOM)
4620 GOSUB 5000            : REM show dialogue
4630 RETURN

4700 REM --- HAZARD HIT ---
4710 LIVES=LIVES-RULEDMG(ROOM)
4720 IF LIVES<0 THEN LIVES=0
4730 GOSUB 5000
4740 IF LIVES=0 THEN RETURN
4750 PX=9:PY=9
4760 RETURN
```


#### Game Over (State 3)

```basic
3000 REM --- GAME OVER ---
3010 PRINT CHR$(147)
3020 PRINT "TERMINAL LOCKDOWN"
3030 PRINT "SCORE:";SCORE;" ROOM:";ROOM
3040 PRINT "TRY AGAIN? (Y/N)"
3050 GET K$:IF K$="" THEN 3050
3060 IF K$="Y" THEN SCORE=0:LIVES=3:ROOM=1:STATE=1:GOTO 100
3070 PRINT CHR$(147);"SHUTTING DOWN..."
3080 END
```
