## Lesson 29 – Score & Timer

Time to build a HUD. You’ll keep the score at a fixed screen position, add a countdown clock using `TI`, and update both without flickering.

> [📷 suggested: HUD showing SCORE and TIME updating at top of screen]

---

### HUD Skeleton

```basic
NEW
10 PRINT CHR$(147)
20 SCORE=0
30 TIMER=600        : REM 10 seconds (600 jiffies / 60 = 10s)
40 TI$="000000"
50 PRINT CHR$(19);"SCORE:000  TIME:10"
```

- `CHR$(19)` homes the cursor so the HUD prints at the top-left.  
- Timer initialised to 600 jiffies (10 seconds).

---

### Updating Score (Zero-Padded)

```basic
60 SCORE=SCORE+5
70 PRINT CHR$(19);"SCORE:";RIGHT$("000"+STR$(SCORE),3);
```

`RIGHT$` keeps the score three digits wide. Combine the HUD elements on one line so you don’t overwrite the timer.

---

### Countdown Timer

```basic
80 REM UPDATE TIMER
90 REM seconds remaining = (TIMER - TI) / 60
100 SECS=INT((TIMER-TI)/60)
110 PRINT CHR$(19);"SCORE:";RIGHT$("000"+STR$(SCORE),3);"  TIME:";RIGHT$("00"+STR$(SECS),2)
120 IF SECS<=0 THEN PRINT CHR$(19);"SCORE:";RIGHT$("000"+STR$(SCORE),3);"  TIME:00" : PRINT "TIME UP!":END
```

Every loop, compute remaining seconds, print the HUD, and end when it hits zero.

---

### Experiment Section

- Increase `TIMER` for longer countdowns (`1800` ≈ 30 seconds).  
- Trigger a penalty when time reaches zero (subtract a life and reset timer).  
- Update a secondary line with `PRINT CHR$(148)` (cursor down) to show “COLLECT THE ORBS!” messages.  
- Add a best score: keep `HISCORE` and update if `SCORE>HISCORE` when the timer ends.

---

### Concept Expansion

HUD updates occur every frame in real games. Keeping the print logic in one place avoids flicker and ensures consistent formatting. Later you’ll combine this with sprite collisions for damage and scoring.

---

### Game Integration

- Use the countdown to gate rooms: reaching zero before collecting items triggers hazards.  
- Reward speed: award bonus points equal to remaining seconds when the player finishes a room.  
- Combine with rule tables so some rooms have shorter timers or faster score multipliers.
