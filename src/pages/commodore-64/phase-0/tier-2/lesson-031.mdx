## Lesson 31 – Enemy AI

Time to give your enemies a brain. We’ll build a position-based chaser, leverage the rule tables for speed, and trigger HUD updates when the player gets caught.

> [📷 suggested: screenshot of an enemy sprite chasing the player sprite]

---

### The One-Minute Tour

- Compare enemy `EX/EY` to player `PX/PY` to decide direction.  
- Use `RULESPEED(ROOM)` (from Lesson 21) to pace enemy steps.  
- When collision fires (Lesson 28), reduce lives via the hazard handler.  
- Randomise initial direction to avoid identical openings.

---

### Chaser Loop

```basic
NEW
10 PRINT CHR$(147)
20 FOR I=832 TO 894:POKE I,255:NEXT I
30 FOR I=896 TO 958:POKE I,170:NEXT I
40 POKE 2040,13:POKE 2041,14
50 POKE 53269,3
60 POKE 53287,12:POKE 53288,2
70 PX=140:PY=120:EX=220:EY=140
80 STEP=0:SPEED=2
90 GET K$:IF K$<>"" THEN 110
100 GOTO 150
110 IF K$="A" THEN PX=PX-3
120 IF K$="D" THEN PX=PX+3
130 IF K$="W" THEN PY=PY-3
140 IF K$="S" THEN PY=PY+3
150 IF PX<24 THEN PX=24
160 IF PX>255 THEN PX=255
170 IF PY<50 THEN PY=50
180 IF PY>229 THEN PY=229
190 STEP=STEP+1
200 IF STEP MOD SPEED=0 THEN GOSUB 300
210 POKE 53248,PX:POKE 53249,PY
220 POKE 53250,EX:POKE 53251,EY
230 IF PEEK(53278) THEN PRINT CHR$(19);"CAUGHT!":END
240 GOTO 90

300 REM --- ENEMY CHASE ---
310 IF EX<PX THEN EX=EX+1
320 IF EX>PX THEN EX=EX-1
330 IF EY<PY THEN EY=EY+1
340 IF EY>PY THEN EY=EY-1
350 RETURN
```

- Player moves with WASD; enemy steps toward the player every `SPEED` frames.  
- Simple collision detection uses `PEEK(53278)`; later you’ll call the hazard routine instead of ending abruptly.

---

### Experiment Section

- Vary enemy speed per room: `SPEED=RULESPEED(ROOM)` to reuse earlier work.  
- Randomise starting position using the pattern from Lesson 30 to keep chase routes fresh.  
- Add sidesteps: if the enemy aligns on X, move vertically faster; vice-versa for Y.  
- Play a collision sound (Lesson 28) when `PEEK(53278)` indicates contact.  
- Trigger dialogue (“It caught up!”) by calling the dialogue box routine from Lesson 23.

---

### Concept Expansion

Chasers provide a baseline for more complex AI. You can add patrol states, retreats, or group tactics by layering additional conditions around this core logic.

---

### Game Integration

- Use chase logic for the main antagonist in your mini-game.  
- Combine with random events: occasionally spawn fast “hunter” enemies with higher `SPEED`.  
- Toggle aggression: slow enemies down when the player collects certain items.  
- Log chase duration with the timer to give the player bonus points for surviving longer.

### Quick Reference

```basic
IF EX<PX THEN EX=EX+1    : REM chase right
IF EX>PX THEN EX=EX-1    : REM chase left
IF EY<PY THEN EY=EY+1    : REM chase down
IF EY>PY THEN EY=EY-1    : REM chase up
IF STEP MOD SPEED=0      : REM throttle enemy move rate
```
