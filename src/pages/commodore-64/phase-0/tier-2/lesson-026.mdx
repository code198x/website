You've learnt to create background music. Now build a complete sound effect library—explosions, lasers, pickups, impacts—triggered by game events whilst preserving your music. This is how professional games bring action to life.

**Voice allocation is key.** Reserve voice 1 for music, use voices 2 and 3 for effects, and every game event gets its own signature sound.

## The One-Minute Tour

- **Voice allocation strategy** keeps music playing whilst effects trigger on demand
- **Each effect type uses different techniques** like noise for explosions, descending pitch for lasers
- **Subroutine library design** makes effects reusable across any game project
- **Waveform selection shapes the character** from harsh sawtooth lasers to clean triangle pickups
- **ADSR control determines duration** with fast attack and instant decay for game effects
- **Trigger system connects code to events** like enemy destruction or item collection

## First Example: Basic Sound Effects

Type this to hear three fundamental effects:

```basic
10 REM SIMPLE SOUND EFFECTS
20 PRINT CHR$(147);CHR$(14)
30 POKE 54296,15:REM VOLUME MAX
40 POKE 54284,15:POKE 54285,0:REM VOICE 2 ADSR
50 PRINT "SOUND EFFECT DEMO"
60 PRINT
70 PRINT "1 - EXPLOSION"
80 PRINT "2 - LASER"
90 PRINT "3 - PICKUP"
100 PRINT
110 PRINT "PRESS A NUMBER KEY"
120 GET K$:IF K$="" THEN 120
130 IF K$="1" THEN GOSUB 1000
140 IF K$="2" THEN GOSUB 1100
150 IF K$="3" THEN GOSUB 1200
160 GOTO 120
1000 REM EXPLOSION SOUND
1010 V=54279:REM VOICE 2 BASE
1020 POKE V+4,129:REM NOISE + GATE
1030 FOR I=200 TO 50 STEP -10
1040 POKE V,I:POKE V+1,0
1050 FOR J=1 TO 3:NEXT J
1060 NEXT I
1070 POKE V+4,0:REM STOP
1080 RETURN
1100 REM LASER SOUND
1110 V=54279:REM VOICE 2 BASE
1120 POKE V+4,33:REM SAWTOOTH + GATE
1130 FOR F=100 TO 20 STEP -5
1140 POKE V,F:POKE V+1,F
1150 FOR J=1 TO 2:NEXT J
1160 NEXT F
1170 POKE V+4,0
1180 RETURN
1200 REM PICKUP SOUND
1210 V=54279:REM VOICE 2 BASE
1220 POKE V+4,17:REM TRIANGLE + GATE
1230 FOR F=50 TO 150 STEP 10
1240 POKE V,F:POKE V+1,F
1250 FOR J=1 TO 3:NEXT J
1260 NEXT F
1270 POKE V+4,0
1280 RETURN
```

**Run this** and press keys 1-3 to trigger effects.

![Basic sound effect library with three effects](/images/c64/phase-0/tier-2/lesson-026/example-1.png)

All three effects use voice 2, leaving voice 1 free for background music. The explosion uses the noise waveform with descending pitch. The laser uses sawtooth for a harsh electronic quality. The pickup uses triangle for a clean, positive sound.

### How It Works

Each effect is a self-contained subroutine:

- **Line 1000-1080: Explosion** uses noise waveform (129) with rapidly descending frequency from 200 to 50
- **Line 1100-1180: Laser** uses sawtooth waveform (33) with descending pitch sweep
- **Line 1200-1280: Pickup** uses triangle waveform (17) with rising pitch for positive feedback

The variable `V=54279` points to voice 2's base address. Adding offsets (`V+4` for control register) makes the code readable and maintainable.

## Second Example: Complete Effect Library

Now let's build a full library with six different effect types:

```basic
10 REM COMPLETE SOUND EFFECT LIBRARY
20 PRINT CHR$(147);CHR$(14)
30 POKE 54296,15:REM VOLUME MAX
40 POKE 54284,15:POKE 54285,0:REM VOICE 2 ADSR
50 POKE 54291,15:POKE 54292,0:REM VOICE 3 ADSR
60 PRINT "SOUND EFFECT LIBRARY"
70 PRINT
80 PRINT "1 - EXPLOSION"
90 PRINT "2 - LASER"
100 PRINT "3 - PICKUP"
110 PRINT "4 - IMPACT"
120 PRINT "5 - WARNING BEEP"
130 PRINT "6 - POWER-UP"
140 PRINT
150 PRINT "PRESS A NUMBER KEY"
160 GET K$:IF K$="" THEN 160
170 ON VAL(K$) GOSUB 1000,1100,1200,1300,1400,1500
180 GOTO 160
1000 REM EXPLOSION (NOISE, DESCENDING)
1010 V=54279:REM VOICE 2 BASE
1020 POKE V+4,129:REM NOISE + GATE
1030 FOR I=200 TO 50 STEP -10
1040 POKE V,I:POKE V+1,0:REM DESCENDING FREQUENCY
1050 FOR J=1 TO 3:NEXT J:REM SHORT DELAY
1060 NEXT I
1070 POKE V+4,0:REM STOP
1080 RETURN
1100 REM LASER (DESCENDING PITCH)
1110 V=54279:REM VOICE 2 BASE
1120 POKE V+4,33:REM SAWTOOTH + GATE
1130 FOR F=100 TO 20 STEP -5
1140 POKE V,F:POKE V+1,F
1150 FOR J=1 TO 2:NEXT J
1160 NEXT F
1170 POKE V+4,0
1180 RETURN
1200 REM PICKUP (RISING PITCH)
1210 V=54286:REM VOICE 3 BASE
1220 POKE V+4,17:REM TRIANGLE + GATE
1230 FOR F=50 TO 150 STEP 10
1240 POKE V,F:POKE V+1,F
1250 FOR J=1 TO 3:NEXT J
1260 NEXT F
1270 POKE V+4,0
1280 RETURN
1300 REM IMPACT (LOW THUMP)
1310 V=54286:REM VOICE 3 BASE
1320 POKE V,20:POKE V+1,0:REM LOW FREQUENCY
1330 POKE V+4,17:REM TRIANGLE + GATE
1340 FOR I=1 TO 20:NEXT I:REM BRIEF
1350 POKE V+4,0
1360 RETURN
1400 REM WARNING BEEP (ALTERNATING)
1410 V=54279:REM VOICE 2 BASE
1420 FOR I=1 TO 3:REM 3 BEEPS
1430 POKE V,100:POKE V+1,0
1440 POKE V+4,65:REM PULSE + GATE
1450 FOR J=1 TO 15:NEXT J
1460 POKE V+4,0
1470 FOR J=1 TO 10:NEXT J:REM GAP
1480 NEXT I
1490 RETURN
1500 REM POWER-UP (ARPEGGIO)
1510 V=54286:REM VOICE 3 BASE
1520 POKE V+4,17:REM TRIANGLE + GATE
1530 FOR N=0 TO 12 STEP 4:REM C-E-G CHORD
1540 F=100+N*8:REM RISING NOTES
1550 POKE V,F:POKE V+1,F
1560 FOR J=1 TO 15:NEXT J
1570 NEXT N
1580 POKE V+4,0
1590 RETURN
```

**Run this** and try all six effects.

![Complete sound effect library with six effects](/images/c64/phase-0/tier-2/lesson-026/example-2.png)

This complete library demonstrates voice allocation strategy—effects alternate between voice 2 and voice 3, preserving voice 1 for continuous background music. Each effect has a distinct character designed for specific game events.

### Voice Allocation Strategy

Notice how effects distribute across voices:

- **Voice 2 (54279):** Explosion, laser, warning beep
- **Voice 3 (54286):** Pickup, impact, power-up

This prevents voice conflicts. If two effects trigger simultaneously, they play on different voices. Voice 1 remains untouched for background music from lesson 25.

### Effect Design Techniques

Each effect uses different synthesis techniques:

**Explosion (1000-1080):**
- Noise waveform creates chaotic sound
- Descending frequency adds "falling" quality
- Fast sweep (step -10) creates brief explosion

**Laser (1100-1180):**
- Sawtooth waveform for harsh electronic sound
- Descending pitch sweep from 100 to 20
- Fast delay (J=1 TO 2) creates quick "pew" sound

**Pickup (1200-1280):**
- Triangle waveform for clean tone
- Rising pitch creates positive feeling
- Used when collecting coins, power-ups, items

**Impact (1300-1360):**
- Very low frequency (20) creates bass thump
- Brief duration (I=1 TO 20) for instant feedback
- Perfect for collisions, hits, landings

**Warning Beep (1400-1490):**
- Pulse waveform for classic beep sound
- Repeats three times with gaps
- Urgent feeling from rhythm pattern

**Power-Up (1500-1590):**
- Rising arpeggio suggests triumph
- Three notes create mini-chord progression
- Longer duration for reward feeling

## Integration with Games

To use these effects in Space Defender from lesson 22:

```basic
4100 REM DESTROY ENEMY
4110 GOSUB 1000:REM EXPLOSION SOUND
4120 GOSUB 3500:REM DESPAWN ENEMY
4130 SC=SC+10
4140 RETURN
```

Simply add `GOSUB` calls at game events. The explosion plays when an enemy is destroyed, the laser plays when firing bullets, the pickup plays when collecting items.

**Important:** These effects use blocking FOR loops—they pause execution whilst playing. This is acceptable for brief effects (50-200 milliseconds). For non-blocking effects that don't pause gameplay, see lesson 27.

## Understanding Waveforms

Different waveforms create different characters:

**Triangle (16/17):**
- Clean, pure tone like a flute
- Used for: pickups, power-ups, positive sounds
- Smooth, musical quality

**Sawtooth (32/33):**
- Harsh, buzzy tone like a brass instrument
- Used for: lasers, engines, aggressive sounds
- Rich harmonic content

**Pulse (64/65):**
- Hollow, retro tone like an organ
- Used for: beeps, alarms, classic game sounds
- Adjustable width with pulse width registers

**Noise (128/129):**
- Random, chaotic sound
- Used for: explosions, wind, static, crashes
- Non-pitched texture

The second number includes gate bit (+1). Gate must be on (bit 0 set) for sound to play.

## ADSR for Quick Effects

Game effects need fast response:

```basic
POKE 54284,15:POKE 54285,0  REM VOICE 2
```

This sets:
- **Attack (high nibble of 54284):** 15 = instant (2ms)
- **Decay (low nibble of 54284):** 15 = instant (6ms)
- **Sustain (high nibble of 54285):** 0 = silent
- **Release (low nibble of 54285):** 0 = instant (6ms)

Fast attack means sound starts immediately. Instant decay and zero sustain mean the note stops as soon as you clear the gate bit. This gives you precise control over effect duration through the FOR loop timing.

For longer, sustained sounds like background music, use different ADSR values with slower attack and higher sustain.

## Common Pitfalls

**Using Voice 1 for Effects**
If you use voice 1 for sound effects, you'll interrupt background music. Always use voices 2 and 3 for effects, reserving voice 1 for continuous music.

**Forgetting to Stop the Sound**
Each effect must `POKE V+4,0` to clear the gate bit. Without this, the sound continues indefinitely, creating noise.

**ADSR Not Reset**
If previous code left different ADSR values, your effects might sound wrong. Always set ADSR values in your initialisation code (lines 40-50).

**Effects Too Long**
If effects last more than 200ms, they feel sluggish. Keep explosions under 100ms, lasers under 50ms for responsive game feel.

**No Voice Allocation Plan**
Random voice assignment causes conflicts. Establish a clear strategy: voice 1 = music, voice 2 = primary effects, voice 3 = secondary effects.

## Extension Ideas

- **Add pitch variation** using `RND(1)*50` to make repeated sounds less monotonous
- **Create environment sounds** like wind or rain using slow noise sweeps
- **Implement echo effects** by playing the same sound twice with decreasing volume
- **Build multi-voice effects** using both voices 2 and 3 for richer explosions
- **Add filter effects** using SID's filter registers to shape sound character
- **Create rhythm patterns** for alarms or machinery using timed sequences

## What You've Learnt

- Voice allocation strategy preserves background music whilst playing effects
- Different waveforms create distinct sound characters for different game events
- Subroutine design makes effects reusable across projects
- ADSR settings control attack speed and duration for responsive effects
- FOR loops create pitch sweeps and timed effects
- Strategic POKE sequences to control register and frequency registers

```basic
V=54279:POKE V+4,129

POKE V,I:FOR J=1 TO 3:NEXT J:NEXT I

```

```basic
V=54279:POKE V+4,33

POKE V,F:POKE V+1,F:FOR J=1 TO 2:NEXT J:NEXT F
POKE V+4,0
```

