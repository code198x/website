## Lesson 20 – Memory Games II

Week 2 taught DATA basics; now we scale up. You’ll load several rooms from DATA into arrays, swap between them, and reset the read pointer on demand. Multiple rooms, shared code.

> [📷 suggested: screenshot showing two different rooms loaded from different DATA blocks]

---

### The One-Minute Tour

- Store each room’s map, enemies, and text blocks sequentially in DATA.  
- Use `RESTORE label` to jump to the start of a dataset.  
- Clear arrays before reading new data to avoid leftovers.  
- Wrap loads in `GOSUB` routines so transitions stay tidy.

---

### Room Loader Skeleton

```basic
NEW
10 PRINT CHR$(147)
20 SCREEN=1024:COLOR=55296
30 DIM MAP(9,17),EX(3),EY(3)
40 ROOM=1
50 GOSUB 5000
60 GOSUB 5100
70 GOSUB 5200
80 GOSUB 5300
90 PRINT "PRESS N FOR NEXT ROOM"
100 GET K$:IF K$<>"N" THEN 100
110 ROOM=ROOM+1:IF ROOM>2 THEN ROOM=1
120 GOTO 50

5000 REM --- CLEAR ARRAYS ---
5010 FOR R=0 TO 9:FOR C=0 TO 17:MAP(R,C)=0:NEXT C:NEXT R
5020 FOR I=0 TO 3:EX(I)=0:EY(I)=0:NEXT I
5030 RETURN
```

Start by clearing arrays; otherwise leftovers from the previous room haunt you.

---

### Reading Room Data by Index

```basic
5100 REM --- LOAD ROOM DATA ---
5110 IF ROOM=1 THEN RESTORE 9000
5120 IF ROOM=2 THEN RESTORE 9100
5130 FOR R=0 TO 9
5140 FOR C=0 TO 17
5150 READ MAP(R,C)
5160 NEXT C
5170 NEXT R
5180 FOR I=0 TO 3
5190 READ EX(I),EY(I)
5200 NEXT I
5210 READ TITLE$
5220 RETURN
```

Switch `RESTORE` targets based on `ROOM`. After you’ve read the room tiles, continue reading enemy positions and a title string.

### Drawing + HUD

```basic
5200 REM --- DRAW ROOM ---
5210 PRINT CHR$(147)
5220 PRINT TITLE$
5230 PRINT ""                                       : REM blank spacer
5240 FOR R=0 TO 9
5250 FOR C=0 TO 17
5260 LOC=SCREEN+(R+4)*40+(C+11)
5270 VAL=MAP(R,C)
5280 CHAR=32:COL=1
5290 IF VAL=1 THEN CHAR=160:COL=0
5300 IF VAL=2 THEN CHAR=4:COL=7
5310 IF VAL=3 THEN CHAR=81:COL=2
5320 POKE LOC,CHAR
5330 POKE COLOR+(R+4)*40+(C+11),COL
5340 NEXT C
5350 NEXT R
5360 RETURN

5300 REM --- DRAW ENEMIES ---
5310 FOR I=0 TO 3
5320 IF EX(I)=0 AND EY(I)=0 THEN NEXT I:GOTO 5340
5330 POKE SCREEN+(EY(I)+4)*40+(EX(I)+11),81
5340 NEXT I
5350 RETURN
```

Now the screen updates directly from the array data you just loaded.

### Experiment Section

- Add additional rooms: clone the DATA block, update offsets, and increase the loop bound.  
- Store multiple strings per room (title, description) by reading them into an array after the enemy loop.  
- Swap palettes: include colour values in the DATA stream and apply them while drawing.  
- Save partial progress: keep the last `ROOM` visited so you can resume when loading the game again.  
- Move DATA to a helper file once you graduate to the development environment—useful for bigger adventures.

---

### Concept Expansion

Structured DATA blocks are the precursor to level files. Once comfortable, you can export them to disk, compress them, or load them from assembly routines for speed.
