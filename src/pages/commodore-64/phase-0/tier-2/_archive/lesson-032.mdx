## Lesson 32 – Mini-Game: Circuit Run

Week 4 ends with Circuit Run—lightning-fast chase action that wraps Weeks 1–4 together. Tilt through a maze, dodge patrollers, race the timer, and bank points with lives to spare.

> [🎥 suggested: clip showing player dodging enemies and collecting random pickups while score/timer HUD updates]

---

### The One-Minute Tour

- State machine (title/play/game over) routes flow with `ON STATE GOTO`.  
- Room loader (Lesson 20–23) sets map, rules, dialogue, and music cues.  
- Movement (Lesson 17–18) controls the player; enemy AI (Lesson 31) gives chase.  
- HUD (Lesson 29) tracks score, lives, and countdown; randomness (Lesson 30) keeps rooms fresh.  
- Collisions (Lesson 28) trigger life loss, sound, and dialogue warnings.

### The Game Listing

```basic
NEW
5 REM === CIRCUIT RUN ===
10 PRINT CHR$(147)
20 SCREEN=1024:COLOR=55296
30 DIM MAP(9,17),EX(2),EY(2),EDX(2)
40 DIM RULEDMG(3),RULEBONUS(3),RULESPEED(3)
50 DIM DIALOG$(4),MUSIC$(3)
60 DIM OPT$(2)
70 DATA "START RUN","INSTRUCTIONS","QUIT"
80 FOR I=0 TO 2:READ OPT$(I):NEXT
90 STATE=1:ROOM=1:SCORE=0:LIVES=3
100 ON STATE GOTO 1000,2000,3000
```

#### Title Screen

```basic
1000 REM --- TITLE ---
1010 SEL=0
1020 GOSUB 4000
1030 GET K$:IF K$="" THEN 1030
1040 IF K$="S" OR K$=CHR$(17) THEN SEL=(SEL+1) MOD 3
1050 IF K$="W" OR K$=CHR$(145) THEN SEL=(SEL-1) MOD 3
1060 IF SEL<0 THEN SEL=2
1070 IF K$=CHR$(13) THEN ON SEL+1 GOTO 1100,1200,1300
1080 GOTO 1020
1100 SCORE=0:LIVES=3:ROOM=1:STATE=2:GOTO 100
1200 GOSUB 4100:STATE=1:GOTO 100
1300 PRINT CHR$(147);"SEE YOU NEXT RUN!":END

4000 REM --- DRAW TITLE MENU ---
4010 PRINT CHR$(147)
4020 PRINT "CIRCUIT RUN"
4030 PRINT "-----------"
4040 FOR I=0 TO 2
4050 IF I=SEL THEN PRINT CHR$(18);"  ";OPT$(I);CHR$(146) ELSE PRINT "  ";OPT$(I)
4060 NEXT I
4070 RETURN

4100 REM --- INSTRUCTIONS ---
4110 PRINT CHR$(147)
4120 PRINT "WASD TO MOVE, AVOID PATROLLERS"
4130 PRINT "COLLECT NODES BEFORE TIMER ENDS"
4140 PRINT "PRESS ANY KEY"
4150 GET K$:IF K$="" THEN 4150
4160 RETURN
```

#### Gameplay State

```basic
2000 REM --- GAMEPLAY ---
2010 GOSUB 5000             : REM load room data + rules + dialogue
2020 GOSUB 5200             : REM spawn player/enemies & random pickups
2030 GOSUB 5300             : REM draw HUD
2040 FRAME=0:STATELOOP=0
2050 TI$="000000" : TIMER=900
2060 REM MAIN GAME LOOP
2070 FRAME=FRAME+1
2080 GOSUB 5400             : REM player input + wrap
2090 GOSUB 5500             : REM enemy AI + collisions
2100 GOSUB 5300             : REM update HUD
2110 IF LIVES<=0 THEN STATE=3:GOTO 100
2120 IF SCORE>=RULEBONUS(ROOM) THEN ROOM=ROOM+1:IF ROOM>3 THEN ROOM=1
2130 IF SCORE>=RULEBONUS(ROOM) THEN STATE=2:GOTO 100
2140 IF TI>TIMER THEN STATE=3:GOTO 100
2150 GOTO 2060
```

#### Loading Data (reuse from previous lessons)

- `5000` reads map, enemies, rules, dialogue, and music ID from new Week 4 DATA blocks (include random node counts).  
- `5200` positions the player, enemy, and randomly spawns pickups (`REM` references Lesson 30).  
- `5300` prints `SCORE`, `LIVES`, and `TIME` via zero-padded strings (Lesson 29).

#### Player Movement with Wrapping

```basic
5400 REM --- PLAYER INPUT ---
5410 GET K$:IF K$="" THEN RETURN
5420 NX=PX:NY=PY
5430 IF K$="W" THEN NY=NY-3
5440 IF K$="S" THEN NY=NY+3
5450 IF K$="A" THEN NX=NX-3
5460 IF K$="D" THEN NX=NX+3
5470 IF NX<24 THEN NX=344
5480 IF NX>344 THEN NX=24
5490 IF NY<50 THEN NY=250
5500 IF NY>250 THEN NY=50
5510 PX=NX:PY=NY
5520 POKE 53248,PX:POKE 53249,PY
5530 REM check pickup
5540 MAPIDX=1024+INT((PY-50)/8)*40+INT((PX-24)/8)
5550 IF PEEK(MAPIDX)=81 THEN POKE MAPIDX,32:SCORE=SCORE+10
5560 RETURN
```

#### Enemy AI (reuse Lesson 31)

```basic
5500 REM --- ENEMY AI ---
5510 FOR I=0 TO 2
5520 POKE SCREEN+(EY(I)+4)*40+(EX(I)+11),32
5530 IF FRAME MOD RULESPEED(ROOM)<>0 THEN POKE SCREEN+(EY(I)+4)*40+(EX(I)+11),81:GOTO 5580
5540 IF EX(I)<PX-11 THEN EX(I)=EX(I)+1
5550 IF EX(I)>PX-11 THEN EX(I)=EX(I)-1
5560 IF EY(I)<PY-5 THEN EY(I)=EY(I)+1
5570 IF EY(I)>PY-5 THEN EY(I)=EY(I)-1
5580 POKE SCREEN+(EY(I)+4)*40+(EX(I)+11),81
5590 IF EX(I)+11=PX AND EY(I)+5=PY THEN GOSUB 5600
5600 NEXT I
5610 RETURN
```

#### Collision Handler

```basic
5600 REM --- HIT HANDLER ---
5610 LIVES=LIVES-RULEDMG(ROOM)
5620 IF LIVES<0 THEN LIVES=0
5630 PRINT CHR$(19);"SCORE:";RIGHT$("000"+STR$(SCORE),3);" LIVES:";LIVES;" TIME:";RIGHT$("00"+STR$(INT((TIMER-TI)/60)),2)
5640 FOR D=1 TO 200:NEXT D
5650 PX=153:PY=137
5660 RETURN
```

#### HUD Update

```basic
5300 REM --- HUD ---
5310 SECS=INT((TIMER-TI)/60)
5320 IF SECS<0 THEN SECS=0
5330 PRINT CHR$(19);"SCORE:";RIGHT$("000"+STR$(SCORE),3);" LIVES:";LIVES;" TIME:";RIGHT$("00"+STR$(SECS),2)
5340 RETURN
```

#### Game Over State

```basic
3000 REM --- GAME OVER ---
3010 PRINT CHR$(147)
3020 PRINT "RUN TERMINATED"
3030 PRINT "SCORE:";SCORE
3040 PRINT "PRESS Y TO RESTART"
3050 GET K$:IF K$="" THEN 3050
3060 IF K$="Y" THEN SCORE=0:LIVES=3:ROOM=1:STATE=1:GOTO 100
3070 PRINT "SHUTTING DOWN..."
3080 END
```
