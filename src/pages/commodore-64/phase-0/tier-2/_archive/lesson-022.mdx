## Lesson 22 – Text Tricks III

Interfaces now need flair: highlightable menus, dialogue boxes, and context-sensitive prompts. We’ll build a reusable menu engine and a dialogue scroller using the padding and input tricks from Lessons 19–21.

> [📷 suggested: screenshot of a highlighted menu option and a scrolling dialogue panel]

---

### The One-Minute Tour

- Menus store their options in arrays; a cursor index determines which option is highlighted.  
- Highlight with inverse block characters (`18`/`146`) or colour RAM toggles.  
- Dialogue boxes print lines into a fixed region using a rolling buffer similar to the command log.

---

### Menu Engine Skeleton

```basic
NEW
10 PRINT CHR$(147)
20 DIM OPT$(3)
30 DATA "START GAME","LOAD GAME","OPTIONS","QUIT"
40 FOR I=0 TO 3:READ OPT$(I):NEXT
50 SEL=0
60 GOSUB 2000
70 GET K$:IF K$="" THEN 70
80 IF K$="S" OR K$=CHR$(17) THEN SEL=SEL+1
90 IF K$="W" OR K$=CHR$(145) THEN SEL=SEL-1
100 IF SEL>3 THEN SEL=0
110 IF SEL<0 THEN SEL=3
120 IF K$=CHR$(13) THEN GOSUB 3000
130 GOTO 60

2000 REM --- DRAW MENU ---
2010 PRINT CHR$(147)
2020 PRINT "MAZE CRAZE"
2030 PRINT "-----------"
2040 FOR I=0 TO 3
2050 LINE$=OPT$(I)
2060 IF I=SEL THEN PRINT CHR$(18);" ";LINE$;" ";CHR$(146) ELSE PRINT "  ";LINE$
2070 NEXT I
2080 RETURN
```

- Use `CHR$(18)` to turn on reverse video and `CHR$(146)` to turn it off. Surround the selected option with spaces for a highlighted bar.  
- Wrap selection when moving past the top or bottom.

---

### Handling Menu Selection

```basic
3000 REM --- MENU ACTIONS ---
3010 ON SEL+1 GOTO 3100,3200,3300,3400
3100 PRINT "START!":END
3200 PRINT "LOAD...":END
3300 PRINT "OPTIONS...":END
3400 PRINT "QUIT":END
```

`ON SEL+1` routes to different handlers depending on the highlighted item.

### Dialogue Box with Scroll

```basic
NEW
10 PRINT CHR$(147)
20 DIM MSG$(4)
30 FOR I=0 TO 4:MSG$(I)="":NEXT
40 DATA "WELCOME TO THE MAZE.","WATCH OUT FOR PATROLS.","FIND THE EXIT TO ADVANCE.","PRESS ANY KEY...","GOOD LUCK!"
50 FOR L=0 TO 4
60 MSG$(4)=READ$:FOR I=3 TO 0 STEP -1:MSG$(I)=MSG$(I-1):NEXT
70 MSG$(0)=MSG$(4)
80 GOSUB 2000
90 GET K$:IF K$="" THEN 90
100 NEXT
110 END

2000 REM --- DRAW DIALOGUE PANEL ---
2010 PRINT CHR$(147)
2020 PRINT "DIALOGUE"
2030 PRINT "--------"
2040 FOR I=0 TO 3
2050 LINE$=LEFT$(MSG$(I),36)
2060 PRINT "  ";LINE$
2070 NEXT I
2080 RETURN
```

Here the window shows the four most recent lines; `MSG$(0)` is newest. You can now plug this into cut-scenes, terminals, or quest givers.

### Experiment Section

- Replace reverse video with colour toggles by poking `COLOR` RAM for the menu line.  
- Add keyboard shortcuts: pressing `S` selects “Start Game” instantly by scanning the first character of each option.  
- Pad dialogue lines with `RIGHT$` and `LEFT$` to align speaker names and text columns.  
- Introduce slow typewriter effects by printing one character at a time with delays.  
- Combine the menu engine with the room loader so the “OPTIONS” item adjusts `RULEDMG` or `RULESPEED` dynamically.

---

### Concept Expansion

Menus and dialogue need to be maintainable. By storing options/lines in arrays and reusing the log buffer, you keep layout logic separate from behaviour, paving the way for larger story scripts later.
