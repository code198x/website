## Lesson 19 – Text Tricks II

Week 2 introduced slicing strings; now we’ll dress up the interface. HUDs, logs, and menus all rely on tidy formatting and responsive text handling. Today: padded numbers, synonyms, and scrolling logs.

> [📷 suggested: screenshot showing a formatted HUD and command log]

---

### The One-Minute Tour

- Use `CHR$(19)` to home the cursor and overwrite HUD text.  
- `RIGHT$`, `LEFT$`, `MID$` handle padding/truncation.  
- Normalise inputs (trim spaces, uppercase, collapse synonyms).  
- Maintain command history in a string array.

---

### HUD with Padded Numbers

```basic
NEW
10 SCORE=125
20 LIVES=3
30 TIMELEFT=42
40 PRINT CHR$(147)
50 PRINT CHR$(19)
60 PRINT "SCORE:";RIGHT$("00000"+STR$(SCORE),5);
70 PRINT "  LIVES:";LIVES;
80 PRINT "  TIME:";RIGHT$("00"+STR$(TIMELEFT),2)
```

`RIGHT$("00000"+STR$(SCORE),5)` keeps the score five digits wide, adding leading zeros automatically.

---

### Normalising Player Input

```basic
NEW
10 INPUT "COMMAND";CM$
20 CM$=CM$+" "
30 FOR I=1 TO LEN(CM$)
40 CH$=MID$(CM$,I,1)
50 IF CH$>="a" AND CH$<="z" THEN MID$(CM$,I,1)=CHR$(ASC(CH$)-32)
60 NEXT I
70 IF LEFT$(CM$,1)=" " THEN CM$=MID$(CM$,2):GOTO 70
80 IF RIGHT$(CM$,1)=" " THEN CM$=LEFT$(CM$,LEN(CM$)-1):GOTO 80
90 PRINT "NORMALISED:";CM$
```

Uppercase conversion and space trimming make comparisons reliable.

---

### Synonym Compression

```basic
NEW
10 VB$="TAKE"
20 IF VB$="GRAB" OR VB$="PICK" THEN VB$="TAKE"
30 PRINT VB$
```

You’ll plug this right after splitting verbs/objects to funnel multiple inputs into a single action.

---

### Command Log Buffer

```basic
NEW
10 DIM LOG$(4)
20 FOR I=0 TO 4:LOG$(I)="":NEXT
30 FOR TURN=0 TO 10
40 INPUT "COMMAND";CM$
50 FOR I=4 TO 1 STEP -1
60 LOG$(I)=LOG$(I-1)
70 NEXT I
80 LOG$(0)=CM$
90 PRINT CHR$(147)
100 PRINT "COMMAND LOG"
110 PRINT "------------"
120 FOR I=0 TO 4:PRINT LOG$(I):NEXT
130 NEXT TURN
```

This rolling buffer keeps the latest commands visible—perfect for debugging or story logs.

### Experiment Section

- Centre text: `PRINT TAB((40-LEN(T$))/2);T$` for menu titles.  
- Truncate long names: `LEFT$(NAME$,12)` before printing inside cramped HUD slots.  
- Combine logs with Lesson 18’s movement to show a textual trail of events.  
- Multi-word object support: after splitting verb/object, store the rest in `DESC$` for longer descriptions.  
- Pre-load synonyms from DATA so designers can tweak vocabulary without touching code.

---

### Concept Expansion

Clean text output keeps retro UI readable despite limited pixels. Later you can use these same routines to log combat events, hint systems, or even disk-based conversation trees.

### Game Integration

- **HUD update:** call the padded score routine whenever `SCORE` changes.  
- **Menus:** highlight the active option by padding with spaces and inverse blocks.  
- **Dialog:** combine log buffers with timed updates for conversation windows.  
- **Save prompts:** reuse the normalisation code to accept both `Y/YES` or `N/NO` gracefully.
