## The Sound of Three Voices

Most home computers in 1982 could play one tone at a time—simple beeps and bloops. The C64's SID chip offered three independent synthesizer voices capable of simultaneous sound. This lesson explores the voice architecture that made C64 music revolutionary: true polyphony without external hardware.

---

### The One-Minute Tour

- SID chip has three independent voices (oscillators)
- Each voice: frequency (2 bytes), waveform, ADSR envelope
- Voice 1 base: $D400-$D406 (54272-54278)
- Voice 2 base: $D407-$D40D (54279-54285)
- Voice 3 base: $D40E-$D414 (54286-54292)
- Frequency = 0-65535 (16-bit value split across low/high bytes)
- All voices share global volume register ($D418 / 54296)
- Attack/release register controls sound envelope

---

### Example Program

```basic
10 REM THREE VOICE CHORD
20 REM SETUP ADSR (REQUIRED!)
30 POKE 54277,9:POKE 54278,0
40 POKE 54284,9:POKE 54285,0
50 POKE 54291,9:POKE 54292,0
60 REM SET VOLUME
70 POKE 54296,15
80 REM VOICE 1 - LOW C (262 HZ)
90 POKE 54272,8:POKE 54273,16
100 POKE 54276,17
110 REM VOICE 2 - E (330 HZ)
120 POKE 54279,161:POKE 54280,20
130 POKE 54283,17
140 REM VOICE 3 - G (392 HZ)
150 POKE 54286,193:POKE 54287,24
160 POKE 54290,17
170 REM PLAY FOR 2 SECONDS
180 FOR T=1 TO 120:NEXT
190 REM RELEASE ALL VOICES
200 POKE 54276,16
210 POKE 54283,16
220 POKE 54290,16
```

<audio controls src="/images/commodore-64/phase-0/tier-2/lesson-023/example-1.wav"></audio>

**Lines 30-50** initialize ADSR envelopes for all three voices—without this, the SID chip produces no sound. **Line 70** sets global volume to maximum (15). **Lines 90-160** configure three voices with different frequencies forming a C major chord. Each voice uses register offset +4 for control (54276, 54283, 54290) with value 17 (waveform + gate on). **Lines 200-220** release all voices by clearing the gate bit (value 16 = waveform only).

> **Note:** Frequency values aren't intuitive—262 Hz (middle C) requires frequency value 4104 (low byte 8, high byte 16). Formula: frequency_value = (Hz * 16777216) / 985248

### Concept Expansion

**SID Voice Architecture**

Each of the three voices is a complete synthesizer with these registers:

```
Voice 1 ($D400-$D406 / 54272-54278):
  +0,+1: Frequency (16-bit, low/high)
  +2,+3: Pulse width (for pulse waveform)
  +4:    Control register (waveform + gate)
  +5:    Attack/Decay
  +6:    Sustain/Release

Voice 2 ($D407-$D40D / 54279-54285):
  [same register layout, +7 offset]

Voice 3 ($D40E-$D414 / 54286-54292):
  [same register layout, +14 offset]
```

Setting a frequency affects only that voice. Setting waveform/gate affects only that voice. This independence enables chords, harmonies, and complex music.

**Frequency Calculation**

The SID chip uses a phase accumulator clocked at 985248 Hz (PAL) or 1022727 Hz (NTSC). To generate a specific frequency:

```
Frequency Value = (Desired Hz × 16777216) / Clock Rate

Middle C (261.63 Hz, NTSC):
(261.63 × 16777216) / 1022727 = 4291

A440 (concert A):
(440 × 16777216) / 1022727 = 7217
```

For practical BASIC programming, use a lookup table or pre-calculated values. The precision of BASIC's floating-point math (5 significant digits) introduces small tuning errors at higher frequencies.

**Control Register Structure**

Register +4 for each voice (54276, 54283, 54290) controls waveform and gating:

```
Bit 7: Noise waveform
Bit 6: Pulse waveform
Bit 5: Sawtooth waveform
Bit 4: Triangle waveform
Bit 3: Test bit (resets oscillator)
Bit 2: Ring modulation
Bit 1: Sync
Bit 0: Gate (1=attack phase, 0=release phase)
```

Common values:
- 17 (00010001): Triangle + gate on
- 33 (00100001): Sawtooth + gate on
- 65 (01000001): Pulse + gate on
- 16 (00010000): Triangle, gate off (release)

**Global Volume Register**

$D418 (54296) controls overall volume and filter routing:

```
Bits 3-0: Volume (0-15)
Bit 4: Low-pass filter
Bit 5: Band-pass filter
Bit 6: High-pass filter
Bit 7: Voice 3 off
```

For simple sound: `POKE 54296,15` (maximum volume, no filter).

**Attack/Release Simplified**

Registers +5 and +6 control the ADSR envelope (covered in detail in Lesson 24). For basic notes:

```basic
REM Fast attack, short decay, full sustain, fast release
POKE 54277,9   REM Voice 1: Attack=0, Decay=9
POKE 54278,240 REM Voice 1: Sustain=15, Release=0
```

Default power-on values work for simple tones, but explicit ADSR control creates more musical sounds.

**Voice Independence in Practice**

Each voice runs continuously once started. To play a chord:

1. Set frequency for voice 1
2. Gate on voice 1 (control register bit 0 = 1)
3. Set frequency for voice 2
4. Gate on voice 2
5. Set frequency for voice 3
6. Gate on voice 3
7. Wait (FOR loop)
8. Gate off all voices (control register bit 0 = 0)

Voices don't interfere. You can gate voice 2 off while voices 1 and 3 continue playing.

### Common Mistakes

**Problem 1: No Sound at All**
```basic
POKE 54296,15  REM Volume
POKE 54272,100:POKE 54273,20  REM Frequency
POKE 54276,17  REM Gate on - still no sound!
```
**Diagnosis:** Forgot to initialize ADSR envelope. SID requires Attack/Decay and Sustain/Release values.

**Fix:** Set ADSR registers before playing any sound:
```basic
POKE 54277,9:POKE 54278,0  REM Attack/Decay
POKE 54296,15  REM Volume
POKE 54272,100:POKE 54273,20
POKE 54276,17  REM Now it works!
```
**Why:** ADSR controls sound envelope—how quickly sound starts (attack) and stops (release). Without initialization, envelope registers contain random power-on values, often resulting in zero sustain level (silence).

**Problem 2: Wrong Pitch - Too High or Too Low**
```basic
POKE 54272,100  REM Intended middle C
POKE 54273,16
POKE 54276,17  REM Sounds wrong!
```
**Diagnosis:** Frequency bytes swapped. Low byte first ($D400), high byte second ($D401).

**Fix:** Correct byte order for middle C (frequency 4104):
```basic
POKE 54272,8   REM Low byte: 4104 AND 255 = 8
POKE 54273,16  REM High byte: INT(4104/256) = 16
POKE 54276,17
```
**Why:** 16-bit frequency stored as two bytes. Formula: `L=F AND 255` (low byte), `H=INT(F/256)` (high byte). Getting bytes backwards produces wildly wrong frequency.

**Problem 3: Sound Never Stops**
```basic
POKE 54276,17  REM Gate on
FOR T=1 TO 100:NEXT
REM Forgot to gate off - sound continues!
```
**Diagnosis:** Gate bit (bit 0 of control register) stays set. Sound plays indefinitely.

**Fix:** Clear gate bit after delay:
```basic
POKE 54276,17  REM Gate on
FOR T=1 TO 100:NEXT
POKE 54276,16  REM Gate off (value 17-1=16)
```
**Why:** Control register bit 0 is the gate. When 1, sound plays. When 0, sound enters release phase. Value 17 = waveform (16) + gate (1). Value 16 = waveform only, gate off.

**Problem 4: Only One Voice Plays in Chord**
```basic
POKE 54277,9:POKE 54278,0  REM Set ADSR for voice 1
POKE 54296,15
POKE 54272,8:POKE 54273,16:POKE 54276,17  REM Voice 1
POKE 54279,161:POKE 54280,20:POKE 54283,17  REM Voice 2 - no sound!
```
**Diagnosis:** ADSR not initialized for voices 2 and 3. Each voice needs separate ADSR setup.

**Fix:** Initialize ADSR for all three voices:
```basic
POKE 54277,9:POKE 54278,0  REM Voice 1 ADSR
POKE 54284,9:POKE 54285,0  REM Voice 2 ADSR
POKE 54291,9:POKE 54292,0  REM Voice 3 ADSR
POKE 54296,15
```
**Why:** Each voice has independent ADSR registers at offsets +5 and +6 from voice base address. Voice 2 base is 54279, so ADSR is at 54284-54285. Voice 3 base is 54286, ADSR at 54291-54292.

### How Games Use This

**The Last Ninja** (1987, System 3): Used all three voices for music—melody on voice 1, bass line on voice 2, rhythm/percussion on voice 3. Sound effects temporarily interrupted voice 3, then restored music.

**International Karate** (1985, System 3): Title screen music used three-voice chords for dramatic impact. During gameplay, voice 1 played punch/kick sounds while voices 2-3 continued background music.

**Commando** (1985, Elite): Background music used all three voices in harmony. Explosion effects briefly took over one voice, creating dynamic mix between music and effects.

**Wizball** (1987, Ocean): Martin Galway's soundtrack used complex three-voice harmonies with rapid voice switching. Some sections played 4-5 note arpeggios across three voices to simulate more instruments.

### Quick Reference

**Voice Register Base Addresses:**
```
Voice 1: $D400 (54272)
Voice 2: $D407 (54279)
Voice 3: $D40E (54286)
```

**Register Offsets (add to base):**
```
+0: Frequency low byte
+1: Frequency high byte
+2: Pulse width low byte
+3: Pulse width high byte
+4: Control register (waveform + gate)
+5: Attack/Decay
+6: Sustain/Release
```

**Common Control Values:**
```basic
REM Triangle waveform
POKE voice_control, 17  REM Gate on
POKE voice_control, 16  REM Gate off

REM Sawtooth waveform
POKE voice_control, 33  REM Gate on
POKE voice_control, 32  REM Gate off

REM Pulse waveform
POKE voice_control, 65  REM Gate on
POKE voice_control, 64  REM Gate off
```

**Setting Global Volume:**
```basic
POKE 54296, 15  REM Maximum volume
```

**Splitting Frequency Value:**
```basic
L = F AND 255        REM Low byte
H = INT(F / 256)     REM High byte
```

### What You've Learnt

- SID chip provides three independent synthesizer voices
- Each voice has separate frequency, waveform, and envelope registers
- Voice 1: 54272-54278, Voice 2: 54279-54285, Voice 3: 54286-54292
- Frequency is 16-bit value (0-65535) split into low/high bytes
- Control register bit 0 gates voice on (1) or off (0)
- Global volume register (54296) affects all voices
- Voice independence enables chords, harmonies, and polyphonic music
- Frequency values calculated from Hz using phase accumulator formula
