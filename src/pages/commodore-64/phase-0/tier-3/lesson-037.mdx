## Lesson 37 – Simple AI

A world without opposition feels empty. Simple AI is not about brilliance—it is about believable habits. Patrol an area, notice the player, give chase, then return to routine. With a few conditionals and distance checks, your enemies gain personality and your levels gain tension.

### The One-Minute Tour

- Patrols are just positions that bounce between limits.
- Switch behaviour when the player enters or leaves a detection radius.
- Use colour or sprite animation to telegraph state changes instantly.

---

### Example Program

```basic
NEW
10 REM *** SIMPLE PATROL AI ***
20 PRINT CHR$(147);"WASD MOVE  SPACE RESET"
30 POKE 2040,13:POKE 2041,14
40 POKE 53269,3
50 POKE 53287,6:POKE 53288,2
60 PX=160:PY=200:EX=40:EY=80:DIR=2:MODE=0
70 GET K$
80 IF K$="A" THEN PX=PX-3
90 IF K$="D" THEN PX=PX+3
100 IF K$="W" THEN PY=PY-3
110 IF K$="S" THEN PY=PY+3
120 IF K$=" " THEN EX=40:EY=80:MODE=0
130 IF PX<24 THEN PX=24
140 IF PX>320 THEN PX=320
150 IF PY<50 THEN PY=50
160 IF PY>233 THEN PY=233
170 POKE 53248,PX:POKE 53249,PY
180 DIST=ABS(EX-PX)+ABS(EY-PY)
190 IF DIST<120 THEN MODE=1
200 IF DIST>160 THEN MODE=0
210 IF MODE=0 THEN EX=EX+DIR:IF EX<40 OR EX>280 THEN DIR=-DIR:EX=EX+DIR
220 IF MODE=1 THEN GOSUB 400
230 IF MODE=1 THEN POKE 53288,10 ELSE POKE 53288,2
240 POKE 53250,EX:POKE 53251,EY
250 FOR D=1 TO 5:NEXT D
260 GOTO 70
400 IF EX<PX THEN EX=EX+2
410 IF EX>PX THEN EX=EX-2
420 IF EY<PY THEN EY=EY+1
430 IF EY>PY THEN EY=EY-1
440 RETURN
```

While the drone patrols, line 210 nudges it back and forth between X positions 40 and 280. Lines 180–200 compute the Manhattan distance (sum of horizontal and vertical gaps) and flip `MODE` into chase when the player wanders inside 120 pixels. The chase subroutine (400–440) steps toward the player on both axes, while line 230 flashes the sprite colour to warn the player that they’ve been spotted.

> **Tip:** Manhattan distance (`ABS(ΔX) + ABS(ΔY)`) is cheaper than square roots. It gives good-enough proximity checks for arcade games.

### Experiment Section

- Add a cooldown timer so the drone stays angry for a moment even after you escape.
- Sprinkle randomness: `IF RND(1)<.1 THEN DIR=-DIR` keeps patrols from feeling robotic.
- Replace the player with a waypoint list to create multi-step patrol paths.
- Spawn multiple drones with different detection radii and colours.

### Concept Expansion

Simple AI is just branching logic. Keep each behaviour tiny—patrol, chase, flee—and control them with a handful of flags. As your levels grow, you can add layers: vertical guard towers, projectiles launched when in chase mode, or helpers that alert nearby drones. Collisions (next lesson) and timing (lesson 39) will round out the illusion.

---

### Game Integration

Sample reaction to a caught player:

```basic
IF DIST<40 THEN LIVES=LIVES-1:PX=160:PY=200:MODE=0
```

Resetting the player and enemy together keeps the loop fair. Drop this inside the main loop and wrap `MODE` checks around attack animations or sound effects to make encounters punchy.

### Quick Reference

```basic
REM Detection radius using Manhattan distance
DIST=ABS(EX-PX)+ABS(EY-PY)
IF DIST<ALERT THEN MODE=CHASE
IF DIST>CALM THEN MODE=PATROL

REM Patrol direction flip
EX=EX+DIR
IF EX<LEFT OR EX>RIGHT THEN DIR=-DIR
```

### What You’ve Learnt

- Patrol AI is just predictable movement between two bounds.
- Detection radii let enemies switch behaviours without expensive maths.
- Visual feedback (colour changes) makes AI states obvious to the player.
