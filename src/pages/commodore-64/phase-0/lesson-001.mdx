# Your First C64 Program

Welcome! You're about to write your first program for the Commodore 64.

## What You'll Build

A simple program that fills the screen with text. When you run it, you'll see "HELLO C64!" scrolling endlessly down the screen.

## The Code

Type this exactly as shown:

```basic
10 PRINT "HELLO C64!"
20 GOTO 10
```

That's it! Just two lines.

## How to Run It

1. Start your C64 emulator (VICE recommended)
2. You'll see a blue screen with `READY.`
3. Type the program exactly as shown above
4. Press `RETURN` after each line
5. When you're done typing, type `RUN` and press `RETURN`

The screen should start filling with "HELLO C64!" over and over. The text will scroll up as the screen fills.

## Stopping the Program

Press `RUN/STOP` key (usually mapped to ESC in emulators).

## What Just Happened?

- **Line 10:** Prints "HELLO C64!" to the screen
- **Line 20:** Goes back to line 10 (creates a loop)
- **Result:** Infinite loop that keeps printing

## You Did It!

You just wrote and ran your first C64 program. The Commodore 64 is responding to your commands!
