# Lesson 6: Match the Rhythm

## From Listening to Playing

In Lesson 5, the computer played notes with perfect timing. You watched.

Now **you** must match that timing. Press spacebar when each note plays - hit it within the timing window and you score a hit, miss it and you fail. This is the core of every rhythm game ever made.

This is where passive playback becomes **interactive gameplay**.

---

## The One-Minute Tour

- **State machine** manages game flow (PLAY → WAIT → NEXT)
- **Timing window** defines hit accuracy (±5 frames = 83ms tolerance)
- **Hit detection** compares input frame to note start frame
- **Visual feedback** displays HIT/MISS in color on screen
- **Result timer** auto-clears messages after 1 second
- **Automatic miss** if note duration expires without input

---

## Example Program: Rhythm Matching Game

This program plays an 8-note pattern and checks your timing on each beat.

```asm
; Lesson 006: Match the Rhythm
; Rhythm matching game with timing detection and hit/miss feedback

        * = $0801       ; BASIC start address
        ; BASIC stub: 10 SYS 2064
        !byte $0c,$08,$0a,$00,$9e,$20,$32,$30,$36,$34,$00,$00,$00

        * = $0810       ; Machine code start

; ============================================================================
; CONSTANTS
; ============================================================================
SCREEN = $0400          ; Screen RAM
COLOR  = $d800          ; Color RAM

TIMER_LO = $2d          ; CIA Timer for 60Hz (PAL)
TIMER_HI = $40

TIMING_WINDOW = 5       ; ±5 frames = generous timing window
QUARTER_NOTE = 30       ; 30 frames at 60fps = 0.5 seconds at 120 BPM

; State machine
STATE_PLAY  = 0         ; Playing current note
STATE_WAIT  = 1         ; Waiting for player input
STATE_SHOW  = 2         ; Showing result

; ============================================================================
; FREQUENCY TABLE
; ============================================================================
freq_lo: !byte $67, $72, $89, $aa, $ed, $3b, $94, $13
freq_hi: !byte $11, $12, $13, $14, $15, $17, $18, $1a

; ============================================================================
; PATTERN DATA - Simple 8-beat pattern
; ============================================================================
pattern: !byte 0, 2, 4, 5, 7, 5, 4, 2, $ff
timing:  !byte QUARTER_NOTE, QUARTER_NOTE, QUARTER_NOTE, QUARTER_NOTE
         !byte QUARTER_NOTE, QUARTER_NOTE, QUARTER_NOTE, QUARTER_NOTE, 0

; ============================================================================
; VARIABLES
; ============================================================================
game_state:     !byte $00       ; Current game state
note_index:     !byte $00       ; Current position in pattern
frame_counter:  !byte $00       ; Global frame counter
note_start:     !byte $00       ; Frame when current note started
result_timer:   !byte $00       ; Countdown for result display

; ============================================================================
; INITIALIZATION
; ============================================================================
        jmp init

init:
        jsr clear_sid
        jsr init_timer
        jsr clear_screen
        jsr show_instructions

        lda #$00
        sta note_index
        sta frame_counter
        sta game_state          ; Start in PLAY state
        jmp main_loop

; ============================================================================
; MAIN LOOP
; ============================================================================
main_loop:
        jsr wait_frame
        inc frame_counter       ; Track frames for timing

        ; Handle result display timer
        lda result_timer
        beq check_state
        dec result_timer
        bne check_state
        jsr clear_message       ; Timer expired, clear message

check_state:
        lda game_state
        cmp #STATE_PLAY
        beq do_play
        cmp #STATE_WAIT
        beq do_wait
        jmp main_loop

; ============================================================================
; STATE: PLAY NOTE
; ============================================================================
do_play:
        ; Check if pattern complete
        ldx note_index
        lda pattern,x
        cmp #$ff
        beq game_complete

        ; Play the note
        jsr play_note

        ; Record when note started
        lda frame_counter
        sta note_start

        ; Move to waiting for input
        lda #STATE_WAIT
        sta game_state
        jmp main_loop

; ============================================================================
; STATE: WAIT FOR INPUT
; ============================================================================
do_wait:
        ; Check for spacebar press
        jsr scan_spacebar
        bcs key_pressed         ; Carry set = key pressed

        ; No key - check if note duration expired (automatic miss)
        lda frame_counter
        sec
        sbc note_start          ; A = frames since note started
        ldx note_index
        cmp timing,x
        bcc main_loop           ; Still time left

        ; Time's up - automatic miss
        jsr show_miss
        jmp next_note

key_pressed:
        ; Calculate timing: frames since note started
        lda frame_counter
        sec
        sbc note_start

        ; Check if within timing window
        cmp #TIMING_WINDOW
        bcc hit                 ; Within window = HIT!

        ; Too early or too late = MISS
        jsr show_miss
        jmp next_note

hit:
        jsr show_hit
        jmp next_note

; ============================================================================
; ADVANCE TO NEXT NOTE
; ============================================================================
next_note:
        ; Turn off current note
        lda #$20
        sta $d404

        ; Move to next note
        inc note_index

        ; Back to PLAY state
        lda #STATE_PLAY
        sta game_state
        jmp main_loop

; ============================================================================
; GAME COMPLETE
; ============================================================================
game_complete:
        jsr show_complete
freeze: jmp freeze              ; Freeze at end

; ============================================================================
; PLAY NOTE - Play current note from pattern
; ============================================================================
play_note:
        ldx note_index
        lda pattern,x
        tay                     ; Y = note index

        lda freq_lo,y
        sta $d400               ; Set frequency
        lda freq_hi,y
        sta $d401

        lda #$21                ; Sawtooth + gate ON
        sta $d404
        rts

; ============================================================================
; SCAN SPACEBAR - Check if spacebar pressed
; ============================================================================
scan_spacebar:
        lda #$7f                ; Select column 7
        sta $dc00
        lda $dc01               ; Read rows
        and #$10                ; Check row 4 (spacebar)
        beq space_down
        clc                     ; No key pressed
        rts
space_down:
        sec                     ; Key pressed
        rts

; ============================================================================
; SHOW HIT - Display HIT message in green
; ============================================================================
show_hit:
        ldx #$00
hit_loop:
        lda msg_hit,x
        beq hit_done
        sta SCREEN+40*12+17,x
        lda #$05                ; Green
        sta COLOR+40*12+17,x
        inx
        jmp hit_loop
hit_done:
        lda #60                 ; Show for 1 second
        sta result_timer
        rts

msg_hit: !text "hit!",0

; ============================================================================
; SHOW MISS - Display MISS message in red
; ============================================================================
show_miss:
        ldx #$00
miss_loop:
        lda msg_miss,x
        beq miss_done
        sta SCREEN+40*12+17,x
        lda #$02                ; Red
        sta COLOR+40*12+17,x
        inx
        jmp miss_loop
miss_done:
        lda #60                 ; Show for 1 second
        sta result_timer
        rts

msg_miss: !text "miss",0

; ============================================================================
; CLEAR MESSAGE - Clear result display area
; ============================================================================
clear_message:
        ldx #$05
clear_loop:
        lda #$20                ; Space
        sta SCREEN+40*12+17,x
        dex
        bpl clear_loop
        rts

; ============================================================================
; SHOW INSTRUCTIONS
; ============================================================================
show_instructions:
        ldx #$00
inst_loop:
        lda msg_inst,x
        beq inst_done
        sta SCREEN+40*2+7,x
        lda #$0e                ; Light blue
        sta COLOR+40*2+7,x
        inx
        jmp inst_loop
inst_done:
        rts

msg_inst: !text "press space on the beat!",0

; ============================================================================
; SHOW COMPLETE
; ============================================================================
show_complete:
        ldx #$00
comp_loop:
        lda msg_comp,x
        beq comp_done
        sta SCREEN+40*12+12,x
        lda #$07                ; Yellow
        sta COLOR+40*12+12,x
        inx
        jmp comp_loop
comp_done:
        rts

msg_comp: !text "pattern complete!",0

; ============================================================================
; CLEAR SCREEN
; ============================================================================
clear_screen:
        lda #$20                ; Space character
        ldx #$00
cs_loop1:
        sta SCREEN,x
        sta SCREEN+$100,x
        sta SCREEN+$200,x
        sta SCREEN+$2e8,x
        inx
        bne cs_loop1

        lda #$0e                ; Light blue
        ldx #$00
cs_loop2:
        sta COLOR,x
        sta COLOR+$100,x
        sta COLOR+$200,x
        sta COLOR+$2e8,x
        inx
        bne cs_loop2
        rts

; ============================================================================
; WAIT FRAME - Wait for 60Hz tick
; ============================================================================
wait_frame:
wf_loop:
        lda $dc0d
        and #$01
        beq wf_loop
        rts

; ============================================================================
; INIT TIMER - Set up CIA Timer A
; ============================================================================
init_timer:
        lda #$00
        sta $dc0e               ; Stop timer
        lda #TIMER_LO
        sta $dc04
        lda #TIMER_HI
        sta $dc05
        lda #$11                ; Start continuous
        sta $dc0e
        rts

; ============================================================================
; CLEAR SID
; ============================================================================
clear_sid:
        lda #$00
        ldx #$00
sid_loop:
        sta $d400,x
        inx
        cpx #$1d
        bne sid_loop

        lda #$08                ; Attack=0, Decay=8
        sta $d405
        lda #$b0                ; Sustain=11, Release=0
        sta $d406
        lda #$0f                ; Max volume
        sta $d418
        rts
```

**To run:**
```bash
acme -f cbm -o lesson-006.prg example-1.asm
x64sc lesson-006.prg
```

The game plays 8 notes. Press spacebar as each note plays - if you're within 5 frames (83ms), you get a HIT! Too slow or too fast? MISS!

## The State Machine

Games need structure. This lesson uses a **state machine** - code that behaves differently based on the current state.

**Three states:**

1. **STATE_PLAY (0)** - Play the current note and record when it started
2. **STATE_WAIT (1)** - Wait for player input, check timing
3. **STATE_SHOW (2)** - (Reserved for future use)

**State flow:**
```
STATE_PLAY → STATE_WAIT → (hit/miss) → STATE_PLAY → ...
```

**Implementation:**
```asm
check_state:
        lda game_state
        cmp #STATE_PLAY
        beq do_play
        cmp #STATE_WAIT
        beq do_wait
        jmp main_loop
```

Each frame, we check `game_state` and jump to the appropriate handler. Clean, modular, extensible.

## Timing Window Explained

The timing window defines how accurate the player must be.

```asm
TIMING_WINDOW = 5       ; ±5 frames
```

**What this means:**

If the note starts at frame 100, the player must press spacebar between frame **100** and frame **105** to score a hit.

**Hit detection:**
```asm
key_pressed:
        lda frame_counter       ; Current frame
        sec
        sbc note_start          ; Subtract note start frame
        ; A now contains frames since note started
        cmp #TIMING_WINDOW      ; Compare to window
        bcc hit                 ; If A < window, it's a hit!
```

**Timing window vs difficulty:**
```
±5 frames = 83ms window  (easy)
±3 frames = 50ms window  (medium)
±2 frames = 33ms window  (hard)
±1 frame  = 17ms window  (expert)
```

At ±5 frames, this game is **generous** - good for learning. Lesson 7 introduces difficulty levels with variable windows.

## Hit Detection Algorithm

The core gameplay logic:

```asm
do_wait:
        jsr scan_spacebar       ; Check spacebar
        bcs key_pressed         ; Carry set = pressed

        ; No key pressed - check timeout
        lda frame_counter
        sec
        sbc note_start          ; Frames since note started
        ldx note_index
        cmp timing,x            ; Compare to note duration
        bcc main_loop           ; Still time? Keep waiting

        ; Time's up!
        jsr show_miss           ; Automatic miss
        jmp next_note

key_pressed:
        lda frame_counter
        sec
        sbc note_start          ; How long since note?
        cmp #TIMING_WINDOW      ; Within window?
        bcc hit                 ; Yes = HIT!
        jsr show_miss           ; No = MISS
```

**Two ways to miss:**
1. **Press too late** - Exceeded timing window
2. **Don't press at all** - Note duration expires

## Screen Memory Display

Text appears at **Screen RAM ($0400)** with colors at **Color RAM ($D800)**.

**Screen layout:**
- 40 columns × 25 rows = 1000 bytes
- Row calculation: `40 * row_number`
- Position: `SCREEN + (40 * row) + column`

**Displaying "HIT!" in green at row 12, column 17:**
```asm
show_hit:
        ldx #$00
hit_loop:
        lda msg_hit,x           ; Get character
        beq hit_done            ; 0 = end of string
        sta SCREEN+40*12+17,x   ; Write to screen
        lda #$05                ; Green color code
        sta COLOR+40*12+17,x    ; Write to color RAM
        inx
        jmp hit_loop
hit_done:
        rts

msg_hit: !text "hit!",0
```

**Why `40*12+17`?**
- Row 12 = 40 × 12 = 480 bytes from screen start
- Column 17 = 17 bytes from start of row
- Total offset: 480 + 17 = 497

The `!text` directive creates a string with a null terminator (0), which the loop uses to detect the end.

## The Result Timer

Messages shouldn't stay on screen forever. `result_timer` counts down each frame and clears the message when it reaches zero.

```asm
main_loop:
        jsr wait_frame

        ; Decrement result timer
        lda result_timer
        beq check_state         ; Already zero? Skip
        dec result_timer        ; Count down
        bne check_state         ; Not zero yet? Continue
        jsr clear_message       ; Just reached zero? Clear!
```

**When setting the timer:**
```asm
show_hit:
        ; ...display "HIT!" on screen...
        lda #60                 ; 60 frames at 60fps = 1 second
        sta result_timer
        rts
```

This creates a **1-second flash** of the result message before it auto-clears.

## Automatic Miss Detection

If the player doesn't press anything, the note eventually expires:

```asm
do_wait:
        jsr scan_spacebar
        bcs key_pressed         ; Key pressed? Handle it

        ; No key - check if note duration expired
        lda frame_counter
        sec
        sbc note_start          ; Frames since note started
        ldx note_index
        cmp timing,x            ; Compare to note's duration
        bcc main_loop           ; Still time left? Keep waiting

        ; Time's up - automatic miss!
        jsr show_miss
        jmp next_note
```

This prevents the game from hanging forever waiting for input. Every note has a **deadline**.

## Color Codes

Color RAM uses values 0-15 for the C64's color palette:

```
$00 = Black       $08 = Orange
$01 = White       $09 = Brown
$02 = Red         $0A = Light red
$03 = Cyan        $0B = Dark grey
$04 = Purple      $0C = Medium grey
$05 = Green       $0D = Light green
$06 = Blue        $0E = Light blue
$07 = Yellow      $0F = Light grey
```

**In this lesson:**
- **Green ($05)** = HIT
- **Red ($02)** = MISS
- **Yellow ($07)** = Pattern complete
- **Light blue ($0E)** = Instructions

Visual feedback through color is **instant** and **intuitive**.

## The `!text` Directive

ACME's `!text` directive converts strings to PETSCII (C64 screen codes):

```asm
msg_hit: !text "hit!",0
```

**What this creates in memory:**
```
$08 $09 $14 $21 $00
 h   i   t   !  null
```

These are **screen codes** (not ASCII!). When written to Screen RAM, they appear as text. The null byte (0) marks the end of the string for the display loop.

## Carry Flag for Key State

The spacebar scan uses the **carry flag** to return key state:

```asm
scan_spacebar:
        lda #$7f        ; Select column 7
        sta $dc00
        lda $dc01       ; Read rows
        and #$10        ; Check row 4 (spacebar)
        beq space_down  ; Bit 0? Key is down
        clc             ; Clear carry = not pressed
        rts
space_down:
        sec             ; Set carry = pressed
        rts
```

**Calling code:**
```asm
jsr scan_spacebar
bcs key_pressed     ; Carry set? Key is down
; Carry clear, no key pressed
```

The carry flag is a common pattern for boolean return values in assembly.

## Quick Reference

**State Machine Pattern:**
```asm
game_state: .byte $00

main:   lda game_state
        cmp #STATE_A
        beq handle_a
        cmp #STATE_B
        beq handle_b
        jmp main

handle_a:
        ; State A logic
        lda #STATE_B
        sta game_state
        jmp main
```

**Timing Check:**
```asm
lda current_frame
sec
sbc start_frame         ; A = elapsed frames
cmp #MAX_FRAMES         ; Within limit?
bcc still_valid         ; Yes
; No, time expired
```

**Screen Text Display:**
```asm
        ldx #$00
loop:   lda text,x
        beq done
        sta SCREEN+offset,x
        lda #color
        sta COLOR+offset,x
        inx
        jmp loop
done:   rts

text: !text "hello",0
```

**Screen Position Calculation:**
```
Position = $0400 + (row × 40) + column
Row 0, Col 0   = $0400 + 0    = $0400
Row 12, Col 17 = $0400 + 497  = $05F1
Row 24, Col 39 = $0400 + 999  = $07E7 (last position)
```

**Color Memory:**
```
Color RAM starts at $D800
Same offset as screen: COLOR + (row × 40) + column
```
