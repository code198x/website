# Your First C64 Assembly Program

Welcome to assembly language! You're about to write your first 6502 assembly program for the Commodore 64.

## What You'll Build

A program that changes the border colour. When you run it, the border will flash between colours continuously.

## The Code

Save this as `hello.asm`:

```nasm
; Your first C64 assembly program
; Changes the border colour

        * = $0801       ; BASIC start address

        ; BASIC stub: 10 SYS 2064
        .byte $0c,$08,$0a,$00,$9e,$20,$32,$30,$36,$34,$00,$00,$00

        * = $0810       ; Start of our program

loop:   inc $d020       ; Increment border colour
        jmp loop        ; Loop forever
```

## How to Assemble and Run It

### Using ACME assembler:
```bash
acme -f cbm -o hello.prg hello.asm
```

### Run in VICE emulator:
```bash
x64sc hello.prg
```

Or in VICE: File → Autostart hello.prg

## Stopping the Program

Press `RUN/STOP` and `RESTORE` together (or use emulator reset).

## What Just Happened?

- **`* = $0801`:** Sets the start address to where BASIC programs begin
- **BASIC stub:** A tiny BASIC program that calls our assembly code (SYS 2064)
- **`* = $0810`:** Our actual assembly code starts here (2064 in decimal = $0810 in hex)
- **`inc $d020`:** Increments the value at memory address $D020 (border colour register)
- **`jmp loop`:** Jumps back to the loop label (infinite loop)

## The 6502 Registers You're Using

- **PC (Program Counter):** Points to the current instruction
- **$D020:** VIC-II border colour register (hardware, not a CPU register!)

## You Did It!

You just wrote and ran your first assembly language program. You're directly controlling the C64's hardware!
