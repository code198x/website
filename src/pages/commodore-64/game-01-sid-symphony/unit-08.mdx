## What You're Building

You've built the pieces. Now they become a game.

By the end of this unit, you'll have:

- A title screen with instructions
- Game over when the crowd empties
- Victory when you complete the song
- Press SPACE to play again
- A complete game loop

## Game States

Every game is a state machine. SID Symphony has four states:

```asm
STATE_TITLE     = 0
STATE_PLAYING   = 1
STATE_GAMEOVER  = 2
STATE_VICTORY   = 3

game_state:     !byte STATE_TITLE
```

The game starts at the title screen. Press SPACE to play. Win or lose, press SPACE to return to the title. Simple, but it's a complete loop.

## The Main Loop as Dispatcher

Instead of one big main loop, we dispatch to different update routines based on state:

```asm
main_loop:
            jsr wait_frame

            lda game_state
            cmp #STATE_TITLE
            bne +
            jsr update_title
            jmp main_loop
+           cmp #STATE_PLAYING
            bne +
            jsr update_playing
            jmp main_loop
+           jsr update_endscreen      ; Game over or victory
            jmp main_loop
```

Each state has its own update routine. The dispatcher just routes to the right one.

## The Title Screen

Simple text, no animation:

```asm
draw_title_screen:
            ; Clear screen
            jsr clear_screen

            ; Draw title
            ldx #$00
-           lda title_text,x
            beq +
            sta SCREEN + (5 * 40) + 13,x
            lda #COL_CYAN
            sta COLOUR + (5 * 40) + 13,x
            inx
            bne -
+
            ; Draw instructions
            ldx #$00
-           lda press_space_text,x
            beq +
            sta SCREEN + (12 * 40) + 10,x
            lda #COL_WHITE
            sta COLOUR + (12 * 40) + 10,x
            inx
            bne -
+
            ; Draw controls
            ldx #$00
-           lda controls_text,x
            beq +
            sta SCREEN + (16 * 40) + 8,x
            lda #COL_GREY
            sta COLOUR + (16 * 40) + 8,x
            inx
            bne -
+           rts
```

The title state just waits for SPACE:

```asm
update_title:
            jsr check_space_key
            beq +
            jsr start_game
+           rts
```

## Checking the Space Key

SPACE is on column 7, row 4 of the keyboard matrix:

```asm
check_space_key:
            lda #%01111111          ; Select column 7
            sta CIA1_PORTA
            lda CIA1_PORTB
            and #%00010000          ; Check row 4 (SPACE)
            bne +                   ; Not pressed
            lda #$01                ; Pressed
            rts
+           lda #$00
            rts
```

<InlineNote>
We need to debounce the space key to prevent multiple triggers. We store the previous state and only act on the transition from not-pressed to pressed.
</InlineNote>

## State Transitions

**Title → Playing**: When SPACE is pressed, call `start_game` and change state.

**Playing → Game Over**: When the crowd meter hits zero:

```asm
trigger_game_over:
            lda #STATE_GAMEOVER
            sta game_state
            jsr draw_gameover_screen
            rts
```

**Playing → Victory**: When the song ends and no notes remain:

```asm
check_victory:
            lda song_playing
            bne +                   ; Song still playing

            ; Song ended - check for remaining notes
            ldx #MAX_NOTES - 1
-           lda note_x,x
            cmp #NOTE_INACTIVE
            bne +                   ; Note still on screen
            dex
            bpl -

            ; No notes! Victory!
            lda #STATE_VICTORY
            sta game_state
            jsr draw_victory_screen
+           rts
```

**Game Over/Victory → Title**: Both end screens wait for SPACE, then return to title.

## Start Game

When starting, reset everything and draw the game screen:

```asm
start_game:
            ; Clear notes
            ldx #MAX_NOTES - 1
            lda #NOTE_INACTIVE
-           sta note_x,x
            dex
            bpl -

            ; Reset song
            lda #<song_data
            sta song_ptr
            lda #>song_data
            sta song_ptr + 1
            ldy #$00
            lda (song_ptr),y
            sta next_note_timer
            lda #$01
            sta song_playing

            ; Reset state
            lda #$00
            sta score_lo
            sta score_hi
            sta streak
            sta best_streak
            sta key_x
            sta key_c
            sta key_v
            sta key_x_prev
            sta key_c_prev
            sta key_v_prev
            sta hit_flash
            sta miss_flash
            sta space_prev

            lda #CROWD_START
            sta crowd_meter
            lda #NOTE_SPEED
            sta move_timer

            ; Draw game screen
            jsr draw_game_screen

            ; Start playing
            lda #STATE_PLAYING
            sta game_state
            rts
```

## End Screens

Game over and victory are similar — show a message, display the final score, wait for SPACE:

```asm
draw_gameover_screen:
            ldx #$00
-           lda gameover_text,x
            beq +
            sta SCREEN + (10 * 40) + 15,x
            lda #COL_RED
            sta COLOUR + (10 * 40) + 15,x
            inx
            bne -
+           jsr draw_final_score
            rts

draw_victory_screen:
            ldx #$00
-           lda victory_text,x
            beq +
            sta SCREEN + (10 * 40) + 12,x
            lda #COL_GREEN
            sta COLOUR + (10 * 40) + 12,x
            inx
            bne -
+           jsr draw_final_score
            rts
```

The update for both end screens is the same — wait for SPACE:

```asm
update_endscreen:
            lda space_prev
            bne +                   ; Was already pressed
            jsr check_space_key
            beq ++                  ; Not pressed now
            ; Space just pressed - return to title
            jsr draw_title_screen
            lda #STATE_TITLE
            sta game_state
++          jsr check_space_key
+           sta space_prev
            rts
```

## The Complete Code

Here's the complete `symphony.asm` including all features from Units 1-8:

```asm
;──────────────────────────────────────────────────────────────
; SID SYMPHONY
; A rhythm game for the Commodore 64
; Unit 8: The Performance
;
; Current features:
; - Three-track display with X/C/V key input
; - Three SID voices (C major chord)
; - Song data drives note spawning
; - Score, streak, and crowd meter
; - Title screen, game over, victory
; - Full game loop with restart
;
; Controls:
;   X     - Hit notes on track 0 (top)
;   C     - Hit notes on track 1 (middle)
;   V     - Hit notes on track 2 (bottom)
;   SPACE - Start game / return to title
;──────────────────────────────────────────────────────────────

; ============================================================
; CONSTANTS
; ============================================================

SCREEN          = $0400
COLOUR          = $d800
BORDER          = $d020
BACKGROUND      = $d021
RASTER          = $d012

SID             = $d400
SID_V1_FREQ_LO  = SID + $00
SID_V1_FREQ_HI  = SID + $01
SID_V1_PW_LO    = SID + $02
SID_V1_PW_HI    = SID + $03
SID_V1_CTRL     = SID + $04
SID_V1_AD       = SID + $05
SID_V1_SR       = SID + $06
SID_V2_FREQ_LO  = SID + $07
SID_V2_FREQ_HI  = SID + $08
SID_V2_PW_LO    = SID + $09
SID_V2_PW_HI    = SID + $0a
SID_V2_CTRL     = SID + $0b
SID_V2_AD       = SID + $0c
SID_V2_SR       = SID + $0d
SID_V3_FREQ_LO  = SID + $0e
SID_V3_FREQ_HI  = SID + $0f
SID_V3_PW_LO    = SID + $10
SID_V3_PW_HI    = SID + $11
SID_V3_CTRL     = SID + $12
SID_V3_AD       = SID + $13
SID_V3_SR       = SID + $14
SID_VOLUME      = SID + $18

CIA1_PORTA      = $dc00
CIA1_PORTB      = $dc01

zp_ptr          = $fb
song_ptr        = $fd

; Screen layout
ROW_SCORE       = 1
ROW_STREAK      = 2
ROW_CROWD       = 3
ROW_TRACK0      = 10
ROW_TRACK1      = 12
ROW_TRACK2      = 14
HIT_ZONE_COL    = 5

; Colours
COL_BLACK       = $00
COL_WHITE       = $01
COL_RED         = $02
COL_CYAN        = $03
COL_GREEN       = $05
COL_BLUE        = $06
COL_YELLOW      = $07
COL_GREY        = $0c

; Game constants
NUM_TRACKS      = 3
MAX_NOTES       = 12
NOTE_INACTIVE   = $ff
NOTE_SPEED      = 4
FLASH_TIME      = 4
HIT_ZONE_W      = 3
POINTS_PER_HIT  = 10
CROWD_MAX       = 20
CROWD_START     = 10

; Game states
STATE_TITLE     = 0
STATE_PLAYING   = 1
STATE_GAMEOVER  = 2
STATE_VICTORY   = 3

; SID frequencies
FREQ_C4_LO      = $c3
FREQ_C4_HI      = $10
FREQ_E4_LO      = $1f
FREQ_E4_HI      = $15
FREQ_G4_LO      = $1e
FREQ_G4_HI      = $19

; ============================================================
; BASIC STUB
; ============================================================
*= $0801
            !byte $0c, $08
            !byte $0a, $00
            !byte $9e
            !text "2064"
            !byte $00
            !byte $00, $00

; ============================================================
; MAIN PROGRAM
; ============================================================
*= $0810
start:
            jsr init_sid
            jsr draw_title_screen
            lda #STATE_TITLE
            sta game_state

main_loop:
            jsr wait_frame

            lda game_state
            cmp #STATE_TITLE
            bne +
            jsr update_title
            jmp main_loop
+           cmp #STATE_PLAYING
            bne +
            jsr update_playing
            jmp main_loop
+           jsr update_endscreen
            jmp main_loop

; ============================================================
; INITIALISATION
; ============================================================

init_sid:
            ldx #$18
            lda #$00
-           sta SID,x
            dex
            bpl -

            lda #$0f
            sta SID_VOLUME

            lda #FREQ_C4_LO
            sta SID_V1_FREQ_LO
            lda #FREQ_C4_HI
            sta SID_V1_FREQ_HI
            lda #$08
            sta SID_V1_PW_LO
            sta SID_V1_PW_HI
            lda #$22
            sta SID_V1_AD
            lda #$a8
            sta SID_V1_SR

            lda #FREQ_E4_LO
            sta SID_V2_FREQ_LO
            lda #FREQ_E4_HI
            sta SID_V2_FREQ_HI
            lda #$08
            sta SID_V2_PW_LO
            sta SID_V2_PW_HI
            lda #$22
            sta SID_V2_AD
            lda #$a8
            sta SID_V2_SR

            lda #FREQ_G4_LO
            sta SID_V3_FREQ_LO
            lda #FREQ_G4_HI
            sta SID_V3_FREQ_HI
            lda #$08
            sta SID_V3_PW_LO
            sta SID_V3_PW_HI
            lda #$22
            sta SID_V3_AD
            lda #$a8
            sta SID_V3_SR
            rts

clear_screen:
            lda #COL_BLACK
            sta BORDER
            sta BACKGROUND

            ldx #$00
            lda #$20
-           sta SCREEN,x
            sta SCREEN + $100,x
            sta SCREEN + $200,x
            sta SCREEN + $2e8,x
            lda #COL_GREY
            sta COLOUR,x
            sta COLOUR + $100,x
            sta COLOUR + $200,x
            sta COLOUR + $2e8,x
            inx
            bne -
            rts

; ============================================================
; TITLE SCREEN
; ============================================================

draw_title_screen:
            jsr clear_screen

            ; Draw title
            ldx #$00
-           lda title_text,x
            beq +
            sta SCREEN + (5 * 40) + 13,x
            lda #COL_CYAN
            sta COLOUR + (5 * 40) + 13,x
            inx
            bne -
+
            ; Draw "PRESS SPACE"
            ldx #$00
-           lda press_space_text,x
            beq +
            sta SCREEN + (12 * 40) + 13,x
            lda #COL_WHITE
            sta COLOUR + (12 * 40) + 13,x
            inx
            bne -
+
            ; Draw controls
            ldx #$00
-           lda controls_text,x
            beq +
            sta SCREEN + (17 * 40) + 10,x
            lda #COL_GREY
            sta COLOUR + (17 * 40) + 10,x
            inx
            bne -
+
            lda #$00
            sta space_prev
            rts

update_title:
            lda space_prev
            bne +
            jsr check_space_key
            beq ++
            jsr start_game
++          jsr check_space_key
+           sta space_prev
            rts

; ============================================================
; START GAME
; ============================================================

start_game:
            ; Clear notes
            ldx #MAX_NOTES - 1
            lda #NOTE_INACTIVE
-           sta note_x,x
            dex
            bpl -

            ; Reset song
            lda #<song_data
            sta song_ptr
            lda #>song_data
            sta song_ptr + 1
            ldy #$00
            lda (song_ptr),y
            sta next_note_timer
            lda #$01
            sta song_playing

            ; Reset state
            lda #$00
            sta score_lo
            sta score_hi
            sta streak
            sta best_streak
            sta key_x
            sta key_c
            sta key_v
            sta key_x_prev
            sta key_c_prev
            sta key_v_prev
            sta hit_flash
            sta miss_flash

            lda #CROWD_START
            sta crowd_meter
            lda #NOTE_SPEED
            sta move_timer

            jsr draw_game_screen

            lda #STATE_PLAYING
            sta game_state
            rts

; ============================================================
; GAME SCREEN
; ============================================================

draw_game_screen:
            jsr clear_screen

            ; Title
            ldx #$00
-           lda title_text,x
            beq +
            sta SCREEN + 4,x
            lda #COL_CYAN
            sta COLOUR + 4,x
            inx
            bne -
+
            ; Labels
            ldx #$00
-           lda score_label,x
            beq +
            sta SCREEN + (ROW_SCORE * 40),x
            lda #COL_WHITE
            sta COLOUR + (ROW_SCORE * 40),x
            inx
            bne -
+
            ldx #$00
-           lda streak_label,x
            beq +
            sta SCREEN + (ROW_STREAK * 40),x
            lda #COL_WHITE
            sta COLOUR + (ROW_STREAK * 40),x
            inx
            bne -
+
            ldx #$00
-           lda crowd_label,x
            beq +
            sta SCREEN + (ROW_CROWD * 40),x
            lda #COL_WHITE
            sta COLOUR + (ROW_CROWD * 40),x
            inx
            bne -
+
            ; Tracks
            jsr draw_tracks
            rts

draw_tracks:
            ldx #39
            lda #$43
-           sta SCREEN + (ROW_TRACK0 * 40),x
            lda #COL_RED
            sta COLOUR + (ROW_TRACK0 * 40),x
            dex
            bpl -

            ldx #39
            lda #$43
-           sta SCREEN + (ROW_TRACK1 * 40),x
            lda #COL_GREEN
            sta COLOUR + (ROW_TRACK1 * 40),x
            dex
            bpl -

            ldx #39
            lda #$43
-           sta SCREEN + (ROW_TRACK2 * 40),x
            lda #COL_BLUE
            sta COLOUR + (ROW_TRACK2 * 40),x
            dex
            bpl -

            ; Hit zone markers
            lda #$5b
            sta SCREEN + (ROW_TRACK0 * 40) + HIT_ZONE_COL - 1
            sta SCREEN + (ROW_TRACK1 * 40) + HIT_ZONE_COL - 1
            sta SCREEN + (ROW_TRACK2 * 40) + HIT_ZONE_COL - 1
            lda #$5d
            sta SCREEN + (ROW_TRACK0 * 40) + HIT_ZONE_COL + HIT_ZONE_W
            sta SCREEN + (ROW_TRACK1 * 40) + HIT_ZONE_COL + HIT_ZONE_W
            sta SCREEN + (ROW_TRACK2 * 40) + HIT_ZONE_COL + HIT_ZONE_W
            lda #COL_WHITE
            sta COLOUR + (ROW_TRACK0 * 40) + HIT_ZONE_COL - 1
            sta COLOUR + (ROW_TRACK0 * 40) + HIT_ZONE_COL + HIT_ZONE_W
            sta COLOUR + (ROW_TRACK1 * 40) + HIT_ZONE_COL - 1
            sta COLOUR + (ROW_TRACK1 * 40) + HIT_ZONE_COL + HIT_ZONE_W
            sta COLOUR + (ROW_TRACK2 * 40) + HIT_ZONE_COL - 1
            sta COLOUR + (ROW_TRACK2 * 40) + HIT_ZONE_COL + HIT_ZONE_W

            ; Track labels
            lda #$18
            sta SCREEN + (ROW_TRACK0 * 40) + 1
            lda #$03
            sta SCREEN + (ROW_TRACK1 * 40) + 1
            lda #$16
            sta SCREEN + (ROW_TRACK2 * 40) + 1
            lda #COL_WHITE
            sta COLOUR + (ROW_TRACK0 * 40) + 1
            sta COLOUR + (ROW_TRACK1 * 40) + 1
            sta COLOUR + (ROW_TRACK2 * 40) + 1
            rts

; ============================================================
; PLAYING STATE
; ============================================================

update_playing:
            jsr read_keys
            jsr check_hits
            jsr check_song
            jsr update_notes
            jsr check_victory
            jsr update_flash
            jsr update_display
            rts

; ============================================================
; FRAME SYNCHRONISATION
; ============================================================

wait_frame:
-           lda RASTER
            cmp #255
            bne -
-           lda RASTER
            cmp #255
            beq -
            rts

; ============================================================
; INPUT HANDLING
; ============================================================

read_keys:
            lda key_x
            sta key_x_prev
            lda key_c
            sta key_c_prev
            lda key_v
            sta key_v_prev

            lda #%01111111
            sta CIA1_PORTA
            lda CIA1_PORTB
            and #%00000100
            beq +
            lda #$00
            jmp ++
+           lda #$01
++          sta key_x

            lda #%11101111
            sta CIA1_PORTA
            lda CIA1_PORTB
            and #%00000100
            beq +
            lda #$00
            jmp ++
+           lda #$01
++          sta key_c

            lda #%01111111
            sta CIA1_PORTA
            lda CIA1_PORTB
            and #%00001000
            beq +
            lda #$00
            jmp ++
+           lda #$01
++          sta key_v
            rts

check_space_key:
            lda #%01111111
            sta CIA1_PORTA
            lda CIA1_PORTB
            and #%00010000
            bne +
            lda #$01
            rts
+           lda #$00
            rts

; ============================================================
; HIT DETECTION
; ============================================================

check_hits:
            lda key_x_prev
            bne +
            lda key_x
            beq +
            lda #$00
            jsr check_hit_on_track
            lda #$00
            jsr play_voice
+
            lda key_c_prev
            bne +
            lda key_c
            beq +
            lda #$01
            jsr check_hit_on_track
            lda #$01
            jsr play_voice
+
            lda key_v_prev
            bne +
            lda key_v
            beq +
            lda #$02
            jsr check_hit_on_track
            lda #$02
            jsr play_voice
+           rts

check_hit_on_track:
            sta check_track
            ldx #MAX_NOTES - 1
-           lda note_x,x
            cmp #NOTE_INACTIVE
            beq +
            lda note_track,x
            cmp check_track
            bne +
            lda note_x,x
            cmp #HIT_ZONE_COL
            bcc +
            cmp #HIT_ZONE_COL + HIT_ZONE_W
            bcs +

            jsr erase_note
            lda #NOTE_INACTIVE
            sta note_x,x

            jsr add_score
            jsr update_crowd_hit

            inc streak
            lda streak
            cmp best_streak
            bcc ++
            sta best_streak
++
            lda #FLASH_TIME
            sta hit_flash
            rts

+           dex
            bpl -
            rts

; ============================================================
; SONG PLAYBACK
; ============================================================

check_song:
            lda song_playing
            beq +

            dec next_note_timer
            bne +

            ldy #$01
            lda (song_ptr),y
            jsr spawn_note_on_track

            clc
            lda song_ptr
            adc #$02
            sta song_ptr
            bcc ++
            inc song_ptr + 1
++
            ldy #$00
            lda (song_ptr),y
            beq +++
            sta next_note_timer
+           rts

+++         lda #$00
            sta song_playing
            rts

spawn_note_on_track:
            sta temp_track

            ldx #MAX_NOTES - 1
-           lda note_x,x
            cmp #NOTE_INACTIVE
            beq +
            dex
            bpl -
            rts

+           lda #38
            sta note_x,x
            lda temp_track
            sta note_track,x
            jsr draw_note
            rts

; ============================================================
; VICTORY CHECK
; ============================================================

check_victory:
            lda song_playing
            bne +

            ldx #MAX_NOTES - 1
-           lda note_x,x
            cmp #NOTE_INACTIVE
            bne +
            dex
            bpl -

            ; Victory!
            lda #STATE_VICTORY
            sta game_state
            jsr draw_victory_screen
+           rts

; ============================================================
; SCORING
; ============================================================

add_score:
            clc
            lda score_lo
            adc #POINTS_PER_HIT
            sta score_lo
            bcc +
            inc score_hi
+           rts

; ============================================================
; CROWD MANAGEMENT
; ============================================================

update_crowd_hit:
            lda crowd_meter
            cmp #CROWD_MAX
            bcs +
            inc crowd_meter
+           rts

update_crowd_miss:
            lda crowd_meter
            sec
            sbc #$02
            bcs +
            lda #$00
+           sta crowd_meter
            bne +
            jsr trigger_game_over
+           rts

trigger_game_over:
            lda #STATE_GAMEOVER
            sta game_state
            jsr draw_gameover_screen
            rts

; ============================================================
; NOTE MOVEMENT
; ============================================================

update_notes:
            dec move_timer
            bne un_done
            lda #NOTE_SPEED
            sta move_timer

            ldx #MAX_NOTES - 1
-           lda note_x,x
            cmp #NOTE_INACTIVE
            beq +

            jsr erase_note

            dec note_x,x
            bmi ++

            jsr draw_note
            jmp +

++          lda #NOTE_INACTIVE
            sta note_x,x

            jsr update_crowd_miss

            lda #$00
            sta streak

            lda #FLASH_TIME
            sta miss_flash

+           dex
            bpl -

un_done:
            rts

; ============================================================
; NOTE DRAWING
; ============================================================

draw_note:
            lda note_track,x
            tay
            lda track_row_lo,y
            sta zp_ptr
            lda track_row_hi,y
            sta zp_ptr + 1

            ldy note_x,x
            lda #$51
            sta (zp_ptr),y

            lda note_track,x
            tay
            lda colour_row_lo,y
            sta zp_ptr
            lda colour_row_hi,y
            sta zp_ptr + 1

            lda note_track,x
            tay
            lda track_note_colour,y
            ldy note_x,x
            sta (zp_ptr),y
            rts

erase_note:
            lda note_track,x
            tay
            lda track_row_lo,y
            sta zp_ptr
            lda track_row_hi,y
            sta zp_ptr + 1

            ldy note_x,x
            lda #$43
            sta (zp_ptr),y

            lda note_track,x
            tay
            lda colour_row_lo,y
            sta zp_ptr
            lda colour_row_hi,y
            sta zp_ptr + 1

            lda note_track,x
            tay
            lda track_line_colour,y
            ldy note_x,x
            sta (zp_ptr),y
            rts

update_flash:

            beq +
            dec hit_flash
            lda #COL_GREEN
            sta BORDER
            rts
+
            lda miss_flash
            beq +
            dec miss_flash
            lda #COL_RED
            sta BORDER
            rts
+
            lda #COL_BLACK
            sta BORDER
            rts

            bne +
            lda #$41
            sta SID_V1_CTRL
            rts
+           cmp #$01
            bne +
            lda #$41
            sta SID_V2_CTRL
            rts
+           lda #$41
            sta SID_V3_CTRL
            rts

draw_gameover_screen:
            ldx #$00
-           lda gameover_text,x
            beq +
            sta SCREEN + (10 * 40) + 15,x
            lda #COL_RED
            sta COLOUR + (10 * 40) + 15,x
            inx
            bne -
+           jsr draw_final_score
            lda #$00
            sta space_prev
            rts

draw_victory_screen:
            ldx #$00
-           lda victory_text,x
            beq +
            sta SCREEN + (10 * 40) + 11,x
            lda #COL_GREEN
            sta COLOUR + (10 * 40) + 11,x
            inx
            bne -
+           jsr draw_final_score
            lda #$00
            sta space_prev
            rts

draw_final_score:
            ; Draw "FINAL SCORE:" on row 13
            ldx #$00
-           lda final_score_text,x
            beq +
            sta SCREEN + (13 * 40) + 10,x
            lda #COL_WHITE
            sta COLOUR + (13 * 40) + 10,x
            inx
            bne -
+
            ; Draw score digits
            jsr convert_score
            ldx #$00
-           lda score_digits,x
            ora #$30
            sta SCREEN + (13 * 40) + 23,x
            lda #COL_WHITE
            sta COLOUR + (13 * 40) + 23,x
            inx
            cpx #$05
            bne -

            ; Draw "PRESS SPACE"
            ldx #$00
-           lda press_space_text,x
            beq +
            sta SCREEN + (18 * 40) + 13,x
            lda #COL_GREY
            sta COLOUR + (18 * 40) + 13,x
            inx
            bne -
+           rts

update_endscreen:
            lda space_prev
            bne +
            jsr check_space_key
            beq ++
            jsr draw_title_screen
            lda #STATE_TITLE
            sta game_state
++          jsr check_space_key
+           sta space_prev
            rts

; ============================================================

update_display:
            jsr convert_score
            jsr draw_score
            jsr convert_streak
            jsr draw_streak
            jsr draw_crowd
            rts

convert_score:
            lda score_lo
            sta work_lo
            lda score_hi
            sta work_hi

            ldx #$00
-           lda work_hi
            cmp #>10000
            bcc +
            bne ++
            lda work_lo
            cmp #<10000
            bcc +
++          lda work_lo
            sec
            sbc #<10000
            sta work_lo
            lda work_hi
            sbc #>10000
            sta work_hi
            inx
            jmp -
+           stx score_digits + 0

            ldx #$00
-           lda work_hi
            cmp #>1000
            bcc +
            bne ++
            lda work_lo
            cmp #<1000
            bcc +
++          lda work_lo
            sec
            sbc #<1000
            sta work_lo
            lda work_hi
            sbc #>1000
            sta work_hi
            inx
            jmp -
+           stx score_digits + 1

            ldx #$00
-           lda work_lo
            cmp #100
            bcc +
            sec
            sbc #100
            sta work_lo
            inx
            jmp -
+           stx score_digits + 2

            ldx #$00
-           lda work_lo
            cmp #10
            bcc +
            sec
            sbc #10
            sta work_lo
            inx
            jmp -
+           stx score_digits + 3

            lda work_lo
            sta score_digits + 4
            rts

draw_score:
            ldx #$00
-           lda score_digits,x
            ora #$30
            sta SCREEN + (ROW_SCORE * 40) + 8,x
            lda #COL_WHITE
            sta COLOUR + (ROW_SCORE * 40) + 8,x
            inx
            cpx #$05
            bne -
            rts

convert_streak:
            lda streak
            ldx #$00
-           cmp #10
            bcc +
            sec
            sbc #10
            inx
            jmp -
+           stx streak_tens
            sta streak_ones
            rts

draw_streak:
            lda streak_tens
            ora #$30
            sta SCREEN + (ROW_STREAK * 40) + 8
            lda streak_ones
            ora #$30
            sta SCREEN + (ROW_STREAK * 40) + 9
            lda #COL_WHITE
            sta COLOUR + (ROW_STREAK * 40) + 8
            sta COLOUR + (ROW_STREAK * 40) + 9
            rts

draw_crowd:
            jsr get_crowd_colour
            sta crowd_colour

            ldx #$00
            ldy crowd_meter
-           cpx #CROWD_MAX
            bcs +
            cpy #$00
            beq ++
            lda #$a0
            dey
            jmp +++
++          lda #$20
+++         sta SCREEN + (ROW_CROWD * 40) + 8,x
            lda crowd_colour
            sta COLOUR + (ROW_CROWD * 40) + 8,x
            inx
            jmp -
+           rts

get_crowd_colour:
            lda crowd_meter
            cmp #$05
            bcc +
            cmp #$0f
            bcc ++
            lda #COL_GREEN
            rts
++          lda #COL_YELLOW
            rts
+           lda #COL_RED
            rts
```
