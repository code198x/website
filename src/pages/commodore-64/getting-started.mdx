## What You Need

To develop for the C64, you need:

1. **A way to compile** - our Docker toolchain handles this
2. **An emulator** - runs your programs (install natively for best experience)

## Docker Toolchain (Recommended)

Our Docker image includes ACME assembler, petcat for BASIC, and build tools — everything needed to compile C64 programs.

<div class="tool-card">

### Quick Start

```bash
docker pull code198x/commodore-64
```

To compile a program:

```bash
docker run --rm -v "$(pwd)":/code code198x/commodore-64 \
  acme -f cbm -o game.prg game.asm
```

Your compiled `.prg` file appears in your current directory, ready to run.

</div>

## Installing the Emulator

We recommend **VICE**. Install it natively for smooth, responsive testing.

<div class="tool-card">

### Installing VICE

**macOS (Homebrew)**

```bash
brew install vice
```

**Linux**

```bash
# Ubuntu/Debian
sudo apt install vice

# Fedora
sudo dnf install vice
```

**Windows**

Download from [vice-emu.sourceforge.io](https://vice-emu.sourceforge.io/). Extract the ZIP and add the folder to your PATH, or run `x64sc.exe` directly.

</div>

The executable you'll use is `x64sc` — that's the accurate C64 emulator. (There's also `x64` which is faster but less accurate. Stick with `x64sc` for development.)

### First Run

Launch VICE to make sure it works:

```bash
x64sc
```

You should see the familiar C64 blue screen with `READY.` and a blinking cursor. Press `Alt+Q` (or `Cmd+Q` on macOS) to quit.

## Your First Program

Create a file called `hello.asm`:

```asm
            * = $0801

            ; BASIC stub: 10 SYS 2064
            !word nextline
            !word 10
            !byte $9e
            !text "2064", 0
nextline:   !word 0

start:
            ; Set border to blue
            lda #6
            sta $d020

            ; Infinite loop
-           jmp -
```

## The Workflow

Every change follows the same cycle:

1. **Edit** your `.asm` file in any text editor
2. **Compile** with `make`
3. **Run** with `make run`

### Using a Makefile

Create a `Makefile` in your project directory:

```makefile
# Commodore 64 Makefile
IMAGE = code198x/commodore-64
SRC   = game.asm
OUT   = game.prg

.PHONY: all run clean

all: $(OUT)

$(OUT): $(SRC)
	docker run --rm -v "$(PWD)":/code -w /code $(IMAGE) \
		acme -f cbm -o $(OUT) $(SRC)

run: $(OUT)
	x64sc $(OUT)

clean:
	rm -f $(OUT)
```

Now your workflow is simply:

```bash
make        # Compile
make run    # Compile and run in VICE
make clean  # Remove built files
```

You should see a blue border. Every lesson includes a working Makefile.

## Key Addresses

| Address | Purpose |
|---------|---------|
| $D020 | Border colour |
| $D021 | Background colour |
| $0400 | Screen memory start |
| $D800 | Colour memory start |
| $D400 | SID (sound) registers |
| $DC00 | CIA #1 (keyboard/joystick) |

## Alternative: Native Assembler

If you prefer not to use Docker, install ACME directly.

<div class="tool-card">

### Installing ACME

**macOS (Homebrew)**

```bash
brew install acme
```

**Linux**

```bash
# Ubuntu/Debian
sudo apt install acme

# Fedora
sudo dnf install acme-crossassembler
```

**Windows**

Download from [sourceforge.net/projects/acme-crossass](https://sourceforge.net/projects/acme-crossass/).

</div>

With native tools, compile directly:

```bash
acme -f cbm -o game.prg game.asm && x64sc game.prg
```
