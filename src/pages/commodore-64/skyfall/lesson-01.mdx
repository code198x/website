## Introduction

Welcome to your journey into Commodore 64 assembly programming! In this first lesson, we'll set up everything you need to develop games for the C64 on your modern computer.

By the end of this lesson, you'll have written your first assembly program and seen it run on an emulated C64.

## Installing the Tools

### The ACME Assembler

ACME is a powerful cross-assembler that converts your assembly code into machine code the C64 can run.

<div class="note">
<div class="note-title">💡 Note</div>
A cross-assembler runs on your modern computer but produces code for a different system (the C64).
</div>

**Installation steps:**
1. Download ACME from [website]
2. Install according to your OS
3. Verify with `acme --version`

### The VICE Emulator

VICE accurately emulates the C64 hardware, letting you test your programs without real hardware.

**Installation steps:**
1. Download VICE from [website]
2. Install the C64 emulator (x64sc)
3. Configure display and joystick settings

## Your First C64 Program

Let's write a simple program that changes the border color:

<div class="code-block">
<div class="code-block-header">hello.asm</div>

```asm
; My first C64 program
; Changes the border color to red

* = $0801                ; BASIC start address

; BASIC launcher (SYS 2061)
!byte $0c,$08,$0a,$00,$9e
!byte $32,$30,$36,$31    ; "2061" in ASCII
!byte $00,$00,$00

* = $080d                ; Our code starts here

start:
    lda #$02             ; Load red color value
    sta $d020            ; Store to border color register
    rts                  ; Return to BASIC
```
</div>

### Understanding the Code

Let's break down each line:

- `* = $0801` - Sets the assembly address to the BASIC start location
- `!byte` directives - Create a BASIC launcher that executes SYS 2061 ($080D)
- `* = $080d` - Our actual machine code starts here
- `lda #$02` - Load the value 2 (red) into the accumulator
- `sta $d020` - Store accumulator to memory address $D020 (border color)
- `rts` - Return to BASIC

## Building and Running

### Assembling the Code

Open your terminal and run:

```bash
acme -o hello.prg hello.asm
```

This creates `hello.prg`, a program file the C64 can load.

### Running in VICE

1. Start VICE (x64sc)
2. Drag and drop `hello.prg` onto the emulator window
3. Type `RUN` and press Enter
4. The border should turn red!

## The Development Cycle

Your typical workflow will be:

1. **Write** assembly code in your text editor
2. **Assemble** with ACME to create a PRG file
3. **Load** into VICE to test
4. **Debug** and refine
5. **Repeat** until perfect!

## New Concepts

### Opcodes Used in This Lesson

**lda #$xx** - Load Accumulator
- Loads a value into the accumulator (the A register)
- The # symbol means "immediate mode" - use the value directly
- Example: `lda #$93` puts the value $93 into A

**jsr $xxxx** - Jump to Subroutine
- Calls a routine at the specified address
- The routine runs, then returns to the next instruction
- Example: `jsr $ffd2` calls the KERNAL print routine

**rts** - Return from Subroutine
- Returns control to whoever called this routine
- In our case, returns to BASIC

### The Accumulator

The accumulator (A) is the 6502's primary working register. Most operations use it - loading values, doing math, and storing results all go through the accumulator.

## Memory Map Basics

The C64 has 64KB of addressable memory. Key locations we'll use:

| Address | Description |
|---------|-------------|
| `$0400-$07FF` | Screen memory (1000 bytes) |
| `$D000-$D3FF` | VIC-II chip (graphics) |
| `$D400-$D7FF` | SID chip (sound) |
| `$D800-$DBFF` | Color RAM |
