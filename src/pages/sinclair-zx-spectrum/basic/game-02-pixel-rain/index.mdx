## What You'll Build

Falling pixels creating patterns. Your first visual game using the PLOT command.

Coloured drops fall from the sky. They accumulate, creating patterns on the screen. This introduces Spectrum pixel graphics — the PLOT command, screen coordinates, and the eight INK colours that define Spectrum visuals.

## Skills You'll Master

- **PLOT command** — placing individual pixels
- **Screen coordinates** — 0-255 horizontal, 0-175 vertical
- **INK colours** — pixel colour control
- **Animation with PLOT** — continuous movement
- **Random positions** — varied placement
- **Simple timing loops** — controlling speed
- **Screen clearing strategies** — display management
- **Visual patterns** — aesthetic effects

Complete **Game 1: Guess Quest** first.
