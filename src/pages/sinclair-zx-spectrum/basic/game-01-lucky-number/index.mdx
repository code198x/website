## What You'll Build

The computer picks a secret number between 1 and 100. You guess. It tells you higher or lower. Keep guessing until you find it.

Simple, ancient, and a perfect first program.

## Why This Game?

Every concept has a purpose you can see immediately. `INPUT` is how the player guesses. `IF/THEN` is how the computer responds. `GO TO` is what keeps the game running. Nothing is abstract.

By the end of 8 units, you'll have written, edited, and run a complete interactive program — from scratch.

## What You'll Learn

- **PRINT** — putting text on screen
- **LET** — storing values in variables
- **INPUT** — asking the player a question
- **IF/THEN** — making decisions
- **GO TO** — loops
- **RND** — random numbers
- **REM** — comments

## Prerequisites

None. This is the very first game. If you've never written a line of code, start here.

## Time Investment

8 units at 60-90 minutes each. Roughly 8-12 hours total.
