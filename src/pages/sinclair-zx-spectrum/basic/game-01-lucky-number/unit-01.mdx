Over the next eight units you'll build a number guessing game. The computer picks a secret number, you guess, and it tells you higher or lower. Simple — but it covers everything you need to start programming.

This unit is even simpler than that. You're going to type one line of code and make the Spectrum do something.

## The Spectrum Keyboard

Before you type anything, you need to know how the Spectrum keyboard works. It's different from a modern computer.

When you switch on (or type `NEW`), the Spectrum starts in **K mode** — keyword mode. You can see this from the **K** cursor flashing in the bottom-left corner. In K mode, pressing a letter key doesn't type a single letter. It types a whole command. Press **P** and the Spectrum types `PRINT` for you. Press **R** and it types `RUN`.

After you type a command, the cursor changes to **L** — letter mode. Now keys type individual letters, the way you'd expect. The Spectrum switches between modes automatically as you type.

Numbers always type normally in either mode. And **Symbol Shift** combined with a key types symbols like `"`, `+`, `=`, and so on.

The cursor letter tells you which mode you're in. Watch it as you type — it'll make sense quickly.

## What Is a Program?

A program is a list of instructions that the computer follows in order. On the Spectrum, each instruction has a **line number** — a number at the start that tells the computer what order to run things in.

The Spectrum runs line 10 before line 20. Line 20 before line 30. The numbers don't have to be consecutive — gaps are fine. Most Spectrum programmers use multiples of 10, leaving room to insert lines later.

## Your First Line

Type this:

```basic
10 PRINT "Hello"
```

Here's how to type it:
1. Type **1** then **0** (numbers work normally in any mode)
2. Type a **space**
3. Press **P** — the Spectrum types `PRINT` for you (you're in K mode)
4. Press **Symbol Shift + P** to type the opening `"`
5. The cursor changes to **L** — now type **H**, **e**, **l**, **l**, **o**
6. Press **Symbol Shift + P** again for the closing `"`
7. Press **ENTER** to store the line

That's it. One line. Here's what each part means:

- **10** — the line number. This is line 10, the first instruction.
- **PRINT** — a command that tells the Spectrum to display something on screen.
- **"Hello"** — the text to display. The quotation marks tell the Spectrum this is text, not a command.

The text between the quotation marks is called a **string**. You can put anything you like in there — letters, numbers, spaces, punctuation. The Spectrum prints it exactly as written.

## Run It

Type `RUN` and press **ENTER**. (In K mode, press **R** — the Spectrum types `RUN` for you.)

![Hello on the Spectrum](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-01-hello-spectrum/hello.png)

The Spectrum prints `Hello` and then `0 OK, 10:1` — its way of saying "I finished, everything went fine." The `10:1` means it stopped at line 10, statement 1.

You've just written and run a program.

## Change the Message

Your program is still in memory. You can change it without retyping the whole thing. Type this and press ENTER:

```basic
10 PRINT "I am a ZX Spectrum"
```

This replaces line 10 — same line number, new content. Type `RUN` again and the Spectrum prints the new message instead.

Try a few more. Put your name in there. Put a rude word in there — nobody's watching. The important thing is that you can see the connection: you change the text between the quotes, and the output changes.

## Line Numbers Control Order

What happens if you type line 20 before line 10? Try it. Type `NEW` (press **N** in K mode) to clear the program, then:

```basic
20 PRINT "I am a ZX Spectrum"
10 PRINT "Hello"
```

Type `RUN`. The output is the same: "Hello" first, then "I am a ZX Spectrum." The Spectrum doesn't care what order you type the lines in. It always runs them in line number order — lowest first.

This is why line numbers matter. They're not just labels. They're the sequence.

## Try This

**Three lines.** Add a line 30 with a third message. What does the output look like?

**Big gaps.** What if your lines are numbered 10, 500, and 9000? Does it still work? (Yes. The Spectrum doesn't mind gaps.)

**Same line number.** Type two different lines both numbered 10. What happens? (The second one replaces the first. Each line number can only hold one instruction.)

## What You've Learnt

- **PRINT** — displays text on screen
- **Strings** — text between quotation marks, printed exactly as written
- **Line numbers** — every line starts with a number; the Spectrum runs them in order, lowest first
- **RUN** — executes the program from the beginning
- **K mode and L mode** — the Spectrum keyboard switches between keywords and individual letters
- **Replacing a line** — typing a new line with the same number overwrites the old one
- **NEW** — clears the current program from memory
