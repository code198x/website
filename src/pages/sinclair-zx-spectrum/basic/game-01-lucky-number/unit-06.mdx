The program gives the right feedback — too high, too low, correct — but it only lets you guess once. After one guess it ends. You have to type `RUN` to try again.

A real game keeps going. Guess wrong? Try again. Guess wrong again? Try again. Keep going until you find it.

You need a way to make the program jump back to the INPUT line. That's `GO TO`.

## Jumping Back

`GO TO` tells the Spectrum to jump to a specific line number instead of continuing to the next line. Try this:

Run it.

![Screen filled with Hello](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-06-play-again/goto-simple.png)

The screen fills with `Hello`. The Spectrum prints "Hello" on line 10, then line 20 sends it back to line 10, which prints "Hello" again, which sends it back to line 10... forever.

This is a **loop** — a section of code that runs over and over. This particular loop never stops. It keeps printing "Hello" until the screen fills up and the Spectrum asks `scroll?`.

Press any key to let it continue, or press **BREAK** (Caps Shift + Space) to stop the program.

## An Infinite Loop Is Too Much

An endless loop is useful sometimes, but the guessing game shouldn't loop forever. It should loop *until the player guesses correctly*, then stop.

You need two things: `GO TO` to create the loop, and `STOP` to break out of it when the guess is right.

![A play session showing Too high, Too low, Correct](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-06-play-again/loop.png)

The game works. Each wrong guess prints feedback and loops back to ask again. When you guess correctly, it prints "Correct!" and stops.

Here's how the new lines work:

- **Line 40** — `IF g = n THEN STOP` — if the guess is correct, stop the program. This line runs *after* line 30 has already printed "Correct!", so the player sees the message before the program ends.
- **Line 70** — `GO TO 20` — jump back to line 20 and ask for another guess. This line only runs if the guess was wrong — because a correct guess hits `STOP` on line 40 first.

The flow looks like this:

1. Line 10 sets the secret number (once, at the start)
2. Line 20 asks for a guess
3. Lines 30-60 check the guess and print the right message
4. If correct, line 40 stops the program
5. If wrong, line 70 jumps back to line 20
6. Back to step 2

## Why GO TO 20, Not GO TO 10?

The loop jumps to line 20, not line 10. If it jumped to line 10, the program would run `LET n = 7` again every time around the loop. That wouldn't cause a problem *now* — the number doesn't change — but in the next unit you'll replace line 10 with a random number. If the loop included line 10, the secret number would change after every guess. That's not a game; that's chaos.

By jumping to line 20, the secret number is set once at the start. The loop only repeats the guessing part.

## STOP and BREAK

`STOP` is a command you put in your program. When the Spectrum reaches a `STOP` line, it ends the program and prints `9 STOP statement` at the bottom of the screen.

`BREAK` is what *you* press (Caps Shift + Space) to interrupt a running program from outside. You'll need BREAK when you accidentally write an infinite loop that has no STOP.

Both stop the program, but STOP is planned — it's part of the game logic. BREAK is an emergency exit.

## Try This

**Change the secret number.** Set `n` to 50 and play the game. How many guesses does it take? Try to be efficient — if the number is between 1 and 100, start with 50, then narrow it down.

**Infinite INPUT.** Try `10 INPUT "Say something: "; a$` followed by `20 PRINT a$` followed by `30 GO TO 10`. The program becomes a conversation — it keeps asking and repeating whatever you type. Press BREAK to escape.

**What happens without STOP?** Remove line 40 from the game. Even when you guess correctly, the program loops back and asks again. There's no way out except BREAK. That's why `STOP` matters.

## What You've Learnt

- **GO TO** — jumps to a specific line number (two words on the Spectrum, not GOTO)
- **Loops** — `GO TO` pointing backwards creates a loop that repeats
- **STOP** — ends the program from inside the code
- **BREAK** — ends the program from the keyboard (Caps Shift + Space)
- **Loop placement** — jump to line 20 (not 10) to avoid re-running setup code
- **The game loop** — guess, check, feedback, repeat until correct
