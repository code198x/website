The game is too predictable — same speed, same word difficulty. Add levels. Every 10 completed words, the level increases: words fall faster and get longer.

## How It Works

**Line 70** adds two new variables: `LET v = 1` (level) and `LET c = 0` (words completed in this level).

**Lines 100-120** select words based on level:

```
100 IF v <= 2 THEN LET n = INT (RND * 20) + 1
110 IF v = 3 OR v = 4 THEN LET n = INT (RND * 20) + 16
120 IF v >= 5 THEN LET n = INT (RND * 15) + 36
```

| Level | Word indices | Lengths |
|-------|-------------|---------|
| 1-2 | 1-20 | 3 letters |
| 3-4 | 16-35 | 3-4 letters |
| 5+ | 36-50 | 5-6 letters |

The ranges overlap slightly — some 3-letter words appear at higher levels too. This prevents abrupt jumps in difficulty.

**Line 380** handles level progression:

```
380 IF c >= 10 THEN LET v = v + 1: LET c = 0: LET s = s - 5: IF s < 5 THEN LET s = 5
```

Every 10 words: increment the level, reset the word counter, reduce the speed threshold by 5. The `IF s < 5` prevents the speed from becoming impossibly fast.

## Two Difficulty Axes

The game gets harder in two ways at once:

1. **Speed** — the fall threshold decreases (30 → 25 → 20 → 15 → 10 → 5)
2. **Word length** — longer words require more keypresses

| Level | Speed | Word length |
|-------|-------|-------------|
| 1 | 30 | 3 |
| 2 | 25 | 3 |
| 3 | 20 | 3-4 |
| 4 | 15 | 3-4 |
| 5 | 10 | 5-6 |

## Try This

**Show level up.** When the level changes, flash a message: `PRINT AT 10, 8; INK 4; BRIGHT 1; "LEVEL "; v; "!"`. Pause briefly, then erase it.

**Custom word list.** Change the DATA words to a theme — animals, colours, food. The game mechanics stay the same; only the content changes.

## What You've Learnt

- **Level progression** — track words completed, advance at thresholds
- **Variable difficulty** — speed and content change together
- **Word selection by level** — different index ranges for different levels
- **Speed floor** — prevent impossibly fast gameplay
