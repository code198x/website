## Word Selection by Level

The pick-word subroutine selects from different parts of the word list:

```
1110 IF v <= 2 THEN LET n = INT (RND * 20) + 1
1120 IF v = 3 OR v = 4 THEN LET n = INT (RND * 20) + 16
1130 IF v >= 5 THEN LET n = INT (RND * 15) + 36
```

| Level | Indices | Word lengths |
|-------|---------|-------------|
| 1-2 | 1-20 | 3 letters |
| 3-4 | 16-35 | 3-5 letters |
| 5+ | 36-50 | 5-7 letters |

## Scoring

Each completed word scores 1 point. Five in a row triggers a streak bonus of 5 extra points. The game-over screen rates the player:

| Words | Message |
|-------|---------|
| 30+ | "Word worm master!" |
| 15-29 | "Well done!" |
| 0-14 | "Better luck next time!" |

## The Game Loop

```
250 LET t = t + 1           ← increment counter
260 IF t < s THEN GO TO 300 ← not time to move yet
270 GO SUB 800              ← move word down
280 IF r >= 19 THEN GO SUB 900  ← missed?
290 LET t = 0               ← reset counter
300 PRINT AT r, 12; INK 6; a$  ← draw word
310 LET k$ = INKEY$         ← check keyboard
320 IF k$ = "" THEN GO TO 250  ← no key, loop
330 GO SUB 700              ← handle keypress
340 GO TO 250               ← loop
```

Counter, move, check, input, repeat. Every game loop follows this pattern.

## Try This
