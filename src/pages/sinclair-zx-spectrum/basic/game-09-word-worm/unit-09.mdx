The game needs consequences. If the word reaches the bottom, it counts as a miss. Three misses and the game is over.

## How It Works

**Line 70** initialises the miss counter: `LET m = 0`.

**Lines 350-430** handle a missed word:

```
360 PRINT AT r - 1, 12; INK 2; a$
370 LET m = m + 1
380 BEEP 0.2, -5
```

The word flashes red at the bottom, the miss counter increments, and a low tone plays. After a brief pause, the word is erased and a new one begins.

**Line 420** checks for game over:

```
420 IF m >= 3 THEN GO TO 450
```

Three misses ends the game. The game-over screen shows the final score.

## Three Lives

The miss counter `m` works like inverse lives. You start with 0 misses. Each missed word adds 1. At 3, the game ends.

| Misses | Status |
|--------|--------|
| 0 | Full health |
| 1 | Warning |
| 2 | Last chance |
| 3 | Game over |

## Sound Feedback

The miss BEEP (`BEEP 0.2, -5`) is low and long — the opposite of the short, high completion BEEP. The player hears the difference immediately.

## Try This

**Five lives.** Change the limit to 5: `IF m >= 5`. More forgiving, especially for beginners.

**Flash warning.** When `m = 2`, change the border colour to red: `IF m = 2 THEN BORDER 2`. Visual urgency.

## What You've Learnt

- **Miss tracking** — counter increments on failure
- **Three-strike rule** — game over after a fixed number of misses
- **Failure feedback** — red text and low BEEP
- **Two exit paths** — complete words (score) or reach the bottom (miss)
