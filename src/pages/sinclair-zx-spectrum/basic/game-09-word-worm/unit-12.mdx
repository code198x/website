## How It Works

**Lines 100-110** create tracking arrays:

```
100 DIM y(2)
110 DIM q(2)
```

`y(i)` stores the row position of word `i`. `q(i)` stores which word from the main list it is. With 2 slots, two words can fall at once.

**Lines 240-290** move all active words in a single loop:

```
240 FOR i = 1 TO h
250 IF y(i) > 1 THEN PRINT AT y(i), i * 10; "       "
260 LET y(i) = y(i) + 1
270 IF y(i) >= 19 THEN GO TO 500
280 PRINT AT y(i), i * 10; INK 6; w$(q(i))(1 TO l(q(i)))
290 NEXT i
```

Each word is drawn at a different column (`i * 10`), so they don't overlap.

**The active word** is always word 1 — the one the player is typing. The player types the first word, and when it's completed, a new word takes its slot.

## Parallel Tracking

To manage multiple objects, you need parallel arrays:

| Array | Purpose |
|-------|---------|
| `y(i)` | Row position of word i |
| `q(i)` | Index into the main word list |

The same pattern works for enemies, bullets, coins — any collection of similar objects moving independently.

## Simplification

This version keeps the typing focused on one word at a time. The second word falls but isn't typed — it adds visual pressure. The player must finish the current word before the second one reaches the bottom.

## Try This

**Type either word.** Compare the keypress against both words. The player can choose which one to type first — whichever is falling fastest.

**Three words.** Change `DIM y(3)` and `DIM q(3)`. Spawn a third word at higher levels.

## What You've Learnt

- **Object arrays** — parallel arrays to track multiple moving things
- **Loop-based movement** — one FOR loop moves all objects
- **Column separation** — placing objects at different screen positions
- **Visual pressure** — additional objects create urgency
