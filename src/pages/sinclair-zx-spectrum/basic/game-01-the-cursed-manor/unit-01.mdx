## How It Works

### Setting the Stage

```basic
10 BORDER 0: PAPER 0: INK 7: CLS
```

Four commands on one line, separated by colons. `BORDER 0` turns the screen border black. `PAPER 0` sets the background colour to black. `INK 7` sets the text colour to white. `CLS` clears the screen — filling it with the current PAPER colour.

The Spectrum has eight colours, numbered 0 to 7:

| Number | Colour  |
|--------|---------|
| 0      | Black   |
| 1      | Blue    |
| 2      | Red     |
| 3      | Magenta |
| 4      | Green   |
| 5      | Cyan    |
| 6      | Yellow  |
| 7      | White   |

### Positioning Text

```basic
20 PRINT AT 8,8; INK 6;"THE CURSED MANOR"
```

`PRINT AT row,column` places text at a specific position on screen. The Spectrum screen is 24 rows tall and 32 columns wide. Row 0 is the top, column 0 is the left edge.

`INK 6` changes the text colour to yellow — but only for this PRINT statement. The semicolons chain everything together on the same line.

To centre text, calculate the starting column: `(32 - length) / 2`. "THE CURSED MANOR" is 16 characters, so `(32 - 16) / 2 = 8`.

### Sound

```basic
50 BEEP 0.5,0: BEEP 0.3,-5: BEEP 0.8,-12
```

`BEEP duration,pitch` plays a note through the Spectrum's speaker. Duration is in seconds. Pitch is in semitones relative to middle C — 0 is middle C, negative values go lower, positive values go higher.

Three descending notes: middle C for half a second, five semitones down for 0.3 seconds, then a low note for 0.8 seconds. Simple, but it sets a mood.

### Waiting for Input

```basic
60 IF INKEY$="" THEN GO TO 60
```

`INKEY$` checks the keyboard. If no key is pressed, it returns an empty string. This line creates a loop: keep checking, keep waiting, until someone presses something.

`GO TO 60` jumps back to the same line. The program spins here until a key is pressed, then falls through to line 70.

### Colour Within Text

```basic
220 PRINT INK 2;"The front door locks behind"
```

`INK 2` before the text changes just this line to red. The rest of the program stays white (INK 7, set on line 10). You can change ink colour mid-PRINT, or set it for a whole line like this.

Red for danger. The door is locked. You're trapped.

## Try This

**Change the colours.** Replace `INK 6` on line 20 with `INK 3` for magenta, or `INK 4` for green. Which feels right for a horror story?

**Change the sound.** Try `BEEP 1,12` for a high note, or `BEEP 2,-24` for a deep rumble. Experiment with the pitch values.

**Add a line.** Between lines 200 and 210, add:

```basic
205 PRINT "None of them breathe."
```

Run it again. One extra sentence changes the atmosphere.

## What You've Learnt

- **BORDER, PAPER, INK** — the three colour commands that control the Spectrum's display
- **CLS** — clears the screen to the current PAPER colour
- **PRINT AT** — positions text anywhere on the 24×32 character grid
- **BEEP** — plays notes with duration (seconds) and pitch (semitones from middle C)
- **INKEY$** — reads the keyboard without waiting for ENTER
- **GO TO** — jumps to a line number, creating loops
- **Colons** — multiple commands on one line, separated by `:`
- **INK within PRINT** — changing colour for a single line of output
