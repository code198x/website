## What You'll Build

Memory/puzzle game with UDG tiles. Find matching pairs against a friend or the clock.

Cards face down, each hiding a custom UDG symbol. Turn two over — do they match? This game uses the full UDG character set, creates proper timing with PEEK (23672), and adds two-player competition.

## Skills You'll Master

- **Full UDG character set** — 21 custom characters
- **Two-dimensional arrays** — grid storage
- **Game state management** — revealed/hidden tracking
- **Turn-based mechanics** — alternating play
- **Match detection** — pair finding
- **Timer using PEEK** — reading system clock
- **Two-player competitive** — multiplayer mode
- **Visual polish** — presentation quality
