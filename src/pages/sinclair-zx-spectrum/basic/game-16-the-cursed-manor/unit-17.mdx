Phase 2 begins. The manor has rooms and a cat, but nothing to pick up. Items transform a walking simulator into a game. The first item is a silver key — it sits in the library, waiting to be found. TAKE KEY picks it up. Later, it will unlock the tower door.

## Item State

Every item needs three pieces of information: its name, its current location (a room number, or 0 if carried, or -1 if nowhere), and whether the player has seen it described. An array tracks each property.

## How It Works

**Lines 30-32** dimension the item arrays. `DIM i$(6,20)` stores item names. `DIM il(6)` stores item locations — the room number where each item currently sits. `DIM ic(6)` will track carried status (0 = not carried, 1 = carried).

**Lines 83-84** set up the first item. `LET i$(1) = "silver key"`. `LET il(1) = 3` places it in room 3 (the library). The remaining five items are initialised in later units.

**Lines 270-280** check for items in the current room during display. A loop runs through all items; if `il(i) = r` and `ic(i) = 0`, the item is here and not carried. The game prints "There is a silver key here." in yellow ink.

**Lines 550-580** handle the TAKE command. When the player types "TAKE KEY", the code searches the item array for an item whose name contains "KEY". If found and in the current room, `ic(i)` is set to 1 and `il(i)` is set to 0. The game prints "You pick up the silver key."

If the item is not in the room, the game prints "You do not see that here." If the item does not exist, "You cannot take that."

## Try This

**Find the key.** Walk to the library and confirm "There is a silver key here" appears. Type TAKE KEY and confirm the success message. Leave and return — the key should no longer be mentioned.

**Try taking something that is not there.** Type TAKE KEY in the entrance hall. The error message should appear. Try TAKE NONSENSE — a different error for unknown items.

**Add a second item.** Place a "dusty lantern" in the cellar (room 15). Follow the same pattern: add it to the arrays, set its location, and test TAKE LANTERN.
