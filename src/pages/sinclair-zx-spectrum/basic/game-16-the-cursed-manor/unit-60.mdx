Experienced text adventure players expect shortcuts. Typing "N" instead of "GO NORTH" saves time and reduces frustration. Single-letter abbreviations for the most common commands make the game faster to play without removing the full command syntax.

## The Abbreviation Table

Before the parser splits the input into verb and noun, check for single-letter abbreviations. If the entire input is one character, expand it to the full command. "N" becomes "GO NORTH". "I" becomes "INVENTORY". "L" becomes "LOOK".

## How It Works

**Lines 305-315** run the abbreviation check before the parser. If `LEN c$ = 1`, the code checks the character against a list:

| Input | Expands To |
|-------|-----------|
| N | GO NORTH |
| S | GO SOUTH |
| E | GO EAST |
| W | GO WEST |
| U | GO UP |
| D | GO DOWN |
| I | INVENTORY |
| L | LOOK |
| X | EXAMINE |
| H | HELP |

**X is special.** "X" alone means nothing, but "X KEY" should mean "EXAMINE KEY". The abbreviation only expands "X" to "EXAMINE" when followed by more text. `IF LEN c$ = 1 AND c$ = "X"` does nothing — but `IF c$(1) = "X" AND LEN c$ > 1` could replace "X " with "EXAMINE " at the start of the string.

**Lines 308-310** handle the expansion. The original `c$` is replaced with the full command string. The parser then processes it normally — it never knows an abbreviation was used.

**The abbreviation check runs before synonym replacement.** This means abbreviations take the highest priority. "N" always means "GO NORTH", even if someone adds "N" as a synonym for something else.

**Update the HELP screen** and the instructions page to mention abbreviations. Players cannot use shortcuts they do not know about.

## Try This

**Navigate with single letters.** Type N, S, E, W, U, D to move around the manor. The game should respond exactly as if you typed the full command.

**Mix abbreviations and full commands.** Type N, then GO SOUTH, then E, then GO WEST. Both forms should work seamlessly. The parser does not care how the input arrived.

**Test X with a noun.** Type "X KEY" and "X PORTRAIT". Both should trigger EXAMINE. Type "X" alone — the game should ask "Examine what?" or give a generic response, not crash.
