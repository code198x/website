Players will type GET instead of TAKE, GRAB instead of TAKE, PICK UP instead of TAKE. A rigid parser that only accepts exact commands frustrates players. A synonym table maps alternative words to the commands your game understands, making the parser feel more intelligent without adding complexity to the command handlers.

## The Synonym Approach

Before processing a command, scan the input for known synonyms and replace them with canonical words. "GET KEY" becomes "TAKE KEY" before the command handler sees it. "GRAB LANTERN" becomes "TAKE LANTERN". The command handlers only need to check for one word per action.

## How It Works

**Lines 9200-9220** store synonym pairs in DATA statements. Each pair is a synonym followed by its canonical replacement: "GET", "TAKE", "GRAB", "TAKE", "PICK UP", "TAKE", "PUT DOWN", "DROP", "LEAVE", "DROP", "WALK", "GO", "RUN", "GO", "INSPECT", "EXAMINE", "SEARCH", "EXAMINE", "CHECK", "EXAMINE".

**Lines 150-170** read the synonym table into arrays at startup. `DIM sy$(20,10)` for synonyms, `DIM sc$(20,10)` for their canonical forms. A counter `ns` tracks how many pairs exist.

**Lines 320-340** run the synonym replacement before command processing. For each synonym pair, the code checks whether the input string starts with or contains the synonym. If found, it replaces the synonym with the canonical word. The replacement happens in place — `c$` is modified before any command handler sees it.

**Order matters.** "PICK UP" must be checked before "PICK" to avoid partial matches. Longer synonyms go first in the table. The code processes them in order, and the first match wins.

## Try This

**Test every synonym.** Type GET KEY, GRAB KEY, PICK UP KEY, and TAKE KEY. All four should work identically. Do the same for DROP and EXAMINE synonyms.

**Add your own synonyms.** Players might type LOOK AT instead of EXAMINE, or ENTER instead of GO. Add these to the DATA table and test them.

**Handle LOOK synonyms carefully.** LOOK is both a standalone command and part of LOOK AT. Make sure "LOOK AT KEY" triggers EXAMINE KEY, while plain "LOOK" still triggers the room description. The order of synonym checks determines which wins.
