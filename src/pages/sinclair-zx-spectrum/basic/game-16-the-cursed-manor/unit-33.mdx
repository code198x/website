Phase 3 begins. The manor has rooms, items, guests, and a parser. Now the puzzles arrive. The first is simple: the tower door is locked, and the silver key unlocks it. UNLOCK DOOR (or USE KEY) while carrying the key and standing at the tower base opens the way. This establishes the pattern for all puzzles — have the right item, be in the right place, use the right command.

## Puzzle Logic

A puzzle is a conditional state change. Check prerequisites (right room, right item, right command), then change the game state (unlock the door). The lock flag system from unit 9 already handles the state — all you need is the trigger.

## How It Works

**Lines 1300-1340** handle the UNLOCK verb. The handler checks three conditions:
1. Is the player at the tower base (room 13)?
2. Is the player carrying the silver key (`ic(1) = 1`)?
3. Is the tower still locked (`lk(14) = 1`)?

If all three are true, `lk(14)` is set to 0, and the game prints "You turn the silver key in the lock. The mechanism clicks and the door swings open." A satisfying sound effect plays — a low-to-high BEEP sequence suggesting a lock opening.

**If the door is already unlocked:** "The door is already open."

**If the player lacks the key:** "You need something to unlock this door." The message hints without naming the item directly.

**If the player is in the wrong room:** "There is nothing to unlock here."

**The tower room** (room 14) is now accessible. Its DATA line already has exits defined — they were just unreachable behind the lock. No data changes are needed; only the flag changes.

## Try This

**Solve the puzzle.** Find the key in the library, carry it to the tower base, and type UNLOCK DOOR. Walk up the stairs to confirm the tower room is accessible.

**Try without the key.** Go to the tower base without the key and type UNLOCK DOOR. The hint message should appear. Then get the key and try again.

**Try in the wrong room.** Type UNLOCK DOOR in the library. The "nothing to unlock" message should appear. Puzzle commands should always fail gracefully outside their intended context.
