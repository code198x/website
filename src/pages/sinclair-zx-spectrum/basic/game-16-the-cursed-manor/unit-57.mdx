A silent manor feels abandoned. A noisy one feels alive — or haunted. Random ambient events fire occasionally between turns: a floorboard creaks, a cold draft blows through the room, a clock chimes in the distance, a curtain moves with no wind. These events have no game effect but they maintain atmosphere.

## Ambient Event System

Each turn, after the NPC phase, there is a chance that an ambient event fires. The event is selected randomly from a list. Some events are generic (they work anywhere). Some are location-specific (wind only in the tower, dripping only in the cellar).

## How It Works

**Lines 9800-9830** store ambient events in DATA statements. Each entry is a message and an optional room restriction (0 means any room):

- "A floorboard creaks somewhere nearby.", 0
- "A cold draft touches the back of your neck.", 0
- "You hear a clock chime in the distance.", 0
- "A shadow moves at the edge of your vision.", 0
- "The wind moans through the tower.", 14
- "Water drips steadily in the darkness.", 15
- "A candle flickers and nearly goes out.", 7
- "Something scratches inside the walls.", 0
- "The curtains billow without any breeze.", 0
- "You smell lavender, faint and old.", 9

**Lines 2600-2640** run the ambient event system. A 20% chance each turn (`IF RND < 0.2`). If triggered, the code selects a random event. If the event has a room restriction and the player is not in that room, it picks again (up to three tries, then skips). The message prints in dim white (`INK 7; BRIGHT 0`), visually distinct from game events.

**Before and after the ritual** — the ambient events change. Before the ritual, events feel menacing: shadows, cold, scratching. After the ritual (`rf = 1`), some events are replaced with warmer ones: "Sunlight begins to creep through the windows.", "The air feels less heavy.", "You hear birdsong outside." The manor is healing.

## Try This

**Play for 20 turns.** Note which ambient events fire. They should feel varied and not overly frequent. One event every 4-5 turns is about right.

**Add room-specific events.** The garden could have "An owl hoots from the trees." The library could have "A book falls from a shelf with a thud." The more specific events you add, the more each room feels unique.

**Test the post-ritual atmosphere.** After completing the ritual, the events should shift in tone. The manor stops being threatening and starts being peaceful. This tonal shift reinforces the narrative — the curse is broken, the place is safe.
