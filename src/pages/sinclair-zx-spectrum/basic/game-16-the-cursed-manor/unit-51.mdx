Phase 1 added illustrations for the entrance hall, library, kitchen, garden, and tower. Fifteen rooms remain unillustrated. This unit fills the gaps — every room gets a drawing. The illustrations do not need to be elaborate, but each should be recognisable and distinct.

## Drawing Every Room

Each room's illustration should capture its defining feature. The corridor is long and narrow. The drawing room has a fireplace. The cellar has barrels. The chapel has an arched window. Focus on one or two elements per room — simple shapes that read clearly at the Spectrum's resolution.

## How It Works

**Lines 910-1990** contain illustration subroutines for all 20 rooms. Each subroutine uses PLOT and DRAW (and occasionally CIRCLE) to create a simple line drawing in the top portion of the screen.

Key illustrations:

- **Corridor (room 2):** Perspective lines converging to a point, doorways on each side
- **Drawing room (room 7):** A fireplace with a mantelpiece, the portrait above it
- **Study (room 10):** A desk with books and a window behind it
- **Cellar (room 15):** Stone arches with barrels beneath them
- **Chapel (room 19):** A pointed arch window with broken tracery
- **Sealed chamber (room 20):** Hexagonal walls with the glowing niche

**Consistent style** — all illustrations use cyan ink (INK 5) on a black background. The line weight is uniform. The composition places the key element at centre. This visual consistency ties the illustrations together as a set.

**Drawing time** — each illustration takes a fraction of a second to render. The PLOT and DRAW commands execute quickly on the Spectrum. The player sees the illustration appear almost instantly, then the text prints below.

## Try This

**Walk every room.** Visit all 20 rooms and check each illustration. Does each one look recognisable? Does any room's drawing conflict with its description?

**Improve the weakest drawing.** Pick the illustration you like least and redraw it. Sometimes moving an element a few pixels, or adding one line, transforms a confusing shape into a clear image.

**Test without illustrations.** Comment out the illustration calls and play the game. Notice how much the drawings add. Text adventures work without graphics, but illustrations provide instant spatial context.
