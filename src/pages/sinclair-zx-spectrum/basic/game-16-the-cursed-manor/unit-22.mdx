The item system handles one item. Now populate it with all six. Each item has a starting room, a name, and an examine description. Each serves a purpose in the puzzle chain — the key unlocks the tower, the lantern lights the cellar, the grimoire contains the ritual, the amulet focuses the curse-breaking, the tinderbox lights the cold fire, and the portrait reveals the true name.

## Six Items, Six Purposes

Every item in a well-designed text adventure earns its place. If an item has no use, it wastes the player's time. If a puzzle needs an item that does not exist, it is unsolvable. Design the items and puzzles together.

**Lines 83-88** initialise all six items with names and starting locations:

**The amulet** starts in the sealed chamber (room 20), which is locked. The player cannot reach it until they solve an earlier puzzle. Items behind locked doors create a natural progression.

**Lines 86-91** set examine descriptions for all six items. Each reveals a clue:
- The key has a crown engraving (hints at royalty)
- The lantern is unlit but has oil (needs the tinderbox)
- The grimoire is written in strange symbols (needs interpretation)
- The amulet pulses with cold light (connected to the curse)
- The tinderbox is dry and ready to strike (pairs with the lantern)
- The portrait shows a stern-faced woman with the name "ELARA" (the true name)

## Try This

**Find every item.** Walk the manor and locate all five reachable items (the amulet is locked away). Take each one, examine it, and note the clue.

**Examine everything.** Read each examine description and think about how the items might work together. The clues point toward a chain: key unlocks tower, grimoire reveals ritual, tinderbox lights lantern, portrait reveals name, amulet focuses power.

**Check item placement.** Are the items spread across the map? Do any two items sit in the same room? Good item placement rewards exploration — the player should visit many rooms to find everything.
