Items, guests, scenery, and the cat — four different systems that all need to show up in room descriptions. This unit organises them into a consistent display order. The room description comes first, then guests, then items on the floor, then the cat. Each category uses a distinct colour so the player can scan quickly.

## Display Order

A predictable display structure helps the player find information. They learn that character descriptions always appear after the room text, and items always appear after characters. Consistency reduces cognitive load.

## How It Works

**Lines 200-300** restructure the display routine into clear sections:

1. **Room name** (line 210) — bright white, always first
2. **Illustration** (line 215) — if the room has one
3. **Room description** (lines 220-225) — full or brief based on visit flag
4. **Guests** (lines 250-260) — green ink, one line per guest present
5. **Items** (lines 270-280) — yellow ink, one line per item on the floor
6. **The cat** (lines 285-290) — cyan ink, if present
7. **Exits** (lines 295-300) — white, always last

**Colour coding** makes each category instantly recognisable. Green for people, yellow for objects, cyan for animals, white for geography. The player does not need to read every word — the colour tells them what kind of information each line contains.

**Empty categories are silent.** If no guests are in the room, the guest section prints nothing. No blank line, no "Nobody is here." The display stays clean and compact.

**A separator line** of dashes sits between the description and the contents list. This visual break signals the transition from narrative text to game-state information.

## Try This

**Check a busy room.** Go to a room with a guest, an item, and the cat (arrange this by dropping items). Verify the display order is correct and the colours are distinct.

**Check an empty room.** Go to a room with no guests, no items, and no cat. The display should show only the room name, description, and exits. No extra blank lines.

**Adjust colours.** If any colour combination is hard to read on your screen, experiment with alternatives. Green on black works well; green on white does not. Test with both PAPER settings.
