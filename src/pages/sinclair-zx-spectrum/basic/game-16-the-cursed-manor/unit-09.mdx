Not every door should open freely. The tower room is locked. The sealed chamber is hidden. Locked doors create goals — the player needs to find keys, solve puzzles, or discover secrets to progress. This unit adds a lock system that blocks movement under certain conditions.

## Lock Flags

A lock is a simple flag: `lk(r)` is 1 if room `r` is locked, 0 if it is open. Before moving to a room, the code checks the lock. If locked, the game prints a message and refuses entry. When the player solves the right puzzle (in Phase 3), the flag changes to 0 and the door opens.

## How It Works

**Line 27** adds `DIM lk(20)` for lock flags. All rooms default to 0 (unlocked).

**Lines 80-82** set initial locks. `LET lk(14) = 1` locks the tower room. `LET lk(20) = 1` locks the sealed chamber. These are the only rooms locked at the start.

**Lines 400-410** modify the movement check. Before updating `r`, the code checks `lk(destination)`. If the destination is locked, it prints "That door is locked" and skips the move. The player stays in the current room.

**The lock message** varies by room. The tower prints "The door is locked — you need a key." The sealed chamber prints "The wall is solid — there must be a hidden mechanism." Different messages give different hints about how to open each one.

This system is intentionally simple. A single array of flags controls access. Unlocking a door means setting one value to 0. The complexity comes from the puzzles that determine when to flip the flag.

## Try This

**Try all locked doors.** Walk to the tower entrance and attempt to go up. Walk to where the sealed chamber would be and try every direction. Confirm the lock messages appear.

**Add a temporary unlock.** For testing, add a cheat command: if the player types "UNLOCK" then set all locks to 0. Remove this before the final game, but it is useful during development.

**Lock a third room.** Pick any room and lock it. Write a message that hints at how to open it. Locked doors without hints frustrate players; locked doors with hints motivate them.
