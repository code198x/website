Free guests do more than walk around. They talk to themselves, examine objects, react to the player's presence, and comment on the manor. These actions happen during the NPC turn — short messages that create the illusion of independent behaviour.

## Action Tables

Each guest has a set of possible actions stored in DATA statements. Each turn, if a guest is in the player's room and does not move, they might perform an action. A random selection from their action list produces varied behaviour.

## How It Works

**Lines 9500-9540** store action strings for each guest. The Colonel has: "The Colonel mutters about the cold.", "The Colonel examines a painting on the wall.", "The Colonel says, 'We must get to the bottom of this.'" The Maid has: "The Maid dusts a surface nervously.", "The Maid says, 'This house was never like this before...'" Each guest has 3-4 actions.

**Lines 2200-2230** select and display an action. If a free guest is in the player's room and did not move this turn, there is a 30% chance they perform an action. The code picks a random action from their list using `INT(RND * count) + 1` and prints it in green ink.

**Actions are atmospheric, not mechanical.** They do not change game state. The Colonel does not actually examine anything — he just appears to. The Maid does not actually clean — she just makes the gesture. These messages exist to make the guests feel alive.

**Room-specific actions** — some actions only make sense in certain rooms. The Colonel examining a painting only works in rooms with paintings. The code checks the guest's current room before selecting from a subset of context-appropriate actions. Generic actions ("mutters about the cold") work anywhere.

**Guest personality** shines through actions. The Colonel is authoritative and restless. The Maid is nervous and dutiful. Dr Hartley is curious and analytical. Lady Ashworth is composed but shaken. Mrs Pemberton is practical and worried. Each action set reflects these traits.

## Try This

**Spend time with each guest.** Stay in a room with a free guest and take 10 turns doing nothing (type WAIT). Observe their actions. Do they feel distinct from each other?

**Add a new action.** Give the Doctor an action specific to the library: "Dr Hartley pulls a book from the shelf and flips through it quickly." Context-specific actions are more memorable than generic ones.

**Test action frequency.** A 30% chance means roughly one action every three turns. Too frequent feels manic; too rare feels empty. Adjust the threshold and find the right balance.
