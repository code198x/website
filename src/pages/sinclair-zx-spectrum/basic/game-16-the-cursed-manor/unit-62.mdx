A program this large will have bugs. Some are obvious — a crash when you type an unexpected command. Some are subtle — a guest that never wakes, a score that counts wrong, a door that locks itself again. Systematic testing finds them all.

## Test Categories

Break testing into categories and work through each one methodically. Do not assume any system works correctly just because it worked once. Edge cases and interactions between systems are where bugs hide.

## How It Works

This unit is not about new code — it is about finding and fixing problems in existing code. The program includes fixes for bugs discovered during testing. Here are the categories to test:

**Movement testing.** Visit every room. Try every exit. Try every impossible direction. Check that locked doors refuse entry with the right message. Check that unlocked doors remain unlocked after leaving and returning.

**Item testing.** Take every item. Drop every item. Take items in different rooms. Drop items in different rooms. Fill your inventory to the carry limit. Try to take an item you are already carrying. Try to drop an item you are not carrying. Examine every item in every state.

**Guest testing.** Examine every frozen guest. Perform the ritual. Watch every guest wake (staggered timing). Talk to every free guest. Give items to every free guest. Examine waking guests. Examine free guests.

**Parser testing.** Type empty input. Type very long input (30+ characters). Type only spaces. Type numbers. Type commands in mixed case. Type unknown verbs. Type known verbs with unknown nouns. Type just a noun with no verb.

**Puzzle testing.** Solve every puzzle in the intended order. Solve them in a different order where possible. Try puzzle commands without prerequisites. Try the ritual with each prerequisite missing individually.

**NPC testing.** Watch the cat for 20 turns. Watch free guests for 20 turns. Check that distant events report the correct direction. Check that guests do not walk into locked rooms.

**Score testing.** Check the score at the start (should be 0). Check after visiting one room. Check after the ritual. Complete the game and verify the final score is correct.

## Try This

**Make a checklist.** Write down every test case from the categories above. Check each one off as you test it. When you find a bug, fix it and re-test the related category.

**Test the ending.** Complete the game and watch the ending sequence. Does the score display correctly? Do the guest names appear? Does the final message feel right?

**Play as a new player.** Pretend you have never seen the game. Follow the clues without prior knowledge. Can you solve every puzzle from the information the game provides? If not, a clue is too vague — rewrite it.
