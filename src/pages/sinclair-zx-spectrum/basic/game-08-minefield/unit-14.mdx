The game works, but white on white doesn't communicate well. Colour turns raw data into readable information — hidden cells look different from revealed ones, mines stand out from numbers, flags are unmistakable.

## How It Works

**Line 10** sets the black background: `BORDER 0: PAPER 0: INK 7: CLS`. Everything starts as white on black.

**Lines 170-250** use `INK 5` (cyan) for column and row headers. These guide the player without competing with the grid content.

**The draw subroutine** uses `INK` per cell type:

```
630 IF s(y, x) = 0 THEN PRINT AT y + 2, x * 2 + 1; INK 1; "."
640 IF s(y, x) = 1 AND m(y, x) = 0 THEN PRINT AT y + 2, x * 2 + 1; INK 5; "-"
650 IF ... THEN PRINT AT y + 2, x * 2 + 1; INK 6; m(y, x)
660 IF ... THEN PRINT AT y + 2, x * 2 + 1; INK 2; "*"
670 IF s(y, x) = 2 THEN PRINT AT y + 2, x * 2 + 1; INK 3; "F"
```

| Element | INK | Colour | Why |
|---------|-----|--------|-----|
| Hidden cell | 1 | Blue | Subtle, doesn't draw attention |
| Empty (0 neighbours) | 5 | Cyan | Safe, neutral |
| Number (1-8) | 6 | Yellow | Important information, stands out |
| Mine | 2 | Red | Danger, immediately visible |
| Flag | 3 | Green | Player action, distinct from data |
| Cursor | 4 | Green + BRIGHT | Current position, brightest element |

## Colour as Information

Without colour, the player has to read every character carefully. With colour, they can scan the grid at a glance:

- **Blue dots** — unexplored territory
- **Yellow numbers** — information to reason about
- **Green F** — their own markers
- **Red stars** — only visible on game over

The cursor uses `BRIGHT 1` to stand out even more. It's the only bright element on the grid, making it impossible to lose.

## Try This

**Colour per number.** Instead of all numbers in yellow, use `INK m(y,x)` — each count gets a different colour. 1 is blue, 2 is red, 3 is magenta, and so on. This matches classic Minesweeper conventions.

**Flash mines.** On game over, add `FLASH 1` to the mine display: `PRINT AT y+2, x*2+1; INK 2; FLASH 1; "*"`. The mines blink to draw attention.

## What You've Learnt

- **BORDER, PAPER, INK** — full control of the colour scheme
- **Per-element colouring** — different INK values for different cell types
- **Colour as communication** — visual hierarchy guides the player's eye
- **BRIGHT for emphasis** — makes the cursor stand out from everything else
