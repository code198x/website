## What You'll Build

Pong-style paddle game. Keyboard-controlled action using INKEY$ for real-time input.

A ball bounces. Paddles defend each side. React quickly or concede points. This introduces real-time gameplay in Sinclair BASIC — the INKEY$ function that makes action games possible.

## Skills You'll Master

- **INKEY$ polling** — real-time keyboard input
- **Real-time game loop** — continuous play
- **Ball movement** — PLOT-based animation
- **Paddle drawing** — DRAW command
- **Simple collision detection** — bounce logic
- **Score keeping** — tracking points
- **Two-player option** — competitive mode
- **Speed control** — game timing
