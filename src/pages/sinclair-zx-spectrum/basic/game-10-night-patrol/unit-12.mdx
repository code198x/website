One floor is a demo. Multiple floors make a game. Three floors of the building are defined in DATA, each with its own layout, guard route, objective position, and exit. Complete one floor and the next loads automatically.

## How It Works

**Line 30** initialises the game state. `v = 3` for lives, `e = 0` for score, `l = 1` for the current floor number.

**Line 40** sets `RESTORE 900` to position DATA reading at the first floor.

**Lines 60-90** load a floor. The loop reads 8 map rows into `m$()`, then reads all the floor's parameters in one line: player position, guard position, route string, objective position, exit position.

**Line 100** calculates the guard speed. `s = 20 - l * 3` means floor 1 has speed 17, floor 2 has 14, floor 3 has 11. Each floor's guard moves faster.

**Lines 550-620** handle floor completion. Score increases by `10 * l` — later floors are worth more. The floor counter increments. If there are more floors, `GO TO 60` loads the next one. If all floors are done, victory.

**Lines 480-490** handle the reset after detection. `RESTORE` rewinds to the start of DATA, then a loop skips forward to the current floor's data. This is how you reload the current floor's starting positions without re-reading the map.

**Lines 900-1190** hold all three floors. Each floor is 9 DATA items: 8 map strings plus one line of parameters. The skip formula `(l - 1) * 9 + 8` accounts for this structure.

## RESTORE and Floor Loading

`RESTORE` resets the DATA pointer to the beginning. To reach floor 2's data, you skip past floor 1's 9 items. To reach floor 3, skip 18 items. The formula `(l - 1) * 9 + 8` calculates how many items to skip, then one more `READ` gets the parameters.

This is how every game with multiple levels works in BASIC: sequential DATA blocks, with `RESTORE` and counting to navigate between them.

## Difficulty as Data

Each floor is harder not through code changes, but through data. Tighter corridors, different guard routes, faster movement. The same game engine plays every floor — only the data changes.
