## What You'll Build

Number guessing game with visual feedback. Text-based introduction to Sinclair BASIC fundamentals.

The computer picks a secret number. You guess. Feedback guides you closer. Score based on attempts. Colour feedback makes hints visual. This simple game teaches the foundations of Sinclair BASIC — variables, conditionals, loops, and the built-in colour commands.

## Skills You'll Master

- **Sinclair BASIC environment** — commands and editor
- **Variables and data types** — storing information
- **INPUT and PRINT** — player interaction
- **IF/THEN/ELSE logic** — making decisions
- **FOR/NEXT loops** — repetition
- **Random numbers** — RND function
- **CLS and screen clearing** — display management
- **Basic colour** — INK/PAPER commands

## Prerequisites

None — this is your first game!

## Time Investment

64 units at 60-90 minutes each. Roughly 64-96 hours total.
