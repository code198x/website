The stripes and checkerboard follow fixed patterns. For the final Colour Flood pattern, every cell gets a random colour.

## Random Fill

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-07/random-fill.bas" />

![Screen filled with random colours](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/random-fill.png)

The outer loop counts rows (1 to 22). The inner loop counts columns (1 to 32). For each cell, `INT (RND * 8)` picks a random colour from 0 to 7.

You've used `RND` before — it gives a random number between 0 and 1. Multiply by 8 to get a range from 0 to 7.999, then `INT` rounds down to a whole number. The result is always 0, 1, 2, 3, 4, 5, 6, or 7 — one of the 8 colours.

This program is noticeably slow. The Spectrum has to calculate `RND`, multiply, round, set the colour, and print — 704 times (22 × 32). You can watch it fill the screen row by row.

## Adding BRIGHT

Double the variety by randomising brightness too.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-07/random-pattern.bas" />

![Random colours with random brightness](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/random-pattern.png)

Line 50 adds `BRIGHT INT (RND * 2)` — randomly either 0 (normal) or 1 (bright) for each cell. Combined with the random `PAPER`, that gives up to 16 different shades.

The result is more varied than the plain random fill. Look closely and you'll see both dark and vivid versions of each colour.

Line 90 resets `BRIGHT 0` after the loop finishes. Without this, the Spectrum's own messages would appear in bright text.

## Why INT (RND * 8)?

This is worth understanding because you'll use it often:

1. `RND` gives a random decimal between 0 and 0.999...
2. `RND * 8` gives a random decimal between 0 and 7.999...
3. `INT (RND * 8)` rounds down to give 0, 1, 2, 3, 4, 5, 6, or 7

Change the 8 to any number to get a different range. `INT (RND * 2)` gives 0 or 1. `INT (RND * 6)` gives 0 to 5.

## Try This

**Fewer colours.** Change `RND * 8` to `RND * 4`. Only the first four colours (black, blue, red, magenta) appear. The pattern looks quite different with a restricted palette.

**Single row.** Remove the outer loop and just run the inner loop once. You get one row of random colours — a colourful stripe.

**Slow it down.** Add `PAUSE 1` after the `PRINT` line. Each cell appears one at a time, slowly painting the screen. It's mesmerising to watch.

## What You've Learnt

- **INT (RND * n)** — generates a random whole number from 0 to n-1
- **Random PAPER** — each cell gets a different background colour
- **Random BRIGHT** — doubles the palette by randomly toggling brightness
- **Always reset BRIGHT** — set `BRIGHT 0` after using random brightness
