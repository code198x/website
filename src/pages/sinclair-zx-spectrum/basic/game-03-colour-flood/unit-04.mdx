You know how to change `PAPER` and print text. Now combine them to fill the screen with solid colour.

## One Coloured Row

The trick is to print spaces. A space character has no visible text, but it still has a background colour.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-04/colour-row.bas" />

![A single red row across the screen](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-row.png)

Line 20 sets `PAPER 2` (red). Line 30 prints 32 spaces — exactly one row's width. The result is a solid red stripe across the top of the screen.

The spaces are enclosed in quotes: `"                                "` — that's 32 space characters. It looks empty, but it fills a full row with colour.

## Rainbow Stripes

Put the colour change inside a loop and you get stripes.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-04/stripes.bas" />

![Eight colour stripes](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/stripes.png)

Each time around the loop, `PAPER c` sets a different colour (0 through 7), then 32 spaces fill that row. Eight colours, eight rows.

This is the first pattern for Colour Flood — though the final version will be taller, filling more of the screen.

## Why Spaces?

You might wonder why we print spaces instead of using a special "fill" command. The Spectrum doesn't have one. Every character cell on screen has a foreground colour (INK) and a background colour (PAPER). Printing a space sets the PAPER colour for that cell without showing any text.

This is how all Spectrum games draw coloured backgrounds — printing invisible characters to paint the screen.

## Try This

**Two-colour stripes.** Instead of cycling through all 8 colours, alternate between two. Use `IF c / 2 = INT (c / 2) THEN PAPER 2` to set red on even rows and `PAPER 6` (yellow) on odd rows.

**Wider stripes.** Print 64 spaces instead of 32. Each colour will fill two rows instead of one. Or print 96 for three rows.

## What You've Learnt

- **Printing spaces sets PAPER colour** — the key technique for filling areas with colour
- **32 spaces = one full row** — the Spectrum screen is 32 characters wide
- **Loops + PAPER = patterns** — changing colour each iteration creates stripes
