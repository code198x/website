Phase 2 begins with the data needed to detect sinking. We already know when a shot hits, but not how much damage each ship has taken. A new array `h(2,5)` tracks the hit count for each ship (1-5) for each player (1-2). When a ship hit count equals its length, it has been sunk.

## How It Works

**Lines 20-30** dimension the new arrays. `DIM h(2,5)` stores hit counts — `h(1,3)` is the number of hits on Player 1 Cruiser (ship 3). `DIM k(2,5)` will later track which ships are sunk (0=afloat, 1=sunk), but we set it up now.

**Lines 40-60** initialise both arrays to 0. Every ship starts with zero hits and afloat status.

**Lines 70-90** print the initial health state for verification. Each ship shows "0 / length" — zero hits out of the total required to sink it.

## The h(2,5) Design

The first index is the player number (1 or 2). The second is the ship number (1-5). This design lets us write `h(o,v)` where `o` is the opponent and `v` is the ship that was hit. We increment with `LET h(o,v) = h(o,v) + 1` and check for sinking with `IF h(o,v) = l(v)`.

Why not store health in the grid arrays? Because a ship spans multiple cells but has one health counter. The Carrier occupies five cells, each with value 1. We could scan the grid and count how many of those cells have been changed to 6 (hit), but that means scanning 100 cells every time we want to check one ship. A dedicated health array gives us the answer in a single lookup.

## Parallel Arrays

The game now uses several parallel arrays:

- `l(5)` — ship lengths
- `n$(5,10)` — ship names
- `h(2,5)` — hit counts per player per ship
- `k(2,5)` — sunk status per player per ship

All indexed by ship number 1-5. Ship number 3 is always the Cruiser, with length `l(3)`, name `n$(3)`, and hit count `h(p,3)`. Keeping these arrays aligned is critical — if the ship data and the health data use different numbering, the game logic breaks silently.

## Try This

**Manually increment hits.** Add `LET h(1,1) = h(1,1) + 1` a few times and print `h(1,1)` after each. When does it equal `l(1)` (the Carrier length of 5)? That is when the ship would sink.

**Print a health table.** Loop through all five ships and print their name, hits, and length in a formatted table. This display will be useful later for the fleet status screen.
