When a shot hits, we know the cell value from the opponent ship array. That value (1-5) tells us exactly which ship was hit. We can now connect the hit to the health tracking array and increment the right counter. This is the link between shooting and sinking.

## How It Works

**Lines 70-80** read the cell value before overwriting it. The line `LET v = b(y,x)` (or `a(y,x)` for the other player) captures the ship number. This must happen before the cell is changed to 6 (hit marker), otherwise the ship identity is lost.

**Lines 90-100** increment the hit counter: `LET h(o,v) = h(o,v) + 1` where `o` is the opponent number and `v` is the ship number from the cell.

**Lines 110-130** display which ship was hit: "Hit the " + `n$(v)` + "!". The player sees "Hit the CRUISER!" rather than just "HIT!", giving them useful tactical information.

## Read Before Write

The order matters: read the cell value, then overwrite it. Once we set the cell to 6, the original ship number is gone. This is a common pattern when arrays serve dual purposes — the cell value means "ship 3 is here" during placement but "this cell was hit" during shooting. The read-before-write pattern captures the information we need before it is destroyed.

An alternative design would use separate values for "hit ship 1", "hit ship 2", and so on (values 6-10 instead of just 6). This preserves the ship identity in the grid, but the health array makes it unnecessary. Once the hit counter is incremented, we do not need the grid to remember which ship it was.

## Naming the Hit

Telling the player which ship they hit serves two purposes. First, it is satisfying — "Hit the BATTLESHIP!" feels better than "HIT!". Second, it gives tactical information. If the player knows they hit the Carrier twice and the Carrier has length 5, they know three more hits in the area will sink it.

## Try This

**Track hits across turns.** Hit the same ship from different cells and watch the hit counter increase. Print `h(o,v)` after each hit to confirm it increments correctly.

**Test the read order.** Temporarily move the cell overwrite before the value read. What happens? The program will always report hitting ship 6, which does not exist. Put it back in the right order.
