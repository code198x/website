Sinking a ship is the most important event in a battleships game. It deserves more than a plain text message. This unit adds a prominent sunk display — large text, bright colour, and a pause so the player can savour the moment.

## How It Works

**Lines 130-150** trigger the sunk display when `k(o,v)` is first set to 1. The message area below the grids clears, then the sunk announcement appears.

**Lines 160-170** format the message with BRIGHT and INK. The text reads "You sank the CARRIER!" (or whichever ship), printed in bright red. The ship name comes from `n$(v)`, the same name array used during placement.

**Lines 180-190** add a pause with `PAUSE 100` (two seconds at 50fps). This gives the player time to read the message and feel the satisfaction of sinking a ship. Without the pause, the message would flash past and disappear on the next turn redraw.

## Message Placement

The sunk message appears below both grids, in the area reserved for feedback. This keeps it separate from the grid display — the player can see the sunk announcement and the grids simultaneously. The message position is fixed at row 20, leaving the bottom two rows for input prompts.

## Building Anticipation

The sunk message appears only after the hit message. The sequence is: "Hit the CARRIER!" followed by "You sank the CARRIER!". Two separate messages in quick succession create a one-two punch. The player first learns they hit something, then discovers the hit was fatal. This micro-narrative plays out over a fraction of a second but makes the event feel more significant.

## Try This

**Sink all five ships.** Work through the opponent fleet and sink each one. Does the sunk message appear correctly for each ship? Does it show the right name?

**Change the display style.** Try `FLASH 1` on the sunk message, or print it in inverse video with `INVERSE 1`. Which treatment makes the message feel most impactful?
