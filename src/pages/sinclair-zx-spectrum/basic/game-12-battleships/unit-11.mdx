Ships are placed, both players are ready. Time to shoot. The current player enters a coordinate, and the program checks the opponent ship array. If the cell contains a ship value (1-5), it is a hit. If it contains 0, it is a miss. The result is reported to the player.

## How It Works

**Lines 20-40** prompt the current player for a target coordinate and parse it into column `x` and row `y` using the same input logic from Unit 5.

**Lines 50-70** determine which opponent array to check. If it is Player 1 turn (variable `p=1`), the target is Player 2 ship array `b()`. If `p=2`, the target is `a()`. The variable `o` tracks the opponent number (3 minus `p` gives the other player).

**Lines 80-100** read the cell value from the opponent array. If the value is greater than 0, the shot is a hit. Otherwise it is a miss. The result is stored for display and tracking.

**Lines 110-130** print the result: "HIT!" in red or "Miss" in cyan. The message appears below the grids where the player can see it clearly.

## Reading the Opponent Array

The shooting code touches the opponent ship array but never displays it. `LET v = b(y,x)` reads the value — we learn whether a ship is there — but the grid drawing code will never show `b()` to Player 1. This is the core of hidden information: the program knows the truth, but the display shows only the tracking grid.

The variable `v` also tells us which ship was hit (values 1-5 correspond to specific ships). We do not use that information yet, but it becomes essential when we add sunk detection in Phase 2.

## Try This

**Fire at a known position.** After placing ships, note where you placed the Carrier. Fire at one of its cells. Does the program correctly report a hit?

**Fire at empty water.** Pick a coordinate you know has no ship. The program should report a miss. Try the corners and edges to make sure the coordinate system is consistent.
