## How It Works

**Lines 20-40** set up the fleet data. Ship lengths are stored in `l(5)` and names in `n$(5,10)`, read from DATA statements. The ships go in order from largest to smallest: 5, 4, 3, 3, 2.

**Lines 50-60** start the outer placement loop: `FOR v=1 TO 5`. The variable `v` serves double duty — it is the loop counter and the value written into the grid array to identify which ship occupies each cell.

**Lines 70-90** display the current grid and prompt with the ship name and length: "Place " + `n$(v)` + " (length " + `STR$(l(v))` + ")".

**Lines 100-140** run the coordinate input, direction choice, bounds check and overlap detection from previous units. If any check fails, the loop returns to the prompt for the same ship.

**Lines 150-170** write the ship to the array and redraw the grid. The NEXT advances to the next ship only after a successful placement.

## Largest First

The fleet places from largest to smallest. This is a deliberate design choice. The Carrier (length 5) has the fewest valid positions on a 10x10 grid, so it is easiest to place when the grid is empty. By the time the Destroyer (length 2) comes around, the grid may be crowded, but a 2-cell ship can squeeze into almost any gap. Reversing the order would make placement frustrating.

## The v Variable

Using `v` as both the loop counter and the cell value keeps the code simple. When `v=1`, we are placing ship 1 (Carrier), and cells get the value 1. When `v=3`, we place the Cruiser and cells get 3. Later, when a shot hits a cell containing value 3, we instantly know it was the Cruiser. The array value is both an identifier and a link to the ship data arrays.

## Try This

**Place all five ships.** Run the program and place the complete fleet. Check that the grid shows all five ships without any overlaps.

**Try to fill a row.** Place ships to cover an entire row. The Carrier (5) plus Battleship (4) nearly fill a row of 10. Can you fit a Destroyer (2) in the remaining gap? This tests whether your overlap detection works with tightly packed ships.
