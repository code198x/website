Placing five ships is a commitment. If the player makes a poor choice early on, they are stuck with it for the entire game. A review step after placement lets the player see their final layout and decide whether to keep it or start over. This small addition significantly improves the experience.

## How It Works

**Lines 170-190** display the complete fleet layout after all five ships are placed. The grid shows every ship in position, giving the player a clear view of their strategy.

**Lines 200-220** prompt: "Happy with this layout? (Y/N)". The program reads a single character with INPUT and checks for Y or N (handling lowercase with the same technique from Unit 5).

**Lines 230-250** handle the N response. If the player wants to redo, the program clears the ship array with a nested loop: `FOR r=1 TO 10: FOR c=1 TO 10: LET a(r,c)=0: NEXT c: NEXT r`. Then it jumps back to the start of placement.

**Lines 260-270** handle the Y response. The program continues to the handover or game start.

## Clearing an Array

Spectrum BASIC has no built-in way to reset an array. You cannot re-DIM an existing array — that would cause an error. Instead, a nested loop sets every element back to 0. For a 10x10 array, that is 100 assignments. It takes a noticeable fraction of a second, but it only runs when the player chooses to redo.

## When to Offer Choice

The review appears after placement is complete, not after each individual ship. Why? Because placement decisions are interdependent — the position of ship 3 depends on where ships 1 and 2 went. Asking "keep this ship?" after each placement would be disruptive. The all-or-nothing approach at the end is simpler and more useful.

The cost of redoing is placing all five ships again. This is not ideal — a player might want to move just one ship. But implementing single-ship repositioning would require tracking which cells belong to which ship and selectively clearing them. The full redo is simpler and good enough for most cases.

## Try This

**Test the redo.** Place all five ships, choose N at the review, and place them again. Verify that the old layout is completely gone — no ghost ships from the first attempt.

**Place the same layout twice.** After redoing, place ships in the same positions as before. This confirms the array was properly cleared and no old data interferes.
