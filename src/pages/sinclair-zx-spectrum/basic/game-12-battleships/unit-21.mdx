Players need to see which ships remain in the opponent fleet. A status display below the tracking grid lists all five ships — afloat ships in white, sunk ships in red with a strikethrough effect. This helps the player plan their strategy.

## How It Works

**Lines 140-160** draw the fleet status list after the grids. A FOR loop runs through ships 1 to 5. For each ship, it prints the name from `n$(v)` at a fixed screen position below the tracking grid.

**Lines 170-190** set the colour based on sunk status. If `k(o,v) = 0` (afloat), the name prints in white INK. If `k(o,v) = 1` (sunk), it prints in red INK with a dash through it — something like "~~CARRIER~~" or the name in a darker colour.

**Lines 200-210** show the count: "Ships remaining: " followed by the number still afloat. This count comes from subtracting the number of sunk ships from 5. A simple loop sums the `k()` values.

## Strategic Information

The fleet status display gives the player two things:

1. **Which ships are sunk** — so they do not waste shots searching for a ship that is already gone
2. **Which ships are still hiding** — a Destroyer (length 2) is harder to find than a Carrier (length 5)

This information changes strategy. If only the Destroyer remains, the player knows they are looking for two adjacent cells. They can narrow their search pattern accordingly.

## Counting with a Loop

To count how many ships are sunk, we sum the `k()` array: `LET s=0: FOR v=1 TO 5: LET s=s+k(o,v): NEXT v`. Since `k()` values are 0 or 1, the sum gives the count directly. Ships remaining is `5 - s`. This counting pattern works for any boolean array.
