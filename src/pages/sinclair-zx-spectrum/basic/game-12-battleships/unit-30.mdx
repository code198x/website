The grids work, but they look raw. Adding border characters — lines around the edges and between the header and the cells — gives the display a polished, finished appearance. The Spectrum block graphics provide the line-drawing characters we need.

## How It Works

**Lines 20-40** draw the top border above each grid. A row of horizontal line characters runs across the width of the grid, with corner pieces at each end. The Spectrum does not have dedicated line-drawing characters, so we use block graphics: `CHR$(131)` for the top-left corner effect, `CHR$(143)` for a solid block as a horizontal line.

**Lines 50-70** draw vertical borders along the left and right edges of each grid. Each cell row gets a border character at the start and end: `CHR$(133)` or a similar block graphic for a vertical bar effect.

**Lines 80-100** draw the bottom border below each grid, mirroring the top border.

**Lines 110-130** draw a separator between the column headers and the grid cells. This horizontal line visually separates the labels from the data, making the grid easier to read.

## Block Graphics

The Spectrum has 16 block graphic characters (codes 128-143). Each divides a character cell into four quadrants, with each quadrant either filled or empty. By choosing the right combination, you can create approximate line-drawing effects:

- `CHR$(131)` — top-right quadrants filled, works as a left border
- `CHR$(133)` — bottom-left quadrants filled, works as a corner
- `CHR$(143)` — all quadrants filled, solid block for lines

These are not smooth lines — they are chunky 4x4 blocks. But at screen distance, they read as borders well enough to frame the grid.

## Visual Hierarchy

Borders create visual hierarchy. Without them, the grid, labels, and messages blur together. Borders separate the grid from the surrounding space, the headers from the data, and the left grid from the right grid. Each boundary tells the eye where one element ends and another begins.

## Try This

**Try different border characters.** Swap `CHR$(143)` for `CHR$(135)` or other block graphics. Some create dotted or dashed effects that might suit the nautical theme.

**Add colour to the borders.** Print border characters in a different INK colour — perhaps white borders on a blue background to suggest the sea. This adds another layer of visual distinction.
