A good game makes you want to play again immediately. Rather than forcing players to type RUN, the program asks "Play again?" and resets everything if they say yes. All arrays clear, counters reset, and placement begins fresh.

## How It Works

**Lines 370-390** prompt "Play again? (Y/N)" after displaying the victory screen and shot statistics. The input uses the same Y/N validation as the placement review.

**Lines 400-420** handle the N response. The program prints "Thanks for playing!" and reaches STOP. The game is over.

**Lines 430-450** handle the Y response. The reset sequence begins.

**Lines 460-500** clear all game state. Four nested loops zero out `a()`, `b()`, `c()`, and `d()`. Two loops zero out `h()` and `k()`. The shot counters reset: `LET s1=0: LET s2=0`. The winner flag resets: `LET w=0`. The current player resets: `LET p=1`.

**Lines 510-520** jump back to the start of placement. Both players place their fleets again, and a new game begins.

## What Needs Resetting

The full reset list:

- `a(10,10)` — Player 1 ships
- `b(10,10)` — Player 2 ships
- `c(10,10)` — Player 1 tracking
- `d(10,10)` — Player 2 tracking
- `h(2,5)` — hit counts
- `k(2,5)` — sunk flags
- `s1`, `s2` — shot counters
- `w` — winner flag
- `p` — current player

Missing any one of these would carry state from the previous game into the new one. Leftover ship positions, hit counts, or tracking data would create bizarre bugs. The reset is thorough by necessity.

## GO TO vs RUN

We could use `RUN` instead of resetting manually. `RUN` clears all variables and restarts from line 1. But `RUN` also re-reads DATA statements and re-dimensions arrays, which is wasteful. More importantly, it looks untidy — the program should feel like it is starting a new game, not rebooting. The manual reset with GO TO gives the same result with more control.

## Try This

**Play two games in a row.** Win the first game, choose to play again, and verify that the second game starts completely fresh. No ships from the first game should appear.

**Check the counters.** After the second game, verify that the shot counts reflect only the second game, not a total of both games.
