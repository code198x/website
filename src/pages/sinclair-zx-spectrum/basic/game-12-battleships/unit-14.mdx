Individual systems work: placement, display, shooting, tracking. Now they need to fit together into a turn cycle. Each turn clears the screen, shows the current player their grids, accepts a shot, displays the result, then hands over to the other player.

## How It Works

**Lines 20-30** start the main game loop. The variable `p` tracks the current player, starting at 1.

**Lines 40-60** clear the screen and draw both grids for the current player. The ship grid on the left shows array `a()` for Player 1 or `b()` for Player 2. The tracking grid on the right shows `c()` for Player 1 or `d()` for Player 2. A header displays "Player 1" or "Player 2".

**Lines 70-90** run the shooting sequence: coordinate input, already-fired check, hit/miss detection, array updates, result message.

**Lines 100-120** pause to let the player see the result, then run the handover. CLS wipes the screen, a message tells the next player to take the keyboard, and PAUSE 0 waits for a keypress.

**Lines 130-150** switch the current player: `LET p = 3 - p`. When `p=1`, this gives 2. When `p=2`, it gives 1. The loop then repeats from line 40.

## The 3 Minus p Trick

`LET p = 3 - p` toggles between 1 and 2 without an IF statement. It works because 3 minus 1 is 2 and 3 minus 2 is 1. This pattern appears in many two-player games. It is shorter than `IF p=1 THEN LET p=2: ELSE LET p=1` and less error-prone.

## Array Selection

When `p=1`, the player sees `a()` (their ships) and `c()` (their shots). When `p=2`, they see `b()` and `d()`. The grid drawing subroutine needs to know which arrays to read. One approach: pass the player number and use IF statements inside the drawing code. Another: copy the relevant arrays into temporary display arrays. The first approach uses less memory; the second is cleaner but doubles the array storage.

## Try This

**Play a full round.** Place ships for both players, then take turns firing. Does the handover feel smooth? Can you see any information leaking between turns?

**Time the handover.** Is `PAUSE 0` the right approach, or would a timed pause with `PAUSE 100` (two seconds) be better? Try both and see which feels more natural.
