## What You'll Build

Classic snake game using character graphics and User-Defined Graphics. Eat food, grow longer, avoid yourself.

Guide a serpent that grows with each meal. Custom UDG characters make the snake distinctive. Arrays track the body. Speed increases with length. This introduces the Spectrum's User-Defined Graphics system.

## Skills You'll Master

- **Array usage** — snake body storage
- **User-Defined Graphics** — custom characters
- **UDG design and POKEing** — character definition
- **Self-collision detection** — body checks
- **Food spawning** — random placement
- **Growth mechanics** — extending length
- **Score display** — on-screen numbers
- **Speed progression** — increasing challenge

## Prerequisites

Complete **Game 4: Dungeon Explorer** first.
