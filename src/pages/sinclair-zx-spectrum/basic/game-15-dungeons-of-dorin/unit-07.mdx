The dungeon exists and the player is placed inside it. Now they need to move. QAOP controls shift the player one cell at a time — Q for up, A for down, O for left, P for right. Each keypress is a turn. Walls block movement. The dungeon responds to input.

## How It Works

**Line 156** is the start of the main loop. PAUSE 0 halts execution until a key is pressed, then INKEY$ captures which key it was. This makes the game turn-based — nothing happens until the player acts.

**Lines 160-168** calculate the target position. The current position is copied into temporary variables `t` and `t2`. Each direction key adjusts one of them: Q subtracts 1 from y (moving up on the grid), A adds 1 to y, O subtracts 1 from x, P adds 1 to x.

**Line 172** checks whether the player actually moved. If `t` and `t2` still equal `x` and `y`, no direction key was pressed, so the loop restarts.

**Line 174** checks grid boundaries. If the target position is outside the 16x16 grid, the move is rejected.

**Line 176** checks for walls. If `d(t2,t)` equals 1 (wall), the move is blocked and the loop restarts.

**Line 186** applies the move. If all checks pass, the player position updates to the target coordinates.

## Turn-Based Input

PAUSE 0 followed by INKEY$ is a clean pattern for turn-based input. PAUSE 0 waits indefinitely until a key is pressed. INKEY$ then reads which key it was. The game processes one action, redraws the screen, and waits again. There is no time pressure — the player can think as long as they want before acting.

This is fundamentally different from the real-time input loops used in action games. There is no INKEY$ polling in a tight loop, no frame timing, no missed inputs. Every keypress is captured and processed.

## Wall Collision

The collision check is a single line: `IF d(t2,t) = 1 THEN GO TO 154`. The dungeon array itself serves as the collision map. Any cell with value 1 is impassable. Floor cells (0), stairs (2), and chests (3) are all passable. This approach means adding new passable cell types only requires ensuring their value is not 1.
