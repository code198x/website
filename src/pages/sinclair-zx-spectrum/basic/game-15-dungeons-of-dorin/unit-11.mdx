The goal of each floor is to find the stairs and descend deeper. Stairs are placed in the last room generated — the room furthest from the player starting position in the generation sequence. Walking onto the stairs triggers a new floor: the dungeon regenerates, the floor counter increments, and the player finds themselves in a fresh set of rooms and corridors.

## How It Works

**Lines 112-116** place the stairs. The last room in the array (room `s`) provides the position. The stairs cell is set to value 2 in the dungeon array with `LET d(t2,t) = 2`. A bounds check ensures the position is within the grid.

**Line 192** in the main loop checks whether the player has stepped onto stairs. If `d(y,x)` equals 2, the stairs subroutine at line 600 is called.

**Lines 600-612** handle the descent. The floor counter `e` increments by 1. A "DESCENDING..." message appears with a brief sound effect (two descending BEEP tones). After a short pause, the program jumps back to line 40 to regenerate the dungeon. The player starts the new floor in the first room of the new layout.

The stairs appear as `>` in the viewport — a downward-pointing symbol that suggests descent.

## Floor Transitions

The floor transition is destructive — the old dungeon is completely overwritten when the new one generates. There is no going back up. This is a design constraint, not a limitation. One-way descent creates tension: every step forward is permanent. The player must decide whether they are ready to leave the current floor before stepping onto the stairs.

Regenerating the dungeon reuses the same arrays. `d(16,16)` is filled with walls again, then new rooms and corridors are carved. The visibility array `v(16,16)` resets to all zeros, so the new floor starts fully hidden. The player keeps their stats, equipment, and gold — only the dungeon changes.

## Placement Strategy

Putting stairs in the last room means the player must explore to find them. The generation algorithm places rooms in sequence, and corridors connect them in order. The last room is typically the furthest from the start in terms of corridor paths, though random placement means this is not guaranteed. The important thing is that the stairs are always in a reachable room.
