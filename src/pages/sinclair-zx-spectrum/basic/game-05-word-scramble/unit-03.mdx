You can measure a string's length. Now you need to reach inside and pull out individual characters or ranges of characters.

## Single Characters

`w$(3)` returns the third character of `w$`. If `w$ = "SPECTRUM"`, then `w$(1)` is "S", `w$(3)` is "E", and `w$(8)` is "M". Positions start at 1, not 0.

## Ranges with TO

`w$(2 TO 5)` returns characters 2 through 5. For "SPECTRUM", that's "PECT". You can also leave one side open: `w$(4 TO )` means "from position 4 to the end", and `w$( TO 3)` means "from the start to position 3".

## Why Slicing Matters

The scramble algorithm works by removing one character at a time from a temporary copy of the word. To remove position `p` from `t$`, you take everything before it and everything after it:

```
LET t$ = t$(1 TO p - 1) + t$(p + 1 TO LEN t$)
```

This is the key operation. If `t$ = "CAT"` and `p = 2`, you get `t$(1 TO 1) + t$(3 TO 3)` which joins "C" and "T" to make "CT".

## Edge Cases

When `p` is 1, `t$(1 TO 0)` produces an empty string — that's fine, the Spectrum handles it gracefully. When `p` equals `LEN t$`, `t$(p + 1 TO LEN t$)` also produces an empty string because the start is past the end.

## Try This

**First and last.** Ask the player for a word, then print the first character and the last character using `w$(1)` and `w$(LEN w$)`.

**Remove the middle.** For a word of known length, build a new string from the first half and second half, skipping the middle character.

## What You've Learnt

- **Single character** — `w$(3)` extracts the third character
- **Range** — `w$(2 TO 5)` extracts characters 2 through 5
- **Open ranges** — `w$(3 TO )` means "from 3 to the end"
- **Removing a character** — combine slices: `t$(1 TO p-1) + t$(p+1 TO LEN t$)`
