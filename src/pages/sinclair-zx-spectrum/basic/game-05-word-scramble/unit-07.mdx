The game works, but correct and wrong answers look the same. Colour and sound make the difference obvious at a glance.

## Coloured Feedback

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-word-scramble/unit-07/feedback.bas" />

![Colour feedback — yellow scrambled word, red wrong answer](/images/sinclair-zx-spectrum/basic/game-05-word-scramble/feedback.png)

Three colour changes make the game easier to read:

- **Yellow scrambled word** (INK 6) — the puzzle stands out from the surrounding text
- **Green "Correct!"** (INK 4) — instant positive feedback
- **Red "Wrong!"** (INK 2) — clearly signals a miss

After each coloured print, `INK 0` resets to black for the next round.

## Sound Effects

`BEEP 0.2, 12` plays a short high note for correct answers — a quick, satisfying chirp. `BEEP 0.3, -5` plays a longer low note for wrong answers — a dull buzz that says "try again".

The two parameters are duration (in seconds) and pitch (semitones from middle C). Positive numbers go higher, negative numbers go lower.

## Combining Statements

Lines 150 and 160 pack multiple statements onto one line using colons:

```
IF g$ = w$ THEN INK 4: PRINT "Correct!": INK 0: BEEP 0.2, 12: LET n = n + 1
```

Everything after `THEN` runs only when the condition is true. This keeps the correct and wrong paths on one line each — clean and easy to follow.

## Try This

**Different sounds per round.** Change the pitch based on the round number: `BEEP 0.2, 12 + i`. Each correct answer plays a slightly higher note.

**Flash on wrong.** Add `FLASH 1` before the "Wrong!" message and `FLASH 0` after. The flashing text draws extra attention to mistakes.

## What You've Learnt

- **INK for feedback** — green for correct, red for wrong, yellow for emphasis
- **BEEP for audio cues** — high notes for success, low notes for failure
- **Reset after colour** — always return to `INK 0` after coloured output
- **Multi-statement lines** — colons pack related actions onto one line after `THEN`
