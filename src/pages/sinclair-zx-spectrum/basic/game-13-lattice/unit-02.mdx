PLOT places a dot. DRAW extends a line from that dot. Together they let you draw straight lines between any two points on screen. This is the core mechanic of Lattice — drawing lines between nodes.

## How It Works

**Line 10** clears the screen.

**Lines 20-30** demonstrate the basic pattern: PLOT moves to a starting position, then DRAW extends a line by a relative offset. DRAW 100,0 draws a horizontal line 100 pixels to the right. DRAW 0,80 draws a vertical line 80 pixels upward.

**Lines 40-60** draw lines between specific points. To draw a line from (30,30) to (200,150), you PLOT 30,30 then DRAW 170,120 — the difference between the end and start coordinates. The formula is always `DRAW (x2-x1),(y2-y1)`.

**Lines 70-90** draw a triangle to show how consecutive DRAW commands chain together. Each DRAW starts from where the previous one ended.

## Relative, Not Absolute

DRAW does not take absolute coordinates. It takes offsets — how far to move from the current position. This is different from how most modern graphics work, and it means you need to calculate the difference between your start and end points every time.

For Lattice, where nodes have known positions, the pattern will always be:

1. PLOT at the start node position
2. Calculate dx = end_x - start_x
3. Calculate dy = end_y - start_y
4. DRAW dx, dy

This will become a subroutine in a later unit.

## Try This

**Draw a square.** PLOT to one corner, then use four DRAW commands to complete the shape. Remember that DRAW is relative — each command starts from where the last one ended.

**Draw a star.** Five lines radiating from a central point. You will need to PLOT back to the centre before each DRAW, because DRAW continues from the last position.
