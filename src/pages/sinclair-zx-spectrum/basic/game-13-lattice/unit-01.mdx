Every game so far has placed characters on screen with PRINT AT. Lattice works differently. It draws directly in pixels using PLOT, DRAW and CIRCLE. This unit introduces PLOT — the simplest graphics command — and the pixel coordinate system that underpins everything in this game.

## How It Works

**Line 10** clears the screen with CLS, giving us a blank canvas.

**Lines 20-30** use PLOT to place dots at specific pixel coordinates. PLOT takes two arguments: an x position (0 to 255) and a y position (0 to 175). The dot appears at that exact pixel.

**Lines 40-60** draw a row of dots in a FOR/NEXT loop, spacing them 20 pixels apart across the screen. This shows how PLOT works with calculated positions.

## Pixel Coordinates vs Character Coordinates

Until now, you have used PRINT AT with character coordinates — row 0 is the top of the screen, column 0 is the left. The screen is 32 characters wide and 22 rows tall.

Pixel coordinates work differently:

- **Origin is bottom-left.** PLOT 0,0 places a dot in the bottom-left corner.
- **X increases rightward.** PLOT 255,0 is the bottom-right corner.
- **Y increases upward.** PLOT 0,175 is the top-left corner.
- **The screen is 256 pixels wide and 176 pixels tall.**

This upside-down relationship to PRINT AT catches everyone out at first. A high y value in PLOT means the top of the screen, but a high row number in PRINT AT means the bottom. Keep this distinction clear in your mind — Lattice uses pixel coordinates throughout.

## Try This

**Plot the four corners.** Place dots at (0,0), (255,0), (0,175) and (255,175). Which corner is which?

**Draw a diagonal.** Use a FOR/NEXT loop to PLOT dots from (0,0) to (175,175). What shape do you see? Why does it stop at 175 and not 255?
