The player needs to know when they have solved a puzzle. After each successful connection, the program checks whether all required connections have been drawn. When they have, the puzzle is complete — time for a score and a congratulations message.

## How It Works

**Lines 10-130** set up and run the puzzle as before, with selection, validation, crossing detection and undo.

**Lines 140-160** check for completion after each successful connection. The subroutine at line 500 loops through all entries in `d()`. If every value is 1, all connections have been drawn and variable `w` is set to 1.

**Lines 500-530** are the completion check. A simple loop tests each `d(i)`. If any value is 0, the puzzle is not yet complete and the subroutine returns early with `w` set to 0.

**Lines 170-210** handle the completion event. The screen flashes briefly, a rising BEEP sequence plays, and the program prints the puzzle number and a score. The score is based on the number of undo moves used — fewer undos means a higher score.

## Scoring

The score formula rewards efficiency. Each puzzle starts with a base score, and each undo reduces it. A player who solves the puzzle without any undos gets the maximum score. A player who undoes many connections still completes the puzzle but earns fewer points.

This scoring model encourages the player to think ahead. Rather than trial-and-error with heavy use of undo, planning the connection order before drawing leads to better scores.

## The Completion Moment

A puzzle game needs a satisfying completion moment. The brief screen flash (using BORDER and PAUSE) gives immediate visual feedback. The ascending BEEP sequence provides audio confirmation. Together they create a clear "you did it" signal before the score is displayed.

## Try This

**Solve the puzzle.** Draw all required connections without any crossings. Does the completion sequence trigger correctly?

**Measure undo impact.** Solve the puzzle once without undo, and once with several undos. Compare the scores. Does the difference feel fair?
