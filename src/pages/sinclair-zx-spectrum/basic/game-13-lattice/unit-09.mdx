A puzzle is not just a set of nodes — it also defines which pairs must be connected. The player does not get to choose arbitrary connections. The puzzle specifies the required pairs, and the player must draw exactly those lines without any crossings. This unit adds connection data to the puzzle definition.

## How It Works

**Lines 10-50** load node positions as before.

**Lines 60-80** read the connection data. After the node coordinates, the DATA contains the number of required connections followed by pairs of node indices. These are stored in arrays `e()` and `f()` — edge start and edge end. Connection 1 links node `e(1)` to node `f(1)`, connection 2 links `e(2)` to `f(2)`, and so on.

**Lines 90-100** track which connections have been drawn using array `d()`. When the player draws connection `i`, we set `d(i)` to 1.

**Lines 110-150** hold the complete puzzle data: four nodes in a diamond, with five required connections between them.

## The Puzzle Data Structure

Each puzzle is now fully described by its DATA:

1. **Node count** — how many nodes
2. **Node positions** — x,y pairs for each node
3. **Connection count** — how many lines must be drawn
4. **Connection pairs** — pairs of node indices

This is the complete puzzle definition. The game engine reads it, draws the nodes, and waits for the player to draw the specified connections. A puzzle is solved when every connection in `d()` is marked as drawn.

## Why Store Connections?

Without connection data, the player could draw any line between any two nodes. That is not a puzzle — it is a drawing tool. The connection list defines the goal. The challenge comes from the constraint that lines must not cross. The player must figure out the correct order to draw connections so that no line passes through an existing one.

## Try This

**Design a crossing puzzle.** Create DATA for four nodes in a square with connections 1-3 and 2-4 (the diagonals). Can this puzzle be solved without crossing? Not all puzzles are solvable — this is part of the design challenge.

**Count the connections.** For a puzzle with N nodes, what is the maximum number of non-crossing connections? Experiment with small node counts.
