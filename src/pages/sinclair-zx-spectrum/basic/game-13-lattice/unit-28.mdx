When all of a node's required connections have been drawn, the node is complete. Changing its colour from green to cyan gives the player a clear visual indicator of progress. Partially connected nodes stay green. Fully connected nodes turn cyan. At a glance, the player can see how much work remains.

## How It Works

**Lines 10-20** add array `nc()` to track how many connections each node needs, and `nd()` to track how many have been drawn. These are calculated from the connection data during puzzle setup.

**Lines 30-50** count required connections per node. For each connection pair `(e(i), f(i))`, both `nc(e(i))` and `nc(f(i))` are incremented. After the loop, `nc(j)` holds the total number of connections that include node `j`.

**Lines 200-220** update `nd()` after each connection is drawn. When connecting nodes `a` and `b`, both `nd(a)` and `nd(b)` are incremented.

**Lines 230-250** check whether either node is now complete. If `nd(j)` equals `nc(j)`, all of that node's connections have been drawn. The node is redrawn in cyan (INK 5) instead of green.

**Lines 260-280** handle undo. When a connection is undone, `nd()` for both nodes is decremented, and if either node was previously complete, it returns to green.

## Progress Visualisation

On a puzzle with ten nodes:
- At the start, all nodes are green
- As connections are drawn, nodes gradually turn cyan
- When the last connection is drawn, the final nodes turn cyan and the puzzle is complete

This creates a visual wave of completion across the puzzle. The player can focus on the green nodes — those are the ones that still need attention.

## Counting Connections Per Node

The connection count is derived from the puzzle data, not hard-coded. For each connection pair, both nodes in the pair get their count incremented. A node that appears in three connection pairs needs three lines drawn to it before it is complete. This calculation happens once during puzzle setup and does not change during play.

**Test with undo.** Draw a connection that completes a node (turns it cyan), then undo it. Does the node return to green correctly?
