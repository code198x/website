Black circles on a black background are invisible. Lattice needs colour to distinguish nodes, lines and the cursor. The INK command sets the colour for all subsequent graphics commands — PLOT, DRAW and CIRCLE all inherit the current ink colour.

## How It Works

**Line 10** clears the screen with a black background.

**Lines 20-30** set the ink to green (INK 4) and draw a circle. The circle appears in green.

**Lines 40-50** change the ink to white (INK 7) and draw a line. PLOT and DRAW both use the current ink colour, so the line appears in white.

**Lines 60-70** switch to yellow (INK 6) and draw another circle. This represents the cursor highlight — a yellow circle drawn over a node to show which one is currently selected.

**Lines 80-100** demonstrate the colour scheme for Lattice: green nodes, white connection lines, and a yellow cursor highlight. The program draws a small puzzle layout with all three colours visible.

## The Lattice Colour Scheme

Colour has meaning in Lattice:

- **Green (INK 4)** — nodes, drawn as circles
- **White (INK 7)** — connection lines between nodes
- **Yellow (INK 6)** — the cursor, highlighting the current node
- **Red (INK 2)** — rejected connections (crossing lines), used later for feedback
- **Cyan (INK 5)** — completed connections, used later for visual confirmation

Setting INK before a graphics command affects only that command and everything after it until INK changes again. This is different from PRINT, where you can set INK per character using embedded colour codes.

## INK and ATTR

Every 8x8 pixel block on the Spectrum shares one ink colour and one paper colour. This is attribute-based colour — a hardware limitation that Lattice actually turns into a feature. Later, we will use ATTR to detect whether a line has been drawn through a character cell, which is how crossing detection works.

## Try This

**Draw all eight colours.** Draw eight circles in a row, each in a different INK colour (0-7). Which colours are visible against a black background? Which would work on white paper?

**Overlay test.** Draw a green circle, then draw a white line through it. What happens where they overlap? Does the circle change colour?
