The player connects nodes by drawing lines between them. Since this happens many times during a game, the line-drawing logic belongs in a subroutine. Pass in two node numbers, and the subroutine PLOTs to the first node and DRAWs to the second.

## How It Works

**Lines 10-50** load the node data and draw all nodes as green circles, exactly as in the previous unit.

**Lines 60-80** demonstrate the subroutine. We set `a` and `b` to the two node indices we want to connect, then call `GO SUB 200`. The main program sets up which nodes to connect; the subroutine does the drawing.

**Lines 200-240** are the line-drawing subroutine. It looks up the positions of node `a` and node `b` from the arrays, PLOTs to node `a`, and DRAWs the relative distance to node `b`. The ink is set to white before drawing, so connection lines are visually distinct from the green nodes.

## The PLOT-DRAW Pattern

Drawing a line between two known points always follows the same steps:

1. Look up the start position: `x(a)`, `y(a)`
2. Look up the end position: `x(b)`, `y(b)`
3. PLOT at the start: `PLOT x(a), y(a)`
4. DRAW the difference: `DRAW x(b)-x(a), y(b)-y(a)`

Wrapping this in a GO SUB means any part of the program can draw a line between any two nodes by setting `a` and `b` and calling the subroutine. The cursor system, the undo system and the completion check will all use this same subroutine.

## Why GO SUB?

Sinclair BASIC does not have named functions or procedures. GO SUB jumps to a line number and RETURN comes back. It is the only way to reuse code without duplicating it. For Lattice, where line-drawing happens in several contexts, a subroutine avoids repeating the same five lines of code in multiple places.

## Try This

**Connect all edges.** Draw lines between nodes 1-2, 2-3, 3-4 and 4-1 to form a closed shape. How many GO SUB calls do you need?

**Add colour as a parameter.** Set a variable `c` before calling GO SUB, and have the subroutine use `INK c` instead of always using white. This will be useful later for different line colours.
