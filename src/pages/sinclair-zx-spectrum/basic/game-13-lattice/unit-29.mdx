Every game needs a first impression. The title screen shows the game name, explains the controls, and sets the visual tone. For Lattice, the title screen uses the same pixel graphics as the game itself — circles and lines forming a decorative pattern around the title text.

## How It Works

**Lines 1600-1620** clear the screen and set the border to black. The title screen starts with a clean slate.

**Lines 1630-1660** draw a decorative lattice pattern using CIRCLE and DRAW. Several nodes are placed in a symmetrical pattern with lines connecting them, creating a visual preview of what the game looks like. The pattern uses the game's colour scheme — green circles, white lines.

**Lines 1670-1690** print the game title "LATTICE" in large text using PRINT AT. The title is centred on the screen. INK 6 (yellow) makes it stand out against the decorative pattern.

**Lines 1700-1730** display the controls below the title:

- QAOP — Move cursor
- SPACE — Select node
- U — Undo
- H — Hint

**Lines 1740-1750** show "PRESS SPACE TO START" at the bottom of the screen, then wait for a key press with `PAUSE 0`. PAUSE 0 waits indefinitely until the player presses any key.

## PAUSE 0 for Waiting

`PAUSE 0` is the standard Sinclair BASIC way to wait for a key press. Unlike an INKEY$ loop, it does not consume CPU time. The program halts completely until a key is pressed. For title screens and "press any key" prompts, PAUSE 0 is cleaner and simpler than polling INKEY$ in a loop.

## Visual Branding

The decorative lattice pattern on the title screen serves two purposes. It shows the player what the game looks like before they start, and it establishes the visual identity — circles and lines on a black background. The title screen feels like part of the game rather than a separate text menu.

## Try This

**Design your own title pattern.** Change the decorative lattice to a different arrangement. Try a circular pattern or an asymmetric design.

**Add colour animation.** Cycle the border colour through several values with short PAUSE delays before settling on black. This adds a brief flash of colour when the title screen appears.
