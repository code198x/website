When the mandatory capture rule rejects a simple move, the player needs to know which piece can capture. This unit enhances the scan to report the position of a piece with an available capture, so the error message is helpful rather than just restrictive.

## How It Works

**Line 1684** now saves the position of the capturing piece in variables `y` (column) and `s` (row) alongside setting `z = 1`. When the scan finds a piece that can capture, it records where that piece is.

**Line 993** uses these coordinates in the error message: "Capture with C3" (for example). This tells the player exactly which piece has a mandatory capture available. `CHR$(64 + y)` converts the column number back to a letter.

## Helpful Error Messages

Compare these two error messages:

- "You must capture" - tells the player what they cannot do, but not what they should do
- "Capture with C3" - tells the player exactly where to look

Good error messages guide the player toward the correct action. In a game with 12 pieces on each side, "you must capture" forces the player to mentally scan the entire board for available captures. Naming the piece saves that effort.

## Systematic Search

The scan subroutine performs a systematic search of the board. It visits every square in order (row 1 column 1, row 1 column 2, and so on), checks whether the square holds the current player's piece, and then checks all four diagonal directions for a capture. The first valid capture it finds terminates the search.

This early-exit optimisation matters on the Spectrum. Scanning all 64 squares in all 4 directions would be 256 checks. Stopping at the first hit means the search is usually much faster than worst-case.

## Try This

**Test with multiple capturable pieces.** Set up a position where two different pieces could capture. The scan reports the first one it finds (scanning from row 1, column 1). Does the reported piece match what you expect?

**Show all captures.** Modify the scan to not return early. Instead, count how many pieces can capture and display the total. This is more complex but gives the player full information.
