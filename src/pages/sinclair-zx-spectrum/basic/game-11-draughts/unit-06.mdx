Previous games used INKEY$ for real-time input. Draughts is different. Players type a move as a coordinate pair like "A3 B4", meaning "move the piece at column A, row 3 to column B, row 4". The program must parse this string into four numbers: source column, source row, destination column, destination row.

## How It Works

**Line 860** uses `INPUT` to read a string from the player. Unlike INKEY$ which grabs a single keypress, INPUT waits for the player to type a full string and press Enter.

**Line 870** checks the string length. A valid move like "A3 B4" has at least 5 characters. If the string is too short, it shows an error and loops back.

**Lines 880-910** parse the string into four variables. `CODE m$(1)` gives the character code of the first letter. Subtracting 64 converts it to a column number (A=1, B=2, and so on). `VAL m$(2 TO 2)` extracts the row number from the second character.

**Lines 920-930** validate the range. All four values must be between 1 and 8. If any coordinate is out of range, the player sees "Invalid source" or "Invalid target" and tries again.

## String Parsing

Parsing means breaking a string apart and extracting useful values. The move string "C3 D4" contains four pieces of information packed into five characters:

| Position | Character | Meaning | Extraction |
|----------|-----------|---------|------------|
| 1 | C | Source column | `CODE m$(1) - 64` = 3 |
| 2 | 3 | Source row | `VAL m$(2 TO 2)` = 3 |
| 3 | (space) | Separator | ignored |
| 4 | D | Destination column | `CODE m$(4) - 64` = 4 |
| 5 | 4 | Destination row | `VAL m$(5 TO 5)` = 4 |

The variables `p` and `q` hold the source (column and row). The variables `u` and `v` hold the destination. These four values drive every validation check that follows.

## Try This

**Display the parsed values.** After parsing, add lines to print "From: C3" and "To: D4" using `CHR$(64 + p)` and the row numbers. This confirms the parsing works before we add move validation.

**Accept lowercase.** The CODE values for lowercase letters are different. Try typing "a3 b4" and see what happens. You could convert to uppercase by checking the code range.
