In draughts, a piece that reaches the far side of the board becomes a king. Kings are more powerful - they can move backward as well as forward. This unit promotes pieces when they land on the back row, changing their array value and display character.

## How It Works

**Line 1025** checks if Player 1's piece has reached row 8 (the opponent's back row). If the piece value is 1 (ordinary piece), it changes to 3 (Player 1 king). Two ascending BEEPs celebrate the promotion.

**Line 1026** does the same for Player 2. When a Player 2 piece reaches row 1, its value changes from 2 to 4 (Player 2 king).

**Lines 660-670** in the draw pieces subroutine handle the new values. A king (value 3 or 4) is drawn as "K" with BRIGHT 1, making it stand out from ordinary pieces.

**Lines 1240-1250** in the draw cell subroutine also handle kings, so that kings display correctly after moving.

## Extended Array Values

The board array now uses four values:

| Value | Meaning | Display |
|-------|---------|---------|
| 0 | Empty | space |
| 1 | Player 1 piece | red "o" |
| 2 | Player 2 piece | green "o" |
| 3 | Player 1 king | bright red "K" |
| 4 | Player 2 king | bright green "K" |

This is a simple form of polymorphism. The array value encodes both the owner (odd = Player 1, even = Player 2) and the type (1-2 = piece, 3-4 = king). The draw routine checks each value and applies the correct visual.

## Promotion Timing

Notice that promotion happens in the make-move subroutine, after the piece is placed at its new position but before the screen updates. This ensures the draw-cell routine sees the updated value and draws a "K" instead of "o" on the very first display. The player sees the piece arrive at the back row already crowned.

## Try This

**Rush a piece to the back row.** Move one piece forward as quickly as possible while the opponent cooperates. Watch it transform into a "K" with the ascending sound effect.

**Check the source validation.** After promoting a king, confirm that Player 1 can still select it (the validation now needs to accept values 1 and 3). The updated lines 920 and 930 check for both values.
