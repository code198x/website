## What You'll Build

A complete two-player draughts (checkers) game on an 8x8 board. Red and green pieces move diagonally, capture by jumping, and become kings on the back row. The game enforces every rule: forward-only for ordinary pieces, mandatory captures, multi-jump chains, and win detection.

![Draughts board with pieces in starting positions](/images/sinclair-zx-spectrum/basic/game-11-draughts/gameplay.png)

## Why This Game?

Night Patrol used arrays to store a map. Draughts uses arrays to store *rules*. The board array doesn't just track where pieces are — it encodes what they can do. Value 1 is a red piece that moves forward. Value 3 is a red king that moves in any direction. The array is the game's brain.

This is also the first game with text input. Instead of INKEY$ for real-time control, players type coordinate pairs like "A3 B4". The program parses the string, validates the move against every rule, and either executes it or explains why it's illegal.

At 300 lines, this is the longest program so far. Organising code into subroutines isn't optional anymore — it's survival.

## What You'll Learn

### Phase 1: The Board and Basic Play (Units 1-16)

- **2D arrays as game state** — `DIM b(8,8)` represents the board
- **PRINT AT with PAPER** — alternating square colours
- **Column/row labels** — CHR$ for letter labels
- **Turn-based flow** — tracking whose turn it is
- **INPUT parsing** — converting "A3 B4" into coordinates
- **Move validation** — diagonal check, forward-only, occupied squares
- **Single captures** — jumping over enemy pieces
- **GO SUB architecture** — organising 100+ lines into subroutines

### Phase 2: Full Rules and Polish (Units 17-32)

- **King promotion** — pieces reaching the back row gain new powers
- **King movement** — backward diagonal moves for crowned pieces
- **Mandatory captures** — scanning the board for available jumps
- **Multi-jump chains** — continuing captures from the landing square
- **Win by elimination** — detecting when a player has no pieces
- **Win by no moves** — detecting stalemate
- **Sound design** — distinct sounds for each game event
- **New game option** — replay without restarting the program
- **Title screen** — instructions and controls
