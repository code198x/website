## What You Built

Phase 1 delivers a working two-player draughts game. The main loop at lines 80-150 runs through a clean sequence for each turn:

1. **Display status** - whose turn, captured counts
2. **Clear messages** - remove any old error text
3. **Read input** - parse the move string
4. **Validate source** - check the piece belongs to the player
5. **Check move** - diagonal, forward, occupied, or capture
6. **Execute move** - update array, redraw, switch turns

Invalid moves loop back to the input prompt with a specific error message. Valid moves update the board and pass control to the other player.

## What Works

- 8x8 board with alternating PAPER colours
- 12 red pieces and 12 green pieces in starting positions
- Coordinate labels A-H and 1-8
- Turn tracking with coloured status display
- Input parsing from "A3 B4" format
- Source validation (empty square, wrong player)
- Diagonal and forward-only move checks
- Occupied square rejection
- Single captures with intermediate square removal
- Capture counting and display
- Sound feedback for moves and captures
- Clean subroutine structure

## What is Missing

Kings, mandatory captures, multi-jump chains, and win detection are all Phase 2 features. Right now, a piece that reaches the back row stays an ordinary piece. Players can choose a simple move even when a capture is available. Games end only when the players agree to stop. Phase 2 will enforce the full rules.

## Try This

**Play a full game.** Two people, one keyboard. Play until one side has been eliminated (manually track this for now). Does the game feel fair? Are the controls comfortable?

**Look for bugs.** Try unusual moves. Move from the edge of the board. Capture toward the corner. Enter unexpected input. Any surprising behaviour is a clue about edge cases to handle in Phase 2.
