A player wins draughts by capturing all of the opponent's pieces. After each move, we scan the board to count remaining pieces for each side. If either count reaches zero, the game is over.

## How It Works

**Line 145** calls `GO SUB 1300` after every move to check the win condition.

**Lines 1310-1370** scan the entire board. Two counters track each player's pieces: `a` for Player 1 (values 1 and 3) and `d` for Player 2 (values 2 and 4). Both ordinary pieces and kings are counted.

**Line 1380** checks if Player 1 has no pieces left. If `a = 0`, Player 2 wins. The message appears in green (INK 4) with BRIGHT 1, followed by a three-note victory fanfare.

**Line 1390** checks if Player 2 has no pieces left. If `d = 0`, Player 1 wins with the same fanfare.

**STOP** ends the program after a win. There is no replay option yet (that comes in unit 28).

## Win Detection Timing

The win check happens after the move is executed and the board is updated. This ensures the check sees the current state of the board, including any pieces just captured. It runs on every turn, even when no capture occurred, because the check is fast and the correctness is worth the small overhead.

## Counting Pieces

The scan visits all 64 squares and increments the appropriate counter for each non-empty square. Most squares are empty (especially late in the game), so the loop is quick. Using OR to check both ordinary and king values (`b(r,c) = 1 OR b(r,c) = 3`) counts all of a player's pieces regardless of type.

## Try This

**Win a game.** Play until one player has no pieces left. The victory message and sound should trigger. Does the game stop cleanly?

**Test with one piece each.** Manually set up a board with one piece per player. A single capture should end the game immediately.
