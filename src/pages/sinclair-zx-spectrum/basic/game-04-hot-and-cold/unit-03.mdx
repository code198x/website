## Q/A/O/P Movement

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-03/move.bas" />

![Cursor moved to a new position](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/move.png)

The program stores the key press in `k$` (line 50), then checks which key it was:

- **Q** — up (decrease row)
- **A** — down (increase row)
- **O** — left (decrease column)
- **P** — right (increase column)

Line 130 sends execution back to line 50 to wait for the next key — the cursor keeps moving until you break the program.

## Why Q/A/O/P?

On the Spectrum's rubber keyboard, these four keys sit in a natural diamond shape on the left side. Q is above A (up/down), and O is left of P (left/right). Most Spectrum games used this layout — it became a standard.

## The Game Loop

This program has the basic shape of every game:

1. **Draw** — print the cursor (line 40, then line 120)
2. **Read input** — wait for a key press (lines 50-60)
3. **Update** — erase old position, change `r` or `c` (lines 70-110)
4. **Repeat** — go back to step 2 (line 130)

This read-update-draw loop runs forever. Every game you build from now on will follow this pattern.

## The Problem

Try moving the cursor to the top edge and pressing Q again. Or move to the right edge and press P. The program crashes with an error — the Spectrum can't print outside the screen.

That's what the next unit fixes.

## Try This

**Different keys.** Change the key checks to use cursor keys or any letters you prefer.

**Faster movement.** Remove the `INKEY$` wait loop — use `IF INKEY$ <> "" THEN ...` instead. The cursor moves whenever a key is held down, not just on each press.

## What You've Learnt

- **Q/A/O/P** — the standard Spectrum movement keys
- **k$ = INKEY$** — store the key press in a variable for multiple checks
- **Four IF statements** — one for each direction, each modifying `r` or `c`
- **The game loop** — draw, read input, update, repeat
