You can move a cursor around the screen. Now give it something to find.

## Random Treasure Position

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-05/treasure.bas" />

![Cursor searching for hidden treasure](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/treasure.png)

Lines 20-30 pick a random position for the treasure:

- `LET tr = INT (RND * 22)` — random row from 0 to 21
- `LET tc = INT (RND * 32)` — random column from 0 to 31

The treasure is invisible. The player moves the cursor around blindly until they land on it.

## Detection

Line 150 checks whether the cursor has reached the treasure:

```
IF r = tr AND c = tc THEN GO TO 170
```

Both the row **and** the column must match. If only the row matches, the cursor is on the right line but the wrong column — not found yet.

When found, the program jumps to line 170:

- `BEEP 0.5, 12` — a victory sound
- `PRINT AT r, c; "*"` — replace the cursor with a star
- `PRINT AT 23, 0; "You found it!"` — a message at the bottom

## The Flow

1. Pick a random treasure position (once, at the start)
2. Draw the cursor
3. Wait for a key press
4. Erase the cursor, update position
5. Draw the cursor at the new position
6. Check if cursor = treasure — if yes, celebrate and stop
7. If not, go back to step 3

Line 160 (`GO TO 70`) sends the loop back to wait for input. Line 150 breaks out of the loop when the treasure is found.

## The Problem

Finding the treasure is pure luck — there's no feedback. You wander randomly until you happen to land on it. That could take hundreds of moves.

The next unit fixes this with the "hot and cold" mechanic.

## Try This

**Visible treasure.** Add `PRINT AT tr, tc; "X"` after lines 20-30 to show where the treasure is. Useful for testing, but removes the challenge.

**Bigger target.** Change the detection to check if you're within 1 square: `IF ABS (r - tr) <= 1 AND ABS (c - tc) <= 1 THEN GO TO 170`. The treasure is now a 3×3 area, much easier to find.

## What You've Learnt

- **Random position** — `INT (RND * 22)` for row, `INT (RND * 32)` for column
- **Detection** — check if `r = tr AND c = tc`
- **Game structure** — setup (random position), loop (move and check), end (celebrate)
