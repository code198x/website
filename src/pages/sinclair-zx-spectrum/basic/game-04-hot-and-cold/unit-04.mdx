The previous program crashes if you move past the screen edge. The fix is simple — only move if the new position is valid.

## Boundary Checks

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-04/bounds.bas" />

![Cursor stopped at the top edge](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/bounds.png)

The key change is `AND` on each movement line:

- `IF k$ = "q" AND r > 0` — only move up if not at the top
- `IF k$ = "a" AND r < 21` — only move down if not at the bottom
- `IF k$ = "o" AND c > 0` — only move left if not at the left edge
- `IF k$ = "p" AND c < 31` — only move right if not at the right edge

## AND — Combining Conditions

`AND` means both conditions must be true. `IF k$ = "q" AND r > 0 THEN LET r = r - 1` only moves up when the key is Q **and** the cursor isn't already at row 0.

If either condition is false, the whole thing is false, and `r` stays where it is. The cursor simply doesn't move — no crash, no error.

## The Safe Area

| Edge | Variable | Limit | Why |
|------|----------|-------|-----|
| Top | `r` | `> 0` | Row 0 is the first row |
| Bottom | `r` | `< 21` | Row 21 is the last safe row |
| Left | `c` | `> 0` | Column 0 is the first column |
| Right | `c` | `< 31` | Column 31 is the last column |

We use 21 for the bottom limit (not 23) to keep the cursor away from the system message area.

## Try This

**Shrink the playing area.** Change the limits to `r > 2` and `r < 19`, `c > 2` and `c < 29`. The cursor is confined to a smaller box in the middle of the screen.

**Wrap around.** Instead of blocking movement at the edge, make the cursor wrap: `IF k$ = "p" AND c >= 31 THEN LET c = 0`. Moving right past the edge puts you on the left.

## What You've Learnt

- **AND** — combines two conditions (both must be true)
- **Boundary checking** — test the position before moving
- **Comparison operators** — `>` (greater than) and `<` (less than)
- **The safe area** — rows 0-21, columns 0-31
