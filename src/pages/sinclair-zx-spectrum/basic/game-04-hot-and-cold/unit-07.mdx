One round isn't much of a game. Let's add five rounds with a move counter and total score.

## Five Rounds

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-07/rounds.bas" />

The outer `FOR g = 1 TO 5` loop wraps the entire game. Each round:

1. Clears the screen
2. Picks a new random treasure position
3. Resets the cursor to the centre
4. Resets the move counter to 0
5. Runs the game loop until the treasure is found
6. Shows how many moves that round took

After five rounds, the total score appears.

## The Move Counter

Variable `m` starts at 0 each round (line 90). Every time the player presses a key, line 260 adds 1:

```
LET m = m + 1
```

When the treasure is found, `m` holds the number of moves for that round.

## Total Score

Variable `s` accumulates moves across all rounds. Line 320 adds each round's moves:

```
LET s = s + m
```

After five rounds, line 390 shows the total. Fewer moves is better.

## Two-Note Victory

Lines 280-290 play two notes instead of one:

```
BEEP 0.3, 12
BEEP 0.3, 16
```

A rising pair of notes feels more rewarding than a single beep. The first note is middle C (pitch 12), the second is E (pitch 16).

## Nested Loops

The `FOR g` loop contains the game loop (`GO TO 110`). This is a different kind of nesting — the inner loop isn't a `FOR/NEXT` but a `GO TO` loop that exits with `GO TO 270`. The `NEXT g` on line 350 advances to the next round.

This pattern — a `FOR` loop containing a game loop that breaks out when done — is common in multi-round games.

## Try This

**Best round.** Add a variable `b` that tracks the fewest moves in any round. After each round, check `IF m < b THEN LET b = m`. Show it at the end.

**Three rounds.** Change the `FOR` loop to `FOR g = 1 TO 3` for a quicker game.

**Show moves live.** Add `PRINT AT 0, 20; "Moves: "; m` inside the game loop so the player can see their move count updating in real time.

## What You've Learnt

- **FOR wrapping a game** — `FOR g = 1 TO 5` runs five rounds
- **Move counter** — `LET m = m + 1` each time the player moves
- **Accumulating score** — `LET s = s + m` adds each round to the total
- **PAUSE** — gives the player time to read the round result before the screen clears
