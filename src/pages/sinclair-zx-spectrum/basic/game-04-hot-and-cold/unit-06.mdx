The game needs feedback. Without it, finding the treasure is just random wandering. The classic solution: the border colour changes based on distance.

## Distance Calculation

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-06/hot-cold.bas" />

![Blue border — the treasure is far away](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/hot-cold-start.png)

Line 80 calculates the distance:

```
LET d = ABS (r - tr) + ABS (c - tc)
```

This is **Manhattan distance** — how many steps it would take to walk from the cursor to the treasure, moving only up/down/left/right. If the cursor is 3 rows away and 5 columns away, the distance is 8.

## ABS — Absolute Value

`ABS` removes the sign from a number. `ABS(-5)` is 5. `ABS(3)` is 3.

Why do we need it? If the cursor is *above* the treasure, `r - tr` is negative. If it's *below*, the result is positive. We don't care about direction — just how far away we are. `ABS` gives us the distance regardless of which side we're on.

## Distance to Colour

Lines 100-140 map the distance to a border colour:

| Distance | Border | Meaning |
|----------|--------|---------|
| 0 | — | Found it! |
| 1-3 | Yellow (6) | Hot |
| 4-7 | Red (2) | Warm |
| 8-14 | Magenta (3) | Cool |
| 15-24 | Blue (1) | Cold |
| 25+ | Black (0) | Freezing |

![Magenta border — getting closer](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/hot-cold-blue.png)

Each `IF` statement checks whether `d` falls in a range. Because 48K BASIC has no `ELSE`, we use separate `IF` statements with explicit range checks using `AND`.

## The Game Loop Pattern

This program follows the classic game loop:

1. **Draw** the cursor (line 70)
2. **Calculate** the distance and update the border (lines 80-140)
3. **Read input** — wait for a key (lines 150-160)
4. **Erase** the old cursor (line 170)
5. **Update** the position (lines 180-210)
6. **Loop** back to step 1 (line 220)

When distance hits 0, line 90 breaks out to the celebration code.

## Try This

**Tighter bands.** Change the distance ranges to make the game harder — for example, only show yellow when `d <= 1`. The player gets less guidance.

**Colour the paper.** Instead of (or in addition to) changing the border, set `PAPER` based on distance. The whole screen changes colour as you move.

## What You've Learnt

- **ABS** — returns the absolute value (removes the sign)
- **Manhattan distance** — `ABS(r - tr) + ABS(c - tc)`
- **Chained IF statements** — mapping a value to ranges without ELSE
- **The game loop** — draw, calculate, input, update, repeat
