Once you've READ through all the DATA, trying to READ again gives an error. `RESTORE` rewinds the pointer so you can read the same data again — or jump to a different section entirely.

## RESTORE

![RESTORE demo — rewind and jump to line 300](/images/sinclair-zx-spectrum/basic/game-06-quiz-master/restore.png)

## Two Forms

**`RESTORE`** (no argument) rewinds to the very first DATA statement in the program. The next READ starts from the beginning.

**`RESTORE 300`** jumps to line 300. The next READ pulls from the DATA statement on or after that line. This is how you create sections — different DATA blocks at different line numbers.

## Why This Matters

A quiz with categories needs to load different question sets. Put Science questions at line 800, Geography at line 900, History at line 1000. Then:

```
IF k = 1 THEN RESTORE 800
IF k = 2 THEN RESTORE 900
IF k = 3 THEN RESTORE 1000
```

Each `RESTORE` points the READ head at a different set of questions. The same loop reads whichever set you chose.

## The DATA Pointer

Think of DATA as a tape and READ as a playback head. Each READ advances the head one position. RESTORE rewinds the tape — either to the start or to a specific point. This mental model explains every behaviour: why you get "Out of DATA" (the tape ran out), why RESTORE fixes it (you rewound), and why RESTORE to a line works (you fast-forwarded to a specific spot).

## Try This

**Replay quiz.** After showing the score, ask "Play again? (Y/N)". If yes, `RESTORE` and `GO TO` the start of the quiz loop. The same questions appear again.

**Two sections.** Write two DATA blocks with different themes. Let the player choose which one to use, then RESTORE to the matching line.

## What You've Learnt

- **RESTORE** — rewinds the DATA pointer to the start
- **RESTORE line** — jumps the pointer to a specific line number
- **Sections** — different DATA blocks at different line numbers create categories
- **The tape model** — DATA is a tape, READ is the head, RESTORE rewinds
