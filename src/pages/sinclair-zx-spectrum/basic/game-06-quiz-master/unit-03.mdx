## Storing a Question

Each question needs five pieces of data: the question text, three options, and which option is correct.

## How the DATA Is Structured

```
DATA "What colour is the sky?","Green","Blue","Red",2
```

Five values in order: question, option 1, option 2, option 3, correct answer number. `READ q$, a$, b$, c$, r` pulls all five into variables in one go.

The correct answer is stored as a number (2 means option 2, "Blue"). Comparing `g = r` checks whether the player picked the right one.

## Mixing Types in READ

A single `READ` can pull strings and numbers together. The types must match: `q$` reads a string, `r` reads a number. If they're in the wrong order, you get an error.

## The Display Pattern

Lines 30-70 lay out the question and options with spacing. The numbered format (1, 2, 3) tells the player what to type. This pattern will repeat for every question in the quiz.

## Try This

**Add a fourth option.** Change the DATA to include four choices and update the display. Remember to change the valid range to 1-4.

**Write your own question.** Replace the DATA line with a question you know the answer to. Test that the correct answer number matches the right option.

## What You've Learnt

- **DATA structure** — question, three options, correct answer number
- **READ multiple values** — `READ q$, a$, b$, c$, r` in one statement
- **Checking answers** — compare the player's number against the stored correct answer
