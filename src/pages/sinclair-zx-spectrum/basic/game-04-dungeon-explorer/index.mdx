## What You'll Build

Navigate through dungeon rooms. DATA statements define room layouts, PRINT AT places characters on screen.

Explore a multi-room dungeon. Walls block your path. Keys unlock doors. Treasures await discovery. This game teaches data-driven design — storing level layouts in DATA statements for easy editing and expansion.

## Skills You'll Master

- **DATA and READ statements** — embedded level data
- **Room data storage** — map definitions
- **Character-based maps** — PRINT AT positioning
- **Four-directional movement** — keyboard control
- **Wall collision** — attribute checking
- **Multiple rooms** — screen transitions
- **Inventory basics** — carrying items
- **Door transitions** — room connections
