The player has been firing one bullet at a time for twenty-two units. The double-shot power-up changes that. When a destroyed enemy drops a power-up icon, the player can collect it by moving the ship to the same column as it falls. Once collected, two bullets fly simultaneously — doubling the fire rate and making dense formations much easier to clear.

## How It Works

**The drop trigger** fires when an enemy is destroyed. RND generates a random number. If it falls below a threshold (roughly 1-in-5), a power-up icon appears at the destroyed enemy position. The icon is UDG G (CHR$ 150) — a distinctive checkerboard pattern in cyan.

**The icon falls** downward one cell per frame, like an enemy bomb. It uses the same movement pattern: erase, move down, check boundaries, draw. If it reaches the bottom without being collected, it disappears.

**Collection check** compares the icon position to the player ship position. If they match, the power-up is collected: the `pw` variable is set to 1, a rising BEEP plays, and the icon disappears.

**The bullet system expands.** With `pw` set to 1, pressing SPACE now activates both bullet slots: `d(1)` and `d(2)`. The first bullet fires from the ship column. The second fires from one column to the right, creating a spread. Both bullets move upward and check collisions independently. The existing collision loop already handles both slots because it iterates through the bullet array.

## From One to Two

The bullet arrays were dimensioned as `DIM b(2): DIM c(2): DIM d(2)` from the start — two slots, but only the first was used. The double-shot power-up simply enables the second slot. The movement and collision code already loops through both. No new collision logic is needed. The arrays were designed for this moment.

## Random Drops

The drop chance is a game design decision. Too frequent and the player always has double shot — it stops feeling special. Too rare and the player never sees it. A 1-in-5 chance per enemy destroyed (roughly one power-up per wave) feels right: uncommon enough to be exciting, common enough to be a real part of the game.

## Try This

**Triple shot.** Expand to three bullet slots and fire three bullets in a fan pattern. Does this make the game too easy? At some point, more firepower removes the challenge of aiming.

**Timed power-up.** Make the double shot last for 50 game ticks, then revert to single shot. The player must make the most of the power-up window. Add a countdown to the HUD.
