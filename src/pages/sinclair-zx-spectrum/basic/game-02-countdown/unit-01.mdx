Over the next eight units you'll build a reaction timer. A word appears on screen, you press a key as fast as you can, and the program measures how quickly you reacted. Five rounds, tracking your best time.

But first — a small problem you may have already noticed.

## The Messy Screen

When you load and run a program from tape, the Spectrum leaves the loading messages on screen. Your program's output appears underneath them. Try this:

![Output with loading messages still visible](/images/sinclair-zx-spectrum/basic/game-02-countdown/unit-01-clear-the-screen/without-cls.png)

The "Program: PROGRAM" text at the top is left over from the tape loading. Your program's output starts below it. It works, but it looks messy.

## CLS

`CLS` stands for **clear screen**. It wipes everything and puts the cursor back at the top-left corner.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-countdown/unit-01/with-cls.bas" />

![Clean output after CLS](/images/sinclair-zx-spectrum/basic/game-02-countdown/unit-01-clear-the-screen/with-cls.png)

The loading messages are gone. The output starts cleanly at the top.

`CLS` is almost always the first thing a program does. From now on, every program you write will start with it.

## Why Line 10?

You could put `CLS` on any line number. We use line 10 because it's the first instruction, and the convention is to start at 10. The program runs lines in order — `CLS` on line 10 clears the screen, then line 20 prints, then line 30.

## Try This

**Fill the screen.** Write a program with ten `PRINT` lines (numbered 20 to 110), each printing a different message. Run it once without `CLS`, then add `CLS` on line 10 and run it again. See the difference.

**CLS in the middle.** What happens if you put `CLS` on line 25 — between two PRINT statements? Try it. The first message appears, then the screen clears, then the second message appears. `CLS` works wherever you put it, not just at the start.

## What You've Learnt

- **CLS** — clears the screen and moves the cursor to the top-left corner
- **Why CLS matters** — without it, old text (loading messages, previous output) stays on screen
- **Convention** — most programs start with `CLS` on line 10
