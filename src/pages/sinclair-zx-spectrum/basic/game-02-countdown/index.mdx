## What You'll Build

A word flashes on screen — FIRE, JUMP, DUCK, RUN, or STOP. Press any key as fast as you can. The program measures your reaction time across five rounds and tracks your best score.

## Why This Game?

Lucky Number used `INPUT` — the program waited patiently while you typed an answer. Real games can't do that. They need to check the keyboard *right now*, without stopping everything.

`INKEY$` is the command that makes this possible. It checks whether a key is being pressed at this exact moment, and the program keeps running either way. Every action game on the Spectrum uses this idea.

The reaction timer makes the difference visceral. You'll feel it in your fingers.

## What You'll Learn

- **CLS** — clearing the screen
- **BEEP** — making sounds (duration and pitch)
- **PAUSE** — timed delays
- **INKEY$** — checking the keyboard without waiting
- **String variables** — storing text in variables like `w$`
- **The difference between INPUT and INKEY$** — blocking vs non-blocking input

## Prerequisites

Complete [Game 1: Lucky Number](/sinclair-zx-spectrum/basic/game-01-lucky-number/) first. You'll need `PRINT`, `LET`, `IF/THEN`, `GO TO`, and `RND`.
