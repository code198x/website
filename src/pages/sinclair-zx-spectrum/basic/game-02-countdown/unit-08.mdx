## The Title Screen

```basic
20 CLS
30 PRINT "== Countdown =="
40 PRINT
50 PRINT "React to the word!"
60 PRINT "5 rounds. Be fast."
70 PAUSE 100
```

The game starts with a title and brief instructions, then waits two seconds before beginning. `PRINT` with nothing after it adds a blank line for spacing — you used this in Lucky Number's final version too.

## Best Score Tracking

```basic
80 LET b = 9999
```

The variable `b` tracks the best (lowest) time. It starts at 9999 — an impossibly high number that any real reaction time will beat. This guarantees the first round's time becomes the initial best.

```basic
290 IF t < b THEN PRINT "New best!"
300 IF t < b THEN LET b = t
```

After each round, the program checks whether the player's time `t` is better (lower) than the current best `b`. If it is, it prints "New best!" and updates `b`. The order matters — print the message *before* updating `b`, otherwise the condition would never be true (you can't be less than yourself).

## The Round Counter

```basic
90 LET n = 1
```

The variable `n` tracks which round the player is on. It starts at 1.

```basic
110 PRINT "Round "; n; " of 5"
```

Each round displays its number using semicolons to combine text and the variable on one line.

```basic
320 LET n = n + 1
330 IF n < 6 THEN GO TO 100
```

After each round, `n` goes up by one. If it's still less than 6 (meaning rounds 1-5 aren't all done), the program jumps back to line 100 to start the next round. When `n` reaches 6, the condition is false and the program falls through to the results screen.

This is the same loop pattern as Lucky Number's guess loop, but now it counts rounds instead of waiting for a correct answer.

## Two Sounds

```basic
220 BEEP 0.05, 12
```

A short, high beep when the word appears — "go!"

```basic
270 BEEP 0.1, 0
```

A lower, slightly longer beep when the player presses a key — acknowledgement.

Two different sounds give the player clear audio feedback. The high beep means "react now!" The lower beep means "got it."

## The Results Screen

```basic
340 CLS
350 PRINT "== Results =="
360 PRINT
370 PRINT "Best time: "; b
380 PRINT
390 PRINT "Well done!"
```

After all five rounds, the program clears the screen and shows the player's best time. `CLS` gives a clean break between gameplay and results.

## The Complete Flow

1. **Lines 10-70** — Title screen with instructions. Runs once.
2. **Lines 80-90** — Set up best time and round counter. Runs once.
3. **Lines 100-130** — Round header and "Get ready..." Runs each round.
4. **Lines 140-220** — Random delay, pick a word, display it, beep. Runs each round.
5. **Lines 230-260** — Timing loop. Spins until keypress. Runs each round.
6. **Lines 270-310** — Show time, check for best, pause. Runs each round.
7. **Lines 320-330** — Increment round, loop or fall through. Runs each round.
8. **Lines 340-390** — Results screen. Runs once.

## Try This

**More rounds.** Change `5` to `10` everywhere — line 60, line 110, and line 330 (`IF n < 11`). Ten rounds gives a better chance of improving.

**Average time.** Add `LET s = 0` at the start, `LET s = s + t` after each round, and `PRINT "Average: "; s / 5` on the results screen. Now you see your average reaction time too.

**Two-player.** Play five rounds, note the best time, then `RUN` again and hand the Spectrum to a friend. Compare best times. Lowest wins.

## What You've Learnt

- **Round counter** — `LET n = n + 1` with `IF n < 6 THEN GO TO` creates a counted loop
- **Best score tracking** — start with a high value, update whenever the player beats it
- **Order matters** — check and report *before* updating the best value
- **Two BEEPs** — different sounds for different events give clear feedback
- **Program structure** — title, setup, game loop, results — a pattern for any game

## What You've Built

You've written a complete reaction timer from scratch. It took eight units, building on Lucky Number's foundation and adding new concepts:

1. **CLS** — clear the screen
2. **BEEP** — make sounds with duration and pitch
3. **PAUSE** — timed delays
4. **INKEY$** — check the keyboard without waiting
5. **String variables** — store text in `w$`
6. **Busy loops** — spin until something happens
7. **Loop counters** — measure time and count rounds
8. **Best score tracking** — remember the player's best performance

You now have two models of input: `INPUT` (wait and ask) and `INKEY$` (check right now). Every game from here on uses `INKEY$` for real-time gameplay. The next game will put these skills to work in a new way.
