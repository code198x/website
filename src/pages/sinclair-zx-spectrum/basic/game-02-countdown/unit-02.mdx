The reaction timer needs to make a sound when the word appears — a short, sharp beep to signal "go!" The Spectrum has a built-in speaker, and `BEEP` is the command that drives it.

## Your First Sound

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-countdown/unit-02/beep-simple.bas" />

Run it. You'll hear a one-second tone at middle C.

`BEEP` takes two numbers:

1. **Duration** — how long the note lasts, in seconds. `1` means one second. `0.5` means half a second. `0.1` means a tenth of a second — a quick blip.
2. **Pitch** — how high or low the note is. `0` is middle C. Positive numbers go higher, negative numbers go lower. Each step is one semitone.

So `BEEP 1, 0` means "play middle C for one second."

## A Simple Tune

You can play several notes in a row. The Spectrum plays each one before moving to the next line:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-countdown/unit-02/beep-tune.bas" />

![The tune program after running](/images/sinclair-zx-spectrum/basic/game-02-countdown/unit-02-making-sounds/beep-tune.png)

Run it and you'll hear a short melody. Each `BEEP` plays and finishes before the next one starts. The duration controls the rhythm — `0.4` for longer notes, `0.2` for shorter ones. The pitch controls the melody — `0` for C, `2` for D, `4` for E, `5` for F.

Nothing appears on screen because `BEEP` only makes sound. It doesn't print anything.

## Pitch Reference

Here are some useful pitch values:

| Pitch | Note | Character |
|-------|------|-----------|
| 0 | C (middle) | Calm, neutral |
| 2 | D | |
| 4 | E | |
| 5 | F | |
| 7 | G | |
| 9 | A | |
| 12 | C (high) | Bright, alert |
| -12 | C (low) | Deep, ominous |

For the reaction timer, you'll use short, high-pitched beeps — they feel urgent. Something like `BEEP 0.05, 12` — a twentieth of a second at high C. Try it.

## Try This

**Alarm clock.** Write three `BEEP` lines that alternate between pitch 12 and pitch 0, with short durations (0.1 seconds each). It should sound like an alarm.

**Doorbell.** `BEEP 0.3, 7` then `BEEP 0.3, 4` — ding-dong. Experiment with the pitches until it sounds right to you.

**Error sound.** `BEEP 0.5, -10` — a long, low buzz. You'll use something like this later for a "wrong" feedback sound.

## What You've Learnt

- **BEEP duration, pitch** — plays a note for a given number of seconds at a given pitch
- **Duration** — measured in seconds; `0.1` is a quick blip, `1` is a full second
- **Pitch** — `0` is middle C; positive numbers go higher, negative go lower; each step is one semitone
- **Sequence** — multiple BEEP lines play one after another
