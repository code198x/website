## What You'll Build

Pac-Man style maze game. Collect dots, avoid ghosts, eat power pills to turn the tables.

Navigate corridors. Eat every dot. Avoid the ghosts — unless you've eaten a power pill. Each ghost has a personality: some chase, some ambush, some patrol. Understanding their behaviour is key to survival.

## Skills You'll Master

- **Tile-based mazes** — constrained movement
- **Corridor navigation** — direction changes
- **Ghost AI personalities** — scatter, chase modes
- **Power-ups** — temporary state changes
- **Wrap-around edges** — tunnel mechanics
- **Level progression** — speed increases
- **Ghost respawn** — return to home
- **Bonus fruit** — score opportunities

## Prerequisites

Complete **Game 5: Ink War** first.
