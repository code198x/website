## What You'll Build

Isometric exploration game. Knight Lore territory — the prestige Spectrum technique.

This is the technique that made Ultimate famous. Isometric projection transforms flat tiles into a 3D world. Objects stack and overlap. The painter's algorithm determines what's in front. It's a completely different way of building games.

## Skills You'll Master

- **Isometric projection** — the mathematics
- **3D coordinate systems** — X, Y, Z axes
- **Depth sorting** — painter's algorithm
- **Isometric movement** — diagonal controls
- **3D collision** — checking in three dimensions
- **Attribute clash management** — isometric solutions
- **Room-based structure** — connected spaces
- **Object interaction** — picking up, using
- **Push block puzzles** — environmental challenges
- **64+ rooms** — large explorable world
