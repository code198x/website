## Transition Types

| Type | Description | Complexity |
|------|-------------|------------|
| Instant | No transition | None |
| Fade | Brightness change | Low |
| Wipe | Progressive reveal | Medium |
| Cascade | Attribute ripple | Medium |

## Attribute Wipe

Clear attributes row by row:

```asm
transition_wipe:
            ld      b, 24           ; 24 rows
            ld      hl, ATTR_BASE
.row:
            push    bc
            ld      b, 32           ; 32 columns
.col:
            ld      (hl), 0         ; Clear attribute
            inc     hl
            djnz    .col
            ; Delay between rows
            call    short_delay
            pop     bc
            djnz    .row
            ret
```
