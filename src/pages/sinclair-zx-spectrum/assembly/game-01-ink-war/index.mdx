## What You're Building

Two players. One board. 64 cells. Control the majority to win.

Ink War is a territory control game where you and your opponent take turns claiming 8x8 attribute cells. Each cell you claim changes colour to show your territory. When the board is full, whoever controls more cells wins.

## Why This Game?

The ZX Spectrum's attribute system is what made Spectrum games look distinctly *Spectrum*. Each 8x8 pixel block shares one foreground colour and one background colour. This creates the infamous "colour clash" when sprites overlap.

But here, the constraint becomes the game. Our board *is* made of 8x8 cells. No clash — just strategy.

## What You'll Learn

By the end of this game, you'll understand:

- **Attribute memory** — How the Spectrum stores colour per 8x8 cell
- **Keyboard input** — Reading the keyboard matrix
- **Game state** — Managing turns, valid moves, and win conditions
- **Simple AI** — Building an opponent that plays sensibly
- **Sound** — Using the beeper for feedback

## Prerequisites

This is Game 1. No prerequisites — just enthusiasm and a willingness to type code into an emulator.

You'll need an emulator (Fuse or ZEsarUX) and an assembler (PasmoNext). If you haven't set these up yet, see [Getting Started](/sinclair-zx-spectrum/getting-started).

## Time Investment

Each unit takes 60-90 minutes. The full game is 16 units, so roughly 16-24 hours total.

Every unit produces something that works. By the end of Unit 1, you'll have a game board drawn on screen using the Spectrum's attribute system.
