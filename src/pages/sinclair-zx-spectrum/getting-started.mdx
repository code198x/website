## What You Need

To develop for the ZX Spectrum, you need:

1. **A way to compile** - our Docker toolchain handles this
2. **An emulator** - runs your programs (install natively for best experience)

## Docker Toolchain (Recommended)

Our Docker image includes pasmonext assembler and zmakebas — everything needed to compile Spectrum programs.

```bash
docker pull code198x/sinclair-zx-spectrum
```

To compile a program:

```bash
docker run --rm -v "$(pwd)":/code code198x/sinclair-zx-spectrum \
  pasmo --tapbas hello.asm hello.tap
```

Your compiled `.tap` file appears in your current directory, ready to run.

## Installing the Emulator

We recommend **Fuse** (Free Unix Spectrum Emulator). Install it natively for smooth, responsive testing.

### macOS

```bash
brew install --cask fuse-emulator
```

Or download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/).

### Linux

```bash
# Ubuntu/Debian
sudo apt install fuse-emulator-gtk

# Fedora
sudo dnf install fuse-emulator
```

### Windows

Download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/).

## Your First Program

Create a file called `hello.asm`:

```asm
            org 32768

start:
            ; Set border to blue
            ld a, 1
            out (254), a

            ; Infinite loop
.hang:
            halt
            jr .hang

            end start
```

## The Workflow

```bash
# Compile
docker run --rm -v "$(pwd)":/code code198x/sinclair-zx-spectrum \
  pasmo --tapbas hello.asm hello.tap

# Run
fuse hello.tap
```

Or drag the `.tap` file onto the Fuse window. The tape will auto-load and run. You should see a blue border.

## Project Structure

For the Code Like It's 198x lessons, organise your files like this:

```
inkwar/
├── inkwar.asm      # Your source code
└── inkwar.tap      # Compiled output
```

## Key Addresses

| Address | Purpose |
|---------|---------|
| 16384 ($4000) | Screen memory start |
| 22528 ($5800) | Attribute memory start |
| 23296 ($5B00) | System variables |
| 32768 ($8000) | Safe location for code |

## Alternative: Native Assembler

If you prefer not to use Docker, you can install pasmo directly.

### macOS (Homebrew)

```bash
brew install pasmo
```

### Linux

```bash
# Ubuntu/Debian
sudo apt install pasmo

# Or build from source
git clone https://github.com/mkoloberdin/pasmo.git
cd pasmo
./configure && make && sudo make install
```

### Windows

Download from the [Pasmo releases page](https://pasmo.speccy.org/) and add to your PATH.

With native pasmo, compile directly:

```bash
pasmo --tapbas hello.asm hello.tap && fuse hello.tap
```
