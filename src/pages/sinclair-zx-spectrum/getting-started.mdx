## What You Need

To develop for the ZX Spectrum, you need:

1. **An assembler** - converts your assembly code to machine code
2. **An emulator** - runs your programs without real hardware

## Installing the Assembler

We use **PasmoNext**, a modern Z80 assembler that outputs Spectrum-compatible formats.

### macOS (Homebrew)

```bash
brew install pasmo
```

### Linux

```bash
# Ubuntu/Debian
sudo apt install pasmo

# Or build from source
git clone https://github.com/mkoloberdin/pasmo.git
cd pasmo
./configure && make && sudo make install
```

### Windows

Download from the [Pasmo releases page](https://pasmo.speccy.org/) and add to your PATH.

### Verify Installation

```bash
pasmo
```

You should see usage information.

## Installing the Emulator

We recommend **Fuse** (Free Unix Spectrum Emulator).

### macOS

```bash
brew install --cask fuse-emulator
```

Or download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/).

### Linux

```bash
# Ubuntu/Debian
sudo apt install fuse-emulator-gtk

# Fedora
sudo dnf install fuse-emulator
```

### Windows

Download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/).

## Your First Program

Create a file called `hello.asm`:

```asm
            org 32768

start:
            ; Set border to blue
            ld a, 1
            out (254), a

            ; Infinite loop
.hang:
            halt
            jr .hang

            end start
```

## Building

```bash
pasmo --tapbas hello.asm hello.tap
```

This creates a `.tap` file with a BASIC loader that auto-runs your machine code.

## Running

### Fuse

```bash
fuse hello.tap
```

Or drag the `.tap` file onto the Fuse window.

The tape will auto-load and run. You should see a blue border.

## Project Structure

For the Code Like It's 198x lessons, organise your files like this:

```
inkwar/
├── inkwar.asm      # Your source code
└── inkwar.tap      # Compiled output
```

## Key Addresses

| Address | Purpose |
|---------|---------|
| 16384 ($4000) | Screen memory start |
| 22528 ($5800) | Attribute memory start |
| 23296 ($5B00) | System variables |
| 32768 ($8000) | Safe location for code |
