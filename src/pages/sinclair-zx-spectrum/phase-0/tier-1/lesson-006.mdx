You've mastered DATA/READ/RESTORE for sequential data access. But what if you need random access—jumping to any question, searching by keyword, or building dynamic databases? Arrays solve this. Think of arrays as numbered boxes: Q$(1), Q$(2), Q$(3)... Each holds a value you can access instantly by index.

Every game with high score tables, inventories, or level maps uses arrays. Elite's galaxy is arrays of star systems. Manic Miner's levels are arrays of tile data. You'll build a complete knowledge database with browse, search, and random quiz modes—bringing together everything learnt in this arc.

## The One-Minute Tour

- **DIM** creates arrays (numbered lists of variables)
- **Array indices** start at 1 by default (Q$(1), Q$(2)...)
- Load arrays from DATA for flexible data manipulation
- Access any element instantly: Q$(5), Q$(10), Q$(COUNT)
- Use loops to search, display, or process array contents
- This is a **synthesis lesson**—combining DATA, RESTORE, GOSUB, and arrays

## Your First Array

```basic
10 REM Array Demo
20 REM Simple array demonstration
30 DIM NAME$(5)
40 DIM SCORE(5)
50 CLS
60 PRINT AT 2,8;"LOADING DATA..."
70 FOR I=1 TO 5
80 READ NAME$(I),SCORE(I)
90 NEXT I
100 CLS
110 PRINT AT 3,7;"HIGH SCORES LIST"
120 PRINT AT 5,0;"Rank  Name         Score"
130 PRINT AT 6,0;"-------------------------"
140 FOR I=1 TO 5
150 PRINT AT 7+I,2;I;".   ";NAME$(I);TAB 17;SCORE(I)
160 NEXT I
170 PAUSE 0
200 DATA "Alice",9500
210 DATA "Bob",8700
220 DATA "Charlie",7200
230 DATA "Diana",6800
240 DATA "Eve",5400
```

**Run this** and see arrays in action!

## How Arrays Work

### Declaration with DIM

```basic
30 DIM NAME$(5)
40 DIM SCORE(5)
```

DIM creates arrays. `DIM NAME$(5)` creates five string variables: NAME$(1), NAME$(2), NAME$(3), NAME$(4), NAME$(5). `DIM SCORE(5)` creates five numeric variables.

**Must DIM before use.** Try to use NAME$(1) without DIM, and you get "Subscript wrong" error.

### Loading Arrays

```basic
70 FOR I=1 TO 5
80 READ NAME$(I),SCORE(I)
90 NEXT I
```

Loop five times. Each iteration reads two values from DATA into the next array slot:
- I=1: READ into NAME$(1) and SCORE(1) → "Alice", 9500
- I=2: READ into NAME$(2) and SCORE(2) → "Bob", 8700
- ...

After the loop, all five array elements hold data.

### Accessing Arrays

```basic
150 PRINT AT 7+I,2;I;".   ";NAME$(I);TAB 17;SCORE(I)
```

Access array elements by index: NAME$(I) where I=1,2,3,4,5. Just like regular variables, but with numbers to select which one.

## Building Fact Finder

Now create a complete knowledge database system that loads facts dynamically and provides three modes: browse, search, and random quiz.

Due to length, here's the complete program structure:

**Lines 200-350:** Main menu with three options

Key techniques:
- **Sentinel pattern**: Use "END" to detect when DATA finishes

- **RND**: Generate random question indices for quiz mode
