Collecting items in an empty maze feels safe. Add an enemy that hunts you—suddenly every move matters. Pac-Man ghosts. Manic Miner spiders. Jet Set Willy monsters. Enemies create tension, demand strategy, transform safe exploration into desperate survival.

This lesson introduces AI—Artificial Intelligence. Not complex neural networks or machine learning. Simple, elegant logic: compare positions, move closer. Six lines of BASIC code create behavior that feels alive, creates challenge that demands player skill.

The enemy tracks you. Follows you. Corners you. This changes everything. No longer wander freely collecting items—now plan routes that collect treasures while avoiding death. Risk versus reward. Strategy versus reaction. This is game design.

## The One-Minute Tour

- **Simple AI** - Compare positions, move toward target
- **Chase algorithm** - Close distance on X axis, close distance on Y axis
- **Multiple moving objects** - Track player and enemy separately
- **Collision detection** - Check if positions match
- **Lives system** - Allow mistakes without instant game over
- **Game pacing** - PAUSE controls enemy speed/difficulty
- Every action game uses variations of this AI pattern

## How This Works

### Tracking Two Objects

```basic
50 REM Player start
60 LET PX=5: LET PY=5
70 PRINT AT PY,PX;"@"
80 REM Enemy start
90 LET EX=25: LET EY=15
100 INK 2
110 PRINT AT EY,EX;"!"
```

Player uses PX, PY variables. Enemy uses EX, EY variables. Both objects have independent positions tracked separately. Player starts top-left (5,5), enemy starts bottom-right (25,15)—maximum distance apart.

Red enemy (INK 2) visually distinct from white player (INK 7). Instant recognition—that thing chasing you is dangerous.

**Variable naming pattern:** P prefix = player, E prefix = enemy. Later add M prefix for missiles, B for bullets, I for items. Systematic naming prevents confusion when managing multiple objects.

### The Chase Algorithm

```basic
240 REM Enemy AI
250 LET OEX=EX: LET OEY=EY
260 IF EX<PX THEN LET EX=EX+1
270 IF EX>PX THEN LET EX=EX-1
280 IF EY<PY THEN LET EY=EY+1
290 IF EY>PY THEN LET EY=EY-1
```

This is AI. Four lines create behavior that feels intelligent:

**Line 260:** IF EX&lt;PX - If enemy X is less than player X, enemy is LEFT of player. Move enemy RIGHT (EX+1) to close distance.

**Line 270:** IF EX>PX - If enemy X is greater than player X, enemy is RIGHT of player. Move enemy LEFT (EX-1) to close distance.

**Line 280:** IF EY&lt;PY - If enemy Y is less than player Y, enemy is ABOVE player. Move enemy DOWN (EY+1) to close distance.

**Line 290:** IF EY>PY - If enemy Y is greater than player Y, enemy is BELOW player. Move enemy UP (EY-1) to close distance.

**Result:** Enemy always moves one step closer on both axes. Diagonal chase emerges naturally—if enemy is left AND above, both X and Y adjustments happen same frame. Enemy moves diagonally toward player automatically.

**Why this works:** Every frame, enemy closes distance. Can't escape permanently—enemy relentlessly pursues. Creates tension. Player must maneuver, use space strategically, collect items before caught.

### Collision Detection

```basic
340 REM Check collision
350 IF PX=EX AND PY=EY THEN GOSUB 1000
```

After all movement completes, check if positions match. Both X coordinates equal AND both Y coordinates equal = same cell = collision = game over.

**AND operator critical:** Not enough for X coordinates to match (player and enemy same column but different rows). Both must match simultaneously.

**Timing matters:** Check collision *after* both player and enemy move. If checked before enemy movement, player escapes even when enemy catches up same frame.

### Game Pacing

```basic
360 REM Slow down
370 PAUSE 3
380 GO TO 130
```

PAUSE 3 = 3/50 second delay = 0.06 seconds between frames. Without this, game runs at full Z80 CPU speed—hundreds of frames per second. Enemy reaches player instantly. Unplayable.

PAUSE slows loop to ~16 frames per second (1/0.06). Playable pace. Player can react, plan moves, develop strategy.

**Difficulty tuning:** Change PAUSE value:
- PAUSE 1 = fast, challenging (0.02s per frame)
- PAUSE 5 = slow, easier (0.1s per frame)
- PAUSE 10 = very slow (0.2s per frame)

One number controls entire game difficulty. Essential tuning parameter.

### Old Position Tracking

```basic
140 LET OPX=PX: LET OPY=PY
...
210 IF PX<>OPX OR PY<>OPY THEN PRINT AT OPY,OPX;" "
```

Store old player position before movement. After movement, compare new to old. If different (PX not equal OPX OR PY not equal OPY), player moved—erase old position.

**Why conditional erase?** If player didn't move (no key pressed), don't erase current position—would make player flicker (erase then immediately redraw). Only erase when actually moving.

Same pattern for enemy (lines 250, 310). Both objects track old positions for clean erasing.

## Understanding the Complete Game

### Integrating Collectibles and Enemy

Game now has three win/lose conditions:
1. Collect all stars (SCORE=ITEMS) → Victory (GOSUB 4000)
2. Get caught by enemy → Lose life (GOSUB 3000)
3. Lose all lives → Game Over (GOSUB 5000)

Creates dynamic tension: collect items while avoiding enemy. Can't focus solely on collection—must watch enemy position, plan escape routes, time movements carefully.

### Smart Enemy AI

```basic
580 REM Enemy AI
590 LET OEX=EX: LET OEY=EY
600 IF EX<PX THEN LET NEX=EX+1: ELSE LET NEX=EX
610 IF EX>PX THEN LET NEX=EX-1
620 IF EY<PY THEN LET NEY=EY+1: ELSE LET NEY=EY
630 IF EY>PY THEN LET NEY=EY-1
640 REM Check enemy destination
650 IF SCREEN$(NEY,NEX)=" " THEN LET EX=NEX: LET EY=NEY
```

Enemy no longer moves blindly. Calculates new position (NEX, NEY), then checks SCREEN$ at destination. Only moves if destination is space—respects walls.

**Pattern evolution:** NEX, NEY = "new enemy X, new enemy Y". Temporary variables like player's NX, NY. Calculate intended move, verify safety, commit if valid.

Line 650: IF SCREEN$(NEY,NEX)=" " - Only update actual position (EX, EY) if destination empty. If blocked by wall, enemy stays put this frame.

**Result:** Enemy chases through maze following valid paths. Won't walk through walls. Follows you around corners. Feels intelligent—adapts to maze layout.

### Lives System

```basic
340 LET LIVES=3
...
3000 REM Lose life
3010 LET LIVES=LIVES-1
3020 PRINT AT 0,25;LIVES
3030 IF LIVES=0 THEN GOSUB 5000
3040 BEEP 0.2,5
3050 REM Reset positions
3060 PRINT AT PY,PX;" "
3070 PRINT AT EY,EX;" "
3080 LET PX=15: LET PY=5
3090 LET EX=15: LET EY=18
```

Three lives provide forgiveness. First collision isn't instant game over—lose one life, reset positions, continue playing.

**Death sequence:**
1. Decrement LIVES
2. Update display
3. Check if zero → game over if true
4. Play death sound (low-pitched BEEP)
5. Erase both player and enemy
6. Reset both to starting positions
7. Redraw both
8. PAUSE 50 (one second break before resuming)

PAUSE 50 critical—gives player moment to recover, see what happened, prepare for resumed play. Without pause, game instantly restarts—disorienting, feels unfair.

**Game design:** Lives system transforms instant death into mistake tolerance. Player learns enemy behavior through multiple attempts. Difficulty curve: first life spent learning, second life applying lessons, third life achieving victory.

### Victory Metrics

```basic
4060 PRINT AT 13,8;"Lives left: ";LIVES
```

Victory screen shows remaining lives. Collected all stars with 3 lives = perfect run. Collected with 1 life = narrow victory. Same win condition, different accomplishment levels. Adds replayability—not just win, but win perfectly.

## How Enemy AI Scales

### Basic Pattern

Every chase enemy uses variations of:
```basic
IF enemy_x < player_x THEN move enemy right
IF enemy_x > player_x THEN move enemy left
IF enemy_y < player_y THEN move enemy down
IF enemy_y > player_y THEN move enemy up
```

**Pac-Man ghosts:** Each ghost uses this logic plus personality (Red chases directly, Pink aims ahead, Blue/Orange use variations)

**Manic Miner:** Obstacles patrol set paths (different logic), but Kong follows similar chase pattern

**Jet Set Willy:** Enemies move in patterns, but when triggered switch to chase behavior

### Multiple Enemies

Add second enemy:
```basic
90 LET E1X=25: LET E1Y=15
95 LET E2X=5: LET E2Y=18
...
REM Enemy 1 AI
IF E1X<PX THEN LET E1X=E1X+1
...
REM Enemy 2 AI
IF E2X<PX THEN LET E2X=E2X+1
...
IF PX=E1X AND PY=E1Y THEN GOSUB 3000
IF PX=E2X AND PY=E2Y THEN GOSUB 3000
```

Each enemy has own X, Y variables. Same AI logic applied to each. Check collision with each. Scales to as many enemies as needed (memory permitting).

### Patrol Patterns

Instead of constant chase, add patrol:
```basic
LET PATROL=0
...
IF PATROL=1 THEN GOSUB patrol_routine
IF PATROL=0 THEN GOSUB chase_routine
...
patrol_routine:
REM Move in set pattern
IF EX&lt;20 THEN LET EX=EX+1: ELSE LET EX=5
RETURN
```

Enemy patrols area normally. When player enters trigger zone, switch to chase. Creates surprise—enemy appears passive, suddenly attacks when approached.

## Experiment: Different Speeds

Make enemy faster or slower:
```basic
REM Fast enemy (moves twice per player move)
IF EX<PX THEN LET EX=EX+2
IF EX>PX THEN LET EX=EX-2
```

Or make enemy move every other frame:
```basic
LET ETURN=1-ETURN
IF ETURN=1 THEN GOSUB enemy_ai
```

ETURN toggles 0/1 each frame. Enemy only moves when ETURN=1. Half speed enemy—easier to escape.

## Experiment: Smart Evasion

Make player automatically avoid if enemy close:
```basic
IF ABS(EX-PX)&lt;3 AND ABS(EY-PY)&lt;3 THEN LET DANGER=1: ELSE LET DANGER=0
IF DANGER=1 THEN INK 1: PRINT AT 1,25;"DANGER!"
```

ABS function returns absolute value (distance ignoring direction). If enemy within 3 cells horizontally AND vertically, display warning. Helps player react before caught.

## Why This Pattern Matters

**Foundation of opponents:**

Every game with opposing forces uses position comparison:

- **Chase enemies:** Move toward player (Pac-Man ghosts, Manic Miner obstacles)
- **Flee enemies:** Move away from player (opposite comparisons)
- **Homing missiles:** Same chase logic for projectiles
- **Following allies:** Companion characters using same algorithm

Simple AI creates emergent complexity. Two enemies chasing creates pincer attacks. Enemy plus maze creates tactical decisions. Speed variations create difficulty levels.

**Core insight:** Intelligence isn't complex code. It's simple rules creating interesting behavior. Four IF statements create enemy that feels smart, requires player skill to defeat, makes games challenging.
