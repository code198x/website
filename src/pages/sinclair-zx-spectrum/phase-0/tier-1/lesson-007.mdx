Text adventures and quizzes are powerful, but games need graphics. The Spectrum gives you 256×176 pixels—44,032 individual dots you can light up instantly. PLOT turns pixels on. Loops draw lines. Patterns emerge. This is where games begin: precise control over every pixel on screen.

## The One-Minute Tour

- **PLOT x,y** draws a pixel at coordinates (x,y)
- X ranges 0-255 (left to right)
- Y ranges 0-175 (bottom to top—inverted!)
- Use FOR loops to draw lines and shapes
- Instant response—no waiting for graphics

## Your First Pixels

```basic
10 REM Plot Demo
20 CLS
30 REM Horizontal line
40 FOR X=0 TO 255
50 PLOT X,87
60 NEXT X
70 REM Vertical line
80 FOR Y=0 TO 175
90 PLOT 128,Y
100 NEXT Y
110 PAUSE 0
```

This draws a crosshair—horizontal line through center (Y=87) and vertical line through center (X=128).

## Understanding Coordinates

Spectrum graphics use pixel coordinates, not character blocks:
- **X axis**: 0 (left edge) to 255 (right edge)
- **Y axis**: 0 (bottom) to 175 (top)—Y is inverted!
- Center is approximately (128, 87)

## Drawing Shapes

```basic
10 REM Pixel Patterns
20 CLS
30 REM Draw box
40 FOR X=50 TO 200
50 PLOT X,50
60 PLOT X,125
70 NEXT X
80 FOR Y=50 TO 125
90 PLOT 50,Y
100 PLOT 200,Y
110 NEXT Y
120 REM Diagonal pattern
130 FOR I=0 TO 100
140 PLOT I,I
150 PLOT 255-I,I
160 NEXT I
170 PAUSE 0
```

Draw box outline with four loops (top, bottom, left, right sides), then add diagonal pattern.

## Quick Reference

- `PLOT x,y` - Draw pixel
- `PLOT INK colour;x,y` - Draw in specific colour
- Screen: 256×176 pixels
- Y inverted: 0=bottom, 175=top

## What You've Learnt

- **PLOT** draws individual pixels
- **Pixel coordinates** (0-255, 0-175)
- **FOR loops** create lines and shapes
- **Y axis inverted** (0 at bottom)
