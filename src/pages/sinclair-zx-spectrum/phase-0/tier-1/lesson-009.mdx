The Spectrum's famous "colour clash"—colours apply to 8×8 pixel blocks, not individual pixels. This architectural choice enabled affordable colour graphics in 1982, but created the defining visual aesthetic of Spectrum games.

## Key Concepts

- Colours apply to 8×8 character blocks (32×24 grid)
- ATTR (row,col) reads attribute at position
- INKEY$ reads keyboard without waiting (returns "" if no key pressed)
- Colour clash = can't have multiple colours within one 8×8 block

## Simple Drawing Tool

```basic
60 LET K$=INKEY$
70 IF K$="q" THEN LET Y=Y+1
80 IF K$="a" THEN LET Y=Y-1
90 IF K$="o" THEN LET X=X-1
100 IF K$="p" THEN LET X=X+1
110 IF K$=" " THEN PLOT X,Y
```

INKEY$ checks keyboard without pausing. Empty string if no key pressed. Build interactive tools with continuous input checking.
