Sound effects established, now create music. Store note pitches and durations in DATA, READ and BEEP them in sequence. Add PAUSE for rhythm. Musical sequences emerge from simple commands.

## Key Concepts

- Musical notes as pitch numbers (C=0, D=2, E=4, F=5, G=7, A=9, B=11)
- PAUSE n waits n/50 seconds (PAUSE 50 = 1 second)
- PAUSE 0 waits for keypress
- Combine BEEP duration with PAUSE for spacing

## Music Box

```basic
40 RESTORE
50 READ P,D
60 IF P=999 THEN STOP
70 BEEP D,P
80 PAUSE D*45
90 GO TO 50
100 DATA 0,0.3,2,0.3,4,0.3,5,0.3,7,0.6
```

Read pitch and duration pairs, BEEP the note, PAUSE for timing, repeat. Sentinel value (999) ends sequence.

## What You've Learnt

- Musical note encoding
- PAUSE for timing control
- DATA-driven music sequences
- Combining BEEP and PAUSE for melodies
