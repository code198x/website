Welcome back! You've mastered colours and positioned text. Now let's make your Spectrum interactive. Learn INPUT to receive user responses and IF/THEN to make decisions. Build programs that react to what you type.

Every great game needs interactivity. The Spectrum's INPUT command pauses and waits for your response. IF/THEN tests conditions and chooses what happens next. Together, they let you create conversations, quizzes, and game menus.

## The One-Minute Tour

- **INPUT** pauses and stores what the user types
- **String variables** end with `$` (e.g. `n$` for names)
- **IF condition THEN command** executes only if condition is true
- **Comparison operators**: `=` equals, `<>` not equals, `<` less than, `>` greater than
- **AND** combines multiple conditions (both must be true)
- **PRINT with semicolons** concatenates text and variables

## Your First Interactive Program

Type this into your Spectrum:

```basic
10 REM The Number Oracle
20 REM Interactive INPUT and IF demo
30 CLS
40 PRINT AT 5,5;"THE NUMBER ORACLE"
50 PRINT AT 8,4;"What is your name?"
60 INPUT n$
70 PRINT AT 10,4;"Hello ";n$;"!"
80 PRINT AT 12,2;"I'm thinking of 7..."
90 PRINT AT 13,2;"Guess my number (1-10):"
100 INPUT g
110 IF g=7 THEN PRINT AT 15,6;"Lucky! You got it!"
120 IF g<>7 THEN PRINT AT 15,4;"Sorry! It was 7."
130 PAUSE 0
```

**Run this** by typing `RUN` and pressing ENTER.

The program asks for your name, greets you, then challenges you to guess its number. It responds differently depending on whether you guess correctly. Simple, but this proves you can make the Spectrum react to input.

## How This Works

### Getting User Input

```basic
60 INPUT n$
```

INPUT pauses the program and displays a flashing cursor. Whatever you type gets stored in the variable. The `$` means it's a string variable—it stores text, not numbers. Without `$`, the variable would only store numbers.

**Try typing your name and pressing ENTER.** The program continues with your name stored in `n$`.

### String Variables vs Number Variables

```basic
50 PRINT AT 8,4;"What is your name?"
60 INPUT n$
70 PRINT AT 10,4;"Hello ";n$;"!"
```

Variables ending with `$` store text. Variables without `$` store numbers. Line 60 uses `n$` because names are text. Line 100 uses `g` (no `$`) because guesses are numbers.

**Spectrum quirk:** You can't store text in a number variable or numbers in a string variable. The Spectrum will give an error if you try. Always use `$` for text.

### Making Decisions with IF/THEN

```basic
110 IF g=7 THEN PRINT AT 15,6;"Lucky! You got it!"
120 IF g<>7 THEN PRINT AT 15,4;"Sorry! It was 7."
```

IF tests a condition. If true, THEN executes the command. If false, the Spectrum skips to the next line. Line 110 checks if `g` equals 7. Line 120 checks if `g` does NOT equal 7 (`<>` means "not equal").

**Only one of these lines will execute.** Either you guessed 7 (line 110 runs) or you didn't (line 120 runs). Never both.

### Concatenating Text

```basic
70 PRINT AT 10,4;"Hello ";n$;"!"
```

Semicolons join multiple things together. This line prints "Hello ", then the contents of `n$`, then "!". If you entered "Alice", you'll see "Hello Alice!".

**Without semicolons**, PRINT moves to the next line after each item. Semicolons keep everything on the same line.

## Experiment: Range Checker

Let's use multiple IF conditions with AND logic:

```basic
10 REM Range Checker
20 REM Multiple IF conditions
30 CLS
40 PRINT AT 5,8;"RANGE CHECKER"
50 PRINT AT 8,2;"Enter a number (1-100):"
60 INPUT n
70 CLS
80 PRINT AT 6,4;"You entered: ";n
90 IF n&lt;1 THEN PRINT AT 10,3;"Too low! Try 1-100."
100 IF n>100 THEN PRINT AT 10,3;"Too high! Try 1-100."
110 IF n>=1 AND n<=100 THEN PRINT AT 10,5;"Perfect! In range."
120 IF n>=1 AND n<=100 AND n&lt;50 THEN PRINT AT 12,2;"That's in the lower half!"
130 IF n>=1 AND n<=100 AND n>=50 THEN PRINT AT 12,2;"That's in the upper half!"
140 PAUSE 0
```

This program checks if your number is within range (1-100). If it is, it tells you which half of the range it's in. Try these inputs:

- **-5** → "Too low! Try 1-100."
- **150** → "Too high! Try 1-100."
- **25** → "Perfect! In range." + "That's in the lower half!"
- **75** → "Perfect! In range." + "That's in the upper half!"

Notice how multiple IF statements can all execute. Lines 110, 120, and 130 ALL check if `n` is in range, but only one of the last two will match.

## Understanding Comparison Operators

The Spectrum has six comparison operators:

| Operator | Meaning | Example | True when... |
|----------|---------|---------|--------------|
| `=` | Equals | `IF a=5` | a is exactly 5 |
| `<>` | Not equals | `IF a<>5` | a is anything except 5 |
| `<` | Less than | `IF a&lt;5` | a is 4, 3, 2, 1, 0, -1... |
| `>` | Greater than | `IF a>5` | a is 6, 7, 8, 9... |
| `<=` | Less or equal | `IF a<=5` | a is 5, 4, 3, 2, 1... |
| `>=` | Greater or equal | `IF a>=5` | a is 5, 6, 7, 8, 9... |

You can combine conditions with AND:

```basic
110 IF n>=1 AND n<=100 THEN PRINT "In range"
```

Both conditions must be true. `n` must be greater-or-equal to 1 AND less-or-equal to 100. If either is false, the whole IF is false.

## Quick Reference: INPUT Command

| Syntax | Purpose | Example |
|--------|---------|---------|
| `INPUT variable` | Get number input | `INPUT age` |
| `INPUT variable$` | Get text input | `INPUT name$` |
| `INPUT "prompt";variable` | Show prompt first | `INPUT "Name";n$` |

**Keyboard:**
- Type your answer
- Press ENTER to submit
- CAPS SHIFT + 0 (DELETE) to correct mistakes
- Flashing cursor shows INPUT is waiting

## Quick Reference: IF/THEN Conditionals

| Syntax | Meaning | When THEN executes |
|--------|---------|-------------------|
| `IF a=5 THEN cmd` | Equals | When a is exactly 5 |
| `IF a<>5 THEN cmd` | Not equals | When a is anything except 5 |
| `IF a&lt;5 THEN cmd` | Less than | When a is less than 5 |
| `IF a>5 THEN cmd` | Greater than | When a is greater than 5 |
| `IF a<=5 THEN cmd` | Less or equal | When a is 5 or less |
| `IF a>=5 THEN cmd` | Greater or equal | When a is 5 or more |
| `IF a=5 AND b=10 THEN cmd` | Multiple conditions | When BOTH are true |

**Important:** IF without THEN is a syntax error. You must write both.

## Quick Reference: Variable Types

| Type | Ending | Stores | Example |
|------|--------|--------|---------|
| Number | None | Numbers | `age`, `score`, `x` |
| String | `$` | Text | `name$`, `word$`, `c$` |

**Remember:** Can't mix types. `INPUT name` for text will fail—must be `INPUT name$`.

## What You've Learnt

- **INPUT** pauses and stores user responses in variables
- **String variables** end with `$` for text (e.g. `name$`)
- **IF condition THEN command** executes only when condition is true
- **Comparison operators**: `=`, `<>`, `<`, `>`, `<=`, `>=`
- **AND** combines multiple conditions (all must be true)
- **Concatenation** with semicolons joins text and variables
- Programs can branch based on user choices
