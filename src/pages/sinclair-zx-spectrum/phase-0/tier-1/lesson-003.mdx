You've mastered colours, text positioning, INPUT, and IF/THEN. Time to combine everything into your first complete game: Cave Explorer, a text adventure where you navigate rooms, collect treasure, and escape. This is synthesis—taking individual skills and building something playable.

Text adventures dominated early home computing. Zork, The Hobbit, and Adventure captivated players with pure text. The Spectrum's fast BASIC and instant PRINT AT positioning make it perfect for text games. You'll build a 4-room adventure with state management and win/lose conditions.

## The One-Minute Tour

- **GOSUB** jumps to a subroutine (like a function)
- **RETURN** comes back from the subroutine
- **State variables** track room location and inventory
- **Game loop** repeats: display → input → process → update
- **Subroutines** organize code (one per room)
- This is your first complete, playable game!

## Your First Complete Game

Type this carefully—it's longer than previous programs:

```basic
10 REM Cave Explorer
20 REM Simple text adventure game
30 LET ROOM=1
40 LET HASKEY=0
50 LET HASTREASURE=0
60 CLS
70 PRINT AT 1,6;"=== CAVE EXPLORER ==="
80 PRINT AT 3,2;"Find the treasure and escape!"
90 PAUSE 100
100 CLS
110 IF ROOM=1 THEN GOSUB 1000
120 IF ROOM=2 THEN GOSUB 2000
130 IF ROOM=3 THEN GOSUB 3000
140 IF ROOM=4 THEN GOSUB 4000
150 IF HASTREASURE=1 AND ROOM=1 THEN GOSUB 5000
160 PRINT AT 20,0;"Command (N/S/E/W/GET/QUIT): "
170 INPUT C$
180 IF C$="QUIT" THEN STOP
190 IF C$="N" THEN GOSUB 6000
200 IF C$="S" THEN GOSUB 6100
210 IF C$="E" THEN GOSUB 6200
220 IF C$="W" THEN GOSUB 6300
230 IF C$="GET" THEN GOSUB 7000
240 GO TO 100
1000 REM Room 1 - Cave Entrance
1010 PRINT AT 5,4;"You are at the cave entrance."
1020 PRINT AT 7,2;"Sunlight filters in from behind."
1030 PRINT AT 9,2;"A dark tunnel leads north."
1040 RETURN
2000 REM Room 2 - Dark Passage
2010 PRINT AT 5,4;"A dank, dark passage."
2020 PRINT AT 7,2;"Water drips from the ceiling."
2030 PRINT AT 9,2;"Exits: South, East"
2040 RETURN
3000 REM Room 3 - Treasure Chamber
3010 PRINT AT 5,4;"A glittering treasure chamber!"
3020 IF HASTREASURE=0 THEN PRINT AT 7,2;"A golden cup sits on a pedestal."
3030 IF HASTREASURE=1 THEN PRINT AT 7,2;"The pedestal is empty now."
3040 PRINT AT 9,2;"Exit: West"
3050 RETURN
4000 REM Room 4 - Pit Room (Game Over)
4010 PRINT AT 5,4;"You fall into a deep pit!"
4020 PRINT AT 10,6;"GAME OVER"
4030 PAUSE 0
4040 STOP
5000 REM Win Condition
5010 PRINT AT 5,2;"You escaped with the treasure!"
5020 PRINT AT 10,8;"YOU WIN!"
5030 PAUSE 0
5040 STOP
6000 REM Move North
6010 IF ROOM=1 THEN LET ROOM=2
6020 RETURN
6100 REM Move South
6110 IF ROOM=2 THEN LET ROOM=1
6120 IF ROOM=2 THEN PRINT AT 22,2;"Can't go that way!": PAUSE 50
6130 RETURN
6200 REM Move East
6210 IF ROOM=2 THEN LET ROOM=3
6220 IF ROOM=1 THEN LET ROOM=4
6230 RETURN
6300 REM Move West
6310 IF ROOM=3 THEN LET ROOM=2
6320 RETURN
7000 REM Get Item
7010 IF ROOM=3 AND HASTREASURE=0 THEN LET HASTREASURE=1: PRINT AT 22,2;"You take the golden cup!": PAUSE 50
7020 RETURN
```

**Run this** and explore the cave. Commands: N, S, E, W, GET, QUIT.

**Goal:** Go north from entrance (Room 1), then east to treasure chamber (Room 3), GET the treasure, return west and south to entrance. You win!

**Warning:** Going east from entrance leads to a pit (Room 4) = game over!

## How This Works

### The Game Loop

```basic
100 CLS
110 IF ROOM=1 THEN GOSUB 1000
120 IF ROOM=2 THEN GOSUB 2000
...
160 PRINT AT 20,0;"Command (N/S/E/W/GET/QUIT): "
170 INPUT C$
...
240 GO TO 100
```

This is the heartbeat of every game: **display current state → get input → process → repeat**. Line 100 clears screen. Lines 110-150 display the current room. Line 170 waits for command. Line 240 loops back. Forever.

### State Management

```basic
30 LET ROOM=1
40 LET HASKEY=0
50 LET HASTREASURE=0
```

Variables track game state. `ROOM` stores current location (1-4). `HASTREASURE` tracks if you picked up the treasure (0=no, 1=yes). These persist across the loop—the game "remembers" where you are and what you're carrying.

### Subroutines with GOSUB/RETURN

```basic
110 IF ROOM=1 THEN GOSUB 1000
...
1000 REM Room 1 - Cave Entrance
1010 PRINT AT 5,4;"You are at the cave entrance."
1020 PRINT AT 7,2;"Sunlight filters in from behind."
1030 PRINT AT 9,2;"A dark tunnel leads north."
1040 RETURN
```

GOSUB jumps to line 1000. The Spectrum executes lines 1010-1030, then hits RETURN and jumps back to line 110. Think of it like calling a function. Each room is a subroutine starting at 1000, 2000, 3000, etc.

**Why subroutines?** Organization. Without them, you'd have messy IF/THEN chains. With them, each room is cleanly separated. Easy to read, easy to add more rooms.

### Movement Logic

```basic
6000 REM Move North
6010 IF ROOM=1 THEN LET ROOM=2
6020 RETURN
```

Movement subroutines check current room and update `ROOM` variable. From Room 1, north leads to Room 2. The next loop iteration displays Room 2 because `ROOM` changed.

**Simple but effective.** Games don't need complexity—just clear state and logic.

### Win and Lose Conditions

```basic
150 IF HASTREASURE=1 AND ROOM=1 THEN GOSUB 5000
...
4000 REM Room 4 - Pit Room (Game Over)
4010 PRINT AT 5,4;"You fall into a deep pit!"
4020 PRINT AT 10,6;"GAME OVER"
4030 PAUSE 0
4040 STOP
```

Line 150 checks: do you have treasure AND are you at entrance? If yes, you win (subroutine 5000). Room 4 is instant game over—STOP ends the program.

## Experiment: Add a Fifth Room

Add a locked door that requires a key:

```basic
145 IF ROOM=5 THEN GOSUB 5500
...
5500 REM Room 5 - Secret Chamber
5510 PRINT AT 5,3;"A secret chamber with ancient runes."
5520 PRINT AT 7,2;"You feel powerful magic here."
5530 PRINT AT 9,2;"Exit: South"
5540 RETURN
```

Add a way to reach it:

```basic
6205 IF ROOM=3 AND HASKEY=1 THEN LET ROOM=5
```

This unlocks from Room 3 if you have a key. Add a key pickup in Room 2:

```basic
7015 IF ROOM=2 AND HASKEY=0 THEN LET HASKEY=1: PRINT AT 22,2;"You found a rusty key!": PAUSE 50
```

Now you need the key to access Room 5!

## Quick Reference: GOSUB/RETURN

| Command | Purpose | Example |
|---------|---------|---------|
| `GOSUB line` | Jump to subroutine | `GOSUB 1000` |
| `RETURN` | Return from subroutine | `RETURN` |
| `STOP` | End program | `STOP` |
| `GO TO line` | Jump unconditionally | `GO TO 100` |

**GOSUB vs GO TO:**
- GOSUB remembers where it came from, RETURN goes back
- GO TO just jumps, never returns
- Use GOSUB for reusable blocks (rooms, functions)
- Use GO TO for main loops

## Quick Reference: Game Structure Pattern

```basic
Main loop (lines 100-240):
  1. Clear screen
  2. Display current state (IF/GOSUB)
  3. Get player input
  4. Process commands (IF/GOSUB)
  5. GO TO step 1

Room subroutines (1000, 2000, 3000...):
  - PRINT AT to display description
  - RETURN when done

Action subroutines (6000-7000+):
  - Check conditions
  - Update state variables
  - RETURN
```
