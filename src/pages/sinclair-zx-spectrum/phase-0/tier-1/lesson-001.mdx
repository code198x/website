Welcome to ZX Spectrum programming! The Spectrum boots straight into Sinclair BASIC—no cassette loading required. You can type commands and see results immediately. This lesson shows you how to control colours and display text.

Every Spectrum program starts with understanding the screen: 256×192 pixels divided into 24 rows and 32 columns of text. You control colours with BORDER, PAPER, and INK commands. Let's make something colourful.

## The One-Minute Tour

- **Sinclair BASIC** runs directly from ROM—type and execute immediately
- **BORDER** sets the screen border colour (0-7)
- **PAPER** sets the background colour for text (0-7)
- **INK** sets the foreground colour for text (0-7)
- **CLS** clears the screen with current PAPER colour
- **PRINT AT** positions text at specific row/column
- **PAUSE 0** waits for a keypress before continuing

## Your First Spectrum Program

Type this into the Spectrum (the one with the rubber keyboard, remember?):

```basic
10 REM Hello, Spectrum World
20 REM Display text with color
30 BORDER 5
40 PAPER 5
50 INK 7
60 CLS
70 PRINT AT 10,8;"HELLO, SPECTRUM!"
80 PAUSE 0
```

**Run this** by typing `RUN` and pressing ENTER.

![Hello, Spectrum World - cyan screen with white text](/images/sinclair-zx-spectrum/phase-0/tier-1/lesson-001/hello-spectrum.png)

The screen displays "HELLO, SPECTRUM!" in white text on a cyan background, with a cyan border. Simple, but this proves you can control colours and position text anywhere on screen.

## How This Works

### Setting Colours

```basic
30 BORDER 5
40 PAPER 5
50 INK 7
```

The Spectrum has 8 basic colours (0-7): black, blue, red, magenta, green, cyan, yellow, white. Each can be bright or dim (we'll cover that later). BORDER sets the border around the screen. PAPER sets the background colour. INK sets the text colour. Colour 5 is cyan, colour 7 is white.

**Why set them before CLS?** Because CLS fills the screen with the current PAPER colour. If you CLS before setting PAPER, you get a black screen.

### Clearing the Screen

```basic
60 CLS
```

CLS stands for Clear Screen. It fills the entire display with the current PAPER colour and moves the cursor to the top-left corner (0,0). On the Spectrum, the cursor is that flashing square—called K mode, meaning it's waiting for a keyword.

### Positioning Text

```basic
70 PRINT AT 10,8;"HELLO, SPECTRUM!"
```

PRINT AT takes two numbers: row (0-23) and column (0-31). Row 10 is roughly middle of screen, column 8 centers our text. The semicolon before the string stops PRINT from adding a newline. Without semicolon, PRINT moves to next line automatically.

**Spectrum quirk:** AT is not a separate command—it's part of PRINT. You can't say `AT 10,8` alone. Always `PRINT AT row,column;data`.

### Waiting for Input

```basic
80 PAUSE 0
```

PAUSE stops the program. PAUSE 0 means "wait forever" (until keypress). PAUSE 50 would wait 1 second (50 frames at 50Hz PAL). Without PAUSE, the program would finish and return to the command prompt immediately.

## Experiment: Different Colours

Change the colour values:

```basic
30 BORDER 2   ; Try 0-7
40 PAPER 4    ; Try 0-7
50 INK 6      ; Try 0-7
```

**Try these combinations:**
- BORDER 0, PAPER 0, INK 7 = Classic black screen, white text
- BORDER 2, PAPER 2, INK 6 = Red screen, yellow text
- BORDER 4, PAPER 4, INK 7 = Green screen, white text
- BORDER 1, PAPER 6, INK 1 = Blue border, yellow background, blue text

**Warning:** INK and PAPER the same colour = invisible text. The Spectrum won't stop you doing this—it trusts you know what you're doing.

## Experiment: Moving Text Around

```basic
70 PRINT AT 0,0;"TOP LEFT"
70 PRINT AT 23,0;"BOTTOM LEFT"
70 PRINT AT 0,20;"TOP RIGHT"
70 PRINT AT 23,24;"BOTTOM RIGHT"
70 PRINT AT 11,12;"MIDDLE"
```

The screen is 24 rows (0-23) and 32 columns (0-31). Text wraps if you go past column 31. Going past row 23 scrolls the screen up—destroying the top line.

| 7 | White | Text, highlights |

## Quick Reference: Screen Control Commands

| Command | Purpose | Range |
|---------|---------|-------|
| BORDER n | Set border colour | 0-7 |
| PAPER n | Set background colour | 0-7 |
| INK n | Set text colour | 0-7 |
| CLS | Clear screen | - |
| PRINT AT r,c | Position text | r: 0-23, c: 0-31 |
| PAUSE n | Wait n frames (0=forever) | 0-65535 |

## Quick Reference: Sinclair BASIC Line Numbers

- Programs start with line numbers (usually 10, 20, 30...)
- Line numbers can be 1-9999
- Lines execute in numerical order
- Use gaps (10, 20, 30) to leave room for insertions
- REM statements are comments (not executed)

## What You've Learnt

- ZX Spectrum boots straight into **Sinclair BASIC**
- **BORDER**, **PAPER**, **INK** control colours (0-7)
- **CLS** clears screen with current PAPER colour
- **PRINT AT row,column** positions text anywhere
- **PAUSE 0** waits for keypress
- Screen is **24 rows × 32 columns** of text
- Colours must contrast or text becomes invisible
