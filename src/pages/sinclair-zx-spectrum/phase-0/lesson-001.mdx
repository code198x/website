# Your First Spectrum Program

Welcome! You're about to write your first program for the ZX Spectrum.

## What You'll Build

A simple program that fills the screen with text. When you run it, you'll see "HELLO SPECTRUM!" scrolling endlessly down the screen.

## The Code

Type this exactly as shown:

```basic
10 PRINT "HELLO SPECTRUM!"
20 GOTO 10
```

That's it! Just two lines.

## How to Run It

1. Start your Spectrum emulator (Fuse recommended)
2. You'll see a white screen with copyright text and a `K` cursor
3. Type the program exactly as shown above
4. Press `ENTER` after each line
5. When you're done typing, type `RUN` and press `ENTER`

## Spectrum BASIC Tip

The Spectrum has keyword shortcuts! Instead of typing out full words:
- Press `P` in K-mode (keyword mode) for `PRINT`
- Press `G` for `GOTO`

The keywords appear as single characters on screen but represent full words.

## Stopping the Program

Press `BREAK` (usually `CAPS SHIFT` + `SPACE` on real hardware, or mapped to a key in your emulator).

## What Just Happened?

- **Line 10:** Prints "HELLO SPECTRUM!" to the screen
- **Line 20:** Goes back to line 10 (creates a loop)
- **Result:** Infinite loop that keeps printing

## You Did It!

You just wrote and ran your first Spectrum program. The ZX Spectrum is responding to your commands!
