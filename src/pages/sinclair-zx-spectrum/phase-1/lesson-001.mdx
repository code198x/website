# Your First Spectrum Assembly Program

Welcome to assembly language! You're about to write your first Z80 assembly program for the ZX Spectrum.

## What You'll Build

A program that changes the border colour. When you run it, the border will cycle through colours continuously.

## The Code

Save this as `hello.asm`:

```nasm
; Your first Spectrum assembly program
; Changes the border colour

        org $8000       ; Start at 32768

loop:   ld a,($5c48)    ; Load current BORDCR value
        inc a           ; Increment it
        and 7           ; Keep only bits 0-2 (colours 0-7)
        ld ($5c48),a    ; Store back to BORDCR
        out ($fe),a     ; Output to ULA port (change border)
        jp loop         ; Loop forever

        end
```

## How to Assemble and Run It

### Using sjasmplus assembler:
```bash
sjasmplus hello.asm
```

This creates `hello.tap` (tape file).

### Run in Fuse emulator:
```bash
fuse hello.tap
```

Or in Fuse: File → Open → hello.tap

Then type: `RANDOMIZE USR 32768` and press ENTER

## Stopping the Program

Press `BREAK` (`CAPS SHIFT` + `SPACE`) or reset the emulator.

## What Just Happened?

- **`org $8000`:** Our program starts at memory address 32768
- **`ld a,($5c48)`:** Loads the current border colour from BORDCR system variable
- **`inc a`:** Increments the accumulator (A register)
- **`and 7`:** Keeps only bits 0-2, giving values 0-7
- **`ld ($5c48),a`:** Stores the new value back to BORDCR
- **`out ($fe),a`:** Outputs to the ULA port $FE, which changes the border
- **`jp loop`:** Jumps back to the loop (infinite loop)

## The Z80 Registers You're Using

- **A (Accumulator):** Main register for calculations and I/O
- **PC (Program Counter):** Points to the current instruction

## ULA Port $FE

The Spectrum's ULA (Uncommitted Logic Array) handles border, speaker, and keyboard. Writing to port $FE changes the border colour (bits 0-2) and speaker state (bit 4).

## You Did It!

You just wrote and ran your first Z80 assembly language program. You're directly controlling the Spectrum's hardware!
