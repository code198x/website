# Z80 Instruction Set Reference

Complete reference for Z80 microprocessor instructions as used in the ZX Spectrum. Includes T-states (clock cycles), byte counts, and flag effects for every instruction.

---

## Reading This Reference

### Notation

- **n** = 8-bit immediate value (0-255)
- **nn** = 16-bit immediate value (0-65535)
- **d** = 8-bit signed displacement (-128 to +127)
- **r** = 8-bit register (A, B, C, D, E, H, L)
- **rr** = 16-bit register pair (BC, DE, HL, SP)
- **(addr)** = memory at address
- **$** = current address (in expressions)

### Flag Notation

- **S** = Sign flag (bit 7 of result)
- **Z** = Zero flag (result is zero)
- **H** = Half-carry flag (carry from bit 3 to 4)
- **P/V** = Parity/Overflow flag
- **N** = Add/Subtract flag (for BCD)
- **C** = Carry flag
- **●** = Flag affected
- **○** = Flag reset
- **—** = Flag unchanged
- **?** = Flag undefined

## 8-Bit Load Instructions

### LD r,n - Load Immediate

Load 8-bit value into register.

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| LD A,n | 2 | 7 | — | — | — | — | — | — |
| LD B,n | 2 | 7 | — | — | — | — | — | — |
| LD C,n | 2 | 7 | — | — | — | — | — | — |
| LD D,n | 2 | 7 | — | — | — | — | — | — |
| LD E,n | 2 | 7 | — | — | — | — | — | — |
| LD H,n | 2 | 7 | — | — | — | — | — | — |
| LD L,n | 2 | 7 | — | — | — | — | — | — |

**Example:**
```nasm
LD A,42          ; A = 42
LD B,0           ; B = 0
LD H,$40         ; H = $40 (64 decimal)
```

**Note:** LD instructions do not affect flags.

### LD r,r' - Load Register to Register

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD A,B | 1 | 4 | None affected |
| LD B,C | 1 | 4 | None affected |
| LD H,L | 1 | 4 | None affected |

**All 49 combinations:** A,B,C,D,E,H,L can be copied to/from each other.

**Example:**
```nasm
LD A,B           ; Copy B to A
LD C,A           ; Copy A to C
LD H,D           ; Copy D to H
```

### LD r,(HL) - Load from Memory

Load register from memory address in HL.

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD A,(HL) | 1 | 7 | None affected |
| LD B,(HL) | 1 | 7 | None affected |
| LD C,(HL) | 1 | 7 | None affected |

**Example:**
```nasm
LD HL,$4000      ; HL = screen start
LD A,(HL)        ; A = byte at $4000
```

### LD (HL),r - Store to Memory

Store register to memory address in HL.

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD (HL),A | 1 | 7 | None affected |
| LD (HL),B | 1 | 7 | None affected |
| LD (HL),n | 2 | 10 | None affected |

**Example:**
```nasm
LD HL,$4000      ; HL = screen start
LD A,255         ; A = white pixel byte
LD (HL),A        ; Store A to screen
```

### LD A,(nn) / LD (nn),A - Direct Memory Access

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD A,(nn) | 3 | 13 | None affected |
| LD (nn),A | 3 | 13 | None affected |

**Example:**
```nasm
LD A,($5C48)     ; Read BORDCR system variable
LD ($5C48),A     ; Write to BORDCR
```

## 16-Bit Load Instructions

### LD rr,nn - Load 16-bit Immediate

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD BC,nn | 3 | 10 | None affected |
| LD DE,nn | 3 | 10 | None affected |
| LD HL,nn | 3 | 10 | None affected |
| LD SP,nn | 3 | 10 | None affected |
| LD IX,nn | 4 | 14 | None affected |
| LD IY,nn | 4 | 14 | None affected |

**Example:**
```nasm
LD HL,$4000      ; HL = $4000
LD BC,6144       ; BC = 6144 (screen size)
LD SP,$FF00      ; Set stack pointer
```

### LD (nn),rr / LD rr,(nn) - 16-bit Memory Access

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LD (nn),HL | 3 | 16 | None affected |
| LD HL,(nn) | 3 | 16 | None affected |
| LD (nn),BC | 4 | 20 | None affected |
| LD BC,(nn) | 4 | 20 | None affected |

**Example:**
```nasm
LD HL,$4000
LD ($8000),HL    ; Store HL at $8000-$8001
LD HL,($8000)    ; Load HL from $8000-$8001
```

## Arithmetic Instructions

### ADD A,r / ADD A,n - Add

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| ADD A,B | 1 | 4 | ● | ● | ● | ● | ○ | ● |
| ADD A,n | 2 | 7 | ● | ● | ● | ● | ○ | ● |
| ADD A,(HL) | 1 | 7 | ● | ● | ● | ● | ○ | ● |

**Example:**
```nasm
LD A,10
ADD A,5          ; A = 15
ADD A,A          ; A = 30 (double A)
```

### ADC A,r - Add with Carry

Like ADD but includes carry flag.

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| ADC A,B | 1 | 4 | S,Z,H,P/V,C affected, N reset |

**Example:**
```nasm
; 16-bit add: DE = DE + BC
LD A,E
ADD A,C          ; Low byte
LD E,A
LD A,D
ADC A,B          ; High byte with carry
LD D,A
```

### SUB r / SUB n - Subtract

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| SUB B | 1 | 4 | ● | ● | ● | ● | ● | ● |
| SUB n | 2 | 7 | ● | ● | ● | ● | ● | ● |

**Example:**
```nasm
LD A,50
SUB 10           ; A = 40
SUB A            ; A = 0 (common idiom)
```

### SBC A,r - Subtract with Carry

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| SBC A,B | 1 | 4 | S,Z,H,P/V,N,C affected |

### INC r / DEC r - Increment/Decrement

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| INC A | 1 | 4 | ● | ● | ● | ● | ○ | — |
| DEC A | 1 | 4 | ● | ● | ● | ● | ● | — |
| INC (HL) | 1 | 11 | ● | ● | ● | ● | ○ | — |
| DEC (HL) | 1 | 11 | ● | ● | ● | ● | ● | — |

**Example:**
```nasm
LD A,0
INC A            ; A = 1
INC A            ; A = 2
DEC A            ; A = 1
```

**Note:** Carry flag is NOT affected by INC/DEC!

## 16-Bit Arithmetic

### ADD HL,rr - 16-bit Add

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| ADD HL,BC | 1 | 11 | — | — | ● | — | ○ | ● |
| ADD HL,DE | 1 | 11 | — | — | ● | — | ○ | ● |
| ADD HL,HL | 1 | 11 | — | — | ● | — | ○ | ● |
| ADD HL,SP | 1 | 11 | — | — | ● | — | ○ | ● |

**Example:**
```nasm
LD HL,$4000
LD DE,32
ADD HL,DE        ; HL = $4020 (advance 32 bytes)
ADD HL,HL        ; HL = $4040 (double HL)
```

**Important:** Only HL can be the destination for 16-bit ADD!

### ADC HL,rr - 16-bit Add with Carry

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| ADC HL,BC | 2 | 15 | S,Z,H,P/V,C affected, N reset |

### SBC HL,rr - 16-bit Subtract with Carry

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| SBC HL,BC | 2 | 15 | S,Z,H,P/V,N,C affected |

### INC rr / DEC rr - 16-bit Increment/Decrement

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| INC BC | 1 | 6 | None affected |
| DEC HL | 1 | 6 | None affected |
| INC SP | 1 | 6 | None affected |

**Example:**
```nasm
LD HL,$4000
INC HL           ; HL = $4001
INC HL           ; HL = $4002
```

**Important:** 16-bit INC/DEC do NOT affect any flags!

## Logical Instructions

### AND r / AND n - Logical AND

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| AND B | 1 | 4 | ● | ● | ● | ● | ○ | ○ |
| AND n | 2 | 7 | ● | ● | ● | ● | ○ | ○ |

**Example:**
```nasm
LD A,$FF
AND $07          ; A = $07 (mask to bits 0-2)
AND A            ; Test if A is zero (sets Z flag)
```

**Common use:** Masking bits, testing for zero.

### OR r / OR n - Logical OR

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| OR B | 1 | 4 | S,Z,P/V affected, H,N,C reset |
| OR n | 2 | 7 | S,Z,P/V affected, H,N,C reset |

**Example:**
```nasm
LD A,$C0
OR $07           ; A = $C7 (set bits 0-2)
OR A             ; Test A for zero (very common!)
```

**OR A idiom:** Sets zero flag without changing A. Use after LD to test for zero.

### XOR r / XOR n - Logical XOR

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| XOR B | 1 | 4 | S,Z,P/V affected, H,N,C reset |
| XOR n | 2 | 7 | S,Z,P/V affected, H,N,C reset |

**Example:**
```nasm
LD A,$FF
XOR $FF          ; A = $00 (toggle all bits)
XOR A            ; A = 0 (fastest way to zero A!)
```

**XOR A idiom:** Fastest way to set A to zero (4 T-states vs LD A,0 = 7 T-states).

### CP r / CP n - Compare

Like SUB but doesn't store result (only sets flags).

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| CP B | 1 | 4 | S,Z,H,P/V,N,C affected |
| CP n | 2 | 7 | S,Z,H,P/V,N,C affected |

**Example:**
```nasm
LD A,10
CP 5             ; Compare A with 5
JR Z,Equal       ; Jump if A = 5
JR C,Less        ; Jump if A &lt;5
                 ; Fall through if A > 5
```

## Rotate and Shift Instructions

### RLCA / RRCA - Rotate Accumulator

| Instruction | Bytes | T-states | S | Z | H | P/V | N | C |
|-------------|-------|----------|---|---|---|-----|---|---|
| RLCA | 1 | 4 | — | — | ○ | — | ○ | ● |
| RRCA | 1 | 4 | — | — | ○ | — | ○ | ● |

**Example:**
```nasm
LD A,%10110010
RLCA             ; A = %01100101, C = 1
RRCA             ; A = %10110010, C = 1
```

### RLC r - Rotate Left through Carry

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| RLC A | 2 | 8 | S,Z,P/V,C affected, H,N reset |

### SLA r - Shift Left Arithmetic

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| SLA A | 2 | 8 | S,Z,P/V,C affected, H,N reset |

**Example:**
```nasm
LD A,1
SLA A            ; A = 2 (multiply by 2)
SLA A            ; A = 4
SLA A            ; A = 8
```

### SRA r - Shift Right Arithmetic (preserves sign)

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| SRA A | 2 | 8 | S,Z,P/V,C affected, H,N reset |

### SRL r - Shift Right Logical

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| SRL A | 2 | 8 | S,Z,P/V,C affected, H,N reset |

**Example:**
```nasm
LD A,8
SRL A            ; A = 4 (divide by 2)
SRL A            ; A = 2
SRL A            ; A = 1
```

## Jump Instructions

### JP nn - Unconditional Jump

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| JP nn | 3 | 10 | None affected |
| JP (HL) | 1 | 4 | None affected |

**Example:**
```nasm
Loop:
        ; ... code ...
        JP Loop       ; Jump back to Loop

        JP (HL)       ; Jump to address in HL
```

### JP cc,nn - Conditional Jump

| Condition | Meaning | Instruction | Bytes | T-states |
|-----------|---------|-------------|-------|----------|
| Z | Zero | JP Z,nn | 3 | 10 |
| NZ | Not zero | JP NZ,nn | 3 | 10 |
| C | Carry | JP C,nn | 3 | 10 |
| NC | No carry | JP NC,nn | 3 | 10 |
| M | Minus (negative) | JP M,nn | 3 | 10 |
| P | Plus (positive) | JP P,nn | 3 | 10 |
| PE | Parity even | JP PE,nn | 3 | 10 |
| PO | Parity odd | JP PO,nn | 3 | 10 |

**Example:**
```nasm
CP 0
JP Z,IsZero      ; Jump if A = 0
JP NC,NoCarry    ; Jump if carry flag clear
```

### JR d - Relative Jump

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| JR d | 2 | 12 | None affected |
| JR Z,d | 2 | 12/7 | None affected |
| JR NZ,d | 2 | 12/7 | None affected |
| JR C,d | 2 | 12/7 | None affected |
| JR NC,d | 2 | 12/7 | None affected |

**Range:** -126 to +129 bytes from current position.

**Example:**
```nasm
Loop:
        ; ... code ...
        JR Loop       ; Jump back (2 bytes vs JP = 3 bytes)

        CP 0
        JR Z,Found    ; Jump if zero (12 T-states if taken, 7 if not)
```

**Advantage:** 1 byte smaller than JP, slightly faster.
**Disadvantage:** Limited range (±127 bytes).

### DJNZ d - Decrement and Jump if Not Zero

Special loop instruction. Decrements B and jumps if B ≠ 0.

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| DJNZ d | 2 | 13/8 | None affected |

**Example:**
```nasm
        LD B,10       ; Loop counter
Loop:
        ; ... code ...
        DJNZ Loop     ; B--, jump if B ≠ 0
```

**Perfect for counted loops!** Very common in Z80 code.

## Call and Return Instructions

### CALL nn - Unconditional Call

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| CALL nn | 3 | 17 | None affected |

**Operation:**
1. Push PC (program counter) onto stack
2. Jump to address nn

**Example:**
```nasm
        CALL PrintMsg    ; Call subroutine
        ; Returns here

PrintMsg:
        ; ... subroutine code ...
        RET
```

### CALL cc,nn - Conditional Call

| Condition | Instruction | Bytes | T-states |
|-----------|-------------|-------|----------|
| Z | CALL Z,nn | 3 | 17/10 |
| NZ | CALL NZ,nn | 3 | 17/10 |
| C | CALL C,nn | 3 | 17/10 |
| NC | CALL NC,nn | 3 | 17/10 |

**Example:**
```nasm
CP 0
CALL Z,HandleZero    ; Call only if A = 0
```

### RET - Return from Subroutine

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| RET | 1 | 10 | None affected |
| RET Z | 1 | 11/5 | None affected |
| RET NZ | 1 | 11/5 | None affected |

**Operation:** Pop PC from stack and jump to it.

**Example:**
```nasm
Subroutine:
        ; ... code ...
        CP 0
        RET Z         ; Early return if zero
        ; ... more code ...
        RET           ; Normal return
```

## Stack Instructions

### PUSH rr - Push to Stack

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| PUSH BC | 1 | 11 | None affected |
| PUSH DE | 1 | 11 | None affected |
| PUSH HL | 1 | 11 | None affected |
| PUSH AF | 1 | 11 | None affected |

**Operation:** SP -= 2, store register pair at (SP).

**Example:**
```nasm
Subroutine:
        PUSH AF       ; Save A and flags
        PUSH BC       ; Save BC
        ; ... use A, BC freely ...
        POP BC        ; Restore BC
        POP AF        ; Restore A and flags
        RET
```

**Important:** PUSH/POP must be balanced!

### POP rr - Pop from Stack

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| POP BC | 1 | 10 | None affected (except POP AF) |
| POP AF | 1 | 10 | All flags loaded from stack |

**Example:**
```nasm
        PUSH HL
        LD HL,$4000
        ; ... use HL ...
        POP HL        ; Restore original HL
```

## Miscellaneous Instructions

### NOP - No Operation

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| NOP | 1 | 4 | None affected |

**Example:**
```nasm
        NOP           ; Delay 4 T-states
        NOP
        NOP           ; Total 12 T-states delay
```

### HALT - Halt CPU

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| HALT | 1 | 4 | None affected |

**Operation:** CPU stops until next interrupt.

**Example:**
```nasm
        HALT          ; Wait for interrupt (50Hz on Spectrum)
```

### DI / EI - Disable/Enable Interrupts

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| DI | 1 | 4 | None affected |
| EI | 1 | 4 | None affected |

**Example:**
```nasm
        DI            ; Disable interrupts
        ; ... critical code ...
        EI            ; Re-enable interrupts
```

### IM n - Set Interrupt Mode

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| IM 0 | 2 | 8 | None affected |
| IM 1 | 2 | 8 | None affected |
| IM 2 | 2 | 8 | None affected |

**Spectrum default:** IM 1 (interrupt vector at $0038)

## Block Instructions

### LDIR - Load, Increment, Repeat

| Instruction | Bytes | T-states | Flags |
|-------------|-------|----------|-------|
| LDIR | 2 | 21/16 | H,P/V,N reset |

**Operation:** Copy byte from (HL) to (DE), increment HL and DE, decrement BC. Repeat until BC = 0.

**Example:**
```nasm
; Copy 6144 bytes from $8000 to $4000
        LD HL,$8000   ; Source
        LD DE,$4000   ; Destination
        LD BC,6144    ; Count
        LDIR          ; Copy all bytes
```

**T-states:** 21 per byte if BC ≠ 0 after, 16 for last byte.

### LDDR - Load, Decrement, Repeat

Like LDIR but decrements HL and DE.

## Common Instruction Patterns

### Clear A Register (fastest)
```nasm
XOR A             ; 4 T-states (vs LD A,0 = 7)
```

### Test if A is Zero
```nasm
OR A              ; Sets Z flag without changing A
JR Z,IsZero
```

### Double A Register
```nasm
ADD A,A           ; Faster than multiplying
```

### Multiply by Power of 2
```nasm
SLA A             ; × 2
SLA A             ; × 4
SLA A             ; × 8
```

### Delay Loop
```nasm
        LD B,100
Delay:  DJNZ Delay    ; 13 × 99 + 8 = 1295 T-states
```

### Preserve Registers in Subroutine
```nasm
Routine:
        PUSH AF
        PUSH BC
        ; ... use AF, BC ...
        POP BC
        POP AF
        RET
```

## Performance Notes

**Fastest instructions:**
- Register operations: 4 T-states
- XOR A (clear A): 4 T-states
- INC/DEC register: 4 T-states

**Slow instructions:**
- LDIR: 21 T-states per byte
- CALL: 17 T-states
- Block instructions: High per-operation cost

**Optimization tips:**
1. Use register operations over memory
2. Use HL instead of IX/IY (3× faster)
3. Use JR instead of JP when possible (saves 1 byte)
4. Use DJNZ for loops (very efficient)
5. Unroll loops in speed-critical code
