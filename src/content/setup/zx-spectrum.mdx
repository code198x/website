# ZX Spectrum Development Setup

Ready to program the ZX Spectrum? This guide will get you creating games for Sir Clive's rubber-keyed wonder in no time.

## Option 1: Docker Quick Start (Recommended)

The fastest way to start coding. Everything pre-configured for Spectrum development.

### 1. Install Docker

- **macOS/Windows**: Download [Docker Desktop](https://www.docker.com/products/docker-desktop)
- **Linux**: Use your package manager (`apt install docker.io` or similar)

### 2. Navigate to Development Environment

```bash
# Already in the Code198x repository!
cd development-environment
```

### 3. Start Development Environment

```bash
# Start all development containers
docker-compose up -d

# Enter main workspace
docker-compose exec workspace bash
```

### 4. Create Your First Spectrum Project

Inside the workspace, use the integrated build system:

```bash
# Create new ZX Spectrum project using the build system
make create-spectrum-project NAME=hello

# Build it automatically
make build-spectrum PROJECT=hello

# Your hello.tap is ready in projects/zx-spectrum/hello/build/
```

The build system automatically creates a working Spectrum program:

```text
; hello.asm - Generated by Code Like It's 198x
    org 32768       ; Start at 32768

start:
    ld a,2          ; Red border
    out (254),a     ; Set border color
    ret             ; Return
```

## Option 2: Local Installation

Prefer to install tools directly? Here's how:

### 1. Install sjasmplus Assembler

**All Platforms:**

The Docker environment includes all tools pre-configured. For local installation:

**macOS:**
```bash
brew install sjasmplus
```

**Linux:**
```bash
sudo apt install sjasmplus
```

**Windows:**
1. Download sjasmplus from GitHub releases
2. Add to system PATH
3. Ensure Docker is properly configured

### 2. Install Fuse Emulator

**All Platforms:**
Download from [Fuse Homepage](http://fuse-emulator.sourceforge.net/)

**macOS Alternative:**
```bash
brew install fuse-emulator
```

### 3. Verify Your Setup

Test with the same workflow as Docker:

```bash
# The Makefile works locally too!
make create-spectrum-project NAME=hello
make build-spectrum PROJECT=hello

# Run in Fuse
fuse projects/zx-spectrum/hello/build/hello.tap
```

Press ENTER when you see the TAP file load, then RANDOMIZE USR 32768 to run!

## Your First Real Program

Let's create the classic Spectrum color bars effect using the build system:

```bash
# Create a new colorful project
make create-spectrum-project NAME=bars

# Edit the generated bars.asm file:
# Replace the contents with this color bars code
```

```text
; bars.asm - Classic Spectrum color bars
    org $8000

start:
    ; Clear screen with black
    ld a,0
    out ($fe),a     ; Black border
    call $0daf      ; Clear screen
    
    ; Draw color bars
    ld hl,$5800     ; Attribute area
    ld b,8          ; 8 colors
    ld c,0          ; Color counter
    
next_bar:
    push bc
    ld b,3          ; 3 rows per color
    
next_row:
    push bc
    ld b,32         ; 32 columns
    
next_col:
    ld a,c          ; Get color
    rlca            ; Shift to paper bits
    rlca
    rlca
    or 7            ; White ink
    ld (hl),a       ; Set attribute
    inc hl
    djnz next_col
    
    pop bc
    djnz next_row
    
    pop bc
    inc c           ; Next color
    djnz next_bar
    
    ret
```

Build and run:
```bash
make build-spectrum PROJECT=bars
# Your bars.tap is in projects/zx-spectrum/bars/build/
```

Watch the classic Spectrum color bars fill your screen!

## TAP File Creation

sjasmplus can create TAP files automatically with a BASIC loader:

```text
        device zxspectrum48

        org     $6000
        
        ; Your code here
start:
        ; ... game code ...
        ret

        ; This creates a TAP with BASIC loader
        savenex open "game.tap", start
        savenex auto
        savenex close
        
        end start
```

## Troubleshooting

**"Tape loading error"**
- Make sure to press ENTER when prompted
- Try: LOAD "" (then ENTER)

**Colors look wrong**
- Spectrum uses attribute-based color
- Each 8x8 block shares ink/paper colors
- This is normal - embrace the limitation!

**Assembly errors**
- sjasmplus is case-insensitive
- Check org address (must be >= 23755)
- Ensure proper label syntax

## Quick Reference

**Build System Commands:**
```bash
make create-spectrum-project NAME=myproject    # Create new project
make build-spectrum PROJECT=myproject          # Build TAP file
make build-spectrum-tzx PROJECT=myproject      # Build TZX file
make clean PROJECT=myproject                   # Clean build files
```

**Direct sjasmplus Commands (if needed):**
```bash
sjasmplus source.asm --lst --tap=output.tap    # Create TAP file
sjasmplus source.asm --raw=output.bin          # Raw binary
sjasmplus source.asm --sld=debug.sld           # Debug symbols
```

**Fuse Keys:**
- `F1` - Menu
- `F2` - Load TAP file
- `F4` - Save snapshot
- `F10` - Quit
