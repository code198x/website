# Commodore 64 Development Setup

Ready to start programming the Commodore 64? This guide will get you up and running in minutes, not hours.

## Option 1: Docker Quick Start (Recommended)

The fastest way to start coding. Everything pre-configured and ready to go.

### 1. Install Docker

- **macOS/Windows**: Download [Docker Desktop](https://www.docker.com/products/docker-desktop)
- **Linux**: Use your package manager (`apt install docker.io` or similar)

### 2. Navigate to Development Environment

```bash
# Already in the Code198x repository!
cd development-environment
```

### 3. Start Development Environment

```bash
# Start all development containers
docker-compose up -d

# Enter main workspace
docker-compose exec workspace bash
```

### 4. Create Your First C64 Project

Inside the workspace, use the integrated build system:

```bash
# Create new C64 project using the build system
make create-c64-project NAME=hello

# Build it automatically
make build-prg PROJECT=hello

# Your hello.prg is ready in projects/commodore-64/hello/build/
```

The build system automatically creates a working C64 program with proper BASIC header:

```asm6502
; hello.asm - Generated by Code Like It's 198x
*=$0801  ; BASIC start address
.byte $0c,$08,$0a,$00,$9e,$20,$32,$30,$36,$31,$00,$00,$00

*=$080d  ; Program start
    lda #$41      ; Load 'A' character
    sta $0400     ; Store to screen
    rts           ; Return
```

## Option 2: Local Installation

Prefer to install tools directly? Here's how:

### 1. Install ACME Assembler

**All Platforms:**

The Docker environment includes all tools pre-configured. For local installation:

**macOS:**
```bash
brew install acme ca65
```

**Linux:**
```bash
sudo apt install acme cc65
```

**Windows:**
1. Download ACME and cc65 from their respective repositories
2. Add to system PATH
3. Ensure Docker is properly configured

### 2. Install VICE Emulator

**All Platforms:**
Download from [VICE Homepage](https://vice-emu.sourceforge.io/)

**macOS Alternative:**
```bash
brew install vice
```

### 3. Verify Your Setup

Test with the same workflow as Docker:

```bash
# The Makefile works locally too!
make create-c64-project NAME=hello
make build-prg PROJECT=hello

# Run in VICE
x64sc projects/commodore-64/hello/build/hello.prg
```

You should see the 'A' character on screen - your first C64 program!

## Your First Real Program

Let's make something more interesting - a colorful border effect using the build system:

```bash
# Create a new colorful project
make create-c64-project NAME=colors

# Edit the generated colors.asm file:
# Replace the contents with this color cycling code
```

```asm6502
; colors.asm - Cycle border colors  
*=$0801
.byte $0c,$08,$0a,$00,$9e,$20,$32,$30,$36,$31,$00,$00,$00

*=$080d
start:
        ldx #$00            ; Color index
loop:
        stx $d020           ; Set border color
        
        ; Wait a bit
        ldy #$40
delay1: ldx #$00
delay2: dex
        bne delay2
        dey
        bne delay1
        
        ldx $d020           ; Get current color
        inx                 ; Next color
        cpx #$10            ; Wrapped around?
        bne loop
        ldx #$00            ; Reset to black
        jmp loop
```

Build and run:
```bash
make build-prg PROJECT=colors
# Your colors.prg is in projects/commodore-64/colors/build/
```

Watch the border cycle through all 16 C64 colors!

## Troubleshooting

**"Command not found" errors**
- Check your PATH includes the tool locations
- Try using full paths to commands

**VICE won't start**
- On macOS: Allow it in Security & Privacy settings
- On Linux: Install SDL libraries if missing

**Assembly errors**
- ACME is case-sensitive
- Check for typos in mnemonics (it's `lda`, not `LDA`)
- Ensure proper spacing around operators

## Quick Reference

**Build System Commands:**
```bash
make create-c64-project NAME=myproject  # Create new project
make build-prg PROJECT=myproject        # Build PRG file
make build-c64-disk PROJECT=myproject   # Build D64 disk image
make clean PROJECT=myproject            # Clean build files
```

**Direct ACME Commands (if needed):**
```bash
acme -f cbm -o output.prg input.asm    # Standard C64 PRG
acme -f plain -o output.bin input.asm  # Raw binary
acme -r report.txt input.asm           # Generate report
```

**VICE Keys:**
- `Alt+W` - Warp mode (fast forward)
- `Alt+R` - Monitor (debugger)
- `Alt+S` - Settings
