## Use it in a project

FRACTION is 0–255, mapping exactly to START and ENDPOINT at its two endpoints. Return START+floor((ENDPOINT−START)×FRACTION/255) when ascending; when descending, subtract floor((START−ENDPOINT)×FRACTION/255). This rounds the travel towards START. All inputs are preserved.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **VALUE, START, ENDPOINT, FRACTION**. They occupy 4 contiguous bytes. Also reserve the private workspace: **T0, T1, T2, T4, T5, T6, T7, T8, T9, T10, T11** (11 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `byte_interpolation_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `byte_interpolation_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none |
| Supply before service | START, ENDPOINT and FRACTION |
| Read after service | VALUE |

First measure unsigned travel, scale it by the fraction, then apply that travel in the chosen direction. Dividing by 255 rather than 256 makes both endpoint values exact.

## Machine contract

The shared mathematical field END is bound as ENDPOINT on Spectrum because END is an assembler directive. The field order and arithmetic are unchanged.

AF/BC/DE/HL may change; IX/IY are preserved. A direct CALL needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The 48K diagnostic boots through ROM tape loading and USR, disables interrupts and owns the screen. The helper performs no port or screen writes.

## Mistake and repair

The wrong caller sends a fraction of zero on every update. The interpolation stays at its starting point. Advance the fraction separately, and retain the original endpoints while that transition is in progress.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 451 code bytes; public state is 4 bytes and private scratch is 11 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Eight product stages followed by up to 255 subtraction stages. A /256 scale is cheaper but needs an explicit final-endpoint policy. A wider fixed-point interpolation or native 68000 multiply/divide can trade code for faster updates.

This computes a position for a supplied fraction; it does not own a clock or easing curve. Replacing START with the previous output every frame creates a different, asymptotic motion. Descending values deliberately use start-relative rounding rather than floor of the final signed expression.

## Execution evidence

Four variants run on 48K PAL ROM tape load and USR, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 64 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
