## Use it in a project

P0–P7 and Q0–Q7 are eight MSB-left mask rows. Place Q SHIFT_X pixels right and SHIFT_Y pixels down relative to P. Return HIT=1 and the first overlapping P row when any opaque bits coincide; otherwise HIT=0 and ROW=255. A shift of eight or more on either axis is a valid empty overlap. Inputs are preserved.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **HIT, ROW, SHIFT_X, SHIFT_Y, P0, P1, P2, P3, P4, P5, P6, P7, Q0, Q1, Q2, Q3, Q4, Q5, Q6, Q7**. They occupy 20 contiguous bytes. Also reserve the private workspace: **T0, T1, T2, T3, T4, T5** (6 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `pixel_mask_collision_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `pixel_mask_collision_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none |
| Supply before service | SHIFT_X, SHIFT_Y and both mask arrays |
| Read after service | HIT and ROW |

Shift each Q row into P’s horizontal alignment, then AND corresponding rows. Any surviving bit is a shared opaque pixel. Transparent corners of overlapping boxes no longer count as contact.

## Machine contract

AF/BC/DE/HL may change; IX/IY are preserved. A direct CALL needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The 48K diagnostic boots through ROM tape loading and USR, disables interrupts and owns the screen. The helper performs no port or screen writes.

## Adapt the caller

A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Mistake and repair

The wrong caller ignores horizontal displacement and aligns the masks. It reports contact between opaque bits that are actually apart. Convert relative coordinates before the narrow-phase mask query.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 282 code bytes; public state is 20 bytes and private scratch is 6 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

At most eight row visits and seven shifts per row. Run an AABB broad phase first. Pre-shifted masks use more memory to reduce shifts; a box or circle may already provide the intended game feel.

This bounded helper covers Q right/down of P. Negative relative placement needs a deliberate swapped/normalised query, including conversion of the returned row to the desired space. It tests collision masks, not display colours or hardware collision latches.

## Execution evidence

Four variants run on 48K PAL ROM tape load and USR, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 50 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
