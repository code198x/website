## Use it in a project

MINIMUM must be below MAXIMUM, POSITION inside them and DIRECTION either 0 towards the minimum or 1 towards the maximum. Consume DISTANCE byte-sized unit steps, reflecting before a step that would leave the interval. BOUNCES counts reflections; landing exactly on an endpoint does not reflect until movement next needs to leave it. Invalid input leaves position/direction unchanged.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **POSITION, MINIMUM, MAXIMUM, DISTANCE, DIRECTION, BOUNCES, VALID**. They occupy 7 contiguous bytes. Also reserve the private workspace: **T0** (1 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `reflected_axis_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `reflected_axis_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | POSITION and DIRECTION |
| Supply before service | MINIMUM, MAXIMUM and DISTANCE |
| Read after service | BOUNCES and VALID |

Each unit of travel checks whether the current direction would leave the interval. Reflect first if it would, then consume that unit. Remaining travel keeps moving, so a large step can bounce more than once.

## Machine contract

AF/BC/DE/HL may change; IX/IY are preserved. A direct CALL needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. Scope or rename routine and field labels and allocate a separate block for each independent instance. Give each block one mutation owner.

The 48K diagnostic boots through ROM tape loading and USR, disables interrupts and owns the screen. The helper performs no port or screen writes.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Mistake and repair

The wrong caller reduces DISTANCE to one. It loses travel remaining after a bounce and changes the motion speed. Pass the full intended travel; use a faster algorithm if the bounded unit-step loop is too expensive.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 257 code bytes; public state is 7 bytes and private scratch is 1 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

At most 255 unit iterations. This is readable and preserves overshoot, but a large-distance folded-coordinate version is the next optimisation to investigate.

This readable version costs up to 255 loop iterations. A folded-coordinate or quotient/remainder version can handle large travel more cheaply, but needs wider arithmetic and careful endpoint direction rules. It models a point and fixed walls, not swept shape collision or damping.

## Execution evidence

Four variants run on 48K PAL ROM tape load and USR, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 64 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
