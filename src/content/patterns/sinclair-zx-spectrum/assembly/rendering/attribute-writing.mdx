## Overview

The Spectrum's attribute system lets you colour 8x8 character cells without drawing pixels. Each attribute byte controls foreground (ink), background (paper), brightness, and flash. This is the fastest way to create colourful displays and is the basis for many classic Spectrum game graphics.


## Calling the routines

Include `attributes.inc` once. Give the program a valid stack and ownership of the attribute memory it writes. No ROM routine or interrupt handler is required.

`set_attribute` takes A = attribute byte, B = row 0–23 and C = column 0–31. `fill_row` takes A = row and E = attribute. `fill_attributes` takes A = attribute, B/C = the top-left cell and D/E = height/width. A zero width or height does nothing. Other rectangles must fit: B + D ≤ 24 and C + E ≤ 32. This routine does not clip.

The cell and rectangle routines preserve AF, BC and DE, and change HL. The row filler changes AF, BC and HL, and preserves DE. The rectangle reserves up to 16 additional stack bytes, plus its caller's return address. Never share that stack or change its loop registers from an interrupt without preserving them.

Attribute bits are FLASH, BRIGHT, PAPER and INK. Setting a cell changes the colours of all its pixels; it does not draw or erase the bitmap. Try a 4 × 3 rectangle, then one at row 23, column 31. Both the visible footprint and the bytes outside it should agree with the requested area.

For example, after establishing the documented stack, state and data:

```z80
    ld a,$47          ; bright white ink, black paper
    ld b,2
    ld c,3
    ld d,3            ; height in character cells
    ld e,4            ; width
    call fill_attributes
    ; Include attributes.inc once, outside the executed control flow.
```

## Trade-offs

| Aspect | Cost |
|--------|------|
| CPU | ~30 cycles per cell |
| Memory | 768 bytes for full screen |
| Limitation | 8x8 cell resolution only |

**When to use:** Board games, puzzles, status displays, any game using character-cell graphics.

**When to avoid:** When you need pixel-level colour control (not possible on Spectrum).

## Attribute Memory Layout

```
$5800-$581F: Row 0  (columns 0-31)
$5820-$583F: Row 1
$5840-$585F: Row 2
...
$5AE0-$5AFF: Row 23
```

Total: 768 bytes (24 rows x 32 columns)
