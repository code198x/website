A ball can lose speed when it hits a surface without losing all of its sideways motion. Separate the component along the chosen surface normal from the tangent, then apply a deliberate bounce coefficient.

## Include and initialise

Reserve public N/D/T/O/A/B/C/R, private P and lines **3000–3150**. There are no arrays. Combine routines.bas and the caller through build.py, keeping END, STOP or a jump before the helper. C64/BBC use GOSUB; Spectrum uses GO SUB. Call **3000** to clear public fields.

A is the incoming normal-speed magnitude, an integral byte. B is its direction bit, zero or one. C is the tangential component's byte representation. R is restitution in quarters: zero through four. The normal uses magnitude plus direction; it is not a signed byte. The tangent is copied unchanged, so the caller owns its interpretation.

## Apply one response

Call **3100**. For valid inputs, N becomes the integer part of A*R/4, D becomes 1-B, T copies C and O=1. All input fields survive. Invalid data clears N/D/T/O while preserving inputs.

R=4 preserves normal-speed magnitude and reverses direction. R=0 removes normal speed, while still reversing the direction bit; a zero magnitude has no motion whichever direction bit is retained. Intermediate multiplication can reach 1020 and must stay wide until divided.

## Compare two materials

The normal caller uses speed eleven, direction one, tangent byte 254 and R=3. It returns normal magnitude eight, direction zero and unchanged tangent 254. The custom caller uses speed 255, direction zero, tangent 128 and R=2, giving 127, one and 128. Fractional remainders are deliberately discarded.

Later calls cover zero speed, fully elastic response and an invalid direction. AA/BB/JJ (Z on Spectrum), line 2000 and the mailbox are diagnostics. A game must decide when a contact is approaching the surface and convert its chosen components back to world velocities.

## Choose the physical approximation

This helper does not discover a surface normal, calculate impact geometry or check whether an object is already moving away. Applying it repeatedly to the same unresolved contact can reverse velocity repeatedly. Separate collision detection, depenetration and response ownership before calling it.

A quarter-step coefficient offers five material choices. Finer fixed-point coefficients can reduce quantisation, at the cost of wider multiplication and additional data or arithmetic. Retaining a fractional remainder changes the interface and state. Tangential friction, spin, coupled bodies and energy conservation need more than this single normal-component calculation.

## Mistake and repair

The wrong caller forces R=4 for every material. It turns the intended damped response into a full-speed bounce; both saved magnitude and preserved-coefficient checks fail. Keep the requested material coefficient authoritative. Repaired source and loaded program match normal exactly.

## Global names and line numbers

BASIC numeric names, arrays and numbered lines are global. To combine helpers, rename public and private fields and renumber the helper together with every GO SUB/GO TO reference. Keep each state block under one owner. The maintained build.py rejects duplicate line numbers; it does not automatically namespace or renumber routines.

## Machine and measured size

Spectrum FOR variables must be single letters: this diagnostic uses Z instead of the other callers’ JJ. The helper uses scalar numeric fields and allocates no arrays. AND/OR in these listings join comparisons; neither is being used as a bitwise operator. The diagnostic reserves its mailbox above CLEAR 59999.

The numbered helper occupies **340 tokenised program bytes** on this interpreter, including line headers. This excludes the caller, test tables, numeric scalar/array storage, interpreter stacks and ROM. Tokenised size is not machine-code size or a hardware-cycle count. No real-time or whole-game performance budget is inferred from the diagnostic. The caller’s AA/BB, Z and RAM mailbox are observation machinery, not required game state.
