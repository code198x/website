## Use it in a project

A 4×4 row-major grid uses zero for traversable and nonzero for blocked cells. FROM and TO must be 0–15. Return FOUND=1, shortest four-connected DISTANCE and the first MOVE (1 left, 2 right, 3 up, 4 down). Already at a clear destination returns distance zero and move zero. Blocked or unreachable endpoints return FOUND=0, DISTANCE=255 and MOVE=0 with VALID=1. Bad indices return VALID=0.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **MOVE, DISTANCE, FOUND, VALID, FROM, TO, C0, C1, C2, C3, C4, C5, C6, C7, C8, C9, C10, C11, C12, C13, C14, C15**. They occupy 22 contiguous bytes. Also reserve the private workspace: **T0, T1, T2, T3, T4, T5, T6, T7, EXPR_SAVE, V0, V1, V2, V3, V4, V5, V6, V7, V8, V9, V10, V11, V12, V13, V14, V15** (25 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `bounded_grid_path_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `bounded_grid_path_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none |
| Supply before service | FROM, TO and C0–C15 |
| Read after service | MOVE, DISTANCE, FOUND and VALID |

Build distance layers outwards from the destination. A cell can join only the next layer, so scanning order cannot turn a long route into a falsely short one. A neighbour one layer closer supplies a valid first move.

## Machine contract

D0–D3/A0–A1/CCR may change; D4–D7/A2–A6 are preserved. A direct BSR/JSR needs four return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The A500 OCS diagnostic cold-boots an OFS disk, owns the Copper and bitplane and disables interrupt/DMA sources. The helper does not take over hardware or allocate Chip RAM.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x` and `BUILD198X=/path/to/build198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Mistake and repair

The wrong caller removes the obstacle before searching. The returned first step goes through the cell that should be blocked. A path query should read the collision map, not clear cells to make a route possible.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 1492 code bytes; public state is 22 bytes and private scratch is 25 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Fifteen layers scan sixteen cells each, using sixteen private distance bytes. A queue-based breadth-first search avoids many repeated probes on larger boards but needs a bounded queue. Incremental search can spread work across frames.

This unit-cost four-neighbour search chooses the first available downhill neighbour in left/right/up/down order. It returns a first step, not a full persistent path. Diagonals, terrain costs and moving obstacles require different rules or a new query.

## Execution evidence

Four variants run on A500 OCS PAL, Kickstart1.3 OFS cold boot, using Asm198x 0.0.72, Emu198x 0.44.2 and Build198x 0.2.9. Each executes 45 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
