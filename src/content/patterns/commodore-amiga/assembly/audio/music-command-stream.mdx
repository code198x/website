## Use it in a project

COUNT is 0–8 pairs N/U. N=0 is rest, 1–95 is a logical note, and 255 ends immediately. Other note codes or a zero duration on a note/rest are invalid. INDEX counts consumed pairs and must not exceed COUNT. If REMAINING is nonzero, decrement it first; when it reaches zero consume the next pair in the same call. A newly emitted note/rest holds for U service intervals, with REMAINING set to U. EVENT=1 emits NOTE; EVENT=2 is a one-shot stop on count exhaustion or N=255. FINISHED is sticky. Validate only the consumed pair before advancing INDEX. Invalid state returns VALID=0 and no event; an elapsed timer may already reach zero.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **NOTE, EVENT, FINISHED, VALID, INDEX, REMAINING, COUNT, N0, N1, N2, N3, N4, N5, N6, N7, U0, U1, U2, U3, U4, U5, U6, U7**. They occupy 23 contiguous bytes. Also reserve the private workspace: **T0, T1** (2 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `music_command_stream_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `music_command_stream_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | INDEX, REMAINING, FINISHED and NOTE; immutable N/U pairs |
| Supply before service | COUNT and one service tick |
| Read after service | EVENT, NOTE, FINISHED and VALID |

Only consume a pair when its predecessor’s interval has expired. A bounded count prevents reading past the stream; explicit end and exhausted count each emit a stop exactly once.

## Machine contract

D0–D3/A0–A1/CCR may change; D4–D7/A2–A6 are preserved. A direct BSR/JSR needs four return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The A500 OCS diagnostic cold-boots an OFS disk, owns the Copper and bitplane and disables interrupt/DMA sources. The helper does not take over hardware or allocate Chip RAM.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x` and `BUILD198X=/path/to/build198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Customise it

## Mistake and repair

The wrong client discards each note’s hold time. It advances to a rest or next note one service too early. Retain REMAINING and use one consistent service clock.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 548 code bytes; public state is 23 bytes and private scratch is 2 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

One pair at most per service, with no scan over instant commands. Rich formats can add instrument/loop commands, but need a command budget to stop malformed streams looping forever.

This is a logical sequencer, not an audible chip driver, tracker, tempo converter or general music format. The caller maps note numbers to chip periods and handles rest/stop by silencing its owned voice. SID, APU and Paula have different tuning, envelope and channel rules; Spectrum beeper playback also consumes CPU time. No emitted PCM or audible-timing claim is made by the state diagnostic.

## Execution evidence

Four variants run on A500 OCS PAL, Kickstart1.3 OFS cold boot, using Asm198x 0.0.72, Emu198x 0.44.2 and Build198x 0.2.9. Each executes 43 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
