## Use it in a project

INPUT_COUNT selects 0–8 bytes B0–B7. Encode consecutive equal values as positive count/value byte pairs in R0–R15, up to CAPACITY 0–16. Preflight all runs before writing. Invalid bounds return VALID=0, ERROR=1; insufficient output returns VALID=1, ERROR=2. Both failures leave output bytes unchanged and WRITTEN=0. Success returns ERROR=0 and the even byte count; unused output bytes are preserved.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **WRITTEN, ERROR, VALID, INPUT_COUNT, CAPACITY, B0, B1, B2, B3, B4, B5, B6, B7, R0, R1, R2, R3, R4, R5, R6, R7, R8, R9, R10, R11, R12, R13, R14, R15**. They occupy 29 contiguous bytes. Also reserve the private workspace: **T0, T1, T2, T3, T4, EXPR_SAVE** (6 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `bounded_rle_encoder_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `bounded_rle_encoder_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | R0–R15 as the owned destination |
| Supply before service | INPUT_COUNT, CAPACITY and B0–B7 |
| Read after service | WRITTEN, ERROR and VALID |

A first pass counts runs and proves that every pair will fit. A second pass writes the pairs. That extra scan gives the caller an all-or-nothing output contract.

## Machine contract

D0–D3/A0–A1/CCR may change; D4–D7/A2–A6 are preserved. A direct BSR/JSR needs four return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The A500 OCS diagnostic cold-boots an OFS disk, owns the Copper and bitplane and disables interrupt/DMA sources. The helper does not take over hardware or allocate Chip RAM.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x` and `BUILD198X=/path/to/build198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Mistake and repair

The wrong caller passes no output capacity for a nonempty block. The encoder rejects the whole request and preserves its output buffer. Pass the actual reserved capacity, rather than a count that has not yet been filled.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 748 code bytes; public state is 29 bytes and private scratch is 6 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Two bounded scans over at most eight bytes, plus sixteen destination writes in the worst case. A streaming encoder can avoid preflight but must report partial output and support continuation explicitly.

RLE can expand data: eight distinct bytes need sixteen encoded bytes. This uses the existing count/value idea, not a new project-wide asset container. A decoder must still validate its own lengths and output bounds.

## Execution evidence

Four variants run on A500 OCS PAL, Kickstart1.3 OFS cold boot, using Asm198x 0.0.72, Emu198x 0.44.2 and Build198x 0.2.9. Each executes 34 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
