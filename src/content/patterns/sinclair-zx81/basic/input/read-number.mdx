## Take the reader

Copy the INPUT statement into a free numbered line in your own command flow. The complete caller shows where to initialise N and where to return after an update.

<CodeFromFile src="sinclair-zx81/patterns/basic/input/read-number/read-number.bas" lang="basic" title="The reusable reader" />

INPUT A is a blocking numeric reader. The caller performs N=N+A, so any valid numeric contribution is added; 0 leaves the total alone. It is not a one-key accept/reject routine.

BASIC owns the keyboard buffer, line editor, return stack and variable storage. The global variable and line-number names belong to your program: reserve or rename them consistently. INPUT waits; no animation or deadline code in your main path can run during that wait.


## Change it and recognise a mistake

Keep the normal display-serviced environment used here. FAST/SLOW choices change what the player sees while the CPU works; the sample does not add an artificial frame timer.

The broken update adds A twice. Submitting 1 reaches 2 immediately. INPUT read the right number; the update used it twice. Restore N=N+A. The caller also checks a nonzero start, so a lost initialiser cannot hide behind zero-filled state.
