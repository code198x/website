## Take the reader

Copy `read-command.bas` into free line numbers, then call it with GOSUB 4000. It replaces A$; the caller checks that value before updating N. Keep N’s initialisation outside the repeated path. Renumber the GOSUB and routine together.

<CodeFromFile src="mattel-aquarius/patterns/basic/input/read-command/read-command.bas" lang="basic" title="The reusable reader" />

GOSUB 4000 replaces A$ with the submitted line. The caller recognises GO. The 4000 range deliberately leaves the existing 3000-range sound DATA intact.

BASIC owns the keyboard buffer, line editor, return stack and variable storage. The global variable and line-number names belong to your program: reserve or rename them consistently. INPUT waits; no animation or deadline code in your main path can run during that wait.

## Change it and recognise a mistake

Reserve the complete numbered ranges. Reusing line 3000 for INPUT replaces a sound DATA line; the native fault run fails before the game starts. The repaired program uses 4000/4010.

This deliberately broken caller reuses an accepted command instead of reading another one. The world advances without you. Restore the GOSUB before the validation/update path; the working caller waits at zero until input arrives.

<CodeFromFile src="mattel-aquarius/patterns/basic/input/read-command/mistakes/stale-command.bas" lang="basic" title="Deliberately broken input/update path" />

<Figure src="/images/mattel-aquarius/patterns/column-expansion/basic/stale-command.png" alt="Mattel Aquarius deliberately broken input caller." caption="Observed fault; use the working caller to repair it." />

The sound helper already uses DATA lines in the 3000 range. Defining INPUT at 3000 overwrote one of them and produced **OD Error in 4** during READ. The repaired reader lives at 4000/4010. A new line number is an integration decision, not spare storage you can assume is free.

## Verification and sources

Target: **stock Aquarius BASIC with an array-backed USR sound helper**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/mattel-aquarius/patterns/basic/input/read-command) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/mattel-aquarius/patterns/basic/input/read-command/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations.
