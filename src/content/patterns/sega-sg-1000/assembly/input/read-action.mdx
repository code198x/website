Load the cartridge produced by the Makefile in the named configuration; retain its reset/header setup.

## Take the reader

`sample.inc` is an inline hardware sampler: include it where the caller samples input. It has no RET/RTS and must not be called as a subroutine. It supplies the held state described below; the caller supplies previous-state storage and decides what a new press does.

<CodeFromFile src="sega-sg-1000/patterns/assembly/input/read-action/sample.inc" lang="z80" title="The reusable reader" />

Controller port $DC returns active-low button-1 bit 4. B receives 0/$10; AF/B change.

Calculate a new-press mask as current AND NOT previous, then store current as previous on every update, including release. Test held state for continuous movement and the new-press mask for an action that should happen once. A key already held at the caller’s first sample counts as a press because previous starts at zero.

Caller storage: previous=$C001; turn=$C000, field clock=$C002/$C003; stack below $C3F0. The sample’s display initialiser and any interrupts have their own ownership requirements; keep them with this complete example.


## Change it and recognise a mistake

Keep pad sampling separate from display modes; shared pad/PSG ideas do not make the SG-1000 VDP a Master System VDP.

The broken caller feeds held state into the action decision. Keeping the button down advances repeatedly; the native fault run reaches 32 instead of remaining at one. Restore the previous-state comparison and update previous on release as well.

## Verification and sources

Target: **NTSC stock SG-1000 cartridge configuration**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/sega-sg-1000/patterns/assembly/input/read-action) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/sega-sg-1000/patterns/assembly/input/read-action/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations.

Sega, SG-1000 technical documentation: controller/PSG I/O; TI SN76489A and TMS9918A data manuals.
