## Take the reader

Copy `read-command.bas` into free line numbers, then call it with GOSUB 3000. It replaces A; the caller checks that value before updating N. Keep N’s initialisation outside the repeated path. Renumber the GOSUB and routine together.

<CodeFromFile src="dragon-32/patterns/basic/input/read-command/read-command.bas" lang="basic" title="The reusable reader" />

INPUT A waits for a submitted number; the caller accepts 1. The routine reads a value and leaves the decision to its caller.

BASIC owns the keyboard buffer, line editor, return stack and variable storage. The global variable and line-number names belong to your program: reserve or rename them consistently. INPUT waits; no animation or deadline code in your main path can run during that wait.

## Fit it into a program

The complete numbered program is `caller.bas`, `draw.bas`, `sound.bas` and `read-command.bas` together. The reader does not accept a move on its own; the IF in the caller does that.

## Change it and recognise a mistake

Choose another accepted number or dispatch several numeric commands. INPUT is useful when the world can wait.

This deliberately broken caller reuses an accepted command instead of reading another one. The world advances without you. Restore the GOSUB before the validation/update path; the working caller waits at zero until input arrives.
