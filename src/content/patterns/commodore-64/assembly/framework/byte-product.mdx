## Use it in a project

LEFT and RIGHT are unsigned 0–255. Return their exact product in PRODUCT_LO/PRODUCT_HI, low byte first. Both inputs are preserved. There is no overflow for this input domain: 255×255 is 65,025.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **PRODUCT_LO, PRODUCT_HI, LEFT, RIGHT**. They occupy 4 contiguous bytes. Also reserve the private workspace: **T0, T1, T4, T5, T6, T7, T8, T9** (8 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `byte_product_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `byte_product_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none |
| Supply before service | LEFT and RIGHT |
| Read after service | PRODUCT_LO and PRODUCT_HI |

The multiplier is inspected one bit at a time. Each set bit adds a shifted multiplicand into a two-byte result. Carry is handled explicitly, so the same byte interface works on the three CPU families.

## Machine contract

A/X/status may change; Y and decimal mode are preserved. Use CLD for binary arithmetic. A direct JSR needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The diagnostic PRG owns screen, font and colour RAM and disables interrupts; it does not return to BASIC. The reusable helper does none of those things.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Customise it

Use the maximum two-byte result instead of a small factor. The maintained custom caller changes its inputs or client sequence rather than hiding a different implementation behind the same label. Compare every state of the two clients, not only their final display.

## Mistake and repair

The wrong caller substitutes a factor of one, often mistaken for a default scale. The result is the original value rather than the requested product. Pass both actual factors; keep the high result byte.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 183 code bytes; public state is 4 bytes and private scratch is 8 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Eight bit stages, with additions only for set multiplier bits. The 68000 has hardware multiplication; a word-oriented MULU implementation is a useful faster alternative. This common byte routine makes the representation visible rather than claiming to be the fastest native implementation.

This is unsigned integer multiplication. Signed values, fixed-point scaling and saturation require explicit conversions; discarding PRODUCT_HI changes the result to multiplication modulo 256.

## Execution evidence

Four variants run on PAL stock-ROM PRG, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 64 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
