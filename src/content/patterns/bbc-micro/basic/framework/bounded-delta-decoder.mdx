## Include and initialise

Reserve Q(8) for delta bytes, R(8) for output, public W/O/N/B and private I/T. Reserve lines **3000–3190**, combine routines.bas with your caller using build.py and keep END, STOP or a jump before the helper. C64/BBC use GOSUB; Spectrum uses GO SUB. Private I/T are not caller scratch during a call.

Call **3000** at a deliberate reset boundary. It clears all public fields and both arrays. Then supply base B, count N=0..8 and the selected delta bytes. Retain an output array only as long as your game needs its decoded values; this is a whole-block service, not a streaming cursor.

## Decode the selected deltas

Call **3100**. Each Q element is a two's-complement byte:0..127 mean that nonnegative difference,128..255 mean −128..−1. Starting at B, add each selected difference modulo 256 and place the successive values in R(1)..R(N). B, N and Q survive the call.

| Field | Use |
|---|---|
| B / N / Q(1)..Q(8) | Base, selected count and source delta bytes |
| R(1)..R(8) | Owned destination; unused tail preserved |
| W / O | Actual written count / valid flag |

N, B and selected Q values must be integral and in range. Success returns W=N,O=1. Invalid input returns W=0,O=0 and preserves **all** output elements; the helper validates the complete selected input before writing. Empty input is valid, writes nothing and does not inspect unused Q elements.

This is deliberate byte wrapping, not clamping. For example 250+10 becomes 4, and 4 plus a delta byte 128(which represents−128) becomes 132 modulo 256. Use a wider or checked-coordinate contract where wrapping would be wrong for the world.

Adding the stored unsigned byte and reducing modulo 256 gives the same wrapped result as adding its signed interpretation. That avoids dialect-specific signed-byte conversion while retaining the specified output. The helper allocates no storage or display resources.

## Keep the base with its stream

The normal caller starts at 100 and decodes a mix of forward, backward and zero moves. The custom caller starts at 250 and includes wrapping and the −128 delta. Later calls exercise empty input, invalid count and a new base while checking the untouched output tail.

Line 2000, AA/BB/JJ/KK (Z/Q on Spectrum) and mailbox writes are diagnostics. A game supplies B/N/Q, calls 3100 and consumes only the first W output elements after checking O. Do not confuse the allocated eight slots with the returned length.

## Customise representation

Choose what the decoded bytes represent: coordinates, table entries or another cyclic byte quantity. A long path needs larger arrays/offsets and perhaps periodic absolute checkpoints for random access. With only deltas, reaching a later point requires summing the earlier differences.

One delta byte still produces one output byte. This alone does **not compress** the stream; savings require narrower packed deltas or another encoding, with an escape rule for changes that do not fit. Absolute bytes can be simpler and give immediate random access.

## Mistake and repair

The wrong caller clears B before decoding. Every output is shifted from the intended route, even though the helper completes successfully. Both saved checks fail because the decoded values and supplied base differ. Preserve the base alongside the deltas. The repair matches the normal source and loaded program exactly.

## Machine and measured size

BBC BASIC arrays include element zero; this one-based array interface leaves it unused. Its diagnostic uses MODE 7 and HIMEM=&6000 to separate program storage, mailbox and screen. The helper itself changes neither mode nor HIMEM.

The numbered helper occupies **334 tokenised program bytes** on this interpreter, including line headers. This excludes the caller, test tables, numeric scalar/array storage, interpreter stacks and ROM. Tokenised size is not machine-code size or a hardware-cycle count. No real-time or whole-game performance budget is inferred from the diagnostic. The caller’s AA/BB, JJ/KK and RAM mailbox are observation machinery, not required game state.

C64 enters stock RUN, Spectrum uses ROM tape loading, and BBC enters every numbered source line through MOS/BASIC.
