Build the complete caller with `make -C memotech-mtx/patterns/assembly/input/read-action`. Press **Space** once, keep it held, then release and press again. The piece moves on each new press and returns to its starting position after two; holding does not repeat the action. Enter the generated DATA/POKE loader through stock BASIC, then RUN; USR takes over until reset.

## Take the reader

`sample.inc` is an inline hardware sampler: include it where the caller samples input. It has no RET/RTS and must not be called as a subroutine. It supplies the held state described below; the caller supplies previous-state storage and decides what a new press does.

<CodeFromFile src="memotech-mtx/patterns/assembly/input/read-action/sample.inc" lang="z80" title="The reusable reader" />

OUT ($05),$7F selects keyboard column 7; IN ($06) supplies the high part of its return. Space is active-low bit 0 of that read. B receives 0/1; AF/B change.

Calculate a new-press mask as current AND NOT previous, then store current as previous on every update, including release. Test held state for continuous movement and the new-press mask for an action that should happen once. A key already held at the caller’s first sample counts as a press because previous starts at zero.

Caller storage: previous=$DF01; turn=$DF00, field clock=$DF02/$DF03; stack below $F7F0. The sample’s display initialiser and any interrupts have their own ownership requirements; keep them with this complete example.


## Change it and recognise a mistake

Preserve the read/write distinction and column drive. This direct reader takes over the keyboard configuration rather than consuming a BASIC character.

The broken caller feeds held state into the action decision. Keeping the button down advances repeatedly; the native fault run reaches 32 instead of remaining at one. Restore the previous-state comparison and update previous on release as well.

## Verification and sources

Target: **MTX500 PAL, stock BASIC DATA/POKE/USR entry**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/memotech-mtx/patterns/assembly/input/read-action) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/memotech-mtx/patterns/assembly/input/read-action/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations.
