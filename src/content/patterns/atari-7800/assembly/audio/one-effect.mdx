## Take the effect

<CodeFromFile src="atari-7800/patterns/assembly/input/read-action/sound.inc" lang="6502" title="The reusable effect" />

Stock TIA channel 0, duration byte $1905; no cartridge POKEY is assumed. A/flags change. The caller owns MARIA display lists, TIA sound and its mode lock.

Include sound.inc once with the caller’s constants and duration byte. Initialise the duration byte to zero before the first service call. Call trigger_sound for an accepted action, then call service_sound exactly once per accepted display update. The eighth service call mutes the effect. Because the supplied caller services in the triggering iteration too, this is a count of service calls, not eight complete elapsed frame intervals. Triggering again restarts the duration; there is no queue.

The complete initialiser also mutes other channels. To reuse just this effect beside music, agree channel ownership and remove unrelated global setup only after providing a replacement. Device latches, power, routing and master volume may affect more than one voice.

## Change it and recognise a mistake

Change TIA tone/noise controls; a POKEY cartridge is an expanded audio configuration with another implementation.

The omitted-trigger control still accepts the action but fails the same audio guard as the working caller. Keyboard clicks or other machine output are not enough: the BASIC checks compare against a separate rejected-command recording.

<CodeFromFile src="atari-7800/patterns/assembly/input/read-action/mistakes/no-sound.asm" lang="6502" title="Deliberately omitted sound trigger" />

The working implementation above repairs that omission. If an effect instead drones on, check the mute/service path and that its state is initialised. Servicing twice makes a counted effect shorter; servicing only after input can leave it running while the player waits. Those are lifecycle decisions to test when adapting it.

## Run the caller

Build the complete caller with `make -C atari-7800/patterns/assembly/input/read-action`. Press **fire** once, keep it held, then release and press again. The piece moves on each new press and returns to its starting position after two; holding does not repeat the action. Load the cartridge produced by the Makefile in the named configuration; retain its reset/header setup.

## Verification and sources

Target: **NTSC 48 KiB cartridge, reset without BIOS authentication**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/atari-7800/patterns/assembly/input/read-action) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/atari-7800/patterns/assembly/input/read-action/verification/results.json).
