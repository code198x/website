## Take the reader

`sample.inc` is an inline hardware sampler: include it where the caller samples input. It has no RET/RTS and must not be called as a subroutine. It supplies the held state described below; the caller supplies previous-state storage and decides what a new press does.

<CodeFromFile src="atari-7800/patterns/assembly/input/read-action/sample.inc" lang="6502" title="The reusable reader" />

Legacy INPT4 at $0C uses active-low bit 7; the inline sampler stores 0/$80 in current=$1904. It changes A/flags and does not read the second independent controller button.

Calculate a new-press mask as current AND NOT previous, then store current as previous on every update, including release. Test held state for continuous movement and the new-press mask for an action that should happen once. A key already held at the caller’s first sample counts as a press because previous starts at zero.

Caller storage: previous=$1901, current=$1904; turn=$1900, field clock=$1902/$1903. The sample’s display initialiser and any interrupts have their own ownership requirements; keep them with this complete example.


## Change it and recognise a mistake

Add the second controller button only after handling its distinct wiring. Do not copy the 5200 bit-0 trigger mask.

The broken caller feeds held state into the action decision. Keeping the button down advances repeatedly; the native fault run reaches 32 instead of remaining at one. Restore the previous-state comparison and update previous on release as well.

## Verification and sources

Target: **NTSC 48 KiB cartridge, reset without BIOS authentication**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/atari-7800/patterns/assembly/input/read-action) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/atari-7800/patterns/assembly/input/read-action/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations.
