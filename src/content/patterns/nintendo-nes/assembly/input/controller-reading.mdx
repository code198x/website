The NES controller sends eight button states through one serial input. Strobe once, read eight times and rotate each returned bit into a byte. After eight shifts the previous byte has been shifted out, so it does not need clearing first.

## Include, initialise and sample

Include `framework/input-to-sound/input.inc` once. Its `controls` byte belongs in writable RAM; the ca65 caller supplies the BSS segment. Set up the stack and APU first, and leave DMC sample DMA disabled for this simple reader.

<CodeFromFile src="nintendo-entertainment-system/patterns/assembly/framework/input-to-sound/input.inc" lang="6502" />

`read_controls` changes A/X and flags, preserves Y and stores held input in `controls`. Its masks are:

| Button | Mask |
| --- | --- |
| A / B | `$80` / `$40` |
| Select / Start | `$20` / `$10` |
| Up / Down | `$08` / `$04` |
| Left / Right | `$02` / `$01` |

Call once at the chosen update point and let movement, menus and [press detection](/patterns/cross-platform/input/edge-detection/) consume the same sample. Holding A keeps its bit set; this reader does not turn that into a single new press.

The [complete caller](/patterns/nintendo-nes/assembly/framework/collect-and-respond/) shows reset, frame ownership and use of the sampled byte. Its NMI announces a frame; the main loop reads the controller and advances the game.

## Ownership and limits

Writing the strobe to `$4016` latches both controllers. A two-controller reader should latch once and consume both serial streams under one owner. Two independent readers that strobe at unrelated times can disturb each other.

DMC sample DMA can interfere with serial reads on relevant NES hardware. This reader's contract excludes it. Repeated reads need a separate bounded timing and failure policy; merely naming a retry loop “safe” does not establish correctness. Use and verify a DMC-compatible implementation before combining these facilities.

**Code status: maintained reader reused by executed NTSC NROM callers.** Their real-input checks establish press, hold and release on that configuration with DMC disabled. This is not a DMC workaround or original-hardware qualification.
