## Use it in a project

One-axis half-open intervals use unsigned byte coordinates. ACTOR_SIZE/SOLID_SIZE must be nonzero; both solid endpoints plus size and the actor endpoint must fit in a byte. The old intervals must not overlap. MINIMUM/MAXIMUM bound the actor’s leading coordinate. Return POSITION, PUSHED and BLOCKED. If the swept solid would push the actor outside those limits, leave POSITION unchanged and set BLOCKED=1. Invalid geometry returns VALID=0. The helper never changes the solid.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **POSITION, PUSHED, BLOCKED, VALID, ACTOR_POSITION, ACTOR_SIZE, SOLID_OLD, SOLID_NEW, SOLID_SIZE, MINIMUM, MAXIMUM**. They occupy 11 contiguous bytes. Also reserve the private workspace: **T0, T1, T2, T3** (4 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `moving_solid_push_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `moving_solid_push_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none |
| Supply before service | actor geometry, old/new solid geometry and bounds |
| Read after service | POSITION, PUSHED, BLOCKED and VALID |

Sweep the solid’s leading face across the actor. A rightward push places the actor at the new right face; a leftward push subtracts the actor size from the new left face. Validate the required destination before returning it.

## Machine contract

A/X/status may change; Y is preserved. The 2A03 has no decimal arithmetic mode. A direct JSR needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. The samples use fixed symbol bindings. Scope or rename every label and binding, including the component_end measurement marker, and allocate a separate block for each independent instance. Different helpers can also use common field names, so combining them needs separate namespaces or explicitly renamed bindings. Give each block one mutation owner.

The NROM caller owns PPU setup and background display, with NMI and DMC disabled. Table and packet sizes are bounded to fit the cartridge caller and internal RAM; the helper owns no PPU registers.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. ## Mistake and repair

The wrong caller replaces the old solid position with the new one before the sweep. In this example, the actor occupies [10,12) and the solid occupies [12,14): they only touch. With old and new positions both 12, the helper sees no movement and returns POSITION=10, PUSHED=0, BLOCKED=0 and VALID=1. Keep previous/current positions distinct so the sweep can produce the required push.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 448 code bytes; public state is 11 bytes and private scratch is 4 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Constant work for one pair. Multiple actors need a validation/commit policy or rollback; resolving only the last frame’s overlap can miss a fast moving solid.

This handles one actor and one axis, without initial penetration. A real moving-solid transaction must inspect all affected actors and other obstacles before committing the solid’s movement. BLOCKED asks the caller to choose stop, crush or another explicit rule; it does not authorise leaving overlapping objects.

## Execution evidence

Four variants run on NTSC NROM, background only, DMC/NMI disabled, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 64 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
