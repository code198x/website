## Use it in a project

LOCAL_X 0–7 selects one of eight unsigned height offsets H0–H7. MIRROR nonzero reverses the profile. Add BASE_Y to the selected offset only if the result fits 0–255. SURFACE is 255 and VALID=0 on invalid x or overflow. The height profile remains unchanged.

Include `component.inc` once (MOS callers include the shared 6502 implementation through it). Reserve the public fields in this exact order: **LOCAL_X, BASE_Y, MIRROR, SURFACE, VALID, H0, H1, H2, H3, H4, H5, H6, H7**. They occupy 13 contiguous bytes. Also reserve the private workspace: **T0, T1, T2** (3 bytes). Array names in the explanation refer to the numbered consecutive bindings, such as C0, C1 and so on.

Call `slope_height_init` once at the intended reset boundary. It clears inputs as well as outputs and workspace. Set your starting state and configuration afterwards, then call `slope_height_step` whenever the described event occurs. The helper reads no device, waits for no frame and installs no interrupt handler.

| Ownership | Fields |
|---|---|
| Retain between calls | none inside the helper |
| Supply before service | LOCAL_X, BASE_Y, MIRROR and H0–H7 |
| Read after service | SURFACE and VALID |

A height profile is a tiny lookup table. Mirroring changes its index rather than duplicating the data. The returned surface is useful to a crossing test, but querying a slope alone cannot decide whether an actor should land.

## Machine contract

A/X/status may change; Y is preserved. The 2A03 has no decimal arithmetic mode. A direct JSR needs two return-address stack bytes. The helper makes no nested calls and adds no other stack use. Its named scratch is private workspace, not a pointer, a ROM variable or shared zero-page space that the game may borrow concurrently. Scope or rename routine and field labels and allocate a separate block for each independent instance. Give each block one mutation owner.

The NROM caller owns PPU setup and background display, with NMI and DMC disabled. Table and packet sizes are bounded to fit the cartridge caller and internal RAM; the helper owns no PPU registers.

## Adapt the caller

`demo.asm` supplies the bindings and include order. `exercise.inc` first runs table cases, then a separate client retaining state between calls. A game can call the public step entry directly and remove the diagnostic packet and display. Do not copy the diagnostic's hardware takeover into an existing game loop.

Build with `make ASM198X=/path/to/asm198x`. The Makefile produces normal, custom, deliberately wrong and repaired programs. Tools must already be installed; the sample downloads nothing.

## Mistake and repair

The wrong caller replaces LOCAL_X with zero. Every query samples one column of the profile, flattening the intended surface. Keep the actual tile-local coordinate and mirror the profile only through MIRROR.

The BROKEN branch lives in the sequential client, not the reusable helper. `wrong.asm` selects it; `repaired.asm` restores the normal call sequence. The repaired executable matches the normal program (for Spectrum, compare loaded CODE rather than the tape filename).

## Cost and alternatives

The measured helper extent is 128 code bytes; public state is 13 bytes and private scratch is 3 bytes. There are no immutable helper tables. Caller data, the test cases, return-address stack, alignment and display buffers cost additional space. These are assembled sizes, not cycle measurements.

Constant work with one profile lookup. An eight-byte profile can represent irregular shapes that a single slope equation cannot, trading data for arithmetic.

This returns geometry, not a full collision response. Convert world coordinates to tile-local x, query the surface, then decide crossing and snapping using the actor’s previous/proposed foot positions. Wide characters need multiple probes; ceilings and moving slopes need their own policy.

## Execution evidence

Four variants run on NTSC NROM, background only, DMC/NMI disabled, using Asm198x 0.0.72, Emu198x 0.44.2. Each executes 64 boundary/varied/error table cases, dirty initialisation and the separate retained-state client. An independent mathematical/container model checks every public byte after every call. This is bounded example coverage, not exhaustive correctness for every possible state.

The records retain loaded immutable code, completion, register sentinels, full packets, source/tool/firmware hashes and captures. The public gate validates these retained observations and rejects altered evidence; it does not run restricted firmware. No firmware is distributed. The eight displayed bytes are the first eight public fields, zero-padded when shorter; the packet includes every field.
