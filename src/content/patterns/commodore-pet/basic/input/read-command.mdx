## Take the reader

Copy `read-command.bas` into free line numbers, then call it with GOSUB 3000. It replaces A$; the caller checks that value before updating N. Keep N’s initialisation outside the repeated path. Renumber the GOSUB and routine together.

<CodeFromFile src="commodore-pet/patterns/basic/input/read-command/read-command.bas" lang="basic" title="The reusable reader" />

INPUT A$ returns a whole line; the caller recognises GO. N survives the subroutine. The ROM owns keyboard scanning and its editing buffer.

BASIC owns the keyboard buffer, line editor, return stack and variable storage. The global variable and line-number names belong to your program: reserve or rename them consistently. INPUT waits; no animation or deadline code in your main path can run during that wait.

## Fit it into a program

The complete numbered program is `caller.bas`, `draw.bas`, `sound.bas` and `read-command.bas` together. The reader does not accept a move on its own; the IF in the caller does that.

## Change it and recognise a mistake

Use another string or add a dispatch table after INPUT. Changing case handling is a separate decision.

This deliberately broken caller reuses an accepted command instead of reading another one. The world advances without you. Restore the GOSUB before the validation/update path; the working caller waits at zero until input arrives.

## Verification and sources

Target: **40-column PET firmware configuration with emulated VIA/CB2 sound output**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/commodore-pet/patterns/basic/input/read-command) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/commodore-pet/patterns/basic/input/read-command/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations. 

Commodore, PET/CBM documentation: BASIC INPUT and GOSUB/RETURN; MOS Technology 6522 VIA data sheet: ACR, shift-register modes and Timer 2; PET sound requires the appropriate CB2 connection.
