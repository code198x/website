Build the complete caller with `make -C tatung-einstein/patterns/assembly/input/read-action`. Press **Space** once, keep it held, then release and press again. The piece moves on each new press and returns to its starting position after two; holding does not repeat the action. Attach `build/demo.dsk` and use Control-BREAK to let MOS boot it. This is a disk-boot program, not a CP/M or BASIC loader.

## Take the reader

`sample.inc` is an inline hardware sampler: include it where the caller samples input. It has no RET/RTS and must not be called as a subroutine. It supplies the held state described below; the caller supplies previous-state storage and decides what a new press does.

<CodeFromFile src="tatung-einstein/patterns/assembly/input/read-action/sample.inc" lang="z80" title="The reusable reader" />

Select AY register 14 and write $FE for keyboard row 0, then select register 15 and read port $02. Space is active-low bit 6. B receives 0/$40; AF/B and the AY register selection change.

Calculate a new-press mask as current AND NOT previous, then store current as previous on every update, including release. Test held state for continuous movement and the new-press mask for an action that should happen once. A key already held at the caller’s first sample counts as a press because previous starts at zero.

Caller storage: previous=$8001; turn=$8000, field clock=$8002/$8003; stack below $FFF0. The sample’s display initialiser and any interrupts have their own ownership requirements; keep them with this complete example.


## Change it and recognise a mistake

Keep the dedicated keyboard interrupt masked as in startup, or synchronise all AY register selections. An interrupt between address and data accesses can redirect a write.

The broken caller feeds held state into the action decision. Keeping the button down advances repeatedly; the native fault run reaches 32 instead of remaining at one. Restore the previous-state comparison and update previous on release as well.

## Verification and sources

Target: **TC-01 PAL, MOS 1.2, Ctrl-BREAK disk boot**. These callers were executed with released Emu198x **0.44.1**; assembly uses Asm198x **0.0.71**. The [sample folder](https://github.com/code198x/code-samples/tree/d385b67e471a8d9e8b6c452c9e090fa22576adaf/tatung-einstein/patterns/assembly/input/read-action) contains reproduction instructions and [retained observations](https://github.com/code198x/code-samples/blob/d385b67e471a8d9e8b6c452c9e090fa22576adaf/tatung-einstein/patterns/assembly/input/read-action/verification/results.json). The independent checker binds source, native captures and actual output; its rejection tests exercise wrong state, missing files and false audio claims.

This qualifies the named emulator/firmware path. Pitch accuracy, original hardware and other peripherals require their own observations. 

Tatung, Einstein Hardware Manual: programmable sound generator/keyboard interface and port decoding; MOS disk boot header; General Instrument AY-3-8910 data manual.
