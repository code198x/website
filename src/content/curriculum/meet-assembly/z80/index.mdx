## What this is

This is **the Z80 itself** — the processor, not any one computer that contains it. Its
instruction set is the chip's own: `LD` to move a byte, compare-and-jump for a decision,
the loop, the stack, the arithmetic. None of that changes from machine to machine. A Z80
in a **ZX Spectrum**, an **Amstrad CPC**, an **MSX**, a **Sord M5** runs the *same*
instructions — so you learn them **once, here**, and carry them to all of them.

We teach on **one home machine — the Spectrum** — because you can't learn a processor in
a vacuum: every real example has to put a byte *somewhere*, and that somewhere is a
machine. Where an example touches the Spectrum specifically — the screen at address
`16384`, the keyboard ports — we'll **flag it**, because that's the one part another Z80
machine does differently. Everything else is the Z80, and travels untouched.

## What it assumes

You've met the ideas every program shares ([General Programming](/foundations/general-programming))
and how the machine counts — binary, hex, two's complement, bit logic
([Numbers & Bits](/foundations/numbers-and-bits)). This course leans on that constantly:
hex addresses, bit flags and signed offsets are the Z80's everyday vocabulary, and we
won't re-teach them here.

## How another Z80 machine joins

This is the point of teaching by processor. To bring a *new* Z80 computer into the fold,
you don't rewrite this course — you write that machine a short **briefing**: what its
screen is, how its sound works, where its memory lives. The briefing points back here for
the instruction set, and adds only its own "what's different." One Z80 course; many
machines hanging off it.

## The shape

The Z80 toolkit, in the order it builds:

- **Assemble and run** — turn text into bytes and watch them execute on the machine.
- **`LD` — moving bytes** — the load, the Z80's most-used instruction; registers and memory.
- **Test, then jump** — comparison and the conditional jump: `IF`, in the machine's own terms.
- **Loops** — counting down, and `DJNZ`, the Z80's built-in loop.
- **Call, return, and the stack** — naming a routine, and the stack that remembers the way back.
- **Arithmetic and the carry** — adding and subtracting beyond a single byte.
- **Addressing and 16-bit work** — pointers, index registers, and values bigger than a byte.

## Where it leads

With the Z80 in hand, you write **games** on your machine of choice — and the machine's
own **briefing** fills in the parts that are its, not the processor's.
