## What You Need

To develop for the C64, you need two things: a way to **compile** your code, and an **emulator** to run it.

<div class="setup-grid">
<div class="setup-column">

### <span class="icon">⚙️</span> Dev Toolchain

**Asm198x** is one binary that assembles for every system in the curriculum.

#### Install

```bash
brew install asm198x/tap/asm198x
```

Or, without Homebrew, the [installer script](https://github.com/asm198x/asm198x/releases/latest)
for macOS, Linux and Windows.

#### Compile

**Assembly**
```bash
asm198x --dialect acme --prg game.asm -o game.prg
```

**BASIC**
```bash
petcat -w2 -o game.prg game.bas
```

`petcat` tokenises a BASIC listing into a loadable program. It comes with
VICE, which you are installing anyway to run what you build.

</div>
<div class="setup-column">

### <span class="icon">🖥️</span> Emulator

Install **VICE** natively for the best experience.

**macOS**
```bash
brew install vice
```

**Linux**
```bash
sudo apt install vice
```

**Windows** — Download from [vice-emu.sourceforge.io](https://vice-emu.sourceforge.io/)

#### Run

```bash
x64sc game.prg
```

Use `x64sc` (accurate) rather than `x64` (faster but less accurate).
