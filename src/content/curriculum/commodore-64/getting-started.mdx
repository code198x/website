## Start with the machine

You can [open the C64 in your browser](/systems/commodore-64/) and type into its BASIC prompt. The [first BASIC lesson](/systems/commodore-64/basic/meet-c64-basic/unit-01/) shows how to type a line, run it and read the answer. Lessons with **Run it here** also let you try their supplied program.

For assembly, [Meet the Machine](/systems/commodore-64/assembly/meet-the-machine/unit-01/) starts by changing the border colour. Its supplied program runs in the browser; use the local build below to assemble your own edits.

## Choose what you need locally

- **Typing BASIC into the C64:** an emulator is enough.
- **Editing a saved BASIC listing:** a plain-text editor, Build198x to tokenise it, and an emulator to run the resulting program.
- **Writing assembly:** a plain-text editor, Asm198x to assemble it, and an emulator.

BASIC and assembly are separate routes. You can start with either.

## Prepare your emulator

[VICE](https://vice-emu.sourceforge.io/) is a local C64 emulator. Choose the download for your operating system and follow its installation instructions. Use its **x64sc** C64 emulator for these lessons.

Check the [C64 ROM guide](/setup/roms/#commodore-64) if your installation asks for firmware. Start the emulator: the blue BASIC screen and `READY.` prompt tell you the machine has booted.

## Build a BASIC listing

<SetupToolInstall tool="build198x" />

Copy the first listing from [You Type the Whole Word](/systems/commodore-64/basic/meet-c64-basic/unit-01/) into a plain-text file named `hello.bas`. Keep the line number. Open a terminal in that file’s folder and run:

```sh
build198x basic hello.bas --machine commodore-c64 -o hello.prg
```

Build198x checks the listing, then turns the BASIC words into the tokens the C64 stores. The result is `hello.prg`, a program the emulator can load.

Open `hello.prg` using VICE’s **Autostart disk/tape image** command. You should see `HELLO`, followed by `READY.`. If it loads without starting, type `RUN` and press Return.

Change the message in `hello.bas`, build it again and open the new `hello.prg`. Keep the `.bas` file: that is the source you can edit again.

## Assemble a program

<SetupToolInstall tool="asm198x" />

Copy the complete listing from [Assemble and Run](/systems/commodore-64/assembly/meet-the-machine/unit-01/) into `border.asm`. In the same folder, run:

```sh
asm198x --dialect acme --prg border.asm -o border.prg
```

Open `border.prg` with VICE’s autostart command. The border turns red. Change `lda #2` to `lda #5`, save and rebuild; the border should turn green when you load the new program.

The `acme` dialect tells Asm198x which source syntax to read. You do not need to install ACME as well. If you already use it, the [alternative ACME guide](/setup/commodore-64/native) covers that path.

## Keep your work and continue

Save the source and built program together in a project folder. Reopen the source in your editor and load the program once more before moving on. Files on your computer survive closing the emulator; an unsaved program in its memory does not.

[Continue with BASIC](/systems/commodore-64/basic/) or [continue with assembly](/systems/commodore-64/assembly/).
