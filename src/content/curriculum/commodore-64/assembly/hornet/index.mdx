## What You'll Build

Multi-sprite action game. More enemies than the hardware allows — enter multiplexing.

The C64 has 8 hardware sprites. You need 32. This game teaches you how to break the limit using raster interrupts to reuse sprites multiple times per frame. It's the technique that made games like Armalyte possible.

## Skills You'll Master

- **Sprite multiplexing** — 16-32 sprites on screen
- **Sorted sprite lists** — efficient sprite ordering
- **Raster interrupt timing** — precise beam racing
- **Sprite priority** — overlap handling
- **Performance optimisation** — cycle counting
- **Arena shooter gameplay** — wave-based combat
