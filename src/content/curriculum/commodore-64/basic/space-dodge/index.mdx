## What You'll Build

Vertical scrolling avoidance game. Dodge obstacles moving down the screen. First encounter with BASIC's performance limits.

Asteroids descend. You weave between them. As play intensifies, you'll notice the game struggling — this is intentional. Space Dodge demonstrates both scrolling concepts and why assembly language exists.

## Skills You'll Master

- **Simulated scrolling** — character movement
- **Multiple obstacle tracking** — object management
- **Difficulty ramping** — increasing challenge
- **High score tracking** — persistence
- **Custom characters** — POKE 53272
- **Sprite concepts** — via character tricks
- **Performance considerations** — speed awareness
- **BASIC speed limits** — understanding constraints

## Prerequisites

Complete **Game 5: Snake Trail** first.
