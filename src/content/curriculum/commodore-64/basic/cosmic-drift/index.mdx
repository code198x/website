## What You'll Build

Character-based animation. Moving stars drift across the screen — your first visual game.

Stars twinkle and scroll across the void of space. Multiple layers of movement create depth. This is your introduction to C64 screen memory — directly POKEing characters and colours to create visual effects.

## Skills You'll Master

- **Screen coordinates** — cursor positioning
- **POKE to screen memory** — $0400 direct access
- **POKE to colour memory** — $D800 for colours
- **Character codes** — PETSCII graphics
- **Animation loops** — continuous movement
- **Timing with FOR/NEXT** — delay loops
- **Multiple moving objects** — parallel motion
- **Colour usage** — the C64's palette

## Prerequisites

Complete **Game 1: Number Hunter** first.

## Time Investment

64 units at 60-90 minutes each. Roughly 64-96 hours total.
