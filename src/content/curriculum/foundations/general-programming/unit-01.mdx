This course teaches the ideas behind every programming language, rather than one
language. You do not need a computer to follow it.

The ideas are written in **pseudocode**: instructions in plain words, written for a
person to read. Every real language spells these ideas its own way. The ideas underneath
stay the same, and those are the ones worth keeping.

## A program is a list of instructions

A program is a list of instructions. The computer starts at the top and does each one in
turn. It does exactly what each instruction says. It never guesses what you meant.

Here is the smallest program there is. One instruction, which shows a word.

```text
SHOW "Hello"
```

Run it and you get:

<Output>Hello</Output>

That is a whole program. You asked for a word, and you got a word. Nothing else happened,
because nothing else was asked for.

Every language has its own word for showing something. BASIC says `PRINT`. Python says
`print`. C says `printf`. We say `SHOW`. They all do the same job.

## The computer does what you say

A computer does not make mistakes the way people do. It follows your instructions
exactly. That sounds helpful, and it is — but it cuts both ways. Write the wrong
instruction and the computer carries out the wrong instruction, perfectly, without
complaint.

So when a program goes wrong, start with what you wrote. Nearly every problem you meet in
your first months is there. The last unit of this course is about finding it.

## When it's wrong, see why

- **The computer refuses the line.** Check the quotation marks. `SHOW "Hello` has one at
  the start and none at the end, so the computer cannot tell where the words stop.
- **Nothing happens.** You wrote the program but never ran it. A program waits until you
  tell it to go.
- **You get a message you do not understand.** Read it anyway. It usually names the
  problem and the line it happened on, which is more help than it looks.

## What you've learnt

- A **program** is a list of instructions, done in order, from the top.
- The computer does **exactly what you write**, not what you meant.
- **Output** is how a program shows you something: `SHOW` here, `PRINT` in BASIC, a
  different word in every language.
