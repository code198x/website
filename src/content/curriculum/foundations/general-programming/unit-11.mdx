Every box so far holds one value: a score, a guess, a name. Plenty of things come in rows,
though. Five high scores. Four lives. A screen full of enemies.

A **list** is one name holding many values, in order.

## Making a list

```text
LET scores = [10, 20, 30]
SHOW scores[1]
```

<Output>10</Output>

The square brackets make the list. `scores[1]` means *the first item in `scores`*. Counting
starts at 1 here: the first item is item 1, the second is item 2.

Not every language counts from 1. Many start at 0, which makes the first item item 0. It
is one of the first things worth checking when you pick a language up.

## Changing and growing

```text
LET scores = [10, 20, 30]
LET scores[2] = 99
APPEND 40 TO scores
SHOW scores[2], " and ", scores[4]
```

<Output>99 and 40</Output>

`LET scores[2] = 99` puts a new value in the second place, the same way `LET` fills any
other box. `APPEND` adds a value to the end, and the list grows to hold it.

`LENGTH(scores)` says how many items a list holds. After that `APPEND`, it is 4.

## Walking the list

A list and a loop belong together. `FOR EACH` runs the work once for every item:

```text
LET scores = [10, 99, 30, 40]
FOR EACH score IN scores
  SHOW score
END
```

<Output>10
99
30
40</Output>

You never had to say how long the list was. `FOR EACH` runs once per item, however many
there are, so those three lines work for four scores or four hundred.

## When it's wrong, see why

- **You ask for an item that is not there.** `scores[9]` in a list of four has nothing to
  give you. Check the length before reaching past the end.
- **Everything is out by one.** You counted from 0 out of habit, or from 1 in a language
  that counts from 0. Check which one you are in.
- **Nothing happens at all.** The list is empty. `FOR EACH` over an empty list runs no
  times, which looks the same as a program that did nothing.

## What you've learnt

- A **list** is one name holding many values, in order.
- **`scores[2]`** reaches one item, counting from 1 here and from 0 in many languages.
- **`APPEND`** grows a list, and **`LENGTH`** says how many items it holds.
- **`FOR EACH`** runs work once per item, without you knowing how many there are.
