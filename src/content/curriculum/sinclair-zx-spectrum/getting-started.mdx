## What You Need

We can start with BASIC or assembly. Neither route requires the other or prior completion of Foundations.

For BASIC, we can type programs directly into a Spectrum emulator; an external build tool is optional. For assembly, we use an **assembler** to turn source code into machine code and an **emulator** to run it. The opening lessons also include browser activities.

### <span class="icon">⚙️</span> Dev Toolchain

The course's assembly sources are written in **pasmo syntax**, and two assemblers build them identically — pick either.

#### Asm198x (recommended)

The 198x family's own assembler: one small binary that covers every platform in the course. Install it with `brew install asm198x/tap/asm198x`, or download it for your machine from [the releases page](https://github.com/asm198x/asm198x/releases), then:

```bash
asm198x --dialect pasmonext --sna game.asm -o game.sna
```

#### PasmoNext

The enhanced [Pasmo](https://pasmo.speccy.org/) our dialect is named for, and the
reference the Asm198x dialect is checked against. Build it from
[source](https://github.com/Ckirby101/pasmoNext) if you want to compare:

```bash
pasmonext --sna game.asm game.sna
```

Both produce the same bytes.

#### BASIC

If we want to write BASIC listings in a text editor, **zmakebas** turns them into tape images. We do not need it to type programs directly into the emulator. Build it
from [source](https://github.com/z00m128/zmakebas), or install it from your
distribution's packages:

```bash
zmakebas -o game.tap game.bas
```

### <span class="icon">🖥️</span> Emulator

For local development, we can use **Fuse**, a Spectrum emulator.

**macOS**
```bash
brew install --cask fredm-fuse
```

The [Homebrew package](https://formulae.brew.sh/cask/fredm-fuse) requires macOS 13 or later and installs Fuse in Applications.

**Linux**
```bash
sudo apt install fuse-emulator-gtk
```

**Windows** — Download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/)

#### Run

On macOS, open Fuse from Applications and open the generated tape or snapshot through its File menu. On Linux, we can launch a tape from the terminal:

```bash
fuse game.tap
```
