## What You Need

To develop for the ZX Spectrum, you need two things: a way to **compile** your code, and an **emulator** to run it.

<div class="setup-grid">
<div class="setup-column">

### <span class="icon">⚙️</span> Dev Toolchain

The course's assembly sources are written in **pasmo syntax**, and two assemblers build them identically — pick either.

#### Asm198x (recommended)

The 198x family's own assembler: one small binary, no installation beyond unpacking, and it covers every platform in the course. Download it for your machine from [the releases page](https://github.com/asm198x/asm198x/releases), then:

```bash
asm198x --dialect pasmonext --sna game.asm -o game.sna
```

#### PasmoNext

The enhanced [Pasmo](https://pasmo.speccy.org/) our dialect is named for. Build it from [source](https://github.com/Ckirby101/pasmoNext), or use it via our (now legacy) Docker image:

```bash
docker run --rm -v "$(pwd)":/code -w /code \
  code198x/sinclair-zx-spectrum pasmonext --sna game.asm game.sna
```

#### BASIC

For the BASIC track, **zmakebas** turns BASIC listings into tape images — it's in the same Docker image:

```bash
docker run --rm -v "$(pwd)":/code -w /code \
  code198x/sinclair-zx-spectrum zmakebas -o game.tap game.bas
```

</div>

### <span class="icon">🖥️</span> Emulator

Install **Fuse** natively for the best experience.

**macOS**
```bash
brew install --cask fuse-emulator
```

**Linux**
```bash
sudo apt install fuse-emulator-gtk
```

**Windows** — Download from [fuse-emulator.sourceforge.net](http://fuse-emulator.sourceforge.net/)

#### Run

```bash
fuse game.tap
```

Or drag the `.tap` file onto the Fuse window.
