## What You Need

We can start with BASIC or assembly. Neither route requires the other or prior completion of Foundations.

The quickest start is in the browser. [Meet BASIC](/systems/sinclair-zx-spectrum/basic/meet-basic/) gives us a Spectrum on the page to type into, and [Meet Assembly](/systems/sinclair-zx-spectrum/assembly/meet-assembly/) assembles and runs our edited source on the page. We do not need to install anything to begin.

Working on your own computer is optional. For BASIC, we type programs directly into a Spectrum emulator; an external build tool is optional. For assembly, we use an **assembler** to turn source code into machine code and an **emulator** to run it.

### <span class="icon">⚙️</span> Dev Toolchain

The course's assembly sources are written in **pasmo syntax**, and two assemblers build them identically — pick either.

#### Asm198x (recommended)

The 198x family's own assembler: one small binary that covers every platform in the course. Install it with `brew install asm198x/tap/asm198x`, or download it for your machine from [the releases page](https://github.com/asm198x/asm198x/releases), then:

```bash
asm198x --dialect pasmo --cpu z80 --tapbas game.asm -o game.tap
```

#### Pasmo

[Pasmo](https://pasmo.speccy.org/) itself, the reference the Asm198x dialect is
checked against. Install it from your distribution's packages or its website:

```bash
pasmo --tapbas game.asm game.tap
```

Both produce the same program bytes. Open the tape in your emulator, type
`LOAD ""` and start the tape.

#### BASIC

If we want to write BASIC listings in a text editor, **zmakebas** turns them into tape images. We do not need it to type programs directly into the emulator. Build it
from [source](https://github.com/z00m128/zmakebas), or install it from your
distribution's packages:

```bash
zmakebas -o game.tap game.bas
```

### <span class="icon">🖥️</span> Emulator

For local work we use **Emu198x**, the 198x family's own emulator. Its Spectrum build runs on macOS, Windows and Linux. Download the `emu198x-spectrum` archive for your computer from the [latest release](https://github.com/emu198x/emu198x/releases/latest), whose notes include checksums, and extract it into a folder you can find again.

The emulator needs a lawfully obtained 48K Spectrum ROM; the [ROM guide](/setup/roms/) explains what firmware is and how to obtain it. Open a terminal in the extracted folder and start the Spectrum:

**macOS or Linux**
```bash
./emu198x-spectrum --rom "path/to/48.rom"
```

**Windows (PowerShell)**
```powershell
.\emu198x-spectrum.exe --rom "C:\path\to\48.rom"
```

Replace the quoted path with your ROM file's location, keeping the quotes if the path contains spaces.

#### Run a tape

To load a tape you have built, add it with `--tape`. `--autoload-tape` waits for the Spectrum to start, types `LOAD ""` and plays the tape:

```bash
./emu198x-spectrum --rom "path/to/48.rom" --tape game.tap --autoload-tape
```

Without `--autoload-tape`, enter `LOAD ""` yourself and press F9 to start the tape. `--scale 3` makes the window three times the Spectrum's size.

Any other 48K Spectrum emulator that opens `.tap` files, such as [Fuse](https://fuse-emulator.sourceforge.net/), also runs these programs.
