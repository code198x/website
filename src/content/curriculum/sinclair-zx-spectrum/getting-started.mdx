## Start in your browser

[Meet BASIC](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-01-make-the-spectrum-answer/) lets you edit a listing and run it in a Spectrum on the page. [Meet Assembly](/systems/sinclair-zx-spectrum/assembly/meet-assembly/unit-01/) lets you edit, assemble and run machine code with Asm198x and Emu198x. Neither needs a local installation or a separate ROM file to begin.

Choose either route. Assembly does not require completing BASIC first. Download your edited source before leaving the lesson so you can keep working on it.

## Choose what you need locally

- **Typing BASIC into a Spectrum:** an emulator is enough.
- **Editing a saved BASIC listing:** a plain-text editor and Build198x to turn it into a tape image.
- **Writing assembly:** a plain-text editor and Asm198x to build the program.

Both file-based routes use a Spectrum emulator to load and run the resulting tape.

## Prepare your Spectrum

On **macOS or Linux with Homebrew**, install the Spectrum emulator:

```sh
brew install emu198x/tap/emu198x-spectrum
```

Homebrew chooses the binary for your processor: Apple silicon or Intel on macOS, ARM64 or x86-64 on Linux. Each Emu198x machine has its own package, so this installs only the Spectrum.

Otherwise, choose the `emu198x-spectrum` archive for your operating system and processor from the [downloads page](https://emu198x.github.io/downloads/). Windows uses the x86-64 ZIP. Extract it into a folder you can find again.

The local emulator needs a 48K Spectrum ROM. The [ROM guide](/setup/roms/#requirements) explains the files and their sources. Open a terminal and start the machine, replacing the quoted path with your ROM’s location:

**macOS or Linux**

```sh
emu198x-spectrum --rom "path/to/48.rom"
```

If you downloaded an archive, open a terminal in its extracted folder and use `./emu198x-spectrum` instead.

**Windows PowerShell**, from the extracted folder

```powershell
.\emu198x-spectrum.exe --rom "C:\path\to\48.rom"
```

The Spectrum’s startup screen confirms that the emulator and ROM work together. Any other 48K Spectrum emulator that opens `.tap` files, such as [Fuse](https://fuse-emulator.sourceforge.net/), can also run these examples.

## Build a BASIC tape

<SetupToolInstall tool="build198x" />

Save your downloaded BASIC listing as `hello.bas`. In a terminal opened in its folder, run:

```sh
build198x basic hello.bas --machine sinclair-zx-spectrum -o hello.tap
```

Build198x checks the listing and tokenises it into the form the Spectrum stores. `hello.tap` contains the program and starts it from its first line when loaded.

If the check reports an error, use its line number to find the problem in your source. Keep the spelling and spacing shown in the lesson’s listing.

## Assemble a tape

<SetupToolInstall tool="asm198x" />

Download `first-program.asm` from the [first assembly lesson](/systems/sinclair-zx-spectrum/assembly/meet-assembly/unit-01/). In its folder, run:

```sh
asm198x --dialect pasmo --cpu z80 --tapbas first-program.asm -o first-program.tap
```

Asm198x reads the lesson’s Pasmo syntax and makes a tape with a BASIC loader for the machine code. You do not need to install Pasmo as well. If you already use it, see the [alternative Pasmo guide](/setup/sinclair-zx-spectrum/native).

## Load, change and save

Open your tape in Emu198x. Add `--tape` and `--autoload-tape` to the startup command; use the full path if the tape is in a different folder:

```sh
emu198x-spectrum --rom "path/to/48.rom" --tape "path/to/hello.tap" --autoload-tape
```

For an extracted archive, run from its folder using `./emu198x-spectrum`, or `.\emu198x-spectrum.exe` on Windows. For assembly, use `first-program.tap` in place of `hello.tap`.

Emu198x waits for the Spectrum to start, types `LOAD ""` and plays the tape. Without `--autoload-tape`, type `LOAD ""` yourself and press F9 to start the tape.

Compare the result with the lesson. Change a message in BASIC, or the border colour in the assembly example, then save, rebuild and load the new tape. Keep your `.bas` or `.asm` source alongside the `.tap`; reopen them to check that your work is saved.
