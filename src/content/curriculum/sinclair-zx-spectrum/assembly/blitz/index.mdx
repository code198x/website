## What You'll Build

Side-scrolling shooter. Horizontal scroll, shoot enemies, navigate terrain.

The world scrolls. The Spectrum has no hardware scrolling — this is all software, shifting bytes across the screen. You'll learn the technique that made R-Type, Midnight Resistance, and countless other side-scrollers possible.

## Skills You'll Master

- **Software horizontal scrolling** — byte shifting
- **Tile map levels** — data-driven design
- **Player in scrolling playfield** — relative positioning
- **Terrain collision** — avoiding walls
- **Scroll-tied enemies** — spawning by position
- **Multiple stages** — varied environments
- **Optimised screen shifting** — performance
- **Foreground/background** — layered elements
