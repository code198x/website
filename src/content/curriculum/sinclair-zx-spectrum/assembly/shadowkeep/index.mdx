## Coming Soon

Shadowkeep is in development — the first *substantial* game of the Spectrum
assembly track. It doesn't start from scratch: it picks up the engine you built
in **Gloaming** — the cell sprite, save/restore, collision, the game loop, the
state machine — and grows it into a lit, multi-room keep you explore by night,
with atmosphere, mood and sound.

The first units arrive soon.
