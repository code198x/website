Not every player reads manuals. In-game help ensures everyone can learn the rules.

## Run It

```bash
pasmonext --sna inkwar.asm inkwar.sna
```

## Help Content

Keep it concise:

```
INK WAR - HOW TO PLAY

1. Move cursor with Q/A/O/P
2. Press SPACE to claim cell
3. Take turns claiming cells
4. Fill the board to end
5. Most cells wins!

PRESS ANY KEY
```
