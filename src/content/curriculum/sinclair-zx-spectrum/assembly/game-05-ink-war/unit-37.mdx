## Pattern Types

| Pattern | Description | Strategy Impact |
|---------|-------------|-----------------|
| Clear | No obstacles | Classic play |
| Cross | Centre blocked | Corner focus |
| Corners | Corners blocked | Edge control |
| Random | Scattered blocks | Adaptive play |
