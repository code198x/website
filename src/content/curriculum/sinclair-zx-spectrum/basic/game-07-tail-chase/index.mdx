The snake moves whether you're ready or not. Steer it. Eat the food. Don't hit the walls. Don't hit yourself. The longer you survive, the longer the snake — and the harder it gets.

## How It Works

Tail Chase teaches **timing** — making the game run at consistent speed regardless of what's happening. PEEK 23672 reads the Spectrum's hardware frame counter, locking movement to the display refresh. This is the universal principle of frame-rate independence: tie your game to a clock, not to how fast the code runs.

Unlike the Foundations games, you build Tail Chase from scratch — no type-in listing. Unit 1 starts with a single moving character. Each unit adds one feature. By Unit 16, you have a complete snake game and understand every line.

## What You'll Learn

- **PEEK 23672** — hardware frame counter for consistent timing
- **Arrays** — storing the snake's body as a list of positions
- **Collision detection** — walls and self-intersection
- **Continuous movement** — the game runs without player input
- **Attribute POKE** — screen transitions between levels

## Prerequisites

Game 6: Quiz Master (all 8 units). The complete Foundations toolkit.
