RUN should show the title. S enters the cave; Q quits. The expedition itself is the same one you just built, with the same fixed map, treasure and patrol.

## Separate the invitation from the expedition

Lines 20–90 explain the goal, directions, waiting, clues and the arrival rule. The title loop releases the previous key, then listens for S or Q. An unrelated key keeps it at the title.

The game setup still begins at 200. That is also R's destination from play or a result, so replay can rebuild the expedition without showing the title every time. RUN starts at 10 and shows the invitation again.

The release routine matters across this boundary. S is both “start” on the title and “south” during play. The title's S must not immediately spend a movement turn. The main input loop waits for its release before accepting the next action.

## Explain what the player can rely on

The cave is fixed. A restart restores the same map, pit, treasure positions and creature phase. This makes experimentation meaningful: change your action and compare its consequences from the same opening.

The creature moves after valid actions, not while the player reads. Space deliberately waits; an invalid key or blocked exit does not. If it arrives, the next valid action must leave. These details are worth explaining because they determine whether the player can make a considered choice.

<Question prompt="Why should R jump to line 200 instead of line 270?">

270 draws the current state. It does not restore treasure, reset the turn count or move the creature back to the start. 200 begins the setup that does all of those jobs.

</Question>
