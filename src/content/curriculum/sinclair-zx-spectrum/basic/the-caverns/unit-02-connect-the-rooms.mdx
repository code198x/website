## One row per room, one column per direction

`DIM m(12,4)` reserves twelve groups of four numbers. The first subscript selects a room; the second selects an exit. We use 1 for north, 2 for south, 3 for east and 4 for west. `m(1,2)` is therefore the entrance's southern destination: 5. Zero means there is no tunnel.

This is a **graph**: places connected by links. The array's rows and columns organise records; they are not positions on the cave screen. The names make places recognisable, while numeric room identifiers let the program follow their connections.

`DIM a$(12,24)` stores twelve names of 24 characters each. `DIM b$(12,28)` stores twelve descriptions of 28 characters each. Shorter strings are padded with spaces; longer ones are cut to fit. `a$(rm)` selects a whole name. Unlike the numeric map, the final dimension of each string array is its text length.

## Read one complete record

Each DATA line has a name, a description and four destinations in N/S/E/W order. RESTORE 9500 points READ to the start. The outer FOR loop visits rooms 1–12. READ takes the two strings, then the inner loop reads four links before the outer loop advances.

The drawing routine now looks up `a$(rm)` and `b$(rm)`. rm starts at 1. The string `d$ = "NSEW"` supplies direction labels: d$(1) is N and d$(4) is W. For each direction, we read the link into v, print `--`, and replace it with Open when v is nonzero.
