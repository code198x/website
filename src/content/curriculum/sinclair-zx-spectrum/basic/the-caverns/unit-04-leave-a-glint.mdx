From the entrance press S, then E. The east tunnel from the Root chamber should show Glint; entering the Old camp raises the count to 1. Go west and east again. The count must remain 1 and the glint must have disappeared.

## A flag for each room

DIM t(12) creates twelve zeros. We put 1 in t(6), t(10) and t(12). Each value is a **flag**: a small value with an agreed meaning. One means an uncollected treasure; zero means none remains. The map does not change when a treasure is picked up.

After a valid action changes rm, line 440 checks t(rm). When it is 1, the line sets it to zero, increases found and selects the discovery message. Clearing the flag is essential: without it, waiting in the room or coming back would collect the same treasure again.

The caption h$ holds the latest message. Ordinary actions replace it with the footsteps message; a discovery then replaces that with the treasure message. Drawing the room uses whichever message the action produced.

## Ask about the destination, not this room

The tunnel loop already puts each destination in v. Line 1140 checks t(v), so its clue refers to the next room. `t(rm)` would answer a different question: whether treasure remains where you are standing.

Zero links skip the rest of that tunnel's work before the array lookup. t(0) is not a valid element. The earlier wall representation therefore matters to the clue routine too.

<Question prompt="What should happen if you press Space just after collecting a treasure?">

The turn count rises, but found does not. t(rm) is already zero. The room's name and map links stay the same too.
