The opening message now asks you to return here. The winning check belongs after collection, so found includes anything recovered on the current action. It belongs before the creature update, so a completed escape ends the turn there.

## Two conditions make one objective

`rm = 1 AND found = 3` requires both the entrance and all three treasures. Returning early does not end the game. Finding the third treasure deeper in the cave does not end it either.

ending 3 selects the successful result. The same display and result input loop used by losses now retain the entrance and the message that the treasures are safe. R rebuilds the expedition; Q stops it.

The game counts actions, but does not impose a turn limit. That leaves waiting available as a deliberate response to the patrol. The tally can help compare routes without turning every extra step into a punishment.
