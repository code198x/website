There is danger but no reward — nothing to go *into* the cave for. Three treasures fix that. Each is
hidden like the hazards and sensed the same way, by a glint in the next room, and collecting all
three is how you win. The difference is there are several of them, so they live in an array and the
game loops over it.

## An array of treasures

Lines 200–260 place three treasures in `t(3)`, each in a random room that is not the pit, the
creature, or another treasure. Storing them in an array means the glint clue is a *loop*: lines
430–450 run `chk = t(i)` through the adjacency subroutine for each treasure, and set `gl = 1` if any
is adjacent (line 460 then prints `A faint glint nearby...`). One check, three values — the array
turns "is a treasure near?" into a sweep, the same way Sonar swept its grid for the nearest target.

## Collecting and winning

When you enter a room, lines 590–610 loop over the treasures: `IF rm = t(i)` picks it up — set
`t(i) = 0` so it is gone and the glint stops, and bump `found`. Setting the slot to `0` is the same
trick the map used for "no exit": a zeroed value drops out of every later check. Line 620 is the win
— `IF found = 3 THEN GO TO 880` — and the escape screen reports your steps. The status line (line
290) shows `Treasures: n/3` so you always know how close you are.

The game is complete: explore, sense, survive, collect, escape. The last unit dresses it for play.
