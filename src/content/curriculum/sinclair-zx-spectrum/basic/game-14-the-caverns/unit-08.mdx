## Placement without overlap

Each treasure must avoid the pit, the creature, and the other treasures. Lines 210–260 handle this with cascading checks. The first treasure avoids the pit and creature. The second also avoids the first treasure. The third avoids all four previous placements. If a collision is found, the line loops back to pick a new random room.

This is the same rejection-sampling pattern used to place the creature (line 190: avoid the pit). Each new entity has more things to avoid, so the check grows longer — but the principle is identical.

## The glint clue

The glint works the same way as the draft and the smell — adjacency check via `GO SUB 740`. But there is a difference: there are three treasures, not one. The FOR loop at lines 430–450 checks each treasure in turn. If any of them is adjacent, the glint fires. The player does not know which treasure is nearby or which direction it lies — just that one of them is close.

The `t(i) > 0` check matters. Once a treasure is collected, its array value becomes 0. The loop skips collected treasures, so the glint only fires for treasures that still exist. As you collect them, the clue becomes more specific — if only one treasure remains and you sense a glint, it must be that one.
