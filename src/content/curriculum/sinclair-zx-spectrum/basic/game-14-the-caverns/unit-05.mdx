A draft means danger. Walking toward it means death.

Line 570 checks whether the player's new room is the pit. If `rm = pit`, control jumps to line 800. Lines 800–820 show the death screen: "You fell into the pit!" in red, a low falling tone, and the program stops.

The check happens after movement (line 550) but before the display loop repeats. This means the player sees the draft warning, chooses to move anyway, and immediately faces the consequence. The game does not ask "are you sure?" — it trusts the player to interpret the clue.

## Warning then consequence

The pit is the game's first lethal hazard, and it follows a two-part pattern: warning, then consequence. The draft warned you. If you ignored it — or if you did not know which exit led to the pit — you fall. There is no health bar, no second chance. One mistake ends the game.

This is harsh, but fair. The clue was there. The decision was yours. In a game with no visual information, consequences must be absolute or the clues lose their weight. If falling into the pit merely cost a life point, the draft would become background noise. Because it kills you, you listen.

## Try it

Run the program and watch the debug line for the pit's room number. Navigate toward it. Feel the draft. Now walk into it deliberately. Then restart and try to avoid it — use the draft as a warning and pick a different exit. The draft does not tell you which direction is dangerous, only that danger is close. You have to reason about which exit leads to the pit based on the room numbers you have visited.
