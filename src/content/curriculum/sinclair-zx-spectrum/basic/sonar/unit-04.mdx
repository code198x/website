Line 460 checks: `IF g(r,c) = 9` — the value 9 means a target is here. On a hit, the program prints "HIT!", sets the cell to -1 (found), and redraws. Line 470 handles misses: just "Miss" and a pause.

Line 280 adds `LET v = g(r,c)` to the grid drawing, reading each cell's value into a variable. Line 310 draws found targets as `*` (when v = -1). The star stays on the grid permanently — the player can see where they have already found targets.

## Three cell states

The grid now has three possible values per cell:
- **0** — unexplored (shown as `.`)
- **9** — hidden target (shown as `X` for debugging, later hidden)
- **-1** — found target (shown as `*`)

The cell value tracks the game state. When the player probes a target cell, its value changes from 9 to -1. The grid drawing reads that value and chooses the right character. The data drives the display — change the number, and the screen updates on the next redraw.
