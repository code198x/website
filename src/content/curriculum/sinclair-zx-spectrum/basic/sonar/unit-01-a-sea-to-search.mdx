One object is waiting beneath the sea. We will find it by sending probes to different squares and comparing their clues. First, give the search somewhere to happen.

Use a **48K ZX Spectrum** with Sinclair BASIC. Save any program you want to keep before entering `NEW`. The Spectrum editor enters keywords as tokens; in Original keyboard mode, R enters `RUN` at the start of a command. Use the mode described in your setup guide. The spaces displayed around a keyword are part of its presentation, not extra keys to press after its token.

## Start with one row

A game square will occupy three character columns and two character rows. The middle space holds its clue; the left space can hold a marker. Enter this first program.

`FOR c = 1 TO 8` changes `c` through the eight board columns. `NEXT c` returns to that loop until the row is complete. `r` stays at 1 for now. These are board coordinates, beginning at 1. `PRINT AT` uses screen coordinates beginning at 0.

The expression `5 + 3 * (c - 1)` starts at screen column 5 and advances three characters for each board column. Likewise, `4 + 2 * (r - 1)` will leave two character rows for each board row. At board `(1,1)`, these give screen row 4, column 5. Board `(8,8)` will begin at screen row 18, column 26.

`PAPER` sets the character background; `INK` sets the printed character colour. Blue is colour 1, cyan is 5, black is 0 and white is 7. `BORDER` sets the surrounding border, and `CLS` clears the display using the current paper colour. A semicolon joins PRINT items without starting a new line. The second `AT` fills the square's lower half with spaces.

For the alternating colours, `INT` rounds down. When `r+c` is even, dividing it by two, taking INT and multiplying by two returns the original value. `IF ... THEN` chooses the cyan paper in that case. The initial blue settings run for every cell, so the previous cell's colour cannot leak into the next.

The program now calls the board routine with `GO SUB 1000`. A subroutine is a named-by-line-number piece of work: BASIC remembers where to come back, and `RETURN` resumes just after the call. `STOP` prevents the main program from falling through into the drawing routines when it finishes. Its `9 STOP statement` report is expected here.

Lines 1020–1040 label the columns. The outer loop beginning at 1070 visits each row; its inner loop beginning at 1120 draws the eight cells. The short `k` loop draws two frame characters down each side of a row. Our earlier position-and-colour calculation now lives at 2000, so both the board and the target use the same calculation.

`tr=3` and `tc=6` name the target's row and column. Lines 40–50 draw its temporary `X`. The target is visible while we check the board, and will disappear when clues become useful.

<Question prompt="Why do we subtract 1 before multiplying the board column by 3?">

Column 1 needs no displacement from screen column 5. Subtracting 1 makes its displacement zero. Without that subtraction, every square would move three characters to the right.

</Question>
