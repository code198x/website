`p$` holds the prompt label and `a$` holds the answer. Sinclair BASIC string names are a single letter followed by `$`. `INPUT LINE` reads the answer as text, so an expression such as `1+1` is not evaluated. The `+` between strings joins them into one prompt.

The routine at 3000 puts the screen colours back to black paper and white ink before asking. It accepts lowercase or uppercase Q using `OR`: either comparison is enough to leave. `LEN` gives the number of characters. We require one character, then compare it with the strings `"1"` and `"8"`. Only after those checks does `VAL` convert the digit into a number. `v` is the routine's result; line 100 copies it into `pr`, the probe row.

Wrong input jumps to the message at 3100 and returns to the same prompt. `GO TO` transfers control without remembering a return address, unlike `GO SUB`. The main loop displays the selected row and asks again. Try an empty answer, 0, 9, a letter and `1.5`, then enter 5.

The first call sets `p$` to Row and stores `pr`. The second sets it to Column and stores `pc`. An invalid column does not repeat the row prompt. Both coordinates are valid before the game uses them.

For this first test, `d=1` means a miss and `d=0` means a hit. The `AND` in line 180 requires both row and column to match the target. `b$` holds the two characters to print: a space and either a dash or an asterisk. Printing `>` before them identifies the latest probe.

`lr` and `lc` remember the last probe position. Zero means that no probe has happened yet. On the next turn, lines 120–150 erase that old marker, restoring the X if necessary. This version remembers only one probe; losing older results will soon give us a reason to store more.

## Protect the display

The ROM normally uses the bottom of the screen for input. A very long answer can make that area expand and scroll the game. Line 3015 calls the recovery routine at 4000 after answers longer than sixteen characters. It redraws the board, target and latest probe before the validation error appears. It does not accept a long answer as a coordinate.

The status line is screen row 21, above the usual input area. Its PRINT statements end in a semicolon to avoid advancing beyond that row. Blank spaces remove any longer previous message. `PAPER 0: INK 7` restores the message colours after drawing a cell.
