The target needs two numbers, but our search can reveal information at 64 different positions. An array gives those positions a common name and a pair of indices.

`DIM g(8,8)` creates a numeric array with eight rows and eight columns. `g(1,2)` names one element: row 1, column 2. It is different from `g(2,1)`. Sinclair numeric array names, like FOR loop variables, use a single letter.

DIM fills the elements with zero. The first PRINT demonstrates that. Our game already uses zero for a hit, so we need a different value for an unknown cell. The nested loops set every element to -1. This special value is called a sentinel: its meaning comes from our program's rules.

The last assignment puts code 3 in `g(1,2)` as an experiment, not as a measured probe. The output is 0, then `-1 -1`, then `3 -1` on separate lines. Changing one element does not change the element with the indices reversed.

At the start, lines 25–26 create and initialise the array. A valid probe still calculates its distance and band, then line 160 stores that code in `g(pr,pc)`. The target stays in `tr` and `tc`. The array contains the player's knowledge, not a secret marker waiting to be read.

We now draw through the cell routine at 2100. It calls 2000 to get the position and paper colour, reads `g(r,c)` into `z`, and chooses the printed clue. A value of -1 leaves the dot. Codes 1, 2 and 3 select N, M and F; zero selects the asterisk. `m$` is a space except at the latest probe, where it becomes `>`.

The main loop saves the previous marker coordinates in `oldr` and `oldc`, then makes the new probe the latest position. Redrawing the old cell removes its marker but keeps its stored clue. Redrawing the new cell adds the marker there. The full-board routine calls the same cell routine for every square, so recovery after a long input answer also restores the search.

The status routine at 2600 clears and prints the message held in `s$`. This moves repeated message work into one place. The renderer reads clues; it never calculates a distance or changes the target.

<Question prompt="Why would using zero for unknown cells make the board misleading?">

Zero already means that a probe found the target. A fresh array of zeros would therefore look like a board full of discoveries. Initialising to -1 gives unknown cells their own meaning.
