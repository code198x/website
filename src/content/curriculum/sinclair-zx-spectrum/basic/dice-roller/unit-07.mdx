Numbers tell you the totals. A bar chart shows you the shape.

Line 260 changes from `STOP` to `PRINT AT 9, 0`, moving the cursor below the dashboard. Lines 270–320 each print a row of blocks — one solid block per roll of that face — and line 330 is the new `STOP`. Each bar line uses a FOR loop: `FOR j = 1 TO t1: PRINT CHR$ 143;: NEXT j` prints `t1` blocks in a row.

`CHR$ 143` is the Spectrum's solid block graphic — the same character Oracle Stone used for its bars. A run of them makes one unbroken bar, far clearer than a row of separate symbols.

Run it with 100 rolls. Six rows of blocks appear below the dashboard. The rows should be roughly equal length — that is what a fair die looks like. Try 1000 rolls: the bars grow longer and more even.

## Data visualisation

This is your first **data visualisation** — turning numbers into a picture. A bar chart works because length is easier to compare than digits. The player can see at a glance whether one face appeared more than others, without reading six numbers.
