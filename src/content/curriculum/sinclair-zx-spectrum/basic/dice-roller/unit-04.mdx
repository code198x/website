Five new lines. Line 80 initialises `t4`, `t5`, `t6`. Lines 160–180 add the IF checks for faces 4–6. Line 270 prints the second row of totals.

<Figure src="/images/sinclair-zx-spectrum/basic/dice-roller/unit-04/screenshot.png" alt="Black ZX Spectrum screen showing two rows of tallies for faces 1 to 6, summing to 100" caption="All six faces counted — the totals add up to 100." />

Run it with 100 rolls. All six faces now show their count. Run it with 1000 (change line 110). The totals converge toward equal — each face appears roughly one-sixth of the time. That convergence is the design concept **accumulation**: randomness produces patterns when you accumulate enough of it.
