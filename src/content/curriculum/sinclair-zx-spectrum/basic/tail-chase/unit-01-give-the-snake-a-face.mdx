A small face makes the moving head easy to find. We will draw it first, then give it a 24×16 arena.

Use a **48K ZX Spectrum** with Sinclair BASIC. Save any program you want to keep, then enter `NEW`. In the original keyword editor, R enters `RUN` at the start of a command. Keywords are tokens; the spaces the ROM displays after them are not extra spaces you must type. The [Meet BASIC entry and saving guide](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/) is available if you need a reminder.

Start a new program. Custom characters and arrays have appeared earlier in this course, but we will explain the parts needed here. There is no previous game's source to convert.

## Draw eight rows

Our right-facing head uses these pixels. `#` is ink and `.` is paper.

```text
..####..
.######.
######..
##..##..
##..##..
######..
.######.
..####..
```

Across a row the bit values are **128, 64, 32, 16, 8, 4, 2, 1**. The first row is 32+16+8+4 = **60**. The fourth is 128+64+8+4 = **204**. Each of the eight rows becomes one byte.

`USR "c"` gives the address of custom character c, character code **146**. Here USR has a string argument and locates graphic storage; it does not call machine code. `READ v` takes the next row number from DATA, and `POKE` stores that byte. `CHR$ 146` makes the one-character string that PRINT displays.

Enter this short program and RUN it. `STOP` prevents execution from falling into the DATA; its `9 STOP statement` report is expected.

The world uses rows **1–16** and columns **1–24**. `PRINT AT` uses screen coordinates starting at zero, so the drawing adds three to each world coordinate. World (8,9) appears at screen (11,12). Border columns 3 and 28 and rows 3 and 20 sit immediately outside the world. The title and bottom message use separate rows.

<Figure src="/images/sinclair-zx-spectrum/basic/tail-chase/teaching/arena.png" width={352} alt="An original white directional face inside a blue brick arena on the Spectrum screen." caption="World (8,9) appears at screen (11,12), inside the border." />

`GO SUB 7000` installs graphics and returns. `GO SUB 1000` draws the arena, calls the head routine at 3000, and returns. Separate RESTORE positions let us load wall a and head c without filling the unused character b.
