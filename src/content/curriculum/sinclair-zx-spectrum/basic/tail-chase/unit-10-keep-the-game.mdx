The complete game is the final source from lesson nine. This lesson changes no numbered lines. Save a version that reconstructs the graphics and begins at the instructions.

## Keep a tape recording

Press Q to return to BASIC. Follow the [tape workflow in Meet BASIC](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) with this unnumbered command:

```basic
SAVE "tail" LINE 10
```

Line 10 installs the custom characters and calls the title routine. Saving that entry point lets a fresh machine reconstruct what the game needs; it does not depend on graphics already left in memory.

Follow the ROM recording prompt, then export the recording using your emulator's tape controls. Keep the readable BASIC source too. Exporting a tape does not necessarily remove earlier recordings; use the intended recording and check its name.

Start a fresh 48K session, attach the tape and enter:

```basic
LOAD "tail"
```

Start playback. The title should appear automatically. If it keeps searching, check the tape position, playback and name. If you see an older game, check which recording was exported.

## Check a complete round

Start with S. Try a turn and an ignored reversal, hit the wall and retry. Eat food and watch the length increase. Deliberately turn into the body after growth, then restart. Complete all eight foods, check that movement stops, retry once more and quit with Q.

A fresh session matters because it begins without the custom graphics and game arrays. The program must rebuild those from its own DATA and initialisation.

The game, seven character designs and supporting code are original course material under the [samples repository's MIT licence](https://github.com/code198x/code-samples/blob/main/LICENSE). The game uses shape as well as colour to distinguish the head, body and fruit. The body order and occupancy grid decide the rules independently of that artwork.

For a small optional experiment, change one character's row bytes while preserving its role. Predict the pixels, reload the graphics and play. The snake should obey exactly the same collision rules. Restore the accepted drawing before keeping your final tape.
