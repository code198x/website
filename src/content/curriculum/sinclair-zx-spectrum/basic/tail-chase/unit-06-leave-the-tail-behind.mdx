## Recognise food before changing the body

Line 300 compares the proposed head with `fr,fc`, the food coordinates. Sinclair BASIC comparisons produce 1 for true and 0 for false. `grow` therefore records whether this move eats the food.

For an ordinary move, erase the tail and advance t. For a growing move, line 330 skips that work. Line 380 increases n and eaten, then the shared code advances h and stores the new head. This is the circular array's growing case: keep the oldest position while appending a new one.

The collision scan must now distinguish both cases. Skip its first live cell only when grow is zero. If the tail stays, its square remains occupied.

<Question prompt="Why is adding one to n insufficient to make the snake grow?">

If the tail were still removed, only four positions would remain live while n claimed there were five. Growth must preserve the tail as well as increasing the count.

</Question>
