## Prepare once, start each flight

Line 10 calls the direction-table routine at 7000, then the title routine at 5000. When S is read, RETURN takes execution back to line 10. With no further statement there, BASIC continues at line 100 to reset the flight.

The table describes the eight fixed orientations and can be reused. R goes straight to 100: it resets position, velocity, heading and steps, then redraws the arena. It does not need to calculate the direction table again or return to the title.

The title says “Space has no brakes.” Here that means there is no automatic slowing or dedicated brake control. The following instructions explain the action we do have: turn back and thrust against the motion.

## Read one key at a time

The title loop waits for S or Q. The flight loop uses O/P for turning and SPACE for thrust. Each loop reads one string from INKEY$, so this game's controls are separate actions: turn, release, then thrust. It does not promise simultaneous turning and burning.

Both upper- and lower-case letters are accepted. The result loop first waits for release and then listens for R/Q. After Q, the final STOP leaves you at the BASIC prompt; RUN begins with the title again.

<Question prompt="Why does R jump to line 100 while RUN begins at line 10?">

R needs a fresh flight, using the direction table already in memory. RUN begins the whole program: it constructs the table, shows the title, then starts a flight. Starting at 100 on a fresh machine would skip the array setup.

</Question>

Try the whole cycle: title, start, wall failure, retry, successful docking and quit. Take time over the successful approach; the point of this check is that every route leaves the program ready for the next action.

If retry shows the old result or leaves the old ship behind, inspect the call to the screen routine at line 110: its CLS clears the previous flight before drawing the arena. If S never begins, check the title's two accepted forms and its RETURN.

You now have the complete game: eight headings, thrust, coasting, a speed limit, readable motion and one soft docking challenge. We will keep this version and save it so a fresh Spectrum can run it too.
