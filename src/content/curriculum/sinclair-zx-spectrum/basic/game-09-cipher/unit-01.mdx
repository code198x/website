Every game so far has stored its data in variables: `LET n = 42`, `LET s$ = ""`. That works for numbers and short strings, but a word list — twenty words, fifty, a hundred — needs something better.

Line 20: `DATA "SPECTRUM"`. The word is stored *in the program*, not in a variable. DATA is a holding area — it sits there waiting to be read.

Line 30: `READ w$`. This takes the next item from DATA and puts it into `w$`. The first READ gets the first DATA item. The second READ would get the second, and so on.

Lines 60–80 print dashes — one per letter. `LEN w$` gives the word's length (8 for "SPECTRUM"). The FOR loop prints an underscore and a space for each character.

## DATA and READ

`DATA` stores values inside the program itself — strings, numbers, anything. `READ` retrieves them in order. Think of DATA as a queue and READ as "take the next one."

```
DATA 10, 20, 30
READ a
READ b
READ c
```

After this, `a` is 10, `b` is 20, `c` is 30. The values are read in the order they appear in DATA.

You can put DATA on any line — the Spectrum collects all DATA statements across the program and reads through them sequentially. Multiple values on one line are separated by commas: `DATA "CAT", "DOG", "FISH"`.
