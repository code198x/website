A word hides behind underscores. The player reveals it one letter at a time.

Line 90 stores a word in DATA. Line 170 reads it into `w$`. Lines 180–190 build a display string `d$` — the same length as the word, but all underscores. Line 260 prints each character of `d$` with spaces between them, so the player can count the letters.

Line 370 asks for a guess. Lines 450–470 are the core: a FOR loop walks through every character of the word. If the character matches the guess, `LET d$(i TO i) = g$` replaces that underscore with the actual letter. Line 520 loops back to show the updated display.

## String indexing

`d$(i TO i)` is Spectrum BASIC's way of replacing a single character inside a string. `d$(3 TO 3) = "E"` replaces the third character with E. The `TO` syntax slices the string — you can read or write any section of it. The FOR loop on lines 450–470 uses this to check every position: if position `i` of the word matches the guess, position `i` of the display string changes from `_` to that letter.

The word `w$` never changes. The display `d$` is a separate string that starts as all underscores and gradually fills in. When every underscore is replaced, the player has guessed the whole word.

Run it. Type a letter. If it is in the word, the underscore at that position reveals itself. The word is always "SPECTRUM" for now — that changes later.
