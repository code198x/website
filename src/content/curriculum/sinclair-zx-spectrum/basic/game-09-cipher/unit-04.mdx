The player guesses "E". Then forgets and guesses "E" again. Without tracking, the second guess costs a life unfairly. The game should remember what has been tried.

## String as set

`LET tried$ = ""` starts empty. After each guess, the letter is appended: `LET tried$ = tried$ + g$`. After guessing E, S, and T, `tried$` holds `"EST"`.

Before accepting a new guess, lines 160–180 scan `tried$` character by character. If the guess matches any character in `tried$`, it has already been tried — the program says so and loops back without costing a life.

This is a **membership check**: "is this value in the set?" The set is a string; the check is a FOR loop. Simple, readable, and the pattern behind every "have I seen this before?" question in every program.

## Display

Line 120: `PRINT "Tried: "; tried$` shows all guessed letters in a row. The player can see at a glance what they have already tried. No more guessing the same letter twice.

The game now handles one word correctly — right guesses, wrong guesses, duplicate prevention, win/lose. Next: many words.
