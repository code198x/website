Three new lines. Line 510 adds a low beep for a wrong guess: `BEEP 0.1, -5`. Line 520 adds a high beep for a correct one: `BEEP 0.1, 10`. Line 530 checks for victory: `IF d$ = w$ THEN PRINT "You cracked it!": STOP`. When the display string matches the word exactly — every underscore replaced — the player wins.

## The win condition

`d$ = w$` is a string comparison. When the game starts, `d$` is `"________"` and `w$` is `"SPECTRUM"`. Each correct guess replaces one or more underscores. When every position has been filled in, the two strings are identical and the comparison returns true.

This is elegant: the win condition does not count letters or track progress — it simply asks "does the display match the word?" The display string does double duty as both what the player sees and the game's state tracker.

The sounds are immediate feedback. The player hears whether they were right before the screen updates. A high beep means "look for the new letters." A low beep means "brace yourself — you just lost a life." Sound arrives faster than the eye can scan the display.
