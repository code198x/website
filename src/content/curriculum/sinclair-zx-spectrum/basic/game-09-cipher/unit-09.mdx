The game starts with a word already hidden. It should start with an explanation.

Lines 10–110 add the title screen. Line 10 sets the stage black. Lines 60–80 explain the game in three lines: guess the hidden word, one letter at a time, seven lives per word. Line 90 draws a small padlock with `PLOT`, `DRAW`, and `CIRCLE`. Line 100 prompts, line 110 waits.

Cipher's title is the simplest of the three most recent games. The rules are short because the concept is familiar — most players already know the word-guessing format. The title just needs to confirm the rules ("7 lives per word") rather than teach a novel mechanic.

## What you have built

Cipher is complete. Seventy-one lines: title, 20 random words in DATA, underscore display with colour, letter-by-letter guessing, lives with a visual bar, duplicate detection, win and lose screens with sound, running totals, and automatic next-word progression.

This game introduced string manipulation as a core mechanic. The display string `d$` and the tried-letters string `z$` are not just data — they are the game's interface. The player interacts with the program through letters, and the strings track everything: what is revealed, what has been guessed, whether the game is won.
