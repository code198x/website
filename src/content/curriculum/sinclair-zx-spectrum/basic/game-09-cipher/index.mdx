Cipher is a word-guessing game. The computer picks a word from a hidden list. You see dashes — one per letter. Guess a letter: if it is in the word, it appears. If not, you lose a life. Find the word before your lives run out.

This is the first game in Volume 2 — **Patterns of State**. Volume 1 taught how games communicate — with colour, sound, and timing. Volume 2 teaches how games think: how they store information, search it, and reason about it. Every V2 game is turn-based and state-driven. No real-time pressure, no continuous loops. The programs get more structured; the design questions get harder.

Cipher introduces `DATA` and `READ` — the tools for separating *content* from *code*. The game's logic never changes; only the word list does. Change the DATA, change the experience.

**What you will learn:**

- `DATA` / `READ` — storing content separately from logic
- `RESTORE` — rewinding DATA for random selection
- String slicing (`w$(i)`, `d$(i TO i)`) — reading and writing individual characters
- String-as-set membership checking
- The design concept: **Data-Driven** — the content shapes the experience

**9 units. About 8–12 hours.**
