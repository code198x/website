Lines 90–120 store 20 words in DATA — all computing terms the player will recognise. Line 130 notes the total. Line 150 picks a random number from 1 to 20. Line 160 `RESTORE` rewinds DATA to the beginning. Line 170 uses a FOR loop to READ through the list, stopping at the chosen word.

## RESTORE and random selection

`RESTORE` resets DATA to the start. Without it, each `READ` moves forward and never goes back. The FOR loop on line 170 reads `pick` words, and the last one read is the word the player must guess.

This is a pattern: `RESTORE` + `FOR i = 1 TO pick: READ w$: NEXT i` picks the n-th item from a DATA block. It is not efficient — it reads and discards every word before the one you want — but with 20 words on a 1982 computer, the delay is invisible.

Line 20 adds `RANDOMIZE` so the word is different each run. The word list is a mix of lengths (5–8 letters) and difficulties. Short words like "PIXEL" have fewer letters to guess but fewer chances for common letters to appear. Long words like "CASSETTE" have repeated letters — guess S and two positions reveal at once.

## Try it

Add your own words to the DATA lines. Change `total` to match. The rest of the program adapts automatically because it uses `LEN w$` to build the underscore string — any length word works.
