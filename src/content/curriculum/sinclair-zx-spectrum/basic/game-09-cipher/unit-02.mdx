## The display string

Line 40 builds `d$` — a string of underscores the same length as the word. If the word is "SPECTRUM" (8 letters), `d$` is "________" (8 underscores). This is the display version — what the player sees. As they guess correctly, underscores get replaced with letters.

## Searching the word

Lines 110–130 loop through every character of `w$`. For each position `i`, if the character at that position matches the guess (`w$(i) = g$`), the matching underscore in `d$` is replaced: `LET d$(i TO i) = g$`.

`w$(i)` reads one character from position `i`. On the Spectrum, `d$(i TO i)` is how you *write* one character at position `i` — the `TO` syntax is required for assignment, even when you are replacing a single character.

## Found or not?

The `found` variable tracks whether any position matched. If `found` is still 0 after the loop, the letter is not in the word.

Run it. Type "S". The first underscore becomes an S: `S _ _ _ _ _ _ _`. Type "T". The second position reveals: `S T _ _ _ _ _ _`. The word emerges one letter at a time.

The program handles one guess, then stops. Next: lives, and a loop that keeps asking.
