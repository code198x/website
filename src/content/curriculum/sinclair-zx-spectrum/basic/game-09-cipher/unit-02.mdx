Line 230 sets `lives` to 7. Line 340 shows the count. Line 470 introduces the `found` flag — set to 0 before the letter-checking loop. Line 490 sets it to 1 if any position matches. After the loop, line 510 checks: `IF found = 0 THEN LET lives = lives - 1`. A wrong guess costs a life. Line 540 ends the game when lives reach zero, revealing the word.

## The found flag

This is the same flag pattern from Hi-Lo. Set `found = 0` (assume the letter is not in the word). The FOR loop on lines 480–500 scans every position — if any match, `found` flips to 1. After the loop, the flag tells you whether the letter was anywhere in the word, without needing to know which positions matched.

The flag separates "checking" from "responding." The loop checks. Line 510 responds. The loop does not need to know about lives, and the lives check does not need to know about string positions.

Seven lives for an eight-letter word is generous enough to be fair but tight enough that random guessing will fail. The player must think about which letters are likely — common letters like E, S, T before rarer ones like X, Z, Q.
