The text-input quiz from unit 1 has a problem: the player must type the exact answer, in the exact case. Multiple choice fixes that. The player sees four options and types a number.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-10-quiz-master/unit-02/choice.bas" />

The DATA now holds six values for one question: the question text, four option strings, and the number of the correct option. Lines 50–70 READ them into separate variables.

The four options print as a numbered list. The player types a number (1–4), not a word. `INPUT g` reads a number — no case problems, no spelling problems. Line 170 checks `g = correct`. If they match, it's right.

## Multi-field DATA

In Cipher, each DATA item was a single word. Here, each question is a *block* of six related fields: question, four options, correct answer number. READ pulls them out in order — the first READ gets the question, the next four get the options, the last gets the answer number.

This is the simplest form of a record: related fields grouped together in DATA, read as a unit. Every quiz program in every magazine listing worked this way.
