## DIM and RESTORE

`DIM` creates an array — a numbered list of values. `DIM k(4)` makes slots 1 through 4. You read and write them with `k(1)`, `k(2)`, etc.

`RESTORE 610` is a targeted rewind. Plain `RESTORE` resets DATA to the very first DATA line. `RESTORE 610` resets to line 610 specifically. This lets you have multiple DATA sections: answers at line 550, questions at line 610. Read the answers first, rewind to the questions, then read those.

The answer DATA is now separate from the question DATA. You can rearrange the options in a question without touching the answer key — just update the number in line 550.
