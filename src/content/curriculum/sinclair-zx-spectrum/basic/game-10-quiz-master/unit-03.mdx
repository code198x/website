One question is a test. Four questions is a quiz. A score counter turns it into something worth playing.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-10-quiz-master/unit-03/score.bas" />

The quiz now has four questions. A FOR loop (line 20) runs four rounds. Each round reads one question block from DATA, displays it, takes the player's answer, and checks it.

Line 10 sets `score` to 0 before the quiz starts. Line 160 adds 1 on a correct answer: `LET score = score + 1`. Line 180 shows the running total after each question.

`CLS` at line 30 clears the screen before each question — otherwise the display scrolls into a mess. `PAUSE 100` at line 190 gives the player two seconds to read the result before the next question clears the screen.

## DATA at the bottom

The four question blocks live at lines 500–530. Putting DATA at the end of the program is a Spectrum convention — it keeps the logic (lines 10–240) separate from the content (lines 500+). You can read the program's behaviour without scrolling past pages of quiz questions.

After all four rounds, the final score appears. But there's a problem: the correct answer number is bundled with each question in DATA. We read it every round and throw it away after checking. If we ever want to replay the quiz, we'd need to re-read everything. There's a better way — and it starts with DIM.
