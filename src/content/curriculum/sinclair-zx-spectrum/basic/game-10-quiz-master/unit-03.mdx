Line 80 initialises `score` and `n` (the question counter). Line 110 starts a FOR loop: `FOR q = 1 TO 4` — four questions. Each pass through the loop reads a question from DATA, displays it, gets the player's answer, and checks it. Line 300 pauses after each question. Line 310 `NEXT q` moves to the next one. Line 360 shows the final score after the loop ends.

Line 270 checks the answer: `IF g = n THEN PRINT "Correct!": LET score = score + 1`. But wait — `n` is the question number, not the correct answer. This works by coincidence because the correct answer for question 1 happens to be option 1, question 2 happens to be option 2, and so on. That is a cheat — the questions are written so the answer number matches the question number.

Lines 610–650 add three more questions to DATA, giving the loop four to work through. `READ q$,a$,b$,c$,d$` consumes five values per question, and each pass through the FOR loop reads the next set. DATA is sequential: first call gets the first question, second call gets the second.
