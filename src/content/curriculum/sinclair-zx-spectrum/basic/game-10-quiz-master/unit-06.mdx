Until now, the quiz printed text line by line and let it scroll. A real quiz game looks different: the question sits in a fixed position, the options are neatly aligned, and the score lives in the corner where you can always see it.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-10-quiz-master/unit-06/card.bas" />

Lines 130–160 build the category header. First, a coloured bar: the loop at line 140 prints 32 spaces with `PAPER ink`, filling row 0 with the category colour. Then `PRINT AT 0,1` places the category name on top of it, and `PRINT AT 0,26` puts the score in the right corner.

Lines 190–240 place each element at a fixed position. The question sits at row 4. The four options start at row 7, indented two columns. The input prompt sits at row 12. The correct/wrong feedback appears at row 14. Every question looks the same — the screen is a *card*, not a scrolling log.

## PRINT AT

`PRINT AT row, column` places the cursor at an exact screen position. Row 0 is the top, row 21 is near the bottom. Column 0 is the left edge, column 31 is the right. You've used it before (Dice Roller's bar chart, Bright Spark's panels), but here it builds a complete structured layout — a page design, not just a positioned number.

## Sound

Line 260: `BEEP 0.2,12` — a short high note for a correct answer. Line 270: `BEEP 0.3,-5` — a longer low tone for wrong. Line 350: four ascending notes for a fanfare when the quiz ends. Sound confirms what the player already sees — it doesn't replace the visual feedback, it punctuates it.

The quiz looks and sounds like a real program. Next: turning the final score into something that feels like an achievement.
