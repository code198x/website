## PRINT AT as page design

The question card is a designed layout, not a stream of text. The category bar is a visual anchor — it tells the player "you are in the Animals section" with colour before they read the word. Green for Animals, cyan for Space, red for History, yellow for Geography.

`PAPER ink` uses the variable `ink` read from DATA. Each category defines its own colour, so the header changes automatically without any IF statements. The data drives the design — adding a fifth category with a different colour would not require any code changes, just more DATA.
