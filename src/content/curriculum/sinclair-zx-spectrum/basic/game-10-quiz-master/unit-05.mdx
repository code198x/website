The DATA is now organised by category. Each category starts with its name and a colour number (line 600: `DATA "Animals",4`). After the name come that category's two questions. Four categories, two questions each, eight questions total.

Line 50: `RESTORE 600`. After loading the correct answers from line 500, the DATA pointer sits past the last answer. RESTORE tells the Spectrum to jump to a specific line. `RESTORE 600` points it at the category DATA, ready for the quiz to begin.

## RESTORE

In Cipher, you used `RESTORE` to rewind to the start of a word list. Here, `RESTORE 600` jumps to a *specific* line — skipping the answer data and landing exactly where the categories begin.

On the Spectrum, `RESTORE` without a number rewinds to the very first DATA statement. `RESTORE n` jumps to line n (or the nearest DATA after it). This lets you organise DATA into sections and jump between them.

## Why `c`, not `cat`?

The outer loop is `FOR c = 1 TO 4` — a single letter. On the Spectrum, `FOR` and `NEXT` only accept single-letter variable names. The same goes for string variables: `t$` is valid, but `cat$` is not. You can use long names with `LET` (like `score` and `ink`), but loop counters and string variables need a single letter.

## Colour as category

Lines 130–150 print the category name with coloured text: `PAPER ink` sets the background to the category's colour, `INK 7` makes the text white. Animals is green (4), Space is cyan (5), History is red (2), Geography is yellow (6). The colour tells the player which category they're in before they read a word.
