## Multiple counters in parallel

This is the pattern: one array, multiple counters, each indexed by the thing being counted. `s(1)` counts Animals. `s(4)` counts Geography. The loop variable `c` selects which counter to update — no IF statements needed.

You'll use this pattern again. In Locksmith, an array tracks which code positions are correct. In Sonar, a grid tracks which cells have been searched. Any time you need to count several things at once, DIM an array and index by category.
