Lines 10–40 add a title screen. Lines 320–330 show a mini-summary after each category ends: the category name and how many the player got right, displayed at the bottom of the last question card. The player sees their performance in each subject before moving to the next.

Line 470 plays a fanfare — four ascending notes. Lines 480–510 add a replay prompt: `INPUT "Play again? (y/n): ";p$`. If yes, `GO TO 10` restarts. If no, "Thanks for playing!" and `STOP`. This is the first game to ask explicitly rather than using `PAUSE 0` — a design choice. A quiz that replays automatically might feel like it is forcing the player to continue.

## What you have built

Quiz Master is complete. Seventy lines of game logic, plus DATA: a title screen, four categories with colour-coded headers, eight multiple-choice questions from an answer-key array, high/low sound feedback, per-category breakdown with a score array, a rating system, and a replay option.

This game used more data structures than any previous one — two arrays (`k()` for answers, `s()` for scores), nested FOR loops, multiple DATA sections with RESTORE, and string variables driven by DATA. It is the most structured program in Volume 1, and the one that most clearly separates data from logic.
