The quiz works, replays, scores, and rates. The last step is polish: a title screen that names the game, and per-category feedback that tells you how you did as you go.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-10-quiz-master/unit-10/quiz-master.bas" />

Lines 10–40 are the title screen. `INK 2` prints "QUIZ MASTER" in red at the centre of the screen. "Press any key to start" below it. `PAUSE 0` waits indefinitely — any keypress starts the quiz.

Lines 320–330 add per-category feedback. After each category's two questions, the program prints the category name and score at the bottom of the card: "Animals: 2 out of 2." `PAUSE 60` gives the player a moment to see it before the next category starts.

Line 490: when the player chooses to replay, `GO TO 10` returns to the title screen — not directly into the quiz. The title screen gives the game a proper entrance each time.

## Make it yours

The quiz is now a complete, expandable program. Here are three ways to grow it:

**Add your own questions.** Write new DATA blocks for a fifth category — pick a subject, choose a colour, write two questions with four options each. Add the correct answer numbers to line 550. Change the loop from `FOR c = 1 TO 4` to `FOR c = 1 TO 5` and update `DIM k(8)` to `DIM k(10)`. The quiz now has ten questions.

**Add a category menu.** Before the quiz starts, list the categories and let the player choose one. Use `RESTORE 600` for Animals, `RESTORE 630` for Space, and so on — each RESTORE points to a different category's DATA. Play just that category's two questions.

**Add difficulty levels.** Double the questions: four per category instead of two, with the first two easy and the last two hard. Let the player choose "Easy" (first two per category) or "Hard" (all four).

The code doesn't change much for any of these. The DATA grows. The loop bounds adjust. The engine stays the same.

Quiz Master is done. You've built a program with arrays, RESTORE, structured layout, ratings, replay, and a title screen — all in about fifty lines of code and a block of DATA.
