Cipher used DATA to store a list of words. Quiz Master uses it to store something more structured: a question *and* its answer, together.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-10-quiz-master/unit-01/one-question.bas" />

Line 20 holds two values in one DATA statement: the question text and the correct answer, separated by a comma. Line 30 reads both into separate variables — `q$` gets the question, `a$` gets the answer.

The quiz asks the question, takes the player's answer via INPUT, and checks whether it matches. If it does: "Correct!" If not: the program shows what the answer was.

## The catch

Try running it. Type `pacific` in lowercase. Nothing happens — the program says "The answer is PACIFIC." The Spectrum's INPUT starts in L mode (lowercase), so you'd need to press CAPS LOCK before typing to match the uppercase answer.

This is genuinely annoying. It's also why real quiz games don't ask you to type the answer — they give you options to choose from. That's what we fix next.
