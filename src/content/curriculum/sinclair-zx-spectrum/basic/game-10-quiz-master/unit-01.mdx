Four lines of game logic. Line 130 clears the screen. Line 210 prints a question. Line 260 asks for the player's answer. Line 280 reveals the correct one.

The answer is always "Eight" regardless of what the player types. There is no checking, no scoring, no right or wrong. The program just asks and tells. That is deliberate — the quiz structure comes first, the game mechanics come second.

This is the skeleton. Every quiz program has this shape: show a question, get an answer, reveal the result. The next nine units add choices, scoring, categories, and polish — but the skeleton stays the same.
