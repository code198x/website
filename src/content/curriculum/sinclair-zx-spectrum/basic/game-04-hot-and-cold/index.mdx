A treasure is hidden somewhere on screen. You can't see it. But the border knows where it is — shifting from cold black through blue, magenta, red, yellow, to blazing white as you get closer. Move the cursor. Read the border. Find the treasure.

## How It Works

Hot and Cold teaches **the game loop** — the universal structure of every real-time game. Input → update → draw, running continuously. The cursor moves. The distance updates. The border changes. Every frame, the same cycle. This is the heartbeat that makes games feel alive.

## What You'll Learn

- **Position variables** — x and y tracking where things are
- **The game loop** — input → erase → move → draw → repeat
- **ABS** — distance without direction
- **SQR** — square root for true distance
- **^** — the power operator
