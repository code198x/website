Lucky Number waited for you. Wire Panic counted down. Bright Spark played a sequence. Hot and Cold does something different: it runs *continuously*. The cursor sits on screen. You press a key. It moves. The border changes colour. You press another key. It moves again. No pauses, no turns, no sequences. Just you, the cursor, and the colour of the border.

This is the **game loop** — and every real-time game ever made uses it.

![Hot and Cold — cursor on a dark screen, border showing warmth](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-01-type-it-in/playing.png)

Type in the listing, play five rounds, and pay attention to the rhythm: press a key, the cursor moves, the border shifts. Press again. Move. Shift. The game never stops to think. It just responds, over and over, as fast as you can press.

Over the next seven units, you'll learn how this loop works — position variables, distance calculations, border feedback, and the universal structure that makes it all run.

- **Unit 3:** The game loop — input → erase → move → draw
- **Unit 4:** Distance — SQR, ^, and Euclidean distance
- **Unit 5:** Border feedback — mapping distance to colour
- **Unit 6:** Finding the treasure — win detection
- **Unit 7:** Multiple rounds — FOR around the whole game
- **Unit 8:** The game loop as universal design pattern
