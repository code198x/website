Over the next eight units you'll build Hot and Cold — a treasure hunt where the border colour tells you how close you are. First, you need to control where text appears on screen.

## The Screen Grid

Every Spectrum program so far has printed text from the top down, one line after another. `PRINT AT` changes that — it places text at any row and column you choose.

The screen is a grid: 24 rows (0-23) and 32 columns (0-31). Row 0 is the top, column 0 is the left edge.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-01/print-at-example.bas" />

`PRINT AT row, col` moves the cursor to that position before printing. The row comes first, then the column, separated by a comma. A semicolon follows the column number before the text.

## Coordinates to Remember

| Position | Row | Column |
|----------|-----|--------|
| Top-left | 0 | 0 |
| Top-right | 0 | 24 |
| Centre | 11 | 12 |
| Bottom-left | 21 | 0 |

Rows 22-23 are reserved for system messages. Stick to rows 0-21 for your own text.

## The Game Screen

Hot and Cold needs a header bar, instructions, and a status line. `PRINT AT` lets you place each piece exactly where it belongs.

Line 5 sets the stage: black border, black paper, white ink. The `FOR` loop on lines 12-16 fills row 0 with magenta spaces to create a coloured header bar. Line 18 prints the title on top of it in bright white.

Line 28 places the status line at row 21 — round number and move count. Everything sits at a precise position because `PRINT AT` puts it there.

## Centring Text

To centre text on a row, calculate the starting column: `(32 - length) / 2`. The title "HOT AND COLD" is 12 characters, plus two spaces of padding makes 14, so it starts at column `(32 - 14) / 2 = 9`. Close enough to 10 — exact centring isn't critical, but it looks better than guessing.

## Try This

**Add more instructions.** Put "Watch the border colour" on a third line below the existing instructions. Pick a row that leaves even spacing.

**Change the header colour.** Replace `PAPER 3` (magenta) with `PAPER 1` (blue) or `PAPER 2` (red). See which looks best against the black background.

## What You've Learnt

- **PRINT AT row, col** — places text at a specific screen position
- **The grid** — 24 rows (0-23) by 32 columns (0-31), with rows 0-21 as the safe area
- **Row first, column second** — always `PRINT AT row, col`
- **Header bars** — a `FOR` loop filling a row with coloured spaces creates a solid bar
