## The Title Screen

Lines 20-180 build a full instructions page. The colour legend (lines 100-150) prints each temperature label in the matching ink colour — black for freezing, blue for cold, magenta for cool, red for warm, yellow for hot, white for "on fire". The white line uses `PAPER 0` to make white text visible against the white title screen background.

The `INKEY$` loop on line 180 waits for any key to start.

After five rounds, the game clears the screen and shows the total moves with a rating:

| Total moves | Rating | Colour |
|-------------|--------|--------|
| 40 or fewer | Treasure hunter! | Green (4) |
| 41-70 | Good instincts! | Yellow (6) |
| 71-100 | Getting warmer! | Cyan (5) |
| Over 100 | Keep searching! | Magenta (3) |

The rating uses the same chained `IF` pattern you've used throughout the game — separate statements checking non-overlapping ranges.

## Cleanup

Line 148 resets the border, paper, and ink to defaults before the final message. Without this, the Spectrum would keep whatever colours the game was using, making the command prompt hard to read.

## The Complete Structure

1. **Title screen** — instructions, colour legend, wait for key
2. **Round loop** (x5) — new treasure, reset cursor, game loop, show result
3. **Game loop** — draw cursor, calculate distance, set border, wait for input, move
4. **Victory** — ascending beeps, flashing star, show moves
5. **Results** — total moves, rating, wait for key, cleanup

This is a proper game with a beginning, middle, and end. It teaches the player the rules, gives them feedback on every move, and rates them at the finish.

## Try This

**Difficulty levels.** Add a menu after the title screen: Easy (wide distance bands), Normal (as is), Hard (narrow bands). Adjust the IF thresholds based on the choice.

**High score.** Track the best total across multiple plays. After the results screen, ask "Play again? (Y/N)" and loop back to line 190 if they say yes.

**Add a timer.** Use the Spectrum's built-in timer: `LET t = PEEK 23672 + 256 * PEEK 23673` at the start and end of each round. Show the elapsed time alongside the move count.
