## What Changed

**Title screen (lines 20-180).** A full instructions page with the colour legend printed in the matching ink colours. The white-on-black line uses `PAPER 0` to make white text visible. The `INKEY$` loop waits for a key to start.

**Round display (line 220).** Each round starts with "Round 1 of 5" at the top of the screen, so the player knows their progress.

**Bright cursor (lines 290-310).** `BRIGHT 1` before printing the cursor makes it stand out, then `BRIGHT 0` resets for normal text.

![Gameplay with round counter and blue border](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/gameplay.png)

**Safe treasure range (line 230).** `INT (RND * 20) + 1` places the treasure on rows 1-20, avoiding the top row (where the round display is) and the bottom edge.

**Victory tune (lines 480-500).** Three ascending notes instead of one beep:

```
BEEP 0.2, 12
BEEP 0.2, 16
BEEP 0.4, 19
```

C, E, G — a major chord played as an arpeggio. The final note is longer for emphasis.

**Score ratings (lines 670-700).** Four different messages based on total moves:

| Total moves | Message |
|-------------|---------|
| Under 50 | "Amazing! You have a gift!" |
| 50-99 | "Well done!" |
| 100-199 | "Not bad, keep practising!" |
| 200+ | "The treasure was well hidden!" |

**Cleanup (lines 570-600).** Restores border, paper, and ink to defaults before the results screen.

## The Complete Structure

1. **Title screen** — instructions, colour legend, wait for key
2. **Round loop** (×5) — new treasure, reset cursor, game loop, show result
3. **Game loop** — draw cursor, calculate distance, set border, wait for input, move
4. **Victory** — tune, show star, display moves
5. **Results** — total moves, rating message

This is a proper game with a beginning, middle, and end. It teaches the player the rules, gives them feedback, and rewards them at the finish.

## Try This

**Add a timer.** Use the Spectrum's built-in timer: `LET t = PEEK 23672 + 256 * PEEK 23673` at the start and end of each round. Show the elapsed time alongside the move count.

**Difficulty levels.** Add a menu after the title screen: Easy (distance bands are wide), Normal (as is), Hard (bands are narrow). Adjust the IF thresholds based on the choice.

**High score.** Track the best total across multiple plays. After the results screen, ask "Play again? (Y/N)" and loop back to line 190 if they say yes.
