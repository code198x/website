In PRINT AT, you used numbers directly: `PRINT AT 10, 15; "+"`. The cursor appeared at row 10, column 15. But those numbers were fixed — the cursor couldn't move.

To make something move, store the position in variables:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-02/move-cursor.bas" />

`x` and `y` hold the cursor's position. INKEY$ reads a keypress. The old position is erased (line 60 prints a space), the variables update, and the new position is drawn. GO TO loops back for the next keypress.

This is **movement** — the first time something on screen responds to the player in real time. The pattern is always the same: **erase** the old position, **update** the variables, **draw** the new position. Every game that has a moving character — from Pac-Man to Mario to the cursor in Hot and Cold — uses this three-step pattern.

The keys Q/A/O/P are the standard Spectrum game layout: Q=up, A=down, O=left, P=right.

## What You've Learnt

- **Position variables** (`x`, `y`) store where something is
- **Movement** = erase old → update variables → draw new
- The Q/A/O/P key layout for Spectrum games
