To move something on screen, you need two ingredients: a character to display and variables to track where it is.

## A Cursor on Screen

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-hot-and-cold/unit-02/cursor.bas" />

![A plus sign cursor in the centre of the screen](/images/sinclair-zx-spectrum/basic/game-04-hot-and-cold/cursor.png)

Variables `r` and `c` store the cursor's row and column. `PRINT AT r, c; "+"` draws the cursor at that position.

## Moving It

The program waits for a key press on line 50, then:

1. **Erases** the cursor by printing a space at the old position (line 60)
2. **Updates** the row variable (line 70)
3. **Draws** the cursor at the new position (line 80)

This erase-update-draw sequence is the fundamental pattern for all movement on the Spectrum. Without erasing first, you'd leave a trail of "+" characters behind.

## Position Variables

Instead of using fixed numbers in `PRINT AT`, we use variables:

- `r` — the **row** (vertical position, 0 = top)
- `c` — the **column** (horizontal position, 0 = left)

To move down, increase `r`. To move up, decrease `r`. To move right, increase `c`. To move left, decrease `c`.

This program only moves down (`LET r = r + 1`), and it only moves once before stopping. In the next unit, you'll add all four directions and keep it moving.

## Try This

**Move up instead.** Change line 70 to `LET r = r - 1`. The cursor moves up one row.

**Move sideways.** Change line 70 to `LET c = c + 1`. The cursor moves right.

**Different starting position.** Change `r` and `c` on lines 20-30 to start the cursor in a corner.

## What You've Learnt

- **Position variables** — `r` for row, `c` for column
- **Erase-update-draw** — print a space at the old position, change the variable, print at the new position
- **LET r = r + 1** — increases the row (moves down)
