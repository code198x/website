Lines 300–330 count bulls. A bull means the right digit in the right position: `g(i) = c(i)`. The FOR loop walks all four positions. If the guess at position `i` exactly matches the code at position `i`, `bulls` increments. Line 340 prints the count.

Run it. Type the code you can see (e.g. if the code is `3 2 5 1`, type `3251`). Four bulls. Type something completely wrong — `6666` against `3251` — zero bulls. Type `3200` — one bull (the 3 at position 1 matches).

## Position-by-position comparison

This is the simplest array comparison: walk both arrays in lockstep, check each pair. Position 1 of the guess against position 1 of the code. Position 2 against position 2. No searching, no nested loops — just a straight march through four slots.

The bull count tells the player how many digits are in their final, correct position. It is the most valuable clue in the game. Four bulls means the code is cracked. Zero bulls means every digit is either wrong or in the wrong position. The player's job is to figure out which.
