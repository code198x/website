## What you have built

Locksmith is complete. Forty-five lines: a title screen with terminology, a hidden four-digit code, input parsing, the digit-counting algorithm for bulls and cows, a ten-guess game loop with visible history, colour-coded clues with pitch feedback, win and lose screens, and a replay loop.

This is the first game where the player's tool is pure logic. No reflexes, no luck, no resource management — just information and deduction. The program provides clues; the player reasons to a conclusion. That relationship between hidden state and visible clues is the foundation of every puzzle game.
