Locksmith is Mastermind on the Spectrum. The computer picks a secret four-digit code — each digit from 1 to 6. You guess, and the computer tells you how close you are: a **bull** means you have the right digit in the right place; a **cow** means you have a digit that appears in the code, but at the wrong position. Ten guesses to crack it.

This is the first pure logic game. No randomness during play, no time pressure, no reflexes. The entire game is deduction — interpreting clues to narrow the possibilities. Every guess should be informed by the clues from previous guesses.

**What you will learn:**

- Arrays for storing and comparing sequences
- Nested FOR loops for cross-array searching
- The digit-counting algorithm for cow detection
- Input parsing — splitting a string into individual digits
- Building a visual history log with PRINT AT

**9 units. About 8–12 hours.**
