The five guests are currently either frozen (0) or free (1). Real NPCs need more nuance. This unit expands the state system to three states: frozen, waking, and free. Each state changes the guest's description, behaviour, and interactions. The transition from frozen to free is not instant — it happens over several turns after the ritual.

## Three States

| State | Value | Description |
|-------|-------|-------------|
| Frozen | 0 | Stone statue, cannot interact except EXAMINE |
| Waking | 1 | Colour returning, confused, limited dialogue |
| Free | 2 | Fully alive, moves between rooms, talks |

The ritual sets all guests to state 1 (waking). Over the next few turns, they transition to state 2 (free) one at a time, with descriptions marking each change.

## How It Works

**Line 37** already has `DIM gs(5)` for guest state. The values now mean: 0 = frozen, 1 = waking, 2 = free. All start at 0.

**Lines 285-300** update the display code to show different descriptions per state:
- **Frozen:** "Colonel Blackwood stands here, grey and motionless as stone."
- **Waking:** "Colonel Blackwood stands here. Colour is returning to his face. He blinks slowly, confused."
- **Free:** "Colonel Blackwood is here, pacing the room."

**Line 38** adds `DIM gw(5)` — a wake timer for each guest. When the ritual triggers, `gw(i)` is set to a delay value (different for each guest). Each turn decrements the timer. When it reaches 0, the guest transitions from waking to free.

**The staggered wake sequence** creates a dramatic effect. The Maid wakes first (shortest delay), then Mrs Pemberton, then Dr Hartley, then Lady Ashworth, and finally the Colonel. The player watches the manor come back to life over several turns.

## Try This

**Test with debug commands.** Add a temporary command WAKE ALL that sets all guests to state 1 with short timers. Watch them wake one by one as you take turns.

**Write waking descriptions.** Each guest's waking description should reflect their personality. The Colonel might straighten his jacket. The Maid might look around in confusion. Dr Hartley might reach for his glasses.

**Plan free-state behaviours.** When free, guests will move and talk (units 42-44). Think about what each guest would do — the Colonel might patrol, the Maid might clean, the Doctor might investigate.
