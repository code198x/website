Players should never have to guess what commands exist. The HELP command lists everything the game understands — movement, item manipulation, examination, inventory, and any special commands. It is a safety net for stuck players and a reference for new ones.

## The Help Screen

HELP clears the screen and displays a formatted list of commands with brief explanations. It then waits for a keypress before returning to the game. The game state does not change — HELP is purely informational.

## How It Works

**Lines 1000-1060** display the help screen. CLS clears everything. The title "COMMANDS" prints in bright white. Each command prints with a brief description:

- **GO [direction]** — move north, south, east, west, up, or down
- **TAKE [item]** — pick up an item in the room
- **DROP [item]** — put down an item you are carrying
- **EXAMINE [thing]** — look closely at an item, person, or object
- **LOOK** — re-read the full room description
- **INVENTORY** — list what you are carrying
- **HELP** — show this list

**Line 1050** prints "Press any key to continue..." and line 1055 waits with a PAUSE 0 loop. The player reads at their own pace and returns to the game when ready.

**Line 1060** jumps back to the display routine to re-show the current room. The help screen replaced the room display, so it must be restored.

**The help text also includes tips:** "Examine everything — clues are hidden in descriptions." "You can carry up to 4 items at once." These guide new players without spoiling puzzles.

## Try This

**Type HELP from different rooms.** The help screen should look the same regardless of location. After pressing a key, the correct room should reappear.

**Update HELP as you add commands.** Every new command you add in later units should appear in the help text. Keep the list current — an incomplete help screen is worse than no help at all.

**Add a HINT command.** Separate from HELP, HINT could give context-sensitive suggestions based on the player's progress. "You have not explored the cellar yet" or "Have you examined all the guests?" This is optional but very player-friendly.
