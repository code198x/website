The cat moves randomly. Free guests should move with more purpose. The Colonel patrols between the drawing room and the corridor. The Maid circles the ground floor. Dr Hartley gravitates toward the library and study. Each guest has a set of preferred rooms, and their movement favours those rooms while still allowing occasional wandering.

## Weighted Movement

Each guest has a "home" set — rooms they prefer. When choosing a direction, the code checks whether any adjacent room is in the home set. If so, it favours that direction. If not, it picks randomly (like the cat). This creates movement patterns that feel intentional without being rigid.

## How It Works

**Lines 9400-9420** store home rooms for each guest in DATA statements. The Colonel prefers rooms 2, 5, 7 (corridor, dining room, drawing room). The Maid prefers rooms 1, 2, 4, 6 (entrance hall, corridor, corridor, kitchen). Each guest has 3-4 preferred rooms.

**Lines 2100-2140** implement weighted movement. For each free guest, the code builds a list of valid exits from their current room (same as the cat). Then it checks if any destination is in their home set. Home rooms get added to the candidate list twice, making them twice as likely to be chosen. The final selection is random from the weighted list.

**Lines 2150-2160** handle arrival and departure messages. If a guest enters the player's room: "Colonel Blackwood strides into the room." If a guest leaves: "The Maid slips away toward the kitchen." Departure messages name the destination when it is a home room, adding personality.

**Movement chance** — guests do not move every turn. A 40% chance of movement each turn creates a natural rhythm. Sometimes they stay put. Sometimes they wander. The manor feels alive without being chaotic.

**The movement sound** differs by guest. The Colonel's footsteps are heavy (`BEEP 0.05, 2`). The Maid's are light (`BEEP 0.03, 8`). This audio cue tells the player who is moving even before the message prints.

## Try This

**Free all guests and observe.** Use a debug command to wake everyone, then take 20 turns. Note the movement patterns. The Colonel should spend most of his time on the ground floor. The Doctor should hover near the library and study.

**Track a specific guest.** Follow the Colonel for 10 turns. Does his path feel believable? If he bounces erratically, increase the weighting for home rooms.

**Test guest encounters.** What happens when two guests are in the same room? Both should appear in the display. Their movements are independent — they do not interact with each other yet.
