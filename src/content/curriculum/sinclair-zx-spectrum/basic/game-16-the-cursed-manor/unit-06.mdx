The data system works. Now fill it with real rooms. The ground floor has eight rooms connected by doorways and corridors. Each room needs a name, a description that sets the mood, and exits that make geographical sense.

## Designing the Ground Floor

Draw the map on paper before writing any code. The entrance hall sits at the centre. Corridors branch north and east. Rooms connect off corridors. Every room must be reachable, and connections must be consistent — if the library is north of the corridor, the corridor must be south of the library.

## How It Works

**Lines 9000-9070** define eight DATA lines, one per room. The descriptions establish atmosphere: dust on surfaces, cobwebs in corners, cold drafts from windows. Each description is a single sentence that fits within the 80-character string limit.

**The exit connections** form a connected graph. Room 1 (entrance hall) connects north to room 2 (corridor). Room 2 branches east to the library and west to the kitchen. The corridor continues north to the drawing room. Side rooms connect back to their parent corridors.

**Consistency checking** — every exit must have a matching return exit. If room 2 has `e(2) = 3` (east to library), then room 3 must have `w(3) = 2` (west back to corridor). A mismatch creates a one-way door, which confuses players. Check every pair.

The game already handles all eight rooms without any code changes to the display or movement routines. The data-driven design pays off immediately.

## Try This

**Draw the map.** On paper, sketch boxes for each room with arrows showing connections. Label each with its room number. This is your reference for the rest of the project.

**Walk every path.** Start in the entrance hall and visit every room. Try going in impossible directions to confirm the "cannot go" messages work. Check that every door works in both directions.

**Write better descriptions.** The initial descriptions are functional. Rewrite them to evoke more atmosphere — mention light, sound, smell, temperature. A good room description makes the player feel present.
