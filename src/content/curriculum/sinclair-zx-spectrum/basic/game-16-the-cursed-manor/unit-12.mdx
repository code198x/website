A static world feels dead. Something needs to move on its own. A cat — not cursed, just independent — wanders the manor. Sometimes the player sees it; sometimes it has already moved on. This is your first autonomous NPC, and the simplest one: it moves to a random adjacent room each turn.

## Autonomous Movement

The cat has a current room stored in `cr`. Each turn, after the player acts, the cat picks a random exit from its current room and moves. If the cat is in the same room as the player, the description mentions it. If the cat enters or leaves the player's room, a message appears.

## How It Works

**Line 85** places the cat in room 5 (the dining room) at the start.

**Lines 600-640** run the cat's turn. The code builds a list of valid exits from the cat's current room, picks one at random using `INT(RND * count) + 1`, and moves the cat there. If the cat has no exits (should not happen in practice), it stays put.

**Lines 250-260** check whether the cat is in the player's room during the display phase. If `cr = r`, the game prints "A black cat sits here, watching you." in green ink. The cat's presence is atmospheric, not mechanical — it does not block movement or trigger puzzles.

**Lines 650-660** handle the cat arriving or departing. If the cat's new room matches the player's room, print "A black cat slinks into the room." If the cat's old room was the player's room, print "The cat slips away through a doorway."

The cat is a simple proof of concept for the NPC system. It has one behaviour (random movement) and one interaction (being visible). Later NPCs will have state machines, goals, and dialogue.

## Try This

**Track the cat.** Add a debug command "WHERE CAT" that prints the cat's current room number and name. Useful for verifying the movement logic.

**Adjust the movement chance.** The cat does not have to move every turn. Add a random check: `IF RND > 0.5 THEN` skip the movement. A cat that sometimes stays put and sometimes wanders feels more natural.

**Change the cat's appearance message.** Instead of always saying "sits here", vary the message: "curled up by the fireplace", "perched on a windowsill", "investigating a corner". Use `INT(RND * 3) + 1` to pick one.
