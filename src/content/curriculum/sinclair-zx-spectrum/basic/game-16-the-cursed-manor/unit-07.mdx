The ground floor is complete. Now add the upper floor — six rooms reached by a staircase from the corridor. GO UP and GO DOWN connect the two floors. The manor gains a vertical dimension.

## Stairs as Exits

Stairs work exactly like compass directions. Add `u(r)` and `d(r)` arrays for up and down exits. The corridor (room 2) gets an up exit to the landing (room 9). The landing gets a down exit back to the corridor. The movement code needs two new command checks: GO UP and GO DOWN.

## How It Works

**Lines 25-26** add two more arrays: `DIM u(20)` and `DIM d(20)` for vertical exits.

**Lines 9080-9130** define six new rooms. Room 9 is the landing — a hub that connects to the bedrooms, the study, and the bathroom. Each upstairs room has its own character: the master bedroom is grand but cold, the guest rooms feel neglected, the study smells of old paper.

**Lines 500-530** handle GO UP and GO DOWN. They follow the same pattern as the compass directions — check the command, check the exit array, update `r` or print a refusal. The code is deliberately repetitive. Six direction blocks, six identical patterns.

**The DATA format** now includes six numbers per room instead of four: north, south, east, west, up, down. Rooms without vertical exits use 0. Most rooms have `0, 0` for up and down, but the corridor and landing have non-zero values.

## Try This

**Test the staircase.** Go up from the corridor, then down from the landing. You should return to the corridor. Try GO UP in a room with no stairs — the game should refuse.

**Add a description change.** When the player goes upstairs for the first time, print "The stairs creak under your weight." You will build a proper first-visit system in unit 10, but a temporary IF check works for now.

**Map the upper floor.** Extend your paper map with the upstairs rooms. Draw the staircase connection between floors. The full map is starting to take shape.
