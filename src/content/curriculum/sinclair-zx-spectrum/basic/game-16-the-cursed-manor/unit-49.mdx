Phase 4 begins with presentation. The game works, but it starts abruptly — no title, no mood-setting, just a room description. A proper title sequence sets the tone before the first command. The player should feel the atmosphere before they start playing.

## The Title Screen

The title screen uses the full screen: large text for the game name, a subtitle, atmospheric colour, and a "Press any key" prompt. It appears once at startup and never again.

## How It Works

**Lines 5-50** are the title sequence, running before any game initialisation.

**Lines 5-10** set the screen: `BORDER 0: PAPER 0: INK 7: CLS`. Black background, white text. The darkness sets the mood.

**Lines 15-25** draw a simple illustration — the outline of a manor house against a night sky. A few PLOT and DRAW lines create a silhouette: peaked roof, chimney, windows (small bright rectangles), and a door. The illustration fills the top third of the screen.

**Lines 30-35** print the title centred on screen. "THE CURSED MANOR" in bright white, large and prominent. Below it, a subtitle in dim cyan: "A Text Adventure". And below that, the author credit.

**Lines 40-45** add atmospheric text. One or two sentences in dim white: "The invitation arrived without a return address. The manor stands alone on the moor, dark against the sky. Nobody has left in a hundred years."

**Line 50** prints "Press any key to begin..." and waits with a loop checking `INKEY$`. When a key is pressed, the game initialisation begins.

**The transition** from title to game is a simple CLS. The title disappears and the entrance hall description appears. The contrast — dark, sparse title screen to detailed room description — signals that the game has begun.

## Try This

**Watch the title.** Run the program and sit on the title screen. Does it create the right mood? The colours, text, and illustration should feel ominous and intriguing.

**Refine the manor illustration.** Add more detail to the silhouette — a gate, a path, trees. Keep it simple but recognisable. The title screen is the player's first impression.

**Add a slow text reveal.** Print the atmospheric text one character at a time using a loop with short PAUSE values. The slow reveal builds tension. Too slow is boring; too fast loses the effect — experiment with the timing.
