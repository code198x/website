Phase 2 ends with the parser — the component that turns player input into game actions. Until now, the code matched entire strings ("GO NORTH", "TAKE KEY"). A proper parser splits input into a verb and a noun, then dispatches to the right handler. This is more flexible and much easier to extend.

## Splitting Input

The parser finds the first space in the input string. Everything before the space is the verb; everything after is the noun. "TAKE SILVER KEY" becomes verb = "TAKE", noun = "SILVER KEY". Single-word commands like "LOOK" have an empty noun.

## How It Works

**Lines 310-340** are the parser. First, the input is converted to uppercase for case-insensitive matching. Then the code searches for a space character by scanning `c$` character by character. If a space is found at position `p`, the verb is `c$(1 TO p-1)` and the noun is `c$(p+1 TO LEN c$)`. If no space exists, the verb is the entire input and the noun is empty.

**Lines 345-348** run synonym replacement on the verb. The synonym table from unit 27 now only needs to match against the verb, not the full input. This is cleaner and avoids partial-match problems.

**Lines 400-500** are the command dispatcher. Instead of comparing the full input string, each handler checks the verb: `IF v$ = "GO" THEN GO SUB 1100`. The noun is passed to the handler subroutine, which uses it to determine the direction, item, or target.

**Lines 1100-1150** are the GO handler. It checks the noun: "NORTH" sets the direction to north, "SOUTH" to south, and so on. The handler is self-contained — it reads the noun, performs the action, and returns.

**Lines 1200-1250** are the TAKE handler. It searches for the noun in the item name array. Partial matching works — "KEY" matches "silver key" because the code checks whether the noun appears within the item name.

**The parser is now the single entry point.** All input flows through the verb/noun split, then to the correct handler. Adding a new command means adding one verb check and one handler subroutine. The structure scales cleanly.

## Try This

**Test case insensitivity.** Type "go north", "Go North", "GO NORTH", and "gO nOrTh". All should work. The uppercase conversion normalises everything.

**Test multi-word nouns.** Type "TAKE SILVER KEY" and "EXAMINE COLONEL BLACKWOOD". The noun should capture everything after the first space.

**Add a new verb.** Create a WAIT command that simply prints "Time passes..." and runs the NPC turn without the player doing anything. It needs one verb check and a one-line handler.
