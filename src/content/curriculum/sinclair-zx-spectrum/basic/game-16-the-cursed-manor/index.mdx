## What You Will Build

A text adventure inspired by The Hobbit — the most ambitious project in the entire Spectrum BASIC curriculum. You arrive at a remote manor house to find five guests frozen in place by an ancient curse. Twenty rooms to explore, six items to find, a two-word parser, autonomous NPCs that move and act on their own, puzzle chains that gate your progress, and a climactic ritual to break the curse.

![The Cursed Manor title screen](/images/sinclair-zx-spectrum/basic/game-16-the-cursed-manor/title-screen.png)

You type commands like GO NORTH, TAKE KEY, EXAMINE PORTRAIT, and TALK TO MAID. The game responds with descriptions, clues, and consequences. A cat wanders the manor independently. Freed guests move between rooms and offer help. The manor itself shifts in mood — distant sounds, flickering lights, cold drafts — making every room feel alive.

![Exploring the manor — room description with items and exits](/images/sinclair-zx-spectrum/basic/game-16-the-cursed-manor/gameplay.png)

This is not a short exercise. Over 64 units you will build a complete game from nothing, layering systems one at a time until they combine into something greater than the sum of their parts.

## Why This Game?

Every technique you have learnt across fifteen games leads here. String handling from Word Scramble. Arrays from Quiz Master. State machines from Night Patrol. DATA statements, subroutines, loops, conditional logic, colour, sound — all of it comes together in a single program.

Text adventures demand everything a programmer can give. You need a world model (rooms, connections, items, characters), a language processor (parsing player input into actions), game logic (puzzles, state changes, win conditions), and presentation (descriptions, feedback, atmosphere). Building one teaches you how real software is structured — not as a single block of code, but as interacting systems.

The Cursed Manor is your capstone. When you finish it, you will have written the largest and most complex program in this curriculum. You will understand how data structures, control flow, and user input combine to create an interactive world.

## What You Will Learn

### Phase 1: The Empty Manor (Units 1-16)

The world itself. You build 20 rooms connected by compass directions, with locked doors, first-visit text, a LOOK command, room illustrations drawn with PLOT and DRAW, ambient sound, and a wandering cat. By the end of Phase 1, you can walk through a complete manor house that feels like a real place.

- Room data stored in DATA statements
- Four-direction movement with boundary checking
- First-visit flags using arrays
- ASCII art room illustrations
- A simple autonomous NPC (the cat)

### Phase 2: Things and People (Units 17-32)

Items and characters populate the world. You add six items that can be taken, dropped, and examined. Five frozen guests each hold a clue. A synonym table makes the parser more forgiving. Better error messages guide the player. By the end of Phase 2, the manor is full of things to interact with.

- Item state arrays (location, carried, described)
- Inventory management with carry limits
- NPC data and examination
- A two-word parser with synonym expansion
- Contextual error messages

### Phase 3: Puzzles and Awakening (Units 33-48)

The game becomes a game. Locked doors need keys. A grimoire reveals a combination. A sealed chamber hides the amulet. Cold fire must be kindled. The true name must be spoken. NPCs wake, move, and act autonomously. The ritual to break the curse requires all the pieces in the right place. By the end of Phase 3, the game is winnable.

- Puzzle chains with prerequisite checks
- NPC state machines (frozen, waking, free)
- Autonomous NPC movement and actions
- Distant event messages ("You hear footsteps above...")
- Win condition and scoring

### Phase 4: Graphics and Polish (Units 49-64)

The game becomes a finished product. A title sequence sets the mood. Instructions explain the commands. Room and guest descriptions get a rewrite for atmosphere. New commands (TALK TO, GIVE TO) deepen NPC interaction. Darkness, ambient events, response variety, and abbreviations make the world feel rich. Optimisation keeps it running smoothly. A bug sweep catches edge cases. The final unit presents the complete, polished game.

- Title screen and instruction pages
- Extended room illustrations
- Dialogue and gift-giving systems
- Darkness mechanics with a lantern
- Random ambient events
- Input abbreviations (N, S, E, W, I, L)
- Memory optimisation techniques

## Prerequisites

Complete all fifteen previous games in the Spectrum BASIC curriculum. You will need every technique they taught — there are no training wheels in this project.

## Time Investment

64 units at 45-90 minutes each. Roughly 50-90 hours total. This is a long project — take breaks, save often, and enjoy the journey.
