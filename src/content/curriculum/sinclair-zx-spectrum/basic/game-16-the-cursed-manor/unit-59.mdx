"You cannot go that way." appears every time the player walks into a wall. After twenty attempts, it feels robotic. Multiple responses for the same action — randomly selected — make the game feel more human. The information is the same, but the delivery varies.

## Response Tables

For each common response (movement refusal, unknown command, take failure, drop failure), store three to four alternative messages. Select one at random each time. The player reads different text for the same situation.

## How It Works

**Lines 9900-9940** store response alternatives in DATA statements, grouped by category:

**Movement refusal:**
1. "There is no way to go in that direction."
2. "You cannot go that way."
3. "A wall blocks your path."
4. "There is no exit that way."

**Unknown command:**
1. "I do not understand that."
2. "That does not make sense here."
3. "Try something else."
4. "I do not know how to do that."

**Take failure (item not present):**
1. "You do not see that here."
2. "There is nothing like that in this room."
3. "You look around but cannot find that."

**Lines 420-425** replace the single movement refusal with a random selection from the movement table. `LET msg = INT(RND * 4) + 1` picks one of four messages. The selected message prints.

**The same pattern** applies to all response categories. Each handler that previously used a fixed error string now picks from a list. The change is small per handler, but across the whole game the variety is noticeable.

**Consistency within variety** — all alternatives convey the same information. "You cannot go that way" and "A wall blocks your path" mean the same thing. The player never receives misleading information from varied responses.

## Try This

**Bump into walls repeatedly.** Walk into the same wall five times. You should see at least two different messages. The variety breaks the monotony.

**Add more alternatives.** Four options per category is a minimum. Six or eight options make repetition much rarer. Write messages that match the game's tone — no jokes, no breaking the fourth wall.

**Vary success messages too.** "You pick up the silver key" could also be "You take the silver key" or "You pocket the silver key." Success messages benefit from variety just as much as failure messages.
