Phase 1 is complete. The manor has 20 rooms, six directions, locked doors, first-visit text, a LOOK command, illustrations, sound effects, and a wandering cat. Before moving on to items and characters, verify that everything works together. This unit is about testing, fixing, and polishing.

## The Complete Map

The manor should feel like a real place. Connections should make geographical sense — you should not go north from the kitchen and arrive in an upstairs bedroom. The map has three layers: ground floor, upper floor, and cellar/grounds. Stairs connect the layers.

## How It Works

**The exit table** is the heart of the map. Every room's DATA line includes six exit numbers. This unit adds a verification routine that runs at startup: for every exit `n(r) = x`, it checks that `s(x) = r` (or the appropriate reverse direction). Mismatches print a warning. This catches data entry errors immediately.

**Lines 90-98** run the verification loop. For each room, for each direction, if the exit is non-zero, the code checks the reverse exit. If room 3 has east exit to room 4, then room 4 should have west exit to room 3. Any mismatch prints "WARNING: Room 3 east goes to 4, but room 4 west goes to [wrong value]".

**The exit display** is refined. Available exits print in a consistent format at the bottom of the room description: "Exits: north, east, up." This line appears every time, on both first and return visits.

**The complete flow** for each turn is now: display room (with illustration if available, full or brief description, exit list, cat if present) then read input, process command, run NPC turns, loop back. This structure will not change — everything you add in later phases slots into this framework.

## Try This

**Run the verification.** Let the startup check run and fix any mismatches in the DATA lines. A clean map with no warnings is the foundation for everything that follows.

**Walk every room.** Start at room 1 and visit all 19 reachable rooms. Note any descriptions that feel flat or connections that feel wrong. This is your last chance to adjust the geography before adding items and NPCs.

**Time a full loop.** How long does it take to walk from the entrance hall to the furthest room and back? If any room takes more than five moves to reach from the entrance, consider adding a shortcut. Players should not spend too long just walking.
