Phase 3 is complete. The game is winnable — puzzles work, the ritual fires, guests wake, and the player can escape. Before moving to polish, add a scoring system that measures how thoroughly the player explored and how efficiently they solved the puzzles.

## Scoring Categories

The score tracks five things:

| Category | Points | Maximum |
|----------|--------|---------|
| Rooms visited | 1 per room | 20 |
| Items found | 5 per item | 30 |
| Guests examined | 3 per guest | 15 |
| Puzzles solved | 10 per puzzle | 30 |
| Ritual completed | 25 | 25 |
| **Total** | | **120** |

A perfect score of 120 requires visiting every room, finding every item, examining every guest, solving every puzzle, and completing the ritual.

## How It Works

**Line 13** initialises the score: `LET sc = 0`.

**Room visits** — the visit flag array `v()` already tracks this. At score time, count the non-zero entries: `FOR i = 1 TO 20: LET sc = sc + v(i): NEXT i`.

**Item discovery** — a new array `id(6)` tracks whether each item has been taken at least once. Set `id(i) = 1` in the TAKE handler. Score: `5 * (sum of id values)`.

**Guest examination** — a new array `ge(5)` tracks whether each guest has been examined. Set `ge(i) = 1` in the EXAMINE handler. Score: `3 * (sum of ge values)`.

**Puzzles solved** — track with individual flags: key used (`pu = 1`), combination entered (`pc = 1`), lantern lit (`pl = 1`). Score: `10 * (pu + pc + pl)`.

**Ritual** — `rf = 1` if complete. Score: `25 * rf`.

**Lines 2500-2540** calculate and display the score. The SCORE command shows the current tally at any time. The ending sequence also displays the final score with a rating:

| Score | Rating |
|-------|--------|
| 120 | "Master of the Manor — a perfect score!" |
| 90-119 | "Curse Breaker — well done indeed." |
| 60-89 | "Explorer — you found your way, but missed some secrets." |
| 0-59 | "Visitor — the manor has more to reveal." |

## Try This

**Type SCORE during play.** Check your score at different stages. It should increase as you explore, find items, and solve puzzles. The steady climb motivates thorough play.

**Aim for 120.** Play through the entire game, visiting every room and examining everything. A perfect score should be achievable but require deliberate effort.

**Add SCORE to the HELP text.** The player should know the command exists. Update the help screen with "SCORE — see how well you are doing."
