The player can take and drop items, but has no way to check what they are carrying without trying to drop things. The INVENTORY command lists all carried items. It is a utility command like LOOK — it changes nothing but gives essential information.

## Listing Carried Items

Loop through the item array. For each item where `ic(i) = 1`, print its name. If nothing is carried, print "You are not carrying anything." Simple, but essential.

## How It Works

**Lines 630-660** handle the INVENTORY command. A flag `found` starts at 0. The loop checks each item — if `ic(i) = 1`, it prints the item name and sets `found = 1`. After the loop, if `found` is still 0, the empty inventory message prints.

**The output format** lists items one per line under a header: "You are carrying:" followed by each item name with a leading dash. This is clean and scannable, especially once the player has multiple items.

**INVENTORY does not consume a turn.** Unlike movement or taking items, checking your inventory should not advance the game clock or move the cat. The command processes and then waits for the next input without running the NPC phase. This distinction between "action" commands and "information" commands will matter more as NPCs become active.

## Try This

**Test with zero, one, and many items.** Check inventory when carrying nothing, after picking up one item, and after picking up several. Each case should display correctly.

**Add a carried weight or count.** After the item list, print "([count] items)". Count the carried items in the loop and display the total. This prepares for carry limits in unit 23.

**Accept I as a shortcut.** Many text adventures let the player type just "I" instead of "INVENTORY". Add a check for `c$ = "I"` that triggers the same code. Abbreviations arrive properly in unit 60, but this one is useful enough to add early.
