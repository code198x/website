Battleships depends on hidden information. If Player 2 can see Player 1 ship grid, the game is pointless. The handover screen solves this: clear the display, show a message telling the next player to take the keyboard, and wait for a keypress before showing anything sensitive.

## How It Works

**Lines 20-30** clear the screen with `CLS` immediately after Player 1 finishes placement. Nothing from Player 1 grid remains visible.

**Lines 40-60** display the handover message centred on screen: "Pass the keyboard to Player 2" and "Press any key when ready". The message is large and clear — there should be no confusion about what to do.

**Lines 70-80** wait for a keypress with `PAUSE 0`. This halts the program until the player presses a key. `PAUSE 0` waits indefinitely, unlike `PAUSE n` which times out after n frames.

**Lines 90-120** run the full fleet placement for Player 2, using array `b()` instead of `a()`. The same placement code works for both players — only the target array changes.

**Lines 130-160** perform a second handover after Player 2 finishes placing ships, preparing for the shooting phase.

## Hidden Information

Hidden information is what makes Battleships a strategy game rather than a puzzle. Each player must deduce where the opponent ships are by firing shots and observing the results. The computer knows everything — all four arrays are in memory — but the display reveals only what the current player should see.

The handover is the low-tech solution to this problem. A networked game would put each player on a separate screen. On a single Spectrum, we use `CLS` and a polite message. It relies on the players being honest, but for a two-player game on the sofa, that is good enough.

## PAUSE 0

`PAUSE 0` is the Spectrum way to wait for a keypress. The parameter is the number of 50th-of-a-second frames to wait, with 0 meaning "forever". It is simpler than an `INKEY$` polling loop and does not consume CPU time. When the player presses any key, execution continues on the next line.

## Try This

**Test the handover.** Run the program, place Player 1 ships, and check that CLS completely removes them before the handover message appears. Can you see any trace of the previous display?

**Add player numbers.** Change the handover messages to say "Player 1 has placed their fleet" and "Player 2, press any key to begin". Naming the players makes the flow clearer.
