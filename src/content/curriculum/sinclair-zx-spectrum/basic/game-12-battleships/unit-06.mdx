Now that we can read coordinates, we can place a ship. The player picks a starting cell and a direction — horizontal or vertical. The program checks that the ship fits within the grid boundaries and writes the ship number into each cell it occupies.

## How It Works

**Lines 20-40** ask for the starting coordinate using the parsing logic from Unit 5. The column goes into `x` and the row into `y`.

**Lines 50-70** ask for direction: H for horizontal, V for vertical. The program stores direction as two delta values: `dx=1, dy=0` for horizontal, `dx=0, dy=1` for vertical.

**Lines 80-100** check bounds. For a horizontal ship of length `l`, the rightmost cell is at column `x + l - 1`. If that exceeds 10, the ship runs off the grid. The same check applies vertically for `y + l - 1`. Out-of-bounds placement loops back to the coordinate prompt.

**Lines 110-140** write the ship into the array. A FOR loop from 0 to `l-1` sets each cell: `LET a(y + i*dy, x + i*dx) = v` where `v` is the ship number (1-5). This writes consecutive cells in the chosen direction.

## Delta-Based Direction

Instead of separate code for horizontal and vertical placement, we use deltas. Horizontal means step by `dx=1` in columns and `dy=0` in rows. Vertical means `dx=0` and `dy=1`. The placement loop uses `x + i*dx` and `y + i*dy` to calculate each cell position. One loop handles both directions. This pattern appears throughout the game wherever direction matters.

## Ship Numbers

Each ship gets a unique number from 1 to 5. The cell value tells us not just that a ship is present, but which ship. Later, when a shot hits, we can look up the cell value to find which ship was hit and update its health counter. If we stored all ships as the same value, we would have no way to tell them apart.

## Try This

**Place the Carrier.** It has length 5. Try placing it horizontally at A1 — it should fill A1 through E1. Then try placing it at G1 — it should be rejected because G+5-1 = K, which is off the grid.

**Try vertical placement.** Place a Destroyer (length 2) vertically at J9. It should fill J9 and J10. Try J10 — it should be rejected.
