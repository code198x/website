The game needs an ending. When all five of a player ships are sunk, the opponent wins. This check runs after every shot — if the sunk count reaches 5, the game loop stops and a winner is declared.

## How It Works

**Lines 140-160** count sunk ships after every shot. A loop sums `k(o,1)` through `k(o,5)`. If the total equals 5, all ships belonging to the opponent are sunk.

**Lines 170-190** break out of the game loop when a win is detected. The variable `w` is set to the current player number (`w = p`), and the program jumps past the turn loop with GO TO.

**Lines 300-320** display the victory message. "Player " + `STR$(w)` + " wins!" appears centred on a cleared screen. The game is over.

**Lines 330-340** use STOP to end the program. Later units will replace this with a rematch option.

## Checking After Every Shot

The win check runs after every shot, even misses. Why? Because a miss never changes the sunk count — but checking unconditionally is simpler than adding a conditional check. The performance cost is negligible: summing five array elements takes microseconds even in BASIC. Simplicity beats optimisation here.

## Breaking the Game Loop

Spectrum BASIC does not have a `WHILE` loop with a condition. The game loop runs with GO TO. To exit, we use another GO TO that jumps past the loop to the victory display. This is the standard BASIC pattern for conditional loop termination: a flag variable plus a jump.

The flag `w` serves double duty. During the game, `w = 0` means no winner. When a win is detected, `w` becomes the winning player number. After the loop, we check `w` to display the right message.

## Try This

**Test the win condition.** Set up a game where you know all ship positions and systematically sink all five. The victory message should appear after the final hit.

**Test that misses do not trigger a win.** Fire a miss after sinking four ships. The game should continue normally, not declare a winner.
