When placing ships, the player needs visual feedback. After each ship is placed, the grid redraws to show where it landed. Without this, the player is working blind — unable to see their fleet layout while deciding where to put the next ship.

## How It Works

**Lines 20-40** draw the grid using the colour scheme from Unit 4. Ship cells (values 1-5) display in grey, empty cells in blue. The grid redraws completely each time a ship is placed.

**Lines 50-70** display the ship name and length above the grid, so the player knows what they are placing. For example: "Place CARRIER (length 5)".

**Lines 80-100** show the current state after placement. The newly placed ship appears on the grid alongside any previously placed ships. The player can see the entire fleet layout developing.

## Visual Feedback During Placement

Placement is a multi-step process. The player places five ships in sequence, and each placement decision depends on where the previous ships went. Showing the grid after each placement lets the player:

- Confirm the ship landed where they intended
- Plan the next placement around existing ships
- Spot mistakes before the game begins

Without the redraw, the player would need to remember where they placed every ship. For five ships of different lengths and orientations, that is too much to track mentally.

## Ship Display Characters

On the ship grid, each ship value (1-5) could display as the same character or as different characters. Using `CHR$(64+v)` shows ships as letters A through E, matching their internal values. This helps the player distinguish ships from each other. Alternatively, a solid block character treats all ships identically, which looks cleaner but gives less information.

## Try This

**Try both display styles.** Print ship cells as `CHR$(64+v)` (letters A-E) and then as a solid block `CHR$(143)`. Which do you prefer? Letters give more information but look busier.

**Add a ship count.** After each placement, print "Ships placed: 2 of 5" below the grid. This tells the player how many remain without them having to count.
