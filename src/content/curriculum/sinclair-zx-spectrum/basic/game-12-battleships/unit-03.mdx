Each player needs to see two things at once: where their own ships are, and where they have fired at the opponent. That means two grids on screen simultaneously. The Spectrum screen is 32 characters wide — tight for two labelled grids, but it fits with careful spacing.

## How It Works

**Lines 20-50** draw the left grid starting at column 0. This is the ship grid — it will show the current player where their own ships sit and where the opponent has fired at them.

**Lines 60-90** draw the right grid starting at column 17. This is the tracking grid — it will show where the current player has fired and what they hit. The column offset of 17 leaves a gap between the two grids.

**Lines 100-110** print labels above each grid: "YOUR SHIPS" on the left, "YOUR SHOTS" on the right. These help the player understand what each grid represents.

## Screen Layout

The Spectrum screen is 32 columns wide. Each grid needs 11 characters (1 for the row label, 10 for cells). Two grids need 22 characters plus a gap. With a 17-column offset for the right grid, the layout uses columns 0-10 for the left grid and columns 17-27 for the right grid. That leaves a 6-character gap and 4 columns spare on the right. The bottom two lines of the screen are free for input prompts and messages.

## The Offset Pattern

Rather than writing separate drawing code for each grid, a single subroutine can draw a grid at any starting column. Pass the column offset as a variable, and every `PRINT AT` adds that offset. This is how the code reuses the same grid-drawing logic twice with different positions.

## Try This

**Narrow the gap.** Change the right grid offset from 17 to 13. Does it still look readable, or do the grids blur together?

**Add a title row.** Print "BATTLESHIPS" centred above both grids at row 0. Move the grids down by one row to make room.
