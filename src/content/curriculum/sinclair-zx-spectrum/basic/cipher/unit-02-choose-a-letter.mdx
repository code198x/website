RUN, then press T without pressing Enter. Both Ts should appear. Try lowercase and uppercase letters, Z, a digit and Space. The letter Z produces a miss message; the digit and Space leave the reveal alone. Press Enter when you want to edit the program.

## Give a subroutine one job

GO SUB 8000 visits the key routine. RETURN resumes the statement after the call. This lets the game ask for a key without putting the keyboard loop into every screen.

INKEY$ reports the current character, or an empty string when none is available. Line 8010 first waits for release of the previous key. Line 8020 then waits for a new character. Holding T should produce one guess, rather than repeatedly processing T while it is down.

The routine returns the character in k$. CODE gives its numeric character code. Uppercase A–Z occupy 65–90; lowercase a–z occupy 97–122. Line 8030 adds 32 to uppercase letters and CHR$ converts that number back to a character. Both cases therefore leave the routine as lowercase.

Enter has code 13 and exits at 320. The OR condition at 340 rejects a code below 97 or above 122. Only a letter reaches 350, where subtracting 32 makes the uppercase guess that matches our stored word.

## Reveal without forgetting

The initial underscore loop runs once. After a guess, GO TO 300 returns to drawing and input, not to that initialisation. Correct guesses from earlier turns remain in d$.

Before each search, found returns to zero. The search changes every matching position, then the message uses STR$ to turn the numeric match count into text. A miss changes the message but leaves d$ alone. CLS currently clears and redraws this small display; a later board will update selected fields.
