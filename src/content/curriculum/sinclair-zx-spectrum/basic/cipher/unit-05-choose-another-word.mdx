RUN now opens the title. S starts a fresh session and Q quits. Complete or lose a word, then press Space: the score stays, the histories clear and the next word differs from the one just played. R starts a new session; it may choose any word.

## Choose a place in the list

DATA holds the words at 9000–9030. The statements do not display them or immediately assign them to w$. READ consumes the next item from that list. RESTORE 9000 returns the reading position to the first DATA statement at or after 9000.

RND supplies a value from zero up to, but not including, one. Multiplying by total gives a value below twenty-four. INT drops the fractional part; adding one chooses an index from one to twenty-four. RANDOMIZE near the start seeds the generator from the machine's timing.

The counted READ loop visits items from the beginning through pick, replacing w$ each time. After the loop, w$ holds the selected word. RESTORE is essential: without it, repeated rounds would carry on reading from the previous location and eventually run past the list.

The value last remembers the previous index. If a new selection equals it, choose again. That prevents an immediate repeat during a session; it does not promise that every word appears before one returns. The reset sets last to zero, which is outside the valid index range.

KETTLE. The three READs take WINDOW, BOTTLE and KETTLE. Reading has moved past those items; RESTORE returns the next selection to the same starting point, so its index still refers to the intended word.

## Content changes the decisions

A familiar word can still be awkward when few useful letters have been revealed. Repeated letters may reward one guess several times. Word length alone does not settle difficulty: familiarity, likely alternatives and letter distribution also matter.

The current list uses uppercase words of four to eight letters. Keep at least two distinct entries if you change it, because rejecting the previous selection cannot finish with a one-item list. Keep total equal to the number of DATA entries. Too small a total leaves the tail unreachable; too large can make READ run out of data. Stay within the stated word length while using this board layout.

The title's GO SUB uses the same release gate as the game. Its controls belong to its own loop, so S starts there but is an ordinary guess during a round. The program remains deliberately silent, and every input waits for a separate press.

Play a win, a loss and another word. Pause halfway through, resume, reset and quit. A successful round should preserve the score on Space while rebuilding the allowance, revealed string and alphabet for the new answer.
