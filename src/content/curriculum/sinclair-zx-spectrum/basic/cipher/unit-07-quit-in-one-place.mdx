## Read the report

Here is what the previous program showed when Q was pressed on the title:

<Figure src="/images/sinclair-zx-spectrum/basic/cipher/teaching/stop-at-title.png" width={352} alt="The Cipher title screen with the report 9 STOP statement, 100:2 printed below the instructions." caption="The previous program after Q on the title. The instructions are still up, and the only sign of an ending is the ROM's report." />

The Spectrum prints a report at the bottom of the screen whenever a BASIC program stops, whatever the reason. It has three parts:

- **9** is the report code. The manual's table of reports runs from 0 to 9 and then from A to R, so you can look a code up. Report 0 is `OK`, a normal finish. Report 9 means the program reached a `STOP`.
- **STOP statement** is the short message that goes with the code.
- **100:2** is where the program stopped: line 100, statement 2. Statement 1 starts the line, and each colon or `THEN` begins the next one. In `IF k$="q" THEN STOP`, the `IF` is statement 1 and the `STOP` after `THEN` is statement 2.

The report is written for the person who wrote the program: it says why the program stopped and exactly where. That is useful while we are building and testing. A player who sees `STOP statement` printed under the instructions has been told nothing they can use, and it reads more like a fault than a goodbye. The same report appeared at 660:2 from the pause menu and at 760:2 from the result, each time on top of whatever was on the screen.

## One way out

Lines 100, 660 and 760 still test for Q, but each now says `GO TO 8500` instead of `STOP`. It is `GO TO`, not `GO SUB`: the closing routine never returns, so nothing needs to remember where it came from.

The routine at 8500 does the whole ending in one place. `CLS` removes the title, pause menu or board, whichever was showing. Line 8500 reprints the name in the same colours as the title. Lines 8520 and 8530 print `wins` and `losses`, the tally that line 2020 has been showing at the top of the board all session. Line 8540 tells the player how to start again, and line 8550 is the program's only `STOP`.

The ROM still prints its report, now `9 STOP statement, 8550:1`. It sits under the game's own words instead of replacing them, and it names the routine's `STOP` whichever menu the player left from. To change the ending later, we edit one routine instead of three lines.

During play, Q is still an ordinary letter guess. Only the three menus send Q to the routine, so a player cannot end a session by guessing a letter.

<Question prompt="Line 25 creates wins and losses before the title appears, yet line 200 sets them both to zero again when S starts a session. Suppose line 25 were left out. What would Q on the title do?">

The routine would stop with `2 Variable not found, 8520:1`. On a fresh RUN, the title's Q is pressed before line 200 has ever run, so `wins` does not exist yet. Line 8510 still prints `Thanks for playing.`, then line 8520 is the first statement to read `wins` and the ROM stops there with report 2. That is the manual's description of report 2: a simple variable used before a `LET`, `READ` or `INPUT` has assigned it.

Line 25 creates both variables at zero, so Q on the title shows a tally of 0 and 0. Line 200 still resets them at the start of every session, which is what R relies on.

</Question>

## After the game ends

`STOP` does not clear the variables. After quitting, type `PRINT wins` as a direct command and the Spectrum still knows the tally. Its report, `0 OK, 0:1`, follows the same rules: code 0 for a normal finish, and line 0 because a direct command has no line number of its own. `RUN` clears every variable and starts again from the lowest line, so the title returns and S begins a fresh session at zero. That is why the closing screen says `RUN plays again.`

Try each exit: Q on the title, Q from the pause menu (Enter during a word) and Q at a result. Each should give the same closing screen with the tally at that moment and the report `9 STOP statement, 8550:1`. Then play on with RUN and S.

This is the version to keep. Save it with the same direct command as before, `SAVE "cipher" LINE 10`, and check the new tape in a fresh machine as the [previous lesson](/systems/sinclair-zx-spectrum/basic/cipher/unit-06-keep-cipher/) describes.
