## Remember an attempt once

The string t$ stores every accepted letter. The string m$ stores only misses. Both begin empty. Before searching the answer, lines 350–380 scan t$ and set seen to one if the letter is already there. Line 355 bypasses that scan when there are no earlier attempts. The duplicate branch returns to the display before appending a letter or spending a mistake.

For a new guess, line 390 appends it and clears found. After the answer search, found equal to zero means this new letter missed: decrease left by one and append the letter to m$. A repeated letter in the *answer* can raise found several times; it is still one guess in the history.

The completion checks happen after revealing and charging. Comparing d$ with w$ asks whether the entire word has been uncovered. The other ending tests left for zero. Each branch updates its score once and enters a separate result loop, so an ignored key cannot score the same round again.

## Menus need their own rules

Q and R must remain available as guesses. Enter now pauses instead of quitting. The pause loop accepts C to continue, R to reset words and scores, or Q to STOP in BASIC. Continuing returns to drawing without changing the word, history or allowance. Reset jumps to 200 and discards the current session.

The result loop uses Space for the next round, R for a reset and Q to quit. Going to 210 retains wins and losses; going to 200 clears them. The round counter increases only on Space. With the fixed word, replay tests state handling rather than variety.

## Separate drawing from decisions

GO SUB 2000 clears the screen and draws the headings, score and controls. It calls 2500 for changing fields: revealed word, allowance, misses and feedback. Most guesses call only 2500. Neither routine changes the game's rules; both return to their caller.

A shorter message could leave the end of an older message behind. Line 2590 appends spaces to a$, then prints the first thirty characters of that padded string. `b$(TO 30)` starts at position one. The blank tail overwrites old text.
