Pause with Enter and choose Q to return to BASIC. Enter this direct command, with **no line number**:

```basic
SAVE "cipher" LINE 10
```

LINE 10 records the starting line for a later load. At the tape prompt, press Enter and wait for the `0 OK` report. In Emu198x, export the recorded tape to a new `.tap` file using **Tape → Export Recording…** or **Cmd/Ctrl+Shift+E**. Choose a new filename: export does not overwrite an existing file. The [Meet BASIC saving guide](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) explains the distinction between recording inside the machine and keeping a file on the host.

Open a fresh 48K machine, insert that exported tape and enter `LOAD ""`, or use the emulator's tape autoload. Do not rely on a program already sitting in memory. The title should appear. S must start a new session with zero wins and losses and seven mistakes.

## Check a complete cycle

Use these checks together:

- Guess a letter. Every matching position should appear; a miss should reduce the allowance once.
- Repeat that same guess. Neither the count nor the miss list should change again.
- Try a digit and Space during play. Neither is a letter guess.
- Pause with Enter, then C. The word, revealed letters, misses and count must survive.
- Finish a word or spend all seven mistakes. The answer and result should remain until another key is chosen.
- Press Space for another word. Keep the score, clear the histories and restore seven mistakes.
- Use R in a menu to reset, then Q in a menu to quit. During play, Q and R must still be usable letters.

<Question prompt="Does loading this saved tape resume a partly played word?">

No. Auto-start at line 10 runs the title and S reaches the session initialisation at 200. That clears scores and chooses a word. This procedure saves a reusable program, not a resumable game session.

</Question>

## Inspect the relationships

The hidden word, revealed word, attempt history and available alphabet are separate strings because they answer different questions. A repeated guess changes none of those records. A new matching guess changes knowledge; a new miss changes the remaining allowance. The display follows those stored facts.

A useful next experiment is to trace two possible guesses on paper before playing them. Which positions might they reveal? Which candidate words would remain? The program knows its answer, but the player's uncertainty is what makes the choice interesting. Keep the source and exported tape together so you can return to the working game after an experiment.
