## Store what can be redrawn

The new u$ begins as the uppercase alphabet. The game already knows that c is the code of a lowercase letter. Subtracting 96 gives its position in u$: a becomes one, z becomes twenty-six. Line 390 replaces that position with a dot. The string can now reconstruct the alphabet after a menu has covered the screen.

This is a second use of slice assignment. In d$, a known letter replaces an underscore; in u$, a used letter becomes a dot. The attempt history still prevents duplicate costs, while u$ describes how the choices should look.

## Fold a row into two

For alphabet position j, first use `j-1` to get a position from zero to twenty-five. Dividing by thirteen and taking INT gives zero for the first row and one for the second. Adding fourteen selects screen row 14 or 15. Subtracting thirteen times that row offset leaves the position within the row. Multiply by two for letter spacing, then add three for the left margin.

PRINT AT addresses a character row and column from zero. It does not use the string's one-based positions. Line 395 performs the same calculation for the newly guessed letter using `c-97`. It prints just that letter's dot during play.

## Redraw only what changed

The complete board routine loops through all twenty-six letters when entering a round, returning from pause or showing a result. Ordinary guesses redraw the word and feedback fields, plus one alphabet cell. Clearing the whole board after every guess would do work the screen does not need and make the response slower.

The word loop prints each character followed by a space. Its starting column, `16-LEN d$`, centres that doubled width in the thirty-two-column display. The marker loop prints O for each remaining mistake and a dot for each spent one; both occupy the same width, so older markers disappear cleanly.

INK chooses text colour, BRIGHT selects brightness, and BORDER and PAPER establish the surrounding and background colours. Colour controls inside PRINT apply to that PRINT statement. The rules still use stored letters and numbers, never the colour of a screen cell.
