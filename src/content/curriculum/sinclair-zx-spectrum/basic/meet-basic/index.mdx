## A greeting becomes a story

Start with one instruction. Store a small program, change it, ask someone for
words, then turn their answers into a story. Each lesson grows from the last,
with complete listings and clear instructions for the lines to add or replace.

These four lessons form a complete first project. No previous programming is
needed, and [Foundations](/foundations/) is optional: its pseudocode explanations
provide another way to explore the ideas we use here.

## Get the Spectrum ready

The lessons use a **48K ZX Spectrum** in **Emu198x v0.22.0 or later**.
Download the Spectrum archive for your host computer:

| Host computer | Download |
|---|---|
| Mac with Apple silicon | [macOS Apple silicon](https://github.com/emu198x/emu198x/releases/download/v0.22.0/emu198x-spectrum-aarch64-apple-darwin.tar.xz) |
| Mac with an Intel processor | [macOS Intel](https://github.com/emu198x/emu198x/releases/download/v0.22.0/emu198x-spectrum-x86_64-apple-darwin.tar.xz) |
| Windows, Intel or AMD 64-bit | [Windows](https://github.com/emu198x/emu198x/releases/download/v0.22.0/emu198x-spectrum-x86_64-pc-windows-msvc.zip) |
| Linux, Intel or AMD 64-bit | [Linux](https://github.com/emu198x/emu198x/releases/download/v0.22.0/emu198x-spectrum-x86_64-unknown-linux-gnu.tar.xz) |

Extract the archive into a folder you can find again. These are ready-built
programs; you do not need Rust or an assembler. The
[release notes](https://github.com/emu198x/emu198x/releases/tag/v0.22.0) include
checksums for checking the downloads.

You also need a lawfully obtained 48K Spectrum ROM; it is not part of our lesson
files. The [ROM guide](/setup/roms/) explains what firmware is and how to obtain it.
Open a terminal in the extracted folder containing the emulator. A terminal
accepts commands for your host computer; this command starts the Spectrum:

On macOS or Linux:

```sh
./emu198x-spectrum --rom "path/to/48.rom"
```

In Windows PowerShell:

```powershell
.\emu198x-spectrum.exe --rom "C:\path\to\48.rom"
```

Replace the quoted path with your ROM file's location. Keep the quotes if the
path contains spaces. The Sinclair copyright message is our starting screen;
from then on, we type BASIC in the emulator window. When a later lesson asks you
to restart Emu198x, use the same launch command.

We enter BASIC using **Host Keyboard** mode: normal host punctuation and capitals,
with the Spectrum's single-key keywords. The first lesson explains the keys.
The menu instructions describe macOS and Windows; Linux uses the keyboard and
launch-command alternatives given alongside them.

## What comes next

Meet BASIC will continue with **Lucky Number**, **Oracle Stone**, and a
**movement and input experiment**. Those revised sections are in development.
They will introduce decisions, repetition, chance, routines and controls through
more small programs.

The wider route leads towards [Bright Spark](/systems/sinclair-zx-spectrum/basic/bright-spark/)
and [Touchdown](/systems/sinclair-zx-spectrum/basic/touchdown/).
You can also browse the existing [BASIC reference lessons](/systems/sinclair-zx-spectrum/basic/basic-reference/)
for individual commands and machine features. They remain available independently
of this new sequence.
