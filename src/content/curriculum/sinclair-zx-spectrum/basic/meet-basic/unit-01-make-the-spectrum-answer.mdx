We can give the Spectrum an instruction and see its answer straight away. Then we’ll
keep instructions together as a program we can run again and change.

You can start here without having programmed before. We’ll explain the words and
keys as we use them.

## Start the Spectrum

These examples use a **48K ZX Spectrum**, and there is one in this page. Press
**Run it here** below, then press **Start** in the panel that opens. The 48K ROM
is included with the player, so there is nothing to install. When the Sinclair
copyright message appears, click the Spectrum’s screen so that it receives your
keys. Tab returns to the page.

<RunIt watch="Press Start in the panel for an empty Spectrum to type into. Run this lesson loads the finished greeting instead." />

The computer you are reading this on is our **host**; the Spectrum the page
recreates is our **target**. The BASIC program runs on that target. If you would
rather use a desktop emulator, see [work locally](/systems/sinclair-zx-spectrum/basic/meet-basic/#optional-work-locally).
There, use the **left** Alt or Option key for SYMBOL SHIFT and Home for EDIT;
the other keys below work the same way.

## Find the keyboard

The Spectrum keyboard has words as well as letters. A **keyword** is a word BASIC
recognises as an instruction or part of one. At the start of an instruction, one
key enters a whole keyword: `P` enters `PRINT`.

The Spectrum also has two shift keys of its own. **CAPS SHIFT** gives capital
letters and editing combinations. **SYMBOL SHIFT** gives the red symbols and words
printed on the keys, such as the quotation mark on P. In the page, your keyboard’s
**Shift** is CAPS SHIFT and **Alt** (**Option** on a Mac) is SYMBOL SHIFT. Enter
finishes a line.

## Give one instruction

Press `P`. `PRINT` appears, followed by a flashing cursor showing where the next
character will go. The cursor changes from **K**, for keyword entry, to **L**, for
ordinary letters. It is telling us how the next key will be interpreted.

Enter this instruction:

```sinclair-basic
PRINT "Hello"
```

After pressing P for `PRINT`, hold Alt and press P for the opening quotation
mark. Hold Shift and press H for a capital H, type `ello`, then use Alt+P again
for the closing mark. Press Enter.

`PRINT` displays the text between the quotation marks. The marks tell BASIC where
the text starts and ends; they do not appear in the greeting. BASIC supplies the
space after its keyword, so you needn’t type an extra one there.

<Figure src="/images/sinclair-zx-spectrum/basic/meet-basic/opening/immediate.png"
  alt="The Spectrum displays Hello, with the report 0 OK at the bottom."
  caption="An instruction without a line number runs when we press Enter." />

The report at the bottom begins `0 OK`. It says the instruction finished without
a reported error. It cannot tell whether we wrote the message we intended: we check
that ourselves.

If a character is wrong before you press Enter, use Backspace to delete the
character immediately before the cursor, then type the replacement. Backspace
stands in for the Spectrum’s DELETE: CAPS SHIFT and 0 together.

## Keep the instruction

This time, type `10` before pressing P for `PRINT`:

<CodeFromFile src="sinclair-zx-spectrum/basic/meet-basic/opening/unit-01/steps/step-01.bas" lang="sinclair-basic" />

Press Enter. The Spectrum lists the numbered instruction instead of carrying it
out. The number tells BASIC to store it as a **program line**.

At the empty input line, press R. The keyword `RUN` appears. Press Enter to run
the stored program. You should see `Hello` again. Repeat R, Enter: the program is
still there. Running it does not use it up.

The [Foundations explanation of instructions](/foundations/basics/unit-01/) explores
how precise instructions produce a result. Here, `PRINT` is the particular word
Sinclair BASIC uses for displaying something.

## Change a line

Enter `10 PRINT "Welcome"`, using the same keyword key and Alt+P for each quotation mark.
There is already a line 10, so BASIC replaces it. Lines 15 and 20 remain:

<CodeFromFile src="sinclair-zx-spectrum/basic/meet-basic/opening/unit-01/steps/step-04.bas" lang="sinclair-basic" />

Press K at the empty input line for `LIST`, then Enter. `LIST` shows the stored
program; `RUN` carries out its instructions. List it, check the new line 10, then
run it and look for `Welcome`.

For these short lines, entering a replacement is a useful way to edit. To bring an
existing line back into the editor, enter `LIST 10`, then press Shift+1 for
**EDIT** and release both keys. The line appears at the bottom. The left and right
arrow keys move within it; Backspace deletes the character before the cursor.
Press Enter to store it again. Pressing Enter without a change keeps the same line.

A line number entered on its own deletes that stored line. The next lesson starts
from these three lines and gives them in full, so it does not matter if your
Spectrum has been cleared by then.

## When the screen disagrees

If Enter leaves an error marker in the input line, the Spectrum has rejected its
syntax: the arrangement of symbols does not form an instruction it accepts.
Check the quotation marks and the keyword. The cursor or marker is a clue to
where checking failed, not proof that the character at that position caused it.

If you see a listing instead of your greeting, the line was stored successfully;
use R, Enter to run it. If the wrong message appears, use K, Enter to inspect what
is stored. A new line number adds a line; reusing the old number replaces it.

We now have a small working cycle: enter an instruction, run the program, inspect
its result, and make a deliberate change. Next we’ll give the greeting a name to
use, and keep a copy outside the running Spectrum.
