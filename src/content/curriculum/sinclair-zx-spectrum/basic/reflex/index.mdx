Reflex is a reaction tester. The screen shows a telegraph bar filling gradually, then flashes red. Press any key as fast as you can. Your reaction time appears with a rating.

<Figure src="/images/sinclair-zx-spectrum/basic/reflex/unit-09/screenshot.png" alt="Black ZX Spectrum screen: Get ready... above a telegraph bar filling a thin rectangular frame" caption="Where you are headed: the telegraph bar fills its frame, then flashes red." />

This is the first game that uses **real-time input** — `INKEY$` checks the keyboard without stopping the program. It is also the first game that puts **pixels** on the screen — `PLOT` and `DRAW` create the telegraph bar.

**What you will learn:**

- `INKEY$` — non-blocking keyboard input
- `PLOT` — placing a pixel on screen
- `DRAW` — drawing a line
- Loop-counter timing
- `PAPER` as a visual event (full-screen colour change)

**9 units. About 7–9 hours.**
