## Arrays indexed by loop variables

`s(c)` is the key insight. The loop variable `c` (1, 2, 3, 4) directly indexes the array. No lookup table, no IF chain — the loop variable is the address. This is why arrays and FOR loops are natural partners: the loop steps through positions, and the array stores one value at each position.

The same principle applies to `k(n)` — the answer key array indexed by the question number. Both arrays use the loop as their address book.

The breakdown gives the results screen depth. "6 out of 8" is a flat score. "Animals: 2/2, Space: 2/2, History: 1/2, Geography: 1/2" tells a story — the player knows History and Geography need work. It turns the end of the quiz into the beginning of a strategy for next time.
