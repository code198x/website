## Nested FOR loops

The outer loop (`c`) steps through categories. The inner loop (`q`) steps through questions within each category. The variable `n` counts the overall question number (1–8) across both loops, used to index into the answer array `k(n)`.

The DATA is structured in groups: each category starts with its name and colour (line 600, 630, 660, 690), followed by two question blocks. The nested loops consume this data in order — the structure of the DATA matches the structure of the loops.

Note the variable names: `c` for the category loop (single letter, required for FOR/NEXT on the Spectrum) and `ink` for the colour number (multi-letter, fine for LET and READ). The Spectrum's ROM requires FOR loop variables to be a single letter, but other variables can be as descriptive as you like.
