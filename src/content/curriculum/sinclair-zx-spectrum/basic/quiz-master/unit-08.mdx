Lines 420–450 add a cascading IF chain. A perfect 8 gets green "Quiz Master!" — the game's title becomes the highest accolade. 6–7 gets cyan "Expert". 4–5 gets yellow "Not bad". Below 4 gets red "Keep trying". Each tier jumps to line 460 with `GO TO`, which resets `INK 0` so subsequent text prints normally.

This is the same pattern from Bright Spark (unit 9) and Hi-Lo (unit 10). Four games now use it. The pattern has become a vocabulary: cascading IF from highest to lowest, each tier with its own colour, the rating prints in that colour. The player already knows what green text means (good) and what red means (try harder).

The top rating shares the game's name — "Quiz Master!" This is a small design choice with a big effect. The player is not just scoring well; they are earning the game's title. It turns the rating into a goal: "I want to be a Quiz Master."
