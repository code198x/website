An open question is hard to check — the player might type "eight", "Eight", "8", or "8 legs". Multiple choice solves this.

<Figure src="/images/sinclair-zx-spectrum/basic/quiz-master/unit-02/screenshot.png" alt="Question with four numbered options and 'Correct!' after choosing option 1" caption="Four options read from DATA; the player picks a number, not a word." />

Line 190 reads five values from DATA: the question `q$` and four options `a$`, `b$`, `c$`, `d$`. Lines 220–250 print the options numbered 1–4. Line 260 now asks for a number instead of text: `INPUT "Answer (1-4): ";g` — note no `$`, so `g` is a number.

Lines 280–290 check the answer. The correct answer is option 1 (Eight), so `IF g <> 1` shows the answer and `IF g = 1` prints "Correct!"

DATA on line 610 holds everything: the question string and all four options in one line. `READ q$,a$,b$,c$,d$` splits them out. This is how DATA works with multiple variables — each `READ` pulls the next comma-separated value.

The correct answer (1) is still hardcoded. That means every question would need its own IF check, which does not scale. The next units fix this with arrays.
