Draughts is a turn-based game. Player 1 moves, then Player 2, then Player 1 again. A single variable `t` tracks whose turn it is: 1 or 2. Below the board, a status line shows "Player 1 (Red)" or "Player 2 (Green)" in the matching colour.

## How It Works

**Line 70** sets `t = 1`. Player 1 always moves first.

**Line 80** calls `GO SUB 800` to display the current player.

**Lines 810-840** form the status display subroutine. Line 810 clears the status area by printing spaces. Lines 820 and 830 check the value of `t` and print the appropriate player name in the matching INK colour. Red for Player 1, green for Player 2.

## Turn-Based Flow

Turn tracking is the foundation of every two-player game. The variable `t` controls everything that depends on whose turn it is:

- Which pieces the player can move (values 1 and 3 for Player 1, values 2 and 4 for Player 2)
- Which direction is "forward" (toward row 8 for Player 1, toward row 1 for Player 2)
- Which pieces count as enemy (the other player's values)

After a valid move, we flip the turn: if `t = 1`, set it to 2. If `t = 2`, set it to 1. We will add this logic in unit 10 when moves are executed.

## The Status Area

Everything below row 11 on the screen is reserved for game information: whose turn it is, move prompts, error messages, and later the piece counts. By keeping the status area separate from the board, we can update messages without redrawing the board itself.

## Try This

**Add a turn counter.** Create a variable that increments after both players have moved. Display "Turn 1", "Turn 2", and so on. This gives a sense of how long the game has been running.
