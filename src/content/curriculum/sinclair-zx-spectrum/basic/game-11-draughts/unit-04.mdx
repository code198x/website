Players need to identify squares by coordinate. A3 means column A, row 3. Without labels, they would have to count squares from the corner. This unit adds letters A to H across the top and numbers 1 to 8 down the left side.

## How It Works

**Lines 710-730** print column labels. `CHR$(64 + c)` converts a number to a letter: when c is 1, `64 + 1 = 65`, which is the character code for "A". When c is 8, it produces "H". Each label sits at row 1, spaced to align with the board columns.

**Lines 740-760** print row numbers 1 to 8 down the left side. Each number sits at column 1, aligned with the board rows using the same `r + 2` offset.

## CHR$ and Character Codes

The Spectrum uses character codes where A=65, B=66, and so on through H=72. The expression `CHR$(64 + c)` maps column numbers 1-8 to letters A-H. This is a standard trick for converting between numbers and letters.

Later, when reading player input, we will use the reverse operation: `CODE "A"` returns 65. Subtracting 64 converts a letter back to a column number. The labels and the input system share the same mapping.

## The Full Display

With labels in place, the board now looks like a proper game. The letters across the top and numbers down the side form a coordinate system. A player can look at a piece on the board, read across to the column letter and down to the row number, and say "C3" to identify that square.

This coordinate system matches standard draughts notation. It also makes the input system straightforward: the player types what they see.

## Try This

**Reverse the labels.** Print row 8 at the top and row 1 at the bottom. In some draughts games, Player 1 starts at the bottom. Which orientation feels more natural?

**Add colour to labels.** Try printing the column letters in cyan (INK 5) and the row numbers in yellow (INK 6). Coloured labels stand out from the board without competing with the pieces.
