Draughts is a two-player board game on an 8x8 grid. Red and green pieces move diagonally, capture by jumping, and become kings on the back row. Before we can draw anything, we need somewhere to store the board state. A 2D array is the natural choice: `DIM b(8,8)` gives us 64 squares, each holding a number that says what sits there.

## How It Works

**Line 20** creates the board with `DIM b(8,8)`. This gives us an 8-row, 8-column grid. Every element starts at 0, meaning empty.

**Lines 40-80** fill the starting positions for Player 1. The loop visits rows 1 to 3. For each square where `(r + c)` is even, it sets `b(r,c) = 1`. This places pieces only on the dark squares, just like a real draughts board.

**Lines 90-130** do the same for Player 2 in rows 6 to 8, setting those squares to 2.

**Lines 150-220** print the raw array values so you can see the pattern: 1s in the top three rows, 2s in the bottom three, 0s everywhere else.

## The Even-Sum Trick

Why check `(r + c) / 2 = INT((r + c) / 2)`? This tests whether `r + c` is even. On a chequerboard, dark and light squares alternate. When both the row and column are odd, or both are even, their sum is even. That gives us the dark squares where pieces belong.

The Spectrum has no MOD operator, so we divide by 2 and check whether the result is a whole number. If it is, the sum was even. This pattern appears throughout the game whenever we need to know if a square is dark.

## Array Values

The board array uses simple integers to represent game state:

- **0** = empty square
- **1** = Player 1 piece (red)
- **2** = Player 2 piece (green)
- Later, **3** and **4** will represent kings

This is a pattern you will see in many board games. The array is the single source of truth. Everything else - drawing, validation, win detection - reads from this array.

## Try This

**Print a specific square.** Add `PRINT b(3,2)` after the loops. What value does it show? Try other coordinates. Can you predict which squares hold 1, 2, or 0?

**Change the starting rows.** What happens if Player 1 starts in rows 1 to 4? The game would begin with pieces closer together. More crowded, more captures available immediately.
