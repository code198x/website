During a multi-jump chain, the player must continue jumping with the same piece. They cannot switch to a different piece or make a simple move. This unit adds a flag `l` that constrains the input and validation during a chain.

## How It Works

**Line 75** initialises the chain flag `l` to 0 (not in a chain).

**Line 853** checks the flag during input. If `l = 1`, it displays "Continue from B4" (or wherever the piece landed), telling the player which piece must move next.

**Line 935** in source validation rejects any move that does not use the chain piece. If `l = 1` and the source coordinates do not match the stored position (`y` and `s`), the error "Must jump with B4" appears.

**Line 965** in move validation rejects simple moves during a chain. If `l = 1` and the move is not a two-square jump, the error "Must capture" appears.

**Line 1769** in the multi-jump check sets `l = 1` and stores the continuing piece's position in `y` and `s` before looping back to input.

**Lines 1035 and 1060** reset `l` to 0 when the chain ends. Line 1035 clears it after a simple move. Line 1060 clears it after a capture where no further jumps are available.

## Mid-Turn Interaction

The chain flag creates a sub-state within the turn. Normally, the game alternates between Player 1 and Player 2. During a multi-jump, the same player takes multiple inputs before the turn switches. The flag `l` controls this:

| Flag `l` | State | Allowed moves |
|---------|-------|--------------|
| 0 | Normal turn | Any valid move or capture |
| 1 | Mid-chain | Capture with the specified piece only |

This is a state machine within a state machine. The outer machine tracks whose turn it is. The inner machine tracks whether that turn is in a chain.

## Try This

**Complete a chain.** Set up a triple jump and execute all three captures. Watch the "Continue from" prompt and the "Jump again!" message cycle until the chain ends.

**Try to cheat.** During a chain, enter a move with a different piece. The error message should name the correct piece and refuse the move.
