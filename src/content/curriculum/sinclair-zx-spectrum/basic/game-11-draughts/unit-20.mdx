In official draughts rules, captures are mandatory. If a player can capture an opponent's piece, they must. They cannot choose a simple move instead. This unit adds a board scan that checks whether any capture is available before allowing a simple move.

## How It Works

**Lines 992-993** in the move validation add a new check after the forward-only rule. Before accepting a simple move, the code calls `GO SUB 1600` to scan the board for available captures.

**Lines 1600-1720** form the capture scanning subroutine. It loops through every square, finds the current player's pieces, and checks all four diagonal directions for a valid capture. For each piece, it checks:

1. Is the landing square (two squares away) on the board and empty?
2. Is the intermediate square occupied by an opponent?
3. Is the direction valid for this piece type (forward-only for non-kings)?

**Line 1684** sets `z = 1` if any capture is found, then immediately returns. The scan does not need to find all captures, just prove that at least one exists.

**Line 993** checks the result. If `z = 1`, the simple move is rejected with "You must capture".

## The Direction Iterator

The scan uses a clever pattern with variables `i` and `k` to check all four diagonal directions. Starting at `i = -1, k = -1` (up-left), it steps through:

- `i = -1, k = -1` (up-left)
- `i = -1, k = 1` (up-right)
- `i = 1, k = -1` (down-left)
- `i = 1, k = 1` (down-right)

Lines 1690-1695 increment `k` by 2 (from -1 to 1), then increment `i` and reset `k`. This iterates all four diagonal neighbours without four separate blocks of code.

## Mandatory Capture

This rule fundamentally changes the game. Without it, a player could avoid captures to preserve their pieces. With it, players are forced into exchanges. This creates tension: setting up a capture position guarantees the opponent must take it, which might expose their pieces to a counter-capture.

## Try This

**Force a capture.** Position pieces so that a capture is available. Try to make a simple move instead. The error message should appear, naming the piece that can capture.

**Remove the rule.** Comment out lines 992-993 and play without mandatory captures. Notice how different the game feels when players can choose to avoid jumping.
