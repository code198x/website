Five dice is fun to watch. A hundred tells you whether the die is fair.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-dice-roller/unit-03/tally-three.bas" />

Line 70 initialises three counters: `t1`, `t2`, `t3` — one per face. Lines 130–150 check each roll: if `d` is 1, increment `t1`. If 2, `t2`. If 3, `t3`. Line 260 prints the totals.

The loop now runs 100 times (line 110) and the inline dice display (old line 190) is gone — replaced by the summary at the end. We are counting, not displaying.

Run it. Each counter should land near 16–17 (one-sixth of 100). If one face shows 25 and another shows 10, that is randomness — try 1000 rolls and the numbers even out.

## Why only three faces?

Faces 4–6 are not counted yet. The pattern is the same for each — one IF, one counter. The next unit adds the other three.
