Lines 170–220 use `PRINT AT` to write each tally at a fixed screen position, inside the loop. Every iteration, the numbers change in place. The screen becomes a live dashboard — you watch the tallies climb in real time.

## PRINT AT

`PRINT AT row, column; value` prints at a specific screen position instead of wherever the cursor happens to be. The Spectrum screen is 24 rows (0–23) by 32 columns (0–31).

`PRINT AT 2, 3; t1; "  "` prints the value of `t1` at row 2, column 3. The trailing `"  "` (two spaces) erases any leftover digits from the previous value — without it, a number like 99 followed by 8 would show as "89" because the second digit of 99 would remain.

This pattern — PRINT AT at a fixed position, with trailing spaces — is how every Spectrum game displays scores, lives, and status. You have just built your first real-time display.

## Watch it run

Set the roll count to 500 and run it. The numbers update so fast they blur — but you can see them converging. At 50 rolls, the tallies are uneven. At 200, they are closer. At 500, they are nearly equal. The accumulation happens in front of your eyes.

Add `PAUSE 1` after line 240 to slow it down — one frame delay per roll. Now you can watch each number tick up individually. The slower version is more hypnotic; the faster version is more dramatic. Both are the same program with one number changed.
