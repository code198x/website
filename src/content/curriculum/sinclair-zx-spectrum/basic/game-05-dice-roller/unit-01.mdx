You already know the range formula from Lucky Number. Here it produces a die roll instead of a secret number.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-dice-roller/unit-01/one-die.bas" />

`INT (RND * 6) + 1` — a random number from 1 to 6. Run it several times. Each time, a different number. The computer is rolling a die.

<Figure src="/images/sinclair-zx-spectrum/basic/game-05-dice-roller/unit-01/screenshot.png" alt="Black ZX Spectrum screen showing the text 'You rolled: 1'" caption="One die, one number — INT (RND * 6) + 1 in action." />

This is the same formula as Lucky Number's `INT (RND * 100) + 1`, just with a smaller range. The pattern — `INT (RND * range) + base` — works for any range you need. A coin flip is `INT (RND * 2) + 1`. A card draw (1–13) is `INT (RND * 13) + 1`. One formula, every game.

Is it fair? Roll it 20 times by running the program 20 times. Tally the results on paper. Does each number appear roughly equally? Probably not — 20 rolls is not enough to see the pattern. You need more rolls, and doing them by hand is tedious. That is what loops are for.
