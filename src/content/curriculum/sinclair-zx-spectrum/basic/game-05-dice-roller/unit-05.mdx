Six new lines (190–240) use `PRINT AT` to update the counts in fixed screen positions — one row per face. The old summary lines (260–270) are gone; the dashboard replaces them. Line 90 changed to "500 dice" and line 110 to `FOR i = 1 TO 500` — more rolls to watch the numbers converge.

Run it. The six numbers flicker upward as each die lands. You can see which face is "winning" and watch the others catch up. That live feedback — numbers changing before your eyes — is what makes the difference between a report and a dashboard.

## PRINT AT

`PRINT AT row, col` places the cursor at a fixed screen position. `PRINT AT 2, 3; t1; "  "` prints `t1` at row 2, column 3 — the same place every time. The trailing spaces overwrite any leftover digits from the previous value.
