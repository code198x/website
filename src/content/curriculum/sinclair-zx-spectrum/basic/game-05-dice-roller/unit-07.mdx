Numbers tell you the totals. A bar chart shows you the shape.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-dice-roller/unit-07/bar-chart.bas" />

Seven new lines (260–320). Line 260 moves the cursor below the dashboard. Lines 270–320 each print a row of asterisks — one `*` per roll of that face. Each line uses a FOR loop: `FOR j = 1 TO t1: PRINT "*";: NEXT j` prints `t1` asterisks in a row.

Run it with 100 rolls. Six rows of asterisks appear below the dashboard. The rows should be roughly equal length — that is what a fair die looks like. Try 1000 rolls: the bars grow longer and more even.

## Data visualisation

This is your first **data visualisation** — turning numbers into a picture. A bar chart works because length is easier to compare than digits. The player can see at a glance whether one face appeared more than others, without reading six numbers.
