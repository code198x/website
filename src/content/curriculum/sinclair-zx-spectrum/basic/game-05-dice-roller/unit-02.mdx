Rolling one die 20 times means running the program 20 times. That is not practical. `FOR/NEXT` rolls five dice in one run.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-dice-roller/unit-02/five-dice.bas" />

Lines 50–90 are the loop:

```
FOR i = 1 TO 5
  LET d = INT (RND * 6) + 1
  PRINT d; " ";
  BEEP 0.05, 20
NEXT i
```

`FOR i = 1 TO 5` starts a counted loop. The variable `i` begins at 1. Every time the program reaches `NEXT i`, it adds 1 to `i` and jumps back to the line after `FOR`. When `i` passes 5, the loop ends and the program continues with line 100.

Inside the loop, each iteration rolls a die and prints the result. The semicolons after `d` and `" "` keep the numbers on the same line, separated by spaces. The BEEP gives each roll a tiny click.

## Change the count

Replace 5 with 50:

```
50 FOR i = 1 TO 50
```

Run it. Fifty numbers fill the screen. Replace 50 with 500. A flood — you cannot read them individually, but you can see that every digit from 1 to 6 appears.

The loop body stays identical. Only the count changes. That is the power of `FOR/NEXT`: write the work once, control the repetition with a number.

## FOR/NEXT vs GO TO

You have used `GO TO` for loops since Lucky Number. `GO TO` loops until a *condition* is met — they run an unknown number of times. `FOR/NEXT` loops a *specific* number of times. Both are loops; the choice depends on what you need:

- "Keep guessing until correct" → `GO TO` (unknown count)
- "Roll 100 dice" → `FOR/NEXT` (known count)

You previewed `FOR/NEXT` in Reflex (the telegraph bar), but this is the formal introduction. From here on, both kinds of loop are in your toolkit.

One quirk to know: the Spectrum only allows **single-letter** variable names for `FOR`/`NEXT` and for string variables (`a$` to `z$`). You can use long names like `score` with `LET`, but `FOR score = 1 TO 10` gives a "Nonsense in BASIC" error. Stick to `i`, `j`, `n`, `x`, `y` — the same letters mathematicians use for counters.
