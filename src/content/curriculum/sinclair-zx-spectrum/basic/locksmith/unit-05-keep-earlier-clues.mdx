The practice code is still 1122. This version records **ten practice guesses**, even if an earlier guess is correct. We are inspecting history before adding the final game's winning rule.

## Advance the attempt

The drawing routine already uses row `4 + t`. It now gets a new t after every submission except the tenth. Attempts 1 through 10 occupy rows 5 through 14, leaving space above for headings and below for the editor.

Line 420 draws the completed guess first. Line 440 checks whether it was the tenth. Otherwise line 450 increases t and empties g$, ready for another guess. Line 460 removes any previous short-guess advice. The next visit to 2000 draws the new attempt number and four empty cells.

The board routine prepares all ten rows with a FOR j loop. Its variable differs from the digit loop's i: each routine can describe the part of the drawing it is visiting.

## Keep the evidence on screen

We have not created an array of old guesses. Their characters and clue counts remain where PRINT put them. Only the current code, editable guess and scoring values are needed for the next comparison.

This representation suits a fixed ten-row game. It also has a limit: after CLS, those earlier guesses are gone. A later feature that needed to analyse old guesses would need to store them explicitly. Reading coloured cells back from the display would make the drawing responsible for game data.

## Stop at the tenth row

After the tenth submission, the program prints its completion message and code, then waits in a separate loop at 5250. It accepts R to clear the board or Q to quit. The release gate prevents the finishing Enter press from carrying into that loop.

Submit 1122 early: 4 EXACT should appear, and another practice attempt should follow. Continue to ten guesses. The program should stop accepting digits without printing an eleventh row. R should erase the history and restore TRY 1 with the same practice code.

If all results overwrite the first row, check the increment at 450. If earlier clues disappear, check that the main loop returns to 230 rather than calling the CLS routine at 1000.
