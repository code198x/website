## The deduction arc

Ten guesses against a four-digit code from six possible digits is generous but not trivial. A random guesser would need luck. A logical guesser narrows the possibilities with each clue.

The first guess is always a stab in the dark. The second is informed by the first clue. By the third or fourth guess, a systematic player knows most of the digits — the remaining guesses pin down positions. That narrowing arc is what makes the game satisfying: each guess is more informed than the last.

The FOR loop with `t` also provides a natural countdown. "Guess 3 of 10" tells the player how much runway remains. As `t` climbs, the pressure builds — even in a turn-based game with no timer, the finite budget creates tension.
