Press 1, 2, 3 and 4, releasing each key. Enter now reports “Four digits ready.” There is no secret code or scoring yet. D erases the last digit; the Spectrum DELETE key also works. R clears the board and Q quits.

## Read, recognise, then change

INKEY$ gives the current key character, or an empty string when no key is recognised. Line 250 waits for a character. The following tests recognise commands before considering digits. OR means either comparison may succeed, so both upper-case and lower-case R work.

`CHR$ 13` is the Enter character and `CHR$ 12` is DELETE. Comparing these characters lets the editor recognise keys that do not print a digit. At line 300, characters outside `"1"` through `"6"` are rejected. The four-character limit at 310 comes next. Only a valid digit with room available reaches `LET g$=g$+k$`, which joins it onto the end.

LEN counts characters. Enter checks that the length is exactly four before confirming the guess. The `<>` operator means “not equal”. A short guess stays available to finish; an ignored key does not use a space.

## Erase and redraw

Line 350 keeps the slice from the beginning of g$ through its penultimate character. Omitting the start before TO means position 1. With one character left, the slice ends at 0 and becomes empty. The length check prevents trying to shorten an already empty string.

The drawing routine first prints all four underscores. Its FOR loop then visits each entered character, with i starting at 1 and NEXT advancing it. `g$(i)` selects that character. The column expression `5 +2 *i` gives 7, 9, 11 and 13: multiply first, then add. Each digit covers one underscore with white ink on blue paper. Drawing the underscores again removes an erased digit too.

## Wait for release

The routine at 9000 waits while INKEY$ is non-empty. The main loop visits it before reading another command. A recognised press therefore changes the guess once, even when held. Release the key before pressing the next one.
