Lines 50–120 add the title screen: the game name, the rules, and — crucially — the bull/cow definitions. "Bull: right digit, right place. Cow: right digit, wrong place." Without these definitions, a new player would not know what the clues mean. The title screen teaches the game's language.

Lines 170–180 (the debug code display) are removed. The code is now truly hidden. The player sees only the clues.

## The moment it becomes real

Every unit so far has shown the code on screen. That was deliberate — you needed to verify the bull and cow counts by hand. "The code is 3251, I guessed 3146, I got 1 bull and 1 cow — is that right?" With the code visible, you could check.

Now the code is invisible. The game is real. The player cannot verify the clues — they must trust them and reason from them. The transition from debugging to playing is one deleted line.

This is also why the title screen explains the terminology. In previous games, the rules were simple enough to discover by playing (press H or L, hold SPACE). Locksmith's clue system is not obvious — the player needs to be told what "bull" and "cow" mean before they see their first clue. The title screen is not decoration; it is prerequisite knowledge.
