The practice caption disappears. Each round has four digits from 1 to 6, with repeats allowed. The code remains unchanged while you guess. Four EXACT opens the lock; ten unsuccessful guesses leave it locked. Both endings reveal the answer and keep the history visible.

## Choose each position separately

RND supplies a pseudo-random value from zero up to, but not including, one. Multiplying by six spreads it over the interval from zero to just below six. INT rounds down to 0–5, then adding one gives 1–6.

Line 210 performs that draw for each of the four positions. No test rejects duplicates, so codes such as 1111 and 6262 are allowed. There are six choices for each position: `6 * 6 * 6 * 6`, or 1,296 possible codes.

RANDOMIZE without a number seeds the generator from the machine's frame counter. It does not promise that every round differs from the last. The code is chosen at 200–210; the normal guess loop goes back to 230 and never chooses it again.

<Question prompt="Why would returning to line 200 after every submitted guess break the deduction game?">

It would choose a new code and clear the round. Earlier clues would no longer describe the same answer. Deduction depends on a fixed secret until the round ends or the player asks for a new one.

</Question>

## Check success before the limit

After drawing the latest result, line 430 tests bulls. Four exact matches jump to the OPEN message. Only an unsuccessful guess reaches the ten-attempt test at 440. This order means a correct tenth guess wins.

The result routines join at 5200, which clears the advice row and reveals c. The result loop accepts R or Q; it does not let another guess overwrite the finished history. R during play also abandons that round and starts a new code at 200.

Try a round using the clues together. For a predictable limit check, submit 1111: if it opens, restart; otherwise repeat that same unsuccessful guess until attempt ten. The clues should remain identical and the round should end locked. Repetition still consumes an attempt. Then press R and check that the old rows and editable guess have cleared.

If the answer changes during a round, inspect the jumps to 200. If a correct tenth guess loses, inspect the order of 430 and 440. There is no time limit: the interesting pressure comes from choosing how to spend ten guesses.
