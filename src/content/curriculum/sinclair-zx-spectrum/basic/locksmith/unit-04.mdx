Bulls tell the player what is in the right place. Cows tell them what is in the code but at the wrong position. Together, the two clues are enough to deduce the code.

Lines 310–400 use the **digit-counting method**. For each possible digit (1 through 6), count how many times it appears in the code (`cc`) and how many times in the guess (`gc`). The smaller of the two is the number of "matches" for that digit — you cannot match more digits than exist. Add those minimums across all six digits and you get `total`: the number of digits in the guess that appear somewhere in the code, regardless of position. Line 410 subtracts the bulls: `LET cows = total - bulls`. What remains are the digits that are present but misplaced.

## Why not just scan?

The obvious approach is: for each guess digit, scan the code for a match. But that over-counts when digits repeat. If the code is `1555` and you guess `5555`, a simple scan would find a match for all four guess digits — but the code only has three 5s and one 1. The correct answer is 3 bulls and 0 cows, not 3 bulls and 1 cow.

The digit-counting method handles repeats correctly because it counts how many of each digit exist in each sequence and takes the minimum. For digit 5: code has 3, guess has 4, minimum is 3. For digit 1: code has 1, guess has 0, minimum is 0. Total matches: 3. Subtract 3 bulls: 0 cows.

## Try it

Type the code exactly — four bulls, zero cows. Rearrange the digits — zero bulls, four cows. Mix right and wrong digits — watch the bull and cow counts move independently. Each guess gives you two numbers, and together they narrow the search.
