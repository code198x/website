## Save the program

Quit with Q and prepare your emulator's tape recording controls. Enter this command without a line number:

```basic
SAVE "locksmith" LINE 10
```

The name identifies the program; LINE 10 supplies the starting point when it loads. Follow [Keep a copy outside the Spectrum](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) for recording and exporting the tape file.

A BASIC program save can include its variables, but this starting point deliberately creates a new game. It is not a way to resume an unfinished deduction. An emulator save state has a different purpose: it preserves the machine session.

## Load and play from the beginning

Open a fresh 48K Spectrum session, attach the exported tape and start playback with the emulator's controls. Enter:

```basic
LOAD "locksmith"
```

The title should appear after loading. Start with S and enter a guess. Check deletion and a short submission, finish a round, then use R to begin again. The old history should disappear. Quit with Q and use RUN to return to the title.

If the loader keeps waiting, check the attached tape, playback and program name. If the listing loads without starting, check whether you saved it with LINE 10. RUN will start a correctly loaded program, but repeat the save and fresh-load check to verify the automatic start too.

<Question prompt="The tape loads and the title appears. Have we also checked that replay clears the old clues?">

No. Automatic loading checks the entry point. Starting, playing and replaying exercise later paths. A finished game needs those paths to agree about what belongs to a round: a fresh code, attempt 1, an empty editable guess and a cleared history.

</Question>

## Explain one clue

Choose a submitted guess and explain its result after the code is revealed. First compare the four positions. Then count each digit on both sides, add the smaller counts and subtract the exact matches. EXACT plus OTHER must never exceed four.

You can now follow the whole journey: a key becomes a character, four characters become numeric values, two counts become a clue, and several clues become evidence for a decision. Keep the working tape so any experiment starts from a game you can recover.
