Try 2211. Expect 0 EXACT and 4 OTHER. The visible practice code and single result row remain; each submission still replaces that row and leaves its guess editable.

## Count what each side can supply

For each digit from 1 to 6, count its occurrences in the code and in the guess. Only the smaller count can contribute matches.

For code 1122 and guess 1111, the counts are:

| Digit | In the code | In the guess | Available matches |
| --- | --- | --- | --- |
| 1 | 2 | 4 | 2 |
| 2 | 2 | 0 | 0 |
| 3–6 | 0 | 0 | 0 |

The four guessed ones cannot all match when the code supplies only two. The total is 2. Both matches are already EXACT, so OTHER is 0.

## Two loops, two questions

The outer loop chooses a digit d, from 1 through 6. At 3040, cc and gc are cleared for that digit. The inner loop then visits all four positions, counting code occurrences in cc and guess occurrences in gc. NEXT i finishes that scan before NEXT d chooses another digit.

Lines 3090 and 3100 add the smaller count to total. When cc equals gc, only the first test succeeds: it uses `<=`, while the second uses `<`. Equal counts are added once.

This total includes correct digits in correct positions. We have already counted those in bulls, so `cows = total - bulls` leaves the OTHER count. The names bulls and cows stay inside the program; the screen explains their meanings as EXACT and OTHER.

<Question prompt="Why would comparing each of the four guessed ones with every code digit give a bad answer for 1111 against 1122?">

The same two code occurrences would be reused for several guessed ones. Even a search that stops at the first matching code digit for each guessed one would incorrectly award four matches. Counting the available occurrences caps the contribution at two. Subtracting the two exact matches then leaves zero other matches.

</Question>

## Check both kinds of clue

Try these guesses against the unchanged 1122 code:

| Guess | EXACT | OTHER |
| --- | --- | --- |
| 1111 | 2 | 0 |
| 2211 | 0 | 4 |
| 1212 | 2 | 2 |
| 1234 | 1 | 1 |
| 1112 | 3 | 0 |
| 3456 | 0 | 0 |

For 1234, the shared digits are one 1 and one 2. Only the 1 is correctly placed. For 1112, the available matches are two ones and one two; all three are already exact.

If a repeated guess changes its clues, check the resets at 3000 and 3040. If EXACT plus OTHER exceeds four, check the two smaller-count tests. Colours and printed characters take no part in these calculations.
