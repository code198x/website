The Oracle always says YES. That is not much of a fortune teller. But the shape is right: ask a question, get an answer.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-oracle-stone/unit-01/ask.bas" />

Run it. Type a question — anything. The Oracle responds: YES.

The program ignores your question entirely. It does not read `q$`, does not check any words, does not think. It just prints YES. The question goes into a variable and is never used.

That is the secret of every fortune-telling program: **the question does not matter**. The ceremony of asking is what makes the answer feel meaningful. The player chooses to believe the Oracle answered *their* question, even though the Oracle never heard it.

Try changing the answer. "The Oracle says... MAYBE" or "The Oracle says... DON'T COUNT ON IT." Each answer changes the Oracle's personality without changing how the program works.
