Oracle Stone is not a game — it is a toy. Ask a question, watch the Oracle think, read the answer. The answer is random, but the ceremony of asking makes it feel deliberate.

<Figure src="/images/sinclair-zx-spectrum/basic/game-03-oracle-stone/unit-09/screenshot.png" alt="Blue ZX Spectrum chamber screen: a centred title, cyan block bars, and a cyan answer" caption="Where you are headed: the Oracle's chamber delivers its verdict." />

No new BASIC commands here. Everything you need — `IF/THEN`, `RND`, `PRINT`, `INPUT` — you learnt in Lucky Number. Oracle Stone is about using those tools in a new pattern: chaining `IF/THEN` on a random number to select from a set of pre-written answers.

**What you will learn:**

- Chained `IF/THEN` — selecting from a fixed set
- `PAUSE` and `BEEP` for dramatic timing
- `INK` and `PAPER` for atmosphere
- The design concept: **Chance** — the program decides

**9 units. About 5–7 hours.**
