Line 70 picks a random number from 1 to 6. Lines 80–130 each check whether `r` matches their number — exactly one of them will be true, so exactly one answer prints.

Run it several times. YES, then DEFINITELY NOT, then PERHAPS. The Oracle gives different answers to the same question. You wrote every possible answer, but the player does not know which one is coming. That gap between what you wrote and what the player sees is **Chance** — the design concept for this game.

## The chained IF pattern

This is a new pattern, not a new command. You already know `IF/THEN` and `RND` from Lucky Number. What is new is using them *together* to select from a fixed set:

```
LET r = INT (RND * n) + 1
IF r = 1 THEN ...
IF r = 2 THEN ...
IF r = 3 THEN ...
```

Each `IF` line is a slot. The random number picks which slot fires. Add more slots to add more answers — just increase the range in the `RND` formula to match.

This pattern is simple, readable, and easy to extend. Later games will use arrays and DATA/READ for the same job, but the chained-IF version works perfectly when the set is small and each answer is a single line.

## Try it

Change the answers. Write them in the Oracle's voice — mysterious, vague, slightly pompous. "THE STARS SAY YES" sounds like an Oracle. "YES" sounds like a computer.
