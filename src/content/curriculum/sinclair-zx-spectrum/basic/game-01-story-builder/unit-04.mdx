Lines 60 and 70 ask for a place and a food. Lines 120 and 130 weave them into the output: the animal is hiding somewhere, and somebody fed it something.

Run it. Type "Dave", "enormous", "penguin", "Tesco", "cheese". The screen shows:

```
Dave found a enormous penguin
hiding in Tesco.
They fed it cheese.
```

## What changed

Four new lines: 60, 70, 120, 130. Line 110 changed its text slightly — "met" became "found" because the story now has a setting, not just a meeting. Everything else is the same program you had before.

Five variables now: `n$`, `a$`, `b$`, `p$`, `f$`. Each INPUT stores one word. Each PRINT uses them to build a sentence. The program is starting to feel like something.
