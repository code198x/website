One line. That is all it takes.

Type this in and press `RUN` (or type `RUN` and press Enter). The screen prints `Hello`. You have written a program.

It does not look like much. But something just happened: you told the computer what to say, and it said it. That relationship — you write, it obeys — is what programming is. Everything else is detail.

## Try changing it

Change the word inside the quotation marks. Type:

```
10 PRINT "Goodbye"
```

Press Enter, then type `RUN`. The old line 10 is replaced. The computer now says `Goodbye`. You did not need to start over — you just replaced the line.

Line 10 clears the screen with `CLS` — everything disappears before the new text prints. Lines 20, 30, and 40 each print a message. They run in order: 10, 20, 30, 40. The line numbers decide the order, not the order you typed them in.

Try adding a line between two existing ones:

```
25 PRINT "---"
```

Type `RUN`. The dashes appear between "Welcome to the Spectrum" and "Your first program." The computer sorts the lines by number and runs them in order.

## What you have built

Two BASIC commands:

- **PRINT** puts text on the screen. Whatever you put between the quotation marks appears exactly as you wrote it.
- **CLS** clears the screen. Without it, new text appears below whatever was already there.

And one editor skill: replacing a line by typing its number again. The Spectrum's editor is built around line numbers — you will use this constantly.

Your program speaks. Next, it listens.
