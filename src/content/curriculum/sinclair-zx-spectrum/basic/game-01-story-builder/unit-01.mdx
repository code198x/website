One line. That is all it takes.

Type this in and press `RUN` (or type `RUN` and press Enter). The screen prints `Hello`. You have written a program.

It does not look like much. But something just happened: you told the computer what to say, and it said it. That relationship — you write, it obeys — is what programming is. Everything else is detail.

## Try changing it

Change the word inside the quotation marks:

```
10 PRINT "Goodbye"
```

Press Enter, then type `RUN`. The old line 10 is replaced. The computer now says `Goodbye`. You did not need to start over — you just replaced the line.

## More to say

What if you want several lines of text? Try this:

```
10 CLS
20 PRINT "Welcome to the Spectrum"
30 PRINT "Your first program"
40 PRINT "is running right now"
```

`CLS` clears the screen — everything disappears before the new text prints. Lines 20, 30, and 40 each print a message. They run in order: 10, 20, 30, 40. The line numbers decide the order, not the order you typed them in.

Try adding a line between two existing ones:

```
25 PRINT "---"
```

Type `RUN`. The dashes appear between the first and second message. Line 25 runs after line 20 and before line 30. Line numbers are how the Spectrum knows what comes next.

This is why programs number their lines in tens rather than ones: it leaves room to slip a line in between. We will lean on that habit all through Story Builder — every gap in the numbering is space held open for something a later unit adds.
