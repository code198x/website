## How It Works

Your first Spectrum program isn't a toy example — it's a real game. You type the whole thing in before you understand any of it, just like millions of children did with magazine listings in the 1980s. Then, over the following units, you learn how it works by taking the game logic apart: variables, input, decisions, loops, and random numbers. Each concept is understood through its visible effect on the running game.

## What You'll Learn

- **PRINT** — putting text on screen
- **LET** — storing values in variables
- **INPUT** — asking the player a question
- **IF/THEN** — making decisions
- **GO TO** — loops that keep the game running
- **RND** — random numbers
- **REM** — comments for the programmer

## Prerequisites

None. This is the beginning.
