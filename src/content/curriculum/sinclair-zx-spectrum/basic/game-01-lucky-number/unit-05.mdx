The program from the last unit knows when the guess is right and when it's wrong. But "Wrong!" isn't very helpful. A guessing game should tell you *which way* you're wrong — is the secret number higher or lower than your guess?

You need two new comparisons: `<` (less than) and `>` (greater than).

## Three Possible Outcomes

Every guess has exactly three possible outcomes:

1. The guess equals the secret number — correct
2. The guess is less than the secret number — too low
3. The guess is greater than the secret number — too high

## How the Comparisons Work

The Spectrum checks each `IF` line in order:

- **Line 30** — `IF g = n` — is `g` equal to `n`? If the guess is 3 and the secret is 7, no. Skip this line.
- **Line 40** — `IF g < n` — is `g` less than `n`? 3 is less than 7, yes. Print "Too low!" and move on.
- **Line 50** — `IF g > n` — is `g` greater than `n`? 3 is not greater than 7, no. Skip this line.

Only one of the three conditions can be true for any guess. The other two lines are skipped.

Here are all the comparison operators you've seen so far:

| Symbol | Meaning |
|--------|---------|
| `=` | Equal to |
| `<>` | Not equal to |
| `<` | Less than |
| `>` | Greater than |

There are two more you might use later: `<=` (less than or equal to) and `>=` (greater than or equal to). But you won't need them for this game.

## Almost a Game

Look at what you have. The program:

1. Stores a secret number
2. Asks for a guess
3. Tells you if you're correct, too high, or too low

That's most of a guessing game. The one thing missing: it only lets you guess once. After the first guess the program ends. You have to type `RUN` to try again, and you already know the number is 7.

In the next unit, you'll fix that. You'll make the program loop back and ask again after a wrong guess, so the player can keep guessing until they find it.

## Try This

**Change the secret number.** Set `n` to something bigger — `LET n = 50`. Run it a few times with different guesses. The feedback still works because the comparisons are between `g` and `n`, not hard-coded numbers.

**Narrow it down.** Play the game properly with a friend. One of you sets the secret number, the other guesses. Even without looping, you can type `RUN` between guesses. How many guesses does it take to find a number between 1 and 100?

**Add all six comparisons.** Just to see them, try `PRINT 5 < 10`. The Spectrum prints `1` — that means true. Try `PRINT 5 > 10`. It prints `0` — false. Every comparison produces `1` (true) or `0` (false).

## What You've Learnt

- **`<` (less than)** — true when the left side is smaller than the right
- **`>` (greater than)** — true when the left side is larger than the right
- **Three-way check** — one IF line for each possible outcome (equal, less than, greater than)
- **Only one is true** — for any two numbers, exactly one of `=`, `<`, `>` is true
- **The game so far** — secret number, input, and feedback all work; it just needs to loop
