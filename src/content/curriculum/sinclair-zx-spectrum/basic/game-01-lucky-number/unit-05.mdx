Your programs so far run every line, every time, in order. Nothing is skipped. Nothing depends on anything. The program does the same thing no matter what the player types.

Lucky Number is different. It looks at your guess and decides: is it too high, too low, or exactly right? Three possible outcomes from the same input. The computer chooses which one to show you.

That's `IF/THEN`.

Line 40 uses `<>`, which means "not equal to". If `g` is anything other than `n`, it prints "Wrong!".

## Comparisons

The part between `IF` and `THEN` is a **comparison**. It asks a yes-or-no question about two values:

- `g = n` — is g equal to n?
- `g <> n` — is g not equal to n?
- `g < n` — is g less than n?
- `g > n` — is g greater than n?

If the answer is yes, the command after THEN runs. If no, the Spectrum skips to the next line. That's all IF/THEN does — run or skip, based on a question.

## What You've Learnt

- **IF/THEN** runs a command only when a condition is true
- **Comparisons** ask yes-or-no questions: `=`, `<>`, `<`, `>`
- The Spectrum checks the condition and either **runs** or **skips** the command after THEN
- **Only one condition** can be true at a time for `<`, `=`, and `>`
- The higher-or-lower logic is just three IF/THEN lines
