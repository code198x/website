The higher-or-lower program from the last unit has a problem. It asks one question, gives one answer, and stops. To play again, you have to type `RUN`. That's not a game — it's a quiz with one question.

A game keeps going. It asks, you answer, it responds, and it asks again. The loop is what makes it a game.

## One Line Changes Everything

Type `NEW`, then this version:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-06/with-loop.bas" />

The difference is two lines. Line 60: `GO TO 20`. Line 30 now says `GO TO 70` instead of printing directly.

`GO TO` jumps to a line number. When the Spectrum reaches line 60, it doesn't continue to line 70 — it jumps back to line 20 and asks for another guess. The program loops: ask → check → respond → ask → check → respond → ask...

Line 30 is the exit. When the guess equals the secret number, `GO TO 70` jumps past the loop to line 70, which prints "Correct!" and the program ends naturally.

Type `RUN` and play. Guess high, guess low, narrow it down.

Each guess adds a line of feedback to the screen. The program keeps asking. You can see the trail of your thinking: too high, too low, too low, too high — getting closer each time.

Find the number and the loop ends:

![Correct! — the program exits the loop](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-06-going-round-again/correct.png)

"Correct!" appears and the program stops at `0 OK, 70:1`. The loop ran five times. Each time, the Spectrum checked three conditions, printed the matching response, and jumped back to line 20. On the fifth guess, the condition on line 30 was true, so it jumped to line 70 instead — out of the loop.

Seven lines. That's a complete guessing game.

## Two Uses of GO TO

This program uses GO TO for two different purposes:

- **Line 60** loops back — `GO TO 20` sends the program to the beginning of the guess cycle. This creates repetition.
- **Line 30** branches forward — `GO TO 70` skips the loop and jumps to the ending. This creates an exit.

Looping and branching. Most programs use GO TO for one or both.

## STOP and CONTINUE

Sometimes you want to pause a running program to see what's happening. Two commands help:

**STOP** halts the program deliberately. If you add `STOP` to a line, the program pauses there and shows `9 STOP statement`. You can then examine variables by typing `PRINT n` or `PRINT g` at the command prompt.

**CONTINUE** resumes from where the program stopped. Type `CONTINUE` (or just press `C` in K mode) and the program picks up where it left off.

**BREAK** (CAPS SHIFT + SPACE) is the emergency exit. If a program loops forever and won't stop, BREAK forces it to halt. You can then type CONTINUE to resume, or RUN to restart.

## What You've Learnt

- **GO TO** jumps to a line number — the program continues from there
- **Loops** repeat code — `GO TO` a lower line number creates a loop
- **Branches** skip code — `GO TO` a higher line number jumps forward
- **A loop with an exit** is the structure of every game — repeat until done
- **STOP** pauses the program, **CONTINUE** resumes, **BREAK** forces a halt
