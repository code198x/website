Lucky Number is about 170 lines long. Most of them are still a mystery. But you don't need to understand all of them to start changing what the game does. You just need one command: `PRINT`.

## Start Fresh

Type `NEW` and press ENTER. This wipes the program from memory — a clean slate. (Don't worry, you can type Lucky Number back in later, or load it from tape.)

Type this and press ENTER:

Now type `RUN` (press `R` in K mode) and press ENTER.

![Hello on screen](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02-your-first-program/hello.png)

One word appears at the top of the screen: **Hello**. Below it, `0 OK, 10:1` — the Spectrum telling you the program finished without errors, at line 10, statement 1.

That's a complete program. One line. It does one thing: puts text on the screen.

## What Just Happened

`PRINT` is a command. It tells the Spectrum to display something. The text after it — `"Hello"` — is called a **string**. A string is any text inside quotation marks. The Spectrum displays whatever is between the quotes, exactly as you wrote it.

Try changing the string. Type this line and press ENTER:

```
10 PRINT "Goodbye"
```

You don't need to delete the old line 10 first. When you type a new line with the same number, it replaces the old one. Now type `RUN` — you'll see "Goodbye" instead of "Hello".

The line number decides the order. The text inside the quotes decides what appears. Change the text, change the output.

Type `LIST` (press `K` in K mode) and press ENTER to see your program. The Spectrum shows all the lines you've typed, in order. This is useful when you need to check what you've entered.

## Comments

Some lines in Lucky Number start with `REM`:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02/with-rem.bas" />

`REM` stands for "remark". The Spectrum ignores everything after `REM` on that line — it's a note for the programmer, not an instruction for the computer. Type this program and `RUN` it. The output is the same as before: "Hello" and "I am a ZX Spectrum". The REM line is invisible to the computer.

Comments are useful in longer programs. Lucky Number has comments like `REM === Rainbow cascade ===` and `REM === Guess loop ===` — they mark where each section of the program begins, making it easier to find your way around.

"Too warm!" instead of "Too high!". "Too cold!" instead of "Too low!". "NAILED IT!" instead of "YOU GOT IT!". The game plays exactly the same — the logic hasn't changed. Only the strings have changed, and the strings are what you see on screen.

What you just changed is the game's **feedback** — how it communicates with the player. "Too high" and "Too warm" carry the same information, but they feel different. The words you choose shape the player's experience. Game designers think carefully about this: every message is a conversation between the game and the player.

You changed a running game by editing three lines. Every string in quotation marks is yours to rewrite. Try others: the "Incredible!" and "Impressive!" messages on lines 980 and 990. The "Guesses:" label on line 460. The "Temperature:" label on line 470. The INPUT prompt on line 530. Each one is a string, and each one is yours.

## What You've Learnt

- **PRINT** displays text on screen
- **Strings** are text inside quotation marks — `"Hello"`, `"Too warm!"`, `"NAILED IT!"`
- **Line numbers** determine the order — the Spectrum runs lines from lowest to highest
- **Replacing a line** is as simple as typing a new line with the same number
- **REM** is a comment — the computer ignores it, but it helps the programmer
- **LIST** shows your program, **NEW** clears it, **RUN** runs it
