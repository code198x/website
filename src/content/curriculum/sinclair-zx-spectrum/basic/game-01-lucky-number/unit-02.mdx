In the last unit you printed text — strings between quotation marks. But a guessing game needs numbers, and those numbers need to change. You need somewhere to store them.

That's what a **variable** is. A name that holds a value.

## Your First Variable

Type this program and run it:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02/let.bas" />

![The number 5 printed on screen](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02-giving-things-names/let.png)

The Spectrum prints `5`. Not the letter "a" — the value that `a` is holding.

Here's what happened:

- **Line 10** — `LET a = 5` creates a variable called `a` and stores the number 5 in it. Think of it as a labelled box: the box is called `a`, and inside it is `5`.
- **Line 20** — `PRINT a` looks up the value in `a` and prints it. No quotation marks around `a` — that's important. `PRINT "a"` would print the letter a. `PRINT a` prints whatever number `a` is holding.

## Change the Value

Now change line 10:

```basic
10 LET a = 42
```

Run it again. The Spectrum prints `42`. The variable `a` holds whatever you last put in it.

Try `10 LET a = 0`. Try `10 LET a = 99999`. The variable holds the new value each time. One box, different contents.

## Longer Names

Variable names don't have to be single letters. Try:

```basic
10 LET score = 0
20 PRINT score
```

The Spectrum prints `0`. The variable is called `score` — a name that tells you what the number means. Longer names are easier to read when programs get bigger.

Any name starting with a letter works. `score`, `lives`, `x`, `guess`, `n` — you choose. The Spectrum doesn't care what you call them, but you will when you're trying to read your own code.

## Arithmetic

Variables aren't just boxes for storage. You can do maths with them:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02/arithmetic.bas" />

![13, 7, and 30 printed on screen](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-02-giving-things-names/arithmetic.png)

Three lines of output: `13`, `7`, `30`. The Spectrum adds, subtracts, and multiplies the values in `a` and `b`.

The operators:

| Symbol | Meaning |
|--------|---------|
| `+` | Add |
| `-` | Subtract |
| `*` | Multiply |
| `/` | Divide |

You can mix variables and numbers in the same expression: `PRINT a + 1` works. So does `PRINT a * b + 10`. The Spectrum follows the usual rules — multiplication before addition — but brackets override everything: `PRINT (a + b) * 2`.

## Strings vs Numbers

Notice the difference:

- `PRINT "Hello"` — quotation marks, prints the text literally
- `PRINT a` — no quotation marks, prints the value stored in the variable

If you type `PRINT "a"` you get the letter `a`. If you type `PRINT a` you get whatever number `a` holds. The quotation marks are the signal: inside quotes means text, outside quotes means look it up.

## Try This

**Temperature.** Store a temperature in a variable and print it. Change it from Celsius to Fahrenheit using `LET f = c * 9 / 5 + 32`.

**Two variables, one answer.** Set `LET width = 8` and `LET height = 5`. Print `width * height`. You've just calculated the area of a rectangle.

**What happens with no LET?** Try `PRINT z` without ever setting `z`. The Spectrum prints `0` — every variable starts at zero until you put something in it.

## What You've Learnt

- **LET** — stores a value in a variable (`LET a = 5`)
- **Variables** — named storage; single letters (`a`) or words (`score`) both work
- **PRINT with variables** — no quotation marks; prints the value, not the name
- **Arithmetic** — `+`, `-`, `*`, `/` work on variables and numbers
- **Strings vs variables** — quotation marks mean text; no quotes means look up the value
