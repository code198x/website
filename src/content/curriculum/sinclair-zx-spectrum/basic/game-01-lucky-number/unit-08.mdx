Your guessing game works, but there's a problem. The secret number is always 42. Once you know the answer, the game is over forever. A guessing game that never changes isn't a game — it's a memory test.

Lucky Number picks a different number every time. The last piece of the puzzle is `RND`.

## Random Decimals

`RND` gives a random number between 0 and 1. Not a whole number — a decimal, like 0.2691803 or 0.7438152. A different value each time.

Try this program — it shows four steps from raw randomness to a useful number:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-08/building-up.bas" />

![Four values: a decimal, times 100, rounded down, plus 1](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-08-a-different-number/building-up.png)

Four lines, four transformations:

1. **RND** — a random decimal between 0 and just under 1 (e.g. `0.2691803`)
2. **RND\*100** — scale it up to between 0 and just under 100 (e.g. `18.934631`)
3. **INT(RND\*100)** — round down to a whole number, 0 to 99 (e.g. `20`)
4. **INT(RND\*100)+1** — shift the range up by one, giving 1 to 100 (e.g. `15`)

`INT` rounds down to the nearest whole number. `INT(3.7)` gives 3. `INT(99.9)` gives 99. Combined with `RND`, it produces a whole number in whatever range you need.

Run the program several times. The numbers change each time — that's randomness at work.

## RANDOMIZE

There's one catch. If you turn the Spectrum off and on again, `RND` produces the same sequence of numbers. The Spectrum starts from the same seed every time.

`RANDOMIZE` fixes this. It seeds the random number generator from the Spectrum's internal frame counter — a value that changes every 1/50th of a second. Since you'll start the program at a slightly different moment each time, the seed is different, and the sequence of random numbers is different.

Put `RANDOMIZE` at the start of the program, before the first `RND`. One line, and every game is truly different.

## The Full Picture

Go back to Lucky Number — the full program you typed in Unit 1. Read through the game logic lines:

- **Line 20:** `RANDOMIZE` — seed the generator
- **Line 310:** `LET n=INT(RND*100)+1` — pick the secret number
- **Line 320:** `LET c=0` — reset the counter
- **Line 510:** `LET c=c+1` — count each guess
- **Line 530:** `INPUT "Your guess? ";g` — ask for a guess
- **Line 570:** `IF g=n THEN GO TO 800` — branch to win
- **Line 700:** `IF g<n THEN...` — too low
- **Line 710:** `IF g>n THEN...` — too high

## What You've Learnt

- **RND** gives a random decimal between 0 and just under 1
- **RND\*100** scales it to 0-99.999...
- **INT** rounds down to a whole number
- **INT(RND\*100)+1** gives a random whole number from 1 to 100
- **RANDOMIZE** seeds the generator so each run is different
