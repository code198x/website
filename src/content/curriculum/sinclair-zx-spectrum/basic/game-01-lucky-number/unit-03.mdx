Lucky Number picks a secret number and remembers it. It counts your guesses — 1, 2, 3, 4 — and tells you the total when you win. How does it remember? Where does the number go between guesses?

The answer is **variables**.

## Names and Values

A variable has two parts: a **name** and a **value**. `LET n = 42` creates a variable named `n` with the value `42`. You can use any single letter as a variable name — `n`, `g`, `c`, `d`, `x`, `y`. The name is just a label. What matters is the value it holds.

You can print a variable alongside text by separating them with a semicolon:

## Changing a Variable

Here's the key idea. A variable can change:

```
10 LET c = 0
20 LET c = c + 1
```

Line 10 sets `c` to 0. Line 20 says: take the current value of `c` (which is 0), add 1, and store the result back in `c`. Now `c` is 1. If you run line 20 again, `c` becomes 2. Then 3. Each time, it takes the old value, adds 1, and stores the new value.

This is counting.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-03/counting.bas" />

![Guess number 1, 2, 3](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-03-remembering-things/counting.png)

Each time `LET c = c + 1` runs, `c` goes up by one. Each `PRINT` shows the new value. The variable remembers the count between lines.

## How Lucky Number Uses Variables

Look at these lines from the game:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-01-lucky-number/unit-03/lucky-number-variables.bas" />

Line 310 stores the secret number in `n`. (The `INT(RND*100)+1` part is how it picks a random number — you'll learn that in Unit 8.) Line 320 sets the guess counter `c` to zero.

Then, every time you guess, line 510 adds 1 to `c`, and line 520 prints the new count on screen. That's why the "Guesses:" display goes up each time — it's printing the variable `c`, and `c` gets bigger with every guess.

The game also uses `g` for your guess and `d` for the distance between your guess and the secret number. Every value the game needs to remember between one moment and the next is stored in a variable.

Game designers call this **state** — everything the game knows right now. The secret number, the guess count, the current guess, the distance. Without state, the game has no memory. It can't count, can't compare, can't progress. Variables are how a program holds state, and state is what makes a game feel like it's *paying attention*.

## What You've Learnt

- **LET** stores a value in a variable — `LET n = 42`
- **Variables** are names that hold numbers — `n`, `c`, `g`, `d`
- **PRINT** can display variables — `PRINT n` shows the value, not the letter
- **Semicolons** join strings and variables — `PRINT "Score: "; c`
- **Arithmetic** works on variables — `n + 10`, `n * 2`
- **Variables can change** — `LET c = c + 1` is how the game counts
