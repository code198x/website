Lucky Number is a guessing game. The computer picks a secret number between 1 and 100. You guess. It tells you higher or lower. ## The Spectrum Keyboard

The Spectrum keyboard works differently from a modern computer. Every key does multiple things depending on the mode:

**K mode** (keyword mode) — the cursor shows `K`. Each key types a whole BASIC keyword. Press `P` and you get `PRINT`, not the letter P. This is the mode you're in at the start of each line.

**L mode** (letter mode) — the cursor shows `L`. Keys type individual letters and numbers. You enter L mode automatically after typing a keyword, or by pressing `CAPS SHIFT` + `2` (the "Caps Lock" position).

**Symbol mode** — hold `SYMBOL SHIFT` (or `Ctrl` on most emulators) with a key to type punctuation: `SYMBOL SHIFT` + `P` gives `"`, `SYMBOL SHIFT` + `N` gives `,`, and so on.

Don't worry about memorising this now. You'll pick it up as you type. If the Spectrum types a keyword when you wanted a letter, or vice versa, just delete the line and try again. Everyone makes mistakes — that's part of the experience.

## Run It

Type `RUN` and press ENTER.

The rainbow should cascade down the screen with ascending tones. "LUCKY NUMBER" appears in coloured blocks. "Press any key" flashes. Press a key and the game screen appears — a blue frame with "LUCKY NUMBER" at the top, a guess counter, and a temperature label.

Type a number and press ENTER. Big yellow digits appear. The temperature bar fills. The border changes colour. "Too high!" or "Too low!" tells you which way to go.

![Too high — the border shifts blue, the bar is short](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-01-type-it-in/too-high.png)

![Too low — getting warmer, the bar stretches further](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-01-type-it-in/too-low.png)

Keep guessing. The temperature bar grows. The border shifts from black through blue, yellow, red, to white as you get closer. When you find the number, the screen erupts — random border colours, ascending tones, green digits, a green bar filling with a rising melody, and your rating.

![Victory — green digits, full bar, "YOU GOT IT!"](/images/sinclair-zx-spectrum/basic/game-01-lucky-number/unit-01-type-it-in/win.png)

## What Just Happened

You typed in about 170 lines of Sinclair BASIC and ran a complete game. Most of those lines are still a mystery — you don't know how the rainbow works, or how the digits are drawn, or what `GO SUB` means. That's fine. Over the next seven units, you'll learn what every piece of game logic does:

- **Unit 2:** `PRINT` and strings — the words on screen
- **Unit 3:** `LET` and variables — how the game remembers things
- **Unit 4:** `INPUT` — how the game asks you a question
- **Unit 5:** `IF/THEN` — how the game makes decisions
- **Unit 6:** `GO TO` — the loop that keeps the game running
- **Unit 7:** Combining everything into a working guessing game
- **Unit 8:** `RND` — the random number that makes every game different

The visual subroutines — the rainbow, the digits, the temperature bar — stay as black boxes for now. Each one uses a technique that gets its own game later in the curriculum. By Game 6, you'll understand every line of this program.

But right now, you've already done the most important thing: you've typed in a program and made it run. Everything else builds on that.
