RUN and choose 1, 2 and 3. The top row should contain X, O, X. The caption names the next player. Try choosing an occupied square: it must not spend a turn.

## One value changes the player

`turn` starts at 1. A legal move copies it into b(n), increments moves and draws the mark. `3 - turn` switches 1 to 2 or 2 to 1. We change turn only after an accepted move, so an ignored key cannot hand the keyboard to the other player.

The caption routine puts either `"X"` or `"O"` in t$ and prints it with the prompt. Spaces at the end erase any longer message that occupied the same row.

The cell routine now branches to line 2100 when the stored value is 2. Its eight DRAW displacements trace an octagon: a short horizontal top, diagonal corner, vertical side and so on back to the start. A second pass, shifted by one pixel, thickens it. X and O have different shapes as well as different colours.

## A full board needs a different loop

After nine accepted moves, line 330 displays the full-board message and goes to 5000. That loop listens only for R and Q. Number keys can no longer change the board. R uses RUN, which recreates the empty array and gives X the first turn again.

The routine at 7000 changes the caption; it does not change turn. Keeping that distinction makes the code easier to trace: ask which statement changes the stored value, and which merely displays it.
