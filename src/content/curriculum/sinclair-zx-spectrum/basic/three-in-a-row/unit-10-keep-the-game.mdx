Quit with Q. Follow the [Meet BASIC tape workflow](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) to prepare recording in your emulator. At the BASIC prompt enter `SAVE "three" LINE 10`. SAVE is a keyword; LINE is entered in extended mode with Symbol Shift and 3. Confirm the recording prompt when the tape recorder or emulator is ready.

`"three"` is the tape filename. `LINE 10` records the line at which execution should begin when loaded. Our line 10 clears the screen and line 20 resets the session, so loading this tape starts with a clean tally and the opening instructions.

## Check the saved copy

Use a fresh stock 48K session. Mount the saved tape, enter `LOAD ""` and start playback. Do not rely on the old program still being in memory. When loading finishes, the title should appear without an extra RUN command.

1. Press S and place a mark. Read O's reply and reason.
2. Complete a round. Leave the result visible and check the tally.
3. Press R. Check that the other side starts.
4. Restart before finishing. Check that the starter and tally stay the same.
5. Press Q. The program should stop cleanly.

If loading leaves you at a prompt instead of the title, check that the saved command included LINE 10. If you cannot find a tape file in the emulator, confirm that its recording was exported or saved to the host; a BASIC SAVE command and a durable host file are separate parts of the workflow.

<Question prompt="Why does loading the program not resume your half-played board?">

The tape starts execution at line 10. The session values are reset and line 200 creates a new empty board. This game deliberately starts afresh instead of providing a saved-match feature.

</Question>

You now have a complete small opponent: it follows rules in a clear order, explains the rule it used and leaves its mistakes open to investigation. Change a preference only after predicting which position it will affect, then replay that position to see whether the change did what you intended.
