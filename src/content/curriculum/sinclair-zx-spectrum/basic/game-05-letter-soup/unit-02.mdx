You've used strings as whole values — `LET w$="cat"`, `IF k$="3"`. But strings are made of individual characters, and Sinclair BASIC lets you pull them apart.

## Slicing

`w$(3 TO 5)` extracts characters 3 through 5 from `w$`. `w$(1 TO 1)` extracts just the first character. `w$(4 TO LEN w$)` extracts from the fourth character to the end.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-letter-soup/unit-02/slice.bas" />

From `"spectrum"`: `w$(1 TO 1)` = `"s"`, `w$(4 TO 6)` = `"ctr"`, `w$(1 TO 4)` = `"spec"`, `w$(5 TO 8)` = `"trum"`.

Letter Soup's scramble algorithm lives on string slicing. To remove a character from position `p` in string `v$`:

```
LET v$ = v$(1 TO p-1) + v$(p+1 TO LEN v$)
```

The left half (everything before position p) joined to the right half (everything after position p). The character at position p vanishes. This is how the scrambler picks random letters out of the word one at a time.

## What You've Learnt

- **`w$(a TO b)`** extracts characters a through b
- **`LEN w$`** gives the string length
- Slicing + concatenation can **remove** a character from any position
- This is the foundation of the scramble algorithm
