The scramble is the cleverest part of Letter Soup. Given a word like `"spectrum"`, produce a random rearrangement like `"mpctruse"`. Every letter appears exactly once. The order is random. The algorithm:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-05-letter-soup/unit-04/scramble.bas" />

A copy of the word goes into `v$`. Each pass: pick a random position `p`, take that character (`v$(p TO p)`) and add it to `s$`, then remove it from `v$` using slicing. Repeat until `v$` is empty. The result in `s$` is a complete shuffle.

Line 230 in Letter Soup adds a safety check: `IF s$=w$ THEN GO TO 170`. If the scrambled version happens to match the original (unlikely for long words, common for short ones like "cat" → "cat"), it rescrambles. The player should never see the answer in plain text.

This is a **Fisher-Yates shuffle** — one of the classic algorithms in computer science, adapted for strings. The principle: pick randomly from what remains, build the result one element at a time. It guarantees every possible arrangement is equally likely.

## What You've Learnt

- **Random selection + removal** shuffles a string
- `v$(1 TO p-1) + v$(p+1 TO LEN v$)` removes the character at position p
- The **safety check** prevents the scrambled version matching the original
- This is a real algorithm — Fisher-Yates shuffle — used in professional software
