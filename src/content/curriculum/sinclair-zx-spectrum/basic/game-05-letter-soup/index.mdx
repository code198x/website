Blue letter tiles appear on screen. The letters are scrambled — an ascending melody reveals them one by one. Unscramble the word. Ten rounds. Words get longer. Short words are easy. Long words are not.

## How It Works

Letter Soup teaches **content vs logic** — the most powerful insight in game development. The game's code (scramble, display, check) never changes. The content (the word list) is pure data. Edit the DATA lines and you have a completely different game — different words, different difficulty — without touching a line of code.

This is the principle behind every level editor, mod tool, and content pipeline in modern game development.

## What You'll Learn

- **String slicing** — extracting parts of strings
- **String concatenation** — building strings character by character
- **LEN** — measuring string length
- **DATA/READ** — storing content separately from code
- **STR$/VAL** — converting between numbers and strings
