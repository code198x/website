The previous four games each had a fixed experience. Lucky Number always guessed numbers. Wire Panic always defused bombs. Bright Spark always flashed panels. Hot and Cold always hunted treasure.

Letter Soup is different. Change two lines of DATA at the bottom of the program and you have a completely different game. Different words, different difficulty, different feel. The code stays the same. The content changes. That separation — content from logic — is the idea that makes games moddable, expandable, and reusable.

![Letter Soup title screen](/images/sinclair-zx-spectrum/basic/game-05-letter-soup/unit-01-type-it-in/title.png)

![Round 1 — scrambled letters on blue tiles](/images/sinclair-zx-spectrum/basic/game-05-letter-soup/unit-01-type-it-in/round.png)

Type in the listing and play ten rounds. The words start short (three letters) and grow longer (nine letters). Notice how the game feels harder without the code doing anything differently — the difficulty comes from the DATA, not the logic.

- **Unit 2:** String slicing — extracting parts of words
- **Unit 3:** DATA/READ — storing words separately from code
- **Unit 4:** The scramble algorithm — shuffling letters with slicing
- **Unit 5:** LEN and string building — measuring and constructing
- **Unit 6:** STR$ and VAL — converting between numbers and text
- **Unit 7:** Animated reveals — the ascending BEEP and letter-by-letter display
- **Unit 8:** Content vs logic — the design principle that changes everything
