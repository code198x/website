Where do the words come from? They're stored in DATA statements at the bottom of the program:

```
9000 DATA "cat","sun","bird","fish","lemon"
9010 DATA "planet","castle","trumpet","dinosaur","adventure"
```

`READ w$` pulls the next value from the DATA. The first READ gets `"cat"`. The second gets `"sun"`. Each READ moves to the next item. The DATA is a list that the program walks through.

Five words, printed in order. The FOR loop calls READ five times, pulling one word per pass. The DATA line sits at the bottom of the program, separate from the code that uses it.

This separation is the key idea. The code on lines 10-50 works with *any* five words. Change the DATA and the program displays different words without touching the loop. The code is the **logic**. The DATA is the **content**. They're independent.

In Letter Soup, the word list is the content. The scramble algorithm, the display, the scoring — that's the logic. You can make the game easier (shorter words), harder (longer words), themed (animals, countries, colours), or educational (spelling words for a class) by editing only the DATA lines. The code never changes.

## What You've Learnt

- **DATA** stores values in the program — strings, numbers, anything
- **READ** pulls the next value from DATA into a variable
- Each READ advances to the next item
- **Content vs logic** — DATA holds what varies, code handles how it works
- Changing DATA changes the game without changing the code
