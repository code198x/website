Strings grow by concatenation: `LET s$ = s$ + "x"` adds one character. `LEN s$` tells you how long the result is. Together, they let you build strings character by character — which is how the scramble algorithm constructs its output and how the letter tiles position themselves.

The tile positioning uses LEN to centre the word: `LET c = (32 - LEN s$ * 2) / 2`. A 3-letter word needs 6 columns (each letter is 2 columns wide). A 9-letter word needs 18 columns. LEN adapts the layout to the word length. The same code draws tiles for "cat" (3 tiles, centred) and "adventure" (9 tiles, spread wider). No special cases needed — LEN handles it.

`STR$` converts a number to a string: `STR$ 42` gives `"42"`. This is how the score display works: `"Score: " + STR$ sc` builds the display text by joining a label with the numeric score converted to text.

`VAL` goes the other way: `VAL "42"` gives the number 42. Together, STR$ and VAL bridge numbers and text — necessary whenever you need to display a number inside a string or parse text as a number.

## What You've Learnt

- **LEN** measures string length — essential for centring and layout
- **Concatenation** (`+`) builds strings piece by piece
- **STR$** converts numbers to strings for display
- **VAL** converts strings to numbers for calculation
- These tools make display code **adaptive** — the same code handles any word length
