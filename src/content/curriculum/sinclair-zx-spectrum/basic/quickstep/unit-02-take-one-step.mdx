Use **I** up, **J** left, **K** down and **L** right. Release between moves. **R** restores the starting board; **Q** stops the program. Reaching the exit does not win yet: we need to be able to walk away from it and inspect the drawing.

## Ask for a key

INKEY$ supplies the current key as a string, or an empty string when no key is detected. Line 210 keeps asking while that string is empty. Lines 295–298 turn a recognised direction into a signed offset: left sets dx to −1, down sets dy to 1. All other movement begins with dx=0 and dy=0.

IF executes the rest of its line only when the condition is true; otherwise execution continues at the next numbered line. OR allows either of two conditions to match. The uppercase alternatives let either case work. At the end of a move, line 470 waits while a key remains held. Only after release does line 480 return to the next command. Without that gate, the same held key could be read again immediately.

R and Q are handled before the movement offsets. R returns to initialisation; Q prints a finishing message and stops. Enter RUN at the BASIC prompt to begin again.

## Propose before accepting

The stored position is x/y. The proposed position is nx/ny. Line 300 adds the offsets without yet changing the player.

The board permits x=0..14 and y=0..2. If any of the four bounds fails, line 310 restores nx/ny to x/y. Line 340 then recognises that nothing changed and skips drawing. Trying to leave the board therefore keeps the player in its last valid cell.

x/y remain (0,2), and nx/ny are restored to (0,2). The invalid proposal must not become the stored position, even briefly: the drawing routine expects a cell on the board.

</Question>

## Put back what was underneath

An accepted move calls 3100 while x/y still describe the old cell. On the empty lane it prints two blank rows. On a dotted strip it restores g$. At the exit it restores the two green rows instead.

Only then does line 341 assign nx/ny to x/y and draw the person. The order is erase, accept, draw. If you change x/y first, the erase routine will clear the destination and leave the old person behind.

This is background restoration, not a collision test. The colours make the board readable; the coordinate comparisons decide whether a move is allowed.

Walk to every edge and press outwards once more. Then walk onto the exit, move sideways and return. The exit should remain marked and the person should leave no trail. If the exit turns into ordinary dotted ground, check line 3110 before changing the drawing routine. If a held direction repeats, check the release gate at 470.
