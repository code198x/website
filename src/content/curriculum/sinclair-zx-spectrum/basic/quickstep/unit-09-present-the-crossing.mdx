The title describes six lanes, the halfway rest and the controls. Start with S, cross or fail, then use R to replay. The movement, traffic, artwork and contact rules are the same as in the previous lesson.

## Three places to wait

The program now has three distinct loops. The title loop at 5100 waits for S or Q. The play loop at 200 polls controls, waits for the update target and advances the crossing. The result loop at 4030 listens for R or Q after the world has stopped.

These loops do not need a new state variable because the program's current control flow already selects the phase. Nothing calls the traffic update from the title or result loop.

Line 10 creates the UDGs and strings, then calls the title routine. S lets that routine RETURN. Execution continues at line 100, where arrays, lane records and starting position are established. Q jumps to the shared finishing routine instead.

The title displays “Six lanes. One halfway rest.” That describes the central resting strip between the two banks. The starting and finishing strips are safe too. The exit is the marked centre cell, not the whole top edge.

<Question prompt="Why does R return to line 100 while RUN begins with line 10?">

R resets the game state using artwork already initialised in this running program. RUN begins the complete program, creating that artwork before showing the title. A fresh load must take the complete initialisation path too.

</Question>

## Check the complete cycle

Try Q from the title, then enter RUN and start with S. During play, try R and confirm that the person and all six lane patterns return to their initial positions. Deliberately enter traffic, release your key and retry from the result.

Finally reach the exit. The success message should freeze the game. Retry once more, then quit. A held key at the result must be released before R or Q is accepted there.

<Figure src="/images/sinclair-zx-spectrum/basic/quickstep/teaching/across.png" width={352} alt="The white player at the centre exit above six traffic lanes, with the message Across! A well-timed journey." caption="The completed crossing stops the world and offers another attempt." />

If the program starts in the middle of an attempt, use RUN rather than jumping to an internal line. If the title runs into game code without S, check its return and wait branches. If vehicles continue moving behind a result, check that the result loop returns to 4030 rather than 200.

This is the complete game: six predictable lanes, one halfway rest and a marked destination. Its difficulty comes from combining the lane patterns and the two contact checks. The last lesson keeps a copy that can rebuild all of this in a fresh machine.
