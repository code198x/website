## Save from the beginning

Quit with Q. Prepare your emulator's tape recording controls, then enter this unnumbered command:

```basic
SAVE "quickstep" LINE 10
```

The name identifies the program. LINE 10 specifies where execution begins after loading. That starting point defines the artwork before showing the title and constructing the crossing.

Follow [Keep a copy outside the Spectrum](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) for the recording and file-export workflow. Keep the exported tape file somewhere you can find again.

An emulator save state preserves a machine session. A BASIC tape lets the Spectrum loader recover the program. Resuming a session halfway through a crossing does not check the program's fresh-start path.

## Start with a fresh machine

Open a fresh 48K session, attach your tape and start playback using the emulator's controls. Enter:

```basic
LOAD "quickstep"
```

After loading, the title should appear. Start with S, try a collision and retry, then complete a crossing. Finish with Q and enter RUN to return to the title.

If loading keeps waiting, check the attached file, tape playback and program name. If the listing loads but does not start, check whether the tape was saved with LINE 10; RUN can start a correctly loaded listing. If custom characters appear as letters, make sure you started at line 10 rather than bypassing the artwork loader.

## Explain a crossing

Choose one move and describe it without referring to a colour: the candidate cell, its lane, the occupied cells before movement, and whether a due vehicle reaches it afterwards. Then explain which stored values change and which drawing strings must follow them.

The picture helps you make the decision. The numeric state makes the decision precise. The countdowns decide when that state changes, while the input buffer keeps a recognised command available until the program can use it.

Keep this working tape before experimenting. Changing one lane period or phase can reshape the route through several lanes, even though each individual contact rule remains the same.
