## A cell made from four characters

The game stores x=7 and y=2. These are **logical cells**, not pixels or character positions. x counts across from 0 to 14; y counts down from 0 to 2. Each cell occupies two character columns and two character rows.

Line 3020 converts the position before printing. The upper row is `2+2*y`, the left column is `1+2*x`, and the lower row is `3+2*y`. PRINT AT takes the row first. At (7,2), our player occupies character rows 6–7 and columns 15–16. Cell (0,0) begins at row 2, column 1; cell (14,2) begins at row 6, column 29.

GO SUB calls a routine, then RETURN resumes after that call. Line 10 creates the artwork; line 180 draws the board and player. STOP prevents execution from falling through into the drawing routines again. LET assigns a value, and colons separate statements on one numbered line.

## Draw your own characters

A user-defined graphic, or UDG, is an 8×8 pattern stored as eight row bytes. USR with a letter gives its pattern address; POKE stores a byte there. Our player uses four UDGs, while the dots use one. The DATA lines contain original artwork for this game.

For a row byte, the left-to-right bit weights are 128, 64, 32, 16, 8, 4, 2 and 1. The value 31 is 16+8+4+2+1: five lit pixels at the right. The value 224 is 128+64+32: three at the left. Follow those rows in the upper halves of the person.

RESTORE 7280 positions the DATA reader. The FOR loop reads forty values, placing them at offsets 64–103 from `USR "a"`. Those offsets reserve the first eight UDG slots for the vehicles we will add later. READ takes the next DATA value; NEXT advances the loop. CHR$ converts a character code to a one-character string. Codes 152–155 select the four player characters; 156 selects the dots. h$ joins the player's upper pair, and f$ joins the lower pair.

## Give the ground a texture

g$ holds two copies of the dotted character. Line 7020 joins fifteen copies of g$ into the thirty-character strip s$. In the board routine, `STEP 2` makes j visit rows 0 and 2. Each visit prints two rows of texture.

PAPER sets the background and INK the foreground. Values 0, 1, 4, 5 and 7 give us black, blue, green, cyan and white. The player routine chooses the background for its cell; the exit uses green. Dots distinguish the safe strips, while the gap between them will carry traffic.

<Question prompt="If x changes from 7 to 8, does the player move one character column or two?">

Two. Its left column changes from 1+2*7=15 to 1+2*8=17. One logical step must move the entire two-character-wide figure to the next cell.

</Question>

If the person appears as letters, check the DATA and the loop at 7000. If the strip is too short, check that line 7020 joins fifteen pairs. RUN restarts the complete drawing after a correction.
