Slicing takes strings apart. Concatenation puts them back together.

## The + Operator

When used with strings, `+` joins them end to end. `"SPEC" + "TRUM"` produces `"SPECTRUM"`. This is called **concatenation**.

## Building Strings Character by Character

The second part of the program reverses a word by starting with an empty string and adding one character at a time:

```
70 LET d$ = ""
80 LET w$ = "HELLO"
90 FOR i = LEN w$ TO 1 STEP -1
100 LET d$ = d$ + w$(i)
110 NEXT i
```

Each pass through the loop takes one character from `w$` (starting from the end) and appends it to `d$`. After all five passes, `d$` contains "OLLEH".

This pattern — start empty, append in a loop — is exactly how the scramble algorithm builds the jumbled word. Instead of going backwards through the original, it picks random positions.

## The Scramble Pattern

Combining everything from the last three units:

1. Start with an empty result string `s$`
2. Pick a random position `p` in the temporary string `t$`
3. Append `t$(p)` to `s$`
4. Remove position `p` from `t$`
5. Repeat until `t$` is empty

Each character gets picked exactly once, producing a random rearrangement.

## What You've Learnt

- **Concatenation** — `+` joins strings: `"AB" + "CD"` produces `"ABCD"`
- **Building in a loop** — start with `""`, append one character per pass
- **The scramble pattern** — pick random, append, remove, repeat
