## How It Works

The word "SPECTRUM" is copied into a temporary string `t$`. An empty string `s$` will hold the scrambled result.

The loop runs until `t$` is empty:

1. **Line 70** picks a random position: `INT (RND * LEN t$) + 1`. If `t$` has 8 characters, this gives a number from 1 to 8.
2. **Line 80** appends that character to `s$`: `LET s$ = s$ + t$(p)`
3. **Line 90** removes it from `t$`: `LET t$ = t$(1 TO p - 1) + t$(p + 1 TO LEN t$)`

Each pass, `t$` gets one character shorter and `s$` gets one character longer. After 8 passes, all letters have moved from `t$` to `s$` in a random order.

## Walking Through an Example

Starting with `t$ = "CAT"`, `s$ = ""`:

| Pass | p | Character | s$ becomes | t$ becomes |
|------|---|-----------|------------|------------|
| 1 | 2 | A | "A" | "CT" |
| 2 | 2 | T | "AT" | "C" |
| 3 | 1 | C | "ATC" | "" |

The word "CAT" becomes "ATC". Every run produces a different result because `RND` gives different values.

## Why Copy First?

Line 30 copies the word: `LET t$ = w$`. The scramble destroys `t$` character by character — without the copy, you'd lose the original word. You need the original later to check the player's guess.

## Try This

**Scramble twice.** Run the program twice and notice the result changes each time. That's `RND` at work.

**Scramble a longer word.** Change line 20 to `LET w$ = "PROGRAMMING"` and see how 11 letters get rearranged. The longer the word, the harder it is to unscramble.

## What You've Learnt

- **The scramble algorithm** — pick random, append, remove, repeat
- **Preserving the original** — copy before scrambling with `LET t$ = w$`
- **Combining techniques** — `LEN`, `RND`, slicing, and concatenation working together
- **Loop until empty** — `IF LEN t$ = 0 THEN GO TO` as an exit condition
