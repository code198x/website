To scramble a word, you need to know how many letters it has. `LEN` tells you.

## LEN

`LEN w$` returns the number of characters in a string. "SPECTRUM" has 8 characters, so `LEN "SPECTRUM"` returns 8.

![LEN demo showing SPECTRUM=8, ZX=2, BASIC=5](/images/sinclair-zx-spectrum/basic/game-05-word-scramble/len-demo.png)

Spaces count as characters. `LEN "HI THERE"` returns 8 — five letters, two spaces, and another letter. An empty string `""` has a length of 0.

## Why LEN Matters

The scramble algorithm needs to pick a random position inside a string. If the word is "CAT" (length 3), valid positions are 1, 2, and 3. If it's "CASTLE" (length 6), positions go up to 6. `LEN` gives you the upper bound for `RND`.

You'll also use `LEN` to centre text on screen. To centre a word on a 32-column display: `(32 - LEN w$) / 2` gives the starting column.

## Try This

**Length checker.** Ask the player to type a word with `INPUT`, then print how many characters they typed. Challenge them to type the longest word they can.

**Is it short or long?** After reading the length, use `IF LEN w$ > 5` to print "That's a long word!" or "That's a short word!" based on the length.

## What You've Learnt

- **LEN** — returns the number of characters in a string
- **Spaces count** — `LEN "A B"` is 3, not 2
- **Empty strings** — `LEN ""` is 0
- **Using LEN with RND** — `INT (RND * LEN w$) + 1` picks a random position
