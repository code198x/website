Over the next eight units you'll build Word Scramble — a game where jumbled letters must be unscrambled. But first, you need to understand how the Spectrum handles text.

## Strings

A **string** is a sequence of characters — letters, numbers, spaces, punctuation. In Spectrum BASIC, string variable names end with a dollar sign: `w$`, `g$`, `name$`.

`LET w$ = "HELLO"` stores the text HELLO in `w$`. The quotes mark where the string starts and ends — the quotes themselves aren't part of the value.

## Comparing Strings

`IF g$ = w$` compares two strings character by character. They must match exactly — "hello" is not equal to "HELLO" because the Spectrum treats uppercase and lowercase as different characters.

`IF g$ <> w$` checks whether two strings are different. Between these two tests, you can handle both the correct and wrong cases.

## INPUT with Strings

`INPUT "Your guess? "; g$` works just like numeric INPUT, but stores the result as a string. The player types text instead of a number.

## Try This

**Ask for a name.** Use `INPUT "What is your name? "; n$` then `PRINT "Hello, "; n$; "!"`. Notice how semicolons join text on the same line.

**Two-word password.** Store two words in `a$` and `b$`. Ask the player for both, and only print "Access granted" if both match.

## What You've Learnt

- **String variables** — names ending in `$` hold text: `LET w$ = "HELLO"`
- **String comparison** — `=` checks for an exact match, `<>` checks for a mismatch
- **INPUT with strings** — `INPUT "prompt"; g$` reads text from the player
