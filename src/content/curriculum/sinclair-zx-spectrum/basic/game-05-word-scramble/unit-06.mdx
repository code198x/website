One word isn't a game. You need a list of words and a way to step through them, round by round.

## DATA and READ

`DATA` stores values inside your program. `READ` fetches the next value from the data list. Each `READ` advances to the next item automatically.

## How DATA Works

`DATA "CAT","DOG","SUN","RED","CUP"` stores five strings. The first `READ w$` gets "CAT", the second gets "DOG", and so on. The Spectrum keeps an internal pointer that advances after each `READ`.

DATA lines can go anywhere in the program — they're not executed as instructions. Putting them at the end keeps them out of the way.

## The Game Loop

The `FOR i = 1 TO 5` loop runs five rounds. Each round:

1. **READ** the next word from DATA
2. **Scramble** it using the algorithm from Unit 5
3. **Display** the scrambled word
4. **INPUT** the player's guess
5. **Check** whether the guess matches the original

The score variable `n` starts at 0 and increases by 1 for each correct answer. After all five rounds, the final score is printed.

## Why DATA Instead of Variables?

You could store five words in `a$`, `b$`, `c$`, `d$`, `e$` — but that doesn't scale. DATA lets you add as many words as you like without changing any code. Just add more items and increase the loop counter.

## Try This

**More words.** Add five more words to the DATA line and change the loop to `FOR i = 1 TO 10`. The program handles it without any other changes.

**Mix difficulties.** Put short words (3 letters) at the start and longer words (5-6 letters) at the end. The game gets harder as you progress.

## What You've Learnt

- **DATA** — stores values in the program: `DATA "CAT","DOG","SUN"`
- **READ** — fetches the next value: `READ w$`
- **Automatic pointer** — each READ advances to the next item
- **Scoring** — a counter variable that increments on correct answers
