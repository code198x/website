Every game so far has used single values or one-dimensional lists. This game lives on a grid.

Line 120 creates the grid: `DIM g(8,8)` — eight rows by eight columns. That is 64 cells, each holding a number. Lines 250–370 draw the grid on screen: the outer FOR loop walks rows, `PRINT AT 3 + r` positions each row, and the inner FOR loop prints eight dots — one per column. Line 240 prints column numbers above the grid.

Run it. An 8x8 grid of dots appears, each row labelled with its number. The grid is empty — every cell in `g()` holds zero, and every dot represents unexplored space.

## Two-dimensional arrays

`DIM g(8,8)` is like `DIM k(4)` from Quiz Master, but with two indices instead of one. `g(3,5)` means row 3, column 5 — a specific cell on the grid. Think of it as a spreadsheet: the first number picks the row, the second picks the column.

The nested FOR loop is the natural way to visit every cell in a 2D array. The outer loop steps through rows, the inner loop steps through columns within each row. You used nested FOR in Quiz Master (categories × questions); here it is categories × cells, but the shape is the same.
