Sonar is Battleship with a twist. Three targets hide on an 8x8 grid. You call coordinates. A hit marks the cell with a star. A miss shows a number — the distance to the nearest target. The closer the number, the warmer you are.

This is the first grid-based game. Instead of a single value or a one-dimensional list, the game state lives in a two-dimensional array — rows and columns, like a chessboard. The player thinks in coordinates, not single numbers.

**What you will learn:**

- `DIM` with two dimensions — arrays that have rows and columns
- `ABS` — absolute value, for distance calculations
- Manhattan distance — how far apart two grid positions are
- Colour as information — red for close, blue for far
- Systematic search — narrowing down a location from clues

**10 units. About 10–14 hours.**
