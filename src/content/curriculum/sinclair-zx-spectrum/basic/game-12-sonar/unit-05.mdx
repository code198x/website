Lines 470–520 find the distance to the nearest target. Line 470 starts with `dist = 99` (impossibly far). Lines 480–520 scan every cell in the grid. For each target found (`g(a,b) = 9`), line 500 calculates the distance: `ABS(r - a) + ABS(c - b)`. If this distance is smaller than the current best, it replaces it. Line 520 ends the scan (`NEXT b: NEXT a`), and line 530 caps the result: `IF dist > 8 THEN LET dist = 8`. Two cells on an 8×8 grid can be up to 14 apart, but each cell shows a single digit — and the value 9 already marks a target — so any distance of 8 or more is reported as 8.

Line 540 stores the distance in the grid: `LET g(r,c) = dist`. Line 320 in the grid drawing shows it: cells with values 1–8 print their number instead of a dot. The player now sees how far each miss was from the nearest target.

## Manhattan distance

`ABS(r - a) + ABS(c - b)` is the Manhattan distance — how many steps it takes to walk from one cell to another, moving only horizontally and vertically (no diagonals). `ABS` gives the absolute value: `ABS(3 - 7)` is 4, not -4. The distance between row 3 and row 7 is 4 regardless of direction.

The name comes from the grid layout of Manhattan streets — you cannot walk diagonally through buildings, so you add the horizontal and vertical distances separately.

## Why scan the whole grid?

There are three targets. The distance clue shows the distance to the *nearest* one, not all three. The scan checks every cell, finds each target, calculates the distance, and keeps the smallest. The `IF d < dist` comparison ensures only the minimum survives. The player sees one number — the closest target — and must triangulate from multiple probes.
