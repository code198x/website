Lines 120–122 ask for a row and column — two separate INPUTs, both numeric. Line 125 validates: if either coordinate is outside the 1–8 range, the player is sent back to try again. Line 130 echoes the coordinates. Line 140 `GO TO 75` redraws the grid.

The `GO TO 75` creates the game loop. After each probe, the screen clears and the grid redraws from scratch. The player sees the grid fresh after every move — the same CLS-and-redraw pattern from Touchdown's dashboard, but now redrawing a 2D grid instead of updating a few numbers.

## Coordinates as language

This is the first game where the player communicates in coordinates — a row number AND a column number. In Locksmith, the player typed a sequence of digits. Here they specify a location on a plane. The grid headers (row numbers on the left, column numbers on top) give the coordinate system a visual anchor — the player looks at the grid, picks a cell, reads its row and column, and types them.
