The game needs an ending beyond "you hit a mine". If the player reveals every safe cell without triggering a mine, they win.

## How It Works

**Line 60** calculates how many safe cells need revealing:

```
60 LET f = 0: LET w = 53
```

64 total cells, minus 10 mines, minus 1 (the starting cell is already revealed) = 53 cells to reveal.

**Line 290** decrements `w` on each reveal:

```
290 LET s(r, c) = 1: LET w = w - 1: BEEP 0.05, 15
```

**Line 340** checks for victory:

```
340 IF w = 0 THEN GO TO 450
```

When `w` reaches zero, every safe cell has been revealed.

## Win Screen

**Lines 460-490** display the victory:

```
470 PRINT AT 8, 8; INK 4; "YOU WIN!"
480 PRINT AT 10, 6; "All safe cells revealed"
490 BEEP 0.15, 12: BEEP 0.15, 16: BEEP 0.3, 19
```

Green text and an ascending three-note fanfare — the opposite of the descending game-over melody.

## Counting Down vs Counting Up

You could count revealed cells upward and check `IF revealed = 53`. Counting down is simpler — you just check for zero. It also means the HUD can show "safe cells remaining" without calculating the difference.

## The Flow

```
Start → w = 53 (safe cells remaining)
  ↓
Reveal → w = w - 1
  ↓
w = 0? → YES → Win!
  ↓ NO
Continue playing
```

The game has two exit paths: hit a mine (game over at line 400) or reveal all safe cells (win at line 450). Both paths display a message, play a sound, and stop the program.

## Try This

**Move counter.** Add a variable `v` that increments on every reveal. Show it on the win screen: `PRINT AT 12, 6; "Moves: "; v`. Fewer moves = better play.

**Both endings.** Play until you trigger each ending. The game-over reveal shows you where all the mines were — useful for learning.

## What You've Learnt

- **Win detection** — count safe cells down to zero
- **Two exit paths** — game over (mine) and victory (all revealed)
- **Countdown tracking** — decrement on each successful reveal
- **Victory feedback** — ascending melody as the inverse of defeat
