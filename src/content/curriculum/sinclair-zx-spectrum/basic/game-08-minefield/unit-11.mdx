Revealing cells is risky. Before pressing SPACE, the player wants to mark cells they think are mines. Press F to flag a cell — press F again to remove the flag. Flagged cells can't be accidentally revealed.

## How It Works

**Line 60** initialises the flag counter: `LET f = 0`.

**Lines 300-310** handle the F key:

```
300 IF k$ = "f" AND s(r, c) = 0 THEN LET s(r, c) = 2: LET f = f + 1: BEEP 0.05, 5
310 IF k$ = "f" AND s(r, c) = 2 THEN LET s(r, c) = 0: LET f = f - 1: BEEP 0.05, 5
```

Line 300: if the cell is hidden (0), flag it (2) and increment the counter.
Line 310: if the cell is already flagged (2), unflag it (0) and decrement the counter.

The state array `s(r,c)` now has three possible values:

| Value | Meaning | Display |
|-------|---------|---------|
| 0 | Hidden | `.` (cyan) |
| 1 | Revealed | Number or `*` |
| 2 | Flagged | `F` (green) |

**Line 280** protects flagged cells from accidental reveal. The SPACE handler checks `s(r,c) = 0` — flagged cells have state 2, so SPACE does nothing on them. The player must unflag first.

**Line 670** in the draw subroutine shows flagged cells:

```
670 IF s(y, x) = 2 THEN PRINT AT y + 2, x * 2 + 1; INK 3; "F"
```

Green `F` markers stand out against the cyan dots.

## Toggle Pattern

Flag and unflag use the same key. The current state determines the action:

```
if state = 0 → set to 2 (flag)
if state = 2 → set to 0 (unflag)
```

This is a **toggle** — pressing the same key switches between two states. BASIC doesn't have a "toggle" command, so you check both conditions separately.

## Try This

**Flag limit.** Only allow as many flags as there are mines. Add `AND f < 10` to line 300. The player can't place more flags than mines.

**Flag count display.** The HUD already shows the flag count. Try placing and removing flags — the counter should update instantly.

## What You've Learnt

- **Three-state cells** — hidden (0), revealed (1), flagged (2)
- **Toggle logic** — same key, two opposite actions based on state
- **Flag protection** — flagged cells can't be revealed by accident
- **Counter tracking** — increment on flag, decrement on unflag
