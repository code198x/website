## Taking the formula apart

`RND` gives a random decimal between 0 and 0.999...

`RND * 100` scales that to 0 up to 99.999...

`INT (RND * 100)` rounds down to a whole number: 0 to 99.

`INT (RND * 100) + 1` shifts the range up by one: 1 to 100.

That is the **range formula**: `INT (RND * range) + base`. You will use it in every game that needs a random number. Change the range and base to get different spans:

- `INT (RND * 6) + 1` — a die roll (1 to 6)
- `INT (RND * 10) + 1` — an easy guessing game (1 to 10)
- `INT (RND * 1000) + 1` — a punishing one (1 to 1000)

## Try it

Change the 100 to 10. Run it. Much easier — you can find the number in three or four guesses. Change it to 1000. Much harder — and the game suddenly feels different. One number in the formula changes the entire experience.
