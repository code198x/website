## Variables are named boxes

Think of `n` as a label on a box. `LET n = 42` writes 42 on a slip of paper and drops it in the box labelled `n`. `PRINT n` opens the box and reads what is inside.

You can change what is in the box:

```
LET n = 42
LET n = 99
PRINT n
```

This prints 99, not 42. The second `LET` replaces the old value. Only one number fits in the box at a time.

## String variables vs number variables

In Story Builder you used `n$` — a string variable that holds text. Here you are using `n` — a number variable that holds a number. The `$` is the difference. String variables hold words; number variables hold numbers. Both work with LET.
