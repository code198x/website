One line changed: `100 GO TO 60`. After the wrong-guess messages, the program jumps back to line 60 and asks again. The loop runs until the player guesses correctly — line 70 prints "Got it!" and `STOP` breaks out.

Run it. Guess wrong a few times. Watch the trail of guesses scroll up the screen. Each one narrows the range. Five or six guesses and you have it.

## The game loop

That `GO TO` line creates a **loop** — a stretch of program that repeats. The loop has:

- A **body**: lines 60–100 (ask, check, respond)
- An **exit condition**: line 70 (`IF g = n THEN ... STOP`)
- A **return**: line 100 (`GO TO 60`)

Every game has a loop. In a guessing game, the loop asks a question each time. In an action game, the loop updates the world each frame. The shape is the same: do something, check if we should stop, go round again.

## Try breaking it

Delete line 100 (type `100` and press Enter with nothing after it). Run the program and guess wrong. The program ends after one guess — no loop, no game.

Now delete line 70's `STOP` (change it to `IF g = n THEN PRINT "Got it!"`). Run it and guess correctly. The program prints "Got it!" — and then asks for another guess. Without `STOP`, the loop never ends.

Both the loop and the exit are essential. One without the other is either a single turn or an infinite loop.
