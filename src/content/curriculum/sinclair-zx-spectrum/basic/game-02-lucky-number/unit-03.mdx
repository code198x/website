Run it. The screen shows the rules, then waits: `Your guess:`. Type a number and press Enter. The program prints what you guessed and what the answer was.

You used INPUT in Story Builder with string variables (`n$`). Here it works with a number variable (`g`). No `$` on the end — so the computer expects a number, not text. If you type something that is not a number, the Spectrum will complain.

## The shape of a game

Look at the program's flow:

1. Set the secret (`LET n = 42`)
2. Tell the player the rules (`PRINT`)
3. Ask for a guess (`INPUT`)
4. Show the result (`PRINT`)

That is the skeleton of every guessing game. Right now the result just shows both numbers — it does not say whether the guess was right or wrong. That needs decisions.
