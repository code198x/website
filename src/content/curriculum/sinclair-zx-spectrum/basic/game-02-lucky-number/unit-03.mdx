Run it. The title and rules appear, then the program waits: `Your guess:`. Type a number and press Enter. The program shows what you guessed and what the answer was.

## Numbers, not text

You used INPUT in Story Builder with string variables (`n$`). Here it works with a number variable (`g`). No `$` — so the computer expects a number, not text. If you type letters, the Spectrum will complain.

## The shape of a game

Look at the flow: set the secret (line 30), show the rules (50–80), ask for a guess (120), show the result (310). That is the skeleton of every guessing game. Right now the result just shows both numbers — it does not say whether the guess was right or wrong. That needs decisions.
