Lucky Number works. It has colour, sound, and a loop. But it starts abruptly, ends abruptly, and does not tell you how well you did. This unit adds the layer that turns a working program into a game you want to show someone.

## What changed

**Title screen (lines 50–100).** A header, the rules, and `PAUSE 0` — which waits until the player presses a key. The pause creates a moment: the player reads the rules, takes a breath, then chooses to begin. That deliberate start makes the game feel *offered*, not *inflicted*.

**Guess counter (lines 40, 130).** `LET c = 0` initialises a counter. `LET c = c + 1` increments it on every guess. Line 320 shows the total: "You found it in 7 guesses." Now the player has a number to beat next time.

**Ratings (lines 340–360).** Under 5 guesses is "Incredible!" Under 10 is "Not bad!" Over 10 is "Keep trying!" The rating reframes the result — 7 guesses is not just a number, it is "Not bad!" The player feels judged (gently) and wants to do better.

**Win colour (line 300).** `BORDER 4` — green — on the winning guess. The border has been shifting all game; green at the end says "done, well done."

## The design lesson

None of these changes affect the game's *mechanics*. The guessing loop, the random number, the colour feedback, the directional sound — all unchanged. What changed is the *presentation*: how the game begins, how it ends, and what it says about the player's performance.

This layer is what game designers call **juice**: signal that is not essential but makes the essential feel alive. The game would still work without the title screen, the counter, or the ratings. It would not *feel* like a game.

Juice is not decoration. It is the difference between a program that runs and a program that *works on you*. The title screen creates anticipation. The counter creates competition (with yourself). The ratings create a goal. Each one is a small thing. Together they make the player care.

## Make it yours

Change the ratings. "Incredible" at 5 guesses assumes a 1–100 range — change the range and the thresholds should change too. Write ratings in your own voice: "Not bad for a human" or "The Oracle sees your future: more practice."

Change the title. Add your name. Add a longer set of rules. Add `INK 5` to make the title cyan. Add a second `PAUSE 0` before the ratings so the player has time to see the border turn green before the numbers appear.

Then show it to someone. Watch them play. The ratings are for them, not for you.

## What you have learnt

Across nine units, you built Lucky Number from a single `PRINT` to a complete game — random numbers, a loop, colour feedback, directional sound, a title screen, and a rating system. Every line is yours. Every design choice is yours. You understand the program because you wrote it, one piece at a time.

And two design concepts:

- **Response** — the game communicates through every channel it has: words, colour, sound. Each channel says the same thing differently.
- **Juice** — the non-essential signal that makes the essential feel alive. A game without juice works. A game with juice *works on you*.
