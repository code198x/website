Three lines do all the thinking:

- `IF g = n THEN PRINT "Got it!": STOP` — if the guess equals the secret, celebrate and stop.
- `IF g < n THEN PRINT "Too low!"` — if the guess is smaller, say so.
- `IF g > n THEN PRINT "Too high!"` — if the guess is bigger, say so.

## How IF/THEN works

`IF` checks a condition. If the condition is true, the computer does whatever follows `THEN`. If the condition is false, the computer skips to the next line.

The conditions use comparison operators:

| Operator | Meaning |
|----------|---------|
| `=` | equal to |
| `<` | less than |
| `>` | greater than |
| `<>` | not equal to |
| `<=` | less than or equal to |
| `>=` | greater than or equal to |

You can put multiple commands after THEN by separating them with colons: `PRINT "Got it!": STOP` prints the message *and* stops the program, all on the same line.

## Response gets teeth

In Unit 1, the program's response was fixed — it always said the same thing. Now the response depends on what the player did. The computer *reasons* about your input and reacts in character.

This is where the design concept **Response** becomes real: the program does not just speak, it speaks *about you*.

But the game ends after one guess. That is not a game — it is a turn. The next step makes it keep asking.
