You already know PRINT. You used it in Story Builder to put words on the screen. Now you are using it to open a game.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-lucky-number/unit-01/welcome.bas" />

Run it. A clean screen, a title, and a tease: *I'm thinking of a number...*

Nothing new here — `CLS` clears the screen, `PRINT` puts text on it, an empty `PRINT` adds a blank line. But the *tone* is different. Story Builder's opening was a greeting. This one is a challenge. The words you choose set the mood before the game even starts.

Try changing the message. "I've chosen a number and you'll never find it." "Pick a number. Any number." Each version makes a different promise to the player.
