## What You Built

A complete graphical puzzle game with these systems:

**Graphics engine:**
- Nodes drawn as circles using CIRCLE at pixel coordinates
- Connection lines drawn with PLOT and DRAW, animated incrementally
- Colour scheme: green nodes, white/cyan/magenta lines by band, yellow cursor
- Node highlighting: completed nodes turn cyan
- Full redraw after undo operations

**Input and selection:**
- QAOP nearest-node cursor navigation
- Two-phase SPACE selection (start node, end node)
- U key for undo with history stack
- H key for hint with star penalty
- B key to return to menu

**Validation:**
- Connection check against required pairs list
- Duplicate connection rejection
- Crossing detection via ATTR sampling along proposed line
- Red flash animation for rejected crossings

**Puzzle system:**
- Twenty-five puzzles across three difficulty bands
- Grid, irregular and circular node layouts
- Node positions and connections defined in DATA
- RESTORE to load puzzles by line number
- Solvability tested for every puzzle

**Scoring and progression:**
- 1-3 star rating based on undo count
- Hint usage reduces maximum stars
- Puzzle select screen with star display
- Band unlocking based on completed puzzles

**Game flow:**
- Title screen with decorative lattice pattern
- Puzzle select screen with navigation
- Gameplay with HUD status display
- Completion fanfare and star award
- Full state machine: title, select, play

**Sound:**
- Rising tone for successful connection
- Falling tone for rejection
- Multi-note fanfare for completion
- Cursor tick for movement

## What You Learned

This game introduced pixel graphics — a fundamentally different way of drawing on the Spectrum. PLOT, DRAW and CIRCLE work in pixel coordinates (256x176, origin bottom-left), while PRINT AT works in character coordinates (32x22, origin top-left). Understanding both systems and converting between them is essential for any graphical program.

The crossing detection technique — sampling ATTR values along a proposed line — turns a hardware limitation (attribute-based colour) into a useful feature. The Spectrum's colour system, where each 8x8 block shares one ink colour, provides a built-in collision detection mechanism. If a character cell has white ink, a line has been drawn through it.

Data-driven design made the puzzle system flexible. The same engine handles every puzzle. Adding or changing puzzles means editing DATA statements, not rewriting code. This separation of data and logic is a principle that scales to every kind of program.

SIN and COS appeared for the first time, used to calculate circular node arrangements. Trigonometry in BASIC is straightforward — the hard part is remembering that Sinclair BASIC uses radians, not degrees.
