When the player selects a start node, they might not remember which connections are available from it. A connection preview briefly highlights the valid end nodes, showing the player their options before they commit to an end node.

## How It Works

**Lines 90-110** trigger the preview when the player selects a start node. After locking in the start node `s`, the program calls `GO SUB 600` to highlight available connections.

**Lines 600-640** are the preview subroutine. It loops through all connection pairs. For each pair that includes node `s` and has not yet been drawn, the other node is highlighted by drawing a cyan circle over it. This shows the player which nodes they can connect to from the current selection.

**Lines 650-660** handle cleanup. When the player moves the cursor or completes the connection, the preview nodes are redrawn in their normal green colour to remove the highlights.

## Why Preview Helps

Without a preview, the player must remember which connections are required and which have already been drawn. On complex puzzles with many nodes, this becomes a memory test rather than a spatial reasoning challenge. The preview shifts the difficulty to where it belongs — figuring out the correct order to draw connections without crossings.

The preview also reduces frustration. Instead of selecting an end node only to have it rejected as an invalid pair, the player can see their valid options before committing.

## Selective Highlighting

The preview only highlights undrawn connections. If a connection from the start node has already been drawn, its end node stays green. This gives the player a clear picture of what remains — the highlighted nodes are exactly the connections still needed from this node.

## Try This

**Watch the preview shrink.** As you draw connections from a node, select it again and notice that fewer preview nodes appear. Does this help you track progress?

**Disable the preview.** Comment out the GO SUB call and play without it. Is the game harder? More frustrating? Or does it feel like a fair challenge without the help?
