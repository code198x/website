## How It Works

**Lines throughout** contain refinements based on testing. No single new feature is added — instead, existing systems are improved:

**Crossing detection edge cases.** Lines that pass through node circles could trigger false positives. The sampling subroutine now skips sample points that are within the radius of either the start or end node. This prevents the node's own colour from being mistaken for a crossing line.

**Cursor at screen edges.** Nodes near the screen edges could place the cursor circle partially off-screen, causing a BASIC error. The drawing code now clips circle positions to ensure they stay within valid coordinates.

**HUD overwrite protection.** After a full redraw, the HUD must be refreshed. A missing HUD update after undo left stale values on screen. The redraw subroutine now always calls the HUD update.

**Puzzle difficulty ordering.** Some Band 2 puzzles were harder than Band 3 puzzles. The DATA has been reordered so difficulty increases smoothly within each band and across bands.

## Testing Methodology

Systematic testing for a puzzle game means:

1. **Solve every puzzle.** If you cannot solve it, neither can the player. Some puzzles that seem solvable turn out to have no valid ordering.
2. **Test every input.** Press every key during every game state. Keys that do nothing should be ignored silently, not cause errors.
3. **Test undo at every stage.** Undo with zero connections drawn. Undo immediately after starting. Undo all connections and redo them. Each case must work correctly.
4. **Test transitions.** Back from gameplay. Back from select. Complete a puzzle and return. Play the same puzzle twice. Each flow must leave the game in a consistent state.

## Difficulty Curve

The ideal difficulty curve for Lattice introduces one new challenge at a time:

- **Puzzles 1-3:** Few nodes, few connections, no crossing risk. Learning the controls.
- **Puzzles 4-8:** First crossing conflicts. The player must choose an order.
- **Puzzles 9-15:** More nodes, tighter spacing. Planning ahead becomes necessary.
- **Puzzles 16-20:** Irregular and circular layouts. Spatial reasoning matters.
- **Puzzles 21-25:** High connection density. Multiple valid orderings, but some are traps.

## Try This

**Find a bug.** Play aggressively — mash keys, undo rapidly, select and deselect repeatedly. Can you crash the program or produce incorrect display?

**Rate each puzzle.** After solving all puzzles, rank them by difficulty. Does the order match the band assignments? If not, suggest reordering.
