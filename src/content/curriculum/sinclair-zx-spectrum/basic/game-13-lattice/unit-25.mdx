Some puzzles are genuinely hard. When the player is stuck, a hint can nudge them forward without giving away the solution. Pressing H briefly flashes all remaining undrawn connections, showing the player what needs to be connected without revealing the correct order.

## How It Works

**Lines 140-150** detect the H key in the input loop and call `GO SUB 900` for the hint.

**Lines 900-930** are the hint subroutine. It loops through all connection pairs. For each undrawn connection (`d(i) = 0`), it draws a line between the two nodes in cyan (INK 5), using the same PLOT/DRAW pattern as the connection-drawing subroutine.

**Lines 940-950** pause briefly (PAUSE 15, about 0.3 seconds) so the player can study the hint lines.

**Lines 960-980** erase the hint by doing a full redraw. All hint lines disappear, and only the actual drawn connections remain. The puzzle returns to its normal state.

## Hint as Information, Not Solution

The hint shows which connections still need to be drawn, but not the order. The player sees dotted-style lines flash between the remaining node pairs. This is enough to remind them which pairs they are missing, but the spatial reasoning challenge — figuring out the non-crossing order — remains.

## Hint Cost

Using a hint could reduce the star rating. If the player presses H, the maximum star rating for that puzzle drops by one. This gives hints a cost — the player trades potential stars for help. Using two or more hints locks the rating to one star.

Variable `hn` tracks hint usage per puzzle. The star calculation in the completion routine subtracts hint penalties from the base rating.

## The Brief Flash

The hint duration matters. Too short and the player cannot read it. Too long and it becomes a crutch. PAUSE 15 (about 0.3 seconds) gives enough time for a quick scan but not enough to memorise the layout. The player might press H multiple times, but each press costs stars.

## Try This

**Use a hint on a hard puzzle.** Press H to see the remaining connections. Does it help you figure out the next move?

**Spam hints.** Press H repeatedly. Does the star penalty accumulate? Is the cost noticeable enough to discourage overuse?
