A number is just a number. A rating gives it meaning.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-06-bright-spark/unit-09/ratings.bas" />

Lines 470–520 add a rating below the score. The IF chain tests from highest to lowest: score 10 or more gets green "Amazing!", 6–9 gets cyan "Good memory!", 3–5 gets yellow "Not bad", below 3 gets red "Keep practising." Line 520 resets `INK 7` so any later text prints white again.

## Colour as feedback

Each rating uses a different `INK` colour. Green for the best result, red for the worst. The player feels the result before reading the word — colour is faster than text. This is the same idea as the red flash in Reflex: colour carries meaning the eye processes instantly.

The IF chain works because each condition is tested in order. If the score is 8, the first check (`score >= 10`) fails, the second (`score >= 6 AND score < 10`) passes, and the rest are skipped because the `PRINT` on line 490 has already happened. The `AND score < 10` on line 490 prevents it from also matching when the score is 12 — without it, both "Amazing!" and "Good memory!" would print.

## Try it

Change the thresholds. Make "Amazing!" require 15. Make "Keep practising" trigger below 5. Add a fifth rating — "Superhuman!" for scores above 20. Each new tier is one more IF line with its own INK colour.
