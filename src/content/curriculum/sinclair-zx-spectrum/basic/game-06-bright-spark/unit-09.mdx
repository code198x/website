A number is just a number. A rating gives it meaning.

Lines 450–500 add a rating below the score. The IF chain tests from highest to lowest: score 10 or more gets green "Amazing!", 6–9 gets cyan "Good memory!", 3–5 gets yellow "Not bad", below 3 gets red "Keep practising." Line 500 resets `INK 7` so any later text prints white again, and line 510 stops the program before it reaches the drawing subroutine.

<Figure src="/images/sinclair-zx-spectrum/basic/game-06-bright-spark/unit-09/screenshot.png" alt="Game over screen with the 'Not bad' rating in yellow below the score" caption="The score becomes a rating — 'Not bad' for a sequence of 3, in its own colour." />

## Colour as feedback

Each rating uses a different `INK` colour. Green for the best result, red for the worst. The player feels the result before reading the word — colour is faster than text. This is the same idea as the red flash in Reflex: colour carries meaning the eye processes instantly.

The IF chain works because each condition tests a range. If the score is 8, the first check (`score >= 10`) fails and the second (`score >= 6 AND score < 10`, line 470) passes and prints. The other checks fail their own ranges, so only one rating shows. The `AND score < 10` on line 470 is what keeps the ranges from overlapping — without it, a score of 12 would match both `score >= 10` and `score >= 6`, printing "Amazing!" and "Good memory!" together.

## Try it

Change the thresholds. Make "Amazing!" require 15. Make "Keep practising" trigger below 5. Add a fifth rating — "Superhuman!" for scores above 20. Each new tier is one more IF line with its own INK colour.
