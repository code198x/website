The game starts with panels appearing out of nowhere. It should start with an introduction.

Lines 10–90 add a title screen before the game begins. Line 10 sets the mood: `BORDER 0: PAPER 0: INK 7: CLS` — a black screen with white text. Lines 30–70 print the game name, a brief explanation, and the key mapping. Line 90 `PAUSE 0` waits for any key.

## The title screen's three jobs

Every title screen answers three questions:

1. **What is this?** — "BRIGHT SPARK" and "Watch the panels flash. Repeat the sequence."
2. **How do I play?** — the key mapping (1=Red, 2=Blue, 3=Green, 4=Yellow).
3. **Am I ready?** — `PAUSE 0` lets the player start when they choose.

The key mapping is especially important here. Without it, the player would see four coloured panels and have no idea which keys to press. The title screen turns a confusing first impression into a clear one.

`BORDER 0` sets the border — the strip around the edge of the screen — to black. Combined with `PAPER 0`, the entire display is dark. This gives the title text room to breathe and makes the coloured panels feel like they appear from nothing when the game starts on line 100.
