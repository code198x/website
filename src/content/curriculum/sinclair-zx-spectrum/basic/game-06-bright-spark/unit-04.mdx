One flash is a signal. A sequence of flashes is a pattern to remember.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-06-bright-spark/unit-04/sequence.bas" />

Line 120 initialises an empty string `s$`. Line 130 appends a random digit (1–4) using `STR$`. Lines 150–190 replay the entire sequence: FOR loops through each character, `VAL` converts it back to a number, and `GO SUB 900` flashes that panel.

The string `s$` IS the sequence. "1" means flash panel 1. "142" means flash 1, then 4, then 2. Each round adds one more character — the sequence grows.
