## Strings as game state

The string `s$` **is** the game. After three rounds it might hold `"142"` — flash panel 1, then 4, then 2. After four rounds it holds `"1423"`. The string grows by one character each round, and the replay loop plays all of it from the start.

Three functions make this work:

- `STR$` converts a number to its string character. `STR$ 3` gives `"3"`.
- `VAL` converts a string character back to a number. `VAL "3"` gives `3`.
- `LEN` gives the length of the string. `LEN "142"` gives `3`.

You could store the sequence in an array, but a string is simpler. One variable holds the entire pattern. Appending is just `s$ + STR$(n)`. Indexing is just `s$(i)`. The string is both the storage and the interface — no arrays, no counters, no bookkeeping.

## Try it

Change line 140 to `LET s$ = "1234"` (remove the RND). Run it. All four panels flash in order — a predictable test sequence. Change it to `"11111"` — the same panel flashes five times. The replay loop does not care what is in the string; it just plays it back.
