## What changed

**Title screen (lines 30–90).** Instructions, key labels, "Press any key to start." The player knows what to do before the game begins. No surprises.

**Panel numbers.** Each panel displays its number ("1", "2", "3", "4") as part of the fill text. The player can see which key matches which panel without checking the bottom of the screen.

**Clean restart (line 550).** `GO TO 10` restarts from the title, not from the panel drawing. Each play feels like a fresh session.

## What you have built

Bright Spark is the most complex program in V1 — about 50 lines of main code plus two subroutines. It combines:

- **FOR/NEXT** for sequence playback and panel drawing
- **INKEY$** for real-time input with key draining
- **Strings** as data structures (`s$` stores the sequence)
- **GO SUB/RETURN** for reusable code (draw panels, flash a panel)
- **BRIGHT** for visual signalling
- **BEEP** for audio identity (one tone per panel)
- **Chained IF/THEN** for panel selection and rating

Every one of those tools came from an earlier game. Bright Spark is where they work together.

And two design concepts:

- **Pattern** — the game is pure pattern recognition. Watch, remember, reproduce. The difficulty scales with human memory, not with code.
- **Signposting** — colour and sound together tell the player what to pay attention to. Each channel reinforces the other.
