Four coloured panels — that is the game board. Start with two.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-06-bright-spark/unit-01/two-panels.bas" />

Line 810 sets `PAPER 2` (red). Line 820 uses a FOR loop to print 8 rows of spaces at the top-left — filling a rectangle with colour. Lines 830–840 do the same in blue at the top-right. Line 890 resets `PAPER 0`.

Each panel is a block of coloured spaces. The number in the middle (1 or 2) tells the player which key to press.
