A second subroutine starts at line 900. Set `p` to a panel number (1–4), then `GO SUB 900`. Lines 910–940 look up the panel's colour, screen position, and musical note. Lines 950–990 do the flash: bright on, redraw, beep, bright off, redraw.

Line 20 adds `RANDOMIZE` so the random numbers change each run. Line 120 picks a random panel. Line 130 calls the flash subroutine. Run it — one panel lights up with a tone.

## BRIGHT

The Spectrum has eight colours (0–7) and each one has a bright variant. `BRIGHT 1` switches to the brighter version — red becomes vivid red, blue becomes vivid blue. `BRIGHT 0` switches back. It is not a separate colour; it is an intensity modifier. Think of it as a light switch for each colour.

The flash subroutine uses this to create a pulse: set `BRIGHT 1`, redraw the panel (line 960), play a tone (line 970), set `BRIGHT 0`, redraw again (line 990). The panel goes bright for the duration of the BEEP — about a third of a second — then returns to normal. The eye catches the change because the shape stays the same but the brightness shifts.

## The flash pattern

Notice the shape of the subroutine: set up, brighten, sound, dim, restore. You will see this pattern whenever a game needs a visual event — a hit, a pickup, a warning. The details change, but the structure is the same: make something visually different for a moment, then put it back.

Line 995 resets `PAPER 0` before returning. Without it, the next PRINT statement would still use the panel's colour. Always clean up after a subroutine — leave the state the way you found it.
