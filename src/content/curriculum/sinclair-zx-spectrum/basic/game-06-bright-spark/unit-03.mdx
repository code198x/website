## The sequence as a string

Line 40: `LET s$ = ""` — an empty string. Each round, line 60 adds one random panel number: `LET s$ = s$ + STR$ (INT (RND * 4) + 1)`. After three rounds, `s$` might hold `"214"` — panel 2, panel 1, panel 4.

`STR$` converts a number to its string character. `STR$(3)` gives `"3"`. The sequence is stored as a string of digit characters, not as separate variables — this lets us grow it by one each round with simple concatenation.

## Replaying it

Lines 100–130 walk through the string with a `FOR` loop:

```
FOR i = 1 TO LEN s$
LET p = VAL s$(i)
GO SUB 900
PAUSE 15
NEXT i
```

`LEN s$` gives the length of the string — how many panels in the sequence. `s$(i)` reads the character at position `i`. `VAL` converts the character back to a number: `VAL "3"` gives 3. That number tells the subroutine which panel to flash.

## GO SUB and RETURN

The flash effect is 10 lines of code. The sequence replays it once per panel, and later the player's input will replay it too. Copying those 10 lines everywhere would be unmanageable. Instead, the flash lives at line 900 as a **subroutine**.

`GO SUB 900` jumps to line 900 and runs until it hits `RETURN`, which jumps back to the line after the `GO SUB`. The subroutine is reusable — call it from anywhere, with different values of `p`, and it flashes the right panel.

The drawing code at line 800 works the same way: `GO SUB 800` draws all four panels, then `RETURN` brings you back.

`GO SUB` is the Spectrum's tool for reusable code. It is not as structured as functions in modern languages, but the principle is identical: write the code once, call it from many places.

## Watch it grow

The loop at lines 50–170 adds one panel per round and replays the full sequence each time. Round 1: one flash. Round 2: two flashes. Round 5: five flashes. The sequence grows, and you watch it get harder. At some point it exceeds what you can hold in memory — that is the game.
