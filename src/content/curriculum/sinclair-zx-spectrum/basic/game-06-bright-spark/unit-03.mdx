A second subroutine at line 900. Set `p` to a panel number (1–4), then `GO SUB 900`. Lines 910–940 look up the panel's colour, position, and tone. Line 950 `BRIGHT 1` makes the panel lighter. Line 970 `BEEP` plays the tone. Line 980 `BRIGHT 0` returns to normal.

Line 120 picks a random panel. Line 130 calls the flash. One panel lights up with sound.

## BRIGHT

`BRIGHT 1` makes every colour lighter — red becomes bright red, blue becomes bright blue. It is the Spectrum's 15th "colour": an intensity modifier, not a separate hue. `BRIGHT 0` turns it off.
