The replay loop is three lines. Line 510 prints "Press any key to play again." Line 520 `PAUSE 0` waits. Line 530 `GO TO 10` restarts from the title screen — black background, title, rules, then a fresh set of panels and a new random sequence.

This unit also polishes the title: line 30 now centres "BRIGHT SPARK" through the `GO SUB 9000` subroutine, and line 90 prints a row of colour swatches above the rules — red, blue, green, yellow — so the key mapping is unmistakable.

## The outer loop

`GO TO 10` jumps all the way back to the beginning — past the title, past `CLS`, past `GO SUB 540`. Everything resets. The sequence string `s$` gets a fresh `LET s$ = ""` on line 140, so the new game starts from one panel again.

This is a different kind of loop from the game loop at `GO TO 150`. The game loop grows the sequence within one play session. The replay loop wraps the entire session — title, game, score, rating — and starts over. Two loops, nested: the inner one runs rounds, the outer one runs games.

Three lines turn a one-shot program into an arcade machine. The player's motivation shifts from "can I do it?" to "can I beat my last score?"
