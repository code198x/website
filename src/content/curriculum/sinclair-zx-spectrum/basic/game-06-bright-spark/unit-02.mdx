Lines 850–880 add green (panel 3) and yellow (panel 4) at rows 12–19. The full board now fills the screen: red and blue on top, green and yellow below.

The bigger change is structural. The drawing code moves to a **subroutine** starting at line 800. Line 110 calls it with `GO SUB 800`. Line 890 ends with `RETURN` instead of `STOP`. Line 115 stops the main program so it does not accidentally fall through into the subroutine below.

## GO SUB / RETURN

`GO SUB` is like `GO TO` with a return ticket. The Spectrum remembers where you called from. When it reaches `RETURN`, it jumps back to the line after the `GO SUB` — in this case, line 115.

Why not just use `GO TO`? Because `GO TO` is a one-way trip. If the main program says `GO TO 800`, the drawing code runs — but `RETURN` has nowhere to go back to. `GO SUB` creates a bookmark. You will call `GO SUB 800` from several places later in this game, and `RETURN` always brings you back to the right one.

Think of it as a function call without a name. The subroutine does one job (draw the board), and any part of the program can ask for that job without knowing or caring what happens after.

## Try it

Delete line 115. Run the program. The panels draw — then the program falls through line 800, draws them again, and hits `RETURN` with nothing to return to. The Spectrum gives error `7 RETURN without GOSUB`. That is why line 115 matters: it is a wall between the main program and its subroutines.
