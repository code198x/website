Lines 850–880 add green (panel 3) and yellow (panel 4) at the bottom. The drawing code moves to a **subroutine** at line 800: `GO SUB 800` on line 110 calls it, `RETURN` on line 890 jumps back. Line 115 `STOP` prevents execution falling into the subroutine.

## GO SUB / RETURN

`GO SUB` is like `GO TO` with a return ticket. The program jumps to line 800, runs the drawing code, then `RETURN` brings it back to line 115. You can call `GO SUB 800` from anywhere and it always returns to where it was called.
