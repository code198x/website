Every game so far has waited for you. Lucky Number waited for your guess. Bright Spark waited for your key. Hi-Lo waited for your prediction. Nothing happened until you acted.

Touchdown is different. Something happens whether you act or not.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-08-touchdown/unit-01/falling.bas" />

Run it. A number counts down from 100 to 0. Nobody presses anything. The program just runs.

That counting number is altitude — how high the lander is above the ground. Each pass through the loop, the altitude drops by 1. When it reaches 0, the program prints "LANDED" and stops.

## The continuous loop

The loop at lines 30–70 is the same `GO TO` structure you know. But unlike Lucky Number's loop (which waited for INPUT each iteration), this loop runs as fast as the Spectrum can manage, paused only by `PAUSE 5` — a tenth of a second per tick.

This is a **continuous game loop**: the world updates every iteration whether the player does anything or not. In Lucky Number, the game waited. In Touchdown, the game *runs*. That difference — waiting vs running — is the line between turn-based and real-time. Every action game, every platformer, every space shooter on the Spectrum uses a continuous loop.

The design concept is **Descent**: the program descends whether you act or not. Right now you cannot act at all — the lander just falls. But the structure is real: altitude decreases, the loop runs, the ground approaches. Next: speed.
