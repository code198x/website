Scrolling numbers are hard to read during a real-time game. An instrument panel stays still.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-08-touchdown/unit-04/dashboard.bas" />

Line 130 draws the labels once: `"ALT:         SPD:         FUEL:"` at row 1. Line 140 draws a ground line at row 21: thirty-two `=` characters. These never change, so they sit outside the game loop.

Inside the loop, lines 210–230 update only the numbers. `PRINT AT 1, 6; alt; "  "` writes the altitude value at a fixed position after the "ALT:" label. The trailing `"  "` clears leftover digits when the number shrinks — "100" to "98" to "3".

This is the same dashboard idea from Hi-Lo, but now it matters more. In Hi-Lo, the display was cosmetic — the game paused for INPUT. Here the game is running in real time. The player must glance at the dashboard while deciding whether to fire. Fixed positions let the eye find the number instantly; scrolling text would make that impossible.

The ground line at row 21 is a visual landmark. The lander will eventually descend toward it — but for now it is just a marker, a reminder that the ground is waiting.
