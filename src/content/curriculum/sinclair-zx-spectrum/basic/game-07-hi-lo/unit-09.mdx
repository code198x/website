The game starts with a number appearing out of nowhere. It should start with a title.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-07-hi-lo/unit-09/titled.bas" />

Lines 10–100 add a title screen. Line 10 sets the stage: `BORDER 0: PAPER 0: INK 7: CLS` — black everywhere, white text. Lines 40–80 explain the game in four lines: what you do, how you play, and the challenge. Line 90 waits with "Press any key to start." Line 100 `PAUSE 0` hands control to the player.

Notice that `LET best = 0` is on line 30 — between the screen setup and the title text. It only runs once, before the first game. The replay loop (`GO TO 110`) skips it, so the best score survives across games. The title screen only shows on the first launch.

The title screen does the same three jobs as Bright Spark's: name the game, explain the controls, wait for the player. It has become a formula — and like all good formulas, it works because the player already knows what to expect from the previous game.
