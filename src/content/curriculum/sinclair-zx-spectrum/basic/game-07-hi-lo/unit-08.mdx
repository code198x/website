Line 30 initialises `best = 0`. Line 170 shows it on the dashboard alongside the current streak. Line 410 updates it: `IF streak > best THEN LET best = streak`. Lines 520–550 add a replay prompt, `PAUSE 0`, and `GO TO 110` to start a new game.

## Where you put a variable matters

`best` is initialised on line 30 — before the game loop. The replay on line 550 jumps to line 110, skipping line 30. That means `best` keeps its value across games. The streak resets every game (line 120), but the best score survives.

If `best` were initialised on line 120 alongside `streak`, it would reset every game and never grow. The position of the initialisation determines the variable's lifetime. Lines before the replay point persist; lines inside the replay loop reset.

## The replay loop

Line 550 `GO TO 110` restarts the game — new random number, streak back to zero — but keeps `best`. The player now competes against their own record. "Streak: 3, Best: 7" is more motivating than "Streak: 3" alone, because it tells the player what they are capable of.

Line 460 shows the best score on the game over screen alongside the current streak. If the player just set a new best, both numbers are the same — and they know it. If they fell short, the gap tells them how much further to push.
