Line 120 starts the streak at 0. Line 160 shows it on screen. Line 270 increments it on each correct guess. Line 260 ends the game on a wrong answer: `STOP`. Line 340 `GO TO 130` loops back for the next round.

The subtle line is 330: `LET a = b`. The revealed number becomes the next round's starting number. The player saw `b`, so now they must predict what comes after it. Without this line, the game would generate a completely new number each round — the player would never build on what they already know. The carry-forward is what makes it feel like a sequence, not isolated guesses.

## The streak as motivation

The streak counter transforms a yes/no question into a competitive arc. "Was I right?" becomes "how long can I keep being right?" The counter resets every game, so each run is a fresh challenge. The player competes against their own memory of past streaks.

This is a design pattern: **competition against yourself**. No opponent, no leaderboard, no network. Just a number that says "you did this well — can you do better?" It is the simplest form of replayability, and it works because the randomness means every game is different.
