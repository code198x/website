## Best-score tracking

Line 30: `LET best = 0` — initialised once, before the title screen.

Line 410: `IF streak > best THEN LET best = streak` — after game over, update the best if the current streak beats it.

Line 170: `PRINT AT 6, 8; "Best:   "; best` — the best streak is visible during play. The player sees two numbers: the current streak and the target to beat.

One variable changes the entire relationship with the game. Without the best score, each round is isolated — win or lose, it is forgotten. With the best score, every round is measured against your own history. The player competes against themselves, not against the program.

## The replay loop

Line 550: `GO TO 110` — after game over, the program starts a new round without going through the title screen. The `best` variable persists because it was initialised at line 30, which is *above* the replay jump. Only a full restart (`RUN`) resets it.

This is a practical consequence of how Spectrum BASIC handles variables: they persist until the program ends or `NEW` clears them. The replay jump skips the `LET best = 0` line, so the best score survives across rounds.

And two design concepts:

- **Narrowing** — each guess, win or lose, gives the player information. A 7 is more likely to go lower than a 3 is. The feedback narrows the possibilities.
- **Feedback loops** — each result shapes the next decision. The streak creates a secondary feedback loop: the longer it gets, the more cautious the player becomes.
