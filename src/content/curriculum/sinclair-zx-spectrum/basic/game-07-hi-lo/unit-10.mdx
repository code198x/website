The game starts with a card appearing out of nowhere. It should start with a title.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-07-hi-lo/unit-10/titled.bas" />

Lines 100–170 add a title screen before the game begins. Line 100 prints the centred title with `GO SUB 9000`. Lines 110–140 explain the game in four lines: what you do, how you play, and the challenge. Line 150 waits with "Press any key to start." Line 170 `PAUSE 0` hands control to the player.

<Figure src="/images/sinclair-zx-spectrum/basic/game-07-hi-lo/unit-10/screenshot.png" alt="HI-LO title screen with four lines of instructions and 'Press any key to start'" caption="The title screen: what the game is, how to play, and the challenge — then any key to begin." />

Notice that `LET best = 0` sits on line 90 — between the setup and the title. It only runs once, before the first game. The replay loop (`GO TO 180`) skips it, so the best score survives across games. The title screen, too, shows only on the first launch.

The title screen does the same three jobs as Bright Spark's: name the game, explain the controls, wait for the player. It has become a formula — and like all good formulas, it works because the player already knows what to expect from the previous game.
