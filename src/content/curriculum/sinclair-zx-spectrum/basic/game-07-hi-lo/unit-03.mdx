After a correct guess, line 180 does something subtle: `LET a = b`. The second number becomes the new first number. Then `GO TO 50` loops back to show it and ask again. The game continues from where it left off — a chain of comparisons, each building on the last.

## Loop-until-condition

This is a different kind of loop from `FOR/NEXT`. A FOR loop runs a fixed number of times. This loop runs *until the player gets one wrong* — that could be 1 time or 100 times. The exit is at line 150: `IF ok = 0 THEN GO TO 200`. If the player is wrong, the loop breaks.

The pattern:

```
[set up]
[do the thing]
[check if we should stop]
IF stop THEN exit
[prepare for next round]
GO TO [do the thing]
```

This is the **loop-until-condition** pattern. Every game loop uses it: run until something specific happens. Lucky Number used it (loop until the guess is correct). Reflex used it (loop until a key is pressed). Here the condition is "the player guessed wrong."

## State transition

`LET a = b` is a **state transition** — the outgoing value becomes the incoming value. The player sees the next number and needs to predict the one after it. Each round's "next" becomes the following round's "current." This pattern appears in every turn-based game where the end of one turn sets up the start of the next.

## The streak counter

`LET streak = streak + 1` on each correct guess. The number grows. The player watches it grow. At some point, the streak matters more than any individual guess — they are not trying to be right, they are trying to *not lose what they have built*. That shift — from "try to win" to "try not to lose" — is the game's emotional core.
