Two ways to be right (H and higher, L and lower), one way to be wrong. The `ok` flag collects the result.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-07-hi-lo/unit-03/right-wrong.bas" />

Line 220 sets `ok = 0` (assume wrong). Lines 230–250 each set `ok = 1` if their condition is true. Line 250 handles ties (equal counts as correct). Lines 260–290 read the flag: 0 means wrong, 1 means right.

This is the **flag pattern**: set a default, check conditions that change it, then act on the final value.
