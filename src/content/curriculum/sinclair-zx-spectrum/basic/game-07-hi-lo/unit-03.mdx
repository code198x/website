## The flag pattern

The alternative is nested IF statements — "if H and higher, print correct, otherwise if L and lower, print correct, otherwise if equal, print correct, otherwise print wrong." That gets tangled fast with three success conditions.

The flag pattern is cleaner: **set a default, check each condition, act on the result**. The variable `ok` starts at 0. Each IF line asks one question and flips the flag if the answer is yes. At the end, the flag holds the combined verdict. One variable, one check, one action.

You will use this pattern whenever a program has several ways to succeed (or several ways to fail) and needs a single decision at the end. It separates the checking from the responding — the checks do not print anything; the response does not check anything.
