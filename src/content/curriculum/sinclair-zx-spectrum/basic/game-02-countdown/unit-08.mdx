## Rating Tiers

The IF/THEN blocks on lines 310-340 check the best time against thresholds. The pattern is identical to Lucky Number's scoring tiers — lower numbers are better, each tier gets a different colour.

Design your own tiers. The thresholds depend on how fast the INKEY$ loop runs (which varies between real hardware and emulators), so adjust them based on your own scores:

```basic
 310 IF b<=5 THEN PRINT AT 10,8; INK 2; BRIGHT 1;"Lightning fast!"
 320 IF b>5 AND b<=15 THEN PRINT AT 10,8; INK 6;"Quick reflexes!"
 330 IF b>15 AND b<=30 THEN PRINT AT 10,8; INK 5;"Not bad!"
 340 IF b>30 THEN PRINT AT 10,8; INK 3;"Keep practising!"
```

## The Complete Game

You've now built a complete game from scratch. Here's what your program does:

1. Clears the screen and draws the game header
2. Shows "Get ready..." and waits a random time
3. Catches cheaters who press too early
4. Shows "NOW!" with a yellow border and a BEEP
5. Times the reaction with an INKEY$ counter loop
6. Shows the time and tracks the best
7. Repeats for five rounds
8. Shows the results with a rating

Every line is something you wrote and understand. No magic, no black boxes.
