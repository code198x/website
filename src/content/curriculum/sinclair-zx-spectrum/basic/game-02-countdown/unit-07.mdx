The reaction timer works, but it always says "Go!" — the same word every time. The final game flashes a random word: FIRE, JUMP, DUCK, RUN, or STOP. Each round is different, keeping the player on their toes.

You already know `RND` from Lucky Number, where you used it to pick a random number. Here you'll use it to pick a random *word*.

## Picking a Random Word

The Spectrum doesn't have arrays yet (you'll meet those in a later game), so you pick a word by generating a random number and using `IF/THEN` to match it:

Run it a few times. Each time you'll see a different word (usually — sometimes the same word comes up twice in a row, which is how randomness works).

## How It Works

```basic
20 LET r = INT (RND * 5) + 1
```

This picks a random number from 1 to 5. You saw this formula in Lucky Number: `RND` gives a decimal between 0 and 1, multiplying by 5 gives 0 to 4.999..., `INT` rounds down to 0-4, and adding 1 gives 1-5.

```basic
30 IF r = 1 THEN LET w$ = "FIRE"
40 IF r = 2 THEN LET w$ = "JUMP"
50 IF r = 3 THEN LET w$ = "DUCK"
60 IF r = 4 THEN LET w$ = "RUN"
70 IF r = 5 THEN LET w$ = "STOP"
```

Five `IF` lines, one for each possible value of `r`. Whichever one matches sets `w$` — a **string variable** — to the corresponding word. Exactly one of these conditions will be true.

The Spectrum runs all five lines. Four of them find a false condition and are skipped. One finds a true condition and sets `w$`. It's not elegant, but it's simple and it works.

## String Variables

`w$` is a string variable — a variable that holds text instead of a number. The `$` at the end tells the Spectrum it's a string. You met string variables briefly with `INKEY$` and `k$` in Unit 4. Here you're using one to store a word that the program chooses.

String variables work like numeric variables:
- `LET w$ = "FIRE"` stores "FIRE" in `w$`
- `PRINT w$` prints whatever is in `w$`
- `IF w$ = "FIRE" THEN ...` checks its contents

The only difference is the `$` and the quotation marks around the values.

## The Random Delay

```basic
90 PAUSE 50 + INT (RND * 100)
```

This waits between 1 and 3 seconds before showing the word. The delay is random — `50 + INT(RND * 100)` gives a value between 50 (one second) and 149 (just under three seconds). This prevents the player from anticipating exactly when the word will appear.

## Try This

**More words.** Change `RND * 5` to `RND * 8` and add three more words on lines 75, 76, and 77 (for `r = 6`, `r = 7`, `r = 8`). More variety keeps the game fresh.

**Show which word.** After the reaction time prints, add `PRINT "The word was: "; w$`. This confirms what the player saw.

**Themed words.** Replace FIRE/JUMP/DUCK/RUN/STOP with animal names, colours, or anything else. The game mechanic doesn't care what the words are.

## What You've Learnt

- **String variables** — `w$` holds text; the `$` marks it as a string
- **Random selection** — use `RND` to pick a number, then `IF/THEN` to match it to a word
- **Random delays** — `PAUSE 50 + INT(RND * 100)` creates unpredictable timing
- **The IF/THEN chain** — multiple IF lines checking the same variable, one for each possible value
