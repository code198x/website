## How FOR/NEXT Works

`FOR n=1 TO 5` sets `n` to 1 and runs everything until `NEXT n`. Then it adds 1 to `n` and runs everything again. When `n` exceeds 5, the loop ends.

Unlike GO TO (which loops forever until something breaks out), FOR/NEXT runs a specific number of times. You used GO TO for the INKEY$ polling loop (which runs an unknown number of times). FOR/NEXT is for loops where you know the count in advance.

You've actually already used FOR/NEXT — lines 10-30 draw the header bar with `FOR i=0 TO 31`. That loop runs 32 times, once per column. Same idea, different scale.

## What You've Learnt

- **FOR/NEXT** — a loop with a built-in counter; runs a specific number of times
- **Best time tracking** — compare each result against a stored best; update when lower
- **Debounce between rounds** — wait for release, then wait for press
- **GO TO vs FOR/NEXT** — GO TO for open-ended loops; FOR/NEXT when you know the count
