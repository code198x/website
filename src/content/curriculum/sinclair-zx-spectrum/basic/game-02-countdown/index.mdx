A word appears on screen after a random delay. Press any key the instant you see it. The program measures how fast you reacted. Play five rounds and try to beat your best.

This is the first game you build from scratch. In Lucky Number, you typed in a complete program and learnt by modifying it. Here, every line is yours.

## How It Works

You build the game incrementally — each unit adds a visible feature, and the program runs after every unit.

## What You'll Learn

- **CLS** — clearing the screen
- **PRINT AT** — placing text at exact positions
- **PAUSE** — timed delays (frames at 50fps)
- **BEEP** — sound effects (duration and pitch)
- **INKEY$** — checking the keyboard without waiting
- **FOR/NEXT** — loops with a built-in counter
- **The difference between INPUT and INKEY$** — blocking vs non-blocking

## Prerequisites

Complete [Game 1: Lucky Number](/sinclair-zx-spectrum/basic/game-01-lucky-number/) first. You'll need PRINT, LET, IF/THEN, GO TO, and RND.
