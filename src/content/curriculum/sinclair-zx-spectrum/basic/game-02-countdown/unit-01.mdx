In Game 1, you typed in a complete program and learnt by changing it. Now you build one from scratch. Every line is yours.

The game you're building is a reaction timer. A word appears on screen after a random delay. You press a key as fast as you can. The program measures your speed. But first, you need a screen to put it on.

![The Countdown game screen — red header bar, round counter, and "Get ready..." prompt](/images/sinclair-zx-spectrum/basic/game-02-countdown/unit-01-the-stage/game-screen.png)

Six lines. A black screen with a red header bar, "COUNTDOWN" in bright white, a round counter in cyan, and "Get ready..." in yellow. It looks like a game screen — because it is one.

Here's what each line does:

- **Line 5** — `BORDER 0: PAPER 0: INK 7: CLS` sets the border to black, the paper (background) to black, the ink (text) to white, and clears the screen. Four commands on one line, separated by colons.
- **Lines 10-30** — a FOR/NEXT loop that prints 32 red spaces across row 0, creating the header bar. You haven't formally learnt FOR/NEXT yet — it runs the PRINT 32 times, once for each column. Think of it as "fill this row with red."
- **Line 40** — prints "COUNTDOWN" on the header bar in bright white. `PRINT AT 0,10` puts the text at row 0, column 10.
- **Line 50** — prints the round counter at row 2 in cyan (`INK 5`).
- **Line 60** — prints the prompt at row 10 in yellow (`INK 6`).

## PRINT AT

In Game 1, PRINT put text wherever the cursor happened to be. `PRINT AT row,column` puts text at an exact position. Row 0 is the top of the screen. Column 0 is the left edge. The Spectrum screen is 24 rows by 32 columns.

Try changing the positions:
- `PRINT AT 0,10` → try `PRINT AT 0,0` and the title moves to the left edge
- `PRINT AT 10,10` → try `PRINT AT 15,5` and "Get ready..." moves lower and further left

The screen is a grid. PRINT AT places text anywhere on it.

## Colour Commands

You've already seen INK and PAPER in Game 1's Lucky Number. Now you're using them deliberately:

- `PAPER 2` — red background (for the header bar)
- `INK 7` — white text
- `INK 5` — cyan text
- `INK 6` — yellow text
- `BRIGHT 1` — brighter version of the colour
- `BORDER 0` — black border around the screen edge

Try changing the header colour: replace `PAPER 2` on lines 20 and 40 with `PAPER 1` (blue) or `PAPER 3` (magenta). The game screen changes character immediately.

## Try This

- Change "COUNTDOWN" to your own game title. Adjust the column number on line 40 to keep it centred.
- Change "Get ready..." to something more dramatic — "STAND BY..." or "WAIT FOR IT..."
- Add a line `70 PRINT AT 20,5; INK 7;"Press any key to begin"` at the bottom. The screen now has a call to action.
- Change `BORDER 0` to `BORDER 2` to match the header bar colour.

## What You've Learnt

- **CLS** — clears the screen completely; the starting point for any game
- **PRINT AT row,column** — places text at an exact position on the 24×32 grid
- **PAPER** — sets the background colour for printed characters
- **INK** — sets the text colour
- **BRIGHT** — makes colours brighter (0=normal, 1=bright)
- **BORDER** — changes the colour of the screen border
- **Colons** — separate multiple commands on one line (`BORDER 0: PAPER 0: INK 7: CLS`)
