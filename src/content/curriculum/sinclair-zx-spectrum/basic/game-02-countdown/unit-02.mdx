The game screen appears. "Get ready..." sits there for two seconds. Then it vanishes and "NOW!" appears in bright yellow, flashing.

Here's what the new lines do:

- **Line 70** — `PAUSE 100` waits for 100 frames. The Spectrum runs at 50 frames per second, so 100 frames = 2 seconds. The program stops and does nothing for two seconds.
- **Line 80** — prints 24 spaces over "Get ready..." to erase it. There's no command to delete text on the Spectrum — you overwrite it with spaces.
- **Line 90** — prints "NOW!" at row 10, column 13 in bright yellow with FLASH. The `FLASH 1` / `FLASH 0` pair makes only the word flash, not everything after it.

## How PAUSE Works

PAUSE N waits for N frames. At 50 frames per second:

| PAUSE value | Duration |
|-------------|----------|
| `PAUSE 25` | Half a second |
| `PAUSE 50` | One second |
| `PAUSE 100` | Two seconds |
| `PAUSE 150` | Three seconds |

Try changing `PAUSE 100` to `PAUSE 25`. The word appears almost immediately — barely time to read "Get ready..." before it's replaced. Try `PAUSE 200` — four seconds of tension.

There's a gotcha: PAUSE also ends early if you press any key. This will matter later when we add cheat detection. For now, just don't press anything during the wait.

## Erasing Text

The Spectrum has no "delete" command for text. To remove something from the screen, you print spaces over it. Line 80 prints 24 spaces starting at row 10, column 4 — wide enough to cover "Get ready..." completely.

This is a pattern you'll use constantly: to update the screen, overwrite the old text with new text (or spaces).

## Try This

- Change `PAUSE 100` to `PAUSE 10`. How does it feel? Too fast to react?
- Change `PAUSE 100` to `PAUSE 250`. Five seconds of waiting. Does the tension build or does it get boring?
- Change "NOW!" to "GO!" or "REACT!" — adjust the column number to keep it centred.
- Remove the `FLASH 1` and `FLASH 0` around "NOW!". It still works, but the flashing makes it more urgent.

## What You've Learnt

- **PAUSE N** — waits for N frames (50 frames = 1 second); also ends if a key is pressed
- **Erasing text** — print spaces over old text to remove it from the screen
- **FLASH** — `FLASH 1` makes text flash; `FLASH 0` turns it off; use both to flash only specific text
- **Timing** — the Spectrum runs at 50 frames per second; all timing is based on frame counts
