In Lucky Number, `INPUT` stopped the program and waited for you to type. That works for a guessing game. But a reaction timer can't stop and wait — it needs to check the keyboard *right now* and keep running either way.

That's what `INKEY$` does.

## INKEY$ vs INPUT

To feel the difference, type `NEW` and try this:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-countdown/unit-04/inkey-example.bas" />

Type `RUN`. The screen sits there — no prompt, no cursor. Press any key and "You pressed a key!" appears instantly.

Line 10 checks `INKEY$`. If no key is pressed, `INKEY$` equals `""` (the empty string) and `GO TO 10` loops back to check again. The instant you press a key, `INKEY$` is no longer empty, the condition is false, and line 20 runs.

This is **polling** — checking continuously in a loop. INPUT blocks and waits. INKEY$ polls and keeps going.

## The Empty String

`INKEY$=""` checks if no key is pressed. `INKEY$<>""` checks if any key is pressed. The `""` is an empty string — two quotation marks with nothing between them. It's not a space. It's nothing.

On the Spectrum keyboard, type `""` with **Symbol Shift + P** twice (two quotation marks in a row).

## Try This

- Remove line 100 (the debounce). Hold a key during the PAUSE. What happens? (The reaction registers instantly — the held key counts as a press.)
- Change `GO TO 110` to `GO TO 100`. What happens? (The program waits for you to release the key, then waits for a new press — same behaviour, but less efficient.)
- Add `115 PRINT AT 14,1;t` inside the loop (before line 110's GO TO). You'll see the counter ticking up in real time. Remove it again afterwards.

## What You've Learnt

- **INKEY$** — checks the keyboard right now; returns the key being pressed or `""` if nothing is pressed
- **Polling** — checking INKEY$ in a loop; the program keeps running between checks
- **The empty string** — `""` means no key is pressed; `<>""` means any key is pressed
- **Debounce** — waiting for a key to be released before checking for a new press
- **INPUT vs INKEY$** — INPUT blocks and waits; INKEY$ polls and keeps going
