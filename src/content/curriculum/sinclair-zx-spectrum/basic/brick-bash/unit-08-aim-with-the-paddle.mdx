## Make the contact matter

Line 410 still reflects ny and makes dy positive, but it now starts dx at zero. That is the default vertical return. Line 420 chooses -4 at the left end, while line 430 chooses +4 at the right end.

Call the paddle's pixel left edge L in this explanation. In the program, L is written as `8*p`; no new variable is needed.

| Test on a caught ball | Return |
|---|---|
| nx+1 is less than L+11 | Left: dx=-4 |
| nx is greater than L+20 | Right: dx=4 |
| Neither edge test succeeds | Vertical: dx=0 |

The left test uses the ball's right edge, while the right test uses its left edge. We only choose an edge return when the whole two-pixel ball lies beyond that zone boundary. The centre includes positions that straddle an inner boundary.

## Trace the boundaries

At p=14, L is 112. These examples describe the rule even where the ordinary four-pixel movement does not visit that exact integer coordinate.

| Ball's lower-left x | Compared edges | Return |
|---|---|---|
| 121 | Right edge 122 is below 123 | Left |
| 122 | Right edge 123 is not below 123 | Vertical |
| 132 | Left edge equals 132, not greater | Vertical |
| 133 | Left edge is greater than 132 | Right |

The earlier overlap check still decides whether there was a catch at all. A ball completely outside the paddle cannot be rescued by these direction tests.

<Question prompt="A ball arrives moving left but touches the right end of the paddle. Does its old horizontal direction win?">

No. On every catch, line 410 first sets dx to zero, then the contact tests choose the new value. A right-end contact returns right regardless of how the ball arrived.

</Question>

## Try to choose the next journey

RUN and try each return. For a rightward return, place the paddle so the ball catches near its right end; for a leftward return, catch near its left end. A centre catch removes sideways movement.

A vertical return may revisit the same cleared column. An edge return can carry the ball towards untouched bricks, but it also changes where the next catch will be. That is why getting underneath the ball and aiming it are different decisions.

These are three discrete directions, not a continuous range of angles. With dy always four after a catch, a diagonal move travels four pixels across as well as four up; a vertical one travels only four up. They therefore do not cover equal distances per update. No trigonometry or constant-speed claim is needed for this game's rule.

If every catch goes vertically, check lines 420–430 and their comparisons. If the ball keeps its old direction through a centre catch, check `LET dx=0` at 410. Keep the paddle width and movement amounts unchanged while judging the new choice.
