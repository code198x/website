Keep the finished program from lesson nine. This lesson changes no numbered lines. We want a tape that starts at the instructions and reconstructs the graphics and wall for itself.

## Save the entry point

Press Q to return to BASIC. Follow the [Meet BASIC tape workflow](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) using this unnumbered command:

```basic
SAVE "bricks" LINE 10
```

LINE 10 records where execution should begin after loading. That line installs the six custom characters and visits the title before initialising the round. Starting in the middle could rely on graphics or variables left behind by a previous run.

Follow the ROM's recording prompt, then export the recording through your emulator's tape controls. Keep the readable source too. Check which recording you export if the tape contains more than one program.

## Load into a fresh session

Start a fresh 48K Spectrum session, attach the tape and enter:

```basic
LOAD "bricks"
```

Start playback. The title should appear automatically. If the ROM keeps searching, check the recording name, tape position and playback. If the wrong version appears, check which tape was attached.

Press S, move the waiting ball and serve. Make a catch, miss deliberately, retry and check that all eighteen bricks return. Play through a clearance, then retry and quit. This checks that the saved program can recreate a round without depending on the old session's memory.

<Question prompt="Does a saved picture of eighteen bricks preserve the rules of the game?">

No. The game needs its program, character data and initialisation. The picture cannot tell a fresh BASIC session how to move the ball, remember removed bricks or restart a round.

## Keep the representations separate

The six character designs and program are original course material under the [samples repository's MIT licence](https://github.com/code198x/code-samples/blob/main/LICENSE). The brick array decides which obstacles exist; rectangle coordinates decide contact; the character data decides how they look.

For a small experiment, change a brick row's colour at lines 1040–1060 and predict what will happen to collision. Play to check it. The same rectangles and live entries should produce the same rules. Restore your preferred colours before saving the version you want to keep.

We have a complete one-wall game: catch, aim, clear or miss, and try again. Keep this version before experimenting with different dimensions or movement amounts. Those values work together; a larger step can cross a thin obstacle without ever landing inside it.
