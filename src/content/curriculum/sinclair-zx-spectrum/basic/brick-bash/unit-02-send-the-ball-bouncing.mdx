## A direction is two changes

Line 110 starts dx and dy at 4. Adding dx moves right; adding dy moves up. A negative value reverses that axis. Line 350 puts the proposed coordinates in nx and ny while x and y still describe the visible ball.

Keep those pairs separate. We may alter a proposed move or reject it entirely before touching the old picture. `steps` counts committed moves; it is a useful trace counter, not a clock or score.

## Bounce the overshoot back

The ball occupies x through x+1. With walls at 15 and 240, its lower-left x must stay between **16 and 238**. Its top pixel is y+1, so y must stay at or below **149**, leaving a clear pixel below the court's top line at 152.

Suppose a move proposes nx=239. It is one pixel beyond the right limit 238. Reflecting it gives 238−1=237. Line 370 writes that as `476-nx`: twice the boundary minus the proposed position.

The other reflection formulas follow the same idea. `32-nx` reflects around x=16, and `298-ny` reflects around y=149. `ABS dx` removes the sign; assigning a negative absolute value guarantees leftward movement, while a positive one guarantees rightward movement.

## Commit one move

Line 490 toggles the old ball off. Line 500 copies nx/ny into x/y and increments steps. Line 510 draws at the new position and returns to keyboard polling. A subroutine call returns; GO TO changes where execution continues without keeping a return address.

`INKEY$` reads a key without waiting for one. With no key, k$ is an empty string and the ball still moves. Q branches to the exit routine; R returns to line 100 to rebuild the initial state. The comparisons accept both lower- and upper-case letters.

An IF condition controls the rest of its BASIC line. In line 390, both assigning e$ and jumping to 4000 happen only when ny is below 32. That candidate is rejected: the last valid ball remains visible.

## Stop, retry, leave

The result routine clears the old message, prints e$ and offers R/Q. Line 4020 waits until the previous key is released. Otherwise a held key could immediately carry us into another attempt. The later polling loop waits for the next choice.

RUN it without touching a key. Watch the right wall and top reflection, then the bottom stop. Retry with R and leave with Q. To investigate the left wall, temporarily give dx the value -4 in line 110, predict the first bounce and run again. Restore dx=4 afterwards.

If a trail remains, check the order of lines 490–510. If the ball never moves, check GO TO 200 at the end of line 510. This loop has no deliberate delay. Its pace comes from the work BASIC performs, so later stages can move more slowly.
