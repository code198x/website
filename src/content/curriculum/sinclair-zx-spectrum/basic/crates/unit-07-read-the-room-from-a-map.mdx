The room currently lives in several assignments and a border-building loop. A small map would let us see the layout in one place. We will change its representation while keeping the same room and movement rules.

## Choose an alphabet

Each string is one row, and each character describes one cell:

| Symbol | Meaning | Stored cell |
|---|---|---|
| `-` | Floor | 0 |
| `#` | Wall | 1 |
| `.` | Target | 2 |
| `C` | Crate on floor | 3 |
| `*` | Crate on target | 4 |
| `P` | Player on floor | 0, plus player coordinates |
| `+` | Player on target | 2, plus player coordinates |

Use eight **visible symbols** per row. A dash is floor; a space is not part of this alphabet. The combined symbols preserve the cell underneath an object.

## Decode one character at a time

Line 20 creates the empty array, resets the count and completion flag, then calls 4000. This replaces the old assignments. `RESTORE 8000` tells READ where the map begins. The graphics routine has its own `RESTORE 7200`; neither routine relies on where the other last stopped reading.

For each row, `READ m$` takes the next string. The column loop extracts `m$(c)`, a one-character slice, into `b$`. Lines 4030–4090 translate the symbol into `v`, then line 4100 stores it in the grid. For P or +, we also record `pr,pc`. The player never becomes a cell code.

`v` starts at -1 for each character so an unrecognised symbol cannot silently reuse the previous cell's code. This version still assumes the supplied map is valid; the next lesson will reject that -1 and other malformed input before play.

The eight DATA rows reproduce the preceding room exactly. R calls the loader again, rebuilding the original positions from those strings. Moving a crate changes `g`, not the DATA text.

After loading, 6000 counts the targets. Line 86 recognises a map whose crates already cover them all. That makes completion depend on the loaded state as well as later pushes.

<Question prompt="Why must the map loader use RESTORE 8000 even though it reads only strings?">

Graphics loading has already advanced the shared DATA reader. READ does not choose a DATA section by the variable’s type. RESTORE explicitly selects the map before any row is read.

</Question>
