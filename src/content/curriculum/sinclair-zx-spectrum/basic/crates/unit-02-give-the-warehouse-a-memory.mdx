A picture tells us what the warehouse looks like. The game also needs to know what is in each square. We will keep that information in an array and use it to reconstruct the picture.

Continue from the restored crate program. This lesson has three runnable stages: a collection of tiles, a room, then a player.

`GO SUB 7000` calls the graphics routine; `RETURN` at 7060 resumes after that call. The loop now reads **160 bytes**, enough for twenty custom characters. The crate's pixels have not changed, but its character codes move to **152–155** because walls and targets come first.

`DIM t$(7,4)` creates **seven strings of four characters each**. The final dimension of a Spectrum string array is the string length. `t$(4)` is the fourth complete string; `t$(4,1 TO 2)` is its first pair of characters. Assignments shorter than four characters are padded with spaces; longer ones are cut to length. This is why each tile fits its row exactly.

`DIM a(7)` holds seven ink colours. Matching positions in the two arrays describe one appearance:

| Appearance index | Four-character image | Ink |
|---|---|---|
| 1 | Four spaces: floor | Black, 0 |
| 2 | Brick wall | Blue, 1 |
| 3 | Target ring | Cyan, 5 |
| 4 | Crate | Yellow, 6 |
| 5 | Same crate | Green, 4 |
| 6 | Player | White, 7 |
| 7 | Player with target ring | Cyan, 5 |

The loop at line 20 prints all seven appearances in order. The first is invisible against black paper. The delivered crate reuses the wooden design in a different colour. The last player design includes a ring, so a target remains visible beneath the player's feet.

## Store an eight-by-eight room

The tile arrays describe appearances. A different array, `g`, will describe the warehouse. Its two indices are row and column, both running from 1 to 8.

Replace lines **10, 20, 30, 40, 50**.

Add lines **15, 60, 70, 80, 100, 110, 1000, 1010, 1040, 1050, 1060, 1080, 2000, 2010, 2030, 2040**.

`DIM g(8,8)` creates 64 numeric cells, initially zero. We use **0 for floor, 1 for wall, 2 for target and 3 for crate**. Lines 30–50 visit every cell. The outer loop selects a row and the inner loop visits its columns. A cell on any outside edge becomes a wall. Lines 60–70 place two inner walls, one target and one crate.

The routine at 1000 clears and redraws the whole room. For each cell it calls 2000. That routine turns board coordinates into screen positions: `y = 3 + 2 * (r - 1)` and `x = 8 + 2 * (c - 1)`. Each tile occupies two character rows and columns. Board `(1,1)` starts at screen `(3,8)`; board `(8,8)` starts at `(17,22)`.

`z = g(r,c) + 1` converts a cell code beginning at zero into an appearance index beginning at one. For example, a crate is world code **3** but appearance **4**. Neither number is an ink colour or a pixel byte. Line 2030 prints the two slices with the chosen ink.

Run it. All four corner cells should be brickwork. The inner wall is at `(3,4)` and `(4,4)`, the target at `(3,5)` and the crate at `(5,4)`. There is no player yet: line 80 remembers a position, but nothing draws it.

Line 2020 substitutes appearance 6 when the cell being drawn matches `pr,pc`. Line 2025 selects appearance 7 if that cell contains a target. These lines change `z`, the choice of picture, **without changing `g(r,c)`**. The player therefore needs only two coordinates; the floor underneath remains in the array.

<Question prompt="Why not replace the target with a player code in the grid?">

We would then need another way to remember that a target was underneath. Separate player coordinates let the drawing routine show the player while the array keeps the original floor or target.

</Question>

Run and find the player at `(6,3)`. For a temporary experiment, replace line 80 with the same line using `pr = 3` and `pc = 5`. Run: the player should include the target ring. Restore **pr = 6, pc = 3**, keeping the other assignments on that line, and run again. The target reappears because its stored cell never changed.

If the room is shifted, check the coordinate calculation. If a wall looks like a crate, check the cell-code-to-appearance conversion before changing the artwork. The room and its drawing now have separate jobs.
