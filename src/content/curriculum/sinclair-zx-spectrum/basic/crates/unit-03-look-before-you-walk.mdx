Lines 150–190 translate I, J, K and L into offsets. Up means one row less (`dr = -1`); right means one column more (`dc = 1`). Each input starts with both offsets zero, so an unrecognised key cannot reuse the previous direction. We accept lower-case and upper-case letters.

`nr,nc` are the **candidate** row and column. Line 220 rejects values outside 1–8 before line 230 looks up `g(nr,nc)`. This order matters even though our current room has border walls: another map might have an open edge. Indexing row 0 would be a BASIC error, not a collision check.

Line 240 rejects walls and crates. At this stage crates are solid obstacles. Floor and targets lead to line 500. We remember the old player position, accept the candidate position and increase `moves` once. A failed attempt returns to input through line 700 without reaching that increment.

## Restore the squares we leave

Lines 520–530 draw the old and new player cells. At the old location, the overlay no longer matches, so the stored floor or target is drawn again. At the new location it does match, so the player appears. There is no need to clear and redraw all 64 cells after every step.

The new routine at 2500 prints the count. The spaces after the number erase leftover digits when a shorter count is drawn. Q goes to 9000, prints a closing message and stops. There is no restart key yet; use Q and `RUN` to begin again.

## Read a deliberate press

`INKEY$` reads the keyboard immediately and returns a character, or the empty string `""`. It does not wait for Enter. Our routine at 3000 compares that reading, `k$`, with the previous reading, `h$`.

An unchanged reading loops without returning an action. A changed reading becomes the remembered value. Empty readings keep waiting, but still clear the remembered key. This means holding I produces one step; releasing and pressing I again produces another. Changing directly to L can also produce a step when L is read.

This is polling, not a queue of key events. A very short tap made while BASIC is drawing can be missed. Press one direction at a time and let the move finish. The Spectrum can return an empty string when several ordinary keys are down, so overlapping keys are not a reliable way to steer.
