Crates is a push puzzle. You can push a crate one square at a time. You can never pull. You can only push one crate, never two. Push a crate into a corner and it is stuck forever.

That is every rule. Three levels, three puzzles, all built from those constraints. The game has no enemies, no timer, no randomness. Just you, the crates, and the targets. Every mistake is yours. Every solution is earned.

This is the eighth game in Volume 2 — **Patterns of State** — and the most spatial of them: the 2D array *is* the world, and the screen is only its picture. Every wall, floor, target and crate is a number in the grid; movement, collision, pushing and winning are all just reading and writing that one array.

**What you will learn:**

- A 2D array as the authoritative game state — the screen is just the display
- DATA-driven level layouts — puzzles defined as strings, loaded into arrays
- `INKEY$` for responsive grid movement without pressing ENTER
- Two-cell lookahead — check what is beyond the crate before pushing
- Level progression with `RESTORE` — multiple puzzles in one program
- The design principle that constraint creates depth

**10 units. About 12–16 hours.**
