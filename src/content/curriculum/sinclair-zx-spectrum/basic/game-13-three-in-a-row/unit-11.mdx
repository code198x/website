## What the record reveals

Play ten games. The record will likely read something like "W: 0 L: 1 D: 9." The computer almost never loses. You might sneak a win in early games before the AI has all its layers, but against the full strategy, draws dominate.

That W:0 L:1 D:9 IS the lesson. Noughts and Crosses is a solved game — perfect play by both sides always draws. The computer's four-tier AI (win, block, centre, corners) is not perfect, but it is good enough that beating it requires finding a specific flaw. The running record proves the point more convincingly than any explanation could.

## What you have built

Three in a Row is complete. Seventy-five lines: a title screen, a 3×3 board with numbered positions, player input with validation, win detection via DATA-driven line scanning, four-tier AI (win → block → centre/corners → any), draw detection, three outcome screens with colour and sound, a replay loop with running W/L/D record.

This is the first adversarial game — the program plays against you, not with you. The AI is not intelligent; it is a priority list. But it feels intelligent because it makes the right move in the right situation. The four layers build one at a time, and each layer changes the game's character. That layered construction is how real game AI works.
