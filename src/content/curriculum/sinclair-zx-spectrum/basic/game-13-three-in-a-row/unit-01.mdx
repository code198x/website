Three in a row. Three noughts or three crosses, connected horizontally, vertically, or diagonally. Before anyone can play, the board needs to exist.

Line 90 creates the board: `DIM b(9)` — nine positions, one per square. Lines 150–220 draw the grid. For each position 1–9, the program calculates the screen row and column from the position number using `INT((n-1)/3)` for the row and the remainder for the column. Line 190 prints the position number using `CHR$(48 + n)` — converting the number to its ASCII character so it prints as a single digit without the leading space that `PRINT n` would add.

Lines 230–240 draw the horizontal grid lines: `---+---+---`.

## Number-to-grid mapping

The board has nine positions, numbered 1–9 like a phone keypad:

```
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

The formula `INT((n-1)/3)` converts a position number to a row: positions 1–3 are row 0, 4–6 are row 1, 7–9 are row 2. The column is the remainder: `n - 1 - row * 3`. This mapping lets a single FOR loop draw all nine cells without hardcoding each position's screen coordinates.

The player will pick positions by number — type "5" for the centre, "1" for the top-left. The numbers double as both the input interface and the visual guide.
