The random computer loses because it ignores threats. This unit teaches it to notice when the player is about to win — and step in the way.

Lines 610–710 replace the random-only AI. `mv` starts at 0 (no move chosen). The FOR loop scans all eight winning lines. Lines 680–700 check each line for a blocking opportunity: if two of the three positions belong to the player (value 1) and the third is empty (value 0), that empty square is the block. Set `mv` to that position.

Line 720: if a block was found, skip the random fallback. Lines 730–740 still pick randomly when no threat exists.

## Threat detection

Each winning line has three permutations to check: positions (p,q,f). The player might have any two of the three. Line 680 checks `b(p)=1 AND b(q)=1 AND b(f)=0` — the first two are X and the third is empty. Lines 690–700 check the other two arrangements. The `mv = 0` guard means only the first threat found is acted on.

Play against the blocking AI. Try to set up a line — the computer will step into the third square. It is no longer easy to win with an obvious line. But it still does not take its own winning opportunities. You need to set up two threats at once — a fork — to beat the blocker.
