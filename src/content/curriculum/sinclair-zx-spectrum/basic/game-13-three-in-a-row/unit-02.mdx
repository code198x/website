Line 250 asks for a position (1–9). Line 260 validates the range. Line 270 checks whether the square is already taken — `IF b(m) <> 0` — and sends the player back with a message if so. Line 280 marks the square: `LET b(m) = 1`. The value 1 means "player's X."

## Three cell states

Each cell in `b()` holds one of three values:
- **0** — empty (shows the position number)
- **1** — player's X (shows cyan X)
- **2** — computer's O (added next unit)

The position number disappears when a cell is filled. The player can see at a glance which squares remain available — they still have numbers. Occupied squares show X or O instead. The board is self-documenting: the available moves are visible.
