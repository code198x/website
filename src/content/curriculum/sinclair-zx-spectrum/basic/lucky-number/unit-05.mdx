One new line: `230 GO TO 120`. After the wrong-guess messages, the program jumps back to line 120 and asks again. The loop runs until the player guesses correctly — line 200 prints "Got it!" and `STOP` breaks out.

Run it. Guess wrong a few times. Watch the trail of guesses scroll up the screen. Each one narrows the range. Five or six guesses and you have it.

## The game loop

That `GO TO` creates a **loop** — a stretch of program that repeats:

- **Body**: lines 120–220 (ask, check, respond)
- **Exit**: line 200 (`IF g = n THEN ... STOP`)
- **Return**: line 230 (`GO TO 120`)

Every game has a loop. In a guessing game, the loop asks a question each time. In an action game, the loop updates the world each frame. The shape is the same: do something, check if we should stop, go round again.

## Try breaking it

Delete line 230 (type `230` and press Enter with nothing after it). Run the program and guess wrong. It ends after one guess — no loop, no game.

Now remove `STOP` from line 200. Guess correctly. The program prints "Got it!" — then asks for another guess. Without `STOP`, the loop never ends.

Both the loop and the exit are essential. One without the other is either a single turn or an infinite loop.
