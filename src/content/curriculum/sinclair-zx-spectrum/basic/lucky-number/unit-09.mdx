## The counter pattern

`LET c = 0` before the loop. `LET c = c + 1` inside the loop. After the loop, `c` holds the total. This pattern — initialise, increment, read — appears in almost every game. Scores, timers, lives, turn counts: all counters.

## PAUSE 0

`PAUSE 0` halts the program until the player presses any key. The `0` means "wait forever" — no timeout. Without it, the title screen flashes past before the player reads it. With it, the game feels *offered*, not *inflicted*. The player decides when to begin.

## The green border

Line 300 adds `BORDER 4` — green — when the player wins. The border has been shifting all game. Green at the end says "done, well done."
