## How IF/THEN works

`IF` checks a condition. If true, the computer does whatever follows `THEN`. If false, it skips to the next line.

- `IF g = n THEN PRINT "Got it!": STOP` — if the guess equals the secret, celebrate and stop.
- `IF g < n THEN PRINT "Too low!"` — if the guess is smaller, say so.
- `IF g > n THEN PRINT "Too high!"` — if the guess is bigger, say so.

The comparison operators: `=` (equal), `<` (less than), `>` (greater than), `<>` (not equal), `<=`, `>=`.

You can put multiple commands after THEN by separating them with colons: `PRINT "Got it!": STOP` prints *and* stops, all on one line.

## Response gets teeth

The program's output now depends on what the player did. The computer reasons about your input and reacts differently each time. This is the design concept **feedback** — the program speaks *about you*, not just *at you*.

But the game ends after one guess. That is not a game — it is a turn. The next step makes it keep asking.
