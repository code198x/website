## The chained IF pattern

You already know `IF/THEN` and `RND` from Lucky Number. What is new is using them *together* to select from a fixed set:

```
LET r = INT (RND * n) + 1
IF r = 1 THEN ...
IF r = 2 THEN ...
IF r = 3 THEN ...
```

Each IF is a slot. The random number picks which slot fires. Add more slots to add more answers — just increase the range to match. That is exactly what the next unit does.
