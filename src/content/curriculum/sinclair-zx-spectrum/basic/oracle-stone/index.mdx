Oracle Stone is not a game — it is a toy. Ask a question, watch the Oracle think, read the answer. The answer is random, but the ceremony of asking makes it feel deliberate.

<Figure src="/images/sinclair-zx-spectrum/basic/oracle-stone/unit-10/screenshot.png" alt="Blue ZX Spectrum chamber screen: a centred title, cyan block bars, and a cyan answer" caption="Where you are headed: the Oracle's chamber delivers its verdict." />

Most of Oracle Stone reuses what you already know — `IF/THEN`, `RND`, `PRINT`, `INPUT` from Lucky Number — in a new pattern: chaining `IF/THEN` on a random number to pick from a set of pre-written answers. The last two units add polish: colour for the answer, then a subroutine and a little block graphics.

**What you will learn:**

- Chained `IF/THEN` — selecting from a fixed set
- `PAUSE` and `BEEP` for dramatic timing
- `INK` and `PAPER` for atmosphere
- `GO SUB` — subroutines: write code once, call it anywhere
- `FOR`/`NEXT` and `CHR$ 143` — simple block graphics
- The design concept: **Chance** — the program decides

**10 units. About 6–8 hours.**
