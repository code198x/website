## Whole people, whole rations

`INT (feed/3)` counts complete three-grain rations. INT rounds down. With 179 grain, the result is 59; two spare grain do not form the sixtieth ration. Line 2010 caps fed at pop, so feeding 183 cannot create a sixty-first resident.

The proposed balance is `grain-feed`. An IF compares that balance with zero. `ok` is a numeric flag: one means the plan passes the checks so far, zero means it does not. We will use it to block a commitment later. At present it explains the displayed warning.

`m$` is a string variable holding that warning. Spectrum string-variable names use one letter followed by `$`. STR$ converts a number into text, and `+` joins strings. This lets the message include the actual number of people who would go without food.

IF applies to the rest of its BASIC line. An assignment after THEN happens only when the comparison is true. Later warning assignments can replace earlier ones: a negative grain balance is a more immediate problem than whether everyone is fed.
