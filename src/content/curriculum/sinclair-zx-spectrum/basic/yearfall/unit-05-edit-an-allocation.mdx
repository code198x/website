RUN, press F, type 179 and press Enter. The plan should warn that one person would starve. Press F again and X to cancel: the allocation must remain 179. Enter 180 to restore full food. Space commits one harvest; the report waits for R to restart or Q to quit. There is no next year yet.

## Read one press

The routine at 8000 first waits for the previous key to be released. INKEY$ returns an empty string when no character is pressed. It then waits for a new character and returns it in k$. Every caller uses the same contract. Holding a digit must append it once; holding Space must not rush through a report.

The planning loop handles Q, R and F. An unmatched key returns to waiting. Space reaches the harvest only when ok is one. A false IF skips the rest of that line, so rejected input does not accidentally fall into the resource changes.

## Keep text until it is safe to convert

The editor builds a string, d$. It begins empty so typing a new amount replaces the existing allocation. CODE gives a character's numeric code: Enter is 13, Delete is 12, and digits run from 48 to 57. Other characters are ignored. LEN supplies the string length; the four-digit limit prevents unbounded entry.

Deleting uses a slice ending one character before the old end. With one character, the result is empty. X returns without assigning feed. Enter on an empty string also leaves the old allocation intact. Only a nonempty string made entirely of digits reaches VAL, which turns it into a number. We never ask VAL to evaluate arbitrary player text.

<Question prompt="Why does typing 9 and then X leave the old food allocation intact?">

The 9 lives only in d$. Cancelling returns before line 6220 assigns the converted value to feed. A draft entry is not yet a draft plan, and neither is committed settlement state.

Try a held digit, Delete, an empty Enter and a letter. Then enter 9999: the editor accepts a whole number, but the budget rejects spending it. Input syntax and game rules are different checks. INKEY$ is entered with N in extended mode; LEN uses K, VAL uses J, and CODE uses I in extended mode.
