A quiz needs to check whether an answer is in range — between 1 and 3. Until now, you'd need two separate IF statements. `AND` and `OR` let you combine conditions into one.

## AND — Both Must Be True

`IF n >= 1 AND n <= 100` only passes when `n` is at least 1 **and** at most 100. If either condition fails, the whole thing fails.

## OR — Either Can Be True

`IF a$ = "A" OR a$ = "B" OR a$ = "C"` passes when `a$` matches **any** of the three options. Only one needs to be true.

## When to Use Which

- **AND** for ranges: "the number must be at least 1 AND at most 3"
- **OR** for options: "the answer must be A OR B OR C"
- **AND** with `<>` for rejection: "not A AND not B AND not C" means none of them

## For the Quiz

Input validation becomes one line:

```
IF g < 1 OR g > 3 THEN PRINT "Pick 1, 2 or 3!": GO TO 130
```

If the answer is below 1 **or** above 3, it's invalid. This replaces two separate checks.

## Try This

**Age check.** Ask for an age. Use AND to check it's between 5 and 120. Print "Valid" or "That can't be right!"

**Yes or No.** Ask a question. Accept "Y", "y", "N", or "n" using OR. Reject anything else.

## What You've Learnt

- **AND** — both conditions must be true: `IF x > 0 AND x < 10`
- **OR** — at least one must be true: `IF a$ = "Y" OR a$ = "y"`
- **Validation** — reject bad input in a single line and loop back
