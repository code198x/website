Each READ advances through the DATA. After the last item, there's nothing left to read. If you want to use the same DATA again — to replay the quiz, or read a different set of values — you need `RESTORE`.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-06-quiz-master/unit-04/restore-demo.bas" />

The first loop reads "cat", "dog", "fish". RESTORE rewinds to the beginning. The second loop reads them again. Without RESTORE, the second loop would get an error — there's no more DATA to read.

RESTORE completes the DATA/READ toolkit. DATA stores content. READ pulls it out. RESTORE rewinds so you can pull it out again. Together they let you store game content (questions, words, levels) separately from code, read it during play, and optionally replay from the start.

## What You've Learnt

- **RESTORE** rewinds DATA so the next READ starts from the beginning
- Without RESTORE, DATA can only be read once
- RESTORE enables **replay** — play the quiz again without restarting the program
- DATA + READ + RESTORE = the complete content pipeline for BASIC
