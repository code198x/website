## What's New

**Input validation (line 140).** `IF g < 1 OR g > 3` catches invalid answers and loops back to the INPUT. The player must pick 1, 2, or 3 — nothing else is accepted.

**Colour feedback (lines 150-160).** Green (INK 4) for correct, red (INK 2) for wrong — the same pattern from Word Scramble.

**CLS between rounds (line 190).** Each question gets a fresh screen. Without this, questions would stack up and scroll off the top.

**Question counter (line 50).** "Question 1 of 5" tells the player how far through the quiz they are.

## Five Questions in DATA

Lines 300-340 store five complete questions. Each READ pulls five values (question, three options, answer number). The FOR loop runs exactly five times — one per question.

If you added a sixth question to DATA but left the loop at 5, the sixth would never be read. The loop count and DATA count must match.

## Try This

**Show the correct answer on wrong.** After "Wrong!", print which option was right: `PRINT "The answer was "; r`. The player learns even when they miss.

**Harder questions.** Replace the five DATA lines with your own questions. Mix easy and hard — the player feels smart getting the easy ones and challenged by the hard ones.

## What You've Learnt

- **Input validation** — `IF g < 1 OR g > 3 THEN GO TO` rejects bad input
- **CLS per round** — fresh screen for each question
- **Running score** — increment `n` on correct, display total at the end
- **DATA/loop matching** — the number of DATA sets must match the loop count
