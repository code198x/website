Quiz Master's results screen aligns category names and scores in neat columns:

```
Science:       3
History:       1
Geography:     2
Entertainment: 0
```

`TAB n` moves the print position to column n on the current line: `PRINT "Score:"; TAB 20; sc`. This aligns values regardless of how long the label is. Without TAB, you'd pad with spaces manually — fragile and tedious.

TAB is a formatting tool. It doesn't change what you display — it changes how it *looks*. A column of numbers aligned on the right is easier to read than numbers scattered at random positions. This is **visual hierarchy** — the arrangement of information guides the reader's eye. Scores in a column invite comparison. Labels on the left, values on the right, consistent spacing between — this is how dashboards, leaderboards, and stat screens work in every game.

## What You've Learnt

- **TAB n** moves the cursor to column n within a PRINT line
- **Alignment** makes information easier to read and compare
- **Visual hierarchy** — how you arrange information guides the player's attention
