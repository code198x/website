So far, each IF/THEN has checked one condition. But sometimes you need to check two things at once. Quiz Master validates input with:

```
IF k$<>"a" AND k$<>"b" AND k$<>"c" AND k$<>"d" THEN GO TO 52
```

Four conditions joined by AND. ALL must be true for the GO TO to fire. If the player pressed anything other than a, b, c, or d, loop back and wait.

**AND** — both conditions must be true: `IF x>0 AND x<31` (x is within bounds)

**OR** — either condition can be true: `IF k$="y" OR k$="Y"` (accept upper or lower case)

**NOT** — reverses a condition: `IF NOT found THEN PRINT "Still searching"`

These **logical operators** let you express complex conditions in one line. Without them, you'd need nested IFs or multiple checks. With them, the intention reads clearly: "if the key is not a valid option, try again."

## What You've Learnt

- **AND** — both conditions must be true
- **OR** — either condition can be true
- **NOT** — reverses true/false
- Combine conditions to make **precise, readable checks**
