This is the last Foundations game — after Quiz Master, you'll have the complete BASIC toolkit. The game itself is a multiple-choice quiz with eight questions across four colour-coded categories. But the real lesson is how the code is *organised*.

Look at line 48: `GO SUB 300`. One line draws the entire question card — the header bar, the category label, the question text, the four options. It draws a different card for every question, but it's the same code every time. That's a **subroutine** — and it's the first step toward structured programming.
