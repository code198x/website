Over the next eight units you'll build Quiz Master — a quiz with categories and score tracking. But first, you need somewhere to store multiple scores.

## The Problem

Imagine a quiz with four players. You could use four variables: `a`, `b`, `c`, `d`. But what if you want to print all scores in a loop? You can't write `FOR i = 1 TO 4: PRINT s(i): NEXT i` without an array.

## DIM

`DIM s(4)` creates an array called `s` with 4 slots, numbered 1 to 4. Each slot holds a number, starting at 0.

`LET s(2) = 25` puts the value 25 into slot 2. `PRINT s(2)` reads it back. The number in brackets is the **index** — it tells the Spectrum which slot you mean.

## Arrays and Loops

The power of arrays is that you can use a variable as the index. `s(i)` in a `FOR` loop accesses a different slot each time. The total loop (lines 120-150) adds up all four scores without naming each one.

## Rules

- **DIM before use** — you must declare the array's size before storing anything
- **Starts at 1** — `DIM s(4)` creates slots 1, 2, 3, 4 (not 0-3)
- **All zeros** — every slot starts at 0
- **Fixed size** — you can't make an array bigger after DIM

## Try This

**Average score.** After the total, calculate and print the average: `LET a = t / 4`. What happens if you change the scores?

**Find the highest.** Write a loop that tracks the biggest value: start with `LET h = s(1)`, then `IF s(i) > h THEN LET h = s(i)` in a loop.

## What You've Learnt

- **DIM** — creates an array: `DIM s(4)` makes 4 numbered slots
- **Array access** — `s(i)` reads or writes slot number `i`
- **Loop access** — arrays and FOR loops work together naturally
