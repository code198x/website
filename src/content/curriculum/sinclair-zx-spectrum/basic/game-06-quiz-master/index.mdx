Eight questions. Four categories — Science, History, Geography, Entertainment. Press A, B, C, or D. Get a score per category and an overall rating.

![A question card — category, question, four options](/images/sinclair-zx-spectrum/basic/game-06-quiz-master/overview/question.png)

## How It Works

Quiz Master teaches **structure** — organising code into reusable pieces. The question card is a GO SUB subroutine: one piece of code that draws any question, called eight times with different data. The per-category scores use an array — one indexed structure instead of four separate variables. RESTORE lets the quiz replay from the beginning.

Structure is the difference between a program that works and a program you can change.

## What You'll Learn

- **GO SUB / RETURN** — reusable subroutines
- **DIM** — arrays for indexed storage
- **RESTORE** — rewinding DATA
- **AND / OR / NOT** — combining conditions
- **TAB** — formatted display
