## What You'll Build

A quiz game with three categories — Science, Geography, and History. Each category has three questions with multiple-choice answers. The game tracks your total score across all categories and rates your performance.

![Quiz Master gameplay — Science category](/images/sinclair-zx-spectrum/basic/game-06-quiz-master/gameplay.png)

## Why This Game?

Word Scramble stored its word list in DATA statements and read through them one by one. But what if you want to go back and read the same data again? Or jump to a different section?

`RESTORE` solves this — it rewinds the DATA pointer so you can read the same values again, or jump to a specific line. Combined with arrays for storing scores and `AND`/`OR` for combining conditions, you have the full BASIC toolkit for building real programs.

## What You'll Learn

- **DIM and arrays** — storing multiple values in numbered slots
- **AND / OR** — combining conditions in a single IF statement
- **Multiple-choice questions** — displaying options and checking answers
- **Input validation** — rejecting answers outside the valid range
- **RESTORE** — rewinding DATA to read it again or jumping to a line
- **Categories** — using RESTORE to select different question sets
- **Code organisation** — structuring a larger program into logical sections

## Prerequisites

Complete [Game 5: Word Scramble](/sinclair-zx-spectrum/basic/game-05-word-scramble/) first. You'll need `DATA`/`READ`, `LEN`, string variables, and colour commands.
