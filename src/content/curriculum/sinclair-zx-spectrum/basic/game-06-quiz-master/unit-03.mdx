Quiz Master tracks scores for four categories. You could use four variables: `LET s1=0`, `LET s2=0`, `LET s3=0`, `LET s4=0`. But what if there were ten categories? Or a hundred?

An **array** stores multiple values under one name, accessed by number:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-06-quiz-master/unit-03/array-demo.bas" />

`DIM s(4)` creates an array with 4 slots. `s(1)` is Science. `s(2)` is History. `s(3)` is Geography. `s(4)` is Entertainment. The number in brackets is the **index** — it selects which slot to read or write.

In Quiz Master, when the player answers a Science question correctly: `LET s(p) = s(p) + 1` where `p` is the category number (1-4). One line handles all four categories. The index `p` comes from the DATA — the question carries its own category number.

Arrays are the first real **data structure** — a way of organising multiple values so code can work with them systematically. Every game from here on uses them.

## What You've Learnt

- **DIM s(n)** creates an array with n slots
- **s(i)** accesses slot i — read or write
- Arrays replace **multiple separate variables** with one indexed structure
- The index can be a **variable** — `s(p)` where p changes each question
