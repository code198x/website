## What You'll Build

A typing game where words fall from the top of the screen. Type each word before it reaches the bottom. Complete five in a row for a streak bonus. Miss three and the game is over.

![Word Worm gameplay — falling word with HUD](/images/sinclair-zx-spectrum/basic/game-09-word-worm/gameplay.png)

## Why This Game?

Minefield taught you to store data in arrays. Word Worm teaches you to store *text* in arrays. A string array holds 50 words. You'll pick them at random, compare individual characters, and build strings letter by letter.

This is also your first game where the screen changes *without* the player pressing anything. The word falls continuously — the game loop runs whether or not a key is held. Input and animation happen in the same loop, controlled by a counter-based timer.

## What You'll Learn

- **String arrays** — `DIM w$(50,7)` stores 50 words
- **DATA/READ for strings** — loading word lists from data statements
- **String slicing** — `a$(p TO p)` extracts a single character
- **CHR$ and CODE** — characters as numbers, numbers as characters
- **Building strings** — concatenating one character at a time
- **Counter-based timing** — controlling animation speed without PAUSE
- **Word completion** — detecting when all characters are typed
- **Miss tracking** — counting failures, game over after three
- **HUD design** — score, level, misses, and streak on one line
- **Level progression** — faster falls, longer words
- **Streak bonuses** — rewarding consecutive completions
- **Sound design** — pitch based on word length
- **GO SUB architecture** — subroutines for input, movement, HUD

## Prerequisites

Complete [Game 8: Minefield](/sinclair-zx-spectrum/basic/game-08-minefield/) first. You'll need 2D arrays, `GO SUB`, `INKEY$` loops, and game state tracking.

## Time Investment

16 units at 45-75 minutes each. Roughly 12-20 hours total.
