## How It Works

**Line 110** tracks the current position in the word: `LET p = 1`. The player needs to type character 1, then 2, then 3.

**Line 130** shows which letter is expected: `PRINT AT 21, 0; "Next letter: "; a$(p TO p)`.

**Lines 240-250** compare the keypress:

```
240 IF k$ = a$(p TO p) THEN ... LET p = p + 1
250 PRINT AT 20, 0; INK 2; "Wrong: "; k$
```

`a$(p TO p)` extracts the single character at position `p`. If the keypress matches, advance `p`. If not, show "Wrong" in red.

**Line 270** checks for completion: `IF p > LEN a$` — all characters have been typed.

## String Slicing

`a$(p TO p)` extracts one character from position `p`. This is string slicing — the same technique you used in Word Scramble.

| Expression | Word "cat" | Result |
|-----------|-----------|--------|
| `a$(1 TO 1)` | position 1 | "c" |
| `a$(2 TO 2)` | position 2 | "a" |
| `a$(3 TO 3)` | position 3 | "t" |

The variable `p` walks through the word one character at a time.

## Try This

**Wrong feedback.** Change the wrong-key display to flash: `PRINT AT 20, 0; INK 2; FLASH 1; "Wrong!"`. Reset it on the next correct key.

**Case check.** What happens if you press a capital letter? Try holding CAPS SHIFT + C when typing "cat". `INKEY$` returns the character as-is, so case matters.

## What You've Learnt

- **Character extraction** — `a$(p TO p)` gets one character
- **Sequential matching** — advance position only on correct input
- **Feedback colours** — green for correct, red for wrong
- **Completion check** — position exceeds word length
