Every character on the Spectrum — letters, numbers, symbols — is stored as a number. `CODE` converts a character to its number. `CHR$` converts a number back to a character. Understanding this connection is essential for string manipulation.

## How It Works

**Lines 100-120** loop through character codes 97 to 122 — the lowercase alphabet:

```
100 FOR i = 97 TO 122
110 PRINT CHR$ i; "       "; i
120 NEXT i
```

`CHR$ 97` returns "a". `CHR$ 122` returns "z". The loop prints each letter alongside its code.

**Lines 150-180** let you explore interactively. Press any key and see its code:

```
170 PRINT AT 20, 0; "Key: "; k$; "  Code: "; CODE k$
```

## Two Directions

| Function | Input | Output | Example |
|----------|-------|--------|---------|
| `CODE` | Character | Number | `CODE "a"` → 97 |
| `CHR$` | Number | Character | `CHR$ 97` → "a" |

They're inverses. `CHR$(CODE "a")` gives "a". `CODE(CHR$ 97)` gives 97.

## Why This Matters

String comparison works character by character. When BASIC checks `IF k$ = a$(p TO p)`, it's comparing character codes. Knowing the codes helps you understand:

- Why "a" and "A" are different (97 vs 65)
- How to check if a character is a letter: `CODE k$ >= 97 AND CODE k$ <= 122`
- How to convert cases: `CHR$(CODE k$ - 32)` turns lowercase to uppercase

## The Spectrum Character Set

| Range | Characters |
|-------|-----------|
| 48-57 | 0-9 |
| 65-90 | A-Z |
| 97-122 | a-z |
| 32 | Space |

The Spectrum uses ASCII-compatible codes for letters and numbers.

## What You've Learnt

- **CODE** — converts a character to its numeric code
- **CHR$** — converts a numeric code to a character
- **Character codes** — lowercase a-z are 97-122, uppercase A-Z are 65-90
- **Characters are numbers** — every string operation works on these codes
