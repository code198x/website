In Lucky Number, you typed lines like `PLOT px+9,py-i` and `DRAW 21,0` without knowing what they did. They were part of the digit renderer — black-box subroutines that produced seven-segment numbers on screen. You typed them on faith.

Now you find out what they do. And once you know, you can draw anything.

## PLOT — A Single Pixel

`PLOT x, y` draws one pixel at coordinates (x, y). The Spectrum's screen is 256 pixels wide and 176 pixels tall. But unlike PRINT AT, where row 0 is the top, PLOT's y coordinate starts at the **bottom**: y=0 is the bottom of the screen, y=175 is the top.

One pixel appears at the centre of the screen. Small, but significant — it's the first time you've controlled an individual dot on screen rather than a whole character cell.

## DRAW — Lines Between Points

`DRAW dx, dy` draws a straight line from wherever the last PLOT or DRAW left off. The numbers aren't a position — they're a **direction**: how far to go right (dx) and how far to go up (dy). Negative numbers go left or down.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-02-wire-panic/unit-03/first-draw.bas" />

![A rectangle drawn with four DRAW commands](/images/sinclair-zx-spectrum/basic/game-02-wire-panic/unit-03-drawing/rectangle.png)

Four lines. PLOT starts at the top-left corner (64, 132). Then:
- `DRAW 128, 0` — right 128 pixels (top edge)
- `DRAW 0, -88` — down 88 pixels (right edge)
- `DRAW -128, 0` — left 128 pixels (bottom edge)
- `DRAW 0, 88` — up 88 pixels (left edge, back to the start)

Each DRAW picks up where the previous one stopped. The four lines form a closed rectangle. This is exactly how Wire Panic draws its device box — `PLOT 40,168: DRAW 176,0: DRAW 0,-96: DRAW -176,0: DRAW 0,96`.

## Pixel Coordinates vs Character Coordinates

You now have two ways to put things on screen:

| | PRINT AT | PLOT / DRAW |
|---|----------|-------------|
| **Units** | Character cells (8×8 pixels) | Individual pixels |
| **Grid size** | 32 columns × 22 rows | 256 × 176 pixels |
| **Origin** | Top-left (row 0, col 0) | Bottom-left (x=0, y=0) |
| **Y direction** | Down (row 0 = top) | Up (y=0 = bottom) |
| **Best for** | Text, labels, UI | Shapes, lines, graphics |

PRINT AT is coarse — each cell is 8×8 pixels. PLOT is precise — every pixel is yours. Wire Panic uses both: PRINT AT for text labels and PLOT/DRAW for the device graphics. Different tools for different jobs.

## Drawing Something Real

With PLOT, DRAW, and INK, you can draw recognisable shapes:

Yellow walls. A red pointed roof. A blue door. Two cyan windows. Ten lines of code, and there's a house on screen — not text that says "house", but a picture of one. Each section uses a different INK colour, and each shape is built from PLOT (start here) and DRAW (go there).

This is what PLOT and DRAW give you: the ability to create **visual meaning**. A rectangle isn't just a rectangle — it's a wall, a window, a door, a device box. The shape communicates what the thing *is* without any text. Wire Panic's bomb doesn't say "this is a bomb" — you can *see* it's a bomb, because it's drawn like one.

Every graphical element in Wire Panic — the box, the inner frame, the wires, the timer bar outline — is built from these two commands. PLOT sets the starting point. DRAW creates lines from there. INK sets the colour. That's all the tools you need.

## What You've Learnt

- **PLOT x, y** draws a pixel at coordinates (x, y)
- **DRAW dx, dy** draws a line from the current position by (dx, dy)
- **Pixel coordinates**: 256 wide, 176 tall, y=0 at the bottom
- **INK** sets the colour for PLOT and DRAW
- **PLOT + four DRAWs** makes a rectangle — the foundation of most shapes
- **Visual meaning** — shapes communicate without words

PLOT and DRAW are no longer black boxes. Every line you typed in Lucky Number's digit renderer — every `PLOT px+9,py-i: DRAW 21,0` — makes sense now. A PLOT sets the pen down. A DRAW moves it. The trail is a line. The lines make shapes. The shapes make a game.
