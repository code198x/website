## Why It Works

**Tension** in games comes from **layering feedback channels** — multiple signals all telling you the same thing at the same time:

1. **The number** tells you how much time is left (information)
2. **The descending pitch** tells your ears time is running out (audio)
3. **The border colour** tells your peripheral vision the situation is getting worse (environmental)
4. **The pause between ticks** creates rhythm — each tick is a heartbeat you can feel

Remove any one layer and the game still works. Remove all the layers and you have the text version — functional but flat. Add them all and you have Wire Panic — the same logic, made tense by design.

This is the difference between a program that *works* and a game that *feels*. The logic is the foundation. The feedback layers are the experience.

## Compare to Wire Panic

Your text game is 26 lines. Your tension version is 54 lines (with the centre text routine). Wire Panic is 130 lines. What do those extra lines buy?

- **The drawn device** — a visual centrepiece that makes the game feel like a *thing*, not just text
- **The timer bar** — a spatial countdown (bar filling with red) alongside the numeric countdown
- **The LED indicators** — colour-changing lights that add atmosphere
- **The cog graphics** — visual detail that makes the bomb feel mechanical
- **The wires** — coloured lines that connect the numbers to the device
- **The explosion celebration** — border strobing with chaotic sound
- **The defusal celebration** — ascending tones, green colour switch, green LEDs

None of these change the game logic. All of them change the game experience. Game designers call this **juice** — the visual and audio details that make interactions satisfying. Your 26-line game and Wire Panic have the same bones. Wire Panic has juice.

## The Full Picture

Wire Panic is complete. You've learnt the programming tools — CLS, PRINT AT, PLOT, DRAW, BEEP, PAUSE, INKEY$, string variables — and the game design concept: **tension** through layered feedback.

Lucky Number taught **feedback** — the game responding to your actions. Wire Panic teaches **escalation** — feedback that gets more urgent over time. The temperature bar in Lucky Number was static feedback: it showed where you were. The countdown in Wire Panic is dynamic feedback: it shows where you're going, and where you're going is *running out of time*.

Every timed game — from Tetris to racing games to boss fights with enrage timers — uses the same principle. A countdown. Escalating signals. Layered feedback channels. The Spectrum has one speaker and 15 colours. That's enough to make your palms sweat.
