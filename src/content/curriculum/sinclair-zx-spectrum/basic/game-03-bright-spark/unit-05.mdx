Bright Spark's sequence grows each round: panel 3, then panel 3-1, then panel 3-1-4, then 3-1-4-2. The game needs to remember an ever-longer pattern. Where does it store it?

In a string.

Each pass through the loop adds one `*` to `s$`. After 5 passes: `"*****"`. The string grows one character at a time — exactly like Bright Spark's sequence growing one panel at a time.

In the game, each round adds a random digit: `LET s$ = s$ + p$` where `p$` is `"1"`, `"2"`, `"3"`, or `"4"`. After three rounds, `s$` might be `"314"` — panel 3, then panel 1, then panel 4.

This is the same pattern Bright Spark uses on lines 310-370: loop from 1 to `LEN s$`, check `s$(i)`, flash the matching panel. The string IS the sequence. The FOR loop IS the player.

## Strings as Data Structures

A string holding `"31242"` is a **sequence** — an ordered list of steps. Each character is one instruction. The string grows, the loop reads it, and the game plays it back. This is one of the simplest data structures in programming: a list stored as text.

Later games will use arrays (DIM) for more complex data. But for a sequence of single-digit values, a string is perfect — it grows naturally with `+`, it's indexable with `s$(i)`, and its length is always `LEN s$`.

## What You've Learnt

- **Concatenation** (`s$ = s$ + p$`) grows a string one character at a time
- **Indexing** (`s$(i)`) reads the character at position `i`
- **LEN** gives the string length
- **A FOR loop through a string** processes each character in order
- **Strings as sequences** — an ordered list stored as text
