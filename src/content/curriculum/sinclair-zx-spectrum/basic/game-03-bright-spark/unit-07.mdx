FOR loops count from start to end, adding 1 each time. But sometimes you need to count backwards, or skip numbers, or step by a different amount. That's `STEP`.

## STEP — Control the Increment

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-bright-spark/unit-07/step-demo.bas" />

![Three counting modes — up, down, and by twos](/images/sinclair-zx-spectrum/basic/game-03-bright-spark/unit-07-getting-harder/step.png)

Three loops:
- `FOR i=1 TO 10` — default, counts up by 1
- `FOR i=10 TO 1 STEP -1` — counts down by 1
- `FOR i=0 TO 20 STEP 2` — counts up by 2

STEP changes how much the loop variable moves each pass. `STEP -1` counts backwards — useful for countdowns (Wire Panic's timer), reverse animations, and clearing things from bottom to top. `STEP 2` skips every other value — useful for drawing every other row, alternating patterns, or processing pairs.

Without STEP, you'd need `LET i = i - 1` inside a GO TO loop, managing the counter manually. STEP makes the intention clear: "count from 10 down to 1" reads exactly as it sounds.

## Difficulty Through Length

Bright Spark doesn't have a difficulty setting. It doesn't need one. The sequence grows by one each round — and that IS the difficulty curve.

- Round 1: remember 1 panel. Trivial.
- Round 3: remember 3 panels. Easy.
- Round 5: remember 5 panels. Manageable.
- Round 7: remember 7 panels. Hard.
- Round 9: remember 9 panels. Very hard.
- Round 12+: remember 12+ panels. Nearly impossible.

The curve is **linear** — one more element per round. But the *perceived* difficulty is exponential because human short-term memory holds about 7 items. Below 7, the game feels comfortable. At 7, it feels challenging. Above 7, it feels desperate. The difficulty curve adapts to human psychology without any code to manage it.

This is an example of **emergent difficulty** — difficulty that arises from the game's structure rather than explicit programming. Nobody coded "make it harder at round 7." The sequence length does it naturally. The best difficulty curves work this way: the system creates the challenge, not a designer tweaking parameters.

## What You've Learnt

- **STEP** controls the loop increment — `STEP -1` counts down, `STEP 2` counts by twos
- Without STEP, the default increment is 1
- **Difficulty curves** can be emergent — arising from the structure rather than explicit design
- **Sequence length** is a natural difficulty curve calibrated to human memory limits
