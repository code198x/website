## The Flash

The flash is simple: redraw the panel with BRIGHT 1, play a BEEP, then redraw with BRIGHT 0. The colour stays the same — only the intensity changes.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-bright-spark/unit-04/flash.bas" />

The panel appears in normal red, pauses for a second, then pops to bright red with a tone, then returns to normal. That *pop* is what the player watches for in the sequence. Each panel has a different colour and a different musical pitch — so the player can identify panels by sight AND sound. Two channels of **feedback** reinforcing the same information.

In Bright Spark, each panel flash is a GO SUB — a reusable subroutine called whenever that panel needs to flash. The subroutine draws BRIGHT 1, BEEPs, then draws BRIGHT 0. Four subroutines, four panels, four colours, four notes.

## What You've Learnt

- A **panel** is a FOR loop filling rows with PAPER colour
- A **flash** is BRIGHT 1 → BEEP → BRIGHT 0
- **Two feedback channels** (colour + sound) make each panel distinct
- GO SUB makes flashing reusable — call it from the sequence player or the player input
