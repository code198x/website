In Lucky Number, you wrote `LET c = c + 1` inside a GO TO loop to count guesses. It worked, but it was manual — you had to manage the counter, the comparison, and the jump yourself. There's a better way.

`FOR/NEXT` counts for you.

## Counting

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-bright-spark/unit-03/counting.bas" />

The numbers 1 to 10 appear on screen, one per line. `FOR i=1 TO 10` means: start `i` at 1, run everything between FOR and NEXT, add 1 to `i`, and repeat until `i` passes 10. The loop runs exactly 10 times. You don't need GO TO. You don't need `LET i = i + 1`. FOR/NEXT handles it all.

The variable `i` changes each time through the loop. On the first pass it's 1. On the second it's 2. On the tenth it's 10. After the loop, `i` is 11 (one past the end) and the program continues with the next line after NEXT.

## Loops with Colour

FOR loops become powerful when you use the loop variable to control something visual:

## Filling a Rectangle

This is how Bright Spark draws its panels:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-bright-spark/unit-03/fill-rect.bas" />

![A red rectangle filled with a FOR loop](/images/sinclair-zx-spectrum/basic/game-03-bright-spark/unit-03-loops/fill-rect.png)

Eleven rows (5 to 15), each filled with 16 red spaces. The loop prints one row per pass. The result is a solid red rectangle — exactly like one of Bright Spark's panels. Change the PAPER colour and you have a blue panel, a green panel, a yellow panel.

This is the pattern: **a FOR loop that prints one row per pass fills a rectangle**. Every panel in Bright Spark is drawn this way.

## Nested Loops

A loop inside a loop creates a grid:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-bright-spark/unit-03/nested.bas" />

![A colourful grid — nested loops cycling through colours](/images/sinclair-zx-spectrum/basic/game-03-bright-spark/unit-03-loops/nested.png)

The outer loop (`r`) controls the row. The inner loop (`c`) controls the column. For each row, the inner loop runs all 8 columns. The colour cycles through all 8 values using `(r+c)` modulo 8. Two loops, 64 coloured blocks, a pattern that shifts with each row.

Nested loops are how computers fill grids, draw tilemaps, and process 2D data. Bright Spark uses them to check each step of the sequence against the player's input. Every game with a grid — Minesweeper, Chess, Tetris — uses nested loops.

## How Bright Spark Uses Loops

Here are four lines from the game:

Lines 2010 and 2030 draw the red and blue panels — a FOR loop filling 8 rows with coloured spaces. Lines 310/370 loop through the sequence string, playing each panel flash in order. The loop variable `i` steps through the string character by character.

Loops are the tool that makes repetition **automatic**. Without FOR/NEXT, drawing a panel would need 8 separate PRINT AT lines. Playing a 10-step sequence would need 10 separate IF/THEN checks. Loops replace repetitive code with a pattern: do this N times, changing one thing each pass.

## What You've Learnt

- **FOR i=start TO end** runs the loop body (end - start + 1) times
- The **loop variable** (`i`, `r`, `c`) changes each pass — use it to control position, colour, or content
- **NEXT i** marks the end of the loop body
- **Nested loops** (a FOR inside a FOR) create grids and 2D patterns
- Loops replace repetitive code with a **pattern** — one structure that handles any count
