Four coloured panels — that is the game board. Start with two.

<CodeFromFile src="sinclair-zx-spectrum/basic/bright-spark/unit-01/two-panels.bas" />

Line 550 sets `PAPER 2` (red). Line 560 uses a FOR loop to print eight rows of spaces at the top-left — filling a rectangle with colour. Lines 570–580 do the same in blue at the top-right. Line 630 resets `PAPER 0` so nothing else prints on a coloured background. Line 640 stops the program.

The trick is that spaces have a background colour. `PAPER 2` does not draw a rectangle — it changes the background for any text that prints next. The FOR loop prints eight rows of fourteen spaces, and each space fills one character cell with red. The result looks like a solid block. The number in the middle (1 or 2) tells the player which key to press later.

`PRINT AT r, 1` controls where each row goes. The first number is the row (2 to 9 — eight rows), the second is the column (1 for the left panel, 17 for the right). The panels sit side by side with a gap between them.

## Try it

Change `PAPER 2` to `PAPER 5` on line 550. Run it. The left panel turns cyan. Change the FOR range to `FOR r = 2 TO 5` — the panel shrinks to four rows. The grid is yours to shape. Four colours, four panels — but first, two is enough to see the idea.
