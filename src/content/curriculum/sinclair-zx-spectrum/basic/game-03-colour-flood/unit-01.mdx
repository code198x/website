Over the next eight units you'll build Colour Flood — a program that fills the screen with three different colour patterns, each more complex than the last. To get there, you need loops.

## Your First Loop

So far, every line of your programs has run once. If you wanted to print ten numbers, you'd need ten `PRINT` lines. Loops change that.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count.bas" />

![Counting from 1 to 10](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/count.png)

`FOR i = 1 TO 10` creates a variable called `i` and sets it to 1. The code between `FOR` and `NEXT i` runs, then `i` goes up by 1. When `i` passes 10, the loop stops.

Three lines replace ten.

## Counting Backwards with STEP

By default, the loop counter goes up by 1 each time. `STEP` changes that.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-step.bas" />

<video src="/images/sinclair-zx-spectrum/basic/game-03-colour-flood/count-step.mp4" autoplay loop muted playsinline width="768" height="576"></video>

`STEP -1` makes `i` count *down* — from 10 to 1. Each number appears with a half-second pause (`PAUSE 25` is half a second at 50 frames per second), then "Go!" with a beep.

The loop runs exactly 10 times, just like before — but in reverse.

## How FOR/NEXT Works

1. `FOR i = 1 TO 10` — create `i`, set it to 1
2. Run every line between `FOR` and `NEXT`
3. `NEXT i` — add 1 to `i` (or whatever `STEP` says)
4. If `i` has passed the limit, stop. Otherwise, go back to step 2.

The variable name can be anything — `i`, `c`, `r`, `x`. Short names are traditional in loops because you use them often.

## Try This

**Count in twos.** Change `STEP -1` to `STEP 2` and start from 0. You'll get 0, 2, 4, 6, 8, 10.

**Count in fives.** Try `FOR i = 0 TO 100 STEP 5`. How many numbers appear?

**Nested countdown.** After the countdown, add a second loop that counts *up* from 1 to 5 and prints each number. Two separate loops, one after the other.

## What You've Learnt

- **FOR/NEXT** — repeats code a set number of times
- **STEP** — controls how the counter changes each time (default is 1)
- **STEP -1** — counts backwards
- **PAUSE** — waits for a number of frames (50 per second)
