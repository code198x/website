You've used FOR/NEXT twice already — once to paint Lucky Number's rainbow header, once to run five rounds of Countdown. Both times it was a black box: type the line, trust that it repeats. Now you open the box and see what's inside.

The game you're building is Colour Flood — a colour memory sequence, Simon Says for the Spectrum. The border floods with colour, one flash at a time, each with its own musical tone. Watch the sequence, then repeat it from memory. Get it right and the sequence grows by one. Get it wrong and it's game over. Every part of this game — playing the sequence, checking the player's answer, drawing the colour key — is a loop. FOR/NEXT is the engine that drives all of it.

## Count to Ten

Type `NEW`, then:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-ten.bas" />

Type `RUN`. Numbers march down the screen — 1, 2, 3, all the way to 10, each on its own line. The Spectrum counts for you.

Three lines do all the work:

- `FOR i=1 TO 10` — creates a counter called `i` and sets it to 1
- `PRINT i` — prints whatever `i` holds right now
- `NEXT i` — adds 1 to `i` and jumps back to the line after `FOR`. When `i` passes 10, the loop ends and the program continues.

The variable `i` changes every time the loop runs. That's the key insight — the same PRINT statement produces different output on each pass because `i` holds a different number.

## Count Backwards

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-step.bas" />

Type `RUN`. The screen counts down — 10, 9, 8... 2, 1 — then "Go!" appears at the bottom. A three-line countdown timer.

`STEP -1` makes the counter decrease instead of increase. Without STEP, the counter always goes up by 1. With `STEP -1`, it goes down by 1. The loop ends when `i` drops below the target (1 in this case).

## Count in Twos

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-twos.bas" />

Type `RUN`. 0, 2, 4, 6... 20. Only the even numbers appear. `STEP 2` skips every other value. You can use any step value — `STEP 5` would give 0, 5, 10, 15, 20.

## Try This

- Change `FOR i=1 TO 10` to `FOR i=1 TO 100`. The numbers fill the screen faster than you can read them. That's the Spectrum doing something a hundred times in under a second.
- Print something other than the number: `20 PRINT "Hello"`. The word appears ten times — same instruction, repeated.
- Use `STEP 10` with `FOR i=0 TO 100`. How many numbers print? Count them.
- Try `FOR i=1 TO 1`. The loop runs exactly once. `FOR i=1 TO 0`? It doesn't run at all — the start is already past the end.

## What You've Learnt

- **FOR/NEXT** — repeats code a specific number of times with an automatic counter
- **Loop variable** — `i` counts up (or down) on each pass; you can use it inside the loop
- **STEP** — controls how much the counter changes each time (default is 1)
- **Why loops matter** — every part of Colour Flood is a loop; FOR/NEXT is the engine
