You've used FOR/NEXT twice — once to draw Lucky Number's header bar, once to run five rounds in Countdown. Now you learn how it actually works.

## Count to Ten

Type `NEW`, then:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-ten.bas" />

Type `RUN`. The Spectrum prints 1, 2, 3... up to 10, each on a new line.

Here's what happens:
- `FOR i=1 TO 10` — sets `i` to 1
- `PRINT i` — prints the current value of `i`
- `NEXT i` — adds 1 to `i` and loops back to the `FOR` line. When `i` exceeds 10, the loop ends.

The variable `i` is the **loop counter**. It changes automatically — you don't need `LET i=i+1`. FOR/NEXT handles it.

## Count Backwards

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-step.bas" />

Type `RUN`. 10, 9, 8... 1, then "Go!" — a countdown. `STEP -1` makes the counter decrease instead of increase. Without STEP, it always goes up by 1.

## Count in Twos

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-twos.bas" />

Type `RUN`. 0, 2, 4, 6... 20. `STEP 2` adds 2 each time instead of 1. You can use any step value — `STEP 5`, `STEP 0.5`, `STEP -3`.

## Why This Matters

FOR/NEXT is the tool that makes the Spectrum paint. Every pattern in this game — stripes, checkerboards, random splashes — is a FOR/NEXT loop that colours one cell at a time. The loop counter becomes a row number, a column number, or a colour value. Change the range, change the step, change what happens inside the loop, and the pattern changes.

## Try This

- Change `FOR i=1 TO 10` to `FOR i=1 TO 100`. How fast does it count?
- Print something other than the number: `20 PRINT "Hello"`. The word appears ten times.
- Change `20 PRINT i` to `20 PRINT i*i`. Now it prints squares: 1, 4, 9, 16...
- Use `STEP 10` with `FOR i=0 TO 100`. How many numbers print?

## What You've Learnt

- **FOR/NEXT** — repeats code a specific number of times with an automatic counter
- **Loop variable** — `i` counts up (or down) on each pass; you can use it inside the loop
- **STEP** — controls how much the counter changes each time (default is 1)
- **NEXT** — sends the program back to FOR; when the counter exceeds the limit, the loop ends
