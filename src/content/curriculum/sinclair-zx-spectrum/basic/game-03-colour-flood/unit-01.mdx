You've used FOR/NEXT twice — once to draw Lucky Number's header bar, once to run five rounds in Countdown. Now you learn how it actually works.

## Count to Ten

Type `NEW`, then:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-ten.bas" />

Type `RUN`. The Spectrum prints 1, 2, 3... up to 10, each on a new line.

- `FOR i=1 TO 10` — sets `i` to 1
- `PRINT i` — prints the current value of `i`
- `NEXT i` — adds 1 to `i` and loops back. When `i` exceeds 10, the loop ends.

## Count Backwards

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-step.bas" />

Type `RUN`. 10, 9, 8... 1, "Go!" — a countdown. `STEP -1` makes the counter decrease. Without STEP, it always goes up by 1.

## Count in Twos

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-01/count-twos.bas" />

Type `RUN`. 0, 2, 4, 6... 20. `STEP 2` adds 2 each time. You can use any step value.

## Why This Matters

The game you're building is a colour memory sequence — Simon Says for the Spectrum. FOR/NEXT will play the sequence (loop through each colour), check the player's input (loop through each expected answer), and draw the game screen (loop through the colour key). Every part of the game is a loop.

## Try This

- Change `FOR i=1 TO 10` to `FOR i=1 TO 100`. How fast does it count?
- Print something other than the number: `20 PRINT "Hello"`. The word appears ten times.
- Use `STEP 10` with `FOR i=0 TO 100`. How many numbers print?

## What You've Learnt

- **FOR/NEXT** — repeats code a specific number of times with an automatic counter
- **Loop variable** — `i` counts up (or down) on each pass; you can use it inside the loop
- **STEP** — controls how much the counter changes each time (default is 1)
