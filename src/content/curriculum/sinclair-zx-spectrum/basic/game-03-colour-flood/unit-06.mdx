## How r+c Creates Diagonals

The formula `(r+c)-INT((r+c)/8)*8` wraps `r+c` into the 0-7 range. At row 0, column 0, `r+c` is 0 (black). At row 0, column 1, it's 1 (blue). At row 1, column 0, it's also 1 (blue). Every cell where `r+c` is the same value gets the same colour — and those cells form a diagonal line.

| Position | r+c | Colour |
|----------|-----|--------|
| Row 0, Col 0 | 0 | Black |
| Row 0, Col 1 | 1 | Blue |
| Row 1, Col 0 | 1 | Blue |
| Row 0, Col 2 | 2 | Red |
| Row 1, Col 1 | 2 | Red |
| Row 2, Col 0 | 2 | Red |

## Nested Loops

This is the same nested loop from units 4 and 5. The outer loop (`r`) counts rows. The inner loop (`c`) counts columns. For every row, the inner loop runs all 32 columns before moving to the next row. That's 22 × 32 = 704 cells, each coloured individually.

The key insight: you can use `r`, `c`, or any combination of both to decide the colour. Rows give horizontal stripes. Columns give vertical stripes. `r+c` gives diagonals. `r*c` gives something else entirely — try it.

## Try This

- Use `r-c` instead of `r+c`. The diagonals slope the other way.
- Use `r*c` in the formula. What pattern does multiplication create?
- Use `r+c*2`. The diagonals stretch horizontally.
- Use `ABS(r-10)` — the stripes form a V-shape centred on row 10.

## What You've Learnt

- **Nested FOR/NEXT** — an inner loop runs completely for each pass of the outer loop
- **r+c** — adding row and column creates diagonal patterns
- **Formula-driven colour** — the relationship between `r` and `c` determines the visual pattern
- **704 cells** — 22 rows × 32 columns; each one independently coloured by the formula
