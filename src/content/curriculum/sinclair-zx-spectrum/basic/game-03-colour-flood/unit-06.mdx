A single loop fills one row. To fill the whole screen, you need a loop inside a loop — a **nested loop**.

## Colour Grid

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-06/grid.bas" />

![Seven colour stripes filling the screen](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/grid.png)

The outer loop (`FOR r = 0 TO 6`) picks the colour. The inner loop (`FOR i = 1 TO 96`) prints 96 spaces in that colour — three full rows (96 ÷ 32 = 3).

Seven colours × 3 rows each = 21 rows. That fills most of the screen. We stop at 7 colours (not 8) and 21 rows (not 24) because the Spectrum reserves the bottom two lines for system messages. Print too many rows and you get a "scroll?" prompt that interrupts the pattern.

## Checkerboard

The checkerboard alternates two colours across each row, then swaps them on the next row.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-06/checkerboard.bas" />

![Red and yellow checkerboard](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/checkerboard.png)

This one is trickier. Variables `a` and `b` hold the two colours (red and yellow). The inner loop prints pairs — one space in colour `a`, one in colour `b` — sixteen times across each row (16 pairs × 2 = 32 characters).

After each row, lines 110-130 swap `a` and `b` using a temporary variable `t`. On even rows, red comes first. On odd rows, yellow comes first. That creates the checkerboard pattern.

## The Swap Trick

Swapping two variables needs a third variable to hold one value temporarily:

```
LET t = a
LET a = b
LET b = t
```

Without `t`, you'd lose one value. If you wrote `LET a = b` first, the original value of `a` would be gone before you could copy it to `b`.

This three-line swap is a fundamental programming pattern. You'll see it in every language.

## Why 22 Rows?

The Spectrum display has 24 rows, but the bottom 2 are reserved for system messages ("0 OK" and the cursor). If your program tries to print past row 22, the Spectrum stops and asks "scroll?" — which breaks the pattern.

22 rows is the safe maximum for filling the screen.

## Try This

**Different colours.** Change `a` and `b` to other colour pairs. Try blue and white (1 and 7), or green and black (4 and 0).

**Larger squares.** Print two spaces in each colour instead of one. You'll need to change the inner loop to `FOR c = 1 TO 8` and print two spaces for each colour.

**Vertical stripes.** Remove the swap (delete lines 110-130). Without swapping, every row starts with the same colour, giving vertical stripes instead of a checkerboard.

## What You've Learnt

- **Nested loops** — an inner loop runs completely for each step of the outer loop
- **The swap trick** — `LET t = a: LET a = b: LET b = t` exchanges two variables
- **22-row limit** — the safe maximum before the Spectrum's "scroll?" prompt appears
- **96 spaces = 3 rows** — printing more spaces than the row width wraps to the next line
