Until now, the sequence has been hardcoded — "246" every time. You can memorise it once and win forever. A real Simon Says game doesn't let you off that easily. Each round, it adds one random colour to the sequence. Round 1: one flash. Round 2: two flashes. Round 5: five flashes, played back at speed, all from memory. The sequence grows until the player's memory gives out.

## Growing the String

Replace the fixed sequence with these lines:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-06/growing-sequence.bas" />

- **Line 32** — `LET s$=""` starts with an empty string.
- **Line 34** — `LET sc=0` initialises the score.
- **Line 42** — `LET s$=s$+STR$(INT(RND*7)+1)` appends a random colour (1-7) to the sequence.

`s$+STR$(...)` is **string concatenation** — joining two strings together. If `s$` is `"24"` and `STR$(INT(RND*7)+1)` produces `"6"`, then `s$` becomes `"246"`. Each round, the string grows by one character.

After the player completes the sequence correctly, `GO TO 40` loops back to line 40, which adds another colour and plays the whole sequence again — now one colour longer.

## The Game Loop

The flow is now:
1. Add a random colour to the sequence
2. Play the whole sequence (FOR/NEXT through the string)
3. Player repeats the whole sequence
4. If correct → score +1, GO TO step 1
5. If wrong → game over

The sequence string is the game state — and it's beautiful in its simplicity. One character per colour, growing by one each round. Round 1 has one colour to remember. Round 5 has five. Round 10 has ten. There's no fixed endpoint — the game runs until the player's memory fails. That's a game that can challenge anyone, from a child playing their first round to an adult pushing past fifteen.

## Try This

- Play a few rounds. How far can you get?
- Add `PRINT AT 15,1; INK 7;s$` to display the sequence string on screen. Now you can see it growing — but that makes the game too easy. Remove it after testing.
- Change `RND*7` to `RND*3`. Now only three colours (1-3) appear. Easier to memorise, but the tones are closer together.

## What You've Learnt

- **String concatenation** — `s$=s$+"6"` appends a character to the end of a string
- **STR$ with RND** — `STR$(INT(RND*7)+1)` produces a random digit character "1" to "7"
- **Growing state** — the sequence string gets longer each round; the game gets harder
- **GO TO as game loop** — jumping back to the start of the round creates an endless game that only stops on failure
