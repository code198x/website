## What You'll Build

A program that floods the screen with three different colour patterns — rainbow stripes, a checkerboard, and a random mosaic — each revealed with a key press.

![The finished Colour Flood program](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-flood-random.png)

## Why This Game?

Countdown used `INKEY$` and `BEEP` — single commands that do one thing. But games need to repeat actions hundreds of times. Drawing a screen full of colour means printing hundreds of coloured spaces.

`FOR/NEXT` loops handle the repetition. Combined with the Spectrum's colour commands — `INK`, `PAPER`, `BORDER`, and `BRIGHT` — you can fill the entire screen with patterns using just a few lines of code.

This game is all about seeing the Spectrum's colour system in action.

## What You'll Learn

- **FOR/NEXT** — repeating code a set number of times
- **STEP** — controlling how the loop counter changes
- **INK** — changing text colour
- **PAPER** — changing background colour
- **BORDER** — changing the border colour
- **BRIGHT** — toggling between normal and bright colours
- **Nested loops** — loops inside loops for grids and patterns
- **RND with colour** — random colours for every cell

## Prerequisites

Complete [Game 2: Countdown](/sinclair-zx-spectrum/basic/game-02-countdown/) first. You'll need `CLS`, `BEEP`, `INKEY$`, and `IF/THEN`.
