Fill the Spectrum's screen with colour. Stripes, checkerboards, diagonals, random splashes — each pattern is just a few lines of code, and the results are immediate and vivid.

![Random colour mosaic](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/unit-08-pattern-picker/random.png)

This is the first game where the result is primarily visual. FOR/NEXT stops being an abstract concept about repetition and becomes a tool for painting the screen.

## What You'll Learn

- **FOR/NEXT** — repeating code with an automatic counter
- **STEP** — controlling how the counter changes each pass
- **PAPER / INK / BORDER** — the Spectrum's three colour controls
- **BRIGHT** — doubling the palette to 16 shades
- **Nested loops** — loops inside loops for filling grids
- **Colour formulae** — row, column, and their combinations create different patterns

## Prerequisites

Complete [Game 2: Countdown](/sinclair-zx-spectrum/basic/game-02-countdown/) first. You'll need CLS, INKEY$, and IF/THEN.
