Black for a beat. Then green, higher pitched. Black. Then yellow, higher still. Three colours, three tones, played in sequence. The room changes colour with each flash.

The sequence string `s$="246"` stores those three colours as characters — "2" for red, "4" for green, "6" for yellow.

## How the String Works

`LET s$="246"` stores three characters: "2", "4", "6". They're text, not numbers — the string doesn't know they represent colours. To use them as colours:

- `s$(i)` reads the i-th character. `s$(1)` is "2", `s$(2)` is "4", `s$(3)` is "6".
- `VAL s$(i)` converts the character to a number. `VAL "2"` gives 2.
- `LEN s$` is the length of the string — 3 in this case. The FOR/NEXT loop uses it to know when to stop.

The loop runs from `i=1` to `i=LEN s$`, reading one colour per pass. Each colour becomes a BORDER and a BEEP. Between colours, the border returns to black for a beat so the flashes are distinct.

## STR$ and VAL

These two commands convert between strings and numbers:

- `STR$ 4` → `"4"` (number to string)
- `VAL "4"` → `4` (string to number)

You'll use STR$ in the next units to build the sequence, and VAL to read it. They're opposites — STR$ packs a number into text, VAL unpacks it.

## Try This

- Change `s$="246"` to `s$="1357"`. Four colours instead of three. The loop adapts because it uses `LEN s$`.
- Change it to `s$="7777"`. The same colour four times — white, white, white, white. The tones are identical. Hard to memorise when it's all the same.
- Change `s$="1234567"`. All seven colours in order — the full rainbow.
- Change `PAUSE 10` to `PAUSE 3`. The flashes become rapid-fire — harder to read.

## What You've Learnt

- **Strings as data** — `s$="246"` stores a sequence of colour numbers as text characters
- **LEN** — returns the length of a string; the loop uses it to know how many colours to play
- **VAL** — converts a string character to a number; `VAL "4"` gives 4
- **STR$** — converts a number to a string; `STR$ 4` gives "4"
- **String indexing** — `s$(i)` reads the i-th character (starting at 1, not 0)
