The Spectrum has eight colours, numbered 0 to 7. You've used them in PAPER, INK, and BORDER. Now you cycle through all of them in a loop — and the border becomes a rainbow.

## The Eight Colours

| Number | Colour |
|--------|--------|
| 0 | Black |
| 1 | Blue |
| 2 | Red |
| 3 | Magenta |
| 4 | Green |
| 5 | Cyan |
| 6 | Yellow |
| 7 | White |

These eight numbers control everything visual on the Spectrum. Every PAPER, INK, BORDER, and colour attribute uses this same 0-7 system.

## Border Rainbow

Type `NEW`, then:

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-02/border-rainbow.bas" />

Type `RUN`. The border sweeps through all eight colours — black, blue, red, magenta, green, cyan, yellow, white — with a half-second pause between each. Then it returns to black.

The loop variable `i` goes from 0 to 7. `BORDER i` uses that number directly as the colour. When `i` is 0, the border is black. When `i` is 3, it's magenta. The loop counter IS the colour number.

## Loop It Forever

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-02/border-loop.bas" />

Line 50 sends the program back to line 10. The rainbow cycles endlessly. Press BREAK (Caps Shift + Space) to stop it.

This is the same FOR/NEXT + GO TO combination you used in Countdown. FOR/NEXT handles the counting. GO TO restarts it.

## Try This

- Change `PAUSE 25` to `PAUSE 5`. The rainbow cycles five times faster.
- Change `FOR i=0 TO 7` to `FOR i=7 TO 0 STEP -1`. The rainbow runs backwards.
- Change `BORDER i` to `BORDER 7-i`. Same thing — the colours reverse.
- Try `FOR i=1 TO 6`. Skip black and white — only the vivid colours cycle.

## What You've Learnt

- **The 8 colours** — numbered 0-7; the same numbers work for BORDER, PAPER, and INK
- **Loop variable as colour** — `BORDER i` uses the counter directly as a colour number
- **Animation** — changing a colour inside a loop with PAUSE creates movement
- **Endless loops** — FOR/NEXT + GO TO repeats the animation forever
