The Spectrum has 8 colours, numbered 0 to 7:

| Number | Colour  |
|--------|---------|
| 0      | Black   |
| 1      | Blue    |
| 2      | Red     |
| 3      | Magenta |
| 4      | Green   |
| 5      | Cyan    |
| 6      | Yellow  |
| 7      | White   |

Every character on screen has two colour attributes: **INK** (the text colour) and **PAPER** (the background colour). By default, the Spectrum uses black ink on white paper.

## Changing the Text Colour

`INK` sets the colour of text that follows it.

## Changing the Background Colour

`PAPER` sets the background colour. To see it clearly, print a full row of spaces.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-02/paper-colours.bas" />

![Eight coloured rows](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/paper-colours.png)

Each iteration of the loop sets a different `PAPER` colour, then prints 32 spaces — one full row. The spaces have no visible text, but the background colour fills the row.

32 is the magic number: the Spectrum screen is 32 characters wide.

## INK vs PAPER

- `INK` changes the **text** (foreground) colour
- `PAPER` changes the **background** colour behind the text
- Both stick until you change them again — they're not reset each line

Once you set `PAPER 2`, everything you print afterwards has a red background until you set a different `PAPER`.

## Try This

**Invisible text.** Set `INK 7` and `PAPER 7` (white on white). Print a message. You won't see it — but it's there. Now set `INK 0` and print again. The new text appears, but the first message stays hidden.

**Coloured labels.** Modify the ink-colours program to also set `PAPER` to a contrasting colour for each line. For instance, `INK 7: PAPER 1` gives white text on blue.

## What You've Learnt

- **INK** — sets the text (foreground) colour (0-7)
- **PAPER** — sets the background colour (0-7)
- **The 8 Spectrum colours** — black, blue, red, magenta, green, cyan, yellow, white
- **Colour persistence** — INK and PAPER remain set until changed
