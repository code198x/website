Vertical stripes. The rainbow runs left to right instead of top to bottom. Column 0 is black, column 1 is blue, column 2 is red... cycling every 8 columns, four times across the 32-column screen.

## What Changed

One letter: `r` became `c`. The formula `PAPER (c-INT(c/8)*8)` uses the column number instead of the row number to pick the colour. Everything else — the loops, the PRINT AT, the space character — is identical.

This is the power of the formula approach. The loop fills every cell. The formula decides the colour. Change the formula, change the pattern. The loop doesn't care.

## Try This

- Use `PAPER (c-INT(c/4)*4)` instead — colours wrap every 4 columns. Twice as many stripes, half as wide.
- Use `PAPER (c-INT(c/2)*2)` — two-column stripes. Alternating black and blue.
- Combine both: `PAPER (r-INT(r/8)*8)` for horizontal and `PAPER (c-INT(c/8)*8)` for vertical. Can you switch between them at a keypress?

## What You've Learnt

- **Column-based colour** — using `c` in the formula instead of `r` creates vertical stripes
- **Same loop, different formula** — the nested loop doesn't change; only the colour calculation does
- **Wrap frequency** — dividing by a smaller number (4, 2) creates more frequent colour changes
