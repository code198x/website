The Spectrum has 8 colours — but it also has a `BRIGHT` mode that makes each one more vivid. That gives you 16 shades to work with.

## Normal vs Bright

![Normal red and bright red side by side](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/bright.png)

The top row is normal red (`PAPER 2`). The bottom row is bright red (`BRIGHT 1` then `PAPER 2`). The difference is clear — bright red is more vivid and saturated.

`BRIGHT 1` turns brightness on. `BRIGHT 0` turns it off. Like `INK` and `PAPER`, it sticks until you change it.

The semicolons after `PRINT "    ";` keep everything on the same line. Without them, each colour block would start a new row.

## How BRIGHT Works

The Spectrum stores colour information per character cell — each 8×8 pixel block has an INK colour, a PAPER colour, and a BRIGHT flag. That's why you can't have normal and bright colours in the same cell.

`BRIGHT` applies to both INK and PAPER in that cell. You can't have bright paper with normal ink, or vice versa — it's all or nothing per cell.

## Resetting BRIGHT

Always set `BRIGHT 0` after you're done using bright colours. If you forget, everything you print afterwards will be bright — including the Spectrum's own messages.

Line 120 in the palette program does exactly this. The `BRIGHT 0` at the end returns to normal.

## Try This

**Bright stripes.** Take the stripes program from the last unit and add `BRIGHT 1` before the loop. All 8 colours will be brighter.

**Alternating brightness.** Print two rows for each colour — one normal, one bright. You'll need to print each colour twice: once with `BRIGHT 0` and once with `BRIGHT 1`.

## What You've Learnt

- **BRIGHT 1** — switches to brighter, more vivid versions of each colour
- **BRIGHT 0** — returns to normal brightness
- **16 shades** — 8 colours × 2 brightness levels (though black and white don't change)
- **BRIGHT is per-cell** — applies to both INK and PAPER in each character cell
