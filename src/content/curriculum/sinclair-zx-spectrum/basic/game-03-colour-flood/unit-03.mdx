When the border flashes a colour, the player needs to press the right number key. But which number is which colour? A colour key on the left side of the screen shows all seven — coloured blocks labelled 1 to 7. The header, score, and status message complete the game screen.

## The Layout

Type `RUN`.

![The Colour Flood game screen — blue header, colour key, score, and status message](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/unit-03-the-game-screen/game-screen.png)

A blue header bar stretches across the top with "COLOUR FLOOD" in bright white — the same header bar technique from Countdown. Below it, seven coloured blocks run down the left side of the screen: blue marked "1", red marked "2", magenta "3", green "4", cyan "5", yellow "6", white "7". A score counter sits below the key in cyan. At the bottom, a yellow status message reads "Watch the border..." — telling the player something is about to happen.

The colour key uses a FOR/NEXT loop (lines 22-26): for each colour 1 to 7, print a coloured space with `PAPER i` and the number beside it. Seven colours, seven iterations, seven labelled blocks. The loop builds the entire reference key in five lines of code.

## PAPER per Character

`PRINT AT r,c; PAPER i;" ";i;" "` sets the PAPER colour for those specific characters only. The rest of the screen stays black. Every character cell on the Spectrum has its own PAPER and INK — you can colour individual cells without affecting neighbours.

## BRIGHT

The header uses `BRIGHT 1` to make the white text brighter — more vivid, more prominent. BRIGHT works like a multiplier: BRIGHT 0 is the normal shade, BRIGHT 1 is the enhanced shade. Combined with the 8 colours, it gives 16 distinct shades.

## Try This

- Change `PAPER 1` on lines 12-18 to `PAPER 2`. Red header instead of blue.
- Add `BRIGHT 1` to the colour key loop: `PRINT AT 2+i,1; PAPER i; BRIGHT 1;" ";i;" "`. Brighter colours.
- Change the status message text and colour. "Ready..." in green, "Waiting..." in cyan — the words set the mood.

## What You've Learnt

- **PAPER per cell** — each character cell has its own background colour
- **FOR/NEXT for layout** — the colour key is built with a loop, not seven separate PRINT statements
- **BRIGHT** — 0 for normal, 1 for bright; makes colours more vivid
- **Game screen structure** — header bar, reference key, score display, status message
