The Spectrum screen has a wide border around the main display area. By default it's white, but you can change it to any of the 8 colours.

## Setting the Border

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-03/border.bas" />

![Red border around the screen](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/border.png)

One line, and the entire border turns red. `BORDER` uses the same colour numbers as `INK` and `PAPER` — 0 for black, 2 for red, 7 for white.

Unlike `INK` and `PAPER`, the border is one single colour for the whole screen. You can't have different border colours in different areas.

## Cycling Colours

Combine `BORDER` with a `FOR` loop and you get a colour cycle.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-03-colour-flood/unit-03/border-cycle.bas" />

<video src="/images/sinclair-zx-spectrum/basic/game-03-colour-flood/border-cycle.mp4" autoplay loop muted playsinline width="768" height="576"></video>

The loop sets the border to each colour in turn, with a half-second pause between each. Line 50 sends execution back to line 10, so the cycle repeats forever.

This is the simplest animation on the Spectrum — no sprites, no graphics, just changing a colour in a loop. You've already used `GO TO` to create infinite loops, and `PAUSE` to control timing. The loop adds structure to the repetition.

## BORDER vs PAPER

- `PAPER` colours the background *behind text* — inside the main display area
- `BORDER` colours the *frame around* the display area

They're separate. Setting `BORDER 2` doesn't change the PAPER, and setting `PAPER 2` doesn't change the border. In the final Colour Flood program, we'll set both — `BORDER 0` for a black frame around the colourful patterns.

## Try This

**Black border.** Change the border to black (`BORDER 0`). Notice how it makes the screen area feel bigger — the border disappears into the TV surround.

**Speed it up.** Remove the `PAUSE 25` line from the cycle program. The colours flash by much faster. Try `PAUSE 10` for a middle ground.

**Reverse cycle.** Change the loop to `FOR c = 7 TO 0 STEP -1`. The colours cycle in reverse order.

## What You've Learnt

- **BORDER** — sets the border colour (0-7)
- **The border is separate from PAPER** — it frames the display area
- **GO TO creates infinite loops** — combined with FOR/NEXT, this makes simple animations
