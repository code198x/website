The program shows a title screen, then three patterns one after another. Press a key to advance through each one.

## How It Works

The program has five sections:

**Title screen (lines 10-70).** Sets a black border, clears the screen, prints the title and instructions, then waits for a key press with the `INKEY$` loop.

**Pattern 1 — Colour stripes (lines 80-150).** Clears the screen and loops through 7 colours (0 to 6), printing 96 spaces in each — three rows per colour. A beep signals it's done, then waits for a key.

![Colour stripes pattern](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-flood-stripes.png)

**Pattern 2 — Checkerboard (lines 170-310).** Clears the screen and draws 22 rows of alternating red and yellow squares. The swap trick (`LET t = a: LET a = b: LET b = t`) alternates the starting colour on each row. Beep, wait for key.

![Checkerboard pattern](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-flood-checker.png)

**Pattern 3 — Random mosaic (lines 330-400).** Clears the screen and fills 704 cells (22 rows × 32 columns) with random colours and random brightness. This is the slowest pattern — you can watch it paint cell by cell. Beep, wait for key.

![Random colour mosaic](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-flood-random.png)

**End screen (lines 420-480).** Restores the border and paper to white, ink to black, clears the screen, and prints "Well done!".

![End screen](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/colour-flood-done.png)

## The INKEY$ Wait Pattern

Each pattern ends with the same two lines:

```
BEEP 0.1, 12
IF INKEY$ = "" THEN GO TO ...
```

The beep tells you the pattern is ready. The `INKEY$` loop keeps checking the keyboard — when you press any key, it moves on. You learnt this pattern in Game 2, and it works the same way here.

## Cleaning Up at the End

Lines 420-450 restore everything to defaults:

- `BORDER 7` — white border
- `PAPER 7` — white background
- `INK 0` — black text
- `CLS` — clear the screen with the new colours

Without this cleanup, the Spectrum would be left with a black border and whatever PAPER colour was last set. Always tidy up when your program finishes.

## Try This

**Add a fourth pattern.** Insert a new section between the random mosaic and the end screen. Try diagonal stripes — use `PAPER ((r + c) MOD 8)` where `r` is the row and `c` is the column.

**Change the checkerboard colours.** Swap `LET a = 2` and `LET b = 6` for any two colours. Blue and green (1 and 4) looks striking.

**Speed up the random fill.** Remove the `BRIGHT` line (360) from pattern 3. With only `PAPER` to calculate, it fills noticeably faster.
