## Speed Up With Score

The sequence playback uses `PAUSE 10` between colours — the same gentle pace whether the player is on round 1 or round 12. That's too forgiving. Make the pause shrink as the score rises:

Replace line 60 with:

```basic
  60 IF 10-sc>1 THEN PAUSE 10-sc
  61 IF 10-sc<=1 THEN PAUSE 1
```

At score 0, the pause is 10 frames — comfortable. At score 5, it's 5 frames — brisk. At score 9, it's 1 frame — barely a flicker. The sequence gets longer *and* faster simultaneously. That's compounding difficulty — two things getting harder at once.

The `IF` check on line 60 prevents the pause from going to zero or negative (which would cause an error). At score 9 and above, the pause bottoms out at 1 frame. The colours flash by so fast they're almost subliminal — the player has to rely on the tones as much as the colours.

## Sound Design

Each colour's pitch is `c*3` semitones — evenly spaced, functional, but not very memorable. The goal is for the player to start recognising colours by ear, not just by sight. Try different spacing:

- `c*4` — wider gaps between notes, more dramatic intervals
- `c*2+5` — starts higher, smaller gaps, a brighter sound overall
- `20-c*3` — inverted: blue is high, white is low. Completely changes the feel.

Play a few rounds with each formula. You'll find that wider spacing makes colours easier to distinguish by ear, while tighter spacing creates a more musical sequence. There's no right answer — it's a design choice. Pick what sounds best to you.

## BRIGHT Colour Key

Add BRIGHT to the colour key loop so the reference blocks stand out more:

```basic
  24 PRINT AT 2+i,1; PAPER i; BRIGHT 1;" ";i;" "
```

The colours pop against the black background. On a real Spectrum, the difference between normal and BRIGHT is subtle for some colours (blue barely changes) and dramatic for others (green becomes vivid lime, red becomes bright scarlet). With BRIGHT enabled, the colour key becomes a visual feature of the game screen, not just a reference table.

## Try This

- Play until you fail. What's your best score? Can you beat 10?
- Change the colour set: `INT(RND*4)+1` uses only blue, red, magenta, and green. Fewer colours makes it easier to remember sequences, but the colours are harder to distinguish — especially by sound.
- Add a "play again" prompt after game over: wait for INKEY$, then `GO TO 5` to restart. Now the player doesn't have to type RUN between games.
- Add a high score: `LET hi=0` at the start, then `IF sc>hi THEN LET hi=sc` on game over. Display it alongside the current score. Suddenly there's something to chase across multiple plays.
