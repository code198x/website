## Build the Menu

Now combine everything. The structure is:

1. Show a menu with numbered options
2. Wait for a keypress (INKEY$)
3. Run the chosen pattern
4. Wait for a keypress, then return to the menu

Each pattern is its own block of lines, chosen by the key pressed. The full program is in the [code-samples repository](https://github.com/code198x/code-samples/tree/main/sinclair-zx-spectrum/basic/game-03-colour-flood/prototype) — you can load it directly or type the menu structure around the patterns you've already written.

The key idea: `LET k$=INKEY$` captures the key, then a series of `IF k$="1" THEN GO TO ...` lines sends the program to the right pattern. After each pattern, `GO TO` returns to the menu. It's the same IF/THEN dispatch you used in Lucky Number's scoring tiers, applied to code flow instead of messages.

## Designing Your Own Pattern

You now have all the tools:

- **r** — row number (0-21)
- **c** — column number (0-31)
- **r+c** — diagonal
- **r-c** — opposite diagonal
- **r*c** — multiplication pattern
- **RND** — random
- **INT(n/8)*8** — modulo wrap
- **INT(n/2)*2=n** — even/odd test
- **BRIGHT** — 16 shades instead of 8

Combine them. `PAPER ((r*c)-INT((r*c)/8)*8)` creates a multiplication table pattern. `PAPER (ABS(r-10)-INT(ABS(r-10)/8)*8)` creates a mirrored V-shape. Experiment until you find something that looks good — then add it as option 7 in your menu.

## Try This

- Add a `BEEP` after each pattern finishes — a short blip to confirm it's done.
- Add option 7: your own pattern using any formula you like.
- Change the random splash to use only warm colours: `PAPER (INT(RND*3)+2)` gives red, magenta, and green.
- Add `BRIGHT INT(RND*2)` to the random splash — now some cells are bright and some aren't. 16 colours instead of 8.

## What You've Learnt

- **RND for colour** — `INT(RND*8)` picks a random colour number; every cell gets a different one
- **Menu structure** — INKEY$ captures a key, IF/THEN dispatches to the right code block, GO TO returns to the menu
- **Code organisation** — each pattern in its own numbered block of lines; the menu ties them together
- **Formula creativity** — any mathematical relationship between `r`, `c`, and a colour number creates a visual pattern
