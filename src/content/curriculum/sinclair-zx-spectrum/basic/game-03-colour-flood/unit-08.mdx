The game works. Now make it better. Speed up the playback as the score climbs. Refine the sounds. Add BRIGHT to the colour key. Make the game feel finished.

## Speed Up With Score

The sequence playback uses `PAUSE 10` between colours. Make it scale with the score:

```basic
  60 PAUSE 10-sc
```

At score 0, the pause is 10 frames. At score 5, it's 5 frames. At score 9, it's 1 frame — barely a flicker. The game gets faster as the sequence gets longer, compounding the difficulty.

Add a minimum so it doesn't go negative:

```basic
  60 IF 10-sc>1 THEN PAUSE 10-sc
  61 IF 10-sc<=1 THEN PAUSE 1
```

## Sound Design

Each colour's pitch is `c*3` semitones — evenly spaced but not very memorable. Try different spacing:

- `c*4` — wider gaps, more dramatic
- `c*2+5` — starts higher, smaller gaps
- `20-c*3` — inverted: blue is high, white is low

The key is that each colour sounds different. Play a few rounds and adjust until you can recognise colours by ear.

## BRIGHT Colour Key

Add BRIGHT to the colour key so it stands out more:

```basic
  24 PRINT AT 2+i,1; PAPER i; BRIGHT 1;" ";i;" "
```

The colours pop. On a real Spectrum, the difference between normal and BRIGHT is subtle for some colours (blue barely changes) and dramatic for others (green becomes vivid lime).

## The Complete Game

The full program is in the [code-samples repository](https://github.com/code198x/code-samples/tree/main/sinclair-zx-spectrum/basic/game-03-colour-flood/prototype). It runs to about 65 lines — half the size of Lucky Number but a tighter, more focused game.

The flow: game screen → add colour → play sequence → player repeats → correct (loop) or wrong (game over with rating). Every round adds one colour. Every round plays faster. The player's memory and speed are both tested.

## What You've Built

A colour memory game. The border floods with colour, the beeper sounds a tone, and the player has to repeat what they saw and heard. The sequence grows. The speed increases. The score climbs until you can't keep up.

You built this from scratch — the game screen, the sequence playback, the input checking, the scoring, the game over. Every line is yours.

## Try This

- Play until you fail. What's your best score? Challenge someone to beat it.
- Change the colour set: `INT(RND*4)+1` uses only blue, red, magenta, green. Fewer colours = easier to remember, harder to distinguish.
- Add a "play again" prompt after game over: wait for INKEY$, then `GO TO 5` to restart.
- Add a high score: `IF sc>hi THEN LET hi=sc`. Display it on the game over screen.
