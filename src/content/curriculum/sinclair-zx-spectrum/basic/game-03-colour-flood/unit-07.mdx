A checkerboard alternates two colours: if the cell is "even", use one colour; if "odd", use the other. The trick is deciding what "even" and "odd" mean for a grid.

Type `RUN`.

![Red and yellow checkerboard filling the screen](/images/sinclair-zx-spectrum/basic/game-03-colour-flood/unit-07-checkerboard/checkerboard.png)

A red and yellow checkerboard. Every cell where `r+c` is even gets red (PAPER 2). Every cell where it's odd gets yellow (PAPER 6). Adjacent cells always differ because adding 1 to either `r` or `c` flips even to odd.

## Even/Odd Detection

The Spectrum has no built-in even/odd check. The formula `INT((r+c)/2)*2` rounds down to the nearest even number. If that equals `r+c`, the number was already even. If not, it's odd.

| r+c | INT((r+c)/2)*2 | Even? |
|-----|----------------|-------|
| 0 | 0 | Yes |
| 1 | 0 | No |
| 2 | 2 | Yes |
| 3 | 2 | No |
| 4 | 4 | Yes |

Because the Spectrum has no ELSE keyword, you need two separate IF/THEN lines — one for even, one for odd. Both check the same condition, one with `=` and one with `<>`.

## Change the Colours

The checkerboard works with any two colours. Replace `PAPER 2` and `PAPER 6` with any pair:

- `PAPER 1` and `PAPER 7` — blue and white
- `PAPER 0` and `PAPER 4` — black and green
- `PAPER 3` and `PAPER 5` — magenta and cyan

The pattern is the same; the personality changes completely.

## Try This

- Add `BRIGHT 1` to one of the two colours. Now it's a three-tone pattern — two shades of one colour plus a contrasting colour.
- Change the even/odd test from `r+c` to `r*c`. What happens? (Whole rows and columns become the same colour because anything multiplied by 0 is 0.)
- Use three colours: even, odd, and a third for cells where `r+c` is a multiple of 3. You'll need a third IF/THEN line.

## What You've Learnt

- **Even/odd detection** — `INT(n/2)*2=n` tests whether `n` is even
- **Two-colour patterns** — alternating colours based on a condition creates visual structure
- **No ELSE** — the Spectrum needs separate IF/THEN lines for each case
- **r+c parity** — adjacent cells always differ in parity, creating the checkerboard effect
