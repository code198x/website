A program still in the Spectrum's memory is a fragile possession. Save Night Patrol, then prove that the saved copy can start the whole game again.

Use **Finish Night Patrol** unchanged. There are no additions, replacements or deletions in this lesson.

## Save an entry point

Quit with Q. Enter this direct command **without a line number**:

```basic
SAVE "patrol" LINE 10
```

SAVE writes the BASIC program and its variables. LINE 10 tells a later load where to begin execution. That line installs the graphics and reaches the title before the attempt is initialised, so a fresh machine needs no earlier game session.

On the Spectrum keyboard, S enters SAVE in keyword mode. For LINE, enter extended mode with Caps Shift and Symbol Shift together, then Symbol Shift with 3. Enter the quoted tape name and the number normally.

At the recording prompt, press Enter and wait for `0 OK`. In Emu198x, choose **Tape → Export Recording…** and give the recording a new host filename, such as `night-patrol.tap`. The [saving guide](/systems/sinclair-zx-spectrum/basic/meet-basic/unit-02-remember-and-save/#keep-a-copy-outside-the-spectrum) explains the tape deck and platform-specific controls. A save report inside the Spectrum does not itself prove that a host file was kept.

## Recover it in a fresh machine

Keep your source listing too, then close the emulator and start a fresh 48K machine. Open the exported file through **File → Open Tape Deck…**. Enter:

```basic
LOAD ""
```

Start **Tape → Play** and wait for the title. On platforms using the command-line tape option, follow the linked saving guide for opening and playback. The empty name loads the next program on the tape. If your recording contains several saves, make sure you select or play the Night Patrol recording.

Check a complete cycle from the loaded copy: S starts, the guard moves without input, sight captures, R resets, and Q quits. Play a successful retrieval and return as well. The title, symbols and opening view should match the program before saving.

<Question prompt="Does this tape resume the attempt you were playing when you saved?">

No. Although SAVE includes variables, the auto-start path resets the attempt. It preserves a reusable program. An emulator snapshot is the separate tool for resuming a particular machine state.

</Question>

If loading reaches BASIC without the title, inspect whether the save included LINE 10. If the title appears but the map or graphics are wrong, compare the complete listing and DATA. If no program loads, check the exported file, tape position and playback before changing any game code.

Keep the map and sight records together with the program. You now have a game whose behaviour you can explain: the map owns walls, the phase table owns the patrol, the visibility mask owns detection and the drawing routines show their results.
