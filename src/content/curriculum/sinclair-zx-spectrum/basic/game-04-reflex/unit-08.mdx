Two new lines and one change. Lines 130–140: `PLOT 28, 88` and `DRAW 200, 0` draw a thin line at the bar's position before the FOR loop fills it pixel by pixel below. Line 200 changed: `PRINT "NOW!"` became `BEEP 0.05, 30` — the red screen flash now has a sharp alert tone instead of text.

## DRAW

`DRAW dx, dy` draws a line from the current PLOT position. `DRAW 200, 0` draws 200 pixels to the right, 0 pixels up — a horizontal line. Combined with `PLOT 28, 88` to set the starting position, it creates the bar outline.
