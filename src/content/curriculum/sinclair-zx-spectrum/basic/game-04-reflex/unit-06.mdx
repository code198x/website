## What changed

**Title screen (lines 10–90).** Black background, white text, instructions, `PAUSE 0` to wait for the player. The same pattern as Lucky Number — by now it should feel like a standard opening.

**DRAW (line 140).** `DRAW 200, 0` draws a line 200 pixels long horizontally from the current PLOT position. Line 130 sets the start with `PLOT 28, 88`; DRAW continues from there. The result is the same bar as before, but drawn as a single line instead of 200 individual pixels. `DRAW` is more concise when you want a straight line.

**Telegraph ticks (line 170).** `BEEP 0.01, 10` inside the filling loop — a tiny tick on each pixel. The sound builds a rhythm that mirrors the visual bar. When the bar finishes and the red flash hits, the ticks stop — the silence before the signal makes the flash louder.

**Signal BEEP (line 200).** A sharp tone when the screen flashes red. Audio confirmation of the visual event.

**Result sound (lines 300–330).** A different pitch for each rating: high for Lightning, low for Slow. The sound tells the player their result before they read the word.

## DRAW

`DRAW dx, dy` draws a line from the current graphics position (set by the last `PLOT`) by `dx` pixels horizontally and `dy` pixels vertically. `DRAW 200, 0` is a horizontal line 200 pixels long. `DRAW 0, 50` would be a vertical line 50 pixels tall. `DRAW 100, 50` would be a diagonal.

PLOT sets the starting point; DRAW extends from it. Together they are the Spectrum's basic pixel-drawing tools — everything from lines to shapes to simple graphics builds on these two commands.

A complete reaction tester: title screen, telegraph bar with audio ticks, red-flash signal, timed response, colour-coded rating with sound. About 25 lines of BASIC and a program you can challenge someone with.
