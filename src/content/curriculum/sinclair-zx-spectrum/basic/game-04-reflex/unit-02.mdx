The player pressed a key. But how fast? Without a number, there is no game — just a reflex with no record.

<CodeFromFile src="sinclair-zx-spectrum/basic/game-04-reflex/unit-02/timed.bas" />

Lines 60–90 are the timing loop:

- Line 60: `LET t = 0` — start the counter at zero.
- Line 70: `IF INKEY$ <> "" THEN GO TO 100` — if a key is pressed, jump to the result.
- Line 80: `LET t = t + 1` — no key pressed, so count one tick.
- Line 90: `GO TO 70` — check again.

When the player finally presses a key, `t` holds the number of times the loop ran before they reacted. Smaller is faster.

## Not real time, but good enough

The number is not in milliseconds — it is in loop iterations. Each iteration takes however long BASIC needs to check `INKEY$` and increment `t`. That is not precise, but it is consistent: the same reaction speed will produce roughly the same number each time.

Run it five times. Watch the number drop as your anticipation improves. The first try might be 20. By the fifth, you are hitting 8 or 9. That dropping number *is* the game — you are competing against yourself.

The counter pattern — `LET t = 0` before a loop, `LET t = t + 1` inside it — is the same accumulator you used in Lucky Number for counting guesses. Here it measures time instead of attempts. Same pattern, different purpose.
