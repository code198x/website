Line 185 (the random PAUSE) is gone. In its place: line 120 (blank line), lines 150–180 (FOR/PLOT/NEXT). This is a FOR/NEXT loop — it repeats the PLOT command for every value of `x` from 28 to 228, drawing one pixel per step. We'll explore FOR/NEXT properly in Dice Roller; for now, read it as "do this 200 times, once per pixel." When the bar is complete, "NOW!" appears.

## PLOT

`PLOT x, 87` places a single pixel at horizontal position `x`, vertical position 87. The FOR loop runs `x` from 28 to 228, drawing 200 pixels — a horizontal line that fills left to right.

The Spectrum's screen is 256×176 pixels. Origin (0, 0) is the bottom-left corner.

## Telegraphing

The bar creeps across the screen. The player watches it approach the right edge. They know the signal is coming — but not exactly when. The bar **telegraphs** the event: it shows something is about to happen without revealing the exact moment.
