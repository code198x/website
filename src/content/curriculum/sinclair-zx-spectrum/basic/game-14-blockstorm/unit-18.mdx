Two more enemy types join the fight. Tanks (UDG C) are heavy, drawn in yellow, and take two hits to destroy — the first hit produces a damage flash, the second triggers the explosion. Bombers (UDG D) are magenta and periodically drop bomb UDGs that fall downward toward the player. Four enemy types, each with distinct behaviour, each with a unique UDG and colour.

## How It Works

**Tanks (type 3)** have `h(i)` set to 2 in the wave data — two hit points. When a bullet hits a tank, the hit routine decreases `h(i)` by 1. If hit points remain, the tank flashes: briefly display in white (INK 7), PAUSE 2, then redraw in yellow (INK 6). Only when `h(i)` reaches 0 does the explosion trigger. Tanks are worth 50 points — the highest value enemy.

**Bombers (type 4)** have a special action during the enemy movement phase. Each frame, every living bomber has a random chance to drop a bomb. The bomb is UDG J (CHR$ 153) in red (INK 2), positioned one row below the bomber. It falls downward one cell per frame, independently of the formation.

**Colour assignment** uses the type number directly:

| Type | Colour | INK |
|------|--------|-----|
| 1 (Drone) | Green | 4 |
| 2 (Scout) | Cyan | 5 |
| 3 (Tank) | Yellow | 6 |
| 4 (Bomber) | Magenta | 3 |

The drawing routine maps type to colour with IF statements: `IF t(i) = 2 THEN LET ci = 5` and so on. Each enemy type is instantly recognisable.

## Multi-Hit Enemies

The `h()` array already exists — it stored 1 for every drone. Tanks simply start with 2. The collision code already decrements `h()` and checks for zero. No new collision logic is needed. The damage flash is the only new visual code.

This is the strength of data-driven design. The collision system does not know about specific enemy types. It knows about hit points. A drone with 1 hit point and a tank with 2 hit points use exactly the same collision code. A hypothetical boss with 10 hit points would also work with no code changes — just a different starting value in `h()`.

## Enemy Projectiles

Bombs create a second threat axis. The player must now dodge falling bombs while aiming upward at enemies. The game shifts from pure offence (shoot everything) to a balance of offence and defence (shoot while dodging). This dual threat is what makes the middle waves of Blockstorm challenging.

## Try This

**Increase tank health.** Set a tank to 3 or 4 hit points. Does the damage flash keep the player informed about progress? At what point does a multi-hit enemy become tedious rather than challenging?

**Bomber accuracy.** Instead of random bomb drops, make bombers drop a bomb when the player is directly below them. Compare the difficulty. Random bombs create general pressure. Aimed bombs create specific threats.
