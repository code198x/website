When every enemy in a wave is destroyed, the wave is clear. The game pauses briefly to celebrate: "WAVE CLEAR!" appears on screen, bonus points are awarded, a fanfare plays. Then the next wave loads from DATA and the fight continues. This unit connects the five waves into a continuous progression.

## How It Works

**Lines 650-676** check for wave clear at the end of each game loop. A FOR/NEXT loop scans the hit points array. If any enemy has hit points greater than 0, the wave is not yet clear and the routine returns immediately. If every entry is 0, all enemies are destroyed.

**Lines 662-670** run the wave clear sequence:

1. Print "WAVE CLEAR!" at the centre of the screen in bright white.
2. Award bonus points: 50 multiplied by the wave number. Wave 1 gives 50 points, wave 5 gives 250.
3. Play the fanfare: three ascending BEEPs.
4. Update the HUD to show the new score.
5. PAUSE 50 — one second of celebration.
6. Increment the wave number.

**Line 674** checks if all waves are complete. If the wave number exceeds the total waves, the game victory screen appears. Otherwise, execution jumps back to line 40 to load the next wave.

**Lines 42-58** reload by using RESTORE 900 and skipping past earlier waves. Each wave header has three values, and each enemy has four. The skip loop reads and discards all values for waves before the current one, then reads the current wave data into the arrays.

## RESTORE and DATA Positioning

RESTORE resets the DATA pointer — the position from which READ takes its next value. By default, READ works through all DATA statements in order. RESTORE 900 moves the pointer back to the DATA statement at line 900.

The wave-skipping approach reads and discards earlier waves. An alternative is to use RESTORE with the exact line number of each wave (RESTORE 910 for wave 2, RESTORE 920 for wave 3, and so on). This requires knowing the line numbers in advance, but avoids the skip loop. The current approach is more flexible — it works even if you rearrange the DATA statements.

## Bonus Points

The wave clear bonus scales linearly: 50, 100, 150, 200, 250 for waves 1-5. This rewards reaching later waves. A player who clears wave 5 earns 750 bonus points across all waves. Combined with per-enemy points, the scoring gives skilled players substantially higher totals.

## Try This

**Adjust the bonus.** Change the multiplier from 50 to 100. Does the bonus feel too generous? The bonus should be noticeable but not dominate the score — per-enemy points should still matter.

**Add a wave counter to the title.** When the game resets after game over, remember which wave the player reached and display it: "Best wave: 4". This gives the player a secondary goal beyond score.
