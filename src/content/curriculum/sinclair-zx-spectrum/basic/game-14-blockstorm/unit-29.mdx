Two special events round out the game mechanics. The first is a reward: reaching 2,000 points earns one extra life, announced with a fanfare and a new life icon appearing in the HUD. The second is a punishment: if the formation descends to the player row, the game ends immediately regardless of remaining lives. The aliens have invaded.

## How It Works

**Line 526** handles the extra life:

```
IF el = 0 AND sc >= 2000 THEN LET li = li + 1: LET el = 1: BEEP 0.1, 15: BEEP 0.1, 19
```

The variable `el` is a one-shot flag. It starts at 0. When the score crosses 2,000 for the first time, the player gains a life, `el` is set to 1, and a two-note fanfare plays. Because `el` is now 1, the condition never triggers again — one extra life only, no matter how high the score climbs.

**Line 426** handles the invasion check:

```
IF fy + nr > 19 THEN GO TO 700
```

After each formation descent, the code checks whether the bottom row of the formation (`fy + nr`) has passed row 19 — one row above the player. If it has, execution jumps directly to the game over screen. No death animation, no life deduction — the invasion is absolute.

## The One-Shot Flag

The `el` variable prevents the extra life from being awarded repeatedly. Without it, the player would gain a life every time the score crosses 2,000 — which, if the score keeps climbing, would mean infinite lives. The one-shot flag is a common pattern: check the condition, do the action, set the flag, never do it again.

One-shot flags are simple but they must be reset at the right time. When the game restarts after game over, `el` resets to 0 (line 742). If it were not reset, the player would never earn the extra life again across multiple games in the same session.

## The Invasion Fail State

The invasion rule creates urgency that pure scoring does not. A player can achieve a high score and still lose if they do not destroy enemies quickly enough. The formation descends relentlessly — each edge bounce drops it one row closer. If the player focuses on dodging bombs instead of shooting, the formation creeps down. If they fire inaccurately, enemies survive longer and descend further.

This mechanic rewards aggressive play. The safest strategy is not to hide at the bottom and dodge — it is to shoot accurately and thin the formation before it reaches danger height.

## The 2,000-Point Threshold

Why 2,000? A player who clears the first three waves with moderate accuracy earns roughly 1,500-2,000 points (80-100 enemies at 10-50 points each, plus wave bonuses). The extra life arrives around wave 3 or 4 — early enough to feel like a genuine reward, late enough that the player has earned it.

## Try This

**Multiple thresholds.** Award extra lives at 2,000, 5,000 and 10,000 points. Use a threshold variable instead of a flag: `IF sc >= th THEN life: LET th = th + 3000`. Does this make the game too easy or does it scale with difficulty?

**Invasion warning.** When `fy + nr` reaches row 15 (5 rows from the bottom), flash the border red. Give the player a warning before the fatal descent. Does this add tension or just clutter?
