## What You'll Build

Pac-Man style maze game. Collect items, avoid ghosts, use power-ups to turn the tables.

Navigate corridors eating pellets. Ghosts hunt you — each with distinct personality. One chases, another ambushes, another wanders. Power pills let you fight back. This game introduces AMOS Banks for data storage and tile-based rendering with PASTE BOB.

## Skills You'll Master

- **Tile-based maze** — PASTE BOB rendering
- **Constrained movement** — corridor navigation
- **Ghost AI personalities** — behaviour patterns
- **Power-up state changes** — mode transitions
- **Screen wrapping** — edge handling
- **AMOS Banks** — data storage
- **Timing control** — speed management
- **Multi-screen maze** — large levels

## Prerequisites

Complete **Game 4: Bounce Back** first.

## Time Investment

64 units at 60-90 minutes each. Roughly 64-96 hours total.
