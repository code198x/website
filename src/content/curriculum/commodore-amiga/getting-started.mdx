## What You Need

To develop for the Amiga, you need three things: a way to **compile** your code, an **emulator** to run it, and **Kickstart ROMs**.

<div class="setup-grid">
<div class="setup-column">

### <span class="icon">⚙️</span> Dev Toolchain

**Asm198x** assembles the program; **Build198x** masters the disk it boots from.

#### Install

```bash
brew install asm198x/tap/asm198x
```

Build198x is a [direct download](https://github.com/build198x/build198x/releases/latest)
for macOS, Linux and Windows — put `build198x` on your PATH.

#### Compile

```bash
asm198x --dialect vasm --exe game.asm -o game
```

#### Create Bootable Disk

```bash
build198x adf game -o game.adf --volume Game
```

One command writes the boot block, the `s/startup-sequence` that runs your
program, and the program itself. The same source always produces the same
disk, byte for byte.

</div>
<div class="setup-column">

### <span class="icon">🖥️</span> Emulator

Install an Amiga emulator natively for the best experience.

**macOS / Linux**
```bash
brew install --cask fs-uae  # macOS
sudo apt install fs-uae     # Linux
```

**Windows** — Download [WinUAE](https://www.winuae.net/)

#### Kickstart ROMs

Amiga emulators require Kickstart ROM files:
- Dump from a real Amiga
- Purchase from [Amiga Forever](https://www.amigaforever.com/)

#### Run

```bash
fs-uae --floppy_drive_0=game.adf
```
