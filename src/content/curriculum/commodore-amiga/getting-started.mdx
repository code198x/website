## Try the result first

The [first Amiga assembly lesson](/systems/commodore-amiga/assembly/meet-the-machine/unit-01/) makes the screen turn red. Its **Run it here** control opens the supplied disk in the browser player. Follow the player’s firmware instructions if it asks for a Kickstart ROM.

To edit and rebuild that program, use the local tools below. For programming inside the Amiga’s own language editors, follow the separate [AMOS setup](/systems/commodore-amiga/amos/getting-started/) or [Blitz BASIC setup](/systems/commodore-amiga/blitz/getting-started/) instead.

## Prepare the tools you need

- **A plain-text editor** for your assembly source.
- **Asm198x** to turn the source into an Amiga executable.
- **Build198x** to put that executable on a bootable disk image.
- **An Amiga emulator and Kickstart ROM** to run the disk locally.

For local emulation, use [FS-UAE](https://fs-uae.net/) or, on Windows, [WinUAE](https://www.winuae.net/). Follow the emulator’s installation instructions for your operating system. Configure an **Amiga 500** for this example and supply its Kickstart ROM; the [Amiga ROM guide](/setup/roms/#commodore-amiga) explains where to obtain one.

## Assemble and make the disk

Copy the complete `screen.asm` listing from the [first assembly lesson](/systems/commodore-amiga/assembly/meet-the-machine/unit-01/) into a plain-text file with that name. Open a terminal in its folder.

First, assemble it:

```sh
asm198x --dialect vasm --exe screen.asm -o screen
```

Then put the executable on a bootable floppy:

```sh
build198x adf screen -o screen.adf --volume Screen
```

The `vasm` dialect names the assembly syntax; Asm198x does the assembling. Build198x writes the disk and the startup instructions that run `screen`.

## Run it and change it

Insert `screen.adf` in your emulator’s `DF0:` drive and restart the emulated Amiga. The screen turns red.

In the source, change the colour in `dc.w COLOR00,$0f00` from `$0f00` to `$00f0`. Save the source, run both build commands again and restart with the new disk. The screen should turn green.

If you see the insert-disk screen, check that `screen.adf` is in `DF0:` and both build commands completed successfully. If an assembler error names a line, compare that line with the lesson before trying again.

## Keep your work and continue

Keep `screen.asm`, the executable and `screen.adf` in the same project folder. Reopen your source and boot the disk once more to check that you can recover the work.

[Continue the Amiga assembly lesson](/systems/commodore-amiga/assembly/meet-the-machine/unit-01/). If you already work with vasm itself, see the [alternative tools guide](/setup/commodore-amiga/native).
