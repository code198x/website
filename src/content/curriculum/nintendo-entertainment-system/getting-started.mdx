## What You Need

To develop for the NES, you need two things: a way to **compile** your code, and an **emulator** to run it.

<div class="setup-grid">
<div class="setup-column">

### <span class="icon">⚙️</span> Dev Toolchain

**Asm198x** is one binary that assembles for every system in the curriculum.

#### Install

```bash
brew install asm198x/tap/asm198x
```

Or, without Homebrew, the [installer script](https://github.com/asm198x/asm198x/releases/latest)
for macOS, Linux and Windows.

#### Compile

```bash
asm198x --dialect ca65 game.asm -o game.nes
```

Assembling and linking happen in one step, against a bounded linker
configuration Asm198x carries itself. There is no `nes.cfg` to supply.

</div>
<div class="setup-column">

### <span class="icon">🖥️</span> Emulator

Install **FCEUX** natively for the best experience.

**macOS**
```bash
brew install fceux
```

**Linux**
```bash
sudo apt install fceux
```

**Windows** — Download from [fceux.com](https://fceux.com/)

#### Run

```bash
fceux game.nes
```
