## Assemble and run in your browser

The [first NES lesson](/systems/nintendo-entertainment-system/assembly/meet-the-machine/unit-01/) contains a complete editable program. Asm198x assembles it into a cartridge and Emu198x runs it on the page. Nothing needs installing.

Start with its red screen, change one instruction to make it blue, then use **Download source** and **Download cartridge** to keep your version. Download before leaving the page; a running browser session is not a saved project.

## Work in your own editor

For local development you need a plain-text editor, **Asm198x** and an NES emulator. The source is the same one you edited in the browser.

<SetupToolInstall tool="asm198x" />

[FCEUX](https://fceux.com/) is one local emulator you can use. Download the version for your operating system and follow its installation instructions. This example supplies its own cartridge program; no separate system ROM is needed.

## Build your cartridge

Use **Download source** in the [first lesson](/systems/nintendo-entertainment-system/assembly/meet-the-machine/unit-01/) to save `screen.asm`. Open a terminal in that folder and run:

```sh
asm198x --dialect ca65 screen.asm -o screen.nes
```

Asm198x assembles and links this example in one step. Its built-in linker configuration supports the layout used here; you do not need a separate `nes.cfg` for this lesson.

Open `screen.nes` in FCEUX. The original source produces a red screen. Change `lda #$16` to `lda #$11` between the `YOUR CODE` markers, save, rebuild and reopen the cartridge: the screen turns blue.

The `ca65` dialect names the source syntax. It does not require installing ca65 too. The [alternative ca65 guide](/setup/nintendo-entertainment-system/native) is available if you already use that toolchain.

## Keep your work and continue

Keep `screen.asm` alongside `screen.nes`. The cartridge is runnable; the source is what lets you change it again. Reopen both to check that you can recover your work.
