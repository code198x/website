# Underground Assault

Your comprehensive introduction to NES game development! **Underground Assault** teaches you to create a complete action-platformer while mastering the NES hardware.

## Game Concept

You're an underground explorer navigating through dangerous cavern systems. Armed with your trusty blaster, you must fight through enemy-infested tunnels, collect power-ups, and reach the exit of each level. The game features multiple underground environments, each with unique challenges and enemy types.

## What You'll Learn

Building Underground Assault will teach you:

- **NES PPU Programming**: Master the Picture Processing Unit for graphics
- **Sprite Management**: Create and animate characters and objects
- **Background Tiles**: Design and implement scrolling environments
- **Controller Input**: Handle precise player control
- **Audio Programming**: Create music and sound effects with the APU
- **Memory Management**: Work within the NES's strict memory constraints

## Development Progression

### Tiers 1-4: NES Fundamentals
- Set up the NES development environment
- Create basic sprites and backgrounds
- Implement player movement

### Tiers 5-8: Core Gameplay
- Add enemy sprites and AI
- Implement collision detection
- Create the combat system

### Tiers 9-12: Level Design
- Build scrolling level systems
- Add power-ups and collectibles
- Implement level progression

### Tiers 13-16: Polish & Optimization
- Add music and sound effects
- Implement visual effects
- Optimize for smooth 60fps gameplay

## Technical Highlights

Underground Assault demonstrates key NES programming concepts:

- **CHR-ROM Management**: Efficient graphics storage and switching
- **Sprite Multiplexing**: Display more sprites than hardware limits
- **Background Scrolling**: Smooth multi-directional scrolling
- **Memory Mappers**: Using bank switching for larger games
- **APU Programming**: Creating authentic NES audio

## Hardware Features Utilized

This game makes full use of NES capabilities:

- **8x8 and 8x16 Sprites**: Character animation and objects
- **Background Layers**: Detailed environmental graphics
- **Palette Animation**: Dynamic color effects
- **Hardware Scrolling**: Smooth camera movement
- **Sprite Priority**: Layering effects for depth

Underground Assault provides a solid foundation in NES development, preparing you for more advanced projects while creating an engaging and playable game.
