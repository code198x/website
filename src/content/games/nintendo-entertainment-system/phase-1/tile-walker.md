# Tile Walker

**"I made sprites move on tiles!"**

Your first complete NES game! **Tile Walker** is where you'll experience the magic of Nintendo's revolutionary Picture Processing Unit (PPU). Watch as your sprite character moves perfectly aligned with beautiful tiles, just like in the legendary NES games that defined console gaming!

## The Wonder You'll Experience

**"Incredible! This looks like a real Nintendo game!"**

This is your gateway to understanding how the NES created some of gaming's most beloved experiences. You'll feel the satisfaction of precise, tile-perfect movement that made NES games feel so polished and professional!

## Game Concept

Control a sprite character that moves in perfect 16×16 tile increments across a tile-based world. This is the foundation of how Super Mario Bros, Zelda, and countless other classics achieved their legendary precision and feel.

## What You'll Learn

Through building Tile Walker, you'll master:

- **6502 Assembly Programming**: Complete instruction set adapted for NES architecture
- **PPU Programming**: Master the Picture Processing Unit for graphics and sprites
- **Tile-Based Design**: Create efficient tile-based game worlds and movement systems
- **Sprite Control**: Direct manipulation of hardware sprites and OAM
- **Controller Input**: Handle NES controller through shift registers
- **Audio Programming**: Generate sound effects using the NES APU

## Development Progression

### Foundation (Lessons 1-8)

- Set up NES development environment and PPU basics
- Create pattern table graphics and display background tiles
- Implement sprite display and controller input
- Build tile-based positioning system with boundaries

### Tile Interaction (Lessons 9-16)

- Read background tile data and implement collision detection
- Create collectible items and dynamic nametable updates
- Design level layouts and implement scoring
- Add player lives and level completion systems

### Visual Enhancement (Lessons 17-24)

- Add sprite animation frames and palette control
- Create status display and tile animations
- Implement special effects and sprite priority
- Design title screen and screen transitions

### Audio and Completion (Lessons 25-32)

- Program APU for sound effects and background music
- Add game options and high score system
- Implement power-up system and final polish
- Create complete ROM packaging

## Technical Highlights

Tile Walker showcases several important NES programming concepts:

- **PPU System**: Direct control of the revolutionary Picture Processing Unit
- **Hardware Sprites**: 64 hardware sprites with automatic priority handling
- **Pattern Tables**: Efficient tile-based graphics storage and display
- **Nametable Updates**: Dynamic background modification during gameplay
- **Controller Reading**: Shift register input handling for responsive controls
- **APU Programming**: 5-channel sound synthesis for music and effects

## Why Tile-Based Movement?

Tile-based movement is the perfect introduction to NES programming because it teaches:

- **PPU System**: Understanding pattern tables and nametables
- **Sprite Control**: Managing hardware sprites and OAM
- **Memory Efficiency**: Working within NES memory constraints
- **Timing Control**: Frame-perfect movement and updates
- **Game Architecture**: Professional NES game structure

## Game Features

- **Tile Movement**: Character moves in discrete 16×16 tile steps
- **Item Collection**: Collect items scattered throughout levels
- **Hazard Avoidance**: Navigate around dangerous tile-based obstacles
- **Dynamic World**: Tiles change as you interact with them
- **Smooth Animation**: Sprite animation during movement
- **Audio Feedback**: APU-generated sound effects and music
