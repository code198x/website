# Demo Creator

**Demo Creator** captures the legendary spirit of the Amiga demo scene, teaching advanced multimedia programming through the creation of stunning audio-visual demonstrations that showcase the system's artistic potential.

## The Game Concept

Build a complete multimedia demonstration system:

- **Visual Effects Creation**: Design stunning graphics effects and transitions
- **Music Synchronization**: Coordinate visuals with multi-channel audio
- **Copper Programming**: Utilize advanced hardware effects
- **Scene Management**: Create complex, multi-part demonstrations
- **Professional Output**: Generate polished, distributable demos

## Why This Game for Tiers 9-12?

**Demo Creator** introduces sophisticated 68000 assembly multimedia concepts:

- **Advanced Graphics**: Master copper programming and hardware effects through assembly
- **Synchronization Systems**: Coordinate complex audio-visual timing via assembly
- **Creative Programming**: Express artistic vision through 68000 assembly code
- **Performance Optimization**: Achieve smooth real-time effects using assembly
- **Demo Scene Culture**: Understand the Amiga's creative computing legacy through assembly
