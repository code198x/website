# Turbo Horizon

Experience the power of the Amiga's custom chips with **Turbo Horizon**, a racing game that demonstrates the system's advanced graphics and audio capabilities.

## Game Concept

Turbo Horizon is a high-speed racing game where you compete against AI opponents on various tracks. The game showcases the Amiga's ability to create smooth, colorful graphics with hardware-accelerated effects. You'll race through different environments, from desert highways to futuristic cityscapes, all rendered with the Amiga's distinctive visual style.

## What You'll Learn

Building Turbo Horizon will teach you:

- **Custom Chip Programming**: Master Agnus, Denise, and Paula
- **Copper Programming**: Create stunning visual effects
- **Blitter Operations**: Achieve fast graphics performance
- **Hardware Sprites**: Implement smooth character animation
- **68000 Assembly**: Program the powerful Motorola processor
- **Audio Programming**: Utilize the 4-channel sound system

## Development Progression

### Tiers 1-4: Amiga Fundamentals
- Set up the Amiga development environment
- Learn the custom chip architecture
- Create basic playfield graphics

### Tiers 5-8: Graphics Programming
- Implement hardware sprites
- Program the copper for effects
- Create scrolling backgrounds

### Tiers 9-12: Game Mechanics
- Add racing physics and controls
- Implement AI opponents
- Create track collision detection

### Tiers 13-16: Advanced Features
- Add 4-channel audio
- Implement visual effects
- Optimize for smooth performance

## Technical Highlights

Turbo Horizon demonstrates advanced Amiga programming:

- **Dual Playfields**: Create depth with multiple background layers
- **Hardware Sprites**: Smooth 16-color animated objects
- **Copper Lists**: Real-time color changes and effects
- **Blitter Programming**: Fast memory-to-memory operations
- **Paula Audio**: Rich 4-channel sound with samples

## Amiga-Specific Features

This game showcases what made the Amiga special:

- **HAM Mode**: Display thousands of colors simultaneously
- **Overscan**: Use the full screen area
- **Interlaced Graphics**: High-resolution display modes
- **Sample Playback**: Rich audio with digital samples
- **Hardware Acceleration**: Smooth performance through custom chips

## Why the Amiga Approach

Turbo Horizon teaches you to think like an Amiga programmer:

- **Hardware Acceleration**: Let the chips do the work
- **Parallel Processing**: Multiple systems working together
- **Rich Audio**: Create immersive soundscapes
- **Efficient 68000 Code**: Write fast, clean assembly

This game provides a complete introduction to Amiga programming while creating a genuinely impressive racing experience that showcases the system's capabilities.
