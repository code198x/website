# Cursor Quest
**"I made text graphics come alive!"**

Your first complete ZX Spectrum game! **Cursor Quest** is where you'll discover the magic of making text graphics interactive and colorful. Watch as simple characters become your first game character, leaving beautiful trails of color across the screen!

## The Wonder You'll Experience

**"Amazing! Text can be a game!"**

This is your introduction to the unique world of Spectrum programming, where creative constraints lead to incredible innovations. You'll experience the joy of making simple text characters dance across the screen in ways that feel magical!

## Game Concept

Navigate a cursor character (@) through a field of text, painting colorful trails using the Spectrum's attribute system. This is how the British bedroom coding scene began - with simple characters becoming the foundation of incredible games.

## What You'll Learn

Through building Cursor Quest, you'll master:

- **Z80 Assembly Programming**: Complete instruction set, addressing modes, and programming techniques
- **Character-Based Graphics**: Master the Spectrum's unique text-mode display system
- **Attribute System**: Control color attributes for visual effects and trail rendering
- **Keyboard Input**: Direct hardware keyboard matrix reading
- **Memory Management**: Efficient use of screen and attribute memory
- **Audio Programming**: Beeper sound generation for effects and music

## Development Progression

### Foundation (Lessons 1-8)
- Set up Spectrum development environment and screen memory basics
- Learn character display and screen address calculation
- Implement keyboard matrix reading
- Build cursor movement system with boundary checking

### Attribute Effects (Lessons 9-16)
- Master attribute memory system for color control
- Create trail effect framework with fading
- Implement target letter system
- Add collision detection and scoring

### Visual Polish (Lessons 17-24)
- Add border effects and character animation
- Generate maze layouts and special zones
- Create particle-like character effects
- Design title screen and transitions

### Audio and Completion (Lessons 25-32)
- Program beeper for sound effects and music
- Add difficulty settings and high score system
- Implement power-up system
- Create loading screen and final polish

## Technical Highlights

Cursor Quest showcases several important Spectrum programming concepts:

- **Character Graphics**: Direct control of screen memory for text-based games
- **Attribute Effects**: Creative use of INK, PAPER, BRIGHT, and FLASH attributes
- **Keyboard Matrix**: Hardware-level input reading without OS overhead
- **Memory Layout**: Understanding the Spectrum's unique screen organization
- **Beeper Programming**: Sound generation using the simple beeper system
- **Color Management**: Working with and around the attribute system

## Why Character Movement?

Character movement is the perfect introduction to Spectrum programming because it teaches:

- **Screen Memory Layout**: Understanding the Spectrum's unique display system
- **Attribute Control**: Managing colors and visual effects
- **Input Handling**: Responsive keyboard controls
- **Memory Efficiency**: Working within the 48K constraint
- **Visual Effects**: Creative use of the attribute system

## Game Features

- **Character Movement**: Cursor (@) moves through 32×24 character grid
- **Trail Effects**: Colored attribute trail showing movement history
- **Target Collection**: Find and collect specific letter targets
- **Maze Navigation**: Navigate through walls and obstacles
- **Sound Effects**: Beeper-based audio feedback
- **Visual Polish**: Border effects and character animation

## Spectrum-Specific Features

**Attribute System**: Learn to work with and creatively use the Spectrum's color attribute system, including managing color clash.

**Character Mode**: Master efficient 8×8 character-based graphics for fast, responsive gameplay.

**Keyboard Matrix**: Direct hardware keyboard reading for responsive controls.

**Beeper Sound**: Create effective audio using the simple but versatile beeper system.

**Memory Banking**: Understand differences between 48K and 128K models.

## Educational Value

Cursor Quest serves as your foundation for all future Spectrum game development. The skills you learn here—character-based graphics, attribute manipulation, keyboard input, and memory management—will be essential for creating more complex games throughout Phase 1.

This project teaches the distinctive programming techniques that made Spectrum games unique and memorable.
