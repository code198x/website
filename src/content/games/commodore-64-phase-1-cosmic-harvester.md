# Cosmic Harvester

Your first complete game for the Commodore 64! In **Cosmic Harvester**, you'll learn the fundamentals of game programming while creating an engaging arcade experience.

## Game Concept

You pilot a small harvesting ship through dangerous asteroid fields in deep space. Your mission is to collect energy crystals while avoiding collisions with asteroids and other cosmic debris. The game gradually increases in difficulty as you progress, testing your reflexes and piloting skills.

## What You'll Learn

Through building Cosmic Harvester, you'll master:

- **Sprite Programming**: Learn to create, animate, and control sprites
- **Game Physics**: Implement realistic movement with inertia and momentum
- **Collision Detection**: Build efficient systems to detect when objects interact
- **Memory Management**: Organize your code and data efficiently in the C64's limited memory
- **Audio Programming**: Create music and sound effects using the SID chip
- **Optimization**: Write fast, efficient 6502 assembly code

## Development Progression

### Tiers 1-4: Foundation
- Set up the game screen and basic controls
- Create the player ship sprite
- Implement basic movement

### Tiers 5-8: Core Mechanics
- Add asteroids and collision detection
- Implement the crystal collection system
- Create the scrolling background

### Tiers 9-12: Polish & Features
- Add sound effects and music
- Implement the scoring system
- Create visual effects

### Tiers 13-16: Advanced Features
- Add multiple asteroid types
- Implement difficulty progression
- Optimize for smooth gameplay

## Technical Highlights

Cosmic Harvester showcases several important C64 programming concepts:

- **Sprite Multiplexing**: Display more objects than the hardware natively supports
- **Raster Interrupts**: Smooth background scrolling and effects
- **Memory Banking**: Efficient use of the C64's memory layout
- **Custom Character Sets**: Create unique visual elements

This game serves as your introduction to professional-quality C64 game development, establishing the foundation for more complex projects in later phases.
