# Tier 1: 6502 Assembly Foundations

Welcome to authentic Commodore 64 programming! With **32 comprehensive lessons**, you'll have plenty of time to thoroughly learn the fundamentals of 6502 assembly language. Starting with assembly gives you direct control over the hardware and teaches you how computers really work.

## What You'll Build

During this tier, you'll work toward creating your first assembly project: **Number Quest** - a simple number guessing game programmed entirely in 6502 machine language, demonstrating fundamental programming concepts at the hardware level.

## Tier Overview

**Lessons 1-8: 6502 Architecture Fundamentals**
- Understanding the 6502 processor and its registers (A, X, Y)
- C64 memory map and how RAM, ROM, and I/O are organized
- Your first assembly program - displaying a character on screen
- Basic load and store instructions (LDA, STA, LDX, STX)

**Lessons 9-16: Memory and Addressing**
- Different addressing modes (immediate, absolute, zero page)
- Understanding how memory addresses work
- Manipulating screen memory directly
- Building simple display and character programs

**Lessons 17-24: Program Flow and Logic**
- Branch instructions and conditional jumps
- Simple loops and program flow control
- Status flags and how the processor makes decisions
- Creating interactive assembly programs

**Lessons 25-32: Number Quest Foundation**
- Applying assembly concepts to game programming
- Random number generation in assembly
- User input handling at the hardware level
- Building toward your first complete assembly game

## Key Concepts

This tier introduces the fundamental building blocks of assembly programming:

- **Direct Hardware Control** - Programming the processor directly
- **Memory Management** - Understanding how data is stored and accessed
- **Processor Architecture** - How the 6502 CPU actually works
- **Machine Language** - The native language of the computer

These concepts teach you how computers really work at the lowest level - knowledge that applies to all modern programming and computer science!
