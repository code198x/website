# Tier 2: Data Storage and Memory Operations

Build on your 6502 foundation by learning how to store and manipulate data in assembly language. This tier focuses on memory operations and data handling - essential skills for creating interactive programs.

## What You'll Build

Continue developing **Number Quest** by adding:
- Data storage for game state and user input
- Memory-based input validation routines
- Efficient data manipulation using zero page
- Assembly-based user interface components

## Tier Overview

**Lessons 1-8: Zero Page Mastery**
- Understanding zero page advantages and addressing
- Storing program data efficiently
- Working with memory locations as variables
- Zero page addressing modes and techniques

**Lessons 9-16: Data Manipulation**  
- Moving data between memory locations
- Basic arithmetic operations on stored data
- Comparing values and making decisions
- Building data processing routines

**Lessons 17-24: Input Processing**
- Reading keyboard input at the hardware level
- Converting input to usable data
- Validating user input in assembly
- Error handling and user feedback

**Lessons 25-32: Number Quest Data Systems**
- Implementing game state storage
- Building input validation for number guessing
- Creating data-driven game logic
- Integrating memory operations with game flow

## Key Assembly Concepts

This tier introduces essential data handling skills:

- **Memory Management** - Efficient use of RAM for data storage
- **Zero Page Optimization** - Using the fastest memory locations
- **Data Validation** - Ensuring data integrity at the hardware level
- **Input Processing** - Direct keyboard handling without BASIC
- **Memory Organization** - Structuring data for optimal access

## Hardware-Level Understanding

These concepts teach you how computers really handle data:

- **Direct memory access** - No operating system overhead
- **Efficient addressing** - Zero page operations are faster
- **Hardware control** - Reading keyboard directly from I/O
- **Memory mapping** - Understanding where data lives
- **Processor efficiency** - Optimizing for 6502 architecture

By mastering data operations in assembly, you understand how all higher-level programming languages implement variables and data structures!
