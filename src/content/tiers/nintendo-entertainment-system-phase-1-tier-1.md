# Tier 1: 6502 Assembly Basics

Welcome to the power of assembly language! Unlike other systems that start with BASIC, the NES teaches you real machine language programming from day one, giving you direct control over every aspect of the hardware.

## What You'll Start Building

Begin **Sprite Symphony** development:
- Generate simple tones using the pulse wave channels
- Display sprites that represent musical notes
- Create basic note sequences and timing
- Build the foundation for a complete music system

## Tier Overview

**Lessons 1-8: Processor Fundamentals**
- Understanding the 6502 architecture
- Registers and their purposes
- Memory organization and addressing
- Basic instruction execution cycle

**Lessons 9-16: First Instructions**
- Load and store operations (LDA, STA, LDX, STX)
- Register transfers and basic operations
- Immediate vs absolute addressing
- Writing your first working programs

**Lessons 17-24: Sound Programming**
- NES APU architecture and channels
- Memory-mapped sound registers
- Generating basic tones and frequencies
- Understanding audio timing

**Lessons 25-32: Visual Feedback**
- Sprite system basics
- Positioning sprites on screen
- Synchronizing visuals with audio
- Building Sprite Symphony's foundation

## Why Start with Assembly?

The NES approach teaches fundamental concepts:

- **Direct Hardware Control** - No abstraction layers hiding the machine
- **Memory Management** - Explicit control over every byte
- **Performance Understanding** - See exactly how fast operations are
- **System Architecture** - Learn how computers really work
- **Optimization Skills** - Make every instruction count

## 6502 Advantages for Learning

The 6502 is perfect for education:

- **Simple Design** - Clean, understandable architecture
- **Limited Instruction Set** - Easy to learn completely
- **Immediate Results** - Audio and visual output from simple code
- **Historical Significance** - Powers Apple II, C64, Atari, and NES
- **Modern Relevance** - Still used in embedded systems today

## Real-World Applications

Assembly programming skills transfer to:

- **Embedded systems** - Microcontrollers and IoT devices
- **Performance optimization** - Critical sections in any language
- **Reverse engineering** - Understanding existing software
- **Game development** - Low-level graphics and audio programming
- **System programming** - Operating systems and drivers

Starting with assembly gives you a deep understanding that high-level languages can't provide!
