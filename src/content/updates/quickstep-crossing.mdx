[Quickstep](/systems/sinclair-zx-spectrum/basic/quickstep/) turns a moving lane
into a crossing that asks you to plan the step after the next gap. Ten lessons
build the game in stock 48K Sinclair BASIC, with eight runnable checkpoints.

Begin with original character artwork and one step per key press. Add traffic,
a clock and contact checks before expanding to six lanes. A route-planning
experiment makes waiting part of the decision; input buffering then retains a
recognised short press while BASIC draws the screen.

Each programming step includes exact editing instructions and a complete
listing. The final lesson saves a tape and checks the game in a fresh machine.
