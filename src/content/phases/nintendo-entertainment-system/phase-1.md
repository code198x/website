# Phase 1: Foundation - NES Development

Welcome to your journey into Nintendo Entertainment System game development! In this foundational phase, you'll build **Underground Assault**, a complete action game that demonstrates the revolutionary capabilities that made the NES a gaming legend.

## What You'll Build

**Underground Assault** is an intense underground combat game that showcases the NES's hardware sprite system and smooth scrolling capabilities. Through 16 progressive lessons across 4 tiers, you'll create:

- Smooth hardware sprite animations
- Responsive controller input
- Advanced projectile systems
- Enemy AI and attack patterns
- Sound effects using the APU
- A complete game with progression and challenge

## The NES Advantage

The NES's custom hardware offers unique development opportunities:

- **6502 Processor**: Master the CPU that powered a generation
- **PPU (Picture Processing Unit)**: Hardware sprites and scrolling
- **Hardware Sprites**: 64 independent sprites with automatic rendering
- **Pattern Tables**: Efficient tile-based graphics system
- **Audio Processing Unit**: Five-channel sound synthesis

## Learning Path

### Tier 1: Core Mechanics (Lessons 1-4)
Start with the basics: creating animated backgrounds, adding a player ship, implementing shooting mechanics, and basic collision detection.

### Tier 2: Enemies and Combat (Lessons 5-8)
Add enemy drones, AI patterns, sprite-to-sprite collision, and explosive effects using the hardware capabilities.

### Tier 3: Power-Ups and Features (Lessons 9-12)
Implement power-up systems, special weapons, boss battles, and scrolling backgrounds.

### Tier 4: Polish and Completion (Lessons 13-16)
Add scoring systems, lives and continues, attract mode, and final polish to create a complete NES experience.

## Development Philosophy

NES development teaches fundamental game programming:

- **Hardware Understanding**: Direct control over every pixel and sound
- **Resource Management**: Work within hardware constraints creatively
- **Performance**: Every cycle counts in real-time games
- **Polish**: Nintendo-quality requires attention to detail

## Prerequisites

Before starting, ensure you have:

- A text editor for writing assembly code
- The cc65 suite (ca65/ld65) installed
- An NES emulator (FCEUX recommended)
- Basic understanding of computer architecture
- Excitement for retro game creation!

## What Makes This Special

This isn't just another tutorial series. You'll:

- Write real 6502 assembly that runs on actual NES hardware
- Understand the techniques behind Nintendo's classic games
- Build a complete, polished game worthy of the NES library
- Join a passionate community of homebrew developers

## Hardware Features You'll Master

### Sprites
- 8×8 or 8×16 pixel hardware sprites
- 64 sprites with automatic priority handling
- Sprite DMA for flicker-free animation
- Multi-sprite objects and meta-sprites

### Backgrounds
- Tile-based background system
- Hardware scrolling capabilities
- Pattern table graphics
- Nametable management

### Sound
- Pulse wave channels for melodies
- Triangle wave for bass lines
- Noise channel for effects
- DMC for sampled sounds
