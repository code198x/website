Welcome to Phase 1 of the ZX Spectrum programming course! This phase introduces you to Z80 assembly language programming on one of the most popular British home computers of the 1980s.

## What You'll Learn

In this phase, you'll build a solid foundation in Z80 assembly programming, starting with basic processor operations and progressing through memory management, graphics, and sound programming. By the end of Phase 1, you'll be comfortable writing assembly programs that interact with the ZX Spectrum's unique hardware features.

## Course Structure

The phase is divided into 16 tiers, each containing 32 focused lessons. You'll progress from simple register operations to creating interactive programs that use the Spectrum's colour graphics and beeper sound.

Start your journey into Z80 assembly programming and discover the power of the processor that powered millions of home computers!
