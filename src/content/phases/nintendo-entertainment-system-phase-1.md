Welcome to Phase 1 of the Nintendo Entertainment System programming course! This phase introduces you to 6502 assembly language programming specifically for NES game development.

## What You'll Learn

In this phase, you'll discover how to program the NES at the lowest level, understanding how classic games were created. You'll learn about the 6502 processor variant used in the NES, the Picture Processing Unit (PPU) for graphics, and the Audio Processing Unit (APU) for sound.

## Course Structure

The phase is divided into 16 tiers, each containing 32 focused lessons. You'll start with basic 6502 operations and progress through NES-specific topics like sprite manipulation, background scrolling, and sound generation.

Begin your journey into NES development and learn the skills that created gaming legends!
