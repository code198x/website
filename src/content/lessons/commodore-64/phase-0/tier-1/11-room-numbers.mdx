# Room Numbers

**Organize your world! Learn to create numbered room systems that make building large adventures manageable and systematic.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={11} />

## Why Number Your Rooms?

As adventures grow larger, keeping track of rooms becomes challenging. Professional game designers use numbered room systems to organize their worlds logically and make connections manageable.

<TryItNow>
```basic
10 REM MYSTERY CAVE - NUMBERED ROOMS
20 RM = 1: REM CURRENT ROOM NUMBER
30 PRINT CHR$(147)
40 REM ROOM DESCRIPTIONS
50 IF RM = 1 THEN PRINT "ROOM 1: CAVE ENTRANCE"
60 IF RM = 1 THEN PRINT "DAYLIGHT FILTERS IN FROM SOUTH"
70 IF RM = 2 THEN PRINT "ROOM 2: MAIN HALLWAY"
80 IF RM = 2 THEN PRINT "ANCIENT STONE CORRIDORS STRETCH N/E/W"
90 IF RM = 3 THEN PRINT "ROOM 3: CRYSTAL CHAMBER"
100 IF RM = 3 THEN PRINT "GLOWING CRYSTALS LIGHT THE WALLS"
110 IF RM = 4 THEN PRINT "ROOM 4: UNDERGROUND LAKE"
120 IF RM = 4 THEN PRINT "DARK WATER LAPS AT ROCKY SHORES"
130 PRINT
140 INPUT "GO WHERE (N/S/E/W)"; D$
150 REM MOVEMENT LOGIC BY ROOM
160 IF RM = 1 AND D$ = "N" THEN RM = 2: GOTO 30
170 IF RM = 1 AND D$ = "S" THEN PRINT "YOU EXIT": END
180 IF RM = 2 AND D$ = "S" THEN RM = 1: GOTO 30
190 IF RM = 2 AND D$ = "N" THEN RM = 3: GOTO 30
200 IF RM = 2 AND D$ = "E" THEN RM = 4: GOTO 30
210 IF RM = 3 AND D$ = "S" THEN RM = 2: GOTO 30
220 IF RM = 4 AND D$ = "W" THEN RM = 2: GOTO 30
230 PRINT "YOU CAN'T GO THAT WAY."
240 GOTO 140
```
</TryItNow>

Now each room has a clear number, making it easy to add new rooms and connections!

## Room Data Tables

Let's create a more sophisticated system that stores room information in a structured way:

<InfoBox type="tip">
**Design Tip**: C64 BASIC uses 2-character variable names. Use meaningful abbreviations like RM (room), EX (exits), TR (treasure) to keep your code readable.
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - ROOM DATA SYSTEM
20 RM = 1: SC = 0: HP = 100
30 PRINT CHR$(147)
40 REM DISPLAY CURRENT ROOM
50 GOSUB 1000: REM GET ROOM DATA
60 PRINT "=============================="
70 PRINT "ROOM"; RM; ": "; R$
80 PRINT "=============================="
90 PRINT D$
100 PRINT
110 IF TR > 0 THEN PRINT "TREASURE: +"; TR; " POINTS!"
120 PRINT "HEALTH:"; HP; " SCORE:"; SC
130 PRINT
140 INPUT "DIRECTION"; MV$
150 REM MOVEMENT HANDLER
160 GOSUB 2000
170 GOTO 30
180 END
990 REM
1000 REM ROOM DATA SUBROUTINE
1010 IF RM = 1 THEN R$ = "ENTRANCE HALL"
1020 IF RM = 1 THEN D$ = "SUNLIGHT STREAMS IN"
1030 IF RM = 1 THEN TR = 0
1040 IF RM = 2 THEN R$ = "CRYSTAL CAVERN"
1050 IF RM = 2 THEN D$ = "BLUE CRYSTALS GLOW SOFTLY"
1060 IF RM = 2 THEN TR = 50
1070 IF RM = 3 THEN R$ = "DRAGON'S LAIR"
1080 IF RM = 3 THEN D$ = "BONES LITTER THE FLOOR"
1090 IF RM = 3 THEN TR = 200
1100 RETURN
1990 REM
2000 REM MOVEMENT SUBROUTINE
2010 NE = 0: REM NEW ROOM (0 = CAN'T MOVE)
2020 IF RM = 1 AND MV$ = "N" THEN NE = 2
2030 IF RM = 1 AND MV$ = "E" THEN NE = 3
2040 IF RM = 2 AND MV$ = "S" THEN NE = 1
2050 IF RM = 2 AND MV$ = "E" THEN NE = 3
2060 IF RM = 3 AND MV$ = "W" THEN NE = 1
2070 IF RM = 3 AND MV$ = "N" THEN NE = 2
2080 IF NE = 0 THEN PRINT "CAN'T GO THERE!": RETURN
2090 RM = NE: SC = SC + TR: REM MOVE AND COLLECT
2100 RETURN
```
</TryItNow>

This system separates room data from movement logic, making it much easier to expand!

## Adding Room Features

Let's enhance our numbered rooms with special features and interactive elements:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ENHANCED ROOMS
20 RM = 1: SC = 0: HP = 100
30 DIM VI(10): REM VISITED ROOMS TRACKER
40 PRINT CHR$(147)
50 REM ROOM DISPLAY
60 GOSUB 1000: REM GET ROOM INFO
70 PRINT "ROOM"; RM; ": "; R$
80 PRINT D$
90 PRINT
100 REM CHECK FOR SPECIAL EVENTS
110 IF VI(RM) = 0 THEN GOSUB 3000: REM FIRST VISIT
120 VI(RM) = 1: REM MARK AS VISITED
130 PRINT "HP:"; HP; " SCORE:"; SC
140 PRINT
150 INPUT "COMMAND"; C$
160 REM HANDLE MOVEMENT AND ACTIONS
170 GOSUB 2000
180 GOTO 40
990 REM
1000 REM ROOM DESCRIPTIONS
1010 IF RM = 1 THEN R$ = "ENTRANCE"
1020 IF RM = 1 THEN D$ = "CAVE MOUTH (N/E TO EXPLORE)"
1030 IF RM = 2 THEN R$ = "MUSHROOM GROVE"
1040 IF RM = 2 THEN D$ = "GLOWING MUSHROOMS (S/E/W)"
1050 IF RM = 3 THEN R$ = "TREASURE VAULT"
1060 IF RM = 3 THEN D$ = "ANCIENT CHESTS LINE WALLS (W/S)"
1070 IF RM = 4 THEN R$ = "CRYSTAL POOL"
1080 IF RM = 4 THEN D$ = "HEALING WATERS BUBBLE (E/N)"
1090 RETURN
1990 REM
2000 REM MOVEMENT HANDLER
2010 NE = 0
2020 IF RM = 1 AND C$ = "N" THEN NE = 2
2030 IF RM = 1 AND C$ = "E" THEN NE = 3
2040 IF RM = 2 AND C$ = "S" THEN NE = 1
2050 IF RM = 2 AND C$ = "E" THEN NE = 4
2060 IF RM = 2 AND C$ = "W" THEN NE = 3
2070 IF RM = 3 AND C$ = "W" THEN NE = 1
2080 IF RM = 3 AND C$ = "S" THEN NE = 4
2090 IF RM = 4 AND C$ = "E" THEN NE = 2
2100 IF RM = 4 AND C$ = "N" THEN NE = 3
2110 IF NE > 0 THEN RM = NE: RETURN
2120 PRINT "CAN'T DO THAT!"
2130 RETURN
2990 REM
3000 REM FIRST VISIT EVENTS
3010 IF RM = 2 THEN PRINT "MUSHROOMS RESTORE 10 HP!"
3020 IF RM = 2 THEN HP = HP + 10
3030 IF RM = 3 THEN PRINT "YOU FIND 150 GOLD!"
3040 IF RM = 3 THEN SC = SC + 150
3050 IF RM = 4 THEN PRINT "CRYSTAL WATERS HEAL YOU!"
3060 IF RM = 4 THEN HP = HP + 25
3070 RETURN
```
</TryItNow>

Now each room has unique first-visit events, and we track which rooms have been explored!

## Building Room Networks

Create a larger cave system with logical room numbering:

<TryItNow>
```basic
10 REM MYSTERY CAVE - LARGE NETWORK
20 RM = 1: SC = 0: HP = 100
30 PRINT CHR$(147)
40 PRINT "ROOM MAP:"
50 PRINT "1=ENTRANCE 2=HALL 3=LIBRARY"
60 PRINT "4=KITCHEN 5=BEDROOM 6=TREASURY"
70 PRINT "7=BASEMENT 8=TOWER 9=GARDEN"
80 PRINT
90 PRINT "CURRENT ROOM:"; RM
100 INPUT "GO TO ROOM NUMBER (1-9)"; NE
110 IF NE < 1 OR NE > 9 THEN PRINT "NO SUCH ROOM!": GOTO 100
120 RM = NE
130 REM ROOM EVENTS
140 IF RM = 1 THEN PRINT "ENTRANCE: FRESH AIR"
150 IF RM = 2 THEN PRINT "HALL: ECHOING FOOTSTEPS"
160 IF RM = 3 THEN PRINT "LIBRARY: ANCIENT BOOKS"
170 IF RM = 4 THEN PRINT "KITCHEN: ABANDONED FEAST"
180 IF RM = 5 THEN PRINT "BEDROOM: DUSTY MATTRESS"
190 IF RM = 6 THEN PRINT "TREASURY: GOLDEN COINS!"
200 IF RM = 7 THEN PRINT "BASEMENT: DARK AND DAMP"
210 IF RM = 8 THEN PRINT "TOWER: VIEW OF LANDSCAPE"
220 IF RM = 9 THEN PRINT "GARDEN: BLOOMING FLOWERS"
230 IF RM = 6 THEN SC = SC + 100: PRINT "+100 POINTS!"
240 PRINT
250 GOTO 90
```
</TryItNow>

This gives you a complete 9-room adventure with easy navigation!
