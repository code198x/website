# Ask the Player

**Give your players real choices! Move beyond yes/no questions to create rich, interactive adventure experiences**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={7} />

## Beyond Simple Questions

So far we've been asking players simple yes/no questions. But real adventure games offer multiple choices that affect the story. Let's expand our input system to handle more sophisticated player decisions.

<TryItNow>
```basic
10 REM MYSTERY CAVE - MULTIPLE CHOICES
20 PRINT CHR$(147)
30 PRINT "YOU FIND A FORK IN THE TUNNEL."
40 PRINT
50 PRINT "WHICH PATH DO YOU CHOOSE?"
60 PRINT "1) LEFT TUNNEL (SOUNDS OF WATER)"
70 PRINT "2) RIGHT TUNNEL (WARM AIR)"
80 PRINT "3) GO BACK"
90 PRINT
100 INPUT "ENTER YOUR CHOICE (1, 2, OR 3)"; C$
110 PRINT "YOU CHOSE: "; C$
```
</TryItNow>

Now players have real choices that can lead to different adventures!

## Processing Multiple Choices

Let's make those choices actually do something:

<TryItNow>
```basic
10 REM MYSTERY CAVE - CHOICE PROCESSING
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "       MYSTERY CAVE"
50 PRINT "==============================="
60 PRINT
70 PRINT "YOU DISCOVER A SPLIT IN THE PATH."
80 PRINT
90 PRINT "CHOOSE YOUR DIRECTION:"
100 PRINT "1) LEFT - FOLLOW THE SOUND OF WATER"
110 PRINT "2) RIGHT - FOLLOW THE WARM BREEZE"
120 PRINT "3) STRAIGHT - CONTINUE FORWARD"
130 PRINT "4) BACK - RETURN TO ENTRANCE"
140 PRINT
150 INPUT "WHAT IS YOUR CHOICE"; C$
160 PRINT
170 IF C$ = "1" THEN PRINT "YOU FOLLOW THE WATER SOUNDS..."
180 IF C$ = "2" THEN PRINT "YOU FEEL THE WARM AIR ON YOUR FACE..."
190 IF C$ = "3" THEN PRINT "YOU PRESS FORWARD INTO THE DARKNESS..."
200 IF C$ = "4" THEN PRINT "YOU RETREAT TO SAFETY..."
210 IF C$ <> "1" AND C$ <> "2" AND C$ <> "3" AND C$ <> "4" THEN PRINT "THAT'S NOT A VALID CHOICE!"
```
</TryItNow>

Look how we can respond differently to each choice the player makes!

## Creating Adventure Menus

Let's build a proper adventure menu system:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ADVENTURE MENU
20 N$ = "HERO"
30 RM = 1: HP = 100: SC = 0
40 REM MAIN ADVENTURE LOOP
50 PRINT CHR$(147)
60 PRINT "==============================="
70 PRINT "  "; N$; "'S CAVE ADVENTURE"
80 PRINT "==============================="
90 PRINT
100 PRINT "ROOM: "; RM; "  HEALTH: "; HP; "  SCORE: "; SC
110 PRINT
120 PRINT "YOU ARE IN THE MYSTERIOUS CAVE."
130 PRINT "WHAT DO YOU WANT TO DO?"
140 PRINT
150 PRINT "1) EXPLORE DEEPER"
160 PRINT "2) SEARCH FOR TREASURE"
170 PRINT "3) REST AND HEAL"
180 PRINT "4) CHECK INVENTORY"
190 PRINT "5) QUIT ADVENTURE"
200 PRINT
210 INPUT "ENTER YOUR CHOICE"; C$
220 PRINT
230 IF C$ = "1" THEN PRINT "YOU VENTURE DEEPER INTO THE CAVE..."
240 IF C$ = "2" THEN PRINT "YOU SEARCH CAREFULLY FOR HIDDEN TREASURE..."
250 IF C$ = "3" THEN PRINT "YOU REST AND REGAIN STRENGTH...": HP = HP + 10
260 IF C$ = "4" THEN PRINT "YOUR PACK CONTAINS: TORCH, ROPE, FOOD"
270 IF C$ = "5" THEN PRINT "THANKS FOR PLAYING!": END
```
</TryItNow>

Now we have the foundation of a real adventure game menu system!

## Handling Player Input Better

Let's make our input more flexible by accepting different ways players might answer:

<TryItNow>
```basic
10 REM MYSTERY CAVE - FLEXIBLE INPUT
20 PRINT "DO YOU WANT TO ENTER THE CAVE?"
30 PRINT "(YES/NO, Y/N, OR 1/2)"
40 INPUT A$
50 REM CONVERT TO UPPERCASE FOR EASIER CHECKING
60 IF A$ = "YES" OR A$ = "Y" OR A$ = "1" THEN GOTO 100
70 IF A$ = "NO" OR A$ = "N" OR A$ = "2" THEN GOTO 200
80 PRINT "I DON'T UNDERSTAND. PLEASE TRY AGAIN."
90 GOTO 20
100 PRINT "YOU BRAVELY ENTER THE CAVE!"
110 END
200 PRINT "YOU DECIDE TO STAY OUTSIDE."
210 END
```
</TryItNow>

Now players can answer in different ways, making the game more user-friendly!

## Adventure Conversation System

Let's create a system for talking to characters in our cave:

<TryItNow>
```basic
10 REM MYSTERY CAVE - CHARACTER DIALOGUE
20 PRINT CHR$(147)
30 PRINT "YOU ENCOUNTER A WISE OLD HERMIT!"
40 PRINT
50 PRINT CHR$(34); "GREETINGS, YOUNG ADVENTURER!"; CHR$(34)
60 PRINT "THE HERMIT SAYS."
70 PRINT
80 PRINT "WHAT DO YOU SAY TO HIM?"
90 PRINT "1) ASK ABOUT THE CAVE"
100 PRINT "2) ASK FOR DIRECTIONS"
110 PRINT "3) ASK ABOUT TREASURE"
120 PRINT "4) SAY GOODBYE"
130 PRINT
140 INPUT "YOUR RESPONSE"; R$
150 PRINT
160 IF R$ = "1" THEN PRINT CHR$(34); "BEWARE THE DEEP CHAMBERS!"; CHR$(34)
170 IF R$ = "2" THEN PRINT CHR$(34); "FOLLOW THE GLOWING STONES..."; CHR$(34)
180 IF R$ = "3" THEN PRINT CHR$(34); "TREASURE COMES TO THE WORTHY!"; CHR$(34)
190 IF R$ = "4" THEN PRINT CHR$(34); "FAREWELL, BRAVE ONE!"; CHR$(34)
200 PRINT "THE HERMIT SAYS, THEN DISAPPEARS!"
```
</TryItNow>

Notice how we use `CHR$(34)` to print quotation marks around the character's speech!
