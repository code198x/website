# Room Variables

**Give your game a memory! Learn to track where your player is using variables - the secret ingredient that makes games interactive**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={3} />

## What Are Variables?

Think of variables as labeled boxes where the computer can store information. In our cave adventure, we need to remember things like:
- Which room is the player in?
- How many treasures have they found?
- How much health do they have?

Variables let us store this information and use it to make decisions in our game.

## Your First Variable

Let's create a variable to track which room the player is in:

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 RM = 1
30 PRINT "CURRENT ROOM: "; RM
40 PRINT
50 PRINT "YOU ARE IN ROOM "; RM
```
</TryItNow>

Amazing! The variable `RM` (short for "room") now stores the number 1. When we print it, the computer shows us the value stored inside.

## Variable Rules in C64 BASIC

C64 BASIC has specific rules for naming variables:

**Numeric Variables:**
- Can be 1 or 2 characters long: `A`, `X1`, `RM`, `HP`
- First character must be a letter
- Second character (if used) can be a letter or number
- No spaces or special characters

**Examples of Valid Variable Names:**
- `A` - Simple single-letter variable
- `RM` - Room number
- `HP` - Hit points
- `X1` - X coordinate
- `T5` - Treasure count

<InfoBox>
**C64 BASIC Quirk:** Variable names like `ROOM` and `HEALTH` get shortened to `RO` and `HE` automatically. It's clearer to use short names from the start!
</InfoBox>

## Building Our Cave Tracker

Now let's use variables to create a more interactive cave system:

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 REM INITIALIZE VARIABLES
30 RM = 1: TR = 0: SC = 0
40 REM RM=ROOM, TR=TREASURES, SC=SCORE
50 PRINT CHR$(147)
60 PRINT "==============================="
70 PRINT "       MYSTERY CAVE"
80 PRINT "==============================="
90 PRINT
100 PRINT "CURRENT LOCATION: ROOM "; RM
110 PRINT "TREASURES FOUND: "; TR
120 PRINT "CURRENT SCORE: "; SC
130 PRINT
140 PRINT "YOU ARE AT THE CAVE ENTRANCE."
150 PRINT "THE DARKNESS BECKONS..."
```
</TryItNow>

Look at what we've added:
- **Line 30:** Multiple variables on one line using colons
- **Line 50:** `CHR$(147)` clears the screen (we'll explore this more later)
- **Variables track:** Room number, treasures found, and score

## Changing Variables

Variables aren't just for storing - we can change them too:

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 RM = 1: TR = 0: SC = 0
30 PRINT "STARTING VALUES:"
40 PRINT "ROOM: "; RM; " TREASURES: "; TR; " SCORE: "; SC
50 PRINT
60 REM SIMULATE FINDING A TREASURE
70 TR = TR + 1
80 SC = SC + 50
90 RM = RM + 1
100 PRINT "AFTER FINDING A TREASURE:"
110 PRINT "ROOM: "; RM; " TREASURES: "; TR; " SCORE: "; SC
```
</TryItNow>

Notice line 70: `TR = TR + 1`. This means "take the current value of TR, add 1, then store the result back in TR." It's like updating a scoreboard!

## Common Variable Operations

```basic
X = 5          : REM SET X TO 5
X = X + 1      : REM ADD 1 TO X (NOW X IS 6)
X = X - 2      : REM SUBTRACT 2 FROM X (NOW X IS 4)
X = X * 2      : REM MULTIPLY X BY 2 (NOW X IS 8)
Y = X + 10     : REM SET Y TO X PLUS 10 (Y IS 18)
```
