# Formatted Display

**Make your adventure look professional! Master the TAB() function to create perfectly aligned text layouts and polished game interfaces.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={13} />

## Understanding TAB() Function

The TAB() function moves the cursor to a specific column position, letting you create perfectly aligned text layouts. This is essential for professional-looking game interfaces!

<TryItNow>
```basic
10 REM MYSTERY CAVE - BASIC TAB DEMO
20 PRINT CHR$(147)
30 PRINT "SIMPLE ALIGNMENT:"
40 PRINT
50 PRINT "NAME"; TAB(15); "LEVEL"; TAB(25); "HEALTH"
60 PRINT "----"; TAB(15); "-----"; TAB(25); "------"
70 PRINT "WIZARD"; TAB(15); "5"; TAB(25); "100"
80 PRINT "THIEF"; TAB(15); "3"; TAB(25); "75"
90 PRINT "KNIGHT"; TAB(15); "7"; TAB(25); "150"
```
</TryItNow>

TAB(15) moves the cursor to column 15, creating perfect alignment regardless of the previous text length!

## Creating Status Displays

Let's use TAB() to create a professional game status screen:

<InfoBox type="tip">
**C64 Screen Tip**: The C64 screen is 40 characters wide. Use TAB() positions that work well within this limit: 10, 15, 20, 25, 30, 35 are good choices.
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - STATUS DISPLAY
20 HP = 85: MP = 42: SC = 1350: LV = 4
30 GO = 247: SV = 18: FD = 6
40 PRINT CHR$(147)
50 REM TOP BORDER
60 PRINT "========================================"
70 PRINT "        MYSTERY CAVE ADVENTURE"
80 PRINT "========================================"
90 PRINT
100 REM CHARACTER STATS
110 PRINT "CHARACTER STATUS:"
120 PRINT
130 PRINT "HEALTH"; TAB(15); HP; "/100"; TAB(25); "MAGIC"; TAB(35); MP
140 PRINT "LEVEL"; TAB(15); LV; TAB(25); "SCORE"; TAB(35); SC
150 PRINT
160 REM INVENTORY DISPLAY
170 PRINT "INVENTORY:"
180 PRINT
190 PRINT "GOLD"; TAB(15); GO; TAB(25); "SILVER"; TAB(35); SV
200 PRINT "FOOD"; TAB(15); FD; " DAYS"; TAB(25); "GEMS"; TAB(35); "3"
210 PRINT
220 REM BOTTOM BORDER
230 PRINT "========================================"
240 PRINT "READY FOR ADVENTURE!"
```
</TryItNow>

Now your game looks like a commercial adventure!

<TryItNow>
```basic

80 PRINT TAB(17); "│"
90 PRINT "╔═══╗"; TAB(8); "╔═╧═╗"; TAB(23); "╔═══╗"
```

Perfect for helping players navigate your adventure world!

## Combat Interface

Create an exciting combat display with aligned statistics:

<TryItNow>
```basic
10 REM MYSTERY CAVE - COMBAT DISPLAY
20 PH = 78: PA = 25: PD = 12
30 EH = 45: EA = 18: ED = 8
40 PRINT CHR$(147)
50 REM COMBAT HEADER
60 PRINT "┌────────────────────────────────────┐"
70 PRINT "│"; TAB(15); "** COMBAT **"; TAB(37); "│"
80 PRINT "└────────────────────────────────────┘"
90 PRINT
100 REM FIGHTER STATS
110 PRINT "PLAYER"; TAB(25); "VS"; TAB(35); "GOBLIN"
120 PRINT "──────"; TAB(25); "──"; TAB(35); "──────"
130 PRINT "HEALTH"; TAB(10); PH; "/100"; TAB(25); "||"; TAB(30); EH; "/50"
140 PRINT "ATTACK"; TAB(10); PA; TAB(25); "||"; TAB(30); EA
150 PRINT "DEFENSE"; TAB(10); PD; TAB(25); "||"; TAB(30); ED
160 PRINT
170 REM ACTION MENU
180 PRINT "CHOOSE ACTION:"
190 PRINT "[A]TTACK"; TAB(15); "[D]EFEND"; TAB(30); "[R]UN"
200 PRINT
210 PRINT "ENTER COMMAND: ";
```
</TryItNow>

This creates a professional combat interface that's easy to read and understand!

## Advanced Formatting Techniques

Let's combine TAB() with variables for dynamic layouts:

<TryItNow>
```basic
10 REM MYSTERY CAVE - DYNAMIC FORMATTING
20 PRINT CHR$(147)
30 PRINT "TREASURE REPORT:"
40 PRINT "================"
50 PRINT
60 REM DYNAMIC COLUMN POSITIONS
70 C1 = 5: C2 = 20: C3 = 30
80 REM TREASURE DATA
90 FOR I = 1 TO 5
100   READ T$, V, W
110   PRINT TAB(C1); T$; TAB(C2); V; " GP"; TAB(C3); W; " LBS"
120 NEXT I
130 PRINT
140 PRINT TAB(C1); "TOTAL VALUE:"; TAB(C2); "1,250 GP"
150 PRINT TAB(C1); "TOTAL WEIGHT:"; TAB(C2); "47 LBS"
160 REM TREASURE DATA
170 DATA "GOLD COINS",500,10
180 DATA "SILVER CUP",200,5
190 DATA "RUBY RING",300,1
200 DATA "MAGIC SWORD",250,20
210 DATA "SPELL BOOK",100,11
```
</TryItNow>

Using variables for TAB positions makes it easy to adjust your entire layout!
