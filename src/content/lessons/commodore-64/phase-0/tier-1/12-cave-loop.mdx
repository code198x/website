# Cave Loop

**Bring your adventure to life! Learn FOR-NEXT loops to create repeating actions, combat sequences, and games that keep running.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={12} />

## Understanding FOR-NEXT Loops

FOR-NEXT loops let you repeat actions a specific number of times. Perfect for creating dramatic effects, combat sequences, and game mechanics that need repetition!

<TryItNow>
```basic
10 REM MYSTERY CAVE - DRAMATIC ENTRANCE
20 PRINT CHR$(147)
30 PRINT "YOU APPROACH THE MYSTERIOUS CAVE..."
40 PRINT
50 REM CREATE SUSPENSE WITH DOTS
60 FOR I = 1 TO 10
70   PRINT ".";
80   FOR J = 1 TO 500: NEXT J: REM DELAY
90 NEXT I
100 PRINT
110 PRINT
120 PRINT "THE ENTRANCE OPENS BEFORE YOU!"
```
</TryItNow>

The inner delay loop creates a pause between each dot, building suspense!

## Combat Sequences

FOR-NEXT loops are perfect for creating exciting combat mechanics:

<InfoBox type="tip">
**C64 BASIC Tip**: The FOR loop variable (like I or J) automatically increments each time through the loop. You can use this counter for calculations and effects!
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - DRAGON BATTLE
20 HP = 100: DH = 50: REM PLAYER & DRAGON HP
30 PRINT CHR$(147)
40 PRINT "A DRAGON BLOCKS YOUR PATH!"
50 PRINT "PREPARE FOR BATTLE!"
60 PRINT
70 REM BATTLE LOOP
80 FOR RO = 1 TO 10: REM UP TO 10 ROUNDS
90   PRINT "ROUND"; RO
100   PRINT "YOUR HP:"; HP; " DRAGON HP:"; DH
110   PRINT
120   REM PLAYER ATTACKS
130   AT = 10 + INT(RND(1) * 10): REM 10-19 DAMAGE
140   DH = DH - AT
150   PRINT "YOU HIT FOR"; AT; "DAMAGE!"
160   IF DH <= 0 THEN PRINT "DRAGON DEFEATED!": GOTO 250
170   REM DRAGON ATTACKS
180   DA = 8 + INT(RND(1) * 8): REM 8-15 DAMAGE
190   HP = HP - DA
200   PRINT "DRAGON HITS FOR"; DA; "DAMAGE!"
210   IF HP <= 0 THEN PRINT "YOU ARE DEFEATED!": END
220   PRINT "---"
230 NEXT RO
240 PRINT "BATTLE ENDS IN A DRAW!"
250 PRINT "VICTORY! THE PATH IS CLEAR!"
```
</TryItNow>

The loop creates an exciting back-and-forth battle with random damage!

## Continuous Game Loops

The most important loop in any adventure game is the main game loop that keeps everything running:

<TryItNow>
```basic
10 REM MYSTERY CAVE - GAME LOOP
20 RM = 1: HP = 100: SC = 0: TU = 0
30 PRINT CHR$(147)
40 PRINT "=============================="
50 PRINT "    MYSTERY CAVE ADVENTURE"
60 PRINT "=============================="
70 PRINT
80 REM MAIN GAME LOOP
90 FOR TU = TU + 1 TO 999: REM TURN COUNTER
100   PRINT "TURN"; TU
110   GOSUB 1000: REM DISPLAY ROOM
120   GOSUB 2000: REM GET PLAYER INPUT
130   GOSUB 3000: REM PROCESS ACTION
140   GOSUB 4000: REM CHECK WIN/LOSE
150   IF GA = 1 THEN GOTO 200: REM GAME OVER
160 NEXT TU
170 PRINT "ADVENTURE TIMES OUT AFTER 999 TURNS!"
180 END
190 REM
200 PRINT "GAME COMPLETED IN"; TU; "TURNS!"
210 PRINT "FINAL SCORE:"; SC
220 END
990 REM
1000 REM DISPLAY ROOM
1010 IF RM = 1 THEN PRINT "CAVE ENTRANCE"
1020 IF RM = 2 THEN PRINT "CRYSTAL CHAMBER"
1030 IF RM = 3 THEN PRINT "TREASURE VAULT"
1040 PRINT "HP:"; HP; " SCORE:"; SC
1050 RETURN
1990 REM
2000 REM GET INPUT
2010 INPUT "COMMAND"; C$
2020 RETURN
2990 REM
3000 REM PROCESS ACTION
3010 IF C$ = "N" AND RM = 1 THEN RM = 2
3020 IF C$ = "S" AND RM = 2 THEN RM = 1
3030 IF C$ = "E" AND RM = 2 THEN RM = 3
3040 IF C$ = "QUIT" THEN GA = 1
3050 RETURN
3990 REM
4000 REM CHECK CONDITIONS
4010 IF HP <= 0 THEN PRINT "YOU DIED!": GA = 1
4020 IF SC >= 500 THEN PRINT "YOU WIN!": GA = 1
4030 RETURN
```
</TryItNow>

This creates a complete game framework that runs until the player wins, dies, or quits!

## Advanced Loop Techniques

Let's use loops for special effects and game mechanics:

<TryItNow>
```basic
10 REM MYSTERY CAVE - SPECIAL EFFECTS
20 PRINT CHR$(147)
30 REM TORCH FLICKERING EFFECT
40 PRINT "YOUR TORCH FLICKERS..."
50 FOR F = 1 TO 5
60   FOR I = 1 TO 100: NEXT I: REM DELAY
70   PRINT "  THE FLAME GROWS BRIGHT"
80   FOR I = 1 TO 100: NEXT I: REM DELAY
90   PRINT "  THE FLAME DIMS"
100 NEXT F
110 PRINT "THE TORCH STEADIES"
120 PRINT
130 REM TREASURE COUNTING
140 PRINT "YOU FIND A PILE OF COINS!"
150 CO = 0
160 FOR I = 1 TO 25
170   CO = CO + (1 + INT(RND(1) * 5))
180   PRINT "COUNTING..."; CO; "GOLD"
190   FOR J = 1 TO 200: NEXT J: REM DELAY
200 NEXT I
210 PRINT "TOTAL:"; CO; "GOLD PIECES!"
```
</TryItNow>

Loops make your adventure feel dynamic and alive!

## Nested Loops for Complex Actions

Sometimes you need loops inside loops for sophisticated effects:

<TryItNow>
```basic
10 REM MYSTERY CAVE - CAVE EXPLORATION
20 PRINT CHR$(147)
30 PRINT "YOU SEARCH THE CAVE SYSTEMATICALLY"
40 PRINT
50 REM SEARCH EACH WALL
60 FOR WA = 1 TO 4: REM 4 WALLS
70   IF WA = 1 THEN PRINT "NORTH WALL:"
80   IF WA = 2 THEN PRINT "EAST WALL:"
90   IF WA = 3 THEN PRINT "SOUTH WALL:"
100   IF WA = 4 THEN PRINT "WEST WALL:"
110   REM SEARCH EACH SECTION OF WALL
120   FOR SE = 1 TO 3: REM 3 SECTIONS
130     PRINT "  SECTION"; SE; ": ";
140     IF INT(RND(1) * 6) = 1 THEN PRINT "SECRET PASSAGE!"
150     IF INT(RND(1) * 8) = 1 THEN PRINT "HIDDEN TREASURE!"
160     IF INT(RND(1) * 10) = 1 THEN PRINT "ANCIENT WRITING!"
170     PRINT "SEARCHING..."
180     FOR D = 1 TO 300: NEXT D: REM DELAY
190   NEXT SE
200 NEXT WA
210 PRINT "SEARCH COMPLETE!"
```
</TryItNow>

Now you have systematic cave exploration with realistic searching mechanics!
