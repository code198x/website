## Understanding DIM Arrays

DIM creates arrays - lists of variables that can store multiple values. Perfect for inventory systems where you need to track many different items!

<TryItNow>
```basic
10 REM MYSTERY CAVE - ARRAY BASICS
20 PRINT CHR$(147)
30 PRINT "BASIC ARRAY DEMONSTRATION"
40 PRINT "========================="
50 PRINT
60 REM CREATE ARRAYS FOR INVENTORY
70 DIM IT$(10): REM ITEM NAMES (10 SLOTS)
80 DIM QU(10): REM QUANTITIES
90 DIM VA(10): REM VALUES
100 REM FILL SOME INVENTORY SLOTS
110 IT$(1) = "GOLD COINS": QU(1) = 47: VA(1) = 1
120 IT$(2) = "MAGIC SWORD": QU(2) = 1: VA(2) = 200
130 IT$(3) = "HEALING POTION": QU(3) = 3: VA(3) = 50
140 IT$(4) = "SILVER KEY": QU(4) = 1: VA(4) = 25
150 REM DISPLAY INVENTORY
160 PRINT "YOUR INVENTORY:"
170 PRINT "==============="
180 FOR I = 1 TO 4
190   PRINT I; ": "; IT$(I)
200   PRINT "   QTY: "; QU(I); " VALUE: "; VA(I)
210   PRINT
220 NEXT I
```
</TryItNow>

Arrays let you organize related data together - item names, quantities, and values all linked by index numbers!

## Building an Inventory System

Let's create a complete inventory management system:

<InfoBox type="tip">
**Array Tip**: In C64 BASIC, arrays start at index 0, but it's often clearer to start using them at index 1. Reserve slot 0 for special purposes or leave it empty.
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - INVENTORY SYSTEM
20 DIM IT$(20), QU(20), VA(20): REM 20 INVENTORY SLOTS
30 SL = 0: REM SLOTS USED
40 PRINT CHR$(147)
50 REM STARTING INVENTORY
60 GOSUB 2000: REM ADD STARTING ITEMS
70 REM MAIN MENU LOOP
80 PRINT CHR$(147)
90 GOSUB 1000: REM DISPLAY INVENTORY
100 PRINT
110 PRINT "[A]DD ITEM  [U]SE ITEM  [Q]UIT"
120 INPUT "COMMAND"; C$
130 IF C$ = "A" THEN GOSUB 3000: GOTO 80
140 IF C$ = "U" THEN GOSUB 4000: GOTO 80
150 IF C$ = "Q" THEN END
160 PRINT "INVALID COMMAND!": GOTO 120
170 END
990 REM
1000 REM DISPLAY INVENTORY
1010 PRINT "=============================="
1020 PRINT "        YOUR INVENTORY"
1030 PRINT "=============================="
1040 IF SL = 0 THEN PRINT "INVENTORY IS EMPTY!": RETURN
1050 TO = 0
1060 FOR I = 1 TO SL
1070   PRINT I; ": "; IT$(I); " ("; QU(I); ")"
1080   TO = TO + (QU(I) * VA(I))
1090 NEXT I
1100 PRINT "------------------------------"
1110 PRINT "TOTAL VALUE: "; TO; " GOLD"
1120 PRINT "SLOTS USED: "; SL; "/20"
1130 RETURN
1990 REM
2000 REM ADD STARTING ITEMS
2010 SL = SL + 1: IT$(SL) = "TORCH": QU(SL) = 1: VA(SL) = 5
2020 SL = SL + 1: IT$(SL) = "BREAD": QU(SL) = 2: VA(SL) = 3
2030 SL = SL + 1: IT$(SL) = "ROPE": QU(SL) = 1: VA(SL) = 10
2040 RETURN
2990 REM
3000 REM ADD NEW ITEM
3010 IF SL >= 20 THEN PRINT "INVENTORY FULL!": RETURN
3020 INPUT "ITEM NAME"; N$
3030 INPUT "QUANTITY"; Q
3040 INPUT "VALUE EACH"; V
3050 SL = SL + 1
3060 IT$(SL) = N$: QU(SL) = Q: VA(SL) = V
3070 PRINT "ADDED "; N$; " TO INVENTORY!"
3080 RETURN
3990 REM
4000 REM USE ITEM
4010 IF SL = 0 THEN PRINT "NO ITEMS TO USE!": RETURN
4020 INPUT "USE ITEM NUMBER"; IT
4030 IF IT < 1 OR IT > SL THEN PRINT "INVALID ITEM!": RETURN
4040 QU(IT) = QU(IT) - 1
4050 PRINT "USED ONE "; IT$(IT)
4060 REM REMOVE ITEM IF QUANTITY REACHES 0
4070 IF QU(IT) <= 0 THEN GOSUB 5000
4080 RETURN
4990 REM
5000 REM REMOVE EMPTY ITEM SLOT
5010 PRINT IT$(IT); " REMOVED FROM INVENTORY"
5020 FOR J = IT TO SL - 1
5030   IT$(J) = IT$(J + 1)
5040   QU(J) = QU(J + 1)
5050   VA(J) = VA(J + 1)
5060 NEXT J
5070 SL = SL - 1
5080 RETURN
```
</TryItNow>

This creates a complete inventory system with adding, using, and automatic cleanup!

## Treasure Collection System

Let's integrate inventory management with treasure discovery:

<TryItNow>
```basic
10 REM MYSTERY CAVE - TREASURE COLLECTION
20 DIM IT$(15), QU(15), VA(15)
30 SL = 3: SC = 0: RO = 1
40 REM STARTING ITEMS
50 IT$(1) = "BACKPACK": QU(1) = 1: VA(1) = 20
60 IT$(2) = "TORCH": QU(2) = 1: VA(2) = 5
70 IT$(3) = "RATIONS": QU(3) = 5: VA(3) = 2
80 PRINT CHR$(147)
90 PRINT "==============================="
100 PRINT "    MYSTERY CAVE EXPLORER"
110 PRINT "==============================="
120 PRINT
130 PRINT "ROOM"; RO; " - SEARCHING FOR TREASURE..."
140 REM RANDOM TREASURE DISCOVERY
150 TR = INT(RND(1) * 100) + 1
160 IF TR <= 40 THEN PRINT "NOTHING FOUND": GOTO 220
170 IF TR <= 70 THEN GOSUB 1000: REM COMMON
180 IF TR <= 90 THEN GOSUB 2000: REM UNCOMMON
190 IF TR <= 100 THEN GOSUB 3000: REM RARE
200 PRINT
210 GOSUB 4000: REM SHOW INVENTORY
220 PRINT
230 INPUT "CONTINUE TO NEXT ROOM (Y/N)"; A$
240 IF A$ = "Y" THEN RO = RO + 1: GOTO 80
250 PRINT "ADVENTURE ENDED!"
260 GOSUB 4000: REM FINAL INVENTORY
270 END
990 REM
1000 REM COMMON TREASURE
1010 TR$ = "COPPER COINS": QU = INT(RND(1) * 10) + 5: VA = 1
1020 GOSUB 5000: RETURN
1990 REM
2000 REM UNCOMMON TREASURE
2010 RA = INT(RND(1) * 3) + 1
2020 IF RA = 1 THEN TR$ = "SILVER RING": QU = 1: VA = 35
2030 IF RA = 2 THEN TR$ = "GEMS": QU = INT(RND(1) * 3) + 1: VA = 25
2040 IF RA = 3 THEN TR$ = "MAGIC SCROLL": QU = 1: VA = 50
2050 GOSUB 5000: RETURN
2990 REM
3000 REM RARE TREASURE
3010 RA = INT(RND(1) * 2) + 1
3020 IF RA = 1 THEN TR$ = "GOLDEN CHALICE": QU = 1: VA = 150
3030 IF RA = 2 THEN TR$ = "ANCIENT ARTIFACT": QU = 1: VA = 200
3040 GOSUB 5000: RETURN
3990 REM
4000 REM DISPLAY INVENTORY
4010 PRINT "CURRENT INVENTORY:"
4020 PRINT "------------------"
4030 TO = 0
4040 FOR I = 1 TO SL
4050   PRINT IT$(I); " ("; QU(I); ")"
4060   TO = TO + (QU(I) * VA(I))
4070 NEXT I
4080 PRINT "TOTAL VALUE: "; TO; " GOLD"
4090 RETURN
4990 REM
5000 REM ADD ITEM TO INVENTORY
5010 IF SL >= 15 THEN PRINT "INVENTORY FULL!": RETURN
5020 PRINT "FOUND: "; TR$; " ("; QU; ")"
5030 SC = SC + (QU * VA)
5040 REM CHECK IF ITEM ALREADY EXISTS
5050 FOR I = 1 TO SL
5060   IF IT$(I) = TR$ THEN QU(I) = QU(I) + QU: RETURN
5070 NEXT I
5080 REM ADD NEW ITEM
5090 SL = SL + 1: IT$(SL) = TR$: QU(SL) = QU: VA(SL) = VA
5100 RETURN
```
</TryItNow>

This system automatically collects treasures and stacks identical items!

## Equipment Management

Create a system for tracking equipped items vs. inventory:

<TryItNow>
```basic
10 REM MYSTERY CAVE - EQUIPMENT SYSTEM
20 DIM IT$(10), QU(10), VA(10): REM INVENTORY
30 DIM EQ$(5): REM EQUIPPED ITEMS
40 SL = 0: REM INVENTORY SLOTS USED
50 REM EQUIPMENT SLOTS: 1=WEAPON 2=ARMOR 3=SHIELD 4=RING 5=HELMET
60 EQ$(1) = "RUSTY SWORD"
70 EQ$(2) = "LEATHER ARMOR"
80 EQ$(3) = "NONE"
90 EQ$(4) = "NONE"
100 EQ$(5) = "NONE"
110 REM ADD SOME INVENTORY ITEMS
120 SL = SL + 1: IT$(SL) = "MAGIC SWORD": QU(SL) = 1: VA(SL) = 200
130 SL = SL + 1: IT$(SL) = "IRON SHIELD": QU(SL) = 1: VA(SL) = 75
140 SL = SL + 1: IT$(SL) = "HEALING POTION": QU(SL) = 3: VA(SL) = 50
150 PRINT CHR$(147)
160 REM DISPLAY CHARACTER STATUS
170 PRINT "=============================="
180 PRINT "     CHARACTER EQUIPMENT"
190 PRINT "=============================="
200 PRINT "WEAPON: "; EQ$(1)
210 PRINT "ARMOR:  "; EQ$(2)
220 PRINT "SHIELD: "; EQ$(3)
230 PRINT "RING:   "; EQ$(4)
240 PRINT "HELMET: "; EQ$(5)
250 PRINT
260 PRINT "INVENTORY:"
270 PRINT "----------"
280 FOR I = 1 TO SL
290   PRINT I; ": "; IT$(I); " ("; QU(I); ")"
300 NEXT I
310 PRINT
320 PRINT "[E]QUIP ITEM  [U]NEQUIP  [Q]UIT"
330 INPUT "COMMAND"; C$
340 IF C$ = "E" THEN GOSUB 1000: GOTO 150
350 IF C$ = "U" THEN GOSUB 2000: GOTO 150
360 IF C$ = "Q" THEN END
370 GOTO 320
380 END
990 REM
1000 REM EQUIP ITEM
1010 INPUT "EQUIP ITEM NUMBER"; IT
1020 IF IT < 1 OR IT > SL THEN PRINT "INVALID ITEM!": RETURN
1030 REM DETERMINE EQUIPMENT SLOT
1040 SL$ = IT$(IT)
1050 ES = 0: REM EQUIPMENT SLOT
1060 IF RIGHT$(SL$, 5) = "SWORD" THEN ES = 1
1070 IF RIGHT$(SL$, 5) = "ARMOR" THEN ES = 2
1080 IF RIGHT$(SL$, 6) = "SHIELD" THEN ES = 3
1090 IF RIGHT$(SL$, 4) = "RING" THEN ES = 4
1100 IF RIGHT$(SL$, 6) = "HELMET" THEN ES = 5
1110 IF ES = 0 THEN PRINT "CAN'T EQUIP THAT ITEM!": RETURN
1120 REM UNEQUIP CURRENT ITEM
1130 IF EQ$(ES) <> "NONE" THEN GOSUB 3000
1140 REM EQUIP NEW ITEM
1150 EQ$(ES) = IT$(IT)
1160 PRINT "EQUIPPED: "; IT$(IT)
1170 GOSUB 4000: REM REMOVE FROM INVENTORY
1180 RETURN
1990 REM
2000 REM UNEQUIP ITEM
2010 PRINT "UNEQUIP: 1=WEAPON 2=ARMOR 3=SHIELD 4=RING 5=HELMET"
2020 INPUT "SLOT"; ES
2030 IF ES < 1 OR ES > 5 THEN PRINT "INVALID SLOT!": RETURN
2040 IF EQ$(ES) = "NONE" THEN PRINT "NOTHING EQUIPPED!": RETURN
2050 GOSUB 3000: REM ADD TO INVENTORY
2060 EQ$(ES) = "NONE"
2070 RETURN
2990 REM
3000 REM ADD EQUIPPED ITEM TO INVENTORY
3010 IF SL >= 10 THEN PRINT "INVENTORY FULL!": RETURN
3020 SL = SL + 1: IT$(SL) = EQ$(ES): QU(SL) = 1: VA(SL) = 100
3030 PRINT "UNEQUIPPED: "; EQ$(ES)
3040 RETURN
3990 REM
4000 REM REMOVE ITEM FROM INVENTORY
4010 FOR J = IT TO SL - 1
4020   IT$(J) = IT$(J + 1): QU(J) = QU(J + 1): VA(J) = VA(J + 1)
4030 NEXT J
4040 SL = SL - 1
4050 RETURN
```
</TryItNow>

Now you have separate equipped items and inventory with realistic equipment management!

## Advanced Inventory Features

Add sorting and searching capabilities:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ADVANCED INVENTORY
20 DIM IT$(15), QU(15), VA(15), TY$(15)
30 SL = 0
40 REM ADD SAMPLE ITEMS WITH TYPES
50 GOSUB 2000: REM POPULATE INVENTORY
60 PRINT CHR$(147)
70 GOSUB 1000: REM SHOW INVENTORY
80 PRINT
90 PRINT "[S]ORT BY VALUE  [F]IND ITEM  [Q]UIT"
100 INPUT "COMMAND"; C$
110 IF C$ = "S" THEN GOSUB 3000: GOTO 60
120 IF C$ = "F" THEN GOSUB 4000: GOTO 60
130 IF C$ = "Q" THEN END
140 GOTO 90
150 END
990 REM
1000 REM DISPLAY INVENTORY
1010 PRINT "==============================="; TAB(35); "TYPE"; TAB(39); "VALUE"
1020 FOR I = 1 TO SL
1030   PRINT I; ": "; IT$(I); TAB(25); "("; QU(I); ")"; TAB(32); TY$(I); TAB(37); VA(I) * QU(I)
1040 NEXT I
1050 RETURN
1990 REM
2000 REM POPULATE WITH SAMPLE ITEMS
2010 SL = SL + 1: IT$(SL) = "GOLD COINS": QU(SL) = 25: VA(SL) = 1: TY$(SL) = "MONEY"
2020 SL = SL + 1: IT$(SL) = "MAGIC SWORD": QU(SL) = 1: VA(SL) = 300: TY$(SL) = "WEAPON"
2030 SL = SL + 1: IT$(SL) = "HEALING POTION": QU(SL) = 5: VA(SL) = 50: TY$(SL) = "POTION"
2040 SL = SL + 1: IT$(SL) = "ANCIENT BOOK": QU(SL) = 1: VA(SL) = 150: TY$(SL) = "MISC"
2050 SL = SL + 1: IT$(SL) = "SILVER ARMOR": QU(SL) = 1: VA(SL) = 200: TY$(SL) = "ARMOR"
2060 SL = SL + 1: IT$(SL) = "ROPE": QU(SL) = 1: VA(SL) = 10: TY$(SL) = "TOOL"
2070 RETURN
2990 REM
3000 REM SORT BY TOTAL VALUE (BUBBLE SORT)
3010 PRINT "SORTING BY VALUE..."
3020 FOR I = 1 TO SL - 1
3030   FOR J = I + 1 TO SL
3040     IF (VA(I) * QU(I)) < (VA(J) * QU(J)) THEN GOSUB 5000
3050   NEXT J
3060 NEXT I
3070 PRINT "SORTED!"
3080 RETURN
3990 REM
4000 REM FIND ITEM
4010 INPUT "SEARCH FOR ITEM"; SE$
4020 FO = 0
4030 FOR I = 1 TO SL
4040   IF LEFT$(IT$(I), LEN(SE$)) = SE$ THEN PRINT "FOUND: "; IT$(I); " IN SLOT "; I: FO = 1
4050 NEXT I
4060 IF FO = 0 THEN PRINT "ITEM NOT FOUND"
4070 RETURN
4990 REM
5000 REM SWAP ITEMS I AND J
5010 T$ = IT$(I): IT$(I) = IT$(J): IT$(J) = T$
5020 TQ = QU(I): QU(I) = QU(J): QU(J) = TQ
5030 TV = VA(I): VA(I) = VA(J): VA(J) = TV
5040 TT$ = TY$(I): TY$(I) = TY$(J): TY$(J) = TT$
5050 RETURN
```
</TryItNow>

Now you have sorting and search functionality for complex inventories!
