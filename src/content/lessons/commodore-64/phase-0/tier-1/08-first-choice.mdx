# First Choice

**The moment your adventure becomes truly interactive! Learn IF-THEN statements to make intelligent decisions based on player choices**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={8} />

## Making Smart Decisions

Yesterday we learned to ask players questions and store their answers. Today we'll make our program react intelligently to those answers using IF-THEN statements. This is where your cave adventure becomes truly interactive!

<TryItNow>
```basic
10 REM MYSTERY CAVE - SMART DECISIONS
20 INPUT "DO YOU WANT TO ENTER THE CAVE (Y/N)"; A$
30 IF A$ = "Y" THEN PRINT "YOU BRAVELY ENTER THE DARK CAVE!"
40 IF A$ = "N" THEN PRINT "YOU DECIDE TO STAY SAFE OUTSIDE."
50 PRINT "THE END"
```
</TryItNow>

Look at that! The computer examines what the player typed and responds differently based on their choice.

## How IF-THEN Works

IF-THEN statements have three parts:
1. **IF** - The condition to check
2. **Condition** - What we're testing (like A$ = "Y")
3. **THEN** - What to do if the condition is true

The format is: `IF condition THEN action`

<TryItNow>
```basic
10 REM MYSTERY CAVE - HEALTH CHECK
20 HP = 75
30 PRINT "YOUR HEALTH: "; HP
40 IF HP > 50 THEN PRINT "YOU FEEL STRONG AND HEALTHY!"
50 IF HP < 25 THEN PRINT "YOU ARE BADLY WOUNDED!"
60 IF HP = 100 THEN PRINT "YOU ARE IN PERFECT CONDITION!"
```
</TryItNow>

## Comparison Operators

C64 BASIC gives us several ways to compare values:

- **=** Equal to
- **&lt;&gt;** Not equal to
- **&lt;** Less than
- **&gt;** Greater than
- **&lt;=** Less than or equal to
- **&gt;=** Greater than or equal to

<InfoBox>
**C64 BASIC Quirk:** Notice we use `&lt;&gt;` for "not equal" instead of `!=` like modern languages. This was standard in early BASIC dialects.
</InfoBox>

## Building Adventure Logic

Let's use IF-THEN to create a proper adventure decision system:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ADVENTURE DECISIONS
20 PRINT CHR$(147)
30 PRINT "YOU FIND A WOODEN CHEST IN THE CAVE!"
40 PRINT
50 INPUT "DO YOU OPEN IT (Y/N)"; A$
60 PRINT
70 IF A$ = "Y" THEN GOTO 100
80 IF A$ = "N" THEN GOTO 200
90 PRINT "PLEASE TYPE Y OR N": GOTO 50
100 PRINT "YOU OPEN THE CHEST..."
110 PRINT "INSIDE YOU FIND 50 GOLD COINS!"
120 SC = SC + 50
130 PRINT "YOUR SCORE: "; SC
140 END
200 PRINT "YOU DECIDE NOT TO RISK IT."
210 PRINT "SOMETIMES CAUTION IS WISE..."
220 END
```
</TryItNow>

Now we have genuine choice and consequence!

## Multiple Conditions

We can check multiple things at once using AND and OR:

<TryItNow>
```basic
10 REM MYSTERY CAVE - COMPLEX CONDITIONS
20 HP = 30: TR = 2
30 PRINT "HEALTH: "; HP; "  TREASURES: "; TR
40 PRINT
50 IF HP < 50 AND TR > 0 THEN PRINT "YOU'RE WEAK BUT WEALTHY!"
60 IF HP > 75 OR TR > 5 THEN PRINT "YOU'RE DOING WELL!"
70 IF HP <= 10 AND TR = 0 THEN PRINT "THINGS LOOK BAD..."
```
</TryItNow>

## Creating Story Branches

Let's build a complete branching story:

<TryItNow>
```basic
10 REM MYSTERY CAVE - BRANCHING STORY
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "       MYSTERY CAVE"
50 PRINT "==============================="
60 PRINT
70 PRINT "YOU STAND BEFORE TWO TUNNELS."
80 PRINT "LEFT: GLOWING CRYSTALS VISIBLE"
90 PRINT "RIGHT: SOUND OF RUNNING WATER"
100 PRINT
110 INPUT "WHICH WAY DO YOU GO (L/R)"; D$
120 PRINT
130 IF D$ = "L" THEN GOTO 200
140 IF D$ = "R" THEN GOTO 300
150 PRINT "THAT'S NOT A VALID DIRECTION!"
160 GOTO 110
170 REM
180 REM LEFT TUNNEL - CRYSTAL CAVE
200 PRINT "YOU FOLLOW THE GLOWING LIGHT..."
210 PRINT "THE TUNNEL OPENS INTO A CRYSTAL CAVE!"
220 PRINT "BEAUTIFUL GEMS LINE THE WALLS."
230 SC = SC + 100
240 PRINT "YOU GAIN 100 POINTS!"
250 END
260 REM
270 REM RIGHT TUNNEL - UNDERGROUND RIVER
300 PRINT "YOU FOLLOW THE SOUND OF WATER..."
310 PRINT "YOU DISCOVER AN UNDERGROUND RIVER!"
320 PRINT "A BOAT WAITS BY THE SHORE."
330 HP = HP + 25
340 PRINT "THE FRESH AIR RESTORES YOUR HEALTH!"
350 END
```
</TryItNow>

Each choice leads to a completely different adventure outcome!

## Your Challenge

Create a mini-adventure with:
- At least 3 different choices for the player
- Each choice leading to a different outcome
- Use of numeric comparisons (health, score, items)
- Proper error handling for invalid input

<InfoBox>
**Adventure Game Wisdom:** The best text adventures make every choice feel meaningful. Players should wonder "what if I had chosen differently?" after each decision.
</InfoBox>
