# Multiple Directions

**Navigate your cave with style! Learn to handle N/S/E/W movement using multiple IF statements and sophisticated direction logic.**

## Building Movement Systems

Real adventures need more than just "left" or "right" - they need full directional movement! Let's build a proper navigation system using multiple IF statements to handle North, South, East, and West movement.

<TryItNow>
```basic
10 REM MYSTERY CAVE - FOUR DIRECTIONS
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "    THE CENTRAL CHAMBER"
50 PRINT "==============================="
60 PRINT
70 PRINT "FOUR TUNNELS BRANCH OUT:"
80 PRINT "NORTH - COLD AIR FLOWS FROM DARKNESS"
90 PRINT "SOUTH - WARM BREEZE AND DISTANT LIGHT"
100 PRINT "EAST - STRANGE ECHOES AND WHISPERS"
110 PRINT "WEST - THE SOUND OF RUNNING WATER"
120 PRINT
130 INPUT "WHICH DIRECTION (N/S/E/W)"; D$
140 IF D$ = "N" THEN GOTO 300
150 IF D$ = "NORTH" THEN GOTO 300
160 IF D$ = "S" THEN GOTO 400
170 IF D$ = "SOUTH" THEN GOTO 400
180 IF D$ = "E" THEN GOTO 500
190 IF D$ = "EAST" THEN GOTO 500
200 IF D$ = "W" THEN GOTO 600
210 IF D$ = "WEST" THEN GOTO 600
220 PRINT "I DON'T UNDERSTAND THAT DIRECTION."
230 GOTO 130
240 REM
250 REM DIRECTION HANDLERS
300 PRINT "NORTH: ICE CAVERN! FROZEN TREASURE!"
310 PRINT "YOU GAIN 100 GOLD BUT LOSE 5 HP!"
320 GO = GO + 100: HP = HP - 5: END
400 PRINT "SOUTH: SUNNY GARDEN! HEALING HERBS!"
410 PRINT "YOU RESTORE 15 HP AND FEEL REFRESHED!"
420 HP = HP + 15: END
500 PRINT "EAST: ECHO CHAMBER! MAGIC SPELL BOOK!"
510 PRINT "YOU LEARN A POWERFUL SPELL!"
520 SP = SP + 1: END
600 PRINT "WEST: UNDERGROUND RIVER! FISHING SPOT!"
610 PRINT "YOU CATCH FISH AND GAIN PROVISIONS!"
620 FD = FD + 3: END
```
</TryItNow>

Notice how we handle both single letters (N, S, E, W) and full words (NORTH, SOUTH, etc.) to make the game more user-friendly!

## Creating Direction Aliases

Players might type directions in different ways. Let's make our game accept multiple input formats:

<TryItNow>
```basic
10 REM MYSTERY CAVE - FLEXIBLE INPUT
20 PRINT CHR$(147)
30 PRINT "YOU'RE IN A ROCKY CHAMBER."
40 PRINT "PASSAGES LEAD IN ALL DIRECTIONS."
50 PRINT
60 INPUT "WHERE DO YOU GO"; M$
70 REM CHECK FOR NORTH VARIANTS
80 IF M$ = "N" THEN GOTO 200
90 IF M$ = "NORTH" THEN GOTO 200
100 IF M$ = "GO NORTH" THEN GOTO 200
110 REM CHECK FOR SOUTH VARIANTS
120 IF M$ = "S" THEN GOTO 300
130 IF M$ = "SOUTH" THEN GOTO 300
140 IF M$ = "GO SOUTH" THEN GOTO 300
150 REM INVALID INPUT
160 PRINT "YOU CAN'T GO THAT WAY."
170 GOTO 60
180 REM
190 REM DESTINATIONS
200 PRINT "NORTH: YOU ENTER A CRYSTAL CAVERN!"
210 END
300 PRINT "SOUTH: YOU FIND THE DRAGON'S LAIR!"
310 END
```
</TryItNow>

This makes your adventure feel more natural and forgiving to play!

## Complex Movement Logic

Let's build a more sophisticated system that tracks your location and limits movement based on where you are:

<InfoBox type="tip">
**C64 BASIC Tip**: We're simulating compound conditions by using multiple separate IF statements. Modern BASIC dialects have AND/OR operators, but C64 BASIC requires this approach.
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - LOCATION SYSTEM
20 LO = 1: REM CURRENT LOCATION (1=START)
30 PRINT CHR$(147)
40 REM DISPLAY CURRENT LOCATION
50 IF LO = 1 THEN PRINT "CAVE ENTRANCE - EXIT SOUTH"
60 IF LO = 2 THEN PRINT "MAIN HALL - PATHS N/E/W"
70 IF LO = 3 THEN PRINT "TREASURE ROOM - EXIT WEST"
80 PRINT
90 INPUT "MOVE WHERE"; D$
100 REM HANDLE MOVEMENT FROM EACH LOCATION
110 IF LO = 1 AND D$ = "N" THEN LO = 2: GOTO 30
120 IF LO = 1 AND D$ = "S" THEN PRINT "EXIT CAVE": END
130 IF LO = 2 AND D$ = "S" THEN LO = 1: GOTO 30
140 IF LO = 2 AND D$ = "E" THEN LO = 3: GOTO 30
150 IF LO = 2 AND D$ = "W" THEN PRINT "DEAD END!": GOTO 90
160 IF LO = 3 AND D$ = "W" THEN LO = 2: GOTO 30
170 REM INVALID MOVE
180 PRINT "YOU CAN'T GO THAT WAY!"
190 GOTO 90
```
</TryItNow>

Now your cave has a real map structure with connections between rooms!
