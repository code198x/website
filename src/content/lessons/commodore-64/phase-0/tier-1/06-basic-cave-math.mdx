# Cave Rooms

**Create your first explorable world! Use GOTO to build connected cave rooms that players can navigate between**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={6} />

## Moving Between Locations

Real adventure games have multiple locations to explore. In our Mystery Cave, we need different rooms with unique descriptions and atmospheres. The GOTO statement is our key to creating this connected world.

GOTO tells the computer to jump to a specific line number and continue running from there. Think of it as teleporting your program to a different location!

<TryItNow>
```basic
10 REM MYSTERY CAVE - FIRST ROOMS
20 PRINT "YOU ARE AT THE CAVE ENTRANCE"
30 PRINT "GO TO ROOM 1? (Y/N)"
40 INPUT A$
50 IF A$ = "Y" THEN GOTO 100
60 PRINT "YOU STAY AT THE ENTRANCE"
70 END
100 PRINT "YOU ARE NOW IN ROOM 1!"
110 PRINT "IT'S DARK AND MYSTERIOUS..."
```
</TryItNow>

Amazing! When the player types "Y", the program jumps to line 100 and shows a completely different room description.

## Creating Our Cave Map

Let's build a simple cave system with three connected rooms:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ROOM SYSTEM
20 REM START AT CAVE ENTRANCE
30 PRINT CHR$(147)
40 PRINT "==============================="
50 PRINT "       MYSTERY CAVE"
60 PRINT "==============================="
70 GOTO 100
80 REM
90 REM ROOM 1 - CAVE ENTRANCE
100 PRINT "YOU ARE AT THE CAVE ENTRANCE."
110 PRINT "MOSS HANGS FROM THE ROCKY WALLS."
120 PRINT "A TUNNEL LEADS DEEPER INTO THE CAVE."
130 PRINT
140 PRINT "GO DEEPER? (Y/N)"
150 INPUT A$
160 IF A$ = "Y" THEN GOTO 200
170 GOTO 100
180 REM
190 REM ROOM 2 - DARK TUNNEL
200 PRINT CHR$(147)
210 PRINT "YOU ARE IN A DARK TUNNEL."
220 PRINT "WATER DRIPS FROM THE CEILING."
230 PRINT "YOU CAN GO BACK OR CONTINUE FORWARD."
240 PRINT
250 PRINT "GO FORWARD? (Y/N)"
260 INPUT A$
270 IF A$ = "Y" THEN GOTO 300
280 GOTO 100
290 REM
300 REM ROOM 3 - CHAMBER
310 PRINT CHR$(147)
320 PRINT "YOU ARE IN A LARGE CHAMBER."
330 PRINT "STRANGE ECHOES FILL THE AIR."
340 PRINT "THIS IS AS FAR AS YOU CAN GO."
350 PRINT
360 PRINT "GO BACK? (Y/N)"
370 INPUT A$
380 GOTO 200
```
</TryItNow>

Look what we've created! Three distinct rooms that players can navigate between using simple Y/N choices.

## Understanding Program Flow

Notice the structure of our cave system:
- **Lines 100-170:** Room 1 (Entrance)
- **Lines 200-280:** Room 2 (Tunnel)
- **Lines 300-380:** Room 3 (Chamber)

Each room section:
1. Clears the screen
2. Describes the location
3. Asks for player input
4. Uses GOTO to jump to the next room

<InfoBox>
**Programming Practice:** Using line numbers like 100, 200, 300 for different rooms makes it easy to add new content later. We can insert lines 150, 250, etc., without renumbering everything.
</InfoBox>

## Adding Room Variables

Let's track which room the player is in using our numeric variables:

<TryItNow>
```basic
10 REM MYSTERY CAVE - ROOM TRACKING
20 RM = 1: ST = 0
30 REM RM=ROOM, ST=STEPS
40 GOTO 100
50 REM
60 REM ROOM 1 - ENTRANCE
100 RM = 1: ST = ST + 1
110 PRINT CHR$(147)
120 PRINT "ROOM "; RM; " - CAVE ENTRANCE"
130 PRINT "STEPS TAKEN: "; ST
140 PRINT
150 PRINT "MOSS-COVERED STONE SURROUNDS YOU."
160 PRINT "A DARK PASSAGE LEADS INWARD."
170 PRINT
180 INPUT "GO DEEPER (Y/N)"; A$
190 IF A$ = "Y" THEN GOTO 200
200 GOTO 100
210 REM
220 REM ROOM 2 - TUNNEL
230 RM = 2: ST = ST + 1
240 PRINT CHR$(147)
250 PRINT "ROOM "; RM; " - DARK TUNNEL"
260 PRINT "STEPS TAKEN: "; ST
270 PRINT
280 PRINT "DRIPPING WATER ECHOES AROUND YOU."
290 INPUT "CONTINUE FORWARD (Y/N)"; A$
300 IF A$ = "Y" THEN GOTO 400
310 GOTO 100
320 REM
330 REM ROOM 3 - CHAMBER
400 RM = 3: ST = ST + 1
410 PRINT CHR$(147)
420 PRINT "ROOM "; RM; " - MYSTERIOUS CHAMBER"
430 PRINT "STEPS TAKEN: "; ST
440 PRINT
450 PRINT "A VAST UNDERGROUND CHAMBER!"
460 INPUT "GO BACK (Y/N)"; A$
470 GOTO 200
```
</TryItNow>

Now we're tracking both location and how many moves the player has made!
