# Hello Cave

**Welcome to the mysterious depths of Commodore 64 BASIC programming - where every adventure begins with a single PRINT**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={1} />

## Your First Steps Into The Cave

Every great adventure starts somewhere. For us, it begins at the entrance to Mystery Cave - a text adventure we'll build together over the next 16 lessons. By the end, you'll have a working game that responds to player choices, tracks inventory, and creates that magical feeling of exploration that defined 1980s gaming.

But first, let's make the computer speak.

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 PRINT "WELCOME TO MYSTERY CAVE"
30 PRINT
40 PRINT "YOU STAND AT THE ENTRANCE"
50 PRINT "DARKNESS AWAITS..."
```
</TryItNow>

Type this program exactly as shown. When you're done, type `RUN` and press RETURN.

## Understanding What Just Happened

Let's break down each line:

**Line 10: REM** - This is a REMark (comment). The computer ignores it, but it helps us remember what our program does. Professional programmers always document their code.

**Lines 20, 40, 50: PRINT** - The workhorse of BASIC. PRINT displays text on screen. The text must be enclosed in quotation marks.

**Line 30: PRINT (empty)** - A PRINT statement with nothing after it creates a blank line. It's like pressing RETURN in a word processor.

**Line Numbers** - Every BASIC line needs a number. We use 10, 20, 30... so we can insert new lines later (like 15 or 25) without renumbering everything.

## Try These Experiments

1. Change line 50 to say something different
2. Add line 60 with another PRINT statement
3. What happens if you type `LIST` instead of `RUN`?

<InfoBox>
**C64 BASIC Quirk:** The Commodore 64 only looks at the first two characters of BASIC keywords. You can type `PR` instead of `PRINT` and it works! But we'll use full words for clarity.
</InfoBox>
