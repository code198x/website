# Player Name

**Transform your adventure from a story to a conversation! The INPUT statement lets players become active participants in your cave exploration**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={5} />

## Making Games Interactive

Up until now, our programs have been one-way conversations - we tell the computer what to say, and it displays text. But real adventure games are interactive! The computer asks questions, and players type answers. The secret is the INPUT statement.

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 PRINT "WHAT IS YOUR NAME, BRAVE ADVENTURER?"
30 INPUT N$
40 PRINT "GREETINGS, "; N$; "!"
50 PRINT "WELCOME TO THE MYSTERY CAVE!"
```
</TryItNow>

Run this program and watch the magic happen! The computer waits for you to type something, then remembers what you typed in the variable N$.

## How INPUT Works

The INPUT statement has two parts:

1. **INPUT** - The command that tells the computer to wait for typing
2. **Variable name** - Where to store what the player types

When the program reaches an INPUT line:
- It displays a question mark (?)
- The cursor appears, waiting for typing
- The player types something and presses RETURN
- The text gets stored in the variable

## Input with Prompts

You can make INPUT more user-friendly by adding your own prompt:

<TryItNow>
```basic
10 REM MYSTERY CAVE - A TEXT ADVENTURE
20 INPUT "WHAT IS YOUR NAME"; N$
30 PRINT
40 PRINT "EXCELLENT, "; N$; "!"
50 PRINT "YOU STAND BEFORE THE MYSTERY CAVE."
60 INPUT "PRESS RETURN TO ENTER"; A$
```
</TryItNow>

Notice how we can put the prompt right in the INPUT statement using semicolons or commas.

<InfoBox>
**INPUT Punctuation:** Using a semicolon (;) after the prompt prints a question mark. Using a comma (,) doesn't print the question mark - just your prompt text.
</InfoBox>

## Building Our Character Creator

Let's create a character creation system for our adventure:

<TryItNow>
```basic
10 REM MYSTERY CAVE - CHARACTER CREATION
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "    MYSTERY CAVE ADVENTURE"
50 PRINT "      CHARACTER CREATION"
60 PRINT "==============================="
70 PRINT
80 INPUT "WHAT IS YOUR NAME"; N$
90 INPUT "WHAT IS YOUR PROFESSION"; P$
100 INPUT "WHAT IS YOUR HOMETOWN"; H$
110 PRINT
120 PRINT "WELCOME, "; N$; " THE "; P$
130 PRINT "FROM THE TOWN OF "; H$; "!"
140 PRINT
150 PRINT "YOUR ADVENTURE BEGINS NOW..."
```
</TryItNow>

Now each player gets a unique, personalized experience!

## Input for Numbers Too

INPUT works with numeric variables as well:

<TryItNow>
```basic
10 REM MYSTERY CAVE - STARTING STATS
20 PRINT "CHOOSE YOUR STARTING ATTRIBUTES:"
30 INPUT "STRENGTH (1-20)"; ST
40 INPUT "MAGIC (1-20)"; MG
50 INPUT "HEALTH (1-100)"; HP
60 PRINT
70 PRINT "YOUR CHARACTER STATS:"
80 PRINT "STRENGTH: "; ST
90 PRINT "MAGIC: "; MG
100 PRINT "HEALTH: "; HP
```
</TryItNow>

If the player types letters when the program expects numbers, you'll get a "REDO FROM START" error message.

## Complete Adventure Opening

Let's combine everything we've learned into a proper adventure game opening:

<TryItNow>
```basic
10 REM MYSTERY CAVE - COMPLETE OPENING
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "       MYSTERY CAVE"
50 PRINT "     A Text Adventure"
60 PRINT "==============================="
70 PRINT
80 INPUT "ENTER YOUR NAME, HERO"; N$
90 PRINT
100 PRINT "GREETINGS, "; N$; "!"
110 PRINT
120 PRINT "YOU ARE A BRAVE ADVENTURER WHO HAS"
130 PRINT "TRAVELED FAR TO REACH THE LEGENDARY"
140 PRINT "MYSTERY CAVE. TALES SPEAK OF GREAT"
150 PRINT "TREASURES HIDDEN IN ITS DEPTHS..."
160 PRINT
170 INPUT "PRESS RETURN TO BEGIN YOUR QUEST"; A$
180 PRINT
190 PRINT "GOOD LUCK, "; N$; "!"
200 PRINT "YOUR ADVENTURE STARTS NOW!"
```
</TryItNow>

## Try These Experiments

1. **Multiple prompts:** Ask for name, age, and favorite color
2. **Validation:** Ask "ARE YOU READY (YES/NO)" and store the answer
3. **Story building:** Use the player's answers to create a custom intro story
4. **Numeric input:** Ask for difficulty level (1-3) and starting gold amount

## Your Challenge

Create an advanced character creator that asks for:
- Player's name
- Character class (WARRIOR, WIZARD, THIEF)
- Starting weapon
- Lucky number (1-10)

Then display a personalized "character sheet" using all the information!

<InfoBox>
**Adventure Game Wisdom:** The best text adventures make players feel like the star of their own story. Personal touches like using the player's name throughout the game create emotional investment.
</InfoBox>
