## Understanding RND() Function

The RND() function generates random numbers between 0 and 1. By multiplying and using INT(), you can create random integers for treasure values, dice rolls, and surprise events!

<TryItNow>
```basic
10 REM MYSTERY CAVE - BASIC RANDOM DEMO
20 PRINT CHR$(147)
30 PRINT "RANDOM NUMBER EXAMPLES:"
40 PRINT
50 PRINT "RND(1) = "; RND(1)
60 PRINT "RND(1) = "; RND(1)
70 PRINT "RND(1) = "; RND(1)
80 PRINT
90 PRINT "RANDOM 1-6 (DICE):"
100 FOR I = 1 TO 5
110   DI = INT(RND(1) * 6) + 1
120   PRINT "ROLL"; I; ": "; DI
130 NEXT I
140 PRINT
150 PRINT "RANDOM 1-100 (PERCENTAGES):"
160 FOR I = 1 TO 3
170   PE = INT(RND(1) * 100) + 1
180   PRINT "CHANCE"; I; ": "; PE; "%"
190 NEXT I
```
</TryItNow>

INT(RND(1) * 6) + 1 creates random integers from 1 to 6 - perfect for dice rolls and random choices!

## Random Treasure Discovery

Let's create a treasure hunting system with random finds:

<InfoBox type="tip">
**Random Tip**: Use different probability ranges for different rarities. Common treasures (1-60), uncommon (61-85), rare (86-95), legendary (96-100).
</InfoBox>

<TryItNow>
```basic
10 REM MYSTERY CAVE - TREASURE HUNT
20 SC = 0
30 PRINT CHR$(147)
40 PRINT "==============================="
50 PRINT "    TREASURE HUNTING SYSTEM"
60 PRINT "==============================="
70 PRINT
80 FOR SE = 1 TO 5: REM 5 SEARCHES
90   PRINT "SEARCH"; SE; ": ";
100   REM ROLL FOR TREASURE
110   RO = INT(RND(1) * 100) + 1
120   IF RO <= 30 THEN PRINT "NOTHING FOUND": GOTO 200
130   IF RO <= 60 THEN GOSUB 300: REM COMMON
140   IF RO <= 80 THEN GOSUB 400: REM UNCOMMON
150   IF RO <= 95 THEN GOSUB 500: REM RARE
160   IF RO <= 100 THEN GOSUB 600: REM LEGENDARY
170   PRINT "TOTAL GOLD: "; SC
180   PRINT
190   FOR J = 1 TO 800: NEXT J: REM DELAY
200 NEXT SE
210 PRINT "TREASURE HUNT COMPLETE!"
220 PRINT "FINAL SCORE: "; SC; " GOLD"
230 END
290 REM
300 REM COMMON TREASURE
310 GO = INT(RND(1) * 25) + 5: REM 5-30 GOLD
320 PRINT "COPPER COINS! +"; GO; " GOLD"
330 SC = SC + GO: RETURN
390 REM
400 REM UNCOMMON TREASURE
410 GO = INT(RND(1) * 75) + 25: REM 25-100 GOLD
420 PRINT "SILVER JEWELRY! +"; GO; " GOLD"
430 SC = SC + GO: RETURN
490 REM
500 REM RARE TREASURE
510 GO = INT(RND(1) * 200) + 100: REM 100-300 GOLD
520 PRINT "GOLDEN ARTIFACT! +"; GO; " GOLD"
530 SC = SC + GO: RETURN
590 REM
600 REM LEGENDARY TREASURE
610 GO = INT(RND(1) * 500) + 300: REM 300-800 GOLD
620 PRINT "ANCIENT RELIC! +"; GO; " GOLD"
630 SC = SC + GO: RETURN
```
</TryItNow>

Now every treasure hunt gives different results with exciting discoveries!

## Random Encounters

Create unpredictable adventure encounters:

<TryItNow>
```basic
10 REM MYSTERY CAVE - RANDOM ENCOUNTERS
20 HP = 100: SC = 0
30 PRINT CHR$(147)
40 PRINT "YOU EXPLORE THE MYSTERIOUS CAVE..."
50 PRINT
60 FOR RO = 1 TO 8: REM 8 ROOMS TO EXPLORE
70   PRINT "ENTERING ROOM"; RO; "..."
80   FOR J = 1 TO 500: NEXT J: REM SUSPENSE
90   REM RANDOM ENCOUNTER ROLL
100   EN = INT(RND(1) * 10) + 1
110   IF EN <= 3 THEN GOSUB 1000: REM TREASURE
120   IF EN >= 4 AND EN <= 6 THEN GOSUB 2000: REM MONSTER
130   IF EN >= 7 AND EN <= 8 THEN GOSUB 3000: REM HEALING
140   IF EN >= 9 THEN GOSUB 4000: REM SPECIAL EVENT
150   PRINT "HP:"; HP; " GOLD:"; SC
160   IF HP <= 0 THEN PRINT "YOU DIED!": END
170   PRINT "---"
180 NEXT RO
190 PRINT "CAVE EXPLORED! FINAL SCORE:"; SC
200 END
990 REM
1000 REM TREASURE ROOM
1010 GO = INT(RND(1) * 50) + 10
1020 PRINT "TREASURE CHEST! +"; GO; " GOLD"
1030 SC = SC + GO: RETURN
1990 REM
2000 REM MONSTER ENCOUNTER
2010 DA = INT(RND(1) * 20) + 5
2020 PRINT "GOBLIN ATTACK! -"; DA; " HP"
2030 HP = HP - DA: RETURN
2990 REM
3000 REM HEALING FOUNTAIN
3010 HE = INT(RND(1) * 30) + 10
3020 PRINT "HEALING SPRING! +"; HE; " HP"
3030 HP = HP + HE
3040 IF HP > 100 THEN HP = 100
3050 RETURN
3990 REM
4000 REM SPECIAL EVENT
4010 EV = INT(RND(1) * 3) + 1
4020 IF EV = 1 THEN PRINT "MAGIC SWORD! ATTACK +5"
4030 IF EV = 2 THEN PRINT "LUCKY CHARM! PROTECTION +3"
4040 IF EV = 3 THEN PRINT "ANCIENT MAP! REVEALS SECRETS"
4050 RETURN
```
</TryItNow>

Every cave exploration becomes a unique adventure!

## Weighted Random Systems

Create more sophisticated random systems with different probabilities:

<TryItNow>
```basic
10 REM MYSTERY CAVE - TREASURE QUALITY SYSTEM
20 PRINT CHR$(147)
30 PRINT "ADVANCED TREASURE GENERATION"
40 PRINT "============================="
50 PRINT
60 FOR CH = 1 TO 10: REM 10 TREASURE CHESTS
70   PRINT "CHEST"; CH; ": ";
80   REM DETERMINE TREASURE QUALITY
90   QU = INT(RND(1) * 1000) + 1
100   IF QU <= 500 THEN GO = INT(RND(1) * 20) + 1: PRINT "COMMON ("; GO; " GOLD)"
110   IF QU > 500 AND QU <= 800 THEN GO = INT(RND(1) * 50) + 20: PRINT "UNCOMMON ("; GO; " GOLD)"
120   IF QU > 800 AND QU <= 950 THEN GO = INT(RND(1) * 100) + 50: PRINT "RARE ("; GO; " GOLD)"
130   IF QU > 950 AND QU <= 990 THEN GO = INT(RND(1) * 200) + 100: PRINT "EPIC ("; GO; " GOLD)"
140   IF QU > 990 THEN GO = INT(RND(1) * 500) + 300: PRINT "LEGENDARY ("; GO; " GOLD)"
150   TO = TO + GO
160 NEXT CH
170 PRINT
180 PRINT "TOTAL TREASURE: "; TO; " GOLD"
190 PRINT
200 REM RARITY STATISTICS
210 PRINT "RARITY CHANCES:"
220 PRINT "COMMON: 50.0%"
230 PRINT "UNCOMMON: 30.0%"
240 PRINT "RARE: 15.0%"
250 PRINT "EPIC: 4.0%"
260 PRINT "LEGENDARY: 1.0%"
```
</TryItNow>

This creates a realistic loot system where common treasures are frequent but legendary finds are incredibly rare!

## Random Cave Generation

Let's create caves with random layouts:

<TryItNow>
```basic
10 REM MYSTERY CAVE - RANDOM CAVE BUILDER
20 DIM RM$(10), EX$(10)
30 PRINT CHR$(147)
40 PRINT "GENERATING RANDOM CAVE..."
50 PRINT
60 REM CREATE 5 RANDOM ROOMS
70 FOR I = 1 TO 5
80   REM RANDOM ROOM TYPE
90   RT = INT(RND(1) * 6) + 1
100   IF RT = 1 THEN RM$(I) = "CRYSTAL CAVERN"
110   IF RT = 2 THEN RM$(I) = "UNDERGROUND LAKE"
120   IF RT = 3 THEN RM$(I) = "MUSHROOM GROVE"
130   IF RT = 4 THEN RM$(I) = "TREASURE VAULT"
140   IF RT = 5 THEN RM$(I) = "DRAGON'S LAIR"
150   IF RT = 6 THEN RM$(I) = "ANCIENT LIBRARY"
160   REM RANDOM EXITS
170   EX = INT(RND(1) * 4) + 1
180   IF EX = 1 THEN EX$(I) = "NORTH"
190   IF EX = 2 THEN EX$(I) = "SOUTH"
200   IF EX = 3 THEN EX$(I) = "EAST, WEST"
210   IF EX = 4 THEN EX$(I) = "N, S, E, W"
220 NEXT I
230 REM DISPLAY GENERATED CAVE
240 PRINT "YOUR RANDOM CAVE SYSTEM:"
250 PRINT "========================"
260 FOR I = 1 TO 5
270   PRINT "ROOM"; I; ": "; RM$(I)
280   PRINT "EXITS: "; EX$(I)
290   PRINT
300 NEXT I
310 PRINT "ADVENTURE AWAITS!"
```
</TryItNow>

Every time you run this, you get a completely different cave to explore!

## Random Event Tables

Create complex random events using data tables:

<TryItNow>
```basic

70   PRINT "ENCOUNTER"; EN; ":"
80   REM ROLL D20 FOR EVENT
90   RO = INT(RND(1) * 20) + 1
100   RESTORE 200: REM RESET DATA POINTER
110   FOR I = 1 TO RO
120     READ EV$, EF

140   PRINT EV$
150   SC = SC + EF
160   PRINT "EFFECT: "; EF; " POINTS"
```
