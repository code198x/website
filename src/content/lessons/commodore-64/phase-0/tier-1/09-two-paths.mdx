## Creating ELSE Logic

C64 BASIC doesn't have a built-in ELSE statement, but we can create the same effect using clever combinations of IF-THEN and GOTO. This lets us build sophisticated decision trees where every choice matters!

<TryItNow>
```basic
10 REM MYSTERY CAVE - TREASURE DECISION
20 PRINT CHR$(147)
30 PRINT "YOU FIND A GLOWING CRYSTAL!"
40 PRINT "BUT IT'S GUARDED BY A SLEEPING DRAGON."
50 PRINT
60 INPUT "DO YOU TAKE THE CRYSTAL (Y/N)"; A$
70 IF A$ = "Y" THEN GOTO 200
80 REM ELSE - PLAYER CHOSE NOT TO TAKE IT
90 PRINT "YOU DECIDE DISCRETION IS WISE."
100 PRINT "YOU QUIETLY BACK AWAY..."
110 PRINT "SOMETIMES THE GREATEST TREASURE"
120 PRINT "IS STAYING ALIVE!"
130 END
200 REM PLAYER CHOSE TO TAKE IT
210 PRINT "YOU CAREFULLY REACH FOR THE CRYSTAL..."
220 PRINT "THE DRAGON STIRS BUT DOESN'T WAKE!"
230 PRINT "YOU SUCCESSFULLY GRAB THE TREASURE!"
240 SC = SC + 200
250 PRINT "YOU GAIN 200 POINTS!"
```
</TryItNow>

Each choice leads to a completely different outcome with unique consequences!

## Multiple Path Adventures

Let's create a complex adventure with three branching paths:

<TryItNow>
```basic
10 REM MYSTERY CAVE - CHAMBER OF CHOICES
20 PRINT CHR$(147)
30 PRINT "==============================="
40 PRINT "    THE CHAMBER OF CHOICES"
50 PRINT "==============================="
60 PRINT
70 PRINT "THREE MYSTERIOUS DOORWAYS:"
80 PRINT "1) BLUE DOOR - ICY MIST FLOWS OUT"
90 PRINT "2) RED DOOR - WARM LIGHT GLOWS"
100 PRINT "3) BLACK DOOR - COMPLETE DARKNESS"
110 PRINT
120 INPUT "WHICH DOOR (1-3)"; C$
130 IF C$ = "1" THEN GOTO 300
140 IF C$ = "2" THEN GOTO 400
150 IF C$ = "3" THEN GOTO 500
160 PRINT "THAT'S NOT A VALID DOOR!"
170 GOTO 120
180 REM
190 REM PATHS WITH DIFFERENT OUTCOMES
300 PRINT "ICE CAVERN! YOU FIND FROZEN TREASURE!"
310 HP = HP - 10: SC = SC + 150: END
400 PRINT "HEALING CHAMBER! YOU FIND A MAGIC SWORD!"
420 HP = HP + 20: SC = SC + 100: END
500 PRINT "TREASURE VAULT! GREATEST REWARD!"
510 SC = SC + 300: END
```
</TryItNow>
