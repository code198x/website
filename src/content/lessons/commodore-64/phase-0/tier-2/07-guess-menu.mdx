## Professional Game Structure

Real games don't just start immediately - they welcome players with attractive menus and let them choose how they want to play. Let's create a proper main menu:

<TryItNow>
```basic
10 REM GAME MENUS - PROFESSIONAL STRUCTURE
15 REM COLOR CONSTANTS
20 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
25 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
30 REM DIFFICULTY VARIABLES
35 MAX_RANGE = 100: MAX_TRIES = 20: HINT_MODE = 1
40 REM MAIN PROGRAM START
45 GOSUB 1000 REM SHOW MAIN MENU
50 GOSUB 2000 REM PLAY GAME
55 GOSUB 3000 REM SHOW RESULTS
60 GOTO 45 REM RETURN TO MENU
1000 REM MAIN MENU SUBROUTINE
1005 PRINT CHR$(147) REM CLEAR SCREEN
1010 PRINT WHITE$; "╔══════════════════════════════════════╗"; OFF$
1015 PRINT WHITE$; "║"; OFF$; "                                      "; WHITE$; "║"; OFF$
1020 PRINT WHITE$; "║"; OFF$; "     "; YELLOW$; "NUMBER GUESSING GAME"; OFF$; "           "; WHITE$; "║"; OFF$
1025 PRINT WHITE$; "║"; OFF$; "        "; GREEN$; "DELUXE EDITION"; OFF$; "              "; WHITE$; "║"; OFF$
1030 PRINT WHITE$; "║"; OFF$; "                                      "; WHITE$; "║"; OFF$
1035 PRINT WHITE$; "╚══════════════════════════════════════╝"; OFF$
1040 PRINT
1045 PRINT YELLOW$; "SELECT DIFFICULTY LEVEL:"; OFF$
1050 PRINT
1055 PRINT GREEN$; "1"; OFF$; " - EASY     (1-50,  UNLIMITED TRIES)"
1060 PRINT YELLOW$; "2"; OFF$; " - MEDIUM   (1-100, 20 TRIES)"
1065 PRINT RED$; "3"; OFF$; " - HARD     (1-200, 15 TRIES, NO HINTS)"
1070 PRINT PURPLE$; "4"; OFF$; " - EXPERT   (1-500, 10 TRIES, NO HINTS)"
1075 PRINT
1080 PRINT "9 - QUIT GAME"
1085 PRINT
1090 INPUT "YOUR CHOICE (1-4, 9)"; CHOICE
1095 ON CHOICE GOSUB 1100,1200,1300,1400
1097 IF CHOICE = 9 THEN END
1098 IF CHOICE < 1 OR CHOICE > 9 THEN 1090
1099 RETURN
1100 REM EASY SETUP
1105 MAX_RANGE = 50: MAX_TRIES = 999: HINT_MODE = 1
1110 PRINT GREEN$; "EASY MODE SELECTED"; OFF$: RETURN
1200 REM MEDIUM SETUP
1205 MAX_RANGE = 100: MAX_TRIES = 20: HINT_MODE = 1
1210 PRINT YELLOW$; "MEDIUM MODE SELECTED"; OFF$: RETURN
1300 REM HARD SETUP
1305 MAX_RANGE = 200: MAX_TRIES = 15: HINT_MODE = 0
1310 PRINT RED$; "HARD MODE SELECTED"; OFF$: RETURN
1400 REM EXPERT SETUP
1405 MAX_RANGE = 500: MAX_TRIES = 10: HINT_MODE = 0
1410 PRINT PURPLE$; "EXPERT MODE SELECTED - GOOD LUCK!"; OFF$: RETURN
2000 REM GAME PLAY (SIMPLIFIED)
2005 PRINT: PRINT "PRESS ANY KEY TO START...": GET A$: IF A$ = "" THEN 2005
2010 SECRET = INT(RND(1)*MAX_RANGE) + 1: TRIES = 0
2015 PRINT CHR$(147): PRINT "I'M THINKING OF A NUMBER FROM 1 TO"; MAX_RANGE
2020 PRINT "YOU HAVE"; MAX_TRIES; "ATTEMPTS";
2025 IF HINT_MODE THEN PRINT " WITH HINTS" ELSE PRINT " NO HINTS"
2030 PRINT: RETURN
3000 REM RESULTS SCREEN
3005 PRINT: PRINT WHITE$; "GAME COMPLETE!"; OFF$
3010 PRINT "PRESS ANY KEY FOR MAIN MENU...": GET A$: IF A$ = "" THEN 3010
3015 RETURN
```
</TryItNow>

Look at the professional structure we've created:

**Lines 45-60:** The main program flow - menu → game → results → repeat

**Lines 1000-1099:** A complete main menu with color-coded difficulty options

**Lines 1095:** The ON-GOSUB statement jumps to different subroutines based on the player's choice

**Lines 1100-1410:** Each difficulty level sets different game parameters

<InfoBox>
ON-GOSUB is a powerful BASIC command that acts like a "smart GOTO." If CHOICE equals 1, it calls subroutine 1100. If CHOICE equals 2, it calls 1200, and so on. This makes menu handling much cleaner than multiple IF statements!
</InfoBox>

## Complete Menu-Driven Game

Now let's integrate our menu system with the full guessing game:

<TryItNow>
```basic
10 REM COMPLETE MENU-DRIVEN GAME
15 DATA "TRY THE MIDDLE!", "NARROW YOUR RANGE!", "YOU'RE GETTING CLOSE!"
20 REM COLOR CONSTANTS
25 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
30 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
35 REM GAME VARIABLES
40 MAX_RANGE = 100: MAX_TRIES = 20: HINT_MODE = 1
45 SECRET = 0: TRIES = 0: HINT_COUNT = 0: WON = 0
50 REM MAIN PROGRAM LOOP
55 GOSUB 1000 REM MAIN MENU
60 GOSUB 2000 REM PLAY GAME
65 GOSUB 3000 REM SHOW RESULTS
70 GOTO 55
1000 REM MAIN MENU
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "    ★ NUMBER GUESSING CHAMPIONSHIP ★"; OFF$
1015 PRINT STRING$(40, "─")
1020 PRINT
1025 PRINT YELLOW$; "CHOOSE YOUR CHALLENGE:"; OFF$
1030 PRINT
1035 PRINT GREEN$; "1"; OFF$; " - ROOKIE    (1-50,  No Limit)"
1040 PRINT YELLOW$; "2"; OFF$; " - AMATEUR   (1-100, 20 Tries)"
1045 PRINT RED$; "3"; OFF$; " - PRO       (1-200, 15 Tries)"
1050 PRINT PURPLE$; "4"; OFF$; " - LEGEND    (1-500, 10 Tries)"
1055 PRINT
1060 PRINT "9 - QUIT"
1065 PRINT
1070 INPUT "SELECT (1-4, 9)"; CHOICE
1075 ON CHOICE GOSUB 1100,1200,1300,1400
1080 IF CHOICE = 9 THEN END
1085 IF CHOICE < 1 OR CHOICE > 9 THEN 1070
1090 RETURN
1100 MAX_RANGE=50:MAX_TRIES=999:HINT_MODE=1: PRINT GREEN$;"ROOKIE LEVEL";OFF$: RETURN
1200 MAX_RANGE=100:MAX_TRIES=20:HINT_MODE=1: PRINT YELLOW$;"AMATEUR LEVEL";OFF$: RETURN
1300 MAX_RANGE=200:MAX_TRIES=15:HINT_MODE=0: PRINT RED$;"PRO LEVEL";OFF$: RETURN
1400 MAX_RANGE=500:MAX_TRIES=10:HINT_MODE=0: PRINT PURPLE$;"LEGEND LEVEL!";OFF$: RETURN
2000 REM MAIN GAME LOOP
2005 PRINT: PRINT "PRESS ENTER TO START YOUR CHALLENGE!": INPUT A$
2010 SECRET = INT(RND(1)*MAX_RANGE) + 1: TRIES = 0: WON = 0
2015 PRINT CHR$(147)
2020 PRINT "RANGE: 1 TO"; MAX_RANGE; "  ATTEMPTS:"; MAX_TRIES
2025 IF HINT_MODE = 0 THEN PRINT RED$; "NO HINTS MODE!"; OFF$
2030 PRINT STRING$(40, "─")
2035 REM GUESSING LOOP
2040 TRIES = TRIES + 1
2045 PRINT "ATTEMPT"; TRIES; "OF"; MAX_TRIES
2050 INPUT "YOUR GUESS"; GUESS
2055 IF GUESS = SECRET THEN WON = 1: RETURN
2060 IF TRIES >= MAX_TRIES THEN RETURN
2065 IF GUESS < SECRET THEN PRINT RED$; "TOO LOW!"; OFF$: GOTO 2080
2070 IF GUESS > SECRET THEN PRINT PURPLE$; "TOO HIGH!"; OFF$: GOTO 2080
2080 IF HINT_MODE = 1 THEN GOSUB 2500 REM SHOW HINT
2085 PRINT: GOTO 2040
2500 REM HINT SYSTEM
2505 HINT_COUNT = HINT_COUNT + 1
2510 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
2515 read HINT$
2520 PRINT YELLOW$; "HINT: "; HINT$; OFF$
2525 RETURN
3000 REM RESULTS SCREEN
3005 PRINT CHR$(147)
3010 IF WON = 1 THEN 3050
3015 REM LOST
3020 PRINT RED$; "CHALLENGE FAILED!"; OFF$
3025 PRINT "THE NUMBER WAS"; SECRET
3030 PRINT "BETTER LUCK NEXT TIME!"
3035 GOTO 3070
3050 REM WON
3055 PRINT GREEN$; "★ CHALLENGE COMPLETED! ★"; OFF$
3060 PRINT "YOU FOUND"; SECRET; "IN"; TRIES; "ATTEMPTS!"
3065 IF TRIES <= 5 THEN PRINT YELLOW$; "INCREDIBLE GUESSING!"; OFF$
3070 PRINT: PRINT "PRESS ENTER TO CONTINUE": INPUT A$
3075 RETURN
```
</TryItNow>

**Professional Features Added:**
- Complete menu system with themed difficulty names
- Different parameters for each difficulty level
- Proper game state tracking (WON variable)
- Results screen that changes based on performance
- Smooth flow between menu → game → results

## Design Patterns for Menus

Notice the patterns we're using:
- **Color coding** for different difficulty levels
- **Descriptive names** instead of just "easy/hard"
- **Clear feedback** when selections are made
- **Consistent visual style** throughout
