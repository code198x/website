## Beyond Simple Hints

Our early lessons used simple DATA statements for hints. Now let's create dynamic hint systems that analyze the secret number mathematically and provide intelligent clues:

<TryItNow>
```basic
10 REM SMART HINTS - MATHEMATICAL ANALYSIS
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 PRINT CHR$(147)
35 PRINT WHITE$; "MATHEMATICAL HINT ANALYSIS"; OFF$
40 PRINT STRING$(30, "═")
45 SECRET = INT(RND(1)*100) + 1
50 PRINT "SECRET NUMBER:", SECRET, "(FOR DEMO ONLY!)"
55 PRINT STRING$(30, "─")
60 REM ANALYZE THE NUMBER
65 GOSUB 1000 REM DIGIT ANALYSIS
70 GOSUB 1500 REM MATHEMATICAL PROPERTIES
75 GOSUB 2000 REM RANGE ANALYSIS
80 END
1000 REM DIGIT ANALYSIS
1005 SECRET$ = STR$(SECRET): IF LEFT$(SECRET$, 1) = " " THEN SECRET$ = RIGHT$(SECRET$, LEN(SECRET$) - 1)
1010 FIRST_DIGIT = VAL(LEFT$(SECRET$, 1))
1015 IF LEN(SECRET$) > 1 THEN LAST_DIGIT = VAL(RIGHT$(SECRET$, 1)) ELSE LAST_DIGIT = FIRST_DIGIT
1020 PRINT YELLOW$; "DIGIT ANALYSIS:"; OFF$
1025 PRINT "FIRST DIGIT:", FIRST_DIGIT
1030 PRINT "LAST DIGIT:", LAST_DIGIT
1035 IF LEN(SECRET$) > 1 THEN PRINT "DIGITS SUM:", FIRST_DIGIT + LAST_DIGIT
1040 RETURN
1500 REM MATHEMATICAL PROPERTIES
1505 PRINT: PRINT YELLOW$; "MATHEMATICAL PROPERTIES:"; OFF$
1510 IF SECRET MOD 2 = 0 THEN PRINT "NUMBER IS EVEN" ELSE PRINT "NUMBER IS ODD"
1515 IF SECRET MOD 5 = 0 THEN PRINT "MULTIPLE OF 5"
1520 IF SECRET MOD 10 = 0 THEN PRINT "MULTIPLE OF 10"
1525 REM PERFECT SQUARE CHECK
1530 SQUARE_ROOT = SQR(SECRET)
1535 IF SQUARE_ROOT = INT(SQUARE_ROOT) THEN PRINT "PERFECT SQUARE!"
1540 RETURN
2000 REM RANGE ANALYSIS
2005 PRINT: PRINT YELLOW$; "RANGE ANALYSIS:"; OFF$
2010 IF SECRET <= 25 THEN PRINT "IN FIRST QUARTER (1-25)"
2015 IF SECRET > 25 AND SECRET <= 50 THEN PRINT "IN SECOND QUARTER (26-50)"
2020 IF SECRET > 50 AND SECRET <= 75 THEN PRINT "IN THIRD QUARTER (51-75)"
2025 IF SECRET > 75 THEN PRINT "IN FOURTH QUARTER (76-100)"
2030 RETURN
```
</TryItNow>

**Mathematical Analysis Features:**
- **Lines 1005-1015:** Extract first and last digits using LEFT$ and RIGHT$
- **Lines 1510-1520:** Test divisibility for mathematical clues
- **Lines 2010-2025:** Provide range guidance without being too specific

<InfoBox>
STR$(SECRET) converts numbers to strings, allowing us to use LEFT$ and RIGHT$ for digit extraction. This opens up powerful analysis possibilities like checking digit patterns, sums, and mathematical relationships!
</InfoBox>

## Adaptive Hint Systems

Let's create hint systems that get more specific as players struggle, adapting their helpfulness based on how many attempts have been made:

<TryItNow>
```basic
10 REM ADAPTIVE HINT SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 SECRET = INT(RND(1)*100) + 1: TRIES = 0
35 PRINT CHR$(147)
40 PRINT WHITE$; "ADAPTIVE HINT DEMO"; OFF$
45 PRINT STRING$(30, "═")
50 PRINT "I'M THINKING OF A NUMBER 1-100"
55 PRINT "(SECRET IS"; SECRET; "FOR DEMO PURPOSES)"
60 PRINT STRING$(30, "─")
65 REM MAIN GAME LOOP
70 TRIES = TRIES + 1
75 PRINT: PRINT "ATTEMPT"; TRIES
80 INPUT "YOUR GUESS"; GUESS
85 IF GUESS = SECRET THEN 500
90 REM PROVIDE ADAPTIVE HINTS
95 IF GUESS < SECRET THEN PRINT RED$; "TOO LOW!"; OFF$ ELSE PRINT PURPLE$; "TOO HIGH!"; OFF$
100 GOSUB 1000 REM ADAPTIVE HINT SYSTEM
105 GOTO 70
500 PRINT GREEN$; "CORRECT! YOU GOT IT!"; OFF$: END
1000 REM ADAPTIVE HINT SYSTEM
1005 REM LEVEL 1: BASIC HINTS (ATTEMPTS 1-3)
1010 IF TRIES <= 3 THEN 1100
1015 REM LEVEL 2: MATHEMATICAL HINTS (ATTEMPTS 4-6)
1020 IF TRIES <= 6 THEN 1200
1025 REM LEVEL 3: SPECIFIC HINTS (ATTEMPTS 7-9)
1030 IF TRIES <= 9 THEN 1300
1035 REM LEVEL 4: VERY SPECIFIC (ATTEMPTS 10+)
1040 GOTO 1400
1100 REM BASIC ENCOURAGEMENT
1105 BASIC_HINTS = 3
1110 ON (TRIES MOD BASIC_HINTS) + 1 GOTO 1110, 1120, 1130
1115 PRINT YELLOW$; "HINT: KEEP TRYING!"; OFF$: RETURN
1120 PRINT YELLOW$; "HINT: TRY THE MIDDLE RANGE"; OFF$: RETURN
1130 PRINT YELLOW$; "HINT: THINK MATHEMATICALLY"; OFF$: RETURN
1200 REM MATHEMATICAL CLUES
1205 PRINT YELLOW$; "MATHEMATICAL HINT: ";
1210 IF SECRET MOD 2 = 0 THEN PRINT "THE NUMBER IS EVEN"; OFF$ ELSE PRINT "THE NUMBER IS ODD"; OFF$
1215 RETURN
1300 REM SPECIFIC CLUES
1305 PRINT YELLOW$; "SPECIFIC HINT: ";
1310 SECRET$ = STR$(SECRET): IF LEFT$(SECRET$, 1) = " " THEN SECRET$ = RIGHT$(SECRET$, LEN(SECRET$) - 1)
1315 FIRST_DIGIT = VAL(LEFT$(SECRET$, 1))
1320 PRINT "FIRST DIGIT IS"; FIRST_DIGIT; OFF$
1325 RETURN
1400 REM VERY SPECIFIC CLUES
1405 RANGE_SIZE = 10
1410 LOWER = INT((SECRET - 1) / RANGE_SIZE) * RANGE_SIZE + 1
1415 UPPER = LOWER + RANGE_SIZE - 1
1420 PRINT YELLOW$; "VERY SPECIFIC: NUMBER IS BETWEEN"; LOWER; "AND"; UPPER; OFF$
1425 RETURN
```
</TryItNow>

**Adaptive Progression System:**
- **Attempts 1-3:** General encouragement and basic strategy
- **Attempts 4-6:** Mathematical properties (even/odd, multiples)
- **Attempts 7-9:** Specific clues like first digit
- **Attempts 10+:** Very specific range information

This creates a natural difficulty curve that helps struggling players without making the game too easy!

## Professional Hint Architecture

Let's build a complete hint system that combines multiple analysis methods for maximum intelligence:

<TryItNow>
```basic
10 REM PROFESSIONAL HINT ARCHITECTURE
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 SECRET = INT(RND(1)*100) + 1: TRIES = 0
35 DIM GUESS_HISTORY(20) REM TRACK PLAYER GUESSES
40 GUESS_COUNT = 0
45 PRINT CHR$(147)
50 PRINT WHITE$; "PROFESSIONAL HINT SYSTEM"; OFF$
55 PRINT STRING$(30, "═")
60 PRINT "FIND THE SECRET NUMBER (1-100)"
65 PRINT "HINTS GET SMARTER AS YOU PLAY!"
70 PRINT STRING$(30, "─")
75 REM MAIN GAME LOOP
80 TRIES = TRIES + 1
85 PRINT: PRINT "ATTEMPT"; TRIES
90 INPUT "YOUR GUESS"; GUESS
95 REM STORE GUESS HISTORY
100 GUESS_COUNT = GUESS_COUNT + 1
105 IF GUESS_COUNT <= 20 THEN GUESS_HISTORY(GUESS_COUNT) = GUESS
110 IF GUESS = SECRET THEN 800
115 REM BASIC FEEDBACK
120 DIFF = ABS(GUESS - SECRET)
125 IF GUESS < SECRET THEN PRINT RED$; "TOO LOW"; OFF$; ELSE PRINT PURPLE$; "TOO HIGH"; OFF$;
130 IF DIFF <= 5 THEN PRINT " - " + GREEN$ + "VERY CLOSE!" + OFF$
135 IF DIFF > 5 AND DIFF <= 15 THEN PRINT " - " + YELLOW$ + "GETTING WARMER" + OFF$
140 IF DIFF > 15 THEN PRINT " - " + WHITE$ + "KEEP SEARCHING" + OFF$
145 PRINT
150 REM INTELLIGENT HINT SYSTEM
155 GOSUB 2000 REM ANALYZE PLAYER BEHAVIOR
160 GOSUB 3000 REM PROVIDE SMART HINT
165 GOTO 80
800 PRINT GREEN$; "★ BRILLIANT! YOU FOUND IT! ★"; OFF$
805 PRINT "THE SECRET WAS"; SECRET
810 END
2000 REM ANALYZE PLAYER BEHAVIOR
2005 IF GUESS_COUNT < 2 THEN RETURN
2010 REM CHECK FOR PATTERNS IN GUESSES
2015 LAST_GUESS = GUESS_HISTORY(GUESS_COUNT - 1)
2020 CURRENT_GUESS = GUESS_HISTORY(GUESS_COUNT)
2025 GUESS_DIRECTION = CURRENT_GUESS - LAST_GUESS
2030 PLAYER_STRATEGY = 0 REM 0=RANDOM, 1=SYSTEMATIC, 2=STRUGGLING
2035 IF ABS(GUESS_DIRECTION) <= 10 THEN PLAYER_STRATEGY = 1 REM SYSTEMATIC
2040 IF ABS(GUESS_DIRECTION) > 30 THEN PLAYER_STRATEGY = 2 REM STRUGGLING
2045 RETURN
3000 REM PROVIDE SMART HINT
3005 REM ADAPTIVE HINT LEVEL
3010 HINT_LEVEL = 1
3015 IF TRIES > 5 THEN HINT_LEVEL = 2
3020 IF TRIES > 10 THEN HINT_LEVEL = 3
3025 IF TRIES > 15 THEN HINT_LEVEL = 4
3030 REM CHOOSE HINT TYPE
3035 ON HINT_LEVEL GOSUB 3100, 3200, 3300, 3400
3040 RETURN
3100 REM LEVEL 1 HINTS - MATHEMATICAL
3105 PRINT YELLOW$; "SMART HINT: ";
3110 IF SECRET MOD 10 = 0 THEN PRINT "ENDS IN ZERO"; OFF$: RETURN
3115 IF SECRET MOD 5 = 0 THEN PRINT "MULTIPLE OF 5"; OFF$: RETURN
3120 IF SECRET MOD 2 = 0 THEN PRINT "EVEN NUMBER"; OFF$ ELSE PRINT "ODD NUMBER"; OFF$
3125 RETURN
3200 REM LEVEL 2 HINTS - DIGIT CLUES
3205 SECRET$ = STR$(SECRET): IF LEFT$(SECRET$, 1) = " " THEN SECRET$ = RIGHT$(SECRET$, LEN(SECRET$) - 1)
3210 PRINT YELLOW$; "DIGIT HINT: ";
3215 IF LEN(SECRET$) = 1 THEN PRINT "SINGLE DIGIT"; OFF$: RETURN
3220 DIGIT_SUM = VAL(LEFT$(SECRET$, 1)) + VAL(RIGHT$(SECRET$, 1))
3225 PRINT "DIGITS ADD TO"; DIGIT_SUM; OFF$
3230 RETURN
3300 REM LEVEL 3 HINTS - SPECIFIC
3305 PRINT YELLOW$; "SPECIFIC HINT: ";
3310 SECRET$ = STR$(SECRET): IF LEFT$(SECRET$, 1) = " " THEN SECRET$ = RIGHT$(SECRET$, LEN(SECRET$) - 1)
3315 PRINT "STARTS WITH"; LEFT$(SECRET$, 1); OFF$
3320 RETURN
3400 REM LEVEL 4 HINTS - VERY SPECIFIC
3405 RANGE_SIZE = 5
3410 LOWER = SECRET - RANGE_SIZE: IF LOWER < 1 THEN LOWER = 1
3415 UPPER = SECRET + RANGE_SIZE: IF UPPER > 100 THEN UPPER = 100
3420 PRINT YELLOW$; "EXACT RANGE:"; LOWER; "TO"; UPPER; OFF$
3425 RETURN
```
</TryItNow>

**Professional Features:**
- **Guess history tracking** to analyze player behavior
- **Proximity feedback** (very close, getting warmer)
- **Player strategy detection** (systematic vs struggling)
- **Multi-level adaptive hints** that escalate intelligently
