## Beyond INPUT: The GET Statement

So far we've used INPUT, which waits for the user to type and press ENTER. But what if we want instant responses? That's where GET comes in - it reads single keypresses immediately:

<TryItNow>
```basic
10 REM SMART INPUT - GET DEMONSTRATION
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "INSTANT INPUT DEMO"; OFF$
35 PRINT STRING$(30, "─")
40 PRINT "PRESS ANY KEY (ESC TO QUIT):"
45 PRINT
50 GET KEY$
55 IF KEY$ = "" THEN 50 REM WAIT FOR KEYPRESS
60 IF KEY$ = CHR$(27) THEN 100 REM ESC KEY
65 PRINT "YOU PRESSED: '"; KEY$; "' (ASCII"; ASC(KEY$); ")"
70 IF KEY$ >= "A" AND KEY$ <= "Z" THEN PRINT GREEN$; "LETTER!"; OFF$
75 IF KEY$ >= "0" AND KEY$ <= "9" THEN PRINT YELLOW$; "NUMBER!"; OFF$
80 IF KEY$ = CHR$(13) THEN PRINT PURPLE$; "ENTER KEY!"; OFF$
85 IF KEY$ = " " THEN PRINT WHITE$; "SPACE BAR!"; OFF$
90 PRINT: GOTO 40
100 PRINT RED$; "GOODBYE!"; OFF$
105 END
```
</TryItNow>

**How GET Works:**
- **Line 50-55:** GET KEY$ reads one character, or returns "" if no key is pressed
- **Line 60:** CHR$(27) is the ESC key code
- **Lines 70-85:** We can instantly analyze what type of key was pressed
- **No ENTER required** - responses are immediate!

<InfoBox>
The GET statement is perfect for menus, confirmations, and action games. Unlike INPUT, it doesn't echo the character to screen or wait for ENTER, giving you complete control over the user experience.
</InfoBox>

## Professional Menu Interface

Let's upgrade our game menu with instant key responses:

<TryItNow>
```basic
10 REM PROFESSIONAL MENU WITH GET
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 DIFFICULTY = 2 REM DEFAULT
30 GOSUB 1000 REM SHOW MENU
35 GOSUB 2000 REM HANDLE INPUT
40 IF CHOICE$ <> "P" THEN 30
45 PRINT "STARTING GAME...": END
1000 REM DISPLAY MENU
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "    ★ GUESSING CHAMPIONSHIP ★"; OFF$
1015 PRINT STRING$(40, "─")
1020 PRINT
1025 PRINT "DIFFICULTY: ";
1030 IF DIFFICULTY = 1 THEN PRINT GREEN$; "EASY"; OFF$
1035 IF DIFFICULTY = 2 THEN PRINT YELLOW$; "MEDIUM"; OFF$
1040 IF DIFFICULTY = 3 THEN PRINT RED$; "HARD"; OFF$
1045 IF DIFFICULTY = 4 THEN PRINT PURPLE$; "EXPERT"; OFF$
1050 PRINT
1055 PRINT "[1-4] CHANGE DIFFICULTY"
1060 PRINT "[P] PLAY GAME"
1065 PRINT "[Q] QUIT"
1070 PRINT
1075 PRINT "SELECT: ";
1080 RETURN
2000 REM HANDLE MENU INPUT
2005 GET CHOICE$
2010 IF CHOICE$ = "" THEN 2005
2015 IF CHOICE$ = "1" THEN DIFFICULTY = 1: RETURN
2020 IF CHOICE$ = "2" THEN DIFFICULTY = 2: RETURN
2025 IF CHOICE$ = "3" THEN DIFFICULTY = 3: RETURN
2030 IF CHOICE$ = "4" THEN DIFFICULTY = 4: RETURN
2035 IF CHOICE$ = "P" OR CHOICE$ = "p" THEN RETURN
2040 IF CHOICE$ = "Q" OR CHOICE$ = "q" THEN END
2045 REM INVALID KEY - BEEP AND CONTINUE
2050 PRINT CHR$(7); REM BELL CHARACTER
2055 GOTO 2005
```
</TryItNow>

**Professional Features:**
- **Instant response** - no waiting for ENTER
- **Live updates** - difficulty changes immediately
- **Error handling** - invalid keys trigger a beep (CHR$(7))
- **Case insensitive** - accepts both P and p

## Input Validation and Safety

Let's add sophisticated input validation to our number guessing:

<TryItNow>
```basic
10 REM SMART NUMBER INPUT
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT "ENTER A NUMBER (1-100):"
35 NUMBER$ = "": CURSOR = 1
40 PRINT "NUMBER: "; NUMBER$; "_"
45 GET KEY$
50 IF KEY$ = "" THEN 45
55 REM HANDLE BACKSPACE
60 IF KEY$ = CHR$(20) AND LEN(NUMBER$) > 0 THEN NUMBER$ = LEFT$(NUMBER$, LEN(NUMBER$) - 1): GOTO 90
65 REM HANDLE ENTER
70 IF KEY$ = CHR$(13) AND NUMBER$ <> "" THEN 100
75 REM HANDLE NUMBERS ONLY
80 IF KEY$ >= "0" AND KEY$ <= "9" AND LEN(NUMBER$) < 3 THEN NUMBER$ = NUMBER$ + KEY$: GOTO 90
85 REM INVALID INPUT - BEEP
90 PRINT CHR$(19); REM CURSOR UP
95 GOTO 40
100 REM VALIDATE RANGE
105 NUM = VAL(NUMBER$)
110 IF NUM < 1 OR NUM > 100 THEN PRINT RED$; "MUST BE 1-100!"; OFF$: GOTO 35
115 PRINT GREEN$; "YOU ENTERED:"; NUM; OFF$
120 END
```
</TryItNow>

**Advanced Input Features:**
- **Character filtering** - only allows digits
- **Length limiting** - maximum 3 characters
- **Backspace support** - CHR$(20) for corrections
- **Live display** - shows input as you type
- **Range validation** - ensures valid numbers
