# Pretty Display

## The Art of Screen Layout

Right now, our game just dumps text onto the screen wherever it feels like it. But professional games organize their information into clear, readable layouts. Let's upgrade our guessing game:

<TryItNow>
```basic
10 REM PRETTY DISPLAY - FORMATTED GAME
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0
30 REM DRAW GAME HEADER
35 PRINT CHR$(147) REM CLEAR SCREEN
40 PRINT "**** NUMBER GUESSING GAME ****"
45 PRINT "=============================="
50 PRINT "I'M THINKING OF A NUMBER 1-100"
55 PRINT
60 REM MAIN GAME LOOP
65 PRINT "ATTEMPT #"; TRIES + 1
70 PRINT STRING$(30, "-")
75 INPUT "YOUR GUESS"; GUESS
80 TRIES = TRIES + 1
85 IF GUESS = SECRET THEN 200
90 IF GUESS < SECRET THEN 150
95 IF GUESS > SECRET THEN 170
100 GOTO 65
145 REM TOO LOW BRANCH
150 HINT_COUNT = HINT_COUNT + 1
155 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
160 READ HINT$
165 PRINT ">> TOO LOW! "; HINT$: PRINT: GOTO 65
170 REM TOO HIGH BRANCH
175 HINT_COUNT = HINT_COUNT + 1
180 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
185 read HINT$
190 PRINT ">> TOO HIGH! "; HINT$: PRINT: GOTO 65
195 REM WIN CONDITION
200 PRINT STRING$(30, "=")
205 PRINT "** CONGRATULATIONS! **"
210 PRINT "THE NUMBER WAS"; SECRET
215 PRINT "YOU SOLVED IT IN"; TRIES; "ATTEMPTS!"
220 PRINT STRING$(30, "=")
225 END
```
</TryItNow>

Look at all the visual improvements we've added:

**Line 35:** CHR$(147) is the C64 code for "clear screen" - it wipes the screen clean for a fresh start.

**Lines 40-50:** A proper game header with title, border, and instructions. This immediately tells the player what they're doing.

**Lines 65-70:** Before each guess, we show the attempt number and draw a separator line with dashes.

**Line 70:** STRING$(30, "-") creates a string of 30 dashes. It's like typing 30 dashes by hand, but much faster!

**Lines 200-225:** A celebration screen with borders and organized information when the player wins.

<InfoBox>
Notice how we use ">>" to make our feedback messages stand out. Visual cues like this help players quickly identify different types of information - instructions vs. feedback vs. results.
</InfoBox>

## Advanced Positioning with TAB

Let's make our display even more professional by using TAB to position text precisely:

<TryItNow>
```basic
10 REM ADVANCED DISPLAY - WITH TAB POSITIONING
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0: BEST_SCORE = 999
30 REM DRAW GAME SCREEN
35 PRINT CHR$(147) REM CLEAR SCREEN
40 PRINT TAB(6); "**** NUMBER GUESSING GAME ****"
45 PRINT TAB(6); "=============================="
50 PRINT TAB(8); "RANGE: 1 TO 100"
52 PRINT TAB(8); "BEST SCORE:"; BEST_SCORE
55 PRINT
60 REM STATUS LINE
65 PRINT TAB(2); "ATTEMPT:"; TAB(12); TRIES + 1; TAB(20); "LAST GUESS:"; TAB(32); "---"
70 PRINT STRING$(40, "-")
75 INPUT "ENTER YOUR GUESS"; GUESS
80 TRIES = TRIES + 1
85 REM UPDATE STATUS LINE
87 PRINT CHR$(19); CHR$(19); REM CURSOR UP 2 LINES
90 PRINT TAB(2); "ATTEMPT:"; TAB(12); TRIES; TAB(20); "LAST GUESS:"; TAB(32); GUESS
95 PRINT STRING$(40, "-")
100 IF GUESS = SECRET THEN 200
105 IF GUESS < SECRET THEN 150
110 IF GUESS > SECRET THEN 170
115 GOTO 75
150 REM TOO LOW BRANCH
155 HINT_COUNT = HINT_COUNT + 1
160 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
165 READ HINT$
170 PRINT "FEEDBACK: TOO LOW! "; HINT$: PRINT: GOTO 75
175 REM TOO HIGH BRANCH
180 HINT_COUNT = HINT_COUNT + 1
185 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
190 read HINT$
195 PRINT "FEEDBACK: TOO HIGH! "; HINT$: PRINT: GOTO 75
200 REM WIN CONDITION
205 PRINT "FEEDBACK: PERFECT! YOU GOT IT!"
210 IF TRIES < BEST_SCORE THEN BEST_SCORE = TRIES
215 PRINT: PRINT "THE NUMBER WAS"; SECRET
220 PRINT "YOUR SCORE:"; TRIES; "ATTEMPTS!"
225 IF TRIES <= 6 THEN PRINT "EXCELLENT GUESSING!"
230 END
```
</TryItNow>

**TAB(X)** moves the cursor to column X before printing. This lets us create organized, table-like layouts.

**Lines 87-90:** We use CHR$(19) (cursor up) to go back and update the status line with the latest information.

**Line 210:** We track the best score and update it when the player does better.
