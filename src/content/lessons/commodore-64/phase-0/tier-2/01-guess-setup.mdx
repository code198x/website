# Guess Setup

**Time to build something that fights back! Let's create a game where the C64 picks a secret number and challenges you to guess it.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={17} />

## The Magic of Random Numbers

In our cave exploration, we made choices that led to different outcomes. But what if the computer could make its own choices? That's where random numbers come in - they let the C64 surprise us!

<TryItNow>
```basic
10 REM GUESS SETUP - OUR FIRST GAME
20 SECRET = INT(RND(1)*100) + 1
30 TRIES = 0
40 PRINT "I'M THINKING OF A NUMBER FROM 1 TO 100"
50 PRINT "CAN YOU GUESS IT?"
```
</TryItNow>

Let's break down what's happening in line 20 - it's doing a lot of work!

**RND(1)** generates a random decimal between 0 and 1 (like 0.3847 or 0.8921)
**RND(1)*100** multiplies that by 100 (now it's 38.47 or 89.21)
**INT(...)** chops off the decimal part (38 or 89)
**... + 1** adds 1 to make it 1-100 instead of 0-99 (39 or 90)

<InfoBox>
The number 1 in RND(1) is called a "seed." It tells the C64 to use the current time to make truly random numbers. Without it, you'd get the same sequence every time!
</InfoBox>

In line 30, we initialize TRIES to 0. This will count how many guesses the player makes. Starting variables at known values is crucial - otherwise, the C64 might use whatever random junk was in that memory location!
