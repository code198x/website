# Data Arrays

**Unlock the power of organized memory! Arrays let us store multiple values, track player behavior, and create sophisticated data analysis systems.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={29} />

## Beyond Single Variables

So far we've used individual variables like SECRET, TRIES, and GUESS. But what if we want to remember every guess the player made? That's where arrays come in - they're like filing cabinets for data:

<TryItNow>
```basic
10 REM DATA ARRAYS - BASIC ARRAY USAGE
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 PRINT CHR$(147)
35 PRINT WHITE$; "ARRAY BASICS DEMONSTRATION"; OFF$
40 PRINT STRING$(30, "═")
45 REM DECLARE ARRAYS
50 DIM GUESSES(10) REM STORE UP TO 10 GUESSES
55 DIM RESULTS$(10) REM STORE "HIGH", "LOW", "CORRECT"
60 GUESS_COUNT = 0
65 PRINT "ARRAYS DECLARED:"
70 PRINT "GUESSES(10) - FOR NUMBERS"
75 PRINT "RESULTS$(10) - FOR TEXT"
80 PRINT: PRINT "LET'S FILL THEM WITH SAMPLE DATA:"
85 PRINT STRING$(30, "─")
90 REM FILL ARRAYS WITH SAMPLE DATA
95 FOR I = 1 TO 5
100 GUESS_COUNT = GUESS_COUNT + 1
105 SAMPLE_GUESS = INT(RND(1)*100) + 1
110 GUESSES(I) = SAMPLE_GUESS
115 REM RANDOM RESULT FOR DEMO
120 RESULT_TYPE = INT(RND(1)*3) + 1
125 ON RESULT_TYPE GOTO 130, 135, 140
130 RESULTS$(I) = "HIGH": GOTO 145
135 RESULTS$(I) = "LOW": GOTO 145
140 RESULTS$(I) = "PERFECT"
145 PRINT "GUESS"; I; ":", GUESSES(I), " - ", RESULTS$(I)
150 NEXT I
155 PRINT: PRINT "PRESS ENTER TO SEE ANALYSIS": INPUT A$
160 REM ANALYZE THE DATA
165 GOSUB 1000 REM STATISTICAL ANALYSIS
170 END
1000 REM STATISTICAL ANALYSIS
1005 PRINT CHR$(147)
1010 PRINT YELLOW$; "STATISTICAL ANALYSIS"; OFF$
1015 PRINT STRING$(30, "═")
1020 REM CALCULATE AVERAGE
1025 TOTAL = 0
1030 FOR I = 1 TO GUESS_COUNT
1035 TOTAL = TOTAL + GUESSES(I)
1040 NEXT I
1045 AVERAGE = TOTAL / GUESS_COUNT
1050 PRINT "AVERAGE GUESS:", INT(AVERAGE)
1055 REM FIND HIGHEST AND LOWEST
1060 HIGHEST = GUESSES(1): LOWEST = GUESSES(1)
1065 FOR I = 2 TO GUESS_COUNT
1070 IF GUESSES(I) > HIGHEST THEN HIGHEST = GUESSES(I)
1075 IF GUESSES(I) < LOWEST THEN LOWEST = GUESSES(I)
1080 NEXT I
1085 PRINT "HIGHEST GUESS:", HIGHEST
1090 PRINT "LOWEST GUESS:", LOWEST
1095 PRINT "GUESS RANGE:", HIGHEST - LOWEST
1100 RETURN
```
</TryItNow>

**Array Fundamentals:**
- **Line 50:** DIM GUESSES(10) creates an array with 10 slots numbered 1-10
- **Line 55:** String arrays use $ like RESULTS$(10) for text storage
- **Lines 110-145:** We fill array slots using GUESSES(I) = VALUE
- **Lines 1030-1040:** Loop through arrays to calculate statistics

<InfoBox>
Arrays in C64 BASIC start at index 1, not 0 like some other languages. DIM GUESSES(10) gives you slots numbered 1, 2, 3... up to 10. Think of it like numbered filing cabinet drawers!
</InfoBox>

## Game History Tracking

Let's integrate arrays into a real guessing game to track and analyze every move:

<TryItNow>
```basic
10 REM GAME HISTORY TRACKING
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM DECLARE GAME ARRAYS
35 DIM GUESSES(20), DISTANCES(20)
40 DIM FEEDBACK$(20)
45 SECRET = INT(RND(1)*100) + 1: TRIES = 0
50 PRINT CHR$(147)
55 PRINT WHITE$; "HISTORY TRACKING GUESSING GAME"; OFF$
60 PRINT STRING$(30, "═")
65 PRINT "I'M THINKING OF A NUMBER 1-100"
70 PRINT "EVERY GUESS WILL BE RECORDED AND ANALYZED!"
75 PRINT STRING$(30, "─")
80 REM MAIN GAME LOOP
85 TRIES = TRIES + 1
90 PRINT: PRINT "ATTEMPT"; TRIES
95 INPUT "YOUR GUESS"; GUESS
100 REM STORE IN ARRAYS
105 GUESSES(TRIES) = GUESS
110 DISTANCES(TRIES) = ABS(GUESS - SECRET)
115 IF GUESS = SECRET THEN FEEDBACK$(TRIES) = "CORRECT!": GOTO 200
120 IF GUESS < SECRET THEN FEEDBACK$(TRIES) = "TOO LOW" ELSE FEEDBACK$(TRIES) = "TOO HIGH"
125 PRINT FEEDBACK$(TRIES)
130 REM PROVIDE PROXIMITY FEEDBACK
135 IF DISTANCES(TRIES) <= 5 THEN PRINT GREEN$; "VERY CLOSE!"; OFF$
140 IF DISTANCES(TRIES) > 5 AND DISTANCES(TRIES) <= 15 THEN PRINT YELLOW$; "GETTING WARMER"; OFF$
145 REM CHECK FOR IMPROVEMENT
150 IF TRIES > 1 THEN 160 ELSE GOTO 85
160 IF DISTANCES(TRIES) < DISTANCES(TRIES-1) THEN PRINT PURPLE$; "GETTING CLOSER!"; OFF$
165 IF DISTANCES(TRIES) > DISTANCES(TRIES-1) THEN PRINT RED$; "MOVING AWAY!"; OFF$
170 GOTO 85
200 REM GAME COMPLETE - SHOW ANALYSIS
205 PRINT: PRINT GREEN$; "CONGRATULATIONS!"; OFF$
210 PRINT "THE SECRET WAS"; SECRET
215 PRINT: PRINT "PRESS ENTER FOR DETAILED ANALYSIS": INPUT A$
220 GOSUB 2000 REM DETAILED GAME ANALYSIS
225 END
2000 REM DETAILED GAME ANALYSIS
2005 PRINT CHR$(147)
2010 PRINT WHITE$; "GAME ANALYSIS REPORT"; OFF$
2015 PRINT STRING$(30, "═")
2020 PRINT "COMPLETE GUESS HISTORY:"
2025 PRINT STRING$(30, "─")
2030 FOR I = 1 TO TRIES
2035 PRINT "ATTEMPT"; I; ":", GUESSES(I), " - ", FEEDBACK$(I), " (OFF BY"; DISTANCES(I); ")"
2040 NEXT I
2045 PRINT STRING$(30, "─")
2050 REM STATISTICAL SUMMARY
2055 PRINT: PRINT YELLOW$; "STATISTICAL SUMMARY:"; OFF$
2060 TOTAL_DISTANCE = 0: CLOSEST = DISTANCES(1): FURTHEST = DISTANCES(1)
2065 FOR I = 1 TO TRIES
2070 TOTAL_DISTANCE = TOTAL_DISTANCE + DISTANCES(I)
2075 IF DISTANCES(I) < CLOSEST THEN CLOSEST = DISTANCES(I)
2080 IF DISTANCES(I) > FURTHEST THEN FURTHEST = DISTANCES(I)
2085 NEXT I
2090 AVERAGE_ERROR = TOTAL_DISTANCE / TRIES
2095 PRINT "AVERAGE ERROR:", INT(AVERAGE_ERROR)
2100 PRINT "CLOSEST GUESS: OFF BY"; CLOSEST
2105 PRINT "FURTHEST GUESS: OFF BY"; FURTHEST
2110 PRINT "TOTAL ATTEMPTS:"; TRIES
2115 REM STRATEGY ANALYSIS
2120 PRINT: PRINT PURPLE$; "STRATEGY ANALYSIS:"; OFF$
2125 IMPROVEMENTS = 0: WORSENINGS = 0
2130 FOR I = 2 TO TRIES - 1 REM SKIP LAST (CORRECT) GUESS
2135 IF DISTANCES(I) < DISTANCES(I-1) THEN IMPROVEMENTS = IMPROVEMENTS + 1
2140 IF DISTANCES(I) > DISTANCES(I-1) THEN WORSENINGS = WORSENINGS + 1
2145 NEXT I
2150 PRINT "IMPROVING MOVES:"; IMPROVEMENTS
2155 PRINT "WORSENING MOVES:"; WORSENINGS
2160 IF IMPROVEMENTS > WORSENINGS THEN PRINT GREEN$; "GOOD STRATEGY!"; OFF$ ELSE PRINT RED$; "INCONSISTENT STRATEGY"; OFF$
2165 RETURN
```
</TryItNow>

**Advanced Array Features:**
- **Lines 105-110:** Store guess, distance, and feedback simultaneously
- **Lines 160-165:** Compare current attempt with previous using array indexing
- **Lines 2030-2040:** Review complete game history from stored data
- **Lines 2135-2145:** Analyze strategy patterns using historical comparisons

## Multi-Game Statistics

Let's create a system that tracks statistics across multiple games using arrays:

<TryItNow>
```basic
10 REM MULTI-GAME STATISTICS TRACKER
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM STATISTICS ARRAYS
35 DIM GAME_TRIES(10), GAME_SECRETS(10), GAME_TIME(10)
40 DIM PLAYER_NAMES$(10)
45 TOTAL_GAMES = 0
50 PRINT CHR$(147)
55 PRINT WHITE$; "MULTI-GAME STATISTICS SYSTEM"; OFF$
60 PRINT STRING$(30, "═")
65 REM MAIN MENU
70 PRINT: PRINT YELLOW$; "STATISTICS TRACKER MENU:"; OFF$
75 PRINT "1 - PLAY NEW GAME"
80 PRINT "2 - VIEW STATISTICS"
85 PRINT "3 - PLAYER RANKINGS"
90 PRINT "9 - QUIT"
95 PRINT: INPUT "YOUR CHOICE"; CHOICE
100 ON CHOICE GOSUB 1000, 2000, 3000
105 IF CHOICE = 9 THEN END
110 GOTO 65
1000 REM PLAY NEW GAME
1005 IF TOTAL_GAMES >= 10 THEN PRINT RED$; "MAXIMUM 10 GAMES REACHED!"; OFF$: RETURN
1010 TOTAL_GAMES = TOTAL_GAMES + 1
1015 GAME_INDEX = TOTAL_GAMES
1020 PRINT: INPUT "PLAYER NAME"; PLAYER_NAMES$(GAME_INDEX)
1025 SECRET = INT(RND(1)*100) + 1: TRIES = 0
1030 START_TIME = TI
1035 PRINT: PRINT "GAME"; GAME_INDEX; "- FIND THE NUMBER 1-100!"
1040 REM SIMPLIFIED GAME LOOP
1045 TRIES = TRIES + 1: INPUT "GUESS"; GUESS
1050 IF GUESS = SECRET THEN 1070
1055 IF GUESS < SECRET THEN PRINT "TOO LOW!" ELSE PRINT "TOO HIGH!"
1060 GOTO 1045
1070 REM STORE GAME RESULTS
1075 GAME_TRIES(GAME_INDEX) = TRIES
1080 GAME_SECRETS(GAME_INDEX) = SECRET
1085 GAME_TIME(GAME_INDEX) = INT((TI - START_TIME) / 60)
1090 PRINT GREEN$; "CORRECT IN"; TRIES; "TRIES!"; OFF$
1095 PRINT "GAME DATA SAVED!"
1100 RETURN
2000 REM VIEW STATISTICS
2005 IF TOTAL_GAMES = 0 THEN PRINT RED$; "NO GAMES PLAYED YET!"; OFF$: RETURN
2010 PRINT CHR$(147)
2015 PRINT WHITE$; "GAME STATISTICS SUMMARY"; OFF$
2020 PRINT STRING$(30, "═")
2025 FOR I = 1 TO TOTAL_GAMES
2030 PRINT "GAME"; I; ":", PLAYER_NAMES$(I)
2035 PRINT "  SECRET:"; GAME_SECRETS(I); " TRIES:"; GAME_TRIES(I); " TIME:"; GAME_TIME(I); "SEC"
2040 NEXT I
2045 PRINT STRING$(30, "─")
2050 REM CALCULATE AVERAGES
2055 TOTAL_TRIES = 0: TOTAL_TIME = 0
2060 FOR I = 1 TO TOTAL_GAMES
2065 TOTAL_TRIES = TOTAL_TRIES + GAME_TRIES(I)
2070 TOTAL_TIME = TOTAL_TIME + GAME_TIME(I)
2075 NEXT I
2080 AVG_TRIES = TOTAL_TRIES / TOTAL_GAMES
2085 AVG_TIME = TOTAL_TIME / TOTAL_GAMES
2090 PRINT YELLOW$; "AVERAGES:"; OFF$
2095 PRINT "TRIES PER GAME:", INT(AVG_TRIES)
2100 PRINT "TIME PER GAME:", INT(AVG_TIME); "SECONDS"
2105 PRINT: PRINT "PRESS ENTER": INPUT A$
2110 RETURN
3000 REM PLAYER RANKINGS
3005 IF TOTAL_GAMES = 0 THEN PRINT RED$; "NO GAMES TO RANK!"; OFF$: RETURN
3010 PRINT CHR$(147)
3015 PRINT WHITE$; "PLAYER RANKINGS"; OFF$
3020 PRINT STRING$(30, "═")
3025 REM SIMPLE BUBBLE SORT BY TRIES
3030 FOR I = 1 TO TOTAL_GAMES - 1
3035 FOR J = I + 1 TO TOTAL_GAMES
3040 IF GAME_TRIES(I) > GAME_TRIES(J) THEN GOSUB 3100
3045 NEXT J, I
3050 REM DISPLAY RANKINGS
3055 PRINT YELLOW$; "RANKINGS (FEWEST TRIES WINS):"; OFF$
3060 FOR I = 1 TO TOTAL_GAMES
3065 PRINT I; ".", PLAYER_NAMES$(I), " - ", GAME_TRIES(I), "TRIES"
3070 NEXT I
3075 PRINT: PRINT "PRESS ENTER": INPUT A$
3080 RETURN
3100 REM SWAP ARRAY ELEMENTS
3105 TEMP = GAME_TRIES(I): GAME_TRIES(I) = GAME_TRIES(J): GAME_TRIES(J) = TEMP
3110 TEMP = GAME_SECRETS(I): GAME_SECRETS(I) = GAME_SECRETS(J): GAME_SECRETS(J) = TEMP
3115 TEMP = GAME_TIME(I): GAME_TIME(I) = GAME_TIME(J): GAME_TIME(J) = TEMP
3120 TEMP$ = PLAYER_NAMES$(I): PLAYER_NAMES$(I) = PLAYER_NAMES$(J): PLAYER_NAMES$(J) = TEMP$
3125 RETURN
```
</TryItNow>

**Multi-Game Features:**
- **Lines 35-45:** Parallel arrays store related data across multiple games
- **Lines 1075-1085:** Store complete game results in arrays
- **Lines 3030-3045:** Bubble sort algorithm to rank players
- **Lines 3100-3125:** Swap subroutine maintains data relationships
