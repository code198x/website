# Guess Logic

**Now we make the game come alive! Time to add the guessing loop that turns static code into an interactive experience.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={18} />

## Building the Game Loop

A game needs to keep running until something happens - a win, a loss, or the player gives up. That's where the game loop comes in. Let's extend our number guessing setup:

<TryItNow>
```basic
10 REM GUESS LOGIC - THE COMPLETE GAME
20 SECRET = INT(RND(1)*100) + 1
30 TRIES = 0
40 PRINT "I'M THINKING OF A NUMBER FROM 1 TO 100"
50 PRINT "CAN YOU GUESS IT?"
60 REM MAIN GAME LOOP STARTS HERE
70 PRINT
80 INPUT "ENTER YOUR GUESS"; GUESS
90 TRIES = TRIES + 1
100 IF GUESS = SECRET THEN 200
110 IF GUESS < SECRET THEN PRINT "TOO LOW!"
120 IF GUESS > SECRET THEN PRINT "TOO HIGH!"
130 GOTO 70
140 REM WIN CONDITION
200 PRINT "YES! YOU GOT IT IN"; TRIES; "TRIES!"
210 END
```
</TryItNow>

Let's walk through the exciting new parts:

**Lines 70-80:** The loop begins! We ask for the player's guess and store it in the GUESS variable.

**Line 90:** Every time through the loop, we increment TRIES. This counts how many attempts the player has made.

**Lines 100-120:** The heart of the game! Three IF statements that check:
- Is the guess exactly right? Jump to the win condition (line 200)
- Is the guess too low? Tell the player
- Is the guess too high? Tell the player

**Line 130:** The magic GOTO that sends us back to line 70. This creates the loop that keeps the game running until the player wins.

<InfoBox>
Notice we use separate IF statements instead of IF-ELSE-IF. BASIC requires this approach, and it makes each condition crystal clear. The program flows naturally from one check to the next.
</InfoBox>

## The Flow of Control

This is your first taste of **control flow** - making the program jump around based on conditions. The GOTO on line 130 creates what programmers call a "loop" - code that repeats until something changes.

When the player guesses correctly, line 100 jumps straight to line 200, skipping the rest of the loop entirely. That's the beauty of structured jumps - they let you escape when the job is done!
