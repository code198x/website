## The Magic of Motion

Static text is boring. But add movement, and suddenly your program feels professional and engaging. Let's start with the classic "thinking" animation:

<TryItNow>
```basic
10 REM VISUAL ANIMATION - THINKING CURSOR
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 PRINT CHR$(147)
35 PRINT WHITE$; "ANIMATED THINKING DEMO"; OFF$
40 PRINT STRING$(30, "═")
45 PRINT "WATCH THE COMPUTER 'THINK'!"
50 PRINT: PRINT "GENERATING SECRET NUMBER";
55 REM ANIMATED THINKING SEQUENCE
60 FOR THINK = 1 TO 30
65 PRINT ".";
70 FOR DELAY = 1 TO 100: NEXT DELAY REM SLOW DOWN
75 NEXT THINK
80 PRINT: PRINT GREEN$; "DONE!"; OFF$
85 PRINT: PRINT "NOW WITH MOVING CURSOR ANIMATION:"
90 PRINT: PRINT "COMPUTER IS THINKING";
95 REM MOVING CURSOR ANIMATION
100 CURSOR_POS = 20: DIRECTION = 1
105 FOR THINK = 1 TO 50
110 REM MOVE CURSOR TO POSITION
115 PRINT CHR$(19); REM CURSOR UP
120 PRINT TAB(CURSOR_POS); "|"
125 REM UPDATE CURSOR POSITION
130 CURSOR_POS = CURSOR_POS + DIRECTION
135 IF CURSOR_POS > 35 THEN DIRECTION = -1
140 IF CURSOR_POS < 20 THEN DIRECTION = 1
145 REM DELAY FOR VISIBLE MOVEMENT
150 FOR DELAY = 1 TO 80: NEXT DELAY
155 NEXT THINK
160 PRINT CHR$(19); REM CURSOR UP
165 PRINT TAB(20); YELLOW$; "READY TO PLAY!"; OFF$
170 END
```
</TryItNow>

**Animation Techniques:**
- **Lines 60-75:** Simple dot progression creates anticipation
- **Lines 105-155:** Moving cursor bounces back and forth
- **Line 115:** CHR$(19) moves cursor up to overwrite previous position
- **Lines 130-140:** Direction reversal creates smooth bouncing motion

<InfoBox>
CHR$(19) is the "cursor up" control character. By printing it, then using TAB to position our cursor, we can overwrite the previous frame of animation. This is the foundation of all text-mode animation on the C64!
</InfoBox>

## Animated Feedback Systems

Let's create sophisticated animated feedback that responds to player actions:

<TryItNow>
```basic
10 REM ANIMATED FEEDBACK SYSTEMS
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 SECRET = INT(RND(1)*100) + 1: TRIES = 0
35 PRINT CHR$(147)
40 PRINT WHITE$; "ANIMATED GUESSING GAME"; OFF$
45 PRINT STRING$(30, "═")
50 PRINT "FIND THE SECRET NUMBER (1-100)"
55 PRINT "WATCH FOR ANIMATED CLUES!"
60 PRINT STRING$(30, "─")
65 REM MAIN GAME LOOP
70 TRIES = TRIES + 1
75 PRINT: PRINT "ATTEMPT"; TRIES; ": ";
80 INPUT GUESS
85 IF GUESS = SECRET THEN 500
90 REM ANIMATED ANALYSIS
95 PRINT: PRINT YELLOW$; "ANALYZING YOUR GUESS";
100 GOSUB 1000 REM THINKING ANIMATION
105 PRINT OFF$
110 REM CALCULATE DIFFERENCE
115 DIFF = ABS(GUESS - SECRET)
120 IF GUESS < SECRET THEN 200 ELSE 300
200 REM TOO LOW - ANIMATED ARROW
205 PRINT: PRINT RED$; "TOO LOW!"; OFF$
210 PRINT "DIRECTION: ";
215 FOR ARROW = 1 TO 5
220 PRINT "↑";
225 FOR DELAY = 1 TO 150: NEXT DELAY
230 NEXT ARROW
235 GOTO 400
300 REM TOO HIGH - ANIMATED ARROW
305 PRINT: PRINT PURPLE$; "TOO HIGH!"; OFF$
310 PRINT "DIRECTION: ";
315 FOR ARROW = 1 TO 5
320 PRINT "↓";
325 FOR DELAY = 1 TO 150: NEXT DELAY
330 NEXT ARROW
335 GOTO 400
400 REM PROXIMITY ANIMATION
405 PRINT: PRINT "PROXIMITY: ";
410 IF DIFF <= 5 THEN GOSUB 2000: GOTO 70 REM VERY CLOSE
415 IF DIFF <= 15 THEN GOSUB 2100: GOTO 70 REM CLOSE
420 IF DIFF <= 30 THEN GOSUB 2200: GOTO 70 REM MEDIUM
425 GOSUB 2300: GOTO 70 REM FAR
500 REM VICTORY ANIMATION
505 PRINT: PRINT GREEN$; "CORRECT!"; OFF$
510 GOSUB 3000 REM CELEBRATION ANIMATION
515 END
1000 REM THINKING ANIMATION
1005 FOR I = 1 TO 8
1010 PRINT ".";
1015 FOR DELAY = 1 TO 200: NEXT DELAY
1020 NEXT I
1025 RETURN
2000 REM VERY CLOSE ANIMATION - FAST FLASH
2005 FOR FLASH = 1 TO 10
2010 PRINT GREEN$; "█";
2015 FOR DELAY = 1 TO 50: NEXT DELAY
2020 PRINT CHR$(20); " "; CHR$(20); REM BACKSPACE AND CLEAR
2025 FOR DELAY = 1 TO 50: NEXT DELAY
2030 NEXT FLASH
2035 PRINT OFF$: RETURN
2100 REM CLOSE ANIMATION - MEDIUM FLASH
2105 FOR FLASH = 1 TO 6
2110 PRINT YELLOW$; "▓";
2115 FOR DELAY = 1 TO 100: NEXT DELAY
2120 PRINT CHR$(20); " "; CHR$(20)
2125 FOR DELAY = 1 TO 100: NEXT DELAY
2130 NEXT FLASH
2135 PRINT OFF$: RETURN
2200 REM MEDIUM ANIMATION - SLOW PULSE
2205 FOR PULSE = 1 TO 4
2210 PRINT WHITE$; "▒";
2215 FOR DELAY = 1 TO 200: NEXT DELAY
2220 PRINT CHR$(20); " "; CHR$(20)
2225 FOR DELAY = 1 TO 200: NEXT DELAY
2230 NEXT PULSE
2235 PRINT OFF$: RETURN
2300 REM FAR ANIMATION - SINGLE DOT
2305 PRINT RED$; "•"; OFF$
2310 RETURN
3000 REM CELEBRATION ANIMATION
3005 FOR PARTY = 1 TO 20
3010 COLOR = INT(RND(1)*6) + 1
3015 ON COLOR GOTO 3020, 3025, 3030, 3035, 3040, 3045
3020 PRINT CHR$(28);: GOTO 3050 REM RED
3025 PRINT CHR$(30);: GOTO 3050 REM GREEN
3030 PRINT CHR$(156);: GOTO 3050 REM PURPLE
3035 PRINT CHR$(158);: GOTO 3050 REM YELLOW
3040 PRINT CHR$(5);: GOTO 3050 REM WHITE
3045 PRINT CHR$(159); REM OFF
3050 PRINT "★";
3055 FOR DELAY = 1 TO 100: NEXT DELAY
3060 NEXT PARTY
3065 PRINT OFF$: RETURN
```
</TryItNow>

**Advanced Animation Features:**
- **Lines 1000-1025:** Thinking dots create suspense during analysis
- **Lines 2000-2300:** Different animations for different proximity levels
- **Lines 2015-2025:** Flashing effect using backspace and overwrite
- **Lines 3000-3065:** Random colored celebration with varying effects

## Professional Loading Animations

Let's create the kind of sophisticated loading animations that made commercial software feel professional:

<TryItNow>
```basic
10 REM PROFESSIONAL LOADING ANIMATIONS
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 PRINT CHR$(147)
35 PRINT WHITE$; "PROFESSIONAL ANIMATION SUITE"; OFF$
40 PRINT STRING$(30, "═")
45 PRINT "1 - PROGRESS BAR DEMO"
50 PRINT "2 - SPINNING CURSOR DEMO"
55 PRINT "3 - WAVE ANIMATION DEMO"
60 PRINT "4 - COMPLETE GAME LOADING"
65 PRINT: INPUT "SELECT DEMO"; CHOICE
70 ON CHOICE GOSUB 1000, 2000, 3000, 4000
75 END
1000 REM PROGRESS BAR ANIMATION
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "PROGRESS BAR DEMO"; OFF$
1015 PRINT STRING$(30, "─")
1020 PRINT: PRINT "LOADING GAME DATA..."
1025 PRINT "["; TAB(31); "]"
1030 FOR PROGRESS = 1 TO 28
1035 PRINT CHR$(19); REM CURSOR UP
1040 PRINT "["; YELLOW$;
1045 FOR I = 1 TO PROGRESS: PRINT "█";: NEXT I
1050 PRINT OFF$; TAB(31); "]";
1055 PERCENT = INT((PROGRESS / 28) * 100)
1060 PRINT "  "; PERCENT; "%"
1065 FOR DELAY = 1 TO 300: NEXT DELAY
1070 NEXT PROGRESS
1075 PRINT: PRINT GREEN$; "LOADING COMPLETE!"; OFF$
1080 RETURN
2000 REM SPINNING CURSOR ANIMATION
2005 PRINT CHR$(147)
2010 PRINT WHITE$; "SPINNING CURSOR DEMO"; OFF$
2015 PRINT STRING$(30, "─")
2020 PRINT: PRINT "PROCESSING DATA ";
2025 DIM SPINNER$(4)
2030 SPINNER$(1) = "|": SPINNER$(2) = "/": SPINNER$(3) = "-": SPINNER$(4) = "\"
2035 FOR SPIN = 1 TO 40
2040 FRAME = (SPIN MOD 4) + 1
2045 PRINT CHR$(20); SPINNER$(FRAME);
2050 FOR DELAY = 1 TO 200: NEXT DELAY
2055 NEXT SPIN
2060 PRINT CHR$(20); GREEN$; "DONE!"; OFF$
2065 RETURN
3000 REM WAVE ANIMATION
3005 PRINT CHR$(147)
3010 PRINT WHITE$; "WAVE ANIMATION DEMO"; OFF$
3015 PRINT STRING$(30, "─")
3020 PRINT: PRINT "WAVE EFFECT:"
3025 FOR WAVE = 1 TO 15
3030 PRINT
3035 FOR X = 1 TO 35
3040 HEIGHT = INT(SIN(X/5 + WAVE/3) * 3) + 4
3045 PRINT TAB(X); PURPLE$; CHR$(HEIGHT + 160);
3050 NEXT X
3055 PRINT OFF$
3060 FOR DELAY = 1 TO 200: NEXT DELAY
3065 REM CLEAR WAVE
3070 FOR CLEAR = 1 TO 8: PRINT CHR$(19);: NEXT CLEAR
3075 NEXT WAVE
3080 RETURN
4000 REM COMPLETE GAME LOADING SEQUENCE
4005 PRINT CHR$(147)
4010 PRINT WHITE$; "GUESSING CHAMPIONSHIP"; OFF$
4015 PRINT STRING$(30, "═")
4020 PRINT: PRINT YELLOW$; "INITIALIZING GAME ENGINE..."; OFF$
4025 GOSUB 4500 REM DOTS ANIMATION
4030 PRINT: PRINT YELLOW$; "LOADING DIFFICULTY SETTINGS..."; OFF$
4035 GOSUB 4600 REM PROGRESS BAR
4040 PRINT: PRINT YELLOW$; "PREPARING RANDOM NUMBER GENERATOR..."; OFF$
4045 GOSUB 4700 REM SPINNER
4050 PRINT: PRINT YELLOW$; "ACTIVATING HINT SYSTEM..."; OFF$
4055 GOSUB 4500 REM DOTS AGAIN
4060 PRINT: PRINT: PRINT GREEN$; "★ READY TO PLAY! ★"; OFF$
4065 PRINT: PRINT "PRESS ENTER TO BEGIN": INPUT A$
4070 RETURN
4500 REM DOTS LOADING ANIMATION
4505 FOR DOT = 1 TO 10
4510 PRINT ".";
4515 FOR DELAY = 1 TO 150: NEXT DELAY
4520 NEXT DOT
4525 RETURN
4600 REM MINI PROGRESS BAR
4605 PRINT "["; TAB(21); "]"
4610 FOR P = 1 TO 18
4615 PRINT CHR$(19); "["; GREEN$;
4620 FOR I = 1 TO P: PRINT "▓";: NEXT I
4625 PRINT OFF$; TAB(21); "]"
4630 FOR DELAY = 1 TO 100: NEXT DELAY
4635 NEXT P
4640 RETURN
4700 REM MINI SPINNER
4705 DIM SPIN$(4)
4710 SPIN$(1) = "|": SPIN$(2) = "/": SPIN$(3) = "-": SPIN$(4) = "\"
4715 FOR S = 1 TO 20
4720 FRAME = (S MOD 4) + 1
4725 PRINT CHR$(20); PURPLE$; SPIN$(FRAME); OFF$;
4730 FOR DELAY = 1 TO 150: NEXT DELAY
4735 NEXT S
4740 PRINT CHR$(20); " ";
4745 RETURN
```
</TryItNow>

**Professional Animation Features:**
- **Lines 1000-1080:** Smooth progress bar with percentage display
- **Lines 2000-2065:** Classic spinning cursor using array of characters
- **Lines 3000-3080:** Mathematical sine wave animation
- **Lines 4000-4745:** Complete loading sequence combining multiple effects

This creates the polished experience that made users feel like they were running commercial software!
