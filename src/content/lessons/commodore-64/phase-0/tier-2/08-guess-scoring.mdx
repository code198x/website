## The Psychology of Competition

In the 1980s, high scores were serious business. Before online leaderboards or social media, getting your three initials on the high score table was the ultimate achievement. Let's add this competitive element to our game:

<TryItNow>
```basic
10 REM HIGH SCORES - COMPETITIVE GAMING
15 DATA "TRY THE MIDDLE!", "NARROW YOUR RANGE!", "YOU'RE GETTING CLOSE!"
20 REM COLOR CONSTANTS
25 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
30 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
35 REM GAME VARIABLES
40 MAX_RANGE = 100: MAX_TRIES = 20: HINT_MODE = 1
45 SECRET = 0: TRIES = 0: SCORE = 0: BONUS = 0
50 REM HIGH SCORE TABLE
55 DIM NAMES$(5), SCORES(5)
60 FOR I = 1 TO 5: NAMES$(I) = "CPU": SCORES(I) = (6-I) * 1000: NEXT
65 REM MAIN PROGRAM
70 GOSUB 1000 REM MAIN MENU
75 GOSUB 2000 REM PLAY GAME
80 GOSUB 3000 REM CALCULATE SCORE
85 GOSUB 4000 REM CHECK HIGH SCORE
90 GOTO 70
1000 REM MAIN MENU WITH HIGH SCORES
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "    ★ GUESSING CHAMPIONSHIP ★"; OFF$
1015 PRINT STRING$(40, "─")
1020 GOSUB 1500 REM SHOW HIGH SCORES
1025 PRINT STRING$(40, "─")
1030 PRINT YELLOW$; "1"; OFF$; " - ROOKIE    (1-50,  No Limit)"
1035 PRINT YELLOW$; "2"; OFF$; " - AMATEUR   (1-100, 20 Tries)"
1040 PRINT RED$; "3"; OFF$; " - PRO       (1-200, 15 Tries)"
1045 PRINT PURPLE$; "4"; OFF$; " - LEGEND    (1-500, 10 Tries)"
1050 PRINT: PRINT "9 - QUIT": PRINT
1055 INPUT "SELECT (1-4, 9)"; CHOICE
1060 ON CHOICE GOSUB 1100,1200,1300,1400
1065 IF CHOICE = 9 THEN END
1070 IF CHOICE < 1 OR CHOICE > 9 THEN 1055
1075 RETURN
1100 MAX_RANGE=50:MAX_TRIES=999:HINT_MODE=1:DIFFICULTY=1: RETURN
1200 MAX_RANGE=100:MAX_TRIES=20:HINT_MODE=1:DIFFICULTY=2: RETURN
1300 MAX_RANGE=200:MAX_TRIES=15:HINT_MODE=0:DIFFICULTY=3: RETURN
1400 MAX_RANGE=500:MAX_TRIES=10:HINT_MODE=0:DIFFICULTY=4: RETURN
1500 REM DISPLAY HIGH SCORES
1505 PRINT GREEN$; "HIGH SCORES:"; OFF$
1510 FOR I = 1 TO 5
1515 PRINT I; ". "; NAMES$(I); TAB(15); SCORES(I)
1520 NEXT I
1525 RETURN
2000 REM SIMPLIFIED GAME (PLACEHOLDER)
2005 PRINT: PRINT "PRESS ENTER TO START!": INPUT A$
2010 SECRET = INT(RND(1)*MAX_RANGE) + 1: TRIES = 0
2015 PRINT "I'M THINKING OF A NUMBER FROM 1 TO"; MAX_RANGE
2020 REM SIMULATE GAME FOR DEMO
2025 TRIES = INT(RND(1) * MAX_TRIES) + 1
2030 PRINT "(DEMO: YOU GUESSED IT IN"; TRIES; "TRIES)"
2035 RETURN
3000 REM CALCULATE SCORE
3005 BASE_SCORE = 1000 * DIFFICULTY
3010 SPEED_BONUS = (MAX_TRIES - TRIES) * 100
3015 IF TRIES = 1 THEN LUCKY_BONUS = 2000 ELSE LUCKY_BONUS = 0
3020 SCORE = BASE_SCORE + SPEED_BONUS + LUCKY_BONUS
3025 PRINT: PRINT YELLOW$; "SCORE BREAKDOWN:"; OFF$
3030 PRINT "BASE SCORE:"; BASE_SCORE
3035 PRINT "SPEED BONUS:"; SPEED_BONUS; "("; MAX_TRIES - TRIES; "TRIES SAVED)"
3040 IF LUCKY_BONUS > 0 THEN PRINT GREEN$; "FIRST-GUESS BONUS:"; LUCKY_BONUS; OFF$
3045 PRINT WHITE$; "FINAL SCORE:"; SCORE; OFF$
3050 RETURN
4000 REM CHECK FOR HIGH SCORE
4005 FOR I = 5 TO 1 STEP -1
4010 IF SCORE > SCORES(I) THEN 4020
4015 NEXT I: RETURN
4020 PRINT: PRINT GREEN$; "NEW HIGH SCORE!"; OFF$
4025 INPUT "ENTER YOUR INITIALS (3 LETTERS)"; NAME$
4030 IF LEN(NAME$) > 3 THEN NAME$ = LEFT$(NAME$, 3)
4035 REM SHIFT SCORES DOWN
4040 FOR J = 5 TO I + 1 STEP -1
4045 SCORES(J) = SCORES(J-1): NAMES$(J) = NAMES$(J-1)
4050 NEXT J
4055 SCORES(I) = SCORE: NAMES$(I) = NAME$
4060 PRINT YELLOW$; "CONGRATULATIONS "; NAME$; "!"; OFF$
4065 RETURN
```
</TryItNow>

Look at all the competitive elements we've added:

**Lines 55-60:** We create arrays to store high scores and player initials, with default "CPU" scores to beat

**Lines 3005-3020:** A sophisticated scoring formula that rewards both difficulty level and efficiency

**Lines 4005-4065:** High score checking and insertion logic that maintains the leaderboard

<InfoBox>
Notice how we use STEP -1 in the high score check (line 4005)? This checks from the lowest score upward, so when we find where the new score belongs, we can insert it in the right position and shift everything else down.
</InfoBox>

## Advanced Scoring Psychology

Let's add even more competitive elements with different types of achievements:

<TryItNow>
```basic
10 REM ADVANCED SCORING WITH ACHIEVEMENTS
15 DATA "TRY THE MIDDLE!", "NARROW YOUR RANGE!", "YOU'RE GETTING CLOSE!"
20 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
25 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
30 REM SCORING VARIABLES
35 PERFECT_GAMES = 0: LUCKY_SHOTS = 0: TOTAL_GAMES = 0
40 BEST_STREAK = 0: CURRENT_STREAK = 0
45 REM MAIN PROGRAM (SIMPLIFIED FOR SCORING DEMO)
50 GOSUB 1000 REM SHOW STATS
55 GOSUB 2000 REM SIMULATE GAME
60 GOSUB 3000 REM UPDATE ACHIEVEMENTS
65 GOSUB 4000 REM CALCULATE FINAL SCORE
70 PRINT: PRINT "PRESS ENTER FOR ANOTHER ROUND": INPUT A$
75 GOTO 50
1000 REM DISPLAY PLAYER STATISTICS
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "PLAYER STATISTICS"; OFF$
1015 PRINT STRING$(30, "═")
1020 PRINT "GAMES PLAYED:"; TOTAL_GAMES
1025 PRINT "PERFECT GAMES:"; PERFECT_GAMES
1030 PRINT "LUCKY SHOTS:"; LUCKY_SHOTS
1035 PRINT "BEST STREAK:"; BEST_STREAK
1040 PRINT "CURRENT STREAK:"; CURRENT_STREAK
1045 PRINT STRING$(30, "═")
1050 RETURN
2000 REM SIMULATE A GAME
2005 DIFFICULTY = INT(RND(1) * 4) + 1
2010 MAX_TRIES = 20: MAX_RANGE = 100 * DIFFICULTY
2015 TRIES = INT(RND(1) * MAX_TRIES) + 1
2020 TOTAL_GAMES = TOTAL_GAMES + 1
2025 PRINT "GAME "; TOTAL_GAMES; ": DIFFICULTY"; DIFFICULTY
2030 PRINT "SOLVED IN"; TRIES; "TRIES (MAX"; MAX_TRIES; ")"
2035 RETURN
3000 REM UPDATE ACHIEVEMENTS
3005 REM PERFECT GAME (UNDER 25% OF ALLOWED TRIES)
3010 PERFECT_THRESHOLD = INT(MAX_TRIES / 4)
3015 IF TRIES <= PERFECT_THRESHOLD THEN PERFECT_GAMES = PERFECT_GAMES + 1: PERFECT = 1 ELSE PERFECT = 0
3020 REM LUCKY SHOT (FIRST GUESS)
3025 IF TRIES = 1 THEN LUCKY_SHOTS = LUCKY_SHOTS + 1: LUCKY = 1 ELSE LUCKY = 0
3030 REM WINNING STREAK
3035 IF PERFECT = 1 OR LUCKY = 1 THEN CURRENT_STREAK = CURRENT_STREAK + 1 ELSE CURRENT_STREAK = 0
3040 IF CURRENT_STREAK > BEST_STREAK THEN BEST_STREAK = CURRENT_STREAK
3045 REM DISPLAY ACHIEVEMENTS
3050 IF PERFECT = 1 THEN PRINT GREEN$; "ACHIEVEMENT: PERFECT GAME!"; OFF$
3055 IF LUCKY = 1 THEN PRINT YELLOW$; "ACHIEVEMENT: LUCKY SHOT!"; OFF$
3060 IF CURRENT_STREAK >= 3 THEN PRINT PURPLE$; "HOT STREAK: "; CURRENT_STREAK; " IN A ROW!"; OFF$
3065 RETURN
4000 REM CALCULATE FINAL SCORE WITH BONUSES
4005 BASE_SCORE = DIFFICULTY * 1000
4010 EFFICIENCY = (MAX_TRIES - TRIES) * 100
4015 PERFECT_BONUS = PERFECT * 1500
4020 LUCKY_BONUS = LUCKY * 2500
4025 STREAK_BONUS = CURRENT_STREAK * 500
4030 TOTAL_SCORE = BASE_SCORE + EFFICIENCY + PERFECT_BONUS + LUCKY_BONUS + STREAK_BONUS
4035 PRINT: PRINT YELLOW$; "SCORE:"; OFF$; TOTAL_SCORE
4040 RETURN
```
</TryItNow>

**Psychological Hooks We've Added:**
- **Achievement tracking** for different play styles
- **Streak counters** that create momentum and tension
- **Multiple bonus categories** so everyone can excel at something
- **Statistical tracking** that shows improvement over time

## The Mathematics of Motivation

Our scoring formula creates multiple paths to success:
- **Difficulty multipliers** reward brave players
- **Efficiency bonuses** reward smart players
- **Lucky bonuses** reward... well, lucky players
- **Streak bonuses** reward consistent players

This means different personality types can compete on their own terms!
