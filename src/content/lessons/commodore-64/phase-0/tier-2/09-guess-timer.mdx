## The C64's Secret Stopwatch

The Commodore 64 has a built-in timer called TI (Timer Interrupt) that counts constantly in the background. It's like having an invisible stopwatch running all the time! Let's use it to add time pressure:

<TryItNow>
```basic
10 REM PRESSURE TIMING - BASIC TIMER
15 DATA "TRY THE MIDDLE!", "NARROW YOUR RANGE!", "HURRY UP!"
20 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
25 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
30 REM TIMER DEMO
35 PRINT CHR$(147)
40 PRINT WHITE$; "TIMER DEMONSTRATION"; OFF$
45 PRINT "THE C64 TIMER (TI) COUNTS IN 60THS OF A SECOND"
50 PRINT "CURRENT TIMER VALUE:"; TI
55 PRINT "WAIT 5 SECONDS AND WATCH..."
60 START_TIME = TI
65 FOR I = 1 TO 5
70 FOR J = 1 TO 1000: NEXT J REM DELAY LOOP
75 ELAPSED = TI - START_TIME
80 SECONDS = INT(ELAPSED / 60)
85 PRINT "ELAPSED:"; ELAPSED; "TICKS ="; SECONDS; "SECONDS"
90 NEXT I
95 PRINT: PRINT "NOW LET'S ADD TIME PRESSURE TO OUR GAME!"
100 PRINT "PRESS ANY KEY TO CONTINUE": GET A$: IF A$ = "" THEN 100
105 REM TIME-LIMITED GUESSING GAME
110 TIME_LIMIT = 30 REM 30 SECONDS
115 SECRET = INT(RND(1)*100) + 1: TRIES = 0
120 START_TIME = TI
125 PRINT CHR$(147)
130 PRINT RED$; "TIME CHALLENGE MODE"; OFF$
135 PRINT "YOU HAVE"; TIME_LIMIT; "SECONDS TO GUESS!"
140 PRINT "SECRET NUMBER: 1 TO 100"
145 PRINT STRING$(40, "─")
150 REM GAME LOOP WITH TIMER
155 ELAPSED = INT((TI - START_TIME) / 60)
160 REMAINING = TIME_LIMIT - ELAPSED
165 IF REMAINING <= 0 THEN 250 REM TIME'S UP!
170 PRINT "TIME LEFT:"; REMAINING; "SECONDS"
175 INPUT "YOUR GUESS"; GUESS
180 TRIES = TRIES + 1
185 IF GUESS = SECRET THEN 200 REM WIN!
190 IF GUESS < SECRET THEN PRINT "TOO LOW!" ELSE PRINT "TOO HIGH!"
195 GOTO 150
200 REM VICTORY WITH TIME BONUS
205 FINAL_TIME = INT((TI - START_TIME) / 60)
210 PRINT GREEN$; "CORRECT! YOU GOT IT!"; OFF$
215 PRINT "TIME USED:"; FINAL_TIME; "OF"; TIME_LIMIT; "SECONDS"
220 TIME_BONUS = (TIME_LIMIT - FINAL_TIME) * 100
225 PRINT "TIME BONUS:"; TIME_BONUS; "POINTS!"
230 GOTO 270
250 REM TIME'S UP - GAME OVER
255 PRINT RED$; "TIME'S UP!"; OFF$
260 PRINT "THE NUMBER WAS"; SECRET
265 PRINT "BETTER LUCK NEXT TIME!"
270 END
```
</TryItNow>

Here's how the C64 timer magic works:

**TI Variable:** Counts in 1/60th second intervals (50 on PAL systems)
**Line 75:** ELAPSED = TI - START_TIME calculates how much time has passed
**Line 80:** Dividing by 60 converts "ticks" to seconds
**Lines 155-165:** We continuously check if time has run out

<InfoBox>
The TI timer resets to 0 every 24 hours, so for longer programs you might need to handle the "midnight rollover." But for games, this simple approach works perfectly!
</InfoBox>

## Advanced Pressure Mechanics

Let's create even more sophisticated timer-based challenges:

<TryItNow>
```basic
10 REM ADVANCED PRESSURE MECHANICS
15 DATA "QUICK!", "FASTER!", "SECONDS LEFT!"
20 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
25 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
30 REM SPEED ROUND SETUP
35 ROUND = 1: TOTAL_SCORE = 0: LIVES = 3
40 REM MAIN SPEED CHALLENGE LOOP
45 GOSUB 1000 REM PLAY ROUND
50 IF LIVES > 0 AND ROUND <= 5 THEN ROUND = ROUND + 1: GOTO 45
55 GOSUB 2000 REM FINAL RESULTS
60 END
1000 REM SPEED ROUND
1005 PRINT CHR$(147)
1010 PRINT WHITE$; "SPEED ROUND"; ROUND; OFF$
1015 TIME_LIMIT = 45 - (ROUND * 5) REM GETS HARDER!
1020 IF TIME_LIMIT < 10 THEN TIME_LIMIT = 10
1025 SECRET = INT(RND(1)*(50 + ROUND*50)) + 1
1030 PRINT "FIND THE NUMBER: 1 TO"; 50 + ROUND*50
1035 PRINT "TIME LIMIT:"; TIME_LIMIT; "SECONDS"
1040 PRINT "LIVES REMAINING:"; LIVES
1045 PRINT STRING$(30, "═")
1050 REM SPEED GAME LOOP
1055 START_TIME = TI: TRIES = 0
1060 ELAPSED = INT((TI - START_TIME) / 60)
1065 REMAINING = TIME_LIMIT - ELAPSED
1070 IF REMAINING <= 0 THEN 1150 REM TIME'S UP
1075 REM VISUAL PRESSURE INDICATOR
1080 IF REMAINING <= 5 THEN PRINT RED$; "⚠ "; REMAINING; " ⚠"; OFF$
1085 IF REMAINING > 5 AND REMAINING <= 10 THEN PRINT YELLOW$; REMAINING; OFF$
1090 IF REMAINING > 10 THEN PRINT GREEN$; REMAINING; OFF$
1095 INPUT "GUESS"; GUESS
1100 TRIES = TRIES + 1
1105 IF GUESS = SECRET THEN 1200 REM SUCCESS!
1110 IF GUESS < SECRET THEN PRINT "LOW!" ELSE PRINT "HIGH!"
1115 HINT_COUNT = HINT_COUNT + 1
1120 IF HINT_COUNT > 2 AND REMAINING > 10 THEN READ HINT$: PRINT HINT$: HINT_COUNT = 0
1125 GOTO 1060
1150 REM TIME UP - LOSE LIFE
1155 LIVES = LIVES - 1
1160 PRINT RED$; "TIME'S UP!"; OFF$
1165 PRINT "THE NUMBER WAS"; SECRET
1170 IF LIVES > 0 THEN PRINT "LIFE LOST! CONTINUING..."
1175 PRINT "PRESS ENTER": INPUT A$
1180 RETURN
1200 REM SUCCESS - CALCULATE SCORE
1205 TIME_USED = INT((TI - START_TIME) / 60)
1210 SPEED_SCORE = (TIME_LIMIT - TIME_USED) * ROUND * 100
1215 EFFICIENCY = (10 - TRIES) * 50
1220 IF EFFICIENCY < 0 THEN EFFICIENCY = 0
1225 ROUND_SCORE = SPEED_SCORE + EFFICIENCY
1230 TOTAL_SCORE = TOTAL_SCORE + ROUND_SCORE
1235 PRINT GREEN$; "SUCCESS!"; OFF$; " SCORE:"; ROUND_SCORE
1240 PRINT "PRESS ENTER": INPUT A$
1245 RETURN
2000 REM FINAL RESULTS
2005 PRINT CHR$(147)
2010 PRINT WHITE$; "SPEED CHALLENGE COMPLETE!"; OFF$
2015 PRINT "LIVES LEFT:"; LIVES
2020 PRINT "TOTAL SCORE:"; TOTAL_SCORE
2025 IF LIVES > 2 THEN PRINT GREEN$; "SPEED DEMON!"; OFF$
2030 IF LIVES = 2 THEN PRINT YELLOW$; "FAST FINGERS!"; OFF$
2035 IF LIVES = 1 THEN PRINT PURPLE$; "CLOSE CALL!"; OFF$
2040 IF LIVES = 0 THEN PRINT RED$; "NEED MORE PRACTICE!"; OFF$
2045 RETURN
```
</TryItNow>

**Advanced Timer Features:**
- **Escalating difficulty** (lines 1015-1020): Each round gets faster
- **Visual pressure indicators** (lines 1080-1090): Color-coded countdown warnings
- **Multiple lives system** (lines 1150-1175): Tension without immediate failure
- **Time-based scoring** (lines 1210-1230): Rewards both speed and accuracy

## The Psychology of Time Pressure

Notice how we use different timer strategies:
- **Long timers** for thinking games (30+ seconds)
- **Medium timers** for action games (10-20 seconds)
- **Short timers** for reflex challenges (5-10 seconds)
- **Visual warnings** when time gets critical
