# Color Magic

**Time to add some color to your game! The C64's 16 colors might not win any beauty contests (they're a bit on the muddy side), but they're perfect for creating visual feedback systems.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={22} />

## The C64's Color Personality

The Commodore 64 had 16 colors to work with - they might be a bit washed-out compared to some other machines, but they get the job done! Let's add color-coded feedback to our guessing game:

<TryItNow>
```basic
10 REM COLOR MAGIC - BASIC COLOR CODES
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0
30 REM COLORFUL HEADER
35 PRINT CHR$(147) REM CLEAR SCREEN
40 PRINT CHR$(5); "**** NUMBER GUESSING GAME ****"; CHR$(159)
45 PRINT CHR$(28); "┌─────────────────────────────┐"; CHR$(159)
50 PRINT CHR$(28); "│"; CHR$(159); " RANGE: 1 TO 100            "; CHR$(28); "│"; CHR$(159)
52 PRINT CHR$(28); "└─────────────────────────────┘"; CHR$(159)
55 PRINT
60 REM MAIN GAME LOOP
65 PRINT "ATTEMPT #"; TRIES + 1
70 PRINT STRING$(30, "─")
75 INPUT "YOUR GUESS"; GUESS
80 TRIES = TRIES + 1
85 IF GUESS = SECRET THEN 200
90 IF GUESS < SECRET THEN 120
95 IF GUESS > SECRET THEN 160
100 GOTO 65
120 REM TOO LOW - RED FEEDBACK
125 HINT_COUNT = HINT_COUNT + 1
130 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
135 READ HINT$
140 PRINT CHR$(28); "◄◄◄ TOO LOW! "; CHR$(159); HINT$
145 PRINT: GOTO 65
160 REM TOO HIGH - PURPLE FEEDBACK
165 HINT_COUNT = HINT_COUNT + 1
170 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
175 read HINT$
180 PRINT CHR$(156); "►►► TOO HIGH! "; CHR$(159); HINT$
185 PRINT: GOTO 65
200 REM WIN - GREEN CELEBRATION
205 PRINT CHR$(30); "★ ★ ★ PERFECT! ★ ★ ★"; CHR$(159)
210 PRINT "THE NUMBER WAS"; SECRET
215 PRINT "SOLVED IN"; TRIES; "ATTEMPTS!"
220 PRINT CHR$(30); STRING$(25, "▓"); CHR$(159)
225 END
```
</TryItNow>

Look at all the color codes we're using:

**CHR$(5)** = White text (for the title)
**CHR$(28)** = Red text (for borders and "too low")
**CHR$(156)** = Purple text (for "too high")
**CHR$(30)** = Green text (for success)
**CHR$(159)** = Back to light blue (C64 default)

<InfoBox>
The C64 uses control characters to change colors. Each CHR$ code switches the color for all text that follows, until you switch to a different color. CHR$(159) is the "color off" code that returns to the default light blue.
</InfoBox>

## Advanced Color Techniques

Let's create an even more sophisticated color system that uses different colors for different types of information:

<TryItNow>
```basic
10 REM ADVANCED COLOR SYSTEM
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0: LOW_RANGE = 1: HIGH_RANGE = 100
30 REM COLOR CONSTANTS
35 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
40 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
45 PRINT CHR$(147) REM CLEAR SCREEN
50 GOSUB 300 REM COLORFUL HEADER
55 REM MAIN GAME LOOP
60 PRINT YELLOW$; "ATTEMPT #"; TRIES + 1; OFF$
65 PRINT "CURRENT RANGE: "; RED$; LOW_RANGE; OFF$; " TO "; RED$; HIGH_RANGE; OFF$
70 PRINT STRING$(30, "─")
75 INPUT "YOUR GUESS"; GUESS
80 TRIES = TRIES + 1
85 IF GUESS = SECRET THEN 250
90 IF GUESS < SECRET THEN LOW_RANGE = GUESS + 1: GOTO 120
95 IF GUESS > SECRET THEN HIGH_RANGE = GUESS - 1: GOTO 160
100 GOTO 55
120 REM TOO LOW WITH COLORS
125 HINT_COUNT = HINT_COUNT + 1
130 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
135 read HINT$
140 PRINT RED$; "◄◄◄ TOO LOW! "; OFF$; HINT$
145 PRINT "NEW RANGE: "; PURPLE$; LOW_RANGE; " TO "; HIGH_RANGE; OFF$
150 PRINT: GOTO 55
160 REM TOO HIGH WITH COLORS
165 HINT_COUNT = HINT_COUNT + 1
170 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
175 read HINT$
180 PRINT PURPLE$; "►►► TOO HIGH! "; OFF$; HINT$
185 PRINT "NEW RANGE: "; PURPLE$; LOW_RANGE; " TO "; HIGH_RANGE; OFF$
190 PRINT: GOTO 55
250 REM COLORFUL WIN CELEBRATION
255 PRINT GREEN$; "✦ ✦ ✦ BRILLIANT! ✦ ✦ ✦"; OFF$
260 PRINT "THE NUMBER WAS "; WHITE$; SECRET; OFF$
265 PRINT "SOLVED IN "; YELLOW$; TRIES; OFF$; " ATTEMPTS!"
270 PRINT GREEN$; STRING$(30, "▓"); OFF$
275 END
300 REM COLORFUL HEADER SUBROUTINE
305 PRINT WHITE$; "╔════════════════════════════════╗"; OFF$
310 PRINT WHITE$; "║"; OFF$; "    NUMBER GUESSING GAME        "; WHITE$; "║"; OFF$
315 PRINT WHITE$; "║"; OFF$; "    COLORFUL EDITION            "; WHITE$; "║"; OFF$
320 PRINT WHITE$; "╚════════════════════════════════╝"; OFF$
325 PRINT
330 RETURN
```
</TryItNow>

**Lines 35-40:** We define color constants as string variables. This makes our code much cleaner and easier to read.

**Lines 65, 145, 185:** We use different colors for different types of information - yellow for attempts, red and purple for ranges, etc.

**Lines 255-270:** Our victory celebration uses multiple colors to create visual excitement.

## Color Design Principles

Notice how we use colors strategically:
- **Red** for warnings ("too low")
- **Purple** for different warnings ("too high")
- **Green** for success and celebration
- **Yellow** for important information
- **White** for emphasis and borders

This creates a visual language that players quickly learn to understand!
