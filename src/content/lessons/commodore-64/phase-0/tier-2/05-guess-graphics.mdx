## PETSCII: The C64's Graphics Language

The C64 came with a built-in set of graphics characters called PETSCII. These aren't just letters and numbers - they include blocks, lines, and shapes that let you draw pictures using text! Let's add a visual number line to our guessing game:

<TryItNow>
```basic
10 REM VISUAL GRAPHICS - PETSCII DEMO
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0
30 REM DRAW GAME SCREEN WITH GRAPHICS
35 PRINT CHR$(147) REM CLEAR SCREEN
40 PRINT CHR$(18); "**** NUMBER GUESSING GAME ****"; CHR$(146)
45 PRINT "┌─────────────────────────────┐"
50 PRINT "│ RANGE: 1 TO 100            │"
52 PRINT "└─────────────────────────────┘"
55 PRINT
60 REM DRAW NUMBER LINE
65 PRINT "NUMBER LINE:"
70 PRINT "1    25    50    75    100"
75 PRINT "█────█─────█─────█─────█"
80 PRINT
85 REM MAIN GAME LOOP
90 PRINT "ATTEMPT #"; TRIES + 1
95 PRINT STRING$(30, "─")
100 INPUT "YOUR GUESS"; GUESS
105 TRIES = TRIES + 1
110 REM SHOW GUESS ON NUMBER LINE
115 POSITION = INT(GUESS / 4) + 1
120 PRINT "YOUR GUESS:"
125 PRINT SPACE$(POSITION - 1); "▼"; CHR$(13)
130 PRINT "█────█─────█─────█─────█"
135 IF GUESS = SECRET THEN 200
140 IF GUESS < SECRET THEN 160
145 IF GUESS > SECRET THEN 180
150 GOTO 85
160 REM TOO LOW WITH GRAPHICS
165 HINT_COUNT = HINT_COUNT + 1
170 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
175 READ HINT$
180 PRINT "◄◄◄ TOO LOW! "; HINT$
185 PRINT: GOTO 85
190 REM TOO HIGH WITH GRAPHICS
195 HINT_COUNT = HINT_COUNT + 1
200 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
205 READ HINT$
210 PRINT "►►► TOO HIGH! "; HINT$
215 PRINT: GOTO 85
220 REM WIN CONDITION WITH CELEBRATION
225 PRINT "★ ★ ★ PERFECT! ★ ★ ★"
230 PRINT "THE NUMBER WAS"; SECRET
235 PRINT "SOLVED IN"; TRIES; "ATTEMPTS!"
240 PRINT "▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓"
245 END
```
</TryItNow>

Look at all the graphics characters we're using:

**Lines 45-52:** Box drawing characters (┌─┐│└┘) create a proper border around our game info.

**Line 75:** The █ (solid block) and ─ (horizontal line) create a visual number line.

**Lines 115-130:** We calculate where the player's guess falls on the number line and show it with ▼ (down arrow).

**Lines 180 & 210:** Direction arrows (◄ and ►) make it visually clear which way to adjust guesses.

**Line 240:** A celebration bar made of ▓ characters!

<InfoBox>
The CHR$(18) and CHR$(146) codes switch the text color to reverse (white on black) for the title, then back to normal. These are C64-specific color codes that make text stand out!
</InfoBox>

## Advanced Visual Feedback

Let's create an even more sophisticated visual system that shows the narrowing range:

<TryItNow>
```basic
10 REM ADVANCED GRAPHICS - SMART RANGE DISPLAY
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
25 TRIES = 0: HINT_COUNT = 0
30 LOW_RANGE = 1: HIGH_RANGE = 100
35 PRINT CHR$(147) REM CLEAR SCREEN
40 GOSUB 300 REM DRAW HEADER
45 REM MAIN GAME LOOP
50 PRINT "ATTEMPT #"; TRIES + 1
55 PRINT "CURRENT RANGE:"; LOW_RANGE; "TO"; HIGH_RANGE
60 GOSUB 350 REM DRAW RANGE BAR
65 INPUT "YOUR GUESS"; GUESS
70 TRIES = TRIES + 1
75 IF GUESS = SECRET THEN 200
80 IF GUESS < SECRET THEN LOW_RANGE = GUESS + 1: GOTO 120
85 IF GUESS > SECRET THEN HIGH_RANGE = GUESS - 1: GOTO 140
90 GOTO 45
120 REM TOO LOW FEEDBACK
125 HINT_COUNT = HINT_COUNT + 1
130 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
135 READ HINT$
140 PRINT "◄◄◄ TOO LOW! "; HINT$
145 PRINT "NEW RANGE:"; LOW_RANGE; "TO"; HIGH_RANGE
150 PRINT: GOTO 45
155 REM TOO HIGH FEEDBACK
160 HINT_COUNT = HINT_COUNT + 1
165 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
170 READ HINT$
175 PRINT "►►► TOO HIGH! "; HINT$
180 PRINT "NEW RANGE:"; LOW_RANGE; "TO"; HIGH_RANGE
185 PRINT: GOTO 45
200 REM WIN CONDITION
205 PRINT "✦ ✦ ✦ BRILLIANT! ✦ ✦ ✦"
210 PRINT "THE NUMBER WAS"; SECRET
215 PRINT "FINAL RANGE:"; LOW_RANGE; "TO"; HIGH_RANGE
220 PRINT "SOLVED IN"; TRIES; "ATTEMPTS!"
225 END
300 REM HEADER SUBROUTINE
305 PRINT "╔════════════════════════════════╗"
310 PRINT "║    NUMBER GUESSING GAME        ║"
315 PRINT "║    SMART RANGE TRACKING        ║"
320 PRINT "╚════════════════════════════════╝"
325 RETURN
350 REM RANGE BAR SUBROUTINE
355 RANGE_SIZE = HIGH_RANGE - LOW_RANGE + 1
360 BAR_LENGTH = INT(RANGE_SIZE / 5) + 1
365 PRINT "RANGE SIZE:"; RANGE_SIZE
370 PRINT "[" + STRING$(BAR_LENGTH, "▓") + STRING$(20 - BAR_LENGTH, "░") + "]"
375 RETURN
```
</TryItNow>

**Lines 30, 80, 85:** We track LOW_RANGE and HIGH_RANGE, updating them based on each guess to narrow down the possibilities.

**Lines 300-325:** A subroutine that draws a fancy header with double-line box characters.

**Lines 350-375:** A visual bar showing how much range is left. As the range narrows, the bar shrinks!

**Line 370:** We mix ▓ (solid blocks) and ░ (light blocks) to show progress.

<RetroMoment title="Visual Revolution: 1982">
PETSCII graphics were revolutionary in 1982. While other computers had basic text displays, the C64 included 256 graphic characters built into ROM. Creative programmers used these to create elaborate art, game graphics, and user interfaces that looked almost like modern applications - all without leaving text mode!
