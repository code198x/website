# Smart Hints

**Time to make our game smarter! Let's add a hint system that gives players strategic advice to improve their guessing.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={19} />

## Storing Data with DATA Statements

So far, our game gives the same "too high" or "too low" feedback every time. But what if we could give players smarter hints? That's where DATA and READ come in - they let us store and retrieve pre-written information.

<TryItNow>
```basic
10 REM SMART HINTS - DATA AND READ
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
30 TRIES = 0
40 PRINT "I'M THINKING OF A NUMBER FROM 1 TO 100"
50 PRINT "CAN YOU GUESS IT?"
60 REM MAIN GAME LOOP
70 PRINT
80 INPUT "ENTER YOUR GUESS"; GUESS
90 TRIES = TRIES + 1
100 IF GUESS = SECRET THEN 200
110 IF GUESS < SECRET THEN 150
120 IF GUESS > SECRET THEN 170
130 GOTO 70
140 REM TOO LOW BRANCH
150 READ HINT$
160 PRINT "TOO LOW! HINT: "; HINT$: GOTO 70
165 REM TOO HIGH BRANCH
170 READ HINT$
180 PRINT "TOO HIGH! HINT: "; HINT$: GOTO 70
190 REM WIN CONDITION
200 PRINT "YES! YOU GOT IT IN"; TRIES; "TRIES!"
210 END
```
</TryItNow>

Let's break down the new magic:

**Line 15:** The DATA statement stores three hint strings. Think of it as a list the computer can read from later.

**Lines 150 and 170:** The READ command grabs the next item from our DATA list and stores it in HINT$. Each READ moves forward in the list.

**Lines 160 and 180:** We print the hint along with our feedback, giving players more helpful information.

<InfoBox>
The $ in HINT$ tells BASIC this variable holds text (strings) instead of numbers. String variables can store words, sentences, or any text you want!
</InfoBox>

## The Problem with Sequential Reading

Run the code above and you'll notice something interesting (and potentially frustrating). After three wrong guesses, the program will crash with an "OUT OF DATA" error. That's because READ moves forward through the DATA list and doesn't automatically restart.

Here's the improved version:

<TryItNow>
```basic
10 REM SMART HINTS - WITH RESTORE
15 DATA "TRY THE MIDDLE!", "NARROW IT DOWN!", "YOU'RE GETTING CLOSE!"
20 SECRET = INT(RND(1)*100) + 1
30 TRIES = 0: HINT_COUNT = 0
40 PRINT "I'M THINKING OF A NUMBER FROM 1 TO 100"
50 PRINT "CAN YOU GUESS IT?"
60 REM MAIN GAME LOOP
70 PRINT
80 INPUT "ENTER YOUR GUESS"; GUESS
90 TRIES = TRIES + 1
100 IF GUESS = SECRET THEN 200
110 IF GUESS < SECRET THEN 150
120 IF GUESS > SECRET THEN 170
130 GOTO 70
140 REM TOO LOW BRANCH
150 HINT_COUNT = HINT_COUNT + 1
155 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
160 READ HINT$
165 PRINT "TOO LOW! HINT: "; HINT$: GOTO 70
170 REM TOO HIGH BRANCH
175 HINT_COUNT = HINT_COUNT + 1
180 IF HINT_COUNT > 3 THEN RESTORE: HINT_COUNT = 1
185 READ HINT$
190 PRINT "TOO HIGH! HINT: "; HINT$: GOTO 70
195 REM WIN CONDITION
200 PRINT "YES! YOU GOT IT IN"; TRIES; "TRIES!"
210 END
```
</TryItNow>

**Lines 155 and 180:** We track how many hints we've given with HINT_COUNT. When we've used all three hints, RESTORE resets the DATA pointer back to the beginning, and we reset our counter.

Now our game can give hints forever without crashing!
