# Beta Testing

**Let fresh eyes break Cosmic Defender so you can launch flawlessly.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={124} />

## Build the test plan

- **Scope:** Full three-level campaign, boss fight, achievements, save/load, manual comprehension.
- **Hardware:** VICE 3.8 (PAL and NTSC), real C64 if available, joystick + keyboard.
- **Session flow:** 15 minutes orientation → 30 minutes play → 10 minutes survey.

## Bug log template

| ID | Title | Steps to Reproduce | Expected | Actual | Status | Notes |
|----|-------|--------------------|----------|--------|--------|-------|
| CDB-01 | Shields stuck overcharged | Collect 3 energy cores in Wave 2 | Shield drains after 10s | Shield stays red forever | Open | Occurs only in NTSC |

Track issues in `docs/testing/BUGLOG.md`. Acknowledge receipt and update status (Open → In Progress → Fixed → Verified).

## Survey questions

1. Rate overall difficulty (1–5).
2. How satisfying are weapon upgrades? (1–5 + comments).
3. Describe any confusing UI moments.
4. Did you experience performance drops? When?
5. Favorite moment? Least favorite?

<InfoBox>
Schedule a feedback loop: triage bug log daily, respond to testers with fixes, and run regression checks after each patch. Keep older builds archived for comparison.
</InfoBox>

Deliver to testers: disk image, manual draft, test plan PDF, bug log link, and contact info.
