# Final Polish

**Give Cosmic Defender the sparkle it deserves before release.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={125} />

## Bug + enhancement triage

- Sort bug log by severity, reproduction rate, and impact.
- Fix blockers (crashes, soft locks) first, then major gameplay issues, then cosmetic tweaks.
- After each fix, run regression tests: intro → wave → boss → save → reload.

## Audio + visual pass

- Normalize SID volume: keep music around 10, SFX bursts 12–13, avoid clipping.
- Ensure palette choices meet accessibility guidelines (contrast ratio, color-blind friendly combos).
- Re-run screenshake and flash effects to confirm they respect cooldowns and don’t obscure HUD.

## UX consistency checklist

- Controls listed identically in manual, pause overlay, and instructions screen.
- Achievement names/descriptions match in pop-ups and manual.
- Save slot names, file names, and manual instructions align.
- Debug mode hidden in release build (remove menu references).

<InfoBox>
Create a “Polish log” noting each tweak, date, and reason. It keeps the team aligned and helps roll back or revisit changes if new bugs appear.
</InfoBox>

Finish with a full playthrough recording (video or GIF) to capture the final state.
