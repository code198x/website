# Instructions

**Tell pilots how to save the colony—and why it matters.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={126} />

## Manual outline

1. **Story:** Brief intro, stakes, villain (Cosmic Raiders), player role.
2. **Controls:** Keyboard + joystick charts, pause/debug info, weapon cycling.
3. **HUD Guide:** Shield meter, combo multiplier, wave tracker, achievement notifications.
4. **Gameplay:** Weapons overview, shield tips, boss strategy hints.
5. **Saving & Loading:** Steps, slot names, troubleshooting.
6. **Credits & Thanks.**

## In-game help screen

- Accessible via pause menu (`P`) → “Help”.
- Display condensed sections: controls, weapon quick tips, scoring.
- Use custom characters for icons (e.g., `↔` for movement) and limit to 3 pages navigated with `<` `>`.

## Production tasks

- Write manual in Markdown (`docs/COSMIC_DEFENDER_MANUAL.md`).
- Export PETSCII version (`tools/manual_to_petscii.py` output) for inclusion in disk image.
- Link manual from README and instructions screen.

<InfoBox>
Test instructions with fresh playtesters—if they can’t finish tutorial wave after reading, clarify wording. Highlight advanced tips to encourage mastery.
</InfoBox>

Deliver the manual alongside `README_cosmic.txt` so players always have guidance.
