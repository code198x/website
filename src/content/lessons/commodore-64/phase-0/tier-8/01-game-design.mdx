# Game Design

**Start Cosmic Defender with a crisp blueprint instead of guesswork.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={113} />

## Craft the core loop

- **Fantasy:** Defend the last colony from cosmic raiders in fast, score-chasing battles.
- **Loop:** `Launch → Engage waves → Collect energy → Trigger super shield → Upgrade ship → Repeat`.
- **Failure:** Shields drain to zero; colony destroyed.
- **Victory:** Survive boss assault wave 5 and escort the colony transport off-screen.

## Plan the milestones

1. **Prototype (Week 1):** Player movement, shooting, basic enemy wave, placeholder graphics.
2. **Alpha (Weeks 2-3):** Shield meter, weapon pickups, boss pattern, scoring, pause menu.
3. **Content Lock (Week 4):** Final sprites/bitmaps, wave scripting, achievements, save support.
4. **Polish (Week 5):** Music tweaks, screen shake, error handling, manual, disk prep.

## Build the feature matrix

| Category | Must | Should | Could |
| --- | --- | --- | --- |
| Gameplay | responsive controls, 3 weapon tiers | combo scoring, shield overcharge | bonus challenge rooms |
| Visuals | hires backdrop, HUD split | parallax layer | color-cycling finale |
| Audio | adaptive music, per-weapon SFX | boss sting | multi-channel crowd cheer |
| UX | pause, debug toggle, instructions | achievement popups | accessibility color themes |

<InfoBox>
Keep this matrix visible as you work through Tier 8. When scope creeps, check the table: “Must” features ship first; “Should/Could” only if time remains.
</InfoBox>
