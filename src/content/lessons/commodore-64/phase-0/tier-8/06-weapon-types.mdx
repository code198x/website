# Weapon Types

**Let pilots switch between precision shots, crowd control, and burst damage.**

## Weapon data table

<TryItNow>
```basic
10 REM WEAPON DEFINITIONS
20 DIM NAME$(3),RATE(3),SPREAD(3),COST(3)
30 DATA "BLASTER",4,0,1
40 DATA "TRIDENT",6,2,3
50 DATA "ION PULSE",10,0,6
60 DATA "QUANTUM ARC",12,0,8
70 FOR I=0 TO 3
80 READ NAME$(I),RATE(I),SPREAD(I),COST(I)
90 NEXT
100 CURRENT=0
110 GOSUB FIREWEAPON
120 CURRENT=2 : GOSUB FIREWEAPON
130 END

200 REM FIRE BASED ON CURRENT
210 SHOTDELAY = RATE(CURRENT)
220 ENERGY = ENERGY - COST(CURRENT)
230 IF ENERGY < 0 THEN PRINT "NO ENERGY" : RETURN
240 IF SPREAD(CURRENT)=0 THEN GOSUB SINGLESHOT ELSE GOSUB SPREADSHOT
250 GOSUB PLAYSFX
260 RETURN
```
</TryItNow>

Stat tables keep weapon logic data-driven. `RATE` governs delay between shots, `SPREAD` tells the sprite system how many bolts to spawn, and `COST` drains shield energy.

<InfoBox>
Blend weapon switching with achievements (Lesson 121): unlock Quantum Arc after a perfect wave, or award Ion Pulse for defeating the boss. Use different SID patches per weapon for instant feedback.
</InfoBox>

Document each weapon’s strengths in the final manual so players can strategize around energy usage and combo scores (Lesson 120).
