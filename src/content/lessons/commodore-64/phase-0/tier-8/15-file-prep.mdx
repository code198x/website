# File Prep

**Bundle Cosmic Defender into a clean, shareable package.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={127} />

## Build script outline

<TryItNow>
```bash
#!/usr/bin/env bash
set -euo pipefail
BASIC=dist/cosmic.bas
D64=dist/cosmic_defender.d64
MANUAL=docs/COSMIC_DEFENDER_MANUAL.txt
ACH=dist/achievements.dat

rm -f "$D64"
# Create new disk image
c1541 -format "COSMIC DEFENDER,CD" d64 "$D64"
# Add main program
petcat -w2 -o dist/cosmic.prg "$BASIC"
c1541 "$D64" -write dist/cosmic.prg "COSMIC"
# Add manual + achievement data
c1541 "$D64" -write "$MANUAL" "MANUAL"
c1541 "$D64" -write "$ACH" "ACHDATA"
```
```

Run the script after a fresh build to produce the release disk.

## Release checklist

- Remove debug toggles and logging prints from source.
- Ensure version header/date is up to date in the program’s title screen.
- Confirm `LOAD"COSMIC",8,1 : RUN` starts the game at the title screen.
- Test `RUNSTOP+RESTORE` recovery in case of crash (should reset gracefully).

<InfoBox>
Generate MD5 checksums for final artifacts (`shasum -a 256 cosmic_defender.d64`) and store in `dist/manifest.txt` so players can verify integrity.
</InfoBox>

Archive the entire `dist/` folder in version control tags for future reference.
