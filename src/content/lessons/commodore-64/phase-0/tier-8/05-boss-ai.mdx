# Boss AI

**Give the Cosmic Raider mothership personality and escalating menace.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={117} />

## Drive multi-phase logic

<TryItNow>
```basic
10 REM BOSS CONTROLLER
20 PHASE=1: TIMER=0: HP=180
30 DATA "SPREAD","LASER", "MINE"
40 DATA "SWEEP","PULSE", "DESPERATION"
50 DO
60 TIMER=TIMER+1
70 IF HP<=120 AND PHASE=1 THEN PHASE=2: TIMER=0
80 IF HP<=60 AND PHASE=2 THEN PHASE=3: TIMER=0
90 ON PHASE GOSUB 200,300,400
100 LOOP UNTIL HP<=0
110 PRINT "BOSS DEFEATED"
120 END

200 REM PHASE 1 PATTERNS
210 IF TIMER MOD 90 = 0 THEN ATTACK$="SPREAD"
220 IF TIMER MOD 150 = 0 THEN ATTACK$="LASER"
230 GOSUB EXECUTE : RETURN

300 REM PHASE 2 PATTERNS
310 IF TIMER=1 THEN ATTACK$="SWEEP"
320 IF TIMER MOD 80 = 0 THEN ATTACK$="MINE"
330 GOSUB EXECUTE : RETURN

400 REM PHASE 3 DESPERATION
410 IF TIMER MOD 40 = 0 THEN ATTACK$="PULSE"
420 IF TIMER MOD 120 = 0 THEN ATTACK$="DESPERATION"
430 GOSUB EXECUTE : RETURN

500 REM EXECUTE ATTACKS
510 SELECT CASE ATTACK$
520 CASE "SPREAD": GOSUB FIRESPREAD
530 CASE "LASER": GOSUB CHARGELASER
540 CASE "MINE": GOSUB DROPMINES
550 CASE "SWEEP": GOSUB LASERSWEEP
560 CASE "PULSE": GOSUB ENERGYBURST
570 CASE "DESPERATION": GOSUB FINALBARRAGE
580 END SELECT
590 RETURN
```
</TryItNow>

Each phase chooses attacks based on timers. Implement the subroutines to spawn projectiles, trigger telegraphs (palette flashes), and perhaps call SID cues. As HP drops, the boss swaps to tougher patterns.

<InfoBox>
Store attack pattern tables in DATA so designers can tweak sequences without editing logic. Combine with sprite manager and parallax layers to make the fight cinematic.
</InfoBox>

Remember to reset bosses on player death and save the phase in case of mid-fight retries.
