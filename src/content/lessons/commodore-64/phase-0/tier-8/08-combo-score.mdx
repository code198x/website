# Combo Score

**Make cosmic defense feel rewarding with streak-based scoring explosions.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={120} />

## Implement streak logic

<TryItNow>
```basic
10 REM COMBO SYSTEM
20 SCORE=0: STREAK=0: TIMER=0
30 DO
40 INPUT "HIT? (Y/N/D)";A$
50 IF A$="Y" THEN GOSUB HIT
60 IF A$="N" THEN GOSUB MISS
70 IF A$="D" THEN GOSUB DAMAGE
80 TIMER=TIMER-1
90 IF TIMER<=0 THEN STREAK=0: MULT=1
100 PRINT "SCORE:";SCORE;" STREAK:";STREAK;" MULT:";MULT
110 LOOP

200 SUB HIT
210 STREAK=STREAK+1
220 MULT=1+INT(STREAK/5)
230 IF MULT>5 THEN MULT=5
240 TIMER=50
250 BASE=100
260 SCORE=SCORE+BASE*MULT
270 RETURN

300 SUB MISS
310 TIMER=MAX(0,TIMER-10)
320 RETURN

400 SUB DAMAGE
410 STREAK=0: MULT=1: TIMER=0
420 RETURN
```
</TryItNow>

Every successful hit increases the streak and multiplier, while misses shave time off the combo window. Taking damage wipes the streak entirely.
