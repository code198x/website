# Speed Test

**Measure before you optimize—know where Cosmic Defender spends each jiffy.**

## Profile the critical loops

<TryItNow>
```basic
10 REM SPEED PROFILER
20 TI$="000000"
30 GOSUB MOVESTEP : MOVETIME = VAL(TI$)
40 TI$="000000"
50 GOSUB SHOOTSTEP : SHOOTTIME = VAL(TI$)
60 TI$="000000"
70 GOSUB ENEMYSTEP : ENEMYTIME = VAL(TI$)
80 TOTAL = MOVETIME + SHOOTTIME + ENEMYTIME
90 PRINT "MOVE:";MOVETIME;"  SHOT:";SHOOTTIME;"  ENEMY:";ENEMYTIME;"  TOTAL:";TOTAL
100 END

200 REM PLAYER MOVEMENT ROUTINE (PLACEHOLDER)
210 FOR I=0 TO 31: PLAYERX = PLAYERX + DX(I): NEXT : RETURN

300 REM PROJECTILE LOOP (PLACEHOLDER)
310 FOR B=0 TO BULLETS-1: BX(B)=BX(B)+SPEED(B): NEXT : RETURN

400 REM ENEMY AI LOOP (PLACEHOLDER)
410 FOR E=0 TO ENEMIES-1: GOSUB UPDATEENEMY: NEXT : RETURN
```
</TryItNow>

Replace the placeholder loops with your real movement, projectile, and enemy routines. Recording times exposes expensive sections before final polish.

## Target frame budget

- **Goal:** 16–17 jiffies (≈1 frame) for gameplay work, leaving room for rendering and music.
- **Red flags:** Any subsystem exceeding 6 jiffies sequentially, or totals above 40 jiffies.

## Optimization reminders

- Use lookup tables for trigonometry, bullet arc, or AI heuristics.
- Offload clearing, character copy, or SID tasks to `SYS` when possible.
- Cache collision results by tile when multiple systems read the same map in a frame.

Record your benchmarks in `docs/performance-log.md` so you can compare pre/post changes during Tier 8.
