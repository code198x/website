## Recharge and overcharge logic

<TryItNow>
```basic
10 REM SHIELD CONTROL
20 MAXSHIELD=100 : SHIELD=60
30 OVERCHARGE=0 : REGENRATE=1
40 TIMER=0
50 DO
60 TIMER=TIMER+1
70 IF TIMER MOD 5=0 AND SHIELD<MAXSHIELD THEN SHIELD=SHIELD+REGENRATE
80 IF SHIELD>MAXSHIELD THEN OVERCHARGE=-1 : SHIELD=MAXSHIELD : OVERCLOCK=100
90 IF OVERCHARGE THEN OVERCLOCK=OVERCLOCK-1 : IF OVERCLOCK<=0 THEN OVERCHARGE=0
100 CALL DAMAGEHANDLER(12)
110 CALL UPDATEVISUALS(SHIELD,OVERCHARGE)
120 LOOP

130 SUB DAMAGEHANDLER(DMG)
140 IF OVERCHARGE THEN DMG=INT(DMG/2)
150 SHIELD=SHIELD-DMG
160 IF SHIELD<0 THEN SHIELD=0
170 END SUB

200 SUB UPDATEVISUALS(S,OC)
210 LEVEL=S/10
220 COLOR=15-LEVEL
230 IF COLOR<2 THEN COLOR=2
240 POKE 53281,COLOR
250 IF OC THEN POKE 53280,2 ELSE POKE 53280,0
260 END SUB
```
</TryItNow>

The shield regenerates gradually; collecting energy pickups pushes it into temporary overcharge, reducing incoming damage and altering palette colors to telegraph invulnerability.

<InfoBox>
Tie shield thresholds to audio cues: low shield beeps, overcharge hum. Save current shield and overcharge cooldown so players resume with the correct state after pausing or loading.
</InfoBox>

Display shield percentage and overcharge timer on the HUD for clarity.
