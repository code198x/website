# Achievements

**Celebrate iconic Cosmic Defender moments with satisfying pop-ups.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={121} />

## Define and trigger achievements

<TryItNow>
```basic
10 REM ACHIEVEMENT SYSTEM
20 DIM ACHFLAG(7)
30 DATA "ACE PILOT", "Reach x5 combo"
40 DATA "IRON SHIELD", "Finish wave without taking damage"
50 DATA "BOSS BREAKER", "Defeat Phase 3 boss"
60 FOR I=0 TO 2: READ TITLE$(I),DESC$(I): NEXT
70 IF MULT>=5 THEN GOSUB UNLOCK(0)
80 IF WAVECLEARED AND DAMAGE=0 THEN GOSUB UNLOCK(1)
90 IF BOSSKILLED THEN GOSUB UNLOCK(2)
100 END

200 SUB UNLOCK(ID)
210 IF ACHFLAG(ID) THEN RETURN
220 ACHFLAG(ID)=-1
230 PRINT "ACHIEVEMENT: ";TITLE$(ID)
240 GOSUB PLAYSFX
250 GOSUB SHOWBANNER(TITLE$(ID),DESC$(ID))
260 RETURN
```
</TryItNow>

The system checks conditions after key events; unlocking triggers an audio cue and on-screen banner. Save unlocked achievements by packing `ACHFLAG` bits alongside quest flags.

<InfoBox>
Display achievement progress in a new menu screen (accessible from pause). Use it to highlight optional challenges that encourage replay.
</InfoBox>

Remember to debounce triggers so the same achievement doesn’t double-fire during a session.
