# Cosmic Defender

**Celebrate completion—your BASIC-era masterpiece is ready for launch.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={128} />

## Final playthrough checklist

- Boot from D64, confirm title animation, music, menu navigation.
- Complete waves 1–3, verify weapon unlock timings, shield behavior, combo pop-ups.
- Face boss, ensure phase transitions, juice effects, and victory flow.
- Trigger save slots, reload, confirm achievements persist.
- View instructions screen, ensure text formatting intact.

## Release notes template

```
Cosmic Defender v1.0 (YYYY-MM-DD)
- Feature highlights (weapons, boss, adaptive music)
- Performance benchmarks (PAL/NTSC frame timings)
- Known issues / future roadmap
- Credits (design, code, art, playtesters)
```

Publish release notes in `RELEASES.md` and include a short version in the manual.

## Repository wrap-up

- Commit final assets, manual, build script, and documentation.
- Tag release (`git tag v1.0-cosmic-defender`), push tag.
- Upload `dist/cosmic_defender.d64` and manual to distribution folder or itch.io page.
- Archive testing notes and bug log for posterity.

Record a gameplay trailer (GIF or MP4). Showcase parallax, boss fight, achievements, and combo scoring. Retro projects shine when players can see the action immediately.
</InfoBox>
