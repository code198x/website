# Galaxy Map

**Chart the trade routes visually on the C64 screen.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={93} />

## Plot the sector

<TryItNow>
```basic
10 REM SPACE TRADER - GALAXY MAP
20 DIM PX(7),PY(7)
30 DATA 5,4, 12,8, 18,6, 25,10, 32,5, 10,14, 28,15, 35,12
40 FOR I=0 TO 7 : READ PX(I),PY(I) : NEXT
50 HOME = 0 : FUEL = 12
60 PRINT CHR$(147)
70 FOR I=0 TO 7
80 SCREEN = 1024 + (PY(I)+2)*40 + (PX(I)+2)
90 SYMBOL = ASC("*")
100 DIST = ABS(PX(I)-PX(HOME)) + ABS(PY(I)-PY(HOME))
110 IF DIST > FUEL THEN SYMBOL = ASC(".")
120 IF I = HOME THEN SYMBOL = ASC("@")
130 POKE SCREEN,SYMBOL
140 NEXT
150 PRINT "@ CURRENT PORT   * REACHABLE   . OUT OF RANGE"
```
</TryItNow>

The map uses a simple Manhattan distance to approximate fuel cost between systems. Reachable worlds show as `*`, the current port as `@`, and distant systems as `.`.

<InfoBox>
Use a small offset when calculating `SCREEN` so the map leaves margins. Later you can add cursor movement to select routes.
</InfoBox>
