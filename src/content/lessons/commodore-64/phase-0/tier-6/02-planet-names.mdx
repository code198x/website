# Planet Names

**Give every market a memorable identity.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={82} />

## Name the system grid

<TryItNow>
```basic
10 REM SPACE TRADER - PLANETS
20 DIM PLANET$(7),CODE$(7)
30 DATA "AURIGA PRIME","AUR","ZELENIA","ZEL","KALLIOPE","KAL","ORTUS","ORT"
40 DATA "MISTRA","MIS","HYPERION","HYP","LYRA IX","LYR","NAROS","NAR","TALOS","TAL"
50 FOR I=0 TO 7
60 READ PLANET$(I),CODE$(I)
70 NEXT
80 HOME = INT(RND(1)*8)
90 PRINT "CURRENT PORT: ";CODE$(HOME);" - ";PLANET$(HOME)
```
</TryItNow>

Storing both the display name and a short code lets you format HUD elements concisely while still showing flavor text in logs.

<InfoBox>
Keep the short code three letters so you can align tables easily and reuse it in file names when saving planet-specific data.
</InfoBox>
