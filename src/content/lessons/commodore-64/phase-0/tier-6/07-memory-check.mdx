# Memory Check

**Guard against overfilling BASIC’s workspace.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={87} />

## Estimate requirements

<TryItNow>
```basic
10 REM SPACE TRADER - MEMORY CHECK
20 AVAILABLE = FRE(0)
30 NEEDED = 2000 : REM rough bytes for arrays + buffers
40 PRINT "FREE:";AVAILABLE;"BYTES"
50 IF AVAILABLE < NEEDED THEN PRINT "NOT ENOUGH MEMORY!" : STOP
60 PRINT "MEMORY OK - CONTINUE LOADING"
```
</TryItNow>

`FRE(0)` returns free memory in bytes. Use a slightly padded estimate for your arrays and buffers; if the free space dips too low, warn the player to delete old programs or warm start.

<InfoBox>
When you dimension arrays dynamically, perform the check before `DIM` to avoid triggering an out-of-memory error mid-load.
</InfoBox>
