# Multiple Saves

**Give traders a hangar full of save slots.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={95} />

## Build the slot menu

<TryItNow>
```basic
10 REM SPACE TRADER - SAVE SLOTS
20 DIM SLOT$(2)
30 SLOT$(0) = "TRADER-1" : SLOT$(1) = "TRADER-2" : SLOT$(2) = "TRADER-3"
40 PRINT "SELECT SLOT (1-3)"
50 FOR I=0 TO 2 : PRINT I+1;" - ";SLOT$(I) : NEXT
60 GET K$ : IF K$ < "1" OR K$ > "3" THEN 60
70 SLOT = VAL(K$)-1
80 FILENAME$ = SLOT$(SLOT)
90 PRINT "USING FILE:";FILENAME$
100 GOSUB 200 : REM save using filename
110 END

200 REM SAVE WRAPPER
210 OPEN 1,8,2,FILENAME$+",S,W"
220 IF ST THEN PRINT "ERROR";ST : CLOSE 1 : RETURN
230 PRINT#1,"PLANET,";CODE$(HOME)
240 CLOSE 1 : PRINT "SAVED"
250 RETURN
```
</TryItNow>

This simplified example uses hardcoded slot names, but you can scan the directory for existing `TRADER-` files and populate the list dynamically before prompting.

<InfoBox>
Store the chosen slot in memory so auto-save routines overwrite the same file unless the player selects a new slot.
</InfoBox>
