# Disk Errors

**Turn raw drive codes into player-friendly feedback.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={86} />

## Query the error channel

<TryItNow>
```basic
10 REM SPACE TRADER - DISK STATUS
20 OPEN 15,8,15
30 INPUT#15, ERR,MS$,TRK,SEC
40 IF ERR = 0 THEN PRINT "OK" : GOTO 80
50 PRINT "DISK ERROR:";ERR;" - ";MS$
60 IF ERR = 62 THEN PRINT "TRY DIFFERENT FILE NAME"
70 IF ERR = 74 THEN PRINT "CHECK DISK DOOR OR WRITE PROTECT"
80 CLOSE 15
```
</TryItNow>

After any disk operation, open channel 15 to read the latest error. Code 0 means success; other codes tell you what went wrong. Track and display them so players know how to recover.

<InfoBox>
Combine this with `ST`: first check `ST` for immediate bus errors, then query the error channel for specifics. Close channel 15 every time to avoid locking the drive.
</InfoBox>
