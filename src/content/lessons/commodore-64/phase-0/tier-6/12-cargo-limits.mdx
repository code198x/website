# Cargo Limits

**Keep the freighter within safe load lines.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={92} />

## Enforce ship capacity

<TryItNow>
```basic
10 REM SPACE TRADER - CARGO CHECK
20 SHIPCAP = 30 : USEDSPACE = 20
30 GOOD = 0 : UNITS = 4
40 REQUIRED = UNITS * CARGO(GOOD)
50 IF USEDSPACE + REQUIRED > SHIPCAP THEN PRINT "CARGO HOLD FULL" : END
60 USEDSPACE = USEDSPACE + REQUIRED
70 FUEL = 15 : JUMPCOST = 3
80 IF FUEL < JUMPCOST THEN PRINT "REFUEL BEFORE DEPARTURE" : END
90 FUEL = FUEL - JUMPCOST
100 PRINT "CARGO:";USEDSPACE;"/";SHIPCAP;"  FUEL:";FUEL
```
</TryItNow>

Cargo space uses the unit size defined back in Lesson 81. Check capacity before finalizing trades; if there’s space, update both cargo usage and fuel to reflect the upcoming jump.

<InfoBox>
Display `USEDSPACE/SHIPCAP` and `FUEL` on the HUD so players see constraints at a glance—helpful before they commit to deals.
</InfoBox>
