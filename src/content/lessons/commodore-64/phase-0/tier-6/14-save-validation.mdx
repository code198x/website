# Save Validation

**Keep corrupted sectors from crashing your run.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={94} />

## Sanity-check loaded data

<TryItNow>
```basic
10 REM SPACE TRADER - VALIDATE SAVE
20 VALID = -1
30 IF HOME < 0 OR HOME > 7 THEN VALID = 0
40 FOR I=0 TO 5
50 IF PRICE(I) <= 0 OR PRICE(I) > 999 THEN VALID = 0
60 IF TODAY(I) < 0 OR TODAY(I) > 999 THEN VALID = 0
70 NEXT
80 IF USEDSPACE < 0 OR USEDSPACE > SHIPCAP THEN VALID = 0
90 IF VALID THEN PRINT "SAVE OK" : GOTO 130
100 PRINT "SAVE CORRUPT. RESTORE BACKUP? (Y/N)"
110 GET K$ : IF K$ = "" THEN 110
120 IF K$ = "Y" THEN GOSUB 200 ELSE GOSUB 220
130 END

200 REM RESTORE DEFAULTS
210 GOSUB LOADDEFAULTS
220 RETURN
```
</TryItNow>

Validate key ranges to avoid negative credits, impossible cargo, or invalid planet indexes. If checks fail, fall back to defaults or prompt for a fresh game.

<InfoBox>
Store a checksum byte in the save file for additional security: sum or XOR each record when saving, then compare during load.
</InfoBox>
