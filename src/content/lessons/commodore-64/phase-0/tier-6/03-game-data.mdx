# Game Data

**Give every world a personality that affects trade.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={83} />

## Attach economy modifiers

<TryItNow>
```basic
10 REM SPACE TRADER - PLANET DATA
20 DIM ECON(7),RISK(7),SPECIAL$(7)
30 DATA 12,3,"MINING BOOM", 8,5,"PIRATE ACTIVITY", 9,2,"FOOD SURPLUS"
40 DATA 11,4,"TECH EXPO", 10,3,"STEADY", 7,6,"QUARANTINE", 13,2,"LUXURY HUB", 6,7,"WAR ZONE"
50 FOR I=0 TO 7
60 READ ECON(I),RISK(I),SPECIAL$(I)
70 NEXT
80 HOME = 0 : REM assume Auriga Prime from previous lesson
90 PRINT PLANET$(HOME);" ECONOMY:";ECON(HOME)/10
100 PRINT "RISK LEVEL:";RISK(HOME);
110 PRINT "NOTES:";SPECIAL$(HOME)
120 FOR G=0 TO 5
130 ADJUST = INT(PRICE(G) * ECON(HOME) / 10 + 0.5)
140 PRINT GOODS$(G);" NOW";ADJUST;"CR"
150 NEXT
```
</TryItNow>

`ECON` values represent price multipliers (e.g., 12 = 1.2×). `RISK` influences encounter tables later. `SPECIAL$` provides flavor text for the HUD.

<InfoBox>
Keep multipliers as integers to avoid floating point slowdown. Divide by 10 when printing to show a decimal multiplier if desired.
</InfoBox>
