## Re-dimension helpers safely

<TryItNow>
```basic
10 REM SPACE TRADER - BUFFER REUSE
20 DIM BUFFER$(8)
30 FOR I=0 TO 8 : BUFFER$(I) = "" : NEXT
40 REM use BUFFER$() to parse load records
50 GOSUB 200
60 REM after loading, reuse as message stack
70 ERASE BUFFER$
80 DIM BUFFER$(3)
90 BUFFER$(0) = "WELCOME CAPTAIN"
100 BUFFER$(1) = "SAVE SLOT READY"
110 FOR I=0 TO 1 : PRINT BUFFER$(I) : NEXT
120 END
```
</TryItNow>

`ERASE` releases the previous array before redimensioning. Document the new role in comments so future edits respect the reuse strategy.

<InfoBox>
Keep permanent data (goods, planets) in dedicated arrays, but share helper structures (parsers, message queues) to save RAM. This matters when adding map buffers later in the tier.
</InfoBox>
