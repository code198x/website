# Load Game

**Rehydrate the Space Trader universe from disk.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={85} />

## Parse saved records

<TryItNow>
```basic
10 REM SPACE TRADER - LOAD GAME
20 OPEN 1,8,2,"TRADER-DATA,S,R"
30 IF ST THEN PRINT "NO SAVE FOUND" : CLOSE 1 : END
40 DO
50 LINE INPUT#1, RECORD$
60 IF LEFT$(RECORD$,5) = "PLANET" THEN HOME = FNLOOK$(MID$(RECORD$,7))
70 IF LEFT$(RECORD$,4) = "GOOD" THEN GOSUB 200
80 IF LEFT$(RECORD$,7) = "CREDITS" THEN CREDITS = VAL(MID$(RECORD$,9))
90 IF LEFT$(RECORD$,5) = "CARGO" THEN GOSUB 220
100 LOOP UNTIL ST
110 CLOSE 1
120 PRINT "LOADED PORT:";CODE$(HOME);" CREDITS:";CREDITS
130 END

200 REM LOAD GOODS
210 PARTS = FNSTRIP$(MID$(RECORD$,6))
220 GOODS$(IDX) = PARTS$(0)
230 PRICE(IDX) = VAL(PARTS$(1))
240 CARGO(IDX) = VAL(PARTS$(2))
250 IDX = IDX + 1 : RETURN

220 REM LOAD CARGO STATE
230 PARTS = FNSTRIP$(MID$(RECORD$,7))
240 SHIPCAP = VAL(PARTS$(0)) : USEDSPACE = VAL(PARTS$(1))
250 RETURN
```
</TryItNow>

`LINE INPUT#` pulls entire records, which you then split by commas. Stub functions `FNLOOK$` and `FNSTRIP$` (implement as needed) map tokens to indexes and return arrays of pieces. `ST` flips to 64 (end-of-file) once records finish.

<InfoBox>
Keep a counter (`IDX`) when rebuilding arrays, or embed the index in the file (e.g., `GOOD3`). Either approach works as long as save and load agree.
</InfoBox>
