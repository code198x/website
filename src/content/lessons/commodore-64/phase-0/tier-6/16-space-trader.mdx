## Main loop skeleton

<TryItNow>
```basic
10 REM SPACE TRADER - FINAL BUILD
20 GOSUB INITDATA
30 GOSUB LOADMENU
40 IF LOADED = 0 THEN GOSUB DEFAULTUNIVERSE
50 GOSUB VALIDATE
60 DO
70 GOSUB DISPLAYHUD
80 GOSUB MARKETLOOP
90 GOSUB GALAXYMAP
100 GOSUB DAYADVANCE
110 LOOP

200 REM MARKET LOOP
210 PRINT "(B)UY (S)ELL (M)AP (F)UEL (Q)SAVE (X)QUIT"
220 GET CHOICE$ : IF CHOICE$ = "" THEN 220
230 IF CHOICE$ = "B" THEN GOSUB BUYGOODS
240 IF CHOICE$ = "S" THEN GOSUB SELLGOODS
250 IF CHOICE$ = "F" THEN GOSUB REFUEL
260 IF CHOICE$ = "Q" THEN GOSUB SAVEGAME
270 IF CHOICE$ = "X" THEN GOSUB SAVEASK : END
280 IF CHOICE$ = "M" THEN RETURN
290 GOTO 210
```
</TryItNow>

This framework stitches together all subsystems: initialization, save selection, market interaction, map navigation, daily price updates, and exit handling. Fill the subroutines with code from previous lessons (trading arrays, economy adjustments, cargo checks, disk routines, map rendering, etc.).
