# Data Packing

**Shrink big datasets into byte-sized bundles.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={89} />

## Combine economy + risk

<TryItNow>
```basic
10 REM SPACE TRADER - PACK DATA
20 ECON = 12 : RISK = 3
30 PACK = RISK*16 + ECON
40 PRINT "PACKED BYTE:";PACK
50 ECON = PACK AND 15
60 RISK = INT(PACK/16)
70 PRINT "ECON:";ECON/10;" RISK:";RISK

80 REM store as string for saves
90 RECORD$ = CHR$(PACK)
100 PRINT "STRING LEN:";LEN(RECORD$)
```
</TryItNow>

Because both fields fit inside four bits, you can store them in one byte. Pack additional fields (e.g., trade status flags) with higher bits or separate bytes as needed.

<InfoBox>
When saving, write the packed byte using `PRINT#1` plus `CHR$`. When loading, read with `ASC()`. This reduces save file size and load parsing time.
</InfoBox>
