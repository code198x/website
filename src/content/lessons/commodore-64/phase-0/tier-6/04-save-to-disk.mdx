# Save to Disk

**Persist the trader’s universe so progress lives beyond a session.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={84} />

## Write a save file

<TryItNow>
```basic
10 REM SPACE TRADER - SAVE GAME
20 FILENAME$ = "TRADER-DATA"
30 OPEN 1,8,2,FILENAME$+",S,W"
40 IF ST THEN PRINT "DISK ERROR:";ST : CLOSE 1 : END
50 PRINT#1,"PLANET,";CODE$(HOME)
60 FOR I=0 TO 5
70 PRINT#1,"GOOD,";GOODS$(I);",";PRICE(I);",";CARGO(I)
80 NEXT
90 PRINT#1,"CREDITS,";CREDITS
100 PRINT#1,"CARGO,";SHIPCAP;",";USEDSPACE
110 CLOSE 1
120 PRINT "GAME SAVED TO";FILENAME$
```
</TryItNow>

The `OPEN` command uses secondary address 2 for sequential writing. Using CSV-like lines keeps loading simple in the next lesson. `ST` returns the serial bus status; non-zero indicates a disk error.

<InfoBox>
Always `CLOSE` even if an error occurs—leaving a channel open can corrupt files. You’ll handle specific error codes in Lesson 86.
</InfoBox>
