# Adaptive Music

**Make your soundtrack respond to player action.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={76} />

## Reactive tempo and timbre

<TryItNow>
```basic
10 REM SID ADAPTIVE LOOP
20 GOSUB 300 : REM setup tables
30 INTENSITY = 0
40 FOR STEP = 0 TO 63
50 IF STEP = 16 OR STEP = 48 THEN INTENSITY = 10
60 IF STEP = 32 THEN INTENSITY = 3
70 BPM = 110 : IF INTENSITY > 5 THEN BPM = 160
80 VOICECTRL = 33 : IF INTENSITY > 5 THEN VOICECTRL = 65
90 GOSUB 200
100 IF INTENSITY > 0 THEN INTENSITY = INTENSITY - 1
110 NEXT
120 END

200 REM PLAY NOTE WITH CURRENT MOOD
210 TI$ = "000000"
220 JIFFIES = INT(3600/BPM)
230 FREQ = MELODY(STEP AND 15)
240 POKE 54273,FREQ AND 255 : POKE 54272,FREQ/256
250 POKE 54272,VOICECTRL
260 IF VAL(TI$) < JIFFIES THEN 260
270 POKE 54272,VOICECTRL-1 : RETURN

300 DIM MELODY(15)
310 DATA 1024,1292,1531,1364,1292,1148,1024,912,1024,0,1292,0,1364,0,1531,0
320 FOR I=0 TO 15 : READ MELODY(I) : NEXT
330 RETURN
```
</TryItNow>

The loop spikes the `INTENSITY` variable to simulate enemy waves. Higher intensity speeds up the tempo and switches the lead waveform from triangle to pulse. As intensity falls, the music cools back down.

<InfoBox>
Tie `INTENSITY` to real gameplay metrics (enemy count, player health). SID changes are instantaneous—perfect for telegraphing danger.
</InfoBox>
