# Song Arrays

**Turn note data into repeatable melodies.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={70} />

## Sequence a theme

<TryItNow>
```basic
10 REM SID SONG ARRAY
20 DIM TABLE(7)
30 DATA 1024,1148,1292,1364,1531,1625,1726,2048
40 FOR I=0 TO 7 : READ TABLE(I) : NEXT
50 DIM MELODY(15),LENGTH(15)
60 DATA 0,4, 2,4, 4,4, 5,4, 4,4, 2,4, 0,4, 0,4
70 FOR I=0 TO 7
80 READ NOTE,BEAT
90 MELODY(I)=NOTE : LENGTH(I)=BEAT
100 NEXT
110 FOR I=0 TO 7 : GOSUB 300 : NEXT
120 END

300 REM PLAY STEP
310 FREQ = TABLE(MELODY(I))
320 POKE 54273,FREQ AND 255
330 POKE 54272,FREQ/256
340 POKE 54272,17
350 FOR T=1 TO LENGTH(I)*200 : NEXT
360 POKE 54272,16 : FOR T=1 TO 80 : NEXT
370 RETURN
```
</TryItNow>

The loop reads note/duration pairs into arrays and plays them sequentially. Adjust the multiplier in line 350 to change tempo.

<InfoBox>
Add a sentinel value (e.g., `-1`) to mark the loop end when you evolve into longer songs; it keeps playback flexible even if array sizes change.
</InfoBox>
