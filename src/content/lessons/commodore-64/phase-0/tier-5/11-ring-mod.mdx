# Ring Mod

**Forge futuristic leads with ring modulation and sync.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={75} />

## Metallic sweep

<TryItNow>
```basic
10 REM SID RING MOD
20 MOD = 54272       : REM voice 1 (carrier)
30 CAR = 54279       : REM voice 2 (modulator)
40 POKE MOD+1,0 : POKE MOD,8
50 POKE MOD+5,4*16+2 : POKE MOD+6,12*16+6
60 POKE CAR+1,20 : POKE CAR,1
70 POKE CAR+5,0*16+2 : POKE CAR+6,0*16+4
80 POKE CAR+4,65 : REM pulse + gate (modulator)
90 POKE MOD+4,65+4+2 : REM pulse + gate + ring + sync
100 FOR STEP=0 TO 255 STEP 4
110 POKE CAR+1,STEP : POKE CAR,0
120 FOR T=1 TO 80 : NEXT
130 NEXT
140 POKE MOD+4,64 : POKE CAR+4,64
```
</TryItNow>

Bit 2 in the control register enables ring modulation; bit 1 engages sync. The carrier (voice 1) inherits overtones from the modulator’s frequency, producing clangorous timbres perfect for sci-fi effects.

<InfoBox>
Try disabling sync (clear bit 1) to hear the difference: ring modulation alone yields bell-like sounds, while sync adds aggressive bite.
</InfoBox>
