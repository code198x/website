# Drum Beats

**Lay down a SID rhythm section with pure noise.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={73} />

## Kick, snare, hat loop

<TryItNow>
```basic
10 REM SID DRUM GROOVE
20 POKE 54296,15
30 BASE = 54272 + 7 : REM voice 2 for drums
40 POKE BASE+5,0*16 + 2 : POKE BASE+6,0*16 + 2
50 FOR STEP = 0 TO 15
60 IF STEP MOD 4 = 0 THEN GOSUB 200  : REM kick
70 IF STEP MOD 4 = 2 THEN GOSUB 220  : REM snare
80 IF STEP MOD 2 = 1 THEN GOSUB 240  : REM hi-hat
90 FOR T=1 TO 120 : NEXT
100 NEXT
110 END

200 REM KICK - lower pitch noise
210 POKE BASE+1,40 : POKE BASE,2
215 POKE BASE+4,129
216 FOR T=1 TO 80 : NEXT
217 POKE BASE+4,128 : RETURN

220 REM SNARE - mid pitch
230 POKE BASE+1,90 : POKE BASE,3
235 POKE BASE+4,129
236 FOR T=1 TO 60 : NEXT
237 POKE BASE+4,128 : RETURN

240 REM HIHAT - fast burst
250 POKE BASE+1,200 : POKE BASE,4
255 POKE BASE+4,129
256 FOR T=1 TO 20 : NEXT
257 POKE BASE+4,128 : RETURN
```
</TryItNow>

Using the same noise voice with different frequencies and durations creates distinct percussion timbres. Interleave the pattern with your melody routine for a complete groove.

<InfoBox>
You can shorten the hi-hat by setting sustain to zero (`POKE BASE+6,0`) and relying solely on release. Tweaking frequency alone yields dozens of drum flavors.
</InfoBox>
