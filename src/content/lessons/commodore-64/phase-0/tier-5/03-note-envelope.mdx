# Note Envelope

**Give your notes punch, swell, or smooth fades.**

## Wrap ADSR in a helper

<TryItNow>
```basic
10 REM SID ENVELOPE LAB
20 GOSUB 300 : REM setup pitch table
30 PRINT "1) STACCATO  2) ORGAN  3) PAD"
40 GET K$ : IF K$ = "" THEN 40
50 IF K$ = "1" THEN A=0: D=2: S=4: R=2: GOSUB 200
60 IF K$ = "2" THEN A=4: D=5: S=12: R=3: GOSUB 200
70 IF K$ = "3" THEN A=9: D=6: S=10: R=8: GOSUB 200
80 GOTO 40

200 REM PLAY PRESET
210 POKE 54277,A*16 + D
220 POKE 54278,S*16 + R
230 FREQ = NOTE(0)
240 POKE 54273,FREQ AND 255
250 POKE 54272,FREQ/256
260 POKE 54272,17
270 FOR T = 1 TO 1200 : NEXT
280 POKE 54272,16 : RETURN

300 DIM NOTE(0)
310 NOTE(0) = 1024 : RETURN
```
</TryItNow>

The example maps keypresses to different envelope shapes. Attack/decay share one byte (high nibble/low nibble); sustain/release share the next.

<InfoBox>
SID envelope values range 0–15. Larger attack/release numbers slow ramps dramatically; experiment to match the mood of your track.
</InfoBox>
