# Note Pitches

**Swap magic numbers for meaningful note names.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={66} />

## Create a pitch table

<TryItNow>
```basic
10 REM SID PITCH TABLE
20 DIM NOTE(7)
30 DATA 1024,1084,1148,1218,1292,1364,1449,1531
40 FOR I = 0 TO 7 : READ NOTE(I) : NEXT
50 GOSUB 200
60 END

200 REM PLAY SCALE
210 FOR I = 0 TO 7
220 FREQ = NOTE(I)
230 POKE 54273,FREQ AND 255
240 POKE 54272,FREQ/256
250 POKE 54272,17
260 FOR T = 1 TO 700 : NEXT
270 POKE 54272,16 : FOR T = 1 TO 200 : NEXT
280 NEXT
290 RETURN
```
</TryItNow>

The DATA block stores C4 through C5 frequency words. Line 230 writes the low byte, 240 the high byte, then 250 gates the note.

<InfoBox>
For more octaves multiply by 2 (up an octave) or divide by 2 (down). Keep values in integer form to avoid floating point slowdown.
</InfoBox>
