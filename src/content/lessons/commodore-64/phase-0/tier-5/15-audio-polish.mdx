# Audio Polish

**Elevate your soundtrack from functional to unforgettable.**

## Vibrato + fade demo

<TryItNow>
```basic
10 REM SID POLISH TRICKS
20 BASEFREQ = 1531
30 PHASE = 0
40 DIM LFO(31)
50 FOR I=0 TO 31 : LFO(I) = INT( SIN(I/32*6.28318)*12 ) : NEXT
60 FOR STEP = 0 TO 255
70 OFFSET = LFO(PHASE)
80 FREQ = BASEFREQ + OFFSET
90 POKE 54273,FREQ AND 255 : POKE 54272,INT(FREQ/256)
100 POKE 54272,33
110 FADEVOL = 15 - (STEP/16)
120 IF FADEVOL < 0 THEN FADEVOL = 0
130 POKE 54296,FADEVOL
140 PHASE = (PHASE + 1) AND 31
150 FOR T=1 TO 80 : NEXT
160 NEXT
170 POKE 54272,32 : POKE 54296,15
```
</TryItNow>

We preload a sine lookup table and add its values around the base frequency for gentle vibrato. As the loop progresses, the master volume fades down, then resets.

<InfoBox>
Stereo illusions: alternate melody notes between voices 0 and 2, each panned left/right through your capture setup. The SID is mono, but alternating voices can mimic spatial motion.
</InfoBox>
