# Melody Maker

**Let your players compose tunes right inside the game.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={80} />

## Interactive sequencer

<TryItNow>
```basic
10 REM SID MELODY MAKER
20 DIM TABLE$(7),FREQ(7)
30 DATA "C","D","E","F","G","A","B","C+"
40 DATA 1024,1148,1292,1364,1531,1625,1726,2048
50 FOR I=0 TO 7 : READ TABLE$(I) : NEXT
60 FOR I=0 TO 7 : READ FREQ(I) : NEXT
70 DIM MELODY(15),LENGTH(15)
80 CURSOR = 0
90 PRINT "ENTER NOTES (C,D,E,F,G,A,B,C+) OR Q TO QUIT"
100 INPUT "NOTE?";N$
110 IF N$ = "Q" THEN GOTO 220
120 GOSUB 300 : INDEX = LOOKUP
130 IF INDEX < 0 THEN PRINT "UNKNOWN NOTE" : GOTO 100
140 INPUT "BEATS?";B
150 MELODY(CURSOR) = INDEX : LENGTH(CURSOR) = B
160 CURSOR = CURSOR + 1 : IF CURSOR > 15 THEN CURSOR = 16
170 GOSUB 400
180 GOTO 100

220 PRINT : PRINT "YOUR SONG:"
230 FOR I=0 TO CURSOR-1
240 PRINT "DATA ";MELODY(I);",";LENGTH(I)
250 NEXT
260 END

300 REM LOOKUP NOTE NAME
310 LOOKUP = -1
320 FOR I=0 TO 7
330 IF TABLE$(I) = N$ THEN LOOKUP = I : RETURN
340 NEXT
350 RETURN

400 REM PREVIEW NOTE
410 FREQVAL = FREQ(MELODY(CURSOR-1))
420 POKE 54273,FREQVAL AND 255 : POKE 54272,INT(FREQVAL/256)
430 POKE 54277,2*16 + 2 : POKE 54278,12*16 + 4
440 POKE 54272,33
450 FOR T=1 TO LENGTH(CURSOR-1)*200 : NEXT
460 POKE 54272,32
470 RETURN
```
</TryItNow>

Players enter note names and durations; the program appends them to arrays, plays each addition back instantly, and finally prints DATA lines ready to paste into your soundtrack code.

<InfoBox>
Extend this tool by saving melodies to disk (`OPEN 1,8,1,"MELODY,S,W"`) or by offering tempo and waveform selectors before playback.
</InfoBox>
