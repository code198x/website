## Compare voices

<TryItNow>
```basic
10 REM SID WAVE DEMO
20 FREQ = 1024
30 POKE 54273,FREQ AND 255
40 POKE 54272,FREQ/256
50 POKE 54277,4*16 + 2 : POKE 54278,12*16 + 3
60 DATA 17,33,65,129
70 DATA "TRIANGLE","SAW","PULSE","NOISE"
80 FOR I = 0 TO 3
90 READ CTRL : READ LABEL$
100 PRINT LABEL$
110 POKE 54272,CTRL
120 FOR T = 1 TO 1200 : NEXT
130 POKE 54272,CTRL AND 254
140 FOR T = 1 TO 200 : NEXT
150 NEXT
```
</TryItNow>

Each control value combines the waveform bit (4=triangle, 8=saw, 16=pulse, 128=noise) with the gate bit (1). Clearing the gate requires ANDing with 254.

<InfoBox>
Pulse wave needs an additional pulse-width setting to shine—we’ll add that later in the tier when we craft full instruments.
</InfoBox>
