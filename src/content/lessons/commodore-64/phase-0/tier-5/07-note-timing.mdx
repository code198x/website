# Note Timing

**Give your song solid tempo even with gameplay load.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={71} />

## Metronome with TI$

<TryItNow>
```basic
10 REM SID TEMPO CONTROL
20 GOSUB 300 : REM build pitch table
30 BPM = 120
35 RESTORE 40
40 DATA 0,1, 2,1, 4,2, 5,1, 4,1, 2,1, 0,2, -1,0
50 READ NOTE,BEAT
60 IF NOTE = -1 THEN END
70 GOSUB 200
80 GOTO 50

200 REM PLAY WITH TIMING
210 TI$ = "000000"
220 JIFFIES = INT(3600/BPM * BEAT)
230 FREQ = TABLE(NOTE)
240 POKE 54273,FREQ AND 255
250 POKE 54272,FREQ/256
260 POKE 54272,17
270 IF VAL(TI$) < JIFFIES THEN 270
280 POKE 54272,16 : RETURN

300 DIM TABLE(7)
310 DATA 1024,1148,1292,1364,1531,1625,1726,2048
320 FOR I=0 TO 7 : READ TABLE(I) : NEXT
330 RETURN
```
</TryItNow>

Line 220 derives the number of jiffies each beat lasts (`60 seconds * 60 jiffies = 3600`). The loop waits until the clock catches up, ensuring each note hits the tempo regardless of CPU spikes.

<InfoBox>
For swing rhythms, add or subtract a small offset per note before waiting—you’ll mimic human feel without rewriting your data.
</InfoBox>
