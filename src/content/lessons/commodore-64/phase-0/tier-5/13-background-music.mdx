# Background Music

**Let gameplay and soundtrack march together.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={77} />

## Frame-synced playback

<TryItNow>
```basic
10 REM GAME LOOP WITH MUSIC
20 GOSUB 400 : REM setup song data
30 FRAME = 0 : PAUSED = 0
40 FOR GAMELOOP = 1 TO 600
50 FRAME = FRAME + 1
60 GOSUB 200 : REM update player, enemies (stub)
70 IF PAUSED THEN GOTO 90
80 GOSUB 300 : REM music step
90 NEXT
100 END

200 REM GAME LOGIC PLACEHOLDER
210 IF FRAME MOD 180 = 0 THEN PAUSED = 1
220 IF FRAME MOD 240 = 0 THEN PAUSED = 0
230 RETURN

300 REM MUSIC STEP
310 IF FRAME MOD 6 <> 0 THEN RETURN
320 STEPIDX = (FRAME/6) MOD SONGSIZE
330 CALLNOTE = MELODY(STEPIDX)
340 CALLDUR = LENGTH(STEPIDX)
350 IF CALLNOTE = -1 THEN RETURN
360 TI$ = "000000"
370 FREQ = TABLE(CALLNOTE)
380 POKE 54273,FREQ AND 255 : POKE 54272,FREQ/256
390 POKE 54272,VOICECTRL
400 IF VAL(TI$) < CALLDUR THEN 400
410 POKE 54272,VOICECTRL-1
420 RETURN

400 REM SETUP
410 GOSUB 420
420 DIM TABLE(7) : DATA 1024,1084,1148,1218,1292,1364,1449,1531
430 FOR I=0 TO 7 : READ TABLE(I) : NEXT
440 DIM MELODY(15),LENGTH(15)
450 DATA 0,40, 2,40, 4,40, 5,40, 4,40, 2,40, 0,80, -1,0
460 FOR I=0 TO 7 : READ N,D : MELODY(I)=N : LENGTH(I)=D : NEXT : SONGSIZE = 8
470 VOICECTRL = 33 : RETURN
```
</TryItNow>

The main loop increments a frame counter, runs minimal music work every sixth frame, and respects a pause flag. As soon as the game pauses, the music routine exits without changing playback state.

<InfoBox>
For more precise timing use the raster or `TI$` between frames; the key idea is to budget music updates so they fit alongside gameplay without skipping beats.
</InfoBox>
