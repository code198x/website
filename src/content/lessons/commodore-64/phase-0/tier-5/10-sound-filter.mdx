# Sound Filter

**Sweep the SID filter for instant drama.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={74} />

## Low-pass sweep demo

<TryItNow>
```basic
10 REM SID FILTER SWEEP
20 FREQ = 1024
30 POKE 54273,FREQ AND 255 : POKE 54272,INT(FREQ/256)
40 POKE 54277,2*16 + 2 : POKE 54278,12*16 + 6
50 POKE 54272,33 : REM saw + gate
60 POKE 54295,17 : REM resonance=1, filter voice 1
70 FOR CUT = 0 TO 2047 STEP 32
80 POKE 54294,CUT AND 255
90 POKE 54293,16 + INT(CUT/256)
100 NEXT
110 POKE 54272,32 : POKE 54293,0
```
</TryItNow>

The cutoff frequency spans 11 bits across `$D416` (low byte) and the high bits in `$D417`. Updating both creates a smooth sweep. Line 90 combines low-pass mode (bit 4, value 16) with the high cutoff bits.

<InfoBox>
Raise resonance by increasing the high nibble in `$D417` (line 60). Values from 0–15 control emphasis; start low to avoid overpowering the mix.
</InfoBox>
