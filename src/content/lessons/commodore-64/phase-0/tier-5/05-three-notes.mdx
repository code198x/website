# Three Notes

**Stack harmonies for instant SID warmth.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={69} />

## Play a chord

<TryItNow>
```basic
10 REM SID CHORD TEST
20 DIM NOTE(2)
30 NOTE(0) = 1024 : NOTE(1) = 1292 : NOTE(2) = 1531
40 FOR V = 0 TO 2
50 BASE = 54272 + V*7
60 FREQ = NOTE(V)
70 POKE BASE+1,FREQ AND 255
80 POKE BASE,FREQ/256
90 POKE BASE+5,4*16 + 2
100 POKE BASE+6,12*16 + 4
110 NEXT
120 FOR V = 0 TO 2
130 BASE = 54272 + V*7
140 POKE BASE+4,33 : REM saw + gate
150 NEXT
160 FOR T = 1 TO 1500 : NEXT
170 FOR V = 0 TO 2
180 BASE = 54272 + V*7
190 POKE BASE+4,32 : REM gate off
200 NEXT
```
</TryItNow>

Each voice uses its own register block (7 bytes apart). When you gate all three simultaneously, you get lush chords perfect for title themes.

<InfoBox>
Mix waveforms: try triangle bass, saw mid, pulse lead to carve space in the mix. We’ll automate this in upcoming lessons.
</InfoBox>
