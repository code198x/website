# Game Sounds

**Layer crunchy effects over your catchy tune.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={72} />

## Split SID duties

<TryItNow>
```basic
10 REM SID MUSIC + SFX
20 DIM MELODYA(15),HARMONY(15)
30 GOSUB 400 : REM load music data
40 FOR STEP = 0 TO 15
50 GOSUB 200 : REM advance melody on voices 0 & 2
60 IF STEP MOD 4 = 0 THEN GOSUB 300
70 NEXT
80 END

200 REM MUSIC STEP
210 FREQ = MELODYA(STEP)
220 POKE 54273,FREQ AND 255 : POKE 54272,FREQ/256 : POKE 54272,17
230 FREQ = HARMONY(STEP)
240 BASE = 54272 + 14 : REM voice 3 base
250 POKE BASE+1,FREQ AND 255 : POKE BASE,FREQ/256 : POKE BASE+4,17
260 RETURN

300 REM FIRE SFX ON VOICE 2
310 BASE = 54272 + 7
320 POKE BASE+5,0*16 + 2 : POKE BASE+6,8*16 + 1
330 POKE BASE+1,90 : POKE BASE,3
340 POKE BASE+4,129 : REM noise + gate
350 FOR T=1 TO 120 : NEXT : POKE BASE+4,128
360 RETURN

400 DATA 1024,1148,1292,1364,1292,1148,1024,0,0,0,0,0,0,0,0,0
410 FOR I=0 TO 15 : READ V : MELODYA(I)=V : NEXT
420 DATA 1531,1625,1726,1821,1726,1625,1531,0,0,0,0,0,0,0,0,0
430 FOR I=0 TO 15 : READ V : HARMONY(I)=V : NEXT
440 RETURN
```
</TryItNow>

Voices 0 and 2 run melody and harmony. Voice 1 (base `54279`) remains free for noise burst effects—here triggered every fourth step. The quick attack/decay keeps the SFX from muddying the music.

<InfoBox>
When a big SFX hits, momentarily lower `POKE 54296` to drop volume, or mute one music voice for a beat to emphasize the effect.
</InfoBox>
