# Dungeon Delver

**Deliver the definitive Phase 0 dungeon crawl.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={112} />

## Core game loop

<TryItNow>
```basic
10 REM DUNGEON DELVER - FINAL BUILD
20 GOSUB INITENGINE
30 DO
40 GOSUB RASTERSPLIT
50 GOSUB PROCESSINPUT
60 GOSUB PROCESSROOM
70 IF STATE=COMBAT THEN GOSUB BATTLELOOP
80 IF STATE=SAVE THEN GOSUB SAVEGAME : STATE=EXPLORE
90 IF STATE=EXIT THEN EXIT DO
100 LOOP
110 GOSUB SHUTDOWN
120 END
```
</TryItNow>

Every subsystem from this tier plugs into the final loop: `INITENGINE` seeds the map, loads custom characters, and restores saves. `RASTERSPLIT` toggles bitmap + HUD each frame. `PROCESSROOM` handles movement, collisions, monster AI, quest triggers, and map reveals. Combat, saving, and exiting are just states the loop branches into.

<InfoBox>
Create a build checklist: confirm bitmap assets load, IRQs fire stably, debug mode still works, and save files restore flags. Capture screenshots of exploration, combat, quest dialogue, and the map overlay for documentation.
</InfoBox>

## Wrap-up checklist

- Procedural dungeon loads with monsters and quest NPCs.
- Raster split keeps bitmap action and HUD readable.
- Combat awards XP, triggers level-ups, and updates quest flags.
- Saves persist bitmap seed, flags, XP, and inventory.
- Debug mode exposes performance counters and reveals the map when needed.
