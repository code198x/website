# Pixel Collision

**Let bitmap walls block the party with pixel-perfect checks.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={106} />

## Test for solid pixels

<TryItNow>
```basic
10 REM BITMAP COLLISION TEST
20 BITMAP = 12288
30 POKE BITMAP + 100*40 + 10,255 : REM draw solid vertical wall
40 PLAYERX = 82 : PLAYERY = 100
50 DX = 1
60 BYTE = BITMAP + PLAYERY*40 + INT(PLAYERX/8)
70 MASK = 128 SHR (PLAYERX AND 7)
80 IF PEEK(BYTE) AND MASK THEN PRINT "BLOCKED" : DX = 0
90 PLAYERX = PLAYERX + DX
100 PRINT "PLAYERX:";PLAYERX
```
</TryItNow>

The code draws a solid byte-wide wall, then tests whether the player is about to step into a set bit. When the masked `PEEK` returns non-zero, you know the pixel is solid and can cancel movement.

<InfoBox>
Use the same logic for attack rays and monster pathfinding: check along the movement vector, and stop when the mask hits a solid pixel. You already have the lookup math from Lesson 100—reuse it everywhere collisions matter.
</InfoBox>
