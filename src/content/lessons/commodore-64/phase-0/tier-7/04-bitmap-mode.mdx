# Bitmap Mode

**Draw detailed dungeon rooms pixel by pixel.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={100} />

## Plot a door in hires

<TryItNow>
```basic
10 REM HIRES BITMAP DEMO
20 SCREEN = 8192 : BITMAP = 12288
30 POKE 53272,(PEEK(53272) AND 240) OR 8 : REM screen at $2000, bitmap at $3000
40 POKE 53265,PEEK(53265) OR 32 : REM enable bitmap
50 FOR I=SCREEN TO SCREEN+999: POKE I,0:NEXT
60 FOR I=BITMAP TO BITMAP+7999: POKE I,0:NEXT
70 FOR Y=80 TO 160
80 FOR X=120 TO 200 STEP 8
90 BYTE = BITMAP + (Y*40) + INT(X/8)
100 MASK = 128 SHR (X AND 7)
110 POKE BYTE, PEEK(BYTE) OR MASK
120 NEXT X
130 NEXT Y
140 PRINT CHR$(19);CHR$(1);CHR$(2);"HIRES DOOR"
```
</TryItNow>

Bitmap memory begins at `$2000` for screen codes and `$3000` for pixel data in this configuration. Plotting requires locating the byte column and setting the appropriate bit. Characters still render via the screen code area, allowing overlays like `HIRES DOOR` at the top.

<InfoBox>
Clean up by restoring text mode later: clear bit 5 in `$D011` and repoint `$D018`. Keep routines handy to toggle modes during your dungeon scenes.
</InfoBox>
