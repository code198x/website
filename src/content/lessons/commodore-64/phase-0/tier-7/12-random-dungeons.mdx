# Random Dungeons

**Deal a fresh maze every time the party descends.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={108} />

## Carve procedural rooms

<TryItNow>
```basic
10 REM RANDOM DUNGEON LAYOUT
20 MAPW=16: MAPH=12
30 DIM TILE(MAPH,MAPW)
40 INPUT "SEED";CODE
50 RND(-CODE)
60 ROOMS=6
70 FOR I=0 TO ROOMS-1
80 RX=INT(RND(1)*MAPW)
90 RY=INT(RND(1)*MAPH)
100 W=INT(RND(1)*3)+3 : H=INT(RND(1)*2)+2
110 GOSUB 500
120 IF I>0 THEN GOSUB 600
130 ROOMX=RX : ROOMY=RY
140 NEXT
150 GOSUB 700 : REM draw map
160 END

500 REM STAMP ROOM
510 FOR Y=RY TO RY+H-1
520 FOR X=RX TO RX+W-1
530 TILE(Y,X)=1
540 NEXT:NEXT:RETURN

600 REM CARVE CORRIDOR TO PREVIOUS ROOM
610 TX=ROOMX: TY=ROOMY
620 WHILE TX<>RX : TILE(TY,TX)=1 : TX=TX+SGN(RX-TX): WEND
630 WHILE TY<>RY : TILE(TY,TX)=1 : TY=TY+SGN(RY-TY): WEND
640 RETURN

700 REM RENDER ASCII MAP
710 PRINT CHR$(147)
720 FOR Y=0 TO MAPH-1
730 FOR X=0 TO MAPW-1
740 PRINT MID$(" .#",TILE(Y,X)+1,1);
750 NEXT: PRINT
760 NEXT:RETURN
```
</TryItNow>

The generator stamps rectangular rooms, then digs L-shaped corridors between successive rooms. Seeding the RNG with an input code lets you share dungeon layouts with friends: same seed, same map.

<InfoBox>
Persist the seed in your save files so returning to a floor regenerates the identical layout. For multi-level crawls, store an array of seeds—one per depth.
</InfoBox>
