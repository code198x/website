# Custom Chars

**Give your UI bespoke icons without paying the sprite cost.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={99} />

## Clone and edit the font

<TryItNow>
```basic
10 REM CUSTOM CHARSET
20 SRC = 53248 : DEST = 4096 : REM copy uppercase set
30 FOR I=0 TO 2047: POKE DEST+I,PEEK(SRC+I): NEXT
40 REM draw a heart at character 81
50 CHAR = 81 : BASE = DEST + CHAR*8
60 DATA 0,24,60,126,126,60,24,0
70 FOR ROW=0 TO 7: READ BYTE: POKE BASE+ROW,BYTE: NEXT
80 POKE 53272,(PEEK(53272) AND 240) OR 4 : REM point to $1000
90 PRINT CHR$(147)
100 PRINT "CUSTOM ICON:";CHR$(CHAR)
```
</TryItNow>

You clone the ROM font to RAM at `$1000`, modify a glyph, then update the VIC-II register (`$D018`) to use the new set. Any screen characters using code 81 now show your heart icon.

<InfoBox>
Reserve a block of character codes (e.g., 80–95) for UI icons—document them so later lessons can draw HUD elements without conflicting with text.
</InfoBox>
