## Patrol → chase logic

<TryItNow>
```basic
10 REM MONSTER AI SAMPLE
20 DIM MX(9),MY(9),STATE(9)
30 FOR I=0 TO 9: MX(I)=INT(RND(1)*320) : MY(I)=INT(RND(1)*200) : STATE(I)=0 : NEXT
40 PLAYERX=150:PLAYERY=100
50 DO
60 FOR I=0 TO 9
70 DIST = ABS(MX(I)-PLAYERX) + ABS(MY(I)-PLAYERY)
80 IF STATE(I)=0 AND DIST < 80 THEN STATE(I)=1
90 IF STATE(I)=1 AND DIST > 120 THEN STATE(I)=0
100 IF STATE(I)=1 THEN GOSUB 500 ELSE GOSUB 550
110 NEXT
120 LOOP

500 REM CHASE PLAYER
510 DX = SGN(PLAYERX-MX(I))
520 DY = SGN(PLAYERY-MY(I))
530 IF NOT COLLIDE(MX(I)+DX,MY(I)) THEN MX(I)=MX(I)+DX
540 IF NOT COLLIDE(MX(I),MY(I)+DY) THEN MY(I)=MY(I)+DY
550 RETURN

550 REM PATROL IDLE
560 IF (I AND 1)=0 THEN MX(I)=MX(I)+SGN(SIN(TI/80))
570 RETURN
```
</TryItNow>

Monsters idle until the player enters their alert radius. When engaged, they step toward the player while running the pixel collision routine from Lesson 106. Leaving the radius drops them back into patrol mode.

<InfoBox>
Add more states as needed: ranged attackers, cowardly treasure goblins, or elite guards that summon reinforcements. The key is storing per-monster state so behavior scales without giant `IF` chains.
</InfoBox>
