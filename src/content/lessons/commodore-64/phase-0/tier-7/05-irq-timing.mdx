# IRQ Timing

**Divide the screen like the pros—with precise raster interrupts.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={101} />

## Split bitmap + HUD

<TryItNow>
```basic
10 REM RASTER SPLIT DEMO
20 POKE 56334,PEEK(56334) AND 254 : REM disable CIA IRQs
30 POKE 53265,PEEK(53265) OR 128 : REM enable raster IRQ bit
40 POKE 53266,120 : REM trigger line 120
50 FOR I=0 TO 24: READ B: POKE 49152+I,B: NEXT
60 POKE 788,0 : POKE 789,192 : POKE 790,96 : REM point IRQ vector to $C000
70 SYS 49152
80 GOTO 80

90 DATA 169,6,141,32,208,169,1,141,33,208
100 DATA 169,200,141,18,208,169,1,141,25,208
110 DATA 173,36,192,141,18,208,76,129,234
120 DATA 0
```
</TryItNow>

This small machine-code routine (assembled load address `$C000`) toggles the border color at raster line 120, re-arms the raster interrupt for line 200, and hands control back to the default IRQ handler (`$EA81`). You now have a safe spot to switch bitmap parameters for the playfield, then return to character mode for your HUD.

<InfoBox>
Want two splits? Modify the routine to track state in zero page: set the next trigger to 120 for the HUD boundary and 200 for the status bar. The pattern—acknowledge `$D019`, set `$D012`, then jump to `$EA81`—is the backbone of every C64 raster trick.
</InfoBox>
