# Level Up

**Reward victories with tangible hero growth.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={110} />

## Handle post-battle growth

<TryItNow>
```basic
10 REM LEVEL UP HANDLER
20 EXP = 1200 : LEVEL = 3 : NEXTLVL = 1000
30 BATTLEXP = 350
40 EXP = EXP + BATTLEXP
50 PRINT "TOTAL XP:";EXP
60 IF EXP < NEXTLVL THEN END
70 LEVEL = LEVEL + 1
80 NEXTLVL = INT(NEXTLVL * 1.5)
90 GAINHP = INT(RND(1)*6)+4
100 GAINATK = INT(RND(1)*3)+1
110 HP = HP + GAINHP : ATK = ATK + GAINATK
120 IF LEVEL = 4 THEN SPELL$="ARC FLASH"
130 PRINT "LEVEL";LEVEL;"! HP+";GAINHP;" ATK+";GAINATK
140 IF SPELL$<>"" THEN PRINT "LEARNED:";SPELL$
```
</TryItNow>

The routine increments experience, checks for level thresholds, then boosts stats accordingly. Milestone rewards—new spells, abilities, or inventory slots—drop in once level requirements are met.

<InfoBox>
Store upcoming thresholds in a table (e.g., `LVLXP(1)=0`, `LVLXP(2)=200`, etc.) to avoid floating-point math. For multiple party members, place this logic in a subroutine and pass character indexes as parameters.
</InfoBox>
