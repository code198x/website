# Turn Combat

**Stage tense battles that honor classic dungeon crawlers.**

## Roll initiative and act

<TryItNow>
```basic
10 REM TURN-BASED COMBAT LOOP
20 DIM HP(4),TYPE$(4),ORDER(4),INIT(4)
30 HP(0)=50:TYPE$(0)="HERO"
40 FOR I=1 TO 4: HP(I)=INT(RND(1)*20)+20:TYPE$(I)="GOB"+CHR$(47+I): NEXT
50 GOSUB 400
60 DO
70 FOR TURN=0 TO 4
80 C=ORDER(TURN)
90 IF HP(C)<=0 THEN 130
100 IF C=0 THEN GOSUB 200 ELSE GOSUB 300
110 IF HP(0)<=0 OR MONSTERSDEAD THEN EXIT DO
130 NEXT
140 GOSUB 400
150 LOOP
160 PRINT "BATTLE OVER"
170 END

200 REM PLAYER ACTION
210 PRINT "(A)TTACK (P)OTION";
220 GET K$: IF K$="" THEN 220
230 IF K$="A" THEN TARGET=FIRSTALIVE : GOSUB 500
240 IF K$="P" THEN HP(0)=HP(0)+15
250 RETURN

300 REM MONSTER AI
310 TARGET=0
320 GOSUB 500
330 RETURN

400 REM ROLL INIT
410 FOR I=0 TO 4: INIT(I)=INT(RND(1)*20)+I : ORDER(I)=I : NEXT
420 FOR I=0 TO 3: FOR J=I+1 TO 4
430 IF INIT(J)>INIT(I) THEN SWAP INIT(J),INIT(I): SWAP ORDER(J),ORDER(I)
440 NEXT:NEXT
450 RETURN

500 REM RESOLVE ATTACKER C AGAINST TARGET
510 DMG=INT(RND(1)*10)+5
520 HP(TARGET)=HP(TARGET)-DMG
530 IF TARGET>0 AND HP(TARGET)<=0 THEN GOSUB 600
540 IF TARGET=0 AND HP(0)<=0 THEN PRINT "YOU FALL!"
550 RETURN

600 REM CHECK MONSTER COUNT
610 MONSTERSDEAD=-1
620 FOR I=1 TO 4: IF HP(I)>0 THEN MONSTERSDEAD=0
630 NEXT
640 RETURN
```
</TryItNow>

Initiative is rolled each round, sorted with a simple bubble swap, and stored in `ORDER()`. The loop cycles through participants, calling either the player or monster subroutine. Victory triggers once all monsters drop; defeat fires when the hero’s HP hits zero.

<InfoBox>
Extend the attack routine to incorporate weapons, spells, and status effects. Because the action resolution is encapsulated in subroutines, adding features simply means expanding those blocks—not rewriting the main loop.
</InfoBox>
