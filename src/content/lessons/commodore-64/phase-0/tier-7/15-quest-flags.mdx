## Manage story state

<TryItNow>
```basic
10 REM QUEST FLAG SYSTEM
20 ELDER_RESCUED = 0
30 DIM FLAG(15)
40 FLAG(ELDER_RESCUED) = 0
50 IF ROOM=12 AND FLAG(ELDER_RESCUED)=0 THEN GOSUB 200
60 PRINT "ELDER SAVED?";FLAG(ELDER_RESCUED)
70 REM SAVE FLAGS PACKED
80 BYTE=0
90 FOR I=0 TO 7
100 BYTE=BYTE OR (FLAG(I) AND 1)*2^I
110 NEXT
120 FLAGSTR$=CHR$(BYTE)
130 PRINT "SAVE BYTE:";ASC(FLAGSTR$)

200 REM ELDER EVENT
210 PRINT "YOU FOUND THE ELDER!"
220 FLAG(ELDER_RESCUED)=1
230 RETURN
```
</TryItNow>

Flags track story milestones in simple arrays. Packing them into a byte makes saving efficient—up to eight quest states per character. When the player re-enters a room, check flags to decide whether to trigger dialogue, spawn bosses, or award treasure.

<InfoBox>
Reserve index ranges: 0–15 for global story, 16–31 for per-level puzzles. Document each flag in a table so writers and coders stay synced.
</InfoBox>
