# Speed Calls

**Borrow the C64 ROM routines to sprint past BASIC bottlenecks.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={97} />

## Compare BASIC vs SYS

<TryItNow>
```basic
10 REM SPEED CALLS BENCHMARK
20 TI$ = "000000"
30 FOR I=1 TO 100: GOSUB 200: NEXT
40 BASICTIME = VAL(TI$)
50 TI$ = "000000"
60 FOR I=1 TO 100: SYS 58732: NEXT
70 KERNALTIME = VAL(TI$)
80 PRINT "BASIC CLS:";BASICTIME;"  SYS CLS:";KERNALTIME
90 END

200 REM BASIC CLEAR SCREEN
210 PRINT CHR$(147);
220 RETURN
```
</TryItNow>

Calling the KERNAL clear-screen routine (`SYS 58732`) dramatically outpaces printing `CHR$(147)` in a loop. Timing with `TI$` reveals just how much time you save when delegating work to machine code.

<InfoBox>
Keep a cheat sheet of KERNAL entry points (e.g., `58672` for home cursor, `65250` for random byte). Each gives you a performance boost without diving fully into assembly yet.
</InfoBox>
