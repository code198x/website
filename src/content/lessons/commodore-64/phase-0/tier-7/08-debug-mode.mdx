# Debug Mode

**Give yourself x-ray vision while building the crawler.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={104} />

## Toggle debug on the fly

<TryItNow>
```basic
10 REM DEBUG TOGGLE SAMPLE
20 DEBUG = 0
30 DO
40 GOSUB GETKEY
50 IF KEY$="\" THEN DEBUG = 1-DEBUG
60 IF DEBUG THEN GOSUB DRAWMAP ELSE GOSUB DRAWROOM
70 IF DEBUG THEN GOSUB SHOWSTATS ELSE GOSUB MONSTERMOVE
80 LOOP

200 REM SHOW STATS
210 PRINT CHR$(19);CHR$(1);CHR$(1);
220 PRINT "DEBUG ON  X:";PLAYERX;" Y:";PLAYERY;
230 PRINT " MONSTERS:";MONCOUNT;" RAM:";FRE(0)
240 RETURN
```
</TryItNow>

With debug active, the game prints coordinates, monster counts, and free memory while skipping the monster AI routine. The toggle lives behind the backslash key; testers can enable it mid-run to diagnose issues without editing code.

<InfoBox>
Extend debug mode with options like revealing the minimap, refilling HP, or spawning loot. Just remember to disable it in release builds (or guard it behind a secret code) so players don’t break progression accidentally.
</InfoBox>
