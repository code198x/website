## Beyond PETSCII Limitations

Your ship customization system works great with standard PETSCII characters, but the C64 has a secret weapon: **custom character sets**. By redefining the character ROM, you can create completely unique ship designs that no other game has ever used:

<TryItNow>
```basic
10 REM CUSTOM SHIP CHARACTER DESIGNER
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "CUSTOM SHIP CHARACTER DESIGNER"; OFF$
40 PRINT STRING$(40, "═")
45 REM SWITCH TO CUSTOM CHARACTER SET
50 POKE 53272, (PEEK(53272) AND 240) OR 14: REM POINT TO $3800
55 REM CUSTOM SHIP DESIGNS (8 BYTES EACH)
60 REM SHIP DESIGN #1 - ARROW FIGHTER
65 FOR I = 0 TO 7
70   READ B: POKE 14336 + I, B: REM $3800 + offset
75 NEXT I
80 REM SHIP DESIGN #2 - WIDE CRUISER
85 FOR I = 0 TO 7
90   READ B: POKE 14344 + I, B: REM $3808 + offset
95 NEXT I
100 REM SHIP DESIGN #3 - NEEDLE SCOUT
105 FOR I = 0 TO 7
110   READ B: POKE 14352 + I, B: REM $3810 + offset
115 NEXT I
120 REM DISPLAY CUSTOM SHIPS
125 PRINT "CUSTOM SHIP DESIGNS:"
130 PRINT STRING$(40, "─")
135 PRINT "ARROW FIGHTER: "; GREEN$; CHR$(0); OFF$; " (BALANCED)"
140 PRINT "WIDE CRUISER:  "; CYAN$; CHR$(1); OFF$; " (HEAVY ARMOR)"
145 PRINT "NEEDLE SCOUT:  "; YELLOW$; CHR$(2); OFF$; " (HIGH SPEED)"
150 PRINT STRING$(40, "─")
155 PRINT "SHIP COMPARISON:"
160 PRINT TAB(5); "STANDARD: "; "▲"; " (PETSCII)"
165 PRINT TAB(5); "CUSTOM:   "; GREEN$; CHR$(0); OFF$; " (UNIQUE DESIGN)"
170 PRINT
175 INPUT "PRESS ENTER TO SEE ANIMATION"; DUMMY$
180 REM ANIMATE CUSTOM SHIPS
185 FOR DEMO = 1 TO 3
190   FOR X = 5 TO 35
195     REM CLEAR OLD POSITION
200     PRINT CHR$(19): PRINT TAB(X - 1); " "
205     REM DRAW SHIP AT NEW POSITION
210     PRINT TAB(X); GREEN$; CHR$(0); OFF$
215     FOR DELAY = 1 TO 50: NEXT DELAY
220   NEXT X
225 NEXT DEMO
230 PRINT: PRINT YELLOW$; "CUSTOM CHARACTERS COMPLETE!"; OFF$
235 END
500 REM ARROW FIGHTER BITMAP DATA
505 DATA 8, 28, 62, 127, 62, 28, 8, 0
510 REM WIDE CRUISER BITMAP DATA
515 DATA 0, 24, 60, 126, 255, 126, 60, 24
520 REM NEEDLE SCOUT BITMAP DATA
525 DATA 16, 16, 24, 28, 28, 24, 16, 16
```
</TryItNow>

**Custom Character Features:**
- **Memory redirection** (line 50) points character set to RAM for modification
- **Bitmap data definition** (505-525) creates unique 8x8 pixel ship designs
- **Direct memory modification** (70, 90, 110) stores custom graphics in character RAM
- **Instant visual results** (135-145) shows custom ships alongside standard PETSCII

Your ships are now completely unique - no other game in the world has these exact designs!

`★ Insight ─────────────────────────────────────`
**Custom character sets are the C64's hidden superpower**. While other systems require complex sprite programming, the C64 lets you create unique graphics by simply redefining letters and symbols. The character ROM becomes your canvas - CHR$(0) can be anything you design.

**Bitmap thinking is pixel art**. Each byte represents one row of 8 pixels. The number 127 = 01111111 binary = a triangle shape. This direct binary-to-visual relationship made 1980s programmers think in pixels and bits.
`─────────────────────────────────────────────────`

## Frame-Based Ship Animation

Custom characters are just the beginning. Let's add animation cycles that make ships feel alive with engine thrust, rotation, and damage states:

<TryItNow>
```basic
10 REM ANIMATED SHIP SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ANIMATED SHIP SYSTEM"; OFF$
40 PRINT STRING$(40, "═")
45 REM SET UP CUSTOM CHARACTER SPACE
50 POKE 53272, (PEEK(53272) AND 240) OR 14
55 REM ANIMATION FRAMES FOR MAIN SHIP (4 FRAMES)
60 REM FRAME 1 - NORMAL
65 FOR I = 0 TO 7: READ B: POKE 14336 + I, B: NEXT I
70 REM FRAME 2 - THRUST LEFT
75 FOR I = 0 TO 7: READ B: POKE 14344 + I, B: NEXT I
80 REM FRAME 3 - THRUST RIGHT
85 FOR I = 0 TO 7: READ B: POKE 14352 + I, B: NEXT I
90 REM FRAME 4 - THRUST FULL
95 FOR I = 0 TO 7: READ B: POKE 14360 + I, B: NEXT I
100 REM ENGINE GLOW CHARACTERS (2 FRAMES)
105 REM GLOW 1 - DIM
110 FOR I = 0 TO 7: READ B: POKE 14368 + I, B: NEXT I
115 REM GLOW 2 - BRIGHT
120 FOR I = 0 TO 7: READ B: POKE 14376 + I, B: NEXT I
125 REM SHIP VARIABLES
130 SHIP_X = 20: SHIP_Y = 12: SHIP_FRAME = 0
135 THRUST_FRAME = 0: ANIMATION_COUNTER = 0
140 REM MAIN ANIMATION LOOP
145 ANIMATION_COUNTER = ANIMATION_COUNTER + 1
150 REM READ CONTROLS
155 GET KEY$
160 OLD_FRAME = SHIP_FRAME: OLD_THRUST = THRUST_FRAME
165 REM DETERMINE ANIMATION BASED ON INPUT
170 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_FRAME = 1: SHIP_X = SHIP_X - 1
175 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_FRAME = 2: SHIP_X = SHIP_X + 1
180 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_FRAME = 3: SHIP_Y = SHIP_Y - 1
185 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
190 IF KEY$ = "" THEN SHIP_FRAME = 0
195 IF KEY$ = "Q" OR KEY$ = "q" THEN 400
200 REM ANIMATE ENGINE GLOW
205 THRUST_FRAME = (ANIMATION_COUNTER MOD 8) / 4: REM ALTERNATE EVERY 4 FRAMES
210 REM BOUNDARY CHECKING
215 IF SHIP_X < 1 THEN SHIP_X = 1
220 IF SHIP_X > 38 THEN SHIP_X = 38
225 IF SHIP_Y < 5 THEN SHIP_Y = 5
230 IF SHIP_Y > 20 THEN SHIP_Y = 20
235 REM CLEAR OLD SHIP POSITION IF MOVED
240 IF SHIP_X <> PREV_X OR SHIP_Y <> PREV_Y THEN GOSUB 2000
245 REM DRAW ANIMATED SHIP
250 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
255 REM SELECT COLOR BASED ON ANIMATION STATE
260 SHIP_COLOR$ = GREEN$
265 IF SHIP_FRAME = 1 THEN SHIP_COLOR$ = CYAN$: REM LEFT THRUST
270 IF SHIP_FRAME = 2 THEN SHIP_COLOR$ = CYAN$: REM RIGHT THRUST
275 IF SHIP_FRAME = 3 THEN SHIP_COLOR$ = RED$: REM FULL THRUST
280 REM DRAW MAIN SHIP
285 PRINT TAB(SHIP_X); SHIP_COLOR$; CHR$(SHIP_FRAME); OFF$
290 REM DRAW ENGINE GLOW BEHIND SHIP
295 IF SHIP_FRAME > 0 THEN PRINT TAB(SHIP_X) SPC(1); YELLOW$; CHR$(4 + THRUST_FRAME); OFF$
300 REM STATUS DISPLAY
305 PRINT CHR$(19): PRINT TAB(25); "FRAME:"; ANIMATION_COUNTER
310 PRINT TAB(25); "STATE:";
315 IF SHIP_FRAME = 0 THEN PRINT "CRUISE"
320 IF SHIP_FRAME = 1 THEN PRINT "LEFT"
325 IF SHIP_FRAME = 2 THEN PRINT "RIGHT"
330 IF SHIP_FRAME = 3 THEN PRINT "BOOST"
335 REM STORE POSITION FOR NEXT FRAME
340 PREV_X = SHIP_X: PREV_Y = SHIP_Y
345 GOTO 145
400 PRINT: PRINT YELLOW$; "ANIMATION SYSTEM OFFLINE"; OFF$
405 END
500 REM SHIP ANIMATION FRAMES
505 REM NORMAL STATE
510 DATA 8, 28, 62, 127, 62, 28, 8, 0
515 REM LEFT THRUST
520 DATA 4, 14, 31, 63, 31, 14, 4, 2
525 REM RIGHT THRUST
530 DATA 16, 56, 124, 252, 124, 56, 16, 32
535 REM FULL THRUST
540 DATA 8, 28, 62, 255, 255, 62, 28, 8
545 REM ENGINE GLOW - DIM
550 DATA 0, 0, 8, 28, 28, 8, 0, 0
555 REM ENGINE GLOW - BRIGHT
560 DATA 0, 8, 28, 62, 62, 28, 8, 0
2000 REM CLEAR OLD SHIP POSITION
2005 PRINT CHR$(19): FOR I = 1 TO PREV_Y: PRINT CHR$(17);: NEXT I
2010 PRINT TAB(PREV_X); " "; TAB(PREV_X + 1); " "
2015 RETURN
```
</TryItNow>

**Frame-Based Animation Features:**
- **Multiple ship states** (510-540) show different thrust directions
- **Animated engine glow** (550-560) pulses behind the ship during movement
- **State-driven colors** (265-275) change ship appearance based on maneuvers
- **Smooth clearing system** (2000-2015) prevents visual artifacts between frames

Your ship now responds visually to every control input with smooth, professional animation!

<InfoBox>
Frame-based animation was the secret sauce of 1980s arcade games. Instead of complex sprite hardware, clever programmers used character animation to create fluid movement. The C64's ability to redefine characters in real-time meant unlimited animation possibilities - limited only by memory and imagination.
</InfoBox>

## Dynamic Ship State System

Let's add the final touch - ships that show damage, power levels, and special states through visual transformation:

<TryItNow>
```basic
10 REM DYNAMIC SHIP STATE SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "DYNAMIC SHIP STATE SYSTEM"; OFF$
40 PRINT STRING$(40, "═")
45 REM SET UP EXTENDED CHARACTER SET
50 POKE 53272, (PEEK(53272) AND 240) OR 14
55 REM SHIP HEALTH STATES (0=PERFECT, 7=DESTROYED)
60 FOR STATE = 0 TO 7
65   FOR I = 0 TO 7
70     READ B: POKE 14336 + (STATE * 8) + I, B
75   NEXT I
80 NEXT STATE
85 REM SHIP VARIABLES
90 SHIP_X = 20: SHIP_Y = 12: SHIP_HEALTH = 100
95 SHIELD_POWER = 50: WEAPON_HEAT = 0
100 BLINK_COUNTER = 0: DAMAGE_COUNTER = 0
105 REM MAIN GAME LOOP
110 BLINK_COUNTER = BLINK_COUNTER + 1
115 REM SIMULATE RANDOM EVENTS
120 IF RND(1) < 0.02 THEN SHIP_HEALTH = SHIP_HEALTH - 5: DAMAGE_COUNTER = 20
125 IF RND(1) < 0.01 THEN SHIELD_POWER = SHIELD_POWER + 10: IF SHIELD_POWER > 100 THEN SHIELD_POWER = 100
130 IF RND(1) < 0.03 THEN WEAPON_HEAT = WEAPON_HEAT + 10: IF WEAPON_HEAT > 100 THEN WEAPON_HEAT = 100
135 REM READ CONTROLS
140 GET KEY$
145 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
150 IF KEY$ = "D" AND SHIP_X < 38 THEN SHIP_X = SHIP_X + 1
155 IF KEY$ = "W" AND SHIP_Y > 5 THEN SHIP_Y = SHIP_Y - 1
160 IF KEY$ = "S" AND SHIP_Y < 20 THEN SHIP_Y = SHIP_Y + 1
165 IF KEY$ = "R" THEN SHIP_HEALTH = 100: SHIELD_POWER = 50: WEAPON_HEAT = 0: REM REPAIR
170 IF KEY$ = "Q" THEN 500
175 REM CALCULATE DAMAGE COUNTERS
180 IF DAMAGE_COUNTER > 0 THEN DAMAGE_COUNTER = DAMAGE_COUNTER - 1
185 IF WEAPON_HEAT > 0 THEN WEAPON_HEAT = WEAPON_HEAT - 1
190 REM DETERMINE SHIP STATE FROM HEALTH
195 DAMAGE_STATE = INT((100 - SHIP_HEALTH) / 12.5): REM 0-7 SCALE
200 IF DAMAGE_STATE > 7 THEN DAMAGE_STATE = 7
205 REM CLEAR AND REDRAW SHIP
210 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
215 REM DETERMINE SHIP COLOR BASED ON STATES
220 SHIP_COLOR$ = GREEN$: REM DEFAULT HEALTHY
225 IF WEAPON_HEAT > 80 THEN SHIP_COLOR$ = RED$: REM OVERHEATING
230 IF SHIELD_POWER > 80 THEN SHIP_COLOR$ = CYAN$: REM SHIELDS UP
235 IF DAMAGE_COUNTER > 0 THEN SHIP_COLOR$ = YELLOW$: REM RECENT DAMAGE
236 REM CRITICAL DAMAGE BLINKING
240 IF SHIP_HEALTH < 25 AND (BLINK_COUNTER MOD 8 < 4) THEN SHIP_COLOR$ = RED$
245 REM DRAW SHIP WITH DAMAGE STATE
250 PRINT TAB(SHIP_X); SHIP_COLOR$; CHR$(DAMAGE_STATE); OFF$
255 REM SHIP STATUS DISPLAY
260 PRINT CHR$(19): PRINT TAB(10); "SHIP STATUS:"
265 PRINT TAB(10); "HEALTH: ";
270 IF SHIP_HEALTH > 70 THEN PRINT GREEN$; ELSE IF SHIP_HEALTH > 30 THEN PRINT YELLOW$; ELSE PRINT RED$
275 FOR I = 1 TO INT(SHIP_HEALTH / 5): PRINT "█";: NEXT I
280 PRINT OFF$; " "; SHIP_HEALTH; "%"
285 PRINT TAB(10); "SHIELDS: ";
290 IF SHIELD_POWER > 70 THEN PRINT CYAN$; ELSE IF SHIELD_POWER > 30 THEN PRINT PURPLE$; ELSE PRINT BLUE$
295 FOR I = 1 TO INT(SHIELD_POWER / 5): PRINT "▒";: NEXT I
300 PRINT OFF$; " "; SHIELD_POWER; "%"
305 PRINT TAB(10); "WEAPONS: ";
310 IF WEAPON_HEAT < 50 THEN PRINT GREEN$; ELSE IF WEAPON_HEAT < 80 THEN PRINT YELLOW$; ELSE PRINT RED$
315 FOR I = 1 TO INT(WEAPON_HEAT / 5): PRINT "▓";: NEXT I
320 PRINT OFF$; " "; WEAPON_HEAT; "%"
325 GOTO 110
500 PRINT: PRINT YELLOW$; "SHIP SYSTEMS OFFLINE"; OFF$
505 END
600 REM SHIP DAMAGE STATES (8 STATES)
605 REM STATE 0 - PERFECT CONDITION
610 DATA 8, 28, 62, 127, 127, 62, 28, 8
615 REM STATE 1 - MINOR DAMAGE
620 DATA 8, 28, 62, 119, 127, 62, 28, 8
625 REM STATE 2 - LIGHT DAMAGE
630 DATA 8, 28, 54, 115, 119, 62, 28, 8
635 REM STATE 3 - MODERATE DAMAGE
640 DATA 8, 28, 50, 99, 115, 54, 28, 8
645 REM STATE 4 - HEAVY DAMAGE
650 DATA 8, 20, 34, 67, 99, 50, 20, 8
655 REM STATE 5 - SEVERE DAMAGE
660 DATA 8, 20, 34, 65, 67, 34, 20, 8
665 REM STATE 6 - CRITICAL DAMAGE
670 DATA 0, 16, 32, 64, 65, 32, 16, 0
675 REM STATE 7 - DESTROYED
680 DATA 0, 16, 40, 68, 68, 40, 16, 0
```
</TryItNow>

**Dynamic State Features:**
- **Progressive damage visualization** (610-680) shows 8 levels of ship deterioration
- **Multi-factor color coding** (225-240) indicates weapon heat, shields, and damage simultaneously
- **Critical damage blinking** (240) creates urgent visual warning when health is low
- **Real-time status bars** (270-320) provide detailed system information

Your ships now tell a visual story of every battle they've endured!
