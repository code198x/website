# High Scores

**From transient fun to lasting glory! Transform individual gaming sessions into permanent achievements that create competition, drive replayability, and give players something to boast about.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={39} />

## The Psychology of Achievement

Your progressive difficulty system creates engaging gameplay, but there's one more ingredient that separates good games from obsessively playable ones: **permanent achievement**. High scores turn every game session into a battle against your previous best:

<TryItNow>
```basic
10 REM BASIC HIGH SCORE SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ASTEROID DODGER - HIGH SCORE EDITION"; OFF$
35 PRINT STRING$(40, "═")
40 REM HIGH SCORE VARIABLES
45 HIGH_SCORE = 0: HIGH_SCORER$ = "NOBODY YET"
50 CURRENT_SCORE = 0: PLAYER_NAME$ = ""
55 REM LOAD PREVIOUS HIGH SCORE (SIMPLE VERSION)
60 READ HIGH_SCORE, HIGH_SCORER$
65 PRINT "CURRENT CHAMPION: "; GREEN$; HIGH_SCORER$; OFF$
70 PRINT "SCORE TO BEAT: "; YELLOW$; HIGH_SCORE; OFF$
75 PRINT STRING$(40, "─")
80 INPUT "ENTER YOUR NAME (8 LETTERS): "; PLAYER_NAME$
85 IF LEN(PLAYER_NAME$) > 8 THEN PLAYER_NAME$ = LEFT$(PLAYER_NAME$, 8)
90 PRINT
95 REM SIMULATE GAME (RANDOM SCORE FOR DEMO)
100 PRINT "STARTING GAME...";
105 FOR I = 1 TO 3: PRINT ".";: FOR J = 1 TO 200: NEXT J: NEXT I
110 PRINT " PLAYING!"
115 REM SIMULATE GAMEPLAY WITH RANDOM SCORE
120 CURRENT_SCORE = RND(1) * 50000 + 10000
125 FOR I = 1 TO 10: PRINT ".";: FOR J = 1 TO 100: NEXT J: NEXT I
130 PRINT
135 PRINT "GAME OVER!"
140 PRINT "YOUR SCORE: "; CURRENT_SCORE
145 REM CHECK FOR HIGH SCORE
150 IF CURRENT_SCORE <= HIGH_SCORE THEN 200
155 REM NEW HIGH SCORE CELEBRATION!
160 PRINT
165 FOR I = 1 TO 3: PRINT CHR$(7);: NEXT I
170 PRINT RED$; "*** NEW HIGH SCORE! ***"; OFF$
175 PRINT GREEN$; PLAYER_NAME$; ", YOU ARE THE NEW CHAMPION!"; OFF$
180 PRINT "PREVIOUS RECORD: "; HIGH_SCORE; " BY "; HIGH_SCORER$
185 PRINT "YOUR NEW RECORD: "; CURRENT_SCORE
190 PRINT YELLOW$; "YOUR INITIALS WILL LIVE FOREVER!"; OFF$
195 GOTO 250
200 REM NOT A HIGH SCORE
205 PRINT
210 DIFFERENCE = HIGH_SCORE - CURRENT_SCORE
215 PRINT "NOT QUITE A HIGH SCORE..."
220 PRINT "YOU NEEDED "; DIFFERENCE; " MORE POINTS"
225 PRINT "CHAMPION "; HIGH_SCORER$; " KEEPS THE CROWN WITH "; HIGH_SCORE
230 PRINT PURPLE$; "TRY AGAIN TO CLAIM VICTORY!"; OFF$
235 GOTO 250
250 PRINT
255 PRINT WHITE$; "GAME SESSION COMPLETE"; OFF$
260 END
300 REM HIGH SCORE DATA
305 DATA 24750, "STARDUST"
```
</TryItNow>

**High Score Psychology:**
- **Permanent record** (line 60) loads previous achievements to beat
- **Personal identity** (80-85) connects the score to the player's name
- **Celebration ritual** (160-190) makes new records feel special
- **Motivation for retry** (210-230) shows exactly what's needed to win

This simple system transforms a one-time game into an ongoing challenge!

`★ Insight ─────────────────────────────────────`
**High scores are pure psychology**. They don't change the gameplay, but they completely transform the emotional experience. Instead of "I played a game," it becomes "I'm hunting for the record." The score becomes more important than the fun - and that's exactly what keeps players coming back!

**Champion displacement** is the secret sauce. When you see "STARDUST - 24750," you're not just playing against the game anymore - you're playing against a person. That makes it personal.
`─────────────────────────────────────────────────`

## Multi-Tier Achievement System

Professional arcade games didn't just track one high score - they created achievement hierarchies that rewarded different types of excellence:

<TryItNow>
```basic
10 REM MULTI-TIER ACHIEVEMENT SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ASTEROID DODGER - ACHIEVEMENT HALL"; OFF$
40 PRINT STRING$(40, "═")
45 REM ACHIEVEMENT CATEGORIES
50 DIM ACHIEVEMENT$(8), RECORD(8), HOLDER$(8)
55 REM LOAD ACHIEVEMENT DATA
60 FOR I = 1 TO 8
65   READ ACHIEVEMENT$(I), RECORD(I), HOLDER$(I)
70 NEXT I
75 PRINT "HALL OF FAME - CURRENT CHAMPIONS"
80 PRINT STRING$(40, "─")
85 FOR I = 1 TO 8
90   PRINT LEFT$(ACHIEVEMENT$(I) + STRING$(20, " "), 20);
95   PRINT RIGHT$(HOLDER$(I) + STRING$(8, " "), 8); ": ";
100   PRINT RECORD(I)
105 NEXT I
110 PRINT STRING$(40, "─")
115 INPUT "PRESS ENTER TO START YOUR ATTEMPT"; DUMMY$
120 REM GAME SIMULATION WITH MULTIPLE STATS
125 FINAL_SCORE = 0: WAVES_COMPLETED = 0: SURVIVAL_TIME = 0
130 PERFECT_DODGES = 0: BULLETS_FIRED = 0: ACCURACY = 0
135 MAX_SPEED_REACHED = 0: ASTEROIDS_DESTROYED = 0
140 REM SIMULATE GAME SESSION
145 PRINT "PLAYING GAME...";
150 FOR I = 1 TO 20: PRINT ".";: FOR J = 1 TO 50: NEXT J: NEXT I
155 PRINT " COMPLETE!"
160 REM GENERATE RANDOM STATS FOR DEMO
165 FINAL_SCORE = RND(1) * 40000 + 15000
170 WAVES_COMPLETED = RND(1) * 15 + 5
175 SURVIVAL_TIME = RND(1) * 300 + 120
180 PERFECT_DODGES = RND(1) * 50 + 20
185 BULLETS_FIRED = RND(1) * 200 + 100
190 ACCURACY = INT((BULLETS_FIRED - RND(1) * 50) / BULLETS_FIRED * 100)
195 MAX_SPEED_REACHED = RND(1) * 8 + 3
200 ASTEROIDS_DESTROYED = RND(1) * 100 + 50
205 PRINT
210 PRINT GREEN$; "FINAL STATISTICS:"; OFF$
215 PRINT "SCORE: "; FINAL_SCORE
220 PRINT "WAVES: "; WAVES_COMPLETED
225 PRINT "SURVIVAL: "; SURVIVAL_TIME; " SEC"
230 PRINT "PERFECT DODGES: "; PERFECT_DODGES
235 PRINT "ACCURACY: "; ACCURACY; "%"
240 PRINT "MAX SPEED: "; MAX_SPEED_REACHED
245 PRINT "DESTROYED: "; ASTEROIDS_DESTROYED
250 REM CHECK FOR RECORDS
255 RECORDS_BROKEN = 0
260 IF FINAL_SCORE > RECORD(1) THEN GOSUB 1000: RECORDS_BROKEN = RECORDS_BROKEN + 1
265 IF WAVES_COMPLETED > RECORD(2) THEN GOSUB 1100: RECORDS_BROKEN = RECORDS_BROKEN + 1
270 IF SURVIVAL_TIME > RECORD(3) THEN GOSUB 1200: RECORDS_BROKEN = RECORDS_BROKEN + 1
275 IF PERFECT_DODGES > RECORD(4) THEN GOSUB 1300: RECORDS_BROKEN = RECORDS_BROKEN + 1
280 IF ACCURACY > RECORD(5) THEN GOSUB 1400: RECORDS_BROKEN = RECORDS_BROKEN + 1
285 IF MAX_SPEED_REACHED > RECORD(6) THEN GOSUB 1500: RECORDS_BROKEN = RECORDS_BROKEN + 1
290 IF ASTEROIDS_DESTROYED > RECORD(7) THEN GOSUB 1600: RECORDS_BROKEN = RECORDS_BROKEN + 1
295 REM OVERALL PERFORMANCE RATING
300 PERFORMANCE = FINAL_SCORE + WAVES_COMPLETED * 1000 + SURVIVAL_TIME * 50
305 IF PERFORMANCE > RECORD(8) THEN GOSUB 1700: RECORDS_BROKEN = RECORDS_BROKEN + 1
310 REM ACHIEVEMENT SUMMARY
315 PRINT
320 IF RECORDS_BROKEN = 0 THEN PRINT PURPLE$; "NO RECORDS BROKEN TODAY"; OFF$: GOTO 350
325 IF RECORDS_BROKEN = 1 THEN PRINT YELLOW$; "1 RECORD BROKEN!"; OFF$: GOTO 350
330 PRINT RED$; RECORDS_BROKEN; " RECORDS BROKEN! INCREDIBLE!"; OFF$
335 FOR I = 1 TO RECORDS_BROKEN: PRINT CHR$(7);: NEXT I
350 END
400 REM ACHIEVEMENT DATA
405 DATA "HIGHEST SCORE", 32500, "PHOENIX"
410 DATA "MOST WAVES", 12, "ENDURER"
415 DATA "LONGEST SURVIVAL", 280, "SURVIVOR"
420 DATA "PERFECT DODGES", 45, "GHOST"
425 DATA "BEST ACCURACY", 89, "SNIPER"
430 DATA "TOP SPEED", 9, "ROCKET"
435 DATA "MOST DESTROYED", 95, "HUNTER"
440 DATA "OVERALL RATING", 75000, "LEGEND"
1000 REM HIGH SCORE RECORD
1005 PRINT CYAN$; "NEW HIGH SCORE RECORD!"; OFF$: RETURN
1100 REM WAVE COMPLETION RECORD
1105 PRINT CYAN$; "NEW WAVE COMPLETION RECORD!"; OFF$: RETURN
1200 REM SURVIVAL TIME RECORD
1205 PRINT CYAN$; "NEW SURVIVAL TIME RECORD!"; OFF$: RETURN
1300 REM PERFECT DODGES RECORD
1305 PRINT CYAN$; "NEW PERFECT DODGE RECORD!"; OFF$: RETURN
1400 REM ACCURACY RECORD
1405 PRINT CYAN$; "NEW ACCURACY RECORD!"; OFF$: RETURN
1500 REM SPEED RECORD
1505 PRINT CYAN$; "NEW SPEED RECORD!"; OFF$: RETURN
1600 REM DESTRUCTION RECORD
1605 PRINT CYAN$; "NEW DESTRUCTION RECORD!"; OFF$: RETURN
1700 REM OVERALL PERFORMANCE RECORD
1705 PRINT RED$; "NEW OVERALL PERFORMANCE RECORD!"; OFF$: RETURN
```
</TryItNow>

**Multi-Tier Achievement Features:**
- **Eight different records** (405-440) reward diverse play styles
- **Automatic record checking** (260-305) tests all categories after each game
- **Record celebration** (1000-1700) makes each achievement feel special
- **Overall performance rating** (300-305) combines multiple factors for ultimate bragging rights

This system ensures every player can find something they excel at!

<InfoBox>
Multi-tier achievements are psychological genius. Even if you can't beat the high score, you might be the best at accuracy, or survival time, or dodging. Everyone gets to be champion at something, which keeps everyone playing. It's the arcade equivalent of participation trophies - but earned through skill!
</InfoBox>

## Hall of Fame Display System

The final touch is a proper Hall of Fame that makes champions feel truly legendary:

<TryItNow>
```basic
10 REM HALL OF FAME DISPLAY SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ASTEROID DODGER - HALL OF FAME"; OFF$
40 PRINT STRING$(40, "═")
45 REM CHAMPION DATA
50 DIM CHAMPION$(5), CH_SCORE(5), CH_DATE$(5), CH_ACHIEVEMENT$(5)
55 FOR I = 1 TO 5
60   READ CHAMPION$(I), CH_SCORE(I), CH_DATE$(I), CH_ACHIEVEMENT$(I)
65 NEXT I
70 REM DISPLAY HALL OF FAME
75 PRINT RED$; "        ETERNAL CHAMPIONS"; OFF$
80 PRINT STRING$(40, "─")
85 FOR I = 1 TO 5
90   PRINT "#"; I; " ";
95   COLOR_CODE$ = GREEN$: IF I = 1 THEN COLOR_CODE$ = YELLOW$
100   PRINT COLOR_CODE$; LEFT$(CHAMPION$(I) + STRING$(12, " "), 12); OFF$;
105   PRINT RIGHT$(STR$(CH_SCORE(I)) + STRING$(8, " "), 8); " ";
110   PRINT PURPLE$; CH_DATE$(I); OFF$
115   PRINT "    "; CYAN$; CH_ACHIEVEMENT$(I); OFF$
120   PRINT
125 NEXT I
130 PRINT STRING$(40, "─")
135 PRINT WHITE$; "CURRENT DIFFICULTY RATINGS:"; OFF$
140 REM SHOW WHAT IT TAKES TO GET IN
145 LOWEST_SCORE = CH_SCORE(5)
150 PRINT "ENTRY REQUIREMENT: "; LOWEST_SCORE; " POINTS"
155 PRINT "TO BEAT #1: "; CH_SCORE(1) + 1; " POINTS"
160 PRINT
165 PRINT YELLOW$; "CAN YOU EARN A PLACE IN HISTORY?"; OFF$
170 PRINT STRING$(40, "═")
175 INPUT "PRESS ENTER TO ATTEMPT GREATNESS"; DUMMY$
180 REM SIMULATE ATTEMPT
185 PRINT "PREPARING FOR LEGENDARY ATTEMPT..."
190 FOR I = 1 TO 30: PRINT ".";: FOR J = 1 TO 30: NEXT J: NEXT I
195 PRINT
200 ATTEMPT_SCORE = RND(1) * 60000 + 20000
205 PRINT "ATTEMPT COMPLETE! SCORE: "; ATTEMPT_SCORE
210 REM CHECK FOR HALL OF FAME ENTRY
215 HALL_ENTRY = 0
220 FOR I = 1 TO 5
225   IF ATTEMPT_SCORE > CH_SCORE(I) THEN HALL_ENTRY = I: I = 5
230 NEXT I
235 IF HALL_ENTRY = 0 THEN 300
240 REM HALL OF FAME ENTRY CEREMONY
245 FOR I = 1 TO 5: PRINT CHR$(7);: FOR J = 1 TO 100: NEXT J: NEXT I
250 PRINT
251 PRINT RED$; "╔═══════════════════════════════════════╗"; OFF$
252 PRINT RED$; "║"; YELLOW$; "    HALL OF FAME ACHIEVEMENT!     "; RED$; "║"; OFF$
253 PRINT RED$; "╚═══════════════════════════════════════╝"; OFF$
255 PRINT
260 PRINT "YOU HAVE EARNED POSITION #"; HALL_ENTRY; "!"
265 IF HALL_ENTRY = 1 THEN PRINT YELLOW$; "YOU ARE THE NEW SUPREME CHAMPION!"; OFF$
270 INPUT "ENTER YOUR LEGENDARY NAME (10 CHARS): "; NEW_CHAMPION$
275 IF LEN(NEW_CHAMPION$) > 10 THEN NEW_CHAMPION$ = LEFT$(NEW_CHAMPION$, 10)
280 PRINT GREEN$; NEW_CHAMPION$; ", WELCOME TO IMMORTALITY!"; OFF$
285 PRINT "YOUR SCORE OF "; ATTEMPT_SCORE; " WILL BE REMEMBERED FOREVER!"
290 GOTO 350
300 REM NOT HALL OF FAME WORTHY
305 PRINT
310 NEEDED = LOWEST_SCORE - ATTEMPT_SCORE + 1
315 PRINT "VALIANT EFFORT, BUT NOT HALL OF FAME WORTHY"
320 PRINT "YOU NEEDED "; NEEDED; " MORE POINTS"
325 PRINT PURPLE$; "THE LEGENDS KEEP THEIR THRONES... FOR NOW"; OFF$
350 END
400 REM HALL OF FAME DATA
405 DATA "STARDUST", 48750, "NOV-85", "REACHED WAVE 16"
410 DATA "ACE", 45200, "OCT-85", "PERFECT ACCURACY RUN"
415 DATA "PHOENIX", 42800, "SEP-85", "300 SECOND SURVIVAL"
420 DATA "GHOST", 38900, "SEP-85", "ZERO COLLISIONS"
425 DATA "NOVA", 35600, "AUG-85", "SPEED DEMON"
```
</TryItNow>

**Hall of Fame Features:**
- **Ranked champion display** (85-125) shows the elite hierarchy
- **Achievement descriptions** (405-425) explain what made each champion special
- **Entry requirements** (145-155) show exactly what's needed for immortality
- **Induction ceremony** (245-285) makes earning a spot feel truly special

This creates a permanent monument to excellence that players will fight to join!

<RetroMoment title="The Birth of the Leaderboard: 1979">
When *Star Fire* introduced the first video game high score table in 1979, it changed everything. Before this, games were just entertainment - after this, they became competition. Arcade owners noticed players would gather around machines just to see the high scores, copying down names and studying the records. The three-letter initial system (limited by memory constraints) became iconic - "AAA" meant you were either lazy or genuinely the best. Players would drive across town to see if their record still stood. Some champions would camp by their machines, protecting their territory like digital kings. The leaderboard didn't just track scores - it created legends.
</RetroMoment>
