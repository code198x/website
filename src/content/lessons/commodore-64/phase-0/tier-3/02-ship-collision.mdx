## From Movement to Interaction

Ship control was just the beginning. Real space games need danger! Let's create a collision detection system that turns your peaceful flight simulator into a heart-pounding asteroid dodger:

<TryItNow>
```basic
10 REM SHIP COLLISION - BASIC COLLISION DETECTION
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "COLLISION DETECTION DEMO"; OFF$
35 PRINT STRING$(30, "═")
40 PRINT "FLY INTO THE RED ASTEROIDS!"
45 PRINT STRING$(30, "─")
50 REM SHIP AND ASTEROID POSITIONS
55 SHIP_X = 10: SHIP_Y = 12
60 AST1_X = 20: AST1_Y = 10: AST2_X = 25: AST2_Y = 15
65 COLLISION = 0: FRAME = 0
70 REM MAIN GAME LOOP
75 FRAME = FRAME + 1
80 REM CLEAR SCREEN AREA
85 FOR I = 8 TO 20: PRINT CHR$(19); CHR$(145);: FOR J = 1 TO 39: PRINT " ";: NEXT J: PRINT: NEXT I
90 REM DRAW ASTEROIDS
95 PRINT CHR$(19): FOR I = 1 TO AST1_Y: PRINT CHR$(17);: NEXT I
100 PRINT TAB(AST1_X); RED$; "▓"; OFF$
105 PRINT CHR$(19): FOR I = 1 TO AST2_Y: PRINT CHR$(17);: NEXT I
110 PRINT TAB(AST2_X); RED$; "▓"; OFF$
115 REM READ SHIP CONTROL
120 GET KEY$
125 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1
130 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
135 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1
140 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1
145 IF KEY$ = "Q" OR KEY$ = "q" THEN 400
150 REM BOUNDARY CHECKING
155 IF SHIP_X < 1 THEN SHIP_X = 1
160 IF SHIP_X > 39 THEN SHIP_X = 39
165 IF SHIP_Y < 8 THEN SHIP_Y = 8
170 IF SHIP_Y > 20 THEN SHIP_Y = 20
175 REM COLLISION DETECTION
180 COLLISION = 0
185 IF SHIP_X = AST1_X AND SHIP_Y = AST1_Y THEN COLLISION = 1
190 IF SHIP_X = AST2_X AND SHIP_Y = AST2_Y THEN COLLISION = 2
195 REM DRAW SHIP (COLOR BASED ON COLLISION)
200 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
205 IF COLLISION > 0 THEN PRINT TAB(SHIP_X); YELLOW$; "☀"; OFF$: REM EXPLOSION
210 IF COLLISION = 0 THEN PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$: REM SAFE SHIP
215 REM STATUS DISPLAY
220 PRINT CHR$(19): PRINT TAB(25); "FRAME:"; FRAME; "  "
225 IF COLLISION > 0 THEN PRINT TAB(25); RED$; "COLLISION!"; OFF$; "  "
230 IF COLLISION = 0 THEN PRINT TAB(25); GREEN$; "SAFE FLIGHT"; OFF$; "  "
235 GOTO 75
400 PRINT: PRINT YELLOW$; "SIMULATION ENDED"; OFF$: END
```
</TryItNow>

**Collision Detection Fundamentals:**
- **Lines 185-190:** Simple coordinate comparison - if ship position equals asteroid position, collision!
- **Lines 205-210:** Visual feedback shows collision state instantly
- **Lines 225-230:** Status display confirms collision detection is working

<InfoBox>
Collision detection is just coordinate comparison! If SHIP_X = ASTEROID_X AND SHIP_Y = ASTEROID_Y, they're occupying the same space. This simple test is the foundation of all game physics.
</InfoBox>

## Professional Collision Systems

Let's create a collision system worthy of commercial space games, with multiple collision types and realistic responses:

<TryItNow>
```basic
10 REM PROFESSIONAL COLLISION SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ASTEROID FIELD NAVIGATOR"; OFF$
35 PRINT STRING$(30, "═")
40 PRINT "AVOID RED ASTEROIDS! COLLECT GREEN POWER-UPS!"
45 PRINT STRING$(30, "─")
50 REM GAME OBJECTS
55 SHIP_X = 5: SHIP_Y = 12: SHIP_LIVES = 3
60 DIM ASTEROID_X(5), ASTEROID_Y(5), POWER_X(3), POWER_Y(3)
65 SCORE = 0: POWER_COLLECTED = 0
70 REM INITIALIZE ASTEROIDS
75 FOR I = 1 TO 5
80 ASTEROID_X(I) = INT(RND(1)*35) + 15
85 ASTEROID_Y(I) = INT(RND(1)*12) + 8
90 NEXT I
95 REM INITIALIZE POWER-UPS
100 FOR I = 1 TO 3
105 POWER_X(I) = INT(RND(1)*25) + 20
110 POWER_Y(I) = INT(RND(1)*10) + 10
115 NEXT I
120 REM MAIN GAME LOOP
125 REM CLEAR PLAY AREA
130 FOR I = 8 TO 20
135 PRINT CHR$(19); CHR$(145);: FOR J = 1 TO 39: PRINT " ";: NEXT J: PRINT
140 NEXT I
145 REM DRAW ASTEROIDS
150 FOR I = 1 TO 5
155 IF ASTEROID_X(I) > 0 THEN GOSUB 2000: REM DRAW ASTEROID
160 NEXT I
165 REM DRAW POWER-UPS
170 FOR I = 1 TO 3
175 IF POWER_X(I) > 0 THEN GOSUB 2100: REM DRAW POWER-UP
180 NEXT I
185 REM SHIP CONTROL
190 GET KEY$
195 OLD_X = SHIP_X: OLD_Y = SHIP_Y
200 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1
205 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
210 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1
215 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1
220 IF KEY$ = "Q" OR KEY$ = "q" THEN 900
225 REM BOUNDARY CHECKING
230 IF SHIP_X < 1 THEN SHIP_X = 1
235 IF SHIP_X > 39 THEN SHIP_X = 39
240 IF SHIP_Y < 8 THEN SHIP_Y = 8
245 IF SHIP_Y > 20 THEN SHIP_Y = 20
250 REM COLLISION DETECTION
255 GOSUB 1000: REM CHECK ASTEROID COLLISIONS
260 GOSUB 1200: REM CHECK POWER-UP COLLISIONS
265 REM DRAW SHIP
270 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
275 PRINT TAB(SHIP_X); GREEN$; "♦"; OFF$
280 REM STATUS DISPLAY
285 PRINT CHR$(19): PRINT TAB(20); "LIVES:"; SHIP_LIVES; " SCORE:"; SCORE; " POWER:"; POWER_COLLECTED; "  "
290 REM GAME OVER CHECK
295 IF SHIP_LIVES <= 0 THEN 800
300 GOTO 125
800 PRINT: PRINT RED$; "SHIP DESTROYED!"; OFF$
805 PRINT "FINAL SCORE:"; SCORE: END
900 PRINT: PRINT YELLOW$; "MISSION ABORTED"; OFF$: END
1000 REM CHECK ASTEROID COLLISIONS
1005 FOR I = 1 TO 5
1010 IF ASTEROID_X(I) <= 0 THEN 1050: REM SKIP DESTROYED ASTEROIDS
1015 IF SHIP_X = ASTEROID_X(I) AND SHIP_Y = ASTEROID_Y(I) THEN 1020 ELSE 1050
1020 REM ASTEROID COLLISION!
1025 SHIP_LIVES = SHIP_LIVES - 1
1030 ASTEROID_X(I) = 0: REM DESTROY ASTEROID
1035 REM COLLISION VISUAL EFFECT
1040 PRINT CHR$(19): FOR J = 1 TO ASTEROID_Y(I): PRINT CHR$(17);: NEXT J
1045 PRINT TAB(SHIP_X); YELLOW$; "☀"; OFF$
1050 NEXT I
1055 RETURN
1200 REM CHECK POWER-UP COLLISIONS
1205 FOR I = 1 TO 3
1210 IF POWER_X(I) <= 0 THEN 1250: REM SKIP COLLECTED POWER-UPS
1215 IF SHIP_X = POWER_X(I) AND SHIP_Y = POWER_Y(I) THEN 1220 ELSE 1250
1220 REM POWER-UP COLLECTED!
1225 SCORE = SCORE + 100
1230 POWER_COLLECTED = POWER_COLLECTED + 1
1235 POWER_X(I) = 0: REM REMOVE POWER-UP
1240 REM COLLECTION VISUAL EFFECT
1245 PRINT CHR$(19): FOR J = 1 TO POWER_Y(I): PRINT CHR$(17);: NEXT J
1250 NEXT I
1255 RETURN
2000 REM DRAW ASTEROID
2005 PRINT CHR$(19): FOR J = 1 TO ASTEROID_Y(I): PRINT CHR$(17);: NEXT J
2010 PRINT TAB(ASTEROID_X(I)); RED$; "▓"; OFF$
2015 RETURN
2100 REM DRAW POWER-UP
2105 PRINT CHR$(19): FOR J = 1 TO POWER_Y(I): PRINT CHR$(17);: NEXT J
2110 PRINT TAB(POWER_X(I)); GREEN$; "◊"; OFF$
2115 RETURN
```
</TryItNow>

**Advanced Collision Features:**
- **Arrays for multiple objects** (lines 60-115) handle many asteroids and power-ups
- **Different collision responses** (1020-1055 vs 1220-1255) for different object types
- **Object destruction** using coordinate zeroing (lines 1030, 1235)
- **Visual collision effects** (lines 1040-1045) provide immediate feedback

`★ Insight ─────────────────────────────────────`
**Professional collision systems need different responses**. Asteroids destroy the ship but disappear. Power-ups boost the player and vanish. Boundaries stop movement. Each collision type needs custom logic.

**Object management through arrays** lets you handle dozens of game entities efficiently. Setting coordinates to 0 or negative values effectively "destroys" objects without complex deletion.
`─────────────────────────────────────────────────`

## Advanced Collision Physics

Let's add realistic collision physics that make impacts feel satisfying and realistic:

<TryItNow>
```basic
10 REM ADVANCED COLLISION PHYSICS
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 PRINT CHR$(147)
35 PRINT WHITE$; "REALISTIC COLLISION PHYSICS"; OFF$
40 PRINT STRING$(30, "═")
45 PRINT "EXPERIENCE REALISTIC SPACE PHYSICS!"
50 PRINT STRING$(30, "─")
55 REM SHIP PHYSICS VARIABLES
60 SHIP_X = 10: SHIP_Y = 12: SHIP_VX = 0: SHIP_VY = 0
65 SHIP_LIVES = 5: INVULNERABLE = 0: SHAKE_TIME = 0
70 REM ASTEROID FIELD
75 DIM AST_X(8), AST_Y(8), AST_VX(8), AST_VY(8)
80 FOR I = 1 TO 8
85 AST_X(I) = INT(RND(1)*35) + 5
90 AST_Y(I) = INT(RND(1)*15) + 8
95 AST_VX(I) = INT(RND(1)*3) - 1: REM -1, 0, OR 1
100 AST_VY(I) = INT(RND(1)*3) - 1
105 NEXT I
110 FRAME = 0
115 REM MAIN PHYSICS LOOP
120 FRAME = FRAME + 1
125 REM REDUCE SPECIAL EFFECTS TIMERS
130 IF INVULNERABLE > 0 THEN INVULNERABLE = INVULNERABLE - 1
135 IF SHAKE_TIME > 0 THEN SHAKE_TIME = SHAKE_TIME - 1
140 REM CLEAR SCREEN
145 FOR I = 8 TO 22
150 PRINT CHR$(19); CHR$(145);: FOR J = 1 TO 39: PRINT " ";: NEXT J: PRINT
155 NEXT I
160 REM SHIP CONTROL WITH PHYSICS
165 GET KEY$: THRUST = 0
170 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_VY = SHIP_VY - 1: THRUST = 1
175 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_VY = SHIP_VY + 1: THRUST = 1
180 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_VX = SHIP_VX - 1: THRUST = 1
185 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_VX = SHIP_VX + 1: THRUST = 1
190 IF KEY$ = "Q" OR KEY$ = "q" THEN 900
195 REM APPLY VELOCITY LIMITS
200 IF SHIP_VX > 2 THEN SHIP_VX = 2
205 IF SHIP_VX < -2 THEN SHIP_VX = -2
210 IF SHIP_VY > 2 THEN SHIP_VY = 2
215 IF SHIP_VY < -2 THEN SHIP_VY = -2
220 REM APPLY FRICTION (SPACE RESISTANCE)
225 IF THRUST = 0 THEN SHIP_VX = SHIP_VX * 0.8: SHIP_VY = SHIP_VY * 0.8
230 REM UPDATE SHIP POSITION
235 SHIP_X = SHIP_X + SHIP_VX: SHIP_Y = SHIP_Y + SHIP_VY
240 REM BOUNDARY PHYSICS
245 IF SHIP_X < 1 THEN SHIP_X = 1: SHIP_VX = -SHIP_VX * 0.5
250 IF SHIP_X > 39 THEN SHIP_X = 39: SHIP_VX = -SHIP_VX * 0.5
255 IF SHIP_Y < 8 THEN SHIP_Y = 8: SHIP_VY = -SHIP_VY * 0.5
260 IF SHIP_Y > 22 THEN SHIP_Y = 22: SHIP_VY = -SHIP_VY * 0.5
265 REM UPDATE ASTEROIDS
270 FOR I = 1 TO 8
275 IF AST_X(I) <= 0 THEN 320: REM SKIP DESTROYED ASTEROIDS
280 AST_X(I) = AST_X(I) + AST_VX(I)
285 AST_Y(I) = AST_Y(I) + AST_VY(I)
290 REM ASTEROID BOUNDARY BOUNCING
295 IF AST_X(I) < 5 OR AST_X(I) > 35 THEN AST_VX(I) = -AST_VX(I)
300 IF AST_Y(I) < 8 OR AST_Y(I) > 20 THEN AST_VY(I) = -AST_VY(I)
305 REM DRAW ASTEROID
310 PRINT CHR$(19): FOR J = 1 TO AST_Y(I): PRINT CHR$(17);: NEXT J
315 PRINT TAB(AST_X(I)); RED$; "▓"; OFF$
320 NEXT I
325 REM COLLISION DETECTION WITH PHYSICS
330 IF INVULNERABLE > 0 THEN 370: REM SKIP IF INVULNERABLE
335 FOR I = 1 TO 8
340 IF AST_X(I) <= 0 THEN 365
345 IF INT(SHIP_X) = AST_X(I) AND INT(SHIP_Y) = AST_Y(I) THEN GOSUB 1500
350 NEXT I
365 REM DRAW SHIP WITH EFFECTS
370 SHIP_DRAW_X = INT(SHIP_X): SHIP_DRAW_Y = INT(SHIP_Y)
375 IF SHAKE_TIME > 0 THEN SHIP_DRAW_X = SHIP_DRAW_X + INT(RND(1)*3) - 1
380 PRINT CHR$(19): FOR I = 1 TO SHIP_DRAW_Y: PRINT CHR$(17);: NEXT I
385 IF INVULNERABLE > 0 AND (FRAME MOD 4) < 2 THEN 395: REM FLASHING EFFECT
390 PRINT TAB(SHIP_DRAW_X); GREEN$; "♦"; OFF$
395 REM STATUS DISPLAY
400 PRINT CHR$(19): PRINT TAB(15); "LIVES:"; SHIP_LIVES; " VEL: X"; INT(SHIP_VX); " Y"; INT(SHIP_VY); "  "
405 GOTO 115
900 PRINT: PRINT YELLOW$; "FLIGHT TERMINATED"; OFF$: END
1500 REM COLLISION PHYSICS
1505 REM BOUNCE SHIP AWAY FROM ASTEROID
1510 SHIP_VX = SHIP_VX + (SHIP_X - AST_X(I)) * 2
1515 SHIP_VY = SHIP_VY + (SHIP_Y - AST_Y(I)) * 2
1520 REM DAMAGE EFFECTS
1525 SHIP_LIVES = SHIP_LIVES - 1
1530 INVULNERABLE = 20: REM 20 FRAME INVULNERABILITY
1535 SHAKE_TIME = 10: REM 10 FRAME SCREEN SHAKE
1540 REM DESTROY ASTEROID
1545 AST_X(I) = 0
1550 RETURN
```
</TryItNow>

**Realistic Physics Features:**
- **Velocity-based movement** (lines 235, 280-285) creates momentum
- **Boundary bouncing** (lines 245-260, 295-300) with energy loss
- **Collision knockback** (lines 1510-1515) pushes ship away from impact
- **Invulnerability frames** (lines 1530, 385-390) prevent cheap deaths
- **Screen shake effects** (lines 375, 1535) add impact feedback

This collision system feels like playing a real arcade game - with physics that make every impact meaningful!
