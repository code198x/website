# Screen Scroll

**From static screens to infinite journeys! Create the illusion of flying through endless space with scrolling starfields, parallax depth, and a universe that never runs out.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={42} />

## The Illusion of Movement

Your animated ship looks amazing, but it's stuck in a static universe. The secret to making players feel like they're traveling through space isn't moving the ship - it's moving everything else! **Screen scrolling** creates the illusion that you're flying forward by making the environment flow backward:

<TryItNow>
```basic
10 REM BASIC VERTICAL SCROLLING
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "INFINITE SPACE SCROLLER"; OFF$
40 PRINT STRING$(40, "═")
45 REM STAR FIELD DATA
50 DIM STAR_X(20), STAR_Y(20), STAR_SPEED(20), STAR_CHAR$(20)
55 REM INITIALIZE RANDOM STARFIELD
60 FOR I = 1 TO 20
65   STAR_X(I) = RND(1) * 38 + 1
70   STAR_Y(I) = RND(1) * 18 + 5
75   STAR_SPEED(I) = RND(1) * 3 + 1: REM 1-3 SPEED
80   IF STAR_SPEED(I) = 1 THEN STAR_CHAR$(I) = "."
85   IF STAR_SPEED(I) = 2 THEN STAR_CHAR$(I) = "·"
90   IF STAR_SPEED(I) = 3 THEN STAR_CHAR$(I) = "*"
95 NEXT I
100 REM SHIP POSITION (STAYS CENTERED)
105 SHIP_X = 20: SHIP_Y = 18
110 FRAME = 0: DISTANCE = 0
115 REM MAIN SCROLLING LOOP
120 FRAME = FRAME + 1: DISTANCE = DISTANCE + 1
125 REM CLEAR SCREEN AREA
130 FOR Y = 5 TO 23
135   PRINT CHR$(19);: FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
140   PRINT STRING$(40, " ")
145 NEXT Y
150 REM MOVE AND DRAW STARS
155 FOR I = 1 TO 20
160   REM SCROLL STAR DOWNWARD
165   IF FRAME MOD (4 - STAR_SPEED(I)) = 0 THEN STAR_Y(I) = STAR_Y(I) + 1
170   REM RECYCLE STAR AT TOP IF IT GOES OFF BOTTOM
175   IF STAR_Y(I) > 23 THEN STAR_Y(I) = 5: STAR_X(I) = RND(1) * 38 + 1
180   REM DRAW STAR WITH DEPTH COLOR
185   PRINT CHR$(19);: FOR Z = 1 TO STAR_Y(I): PRINT CHR$(17);: NEXT Z
190   IF STAR_SPEED(I) = 1 THEN COLOR$ = BLUE$: REM DISTANT
195   IF STAR_SPEED(I) = 2 THEN COLOR$ = WHITE$: REM MIDDLE
200   IF STAR_SPEED(I) = 3 THEN COLOR$ = CYAN$: REM CLOSE
205   PRINT TAB(STAR_X(I)); COLOR$; STAR_CHAR$(I); OFF$
210 NEXT I
215 REM DRAW STATIC SHIP
220 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
225 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$
230 REM STATUS DISPLAY
235 PRINT CHR$(19): PRINT TAB(25); "DISTANCE:"; DISTANCE
240 PRINT TAB(25); "SPEED: WARP "; INT(FRAME / 10)
245 REM READ SHIP CONTROLS (SHIP MOVES, STARS KEEP SCROLLING)
250 GET KEY$
255 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
260 IF KEY$ = "D" AND SHIP_X < 39 THEN SHIP_X = SHIP_X + 1
265 IF KEY$ = "Q" THEN 500
270 FOR DELAY = 1 TO 50: NEXT DELAY: REM SPEED CONTROL
275 GOTO 120
500 PRINT: PRINT YELLOW$; "JOURNEY COMPLETE AT "; DISTANCE; " PARSECS"; OFF$
505 END
```
</TryItNow>

**Scrolling Mechanics:**
- **Star movement** (line 165) moves objects down based on their speed
- **Object recycling** (175) reuses stars that leave the screen
- **Parallax layers** (190-200) create depth with different speeds and colors
- **Static ship** (220-225) stays in place while the universe moves around it

The ship isn't moving through space - space is moving past the ship!

`★ Insight ─────────────────────────────────────`
**Scrolling is pure psychology**. The ship never moves, but your brain interprets the flowing starfield as forward motion. This is the same illusion used in every scrolling game from *Star Raiders* to *Gradius*.

**Parallax creates 3D from 2D**. By moving distant stars slower than close ones, we simulate depth perception. Your brain automatically interprets speed differences as distance - no 3D hardware needed!
`─────────────────────────────────────────────────`

## Advanced Parallax System

Let's create a multi-layer universe with asteroids, debris, and nebula clouds all moving at different speeds:

<TryItNow>
```basic
10 REM ADVANCED PARALLAX SCROLLING
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "PARALLAX SPACE ENVIRONMENT"; OFF$
40 PRINT STRING$(40, "═")
45 REM LAYER 1: DISTANT NEBULA (SLOWEST)
50 DIM NEBULA_X(5), NEBULA_Y(5)
55 FOR I = 1 TO 5
60   NEBULA_X(I) = RND(1) * 35 + 2: NEBULA_Y(I) = RND(1) * 15 + 5
65 NEXT I
70 REM LAYER 2: MIDDLE STARS
75 DIM STAR_X(15), STAR_Y(15)
80 FOR I = 1 TO 15
85   STAR_X(I) = RND(1) * 38 + 1: STAR_Y(I) = RND(1) * 18 + 5
90 NEXT I
95 REM LAYER 3: CLOSE DEBRIS (FASTEST)
100 DIM DEBRIS_X(8), DEBRIS_Y(8), DEBRIS_TYPE$(8)
105 FOR I = 1 TO 8
110   DEBRIS_X(I) = RND(1) * 38 + 1: DEBRIS_Y(I) = RND(1) * 18 + 5
115   R = RND(1) * 3
120   IF R < 1 THEN DEBRIS_TYPE$(I) = "o": REM SMALL
125   IF R >= 1 AND R < 2 THEN DEBRIS_TYPE$(I) = "O": REM MEDIUM
130   IF R >= 2 THEN DEBRIS_TYPE$(I) = "●": REM LARGE
135 NEXT I
140 REM LAYER 4: ASTEROIDS (GAMEPLAY LAYER)
145 DIM AST_X(4), AST_Y(4), AST_ACTIVE(4)
150 FOR I = 1 TO 4
155   AST_X(I) = RND(1) * 35 + 2: AST_Y(I) = 5
160   AST_ACTIVE(I) = (RND(1) > 0.5)
165 NEXT I
170 REM SHIP AND GAME STATE
175 SHIP_X = 20: SHIP_Y = 18: FRAME = 0
180 REM MAIN PARALLAX LOOP
185 FRAME = FRAME + 1
190 REM CLEAR PLAYFIELD
195 FOR Y = 5 TO 23
200   PRINT CHR$(19);: FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
205   PRINT STRING$(40, " ")
210 NEXT Y
215 REM LAYER 1: SCROLL NEBULA (EVERY 8 FRAMES)
220 IF FRAME MOD 8 = 0 THEN
225   FOR I = 1 TO 5
230     NEBULA_Y(I) = NEBULA_Y(I) + 1
235     IF NEBULA_Y(I) > 23 THEN NEBULA_Y(I) = 5: NEBULA_X(I) = RND(1) * 35 + 2
240   NEXT I
245 END IF
250 REM DRAW NEBULA
255 FOR I = 1 TO 5
260   PRINT CHR$(19);: FOR Z = 1 TO NEBULA_Y(I): PRINT CHR$(17);: NEXT Z
265   PRINT TAB(NEBULA_X(I)); PURPLE$; "░░░"; OFF$
270 NEXT I
275 REM LAYER 2: SCROLL STARS (EVERY 4 FRAMES)
280 IF FRAME MOD 4 = 0 THEN
285   FOR I = 1 TO 15
290     STAR_Y(I) = STAR_Y(I) + 1
295     IF STAR_Y(I) > 23 THEN STAR_Y(I) = 5: STAR_X(I) = RND(1) * 38 + 1
300   NEXT I
305 END IF
310 REM DRAW STARS
315 FOR I = 1 TO 15
320   PRINT CHR$(19);: FOR Z = 1 TO STAR_Y(I): PRINT CHR$(17);: NEXT Z
325   PRINT TAB(STAR_X(I)); WHITE$; "·"; OFF$
330 NEXT I
335 REM LAYER 3: SCROLL DEBRIS (EVERY 2 FRAMES)
340 IF FRAME MOD 2 = 0 THEN
345   FOR I = 1 TO 8
350     DEBRIS_Y(I) = DEBRIS_Y(I) + 1
355     IF DEBRIS_Y(I) > 23 THEN DEBRIS_Y(I) = 5: DEBRIS_X(I) = RND(1) * 38 + 1
360   NEXT I
365 END IF
370 REM DRAW DEBRIS
375 FOR I = 1 TO 8
380   PRINT CHR$(19);: FOR Z = 1 TO DEBRIS_Y(I): PRINT CHR$(17);: NEXT Z
385   PRINT TAB(DEBRIS_X(I)); CYAN$; DEBRIS_TYPE$(I); OFF$
390 NEXT I
395 REM LAYER 4: SCROLL ASTEROIDS (EVERY FRAME)
400 FOR I = 1 TO 4
405   IF AST_ACTIVE(I) = 0 THEN 425
410   AST_Y(I) = AST_Y(I) + 1
415   IF AST_Y(I) > 23 THEN AST_Y(I) = 5: AST_X(I) = RND(1) * 35 + 2: AST_ACTIVE(I) = (RND(1) > 0.3)
420   PRINT CHR$(19);: FOR Z = 1 TO AST_Y(I): PRINT CHR$(17);: NEXT Z
425   IF AST_ACTIVE(I) = 1 THEN PRINT TAB(AST_X(I)); RED$; "▓▓▓"; OFF$
430 NEXT I
435 REM DRAW SHIP ON TOP
440 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
445 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$
450 REM SHIP CONTROL
455 GET KEY$
460 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
465 IF KEY$ = "D" AND SHIP_X < 38 THEN SHIP_X = SHIP_X + 1
470 IF KEY$ = "W" AND SHIP_Y > 8 THEN SHIP_Y = SHIP_Y - 1
475 IF KEY$ = "S" AND SHIP_Y < 22 THEN SHIP_Y = SHIP_Y + 1
480 IF KEY$ = "Q" THEN 600
485 REM STATUS
490 PRINT CHR$(19): PRINT TAB(15); "PARALLAX LAYERS ACTIVE"
495 PRINT TAB(15); "DEPTH SIMULATION: ON"
500 FOR DELAY = 1 TO 30: NEXT DELAY
505 GOTO 185
600 PRINT: PRINT YELLOW$; "PARALLAX ENGINE OFFLINE"; OFF$
605 END
```
</TryItNow>

**Multi-Layer Features:**
- **Four distinct layers** with different scroll rates create depth
- **Nebula clouds** (220-270) move slowest, appearing most distant
- **Stars** (280-330) provide middle-ground reference
- **Debris** (340-390) moves fast, appearing close
- **Asteroids** (400-430) exist in gameplay space at full speed

This creates a rich, living universe with genuine depth perception!

<InfoBox>
Parallax scrolling was the holy grail of 2D graphics. When *Moon Patrol* introduced it in 1982, players were amazed at the 3D effect achieved with just 2D layers. The C64's ability to handle multiple moving layers made it perfect for creating these immersive scrolling environments.
</InfoBox>

## Infinite Object Generation

The final touch is creating a universe that never repeats, with procedural generation ensuring every journey feels unique:

<TryItNow>
```basic
10 REM INFINITE PROCEDURAL UNIVERSE
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "INFINITE UNIVERSE GENERATOR"; OFF$
40 PRINT STRING$(40, "═")
45 REM OBJECT POOL SYSTEM
50 MAX_OBJECTS = 30: DIM OBJ_X(30), OBJ_Y(30), OBJ_TYPE(30), OBJ_ACTIVE(30)
55 DIM OBJ_SPEED(30), OBJ_COLOR$(30), OBJ_CHAR$(30)
60 REM ZONE VARIABLES
65 CURRENT_ZONE = 1: ZONE_DISTANCE = 0: ZONE_LENGTH = 500
70 ZONE_SEED = RND(-TI): REM UNIQUE SEED PER SESSION
75 REM INITIALIZE EMPTY POOL
80 FOR I = 1 TO MAX_OBJECTS: OBJ_ACTIVE(I) = 0: NEXT I
85 REM SHIP AND COUNTERS
90 SHIP_X = 20: SHIP_Y = 18: FRAME = 0: TOTAL_DISTANCE = 0
95 REM MAIN INFINITE LOOP
100 FRAME = FRAME + 1: TOTAL_DISTANCE = TOTAL_DISTANCE + 1
105 ZONE_DISTANCE = ZONE_DISTANCE + 1
110 REM CHECK FOR ZONE TRANSITION
115 IF ZONE_DISTANCE > ZONE_LENGTH THEN GOSUB 2000: REM NEW ZONE
120 REM SPAWN NEW OBJECTS BASED ON ZONE
125 IF RND(1) < 0.1 + CURRENT_ZONE * 0.02 THEN GOSUB 3000
130 REM CLEAR SCREEN
135 FOR Y = 5 TO 23
140   PRINT CHR$(19);: FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
145   PRINT STRING$(40, " ")
150 NEXT Y
155 REM UPDATE AND DRAW ALL OBJECTS
160 FOR I = 1 TO MAX_OBJECTS
165   IF OBJ_ACTIVE(I) = 0 THEN 220
170   REM SCROLL OBJECT
175   IF FRAME MOD OBJ_SPEED(I) = 0 THEN OBJ_Y(I) = OBJ_Y(I) + 1
180   REM DEACTIVATE IF OFF SCREEN
185   IF OBJ_Y(I) > 23 THEN OBJ_ACTIVE(I) = 0: GOTO 220
190   REM DRAW OBJECT
195   PRINT CHR$(19);: FOR Z = 1 TO OBJ_Y(I): PRINT CHR$(17);: NEXT Z
200   PRINT TAB(OBJ_X(I)); OBJ_COLOR$(I); OBJ_CHAR$(I); OFF$
205   REM SPECIAL EFFECTS FOR SOME OBJECTS
210   IF OBJ_TYPE(I) = 4 AND (FRAME MOD 4 < 2) THEN PRINT TAB(OBJ_X(I) - 1); "("; TAB(OBJ_X(I) + 1); ")"
215   IF OBJ_TYPE(I) = 5 THEN PRINT TAB(OBJ_X(I)); PURPLE$; "░"; OFF$
220 NEXT I
225 REM DRAW SHIP
230 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
235 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$
240 REM ZONE INDICATOR
245 PRINT CHR$(19): PRINT TAB(10); "ZONE "; CURRENT_ZONE; ": ";
250 IF CURRENT_ZONE = 1 THEN PRINT "OUTER BELT"
255 IF CURRENT_ZONE = 2 THEN PRINT "ASTEROID FIELD"
260 IF CURRENT_ZONE = 3 THEN PRINT "DEBRIS CLOUD"
265 IF CURRENT_ZONE = 4 THEN PRINT "NEBULA EDGE"
270 IF CURRENT_ZONE = 5 THEN PRINT "DEEP SPACE"
275 IF CURRENT_ZONE > 5 THEN PRINT "UNKNOWN REGION"
280 PRINT TAB(10); "DISTANCE: "; TOTAL_DISTANCE
285 REM SHIP CONTROL
290 GET KEY$
295 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
300 IF KEY$ = "D" AND SHIP_X < 38 THEN SHIP_X = SHIP_X + 1
305 IF KEY$ = "Q" THEN 900
310 FOR DELAY = 1 TO 40: NEXT DELAY
315 GOTO 100
900 PRINT: PRINT YELLOW$; "EXPLORED "; CURRENT_ZONE; " ZONES"; OFF$
905 PRINT "TOTAL DISTANCE: "; TOTAL_DISTANCE; " UNITS"
910 END
2000 REM ENTER NEW ZONE
2005 CURRENT_ZONE = CURRENT_ZONE + 1: ZONE_DISTANCE = 0
2010 REM CHANGE ZONE CHARACTERISTICS
2015 ZONE_SEED = RND(-CURRENT_ZONE * 1000)
2020 PRINT CHR$(7): REM BEEP FOR NEW ZONE
2025 RETURN
3000 REM SPAWN NEW OBJECT
3005 REM FIND FREE SLOT
3010 FOR I = 1 TO MAX_OBJECTS
3015   IF OBJ_ACTIVE(I) = 1 THEN 3085
3020   REM ACTIVATE AND CONFIGURE BASED ON ZONE
3025   OBJ_ACTIVE(I) = 1: OBJ_X(I) = RND(1) * 37 + 2: OBJ_Y(I) = 5
3030   REM ZONE-SPECIFIC OBJECT TYPES
3035   TYPE_ROLL = RND(1) * CURRENT_ZONE
3040   IF TYPE_ROLL < 1 THEN OBJ_TYPE(I) = 1: REM STAR
3045   IF TYPE_ROLL >= 1 AND TYPE_ROLL < 2 THEN OBJ_TYPE(I) = 2: REM DEBRIS
3050   IF TYPE_ROLL >= 2 AND TYPE_ROLL < 3 THEN OBJ_TYPE(I) = 3: REM ASTEROID
3055   IF TYPE_ROLL >= 3 AND TYPE_ROLL < 4 THEN OBJ_TYPE(I) = 4: REM ENERGY
3060   IF TYPE_ROLL >= 4 THEN OBJ_TYPE(I) = 5: REM ANOMALY
3065   REM SET OBJECT PROPERTIES
3070   GOSUB 4000
3075   RETURN
3085 NEXT I
3090 RETURN
4000 REM CONFIGURE OBJECT PROPERTIES
4005 IF OBJ_TYPE(I) = 1 THEN OBJ_CHAR$(I) = ".": OBJ_COLOR$(I) = WHITE$: OBJ_SPEED(I) = 3
4010 IF OBJ_TYPE(I) = 2 THEN OBJ_CHAR$(I) = "o": OBJ_COLOR$(I) = CYAN$: OBJ_SPEED(I) = 2
4015 IF OBJ_TYPE(I) = 3 THEN OBJ_CHAR$(I) = "●": OBJ_COLOR$(I) = RED$: OBJ_SPEED(I) = 1
4020 IF OBJ_TYPE(I) = 4 THEN OBJ_CHAR$(I) = "◊": OBJ_COLOR$(I) = YELLOW$: OBJ_SPEED(I) = 2
4025 IF OBJ_TYPE(I) = 5 THEN OBJ_CHAR$(I) = "?": OBJ_COLOR$(I) = PURPLE$: OBJ_SPEED(I) = 4
4030 RETURN
```
</TryItNow>

**Infinite Generation Features:**
- **Object pool system** (50-55) efficiently reuses memory for endless objects
- **Zone progression** (2000-2025) creates distinct regions with different characteristics
- **Procedural spawning** (3000-3090) generates objects based on current zone
- **Dynamic difficulty** (125) increases spawn rate as zones progress

Your universe literally never ends - each zone brings new challenges and discoveries!

<RetroMoment title="The Scrolling Revolution: 1981">
*Defender* changed everything by introducing horizontal scrolling that extended the playfield beyond the screen. Suddenly, game worlds weren't limited to 40x25 characters. The technique was so revolutionary that Williams Electronics patented aspects of it. When programmers figured out how to implement scrolling on home computers, it democratized game design - bedroom coders could now create experiences that felt as expansive as arcade games. The C64's smooth scrolling hardware made it particularly good at this, leading to classics like *Uridium* and *Armalyte*. The psychological impact was profound: scrolling meant exploration, discovery, and the promise that there was always more to see beyond the screen edge.
</RetroMoment>
