## Dynamic Asteroid Patterns

Your scrolling universe needs threats that feel real. Asteroids shouldn't just fall straight down - they tumble, cluster, and move in realistic patterns that challenge players to think ahead:

<TryItNow>
```basic
10 REM INTELLIGENT ASTEROID MOVEMENT
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "DYNAMIC ASTEROID FIELD"; OFF$
35 PRINT STRING$(40, "═")
40 REM ASTEROID DATA ARRAYS
45 DIM AST_X(10), AST_Y(10), AST_VX(10), AST_VY(10)
50 DIM AST_SIZE(10), AST_ROTATION(10), AST_ACTIVE(10)
55 REM INITIALIZE ASTEROID FIELD
60 FOR I = 1 TO 10
65   AST_X(I) = RND(1) * 36 + 2: AST_Y(I) = RND(1) * 10 + 5
70   AST_VX(I) = (RND(1) - 0.5) * 2: REM HORIZONTAL DRIFT
75   AST_VY(I) = RND(1) + 0.5: REM DOWNWARD MOVEMENT
80   AST_SIZE(I) = INT(RND(1) * 3) + 1: REM 1=SMALL, 2=MED, 3=LARGE
85   AST_ROTATION(I) = 0: AST_ACTIVE(I) = 1
90 NEXT I
95 SHIP_X = 20: SHIP_Y = 20: FRAME = 0
100 REM MAIN MOVEMENT LOOP
105 FRAME = FRAME + 1
110 REM CLEAR SCREEN
115 FOR Y = 5 TO 23: PRINT CHR$(19);
120   FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
125   PRINT STRING$(40, " ")
130 NEXT Y
135 REM UPDATE AND DRAW ASTEROIDS
140 FOR I = 1 TO 10
145   IF AST_ACTIVE(I) = 0 THEN 230
150   REM APPLY VELOCITY
155   AST_X(I) = AST_X(I) + AST_VX(I)
160   AST_Y(I) = AST_Y(I) + AST_VY(I)
165   REM ROTATE ASTEROID
170   AST_ROTATION(I) = (AST_ROTATION(I) + 1) MOD 4
175   REM BOUNDARY CHECK AND WRAP
180   IF AST_X(I) < 1 THEN AST_X(I) = 38
185   IF AST_X(I) > 38 THEN AST_X(I) = 1
190   IF AST_Y(I) > 23 THEN AST_Y(I) = 5: AST_X(I) = RND(1) * 36 + 2
195   REM DRAW ASTEROID BASED ON SIZE AND ROTATION
200   PRINT CHR$(19);: FOR Z = 1 TO INT(AST_Y(I)): PRINT CHR$(17);: NEXT Z
205   PRINT TAB(INT(AST_X(I)));
210   IF AST_SIZE(I) = 1 THEN PRINT RED$; "·"; OFF$
215   IF AST_SIZE(I) = 2 THEN PRINT RED$; "o"; OFF$
220   IF AST_SIZE(I) = 3 AND AST_ROTATION(I) < 2 THEN PRINT RED$; "O"; OFF$
225   IF AST_SIZE(I) = 3 AND AST_ROTATION(I) >= 2 THEN PRINT RED$; "●"; OFF$
230 NEXT I
235 REM DRAW SHIP
240 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
245 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$
250 GET KEY$: IF KEY$ = "Q" THEN END
255 FOR D = 1 TO 30: NEXT D: GOTO 105
```

**Movement Features:**
- **Diagonal trajectories** (lines 70-75) create unpredictable paths
- **Size variation** (80) affects visual appearance and threat level
- **Rotation animation** (170, 220-225) makes asteroids feel three-dimensional
- **Screen wrapping** (180-190) keeps asteroids in play

`★ Insight ─────────────────────────────────────`
**Asteroid movement is about implied physics**. Real asteroids tumble due to angular momentum, but we simulate this with simple rotation cycles. The diagonal movement suggests gravitational influences that don't exist in our code but feel real to players.
