## Visual Impact

Great games make failure spectacular. Transform boring collisions into memorable moments with expanding explosions:

<TryItNow>
```basic
10 REM SPECTACULAR EXPLOSION SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): YELLOW$ = CHR$(158)
20 ORANGE$ = CHR$(129): CYAN$ = CHR$(159): OFF$ = CHR$(144)
25 PRINT CHR$(147)
30 PRINT WHITE$; "EXPLOSION EFFECTS DEMO"; OFF$
35 PRINT STRING$(40, "═")
40 REM EXPLOSION DATA
45 DIM EXP_X(10), EXP_Y(10), EXP_FRAME(10), EXP_TYPE(10)
50 DIM PARTICLE_X(20), PARTICLE_Y(20), PARTICLE_VX(20)
55 DIM PARTICLE_VY(20), PARTICLE_LIFE(20)
60 REM INITIALIZE
65 FOR I = 1 TO 10: EXP_FRAME(I) = 0: NEXT I
70 FOR I = 1 TO 20: PARTICLE_LIFE(I) = 0: NEXT I
75 SHIP_X = 20: SHIP_Y = 15: SHAKE = 0
80 REM MAIN LOOP
85 FRAME = (FRAME + 1) MOD 100
90 REM APPLY SCREEN SHAKE
95 IF SHAKE > 0 THEN
100   PRINT CHR$(19); TAB(RND(1) * 2);
105   SHAKE = SHAKE - 1
110 ELSE
115   PRINT CHR$(19);
120 END IF
125 REM CLEAR SCREEN
130 FOR Y = 5 TO 23:
135   FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
140   PRINT STRING$(40, " ")
145 NEXT Y
150 REM UPDATE EXPLOSIONS
155 FOR I = 1 TO 10
160   IF EXP_FRAME(I) = 0 THEN 290
165   REM CALCULATE EXPLOSION RADIUS
170   RADIUS = EXP_FRAME(I) / 3
175   REM DRAW EXPLOSION PATTERN
180   FOR ANGLE = 0 TO 7
185     DX = INT(COS(ANGLE * 0.785) * RADIUS)
190     DY = INT(SIN(ANGLE * 0.785) * RADIUS)
195     PX = EXP_X(I) + DX: PY = EXP_Y(I) + DY
200     IF PX > 0 AND PX < 40 AND PY > 5 AND PY < 24 THEN
205       PRINT CHR$(19);: FOR Z = 1 TO PY: PRINT CHR$(17);: NEXT Z
210       PRINT TAB(PX);
215       IF EXP_FRAME(I) < 5 THEN PRINT WHITE$; "*"; OFF$
220       IF EXP_FRAME(I) >= 5 AND EXP_FRAME(I) < 10 THEN
225         PRINT YELLOW$; "+"; OFF$
230       END IF
235       IF EXP_FRAME(I) >= 10 AND EXP_FRAME(I) < 15 THEN
240         PRINT ORANGE$; "·"; OFF$
245       END IF
250       IF EXP_FRAME(I) >= 15 THEN PRINT RED$; "."; OFF$
255     END IF
260   NEXT ANGLE
265   REM ADVANCE EXPLOSION FRAME
270   EXP_FRAME(I) = EXP_FRAME(I) + 1
275   IF EXP_FRAME(I) > 20 THEN
280     EXP_FRAME(I) = 0: REM EXPLOSION COMPLETE
285   END IF
290 NEXT I
295 REM UPDATE PARTICLES
300 FOR I = 1 TO 20
305   IF PARTICLE_LIFE(I) = 0 THEN 370
310   REM APPLY PHYSICS
315   PARTICLE_X(I) = PARTICLE_X(I) + PARTICLE_VX(I)
320   PARTICLE_Y(I) = PARTICLE_Y(I) + PARTICLE_VY(I)
325   PARTICLE_VY(I) = PARTICLE_VY(I) + 0.1: REM GRAVITY
330   REM DRAW PARTICLE
335   IF PARTICLE_X(I) > 0 AND PARTICLE_X(I) < 40 THEN
340     IF PARTICLE_Y(I) > 5 AND PARTICLE_Y(I) < 24 THEN
345       PRINT CHR$(19);: FOR Z = 1 TO INT(PARTICLE_Y(I)): PRINT CHR$(17);: NEXT Z
350       PRINT TAB(INT(PARTICLE_X(I))); CYAN$; "·"; OFF$
355     END IF
360   END IF
365   PARTICLE_LIFE(I) = PARTICLE_LIFE(I) - 1
370 NEXT I
375 REM DRAW SHIP
380 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
385 PRINT TAB(SHIP_X); WHITE$; "▲"; OFF$
390 REM CONTROLS
395 GET KEY$: IF KEY$ = "" THEN 450
400 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
405 IF KEY$ = "D" AND SHIP_X < 38 THEN SHIP_X = SHIP_X + 1
410 IF KEY$ = "W" AND SHIP_Y > 5 THEN SHIP_Y = SHIP_Y - 1
415 IF KEY$ = "S" AND SHIP_Y < 23 THEN SHIP_Y = SHIP_Y + 1
420 IF KEY$ = " " THEN GOSUB 1000: REM TRIGGER EXPLOSION
425 IF KEY$ = "P" THEN GOSUB 1500: REM SPAWN PARTICLES
430 IF KEY$ = "Q" THEN END
450 FOR D = 1 TO 30: NEXT D: GOTO 85
1000 REM CREATE NEW EXPLOSION
1005 FOR I = 1 TO 10
1010   IF EXP_FRAME(I) = 0 THEN
1015     EXP_X(I) = SHIP_X: EXP_Y(I) = SHIP_Y
1020     EXP_FRAME(I) = 1
1025     EXP_TYPE(I) = INT(RND(1) * 3) + 1
1030     SHAKE = 10: REM SCREEN SHAKE
1035     GOSUB 1500: REM SPAWN PARTICLES TOO
1040     RETURN
1045   END IF
1050 NEXT I
1055 RETURN
1500 REM SPAWN PARTICLE BURST
1505 FOR I = 1 TO 20
1510   IF PARTICLE_LIFE(I) = 0 THEN
1515     PARTICLE_X(I) = SHIP_X
1520     PARTICLE_Y(I) = SHIP_Y
1525     PARTICLE_VX(I) = (RND(1) - 0.5) * 3
1530     PARTICLE_VY(I) = -RND(1) * 2 - 1
1535     PARTICLE_LIFE(I) = 20 + RND(1) * 20
1540   END IF
1545 NEXT I
1550 RETURN
```

**Explosion Features:**
- **Expanding rings** (170-260) grow outward from center
- **Multi-stage animation** (215-250) with color transitions
- **Screen shake** (95-120) adds physical impact
- **Particle physics** (315-325) with gravity and velocity
- **Layered effects** combine for maximum spectacle

`★ Insight ─────────────────────────────────────`
**Screen shake creates visceral feedback** - even a few pixels of random offset makes explosions feel powerful. The particle system uses simple physics (velocity + gravity) to create debris that feels real. This combination of expanding patterns and flying particles became the standard for 2D explosion effects.

When *Robotron: 2084* filled the screen with explosions, particles, and enemies, it showed that visual chaos could be controlled art.
