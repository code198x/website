# Ship Design

**From generic spaceship to personal starfighter! Create ship customization systems that let players express their style while gaining tactical advantages through meaningful design choices.**

<PrerequisiteBox system="commodore-64" phase={0} lessonNumber={40} />

## The Psychology of Choice

Your high score system creates lasting achievement, but there's another psychological hook that turns players into collectors: **ship variety**. When players can choose their starfighter, they become invested in their selection. It's not just "the ship" anymore - it's "MY ship":

<TryItNow>
```basic
10 REM SHIP SELECTION SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ASTEROID DODGER - SHIP SELECTION"; OFF$
40 PRINT STRING$(40, "═")
45 REM SHIP DATA ARRAYS
50 DIM SHIP_NAME$(5), SHIP_CHAR$(5), SHIP_COLOR$(5)
55 DIM SHIP_SPEED(5), SHIP_ARMOR(5), SHIP_FIREPOWER(5)
60 REM LOAD SHIP DEFINITIONS
65 FOR I = 1 TO 5
70   READ SHIP_NAME$(I), SHIP_CHAR$(I), SHIP_COLOR$(I)
75   READ SHIP_SPEED(I), SHIP_ARMOR(I), SHIP_FIREPOWER(I)
80 NEXT I
85 REM DISPLAY SHIP CATALOG
90 PRINT "AVAILABLE STARFIGHTERS:"
95 PRINT STRING$(40, "─")
100 FOR I = 1 TO 5
105   PRINT "#"; I; " "; SHIP_COLOR$(I); SHIP_CHAR$(I); " "; SHIP_NAME$(I); OFF$
110   PRINT "    SPEED:"; SHIP_SPEED(I); " ARMOR:"; SHIP_ARMOR(I); " POWER:"; SHIP_FIREPOWER(I)
115   PRINT
120 NEXT I
125 PRINT STRING$(40, "─")
130 INPUT "SELECT YOUR SHIP (1-5): "; CHOICE
135 IF CHOICE < 1 OR CHOICE > 5 THEN 130
140 REM SHIP SELECTION CONFIRMATION
145 SELECTED_SHIP = CHOICE
150 PRINT
155 PRINT GREEN$; "SHIP SELECTED: "; SHIP_NAME$(SELECTED_SHIP); OFF$
160 PRINT "APPEARANCE: "; SHIP_COLOR$(SELECTED_SHIP); SHIP_CHAR$(SELECTED_SHIP); OFF$
165 PRINT "STATS - SPEED:"; SHIP_SPEED(SELECTED_SHIP);
170 PRINT " ARMOR:"; SHIP_ARMOR(SELECTED_SHIP);
175 PRINT " FIREPOWER:"; SHIP_FIREPOWER(SELECTED_SHIP)
180 PRINT
185 PRINT YELLOW$; "LAUNCHING INTO ASTEROID FIELD..."; OFF$
190 FOR I = 1 TO 30: PRINT ".";: FOR J = 1 TO 50: NEXT J: NEXT I
195 PRINT
200 PRINT CYAN$; "GOOD LUCK, PILOT!"; OFF$
205 END
300 REM SHIP DATABASE
305 DATA "INTERCEPTOR", "▲", ""
310 DATA 8, 3, 6
315 DATA "DESTROYER", "♦", ""
320 DATA 5, 8, 7
325 DATA "SCOUT", "▴", ""
330 DATA 9, 2, 4
335 DATA "BATTLESHIP", "▲", ""
340 DATA 4, 9, 9
345 DATA "FIGHTER", "►", ""
350 DATA 7, 5, 8
```
</TryItNow>

**Ship Selection Psychology:**
- **Visual identity** (305-350) creates instant personality for each ship type
- **Stat trade-offs** (speed vs armor vs firepower) force meaningful choices
- **Selection ritual** (130-200) makes the choice feel important and personal
- **Confirmation display** (155-175) reinforces the player's decision

This simple system transforms players from "users" into "pilots with preferences"!

`★ Insight ─────────────────────────────────────`
**Ship selection is identity formation**. When a player chooses the fast Scout over the heavy Battleship, they're not just picking stats - they're declaring "I'm the type of pilot who relies on speed and skill." The ship becomes an extension of their gaming personality.

**PETSCII limitations become features**. We can't draw detailed spaceships, but `▲`, `♦`, `▴`, and `►` create instantly recognizable silhouettes that players memorize and prefer.
`─────────────────────────────────────────────────`

## Visual Ship Customizer

Let's add a proper ship preview system that lets players see exactly what they're choosing:

<TryItNow>
```basic
10 REM VISUAL SHIP CUSTOMIZER
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "STARFIGHTER CUSTOMIZATION BAY"; OFF$
40 PRINT STRING$(40, "═")
45 REM SHIP DESIGN ELEMENTS
50 DIM HULL$(4), ENGINE$(3), WEAPON$(3)
55 DIM HULL_COLOR$(4), ENGINE_COLOR$(3), WEAPON_COLOR$(3)
60 REM LOAD CUSTOMIZATION OPTIONS
65 HULL$(1) = "▲": HULL$(2) = "♦": HULL$(3) = "▴": HULL$(4) = "►"
70 ENGINE$(1) = "▼": ENGINE$(2) = "♢": ENGINE$(3) = "▾"
75 WEAPON$(1) = "┬": WEAPON$(2) = "╬": WEAPON$(3) = "┼"
80 REM COLORS FOR EACH COMPONENT
85 HULL_COLOR$(1) = GREEN$: HULL_COLOR$(2) = RED$
90 HULL_COLOR$(3) = YELLOW$: HULL_COLOR$(4) = CYAN$
95 ENGINE_COLOR$(1) = RED$: ENGINE_COLOR$(2) = YELLOW$: ENGINE_COLOR$(3) = PURPLE$
100 WEAPON_COLOR$(1) = CYAN$: WEAPON_COLOR$(2) = WHITE$: WEAPON_COLOR$(3) = GREEN$
105 REM CURRENT SELECTION
110 HULL_CHOICE = 1: ENGINE_CHOICE = 1: WEAPON_CHOICE = 1
115 REM CUSTOMIZATION LOOP
120 GOSUB 2000: REM DISPLAY CURRENT DESIGN
125 PRINT STRING$(40, "─")
130 PRINT "1) CHANGE HULL  2) CHANGE ENGINE  3) CHANGE WEAPONS"
135 PRINT "4) LAUNCH SHIP  5) RESET DESIGN"
140 PRINT STRING$(40, "─")
145 INPUT "YOUR CHOICE (1-5): "; MENU_CHOICE
150 IF MENU_CHOICE = 1 THEN GOSUB 1000
155 IF MENU_CHOICE = 2 THEN GOSUB 1100
160 IF MENU_CHOICE = 3 THEN GOSUB 1200
165 IF MENU_CHOICE = 4 THEN GOSUB 3000: END
170 IF MENU_CHOICE = 5 THEN HULL_CHOICE = 1: ENGINE_CHOICE = 1: WEAPON_CHOICE = 1
175 GOTO 115
1000 REM HULL SELECTION
1005 PRINT "HULL OPTIONS:"
1010 FOR I = 1 TO 4
1015   PRINT I; ") "; HULL_COLOR$(I); HULL$(I); " HULL TYPE "; I; OFF$
1020 NEXT I
1025 INPUT "SELECT HULL (1-4): "; HULL_CHOICE
1030 IF HULL_CHOICE < 1 OR HULL_CHOICE > 4 THEN 1025
1035 RETURN
1100 REM ENGINE SELECTION
1105 PRINT "ENGINE OPTIONS:"
1110 FOR I = 1 TO 3
1115   PRINT I; ") "; ENGINE_COLOR$(I); ENGINE$(I); " ENGINE TYPE "; I; OFF$
1120 NEXT I
1125 INPUT "SELECT ENGINE (1-3): "; ENGINE_CHOICE
1130 IF ENGINE_CHOICE < 1 OR ENGINE_CHOICE > 3 THEN 1125
1135 RETURN
1200 REM WEAPON SELECTION
1205 PRINT "WEAPON OPTIONS:"
1210 FOR I = 1 TO 3
1215   PRINT I; ") "; WEAPON_COLOR$(I); WEAPON$(I); " WEAPON SYSTEM "; I; OFF$
1220 NEXT I
1225 INPUT "SELECT WEAPONS (1-3): "; WEAPON_CHOICE
1230 IF WEAPON_CHOICE < 1 OR WEAPON_CHOICE > 3 THEN 1225
1235 RETURN
2000 REM DISPLAY CURRENT SHIP DESIGN
2005 PRINT CHR$(147)
2010 PRINT WHITE$; "STARFIGHTER CUSTOMIZATION BAY"; OFF$
2015 PRINT STRING$(40, "═")
2020 PRINT "CURRENT DESIGN:"
2025 PRINT
2030 REM DISPLAY SHIP COMPONENTS
2035 PRINT TAB(18); WEAPON_COLOR$(WEAPON_CHOICE); WEAPON$(WEAPON_CHOICE); OFF$
2040 PRINT TAB(17); HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$;
2045 PRINT HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$;
2050 PRINT HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$
2055 PRINT TAB(18); ENGINE_COLOR$(ENGINE_CHOICE); ENGINE$(ENGINE_CHOICE); OFF$
2060 PRINT
2065 PRINT "CONFIGURATION:"
2070 PRINT "HULL: "; HULL_COLOR$(HULL_CHOICE); "TYPE "; HULL_CHOICE; OFF$
2075 PRINT "ENGINE: "; ENGINE_COLOR$(ENGINE_CHOICE); "TYPE "; ENGINE_CHOICE; OFF$
2080 PRINT "WEAPONS: "; WEAPON_COLOR$(WEAPON_CHOICE); "TYPE "; WEAPON_CHOICE; OFF$
2085 PRINT
2090 RETURN
3000 REM LAUNCH SEQUENCE
3005 PRINT CHR$(147)
3010 PRINT GREEN$; "SHIP CONSTRUCTION COMPLETE!"; OFF$
3015 PRINT
3020 PRINT "FINAL STARFIGHTER:"
3025 PRINT TAB(18); WEAPON_COLOR$(WEAPON_CHOICE); WEAPON$(WEAPON_CHOICE); OFF$
3030 PRINT TAB(17); HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$;
3035 PRINT HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$;
3040 PRINT HULL_COLOR$(HULL_CHOICE); HULL$(HULL_CHOICE); OFF$
3045 PRINT TAB(18); ENGINE_COLOR$(ENGINE_CHOICE); ENGINE$(ENGINE_CHOICE); OFF$
3050 PRINT
3055 PRINT YELLOW$; "LAUNCHING INTO COMBAT!"; OFF$
3060 FOR I = 1 TO 20: PRINT ".";: FOR J = 1 TO 100: NEXT J: NEXT I
3065 PRINT
3070 PRINT CYAN$; "FLY WELL, PILOT!"; OFF$
3075 RETURN
```
</TryItNow>

**Visual Customizer Features:**
- **Component preview** (2035-2055) shows assembled ship design in real-time
- **Category-based selection** (1000-1200) organizes choices by ship system
- **Construction ritual** (3000-3075) celebrates the final custom design
- **PETSCII assembly** creates the illusion of building a unique starfighter

Players now design their own personal starfighter from component parts!

<InfoBox>
Visual ship customization taps into the same psychology that made model kits popular in the 1980s. Even with simple PETSCII characters, players feel like they're "building" something unique. The preview system is crucial - players need to see their choices come together into a cohesive design.
</InfoBox>

## Performance-Based Ship Design

The ultimate customization system ties ship appearance to actual gameplay advantages:

<TryItNow>
```basic
10 REM PERFORMANCE-BASED SHIP DESIGN
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ADVANCED SHIP ENGINEERING"; OFF$
40 PRINT STRING$(40, "═")
45 REM PERFORMANCE CATEGORIES
50 DIM HULL_STATS(4, 3), ENGINE_STATS(3, 3), WEAPON_STATS(3, 3)
55 DIM SHIP_NAME$(20), TOTAL_SPEED, TOTAL_ARMOR, TOTAL_FIREPOWER
60 REM LOAD COMPONENT PERFORMANCE DATA
65 REM HULL STATS: SPEED, ARMOR, FIREPOWER
70 HULL_STATS(1, 1) = 0: HULL_STATS(1, 2) = 5: HULL_STATS(1, 3) = 2: REM LIGHT
75 HULL_STATS(2, 1) = -2: HULL_STATS(2, 2) = 8: HULL_STATS(2, 3) = 3: REM HEAVY
80 HULL_STATS(3, 1) = 3: HULL_STATS(3, 2) = 2: HULL_STATS(3, 3) = 1: REM FAST
85 HULL_STATS(4, 1) = 1: HULL_STATS(4, 2) = 6: HULL_STATS(4, 3) = 4: REM BALANCED
90 REM ENGINE STATS: SPEED, ARMOR, FIREPOWER
95 ENGINE_STATS(1, 1) = 3: ENGINE_STATS(1, 2) = 0: ENGINE_STATS(1, 3) = 1: REM SPEED
100 ENGINE_STATS(2, 1) = 1: ENGINE_STATS(2, 2) = 2: ENGINE_STATS(2, 3) = 0: REM STABLE
105 ENGINE_STATS(3, 1) = 5: ENGINE_STATS(3, 2) = -1: ENGINE_STATS(3, 3) = 2: REM TURBO
110 REM WEAPON STATS: SPEED, ARMOR, FIREPOWER
115 WEAPON_STATS(1, 1) = 0: WEAPON_STATS(1, 2) = 0: WEAPON_STATS(1, 3) = 4: REM BASIC
120 WEAPON_STATS(2, 1) = -1: WEAPON_STATS(2, 2) = 1: WEAPON_STATS(2, 3) = 7: REM HEAVY
125 WEAPON_STATS(3, 1) = 2: WEAPON_STATS(3, 2) = 0: WEAPON_STATS(3, 3) = 6: REM RAPID
130 REM COMPONENT NAMES FOR DISPLAY
135 DIM HULL_NAME$(4), ENGINE_NAME$(3), WEAPON_NAME$(3)
140 HULL_NAME$(1) = "LIGHT FRAME": HULL_NAME$(2) = "ARMOR PLATING"
145 HULL_NAME$(3) = "SPEED CHASSIS": HULL_NAME$(4) = "BALANCED HULL"
150 ENGINE_NAME$(1) = "SPEED DRIVE": ENGINE_NAME$(2) = "STABLE ENGINE"
155 ENGINE_NAME$(3) = "TURBO BOOST"
160 WEAPON_NAME$(1) = "BASIC LASERS": WEAPON_NAME$(2) = "HEAVY CANNONS"
165 WEAPON_NAME$(3) = "RAPID FIRE"
170 REM CURRENT CONFIGURATION
175 HULL_TYPE = 1: ENGINE_TYPE = 1: WEAPON_TYPE = 1
180 REM ENGINEERING INTERFACE
185 GOSUB 2000: REM CALCULATE AND DISPLAY STATS
190 PRINT STRING$(40, "─")
195 PRINT "1) HULL  2) ENGINE  3) WEAPONS  4) TEST FLIGHT  5) OPTIMIZE"
200 PRINT STRING$(40, "─")
205 INPUT "MODIFY COMPONENT (1-5): "; CHOICE
210 IF CHOICE = 1 THEN GOSUB 1000
215 IF CHOICE = 2 THEN GOSUB 1100
220 IF CHOICE = 3 THEN GOSUB 1200
225 IF CHOICE = 4 THEN GOSUB 3000
230 IF CHOICE = 5 THEN GOSUB 4000
235 GOTO 185
1000 REM HULL SELECTION WITH STATS
1005 PRINT "HULL OPTIONS:"
1010 FOR I = 1 TO 4
1015   PRINT I; ") "; HULL_NAME$(I)
1020   PRINT "   SPD:"; HULL_STATS(I, 1); " ARM:"; HULL_STATS(I, 2); " PWR:"; HULL_STATS(I, 3)
1025 NEXT I
1030 INPUT "SELECT HULL (1-4): "; HULL_TYPE
1035 IF HULL_TYPE < 1 OR HULL_TYPE > 4 THEN 1030
1040 RETURN
1100 REM ENGINE SELECTION WITH STATS
1105 PRINT "ENGINE OPTIONS:"
1110 FOR I = 1 TO 3
1115   PRINT I; ") "; ENGINE_NAME$(I)
1120   PRINT "   SPD:"; ENGINE_STATS(I, 1); " ARM:"; ENGINE_STATS(I, 2); " PWR:"; ENGINE_STATS(I, 3)
1125 NEXT I
1130 INPUT "SELECT ENGINE (1-3): "; ENGINE_TYPE
1135 IF ENGINE_TYPE < 1 OR ENGINE_TYPE > 3 THEN 1130
1140 RETURN
1200 REM WEAPON SELECTION WITH STATS
1205 PRINT "WEAPON OPTIONS:"
1210 FOR I = 1 TO 3
1215   PRINT I; ") "; WEAPON_NAME$(I)
1220   PRINT "   SPD:"; WEAPON_STATS(I, 1); " ARM:"; WEAPON_STATS(I, 2); " PWR:"; WEAPON_STATS(I, 3)
1225 NEXT I
1230 INPUT "SELECT WEAPONS (1-3): "; WEAPON_TYPE
1235 IF WEAPON_TYPE < 1 OR WEAPON_TYPE > 3 THEN 1230
1240 RETURN
2000 REM CALCULATE AND DISPLAY TOTAL STATS
2005 PRINT CHR$(147)
2010 PRINT WHITE$; "ADVANCED SHIP ENGINEERING"; OFF$
2015 PRINT STRING$(40, "═")
2020 REM CALCULATE TOTAL PERFORMANCE
2025 TOTAL_SPEED = 5 + HULL_STATS(HULL_TYPE, 1) + ENGINE_STATS(ENGINE_TYPE, 1) + WEAPON_STATS(WEAPON_TYPE, 1)
2030 TOTAL_ARMOR = 5 + HULL_STATS(HULL_TYPE, 2) + ENGINE_STATS(ENGINE_TYPE, 2) + WEAPON_STATS(WEAPON_TYPE, 2)
2035 TOTAL_FIREPOWER = 5 + HULL_STATS(HULL_TYPE, 3) + ENGINE_STATS(ENGINE_TYPE, 3) + WEAPON_STATS(WEAPON_TYPE, 3)
2040 REM DISPLAY CURRENT CONFIGURATION
2045 PRINT "CURRENT CONFIGURATION:"
2050 PRINT "HULL: "; HULL_NAME$(HULL_TYPE)
2055 PRINT "ENGINE: "; ENGINE_NAME$(ENGINE_TYPE)
2060 PRINT "WEAPONS: "; WEAPON_NAME$(WEAPON_TYPE)
2065 PRINT
2070 REM DISPLAY TOTAL STATS WITH COLOR CODING
2075 PRINT "TOTAL PERFORMANCE:"
2080 COLOR$ = GREEN$: IF TOTAL_SPEED < 5 THEN COLOR$ = RED$: IF TOTAL_SPEED > 7 THEN COLOR$ = CYAN$
2085 PRINT "SPEED: "; COLOR$; TOTAL_SPEED; OFF$
2090 COLOR$ = GREEN$: IF TOTAL_ARMOR < 5 THEN COLOR$ = RED$: IF TOTAL_ARMOR > 7 THEN COLOR$ = CYAN$
2095 PRINT "ARMOR: "; COLOR$; TOTAL_ARMOR; OFF$
2100 COLOR$ = GREEN$: IF TOTAL_FIREPOWER < 5 THEN COLOR$ = RED$: IF TOTAL_FIREPOWER > 7 THEN COLOR$ = CYAN$
2105 PRINT "FIREPOWER: "; COLOR$; TOTAL_FIREPOWER; OFF$
2110 REM PERFORMANCE RATING
2115 PERFORMANCE_RATING = TOTAL_SPEED + TOTAL_ARMOR + TOTAL_FIREPOWER
2120 PRINT "OVERALL RATING: "; PERFORMANCE_RATING; "/30"
2125 PRINT
2130 RETURN
3000 REM TEST FLIGHT SIMULATION
3005 PRINT "LAUNCHING TEST FLIGHT..."
3010 FOR I = 1 TO 20: PRINT ".";: FOR J = 1 TO 50: NEXT J: NEXT I
3015 PRINT
3020 REM SIMULATE PERFORMANCE RESULTS
3025 SPEED_RESULT = TOTAL_SPEED * (RND(1) * 0.4 + 0.8)
3030 ARMOR_RESULT = TOTAL_ARMOR * (RND(1) * 0.4 + 0.8)
3035 FIREPOWER_RESULT = TOTAL_FIREPOWER * (RND(1) * 0.4 + 0.8)
3040 PRINT GREEN$; "TEST FLIGHT RESULTS:"; OFF$
3045 PRINT "SPEED PERFORMANCE: "; INT(SPEED_RESULT * 10); "%"
3050 PRINT "ARMOR EFFECTIVENESS: "; INT(ARMOR_RESULT * 10); "%"
3055 PRINT "FIREPOWER RATING: "; INT(FIREPOWER_RESULT * 10); "%"
3060 PRINT
3065 INPUT "PRESS ENTER TO CONTINUE"; DUMMY$
3070 RETURN
4000 REM AUTO-OPTIMIZATION
4005 PRINT "ANALYZING OPTIMAL CONFIGURATION..."
4010 FOR I = 1 TO 15: PRINT ".";: FOR J = 1 TO 50: NEXT J: NEXT I
4015 PRINT
4020 REM SUGGEST BEST BALANCE
4025 HULL_TYPE = 4: ENGINE_TYPE = 2: WEAPON_TYPE = 1: REM BALANCED BUILD
4030 PRINT YELLOW$; "OPTIMIZATION COMPLETE!"; OFF$
4035 PRINT "RECOMMENDED: BALANCED HULL + STABLE ENGINE + BASIC LASERS"
4040 PRINT "FOR WELL-ROUNDED PERFORMANCE"
4045 INPUT "APPLY THESE SETTINGS? (Y/N): "; APPLY$
4050 IF APPLY$ <> "Y" AND APPLY$ <> "y" THEN RETURN
4055 PRINT GREEN$; "CONFIGURATION APPLIED!"; OFF$
4060 RETURN
```
</TryItNow>

**Performance-Based Features:**
- **Stat calculation** (2025-2035) combines component effects into meaningful totals
- **Color-coded feedback** (2080-2105) shows at-a-glance performance levels
- **Test flight simulation** (3000-3070) lets players experience their design choices
- **Auto-optimization** (4000-4060) suggests balanced configurations for new players

Now ship design directly affects gameplay performance!

<RetroMoment title="The Rise of Player Expression: 1984">
When *Elite* let players name their ships and choose their cargo, it changed how players related to their virtual possessions. Before this, you played "the game" - after this, you flew "your ship."
