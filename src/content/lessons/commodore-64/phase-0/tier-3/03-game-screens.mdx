## Beyond Raw Gameplay

You've mastered ship control and collision detection - the core mechanics. Now comes the presentation layer that transforms bedroom programming into commercial-quality software:

<TryItNow>
```basic
10 REM GAME SCREENS - PROFESSIONAL PRESENTATION
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
```

**Professional Screen Architecture:**
- **State management** (line 35) controls which screen displays
- **Persistent data** (lines 40-45) carries between screens
- **Clean transitions** (lines 1080, 2075, 3160) switch states smoothly
- **Player identity** (lines 1055-1065) personalizes the experience

<InfoBox>
Game states transform chaotic code into organized flow. Instead of one massive program, you have discrete screens that hand control to each other. This is how professional games manage complex user experiences!

## Real-Time Status Systems

Let's create the kind of sophisticated status displays that made arcade games feel alive and responsive:

<TryItNow>
```basic
10 REM REAL-TIME STATUS SYSTEMS
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM GAME DATA
35 SCORE = 0: LIVES = 5: SHIELD = 100: FUEL = 80
40 ASTEROIDS_DESTROYED = 0: POWER_UPS = 0
45 GAME_TIME = 0: BONUS_TIMER = 300
50 SHIP_X = 20: SHIP_Y = 15: FRAME = 0
55 REM MAIN GAME WITH REAL-TIME STATUS
60 FRAME = FRAME + 1: GAME_TIME = GAME_TIME + 1
65 IF BONUS_TIMER > 0 THEN BONUS_TIMER = BONUS_TIMER - 1
70 PRINT CHR$(147): REM CLEAR SCREEN
75 REM TITLE BAR
80 PRINT WHITE$; "▓▓▓ ASTEROID DODGER COMMAND ▓▓▓"; OFF$
85 PRINT STRING$(40, "═")
90 REM PRIMARY STATUS
95 PRINT "SCORE: "; YELLOW$;
100 FOR I = LEN(STR$(SCORE)) TO 7: PRINT "0";: NEXT I
105 PRINT SCORE; OFF$;
110 PRINT " LIVES: "; GREEN$;
115 FOR I = 1 TO LIVES: PRINT "♦";: NEXT I
120 PRINT OFF$
125 REM SECONDARY STATUS
130 PRINT "SHIELD: ";
135 SHIELD_BARS = INT(SHIELD / 10)
140 FOR I = 1 TO SHIELD_BARS: PRINT GREEN$; "█"; OFF$;: NEXT I
145 FOR I = SHIELD_BARS + 1 TO 10: PRINT RED$; "▒"; OFF$;: NEXT I
150 PRINT " "; SHIELD; "%"
155 PRINT "FUEL:   ";
160 FUEL_BARS = INT(FUEL / 10)
165 IF FUEL > 20 THEN FUEL_COLOR$ = YELLOW$ ELSE FUEL_COLOR$ = RED$
170 FOR I = 1 TO FUEL_BARS: PRINT FUEL_COLOR$; "█"; OFF$;: NEXT I
175 FOR I = FUEL_BARS + 1 TO 10: PRINT " ";: NEXT I
180 PRINT " "; FUEL; "%"
185 PRINT STRING$(40, "─")
190 REM GAME AREA HEADER
195 PRINT "ASTEROIDS: "; ASTEROIDS_DESTROYED; " POWER-UPS: "; POWER_UPS;
200 IF BONUS_TIMER > 0 THEN PRINT " BONUS: "; BONUS_TIMER ELSE PRINT
205 PRINT STRING$(40, "─")
210 REM SIMPLIFIED GAME AREA
215 FOR I = 1 TO 10: PRINT: NEXT I: REM GAME AREA SPACER
220 REM STATUS FOOTER
225 PRINT STRING$(40, "─")
230 PRINT "TIME: "; INT(GAME_TIME / 60); ":";
235 SECONDS = (GAME_TIME MOD 60)
240 IF SECONDS < 10 THEN PRINT "0";
245 PRINT SECONDS;
250 PRINT "  FRAME: "; FRAME;
255 PRINT "  SHIP: ("; SHIP_X; ","; SHIP_Y; ")"
260 REM SIMULATE GAME CHANGES
265 IF FRAME MOD 30 = 0 THEN SCORE = SCORE + 100: ASTEROIDS_DESTROYED = ASTEROIDS_DESTROYED + 1
270 IF FRAME MOD 45 = 0 THEN FUEL = FUEL - 1: IF FUEL < 0 THEN FUEL = 0
275 IF FRAME MOD 60 = 0 THEN SHIELD = SHIELD - 5: IF SHIELD < 0 THEN SHIELD = 0
280 REM CONTROLS
285 GET KEY$
290 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1
295 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
300 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1
305 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1
310 IF KEY$ = "Q" OR KEY$ = "q" THEN 400
315 REM BOUNDARY CHECKING
320 IF SHIP_X < 1 THEN SHIP_X = 1
325 IF SHIP_X > 39 THEN SHIP_X = 39
330 IF SHIP_Y < 1 THEN SHIP_Y = 1
335 IF SHIP_Y > 20 THEN SHIP_Y = 20
340 GOTO 60
400 PRINT: PRINT YELLOW$; "MISSION TERMINATED"; OFF$: END
```
</TryItNow>

**Real-Time Display Features:**
- **Zero-padded scores** (lines 95-105) look professional
- **Visual health bars** (lines 135-150) show status at a glance
- **Color-coded warnings** (line 165) highlight danger
- **Time displays** (lines 230-245) track mission progress
- **Dynamic updates** (lines 265-275) simulate live gameplay

`★ Insight ─────────────────────────────────────`
**Professional status displays are information hierarchies**. Critical data (score, lives) goes at the top in big, clear fonts. Secondary data (fuel, time) uses visual indicators like bars and colors. Tertiary data (coordinates, frame count) goes at the bottom in small text.

**Color psychology matters**. Green = good/safe. Yellow = caution. Red = danger. This isn't just decoration - it helps players make split-second decisions without reading numbers.
`─────────────────────────────────────────────────`

## Complete Game Flow

Let's integrate everything into a complete game flow that feels like a commercial release:

<TryItNow>
```basic
10 REM COMPLETE PROFESSIONAL GAME FLOW
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM PERSISTENT GAME DATA
35 HIGH_SCORE = 5000: TOTAL_GAMES = 0
40 BEST_PILOT$ = "COMMANDER_ACE"
45 REM CURRENT GAME DATA
50 GAME_STATE = 0: REM 0=ATTRACT, 1=TITLE, 2=PLAY, 3=OVER
55 PLAYER_NAME$ = "": SCORE = 0: LIVES = 3: LEVEL = 1
60 DEMO_TIMER = 0
65 REM MAIN GAME LOOP
70 IF GAME_STATE = 0 THEN GOSUB 1000: REM ATTRACT MODE
75 IF GAME_STATE = 1 THEN GOSUB 2000: REM TITLE SCREEN
80 IF GAME_STATE = 2 THEN GOSUB 3000: REM GAMEPLAY
85 IF GAME_STATE = 3 THEN GOSUB 4000: REM GAME OVER
90 GOTO 70
1000 REM ATTRACT MODE
1005 DEMO_TIMER = DEMO_TIMER + 1
1010 PRINT CHR$(147)
1015 REM ANIMATED TITLE
1020 TITLE_FLASH = (DEMO_TIMER MOD 40) < 20
1025 IF TITLE_FLASH THEN PRINT TAB(8); YELLOW$; "★ ASTEROID DODGER ★"; OFF$
1030 IF NOT TITLE_FLASH THEN PRINT TAB(8); WHITE$; "★ ASTEROID DODGER ★"; OFF$
1035 PRINT STRING$(40, "═")
1040 PRINT: PRINT TAB(12); "DEMO MODE"
1045 PRINT: PRINT "HIGH SCORE: "; GREEN$; HIGH_SCORE; OFF$
1050 PRINT "RECORD HOLDER: "; YELLOW$; BEST_PILOT$; OFF$
1055 PRINT: PRINT "GAMES PLAYED: "; TOTAL_GAMES
1060 PRINT: PRINT STRING$(40, "─")
1065 REM DEMO GAMEPLAY SIMULATION
1070 PRINT: PRINT "SIMULATING EXPERT GAMEPLAY..."
1075 DEMO_SCORE = INT(RND(1) * 3000) + 1000
1080 PRINT "DEMO PILOT SCORE: "; DEMO_SCORE
1085 PRINT: PRINT STRING$(40, "─")
1090 PRINT: PRINT TAB(8); "PRESS ANY KEY TO PLAY!"
1095 GET KEY$
1100 IF KEY$ <> "" THEN GAME_STATE = 1: DEMO_TIMER = 0
1105 IF DEMO_TIMER > 200 THEN DEMO_TIMER = 0: REM RESTART DEMO
1110 RETURN
2000 REM TITLE SCREEN
2005 PRINT CHR$(147)
2010 REM PROFESSIONAL TITLE DESIGN
2015 PRINT TAB(6); WHITE$; "▓▓▓ ASTEROID DODGER ▓▓▓"; OFF$
2020 PRINT STRING$(40, "═")
2025 PRINT: PRINT TAB(5); PURPLE$; "COMMAND YOUR SHIP THROUGH"; OFF$
2030 PRINT TAB(7); PURPLE$; "THE DEADLY ASTEROID FIELD"; OFF$
2035 PRINT: PRINT STRING$(40, "─")
2040 PRINT: PRINT "HALL OF FAME:"
2045 PRINT "1ST: "; YELLOW$; BEST_PILOT$; OFF$; TAB(25); HIGH_SCORE; " PTS"
2050 PRINT "2ND: STAR_CAPTAIN"; TAB(25); INT(HIGH_SCORE * 0.8); " PTS"
2055 PRINT "3RD: SPACE_CADET"; TAB(25); INT(HIGH_SCORE * 0.6); " PTS"
2060 PRINT: PRINT STRING$(40, "─")
2065 PRINT: PRINT "DIFFICULTY LEVELS:"
2070 PRINT "1 - CADET (EASY)"
2075 PRINT "2 - PILOT (NORMAL)"
2080 PRINT "3 - ACE (HARD)"
2085 PRINT: INPUT "SELECT DIFFICULTY (1-3)"; DIFFICULTY
2090 IF DIFFICULTY < 1 OR DIFFICULTY > 3 THEN DIFFICULTY = 2
2095 PRINT: INPUT "ENTER PILOT CALLSIGN"; PLAYER_NAME$
2100 IF PLAYER_NAME$ = "" THEN PLAYER_NAME$ = "ROOKIE"
2105 PRINT: PRINT GREEN$; "LAUNCHING MISSION FOR "; PLAYER_NAME$; OFF$
2110 PRINT "PRESS ANY KEY WHEN READY!"
2115 GET KEY$: IF KEY$ = "" THEN 2115
2120 TOTAL_GAMES = TOTAL_GAMES + 1
2125 GAME_STATE = 2
2130 RETURN
3000 REM GAMEPLAY SCREEN
3005 PRINT CHR$(147)
3010 REM GAME HUD
3015 PRINT WHITE$; "MISSION STATUS"; OFF$; TAB(25); "PILOT: "; PLAYER_NAME$
3020 PRINT STRING$(40, "═")
3025 PRINT "SCORE: "; SCORE; " LIVES: "; LIVES; " LEVEL: "; LEVEL
3030 PRINT STRING$(40, "─")
3035 REM SIMULATE GAMEPLAY
3040 PRINT: PRINT "NAVIGATING ASTEROID FIELD LEVEL "; LEVEL; "..."
3045 FOR I = 1 TO 50 + (LEVEL * 10)
3050 SCORE = SCORE + (DIFFICULTY * 10)
3055 NEXT I
3060 PRINT: PRINT GREEN$; "LEVEL CLEARED! BONUS +"; (LEVEL * 100); OFF$
3065 SCORE = SCORE + (LEVEL * 100)
3070 LEVEL = LEVEL + 1
3075 REM CHECK FOR LIFE LOST (RANDOM)
3080 IF INT(RND(1) * 4) = 0 THEN LIVES = LIVES - 1: PRINT RED$; "SHIP DAMAGED!"; OFF$
3085 PRINT: PRINT "PRESS ANY KEY FOR NEXT LEVEL"
3090 GET KEY$: IF KEY$ = "" THEN 3090
3095 IF LIVES <= 0 THEN GAME_STATE = 3
3100 IF LEVEL > 10 THEN GAME_STATE = 3: REM WIN CONDITION
3105 RETURN
4000 REM GAME OVER SCREEN
4005 PRINT CHR$(147)
4010 IF LIVES > 0 THEN 4100: REM VICTORY
4015 REM DEFEAT SCREEN
4020 PRINT: PRINT: PRINT TAB(12); RED$; "SHIP LOST"; OFF$
4025 PRINT: PRINT STRING$(40, "═")
4030 GOTO 4150
4100 REM VICTORY SCREEN
4105 PRINT: PRINT: PRINT TAB(10); GREEN$; "MISSION SUCCESS!"; OFF$
4110 PRINT: PRINT STRING$(40, "═")
4115 SCORE = SCORE + (LIVES * 500): REM SURVIVAL BONUS
4150 REM COMMON ENDING
4155 PRINT: PRINT "PILOT: "; YELLOW$; PLAYER_NAME$; OFF$
4160 PRINT "FINAL SCORE: "; YELLOW$; SCORE; OFF$
4165 PRINT "LEVELS COMPLETED: "; LEVEL - 1
4170 PRINT: PRINT STRING$(40, "─")
4175 IF SCORE > HIGH_SCORE THEN 4200
4180 PRINT: PRINT "RESPECTABLE PERFORMANCE, "; PLAYER_NAME$
4185 GOTO 4250
4200 REM NEW HIGH SCORE
4205 PRINT: PRINT GREEN$; "★ NEW RECORD! ★"; OFF$
4210 HIGH_SCORE = SCORE: BEST_PILOT$ = PLAYER_NAME$
4215 PRINT "CONGRATULATIONS, COMMANDER "; PLAYER_NAME$; "!"
4250 PRINT: PRINT STRING$(40, "─")
4255 PRINT: PRINT "R - RESTART MISSION"
4260 PRINT "A - RETURN TO ATTRACT MODE"
4265 PRINT "Q - QUIT TO COMMAND DECK"
4270 GET KEY$
4275 IF KEY$ = "R" OR KEY$ = "r" THEN SCORE = 0: LIVES = 3: LEVEL = 1: GAME_STATE = 1
4280 IF KEY$ = "A" OR KEY$ = "a" THEN GAME_STATE = 0
4285 IF KEY$ = "Q" OR KEY$ = "q" THEN END
4290 IF KEY$ = "" THEN 4270
4295 RETURN
```
</TryItNow>

**Complete Game Experience:**

- **Difficulty selection** (lines 2065-2090) customizes challenge level
- **Victory conditions** (lines 4100-4115) reward excellence
- **Persistent records** (lines 4205-4215) make achievements meaningful
