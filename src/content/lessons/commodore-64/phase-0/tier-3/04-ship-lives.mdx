## From Events to Consequences

Your collision detection works perfectly - now let's make it matter! Games without consequences are just tech demos. Real games create tension through limited lives:

<TryItNow>
```basic

15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM GAME VARIABLES
35 LIVES = 3: SCORE = 0: LEVEL = 1
40 SHIP_X = 10: SHIP_Y = 15
45 AST_X = 25: AST_Y = 12

155 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$

205 IF SHIP_X > 39 THEN SHIP_X = 39
210 IF SHIP_Y < 5 THEN SHIP_Y = 5
215 IF SHIP_Y > 20 THEN SHIP_Y = 20
220 REM COLLISION DETECTION

230 REM SIMPLE ASTEROID MOVEMENT
235 IF FRAME MOD 20 = 0 THEN AST_X = AST_X - 1: IF AST_X < 1 THEN AST_X = 39: SCORE = SCORE + 100
240 GOTO 60

2000 REM COLLISION - LOSE LIFE
2005 LIVES = LIVES - 1
2010 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
2015 PRINT TAB(SHIP_X); YELLOW$; "☀"; OFF$

2030 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
2035 PRINT TAB(SHIP_X); RED$; "☀"; OFF$
2040 FOR DELAY = 1 TO 200: NEXT DELAY
2045 NEXT FLASH
2050 REM CHECK GAME OVER
2055 IF LIVES <= 0 THEN 3000
2060 REM RESPAWN SHIP SAFELY

3015 PRINT: PRINT STRING$(40, "═")

3025 PRINT "FINAL SCORE: "; SCORE
3030 PRINT "ASTEROIDS DODGED: "; INT(SCORE / 100)
3035 END
```
</TryItNow>

**Life System Fundamentals:**
- **Lives display** (lines 85-125) shows remaining and lost lives visually
- **Collision consequences** (lines 2005, 2055) decrement lives and check game over
- **Dramatic feedback** (lines 2020-2045) makes ship destruction visible
- **Safe respawn** (line 2065) gives player a fresh start

<InfoBox>
The key to good life systems is making the loss dramatic but not punitive. Players should feel the impact (explosion animation, screen flash) but get back to action quickly. The tension comes from knowing they have limited chances, not from long delays.
</InfoBox>

## Professional Respawn Systems

Let's add the sophisticated respawn mechanics that made arcade games fair and exciting:

<TryItNow>
```basic
10 REM PROFESSIONAL RESPAWN SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM GAME STATE
35 LIVES = 5: SCORE = 0: SHIP_X = 15: SHIP_Y = 15
40 INVULNERABLE = 0: RESPAWN_TIMER = 0
45 DIM AST_X(6), AST_Y(6)
50 REM INITIALIZE ASTEROIDS
55 FOR I = 1 TO 6
60 AST_X(I) = INT(RND(1)*30) + 20
65 AST_Y(I) = INT(RND(1)*15) + 5
70 NEXT I
75 FRAME = 0
80 REM MAIN GAME LOOP
85 FRAME = FRAME + 1
90 REM REDUCE SPECIAL TIMERS
95 IF INVULNERABLE > 0 THEN INVULNERABLE = INVULNERABLE - 1
100 IF RESPAWN_TIMER > 0 THEN RESPAWN_TIMER = RESPAWN_TIMER - 1
105 PRINT CHR$(147)
110 REM ENHANCED STATUS DISPLAY
115 PRINT WHITE$; "▓▓▓ DEEP SPACE SURVIVAL ▓▓▓"; OFF$
120 PRINT STRING$(40, "═")
125 PRINT "SCORE: ";
130 FOR I = LEN(STR$(SCORE)) TO 6: PRINT "0";: NEXT I
135 PRINT SCORE; " LIVES: ";
140 REM ANIMATED LIFE DISPLAY
145 FOR I = 1 TO LIVES
150 IF INVULNERABLE > 0 AND (FRAME MOD 8) < 4 THEN PRINT YELLOW$; "♦"; OFF$; ELSE PRINT GREEN$; "♦"; OFF$;
155 NEXT I
160 FOR I = LIVES + 1 TO 5: PRINT " ";: NEXT I
165 PRINT " STATUS: ";
170 IF INVULNERABLE > 0 THEN PRINT GREEN$; "SHIELDED"; OFF$ ELSE PRINT WHITE$; "ACTIVE"; OFF$
175 PRINT STRING$(40, "─")
180 REM DRAW ASTEROIDS
185 FOR I = 1 TO 6
190 IF AST_X(I) > 0 THEN GOSUB 4000
195 NEXT I
200 REM SHIP CONTROL (DISABLED DURING RESPAWN)
205 IF RESPAWN_TIMER > 0 THEN 250
210 GET KEY$
215 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1
220 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
225 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1
230 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1
235 IF KEY$ = "Q" OR KEY$ = "q" THEN 800
240 REM BOUNDARY CHECKING
245 IF SHIP_X < 1 THEN SHIP_X = 1
250 IF SHIP_X > 39 THEN SHIP_X = 39
255 IF SHIP_Y < 5 THEN SHIP_Y = 5
260 IF SHIP_Y > 20 THEN SHIP_Y = 20
265 REM DRAW SHIP WITH INVULNERABILITY EFFECTS
270 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
275 IF RESPAWN_TIMER > 0 THEN 300: REM SKIP SHIP DURING RESPAWN
280 IF INVULNERABLE > 0 AND (FRAME MOD 6) < 3 THEN 300: REM FLASHING
285 PRINT TAB(SHIP_X); GREEN$; "♦"; OFF$
300 REM COLLISION DETECTION (SKIP IF INVULNERABLE)
305 IF INVULNERABLE > 0 OR RESPAWN_TIMER > 0 THEN 350
310 FOR I = 1 TO 6
315 IF AST_X(I) <= 0 THEN 340
320 IF SHIP_X = AST_X(I) AND SHIP_Y = AST_Y(I) THEN GOSUB 2000
325 NEXT I
340 REM ASTEROID MOVEMENT
350 IF FRAME MOD 15 = 0 THEN GOSUB 5000
355 REM STATUS LINE
360 PRINT CHR$(19): PRINT "FRAME: "; FRAME; " INVULN: "; INVULNERABLE; " RESPAWN: "; RESPAWN_TIMER; "  "
365 GOTO 85
800 PRINT: PRINT YELLOW$; "MISSION ABORTED"; OFF$: END
2000 REM SHIP DESTRUCTION SEQUENCE
2005 LIVES = LIVES - 1
2010 REM EXPLOSION ANIMATION
2015 FOR EXPLOSION = 1 TO 8
2020 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
2025 ON EXPLOSION MOD 3 + 1 GOTO 2030, 2040, 2050
2030 PRINT TAB(SHIP_X); YELLOW$; "☀"; OFF$: GOTO 2060
2040 PRINT TAB(SHIP_X); RED$; "※"; OFF$: GOTO 2060
2050 PRINT TAB(SHIP_X); WHITE$; "*"; OFF$
2060 FOR DELAY = 1 TO 80: NEXT DELAY
2065 NEXT EXPLOSION
2070 REM CHECK GAME OVER
2075 IF LIVES <= 0 THEN 3000
2080 REM RESPAWN SEQUENCE
2085 RESPAWN_TIMER = 60: REM 60 FRAME RESPAWN DELAY
2090 INVULNERABLE = 120: REM 120 FRAME INVULNERABILITY
2095 REM FIND SAFE RESPAWN POSITION
2100 FOR ATTEMPT = 1 TO 10
2105 TEST_X = INT(RND(1)*20) + 5
2110 TEST_Y = INT(RND(1)*10) + 8
2115 SAFE = 1

2130 NEXT I
2135 IF SAFE = 1 THEN SHIP_X = TEST_X: SHIP_Y = TEST_Y: ATTEMPT = 10
2140 NEXT ATTEMPT
2145 RETURN
3000 REM GAME OVER SEQUENCE
3005 PRINT CHR$(147)

3030 FOR DELAY = 1 TO 200: NEXT DELAY
3035 NEXT I
3040 PRINT CHR$(147)
3045 PRINT: PRINT: PRINT TAB(10); WHITE$; "FINAL STATISTICS"; OFF$
3050 PRINT STRING$(40, "═")
3055 PRINT "SHIPS LOST: "; 5 - LIVES
3060 PRINT "FINAL SCORE: "; SCORE
3065 PRINT "SURVIVAL TIME: "; INT(FRAME / 60); " SECONDS"
3070 END
4000 REM DRAW ASTEROID
4005 PRINT CHR$(19): FOR J = 1 TO AST_Y(I): PRINT CHR$(17);: NEXT J
4010 PRINT TAB(AST_X(I)); RED$; "▓"; OFF$
4015 RETURN
5000 REM MOVE ASTEROIDS
5005 FOR I = 1 TO 6
5010 IF AST_X(I) > 0 THEN AST_X(I) = AST_X(I) - 1
5015 IF AST_X(I) <= 0 THEN AST_X(I) = 40: SCORE = SCORE + 50
5020 NEXT I
5025 RETURN
```
</TryItNow>

**Advanced Respawn Features:**
- **Invulnerability frames** (lines 90, 305) prevent cheap deaths
- **Visual feedback** (lines 150, 280) shows invulnerable state
- **Safe respawn positioning** (lines 2100-2140) avoids immediate re-collision
- **Explosion animation** (lines 2015-2065) makes destruction dramatic
- **Respawn delay** (lines 2085, 205) gives moment to process the loss

`★ Insight ─────────────────────────────────────`
**Professional life systems balance drama with fairness**. The explosion animation creates emotional impact, but invulnerability frames ensure the next collision is the player's fault, not bad luck.

**Safe respawn logic** is crucial. Nothing frustrates players more than respawning directly into another asteroid. The algorithm tests multiple positions and picks the safest one.

## Advanced Life Management

Let's create the kind of sophisticated life system that made players feel every loss mattered:

<TryItNow>
```basic
10 REM ADVANCED LIFE MANAGEMENT SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 RANDOMIZE TI
30 REM EXTENDED GAME STATE
35 LIVES = 3: MAX_LIVES = 7: EXTRA_LIFE_SCORE = 10000
40 SCORE = 0: LAST_EXTRA_LIFE = 0
45 SHIP_X = 10: SHIP_Y = 15: SHIP_HEALTH = 100
50 INVULNERABLE = 0: SHIELD_POWER = 0
55 CLOSE_CALLS = 0: TOTAL_LIVES_LOST = 0
60 DIFFICULTY = 1: LEVEL = 1: FRAME = 0
65 REM MAIN ENHANCED GAME LOOP
70 FRAME = FRAME + 1
75 IF INVULNERABLE > 0 THEN INVULNERABLE = INVULNERABLE - 1
80 IF SHIELD_POWER > 0 THEN SHIELD_POWER = SHIELD_POWER - 1
85 PRINT CHR$(147)
90 REM COMPREHENSIVE STATUS DISPLAY
95 PRINT WHITE$; "★ ULTIMATE SURVIVAL CHALLENGE ★"; OFF$
100 PRINT STRING$(40, "═")
105 REM SCORE WITH EXTRA LIFE PROGRESS
110 PRINT "SCORE: "; SCORE; " NEXT EXTRA: ";
115 NEXT_EXTRA = EXTRA_LIFE_SCORE * (INT(LAST_EXTRA_LIFE / EXTRA_LIFE_SCORE) + 1)
120 PRINT NEXT_EXTRA - SCORE
125 REM LIVES WITH DIFFERENT STATES
130 PRINT "LIVES: ";
135 FOR I = 1 TO LIVES
140 IF I <= 3 THEN PRINT GREEN$; "♦"; OFF$;: REM NORMAL LIVES
145 IF I > 3 AND I <= 5 THEN PRINT YELLOW$; "♦"; OFF$;: REM BONUS LIVES
150 IF I > 5 THEN PRINT PURPLE$; "♦"; OFF$;: REM RARE EXTRA LIVES
155 NEXT I
160 PRINT " HEALTH: ";
165 HEALTH_BARS = INT(SHIP_HEALTH / 10)
170 FOR I = 1 TO HEALTH_BARS: PRINT GREEN$; "█"; OFF$;: NEXT I
175 FOR I = HEALTH_BARS + 1 TO 10: PRINT RED$; "▒"; OFF$;: NEXT I
180 PRINT " "; SHIP_HEALTH; "%"
185 REM SPECIAL EFFECTS STATUS
190 PRINT "EFFECTS: ";
195 IF INVULNERABLE > 0 THEN PRINT GREEN$; "SHIELD"; OFF$; " ("; INVULNERABLE; ") ";
200 IF SHIELD_POWER > 0 THEN PRINT PURPLE$; "ARMOR"; OFF$; " ("; SHIELD_POWER; ") ";
205 IF INVULNERABLE = 0 AND SHIELD_POWER = 0 THEN PRINT WHITE$; "NONE"; OFF$
210 PRINT: PRINT STRING$(40, "─")
215 REM SIMULATE GAMEPLAY AND DAMAGE
220 GET KEY$
225 IF KEY$ = "H" OR KEY$ = "h" THEN GOSUB 3000: REM HIT SHIP
230 IF KEY$ = "E" OR KEY$ = "e" THEN GOSUB 3500: REM EXTRA LIFE
235 IF KEY$ = "S" OR KEY$ = "s" THEN GOSUB 4000: REM SHIELD POWER-UP
240 IF KEY$ = "D" OR KEY$ = "d" THEN GOSUB 4500: REM DAMAGE SHIP
245 IF KEY$ = "R" OR KEY$ = "r" THEN GOSUB 5000: REM RESET GAME
250 IF KEY$ = "Q" OR KEY$ = "q" THEN 900
255 REM CHECK FOR EXTRA LIFE
260 IF SCORE >= NEXT_EXTRA AND LAST_EXTRA_LIFE < SCORE THEN GOSUB 2000
265 REM GAME STATISTICS DISPLAY
270 PRINT: PRINT "STATISTICS:"
275 PRINT "TOTAL DEATHS: "; TOTAL_LIVES_LOST
280 PRINT "CLOSE CALLS: "; CLOSE_CALLS
285 PRINT "SURVIVAL RATE: "; INT((FRAME - TOTAL_LIVES_LOST * 60) / FRAME * 100); "%"
290 PRINT: PRINT "CONTROLS:"
295 PRINT "H-HIT, E-EXTRA LIFE, S-SHIELD, D-DAMAGE, R-RESET, Q-QUIT"
300 GOTO 70
900 PRINT: PRINT YELLOW$; "MISSION TERMINATED"; OFF$: END
2000 REM EXTRA LIFE AWARDED
2005 IF LIVES >= MAX_LIVES THEN 2050: REM CAN'T EXCEED MAXIMUM
2010 LIVES = LIVES + 1
2015 LAST_EXTRA_LIFE = SCORE
2020 REM EXTRA LIFE CELEBRATION
2025 FOR CELEBRATION = 1 TO 5
2030 PRINT CHR$(19): PRINT TAB(10); GREEN$; "★ EXTRA LIFE EARNED! ★"; OFF$
2035 FOR DELAY = 1 TO 150: NEXT DELAY
2040 PRINT CHR$(19): PRINT TAB(10); YELLOW$; "★ EXTRA LIFE EARNED! ★"; OFF$
2045 FOR DELAY = 1 TO 150: NEXT DELAY
2050 NEXT CELEBRATION
2055 RETURN
3000 REM DIRECT HIT - LOSE LIFE
3005 IF INVULNERABLE > 0 THEN PRINT "SHIELD ABSORBED HIT!": RETURN
3010 IF SHIELD_POWER > 0 THEN SHIELD_POWER = 0: PRINT "ARMOR DESTROYED!": RETURN
3015 LIVES = LIVES - 1: TOTAL_LIVES_LOST = TOTAL_LIVES_LOST + 1
3020 SHIP_HEALTH = 100: REM RESET HEALTH
3025 REM DEATH SEQUENCE
3030 PRINT TAB(15); RED$; "SHIP DESTROYED!"; OFF$
3035 IF LIVES <= 0 THEN 6000: REM GAME OVER
3040 INVULNERABLE = 180: REM 3 SECOND INVULNERABILITY
3045 PRINT "RESPAWNING WITH SHIELD..."
3050 RETURN
3500 REM AWARD EXTRA LIFE (CHEAT)
3505 IF LIVES < MAX_LIVES THEN LIVES = LIVES + 1: PRINT "EXTRA LIFE!"
3510 RETURN
4000 REM SHIELD POWER-UP
4005 SHIELD_POWER = 300: REM 5 SECOND ARMOR
4010 PRINT "ARMOR ACTIVATED!"
4015 RETURN
4500 REM DAMAGE SHIP HEALTH
4505 IF INVULNERABLE > 0 OR SHIELD_POWER > 0 THEN RETURN
4510 SHIP_HEALTH = SHIP_HEALTH - 25
4515 IF SHIP_HEALTH <= 0 THEN GOSUB 3000: REM LOSE LIFE
4520 IF SHIP_HEALTH > 0 THEN PRINT "HULL DAMAGE! "; SHIP_HEALTH; "% REMAINING"
4525 RETURN
5000 REM RESET GAME
5005 LIVES = 3: SCORE = 0: SHIP_HEALTH = 100
5010 INVULNERABLE = 0: SHIELD_POWER = 0
5015 TOTAL_LIVES_LOST = 0: CLOSE_CALLS = 0: FRAME = 0
5020 PRINT "GAME RESET!"
5025 RETURN
6000 REM ADVANCED GAME OVER
6005 PRINT CHR$(147)
6010 PRINT: PRINT: PRINT TAB(12); RED$; "MISSION FAILED"; OFF$
6015 PRINT STRING$(40, "═")
6020 PRINT "FINAL STATISTICS:"
6025 PRINT "SHIPS LOST: "; TOTAL_LIVES_LOST
6030 PRINT "FINAL SCORE: "; SCORE
6035 PRINT "SURVIVAL TIME: "; INT(FRAME / 60); " SECONDS"
6040 SURVIVAL_RATE = INT((FRAME - TOTAL_LIVES_LOST * 60) / FRAME * 100)
6045 PRINT "SURVIVAL RATE: "; SURVIVAL_RATE; "%"
6050 PRINT: IF SURVIVAL_RATE > 80 THEN PRINT GREEN$; "EXCELLENT PILOTING!"; OFF$
6055 IF SURVIVAL_RATE > 50 AND SURVIVAL_RATE <= 80 THEN PRINT YELLOW$; "DECENT FLYING"; OFF$
6060 IF SURVIVAL_RATE <= 50 THEN PRINT RED$; "NEEDS MORE TRAINING"; OFF$
6065 END
```

<RetroMoment title="The Psychology of Lives: 1981">
The "three lives" convention wasn't arbitrary - it came from careful arcade psychology. One life felt unfair, two lives didn't create enough tension, but four or more made games feel too easy. Three lives hit the sweet spot: enough to feel fair, few enough to create genuine stakes. Arcade operators discovered that games with good life systems kept players feeding quarters, not from frustration, but from the compelling desire to "do better next time." The best arcade games made you feel like your next attempt could be the perfect run.
</RetroMoment>
