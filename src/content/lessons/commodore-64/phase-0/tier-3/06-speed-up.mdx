# Speed Up

**From static challenge to escalating intensity! Transform your armed spaceship into a progressively difficult survival experience that keeps players in the challenge zone.**

## The Difficulty Curve

You've created a spaceship with weapons, but every great arcade game has one secret: it gets harder! Not randomly harder, but intelligently harder. Professional games use **progressive difficulty** - they analyze how well you're playing and adjust the challenge accordingly:

<TryItNow>
```basic
10 REM PROGRESSIVE DIFFICULTY DEMO
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ASTEROID DODGER - PROGRESSIVE DIFFICULTY"; OFF$
35 PRINT STRING$(40, "═")
40 PRINT "WATCH THE SPEED INCREASE AS YOU SURVIVE!"
45 PRINT STRING$(40, "─")
50 REM DIFFICULTY VARIABLES
55 GAME_SPEED = 5: SPEED_INCREASE = 0
60 WAVE_NUMBER = 1: SURVIVAL_TIME = 0
65 ASTEROID_COUNT = 3: MAX_ASTEROIDS = 8
70 REM SHIP AND GAME STATE
75 SHIP_X = 20: SHIP_Y = 15: SCORE = 0
80 DIM AST_X(8), AST_Y(8), AST_ACTIVE(8)
85 REM INITIALIZE FIRST WAVE
90 FOR I = 1 TO ASTEROID_COUNT
95   AST_X(I) = RND(1) * 35 + 2
100   AST_Y(I) = RND(1) * 5 + 7
105   AST_ACTIVE(I) = 1
110 NEXT I
115 REM MAIN GAME LOOP WITH SPEED CONTROL
120 FRAME = FRAME + 1: SURVIVAL_TIME = SURVIVAL_TIME + 1
125 REM SPEED INCREASE EVERY 300 FRAMES (5 SECONDS AT 60FPS)
130 IF SURVIVAL_TIME MOD 300 = 0 THEN GOSUB 2000
135 REM MOVEMENT (ONLY PROCESS EVERY GAME_SPEED FRAMES)
140 IF FRAME MOD GAME_SPEED <> 0 THEN 180
145 REM MOVE ASTEROIDS DOWN
150 FOR I = 1 TO ASTEROID_COUNT
155   IF AST_ACTIVE(I) = 1 THEN AST_Y(I) = AST_Y(I) + 1
160   IF AST_Y(I) > 22 THEN AST_Y(I) = 7: AST_X(I) = RND(1) * 35 + 2
165 NEXT I
170 SCORE = SCORE + 1
175 REM SHIP CONTROL
180 GET KEY$: IF KEY$ = "Q" OR KEY$ = "q" THEN 900
185 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
190 IF KEY$ = "D" AND SHIP_X < 39 THEN SHIP_X = SHIP_X + 1
195 IF KEY$ = "W" AND SHIP_Y > 7 THEN SHIP_Y = SHIP_Y - 1
200 IF KEY$ = "S" AND SHIP_Y < 20 THEN SHIP_Y = SHIP_Y + 1
205 REM DISPLAY EVERYTHING
210 PRINT CHR$(19): PRINT TAB(25); "WAVE:"; WAVE_NUMBER; "  "
215 PRINT TAB(25); "SPEED:"; 10 - GAME_SPEED; "  "
220 PRINT TAB(25); "SCORE:"; SCORE; "  "
225 REM DRAW ASTEROIDS
230 FOR I = 1 TO ASTEROID_COUNT
235   IF AST_ACTIVE(I) = 1 THEN PRINT TAB(AST_X(I)) SPC(AST_Y(I) - 7); RED$; "●"; OFF$
240 NEXT I
245 REM DRAW SHIP
250 PRINT TAB(SHIP_X) SPC(SHIP_Y - 7); GREEN$; "▲"; OFF$
255 GOTO 120
900 PRINT: PRINT YELLOW$; "FINAL WAVE: "; WAVE_NUMBER; OFF$
905 PRINT "FINAL SPEED: "; 10 - GAME_SPEED
910 END
2000 REM INCREASE DIFFICULTY SUBROUTINE
2005 WAVE_NUMBER = WAVE_NUMBER + 1
2010 REM INCREASE SPEED (DECREASE FRAME DELAY)
2015 IF GAME_SPEED > 1 THEN GAME_SPEED = GAME_SPEED - 1
2020 REM ADD MORE ASTEROIDS
2025 IF ASTEROID_COUNT < MAX_ASTEROIDS THEN ASTEROID_COUNT = ASTEROID_COUNT + 1
2030 PRINT CHR$(7): REM BEEP FOR WAVE CHANGE
2035 RETURN
```
</TryItNow>

**Progressive Difficulty Mechanics:**
- **Frame-based timing** (line 140) controls overall game speed
- **Survival time tracking** (130) triggers difficulty increases every 5 seconds
- **Speed escalation** (2015) makes everything move faster
- **Asteroid density** (2025) adds more obstacles as waves progress

`★ Insight ─────────────────────────────────────`
**Progressive difficulty is psychological warfare**. Too easy = boring. Too hard = frustrating. The sweet spot is **just beyond current ability**. Great arcade games measure player performance and adjust accordingly - they want you to fail, but only after feeling awesome about how far you got!

**Frame modulo timing** (`IF FRAME MOD GAME_SPEED <> 0`) is how 1980s games controlled speed without complex timing systems. Smaller GAME_SPEED = faster action.
`─────────────────────────────────────────────────`

## Adaptive Challenge Systems

Professional games don't just get faster - they adapt to how well you're playing. Let's add performance tracking that responds to player skill:

<TryItNow>
```basic
10 REM ADAPTIVE DIFFICULTY ENGINE
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ADAPTIVE ASTEROID DODGER"; OFF$
35 PRINT STRING$(40, "═")
40 PRINT "DIFFICULTY ADAPTS TO YOUR SKILL LEVEL!"
45 PRINT STRING$(40, "─")
50 REM ADAPTIVE VARIABLES
55 GAME_SPEED = 5: PERFORMANCE_SCORE = 0
60 NEAR_MISSES = 0: CLOSE_CALLS = 0: PERFECT_DODGES = 0
65 DIFFICULTY_LEVEL = 1: ADJUSTMENT_TIMER = 0
70 ASTEROID_COUNT = 3: SPAWN_RATE = 100
75 REM SHIP AND ENVIRONMENT
80 SHIP_X = 20: SHIP_Y = 15: LAST_X = 20: LAST_Y = 15
85 DIM AST_X(10), AST_Y(10), AST_ACTIVE(10)
90 FRAME = 0
95 REM INITIALIZE ASTEROIDS
100 FOR I = 1 TO ASTEROID_COUNT
105   AST_X(I) = RND(1) * 35 + 2: AST_Y(I) = 7
110   AST_ACTIVE(I) = 1
115 NEXT I
120 REM ADAPTIVE GAME LOOP
125 FRAME = FRAME + 1: ADJUSTMENT_TIMER = ADJUSTMENT_TIMER + 1
130 REM CHECK FOR DIFFICULTY ADJUSTMENT EVERY 500 FRAMES
135 IF ADJUSTMENT_TIMER >= 500 THEN GOSUB 3000
140 REM MOVEMENT BASED ON CURRENT SPEED
145 IF FRAME MOD GAME_SPEED <> 0 THEN 220
150 REM ASTEROID MOVEMENT AND SPAWNING
155 FOR I = 1 TO 10
160   IF AST_ACTIVE(I) = 1 THEN AST_Y(I) = AST_Y(I) + 1
165   IF AST_Y(I) > 22 THEN AST_ACTIVE(I) = 0: PERFECT_DODGES = PERFECT_DODGES + 1
170 NEXT I
175 REM SPAWN NEW ASTEROIDS BASED ON DIFFICULTY
180 IF RND(1) * 1000 < SPAWN_RATE THEN GOSUB 4000
185 REM PERFORMANCE ANALYSIS
190 GOSUB 5000
195 LAST_X = SHIP_X: LAST_Y = SHIP_Y
200 REM SHIP CONTROL
205 GET KEY$: IF KEY$ = "Q" OR KEY$ = "q" THEN 900
210 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
215 IF KEY$ = "D" AND SHIP_X < 39 THEN SHIP_X = SHIP_X + 1
220 IF KEY$ = "W" AND SHIP_Y > 7 THEN SHIP_Y = SHIP_Y - 1
225 IF KEY$ = "S" AND SHIP_Y < 20 THEN SHIP_Y = SHIP_Y + 1
230 REM DISPLAY ADAPTIVE STATUS
235 PRINT CHR$(19): PRINT TAB(25); "SKILL LV:"; DIFFICULTY_LEVEL; "  "
240 PRINT TAB(25); "SPEED:"; 10 - GAME_SPEED; "  "
245 PRINT TAB(25); "PERF:"; PERFORMANCE_SCORE; "  "
250 PRINT TAB(25); "NEAR:"; NEAR_MISSES; "  "
255 REM DRAW ASTEROIDS WITH PROXIMITY WARNING
260 FOR I = 1 TO 10
265   IF AST_ACTIVE(I) = 1 THEN PRINT TAB(AST_X(I)) SPC(AST_Y(I) - 7); RED$; "●"; OFF$
270 NEXT I
275 REM DRAW SHIP
280 PRINT TAB(SHIP_X) SPC(SHIP_Y - 7); GREEN$; "▲"; OFF$
285 GOTO 125
900 PRINT: PRINT YELLOW$; "ADAPTIVE SESSION COMPLETE"; OFF$
905 PRINT "FINAL DIFFICULTY LEVEL: "; DIFFICULTY_LEVEL
910 PRINT "PERFORMANCE SCORE: "; PERFORMANCE_SCORE
915 END
3000 REM DIFFICULTY ADJUSTMENT ENGINE
3005 ADJUSTMENT_TIMER = 0
3010 REM CALCULATE PERFORMANCE RATIO
3015 TOTAL_EVENTS = NEAR_MISSES + PERFECT_DODGES + CLOSE_CALLS
3020 IF TOTAL_EVENTS = 0 THEN RETURN
3025 SKILL_RATIO = (PERFECT_DODGES * 3 + NEAR_MISSES * 1) / TOTAL_EVENTS
3030 REM ADJUST DIFFICULTY BASED ON SKILL
3035 IF SKILL_RATIO > 2.5 AND DIFFICULTY_LEVEL < 9 THEN GOSUB 3100
3040 IF SKILL_RATIO < 1.5 AND DIFFICULTY_LEVEL > 1 THEN GOSUB 3200
3045 RETURN
3100 REM INCREASE DIFFICULTY
3105 DIFFICULTY_LEVEL = DIFFICULTY_LEVEL + 1
3110 IF GAME_SPEED > 1 THEN GAME_SPEED = GAME_SPEED - 1
3115 SPAWN_RATE = SPAWN_RATE + 20
3120 PRINT CHR$(7): REM BEEP FOR LEVEL UP
3125 RETURN
3200 REM DECREASE DIFFICULTY
3205 DIFFICULTY_LEVEL = DIFFICULTY_LEVEL - 1
3210 IF GAME_SPEED < 8 THEN GAME_SPEED = GAME_SPEED + 1
3215 SPAWN_RATE = SPAWN_RATE - 10: IF SPAWN_RATE < 50 THEN SPAWN_RATE = 50
3220 RETURN
4000 REM ASTEROID SPAWNING
4005 FOR I = 1 TO 10
4010   IF AST_ACTIVE(I) = 0 THEN AST_X(I) = RND(1) * 35 + 2: AST_Y(I) = 7: AST_ACTIVE(I) = 1: RETURN
4015 NEXT I
4020 RETURN
5000 REM PERFORMANCE TRACKING
5005 FOR I = 1 TO 10
5010   IF AST_ACTIVE(I) = 0 THEN 5030
5015   DISTANCE = ABS(AST_X(I) - SHIP_X) + ABS(AST_Y(I) - SHIP_Y)
5020   IF DISTANCE <= 2 THEN NEAR_MISSES = NEAR_MISSES + 1
5025   IF DISTANCE <= 1 THEN CLOSE_CALLS = CLOSE_CALLS + 1
5030 NEXT I
5035 PERFORMANCE_SCORE = PERFECT_DODGES * 10 + NEAR_MISSES * 5 - CLOSE_CALLS * 3
5040 RETURN
```
</TryItNow>

**Adaptive Systems in Action:**
- **Performance tracking** (5000-5040) measures player skill through proximity analysis
- **Difficulty adjustment** (3000-3045) increases challenge for skilled players, reduces for struggling players
- **Multi-factor scoring** (3015-3025) weighs perfect dodges higher than near misses
- **Dynamic spawn rate** (180) creates more or fewer asteroids based on skill level

The game becomes a personal trainer - pushing you to improve without overwhelming you!

<InfoBox>
This adaptive system is the difference between arcade classics and bedroom coder games. Professional arcade games wanted players to feel challenged but not cheated. They analyzed every move you made and adjusted accordingly. The goal wasn't to kill you quickly - it was to keep you playing longer!
</InfoBox>

## Wave-Based Progression

Let's add the final touch - distinct waves with unique characteristics that create memorable "episodes" in your space adventure:

<TryItNow>
```basic
10 REM WAVE-BASED PROGRESSION SYSTEM
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
25 BLUE$ = CHR$(154): OFF$ = CHR$(159)
30 PRINT CHR$(147)
35 PRINT WHITE$; "ASTEROID DODGER - WAVE SYSTEM"; OFF$
40 PRINT STRING$(40, "═")
45 PRINT "EACH WAVE BRINGS NEW CHALLENGES!"
50 PRINT STRING$(40, "─")
55 REM WAVE SYSTEM VARIABLES
60 CURRENT_WAVE = 1: WAVE_TIMER = 0: WAVE_COMPLETE = 0
65 ENEMIES_THIS_WAVE = 0: ENEMIES_DESTROYED = 0
70 WAVE_TYPE = 1: REM 1=ASTEROID, 2=FAST, 3=DENSE, 4=BOSS
75 GAME_SPEED = 6: BASE_SPEED = 6
80 REM WAVE PATTERNS
85 DIM WAVE_NAME$(4), WAVE_COLOR$(4), WAVE_ENEMIES(4), WAVE_SPEED(4)
90 WAVE_NAME$(1) = "ASTEROID FIELD": WAVE_COLOR$(1) = RED$
95 WAVE_NAME$(2) = "SPEED BURST": WAVE_COLOR$(2) = YELLOW$
100 WAVE_NAME$(3) = "DENSE CLOUD": WAVE_COLOR$(3) = PURPLE$
105 WAVE_NAME$(4) = "MEGA STORM": WAVE_COLOR$(4) = CYAN$
110 WAVE_ENEMIES(1) = 5: WAVE_SPEED(1) = 6
115 WAVE_ENEMIES(2) = 4: WAVE_SPEED(2) = 3
120 WAVE_ENEMIES(3) = 8: WAVE_SPEED(3) = 5
125 WAVE_ENEMIES(4) = 12: WAVE_SPEED(4) = 2
130 REM SHIP AND OBJECTS
135 SHIP_X = 20: SHIP_Y = 18: SCORE = 0
140 DIM AST_X(12), AST_Y(12), AST_ACTIVE(12)
145 GOSUB 6000: REM INITIALIZE WAVE
150 REM MAIN WAVE-BASED LOOP
155 FRAME = FRAME + 1: WAVE_TIMER = WAVE_TIMER + 1
160 REM CHECK WAVE COMPLETION
165 IF WAVE_COMPLETE = 1 AND WAVE_TIMER > 180 THEN GOSUB 7000
170 REM MOVEMENT TIMING
175 IF FRAME MOD GAME_SPEED <> 0 THEN 240
180 REM ASTEROID MOVEMENT
185 ENEMIES_ACTIVE = 0
190 FOR I = 1 TO 12
195   IF AST_ACTIVE(I) = 1 THEN AST_Y(I) = AST_Y(I) + 1: ENEMIES_ACTIVE = ENEMIES_ACTIVE + 1
200   IF AST_Y(I) > 22 THEN AST_ACTIVE(I) = 0: ENEMIES_DESTROYED = ENEMIES_DESTROYED + 1
205 NEXT I
210 REM CHECK IF WAVE IS COMPLETE
215 IF ENEMIES_ACTIVE = 0 AND WAVE_COMPLETE = 0 THEN WAVE_COMPLETE = 1: WAVE_TIMER = 0
220 REM SPAWN NEW ENEMIES FOR CURRENT WAVE TYPE
225 IF ENEMIES_ACTIVE < WAVE_ENEMIES(WAVE_TYPE) AND WAVE_COMPLETE = 0 THEN GOSUB 8000
230 SCORE = SCORE + 1
235 REM SHIP CONTROL
240 GET KEY$: IF KEY$ = "Q" OR KEY$ = "q" THEN 900
245 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
250 IF KEY$ = "D" AND SHIP_X < 39 THEN SHIP_X = SHIP_X + 1
255 IF KEY$ = "W" AND SHIP_Y > 7 THEN SHIP_Y = SHIP_Y - 1
260 IF KEY$ = "S" AND SHIP_Y < 20 THEN SHIP_Y = SHIP_Y + 1
265 REM WAVE STATUS DISPLAY
270 PRINT CHR$(19): PRINT TAB(10); WAVE_COLOR$(WAVE_TYPE); WAVE_NAME$(CURRENT_WAVE); OFF$
275 PRINT TAB(10); "WAVE "; CURRENT_WAVE; " - ENEMIES: "; ENEMIES_ACTIVE
280 IF WAVE_COMPLETE = 1 THEN PRINT TAB(10); GREEN$; "WAVE COMPLETE!"; OFF$
285 PRINT TAB(10); "SCORE: "; SCORE
290 REM DRAW ENEMIES WITH WAVE-SPECIFIC COLORS
295 FOR I = 1 TO 12
300   IF AST_ACTIVE(I) = 1 THEN PRINT TAB(AST_X(I)) SPC(AST_Y(I) - 7); WAVE_COLOR$(WAVE_TYPE); "●"; OFF$
305 NEXT I
310 REM DRAW SHIP
315 PRINT TAB(SHIP_X) SPC(SHIP_Y - 7); GREEN$; "▲"; OFF$
320 GOTO 155
900 PRINT: PRINT GREEN$; "SPACE PILOT MISSION COMPLETE"; OFF$
905 PRINT "WAVES COMPLETED: "; CURRENT_WAVE - 1
910 PRINT "FINAL SCORE: "; SCORE
915 END
6000 REM INITIALIZE NEW WAVE
6005 WAVE_TYPE = ((CURRENT_WAVE - 1) MOD 4) + 1
6010 GAME_SPEED = WAVE_SPEED(WAVE_TYPE)
6015 ENEMIES_THIS_WAVE = 0: ENEMIES_DESTROYED = 0: WAVE_COMPLETE = 0
6020 REM CLEAR ALL ASTEROIDS
6025 FOR I = 1 TO 12: AST_ACTIVE(I) = 0: NEXT I
6030 PRINT CHR$(7): CHR$(7): CHR$(7): REM TRIPLE BEEP
6035 RETURN
7000 REM ADVANCE TO NEXT WAVE
7005 CURRENT_WAVE = CURRENT_WAVE + 1
7010 IF CURRENT_WAVE > 16 THEN 900: REM END GAME AFTER 16 WAVES
7015 GOSUB 6000: REM INITIALIZE NEW WAVE
7020 RETURN
8000 REM SPAWN ENEMY FOR CURRENT WAVE
8005 FOR I = 1 TO 12
8010   IF AST_ACTIVE(I) = 0 THEN AST_X(I) = RND(1) * 35 + 2: AST_Y(I) = 7: AST_ACTIVE(I) = 1: RETURN
8015 NEXT I
8020 RETURN
```
</TryItNow>

**Wave System Features:**
- **Wave-specific characteristics** (85-125) define unique behavior for each wave type
- **Completion tracking** (215) detects when all enemies are cleared
- **Progressive wave types** (6005) cycle through different challenge patterns
- **Visual wave identity** (270-280) shows current wave status and theme colors

Each wave feels like a distinct challenge with its own personality and difficulty curve!

<RetroMoment title="The Science of Quarters: 1983">
Arcade operators discovered that progressive difficulty was pure psychology. Too easy meant players walked away bored after 30 seconds. Too hard meant they felt cheated and never returned. The sweet spot was making players feel like they were "almost" good enough to reach the next level. Games like Robotron and Defender used adaptive systems that tracked your performance and adjusted accordingly. They wanted your quarter, but they also wanted you to come back tomorrow with three more quarters, convinced that THIS time you'd beat your high score. The best games made you feel like the difficulty increase was earned, not imposed.
