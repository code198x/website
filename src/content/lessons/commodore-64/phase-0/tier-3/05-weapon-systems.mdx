Your ship can dodge and survive - but real arcade games let you fight back! The moment players can shoot asteroids instead of just avoiding them transforms the entire game experience:

- **Spacebar firing** (line 130) creates immediate player agency

`★ Insight ─────────────────────────────────────`
**Professional weapon systems balance power with limitations**. Unlimited rapid fire isn't fun - it's the constraints (heat, ammo, rate limits) that create interesting tactical decisions.

**Visual feedback is crucial**. The ship changes color when overheated, weapon heat displays as bars, different asteroid sizes use different characters. Players need to see system states instantly.


<RetroMoment title="The Weapon Revolution: 1979">
The ability to shoot back transformed arcade gaming forever. Early games like Space Invaders proved that giving players offensive capabilities created addictive gameplay loops.
