## Risk and Reward

Power-ups transform your game from survival to strategy. Place them in dangerous spots to tempt brave pilots:

```basic
10 REM POWER DOT COLLECTION SYSTEM
15 WHITE$ = CHR$(5): YELLOW$ = CHR$(158): CYAN$ = CHR$(159)
20 RED$ = CHR$(28): GREEN$ = CHR$(30): OFF$ = CHR$(144)
25 PRINT CHR$(147)
30 PRINT WHITE$; "POWER-UP COLLECTION"; OFF$
35 PRINT STRING$(40, "═")
40 REM POWER DOT DATA
45 DIM PWR_X(5), PWR_Y(5), PWR_TYPE(5), PWR_ACTIVE(5)
50 REM SHIP AND GAME STATE
55 SHIP_X = 20: SHIP_Y = 20: SCORE = 0: MULTIPLIER = 1
60 SHIELD_TIME = 0: SPEED_BOOST = 0: MAGNET_RANGE = 0
65 REM INITIALIZE POWER DOTS
70 FOR I = 1 TO 5
75   GOSUB 2000: REM SPAWN POWER DOT
80 NEXT I
85 FRAME = 0
90 REM MAIN GAME LOOP

100 REM CLEAR PLAY AREA
105 FOR Y = 5 TO 23: PRINT CHR$(19);
110   FOR Z = 1 TO Y: PRINT CHR$(17);: NEXT Z
115   PRINT STRING$(40, " ")
120 NEXT Y
125 REM UPDATE POWER EFFECTS
130 IF SHIELD_TIME > 0 THEN SHIELD_TIME = SHIELD_TIME - 1
135 IF SPEED_BOOST > 0 THEN SPEED_BOOST = SPEED_BOOST - 1
140 IF MAGNET_RANGE > 0 THEN MAGNET_RANGE = MAGNET_RANGE - 1
145 REM UPDATE AND DRAW POWER DOTS
150 FOR I = 1 TO 5
155   IF PWR_ACTIVE(I) = 0 THEN 280
160   REM MAGNETIC ATTRACTION
165   IF MAGNET_RANGE > 0 THEN GOSUB 3000
170   REM MOVE POWER DOT DOWN
175   PWR_Y(I) = PWR_Y(I) + 0.5
180   IF PWR_Y(I) > 23 THEN GOSUB 2000: GOTO 280
185   REM CHECK COLLECTION
190   DX = ABS(SHIP_X - PWR_X(I))
195   DY = ABS(SHIP_Y - PWR_Y(I))
200   IF DX < 2 AND DY < 2 THEN GOSUB 2500: GOTO 280
205   REM DRAW POWER DOT
210   PRINT CHR$(19);: FOR Z = 1 TO INT(PWR_Y(I)): PRINT CHR$(17);: NEXT Z
215   PRINT TAB(INT(PWR_X(I)));
220   IF PWR_TYPE(I) = 1 THEN PRINT YELLOW$; "◆"; OFF$: REM POINTS
225   IF PWR_TYPE(I) = 2 THEN PRINT CYAN$; "●"; OFF$: REM SHIELD
230   IF PWR_TYPE(I) = 3 THEN PRINT GREEN$; "★"; OFF$: REM SPEED
235   IF PWR_TYPE(I) = 4 THEN PRINT RED$; "♦"; OFF$: REM MAGNET
280 NEXT I
285 REM DRAW SHIP WITH EFFECTS
290 PRINT CHR$(19);: FOR Z = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT Z
295 PRINT TAB(SHIP_X);
300 IF SHIELD_TIME > 0 AND (FRAME AND 1) = 0 THEN PRINT CYAN$;
305 IF SPEED_BOOST > 0 THEN PRINT GREEN$;
310 PRINT "▲"; OFF$
315 REM DRAW STATUS
320 PRINT CHR$(19); CHR$(19); TAB(2);
325 PRINT "SCORE:"; SCORE; "  x"; MULTIPLIER
330 IF SHIELD_TIME > 0 THEN PRINT " SHIELD:"; INT(SHIELD_TIME/10)
335 REM SHIP CONTROL
340 SPEED = 1: IF SPEED_BOOST > 0 THEN SPEED = 2
345 GET KEY$: IF KEY$ = "" THEN 380
350 IF KEY$ = "A" AND SHIP_X > 1 THEN SHIP_X = SHIP_X - SPEED
355 IF KEY$ = "D" AND SHIP_X < 38 THEN SHIP_X = SHIP_X + SPEED
360 IF KEY$ = "W" AND SHIP_Y > 5 THEN SHIP_Y = SHIP_Y - SPEED
365 IF KEY$ = "S" AND SHIP_Y < 23 THEN SHIP_Y = SHIP_Y + SPEED
370 IF KEY$ = "Q" THEN END
380 FOR D = 1 TO 50: NEXT D: GOTO 95
2000 REM SPAWN NEW POWER DOT
2005 PWR_X(I) = RND(1) * 36 + 2
2010 PWR_Y(I) = 5 + RND(1) * 3
2015 PWR_TYPE(I) = INT(RND(1) * 4) + 1
2020 PWR_ACTIVE(I) = 1
2025 RETURN
2500 REM COLLECT POWER DOT
2505 PWR_ACTIVE(I) = 0
2510 ON PWR_TYPE(I) GOTO 2520, 2540, 2560, 2580
2520 REM POINTS BONUS
2525 SCORE = SCORE + 100 * MULTIPLIER
2530 MULTIPLIER = MULTIPLIER + 1: IF MULTIPLIER > 5 THEN MULTIPLIER = 5
2535 RETURN
2540 REM SHIELD
2545 SHIELD_TIME = 100
2550 RETURN
2560 REM SPEED BOOST
2565 SPEED_BOOST = 150
2570 RETURN
2580 REM MAGNET
2585 MAGNET_RANGE = 200
2590 RETURN
3000 REM MAGNETIC ATTRACTION
3005 IF ABS(SHIP_X - PWR_X(I)) < 8 THEN
3010   IF PWR_X(I) < SHIP_X THEN PWR_X(I) = PWR_X(I) + 0.5
3015   IF PWR_X(I) > SHIP_X THEN PWR_X(I) = PWR_X(I) - 0.5
3020 END IF
```

**Power-Up Features:**
- **Yellow Diamonds** (220) - Score multiplier increases up to 5x
- **Cyan Circles** (225) - Temporary shield protection for 10 seconds
- **Green Stars** (230) - Double movement speed for agility
- **Red Diamonds** (235) - Magnetic attraction pulls nearby power-ups

`★ Insight ─────────────────────────────────────`
**The magnetic power-up creates cascading rewards** - once you get one magnet, it's easier to chain collect other power-ups. This positive feedback loop rewards skilled players who can survive the initial risk. It's a design pattern seen in games like Geometry Wars where success breeds more success.
