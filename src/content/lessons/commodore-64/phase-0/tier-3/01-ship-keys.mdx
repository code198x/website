## Beyond Turn-Based Gaming

You've conquered sophisticated turn-based games with intelligent hint systems and complex data analysis. Now comes the leap that defined 1980s gaming: **real-time action**. Instead of waiting for the player to press ENTER, we'll read keystrokes instantly:

<TryItNow>
```basic
10 REM SHIP KEYS - REAL-TIME CONTROL DEMO
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "REAL-TIME SHIP CONTROL"; OFF$
35 PRINT STRING$(30, "═")
40 PRINT "USE WASD KEYS TO MOVE YOUR SHIP"
45 PRINT "PRESS Q TO QUIT"
50 PRINT STRING$(30, "─")
55 REM SHIP STARTING POSITION
60 SHIP_X = 20: SHIP_Y = 12
65 REM MAIN REAL-TIME LOOP
70 REM CLEAR OLD SHIP POSITION
75 PRINT CHR$(19); CHR$(19); CHR$(19); CHR$(19); CHR$(19)
80 PRINT TAB(SHIP_X); " "
85 REM READ INSTANT KEYPRESS
90 GET KEY$: IF KEY$ = "" THEN 90
95 REM PROCESS MOVEMENT
100 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1
105 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1
110 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1
115 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1
120 IF KEY$ = "Q" OR KEY$ = "q" THEN 200
125 REM BOUNDARY CHECKING
130 IF SHIP_X < 1 THEN SHIP_X = 1
135 IF SHIP_X > 39 THEN SHIP_X = 39
140 IF SHIP_Y < 7 THEN SHIP_Y = 7
145 IF SHIP_Y > 20 THEN SHIP_Y = 20
150 REM POSITION CURSOR AND DRAW SHIP
155 FOR I = 1 TO SHIP_Y - 7: PRINT CHR$(17);: NEXT I
160 PRINT TAB(SHIP_X); GREEN$; "▲"; OFF$
165 GOTO 70
200 PRINT: PRINT YELLOW$; "SHIP CONTROL OFFLINE"; OFF$
205 END
```
</TryItNow>

**Real-Time Revolution:**
- **Line 90:** GET KEY$ reads instantly without waiting for ENTER
- **Lines 75-80:** Clear previous ship position before drawing new one
- **Lines 100-115:** Instant response to WASD movement keys
- **Lines 130-145:** Boundary checking keeps ship on screen

<InfoBox>
The magic of GET is that it doesn't stop the program waiting for input! If no key is pressed, KEY$ becomes empty ("") and the loop continues. This creates the illusion of continuous movement - the hallmark of action games.
</InfoBox>

## Professional Ship Control

Let's add the polish that made commercial games feel smooth and responsive:

<TryItNow>
```basic
10 REM PROFESSIONAL SHIP CONTROL
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ASTEROID DODGER - SHIP CONTROL"; OFF$
35 PRINT STRING$(30, "═")
40 PRINT "CONTROLS: W/A/S/D TO MOVE, Q TO QUIT"
45 PRINT "ESCAPE THE ASTEROID FIELD!"
50 PRINT STRING$(30, "─")
55 REM SHIP VARIABLES
60 SHIP_X = 20: SHIP_Y = 15: OLD_X = 20: OLD_Y = 15
65 MOVE_DELAY = 0: MAX_DELAY = 3
70 FRAME = 0
75 REM MAIN GAME LOOP
80 FRAME = FRAME + 1
85 REM MOVEMENT DELAY FOR SMOOTH CONTROL
90 MOVE_DELAY = MOVE_DELAY + 1: IF MOVE_DELAY < MAX_DELAY THEN 180
95 MOVE_DELAY = 0
100 REM READ KEYBOARD
105 GET KEY$
110 OLD_X = SHIP_X: OLD_Y = SHIP_Y
115 REM PROCESS MOVEMENT WITH VALIDATION
120 IF KEY$ = "W" OR KEY$ = "w" THEN GOSUB 1000
125 IF KEY$ = "S" OR KEY$ = "s" THEN GOSUB 1100
130 IF KEY$ = "A" OR KEY$ = "a" THEN GOSUB 1200
135 IF KEY$ = "D" OR KEY$ = "d" THEN GOSUB 1300
140 IF KEY$ = "Q" OR KEY$ = "q" THEN 900
145 REM CLEAR OLD POSITION IF SHIP MOVED
150 IF SHIP_X <> OLD_X OR SHIP_Y <> OLD_Y THEN GOSUB 2000
155 REM DRAW SHIP
160 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
165 PRINT TAB(SHIP_X); GREEN$; "♦"; OFF$
170 REM STATUS DISPLAY
180 PRINT CHR$(19): PRINT TAB(32); "FRAME:"; FRAME
185 GOTO 80
900 PRINT CHR$(19); CHR$(19): PRINT YELLOW$; "MISSION ABORTED"; OFF$: END
1000 REM MOVE UP
1005 IF SHIP_Y > 7 THEN SHIP_Y = SHIP_Y - 1
1010 RETURN
1100 REM MOVE DOWN
1105 IF SHIP_Y < 22 THEN SHIP_Y = SHIP_Y + 1
1110 RETURN
1200 REM MOVE LEFT
1205 IF SHIP_X > 1 THEN SHIP_X = SHIP_X - 1
1210 RETURN
1300 REM MOVE RIGHT
1305 IF SHIP_X < 39 THEN SHIP_X = SHIP_X + 1
1310 RETURN
2000 REM CLEAR OLD SHIP POSITION
2005 PRINT CHR$(19): FOR I = 1 TO OLD_Y: PRINT CHR$(17);: NEXT I
2010 PRINT TAB(OLD_X); " "
2015 RETURN
```
</TryItNow>

**Professional Features:**
- **Movement delay system** (lines 90-95) prevents ship from moving too fast
- **Subroutines for each direction** (1000-1310) keep code organized
- **Clean position clearing** (2000-2015) prevents screen artifacts
- **Frame counter** (line 180) shows the game is running continuously

`★ Insight ─────────────────────────────────────`
**Real-time programming changes everything**. Your guessing games used sophisticated algorithms to analyze single inputs. Action games need simple algorithms that run hundreds of times per second. The complexity moves from data analysis to timing and coordination.

**GET vs INPUT represents the great divide** in 1980s programming. INPUT = turn-based strategy games. GET = arcade action. Most bedroom coders never made this leap!
`─────────────────────────────────────────────────`

## Responsive Ship Design

Let's add visual feedback that makes the ship feel alive and responsive:

<TryItNow>
```basic
10 REM RESPONSIVE SHIP WITH VISUAL FEEDBACK
15 WHITE$ = CHR$(5): RED$ = CHR$(28): GREEN$ = CHR$(30)
20 PURPLE$ = CHR$(156): YELLOW$ = CHR$(158): OFF$ = CHR$(159)
25 PRINT CHR$(147)
30 PRINT WHITE$; "ADVANCED SHIP CONTROL"; OFF$
35 PRINT STRING$(30, "═")
40 PRINT "SHIP RESPONDS TO YOUR PILOTING STYLE!"
45 PRINT STRING$(30, "─")
50 REM SHIP STATE VARIABLES
55 SHIP_X = 20: SHIP_Y = 15: OLD_X = 20: OLD_Y = 15
60 SHIP_FACING = 1: REM 1=UP, 2=DOWN, 3=LEFT, 4=RIGHT
65 MOVE_COUNT = 0: IDLE_COUNT = 0
70 THROTTLE = 0: MAX_THROTTLE = 5
75 REM SHIP CHARACTER ARRAY
80 DIM SHIP$(4)
85 SHIP$(1) = "▲": SHIP$(2) = "▼": SHIP$(3) = "◄": SHIP$(4) = "►"
90 REM MAIN CONTROL LOOP
95 GET KEY$
100 OLD_X = SHIP_X: OLD_Y = SHIP_Y: OLD_FACING = SHIP_FACING
105 MOVED = 0
110 REM MOVEMENT WITH SHIP ORIENTATION
115 IF KEY$ = "W" OR KEY$ = "w" THEN SHIP_Y = SHIP_Y - 1: SHIP_FACING = 1: MOVED = 1
120 IF KEY$ = "S" OR KEY$ = "s" THEN SHIP_Y = SHIP_Y + 1: SHIP_FACING = 2: MOVED = 1
125 IF KEY$ = "A" OR KEY$ = "a" THEN SHIP_X = SHIP_X - 1: SHIP_FACING = 3: MOVED = 1
130 IF KEY$ = "D" OR KEY$ = "d" THEN SHIP_X = SHIP_X + 1: SHIP_FACING = 4: MOVED = 1
135 IF KEY$ = "Q" OR KEY$ = "q" THEN 500
140 REM BOUNDARY ENFORCEMENT
145 IF SHIP_X < 1 THEN SHIP_X = 1: MOVED = 0
150 IF SHIP_X > 39 THEN SHIP_X = 39: MOVED = 0
155 IF SHIP_Y < 7 THEN SHIP_Y = 7: MOVED = 0
160 IF SHIP_Y > 22 THEN SHIP_Y = 22: MOVED = 0
165 REM UPDATE MOVEMENT STATISTICS
170 IF MOVED = 1 THEN MOVE_COUNT = MOVE_COUNT + 1: IDLE_COUNT = 0
175 IF MOVED = 0 THEN IDLE_COUNT = IDLE_COUNT + 1
180 REM THROTTLE SYSTEM
185 IF MOVED = 1 AND THROTTLE < MAX_THROTTLE THEN THROTTLE = THROTTLE + 1
190 IF MOVED = 0 AND THROTTLE > 0 THEN THROTTLE = THROTTLE - 1
195 REM CLEAR OLD POSITION IF CHANGED
200 IF SHIP_X <> OLD_X OR SHIP_Y <> OLD_Y OR SHIP_FACING <> OLD_FACING THEN GOSUB 1000
205 REM DRAW SHIP WITH CURRENT ORIENTATION
210 PRINT CHR$(19): FOR I = 1 TO SHIP_Y: PRINT CHR$(17);: NEXT I
215 SHIP_COLOR$ = GREEN$
220 IF THROTTLE > 3 THEN SHIP_COLOR$ = YELLOW$
225 IF THROTTLE = MAX_THROTTLE THEN SHIP_COLOR$ = RED$
230 PRINT TAB(SHIP_X); SHIP_COLOR$; SHIP$(SHIP_FACING); OFF$
235 REM PILOT FEEDBACK
240 PRINT CHR$(19): PRINT TAB(25); "MOVES:"; MOVE_COUNT; "  "
245 PRINT TAB(25); "THROTTLE:";
250 FOR T = 1 TO THROTTLE: PRINT "▓";: NEXT T
255 FOR T = THROTTLE + 1 TO MAX_THROTTLE: PRINT "▒";: NEXT T
260 PRINT "  "
265 GOTO 95
500 PRINT: PRINT YELLOW$; "PILOT LOGGED OFF"; OFF$
505 PRINT "FINAL STATS: "; MOVE_COUNT; "MOVES"
510 END
1000 REM CLEAR OLD SHIP POSITION
1005 PRINT CHR$(19): FOR I = 1 TO OLD_Y: PRINT CHR$(17);: NEXT I
1010 PRINT TAB(OLD_X); " "
1015 RETURN
```
</TryItNow>

**Advanced Ship Features:**
- **Directional ship sprites** (lines 80-85) show which way you're facing
- **Throttle system** (185-190) builds up speed with continuous movement
- **Dynamic ship colors** (215-225) change based on throttle level
- **Pilot statistics** (240-260) track your flying performance

This creates the foundation for all action games - responsive control that feels immediate and alive!
