# Sprite Colors: Painting Your Digital World
**Learn the C64's two sprite color modes and how to use them effectively**

Sprite coloring on the C64 involves more than just picking a color—it's about understanding two fundamentally different display modes. Single-color mode provides high resolution with one color per sprite. Multicolor mode trades resolution for the ability to display three colors simultaneously. Knowing when and how to use each mode is essential for creating visually appealing games.

In 1982, most computers displayed sprites in one color. The C64 revolutionized gaming by offering multicolor sprites—each sprite could display three colors plus transparency. Games like "Impossible Mission" used this for detailed characters, "Bubble Bobble" created cute dragons, and "The Last Ninja" rendered complex warriors. The secret? Understanding the VIC-II's two sprite modes and how to maximize their potential.

## What You'll Learn

In this lesson, you'll discover:
- **Single-color mode** - High resolution sprites with one color
- **Multicolor mode** - Lower resolution with three colors per sprite
- **Color registers** - How $D027-$D02E control individual sprite colors
- **Shared colors** - Using $D025 and $D026 for multicolor sprites
- **Mode switching** - Enabling multicolor mode per sprite
- **Design techniques** - Creating effective sprites within color limitations

## Understanding Sprite Color Modes

### Single-Color Mode (High Resolution)

In single-color mode, each pixel is either on or off:

<CodeBlock title="Single-Color Sprite Structure" code={`Single-Color Mode:
- Resolution: 24×21 pixels
- Colors: 1 color + transparent
- Each bit = 1 pixel
- Bit 0 = transparent
- Bit 1 = sprite color

Memory Layout (per row):
Byte 0: [7][6][5][4][3][2][1][0] = 8 pixels
Byte 1: [7][6][5][4][3][2][1][0] = 8 pixels  
Byte 2: [7][6][5][4][3][2][1][0] = 8 pixels
Total: 24 pixels wide

Best for: Text, thin lines, detailed graphics`} />

### Multicolor Mode (Lower Resolution, More Colors)

Multicolor mode trades resolution for colors:

<CodeBlock title="Multicolor Sprite Structure" code={`Multicolor Mode:
- Resolution: 12×21 pixels (half width)
- Colors: 3 colors + transparent
- Each pixel pair = 1 multicolor pixel
- 00 = transparent
- 01 = Multicolor register 0 ($D025)
- 10 = Sprite color register
- 11 = Multicolor register 1 ($D026)

Memory Layout (per row):
Byte 0: [76][54][32][10] = 4 multicolor pixels
Byte 1: [76][54][32][10] = 4 multicolor pixels
Byte 2: [76][54][32][10] = 4 multicolor pixels
Total: 12 multicolor pixels wide

Best for: Characters, enemies, colorful objects`} />

## Color Design Strategies

### Maximizing Color Variety

<CodeBlock title="Using Multiple Sprites for More Colors" language="asm" code={`; Overlay technique - combine sprites for more colors
; Each sprite adds its colors to the total

create_colorful_character:
        ; Base sprite (body)
        lda #$04        ; Enable sprites 2 and 3
        ora #$08
        sta $d015
        
        ; Position both sprites at same location
        lda #100
        sta $d004       ; Sprite 2 X
        sta $d006       ; Sprite 3 X
        lda #100
        sta $d005       ; Sprite 2 Y
        sta $d007       ; Sprite 3 Y
        
        ; Sprite 2: Main body (multicolor)
        lda $d01c
        ora #$04        ; Multicolor for sprite 2
        sta $d01c
        
        lda #$0f        ; Light gray
        sta $d029       ; Sprite 2 color
        
        ; Sprite 3: Details overlay (single color)
        lda $d01c
        and #$f7        ; Single color for sprite 3
        sta $d01c
        
        lda #$00        ; Black
        sta $d02a       ; Sprite 3 color
        
        ; Set different patterns
        lda #$82        ; Body pattern
        sta $07fa       ; Sprite 2 pointer
        
        lda #$83        ; Detail pattern
        sta $07fb       ; Sprite 3 pointer
        
        rts

; Priority layering for color effects
set_sprite_priorities:
        ; Sprite 3 in front of sprite 2
        lda $d01b
        and #$fb        ; Sprite 2 behind
        ora #$08        ; Sprite 3 in front
        sta $d01b
        rts`} />

### Color Cycling Effects

<CodeBlock title="Dynamic Color Changes" language="asm" code={`; Cycle colors for visual effects
; Creates pulsing, flashing, or rainbow effects

cycle_colors:
        inc color_timer
        lda color_timer
        and #$07        ; Every 8 frames
        bne no_cycle
        
        ; Cycle sprite color
        inc current_color
        lda current_color
        and #$0f        ; 16 colors
        sta $d027       ; Update sprite 0 color
        
        ; Pulse multicolor registers
        lda pulse_direction
        beq brighten
        
darken:
        dec multicolor_value
        lda multicolor_value
        cmp #$00
        bne update_multi
        lda #$00
        sta pulse_direction
        jmp update_multi
        
brighten:
        inc multicolor_value
        lda multicolor_value
        cmp #$0f
        bne update_multi
        lda #$01
        sta pulse_direction
        
update_multi:
        lda multicolor_value
        sta $d025       ; Update multicolor 0
        rts
        
no_cycle:
        rts

color_timer:       !byte 0
current_color:     !byte 1
pulse_direction:   !byte 0
multicolor_value:  !byte 8`} />

### Converting High-Res to Multicolor

<CodeBlock title="Sprite Mode Conversion" language="asm" code={`; Switch sprite between modes at runtime
; Useful for different game states

toggle_sprite_mode:
        lda sprite_mode
        eor #$01
        sta sprite_mode
        
        beq set_single_color
        
set_multicolor:
        ; Switch to multicolor
        lda $d01c
        ora #$01        ; Set bit 0
        sta $d01c
        
        ; Load multicolor pattern
        lda #$81        ; Multicolor sprite
        sta $07f8
        
        ; Set up colors
        lda #$00        ; Black
        sta $d025
        lda #$01        ; White
        sta $d026
        
        jmp mode_done
        
set_single_color:
        ; Switch to single color
        lda $d01c
        and #$fe        ; Clear bit 0
        sta $d01c
        
        ; Load single color pattern
        lda #$80        ; Single color sprite
        sta $07f8
        
mode_done:
        rts

sprite_mode: !byte 0`} />

        sta $d005

        ; Sprite 3: Flashing

        sta $d006
        lda #80
        sta $d007

        lda #$01        ; White

rainbow_cycle:
