# Screen Memory: Understanding the C64's Display System
**Master the foundation of all C64 graphics - the screen and color RAM**

Before you can create custom characters or build game worlds, you need to understand how the C64 organizes its display. Unlike modern systems with pixel buffers, the C64 uses a character-based display: 40 columns by 25 rows of characters, each with its own color. This elegant system powered every text adventure, every RPG dialog, every high score table.

Understanding screen memory is like learning the street layout of a city. Once you know that screen memory starts at $0400 and color memory at $D800, once you can calculate any position instantly, you gain direct control over every character on screen. This is how "Elite" displayed its trading screens, how "Zork" rendered its text, how "Boulder Dash" built its caves.

This lesson unlocks the C64's display system at its most fundamental level.

## What You'll Learn

In this lesson, you'll discover:
- **Screen memory layout** - The 40×25 grid at $0400-$07E7
- **Color memory** - How $D800-$DBE7 controls character colors
- **Position calculation** - Converting row/column to memory addresses
- **Character codes** - Understanding PETSCII vs screen codes
- **Direct manipulation** - Writing to screen without KERNAL routines
- **Memory efficiency** - Working with the C64's character-based display

## The C64 Display Architecture

### Screen Memory ($0400-$07E7)

The screen is a grid of 1000 character positions:

```text
Screen Organization:
- 40 columns × 25 rows = 1000 characters
- Memory: $0400 to $07E7 (1000 bytes)
- Each byte = one character code

Memory Map:
$0400-$0427: Row 0 (top of screen)
$0428-$044F: Row 1
$0450-$0477: Row 2
...
$07C0-$07E7: Row 24 (bottom)

Character Codes:
$00-$1F: Control codes
$20-$3F: Numbers and symbols
$40-$5F: Uppercase letters
$60-$7F: Graphic symbols
$80-$FF: Reversed versions
```

### Color Memory ($D800-$DBE7)

Each character has an associated color:

```text
Color RAM Organization:
- Same layout as screen memory
- Memory: $D800 to $DBE7 (1000 locations)
- Only lower 4 bits used (16 colors)

Color Values:
$0: Black      $8: Orange
$1: White      $9: Brown
$2: Red        $A: Light Red
$3: Cyan       $B: Dark Gray
$4: Purple     $C: Medium Gray
$5: Green      $D: Light Green
$6: Blue       $E: Light Blue
$7: Yellow     $F: Light Gray
```

```asm

; Shows fundamental screen control

        * = $0801

        * = $080d
start:
        ; Clear the screen
        jsr clear_screen
        
        ; Write "HELLO" at position (10,5)
        jsr write_hello
        
        ; Color it rainbow
        jsr color_hello
        
        ; Create a border
        jsr draw_border
        
        ; Fill pattern
        jsr fill_pattern
        
endless:
        jmp endless

clear_screen:
        ; Clear screen and color memory
        ldx #0
clear_loop:
        lda #$20        ; Space character
        sta $0400,x
        sta $0500,x
        sta $0600,x
        sta $06e8,x
        
        lda #$01        ; White
        sta $d800,x
        sta $d900,x
        sta $da00,x
        sta $dae8,x
        
        inx
        bne clear_loop
        rts

write_hello:
        ; Calculate position: row 5, column 10
        ; Position = $0400 + (row * 40) + column
        ; Position = $0400 + (5 * 40) + 10
        ; Position = $0400 + 200 + 10 = $04D2
        
        lda #'H'        ; PETSCII 'H'
        sta $04d2
        lda #'E'
        sta $04d3
        lda #'L'
        sta $04d4
        sta $04d5       ; Second 'L'
        lda #'O'
        sta $04d6
        rts

color_hello:
        ; Color each letter differently
        lda #$02        ; Red
        sta $d8d2
        lda #$07        ; Yellow
        sta $d8d3
        lda #$05        ; Green
        sta $d8d4
        lda #$06        ; Blue
        sta $d8d5
        lda #$04        ; Purple
        sta $d8d6
        rts
```

### Position Calculation

```asm
; Calculate any screen position
; Input: X = column (0-39), Y = row (0-24)
; Output: Address in screen_ptr

calculate_position:
        ; Save column
        stx temp_x
        
        ; Calculate row offset (Y * 40)
        lda #0
        sta screen_ptr+1
        tya
        
        ; Multiply by 40
        asl             ; × 2
        asl             ; × 4
        asl             ; × 8
        sta screen_ptr
        
        tya
        asl             ; × 2
        asl             ; × 4
        asl             ; × 8
        asl             ; × 16
        asl             ; × 32
        clc
        adc screen_ptr  ; 8Y + 32Y = 40Y
        sta screen_ptr
        
        ; Add column
        lda temp_x
        clc
        adc screen_ptr
        sta screen_ptr
        
        ; Add base address ($0400)
        lda screen_ptr+1
        adc #$04
        sta screen_ptr+1
        
        rts

; Faster version using lookup table
fast_calculate:
        ; Use pre-calculated row table
        tya
        asl             ; × 2 for word index
        tay
        lda row_table_lo,y
        sta screen_ptr
        lda row_table_hi,y
        sta screen_ptr+1
        
        ; Add column
        txa
        clc
        adc screen_ptr
        sta screen_ptr
        bcc no_carry
        inc screen_ptr+1
no_carry:
        rts

; Variables
temp_x:      !byte 0
screen_ptr:  !word 0

; Lookup tables for each row
row_table_lo:
        !byte <$0400, <$0428, <$0450, <$0478, <$04a0
        !byte <$04c8, <$04f0, <$0518, <$0540, <$0568
        !byte <$0590, <$05b8, <$05e0, <$0608, <$0630
        !byte <$0658, <$0680, <$06a8, <$06d0, <$06f8
        !byte <$0720, <$0748, <$0770, <$0798, <$07c0

row_table_hi:
        !byte >$0400, >$0428, >$0450, >$0478, >$04a0
        !byte >$04c8, >$04f0, >$0518, >$0540, >$0568
        !byte >$0590, >$05b8, >$05e0, >$0608, >$0630
        !byte >$0658, >$0680, >$06a8, >$06d0, >$06f8
        !byte >$0720, >$0748, >$0770, >$0798, >$07c0
```

## Creating Screen Effects

### Drawing Borders and Boxes

```asm
draw_neon_nexus_border:
        ; Draw network-themed game border for Neon Nexus
        
        ; Top border with network nodes
        ldx #39
top_border_loop:
        ; Alternate between connection lines and nodes
        txa
        and #$03
        cmp #$00
        beq top_node
        lda #$40        ; Horizontal line (connection)
        jmp top_store
top_node:
        lda #$71        ; Network node character
top_store:
        sta $0400,x
        lda #$0b        ; Dark cyan for network theme
        sta $d800,x
        dex
        bpl top_border_loop
        
        ; Bottom status border
        ldx #39
bottom_border_loop:
        lda #$40        ; Clean line for status area
        sta $07c0,x
        lda #$0b        ; Dark cyan
        sta $dbc0,x
        dex
        bpl bottom_border_loop
        
        ; Left and right game boundaries
        ldy #23         ; Rows 1-23
side_border_loop:
        ; Calculate row position
        tya
        asl
        tax
        lda row_table_lo,x
        sta screen_ptr
        lda row_table_hi,x
        sta screen_ptr+1
        
        ; Different border for top area vs bottom area
        cpy #20
        bcs status_area_border
        
        ; Game area - network themed
        lda #$7d        ; Network connection vertical
        jmp store_sides
        
status_area_border:
        ; Status area - clean lines
        lda #$5d        ; Clean vertical line
        
store_sides:
        ; Left side
        ldy #0
        sta (screen_ptr),y
        
        ; Right side  
        ldy #39
        sta (screen_ptr),y
        
        ; Color the borders
        lda screen_ptr+1
        clc
        adc #$d4        ; Color RAM offset
        sta screen_ptr+1
        
        lda #$0b        ; Dark cyan
        ldy #0
        sta (screen_ptr),y
        ldy #39
        sta (screen_ptr),y
        
        ; Next row
        ldy side_border_loop+1
        dey
        sty side_border_loop+1
        bpl side_border_loop
        
        ; Special corner pieces for network theme
        lda #$70        ; Network junction
        sta $0400       ; Top-left
        sta $0427       ; Top-right
        sta $07c0       ; Bottom-left
        sta $07e7       ; Bottom-right
        
        ; Add network pulse points at mid-borders
        lda #$2a        ; Pulse marker (*)
        sta $0414       ; Top middle
        sta $07d4       ; Bottom middle
        
        ; Add side pulse points
        lda #$2a        ; Pulse marker
        sta $0540       ; Left middle (row 10)
        sta $0567       ; Right middle (row 10)
        
        rts
```

### Color Gradients and Patterns

```asm
create_gradient:
        ; Fill screen with color gradient
        ldx #0
        ldy #0
gradient_loop:
        ; Calculate color based on position
        tya
        lsr             ; Divide by 2
        and #$0f        ; Keep in color range
        sta $d800,x
        sta $d900,x
        sta $da00,x
        sta $dae8,x
        
        ; Increment and loop
        inx
        iny
        cpx #0
        bne gradient_loop
        rts

checkerboard_pattern:
        ; Create checkerboard pattern
        ldy #24         ; Row counter
check_row:
        ldx #39         ; Column counter
check_col:
        ; Calculate if even or odd square
        txa
        eor row_counter
        and #$01
        beq white_square
        
black_square:
        lda #$a0        ; Solid block
        jmp store_square
        
white_square:
        lda #$20        ; Space
        
store_square:
        ; Calculate position and store
        pha
        jsr calculate_position
        pla
        ldy #0
        sta (screen_ptr),y
        
        ; Next column
        dex
        bpl check_col
        
        ; Next row
        dec row_counter
        ldy row_counter
        bpl check_row
        rts

row_counter: !byte 24
```

## Text Display Techniques

### Printing Strings

```asm
print_string:
        ; Print null-terminated string
        ; Input: string_ptr = address of string
        ;        X = column, Y = row
        
        jsr calculate_position
        
        ldy #0
print_loop:
        lda (string_ptr),y
        beq print_done  ; Null terminator
        
        ; Convert ASCII to PETSCII if needed
        cmp #$40
        bcc no_convert
        cmp #$60
        bcs no_convert
        sec
        sbc #$40        ; Convert to PETSCII
        
no_convert:
        sta (screen_ptr),y
        iny
        jmp print_loop
        
print_done:
        rts

; Example usage
display_message:
        ; Set up string pointer
        lda #<message
        sta string_ptr
        lda #>message
        sta string_ptr+1
        
        ; Print at position (5,10)
        ldx #5
        ldy #10
        jsr print_string
        rts

message:
        !text "HELLO C64 WORLD!"
        !byte 0         ; Null terminator

string_ptr: !word 0
```

### Scrolling Text

```asm
scroll_line_left:
        ; Scroll a single line left
        ; Input: Y = row number
        
        ; Calculate row start
        tya
        asl
        tax
        lda row_table_lo,x
        sta screen_ptr
        lda row_table_hi,x
        sta screen_ptr+1
        
        ; Scroll characters
        ldy #0
scroll_char:
        iny
        lda (screen_ptr),y
        dey
        sta (screen_ptr),y
        iny
        cpy #39
        bne scroll_char
        
        ; Blank last character
        lda #$20
        sta (screen_ptr),y
        
        ; Scroll colors too
        lda screen_ptr+1
        clc
        adc #$d4
        sta screen_ptr+1
        
        ldy #0
scroll_color:
        iny
        lda (screen_ptr),y
        dey
        sta (screen_ptr),y
        iny
        cpy #39
        bne scroll_color
        
        rts

smooth_scroll_message:
        ; Smooth scroll using hardware register
        dec scroll_counter
        bpl no_scroll
        
        ; Reset counter
        lda #7
        sta scroll_counter
        
        ; Shift message
        jsr scroll_line_left
        
        ; Add next character
        inc message_index
        ldx message_index
        lda scroll_message,x
        bne not_end
        
        ; Reset message
        ldx #0
        stx message_index
        lda scroll_message,x
        
not_end:
        ; Store at right edge
        ldy #12         ; Row 12
        tya
        asl
        tax
        lda row_table_lo,x
        sta screen_ptr
        lda row_table_hi,x
        sta screen_ptr+1
        
        ldy #39
        lda scroll_message,x
        sta (screen_ptr),y
        
no_scroll:
        rts

scroll_counter:  !byte 7
message_index:   !byte 0
scroll_message:
        !text "  WELCOME TO THE C64!  THIS IS SCROLLING TEXT...  "
        !byte 0
```

## Color RAM Tricks

### Dynamic Color Changes

```asm
animate_neon_border:
        ; Pulse the network border colors for Neon Nexus
        inc color_timer
        lda color_timer
        and #$0f
        bne no_border_pulse
        
        ; Pulse the network nodes
        lda pulse_state
        eor #$01
        sta pulse_state
        beq dim_pulse
        
bright_pulse:
        ; Bright cyan for active network
        lda #$03        ; Cyan
        jmp update_pulse_points
        
dim_pulse:
        ; Dark cyan for inactive
        lda #$0b        ; Dark cyan
        
update_pulse_points:
        ; Update the pulse markers
        sta $d814       ; Top middle pulse
        sta $dbd4       ; Bottom middle pulse
        sta $d940       ; Left middle pulse (row 10)
        sta $d967       ; Right middle pulse (row 10)
        
        ; Also pulse the corner junctions
        sta $d800       ; Top-left corner
        sta $d827       ; Top-right corner
        sta $dbc0       ; Bottom-left corner
        sta $dbe7       ; Bottom-right corner
        
no_border_pulse:
        rts

flash_text:
        ; Flash important text
        lda flash_state
        eor #$01
        sta flash_state
        beq normal_color
        
        ; Bright color
        lda #$01        ; White
        jmp set_flash
        
normal_color:
        lda #$02        ; Red
        
set_flash:
        ; Color "GAME OVER" at center
        ldx #8
flash_loop:
        sta $d8d0,x     ; Row 12, starting column 16
        dex
        bpl flash_loop
        rts

color_timer: !byte 0
flash_state: !byte 0
pulse_state: !byte 0
```

## Memory-Efficient Techniques

```text
Screen Memory Tips:

1. Use lookup tables for row addresses
   - Faster than multiplication
   - 50 bytes for huge speed gain

2. Combine operations when possible
   - Write character and color together
   - Use indexed addressing modes

3. Unroll loops for critical sections
   - 4x unrolling for screen clear
   - Trade size for speed

4. Use character codes efficiently
   - PETSCII graphics for borders
   - Reversed characters for effects

5. Color RAM peculiarities
   - Only lower 4 bits matter
   - Can't be saved/restored easily
   - Always at $D800 (can't move)
```
