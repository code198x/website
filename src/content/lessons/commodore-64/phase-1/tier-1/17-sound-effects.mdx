# Sound Effects: Your First Beeps and Boops
**Unleash the power of the legendary SID chip**

The C64's SID (Sound Interface Device) chip was revolutionary. While other computers beeped, the C64 sang. This single chip, designed by Bob Yannes (who later founded Ensoniq), gave the C64 a 3-voice synthesizer that rivaled dedicated music keyboards. It's why C64 music became legendary—from Rob Hubbard's masterpieces to Martin Galway's innovations to the modern demoscene.

But before you can compose symphonies, you need to make your first beep. Today you'll learn the fundamentals: how to wake up the SID chip, how to make it produce sound, and how to create the essential sound effects every game needs. A jump sound. A collect sound. An explosion. These building blocks will grow into the rich soundscapes that made the C64 famous.

This is your first step into the world of C64 audio—where every game had a voice.

## What You'll Learn

In this lesson, you'll discover:
- **SID chip basics** - Understanding the 6581/8580 sound synthesizer
- **Voice control** - Managing three independent sound channels
- **Waveforms** - Triangle, sawtooth, pulse, and noise
- **ADSR envelope** - Attack, Decay, Sustain, Release
- **Frequency control** - Creating different pitches
- **Sound triggering** - Starting and stopping sounds with the gate bit

## Understanding the SID Chip

### The 6581/8580 Architecture

The SID chip is a complete 3-voice synthesizer:

<CodeBlock title="SID Chip Memory Map" code={`SID Registers: $D400-$D41C

Voice 1: $D400-$D406
$D400-01: Frequency (low/high)
$D402-03: Pulse width (low/high)
$D404: Control register (waveform, gate)
$D405: Attack/Decay
$D406: Sustain/Release

Voice 2: $D407-$D40D
(Same structure as Voice 1)

Voice 3: $D40E-$D414
(Same structure as Voice 1)

Filter: $D415-$D417
$D415-16: Filter cutoff
$D417: Filter resonance/control

Volume & Filter Select: $D418
Bits 0-3: Master volume (0-15)
Bits 4-7: Filter enables

Special: $D419-$D41C
$D419-1A: Paddle readings
$D41B-1C: Voice 3 oscillator/envelope output`} />

### Waveform Types

Each voice can produce four waveforms:

<CodeBlock title="SID Waveforms" code={`Waveform Control (Register $D404, $D40B, $D412):
Bit 0: Gate (1=start, 0=release)
Bit 1: Sync (sync to voice 1/2)
Bit 2: Ring modulation
Bit 3: Test bit (disable oscillator)
Bit 4: Triangle waveform
Bit 5: Sawtooth waveform
Bit 6: Pulse waveform
Bit 7: Noise waveform

Waveform Characteristics:
Triangle ($10): Smooth, flute-like
Sawtooth ($20): Bright, brass-like
Pulse ($40): Variable, hollow to nasal
Noise ($80): Random, percussion/effects

Note: Only one waveform bit should be set!`} />

## Your First Sound

<CodeBlock title="Making Your First Beep" language="asm" code={`; First sound on the C64
; The "Hello World" of SID programming

        * = $0801
        !byte $0b,$08,$0a,$00,$9e,$32,$30,$36,$31,$00,$00,$00

        * = $080d
start:
        ; Initialize SID
        jsr init_sid
        
        ; Make a simple beep
        jsr beep
        
        ; Wait for keypress
        jsr $ffe4
        beq *-3
        
        ; Silence
        jsr silence_sid
        rts

init_sid:
        ; Clear all SID registers
        ldx #$18
        lda #0
clear_sid:
        sta $d400,x
        dex
        bpl clear_sid
        
        ; Set master volume
        lda #15         ; Maximum volume
        sta $d418
        
        rts

beep:
        ; Simple beep sound
        
        ; Set frequency (middle C = 262 Hz)
        ; Frequency = Hz * 0.0596
        ; 262 * 0.0596 = 15.6 ≈ $0F9B
        lda #$9b
        sta $d400       ; Voice 1 frequency low
        lda #$0f
        sta $d401       ; Voice 1 frequency high
        
        ; Set ADSR envelope
        ; Attack=2, Decay=8
        lda #$28
        sta $d405
        ; Sustain=15, Release=9
        lda #$f9
        sta $d406
        
        ; Set waveform and gate
        lda #$11        ; Triangle wave + gate
        sta $d404
        
        ; Let it play
        ldx #30
beep_wait:
        lda #250
wait:   cmp $d012
        bne wait
        dex
        bne beep_wait
        
        ; Release (gate off)
        lda #$10        ; Triangle wave, gate off
        sta $d404
        
        rts

silence_sid:
        ; Turn off all voices
        lda #0
        sta $d404       ; Voice 1 off
        sta $d40b       ; Voice 2 off
        sta $d412       ; Voice 3 off
        rts`} />

## Essential Game Sound Effects

### Jump Sound

<CodeBlock title="Classic Jump Sound Effect" language="asm" code={`jump_sound:
        ; Classic platform game jump sound
        ; Rising pitch sweep
        
        ; Initial frequency (low)
        lda #$00
        sta $d400
        lda #$08
        sta $d401
        
        ; Fast attack, slow decay
        lda #$09        ; Attack=0, Decay=9
        sta $d405
        lda #$00        ; Sustain=0, Release=0
        sta $d406
        
        ; Pulse wave for hollow sound
        lda #$00
        sta $d402       ; Pulse width low
        lda #$08        ; 50% duty cycle
        sta $d403       ; Pulse width high
        
        ; Start sound
        lda #$41        ; Pulse + gate
        sta $d404
        
        ; Sweep up
        ldx #0
jump_sweep:
        ; Increase frequency
        lda $d400
        clc
        adc #$20
        sta $d400
        lda $d401
        adc #0
        sta $d401
        
        ; Small delay
        ldy #2
jump_delay:
        lda #250
jw:     cmp $d012
        bne jw
        dey
        bne jump_delay
        
        inx
        cpx #20
        bne jump_sweep
        
        ; Gate off
        lda #$40
        sta $d404
        
        rts`} />

## Timing and Triggers

### Syncing Sound with Action

<CodeBlock title="Sound Triggering System" language="asm" code={`; Sound trigger system
; Queue and play sounds without conflicts

init_sound_queue:
        lda #0
        sta sound_queue
        sta sound_playing
        sta sound_timer
        rts

queue_sound:
        ; Input: A = sound ID
        ; Add sound to queue
        
        ora sound_queue
        sta sound_queue
        rts

process_sounds:
        ; Called every frame
        
        ; Check if sound playing
        lda sound_playing
        beq check_queue
        
        ; Decrement timer
        dec sound_timer
        bne sounds_done
        
        ; Sound finished
        lda #0
        sta sound_playing
        jsr silence_voice1
        
check_queue:
        ; Check for queued sounds
        lda sound_queue
        beq sounds_done
        
        ; Priority system
        lsr
        bcc not_jump
        jsr trigger_jump
        lda #JUMP_DURATION
        sta sound_timer
        lda #1
        sta sound_playing
        jmp clear_sound
        
not_jump:
        lsr
        bcc not_collect
        jsr trigger_collect
        lda #COLLECT_DURATION
        sta sound_timer
        lda #2
        sta sound_playing
        jmp clear_sound
        
not_collect:
        lsr
        bcc not_damage
        jsr trigger_damage
        lda #DAMAGE_DURATION
        sta sound_timer
        lda #3
        sta sound_playing
        
clear_sound:
        ; Clear from queue
        lda sound_queue
        and #$f8        ; Clear processed bit
        sta sound_queue
        
sounds_done:
        rts

trigger_jump:
        ; Start jump sound
        lda #$00
        sta $d400
        lda #$08
        sta $d401
        lda #$09
        sta $d405
        lda #$00
        sta $d406
        lda #$41
        sta $d404
        rts

trigger_collect:
        ; Start collect sound
        lda #$00
        sta $d400
        lda #$20
        sta $d401
        lda #$00
        sta $d405
        lda #$f0
        sta $d406
        lda #$11
        sta $d404
        rts

trigger_damage:
        ; Start damage sound
        lda #$00
        sta $d400
        lda #$02
