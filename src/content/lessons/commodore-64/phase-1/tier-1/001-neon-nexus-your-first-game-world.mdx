# Lesson 1: Neon Nexus - Your First Game World

Welcome to assembly programming on the Commodore 64! Today, you'll create the foundation of **Neon Nexus**, a fast-paced action game set in a glowing electronic arena. But we'll start small - just getting something on screen.

## Setting Up Your Development Environment

Before we code, you'll need:

**Essential Tools:**
- **Text Editor**: Any editor that saves plain text (Notepad++, VS Code, etc.)
- **Assembler**: KickAssembler (recommended) or ACME
- **Emulator**: VICE C64 emulator
- **File Transfer** (optional): For real C64 hardware

**Quick Setup:**
1. Download VICE emulator from vice-emu.sourceforge.net
2. Download KickAssembler from www.theweb.dk/KickAssembler
3. Create a folder for your projects (like `C64Projects`)
4. Test VICE runs - you should see the blue C64 startup screen

**Don't worry if this seems complex** - we'll walk through each step as we go!

## What We're Building

In this lesson, we'll:
1. Write a minimal C64 program that runs
2. Change the screen colors to create our "neon" atmosphere  
3. Clear the screen properly
4. Set up the foundation for our game

By the end, you'll have a working program that transforms your C64 screen into the beginning of a game world!

## Your First Assembly Program

Let's start with the absolute minimum - a program that does nothing but runs:

```asm
* = $0801        ; Start at BASIC area

; BASIC stub to run our program
.byte $0b,$08    ; Line link
.byte $0a,$00    ; Line number (10)
.byte $9e        ; SYS token
.byte $32,$30,$36,$31  ; "2061" in ASCII
.byte $00,$00,$00      ; End of BASIC

; Our actual program starts here
start:
    rts          ; Return to BASIC
```

**What's happening here?**
- `* = $0801` tells the assembler where to put our code in memory
- The `.byte` lines create a tiny BASIC program that says "SYS 2061"
- `start:` is a label marking where our code begins (at address 2061)
- `rts` (Return from Subroutine) gives control back to BASIC

Now we need to turn this source code into a program the C64 can run.

## How to Assemble Your Code

You have several options for assembling C64 programs:

### Option 1: Modern Cross-Assembler (Recommended)
Download **KickAssembler** or **ACME** for your computer:

1. Save your code as `neon1.asm`
2. Open a command prompt/terminal in your project folder
3. Run: `java -jar KickAss.jar neon1.asm` (for KickAssembler)
4. This creates `neon1.prg` - the compiled program
5. **To run it:**
   - Start VICE emulator
   - Press Alt+A (Attach Disk Image) and create a new disk
   - Drag `neon1.prg` onto the VICE window, or use File → Autostart Image
   - The program should run automatically!

### Option 2: Online Assembler
Use an online C64 development environment:

1. Go to a C64 online compiler
2. Paste your code
3. Click "Assemble" 
4. Run in the built-in emulator

### Option 3: On-Device Assembly
If you have Turbo Assembler on your C64:

1. Type in your source code
2. Press F1 to assemble
3. Fix any errors, then F3 to run

**For this course, we recommend Option 1 with VICE emulator** - it's most like professional development.

Type this in, assemble it, and run it. Nothing visible happens - but it works!

## Troubleshooting Your First Program

**"Command not found" error?**
- Make sure Java is installed (`java -version` in terminal)
- Check the path to KickAss.jar is correct
- Try the full path: `java -jar C:\path\to\KickAss.jar neon1.asm`

**Assembly errors?**
- Check every character matches exactly (assembly is picky!)
- Make sure you're using the right assembler syntax
- The BASIC stub bytes must be exactly as shown

**Program won't run in VICE?**
- Try typing `LOAD "NEON1",8` then `RUN` in VICE
- Or use File → Autostart Disk/Tape Image
- Make sure the .prg file was created successfully

**Still stuck?** Don't worry! Getting the toolchain working is often the hardest part. Try the online assembler option to get started coding while you sort out the local setup.

## Adding Our First Visual Effect

Now let's make something happen. We'll change the border color:

```asm
start:
    lda #$01     ; Load 1 (white) into accumulator
    sta $d020    ; Store it to border color register
    rts          ; Return to BASIC
```

**New concepts:**
- `lda` (Load Accumulator) puts a value into the A register
- `#$01` means the literal number 1 (in hex)
- `sta` (Store Accumulator) saves the A register to memory
- `$d020` is the C64's border color register

Run this and your border turns white! Try changing `#$01` to other values:
- `#$00` = black
- `#$02` = red  
- `#$05` = green
- `#$0e` = light blue

## Creating the Neon Arena

Let's expand our program to set up a proper game screen:

```asm
start:
    ; Set border color to dark blue
    lda #$06     
    sta $d020    
    
    ; Set background color to black
    lda #$00
    sta $d021
    
    ; Clear the screen
    lda #$93     ; Clear screen character
    jsr $ffd2    ; Call KERNAL CHROUT routine
    
    rts
```

**What's new:**
- `$d021` controls the background color
- `jsr` (Jump to Subroutine) calls built-in C64 routines
- `$ffd2` is CHROUT - it prints the character in A register
- Character 147 ($93) clears the screen

## Understanding What We've Built

Let's add comments to document our complete program:

```asm
;===============================================
; NEON NEXUS - Lesson 1: First Game World
; Creates the basic visual environment
;===============================================

* = $0801        ; Program starts at BASIC area

; BASIC launcher (SYS 2061)
.byte $0b,$08,$0a,$00,$9e
.byte $32,$30,$36,$31
.byte $00,$00,$00

;-----------------------------------------------
; Main Program Entry Point
;-----------------------------------------------
start:
    ; Create neon arena visual style
    lda #$06     ; Dark blue for border
    sta $d020    ; Border color register
    
    lda #$00     ; Black for main area  
    sta $d021    ; Background color register
    
    ; Clear screen for fresh start
    lda #$93     ; Clear screen character
    jsr $ffd2    ; CHROUT clears screen
    
    ; Program complete
    rts          ; Return to BASIC
```

## Adding Your Arena Title

Let's display "NEON NEXUS" on screen to complete our foundation:

```asm
    ; Previous color setup code here...
    
    ; Position cursor for title
    lda #$13     ; HOME character
    jsr $ffd2    ; Cursor to top-left
    
    ; Print each letter of "NEON NEXUS"
    lda #'N'     ; Letter N
    jsr $ffd2    ; Print it
    lda #'E'     
    jsr $ffd2
    lda #'O'
    jsr $ffd2
    lda #'N'
    jsr $ffd2
    
    rts
```

## Complete Lesson 1 Program

Here's our complete first program:

```asm
;===============================================
; NEON NEXUS - Lesson 1: First Game World
; A simple start to our assembly game
;===============================================

* = $0801

; BASIC stub
.byte $0b,$08,$0a,$00,$9e
.byte $32,$30,$36,$31
.byte $00,$00,$00

start:
    ; Set up neon color scheme
    lda #$06     ; Dark blue border
    sta $d020    
    lda #$00     ; Black background
    sta $d021    
    
    ; Clear and prepare screen
    lda #$93     ; Clear screen
    jsr $ffd2    
    
    ; Display title
    lda #'N'
    jsr $ffd2
    lda #'E'  
    jsr $ffd2
    lda #'O'
    jsr $ffd2
    lda #'N'
    jsr $ffd2
    
    ; Done - return to BASIC
    rts
```

Save this as `neon1.asm` - we'll build on it in the next lesson!
