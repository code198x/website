# Lesson 1: Neon Nexus - Your First Game World

Welcome to assembly programming on the Commodore 64! Today, you'll create the foundation of **Neon Nexus**, a fast-paced action game set in a glowing electronic arena. But we'll start small - just getting something on screen.

## Setting Up Your Development Environment

Before we can write any code, we need to install our tools. We'll use **CC65**, a modern, cross-platform toolchain that includes the CA65 assembler.

### Windows Setup

1. **Download CC65:**
   - Go to https://cc65.github.io/
   - Download the Windows snapshot (cc65-win32.zip)
   - Extract to `C:\cc65`

2. **Add to PATH:**
   - Right-click "This PC" → Properties → Advanced system settings
   - Click "Environment Variables"
   - Under System Variables, find "Path" and click Edit
   - Add new entry: `C:\cc65\bin`
   - Click OK to save

3. **Test installation:**
   - Open Command Prompt (cmd)
   - Type: `ca65 --version`
   - Should show: CA65 version info

4. **Get VICE emulator:**
   - Download from https://vice-emu.sourceforge.io/
   - Install to default location
   - VICE includes `x64sc` - the accurate C64 emulator

### macOS Setup

1. **Using Homebrew (recommended):**
   ```bash
   # Install Homebrew if you don't have it
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   
   # Install cc65
   brew install cc65
   
   # Install VICE
   brew install --cask vice
   ```

2. **Manual installation:**
   - Download cc65 from https://cc65.github.io/
   - Extract and add to PATH in ~/.zshrc or ~/.bash_profile:
   ```bash
   export PATH="$PATH:/path/to/cc65/bin"
   ```

3. **Test installation:**
   ```bash
   ca65 --version
   ```

### Linux Setup

**Ubuntu/Debian:**
```bash
# Install cc65
sudo apt-get update
sudo apt-get install cc65

# Install VICE
sudo apt-get install vice
```

**Arch Linux:**
```bash
# Install from AUR
yay -S cc65
yay -S vice
```

**Other distros:**
- Download source from https://github.com/cc65/cc65
- Build with: `make` and `sudo make install`

### Create Your Project Folder

1. Create a folder for your C64 projects:

## Your First Assembly Program

Let's start with the absolute minimum - a program that does nothing but runs.

Create a new file called `neon1.s` (the `.s` extension is standard for assembly source files) and type:

```asm
; Neon Nexus - Lesson 1
; Our first C64 program

        .org $0801      ; Start at BASIC area of memory

; BASIC stub that runs our machine language program
        .byte $0b,$08   ; Link to next BASIC line
        .byte $0a,$00   ; Line number 10
        .byte $9e       ; SYS token
        .byte $32,$30,$36,$31 ; "2061" in ASCII
        .byte $00       ; End of BASIC line
        .byte $00,$00   ; End of BASIC program

; Our machine language program starts here
start:
        rts             ; Return to BASIC
```

**What's happening here?**
- `.org $0801` tells the assembler where to put our code in memory
- The `.byte` lines create a tiny BASIC program that says "10 SYS 2061"
- `start:` is a label marking where our code begins (at address 2061)
- `rts` (Return from Subroutine) gives control back to BASIC

## Assembling Your First Program

Now let's turn this source code into a program the C64 can run.

### Step 1: Assemble to Object File

Open your terminal/command prompt in your project folder and run:

```bash
ca65 -t c64 neon1.s -o neon1.o
```

This creates `neon1.o` - an object file. The `-t c64` tells CA65 we're targeting the C64.

### Step 2: Link to PRG File

Now link it into a C64 program file:

```bash
ld65 -t c64 -o neon1.prg neon1.o
```

This creates `neon1.prg` - a file the C64 can actually run!

### Step 3: Run in VICE

**Windows:**
```bash
"C:\Program Files\VICE\x64sc.exe" neon1.prg
```

**macOS/Linux:**
```bash
x64sc neon1.prg
```

The program should load and run automatically. Nothing visible happens - but it worked!

## Troubleshooting

**"Command not found" errors?**
- Check that cc65 is in your PATH
- Try using the full path to ca65/ld65
- Restart your terminal after PATH changes

**Assembly errors?**
- Check for typos - assembly is very picky!
- Make sure you saved the file
- Use `.s` extension for source files

**VICE won't start?**
- Check VICE is installed correctly
- Try running VICE without a program first
- On Linux, you might need `x64` instead of `x64sc`

## Adding Our First Visual Effect

Now let's make something happen. Edit your program to change the border color:

```asm
; Our machine language program starts here
start:
        lda #$01        ; Load 1 (white) into accumulator
        sta $d020       ; Store it to border color register
        rts             ; Return to BASIC
```

**New concepts:**
- `lda` (Load Accumulator) puts a value into the A register
- `#$01` means the literal number 1 (in hex)
- `sta` (Store Accumulator) saves the A register to memory
- `$d020` is the C64's border color register

Assemble and run again:
```bash
ca65 -t c64 neon1.s -o neon1.o
ld65 -t c64 -o neon1.prg neon1.o
x64sc neon1.prg
```

Your border turns white! Try changing `#$01` to other values:
- `#$00` = black
- `#$02` = red  
- `#$05` = green
- `#$0e` = light blue

## Creating the Neon Arena

Let's expand our program to set up a proper game screen:

```asm
; Our machine language program starts here
start:
        ; Set border color to dark blue
        lda #$06     
        sta $d020       ; Border color register
        
        ; Set background color to black
        lda #$00
        sta $d021       ; Background color register
        
        ; Clear the screen
        lda #$93        ; Clear screen character (147 in decimal)
        jsr $ffd2       ; Call KERNAL CHROUT routine
        
        rts
```

**What's new:**
- `$d021` controls the background color
- `jsr` (Jump to Subroutine) calls built-in C64 routines
- `$ffd2` is CHROUT - it prints the character in A register
- Character 147 ($93) clears the screen

## Making Assembly Easier with a Build Script

Typing two commands every time gets old. Let's create a build script:

**Windows (build.bat):**
```batch
@echo off
ca65 -t c64 %1.s -o %1.o
if %errorlevel% neq 0 exit /b %errorlevel%
ld65 -t c64 -o %1.prg %1.o
if %errorlevel% neq 0 exit /b %errorlevel%
echo Build complete: %1.prg
```

**macOS/Linux (build.sh):**
```bash
#!/bin/bash
ca65 -t c64 $1.s -o $1.o || exit 1
ld65 -t c64 -o $1.prg $1.o || exit 1
echo "Build complete: $1.prg"
```

Make it executable (macOS/Linux):
```bash
chmod +x build.sh
```

Now you can build with:
- Windows: `build neon1`
- macOS/Linux: `./build.sh neon1`

## Adding Your Arena Title

Let's display "NEON NEXUS" on screen to complete our foundation:

```asm
start:
        ; Previous color setup code here...
        lda #$06     
        sta $d020
        lda #$00
        sta $d021
        lda #$93
        jsr $ffd2
        
        ; Position cursor for title
        lda #$13        ; HOME character (19 decimal)
        jsr $ffd2       ; Cursor to top-left
        
        ; Print each letter of "NEON"
        lda #'N'        ; ASCII letter N
        jsr $ffd2       ; Print it
        lda #'E'     
        jsr $ffd2
        lda #'O'
        jsr $ffd2
        lda #'N'
        jsr $ffd2
        
        rts
```

## Complete Lesson 1 Program

Here's our complete first program with proper comments:

```asm
;===============================================
; NEON NEXUS - Lesson 1: First Game World
; A simple start to our assembly game
;===============================================

        .org $0801      ; Program starts at BASIC area

; BASIC stub (10 SYS 2061)
        .byte $0b,$08,$0a,$00,$9e
        .byte $32,$30,$36,$31
        .byte $00,$00,$00

;-----------------------------------------------
; Main Program Entry Point
;-----------------------------------------------
start:
        ; Set up neon color scheme
        lda #$06        ; Dark blue border
        sta $d020       ; VIC-II border color
        lda #$00        ; Black background
        sta $d021       ; VIC-II background color
        
        ; Clear and prepare screen
        lda #$93        ; Clear screen character
        jsr $ffd2       ; KERNAL CHROUT routine
        
        ; Display title
        lda #'N'
        jsr $ffd2
        lda #'E'  
        jsr $ffd2
        lda #'O'
        jsr $ffd2
        lda #'N'
        jsr $ffd2
        
        ; Done - return to BASIC
        rts

; End of program
```

Build and run your complete program:
```bash
ca65 -t c64 neon1.s -o neon1.o
ld65 -t c64 -o neon1.prg neon1.o
x64sc neon1.prg
```

## Quick Reference

**CA65 Assembler Directives:**
- `.org` - Set memory location
- `.byte` - Define bytes in memory

**6502 Instructions So Far:**
- `lda` - Load Accumulator
- `sta` - Store Accumulator  
- `jsr` - Jump to Subroutine
- `rts` - Return from Subroutine

**C64 Memory Locations:**
- `$d020` - Border color
- `$d021` - Background color
- `$ffd2` - CHROUT (print character)
