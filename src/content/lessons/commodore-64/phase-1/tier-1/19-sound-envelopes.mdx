# Sound Envelopes: Shaping Sound with ADSR
**Transform beeps into bells, organs, and drums**

A piano key struck hard sounds different than one pressed gently. A guitar string plucked sharply has a different character than one strummed softly. A drum hit has an instant attack while a violin builds gradually. These differences aren't about pitch or waveform—they're about how the sound evolves over time. This evolution is controlled by the envelope.

The SID chip's ADSR envelope generator is its secret weapon. Those four parameters—Attack, Decay, Sustain, Release—transform simple waveforms into expressive instruments. Rob Hubbard didn't just write melodies; he programmed envelopes that made the SID sound like guitars, drums, and synthesizers. Today you'll master this crucial aspect of sound design, learning to shape sounds from harsh stabs to smooth pads.

This is where sounds gain character and expression—the difference between mechanical beeps and living music.

## Understanding ADSR

### The Four Stages

Every SID sound follows the ADSR envelope:

```text
The ADSR Envelope:

Volume
  ^
15|     /\
  |    /  \___________  <- Sustain Level
  |   /    \          \
  |  /      \          \
  | /        \          \
0 |/__________\__________\____> Time
  | A    D    S     R
  |
  Gate ON         Gate OFF

Attack (A): Time to reach maximum volume
- 0 = 2ms (instant)
- 15 = 8 seconds (very slow)

Decay (D): Time to fall to sustain level
- 0 = 6ms
- 15 = 24 seconds

Sustain (S): Volume level while gate is on
- 0 = silent
- 15 = maximum

Release (R): Time to fade to silence after gate off
- 0 = 6ms
- 15 = 24 seconds

Register Format:
$D405/$D40C/$D413: AAAADDDD (Attack/Decay)
$D406/$D40D/$D414: SSSSRRRR (Sustain/Release)
```

### ADSR Timing Tables

```text
Attack Times (milliseconds):
0: 2      8: 100
1: 8      9: 250
2: 16     A: 500
3: 24     B: 800
4: 38     C: 1000
5: 56     D: 3000
6: 68     E: 5000
7: 80     F: 8000

Decay/Release Times (milliseconds):
0: 6       8: 300
1: 24      9: 750
2: 48      A: 1500
3: 72      B: 2400
4: 114     C: 3000
5: 168     D: 9000
6: 204     E: 15000
7: 240     F: 24000

Common Combinations:
Pluck: A=0, D=6, S=0, R=6
Piano: A=0, D=9, S=0, R=9
Organ: A=2, D=0, S=F, R=2
Strings: A=9, D=4, S=C, R=9
Brass: A=6, D=6, S=9, R=6
Drum: A=0, D=4, S=0, R=4
```

## Dynamic Envelopes

### Changing Envelopes in Real-Time

```asm
; Dynamic envelope modification
; Change sound character during playback

velocity_sensitive:
        ; Simulate velocity by changing attack
        ; Input: A = velocity (0-15)
        
        ; Invert for attack (high velocity = fast attack)
        eor #$0f
        asl
        asl
        asl
        asl             ; Move to upper nibble
        
        ora #$09        ; Keep decay at 9
        sta $d405
        
        rts

expression_control:
        ; Change sustain level dynamically
        ; Input: A = expression (0-15)
        
        asl
        asl
        asl
        asl             ; Move to upper nibble
        
        ora #$06        ; Keep release at 6
        sta $d406
        
        rts

morphing_envelope:
        ; Gradually change envelope over time
        
        lda morph_position
        lsr
        lsr
        lsr             ; Divide by 8
        tax
        
        ; Interpolate between two presets
        lda morph_table_ad,x
        sta $d405
        lda morph_table_sr,x
        sta $d406
        
        inc morph_position
        
        rts

tremolo_effect:
        ; Vary sustain level for tremolo
        
        lda tremolo_phase
        lsr
        lsr
        and #$07
        tax
        lda tremolo_table,x
        
        asl
        asl
        asl
        asl
        ora #$06        ; Keep release
        sta $d406
        
        inc tremolo_phase
        
        rts

; Dynamic envelope data
morph_position:   !byte 0
tremolo_phase:    !byte 0

morph_table_ad:
        !byte $09,$19,$29,$39,$49,$59,$69,$79
        !byte $89,$99,$a9,$b9,$c9,$d9,$e9,$f9

morph_table_sr:
        !byte $09,$19,$29,$39,$49,$59,$69,$79
        !byte $89,$99,$a9,$b9,$c9,$d9,$e9,$f9

tremolo_table:
        !byte $08,$0a,$0c,$0e,$0f,$0e,$0c,$0a
```

## Envelope Effects

### Special Envelope Techniques

```asm
; Special envelope effects
; Creative use of ADSR

auto_wah_effect:
        ; Sweep through different decay rates
        
        lda wah_position
        and #$0f
        ora #$00        ; Attack = 0
        sta $d405
        
        ; Update position
        inc wah_position
        
        rts

gate_stutter:
        ; Rapid gate on/off for stuttering
        
        lda stutter_counter
        and #$03
        bne stutter_off
        
stutter_on:
        lda current_waveform
        ora #$01        ; Gate on
        sta $d404
        jmp stutter_done
        
stutter_off:
        lda current_waveform
        sta $d404       ; Gate off
        
stutter_done:
        inc stutter_counter
        rts

envelope_sweep:
        ; Sweep all parameters
        
        inc sweep_timer
        lda sweep_timer
        
        ; Change attack every 16 frames
        and #$f0
        ora #$08        ; Decay = 8
        sta $d405
        
        ; Change sustain continuously
        lda sweep_timer
        lsr
        lsr
        and #$0f
        asl
        asl
        asl
        asl
        ora #$08        ; Release = 8
        sta $d406
        
        rts

reverse_envelope:
        ; Simulate reverse sound
        
        ; Start with no attack, full sustain
        lda #$0f        ; Attack=0, Decay=15
        sta $d405
        lda #$f0        ; Sustain=15, Release=0
        sta $d406
        
        ; Gate on
        lda #$11
        sta $d404
        
        ; Gradually reduce sustain
        ldx #15
reverse_loop:
        txa
        asl
        asl
        asl
        asl
        ora #$00        ; Release=0
        sta $d406
        
        ; Wait
        ldy #10
rev_wait:
        lda #250
        cmp $d012
        bne *-3
        dey
        bne rev_wait
        
        dex
        bpl reverse_loop
        
        ; Gate off
        lda #$10
        sta $d404
        
        rts

; Effect variables
wah_position:     !byte 0
stutter_counter:  !byte 0
sweep_timer:      !byte 0
```

```text
Register Layout:
$D405: AAAADDDD (Attack/Decay)
$D406: SSSSRRRR (Sustain/Release)

Common Instruments:
Piano:    A=0 D=9 S=0 R=9
Organ:    A=2 D=0 S=F R=2
Strings:  A=9 D=4 S=C R=9
Brass:    A=6 D=6 S=9 R=6
Flute:    A=8 D=2 S=A R=6
Guitar:   A=0 D=2 S=8 R=6
Bass:     A=0 D=0 S=F R=9
Drums:    A=0 D=4 S=0 R=4

Envelope Tips:
- Fast attack (0-2) for percussive
- Slow attack (8-F) for pads/strings
- High sustain (C-F) for held notes
- Low sustain (0-4) for plucked
- Long release (8-F) for reverb
- Short release (0-4) for staccato

Effects:
Tremolo: Vary sustain level
Wah: Sweep decay rate
Stutter: Rapid gate on/off
Reverse: Start high, decay down

Best Practices:
- Match envelope to waveform
- Consider note duration
- Use velocity for expression
- Keep drums short
- Let pads breathe
```
