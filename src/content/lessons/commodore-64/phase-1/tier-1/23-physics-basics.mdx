# Physics Basics: Gravity and Realistic Motion
**Implement fundamental physics for natural game movement**

Physics simulation brings games to life. Objects should fall when dropped, accelerate as they fall, bounce when they hit the ground, and lose energy over time. These behaviors follow real-world physics laws that we can simulate with simple math. Understanding gravity, velocity, and acceleration lets you create movement that feels natural and satisfying.

## What You'll Learn

In this lesson, you'll discover:
- **Gravity simulation** - Constant downward acceleration
- **Velocity and acceleration** - How speed changes over time
- **Fixed-point math** - Handling fractional positions and speeds
- **Energy dampening** - Making bounces gradually decrease
- **Jump mechanics** - Creating satisfying player control
- **Collision response** - How objects react when they hit surfaces

## Understanding Gravity

Gravity constantly pulls objects down, accelerating them over time:

<CodeBlock title="Basic Gravity System" code={`; Physics constants (in 8.8 fixed point)
GRAVITY         = 20    ; Gravity acceleration (0.08 pixels/frame²)
TERMINAL_VEL    = $0400 ; Max fall speed (4 pixels/frame)
BOUNCE_DAMPING  = 200   ; Energy lost on bounce (78%)

; Ball physics variables (8.8 fixed point)
; High byte = pixel position, Low byte = fraction
ball_y_pos:     !word $3000  ; Y position (48 pixels)
ball_y_vel:     !word $0000  ; Y velocity
ball_x_pos:     !word $8000  ; X position (128 pixels)
ball_x_vel:     !word $0000  ; X velocity

; Apply gravity each frame
apply_gravity:
    ; Add gravity to Y velocity
    lda ball_y_vel
    clc
    adc #<GRAVITY
    sta ball_y_vel
    lda ball_y_vel+1
    adc #>GRAVITY
    sta ball_y_vel+1
    
    ; Cap at terminal velocity
    lda ball_y_vel+1
    cmp #>TERMINAL_VEL
    bcc gravity_done
    
    lda #<TERMINAL_VEL
    sta ball_y_vel
    lda #>TERMINAL_VEL
    sta ball_y_vel+1
    
gravity_done:
    rts

; Update position based on velocity
update_physics:
    ; Update Y position
    lda ball_y_pos
    clc
    adc ball_y_vel
    sta ball_y_pos
    lda ball_y_pos+1
    adc ball_y_vel+1
    sta ball_y_pos+1
    
    ; Update X position
    lda ball_x_pos
    clc
    adc ball_x_vel
    sta ball_x_pos
    lda ball_x_pos+1
    adc ball_x_vel+1
    sta ball_x_pos+1
    
    ; Convert to sprite coordinates
    lda ball_x_pos+1    ; High byte = pixel position
    sta $D000           ; Sprite 0 X
    lda ball_y_pos+1
    sta $D001           ; Sprite 0 Y
    
    rts`} language="asm" />

## Bouncing Mechanics

When the ball hits the ground, reverse its velocity with energy loss:

<CodeBlock title="Realistic Bounce Physics" code={`; Check for ground collision and bounce
check_bounce:
    ; Check if ball hit ground (Y > 220)
    lda ball_y_pos+1
    cmp #220
    bcc no_bounce
    
    ; Hit ground - bounce!
    ; Set position to ground level
    lda #220
    sta ball_y_pos+1
    lda #0
    sta ball_y_pos
    
    ; Reverse and dampen Y velocity
    ; First negate velocity
    lda #0
    sec
    sbc ball_y_vel
    sta ball_y_vel
    lda #0
    sbc ball_y_vel+1
    sta ball_y_vel+1
    
    ; Apply damping (multiply by 0.78)
    ; Approximate with 200/256
    lda ball_y_vel+1
    sta temp_hi
    lda ball_y_vel
    sta temp_lo
    
    ; Multiply by 200
    lda temp_lo
    ldx #200
    jsr multiply_8bit
    sta ball_y_vel
    stx ball_y_vel+1
    
    ; Divide by 256 (just use high byte)
    lda ball_y_vel+1
    sta ball_y_vel
    lda temp_hi
    
    ; Multiply high byte
    ldx #200
    jsr multiply_8bit
    clc
    adc ball_y_vel
    sta ball_y_vel
    txa
    sta ball_y_vel+1
    
    ; Bounce sound
    jsr bounce_sound
    
    ; Stop tiny bounces
    lda ball_y_vel+1
    cmp #$FF        ; Very small negative velocity
    bne no_bounce
    lda ball_y_vel
    cmp #$E0
    bcs stop_bounce
    jmp no_bounce
    
stop_bounce:
    ; Ball has stopped bouncing
    lda #0
    sta ball_y_vel
    sta ball_y_vel+1
    
no_bounce:
    rts

; Simple 8-bit multiply
multiply_8bit:
    ; A * X -> A (low), X (high)
    stx multiplier
    ldx #0
    stx product_hi
    
mult_loop:
    lsr multiplier
    bcc no_add
    clc
    adc product_hi
no_add:
    ror
    ror product_hi
    lda multiplier
    bne mult_loop
    
    lda product_hi
    ldx #0
    rts

temp_hi:        .byte 0
temp_lo:        .byte 0
multiplier:     .byte 0
product_hi:     .byte 0`} language="asm" />

## Jump Mechanics

Create satisfying jump arcs with initial velocity:

<CodeBlock title="Jumping System" code={`; Jump parameters
JUMP_VELOCITY   = $FB00  ; Initial jump speed (-5 pixels/frame)
DOUBLE_JUMP_VEL = $FD00  ; Double jump speed (-3 pixels/frame)
COYOTE_TIME     = 5      ; Frames can jump after leaving ground
JUMP_BUFFER     = 5      ; Frames to buffer jump input

; Jump state
on_ground:      .byte 1
can_jump:       .byte 1
coyote_timer:   .byte 0
jump_buffer:    .byte 0
double_jumped:  .byte 0

; Handle jump input
check_jump:
    ; Check fire button
    lda $DC00
    and #$10
    bne no_jump_pressed
    
    ; Button pressed - buffer it
    lda #JUMP_BUFFER
    sta jump_buffer
    
no_jump_pressed:
    ; Check if we can jump
    lda jump_buffer
    beq jump_done
    dec jump_buffer
    
    ; Check ground or coyote time
    lda on_ground
    bne do_jump
    
    lda coyote_timer
    beq check_double
    
do_jump:
    ; Perform jump
    lda #<JUMP_VELOCITY
    sta ball_y_vel
    lda #>JUMP_VELOCITY
    sta ball_y_vel+1
    
    ; Clear states
    lda #0
    sta on_ground
    sta coyote_timer
    sta jump_buffer
    sta double_jumped
    
    ; Jump sound
    jsr jump_sound
    jmp jump_done
    
check_double:
    ; Check for double jump
    lda can_jump
    beq jump_done
    lda double_jumped
    bne jump_done
    
    ; Perform double jump
    lda #<DOUBLE_JUMP_VEL
    sta ball_y_vel
    lda #>DOUBLE_JUMP_VEL
    sta ball_y_vel+1
    
    lda #1
    sta double_jumped
    lda #0
    sta jump_buffer
    
    ; Double jump sound
    jsr double_jump_sound
    
jump_done:
    rts

; Update ground state
update_ground_state:
    ; Check if on ground
    lda ball_y_pos+1
    cmp #220
    bne not_on_ground
    
    ; On ground
    lda #1
    sta on_ground
    sta can_jump
    lda #0
    sta double_jumped
    lda #COYOTE_TIME
    sta coyote_timer
    rts
    
not_on_ground:
    lda #0
    sta on_ground
    
    ; Update coyote time
    lda coyote_timer
    beq coyote_done
    dec coyote_timer
    
coyote_done:
    rts`} language="asm" />

read_input:
    lda $DC00

    bne check_right_input

    sec

    sta ball_x_vel
    lda ball_x_vel+1
    sbc #$00
    sta ball_x_vel+1
    
check_right_input:
    lda joy_state
    and #$08        ; Right
    bne check_up_input
    
    lda ball_x_vel
    clc
    adc #$20        ; Add right velocity
    sta ball_x_vel
    lda ball_x_vel+1
    adc #$00
    sta ball_x_vel+1
    
check_up_input:
    ; Up to jump
    lda joy_state
    and #$01
    bne check_fire_input
    jsr check_jump
    
check_fire_input:
    ; Fire to throw ball
    lda joy_state
    and #$10
    bne input_done
    
    ; Launch ball upward
    lda #$00
    sta ball_y_vel
    lda #$FA        ; Strong upward velocity
    sta ball_y_vel+1
    
    ; Random X velocity
    lda $D012
    and #$03
    sec
    sbc #$02
    sta ball_x_vel+1
    
input_done:
    rts

; Check screen boundaries
check_boundaries:
    ; Left boundary
    lda ball_x_pos+1
    cmp #24
    bcs check_right_bound
    
    ; Hit left wall
    lda #24
    sta ball_x_pos+1

    lda #0
    sec

    sta ball_x_vel

    sta ball_x_vel+1
    
check_right_bound:

    lda ball_x_pos+1

    lda ball_x_vel+1

    sta ball_x_vel+1
    bmi friction_done

    lda #0
    sta ball_x_vel
    sta ball_x_vel+1
    
friction_done:

check_platforms:

    cmp #152
    bcs check_plat2

    cmp #60
    bcc check_plat2
    cmp #100
    bcs check_plat2

    bmi check_plat2     ; Moving up

    sta ball_y_pos+1
    jsr bounce_on_platform

check_plat2:

    bcs platform_done

    cmp #180

### Network Physics for Neon Nexus

Apply physics concepts to create authentic network physics with momentum, gravity effects, and digital inertia.

<CodeBlock title="Network Physics System" language="asm" code={`; Network physics for cyberpunk environment
init_network_physics:
        lda #0
        sta data_momentum_x
        sta data_momentum_y
        sta network_gravity
        sta zone_resistance
        
        ; Different zones have different physics
        lda current_zone
        cmp #SECURE_ZONE
        beq setup_secure_physics
        cmp #DATA_STREAM_ZONE  
        beq setup_stream_physics
        
        ; Default zone physics
        lda #2
        sta network_gravity
        lda #1
        sta zone_resistance
        rts
        
setup_secure_zone_physics:
        ; Secure zones: normal physics
        lda #2
        sta network_gravity
        lda #1
        sta zone_resistance
        rts
        
setup_stream_physics:
        ; Data streams: reduced gravity, momentum carries
        lda #1
        sta network_gravity
        lda #0
        sta zone_resistance
        rts

update_network_physics:
        ; Apply network zone physics each frame
        
        ; Apply gravity in vertical data streams
        lda data_momentum_y
        clc
        adc network_gravity
        sta data_momentum_y
        
        ; Apply zone resistance
        lda zone_resistance
        beq skip_resistance
        
        ; Reduce momentum by resistance
        lda data_momentum_x
        beq check_y_resistance
        sec
        sbc zone_resistance
        bpl store_x_momentum
        lda #0
store_x_momentum:
        sta data_momentum_x
        
check_y_resistance:
        lda data_momentum_y
        beq skip_resistance
        sec
        sbc zone_resistance
        bpl store_y_momentum
        lda #0
store_y_momentum:
        sta data_momentum_y
        
skip_resistance:
        ; Apply momentum to position
        lda player_x
        clc
        adc data_momentum_x
        sta player_x
        
        lda player_y
        clc
        adc data_momentum_y
        sta player_y
        
        rts

enter_data_stream:
        ; Player enters a data stream - physics change
        lda #DATA_STREAM_ZONE
        sta current_zone
        
        ; Give initial stream momentum
        lda stream_direction
        cmp #HORIZONTAL_STREAM
        beq horizontal_boost
        
        ; Vertical stream
        lda #4
        sta data_momentum_y
        rts
        
horizontal_boost:
        lda #4
        sta data_momentum_x
        rts

; Network physics variables
data_momentum_x:    !byte 0
data_momentum_y:    !byte 0
network_gravity:    !byte 0
zone_resistance:    !byte 0
current_zone:       !byte 0
stream_direction:   !byte 0

; Zone constants
SECURE_ZONE         = 0
DATA_STREAM_ZONE    = 1
HORIZONTAL_STREAM   = 0
VERTICAL_STREAM     = 1`} />
