# Score and UI Systems: The Player's Window
**From functional to fantastic interfaces**

In 1984, "Impossible Mission" didn't just have a score - it had a complete computer terminal interface with animated readouts, countdown timers, and status displays that made you feel like a secret agent. "The Last Ninja" presented ornate oriental interfaces that transported you to ancient Japan. "IK+" displayed energy bars, round timers, and combo indicators worthy of any arcade fighter.

These games understood that the interface is part of the experience. Every number, every icon, every flash of color communicates with the player. A well-designed UI doesn't just show information - it creates atmosphere, builds tension, and provides satisfying feedback for every action.

This lesson reveals how to create professional game interfaces using the C64's character mode. You'll learn the secrets behind arcade-quality status displays, responsive feedback systems, and the mathematics that make scoring feel rewarding.

## The Psychology of Game Interfaces

Before we dive into code, consider what great C64 interfaces achieved psychologically:

- **"Defender"** - The scanner created spatial awareness of the entire battlefield
- **"Wizball"** - Color-coded interfaces that matched the game's chromatic theme
- **"Paradroid"** - Computer terminal aesthetics that reinforced the sci-fi setting
- **"Boulder Dash"** - Simple, clear displays that never distracted from the frantic action

Each interface was designed not just to inform, but to immerse. The best C64 UIs felt like part of the game world, not overlays on top of it.

## BCD: The Secret of Smooth Scoring

Binary Coded Decimal revolutionizes score handling. Instead of complex binary-to-decimal conversion, each digit is stored directly:

```asm
; Professional BCD score system
; Used by countless arcade and home games

; 8-digit score system (4 bytes) - supports up to 99,999,999 points
score:      .byte $00,$00,$00,$00  ; 00000000
hi_score:   .byte $00,$12,$34,$56  ; 00123456
temp_score: .byte $00,$00,$00,$00  ; Working copy

; The magic of BCD addition
; Add any amount to score with automatic decimal carry
add_score:
    ; Input: A = low byte of points to add
    ;        X = high byte of points to add
    
    sed             ; Enter decimal mode - crucial!
    
    ; Add to lowest byte
    clc
    adc score+3
    sta score+3
    
    ; Propagate carries through all bytes
    txa
    adc score+2
    sta score+2
    
    lda score+1
    adc #0          ; Add carry only
    sta score+1
    
    lda score+0
    adc #0          ; Add carry only
    sta score+0
    
    cld             ; Exit decimal mode - don't forget!
    
    ; Update display and check milestones
    jsr display_score
    jsr check_high_score
    jsr check_bonus_thresholds
    rts

; Add common point values efficiently
add_small_score:
    ; For values 0-99 (single byte BCD)
    pha
    lda #0
    tax
    pla
    jsr add_score
    rts

add_100_points:
    lda #$00
    ldx #$01        ; $01 in BCD = 100 in decimal
    jsr add_score
    rts

add_1000_points:
    lda #$00
    ldx #$10        ; $10 in BCD = 1000 in decimal  
    jsr add_score
    rts

add_5000_points:
    lda #$00
    ldx #$50        ; $50 in BCD = 5000 in decimal
    jsr add_score
    rts
```

The genius of BCD: `$12` in memory equals exactly 12 in decimal. No conversion needed for display!

## Professional Score Display

Create arcade-quality score presentations:

```asm
; Display system that rivals any arcade game
display_score:
    ; Position: "SCORE: 00,000,000" starting at screen position 2
    
    ; Draw label with style
    ldx #0
.label_loop:
    lda score_label,x
    beq .start_digits
    sta $0400+2,x
    lda #SCORE_LABEL_COLOR
    sta $d800+2,x
    inx
    jmp .label_loop
    
.start_digits:
    ; Display with comma separators for readability
    ; Format: XX,XXX,XXX
    
    ; Millions (first two digits)
    lda score+0
    jsr display_bcd_byte
    stx .temp_x
    
    ; Thousands separator comma
    lda #','
    sta $0400+11
    lda #COMMA_COLOR
    sta $d800+11
    
    ; Thousands (middle two digits)  
    ldx .temp_x
    lda score+1
    jsr display_bcd_byte
    stx .temp_x
    
    ; Hundreds separator comma
    lda #','
    sta $0400+15
    lda #COMMA_COLOR
    sta $d800+15
    
    ; Ones (last two digits)
    ldx .temp_x
    lda score+2
    jsr display_bcd_byte
    
    rts

display_bcd_byte:
    ; Display one BCD byte (2 digits) at screen position X
    ; Input: A = BCD byte, X = screen position
    
    pha
    
    ; High nibble (tens digit)
    lsr
    lsr
    lsr
    lsr
    clc
    adc #'0'        ; Convert to screen code
    sta $0400,x
    lda #SCORE_COLOR
    sta $d800,x
    inx
    
    ; Low nibble (ones digit)
    pla
    and #$0f
    clc
    adc #'0'
    sta $0400,x
    lda #SCORE_COLOR
    sta $d800,x
    inx
    
    rts

; Score display constants
SCORE_LABEL_COLOR = $0e  ; Light blue
SCORE_COLOR       = $01  ; White  
COMMA_COLOR       = $0c  ; Gray

score_label:
    .text "SCORE: "
    .byte 0
    
.temp_x: .byte 0
```

This creates the professional look of games like "Green Beret" and "Commando" - clear, readable, and impressive.

## Advanced High Score Detection

Proper high score comparison for multi-byte BCD:

```asm
; Compare two 4-byte BCD scores
; Returns: Carry set if current score > high score
compare_scores:
    ; Start from most significant byte
    lda score+0
    cmp hi_score+0
    bne .comparison_done
    
    ; First bytes equal, check second
    lda score+1
    cmp hi_score+1
    bne .comparison_done
    
    ; Second bytes equal, check third
    lda score+2
    cmp hi_score+2
    bne .comparison_done
    
    ; Third bytes equal, check fourth
    lda score+3
    cmp hi_score+3
    
.comparison_done:
    rts

check_high_score:
    jsr compare_scores
    bcc .not_high_score    ; Carry clear = score not higher
    
    ; New high score! Copy and celebrate
    ldx #3
.copy_loop:
    lda score,x
    sta hi_score,x
    dex
    bpl .copy_loop
    
    ; Trigger celebration sequence
    jsr new_high_score_fanfare
    
.not_high_score:
    rts

new_high_score_fanfare:
    ; Flash the high score display
    lda #HIGH_SCORE_FLASH_FRAMES
    sta flash_timer
    
    ; Play fanfare sound
    jsr play_high_score_music
    
    ; Show congratulations message
    lda #<msg_new_high_score
    ldy #>msg_new_high_score
    jsr show_popup_message
    
    rts

HIGH_SCORE_FLASH_FRAMES = 180  ; 3 seconds of flashing

msg_new_high_score:
    .text "*** NEW HIGH SCORE! ***"
    .byte 0
```

display_lives_hearts:

    bne .clear_remaining

    rts

    lsr
    lsr
    lsr

    rts

; Method 3: Mini-sprite icons (advanced)

    ; Use character combinations to create small player icons
    ldx #0
    ldy player_lives
    beq .no_lives_sprites
    
.sprite_loop:
    ; Two-character mini player sprite
    lda #MINI_SPRITE_TOP
    sta $0400+LIVES_SPRITE_POS,x
    lda #MINI_SPRITE_BOTTOM  
    sta $0400+LIVES_SPRITE_POS+40,x  ; Next row
    
    lda #SPRITE_COLOR
    sta $d800+LIVES_SPRITE_POS,x
    sta $d800+LIVES_SPRITE_POS+40,x
    
    inx
    inx                     ; Skip space between sprites
    dey
    bne .sprite_loop
    
.no_lives_sprites:
    rts

; Lives system constants
HEART_CHARACTER      = 140  ; Custom character
HEART_COLOR         = $02   ; Red

LIVES_LABEL_COLOR   = $0e   ; Light blue

## Precision Timer Systems

Professional countdown timers with proper formatting:

```asm
; Timer system supporting MM:SS.FF format (minutes:seconds.frames)
; Used in games like "Bomb Jack" and "Mr. Do!"

game_timer_min:    .byte $05  ; 5 minutes
game_timer_sec:    .byte $00  ; 00 seconds  
game_timer_frame:  .byte 60   ; 60 frames = 1 second
timer_warning:     .byte 0    ; Warning flag for low time

update_game_timer:
    ; Decrement frame counter
    dec game_timer_frame
    bne .timer_display
    
    ; Frame counter expired, reset and decrement seconds
    lda #60
    sta game_timer_frame
    
    ; Decrement seconds in BCD
    sed
    lda game_timer_sec
    sec
    sbc #$01
    sta game_timer_sec
    cld
    
    ; Check for seconds underflow
    cmp #$99                ; BCD underflow indicator
    bne .check_warning
    
    ; Seconds underflowed, borrow from minutes
    lda game_timer_min
    beq .time_expired
    
    sed
    sec
    sbc #$01
    sta game_timer_min
    cld
    
    lda #$59                ; Reset seconds to 59
    sta game_timer_sec
    
.check_warning:
    ; Activate warning when < 30 seconds left
    lda game_timer_min
    bne .timer_display
    lda game_timer_sec
    cmp #$30
    bcs .timer_display
    
    ; Activate warning
    lda #1
    sta timer_warning
    
.timer_display:
    jsr display_timer
    
    ; Handle warning effects
    lda timer_warning
    beq .timer_done
    jsr timer_warning_effects
    
.timer_done:
    rts

.time_expired:
    jsr handle_time_over
    rts

display_timer:
    ; Format: "TIME: 5:00" at screen position
    ldx #0
.timer_label_loop:
    lda timer_label,x
    sta $0400+TIMER_POSITION,x
    lda #TIMER_LABEL_COLOR
    sta $d800+TIMER_POSITION,x
    inx
    cpx #6
    bne .timer_label_loop
    
    ; Minutes digit
    lda game_timer_min
    and #$0f
    clc
    adc #'0'
    sta $0400+TIMER_POSITION+6
    
    ; Colon
    lda #':'
    sta $0400+TIMER_POSITION+7
    
    ; Seconds tens
    lda game_timer_sec
    lsr
    lsr
    lsr
    lsr
    clc
    adc #'0'
    sta $0400+TIMER_POSITION+8
    
    ; Seconds ones
    lda game_timer_sec
    and #$0f
    clc
    adc #'0'
    sta $0400+TIMER_POSITION+9
    
    ; Color based on time remaining
    lda timer_warning
    beq .normal_timer_color
    
    ; Flash red when warning active
    lda flash_counter
    lsr
    lsr
    and #1
    beq .warning_red
    lda #TIMER_NORMAL_COLOR
    jmp .set_timer_color
.warning_red:
    lda #TIMER_WARNING_COLOR
    jmp .set_timer_color
    
.normal_timer_color:
    lda #TIMER_NORMAL_COLOR
    
.set_timer_color:
    ldx #4                  ; Color 4 characters
.color_loop:
    sta $d800+TIMER_POSITION+6,x
    dex
    bpl .color_loop
    
    rts

timer_warning_effects:
    ; Sound beep every second when warning
    lda game_timer_frame
    cmp #30
    bne .no_beep
    jsr play_timer_warning_beep
.no_beep:
    
    ; Update flash counter for color pulsing
    inc flash_counter
    rts

; Timer constants
TIMER_POSITION       = 50   ; Screen position
TIMER_LABEL_COLOR   = $0e   ; Light blue
TIMER_NORMAL_COLOR  = $01   ; White
TIMER_WARNING_COLOR = $02   ; Red

timer_label:
    .text "TIME: "

flash_counter: .byte 0
```

This creates the professional timer displays seen in arcade games. The warning system builds tension as time runs low.

## Message and Notification System

Professional popup messages that don't interrupt gameplay:

```asm
; Advanced message system with queue support
MESSAGE_QUEUE_SIZE = 8
MESSAGE_DISPLAY_TIME = 120  ; 2 seconds

message_queue:     .res MESSAGE_QUEUE_SIZE * 2  ; Address storage
message_timers:    .res MESSAGE_QUEUE_SIZE      ; Timer per message
message_colors:    .res MESSAGE_QUEUE_SIZE      ; Color per message
queue_head:        .byte 0
queue_tail:        .byte 0
active_messages:   .byte 0

; Add message to queue
; Input: A/Y = message address, X = color
queue_message:
    ; Check if queue is full
    lda active_messages
    cmp #MESSAGE_QUEUE_SIZE
    bcs .queue_full
    
    ; Store message address
    ldy queue_tail
    sta message_queue,y
    sta message_queue+1,y
    
    ; Store color
    txa
    sta message_colors,y
    
    ; Set timer
    lda #MESSAGE_DISPLAY_TIME
    sta message_timers,y
    
    ; Advance tail pointer
    inc queue_tail
    lda queue_tail
    cmp #MESSAGE_QUEUE_SIZE
    bne .tail_ok
    lda #0
    sta queue_tail
.tail_ok:
    
    inc active_messages
    
.queue_full:
    rts

update_messages:
    ; Process all active messages
    lda active_messages
    beq .no_messages
    
    ldx queue_head
    ldy #0                  ; Message counter
    
.message_loop:
    ; Check if this message is active
    lda message_timers,x
    beq .next_message
    
    ; Decrement timer
    dec message_timers,x
    bne .draw_message
    
    ; Message expired, remove from queue
    dec active_messages
    
    ; Advance head pointer if this was the head
    cpx queue_head
    bne .next_message
    inc queue_head
    lda queue_head
    cmp #MESSAGE_QUEUE_SIZE
    bne .next_message
    lda #0
    sta queue_head
    
    jmp .next_message
    
.draw_message:
    ; Draw this message at appropriate position
    jsr draw_queue_message
    
.next_message:
    inx
    cpx #MESSAGE_QUEUE_SIZE
    bne .no_wrap
    ldx #0
.no_wrap:
    iny
    cpy active_messages
    bne .message_loop
    
.no_messages:
    rts

draw_queue_message:
    ; Draw message X at screen position based on Y
    ; Calculate screen position (messages stack vertically)
    tya
    asl
    asl
    asl                     ; * 8 for spacing
    clc
    adc #MESSAGE_START_ROW
    tax                     ; X = row
    
    ; Get message address
    txa
    pha
    ldx queue_head          ; Restore message index
    lda message_queue,x
    sta .temp_ptr
    lda message_queue+1,x
    sta .temp_ptr+1
    pla
    tax
    
    ; Draw centered message
    jsr draw_centered_text
    
    rts

draw_centered_text:
    ; Draw text centered on row X
    ; Text pointer in .temp_ptr
    
    ; Calculate starting column for centering
    jsr calculate_text_length
    lsr                     ; Length / 2
    sta .temp_length
    lda #20                 ; Screen center
    sec
    sbc .temp_length
    sta .start_col
    
    ; Calculate screen address
    txa                     ; Row in X
    jsr row_to_screen_address
    lda .start_col
    clc
    adc .screen_ptr
    sta .screen_ptr
    
    ; Draw the text
    ldy #0
.text_loop:
    lda (.temp_ptr),y
    beq .text_done
    sta (.screen_ptr),y
    
    ; Set color
    ldx queue_head          ; Get message color
    lda message_colors,x
    sta (.color_ptr),y
    
    iny
    bne .text_loop
    
.text_done:
    rts

; Combo system - builds score multipliers for consecutive actions
combo_count:        .byte 0     ; Current combo count
combo_timer:        .byte 0     ; Time until combo expires
combo_multiplier:   .byte 1     ; Current score multiplier
combo_flash:        .byte 0     ; Flash counter for visual feedback

COMBO_TIMEOUT     = 180        ; 3 seconds until combo expires
MAX_COMBO         = 10         ; Maximum combo count
COMBO_FLASH_SPEED = 8          ; Flash animation speed

update_combo_system:
    ; Decrement combo timer
    lda combo_timer
    beq .no_active_combo
    
    dec combo_timer
    bne .update_combo_display
    
    ; Combo expired - reset everything
    lda #0
    sta combo_count
    sta combo_multiplier
    lda #1
    sta combo_multiplier        ; Base multiplier is 1
    jsr clear_combo_display
    rts
    
.update_combo_display:
    ; Update flashing effect for active combo
    inc combo_flash
    lda combo_flash
    and #(COMBO_FLASH_SPEED-1)
    bne .no_flash_update
    
    ; Flash the combo display
    lda combo_count
    cmp #3                      ; Start flashing at 3+ combo
    bcc .display_combo
    
    ; Alternate between bright and normal colors
    lda combo_flash
    lsr
    lsr
    lsr
    and #1
    bne .flash_bright
    
    lda #$01                    ; Normal white
    jmp .set_combo_color
.flash_bright:
    lda #$07                    ; Bright yellow
.set_combo_color:
    sta combo_display_color
    
.display_combo:
    jsr display_combo
    
.no_flash_update:
.no_active_combo:
    rts

; Called when player performs a successful action
register_combo_action:
    ; Increment combo count
    inc combo_count
    lda combo_count
    cmp #MAX_COMBO
    bcc .combo_ok
    lda #MAX_COMBO
    sta combo_count
    
.combo_ok:
    ; Reset timer
    lda #COMBO_TIMEOUT
    sta combo_timer
    
    ; Calculate new multiplier (combo_count / 2, minimum 1)
    lda combo_count
    lsr                         ; Divide by 2
    clc
    adc #1                      ; Add 1 for base multiplier
    sta combo_multiplier
    
    ; Visual feedback based on combo level
    lda combo_count
    cmp #3
    bcc .small_combo
    cmp #6
    bcc .medium_combo
    cmp #9
    bcc .large_combo
    
    ; Massive combo (9+)
    lda #$0a                    ; Light red
    sta combo_display_color
    lda #<msg_amazing_combo
    ldy #>msg_amazing_combo
    ldx #$0a
    jsr queue_message
    jmp .combo_feedback_done
    
.large_combo:
    lda #$03                    ; Cyan  
    sta combo_display_color
    lda #<msg_great_combo
    ldy #>msg_great_combo
    ldx #$03
    jsr queue_message
    jmp .combo_feedback_done
    
.medium_combo:
    lda #$07                    ; Yellow
    sta combo_display_color
    lda #<msg_good_combo
    ldy #>msg_good_combo
    ldx #$07
    jsr queue_message
    jmp .combo_feedback_done
    
.small_combo:
    lda #$01                    ; White
    sta combo_display_color
    
.combo_feedback_done:
    jsr display_combo
    rts

; Called when player takes damage or fails
break_combo:
    ; Only break if we had a significant combo
    lda combo_count
    cmp #3
    bcc .reset_combo
    
    ; Show "combo broken" message
    lda #<msg_combo_broken
    ldy #>msg_combo_broken
    ldx #$02                    ; Red
    jsr queue_message
    
.reset_combo:
    lda #0
    sta combo_count
    sta combo_timer
    sta combo_flash
    lda #1
    sta combo_multiplier
    
    jsr clear_combo_display
    rts

display_combo:
    ; Only display if combo is active
    lda combo_count
    beq .no_display
    cmp #2
    bcc .no_display             ; Don't show until 2+ combo
    
    ; Display "COMBO x3" format at position
    ldx #0
.combo_label_loop:
    lda combo_label,x
    sta $0400+COMBO_POSITION,x
    lda combo_display_color
    sta $d800+COMBO_POSITION,x
    inx
    cpx #6                      ; "COMBO "
    bne .combo_label_loop
    
    ; Display multiplier
    lda combo_multiplier
    cmp #10
    bcc .single_digit
    
    ; Two digit multiplier
    lda #'1'
    sta $0400+COMBO_POSITION+6
    lda combo_multiplier
    sec
    sbc #10
    clc
    adc #'0'
    sta $0400+COMBO_POSITION+7
    
    lda combo_display_color
    sta $d800+COMBO_POSITION+6
    sta $d800+COMBO_POSITION+7
    jmp .display_x
    
.single_digit:
    lda combo_multiplier
    clc
    adc #'0'
    sta $0400+COMBO_POSITION+6
    lda combo_display_color
    sta $d800+COMBO_POSITION+6
    
.display_x:
    ; Display "x" suffix
    lda #'x'
    sta $0400+COMBO_POSITION+8
    lda combo_display_color
    sta $d800+COMBO_POSITION+8
    
.no_display:
    rts

clear_combo_display:
    ; Clear combo display area
    ldx #8                      ; "COMBO 00x" length
    lda #' '
.clear_loop:
    sta $0400+COMBO_POSITION,x
    dex
    bpl .clear_loop
    rts

; Apply combo multiplier to score
; Input: A = base points
apply_combo_score:
    sta .base_points
    
    ; Check if combo is active
    lda combo_multiplier
    cmp #2
    bcc .no_combo_bonus         ; No bonus for 1x multiplier
    
    ; Calculate bonus points (base * (multiplier - 1))
    tax                         ; X = multiplier
    dex                         ; X = multiplier - 1
    lda .base_points
    
.multiply_loop:
    cpx #0
    beq .bonus_calculated
    clc
    adc .base_points            ; Add base points again
    dex
    jmp .multiply_loop
    
.bonus_calculated:
    ; A now contains bonus points
    jsr add_small_score
    
.no_combo_bonus:
    ; Add base points
    lda .base_points
    jsr add_small_score
    rts

; Combo system constants and data
COMBO_POSITION = 70             ; Screen position for combo display

combo_label:
    .text "COMBO "
    
combo_display_color: .byte $01  ; Current combo color

msg_good_combo:
    .text "NICE!"
    .byte 0
    
msg_great_combo:
    .text "GREAT!"
    .byte 0
    
msg_amazing_combo:
    .text "AMAZING!"
    .byte 0
    
msg_combo_broken:
    .text "COMBO LOST"
    .byte 0

.base_points: .byte 0

; Message system constants
MESSAGE_START_ROW = 15      ; Where messages start appearing

; Working variables
.temp_ptr:     .word 0
.temp_length:  .byte 0
.start_col:    .byte 0
.screen_ptr:   .word 0
.color_ptr:    .word 0
```

## Animated UI Feedback

Make your interface respond to player actions:

```asm
; Score pulsing system - makes scoring feel impactful
score_pulse_timer:   .byte 0
score_pulse_phase:   .byte 0

trigger_score_pulse:
    ; Start a score pulse animation
    lda #SCORE_PULSE_DURATION
    sta score_pulse_timer
    rts

update_score_pulse:
    lda score_pulse_timer
    beq .no_pulse
    
    dec score_pulse_timer
    
    ; Calculate pulse intensity
    lda score_pulse_timer
    lsr
    lsr                     ; Divide by 4 for slower pulse
    and #3                  ; 0-3 range
    tax
    
    lda pulse_colors,x
    
    ; Apply to score digits
    ldx #SCORE_DIGIT_COUNT
.pulse_loop:
    sta $d800+SCORE_START_POS,x
    dex
    bpl .pulse_loop
    
.no_pulse:
    rts

; Screen shake effect for major events
shake_intensity:  .byte 0
shake_timer:     .byte 0

trigger_screen_shake:
    ; Input: A = intensity
    sta shake_intensity
    lda #SHAKE_DURATION
    sta shake_timer
    rts

update_screen_shake:
    lda shake_timer
    beq .no_shake
    
    dec shake_timer
    
    ; Apply random offset to scroll registers
    jsr get_random_byte
    and #$07                ; 0-7 range
    
    ; Reduce by intensity decay
    ldx shake_intensity
    beq .no_shake
    dec shake_intensity
    
    ; Apply to hardware scroll
    sta $d016               ; Horizontal shake
    
    jsr get_random_byte
    and #$07
    sta $d011               ; Vertical shake
    
    rts
    
.no_shake:
    ; Restore normal scroll
    lda #$08
    sta $d016
    lda #$1b
    sta $d011
    rts

; Level transition wipe effect
transition_column:  .byte 0
transition_active:  .byte 0

start_level_transition:
    lda #1
    sta transition_active
    lda #0
    sta transition_column
    rts

update_level_transition:
    lda transition_active
    beq .no_transition
    
    ; Fill columns from left to right
    ldx transition_column
    ldy #24                 ; Bottom to top
.fill_column:
    lda #TRANSITION_CHARACTER
    sta $0400,x
    lda #TRANSITION_COLOR
    sta $d800,x
    
    txa
    clc
    adc #40                 ; Next row
    tax
    dey
    bpl .fill_column
    
    ; Next column
    inc transition_column
    lda transition_column
    cmp #40
    bne .transition_continue
    
    ; Transition complete
    lda #0
    sta transition_active
    jsr load_next_level
    
.transition_continue:
.no_transition:
    rts

; Animation constants
SCORE_PULSE_DURATION = 32
SCORE_DIGIT_COUNT   = 10
SCORE_START_POS     = 8
SHAKE_DURATION      = 20
TRANSITION_CHARACTER = $a0
TRANSITION_COLOR    = $00

pulse_colors:
    .byte $01,$07,$0f,$07    ; White -> Yellow -> Light Gray -> Yellow
```

## Quick Reference

### BCD Operations
```asm
SED         ; Enable decimal mode
CLC         ; Clear carry for addition  
SEC         ; Set carry for subtraction
CLD         ; Disable decimal mode
```

### Status Bar Layout Tips
- Row 0: Primary info (Score, Lives)
- Row 1: Secondary info (Timer, Level)  
- Row 2: Separator line
- Keep critical info in consistent positions
- Use colors to indicate status (red=danger, green=good)

### Message System Patterns
- Queue messages to avoid overlap
- Center important messages
- Use timers for automatic dismissal
- Color-code message types
- Keep text concise (10-15 characters max)

### Visual Feedback Guidelines
- Pulse scores when they increase
- Flash warnings for attention
- Shake screen for major events
- Use transitions between states
- Make UI respond to every player action

Master UI design, and your games will feel professional and polished!
