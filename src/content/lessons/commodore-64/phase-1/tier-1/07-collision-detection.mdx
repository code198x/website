## Understanding Collision Detection

### The Foundation of Interactive Gaming

In 1980, collision detection was the breakthrough that separated simple animations from true games. While earlier programs could move graphics around the screen, they couldn't make those graphics meaningfully interact. The algorithms you'll learn today powered every classic game:

**Historic Implementations:**
- **"Pac-Man"** - Dot collection and ghost encounters
- **"Asteroids"** - Ship-asteroid and bullet-rock collisions
- **"Jumpman"** - Platform detection and enemy contact
- **"Impossible Mission"** - Elevator boarding and robot avoidance
- **"The Last Ninja"** - Combat system and object interaction

### Collision Detection Mathematics

The most common and efficient method is **bounding box collision** - treating each sprite as a rectangle and testing for overlap:

<CodeBlock title="Bounding Box Collision Theory" code={`Rectangle A overlaps Rectangle B if:
A.left < B.right AND
A.right > B.left AND  
A.top < B.bottom AND
A.bottom > B.top

For C64 sprites (24×21 pixels):
Sprite Width = 24 pixels
Sprite Height = 21 pixels`} />

### Professional Optimization

Real games don't check every sprite against every other sprite—that's inefficient. Professional techniques include:

<CodeBlock title="Collision Optimization Strategies" code={`1. Distance Pre-Check:
   Only test detailed collision if sprites are nearby

2. Type-Based Filtering:  
   Player bullets don't collide with other player bullets

3. Spatial Partitioning:
   Divide screen into regions, only check within regions

4. Frame Spreading:
   Check different collision pairs on different frames`} />

## Basic Collision Detection

### The Core Algorithm

<CodeBlock title="Fundamental Collision Detection Function" language="asm" code={`check_collision:
        ; Input: X = first sprite, Y = second sprite
        ; Output: Carry set if collision detected
        
        ; Get first sprite bounds
        lda sprite_x_pos,x
        sta temp_x1            ; Left edge
        clc
        adc #24                ; Add sprite width
        sta temp_x2            ; Right edge
        
        lda sprite_y_pos,x  
        sta temp_y1            ; Top edge
        clc
        adc #21                ; Add sprite height
        sta temp_y2            ; Bottom edge
        
        ; Get second sprite bounds
        lda sprite_x_pos,y
        sta temp_x3            ; Left edge
        clc
        adc #24
        sta temp_x4            ; Right edge
        
        lda sprite_y_pos,y
        sta temp_y3            ; Top edge
        clc
        adc #21
        sta temp_y4            ; Bottom edge
        
        ; Test overlap: temp_x1 < temp_x4 AND temp_x2 > temp_x3
        lda temp_x1
        cmp temp_x4
        bcs no_collision       ; temp_x1 >= temp_x4, no overlap
        
        lda temp_x2
        cmp temp_x3
        bcc no_collision       ; temp_x2 < temp_x3, no overlap
        
        ; Test Y overlap: temp_y1 < temp_y4 AND temp_y2 > temp_y3
        lda temp_y1
        cmp temp_y4
        bcs no_collision       ; temp_y1 >= temp_y4, no overlap
        
        lda temp_y2
        cmp temp_y3
        bcc no_collision       ; temp_y2 < temp_y3, no overlap
        
        ; Collision detected!
        sec                    ; Set carry flag
        rts
        
no_collision:
        clc                    ; Clear carry flag
        rts

; Temporary variables for collision calculations
temp_x1:    !byte 0
temp_x2:    !byte 0  
temp_x3:    !byte 0
temp_x4:    !byte 0
temp_y1:    !byte 0
temp_y2:    !byte 0
temp_y3:    !byte 0
temp_y4:    !byte 0`} />

### Efficient Collision Manager

<CodeBlock title="Professional Collision Management System" language="asm" code={`check_all_collisions:
        ; Check player against all other objects
        ldx #0                 ; Player is always sprite 0
        ldy #1                 ; Start with sprite 1
        
player_collision_loop:
        ; Skip inactive sprites
        lda sprite_active,y
        beq next_player_check
        
        ; Check collision between player and this sprite
        jsr check_collision
        bcc next_player_check  ; No collision
        
        ; Collision detected - handle based on object type
        lda sprite_type,y
        cmp #1
        beq handle_enemy_collision
        cmp #2  
        beq handle_collectible_collision
        cmp #3
        beq handle_obstacle_collision
        
next_player_check:
        iny
        cpy #8                 ; Check all sprites
        bne player_collision_loop
        
        ; Check projectiles against enemies
        jsr check_projectile_collisions
        rts

handle_enemy_collision:
        ; Player touched enemy - lose life or game over
        dec player_lives
        lda player_lives
        bne respawn_player
        
        ; Game over
        jmp game_over_sequence
        
respawn_player:
        ; Reset player to safe position
        lda #160
        sta sprite_x_pos       ; Center screen
        lda #200  
        sta sprite_y_pos       ; Bottom of screen
        
        ; Brief invincibility period
        lda #60                ; 60 frames = ~1 second
        sta invincibility_timer
        rts

handle_collectible_collision:  
        ; Player collected item
        lda #0
        sta sprite_active,y    ; Deactivate collectible
        
        ; Increase score
        sed                    ; Set decimal mode for BCD scoring
        clc
        lda score_low
        adc #$10               ; Add 10 points (BCD)
        sta score_low
        lda score_high
        adc #$00               ; Add carry
        sta score_high
        cld                    ; Clear decimal mode
        
        ; Check if all collectibles gathered
        jsr check_level_complete
        rts

handle_obstacle_collision:
        ; Solid obstacle - push player back
        ; Simple response: reverse last movement
        lda last_move_direction
        cmp #1                 ; Was moving up?
        bne check_down_reverse
        inc sprite_y_pos       ; Move back down
        inc sprite_y_pos
        rts
        
check_down_reverse:
        cmp #2                 ; Was moving down?
        bne check_left_reverse  
        dec sprite_y_pos       ; Move back up
        dec sprite_y_pos
        rts
        
check_left_reverse:
        cmp #3                 ; Was moving left?
        bne check_right_reverse
        inc sprite_x_pos       ; Move back right  
        inc sprite_x_pos
        rts
        
check_right_reverse:
        dec sprite_x_pos       ; Move back left
        dec sprite_x_pos
        rts`} />

## Advanced Collision Systems

### Projectile-Enemy Interactions

<CodeBlock title="Projectile Collision System" language="asm" code={`check_projectile_collisions:
        ldx #1                 ; Start with sprite 1 (skip player)
        
projectile_loop:
        ; Only check projectiles
        lda sprite_type,x
        cmp #3                 ; Type 3 = projectile
        bne next_projectile
        
        lda sprite_active,x
        beq next_projectile    ; Skip inactive projectiles
        
        ; Check this projectile against all enemies
        ldy #1                 ; Start with sprite 1
        
enemy_check_loop:
        cpy x                  ; Don't check projectile against itself
        beq next_enemy_check
        
        lda sprite_type,y
        cmp #1                 ; Type 1 = enemy
        bne next_enemy_check
        
        lda sprite_active,y
        beq next_enemy_check
        
        ; Check collision between projectile X and enemy Y
        jsr check_collision
        bcc next_enemy_check   ; No collision
        
        ; Hit! Destroy both projectile and enemy
        lda #0
        sta sprite_active,x    ; Deactivate projectile
        sta sprite_active,y    ; Deactivate enemy
        
        ; Add score for enemy destruction
        sed
        clc
        lda score_low
        adc #$50               ; 50 points for enemy (BCD)
        sta score_low
        lda score_high
        adc #$00
        sta score_high
        cld
        
        ; Create explosion effect (use a free sprite)
        jsr create_explosion_at_position
        
        rts                    ; Exit early - projectile destroyed
        
next_enemy_check:
        iny
        cpy #8
        bne enemy_check_loop
        
next_projectile:
        inx
        cpx #8
        bne projectile_loop
        rts`} />

### Smart Collision Response

<CodeBlock title="Context-Sensitive Collision Responses" language="asm" code={`create_explosion_at_position:
        ; Find free sprite for explosion effect
        ldx #6                 ; Start with sprite 6 (reserve 7 for special)
find_explosion_sprite:
        lda sprite_active,x
        beq found_explosion_sprite
        dex
        cpx #5                 ; Don't use player/projectile sprites
        bpl find_explosion_sprite
        rts                    ; No free sprite for explosion
        
found_explosion_sprite:
        ; Activate explosion sprite
        lda #1
        sta sprite_active,x
        lda #4                 ; Type 4 = explosion effect
        sta sprite_type,x
        
        ; Position at collision point
        lda temp_x1            ; Use collision calculation data
        clc
        adc #12                ; Center of collision area
        sta sprite_x_pos,x
        
        lda temp_y1
        clc  
        adc #10
        sta sprite_y_pos,x
        
        ; Set explosion timer
        lda #30                ; 30 frames = half second
        sta explosion_timer,x
        
        ; Set explosion color (bright white/yellow)
        lda #$01               ; White
        sta sprite_colors,x
        rts

update_explosions:
        ; Update all explosion effects
        ldx #8
explosion_update_loop:
        dex
        
        lda sprite_type,x
        cmp #4                 ; Type 4 = explosion
        bne explosion_update_continue
        
        lda sprite_active,x
        beq explosion_update_continue
        
        ; Count down explosion timer
        dec explosion_timer,x
        bne explosion_still_active
        
        ; Explosion finished
        lda #0
        sta sprite_active,x
        jmp explosion_update_continue
        
explosion_still_active:
        ; Animate explosion colors
        lda explosion_timer,x
        and #$07               ; Change color every 8 frames
        clc
        adc #$01               ; Cycle through colors 1-8
        sta sprite_colors,x
        
explosion_update_continue:
        cpx #0
        bne explosion_update_loop
        rts

; Explosion timer array
explosion_timer:
        !byte 0,0,0,0,0,0,0,0`} />

## Game State Management

### Level Completion Detection

<CodeBlock title="Win/Lose Condition Management" language="asm" code={`check_level_complete:
        ; Count remaining collectibles
        ldx #7
        ldy #0                 ; Collectible counter
        
count_collectibles:
        lda sprite_type,x
        cmp #2                 ; Type 2 = collectible
        bne not_collectible
        
        lda sprite_active,x
        beq not_collectible
        
        iny                    ; Count active collectible
        
not_collectible:
        dex
        bpl count_collectibles

        cpy #0
        bne level_not_complete
        
        ; Level complete!
        jmp level_victory_sequence
        
level_not_complete:
        rts

level_victory_sequence:
        ; Bonus points for time remaining
        sed
        clc
        lda score_low
        adc time_bonus_low
        sta score_low
        lda score_high
        adc time_bonus_high
        sta score_high

        inc current_level
        
        ; Reset game world for new level
        jsr init_next_level
        rts

game_over_sequence:
        ; Flash screen border
        lda #$02               ; Red border
        sta $d020
        
        ; Display game over message
        jsr display_game_over_text
        
        ; Wait for fire button to restart
        jmp wait_for_restart

; Game state variables
player_lives:       !byte 3
current_level:      !byte 1
score_low:          !byte 0

## Professional Optimization Techniques

### Distance Pre-Check

<CodeBlock title="Optimized Collision with Distance Check" language="asm" code={`fast_collision_check:
        ; Quick distance check before expensive bounding box test
        ; Input: X = sprite 1, Y = sprite 2
        
        ; Calculate rough distance (Manhattan distance)
        lda sprite_x_pos,x
        sec
        sbc sprite_x_pos,y
        bcs positive_x_diff
        eor #$ff               ; Make positive (approximate)
        adc #1
positive_x_diff:
        sta temp_x_diff
        
        lda sprite_y_pos,x
        sec  
        sbc sprite_y_pos,y
        bcs positive_y_diff
        eor #$ff               ; Make positive (approximate)
        adc #1
positive_y_diff:
        clc
        adc temp_x_diff        ; Manhattan distance
        
        cmp #48                ; 24+24 = max collision distance
        bcs definitely_no_collision
        
        ; Close enough - do full collision check
        jmp check_collision
        
definitely_no_collision:
        clc                    ; No collision
        rts

temp_x_diff: !byte 0`} />
