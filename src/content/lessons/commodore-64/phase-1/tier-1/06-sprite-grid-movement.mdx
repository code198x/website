## Grid to Pixel Conversion

Convert grid coordinates to screen position using multiplication:

<InteractiveExample
  title="Calculate Sprite Position"
  description="Convert grid to pixel coordinates"
>
```asm
grid_to_sprite_position:
        ; Convert grid X to sprite X
        ; sprite_x = GRID_START_X + (grid_x * GRID_CELL_WIDTH)
        lda grid_x
        asl                    ; × 2
        asl                    ; × 4
        asl                    ; × 8
        asl                    ; × 16
        asl                    ; × 32 (GRID_CELL_WIDTH)
        clc
        adc #GRID_START_X      ; Add screen offset
        sta sprite_x
        
        ; Convert grid Y to sprite Y (same process)
        lda grid_y
        asl                    ; × 2
        asl                    ; × 4
        asl                    ; × 8
        asl                    ; × 16
        asl                    ; × 32 (GRID_CELL_HEIGHT)
        clc
        adc #GRID_START_Y
        sta sprite_y
        
        rts
```
</InteractiveExample>

## Multiplication by Shifting

ASL (Arithmetic Shift Left) multiplies by 2:

<VisualConcept
  title="Bit Shifting for Multiplication"
  description="How ASL multiplies by 2"
>
```
Original value:  00000101 (5)
After 1 ASL:     00001010 (10)  × 2
After 2 ASLs:    00010100 (20)  × 4
After 3 ASLs:    00101000 (40)  × 8
After 4 ASLs:    01010000 (80)  × 16
After 5 ASLs:    10100000 (160) × 32

Grid position 5 → Pixel position 160
```

## Discrete Movement

Implement grid-based movement with boundary checking:

<InteractiveExample
  title="Grid Movement Logic"
  description="Move one grid cell at a time"
>
```asm
move_grid:
        ; Check Up
        lda joystick_state
        and #$01
        bne check_grid_down
        
        ; Move up one grid position
        lda grid_y
        beq check_grid_down    ; Already at top (Y=0)
        dec grid_y             ; Move up one cell
        jsr wait_for_release   ; Prevent continuous movement
        
check_grid_down:
        ; Check Down
        lda joystick_state
        and #$02
        bne check_grid_left
        
        ; Move down one grid position
        lda grid_y
        cmp #GRID_HEIGHT-1     ; Check if at bottom
        beq check_grid_left    ; Can't move down
        inc grid_y             ; Move down one cell
        jsr wait_for_release
```
</InteractiveExample>

## One-Move-Per-Press

Prevent continuous jumping with release detection:

<InteractiveExample
  title="Input Control"
  description="Wait for joystick release"
>
```asm
wait_for_release:
        ; Wait for joystick to return to center
        ; This prevents continuous movement
wait_loop:
        jsr read_joystick_only ; Just read hardware
        lda joystick_state
        and #$0f               ; Check all directions
        cmp #$0f               ; All bits high = centered
        bne wait_loop          ; Keep waiting if pressed
        rts
```
</InteractiveExample>

## Complete Game Loop

Put it all together for grid-based gameplay:

<InteractiveExample

game_loop:
        jsr read_joystick          ; Get input
        jsr move_grid              ; Update grid position
        jsr grid_to_sprite_position ; Convert to pixels
        jsr update_sprite_position ; Update hardware
        jsr display_current_position ; Show coordinates
        jsr wait_frame
        jmp game_loop

## Movement Characteristics

Grid movement has different properties than pixel movement:
- **Discrete**: Jumps between positions
- **Predictable**: Always lands on grid centers
- **Turn-Based Feel**: One move at a time
- **Clear Boundaries**: Can't partially leave grid
