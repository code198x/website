# Screen Colors: Borders, Backgrounds, and Atmosphere
**Set the mood and atmosphere of your game with color**

Every C64 game makes a statement the moment it loads. "The Last Ninja" greets you with dark, moody colors that promise mystery. "Bubble Bobble" explodes with bright pastels that scream fun. "Paradroid" uses stark contrasts that feel futuristic. These aren't accidents—they're deliberate choices using the C64's color registers to create atmosphere before a single sprite moves.

The C64 gives you control over three main color areas: the border ($D020), the background ($D021), and individual character colors. But the real magic happens when you change these during the screen refresh, creating the legendary "raster bars" that became the C64's signature effect. Today you'll master these color controls, from simple mood-setting to dynamic effects.

This is where your game develops its visual personality beyond just graphics—through the emotional language of color.

## What You'll Create

By lesson's end, you'll:

- Build atmospheric displays that set the mood

## Understanding C64 Color Control

### The Color Registers

The VIC-II chip provides simple but powerful color control:

<CodeBlock title="C64 Color Register Map" code={`Primary Color Registers:
$D020 - Border color (0-15)
$D021 - Background color 0 (0-15)
$D022 - Background color 1 (multicolor)
$D023 - Background color 2 (multicolor)
$D024 - Background color 3 (extended color)

The 16 C64 Colors:
$0 - Black        $8 - Orange
$1 - White        $9 - Brown
$2 - Red          $A - Light Red
$3 - Cyan         $B - Dark Gray
$4 - Purple       $C - Medium Gray
$5 - Green        $D - Light Green
$6 - Blue         $E - Light Blue
$7 - Yellow       $F - Light Gray

Special Properties:
- Border extends beyond display area
- Background shows through spaces
- Colors are shared system-wide
- Changes take effect immediately`} />

## Basic Color Control

<CodeBlock title="Simple Border and Background Control" language="asm" code={`; Basic color control demonstration
; Shows fundamental color register usage

        * = $0801
        !byte $0b,$08,$0a,$00,$9e,$32,$30,$36,$31,$00,$00,$00

        * = $080d
start:
        ; Clear screen first
        lda #147
        jsr $ffd2
        
        ; Set initial colors
        jsr set_game_colors
        
        ; Display color info
        jsr show_color_values
        
main_loop:
        ; Wait for key
        jsr $ffe4       ; GETIN
        beq main_loop
        
        ; Handle color changes
        cmp #'B'
        beq cycle_border
        cmp #'G'
        beq cycle_background
        cmp #'R'
        beq random_colors
        cmp #'T'
        beq theme_select
        cmp #'Q'
        beq exit
        
        jmp main_loop
        
exit:
        rts

set_game_colors:
        ; Set a pleasant color scheme
        lda #$06        ; Blue border
        sta $d020
        
        lda #$00        ; Black background
        sta $d021
        
        ; Multicolor backgrounds
        lda #$0b        ; Dark gray
        sta $d022
        
        lda #$0c        ; Medium gray
        sta $d023
        
        rts

cycle_border:
        ; Cycle through border colors
        inc $d020
        lda $d020
        and #$0f        ; Keep in range 0-15
        sta $d020
        jsr show_color_values
        jmp main_loop

cycle_background:
        ; Cycle through background colors
        inc $d021
        lda $d021
        and #$0f
        sta $d021
        jsr show_color_values
        jmp main_loop

random_colors:
        ; Random color combination
        jsr get_random
        and #$0f
        sta $d020
        
        jsr get_random
        and #$0f
        sta $d021
        
        jsr show_color_values
        jmp main_loop

get_random:
        ; Simple random number
        lda random_seed
        asl
        adc random_seed
        adc #$17
        sta random_seed
        rts

show_color_values:
        ; Display current colors
        ldx #5
        ldy #10
        jsr position_cursor
        
        ; Show border value
        ldx #0
border_text:
        lda border_label,x
        beq show_border_val
        jsr $ffd2
        inx
        bne border_text
        
show_border_val:
        lda $d020
        and #$0f
        cmp #10
        bcc border_digit
        
        ; Hex value A-F
        sec
        sbc #10
        clc
        adc #'A'
        jsr $ffd2
        jmp show_bg
        
border_digit:
        ora #$30
        jsr $ffd2
        
show_bg:
        ; Show background value
        lda #13         ; New line
        jsr $ffd2
        
        ldx #5
        ldy #11
        jsr position_cursor
        
        ldx #0
bg_text:
        lda bg_label,x
        beq show_bg_val
        jsr $ffd2
        inx
        bne bg_text
        
show_bg_val:
        lda $d021
        and #$0f
        cmp #10
        bcc bg_digit
        
        sec
        sbc #10
        clc
        adc #'A'
        jsr $ffd2
        rts
        
bg_digit:
        ora #$30
        jsr $ffd2
        rts

position_cursor:
        ; Position at X,Y
        lda #19         ; Home
        jsr $ffd2
        
        cpy #0
        beq pos_x
pos_y:  lda #17         ; Down
        jsr $ffd2
        dey
        bne pos_y
        
pos_x:  cpx #0
        beq pos_done
        lda #29         ; Right
        jsr $ffd2
        dex
        bne pos_x
pos_done:
        rts

; Data
border_label: !text "BORDER: "
              !byte 0
bg_label:     !text "BACKGROUND: "
              !byte 0
random_seed:  !byte $42`} />

## Color Themes

### Creating Atmospheric Color Schemes

<CodeBlock title="Thematic Color Schemes" language="asm" code={`theme_select:
        ; Cycle through predefined themes
        inc current_theme
        lda current_theme
        and #$07        ; 8 themes
        sta current_theme
        
        asl             ; × 2 for word index
        tax
        lda theme_table,x
        sta theme_ptr
        lda theme_table+1,x
        sta theme_ptr+1
        
        jmp (theme_ptr)

theme_space:
        ; Dark space theme
        lda #$00        ; Black border
        sta $d020
        lda #$00        ; Black background
        sta $d021
        lda #$06        ; Blue for multicolor
        sta $d022
        lda #$0e        ; Light blue
        sta $d023
        jsr display_theme_name
        !text "SPACE THEME",0
        jmp main_loop

theme_underwater:
        ; Underwater theme
        lda #$06        ; Blue border
        sta $d020
        lda #$0e        ; Light blue background
        sta $d021
        lda #$03        ; Cyan
        sta $d022
        lda #$05        ; Green (seaweed)
        sta $d023
        jsr display_theme_name
        !text "UNDERWATER",0
        jmp main_loop

theme_fire:
        ; Fire/lava theme
        lda #$02        ; Red border
        sta $d020

theme_forest:

        sta $d020

        sta $d021
        lda #$0d        ; Light green
        sta $d022
        lda #$09        ; Brown (tree trunks)
        sta $d023
        jsr display_theme_name
        !text "FOREST",0
        jmp main_loop

theme_ice:
        ; Ice/snow theme
        lda #$01        ; White border
        sta $d020
        lda #$0f        ; Light gray background
        sta $d021
        lda #$03        ; Cyan
        sta $d022
        lda #$0e        ; Light blue
        sta $d023
        jsr display_theme_name
        !text "ICE WORLD",0
        jmp main_loop

theme_desert:
        ; Desert theme
        lda #$07        ; Yellow border
        sta $d020
        lda #$08        ; Orange background
        sta $d021
        lda #$09        ; Brown
        sta $d022
        lda #$0a        ; Light red
        sta $d023
        jsr display_theme_name
        !text "DESERT",0
        jmp main_loop

theme_night:
        ; Night theme
        lda #$0b        ; Dark gray border
        sta $d020
        lda #$00        ; Black background
        sta $d021
        lda #$06        ; Blue (night sky)
        sta $d022
        lda #$01        ; White (stars)
        sta $d023
        jsr display_theme_name
        !text "NIGHT TIME",0
        jmp main_loop

theme_retro:
        ; Classic C64 theme
        lda #$0e        ; Light blue border
        sta $d020
        lda #$06        ; Blue background
        sta $d021
        lda #$01        ; White
        sta $d022
        lda #$0f        ; Light gray
        sta $d023
        jsr display_theme_name
        !text "CLASSIC C64",0
        jmp main_loop

display_theme_name:
        ; Display theme name
        ; Text follows JSR as null-terminated string
        
        ; Position cursor
        ldx #15
        ldy #5
        jsr position_cursor
        
        ; Get return address (points to text)
        pla
        sta text_ptr
        pla
        sta text_ptr+1
        
        ; Display text
        ldy #0
theme_char:
        inc text_ptr
        bne no_hi_inc
        inc text_ptr+1
no_hi_inc:
        lda (text_ptr),y
        beq theme_done
        jsr $ffd2
        jmp theme_char
        
theme_done:
        ; Return after text
        lda text_ptr+1
        pha
        lda text_ptr
        pha
        rts

; Theme data
current_theme: !byte 0
theme_ptr:     !word 0
text_ptr:      !word 0

theme_table:
        !word theme_space, theme_underwater
        !word theme_fire, theme_forest
        !word theme_ice, theme_desert
        !word theme_night, theme_retro`} />

## Raster Effects

### Simple Raster Bars

The C64's most famous effect - changing colors mid-screen:

<CodeBlock title="Basic Raster Bar Effect" language="asm" code={`create_raster_bars:
        ; Simple raster bar effect
        ; Changes border color at specific scan lines
        
raster_loop:
        ; Wait for top of screen
        lda #50
wait_50:
        cmp $d012
        bne wait_50
        
        ; First bar - red
        lda #$02
        sta $d020
        
        ; Wait for next position
        lda #100
wait_100:
        cmp $d012
        bne wait_100
        
        ; Second bar - yellow
        lda #$07
        sta $d020
        
        ; Wait for next position
        lda #150
wait_150:
        cmp $d012
        bne wait_150
        
        ; Third bar - green
        lda #$05
        sta $d020
        
        ; Wait for next position
        lda #200
wait_200:
        cmp $d012
        bne wait_200
        
        ; Fourth bar - blue
        lda #$06
        sta $d020
        
        ; Wait for bottom
        lda #250
wait_250:
        cmp $d012
        bne wait_250
        
        ; Reset to black
        lda #$00
        sta $d020
        
        ; Check for key
        jsr $ffe4
        beq raster_loop
        
        rts

; Smooth gradient raster bars
smooth_raster:
        ; Create smooth color gradient
        
        ldx #0
gradient_loop:
        ; Wait for raster line
        lda raster_positions,x
        beq gradient_done
wait_raster:
        cmp $d012
        bne wait_raster
        
        ; Set color
        lda raster_colors,x
        sta $d020
        
        ; Small delay for stability
        nop
        nop
        nop
        nop
        
        inx
        jmp gradient_loop
        
gradient_done:
        ; Reset and loop
        lda #$00
        sta $d020
        
        jsr $ffe4
        beq smooth_raster
        rts

; Gradient data
raster_positions:
        !byte 50,60,70,80,90,100,110,120
        !byte 130,140,150,160,170,180,190,200
        !byte 210,220,230,240,250
        !byte 0         ; End marker

raster_colors:
        !byte $00,$0b,$0c,$0f,$01,$01,$0f,$0c
        !byte $0b,$00,$00,$0b,$0c,$0f,$01,$01
        !byte $0f,$0c,$0b,$00,$00
        !byte 0`} />

## Dynamic Color Changes

### Color as Game Feedback

<CodeBlock title="Using Color for Game State" language="asm" code={`; Color changes for game events

flash_damage:
        ; Flash red when player takes damage
        
        lda $d020       ; Save current border
        sta saved_border
        lda $d021       ; Save current background
        sta saved_bg
        
        ; Flash sequence
        ldx #3          ; Number of flashes
flash_loop:
        lda #$02        ; Red
        sta $d020
        sta $d021
        
        ; Wait
        ldy #10
delay1: lda #250
wait1:  cmp $d012
        bne wait1
        dey
        bne delay1
        
        ; Original colors
        lda saved_border
        sta $d020
        lda saved_bg
        sta $d021
        
        ; Wait
        ldy #10
delay2: lda #250
wait2:  cmp $d012
        bne wait2
        dey
        bne delay2
        
        dex
        bne flash_loop
        
        rts

pulse_powerup:
        ; Pulse colors for power-up
        
        ldx #0
pulse_loop:
        lda pulse_table,x
        sta $d020
        
        ; Wait a bit
        ldy #4
pulse_wait:
        lda #250
pwait:  cmp $d012
        bne pwait
        dey
        bne pulse_wait
        
        inx
        cpx #16
        bne pulse_loop
        
        ; Restore normal
        lda #$06
        sta $d020
        rts

warning_flash:
        ; Flash for low time/health warning
        
        lda flash_counter
        and #$0f
        
        cmp #$08
        bcc normal_color
        
        ; Warning color
        lda #$0a        ; Light red
        sta $d020
        jmp flash_done
        
normal_color:
        lda #$06        ; Normal blue
        sta $d020
        
flash_done:
        inc flash_counter
        rts

level_transition:
        ; Smooth transition between levels
        
        ldx #0
fade_out:
        lda fade_table,x
        sta $d020
        sta $d021
        
        ; Delay
        ldy #8
fade_delay:
        lda #250
fwait:  cmp $d012
        bne fwait
        dey
        bne fade_delay
        
        inx
        cpx #8
        bne fade_out
        
        ; Change to new level colors
        jsr load_level_colors
        
        ; Fade in
        ldx #7
fade_in:
        lda fade_table,x
        sta $d020
        sta $d021
        
        ; Delay
        ldy #8
fade_delay2:
        lda #250
fwait2: cmp $d012
        bne fwait2
        dey
        bne fade_delay2
        
        dex
        bpl fade_in
        
        rts

; Effect data
saved_border:  !byte 0
saved_bg:      !byte 0
flash_counter: !byte 0

pulse_table:
        !byte $06,$0e,$03,$01,$01,$03,$0e,$06
        !byte $06,$0e,$03,$01,$01,$03,$0e,$06

fade_table:
        !byte $06,$0e,$03,$0f,$0c,$0b,$00,$00`} />

## Screen Modes and Colors

### Extended Color Mode

<CodeBlock title="Using Extended Background Colors" language="asm" code={`setup_extended_color:
        ; Enable extended color mode
        ; Gives 4 background colors but only 64 characters
        
        lda $d011
        ora #$40        ; Set ECM bit
        sta $d011
        
        ; Set up 4 background colors
        lda #$00        ; Black
        sta $d021       ; Background 0
        
        lda #$06        ; Blue
        sta $d022       ; Background 1
        
        lda #$05        ; Green
        sta $d023       ; Background 2
        
        lda #$02        ; Red
        sta $d024       ; Background 3
        
        ; Characters 0-63: use bg 0
        ; Characters 64-127: use bg 1
        ; Characters 128-191: use bg 2
        ; Characters 192-255: use bg 3
        
        ; Demo: show all backgrounds
        lda #'A'        ; Uses bg 0 (black)
        sta $0400
        
        lda #'A'+64     ; Uses bg 1 (blue)
        sta $0401
        
        lda #'A'+128    ; Uses bg 2 (green)
        sta $0402
        
        lda #'A'+192    ; Uses bg 3 (red)
        sta $0403
        
        rts

disable_extended_color:
        ; Return to normal mode
        lda $d011
        and #$bf        ; Clear ECM bit
        sta $d011
        rts`} />
