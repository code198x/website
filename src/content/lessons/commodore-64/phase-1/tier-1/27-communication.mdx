# Communication and Networking

In 1982, the idea of home computers talking to each other seemed like science fiction. But the C64 came equipped with not one, but multiple communication ports. Visionaries saw the potential immediately - bulletin board systems (BBSes), online services like CompuServe and QuantumLink (which became AOL), and even early multiplayer games.

Today, you'll learn how to make C64s communicate - the same techniques that created the first online communities and multiplayer experiences.

## The Dawn of Connected Computing

The C64's user port wasn't just for joysticks - it was a gateway to the connected world. With simple cables and clever programming, C64 users were sending messages across phone lines, downloading software, and playing games together years before the internet went mainstream.

## User Port Serial Communication

The user port provides direct access to data lines that can be programmed for serial communication. This is the foundation of all C64 networking:

```asm
; User port serial communication
; Pin 2 = Data out, Pin 3 = Data in
init_serial:
    lda #$FF        ; Set data direction
    sta $DD03       ; User port DDR
    rts

send_byte:
    ; A = byte to send
    sta send_data
    ldx #8          ; 8 bits
send_bit:
    lsr send_data
    bcc send_zero
    
    lda #$04        ; Set bit 2
    jmp set_bit
send_zero:
    lda #$00
set_bit:
    sta $DD01       ; User port
    
    ; Delay for baud rate
    jsr delay_baud
    
    dex
    bne send_bit
    rts

receive_byte:
    ldx #8
    lda #0
    sta recv_data
recv_bit:
    lda $DD01       ; Read user port
    and #$08        ; Check bit 3
    beq got_zero
    
    sec
    jmp shift_bit
got_zero:
    clc
shift_bit:
    ror recv_data
    
    jsr delay_baud
    
    dex
    bne recv_bit
    
    lda recv_data
    rts

send_data: .byte 0
recv_data: .byte 0
```

## Making History with Serial Links

This simple serial communication was the foundation of incredible achievements. "Netrek" used similar techniques for network play. Early BBS door games like "Trade Wars" relied on serial protocols. Even the famous "MIDI Maze" on Atari ST (which inspired modern FPS networking) used these same principles.

The baud rate timing you implement here is the same concept that governed all modem communications. Every online service, every downloaded file, every multiplayer game of the 1980s relied on precisely timed serial bits, just like the code above.

## Building Connected Worlds

With these techniques, C64 programmers created:
- **Modem terminal programs** that connected to BBSes worldwide
- **File transfer protocols** that moved data reliably over noisy phone lines  
- **Multiplayer games** where players competed in real-time
- **Chat systems** that predated modern instant messaging by decades

The C64's communication capabilities helped create the first online communities. Users weren't just playing games - they were pioneering digital communication, creating the foundations of our connected world.

Simple serial communication, implemented byte by byte, bit by bit - but it connected the world!
