# Number Display: Scores, Lives, and Timers
**The foundation of every game's user interface**

Every game displays numbers. The score at the top. Lives remaining in the corner. Time ticking down. High scores that players strive to beat. Yet the 6502 processor doesn't understand decimal—it works in binary. Converting those binary values into readable digits on screen is a fundamental skill that appears in every C64 game ever made.

"Pac-Man" needed to show scores up to 999,990. "Defender" displayed scores in the millions. "Boulder Dash" counted down time from 999 seconds. "Elite" showed your credits in a formatted display. They all faced the same challenge: how do you efficiently convert a 16-bit binary number into individual decimal digits for display? Today you'll master multiple techniques, from simple to optimized.

This is where your game gains its competitive element—the numbers that drive players to achieve "just one more point."

## What You'll Create

By lesson's end, you'll:
- Display scores from 0 to 9,999,999
- Show lives and level numbers
- Create countdown timers
- Format numbers with leading zeros or spaces
- Update displays efficiently without flicker

## Binary to Decimal Conversion

### The Division Method

The classic approach uses repeated division by 10:

<CodeBlock title="Basic Binary to Decimal Conversion" language="asm" code={`; Convert 16-bit binary to decimal digits
; The fundamental technique used everywhere

        * = $0801
        !byte $0b,$08,$0a,$00,$9e,$32,$30,$36,$31,$00,$00,$00

        * = $080d
start:
        ; Clear screen
        lda #147
        jsr $ffd2
        
        ; Set up test score
        lda #<12345    ; Low byte
        sta score_lo
        lda #>12345    ; High byte  
        sta score_hi
        
        ; Convert and display
        jsr convert_score
        jsr display_score
        
        ; Show different examples
        jsr display_examples
        
endless:
        jmp endless

convert_score:
        ; Convert 16-bit score to 5 decimal digits
        ; Uses repeated division by 10
        
        ; Clear digit buffer
        ldx #4
clear_digits:
        lda #0
        sta digit_buffer,x
        dex
        bpl clear_digits
        
        ; Start conversion
        lda score_lo
        sta temp_lo
        lda score_hi
        sta temp_hi
        
        ; Extract digits from right to left
        ldx #0          ; Digit position
        
extract_loop:
        ; Divide by 10
        ldy #16         ; 16 bits
        lda #0
        sta remainder
        
div_loop:
        asl temp_lo
        rol temp_hi
        rol remainder
        
        lda remainder
        sec
        sbc #10
        bcc div_skip
        sta remainder
        inc temp_lo
        
div_skip:
        dey
        bne div_loop
        
        ; Store digit
        lda remainder
        sta digit_buffer,x
        
        ; Check if more digits
        inx
        cpx #5
        beq done_convert
        
        lda temp_lo
        ora temp_hi
        bne extract_loop
        
done_convert:
        rts

display_score:
        ; Display the converted digits
        
        ; Position cursor
        ldx #10
        ldy #5
        jsr position_cursor
        
        ; Display "SCORE: "
        ldx #0
score_label:
        lda score_text,x
        beq show_digits
        jsr $ffd2
        inx
        bne score_label
        
show_digits:
        ; Display digits (reversed order)
        ldx #4
digit_loop:
        lda digit_buffer,x
        ora #$30        ; Convert to ASCII
        jsr $ffd2
        dex
        bpl digit_loop
        
        rts

position_cursor:
        ; Position at X,Y
        lda #19         ; Home
        jsr $ffd2
        
        ; Move down Y times
        cpy #0
        beq pos_x
pos_y:  lda #17         ; Down
        jsr $ffd2
        dey
        bne pos_y
        
        ; Move right X times
pos_x:  cpx #0
        beq pos_done
        lda #29         ; Right
        jsr $ffd2
        dex
        bne pos_x
pos_done:
        rts

; Data
score_lo:     !byte 0
score_hi:     !byte 0
temp_lo:      !byte 0
temp_hi:      !byte 0
remainder:    !byte 0
digit_buffer: !byte 0,0,0,0,0

score_text:   !text "SCORE: "
              !byte 0`} />

### Optimized Subtraction Method

For better performance, use successive subtraction:

<CodeBlock title="Fast Conversion Using Subtraction" language="asm" code={`fast_convert:
        ; Faster method using subtraction tables
        ; No division required!
        
        ; Clear all digits
        ldx #5
        lda #0
clear_fast:
        sta digits,x
        dex
        bpl clear_fast
        
        ; Convert using subtraction
        lda score_lo
        sta work_lo
        lda score_hi
        sta work_hi
        
        ; Ten thousands (10000)
conv_10000:
        lda work_lo
        sec
        sbc #<10000
        sta temp_lo
        lda work_hi
        sbc #>10000
        bcc conv_1000   ; If negative, done with 10000s
        
        sta work_hi     ; Store result
        lda temp_lo
        sta work_lo
        inc digits+4    ; Increment 10000s digit
        jmp conv_10000
        
        ; Thousands (1000)
conv_1000:
        lda work_lo
        sec
        sbc #<1000
        sta temp_lo
        lda work_hi
        sbc #>1000
        bcc conv_100
        
        sta work_hi
        lda temp_lo
        sta work_lo
        inc digits+3
        jmp conv_1000
        
        ; Hundreds (100)
conv_100:
        lda work_lo
        sec
        sbc #100
        bcc conv_10
        sta work_lo
        inc digits+2
        jmp conv_100
        
        ; Tens (10)
conv_10:
        lda work_lo
        sec
        sbc #10
        bcc conv_1
        sta work_lo
        inc digits+1
        jmp conv_10
        
        ; Ones (1)
conv_1:
        lda work_lo
        sta digits+0
        rts

; Working variables
work_lo:  !byte 0
work_hi:  !byte 0
digits:   !byte 0,0,0,0,0,0`} />

## Formatting Numbers

### Leading Zeros vs Spaces

Professional games format numbers consistently:

<CodeBlock title="Number Formatting Options" language="asm" code={`format_with_zeros:
        ; Display score with leading zeros
        ; "007500" style (like arcade games)
        
        ldx #5          ; 6 digits
show_zeros:
        lda digits,x
        ora #$30        ; To ASCII
        jsr $ffd2
        dex
        bpl show_zeros
        rts

format_with_spaces:
        ; Display with leading spaces
        ; "  7500" style (like home computer games)
        
        ldx #5
        ldy #0          ; Leading zero flag
        
show_spaces:
        lda digits,x
        bne found_digit ; Non-zero digit
        
        cpy #0          ; Have we found a digit yet?
        bne show_digit  ; Yes, show zero
        
        ; Show space instead
        lda #32         ; Space
        jsr $ffd2
        jmp next_digit
        
found_digit:
        ldy #1          ; Set flag
show_digit:
        ora #$30        ; To ASCII
        jsr $ffd2
        
next_digit:
        dex
        bpl show_spaces
        
        ; Always show at least one zero
        cpy #0
        bne format_done
        lda #$30        ; '0'
        jsr $ffd2
format_done:
        rts

format_with_commas:
        ; Display with thousands separators
        ; "1,234,567" style
        
        ldx #6          ; Start with millions
        ldy #0          ; Digit counter
        
comma_loop:
        ; Check for comma position
        cpy #3
        bne no_comma1
        lda #','
        jsr $ffd2
        ldy #0
        
no_comma1:
        cpy #6
        bne no_comma2
        lda #','
        jsr $ffd2
        ldy #0
        
no_comma2:
        lda digits,x
        ora #$30
        jsr $ffd2
        iny
        dex
        bpl comma_loop
        rts`} />

### Fixed-Width Display

Keep scores aligned in columns:

<CodeBlock title="Fixed-Width Number Display" language="asm" code={`display_fixed_width:
        ; Always uses exactly 8 characters
        ; Right-aligned with padding
        
        ; Calculate padding needed
        jsr count_digits
        lda #8
        sec
        sbc digit_count
        tax             ; X = spaces needed
        
        ; Print leading spaces
        beq no_padding
pad_loop:
        lda #32
        jsr $ffd2
        dex
        bne pad_loop
        
no_padding:
        ; Print the number
        jsr format_with_spaces
        rts

count_digits:
        ; Count significant digits
        ldx #5
        ldy #0
count_loop:
        lda digits,x
        bne found_first
        dex
        bpl count_loop
        
        ; All zeros - return 1
        ldy #1
        sty digit_count
        rts
        
found_first:
        ; X = highest digit position
        inx
        stx digit_count
        rts

digit_count: !byte 0`} />

## Efficient Updates

### Differential Updates

Only update changed digits:

<CodeBlock title="Efficient Score Updates" language="asm" code={`update_score_display:
        ; Only update digits that changed
        ; Prevents flicker and saves cycles
        
        ; Compare with previous display
        ldx #5
compare_loop:
        lda digits,x
        cmp old_digits,x
        bne digit_changed
        dex
        bpl compare_loop
        rts             ; Nothing changed
        
digit_changed:
        ; Update from this digit leftward
        stx first_changed
        
        ; Position cursor at changed digit
        lda #8          ; Score X position
        clc
        adc #5          ; Right side
        sec
        sbc first_changed
        tax
        ldy #0          ; Score Y position
        jsr position_cursor
        
        ; Update changed digits
        ldx first_changed
update_loop:
        lda digits,x
        sta old_digits,x
        ora #$30
        jsr $ffd2
        dex
        bpl update_loop
        
        rts

first_changed: !byte 0
old_digits:    !byte 0,0,0,0,0,0

; Direct screen memory update (faster)
fast_score_update:
        ; Write directly to screen RAM
        ; No KERNAL overhead
        
        ldx #5
        ldy #5          ; Screen position offset
        
direct_loop:
        lda digits,x
        ora #$30        ; To PETSCII
        sta $0400,y     ; Screen RAM
        lda #1          ; White
        sta $d800,y     ; Color RAM
        dey
        dex
        bpl direct_loop
        rts`} />

## Special Number Types

### Timer Display

Show time in minutes:seconds format:

<CodeBlock title="Timer and Clock Display" language="asm" code={`display_timer:
        ; Convert seconds to MM:SS format
        ; Input: timer_seconds (16-bit)
        
        ; Calculate minutes
        lda timer_seconds_lo
        sta temp_lo
        lda timer_seconds_hi
        sta temp_hi
        
        lda #0
        sta minutes
        
calc_minutes:
        lda temp_lo
        sec
        sbc #60
        sta work_lo
        lda temp_hi
        sbc #0
        bcc got_minutes
        
        sta temp_hi
        lda work_lo
        sta temp_lo
        inc minutes
        jmp calc_minutes
        
got_minutes:
        ; temp_lo now has seconds
        lda temp_lo
        sta seconds
        
        ; Display minutes (2 digits)
        lda minutes
        lsr
        lsr
        lsr
        lsr             ; Tens
        ora #$30
        jsr $ffd2
        
        lda minutes
        and #$0f        ; Ones
        ora #$30
        jsr $ffd2
        
        ; Display colon
        lda #':'
        jsr $ffd2
        
        ; Display seconds (2 digits)
        lda seconds
        jsr display_two_digits
        rts

display_two_digits:
        ; Display A as 2 decimal digits
        ldx #0
        sec
tens_loop:
        sbc #10
        bcc show_tens
        inx
        bne tens_loop
        
show_tens:
        adc #10         ; Restore ones
        pha             ; Save ones
        txa             ; Tens
        ora #$30
        jsr $ffd2
        pla             ; Restore ones
        ora #$30
        jsr $ffd2
        rts

timer_seconds_lo: !byte 0
timer_seconds_hi: !byte 0
minutes:          !byte 0
seconds:          !byte 0`} />

no_lives:

        ldy #0
        jsr position_cursor
