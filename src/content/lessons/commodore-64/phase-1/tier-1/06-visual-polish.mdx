## Color Scheme Design

Professional games use cohesive color palettes that create visual hierarchy and guide the player's eye:

<InteractiveExample
  title="Color Constants"
  description="Define a professional color scheme"
>
```asm
; Color scheme constants
COLOR_BORDER = $00             ; Black border
COLOR_BACKGROUND = $0B         ; Dark gray background
COLOR_GRID_BG = $0C            ; Medium gray for grid area
COLOR_UI_TEXT = $01            ; White text
COLOR_TITLE = $07              ; Yellow title
COLOR_GRID_LINES = $0F         ; Light gray grid lines
COLOR_PLAYER = $07             ; Yellow player sprite

setup_color_scheme:
        ; Set border color
        lda #COLOR_BORDER
        sta $d020              ; VIC-II border color register
        
        ; Set background color
        lda #COLOR_BACKGROUND
        sta $d021              ; VIC-II background color register
        
        rts
```
</InteractiveExample>

## Drawing Borders

Borders frame your game and create focus. We use PETSCII's reversed space character:

<InteractiveExample
  title="Border Drawing"
  description="Create screen borders with PETSCII characters"
>
```asm
draw_borders:
        ; Draw top border (row 0)
        ldx #0
draw_top:
        lda #$A0               ; Reversed space character
        sta $0400,x            ; Screen memory row 0
        lda #COLOR_GRID_LINES
        sta $d800,x            ; Color memory row 0
        inx
        cpx #40
        bne draw_top
        
        ; Draw side borders
        ldx #1                 ; Start from row 1
draw_sides:
        ; Calculate row offset = X * 40
        txa
        pha                    ; Save X
        lda #40
        jsr multiply_x_by_a    ; Result in A
        tay                    ; Y = row offset
        
        ; Draw left border
        lda #$A0               ; Reversed space
        sta $0400,y            ; Screen memory
        lda #COLOR_GRID_LINES
        sta $d800,y            ; Color memory
        
        ; Draw right border (add 39 to position)
        tya
        clc
        adc #39
        tay
        lda #$A0               ; Reversed space
        sta $0400,y            ; Screen memory
        lda #COLOR_GRID_LINES
        sta $d800,y            ; Color memory
        
        pla                    ; Restore X
        tax
        inx
        cpx #24                ; Stop before bottom border
        bne draw_sides
```
</InteractiveExample>

## Grid Visualization

Subtle grid lines help players understand movement constraints:

<InteractiveExample
  title="Grid Background"
  description="Create visual grid with PETSCII line characters"
>
```asm
draw_grid_lines:
        ; Draw horizontal grid lines (every 4 characters)
        ldx #12                ; First line at row 12
h_grid_line_loop:
        ldy #4                 ; Start column
h_grid_col_loop:
        ; Calculate position
        txa
        pha
        lda #40
        jsr multiply_x_by_a
        sty temp_y
        clc
        adc temp_y
        tay
        
        ; Draw line character
        lda #$40               ; Horizontal line
        sta $0400,y
        lda #COLOR_GRID_LINES
        sta $d800,y
        
        ldy temp_y
        iny
        cpy #36
        bne h_grid_col_loop
```
</InteractiveExample>

## UI Text Display

Clear, well-positioned text provides essential information:

<InteractiveExample
  title="UI Elements"
  description="Display game title and instructions"
>
```asm
display_ui:
        ; Display game title with color
        ldx #0
display_title:
        lda title_text,x
        beq title_done
        sta $0400 + 40*2 + 11,x    ; Centered on row 2
        lda #COLOR_TITLE           ; Yellow title
        sta $d800 + 40*2 + 11,x
        inx
        jmp display_title
title_done:

; Title text data (PETSCII values)
title_text:
        !byte 16,9,24,5,12,32,16,1,20,18,15,12  ; "PIXEL PATROL"
        !byte 0                                   ; Null terminator
```
</InteractiveExample>

## PETSCII Graphics Characters

```
$A0 = █ (Reversed space - solid block)
$40 = ─ (Horizontal line)
$5D = │ (Vertical line)
$5B = ┼ (Cross/intersection)
$55 = ╔ (Top-left corner)
$49 = ╗ (Top-right corner)
$4A = ╚ (Bottom-left corner)
$4B = ╝ (Bottom-right corner)
```

## Screen Memory Organization

Understanding C64 screen layout is crucial for UI work:

<MemoryMapC64
  highlight={[
    { start: 0x0400, end: 0x07E7, label: "Screen Memory (1000 bytes)" },
    { start: 0xD800, end: 0xDBE7, label: "Color Memory (1000 bytes)" }

Each screen position requires two bytes:
- **Screen Memory**: Character code (what to display)
- **Color Memory**: Character color

## Visual Hierarchy

Good UI design guides the player's attention:

1. **Brightest = Most Important**: Title in yellow
2. **Medium = Active Areas**: White text for instructions
3. **Dim = Background**: Gray for grid and borders
4. **Consistent Spacing**: Aligned elements look professional

## Performance Considerations

- **Draw Once**: Static UI elements drawn at startup
- **Efficient Loops**: Optimized border drawing
- **Direct Addressing**: Fast screen/color updates
- **Minimal Overdraw**: Only update changing elements
