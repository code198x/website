## Your Electronic Pulse Awakens

Let's start with the magic - adding electronic music and pulsing effects to your neon world:

```nasm
; Neon Nexus - Electronic Pulse Creation
* = $0801
        .byte $0b,$08,$0a,$00,$9e,$32,$30,$36,$31,$00,$00,$00

start:
    ; Set up your neon grid world from Lessons 1-2
    lda #$93        ; Clear screen
    jsr $ffd2       ; CHROUT
    
    ; Draw neon grid foundation
    lda #$2d        ; Horizontal line character
    sta $0400       ; Top grid line
    sta $0401
    sta $0402
    
    ; Initialize your geometric entity from Lesson 2
    ldx #$05        ; Player X position
    ldy #$03        ; Player Y position
    stx $80         ; Store in zero page
    sty $81         ; Store in zero page
    
    ; Initialize SID chip for electronic pulse
    jsr init_sid_chip
    
    ; Create electronic pulse pattern
    jsr start_electronic_pulse
    
    ; Main neon pulse loop
main_loop:
    jsr update_entity_position
    jsr update_electronic_pulse
    jsr sync_visual_pulse
    jmp main_loop

; Initialize SID chip for electronic music
init_sid_chip:
    ; Clear all SID registers first
    ldx #$00
clear_sid:
    lda #$00
    sta $d400,x     ; Clear SID register (absolute addressing)
    inx
    cpx #$1d        ; Clear all 29 SID registers
    bne clear_sid
    
    ; Set up Voice 1 for electronic pulse
    lda #$21        ; Pulse wave type
    sta $d404       ; Voice 1 waveform (absolute addressing)
    
    lda #$40        ; Medium attack, decay
    sta $d405       ; Voice 1 attack/decay (absolute addressing)
    
    lda #$80        ; Medium sustain, fast release
    sta $d406       ; Voice 1 sustain/release (absolute addressing)
    
    ; Set pulse width for electronic sound
    lda #$00        ; Pulse width low byte
    sta $d402       ; Voice 1 pulse width low (absolute addressing)
    lda #$08        ; Pulse width high byte  
    sta $d403       ; Voice 1 pulse width high (absolute addressing)
    
    ; Set main volume
    lda #$0f        ; Maximum volume
    sta $d418       ; SID volume register (absolute addressing)
    
    rts

; Start the electronic pulse sequence
start_electronic_pulse:
    ; Store pulse timing in zero page for fast access
    lda #$40        ; Pulse interval (zero page addressing)
    sta $82         ; Store timing counter
    
    lda #$00        ; Pulse state (off/on)
    sta $83         ; Store pulse state (zero page addressing)
    
    ; Start first electronic note
    jsr play_pulse_note
    rts

; Update electronic pulse rhythm
update_electronic_pulse:
    ; Decrement pulse timer (zero page addressing)
    dec $82         ; Fast zero page access
    bne pulse_continue
    
    ; Time for next pulse!
    lda #$40        ; Reset pulse interval
    sta $82         ; Store in zero page (zero page addressing)
    
    ; Toggle pulse state
    lda $83         ; Load current pulse state (zero page addressing)
    eor #$01        ; Toggle between 0 and 1
    sta $83         ; Store new state (zero page addressing)
    
    ; Play pulse based on state
    beq silence_pulse
    jsr play_pulse_note
    jmp pulse_continue
    
silence_pulse:
    jsr stop_pulse_note
    
pulse_continue:
    rts

; Play electronic pulse note
play_pulse_note:
    ; Set electronic frequency (addressing modes demonstration)
    lda #$85        ; Frequency low byte (immediate addressing)
    sta $d400       ; Voice 1 frequency low (absolute addressing)
    
    lda #$17        ; Frequency high byte (immediate addressing)
    sta $d401       ; Voice 1 frequency high (absolute addressing)
    
    ; Start the note
    lda #$21        ; Pulse wave + gate bit (immediate addressing)
    sta $d404       ; Voice 1 control (absolute addressing)
    
    rts

; Stop electronic pulse note
stop_pulse_note:
    ; Stop the note (keep waveform, remove gate)
    lda #$20        ; Pulse wave, no gate (immediate addressing)
    sta $d404       ; Voice 1 control (absolute addressing)
    
    rts

; Synchronize visual effects with electronic pulse
sync_visual_pulse:
    ; Check if pulse is active
    lda $83         ; Load pulse state (zero page addressing)
    beq dim_pulse   ; If 0, dim the visuals
    
    ; Brighten pulse effect
    lda #$01        ; Bright white (immediate addressing)
    sta $d020       ; Border color (absolute addressing)
    sta $d021       ; Background color (absolute addressing)
    
    ; Pulse the entity character
    lda #$2a        ; Bright star character (immediate addressing)
    jmp draw_entity
    
dim_pulse:
    ; Dim pulse effect  
    lda #$00        ; Black (immediate addressing)
    sta $d020       ; Border color (absolute addressing)
    lda #$06        ; Dark blue background (immediate addressing)
    sta $d021       ; Background color (absolute addressing)
    
    ; Normal entity character
    lda #$51        ; Geometric block character (immediate addressing)
    
draw_entity:
    ; Calculate entity screen position
    ldy $81         ; Load Y position (zero page addressing)
    ldx $80         ; Load X position (zero page addressing)
    
    ; Simple position calculation for demonstration
    lda $0400,x     ; Read current screen position (absolute indexed)
    ; Store entity character
    sta $0400,x     ; Place entity (absolute indexed)
    
    rts

; Update entity position (from Lesson 2, enhanced)
update_entity_position:
    ; Simple movement - increment X position
    ldx $80         ; Load current X (zero page addressing)
    inx             ; Move right
    cpx #$28        ; Check screen edge (40 columns)
    bne store_new_x
    ldx #$00        ; Wrap to left edge
    
store_new_x:
    stx $80         ; Store new X position (zero page addressing)
    rts
```

## What Just Happened? The Magic Behind Electronic Sound

Now that you've heard your electronic pulse, let's understand how **addressing modes** orchestrated this audio-visual experience.

### Addressing Modes: Your Audio Control System

The most important thing to understand: **addressing modes determine how fast and efficiently you can control audio**. In your electronic pulse code:

**Immediate Addressing (#$value)**: Loading known values
```nasm
lda #$85        ; Load frequency value 133 (immediate addressing)
lda #$21        ; Load pulse wave + gate (immediate addressing)
lda #$0f        ; Load maximum volume (immediate addressing)
```

**Absolute Addressing ($address)**: Controlling SID chip registers
```nasm
sta $d400       ; Store to SID frequency low register (absolute addressing)
sta $d404       ; Store to SID voice control register (absolute addressing)  
sta $d418       ; Store to SID volume register (absolute addressing)
```

**Zero Page Addressing ($zp)**: Lightning-fast audio timing
```nasm
sta $82         ; Store pulse timer (zero page addressing - fastest!)
lda $83         ; Load pulse state (zero page addressing - fastest!)
dec $82         ; Decrement timer (zero page addressing - fastest!)
```

**Addressing Mode Examples in Electronic Audio Control:**

| Mode | Example | Use Case |
|------|---------|----------|
| **Immediate** | `lda #$85` | Load frequency values for electronic notes |
| **Absolute** | `sta $d400` | Control SID chip registers for audio output |
| **Zero Page** | `dec $82` | Fast timing control for rhythm patterns |

### The Legendary SID Chip: Your Electronic Orchestra

**SID Memory Map - Your Electronic Control Panel:**
- **$D400-$D401**: Voice 1 Frequency (electronic note pitch)
- **$D402-$D403**: Voice 1 Pulse Width (electronic tone character)
- **$D404**: Voice 1 Control (start/stop electronic notes)
- **$D405-$D406**: Voice 1 ADSR (electronic note envelope)
- **$D418**: Volume & Filter (overall electronic output)

When you write `sta $d400`, you're directly controlling the legendary SID chip that defined electronic music!

### Why These Addressing Modes Matter for Electronic Music

**Immediate Addressing** - Perfect for audio constants:
```nasm
lda #$21        ; Pulse wave pattern (known at programming time)
lda #$0f        ; Maximum volume (constant value)
```

**Absolute Addressing** - Essential for hardware control:
```nasm
sta $d400       ; SID frequency register (hardware location)
sta $d404       ; SID control register (hardware location)
```

**Zero Page Addressing** - Critical for real-time timing:
```nasm
dec $82         ; Pulse timer (needs maximum speed for rhythm)
lda $83         ; Pulse state (checked every frame for timing)
```

**Why this matters for electronic games**: Audio timing happens 50/60 times per second - zero page addressing ensures your rhythm stays perfect.
