# Sound Timing: Sequencing and Synchronization
**Master the art of timing multiple sounds together**

Music isn't just notes—it's when those notes play. A drum beat is nothing more than sounds triggered at the right moments. A melody is notes played in sequence. Game music layers these elements, playing drums, bass, and melody simultaneously, all perfectly synchronized. This coordination is the essence of sound timing.

The SID chip has three voices, but managing them requires careful timing. Playing a chord means triggering three notes at once. Creating a rhythm means spacing drum hits precisely. Building a song means orchestrating all these elements over time. Today you'll learn to control this timing, creating your own drum machine as a practical example of sound sequencing.

## What You'll Learn

In this lesson, you'll discover:
- **Sequencer design** - Creating pattern-based playback systems
- **Tempo control** - Managing the speed of musical playback
- **Multi-channel coordination** - Using all three SID voices together
- **Pattern storage** - Efficient ways to store rhythm data
- **Frame-based timing** - Synchronizing with the display refresh
- **Interactive control** - Real-time pattern modification

## The Beat Grid

First, let's create our sequencer data structure:

```text
; Drum pattern storage (16 steps x 3 tracks)
kick_pattern:   .byte %1000100010001000  ; Kick drum on steps 1,5,9,13
snare_pattern:  .byte %0000100000001000  ; Snare on steps 5,13  
hihat_pattern:  .byte %1010101010101010  ; Hi-hat on every other step

; Sequencer state
current_step:   .byte 0    ; 0-15
tempo_counter:  .byte 0    ; Counts frames between steps
tempo_speed:    .byte 6    ; Frames per step (lower = faster)

; Initialize sequencer
init_sequencer:
    lda #$0F
    sta $D418       ; Max volume
    
    ; Set up drum ADSR values
    lda #$00        ; Fast attack for drums
    sta $D405       ; Voice 1 A/D
    sta $D40C       ; Voice 2 A/D  
    sta $D413       ; Voice 3 A/D
    
    lda #$09        ; Quick release
    sta $D406       ; Voice 1 S/R
    sta $D40D       ; Voice 2 S/R
    sta $D414       ; Voice 3 S/R
    rts
```

## Playing the Pattern

Now let's make it play:

```text
; Main sequencer update (call every frame)
update_sequencer:
    dec tempo_counter
    bne sequencer_done
    
    ; Reset tempo counter
    lda tempo_speed
    sta tempo_counter
    
    ; Get current step bit position
    ldx current_step
    lda bit_masks,x     ; Table of single bits
    sta current_bit
    
    ; Check kick drum
    and kick_pattern
    beq check_snare
    jsr play_kick
    
check_snare:
    lda current_bit
    and snare_pattern
    beq check_hihat
    jsr play_snare
    
check_hihat:
    lda current_bit
    and hihat_pattern
    beq advance_step
    jsr play_hihat
    
advance_step:
    ; Visual feedback
    ldx current_step
    lda #160            ; Inverse space character
    sta $0400,x         ; Show on screen
    
    ; Clear previous step
    dex
    bpl clear_prev
    ldx #15
clear_prev:
    lda #32             ; Normal space
    sta $0400,x
    
    ; Move to next step
    inc current_step
    lda current_step
    and #$0F            ; Wrap at 16
    sta current_step
    
sequencer_done:
    rts

; Bit position lookup table
bit_masks:
    .byte $80,$40,$20,$10,$08,$04,$02,$01
    .byte $80,$40,$20,$10,$08,$04,$02,$01
    
current_bit: .byte 0
```

## Drum Sound Generators

Each drum gets its own unique sound:

```text
play_kick:
    ; Deep thump on voice 1
    lda #$10        ; Low frequency
    sta $D400
    lda #$08
    sta $D401
    
    ; Triangle + noise for punch
    lda #$81        ; Noise waveform
    sta $D404       ; Gate on
    
    ; Quick pitch sweep for impact
    ldx #4
kick_sweep:
    lda kick_freqs,x
    sta $D400
    dex
    bpl kick_sweep
    
    ; Visual flash
    lda #2          ; Red
    sta $D020       ; Border
    
    rts

kick_freqs: .byte $10,$18,$20,$15,$10
```

```text
play_snare:
    ; Crisp snap on voice 2
    lda #$40        ; Mid frequency
    sta $D407
    lda #$20
    sta $D408
    
    ; Pure noise
    lda #$81        ; Noise waveform
    sta $D40B       ; Gate on
    
    ; Brightness sweep
    ldx #3
snare_sweep:
    txa
    asl
    asl
    asl
    asl
    sta $D407
    dex
    bpl snare_sweep
    
    ; Visual flash
    lda #1          ; White
    sta $D020
    
    rts
```

```text
play_hihat:
    ; Metallic tick on voice 3
    lda #$80        ; High frequency
    sta $D40E
    lda #$40
    sta $D40F
    
    ; Short noise burst
    lda #$81        ; Noise
    sta $D412       ; Gate on
    
    ; Very quick off
    ldx #2
hihat_delay:
    dex
    bne hihat_delay
    
    lda #$80        ; Gate off
    sta $D412
    
    ; Subtle visual
    lda #15         ; Light gray
    sta $D020
    
    rts
```

## Pattern Editor

Let's make it interactive - use the keyboard to edit patterns:

```text
; Check keyboard input
check_keys:
    jsr $FFE4       ; GETIN - get key
    beq no_key
    
    ; Number keys 1-8 toggle kick pattern
    cmp #'1'
    bcc check_snare_keys
    cmp #'9'
    bcs check_snare_keys
    
    ; Toggle kick bit
    sec
    sbc #'1'        ; Convert to 0-7
    tax
    lda bit_masks,x
    eor kick_pattern
    sta kick_pattern
    jmp show_pattern
    
check_snare_keys:
    ; Q-I keys toggle snare
    cmp #'Q'
    bcc check_hihat_keys
    cmp #'P'
    bcs check_hihat_keys
    
    sec
    sbc #'Q'
    tax
    lda bit_masks,x
    eor snare_pattern
    sta snare_pattern
    jmp show_pattern
    
check_hihat_keys:
    ; A-K keys toggle hi-hat
    cmp #'A'
    bcc check_tempo
    cmp #'L'
    bcs check_tempo
    
    sec
    sbc #'A'
    tax
    lda bit_masks,x
    eor hihat_pattern
    sta hihat_pattern
    jmp show_pattern
    
check_tempo:
    ; +/- adjust tempo
    cmp #'+'
    bne check_minus
    dec tempo_speed     ; Faster
    lda tempo_speed
    cmp #2
    bcs no_key
    lda #2
    sta tempo_speed
    jmp no_key
    
check_minus:
    cmp #'-'
    bne no_key
    inc tempo_speed     ; Slower
    lda tempo_speed
    cmp #12
    bcc no_key
    lda #12
    sta tempo_speed
    
no_key:
    rts
```

## Visual Pattern Display

Show the patterns on screen:

```text
show_pattern:
    ; Display all three tracks
    ldx #0
show_loop:
    ; Kick track (row 5)
    lda kick_pattern
    jsr show_track_bit
    sta $0400+40*5,x
    
    ; Snare track (row 7)
    lda snare_pattern
    jsr show_track_bit
    sta $0400+40*7,x
    
    ; Hi-hat track (row 9)
    lda hihat_pattern
    jsr show_track_bit
    sta $0400+40*9,x
    
    ; Color the columns
    lda #1              ; White for active
    sta $D800+40*5,x
    sta $D800+40*7,x
    sta $D800+40*9,x
    
    inx
    cpx #16
    bne show_loop
    rts

show_track_bit:
    ; Check if bit X is set in pattern (A)
    pha
    lda bit_masks,x
    sta temp
    pla
    and temp
    beq show_off
    lda #81             ; Ball character
    rts
show_off:
    lda #46             ; Dot
    rts
    
temp: .byte 0
```

## Complete Drum Machine

Put it all together:

```text
* = $0801
    !byte $0B,$08,$0A,$00,$9E
    !text "2061"
    !byte $00,$00,$00

* = $080D

main:
    ; Clear screen
    lda #147
    jsr $FFD2
    
    ; Initialize
    jsr init_sequencer
    jsr draw_interface
    jsr show_pattern
    
    ; Print instructions
    ldx #0
print_inst:
    lda instructions,x
    beq main_loop
    jsr $FFD2
    inx
    bne print_inst

main_loop:
    ; Wait for raster
    lda #251
wait:
    cmp $D012
    bne wait
    
    ; Reset border
    lda #0
    sta $D020
    
    ; Update everything
    jsr update_sequencer
    jsr check_keys
    
    jmp main_loop

draw_interface:
    ; Draw track labels
    ldx #0
draw_labels:
    lda label_kick,x
    beq next_label
    sta $0400+40*5-5,x
    lda label_snare,x
    sta $0400+40*7-5,x
    lda label_hihat,x
    sta $0400+40*9-5,x
    inx
    bne draw_labels
next_label:
    rts

instructions:
    !text "C64 DRUM MACHINE",13,13
    !text "1-8: KICK  Q-I: SNARE  A-K: HIHAT",13
    !text "+/-: TEMPO",13,13
    !byte 0

label_kick:  !text "KICK ",0
label_snare: !text "SNARE",0
label_hihat: !text "HIHAT",0
```

## Bonus: Preset Patterns

Add some built-in beats:

```text
; Classic patterns
preset_rock:
    !byte %1000100010001000  ; Kick
    !byte %0000100000001000  ; Snare
    !byte %1111111111111111  ; Hi-hat

preset_funk:
    !byte %1001001010010010  ; Kick
    !byte %0100001001000010  ; Snare
    !byte %0101101001011010  ; Hi-hat

preset_techno:
    !byte %1010101010101010  ; Kick
    !byte %0000000000000000  ; Snare
    !byte %0001000100010001  ; Hi-hat

; Load preset with F1-F3 keys
load_preset:
    cmp #133            ; F1
    bne check_f3
    ldx #preset_rock
    jmp copy_preset
    
check_f3:
    cmp #134            ; F3
    bne check_f5
    ldx #preset_funk
    jmp copy_preset
    
check_f5:
    cmp #135            ; F5
    bne no_preset
    ldx #preset_techno
    
copy_preset:
    lda 0,x
    sta kick_pattern
    lda 1,x
    sta snare_pattern
    lda 2,x
    sta hihat_pattern
    jsr show_pattern
    
no_preset:
    rts
```

## Applying to Your Game

### Network Pulse Rhythm for Neon Nexus

Apply sound timing techniques to create a sophisticated network pulse rhythm system for our cyberpunk game, with synchronized audio-visual feedback.

### Network Traffic Pulse System

```asm
network_pulse_init:
        ; Initialize network pulse rhythm system
        lda #0
        sta network_pulse_step
        sta security_level
        sta traffic_intensity
        
        ; Base network tempo (moderate)
        lda #8
        sta network_tempo
        sta network_counter
        
        rts

update_network_pulse:
        ; Update network pulse rhythm every frame
        dec network_counter
        bne pulse_done
        
        ; Reset counter based on security level
        lda security_level
        asl                     ; Double for tempo variation
        clc
        adc network_tempo       ; Add base tempo
        sta network_counter
        
        ; Trigger network pulse sound
        jsr play_network_pulse
        
        ; Advance pulse step
        inc network_pulse_step
        lda network_pulse_step
        and #$0f               ; Wrap at 16 steps
        sta network_pulse_step
        
        ; Visual sync - flash network indicator
        jsr sync_visual_pulse
        
pulse_done:
        rts

play_network_pulse:
        ; Background network traffic pulse
        lda #$2d
        sta $d400              ; Low frequency for subtle pulse
        lda #$04
        sta $d401
        
        ; Quick pulse envelope
        lda #$00               ; Attack=0, Decay=0
        sta $d405
        lda #$82               ; Sustain=8, Release=2
        sta $d406
        
        ; Triangle for smooth pulse
        lda #$11               ; Triangle + gate
        sta $d404
        
        ; Auto-release after brief time
        ldx #4
pulse_sustain:
        lda #250
        cmp $d012
        bne *-3
        dex
        bne pulse_sustain
        
        lda #$10               ; Gate off
        sta $d404
        
        rts

set_security_level:
        ; Input: A = security level (0-3)
        ; Changes network pulse timing
        sta security_level
        
        ; Adjust tempo based on security
        cmp #0
        beq normal_tempo
        cmp #1
        beq alert_tempo
        cmp #2
        beq danger_tempo
        
        ; Critical tempo
        lda #3                  ; Very fast pulse
        sta network_tempo
        rts
        
normal_tempo:
        lda #8                  ; Normal pulse
        sta network_tempo
        rts
        
alert_tempo:
        lda #6                  ; Faster pulse
        sta network_tempo
        rts
        
danger_tempo:
        lda #4                  ; Fast pulse
        sta network_tempo
        rts

sync_visual_pulse:
        ; Synchronize visual effects with audio pulse
        ldx network_pulse_step
        
        ; Flash border color briefly
        lda pulse_colors,x
        sta $d020              ; Border color
        
        ; Reset border after brief flash
        ; (This would be called a few frames later)
        rts

; Network timing variables
network_pulse_step: !byte 0
network_counter:    !byte 0
network_tempo:      !byte 0
security_level:     !byte 0
traffic_intensity:  !byte 0

pulse_colors:
        !byte 0,0,0,0,6,0,0,0   ; Subtle blue flash every 5th step
        !byte 0,0,0,0,6,0,0,0
```

**Network Integration:** Your Neon Nexus now pulses with life! The network timing system creates an immersive cyberpunk environment where the rhythm changes based on security threats, creating tension and atmosphere through perfectly synchronized audio-visual feedback.

## Memory Map

**SID Chip Registers:**
- `$D400-$D406`: Voice 1 (Kick drum)
- `$D407-$D40D`: Voice 2 (Snare drum)
- `$D40E-$D414`: Voice 3 (Hi-hat)
- `$D418`: Volume/Filter Control

**Screen Display:**
- `$0400`: Step indicator (16 chars)
- `$0400+200`: Kick pattern display
- `$0400+280`: Snare pattern display
- `$0400+360`: Hi-hat pattern display
