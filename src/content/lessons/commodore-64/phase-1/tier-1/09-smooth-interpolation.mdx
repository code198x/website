## Understanding Linear Interpolation

Before we code, let's understand the concept:

### The Problem with Instant Movement
```
Frame 1: Sprite at grid 3 (pixel 106)
Frame 2: Sprite at grid 4 (pixel 132)
Result: 26-pixel jump - jarring!
```

### The Interpolation Solution
```
Frame 1: Sprite at pixel 106 (start)
Frame 2: Sprite at pixel 108 (+2)
Frame 3: Sprite at pixel 110 (+2)
...13 frames later...
Frame 14: Sprite at pixel 132 (complete)
Result: Smooth glide across 26 pixels
```

## Building the Interpolation System

Let's add smooth movement to our Grid Protocol!

### Step 1: Movement State Machine
**"Track whether we're moving or ready for input!"**

```asm
; Movement states
STATE_IDLE = 0         ; Ready for new input
STATE_MOVING = 1       ; Currently interpolating

movement_state: !byte 0
interp_step:    !byte 0
```

**Key Point**: Only accept new movement when IDLE!

### Step 2: Separate Position Tracking
**"Current position vs where we're going!"**

```asm
; Grid positions
grid_x:         !byte 6
grid_y:         !byte 4
target_grid_x:  !byte 6
target_grid_y:  !byte 4

; Pixel positions (target)
pixel_x:        !byte 0
pixel_x_msb:    !byte 0
pixel_y:        !byte 0

; Current interpolated positions
current_x:      !byte 0
current_x_msb:  !byte 0
current_y:      !byte 0
```

**Key Point**: Three levels of position tracking!

### Step 3: MSB-Aware Interpolation
**"Handle the 256-pixel boundary correctly!"**

```asm
interpolate_position:
        ; Check if MSBs are different
        lda current_x_msb
        cmp pixel_x_msb
        beq same_msb_x
        
        ; Different MSB - handle boundary
        bcc move_right_with_msb
        
        ; Moving left across boundary (MSB 1->0)
        lda current_x
        sec
        sbc #INTERP_SPEED
        sta current_x
        bcs done
        lda #0
        sta current_x_msb
        jmp done
        
move_right_with_msb:
        ; Moving right across boundary (MSB 0->1)
        lda current_x
        clc
        adc #INTERP_SPEED
        sta current_x
        bcc done
        lda #1
        sta current_x_msb
```

**Key Point**: Check MSB first to detect boundary crossings!

### Step 4: Process Movement Requests
**"Only start new movement when idle!"**

```asm
process_movement:
        ; Only process if idle
        lda movement_state
        cmp #STATE_IDLE
        bne movement_done
        
        ; Check for input and set target
        lda joystick_state
        and #$01              ; Up?
        bne check_down
        dec target_grid_y
        jmp start_interpolation
        
start_interpolation:
        ; Begin movement
        lda #STATE_MOVING
        sta movement_state
        
        ; Update grid position
        lda target_grid_x
        sta grid_x
        lda target_grid_y
        sta grid_y
        
        ; Calculate pixel target
        jsr grid_to_pixels
```

**Key Point**: Set state to MOVING to block new input!

### Step 5: Completion Detection
**"Know when we've arrived!"**

```asm
check_complete:
        ; Check MSB first
        lda current_x_msb
        cmp pixel_x_msb
        bne not_complete
        
        ; Check X position
        lda current_x
        cmp pixel_x
        bne not_complete
        
        ; Check Y position
        lda current_y
        cmp pixel_y
        bne not_complete
        
        ; Movement complete!
        lda #STATE_IDLE
        sta movement_state
```

**Key Point**: Must check MSB for proper completion!

## Understanding the Smoothness

### Interpolation Speed
At 2 pixels per frame:
- **Short moves**: 13 frames for adjacent cells (26 pixels)
- **Long moves**: Up to 128 frames for full width
- **50 FPS**: Smooth motion at PAL refresh rate

### The MSB Challenge Solved
Moving from grid 8 to 9:
- **Grid 8**: X = 236, MSB = 0 (actual: 236)
- **Grid 9**: X = 6, MSB = 1 (actual: 262)
- **Solution**: Detect MSB difference, interpolate right to 262

Without MSB awareness, sprite would move LEFT from 236 to 6!

## Technical Reference

### Movement States
- **STATE_IDLE (0)**: Ready for input
- **STATE_MOVING (1)**: Currently interpolating

### Interpolation Settings
- **INTERP_SPEED**: 2 pixels per frame
- **Frame rate**: 50 FPS (PAL)

### Position Variables
- **grid_x/y**: Current grid position
- **target_grid_x/y**: Destination grid position
- **pixel_x/y**: Target pixel position
- **current_x/y**: Interpolated pixel position
- **x_msb variables**: Handle positions > 255

### MSB Boundary
- **Positions 0-8**: MSB = 0 (pixels 28-236)
- **Positions 9-11**: MSB = 1 (pixels 262-314)
- **Boundary**: Between positions 8 and 9
