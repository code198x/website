# Lesson 5: Neon Nexus - Energy Combat

**Your neon world needs explosive combat!** In the last lesson, you added intelligent digital opposition with moving enemy shapes. Today, you'll unleash energy-based combat systems - creating projectile weapons, collision-based destruction, and energy management that transforms your geometric realm into an engaging combat arena!

## Your Energy Combat Activates

Let's start with the magic - adding projectile weapons and combat systems to your neon world:

```nasm
; Neon Nexus - Energy Combat Creation
* = $0801
        .byte $0b,$08,$0a,$00,$9e,$32,$30,$36,$31,$00,$00,$00

start:
    ; Set up enhanced neon world from Lessons 1-4
    lda #$93        ; Clear screen
    jsr $ffd2       ; CHROUT
    
    ; Draw enhanced neon grid with combat elements
    lda #$2d        ; Horizontal line character
    sta $0400       ; Top grid line
    sta $0401
    sta $0402
    
    ; Initialize player entity from previous lessons
    ldx #$05        ; Player X position
    ldy #$03        ; Player Y position
    stx $80         ; Store in zero page
    sty $81         ; Store in zero page
    
    ; Initialize digital opposition from Lesson 4
    jsr init_enemy_system
    jsr create_enemy_entities
    
    ; Initialize energy combat system
    jsr init_combat_system
    
    ; Create weapon systems
    jsr init_weapon_systems
    
    ; Initialize energy management
    jsr init_energy_systems
    
    ; Main energy combat loop
main_loop:
    jsr read_combat_input
    jsr update_player_combat
    jsr update_weapon_systems
    jsr update_enemy_entities
    jsr check_combat_collisions
    jsr update_energy_systems
    jsr update_combat_effects
    jmp main_loop

; Initialize energy combat system
init_combat_system:
    ; Set up combat state variables
    lda #$64        ; Player health (100)
    sta $a0         ; Store player health
    
    lda #$32        ; Player energy (50)
    sta $a1         ; Store player energy
    
    lda #$20        ; Weapon ammo (32 shots)
    sta $a2         ; Store weapon ammo
    
    ; Initialize combat timing
    lda #$00        ; Combat timer
    sta $a3         ; Store timer
    
    ; Set combat flags
    lda #$00        ; No weapon firing initially
    sta $a4         ; Weapon fire flag
    sta $a5         ; Hit flash flag
    sta $a6         ; Enemy destruction flag
    
    rts

; Initialize weapon systems
init_weapon_systems:
    ; Set up projectile array (8 projectiles maximum)
    ldx #$07        ; Projectile index counter
clear_projectiles:
    lda #$00        ; Inactive projectile
    sta $b0,x       ; Clear projectile active flag
    sta $b8,x       ; Clear projectile X position
    sta $c0,x       ; Clear projectile Y position
    sta $c8,x       ; Clear projectile direction
    dex             ; Decrement index
    bpl clear_projectiles ; Continue until all cleared
    
    ; Set up weapon parameters
    lda #$08        ; Weapon power
    sta $d0         ; Store weapon damage
    lda #$04        ; Weapon speed
    sta $d1         ; Store projectile speed
    lda #$10        ; Weapon energy cost
    sta $d2         ; Store energy per shot
    
    rts

; Initialize energy management systems
init_energy_systems:
    ; Set up energy regeneration
    lda #$3c        ; Energy regen rate (60 frames)
    sta $e0         ; Store regen timer
    
    lda #$02        ; Energy regen amount
    sta $e1         ; Store regen per cycle
    
    ; Set up health systems
    lda #$ff        ; Health regen rate (255 frames)
    sta $e2         ; Store health timer
    
    lda #$01        ; Health regen amount
    sta $e3         ; Store health per cycle
    
    rts

; Read combat input from player
read_combat_input:
    ; Read keyboard for combat controls
    lda $dc01       ; Read keyboard port
    
    ; Check for weapon fire (space bar)
    and #%00010000  ; Check space bar bit
    bne no_weapon_fire ; Branch if not pressed
    
    ; Weapon fire requested
    lda #$01        ; Set fire flag
    sta $a4         ; Store fire request
    jmp input_done
    
no_weapon_fire:
    lda #$00        ; Clear fire flag
    sta $a4         ; Store no fire
    
input_done:
    rts

; Update player combat systems
update_player_combat:
    ; Check if weapon fire requested
    lda $a4         ; Load fire flag
    beq no_fire     ; Branch if no fire requested
    
    ; Check if player has energy for weapon
    lda $a1         ; Load player energy
    cmp $d2         ; Compare with weapon cost
    bcc no_fire     ; Branch if insufficient energy
    
    ; Check weapon cooldown
    lda $a3         ; Load combat timer
    bne no_fire     ; Branch if weapon on cooldown
    
    ; Fire weapon
    jsr fire_player_weapon
    
    ; Consume energy
    lda $a1         ; Load current energy
    sec             ; Set carry for subtraction
    sbc $d2         ; Subtract weapon cost
    sta $a1         ; Store new energy
    
    ; Set weapon cooldown
    lda #$08        ; Cooldown time
    sta $a3         ; Store cooldown timer
    
no_fire:
    ; Update combat timer
    lda $a3         ; Load combat timer
    beq timer_done  ; Skip if already zero
    dec $a3         ; Decrement timer
    
timer_done:
    rts

; Fire player weapon projectile
fire_player_weapon:
    ; Find empty projectile slot
    ldx #$07        ; Start with last projectile
find_empty_slot:
    lda $b0,x       ; Load projectile active flag
    beq found_slot  ; Branch if empty slot found
    dex             ; Try previous slot
    bpl find_empty_slot ; Continue if more slots
    rts             ; No empty slots available
    
found_slot:
    ; Activate projectile
    lda #$01        ; Set active flag
    sta $b0,x       ; Store in projectile array
    
    ; Set projectile position to player position
    lda $80         ; Load player X
    clc             ; Clear carry
    adc #$01        ; Offset slightly right
    sta $b8,x       ; Store projectile X
    
    lda $81         ; Load player Y
    sta $c0,x       ; Store projectile Y
    
    ; Set projectile direction (moving right)
    lda #$01        ; Direction right
    sta $c8,x       ; Store direction
    
    ; Play weapon fire sound
    jsr play_weapon_sound
    
    rts

; Update all weapon projectiles
update_weapon_systems:
    ; Loop through all projectiles
    ldx #$07        ; Start with last projectile
update_projectile_loop:
    ; Check if projectile is active
    lda $b0,x       ; Load active flag
    beq skip_projectile ; Skip if inactive
    
    ; Update projectile position
    lda $c8,x       ; Load direction
    cmp #$01        ; Check if moving right
    beq move_right
    
move_left:
    ; Move projectile left
    lda $b8,x       ; Load X position
    sec             ; Set carry for subtraction
    sbc $d1         ; Subtract speed
    bcc deactivate_projectile ; Deactivate if off screen
    sta $b8,x       ; Store new position
    jmp check_projectile_collision
    
move_right:
    ; Move projectile right
    lda $b8,x       ; Load X position
    clc             ; Clear carry
    adc $d1         ; Add speed
    cmp #$28        ; Check screen boundary
    bcs deactivate_projectile ; Deactivate if off screen
    sta $b8,x       ; Store new position
    
check_projectile_collision:
    ; Check collision with enemies
    jsr check_projectile_enemy_collision
    jmp continue_projectile_update
    
deactivate_projectile:
    ; Deactivate off-screen projectile
    lda #$00        ; Clear active flag
    sta $b0,x       ; Store in array
    
continue_projectile_update:
skip_projectile:
    dex             ; Previous projectile
    bpl update_projectile_loop ; Continue until all processed
    
    rts

; Check projectile collision with enemies
check_projectile_enemy_collision:
    ; Save projectile index
    stx $f0         ; Temporary storage
    
    ; Check collision with Enemy 1
    lda $91         ; Load Enemy 1 status
    beq check_enemy_2 ; Skip if inactive
    
    ; Compare positions
    lda $b8,x       ; Load projectile X
    cmp $95         ; Compare with Enemy 1 X
    bne check_enemy_2 ; Different X positions
    
    lda $c0,x       ; Load projectile Y
    cmp $96         ; Compare with Enemy 1 Y
    bne check_enemy_2 ; Different Y positions
    
    ; Hit detected!
    jsr handle_enemy_hit
    
    ; Deactivate projectile
    ldx $f0         ; Restore projectile index
    lda #$00        ; Clear active flag
    sta $b0,x       ; Deactivate projectile
    
    ; Damage Enemy 1
    lda #$00        ; Destroy enemy
    sta $91         ; Mark Enemy 1 as destroyed
    
    jmp collision_check_done
    
check_enemy_2:
    ; Similar collision check for Enemy 2
    lda $92         ; Load Enemy 2 status
    beq check_enemy_3 ; Skip if inactive
    
    ldx $f0         ; Restore projectile index
    lda $b8,x       ; Load projectile X
    cmp $98         ; Compare with Enemy 2 X
    bne check_enemy_3 ; Different X positions
    
    lda $c0,x       ; Load projectile Y
    cmp $99         ; Compare with Enemy 2 Y
    bne check_enemy_3 ; Different Y positions
    
    ; Hit detected!
    jsr handle_enemy_hit
    
    ; Deactivate projectile and enemy
    ldx $f0         ; Restore projectile index
    lda #$00        ; Clear flags
    sta $b0,x       ; Deactivate projectile
    sta $92         ; Mark Enemy 2 as destroyed
    
    jmp collision_check_done
    
check_enemy_3:
    ; Similar collision check for Enemy 3
    lda $93         ; Load Enemy 3 status
    beq collision_check_done ; Skip if inactive
    
    ldx $f0         ; Restore projectile index
    lda $b8,x       ; Load projectile X
    cmp $9b         ; Compare with Enemy 3 X
    bne collision_check_done ; Different X positions
    
    lda $c0,x       ; Load projectile Y
    cmp $9c         ; Compare with Enemy 3 Y
    bne collision_check_done ; Different Y positions
    
    ; Hit detected!
    jsr handle_enemy_hit
    
    ; Deactivate projectile and enemy
    ldx $f0         ; Restore projectile index
    lda #$00        ; Clear flags
    sta $b0,x       ; Deactivate projectile
    sta $93         ; Mark Enemy 3 as destroyed
    
collision_check_done:
    ldx $f0         ; Restore projectile index
    rts

; Handle enemy hit effects
handle_enemy_hit:
    ; Flash screen for hit effect
    lda #$01        ; Red flash
    sta $d020       ; Border color
    sta $d021       ; Background color
    
    ; Play hit sound
    jsr play_hit_sound
    
    ; Award points/energy
    lda $a1         ; Load current energy
    clc             ; Clear carry
    adc #$05        ; Add energy reward
    cmp #$64        ; Check maximum
    bcc store_energy ; Store if within limit
    lda #$64        ; Clamp to maximum
    
store_energy:
    sta $a1         ; Store updated energy
    
    ; Set destruction effect flag
    lda #$10        ; Effect duration
    sta $a6         ; Store destruction timer
    
    rts

; Check combat collisions (enemy damage to player)
check_combat_collisions:
    ; Check collision with Enemy 1
    lda $91         ; Load Enemy 1 status
    beq check_player_enemy_2 ; Skip if inactive
    
    ; Compare player and Enemy 1 positions
    lda $80         ; Load player X
    cmp $95         ; Compare with Enemy 1 X
    bne check_player_enemy_2 ; Different X positions
    
    lda $81         ; Load player Y
    cmp $96         ; Compare with Enemy 1 Y
    bne check_player_enemy_2 ; Different Y positions
    
    ; Collision detected! Handle player damage
    jsr handle_player_damage
    
check_player_enemy_2:
    ; Similar collision check for Enemy 2
    lda $92         ; Load Enemy 2 status
    beq check_player_enemy_3 ; Skip if inactive
    
    lda $80         ; Load player X
    cmp $98         ; Compare with Enemy 2 X
    bne check_player_enemy_3 ; Different X positions
    
    lda $81         ; Load player Y
    cmp $99         ; Compare with Enemy 2 Y
    bne check_player_enemy_3 ; Different Y positions
    
    ; Collision detected!
    jsr handle_player_damage
    
check_player_enemy_3:
    ; Similar collision check for Enemy 3
    lda $93         ; Load Enemy 3 status
    beq player_collision_done ; Skip if inactive
    
    lda $80         ; Load player X
    cmp $9b         ; Compare with Enemy 3 X
    bne player_collision_done ; Different X positions
    
    lda $81         ; Load player Y
    cmp $9c         ; Compare with Enemy 3 Y
    bne player_collision_done ; Different Y positions
    
    ; Collision detected!
    jsr handle_player_damage
    
player_collision_done:
    rts

; Handle player taking damage
handle_player_damage:
    ; Reduce player health
    lda $a0         ; Load current health
    sec             ; Set carry for subtraction
    sbc #$0a        ; Subtract damage (10 points)
    bcs store_health ; Store if positive
    lda #$00        ; Clamp to zero
    
store_health:
    sta $a0         ; Store updated health
    
    ; Flash screen red for damage
    lda #$02        ; Red color
    sta $d020       ; Border color
    sta $d021       ; Background color
    
    ; Set hit flash timer
    lda #$08        ; Flash duration
    sta $a5         ; Store flash timer
    
    ; Play damage sound
    jsr play_damage_sound
    
    ; Check for game over
    lda $a0         ; Load health
    bne damage_done ; Continue if health remaining
    
    ; Game over sequence
    jsr handle_game_over
    
damage_done:
    rts

; Update energy management systems
update_energy_systems:
    ; Update energy regeneration
    dec $e0         ; Decrement energy timer
    bne check_health_regen ; Skip if timer not zero
    
    ; Regenerate energy
    lda $a1         ; Load current energy
    clc             ; Clear carry
    adc $e1         ; Add regen amount
    cmp #$64        ; Check maximum energy
    bcc store_regen_energy ; Store if within limit
    lda #$64        ; Clamp to maximum
    
store_regen_energy:
    sta $a1         ; Store updated energy
    
    ; Reset energy timer
    lda #$3c        ; Reset timer
    sta $e0         ; Store reset value
    
check_health_regen:
    ; Update health regeneration
    dec $e2         ; Decrement health timer
    bne energy_update_done ; Skip if timer not zero
    
    ; Check if health is below maximum
    lda $a0         ; Load current health
    cmp #$64        ; Compare with maximum
    bcs reset_health_timer ; Skip if at maximum
    
    ; Regenerate health
    clc             ; Clear carry
    adc $e3         ; Add regen amount
    cmp #$64        ; Check maximum
    bcc store_regen_health ; Store if within limit
    lda #$64        ; Clamp to maximum
    
store_regen_health:
    sta $a0         ; Store updated health
    
reset_health_timer:
    ; Reset health timer
    lda #$ff        ; Reset timer
    sta $e2         ; Store reset value
    
energy_update_done:
    rts

; Update combat visual and audio effects
update_combat_effects:
    ; Update hit flash effect
    lda $a5         ; Load flash timer
    beq check_destruction_effect ; Skip if no flash
    
    dec $a5         ; Decrement flash timer
    bne flash_continue ; Continue flashing
    
    ; Flash finished - restore normal colors
    lda #$00        ; Black border
    sta $d020       ; Border color
    lda #$06        ; Blue background
    sta $d021       ; Background color
    
flash_continue:
check_destruction_effect:
    ; Update destruction effect
    lda $a6         ; Load destruction timer
    beq draw_combat_hud ; Skip if no effect
    
    dec $a6         ; Decrement effect timer
    
    ; Create destruction visual effect
    lda $a6         ; Load timer
    and #$03        ; Mask for color cycling
    clc             ; Clear carry
    adc #$01        ; Offset color
    sta $d020       ; Border flash effect
    
draw_combat_hud:
    ; Draw heads-up display
    jsr draw_health_bar
    jsr draw_energy_bar
    jsr draw_projectiles
    
    rts

; Draw player health bar
draw_health_bar:
    ; Position cursor for health display
    lda #$19        ; Row 25
    sta $d6         ; Cursor row
    lda #$00        ; Column 0
    sta $d3         ; Cursor column
    
    ; Display health value
    lda $a0         ; Load health
    jsr display_hex_value
    
    ; Draw health bar visual
    ldx #$0a        ; Bar width
    ldy #$00        ; Bar position
health_bar_loop:
    lda $a0         ; Load health
    cmp health_thresholds,y ; Compare with threshold
    bcc empty_health ; Draw empty if below threshold
    
    lda #$a0        ; Full health character
    jmp store_health_char
    
empty_health:
    lda #$20        ; Empty space
    
store_health_char:
    sta $0400+$318,y ; Store in bottom screen area
    iny             ; Next position
    dex             ; Decrement counter
    bne health_bar_loop ; Continue until bar complete
    
    rts

; Draw player energy bar
draw_energy_bar:
    ; Position cursor for energy display
    lda #$19        ; Row 25
    sta $d6         ; Cursor row
    lda #$14        ; Column 20
    sta $d3         ; Cursor column
    
    ; Display energy value
    lda $a1         ; Load energy
    jsr display_hex_value
    
    ; Draw energy bar visual
    ldx #$0a        ; Bar width
    ldy #$00        ; Bar position
energy_bar_loop:
    lda $a1         ; Load energy
    cmp energy_thresholds,y ; Compare with threshold
    bcc empty_energy ; Draw empty if below threshold
    
    lda #$a1        ; Full energy character
    jmp store_energy_char
    
empty_energy:
    lda #$20        ; Empty space
    
store_energy_char:
    sta $0400+$328,y ; Store in bottom screen area
    iny             ; Next position
    dex             ; Decrement counter
    bne energy_bar_loop ; Continue until bar complete
    
    rts

; Draw active projectiles
draw_projectiles:
    ; Loop through all projectiles
    ldx #$07        ; Start with last projectile
draw_projectile_loop:
    ; Check if projectile is active
    lda $b0,x       ; Load active flag
    beq skip_draw_projectile ; Skip if inactive
    
    ; Calculate projectile screen position
    lda $c0,x       ; Load projectile Y
    asl             ; Multiply by 2
    asl             ; Multiply by 4
    asl             ; Multiply by 8
    asl             ; Multiply by 16
    asl             ; Multiply by 32
    clc             ; Clear carry
    adc $b8,x       ; Add projectile X
    tay             ; Transfer to Y for indexing
    
    ; Draw projectile character
    lda #$2e        ; Projectile character (dot)
    sta $0400,y     ; Place on screen
    
skip_draw_projectile:
    dex             ; Previous projectile
    bpl draw_projectile_loop ; Continue until all processed
    
    rts

; Play weapon fire sound
play_weapon_sound:
    ; Use pulse channel for weapon sound
    lda #$81        ; Attack, sustain
    sta $d404       ; Voice 1 control
    
    lda #$f0        ; High frequency for weapon
    sta $d400       ; Voice 1 frequency low
    lda #$04        ; High frequency
    sta $d401       ; Voice 1 frequency high
    
    rts

; Play hit sound
play_hit_sound:
    ; Use noise channel for hit sound
    lda #$81        ; Attack, sustain
    sta $d40b       ; Voice 2 control
    
    lda #$20        ; Hit frequency
    sta $d407       ; Voice 2 frequency low
    lda #$08        ; Hit frequency high
    sta $d408       ; Voice 2 frequency high
    
    rts

; Play damage sound
play_damage_sound:
    ; Use triangle channel for damage sound
    lda #$41        ; Attack, sustain
    sta $d412       ; Voice 3 control
    
    lda #$80        ; Damage frequency
    sta $d40e       ; Voice 3 frequency low
    lda #$02        ; Damage frequency high
    sta $d40f       ; Voice 3 frequency high
    
    rts

; Handle game over sequence
handle_game_over:
    ; Flash screen multiple times
    ldx #$08        ; Flash count
game_over_flash:
    lda #$02        ; Red color
    sta $d020       ; Border color
    sta $d021       ; Background color
    
    ; Delay
    ldy #$ff        ; Delay counter
game_over_delay1:
    dey             ; Decrement counter
    bne game_over_delay1 ; Continue until zero
    
    lda #$00        ; Black color
    sta $d020       ; Border color
    sta $d021       ; Background color
    
    ; Delay
    ldy #$ff        ; Delay counter
game_over_delay2:
    dey             ; Decrement counter
    bne game_over_delay2 ; Continue until zero
    
    dex             ; Decrement flash counter
    bne game_over_flash ; Continue flashing
    
    ; Reset game
    jmp start
    
; Display hexadecimal value
display_hex_value:
    ; Convert and display hex value (simplified)
    lsr             ; Shift right 4 times
    lsr
    lsr
    lsr
    clc             ; Clear carry
    adc #$30        ; Convert to ASCII
    jsr $ffd2       ; Display character
    rts

; Enhanced enemy system from Lesson 4 (simplified)
init_enemy_system:
    lda #$03        ; Number of enemies
    sta $90         ; Store enemy count
    
    ; Initialize enemy states
    lda #$01        ; All enemies active
    sta $91         ; Enemy 1 status
    sta $92         ; Enemy 2 status
    sta $93         ; Enemy 3 status
    
    rts

create_enemy_entities:
    ; Create Enemy 1
    lda #$0a        ; Enemy 1 X position
    sta $95         ; Store X
    lda #$05        ; Enemy 1 Y position
    sta $96         ; Store Y
    
    ; Create Enemy 2
    lda #$15        ; Enemy 2 X position
    sta $98         ; Store X
    lda #$08        ; Enemy 2 Y position
    sta $99         ; Store Y
    
    ; Create Enemy 3
    lda #$20        ; Enemy 3 X position
    sta $9b         ; Store X
    lda #$0c        ; Enemy 3 Y position
    sta $9c         ; Store Y
    
    rts

update_enemy_entities:
    ; Simplified enemy movement (from Lesson 4)
    ; Enemy 1 horizontal patrol
    lda $91         ; Check if active
    beq skip_enemy_1 ; Skip if destroyed
    
    lda $95         ; Load Enemy 1 X
    clc             ; Clear carry
    adc #$01        ; Move right
    cmp #$25        ; Check boundary
    bcc store_enemy_1_x ; Store if within bounds
    lda #$05        ; Reset to start
    
store_enemy_1_x:
    sta $95         ; Store new position
    
skip_enemy_1:
    ; Similar updates for Enemy 2 and 3 (simplified)
    rts

; Data tables for combat systems
health_thresholds:
    .byte $06, $0c, $12, $18, $1e, $24, $2a, $30, $36, $3c

energy_thresholds:
    .byte $06, $0c, $12, $18, $1e, $24, $2a, $30, $36, $3c
```

## What Just Happened? The Magic Behind Combat Systems

Now that you've experienced energy combat, let's understand how **loops and arrays** orchestrated this dynamic weapon system.

### Loops and Arrays: Your Combat Management System

The most important thing to understand: **loops and arrays enable efficient management of multiple combat entities**. In your energy combat code:

**Array Management**: Organizing multiple projectiles efficiently
```nasm
ldx #$07        ; Projectile index counter
clear_projectiles:
    lda #$00        ; Inactive projectile
    sta $b0,x       ; Clear projectile active flag
    sta $b8,x       ; Clear projectile X position
    sta $c0,x       ; Clear projectile Y position
    dex             ; Decrement index
    bpl clear_projectiles ; Continue until all cleared
```

**Loop Processing**: Updating all combat entities systematically
```nasm
update_projectile_loop:
    lda $b0,x       ; Load active flag
    beq skip_projectile ; Skip if inactive
    ; Update projectile position and collision
    dex             ; Previous projectile
    bpl update_projectile_loop ; Continue until all processed
```

**Combat System Examples Using Loops and Arrays:**

| Technique | Example | Use Case |
|-----------|---------|----------|
| **Array Initialization** | `sta $b0,x` | Set up projectile storage arrays |
| **Loop Processing** | `bpl update_projectile_loop` | Process all active projectiles |
| **Index Management** | `dex / bpl loop` | Efficiently iterate through arrays |

### Why Loops and Arrays Matter for Combat Games

**Efficient Entity Management** - Essential for multiple projectiles:
```nasm
ldx #$07        ; Start with last projectile
find_empty_slot:
```
