# NES Assembly Programming Coming Soon!

We're developing comprehensive 6502 assembly programming lessons for the Nintendo Entertainment System. Soon you'll learn to create authentic 8-bit games!

## What's Coming

- **6502 Assembly for NES** - Learn the NES's custom 6502 variant without decimal mode
- **PPU Programming** - Master sprites, backgrounds, and scrolling
- **Pattern Tables** - Design and organize your graphics tiles
- **Name Tables** - Create scrolling game worlds
- **APU Sound** - Program the five sound channels
- **Controller Input** - Read button presses and create responsive controls

## NES Architecture We'll Cover

- CHR ROM for graphics data
- PRG ROM for program code
- PPU registers at $2000-$2007
- Sprite DMA at $4014
- NMI-driven game loops
- Mappers for extended capabilities

## Classic Techniques You'll Learn

- Sprite multiplexing for more than 8 sprites per scanline
- Parallax scrolling effects
- Status bars with split-screen techniques
- Music engines and sound effect priority
- Save data using battery-backed RAM

## Development Timeline

The NES defined gaming for a generation, and we're crafting lessons that honor its technical achievements while making them accessible to modern learners.

Check back soon for the full course, or explore our [Commodore 64 lessons](/lessons/commodore-64) which are available now!
