# ZX Spectrum Assembly Programming Coming Soon!

We're developing comprehensive Z80 assembly programming lessons for the ZX Spectrum. Soon you'll learn:

## What's Coming

- **Z80 Assembly Fundamentals** - Master the Z80 processor that powers the Spectrum
- **Attribute System** - Work with the Spectrum's unique color attribute system
- **Border Effects** - Create the iconic loading screen border effects
- **Beeper Sound** - Generate sound through the built-in beeper
- **Tape Loading** - Understand how games loaded from cassette
- **48K Memory Management** - Make the most of limited RAM

## Spectrum Specifics We'll Cover

- Screen memory at 16384 (0x4000)
- Attribute memory for 8x8 character blocks
- The famous "color clash" and how to work with it
- OUT instructions for border control
- Interrupt-driven effects

## Development Timeline

We're actively developing these lessons. The ZX Spectrum was one of the most popular 8-bit computers in Europe, and we want to do justice to its unique architecture and the incredible games created for it.

Check back soon for the full course, or explore our [Commodore 64 lessons](/lessons/commodore-64) which are available now!
