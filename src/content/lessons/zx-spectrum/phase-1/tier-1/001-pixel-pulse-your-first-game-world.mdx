# Lesson 1: Pixel Pulse - Your First Game World

Welcome to ZX Spectrum assembly programming! In this lesson, you'll create your first game world using Z80 assembly language. You'll learn how the Spectrum's unique screen format works and build a colorful arena for your upcoming game.

## Understanding the ZX Spectrum

The ZX Spectrum has distinctive characteristics:

1. **Z80 CPU** - 8-bit processor running at 3.5MHz
2. **Screen format** - 256×192 pixels with attribute colors
3. **Memory layout** - Screen at $4000-$57FF, attributes at $5800-$5AFF
4. **Color system** - 8 colors with BRIGHT and FLASH attributes
5. **BASIC integration** - Easy loading from BASIC with LOAD "" CODE

## Step 1: Your First Z80 Program

Let's create a simple program that sets up the screen:

```z80
; Pixel Pulse - Lesson 1
; ZX Spectrum Z80 Assembly

        ORG $8000       ; Start at 32768

start:
        ; Clear screen to black
        CALL clear_screen
        
        ; Set border color to cyan
        LD A, 5         ; Cyan
        OUT (254), A    ; Set border
        
        ; Create title
        CALL draw_title
        
        ; Wait for key press
        CALL wait_key
        
        ; Return to BASIC
        RET

clear_screen:
        ; Clear display memory ($4000-$57FF)
        LD HL, $4000    ; Start of screen
        LD DE, $4001    ; Destination
        LD BC, $17FF    ; 6144 bytes
        LD (HL), 0      ; Clear first byte
        LDIR            ; Copy zeros to rest
        
        ; Clear attributes ($5800-$5AFF) 
        LD HL, $5800    ; Start of attributes
        LD DE, $5801    ; Destination  
        LD BC, $2FF     ; 768 bytes
        LD (HL), $07    ; Black on white
        LDIR            ; Fill attributes
        
        RET

draw_title:
        ; Position for "PIXEL PULSE" at row 10
        LD HL, $4000    ; Screen base
        LD BC, 10 * 32  ; Row 10 (32 bytes per row)
        ADD HL, BC      ; Point to row 10
        LD BC, 11       ; Center horizontally
        ADD HL, BC
        
        ; Draw each letter manually
        LD DE, letter_p ; P
        CALL draw_letter
        
        LD DE, letter_i ; I
        CALL draw_letter
        
        LD DE, letter_x ; X
        CALL draw_letter
        
        LD DE, letter_e ; E
        CALL draw_letter
        
        LD DE, letter_l ; L
        CALL draw_letter
        
        RET

draw_letter:
        ; Draw an 8x8 character from DE to screen at HL
        LD B, 8         ; 8 rows
        
draw_row:
        LD A, (DE)      ; Get character row
        LD (HL), A      ; Write to screen
        INC DE          ; Next character row
        
        ; Move to next screen row
        PUSH BC         ; Save row counter
        LD BC, 32       ; 32 bytes per row
        ADD HL, BC      ; Next row
        POP BC          ; Restore counter
        
        DJNZ draw_row   ; Next row
        
        ; Move HL back up and right for next letter
        LD BC, -256 + 1 ; Up 8 rows, right 1 column
        ADD HL, BC
        
        RET

wait_key:
        ; Wait for any key press
        LD A, $7F       ; Scan all rows
        IN A, (254)     ; Read keyboard
        AND $1F         ; Mask key bits
        CP $1F          ; All keys up?
        JR Z, wait_key  ; Keep waiting
        RET

; Character data (8x8 pixels each)
letter_p:
        DB %11111000
        DB %10001000  
        DB %10001000
        DB %11111000
        DB %10000000
        DB %10000000
        DB %10000000
        DB %00000000

letter_i:
        DB %11111000
        DB %00100000
        DB %00100000
        DB %00100000
        DB %00100000
        DB %00100000
        DB %11111000
        DB %00000000

letter_x:
        DB %10001000
        DB %01010000
        DB %00100000
        DB %00100000
        DB %01010000
        DB %10001000
        DB %10001000
        DB %00000000

letter_e:
        DB %11111000
        DB %10000000
        DB %10000000
        DB %11110000
        DB %10000000
        DB %10000000
        DB %11111000
        DB %00000000

letter_l:
        DB %10000000
        DB %10000000
        DB %10000000
        DB %10000000
        DB %10000000
        DB %10000000
        DB %11111000
        DB %00000000
```

## Step 2: Understanding Screen Memory

The ZX Spectrum has a unique screen layout:

```z80
set_pixel:
        ; Set pixel at coordinates B=Y, C=X
        
        ; Calculate screen address
        LD A, B         ; Y coordinate
        AND 7           ; Y mod 8 (pixel row in character)
        RRCA            ; Multiply by 32
        RRCA
        RRCA
        LD L, A         ; Low byte of address
        
        LD A, B         ; Y coordinate again
        AND $18         ; Character row (0, 8, 16)
        OR $40          ; Add screen base ($4000)
        LD H, A         ; High byte
        
        LD A, B         ; Y coordinate
        RLCA            ; Calculate middle section
        RLCA
        AND $E0
        LD B, A
        
        LD A, C         ; X coordinate
        RRCA            ; X / 8 = character column
        RRCA  
        RRCA
        AND $1F
        OR B
        LD L, A         ; Complete address
        
        ; Calculate pixel mask
        LD A, C         ; X coordinate
        AND 7           ; X mod 8
        LD B, A
        LD A, $80       ; Start with leftmost bit
        
shift_loop:
        RLC A           ; Rotate for pixel position
        DJNZ shift_loop
        
        ; Set the pixel
        OR (HL)         ; Combine with existing
        LD (HL), A      ; Write back
        
        RET
```

## Step 3: Color Attributes

Add color to your graphics using the attribute system:

```z80
set_attribute:
        ; Set color at character position B=row, C=column
        ; D = color value (INK + PAPER*8 + BRIGHT*64 + FLASH*128)
        
        ; Calculate attribute address
        LD A, B         ; Row
        RLCA            ; * 2
        RLCA            ; * 4  
        RLCA            ; * 8
        RLCA            ; * 16
        RLCA            ; * 32
        LD L, A         ; Low byte
        LD A, C         ; Column
        ADD A, L        ; Add column offset
        LD L, A
        LD H, $58       ; Attribute base ($5800)
        
        ; Set the color
        LD (HL), D      ; Write attribute
        RET

; Color constants for easy reference
INK_BLACK       EQU 0
INK_BLUE        EQU 1
INK_RED         EQU 2
INK_MAGENTA     EQU 3
INK_GREEN       EQU 4
INK_CYAN        EQU 5
INK_YELLOW      EQU 6
INK_WHITE       EQU 7

PAPER_BLACK     EQU 0
PAPER_BLUE      EQU 8
PAPER_RED       EQU 16
PAPER_MAGENTA   EQU 24
PAPER_GREEN     EQU 32
PAPER_CYAN      EQU 40
PAPER_YELLOW    EQU 48
PAPER_WHITE     EQU 56

BRIGHT          EQU 64
FLASH           EQU 128

draw_colorful_border:
        ; Create a colorful border around the screen
        
        ; Top border - cyan on blue
        LD B, 0         ; Row 0
        LD D, INK_CYAN + PAPER_BLUE + BRIGHT
        
top_border:
        LD C, B         ; Column = row counter
        CALL set_attribute
        INC B
        LD A, B
        CP 32           ; Full width?
        JR NZ, top_border
        
        ; Left border - yellow on red
        LD C, 0         ; Column 0
        LD B, 1         ; Start row 1
        LD D, INK_YELLOW + PAPER_RED + BRIGHT
        
left_border:
        CALL set_attribute
        INC B
        LD A, B
        CP 23           ; Screen height - 1?
        JR NZ, left_border
        
        ; Right border - green on magenta
        LD C, 31        ; Column 31
        LD B, 1         ; Start row 1
        LD D, INK_GREEN + PAPER_MAGENTA + BRIGHT
        
right_border:
        CALL set_attribute
        INC B
        LD A, B
        CP 23           ; Screen height - 1?
        JR NZ, right_border
        
        ; Bottom border - white on black
        LD B, 23        ; Row 23
        LD C, 0         ; Start column 0
        LD D, INK_WHITE + PAPER_BLACK + BRIGHT + FLASH
        
bottom_border:
        CALL set_attribute
        INC C
        LD A, C
        CP 32           ; Full width?
        JR NZ, bottom_border
        
        RET
```

## Step 4: BASIC Loader

Create a BASIC program to load your assembly code:

```basic
10 REM PIXEL PULSE - LOADER
20 BORDER 5: PAPER 0: INK 7: CLS
30 PRINT AT 10,8;"LOADING PIXEL PULSE..."
40 LOAD "pulse" CODE 32768
50 RANDOMIZE USR 32768
60 PRINT AT 12,10;"PRESS ANY KEY"
70 PAUSE 0
80 RUN
```

Save this as a BASIC program and your assembly as machine code at address 32768.

```z80
        CALL clear_screen
        
        ; Draw arena borders
        CALL draw_arena_walls

        CALL draw_corners
        
        ; Set arena colors
        CALL color_arena
        
        RET

draw_arena_walls:
        ; Draw top wall
        LD B, 2         ; Row 2
        LD C, 4         ; Start column 4
        LD A, $FF       ; Solid line
        
top_wall:
        PUSH BC
        CALL set_pixel_byte ; Set whole byte
        POP BC
        INC C
        LD A, C
        CP 28           ; End column
        JR NZ, top_wall
        
        ; Draw bottom wall (similar pattern)
        ; Draw left wall (vertical line)
        ; Draw right wall (vertical line)
        
        RET

set_pixel_byte:
        ; Set entire byte at character position B,C to value A
        PUSH AF
        
        ; Calculate screen address
        LD A, B
        AND $18
        OR $40
        LD H, A
        
        LD A, B
        RLCA
        RLCA
        AND $E0
        LD L, A
        
        LD A, C
        AND $1F
        OR L
        LD L, A
        
        ; Set the byte
        POP AF
        LD (HL), A
        
        RET

color_arena:
        ; Set colors for different arena zones
        
        ; Wall colors - white on blue
        LD D, INK_WHITE + PAPER_BLUE + BRIGHT
        LD B, 2         ; Top wall row
        LD C, 4         ; Start column
        
color_top_wall:
        CALL set_attribute
        INC C
        LD A, C
        CP 28
        JR NZ, color_top_wall
        
        ; Playing field - green on black
        LD D, INK_GREEN + PAPER_BLACK
        LD B, 3         ; Start row
        
color_field_row:
        LD C, 5         ; Start column
        
color_field_col:
        CALL set_attribute
        INC C
        LD A, C
        CP 27           ; End column
        JR NZ, color_field_col
        
        INC B
        LD A, B
        CP 20           ; End row
        JR NZ, color_field_row
        
        RET
```

## Understanding ZX Spectrum Architecture

### Memory Layout

The ZX Spectrum has a unique memory organization:

- **$0000-$3FFF**: ROM (BASIC interpreter)
- **$4000-$57FF**: Screen memory (6144 bytes)
- **$5800-$5AFF**: Attribute memory (768 bytes)  
- **$5B00-$FFFF**: RAM (available for programs)

### Screen Format

The screen memory is organized unusually:
- First third: pixel rows 0-63
- Second third: pixel rows 64-127  
- Third third: pixel rows 128-191

This makes vertical scrolling efficient but row calculations complex.

### Color System

Each 8×8 character cell has one attribute byte:
- Bits 0-2: INK color (0-7)
- Bits 3-5: PAPER color (0-7)
- Bit 6: BRIGHT flag (normal/bright)
- Bit 7: FLASH flag (steady/flashing)

## Common Issues

**Garbled display:** Check that you're writing to the correct screen memory addresses.

**Wrong colors:** Verify attribute memory calculations and color bit patterns.

**Crashes:** Ensure your code doesn't overflow into system areas below $4000.

**Loading problems:** Verify BASIC loader uses correct CODE address (32768).
