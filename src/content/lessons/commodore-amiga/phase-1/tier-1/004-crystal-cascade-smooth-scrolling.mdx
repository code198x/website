# Lesson 4: Crystal Cascade - Smooth Scrolling

**Your parallax world needs seamless movement!** In the last lesson, you added mesmerizing copper effects and color cycling to your multi-layered world. Today, you'll implement professional hardware-assisted smooth scrolling using the Amiga's revolutionary Agnus chip - creating seamless parallax movement that showcases commercial-quality directional control!

## Your Smooth Scrolling Awakens

Let's start with the magic - adding professional hardware-assisted scrolling to your parallax world:

```nasm
; Crystal Cascade - Smooth Scrolling Creation
    SECTION code,CODE

start:
    ; Set up enhanced parallax world from Lessons 1-3
    MOVE.L  #$00040000, A0      ; Background bitplane 0
    MOVE.L  #$00042000, A1      ; Middle layer bitplane 1
    MOVE.L  #$00044000, A2      ; Foreground bitplane 2
    
    ; Initialize crystal entities with copper effects from Lesson 3
    MOVE.L  #CrystalEntity, A3  ; Point to entity data
    MOVE.W  #160, ENTITY_X(A3)  ; Entity X position
    MOVE.W  #100, ENTITY_Y(A3)  ; Entity Y position
    
    ; Initialize professional scrolling system
    JSR     InitScrollingSystem
    
    ; Set up hardware-assisted scroll registers
    JSR     ConfigureScrollRegisters
    
    ; Create infinite scrolling buffers
    JSR     CreateScrollBuffers
    
    ; Initialize directional input system
    JSR     InitInputSystem
    
    ; Professional scrolling game loop
main_loop:
    JSR     ProcessPlayerInput      ; Handle directional control
    JSR     UpdateScrollPosition    ; Calculate scroll movement
    JSR     UpdateParallaxLayers    ; Coordinate multi-layer scrolling
    JSR     SyncScrollWithCopper    ; Maintain copper effect synchronization
    JSR     UpdateCrystalEntity     ; Update floating entity from Lesson 2
    BRA.S   main_loop

; Initialize professional scrolling system
InitScrollingSystem:
    ; Set up scroll position variables
    MOVE.W  #0, ScrollX         ; X scroll position
    MOVE.W  #0, ScrollY         ; Y scroll position
    MOVE.W  #0, ScrollXFine     ; Fine X scroll (0-15 pixels)
    MOVE.W  #0, ScrollYFine     ; Fine Y scroll (0-15 pixels)
    
    ; Initialize scroll velocities
    MOVE.W  #0, ScrollVelX      ; X scroll velocity
    MOVE.W  #0, ScrollVelY      ; Y scroll velocity
    
    ; Set up parallax layer offsets
    MOVE.W  #0, Layer0OffsetX   ; Background scroll offset
    MOVE.W  #0, Layer1OffsetX   ; Middle layer offset
    MOVE.W  #0, Layer2OffsetX   ; Foreground offset
    
    RTS

; Configure Agnus chip scroll registers
ConfigureScrollRegisters:
    ; Set up display window for scrolling
    MOVE.W  #$2C81, $DFF08E     ; Display start (DIWSTRT)
    MOVE.W  #$2CC1, $DFF090     ; Display stop (DIWSTOP)
    
    ; Configure data fetch for scrolling
    MOVE.W  #$0038, $DFF092     ; Data fetch start (DDFSTRT)
    MOVE.W  #$00D0, $DFF094     ; Data fetch stop (DDFSTOP)
    
    ; Set up scroll registers for each bitplane
    MOVE.W  #$0000, $DFF102     ; Bitplane 1 horizontal scroll
    MOVE.W  #$0000, $DFF104     ; Bitplane 2 horizontal scroll
    MOVE.W  #$0000, $DFF106     ; Bitplane 3 horizontal scroll
    
    ; Configure bitplane control for scrolling
    MOVE.W  #$3200, $DFF100     ; Bitplane control (3 planes, scrolling enabled)
    
    RTS

; Create infinite scrolling buffer system
CreateScrollBuffers:
    ; Set up background buffer (slowest parallax)
    MOVE.L  #BackgroundBuffer, A4 ; Buffer pointer
    MOVE.W  #320, BufferWidth     ; Buffer width
    MOVE.W  #256, BufferHeight    ; Buffer height
    
    ; Initialize buffer with repeating background pattern
    MOVE.W  #255, D0              ; Row counter
    MOVE.L  A4, A5                ; Working pointer
    
fill_background_buffer:
    MOVE.W  #319, D1              ; Column counter
    
fill_background_row:
    ; Create mountain/crystal background pattern
    MOVE.W  D0, D2                ; Use row as pattern base
    ADD.W   D1, D2                ; Add column for variation
    AND.W   #$001F, D2            ; Mask to pattern range
    MOVE.L  #BackgroundPatterns, A6 ; Pattern table
    MOVE.B  0(A6,D2.W), (A5)+     ; Place pattern byte
    
    DBRA    D1, fill_background_row ; Continue row
    DBRA    D0, fill_background_buffer ; Continue buffer
    
    ; Set up middle layer buffer (medium parallax)
    MOVE.L  #MiddleBuffer, A4     ; Middle buffer pointer
    JSR     FillMiddleLayerBuffer
    
    ; Set up foreground buffer (fastest parallax)  
    MOVE.L  #ForegroundBuffer, A4 ; Foreground buffer pointer
    JSR     FillForegroundBuffer
    
    RTS

; Initialize input system for directional control
InitInputSystem:
    ; Set up input state variables
    MOVE.B  #0, InputLeft         ; Left direction pressed
    MOVE.B  #0, InputRight        ; Right direction pressed
    MOVE.B  #0, InputUp           ; Up direction pressed
    MOVE.B  #0, InputDown         ; Down direction pressed
    
    ; Configure joystick/gamepad reading
    MOVE.W  #$0000, $DFF034       ; Joystick port control
    
    RTS

; Process player directional input
ProcessPlayerInput:
    ; Read joystick port 1
    MOVE.W  $DFF00C, D0          ; Read joystick data
    
    ; Check horizontal movement
    BTST    #9, D0               ; Test right direction
    BNE.S   check_left           ; Not pressed
    MOVE.B  #1, InputRight       ; Right pressed
    BRA.S   check_vertical
    
check_left:
    BTST    #1, D0               ; Test left direction
    BNE.S   clear_horizontal     ; Not pressed
    MOVE.B  #1, InputLeft        ; Left pressed
    BRA.S   check_vertical
    
clear_horizontal:
    MOVE.B  #0, InputLeft        ; Clear horizontal input
    MOVE.B  #0, InputRight
    
check_vertical:
    ; Check vertical movement
    BTST    #8, D0               ; Test down direction
    BNE.S   check_up             ; Not pressed
    MOVE.B  #1, InputDown        ; Down pressed
    BRA.S   process_input_done
    
check_up:
    BTST    #0, D0               ; Test up direction
    BNE.S   clear_vertical       ; Not pressed
    MOVE.B  #1, InputUp          ; Up pressed
    BRA.S   process_input_done
    
clear_vertical:
    MOVE.B  #0, InputUp          ; Clear vertical input
    MOVE.B  #0, InputDown
    
process_input_done:
    RTS

; Update scroll position based on input
UpdateScrollPosition:
    ; Update horizontal scrolling
    TST.B   InputRight           ; Check right input
    BEQ.S   check_scroll_left    ; Not pressed
    
    ; Scroll right with acceleration
    MOVE.W  ScrollVelX, D0       ; Load current velocity
    ADDQ.W  #1, D0               ; Accelerate
    CMP.W   #8, D0               ; Check maximum velocity
    BLE.S   store_right_vel      ; Within limits
    MOVE.W  #8, D0               ; Clamp velocity
    
store_right_vel:
    MOVE.W  D0, ScrollVelX       ; Store velocity
    BRA.S   update_x_position
    
check_scroll_left:
    TST.B   InputLeft            ; Check left input
    BEQ.S   decelerate_x         ; Not pressed
    
    ; Scroll left with acceleration  
    MOVE.W  ScrollVelX, D0       ; Load current velocity
    SUBQ.W  #1, D0               ; Accelerate left
    CMP.W   #-8, D0              ; Check minimum velocity
    BGE.S   store_left_vel       ; Within limits
    MOVE.W  #-8, D0              ; Clamp velocity
    
store_left_vel:
    MOVE.W  D0, ScrollVelX       ; Store velocity
    BRA.S   update_x_position
    
decelerate_x:
    ; Decelerate when no input
    MOVE.W  ScrollVelX, D0       ; Load velocity
    TST.W   D0                   ; Check direction
    BEQ.S   update_x_position    ; Already stopped
    BMI.S   decel_left           ; Negative velocity
    
    SUBQ.W  #1, D0               ; Decelerate right
    BRA.S   store_decel_x
    
decel_left:
    ADDQ.W  #1, D0               ; Decelerate left
    
store_decel_x:
    MOVE.W  D0, ScrollVelX       ; Store decelerated velocity
    
update_x_position:
    ; Apply velocity to scroll position
    MOVE.W  ScrollX, D1          ; Load current X position
    ADD.W   ScrollVelX, D1       ; Apply velocity
    MOVE.W  D1, ScrollX          ; Store new position
    
    ; Update fine scroll position for hardware
    MOVE.W  D1, D2               ; Copy position
    AND.W   #$000F, D2           ; Extract fine scroll (0-15)
    MOVE.W  D2, ScrollXFine      ; Store fine position
    
    ; Similar vertical scrolling update
    JSR     UpdateVerticalScroll
    
    RTS

; Update vertical scrolling (similar to horizontal)
UpdateVerticalScroll:
    ; Update vertical scrolling with input
    TST.B   InputDown            ; Check down input
    BEQ.S   check_scroll_up      ; Not pressed
    
    ; Scroll down with acceleration
    MOVE.W  ScrollVelY, D0       ; Load current velocity
    ADDQ.W  #1, D0               ; Accelerate
    CMP.W   #6, D0               ; Check maximum velocity (slower vertical)
    BLE.S   store_down_vel       ; Within limits
    MOVE.W  #6, D0               ; Clamp velocity
    
store_down_vel:
    MOVE.W  D0, ScrollVelY       ; Store velocity
    BRA.S   update_y_position
    
check_scroll_up:
    TST.B   InputUp              ; Check up input
    BEQ.S   decelerate_y         ; Not pressed
    
    ; Scroll up with acceleration
    MOVE.W  ScrollVelY, D0       ; Load current velocity
    SUBQ.W  #1, D0               ; Accelerate up
    CMP.W   #-6, D0              ; Check minimum velocity
    BGE.S   store_up_vel         ; Within limits
    MOVE.W  #-6, D0              ; Clamp velocity
    
store_up_vel:
    MOVE.W  D0, ScrollVelY       ; Store velocity
    BRA.S   update_y_position
    
decelerate_y:
    ; Decelerate when no input
    MOVE.W  ScrollVelY, D0       ; Load velocity
    TST.W   D0                   ; Check direction
    BEQ.S   update_y_position    ; Already stopped
    BMI.S   decel_up             ; Negative velocity
    
    SUBQ.W  #1, D0               ; Decelerate down
    BRA.S   store_decel_y
    
decel_up:
    ADDQ.W  #1, D0               ; Decelerate up
    
store_decel_y:
    MOVE.W  D0, ScrollVelY       ; Store decelerated velocity
    
update_y_position:
    ; Apply velocity to scroll position
    MOVE.W  ScrollY, D1          ; Load current Y position
    ADD.W   ScrollVelY, D1       ; Apply velocity
    MOVE.W  D1, ScrollY          ; Store new position
    
    ; Update fine scroll position for hardware
    MOVE.W  D1, D2               ; Copy position
    AND.W   #$000F, D2           ; Extract fine scroll (0-15)
    MOVE.W  D2, ScrollYFine      ; Store fine position
    
    RTS

; Update parallax layers with coordinated scrolling
UpdateParallaxLayers:
    ; Calculate parallax offsets for each layer
    MOVE.W  ScrollX, D0          ; Load main scroll position
    
    ; Background layer (slowest - 1/4 speed)
    MOVE.W  D0, D1               ; Copy scroll position
    ASR.W   #2, D1               ; Divide by 4 for slow parallax
    MOVE.W  D1, Layer0OffsetX    ; Store background offset
    
    ; Middle layer (medium - 1/2 speed)
    MOVE.W  D0, D2               ; Copy scroll position
    ASR.W   #1, D2               ; Divide by 2 for medium parallax
    MOVE.W  D2, Layer1OffsetX    ; Store middle offset
    
    ; Foreground layer (full speed)
    MOVE.W  D0, Layer2OffsetX    ; Store foreground offset (full speed)
    
    ; Apply scrolling to hardware registers
    JSR     ApplyHardwareScroll
    
    ; Update buffer positions for infinite scrolling
    JSR     UpdateScrollBuffers
    
    RTS

; Apply scroll positions to Agnus chip registers
ApplyHardwareScroll:
    ; Set bitplane horizontal scroll registers
    MOVE.W  Layer0OffsetX, D0    ; Background offset
    AND.W   #$000F, D0           ; Extract fine scroll bits
    MOVE.W  D0, $DFF102          ; Set bitplane 1 scroll
    
    MOVE.W  Layer1OffsetX, D1    ; Middle layer offset
    AND.W   #$000F, D1           ; Extract fine scroll bits
    MOVE.W  D1, $DFF104          ; Set bitplane 2 scroll
    
    MOVE.W  Layer2OffsetX, D2    ; Foreground offset
    AND.W   #$000F, D2           ; Extract fine scroll bits
    MOVE.W  D2, $DFF106          ; Set bitplane 3 scroll
    
    ; Update bitplane pointers for coarse scrolling
    JSR     UpdateBitplanePointers
    
    RTS

; Update bitplane pointers for seamless scrolling
UpdateBitplanePointers:
    ; Calculate new bitplane addresses based on scroll position
    MOVE.W  Layer0OffsetX, D0    ; Background scroll
    LSR.W   #4, D0               ; Convert to coarse scroll (divide by 16)
    MOVE.W  ScrollY, D1          ; Vertical scroll
    LSR.W   #4, D1               ; Convert to coarse scroll
    
    ; Calculate background bitplane address
    MULU.W  #40, D1              ; Multiply Y by row size
    ADD.W   D0, D1               ; Add X offset
    MOVE.L  #$00040000, A0       ; Base bitplane address
    ADD.L   D1, A0               ; Calculate scrolled address
    
    ; Set bitplane pointers
    MOVE.L  A0, $DFF0E0          ; Bitplane 1 pointer high
    MOVE.W  A0, $DFF0E2          ; Bitplane 1 pointer low
    
    ; Similar calculations for other bitplanes
    JSR     UpdateMiddleBitplane
    JSR     UpdateForegroundBitplane
    
    RTS

; Synchronize scrolling with copper effects from Lesson 3
SyncScrollWithCopper:
    ; Ensure copper effects remain synchronized during scrolling
    MOVE.W  ScrollX, D0          ; Load scroll position
    AND.W   #$003F, D0           ; Mask to color cycle range
    
    ; Update copper color cycling based on scroll position
    MOVE.L  #$00DFF180, A1       ; Color register base
    MOVE.L  #ColorGradientData, A2 ; Gradient data from Lesson 3
    LSL.W   #1, D0               ; Convert to word offset
    MOVE.W  0(A2,D0.W), 8(A1)    ; Update background color
    
    ; Maintain entity positioning during scroll
    JSR     AdjustEntityForScroll
    
    RTS

; Adjust crystal entity position relative to scrolling
AdjustEntityForScroll:
    ; Load entity position from Lesson 2
    MOVE.L  #CrystalEntity, A3   ; Entity data pointer
    MOVE.W  ENTITY_X(A3), D3     ; Load entity X
    MOVE.W  ENTITY_Y(A3), D4     ; Load entity Y
    
    ; Adjust for current scroll position
    SUB.W   ScrollX, D3          ; Adjust for horizontal scroll
    SUB.W   ScrollY, D4          ; Adjust for vertical scroll
    
    ; Keep entity on screen with wrapping
    CMP.W   #-32, D3             ; Check left boundary
    BGE.S   check_right_bound    ; Within bounds
    ADD.W   #384, D3             ; Wrap from right
    
check_right_bound:
    CMP.W   #352, D3             ; Check right boundary
    BLE.S   check_vertical       ; Within bounds
    SUB.W   #384, D3             ; Wrap to left
    
check_vertical:
    CMP.W   #-32, D4             ; Check top boundary
    BGE.S   check_bottom         ; Within bounds
    ADD.W   #288, D4             ; Wrap from bottom
    
check_bottom:
    CMP.W   #256, D4             ; Check bottom boundary
    BLE.S   store_adjusted       ; Within bounds
    SUB.W   #288, D4             ; Wrap to top
    
store_adjusted:
    ; Store adjusted screen position for rendering
    MOVE.W  D3, EntityScreenX    ; Store screen X
    MOVE.W  D4, EntityScreenY    ; Store screen Y
    
    RTS

; Fill middle layer buffer with crystal formations
FillMiddleLayerBuffer:
    ; Create middle layer crystal patterns
    MOVE.W  #255, D0             ; Row counter
    
fill_middle_loop:
    MOVE.W  #319, D1             ; Column counter
    
fill_middle_row:
    ; Create crystal formation pattern
    MOVE.W  D0, D2               ; Use row as base
    LSL.W   #2, D2               ; Scale pattern
    ADD.W   D1, D2               ; Add column variation
    AND.W   #$003F, D2           ; Mask to pattern range
    MOVE.L  #CrystalPatterns, A6 ; Crystal pattern table
    MOVE.B  0(A6,D2.W), (A4)+    ; Place crystal byte
    
    DBRA    D1, fill_middle_row  ; Continue row
    DBRA    D0, fill_middle_loop ; Continue buffer
    
    RTS

; Fill foreground buffer with detail elements
FillForegroundBuffer:
    ; Create foreground detail patterns
    MOVE.W  #255, D0             ; Row counter
    
fill_foreground_loop:
    MOVE.W  #319, D1             ; Column counter
    
fill_foreground_row:
    ; Create detail pattern with transparency
    MOVE.W  D0, D2               ; Use row as base
    ADD.W   D1, D2               ; Add column
    LSL.W   #1, D2               ; Scale for detail
    AND.W   #$001F, D2           ; Mask to pattern range
    
    ; Add some transparency for foreground effect
    CMP.W   #16, D2              ; Check pattern value
    BLT.S   place_detail         ; Place detail
    MOVE.B  #0, (A4)+            ; Transparent pixel
    BRA.S   continue_foreground
    
place_detail:
    MOVE.L  #DetailPatterns, A6  ; Detail pattern table
    MOVE.B  0(A6,D2.W), (A4)+    ; Place detail byte
    
continue_foreground:
    DBRA    D1, fill_foreground_row  ; Continue row
    DBRA    D0, fill_foreground_loop ; Continue buffer
    
    RTS

; Update scroll buffers for infinite scrolling
UpdateScrollBuffers:
    ; Check if buffers need updating for seamless scrolling
    MOVE.W  ScrollX, D0          ; Load scroll position
    AND.W   #$01FF, D0           ; Mask to buffer wrap point
    CMP.W   #480, D0             ; Check wrap threshold
    BLT.S   no_buffer_update     ; No update needed
    
    ; Refresh buffer content for continuous scrolling
    JSR     RefreshScrollBuffers
    
no_buffer_update:
    RTS

; Refresh scroll buffers for continuous movement
RefreshScrollBuffers:
    ; Regenerate buffer content at new position
    MOVE.L  #BackgroundBuffer, A4 ; Background buffer
    JSR     FillMiddleLayerBuffer  ; Refresh middle layer
    
    MOVE.L  #ForegroundBuffer, A4 ; Foreground buffer  
    JSR     FillForegroundBuffer  ; Refresh foreground
    
    RTS
```

## What Just Happened? The Magic Behind Professional Scrolling

Now that you've experienced your smooth scrolling, let's understand how **memory management** orchestrated this professional movement system.

### Memory Management: Your Professional Scrolling Foundation

The most important thing to understand: **efficient memory management enables smooth scrolling performance**. In your smooth scrolling code:

**Buffer Management**: Organizing scrolling data efficiently
```nasm
MOVE.L  #BackgroundBuffer, A4 ; Buffer pointer (absolute addressing)
MOVE.W  #320, BufferWidth     ; Buffer dimensions (immediate to absolute)
JSR     FillMiddleLayerBuffer ; Efficient buffer operations
```

**Register Allocation**: Using address registers for pointer operations
```nasm
MOVE.L  #CrystalEntity, A3   ; Entity data pointer (absolute addressing)
MOVE.W  ENTITY_X(A3), D3     ; Structure field access (register indirect with displacement)
ADD.L   D5, A6               ; Pointer arithmetic (register to register)
```

**Hardware Integration**: Coordinating with Agnus chip registers
```nasm
MOVE.W  D0, $DFF102          ; Hardware scroll register (register to absolute)
MOVE.L  A0, $DFF0E0          ; Bitplane pointer (register to absolute)
MOVE.W  #$3200, $DFF100      ; Bitplane control (immediate to absolute)
```

**Memory Management Examples in Professional Scrolling:**

| Technique | Example | Use Case |
|-----------|---------|----------|
| **Buffer Allocation** | `BackgroundBuffer: DS.B 81920` | Efficient scrolling buffer management |
| **Pointer Arithmetic** | `ADD.L D5, A6` | Dynamic bitplane address calculation |
| **Structure Access** | `ENTITY_X(A3)` | Organized entity data management |

### The Agnus Chip: Your Scrolling Accelerator

**Why Agnus Made Amiga Scrolling Legendary:**
- **Hardware Assistance**: Automatic bitplane shifting without CPU overhead
