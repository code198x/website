The PlayStation 2 achieved unprecedented success through smart positioning and an overwhelming game library. Launching as an affordable DVD player when standalone units cost more, it entered homes beyond gaming enthusiasts. Sony's third-party relationships delivered exclusive content while backwards compatibility preserved PlayStation 1 libraries. No console before or since has matched its 155 million sales.

## Fast facts

- **Manufacturer:** [Sony Computer Entertainment](/vault/companies/sony).
- **Release:** March 2000 (Japan), October 2000 (NA/EU).
- **Units sold:** 155+ million (best-selling console ever).
- **Library:** 4,000+ titles.
- **Production ended:** 2013.

## The specification, as announced

Sony gave the machine's numbers at announcement and *Edge* printed the table in
April 1999. Two scans of that issue are held here, which is how the noisier
figures were read.

| | |
|---|---|
| Floating point | 6.2 GFLOPS |
| Geometry, transform only | 66m polys/sec |
| ...plus lighting | 38m polys/sec |
| ...plus fog | 36m polys/sec |
| Bézier surface generation | 16m polys/sec |
| Image processing | 150m pixels/sec |
| Memory bus | 3.2 Gb/sec |

The geometry row is the honest one, and it is unusual for a launch table to
include it. The headline number is 66 million polygons a second, but that is
transform alone; light the polygons and it falls to 38 million, add fog and it is
36. Sony published the cost of doing the work rather than the number with the
work removed — a distinction most of the generation's marketing declined to make.

The Graphics Synthesiser's figures are all about bandwidth to embedded memory:
"Total Memory Bandwidth 48Gb/sec" across a "DRAM Bus Width" of "2,560bits". The
pixel format is spelled out as "RGB:Alpha:Z Buffer (24:8:32)".

## The old machine is still in there

The most interesting line in the table is the shortest. Under the I/O processor,
where a spec sheet would normally name a controller chip, it says:

> CPU Core — Current PlayStation CPU

Backward compatibility is not emulation and not a compatibility mode. The
original PlayStation's processor sits inside the PlayStation 2 doing the I/O, and
when a PS1 disc goes in, the subordinate chip is simply given the machine.

This is the same move Sega made with the [Mega Drive](/vault/systems/sega-mega-drive),
where the Master System's Z80 stays on board as the sound processor and becomes
the whole computer again in Master System mode. The cost of an old CPU had fallen
far enough that keeping one was cheaper than pretending to be one.

## The DVD advantage

Trojan horse strategy:
- DVD players cost 300+ dollars in 2000.
- PS2 launched at 299 dollars with DVD playback.
- Families bought it for films.
- Gaming became secondary benefit for some.
- Accelerated DVD adoption.
