The **Atari Falcon030** continued the [Atari ST](/vault/systems/atari-st) computer line with a new combination of processors. A 16MHz Motorola 68030 ran the main system. A separate 32MHz [Motorola 56001](/vault/hardware/motorola-56001) digital signal processor, or DSP, supplied programmable processing suited to streams of data, including sound. MIDI connections remained part of the machine.

Atari's October 1992 service guide documents the hardware, while the owner's manual carries a 1992 copyright and a January 1993 printing date. Announcement-era documentation is not evidence of immediate worldwide delivery. The February 1993 *Atari Explorer Online* was still carrying forward-looking statements about North American machines arriving in March. ([Service guide](https://archive.org/details/Atari_Falcon030_Service_Guide_P_C303062-001_Oct_1_1992); [contemporary newsletter](https://www.neperos.com/article/pwn9dx08ab1f4891).)

## Two processors need a plan

The DSP did not make an ordinary 68030 program automatically run on two processors. Software had to give it work, exchange data and coordinate results. Its local processing resources and connections to the audio system made that arrangement useful, but the program still had to use them.

The distinction also prevents a misleading sound specification. The 56001's 24-bit processing words describe its arithmetic. The Falcon's audio conversion hardware has its own sample format; the service guide documents 16-bit stereo conversion. Processor word width is not the same thing as the resolution of the analogue sound output.

## A configuration, not one universal specification

The owner's manual lists 1MB, 4MB and 14MB memory configurations, a high-density floppy drive and provision for optional equipment. A hard disk or floating-point coprocessor should not be assumed because the machine could accommodate one. The display facilities also go beyond the ST, through the Falcon's VIDEL video hardware. ([Owner's manual, introduction and features](https://www.atarimania.com/documents/Atari-Falcon030-Owners-Manual.pdf).)

TOS supplied the recognisable desktop environment. MultiTOS belongs in the machine's software history, but should not be conflated with a claim that every Falcon shipped with a multitasking operating system in ROM.

## Compatibility includes the expanded machines

The ST connection explains familiar software and MIDI use; it does not guarantee every program that depended on ST hardware timing will behave identically. The same caution applies when looking forward to the [demoscene](/vault/communities/demo-scene). A demonstration made for an accelerated Falcon is evidence about that expanded configuration, not a benchmark for a stock 68030 machine.

The [Black Lotus](/vault/groups/the-black-lotus) entry connects Falcon-related demo work to a broader history of productions and ports. Checking the processor, memory and expansion requirements is part of identifying which machine a particular release expects.
