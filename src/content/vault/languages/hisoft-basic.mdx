A BASIC compiler offers a tempting arrangement: keep the language used to write the program, but turn it into machine code before running it. **HiSoft BASIC** sold that possibility on several home computers. The important questions are which edition is being used, which BASIC features it accepts and what its compiled program still needs at run time.

The Spectrum version has unusually clear surviving documentation. Its author, **Cameron Hayne**, preserved the October 1986 manual and corrected its transcription. That is evidence for this compiler’s design; it does not establish the authorship or features of every HiSoft product with the same name.

## Choose what to compile

The Spectrum manual uses compiler directives inside `REM` statements. `REM: OPEN#` and `REM: CLOSE#` mark the portions to compile. Those remarks are instructions to the compiler even though ordinary [Sinclair BASIC](/vault/languages/sinclair-basic) treats them as comments.

Compilation produces machine code that must fit into memory alongside the program’s other needs. The manual describes where the output is placed and how entry addresses are reported. It also lists differences from interpreted Spectrum BASIC. A working interpreted program therefore needs checking against the supported language before compilation, rather than assuming every legal statement can be translated unchanged. (Manual, commands and differences sections.)

The author recommends testing the BASIC first with varied inputs. Compilation is a change in execution method, not a repair for faulty logic. A loop with the wrong stopping condition remains wrong when it runs faster.

## A family name needs an edition

The Centre for Computing History also holds an Amiga HiSoft BASIC manual, dated 1988, describing an interactive compiler with Amiga graphics support. Its environment is different from the Spectrum compiler’s. Memory organisation, operating-system interfaces and libraries belong to that platform edition.

This places HiSoft BASIC beside [GFA BASIC](/vault/languages/gfa-basic), [AMOS](/vault/languages/amos) and [Blitz BASIC 2](/vault/languages/blitz-basic-2) as another route through the period’s programming tools. They offered different combinations of editing, compilation and machine facilities. A claim of speed or compatibility needs a particular program and version behind it.

The compiler’s practical bargain is precise: the programmer can retain a higher-level source language, while taking responsibility for the subset, memory layout and runtime arrangements its implementation requires.
