The **Konami Code** (↑↑↓↓←→←→BA) is the most famous cheat code in gaming history. Created by Kazuhisa Hashimoto to make Gradius easier during testing, it was left in the released game and spread to over 100 Konami titles and countless others as a gaming cultural touchstone.

## Fast facts

- **Sequence:** ↑ ↑ ↓ ↓ ← → ← → B A
- **Creator:** Kazuhisa Hashimoto
- **First game:** [Gradius](/vault/games/gradius) (1986)
- **Famous use:** [Contra](/vault/games/contra) (30 lives)
- **Legacy:** widely reused, though the often-cited "100+ games" figure is unsourced

## Origin

The code belongs to the **Famicom port**, not the arcade game. *Gradius* reached
arcades in 1985 without it; Kazuhisa Hashimoto added it to the 1986 home
conversion, which is the version a tester had to replay until he could no longer
finish it unaided.

| Aspect | Detail |
|--------|--------|
| **Game** | *Gradius*, Famicom port (1986) — not the 1985 arcade original |
| **Purpose** | Testing aid |
| **Left in** | Accidentally shipped |
| **Effect in Gradius** | Entered while paused; upgrades the Vic Viper's weapons |

**Why that sequence.** It was picked to be "relatively easy for game testers to
remember, but difficult to input accidentally." Both constraints are doing work:
a memorable code a player could stumble into would fire during ordinary play.

**Why renderings disagree about Start.** Because *Gradius* takes the code while
paused, "the START is technically optional" — the game's state changes as soon as
the sequence completes, and Start only unpauses it so you can see the effect. "As
a result, not all games include it in their implementations." *Nintendo Power*
printed it with Start; this entry prints it without; both were current.

## The Contra Effect

| Without Code | With Code |
|--------------|-----------|
| 3 lives | 30 lives |
| "Almost necessary" to have a chance | Completable |
| Frustrating | Fun |

Contra made the code famous. Sega Retro records the effect on the game's reputation: the code was "often dubbed the 'Contra code' or '30 lives code', almost necessary for players to have a chance of beating the game."

## Widespread adoption

*Nintendo Power* documented it in January 1993 as a portable convention — "a
long-standing code which makes for special circumstances in several games" —
rather than one title's cheat:

| Game | Effect | Entered |
|------|--------|---------|
| **Contra** | 30 fighters in reserve | Title screen |
| **Life Force** | 29 ships in reserve | Title screen |
| **Gradius** / **Nemesis** | Weapons and power-ups | Paused, mid-action |
| **T.M.N.T. — Fall of the Foot Clan** (Game Boy) | One-time energy recharge | Paused |

On Sega hardware the implementations are nameable: *Castlevania: Bloodlines*, *The
Jungle Book*, *King of the Monsters* and *Mega Turrican* on Mega Drive; the
Gradius, Salamander and Detana Twinbee Deluxe Packs, *Parodius*, *Sexy Parodius*
and *F1 Challenge* on Saturn; *ESPN International Track & Field* on Dreamcast; and
*Super Monkey Ball Jr.* on Game Boy Advance, which "teases the user if they try
and use the Konami code on its title screen."

⚠ **The "100+ games" figure is not sourced, and the spread was slower than it
sounds.** "For many years, the Konami code was restricted to just Konami games,
becoming more mainstream after the dawn of the internet" — and not even
consistently within Konami, with "even Konami failing to include it in many of
their releases."
