**Tool-Assisted Speedruns** (TAS) are speedruns created using emulator features like frame advance, save states, and input recording. While not humanly possible, TAS demonstrates theoretical perfect play, often reveals new strategies, and provides entertainment through superhuman precision.

## Fast facts

- **Tools:** Frame advance, save states, rerecording
- **Platform:** Emulators (BizHawk, FCEUX, etc.)
- **Goal:** Theoretical perfection
- **Entertainment:** Often more impressive than RTA
- **Research:** Discovers new techniques

## TAS vs RTA

| TAS | RTA (Real-Time Attack) |
|-----|------------------------|
| Frame-perfect inputs | Human execution |
| Emulator required | Can use original hardware |
| Rerecording allowed | Single attempt |
| Theoretical limit | Practical limit |
