## Overview

Publishers wanted to sell software. Users wanted to copy it. Copy protection became an arms race—each new technique defeated, each defeat spawning new protection. From bad sectors to code wheels to manual lookups, the battle between protection and cracking shaped software distribution and spawned the crack intro artform.

## Fast facts

- **Purpose:** Prevent unauthorised copying.
- **Result:** Arms race with crackers.
- **Side effects:** Legitimate user frustration.
- **Legacy:** DRM evolution.
