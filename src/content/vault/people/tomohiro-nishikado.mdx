## Overview

Tomohiro Nishikado did everything. He designed *Space Invaders*. He programmed it. When existing hardware couldn't handle his vision, he designed custom hardware. The 1978 result caused coin shortages in Japan and launched the arcade boom. One person created an industry.

## Fast facts

- **Born:** 1944, Japan.
- **Company:** Taito.
- **Creation:** Space Invaders (1978).
- **Role:** Designer, programmer, hardware engineer.

## Space Invaders development

| Challenge | Solution |
|-----------|----------|
| Slow hardware | Made enemies accelerate as they die |
| Limited graphics | Simple, iconic sprites |
| No precedent | Invented the template |
| Hardware limits | Designed custom board |

## Technical innovation

Nishikado built custom hardware because existing systems couldn't:
- Handle enough sprites
- Process fast enough
- Create the experience he envisioned

The Intel 8080-based board became standard.

## Design decisions

| Choice | Impact |
|--------|--------|
| Descending enemies | Created tension |

| Mystery ship | Risk/reward bonus |

## The speed increase

Originally a limitation:
- Fewer enemies = faster processing
- Became core gameplay feature
- Tension builds naturally
- Accidental design genius
