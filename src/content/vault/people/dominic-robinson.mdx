**Dominic Robinson** reached **Hewson** with demonstrations of what he could make the [ZX Spectrum](/vault/systems/sinclair-zx-spectrum) do. In a February 1988 *Sinclair User* interview, he recalls answering the publisher’s call for programmers before he had completed a game.

His work on [Uridium](/vault/games/uridium) and **Zynaps** turned those technical experiments into software that people could play. The route is useful to distinguish: demonstrating a scrolling or drawing effect was a starting point, while completing a game required rules, controls, levels and tools around it.

## An arcade game built with other tools

Robinson’s signed *Background Noise* article about *Zynaps* describes using an **Amstrad PCW 8512** in development. The machine on which the programmer worked was not necessarily the machine on which the game ran.

That separation made room for tools which prepared code and data for the Spectrum. It also helped organise the game’s movement and encounters through its **Manoeuvre** and **Episode** interpreters. The article describes a way to express patterns of behaviour without writing each encounter as a fresh block of unrelated instructions. (*Sinclair User* 65, p. 30.)

These tools are part of the game’s design. Reusable descriptions make it possible to adjust how enemies arrive and move while keeping the underlying routine responsible for carrying out those descriptions.

## More than one update rate

The same account gives a target of 25 frames per second, synchronised with the Spectrum’s 50 Hz interrupts. It also describes priority-based background work and credits Steve Turner with the music. Drawing, sound and less urgent tasks did not all need the same place in the schedule.

That division connects Robinson’s work with [frame timing](/vault/techniques/frameskipping-and-interpolation). Smooth sound, responsive input and a moving background each impose costs, but their routines can be organised differently. The useful question is what must be ready for the next visible frame and what needs an update between frames.

The interview and signed article complement one another. The former explains how Robinson found the work; the latter shows some of the machinery needed to finish it. Together they give a more precise picture than treating a Spectrum conversion as a single clever display effect.
