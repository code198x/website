## Overview

ProTracker democratised music production on the Amiga. Its four-channel sample-based interface let anyone with an Amiga create music—no formal training required. The MOD files it produced spread across BBSes and demo scene networks, creating a shared musical language that echoes in modern DAWs.

## Fast facts

- **Original author:** Lars "Zap" Hamre (from Amiga Noisetracker).
- **First release:** 1990.
- **Channels:** 4 (matching Paula hardware).
- **Format:** .MOD files became universal standard.

## The tracker interface

| Element | Function |
|---------|----------|
| Pattern editor | Note entry in vertical columns |
| Sample list | Loaded instruments |
| Song sequence | Pattern playback order |
| Sample editor | Cut, loop, tune samples |

## Pattern format

Each row contained:
```
Note Sample Effect
C-3  01      C10    (C-3 with sample 1, volume slide)
```

Patterns typically 64 rows, tempo adjustable.

## Effects

| Effect | Code | Use |
|--------|------|-----|
| Arpeggio | 0xy | Rapid note cycling |
| Portamento | 1xx/2xx | Pitch slide |
| Vibrato | 4xy | Pitch wobble |
| Volume slide | Axy | Fade in/out |
| Pattern break | Dxx | Jump to next pattern |
| Set speed | Fxx | Change tempo |

## Workflow

Creating a track:
1. Load or sample instruments
2. Create patterns (4-channel chunks)
3. Arrange patterns into song
4. Fine-tune with effects
5. Save as .MOD

## Sample-based music

ProTracker's approach:
- Record or find samples
- Loop points define sustain
- Pitch shifted for different notes
- Memory limited total samples

## The MOD format

.MOD files were self-contained:
- Samples embedded in file
- Portable across platforms
- Small file sizes
- Easy to share on BBSes

## Scene adoption

Demo scene embraced ProTracker:

- Established composers emerged
- Music traded alongside demos
