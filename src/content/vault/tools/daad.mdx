**DAAD** lets an author keep the core of an adventure in one source file, then prepare it for several computers. [Tim Gilberts](/vault/people/tim-gilberts) wrote the system in the late 1980s for the Spanish adventure publisher **Aventuras AD**, founded by **Andrés Samudio**.

It continued the line of ideas behind [Gilsoft](/vault/companies/gilsoft)’s [The Quill](/vault/tools/the-quill) and [PAW](/vault/tools/paw). Its November 1991 technical guide describes a compiler-based system with interpreters for machines including the Spectrum, C64, CPC, MSX, Atari ST, Amiga, PC and PCW.

## Source, database, interpreter

The author writes tables describing locations, vocabulary, objects, text and processes. The compiler checks the source and makes a **database** for the selected target. An interpreter on that computer runs it, supplying the routines for input, display and adventure behaviour.

Processes use **CondActs**: conditions which test the game state and actions which change it. A test can establish that an object is present; a following action can move it or print a response. The guide describes both English and Spanish parsers.

## Portability has boundaries

The guide’s opening explicitly qualifies the write-once ambition. The core design can remain shared while extra work makes use of each machine. Graphics are a clear example: the documented system distinguishes compact drawing commands for 8-bit targets from image-based work for 16-bit machines.

Its separate *EXTERN.DOC* makes another boundary concrete. Added assembly routines need the correct processor code and addresses for each machine. An adventure database can carry shared logic without making machine-specific extensions portable.

## A continuing toolset

The maintained repository records Samudio’s contribution of DAAD to the public domain. It also points to later tools, including a replacement compiler and **Maluva**, which adds facilities such as pixel images and extra disk content. Those additions belong to the system’s continuation, rather than to every original DAAD release.

[Adventuron](/vault/tools/adventuron) offers a different browser-based route to adventure writing. Both preserve an approach in which an author describes a world and rules, while software supplies much of the machinery for playing it.
