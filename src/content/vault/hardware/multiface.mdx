## Overview

The **Multiface One** (and later **Multiface 128**) was a hardware device from Romantic Robot that plugged into the ZX Spectrum and could freeze any running program. Users could then search memory for values, create cheats, and save the entire memory state to tape or disk. While marketed as a backup and development tool, it was equally useful for piracy and cheat creation.

## Fast Facts

- **Manufacturer:** Romantic Robot
- **Released:** 1986
- **Platform:** ZX Spectrum
- **Function:** Freeze, peek, poke, save
- **Price:** ~£40
- **Controversy:** Piracy enabler

## Capabilities

| Feature | Use |
|---------|-----|
| **Freeze** | Stop any running program |
| **Search** | Find specific values in memory |
| **Poke** | Modify memory directly |
| **Save** | Snapshot entire memory state |
| **Toolkit** | Disassemble, examine code |

## How It Worked

1. **Press red button** - Hardware interrupts CPU
2. **Enter Multiface menu** - Program frozen
3. **Search/modify** - Find lives counter, etc.
4. **Save snapshot** - To tape or disk
5. **Resume** - Continue or restart

## Creating Cheats

The typical POKE hunting process:

| Step | Action |
|------|--------|
| **1** | Note current lives (e.g., 3) |
| **2** | Search memory for value 3 |
| **3** | Lose a life (now 2) |
| **4** | Search again for 2 |
| **5** | Narrow down to correct address |
| **6** | POKE to maximum value |

## Controversy

The Multiface occupied legal grey area:

| Use | Legality |
|-----|----------|
| **Backup own games** | Arguably legal |
| **Create cheats** | Legal |
| **Copy others' games** | Piracy |
| **Crack protection** | Enabled this |

## Magazine Integration

Multiface became part of the ecosystem:

- Magazines published POKE addresses found with it
- Readers submitted discoveries
- POKE pages became regular features
- Created community participation

## Legacy

The Multiface represented technology's dual-use nature—equally capable of legitimate backup and development as piracy and cheating. It democratised game hacking, enabling anyone with the device to discover and share cheats.
