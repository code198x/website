With a game cartridge fitted, a [ZX Spectrum](/vault/systems/sinclair-zx-spectrum) could start playing as soon as its power came on. Sinclair's ZX Interface 2 added the cartridge socket and two joystick ports in one box, launched in late September 1983 for £19.95. The cartridges cost £14.95 each, a substantial extra purchase beside the interface. ([*Sinclair User*, December 1983, news and review](https://worldofspectrum.org/hardware/feat6.html).)

## Running from the cartridge

An ordinary cassette program has to be copied into RAM before it can run. An Interface 2 cartridge holds its program in read-only memory, or ROM, which the processor can use directly. Sinclair's service manual explains that inserting the cartridge disables the Spectrum's own ROM and gives the processor access to the cartridge through the expansion connector. The game takes the place normally occupied by BASIC. ([Service manual](https://spectrumforeveryone.com/wp-content/uploads/2017/08/ZX-Interface-1-2-Microdrive-Service-Manual.pdf), section 1.3.)

That arrangement imposed a limit: without extra paging hardware to switch memory banks, a cartridge could provide only 16K of program ROM. *Sinclair User*'s reviewer identified the missing switching facility as a drawback. The contemporary catalogue included [*Jetpac*](/vault/games/jetpac), *Cookie*, *Hungry Horace*, *Chess* and *Backgammon*. [Ultimate Play the Game](/vault/companies/ultimate)'s early 16K releases fitted this format. ([December 1983 report and review](https://worldofspectrum.org/hardware/feat6.html).)

Sinclair's instruction card told owners to insert or remove cartridges only with the power off. Once fitted, the program started automatically at switch-on. The rear expansion connector accepted a ZX Printer only; other peripherals had to sit between Interface 2 and the computer. That included Interface 1, which controlled the [Microdrive](/vault/hardware/sinclair-microdrive). The two interfaces could be used together. ([Instruction card](https://worldofspectrum.net/pub/sinclair/hardware-info/z/ZXInterface2_Manual.html), “Connection” and “ROM software cartridges”.)

## A joystick that presses number keys

The joystick sockets looked familiar, but software compatibility depended on how the computer read them. Interface 2 presented each stick as five number keys:

| Action | Joystick 1 | Joystick 2 |
|---|---|---|
| Left | 6 | 1 |
| Right | 7 | 2 |
| Down | 8 | 3 |
| Up | 9 | 4 |
| Fire | 0 | 5 |

Sinclair's programming instructions gave `IN 61438` and `IN 63486` for reading the two sticks. Unlike `INKEY$`, these reads could detect a direction and fire together. A program needed to understand those inputs, or let the player redefine its keys; having a physically suitable plug did not make a Kempston-only game compatible. ([Instruction card](https://worldofspectrum.net/pub/sinclair/hardware-info/z/ZXInterface2_Manual.html), “Joystick programming”; *Sinclair User*, December 1983 review.)

The [Spectrum hardware ports reference](/vault/reference/zx-spectrum-hardware-ports) follows those keyboard-row inputs into the later +2 and +3 joystick sockets. The cartridge story belongs alongside [copy protection](/vault/technologies/copy-protection): ROMs avoided cassette loading, but manufacturing cost and the 16K limit made them a different proposition from cheap tapes.
