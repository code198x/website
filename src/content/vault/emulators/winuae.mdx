## Overview

**WinUAE** is the gold standard for Amiga emulation, offering cycle-accurate emulation of the entire Amiga range from the A500 to the A4000. Maintained by Toni Wilen since 2000, it supports virtually every Amiga hardware configuration, peripheral, and software protection scheme. For Amiga preservation and development, WinUAE is the reference implementation.

## Fast Facts

- **Based on:** UAE (Unix Amiga Emulator)
- **Maintainer:** Toni Wilen
- **Platform:** Windows
- **First release:** 2000
- **Accuracy:** Cycle-accurate
- **Cross-platform variant:** FS-UAE

## Emulation Capabilities

| Component | Emulation |
|-----------|-----------|
| **CPUs** | 68000 through 68060 |
| **Chipsets** | OCS, ECS, AGA |
| **Custom chips** | Agnus, Denise, Paula, Copper, Blitter |
| **Memory** | All configurations |
| **Peripherals** | Drives, CD-ROMs, SCSI, networking |

## Key Features

What makes WinUAE definitive:

- **Cycle-accurate** - Timing matches real hardware
- **Configuration options** - Every Amiga variant
- **Debugger** - Comprehensive development tools
- **Save states** - Snapshot any moment
- **Hard drive emulation** - HDF files, directory mounting
- **RTG graphics** - High-resolution Workbench

## Copy Protection Support

WinUAE handles protected software:

- Disk-based protection schemes
- Rob Northen Copylock
- Weak sector protection
- Timing-based protection
- Works with Kryoflux dumps

## Development Use

Essential for Amiga developers:

- Test without real hardware
- Debugger with breakpoints
- Memory inspection
- Copper list debugging
- Performance profiling

## FS-UAE

Cross-platform alternative:

- Based on WinUAE emulation core
- Linux, macOS, Windows
- Modern UI
- RetroArch core available
- Same accuracy, different interface
