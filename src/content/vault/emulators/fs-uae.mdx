## Overview

FS-UAE built upon the WinUAE emulation core to provide user-friendly Amiga emulation across Windows, macOS, and Linux. The emulator integrates with the OpenRetro game database for automatic configuration, supports WHDLoad for hard disk game installation, and offers modern conveniences like shader support and controller configuration while maintaining emulation accuracy.

## Fast facts

- **Core:** based on WinUAE emulation code.
- **Platforms:** Windows, macOS, Linux.
- **Features:** game database integration, WHDLoad support.
- **Configurations:** A500, A1200, A4000, CD32.
- **Modern amenities:** shaders, netplay, controller support.

## User-friendly features

What FS-UAE adds:
- **OpenRetro database:** automatic game configuration.
- **Launcher:** graphical game selection interface.
- **WHDLoad integration:** run games from hard disk images.
- **Controller mapping:** modern gamepad support.

## Emulation capabilities

What it emulates:
- **Chipsets:** OCS, ECS, AGA.
- **CPU:** 68000 through 68060.
- **Sound:** Paula, CD audio.
- **Peripherals:** joysticks, mice, CD-ROM.
