## Overview

*Advanced Computer Entertainment* stood apart from platform-specific magazines. Covering all major systems with consistent review standards, ACE brought a mature perspective to game criticism. Its percentage scores and detailed analysis influenced how games were evaluated across the industry.

## Fast facts

- **Publisher:** Future Publishing.
- **Run:** 1987–1992.
- **Focus:** Multi-format gaming.
- **Approach:** Serious criticism.

## Editorial philosophy

| Principle | Implementation |
|-----------|----------------|
| Platform agnostic | Same standards across systems |
| Mature tone | Assumed intelligent readers |
| Critical analysis | Detailed assessments |
| Percentage scores | Granular ratings |

## Coverage format

| Section | Content |
|---------|---------|
| Reviews | Cross-platform comparisons |
| Features | Industry analysis |
| Previews | Upcoming releases |
| Technical | Hardware coverage |

## Review approach

| Aspect | Detail |
|--------|--------|
| Scores | Percentage system |
| Categories | Graphics, sound, playability |
| Comparisons | Version differences noted |
| Length | Substantial analysis |

## Multi-format advantage

ACE could compare:
- Same game across platforms
- Platform-exclusive titles objectively
- Technical implementations
- Value propositions

## Staff

Notable writers who brought journalistic rigour to game coverage, influencing future publications.

## Design quality

Magazine presentation:
- Professional layout
- Quality screenshots
- Clean typography
- Mature aesthetic

## Market position

| Audience | Appeal |
|----------|--------|
| Multi-system owners | Practical guidance |
| Serious gamers | Trusted analysis |
| Adults | Mature content |
| Industry | Professional coverage |

## End of publication

Folded into other Future titles as market fragmented and platform-specific magazines dominated.

## Influence

ACE established:
- Multi-format review standards
- Serious game journalism model
- Percentage score precision
- Comparative analysis value
