## Overview

The game that built a genre. Before Dune II, real-time strategy didn't exist as we know it. Westwood Studios combined resource harvesting, base construction, and unit production into a template so effective that every RTS for the next two decades followed it. The spice must flow—and harvesters, refineries, and tank rushes became gaming vocabulary overnight.

## Fast facts

- **Developer:** Westwood Studios.
- **Year:** 1992.
- **License:** Frank Herbert's Dune.
- **Innovation:** RTS template.
