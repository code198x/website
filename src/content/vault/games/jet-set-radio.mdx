## Overview

Style as substance. Jet Set Radio's cel-shading made 3D graphics look hand-drawn—a technique that would spread across the industry. The game beneath the visuals matched: inline skaters tagged Tokyo-to with graffiti while evading police, set to an eclectic soundtrack mixing J-pop, hip-hop, and funk. The Dreamcast had found its aesthetic manifesto.
