# Raster Bars

**Raster bars** are the "Hello World" of demoscene effects - horizontal color bars that move smoothly across the screen.

## The Technique

Raster bars work by racing the beam:

1. Wait for specific scanline
2. Change background color register
3. Repeat for each bar
4. Restore original color

## Platform Implementation

### Commodore 64

```assembly
loop:   lda $d012      ; Wait for raster line
        cmp #$80
        bne loop
        lda #$01       ; Set new color
        sta $d021      ; Background register
```

### Amiga

```assembly
COPPERLIST:
    dc.w $8001,$fffe  ; Wait for line $80
    dc.w $0180,$0f00  ; COLOR00 = red
    dc.w $8101,$fffe  ; Wait for line $81
    dc.w $0180,$00f0  ; COLOR00 = green
```

## Evolution

From simple bars to complex effects:

- Sine wave movement patterns
- Plasma effects with gradients
- Combining with sprites and scrollers
- Full-screen color cycling

## Learning Value

Raster bars teach fundamental concepts:

- Display timing and synchronization
- Hardware register manipulation
- Optimization for smooth animation
- Creative use of limitations
